# An Omitted Mode Is a Rare Rule: The Sampling-Verification Danger Law in Continuous Code World Models

## Insight
连续 code world model 通过 N 条随机轨迹验收时，漏掉概率为 r 的关键 mode 的概率精确为(1−r)^N；planner 却会主动把查询推到该稀有边界，故随机 gate 覆盖与部署查询分布严重错位。光滑误差受 Lipschitz 体积下界约束，离散 reset/mode 没有这种“暴露预算”。

## Motivation
LLM生成可执行动力学代码并经样本验证，看似可靠，但连续控制中的罕见规则一旦遗漏会被规划器系统性利用。问题直接关系 code WM 的证书含义。

## Method
构造三类 hybrid instruments 与mode-blind可执行模型，推导采样危险律、localization bound和class-relative version-space certificate；真实GPT-5.x多轮生成/干预，独立重评分1034 artifacts，并用planner exploitation和mitigation sweep验证。

## Experiment
1D clamp 在111个含mode样本中修复105次；2D region 0/156恢复，8种targeted intervention仍失败。被接受的盲模型在边界处遭近乎全回报 regret；声明模型类后20/20拟合，18/20所有sample-consistent circles在容差内。宽泛gate仅覆盖约2%的实际planner queries。

## Value
非常重要的审计结论：随机转移一致性只证明样本一致，不能认证planner安全；对代码世界模型、模拟器生成和稀有事件benchmark值得精读。

## Strengths
闭式危险律、理论边界、真实LLM大规模artifact审计和正/负对照齐全；明确区分可识别性与prompt修复。

## Weaknesses
92页且主要是人为instrument；真实复杂环境与代码生成分布差异大；certificate依赖声明模型类；尚未给出通用、廉价的主动验证算法。

## Future Work
planner-aware coverage、主动边界探测、hybrid mode class发现及真实控制代码审计。
