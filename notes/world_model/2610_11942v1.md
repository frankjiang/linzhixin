# Right Screen, Wrong Transition: World Models as Verifiers for GUI Agents

## Insight

**观察**：相同的登录界面，点击“登录”后出现是正常转移，点击“查看订单”后出现则可疑；只看结果画面无法区分。**推论**：世界模型若直接预测下一观测的表征，可把预测残差作为逐步验证信号：残差大小检测“是否违背预期”，方向再辨识“是否有害”。作者用每个登录界面在合法/劫持情境中像素完全相同的成对基准证明结果屏检测理论上只有 0.5 AUC，并实测潜预测器达到 0.987。

## Motivation

GUI 代理的风险往往存在于“动作→结果”关系而不是静态屏幕。现有 GUI 世界模型输出文本、代码或图像，还需第二个模型判断与真实结果是否一致，时延高。验证器需要可直接与观测比较的、动作条件未来表示；这个需求与 JEPA 式隐式预测相契合，但应用场景与视频/3D 物理世界不同。

## Method

- DINOv2 ViT-B/14 编码 448×224 屏幕为 512 个 patch token；12 层 Transformer 接收当前屏幕与动作类型、文本和触摸坐标，预测下一屏表征，EMA 编码器提供目标。触摸坐标与视觉 patch 共用二维位置基。
- 1.85M 真实 GUI 转移自监督训练，变更 patch 的 Smooth L1 损失权重为 8，并加方差/协方差防坍缩与逆动力学头；后期用 2–3 步递归训练。推理无解码器。
- 观测下一屏后，以 `1−cos(预测,观测)` 为无攻击标签的完整性分数；仅在判别危害时，用残差及动作嵌入训练线性头。运行路径约 173M 参数，261M 是训练图规模。

## Experiment

- RSWT-Bench：222 个像素相同的合法/劫持登录结果成对出现，总计 966 转移；附无害但意外的结果、良性替换等控制组。主指标成对 AUC，另测 Swap、Cred 与危害 AUC。
- 无监督完整性分数 RSWT 0.987 AUC、222 对中正确排序 219 对；gWorld-8B 为 0.885，Code2World 0.870；单 A100 每次 17.1 ms、0.408 TFLOPs。危害判别中残差大小仅 0.513 AUC，监督线性头 0.953。
- 未来表征相似度 0.618，高于与当前屏 0.245；相同来源候选中后继检索 R@1 68.3%，近邻训练转移基线 44.6%；替换动作、递归十步和较小模型消融支持确实在预测状态。闭源 VLM 的请求时延未纳入本地 A100 对比。

## Value

可借鉴的核心是“隐式世界模型用于在线校验实际后果”，以及分别解释残差范数与方向；可迁移到视频世界模型的动作执行监测、模拟器偏差检测。不过论文没有评估物理视频、3D 状态或规划。

## Strengths

像素相同结果的配对设计严格隔离屏幕外观捷径；对预测是否复制输入、是否记忆训练集、是否依赖动作都有诊断；低时延结果清晰。

## Weaknesses

基准主要是凭证页劫持，结果屏选择和真实开放世界攻击分布可能不同。无害/有害区分需要监督数据；把余弦误差当异常分数可能受正常界面变化影响。像素相同配对保证只针对结果屏分类器，不能证明其他转移模型一定劣于本法。

## Future Work

作者建议作为低成本逐步门控，触发时再调用渲染器或 VLM；尚需量化自适应攻击能否伪造模型表征中的合理结果，并在更开放的 GUI 变化下验证误报。

## Rating

创新度评分：3/5 - 以 JEPA 式未来表征做转移验证及成对基准有明确新用途，网络本体较常规。
相关度评分：2/3 (Related) - 隐式预测和残差读出可直接借鉴，但研究对象是 GUI 而非视频/3D 物理世界。

## TL;DR

用动作条件潜表征预测下一屏并以残差验证转移，成对登录界面测试达高精度；隐式模型的新用途可选读。
