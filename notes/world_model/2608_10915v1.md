# ComBodied Agents: a New Paradigm of Human-Centric Agentic AI

## Insight
若代理长期改变的是人的状态，仅优化任务完成会漏掉依赖、操纵和能力退化；因此“人本身的可纠正状态轨迹”应成为模型、干预和评价对象。作者据此把 Personal World Model 定义为目的受限、个体特定、带不确定性的干预条件事件动力学模型，并把预测与行动授权严格分开。

## Motivation
数字代理改变软件状态，具身代理改变物理状态，但二者通常不建模一个人的长期生理、认知、情绪、行为和关系变化。论文试图统一健康助手、陪伴代理、可穿戴设备和机器人支持。议题重要，尤其涉及长期安全与自主权，但目前主要是概念框架而非经验证的方法。

## Method
提出 Combodied 闭环：事件级多模态感知重建个人事件；可纠正的纵向记忆形成状态后验；PWM 在候选用户决策、代理干预和环境变化下预测未来状态/事件/结果分布；admissible intervention policy 再以同意、安全、可逆、可控和升级规则筛选行动，反馈继续更新记忆与模型。作者还给出 edge/cloud 路由、分类法、场景化基准与 agency-preservation 指标。核心是系统设计契约，没有实现具体模型。

## Experiment
无训练、数据集或实证结果。论文仅梳理现有个性化、长期记忆、健康与可穿戴资源的覆盖缺口，并提出未来 CombodiedBench：同时评价预测校准、干预反应、漂移、物理安全、人类结果和自主权，严重安全失败不得被平均指标抵消。

## Value
最大价值是厘清 personal memory、personalized agent、generative agent 与 action-conditioned PWM 的边界，并强调预测收益不等于行动许可、写出 $do(\cdot)$ 也不等于个体反事实已识别。这对高风险长期代理治理有启发，但与视频/3D/JEPA/Dreamer 世界模型仅在抽象原则上相通。

## Strengths
- 对 PWM 的功能契约、因果识别边界和不确定性要求定义清楚。
- 把自主权、同意、可逆性和不干预纳入闭环，而非事后伦理附录。
- 系统性列出个人模型的多时间尺度、边云架构和基准缺口。

## Weaknesses
- 38 页框架几乎没有可证伪技术命题、实现或实验。
- “新范式”很大程度是个人数字孪生、因果个性化、长期记忆和安全策略的重新组织。
- 人类状态难观测、强混杂且跨时间漂移，论文没有给出可行识别或数据采集方案。
- 指标体系庞杂，如何聚合、验证 agency preservation 仍不明确。

## Future Work
作者提出稀疏纵向数据下的个体动力学与因果干预学习、agency-aligned policy、可信 edge-native 个人基础设施、多代理协调、跨文化/全生命周期评测，以及场景化 CombodiedBench。

## Rating
创新度评分：2/5 - 概念整合全面且边界意识强，但缺少方法实现和验证，技术贡献有限。
相关度评分：1/3 (Tangential) - 使用 action-conditioned Personal World Model 概念，但研究对象和方法不属于目标视频/3D/隐式世界模型。

## TL;DR
提出以个人状态轨迹和自主权为中心的代理框架，概念严谨但无实现验证，对目标方向可跳过。
