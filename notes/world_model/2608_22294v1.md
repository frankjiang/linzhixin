# Beyond Instance Slots: Semantically Rich World Models for Physical Interaction Planning

## Insight

观察是：同样的对象实例在不同任务中承担的因果角色不同，仅按实例分槽会让动作生成和未来预测缺少共同语义。作者据此将潜变量绑定为 gripper、target、goal、relation、phase 五类任务角色，并用“候选未来是否满足角色级谓词”选择和修复动作。LIBERO 中语义选择器把成功率从角色模型候选 0 的 62.8% 提到 75.3%，再以违规后缀重采样升至 83.0%，支持“可读的任务角色可成为规划接口”这一推论；但证据限于带有角色监督的仿真任务。

## Motivation

潜空间世界模型虽能预测未来，却常只优化像素/特征误差，难以回答“抓住了目标吗、关系是否维持、该修复哪段动作”。既有 LeWM 和实例槽模型将实体分开，但不表达实体相对任务的功能，也无法把预测直接用于候选筛选和局部修复。对长程机器人操作而言，这是影响可解释规划和错误恢复的关键问题。

## Method

在约 15M 参数的 LeWM 主干上引入软实体查询，可选用 GroundingDINO+SAM/SAM2 掩码作为带 dropout 的注意力先验；随后将实体绑定为五个任务角色。Future Motion（FM）头一次生成 K=4 个动作块；动作条件转移 Transformer 在多个子时域预测接触、抓取、关系建立/保持、夹具状态和阶段变化。训练加入跨轨迹、打乱和反转等 hard negatives。推理时语义选择器给四个候选排序，检测首次谓词违规并只重采样其后的动作后缀。完整模型 45.4M 参数。创新点是把语义状态、动作生成、评价与修复串成统一潜态接口，而非新的底层动力学范式。

## Experiment

在 LIBERO 的四个仿真套件评测长程成功率。平均成功率：LeWM 候选 0 为 45.5%，单体选择器 50.5%，实例槽选择器 55.8%；角色模型候选 0 为 62.8%，随机四选一 61.8%，固定规则 64.8%，语义选择 75.3%，完整重采样 78.5%，违规后缀修复 83.0%；角色 oracle 为 89.5%，而 LeWM oracle 为 68.0%。无掩码、软掩码先验、破坏掩码和 oracle 掩码的 rollout 成功率分别为 72.6%、75.1%、70.8%、78.4%。去掉 hard negatives 后排序率由 78.2% 降至 53.7%，去掉语义头降至 60.8%。状态表达逐级增强时成功率由 55.0% 升至 62%、68%、73%、83%。迁移实验中 Object→Goal 微调 74.6%，高于从零训练 66.3%；LIBERO-10 为 58.7% 对 50.6%，但 Object→Spatial 微调 72.1% 与从零 72.8% 持平。A100 上生成/评分约 30.2/7.3 ms，峰值显存 9.2 GB。

## Value

论文最有价值之处是把“预测未来”变成可检查、可选择、可局部修复的控制组件，说明语义结构可能比单纯增大潜态容量更直接地提升闭环成功率。对对象中心 3D/视频世界模型，可借鉴角色绑定、谓词保持和 violation-aware repair；待解决的是如何从视觉与语言自动归纳开放式角色，而非依赖固定本体。

## Strengths

系统闭环完整，比较了单体、实例槽和角色状态，并报告候选、oracle、选择、重采样和后缀修复的逐级收益；hard-negative、掩码质量和语义头消融较有诊断性。推理代价、参数量以及多个迁移设置也有量化，核心收益不只来自一张总表。

## Weaknesses

所有结果都来自 LIBERO 仿真，没有真实机器人、感知噪声和安全评估。五角色本体及接触/阶段/谓词标签依赖任务规格或额外标注，尚不能处理可变数量对象、双臂、可变形物体和工具。论文把状态容量与监督语义同时逐级改变，不能完全归因于“角色”本身；复杂 LIBERO-10 的零样本成功率仅 27.9%。关键训练超参数、时域尺寸和 rollout 数未在正文充分给出，而后缀修复还增加多次生成调用。

## Future Work

作者明确讨论了可变基数图结构、更丰富的触觉与阶段信号、真实物理平台和安全验证。合理推断还需用无人工角色标签的开放词汇绑定、等容量对照及遮挡/检测误差压力测试，判断收益是否能扩展到真实 3D 交互。

## Rating

创新度评分：3/5 - 角色化潜态与语义筛选、局部修复的组合有实质创新，但依赖手工本体和强监督，尚非新范式。
相关度评分：3/3 (Core) - 直接研究对象中心潜空间世界模型及其机器人交互规划用途。

## TL;DR

以任务角色化潜态统一动作生成、语义筛选与局部修复，仿真证据扎实，值得精读。
