# EMPIRIC: Experiment-Driven Learning of Residual World Models for Robot Planning

## Insight
给定刚体引擎仍会缺少胶水固化、风力、加热等整类机制；相同可见场景也可能因隐藏历史产生不同结果。作者据此把新机制写成带隐状态的可执行残差程序，并通过主动实验识别参数。五类模拟任务的消融显示显式不确定性尤其能避免不可逆动作失败；这是实证结论，而非一般性最优性证明。

## Motivation
场景重建无法自动恢复未知物理机制；纯学习或从零写模拟器又浪费已知接触与运动先验。目标是在少量、嘈杂交互中发现缺失机制、推断不可见状态，再用于跨任务规划。机器人世界模型中这一问题关键，但论文使用符号物理引擎而非学习视频/3D 潜表示。

## Method
编码代理继承已给定场景几何与刚体引擎的模拟器，写 Python hook 增加力、约束、温度/水量等变量及递归隐状态；同一更新同时用于模拟和真实观察历史。记录动作观察后，回放轨迹拟合参数的均值场近似后验，并由噪声观测估计场景状态。候选技能序列在参数与状态联合抽样下反复模拟，以成功概率选择执行；也可用谓词读数对参数的互信息选择实验。执行后检查谓词，失配时重估参数或改写机制程序。

## Experiment
五个 PyBullet 桌面域：多米诺、胶水桥、气球、水壶加热、风扇；每域五个种子，训练后测试，计环境交互步数。EMPIRIC 解决 25/25 次完整运行，直接代理、给场景的直接代理、自写独立模拟器分别为 16/25、14/25、16/25；与三者的总体差异 Fisher 检验 p≤0.002。给真值动力学的 oracle 也为 25/25；去掉自动参数信念拟合为 20/25，去掉显式不确定性为 21/25，气球任务尤其下降至 2/5 和 3/5。单次真实机器人案例中，两次风扇实验后学到风力和多米诺质量，以级联撞击完成目标；预测滑行 10.1±2.3 cm，实测 9.9 cm。附录显示参数后验由加权回放误差构造，含近似与模型失配筛查。

## Value
说明世界模型可作为可编辑的“物理先验+新机制+隐状态”系统，而非完全端到端视频生成器；对研究可交互、可诊断的 3D 物理世界模型很有启发，值得精读。下一步应将场景几何与可观测特征也纳入学习。

## Strengths
显式处理机制发现、参数不确定性和部分可观测隐状态；基线、oracle 和消融完整；任务按训练到测试的持续协议评价交互成本，真实机器人给出初步验证。

## Weaknesses
实验预给精确场景几何、对象特征和技能库，视觉建模负担较轻；真实机器人仅一例。计算成本高，单次运行中位数 424 次模拟展开、162 轮语言模型调用、107 分钟；结果也依赖编码代理能力与程序接口。参数后验采用均值场及回放近似，概率校准尚不明。

## Future Work
作者明确提出从感知中重建并修订带不确定性的几何、关节与对象身份，以及自动提出和检验图像特征提取器；概率动力学也留待后续研究。

## Rating
创新度评分：4/5 - 把可编辑残差机制、隐状态、贝叶斯拟合和主动实验闭环整合为可运行机器人世界模型，实证强；基础组件多有先例。
相关度评分：2/3 (Related) - 物理/3D 世界模型与交互规划密切相关，但不是目标中的视频生成或 JEPA/Dreamer 表示模型。

## TL;DR
代理通过实验给刚体引擎编写缺失物理机制并维护隐状态信念，显著减少机器人试错；对可编辑3D世界模型值得精读。
