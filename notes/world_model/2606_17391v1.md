# NarrativeWorldBench: A Frontier-Saturated Benchmark and a Latent World Model for Long-Horizon Co-Creative Audio Drama

## Insight
论文 insight 是长篇叙事不是普通 long-context retrieval，而是部分可观测的 latent state process：人物关系、伏笔、世界规则、主题动机等状态无法从局部上下文完全恢复。显式结构化 latent world state 可以减轻长时遗忘。

## Motivation
解决 200-800 集音频剧的长时结构一致性和共同创作控制问题。同行 long-context benchmark 主要测检索/总结，故事生成方法多为 plan-and-write 或 search。问题在叙事生成中重要，但与用户的视频/3D/隐式物理世界模型方向基本无关，只能类比 latent state maintenance。

## Method
提出 NarrativeWorldBench，9 个叙事结构指标、h={10,20,50,100,200} horizons、跨 4 种 Indic 语言。N-VSSM 在 Mamba-2 8B decoder 上加入 256 维 narrative latent state，每个 scene boundary 用 event tuple 更新 posterior，并通过 low-rank adapter cross-attention 条件化 decoder。Cultural Transfer Function 是对 latent 的 2 层 MLP residual transform。

## Experiment
评测 21 个 LLM。闭源/推理模型在 h=50 plot-beat F1 饱和于 0.78-0.81，h=200 相比 h=10 下降约 0.20；N-VSSM 保持 0.84 以上。去掉 latent posterior 在 h=200 掉 0.11，替换 Mamba-2 为 transformer 掉 0.06。12 位专业作者、240 trials 中，N-VSSM 在 long-arc consistency 上 71% 被偏好，controllability 高 +1.3 Likert。

## Value
对用户方向只有抽象启发：长时世界状态需要显式 latent state 和事件驱动更新。但领域是纯叙事/NLP，无视频、3D、物理或 embodied dynamics。可跳过。
