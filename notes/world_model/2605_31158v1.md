# Light Interaction: Training-Free Inference Acceleration for Interactive Video World Models

## Insight
交互式视频世界模型的推理瓶颈来源于三个方面：不断增长的上下文记忆、二次方注意力复杂度、重复去噪步骤。核心洞察：交互本身提供了自适应计算的天然信号——探索新区域时可丢弃空间记忆、局部动态平稳时可压缩时序上下文、重访已知区域时可复用早期去噪输出。

## Motivation
- 问题：交互式视频世界模型（如HY-WorldPlay）的长轨迹推理计算开销极大
- 需求：实时游戏模拟、虚拟场景导航、embodied AI训练都需要低延迟推理
- 约束：不能重新训练模型（training-free），需保持视觉质量

## Method
- **自适应上下文管理**：根据轨迹类型（新探索vs重访）动态调整空间记忆和时序上下文长度
- **去噪缓存加速**：重访熟悉区域时复用早期去噪步骤的模型输出，跳过冗余计算
- **3D块稀疏注意力**：硬件-软件协同设计的稀疏注意力，配合定制Triton kernel实现
- 三个模块可独立使用也可组合，均无需模型微调

## Experiment
- HY-WorldPlay：2.59x加速，FVD/FID/SSIM与原始模型接近
- Matrix-Game-3.0：类似加速比，视觉质量保持
- 消融：各模块独立贡献分析，上下文管理和去噪缓存贡献最大
- GPU利用率和内存占用显著下降

## Value
工作聚焦于推理效率优化，不涉及世界模型本身的建模能力提升。方法是实用的工程优化，对部署交互式世界模型有价值，但缺乏方法论层面的深度创新。
