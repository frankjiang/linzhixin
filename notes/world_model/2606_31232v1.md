# Delta-JEPA: Learning Action-Sensitive World Models via Latent Difference Decoding

## Insight
核心 insight 是 JEPA 式 latent world model 的 collapse 不只是表示常数化，也包括 action-insensitive：不同动作在 latent 中诱导的位移不可分，导致 rollout 对规划无用。论文观察到 endpoint concatenation 的 inverse dynamics 可能走捷径，于是要求仅从 latent difference z_{t+1}-z_t 重建动作，迫使转移几何携带动作信息。

## Motivation
论文解决 reconstruction-free latent world model 在视觉控制中容易学到弱动作敏感表征的问题。Dreamer/PlaNet 类方法重建像素，成本高且包含控制无关细节；JEPA 直接预测 latent 更高效，但容易 collapse。已有 LeWorldModel、PLDM 用 SigReg/VICReg/逆动力学等正则，目标复杂或不能直接约束转移差分。该问题是隐式世界模型的核心问题。

## Method
Delta-JEPA 包含共享视觉 encoder、action-conditioned latent predictor 和 Latent Difference Action Decoder。训练目标只有两项：latent forward prediction 预测 z_{t+1}，以及 LDAD 从 Delta z = z_{t+1}-z_t 重建动作。因为 decoder 只能看位移，模型必须让不同动作产生可区分的 latent displacement。整体避免 pixel reconstruction、冻结 encoder 和复杂分布正则。方法简洁，但本质是逆动力学监督位置的改进。

## Experiment
论文在四个视觉连续控制任务上评估规划，并与 PLDM、Sub-JEPA、LeWorldModel 等 JEPA/latent baselines 比较。主文报告 Delta-JEPA 在规划性能上更强，action-sensitivity analysis 显示动作条件 latent response 更清晰。附录用 physical state probing 和 state-delta probing 检查 latent 是否保留物理状态/变化；在 OGB-Cube 等任务上 Delta-JEPA 对 end-effector/block position 的 probe 指标明显好，但在部分 Push-T block location、DMC Reacher 等变量上并非全面领先。注意：实验支持“动作差分监督有用”，但优势不是所有物理变量都一致碾压。

## Value
对 JEPA/隐式世界模型很值得读：它给出一个低成本、目标清晰的 action-sensitive 正则，适合与现有 latent planner 结合。局限是贡献相对局部，主要是 inverse decoder 输入从 endpoint 改成 displacement；规模和任务还偏小，尚未证明能扩展到复杂视频/机器人长程世界模型。
