# Toward Goal-Agnostic Joint-Embedding Predictive Control of Partial Differential Equations

## Insight
有。论文的 observation 是：JEPA latent dynamics 可以做到 goal-agnostic，但 raw latent L2 并不自动等价于物理状态误差。推论是：若存在能从 latent 中稳定读出的、对控制目标有唯一性/可观测意义的物理 observable，就应在该 observable 上定义 MPPI cost，而不是要求 learned representation 自身成为校准度量空间。本文用 kinetic energy probe 证明了这一点。

## Motivation
论文解决 PDE 控制中 surrogate dynamics 与任务目标耦合的问题。传统 PDE 控制要么依赖昂贵数值仿真和专门 ROM，要么训练全状态 surrogate/强化学习策略，换目标常需重新设计 reward 或训练。JEPA 提供一种重构无关的 latent world model，可离线学习 action-conditioned dynamics，部署时再指定不同控制目标。问题对隐式世界模型有方法借鉴，但 PDE/流体不是用户的视频/3D主场景。

## Method
模型是 masked JEPA for PDE：输入 21x21x2 Navier-Stokes velocity field，经轻量 2D ViT encoder 得到 256 维 latent；action-conditioned predictor 用 4 个历史 latent/action，自回归预测 12 个 latent step，训练目标是 rollout latent MSE。为避免 collapse，加入 VICReg variance/covariance；为改善几何，加入 temporal straightening；为增强动作敏感性，加入 Delta-JEPA 风格的 latent difference action decoder。

控制时冻结 encoder/predictor，用 MPPI 采样 512 条 action sequences、迭代 3 次、执行第一步。基线 cost 是 latent L2 tracking；本文 cost 是在 rollout latent 上训练 ridge/linear kinetic-energy probe，用 probe 输出与目标 KE 的误差做规划。所有任务共用同一 checkpoint 和 5-step latent horizon。

## Experiment
环境是 PDE Control Gym 2D Navier-Stokes：21x21 网格，标量 action 控制上边界 Dirichlet 条件。离线数据 6,930 条轨迹，每条 200 fields/199 actions，约 92/8 train/val；训练 50k steps 后再 50k 低学习率 finetune。

结果：在默认 benchmark reward 上，latent-L2 MPPI 50 episodes 得分 -12.084，KE-probe MPPI 为 -10.901，late field RMSE 从 0.07650 降到 0.06917；仍弱于 PPO 和 model-based optimization，但优于 SAC。三个 withheld aperiodic targets 上，KE planning 把 pooled late field RMSE 从 0.04687 降到 0.02204，30/30 paired episodes 都更好。固定 KE regulation 中 probe 的 held-out R2 为 0.9891，平均相对误差 2.66%。但 corrupted observation 下 probe 很脆弱，噪声/缺像素会把误差提高到 46-85%。

## Value
对我们有两点启发：第一，隐式世界模型可以把 dynamics learning 与 runtime goal 分开；第二，规划 cost 不必直接用 latent distance，最好接入可校准的物理/任务 readout。局限是它在 PDE 单标量控制上验证，和视频/3D世界模型的观测复杂度、动作空间、部分可观测性差异很大。

## Strengths
亮点是 goal-agnostic JEPA 控制问题定义清楚；明确指出 latent L2 的度量问题；同一 frozen checkpoint 支持 benchmark tracking、aperiodic tracking 和 fixed KE regulation；实验中保留 state-space RMSE 作为独立评估，而不是只看 probe cost。

## Weaknesses
KE 作为 observable 的有效性依赖单 actuator 和窄响应族，不能推广到多模态/拓扑不同流场；probe 对噪声和缺失像素很脆；没有和更强 latent MBRL 或 neural operator 控制做充分公平比较；不是视频或机器人世界模型。

## Future Work
作者提出训练对 corrupted latents 鲁棒的 readout、加入不确定性、寻找更多满足唯一性的 observables、扩展到更复杂 PDE 和更长 horizon。

## Rating
创新度评分：3/5 - JEPA+MPPI+observable probe 是有价值组合，但实验域窄，主要是方法迁移和 cost interface 改进。
相关度评分：2/3 (Related) - 与 JEPA/隐式世界模型控制密切相关，但 PDE 场景不是用户核心方向。
