# GameWAM: A World Action Model for Video Games

## Insight

最有价值的 insight 是 **Low-Frequency Action Source Imprinting（LASI）**。作者观察到，闭环重规划时若反复复用同一高斯 action source，部分 source 会诱发稳定转向偏置甚至原地打转；推论是生成式控制中的 source 不只选择随机动作样本，其低时频结构会被映射为粗粒度相机运动，并在反复闭环中相干累积。论文在固定视觉/历史/状态条件下做 DCT 干预：替换 source 的低频模态后，yaw DCT0 输出以 **94.8%** 概率跟随 donor；将该频段置零移除 **99.25%** 输出方差；低频扰动响应为高频的 3.53–4.58 倍；迭代生成路径把 yaw DCT0 source gain 放大到单次解析路径的 **6.897 倍**。300 条闭环轨迹、16,707 次重规划中，正确 source-action 对齐在 75 个循环平移中排名第一，置换检验 $p=0.001$。这是较完整的“观察—干预—机制边界—闭环验证”链条；但目前只能靠每次重采样减轻累积，尚未消除 source 敏感性。

## Motivation

现有游戏 agent 从画面/任务直接预测动作，没有显式世界演化目标；交互式游戏世界模型则需要外部玩家给动作，不能自己完成任务。已有机器人 WAM 又多针对单一动作制度和较慢的桌面交互，难以覆盖第一人称快速运动、连续鼠标、并发按键、GUI cursor 以及持久游戏状态。GameWAM 试图用一个模型联合训练未来视频与原生键鼠动作，并在密集采样导致“未来视野短、历史跨度短”的约束下维持频繁闭环反馈。问题对视频 WAM 很直接，但论文解决的是低层控制而非高层开放世界规划。

## Method

- **数据**：Minecraft 使用三路同步 observation-state-action 数据：常规 VPT、从同一录像按 MineStudio state change 检测事件并截取的 Event-Anchored VPT、以及脚本生成的 MineStudio GUI 轨迹；动作、状态都按“动作执行前的 state”对齐，过滤空动作时同步删除帧。事件集经重叠/同类邻近过滤和 max-min fair allocation，保留 20 万条 96 帧子轨迹。训练采样混合为 80% event-anchored、5% regular VPT、15% GUI，并在事件前后半径 8 帧内加密采样。ViZDoom 则用 APPO expert 收集四地图轨迹。
- **动作表示**：Minecraft 原生 22 维动作含 pitch/yaw 连续量及移动、攻击、物品栏等二值键；ViZDoom 为 9 维。Minecraft 每个 action timestep 由 router 判断 gameplay/GUI，选择共享 Action DiT 上的模式专属 flow head；相机/光标连续量按模式分别归一化，二值维共享表示并在生成后阈值化。
- **世界-动作架构**：视觉分支从 Wan2.2-TI2V-5B 初始化（5B），Action DiT 为同布局缩窄至 1024 hidden 的约 1B 模型，并由视频权重初始化。两分支用独立噪声做 flow matching。默认采用 Fast-WAM 式 modality-decoupled block mask：视频和动作 target 都读取由 Video DiT 编码的已实现视觉 prefix，但同一未来 block 的 noisy video/action 不互看；因此视频损失会塑造动作所用历史表示，在线 action-only inference 又可省掉未来视频去噪。
- **块循环控制**：224×224 观测每两个 native action 采一帧；每次预测 $P=16$ 个动作，只执行前 $E=8$ 个，再读取真实新帧并重规划，未执行 suffix 丢弃。训练以每 8 步为 anchor 构造重叠的 16 步 teacher-forced 目标；三次执行块组成 24-action cycle。
- **层级历史**：cycle 内用未压缩 KV 保存已真实到达的观测；cycle 结束后 VAE+Conv3D 把执行片段压成 16 token，最近两个片段显式保留。更旧片段以 attention pooling 和带半衰期先验的 gated update 写入两级、每级 4 个 long-term slot，跨 cycle 历史最多 40 token。辅助 loss 让历史预测当前 clean visual feature。预测但未执行的画面永不写入记忆。
- **目标与训练**：视频 flow loss、按连续/二值维分别归约的 action flow loss、router BCE 和 history prediction loss，权重 1/1/0.05/0.5。两 epoch 共 21,900 step、2.79B 有效 token；8×H200、BF16/ZeRO-2、全局 batch 352，约 22 小时。推理用 10 次一阶积分，并在每轮重采样 action source 以缓解 LASI。

创新主要是把原生 gameplay/GUI 路由、predict-long/execute-short 和跨循环压缩记忆整合进视频 WAM；底层 DiT、flow、Fast-WAM mask 与分层 memory 均是已有技术。需要注意：默认在线控制不生成或利用想象出的未来视频，因此并非基于视觉 rollout 规划，而是“未来视频联合训练、动作单独部署”。

## Experiment

- **Minecraft MCU（800+任务）**：Mini 每任务 10 次、Full 每任务 5 次，指标为平均成功率 ASR 与成功 episode 的原生动作步数。GameWAM 在 Mini/Full 平均 ASR 为 **50.7/46.6**，Full 高于 Game-TARS 42.5；三类成功 episode 仅需 138/155/203 步，明显少于表中基线。不同方法的训练数据、输入、动作抽象和模型类别并不一致，作者也明确将其界定为系统级比较；“只在成功 episode 计步”还会产生任务难度选择偏差。
- **ViZDoom**：Battle 1/2、Defend Line/Center 各 50 episode，以平均 reward 比较 Game-TARS、o4-mini、GPT-5、Gemini-2.5-Pro、Claude-4-Sonnet。GameWAM 四图分别为 **43.12/19.02/23.52/15.36**，均高于 Game-TARS 的 18.87/10.04/15.24/14.00；Battle 2 与 Defend Center 并非对所有大模型 baseline 都最佳（如 GPT-5 为 10.04/13.46）。
- **核心消融（MCU Mini）**：完整模型 50.7；仅动作监督 **35.7**，较粗时间采样 36.7，无事件锚采样 38.0，统一 gameplay/GUI 分布 38.3，令 $P=E$ 为 41.3，无跨 cycle 历史 46.7。由此，未来视频监督和密集视觉-动作对齐贡献最大，跨 cycle 历史整体作用较小且 embodied 类点估计反而上升。各任务标准差很大，未给多随机种子。
- **mask/效率消融**：默认 modality-decoupled 对 joint within-block coupling 的 Mini/Full ASR 为 **50.7/46.6 vs 46.3/39.6**，在线频率 **12.51 vs 8.12 Hz**。作者观察 joint 模型 action loss 拟合更快、视频更慢且更模糊，将其解释为不对称优化干扰，但明确标为未证机制假说。
- **跨游戏**：Minecraft checkpoint 零样本部署 VoxeLibre，6 个相近低层任务各 20 次，合计 **71/120=59.2%**；无 baseline，且两者共享 voxel 结构，属于有限 transfer diagnostic。
- **LASI**：固定 24 条 condition×16 source 共 384 样本，辅以 donor/zeroing、反向 source、单次 forward、模型路径、frequency selectivity 与 bootstrap CI；闭环还有 300 trace/16,707 replanning step。证据足以证明低频 source 对相机动作的因果影响和迭代放大，但未定位内部层/训练路径，也没有无损的训练时修复。
- **定性案例**：展示 Minecraft 搜索、持续采矿、追击、GUI 精确放置/纠错及 ViZDoom 生存/恢复。作者谨慎声明这些是挑选案例，不表示发生频率。

## Value

对视频世界模型研究，GameWAM 的价值有两层。系统层面证明未来视频辅助监督可以迁移到高频原生游戏控制，并给出较完整的低层闭环工程模板；科学层面则把生成式动作 source 的低频偏置从偶发 bug 提炼成可重复、可干预的 LASI 现象。后者比小幅 MCU SOTA 更有普适启发，可能适用于 diffusion/flow robot policy。另一方面，当前部署省略未来视觉生成，尚未证明“在线想象”优于普通 predictive representation co-training，也未进入 Dreamer 式以世界模型规划/学习策略的范畴。

## Strengths

- 44 页正文/附录披露模型、token、GPU、训练时长、动作接口、采样与评测细节，复现信息较充分，并承诺发布代码、数据、权重。
- 覆盖 gameplay 连续相机、并发按键和 GUI cursor 的同一原生接口，per-step router 允许轨迹中途切换模式。
- 关键组件均有定量消融；未来视频监督带来约 15 点 Mini ASR 增益。
- LASI 分析同时包含固定条件干预、频率对照、置信区间、生成路径放大和大规模闭环统计，论证严谨且边界表述克制。
- 主动给出跨方法不可比性、定性案例选择偏差和物理迁移限制，没有把营销性 SOTA 扩张为架构定论。

## Weaknesses

- MCU 主表是异构系统比较，Game-TARS/OpenHA 等在数据规模、抽象和输入上差异巨大，46.6 对 42.5 不能视为受控架构优势。
- 在线控制不生成未来视觉、也不基于候选视觉未来选动作；“世界模型”主要作为训练正则和历史 encoder，策略/模拟器统一程度有限。
- MCU 方差很大，消融仅报单个最终 checkpoint，缺多随机种子和统计显著性；成功 episode 条件下的步数并非无偏效率指标。
- long-term history 只直接监督视觉可预测性，不保证保留任务、动作、inventory 或因果相关信息；消融增益也较小。
- LASI 的 resampling 只是部署缓解，会降低跨轮确定性且没有根治；效应目前最清楚地局限于连续相机控制。
- 只评数字游戏和低层任务，VoxeLibre 与 Minecraft 结构相近；不能推出对物理接触、一般软件 GUI 或开放世界长程规划的泛化。

## Future Work

作者明确提出五类方向：与高层 planner/结构化 recipe 表示结合；为历史加入 task/action-aware objective、显式 retrieval、跨 cycle credit assignment 与多模态 inventory/action memory；构造具有连贯意图和演化状态的 chain-of-interaction 数据/评测；验证物理控制迁移；设计不压制合法平滑动作与多样性的 LASI 机制级修复。最后一项仍是开放问题，作者测试的频率惩罚、一致性目标和加强条件监督都出现性能权衡。

## Rating

创新度评分：3/5 - 首次把原生游戏/GUI 纳入 WAM，并提出扎实的 LASI 新现象；但控制架构主要是现有 DiT、Fast-WAM mask、receding horizon 与层级记忆的组合，在线也不使用未来视觉推演。

相关度评分：3/3 (Core) - 直接研究视频-动作联合世界模型、动作条件视觉预测和闭环生成式控制，虽场景是游戏，仍属于视频世界模型核心方向。

## TL;DR

原生键鼠WAM以块循环统一视频与动作，并揭示LASI源偏置；方法增量、分析扎实，值得精读。
