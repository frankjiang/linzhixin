# World Machine: Towards Generative World Modeling for Time-Series

## Insight
Observation：时间序列背后存在隐含的"世界状态"（如物理系统的位置/速度），但传统时序模型仅建模观测序列本身。设想：用transformer自回归地建模观测+潜在世界状态的联合序列，让世界状态在训练过程中自发涌现（"State Discovery"），无需显式标注。

## Motivation
问题：能否从纯观测时序中学习到隐含世界状态的生成式世界模型？本文提出一个概念框架，将世界模型形式化为(observations, world states)的联合自回归生成，用decoder-only transformer实现。目标是使模型能推断隐状态、预测未来、补全缺失观测。

## Method
核心设计：
1. 序列格式：交替排列observation token和world-state token，自回归预测
2. State Discovery训练协议：world state初始化为零，每个epoch结束后用模型当前预测更新target state，迭代收敛
3. Sensory Masking：随机mask observation token，迫使模型通过world state桥接信息
4. Sequence Breaking：随机切断序列连续性，促进world state编码长程依赖
5. Local Mode：只用局部窗口预测当前状态（无未来信息泄漏）
6. 架构：GPT-2 style transformer + ALiBi位置编码

创新程度：概念有趣但实现极其初步。State Discovery的收敛性无理论保证，仅在1D合成数据上验证。

## Experiment
- 仅在Toy1D数据集上测试：阻尼弹簧系统，观测=位置，真实状态=速度
- 结果：模型学到的world state与真实速度高度相关（视觉对比）
- 能完成：未来预测、缺失数据补全、状态推断
- 无定量对比baseline，无真实数据实验，无scale-up验证

## Value
概念论文，提出了一个将世界状态学习形式化为联合自回归生成的有趣思路。但(1)仅1D合成验证，(2)State Discovery无收敛保证，(3)无法扩展到高维/视觉，(4)与现有latent world model（Dreamer/JEPA）的优势未讨论清楚。对我们的直接价值极低。

创新度：2⭐
相关度：1 (Tangential)

## TL;DR
概念性工作：用transformer自回归建模观测+潜在世界状态，通过State Discovery迭代让隐状态涌现，仅在1D合成数据验证。过于初期，可跳过。
