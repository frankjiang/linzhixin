# Sparse Planning in Visual World Models via Cost Gradients

## Insight

观察：预测误差小的区域也可能决定控制结果，注意力权重亦不稳定。推论：按**目标代价对输入 token 的敏感度**选位置，比按预测质量选位置更适合规划。作者用一阶扰动上界说明 top-K 梯度范数可最小化被丢弃 token 的局部代价影响；这不是删 token 后多步规划的误差保证。实证还发现，同一选择器在 AdaLN 与动作拼接架构上的表现相反，说明动作响应在稀疏输入下是否稳定同样关键。

## Motivation

DINO-WM/JEPA-WMs 的空间 token 模型要在 CEM 中反复展开候选动作，256 token、6 步、300 候选、30 轮使单次规划昂贵。随机稀疏化或按注意力/预测误差筛选没有直接对齐到达目标的代价。目标重要且是实际推理瓶颈。

## Method

冻结 DINOv2 ViT-S/14 编码器与六层预测器。每个环境步先以零动作全 token 预测一步，计算预测特征与目标特征的平方距离，对最近观测帧各 token 求梯度范数，保留 top-128/256；观测、目标及整个 CEM 搜索共用原位置索引的子集，下一个环境步重选。只增加一次前后向，不重训模型。核心创新是把规划目标用作推理时稀疏选择信号；梯度显著性本身是既有技术。

## Experiment

- 四个模拟控制任务、每方法 3 个评测种子且每种子 96 回合；50% token 时成功率均值：Full 73.5%，COSTGRAD 77.3%，Random 58.1%，预测注意力 65.2%。分任务 COSTGRAD 为 PointMaze 86.2%、Wall 92.0%、PushT 65.2%、MetaWorld Reach 65.6%，前者略低于 Full 88.2%，其余高于 Full。
- 单 H100 的 Wall 规划步耗时 88.61→34.04 秒，提速 2.60 倍，选择开销 27.53 毫秒；将 CEM 轮数减半后约 17 秒、成功率 92.0±5.1%，但只在 Wall 测此组合。稀疏率低于约 25% 时性能明显下滑。
- 匹配训练条件的动作拼接预测器在 Wall 的 Full/COSTGRAD/Random 为 85.1/80.0/80.2%；相同筛选不再优于随机。动作效果空间分布的 KL 漂移，COSTGRAD/Random 比率在 AdaLN 为 0.29、拼接为 1.33；这是相关性诊断，不直接保证动作排序。

## Value

对已有视觉潜空间模型，提供无需重训的加速基线与目标驱动 token 选择思路。设计稀疏世界模型时须同时评估目标相关性、稀疏展开后的动作响应和真实规划耗时，而不能只看全 token 预测损失。

## Strengths

与注意力、预测梯度、ToMe、随机选择及公开检查点对照；报告真实墙钟时间、CEM 预算配平、稀疏率扫描和架构失败案例，结论边界较清楚。

## Weaknesses

仅四个模拟任务、单一视觉编码器和 CEM；目标选择探针仅看一步、零动作。AdaLN 与拼接的差异未被机制性证明，KL 诊断忽略动作效果的方向和总幅度；多步删 token 对规划排序无理论保证。

## Future Work

作者建议在真实系统、FiLM/交叉注意力/前缀等动作注入方式上检验，并研究稀疏训练、在线适应、学习式选择器及更长时域探针的收益与成本。

## Rating

创新度评分：3/5 - 将目标代价梯度用于固定世界模型的稀疏 CEM，并揭示架构依赖；核心筛选仍是一阶显著性方法。
相关度评分：3/3 (Core) - 直接研究隐式视觉世界模型的目标条件规划与推理加速。

## TL;DR

用目标代价梯度筛选视觉 token，半数 token 保持规划成功率并提速，但依赖动作注入架构；值得精读。
