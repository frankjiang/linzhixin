# WorldRoamBench: An Open-World Benchmark for Long-Horizon Stability of Interactive World Models

## Insight
主要 insight 是交互式世界模型不能只用轨迹级 action following 或单一画质指标评估。观察是模型可能轨迹大致对，但逐帧按键错；也可能开头/结尾正常，中段视觉崩溃；还可能执行了动作但违反物理或忘记场景。论文据此把长程稳定性拆成 Action、Vision、Physics、Memory 四个维度，并设计针对性指标。

## Motivation
论文解决 interactive world models 的长时评测问题。已有 benchmark 多关注短视频质量、prompt following 或轨迹级动作对齐，忽略 per-frame action、非单调视觉漂移、交互物理和 revisit memory。随着 Genie/World Labs/游戏式世界模型发展，评测是否能暴露长时失败本身就是关键问题。

## Method
WorldRoamBench 提供 600+ open-world test cases，覆盖 Nature/Urban/Indoor、FPV/TPV、10-60s WASD/IJKL 连续交互。Action 维度用 ViPE 估计相机轨迹，再离散成 per-frame action，报告 strict/partial accuracy 和 TrajScore。Vision 维度结合 aesthetic、MUSIQ 和 segment-based drift，捕捉中途崩溃。Physics 维度覆盖 mechanics、optics、3D consistency，并带 controllability gate。Memory 维度分 scene memory 和 subject memory：前者用观察/重访段 point cloud reconstruction 对齐，后者用 tracking + Qwen3-VL 判断主体身份、结构、外观稳定性。

## Experiment
论文评测 10+ 开源/闭源 IWM。结果显示没有模型可靠满足四个维度，即使最佳模型也只是中等水平。测试集按维度设计不同 action suite：action 和 memory 避免碰撞等物理混杂，physics 则专门触发碰撞、重力、反射、遮挡、3D consistency。指标体系强调 per-dimension ranking，而不是单一总分。主要贡献是 benchmark 定义、指标设计、案例覆盖和失败模式分析。

## Value
对视频世界模型研究非常有用，尤其适合筛掉“短片好看但长程不可控”的模型。启发是 future video/world model 的评测应同时看可控性、稳定性、物理和记忆，而不是只看 FVD/CLIP/VQA。局限是评估链条依赖 pose estimation、3D reconstruction、VLM judge，可能引入工具误差；此外 benchmark 工作本身不提出新模型。

## Strengths
亮点在于它把WorldRoamBench这类问题转成了可复现的基准，能直接暴露现有模型在核心能力上的短板。

## Weaknesses
不足是评估链条依赖 pose estimation、3D reconstruction、VLM judge，可能引入工具误差；

## Future Work
作者未明确提出具体未来工作；从局限看，后续需要围绕“评估链条依赖 pose estimation、3D reconstruction、VLM judge，可能引入工具误差”补充更大规模验证、跨场景扩展或方法改进。
