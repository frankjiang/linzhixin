# ActionRoPE: action as coordinates for spatially consistent control in planar-camera game world models

## Insight
俯视/等距游戏中，角色动作常对应近似刚性的平面相机位移。同一世界点在不同画面的位置不同，用屏幕坐标 RoPE 会换地址；给 token 坐标加累计相机位移后，同一世界点可共享位置编码。作者用位移测量、往返测试和跨骨干实验验证了这一几何推论；它依赖事先标定动作到相机位移的映射。

## Motivation
常见视频世界模型把动作当 token、特征或调制量，要求模型从数据学出几何位移，容易在速度变化和往返时漂移。对平面相机游戏，这个问题关键且可直接用几何先验处理。

## Method
将视频 DiT 的空间 RoPE 由屏幕位置改为世界位置：当前 token 坐标加累计相机位移（按像素/token 比例换算）。首帧覆盖的世界区域被标为“已知”，新露出区域标为“未知”；CNS 给已知区域更早降噪的 token 级 flow schedule，并加一个约 0.015M 参数的已知性输入通道。控制路径无新增参数，但整个视频主干仍需微调；动作位移来自游戏记录与标定。

## Experiment
在单一 2.5D 游戏采集 50.9 小时，主实验以 Wan2.2 5B 对比 Prompt、Linear、AdaLN、Cross-Attn。指标含速度指令与实测位移回归斜率/R²、角度误差、往返 PSNR/SSIM/NCC/DINO 相似度和像素漂移。完整方法斜率 0.981、R² 0.952、角误差 0.68°、漂移 7.8 px；最强漂移对照 AdaLN 为 22.6 px，降低约 66%。去掉 CNS 后漂移 11.7 px，PSNR 22.81→23.94 dB；附录指出 CNS 收益主要来自训练安排，单改采样无明显收益。50 张风格外首帧上漂移 7.6 px，对照最佳 16.5 px。跨 1.3B–33B 骨干均可工作，但只有主骨干与四类动作注入做同条件对比。

## Value
对视频/3D 世界模型的控制接口很有启发：当动作效果有已知几何结构，应直接作用于空间地址与可见性，而非全交给网络拟合；往返漂移也是有用的世界一致性指标。

## Strengths
控制机制简单，连续位移可精确外推到不同速度；主干同条件对比、往返评测和 CNS 消融具体，附录披露标定质量与 SIFT 测量规则。

## Weaknesses
适用近似刚性的平面场景，无法直接处理缩放、强视差和移动物体；“已知”仅追踪首帧，后来新见区域再访不会被记忆。Prompt/Cross-Attn 对照把速度量化为方向，削弱速度对比的公平性；未验证复杂 3D 自由相机。

## Future Work
作者未提出明确路线；自然扩展是随时间更新已见世界区域，并处理动态对象、视差和非平面相机。

## Rating
创新度评分：3/5 - 利用 RoPE 几何编码已有先例，动作直接写入世界坐标并联动降噪是有效的新组合。
相关度评分：3/3 (Core) - 直接研究可控视频世界模型的空间一致性。

## TL;DR
把相机动作写入世界坐标 RoPE 并按已知区域降噪，明显降低游戏往返漂移；做视频世界模型值得精读。
