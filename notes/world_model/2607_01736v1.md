# Predicting Closed-Loop Performance of Latent World Models: Offline Checkpoint Selection for MPC and Model-Based RL Under Non-Markovian Rewards in LunarLander

## Insight
核心 insight 是 latent world model 的 validation loss 或 open-loop RMSE 不能可靠预测闭环 MPC/RL 表现，尤其在 reward 非 Markovian 或被 shaping 后。Observation 是某些 checkpoint 预测误差继续下降，但闭环控制性能反而崩溃。作者据此提出用控制结构指标，特别是 Reward Observability Fraction (ROF)，来离线判断 checkpoint 是否适合闭环使用。

## Motivation
论文解决 model-based RL 中“选哪个 world model checkpoint”这一实际问题。同行常按验证损失、一步/多步预测误差或 reward prediction error 选模型；这些指标与闭环 planning performance 相关性弱。对 Dreamer/RSSM 类 latent world model 来说，这很关键：世界模型不是为了预测好看，而是为了让 planner/actor 做对。

## Method
作者训练 RSSM latent dynamics，并在 LunarLander 上用 CEM-MPC 和 latent imagination A2C 做闭环评估。离线计算约 40 个结构指标，包括 Jacobian controllability/observability ranks、RCF/OCF/ROF 等。CROF 将 ROF、controllability rank、observability rank、open-loop observation error 组合成 checkpoint score；分数越低越优。

## Experiment
数据为 872 条人工驾驶 episode、180,916 环境步和 100 个 checkpoint。相关性表中 jac_rof_combined 与 MPC return 的 Spearman 约 -0.710，明显强于 validation loss 的 0.090 和 open-loop observation error 的 0.017。checkpoint selection 中 raw CROF-A/B 选到 epoch 280，MPC return +162.8，接近 oracle smoothed epoch 310 的 +153.0，并远好于最小 val loss/reward RMSE 的 +79.3。A2C 上 CROF raw WM 可达 mean +217.5、79 个 perfect episodes，但 worst-case 仍有 -178.9 和 2 次 catastrophe。

## Value
对隐式 world model 很有价值：它提醒我们应以闭环可控性、reward observability 和结构指标选择模型，而不是只看预测误差。对 JEPA/Dreamer 类方法尤其适合做训练监控和早停。

## Strengths
问题小但很关键；把控制理论指标和 latent model 选择连接起来；对比 open-loop loss 的失效很清楚；同时评估 MPC 和 imagined actor。

## Weaknesses
实验只在 LunarLander，环境和 reward 结构特殊；CROF 可能依赖非 Markovian/shaped reward 特性；最优 mean 和最安全 worst-case checkpoint 不一致，部署还需风险指标。

## Future Work
作者提出未来要跨环境验证 ROF/CROF，把 ROF 用作训练 regularizer，并扩展到 A2C checkpoint selection。

## Rating
创新度评分：3/5 - 对 latent world model 闭环评估提出有用结构指标，但验证范围仍窄。
相关度评分：3/3 (Core) - 直接面向 Dreamer/RSSM 式 latent world model 的闭环性能，核心相关。

## TL;DR
用 reward observability 等结构指标选 latent world model checkpoint，闭环导向明确，值得读。
