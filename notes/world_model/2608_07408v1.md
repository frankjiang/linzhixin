# Addressable Memory for Video World Models

## Insight
长视频记忆失败不只是“缓存容量不够”：RoPE 相对距离超出训练范围后，缓存内容虽存在却不可寻址；直接平均已旋转 key 又会因不同相位抵消。把 key 先逆旋转到 canonical 空间压缩，再给每个 summary slot 分配固定、互异且训练内的虚拟位置，可同时恢复可读性和信息量；位置控制实验与相位消融分别验证了两项机制。

## Motivation
自回归视频世界模型靠不断增长的 KV cache 保持视觉世界，实际必须压到固定预算；滑窗遗忘远景，普通压缩又无法支持超训练时域的重访。长期视觉持续性与场景回忆是交互视频世界模型的核心问题。

## Method
WorldTrace 将固定六帧 cache 分成 recent verbatim slots 与 summary slots，按 slot rank 而非真实时间给后者分配 query-relative 虚拟位置，使相对 offset 始终在训练窗口内且不碰撞。WorldTrace-Field 将历史 keys unrotate 到 canonical RoPE 空间、分组平均后在虚拟位置 rerotate，偏向连续一致性；WorldTrace-Landmark 在检测到场景入口时保存 verbatim canonical key，偏向 episodic recall。全程冻结模型、$O(1)$ 内存，单 chunk 仅改 cache writer。

## Experiment
主模型为 1.3B Matrix-Game-2，附加 14B LingBot-World；新 LoopBench 用 ABA/ABCA/ABCDA、路径长度、转向与多次重访评测。48 chunks 时 WorldTrace-Field 的 TempSSIM 0.545 vs 滑窗 0.472（+15.5%），scene drift 0.0295 vs 0.0305；canonical averaging 在四 slots 下把 LatentDiff 0.312→0.233。ABA $N=16$ 的 Landmark PAC 0.864 vs 0.723，$N=32$ 为 0.825 vs 0.627；扩展扫描到 $N=256$ 仍为 0.989。每条件 100 初始场景；A100 上 0.99/1.00 s 每 chunk，对比滑窗 0.95 s，总实验约 100 GPU-hours。

## Value
这是少见的从 positional addressability 而非网络容量解释长期记忆退化的工作，诊断和训练免费修复都很干净。WorldTrace 可直接用于基于 RoPE 的自回归视频模型；更一般的启发是缓存设计必须同时回答“存什么”和“以哪个坐标可被查询”。

## Strengths
- 将位置 OOD 与内容相位抵消分开，给出控制变量实验。
- $O(1)$ 内存、无需重训，运行开销小，易移植到现有 backbone。
- LoopBench 显式测离开后回访，比相邻帧一致性更接近持久世界。
- 包含两种 backbone、并发基线、长时扫描、slot allocation 和资源报告。

## Weaknesses
- 只适用于 temporal RoPE、局部 attention、可直接编辑 KV 的自回归模型。
- Field 平均随时域增长必然模糊细节；Landmark 最多记 $N_s$ 个场景且完全依赖入口检测。
- PAC/CLIP 与 TempSSIM 仍是外观代理，没有 3D 几何、对象状态或动作因果一致性。
- LoopBench 轨迹受控且主要是游戏/相机运动，复杂交互导致的状态变化未充分覆盖。
- verbatim key 的近乎完美长程 recall 可能受精确回访姿态和场景重复协议便利。

## Future Work
作者提出几何/相机位姿对齐的 canonical writer、学习场景入口和 eviction policy、context-extension 微调、用重访监督训练记忆策略，并扩展 LoopBench 的路径和模型覆盖。
