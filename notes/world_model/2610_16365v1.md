# World Models Need a Physical Registry: Learning Internal Predictive States for Physically Plausible World Models

## Insight
观察：把 JEPA 未来表征只作为外部条件或直接对齐视频 token，物理一致性增益有限；生成器缺少可单独监督和读取的未来动力学状态。推论：在视频 DiT 内设置随视频 token 共演化的专用预测槽位，能让预报成为生成过程中的可读内部状态。作者用相同骨干/预算的接口对照验证增益，又以去除预报、去除对齐和只加普通 register 的消融说明预报内容与监督均重要；这仍是经验机制证据。

## Motivation
视频生成器画面逼真却常违反碰撞、流体等物理过程。现有外部运动条件依赖标签，REPA 式中间特征对齐可能仍将外观与动力学混在同一视频流。本文关注预测表示应该存于生成器何处，是视频世界模型结构的重要问题。

## Method
冻结 JEPA 编码器/预测器，用首帧产生未来七个时间位置的特征，加首帧共八个预测槽；时空投影后将槽位接在噪声视频潜变量后，与视频 token 共用 DiT 双向注意力，并按对应视频时间赋 RoPE 坐标。每个去噪步以相同 JEPA 预报初始化槽位，交互后其隐藏态随候选视频改变；在中间层通过读出头，以余弦损失对齐真实未来视频的 JEPA 表征，同时保持原有 flow-matching 视频目标。推理时 PRS 对同一起点的多噪声候选只生成前缀，选取读出与共同预报**角度偏离最大**的候选继续去噪。此选择规则由实验证据支持，并非偏离越大必然越物理的理论结论。

## Experiment
Physics-IQ Verified 评测 I2V/V2V，WorldModelBench 评测指令跟随、物理遵循、常识与总分。控制实验在 66 个中心视角视频微调、132 个左右视角测试：普通微调 I2V/V2V 为 41.3/46.4，REPA 41.8/46.9，仅 registry 45.0/50.3，完整 Physical Registry 51.2/55.1（+9.9/+8.7）。Enlarge 数据微调跨 Cosmos、WAN 骨干均有 Physics-IQ 收益；例如 Cosmos 3 Nano 16B 的 I2V/V2V 30.18/38.78→36.01/45.12；扩展提示配置 37.3/46.45→43.56/49.54，I2V 高于公开 Cosmos Super 64B 的 42.7。WorldModelBench 四骨干物理遵循与总分均升，但 Cosmos v2.5/WAN TI2V-5B 指令分分别降 0.07/0.09。十候选 PRS 的 I2V 相对 Plain 提升 5.6%–15.9%；Cosmos v2.5 前 10/35 步选择节省 64% 候选去噪步，端到端相对完整候选+WMReward 快 2.84 倍。参数只增约 0.45%（Nano），但每步采样时间 Nano 1.384→2.148 s，Cosmos v2.5 6.514→10.909 s。

## Value
为 JEPA 与生成式视频世界模型结合提供清晰结构范例：把潜在未来表示作为持续参与计算、可读出的内部状态。可用于未来轨迹排序和分析；还需检验是否提升动作预测、可执行性和真实物理外推，而不只提升视频评测分数。

## Strengths
- 控制比较外部条件、视频流对齐、联合生成、普通寄存器与带预测监督的寄存器。
- 在两类视频骨干、多种物理评测和消融上观察一致收益；能直接读取中间状态做早期候选选择。
- 明确给出参数、单步计算、显存和端到端候选选择成本。

## Weaknesses
- 主要证据是视频物理评分与可视化，没有真实机器人动作、长期交互或可执行性验证；JEPA 表征与评测偏好可能相关。
- PRS 的“偏离预报越大越好”是经验相关性，WAN 两款的完整视频 WMReward 仍优于 PRS；十候选搜索仍昂贵。
- 虽参数开销小，额外 token 令单步生成耗时增加约 55%–67%，不适合直接称为廉价扩展。
- 改善物理分数时部分骨干的指令跟随退化，需研究多目标权衡。

## Future Work
作者未提出具体后续计划；从现有局限看，应评测更长时域、交互动作可执行性和内置状态的物理可解释性，并改进选择规则与 token 计算成本。

## Rating
创新度评分：4/5 - 设计有时间锚定、预测初始化和未来表征监督的生成器内部状态，并用于提前选择候选；多骨干验证充分。
相关度评分：3/3 (Core) - 直接连接 JEPA 隐式预测表示与视频世界模型的结构、训练及评测。

## TL;DR
在视频DiT中加入JEPA预报寄存器，使未来动力学可监督、可读出并辅助选样，值得精读。
