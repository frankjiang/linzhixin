# Grounded Iterative Language Planning: How Parameterized World Models Reduce Hallucination Propagation in LLM Agents

## Insight
GILP 的 insight 是 LLM agent 自身也是一种 language world model，但它的转移错误表现为“状态幻觉”并会写入上下文继续传播；小型参数化 world model 虽然规划弱，却能提供可度量的 transition signal 来纠错。Observation 是 agent-only 的 hallucinated-state rate 会随 horizon 增长，而纯参数模型又缺少语义规划能力。作者让两者分工。

## Motivation
论文解决 LLM agent 长程图规划中的 hallucination propagation。同行包括 ReAct、Reflexion、agent verifier、parametric-WM-MPC 和 hybrid prompting；它们要么完全依赖 LLM 状态想象，要么无法处理语义目标。该问题与 agent world model 有关，但不是视觉/3D/JEPA/Dreamer 主线。

## Method
GILP 训练一个小参数化 backbone，预测 action validity、state delta、risk、value 等；LLM 仍负责读任务、草拟 action 和 imagined_next_state。系统用 Jaccard consistency gate 比较 LLM delta 与 backbone delta：一致则接受，中等一致加 risk penalty，低于阈值 0.30 时触发 targeted re-prompt，指出冲突节点。backbone 不替代 LLM，只负责暴露可计算的转移不一致。

## Experiment
四个 graph-structured planning benchmarks。仿真主结果中 Agent-Replan 成功率 0.668，GILP 0.838，tokens/success 从 16,385 降到 15,012；Parametric-WM-MPC 单独只有 0.565。长 horizon H>10 时 Agent-Replan 成功率 0.471，GILP 0.758。真实 GPT-4o-mini 验证中 pooled HSR 从 0.176 降到 0.035，约 80% 相对下降，额外 token 约 20%。局限是主表来自 calibrated behavioural simulator，真实 API 验证规模 n=80 较小。

## Value
对目标方向的价值主要是概念层：world model 可作为 LLM agent 的 grounding/verifier，减少 rollout 中状态幻觉。对视频/3D/隐式世界模型没有直接方法贡献。

## Strengths
清楚区分 agent-based 和 parameterized world model；提出 HSR、propagation depth 等可操作 hallucination 指标；展示小 backbone 足以提供纠错信号。

## Weaknesses
主要任务是图规划，状态空间离视觉/物理世界很远；真实 LLM 实验规模小；hallucination 定义不覆盖实体集合幻觉和 reward attribution 等；性能依赖 backbone 校准质量。

## Future Work
作者指出需要更大规模真实 API 验证、扩展 hallucination 类型、改进 backbone 校准，并研究更复杂 agent/environment。

## Rating
创新度评分：2/5 - hybrid grounding 思路实用，但对目标 world model 方向是间接借鉴。
相关度评分：1/3 (Tangential) - 仅与 agentic/language world model 间接相关。

## TL;DR
用小参数 world model 校验 LLM 状态想象，减幻觉传播但与主线偏远，可选读。
