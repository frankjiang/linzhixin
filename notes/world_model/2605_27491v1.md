# GE-Sim 2.0: A Roadmap Towards Comprehensive Closed-loop Video World Simulators for Robotic Manipulation

## Insight
视频世界模型从"视觉模拟器"到"闭环模拟器"需要弥合三个缺口：(1) 缺少本体感知状态（关节角/夹爪）→ 策略无法获得完整观测；(2) 缺少可验证奖励信号 → 无法做 reward-driven learning；(3) 吞吐量不足 → 无法大规模并行评估。GE-Sim 2.0 通过 proprioceptive state expert + world judge + acceleration framework 分别解决这三个问题。

## Motivation
action-conditioned 视频世界模型已能生成逼真的机器人操作视频，但仅有视觉预测不足以支撑闭环策略学习：策略需要本体感知状态作为输入、需要奖励信号作为反馈、需要高吞吐量进行大规模评估。现有系统（IRASim、1xWM、Ctrl-World 等）至多覆盖其中一两项能力。

## Method
- **Vision Expert**：基于 Cosmos-Predict2-2B DiT，action-conditioned 多视图视频生成，chunk-wise 自回归 + sparse memory，用 Pose2Image + Camera Raymap 做 action conditioning
- **Proprioceptive State Expert**：轻量 transformer 分支，从 vision expert 的中间特征通过 cross-attention 解码双臂关节角和夹爪状态（16维），flow matching 训练
- **World Judge**：VLM-based reward model，逐帧二分类（success/ongoing），提供机器可验证的奖励信号
- **Acceleration**：DMD2 蒸馏（50步→few-step）+ random-stride training（支持 4× 帧跳跃），单 H100 上 25 帧 rollout 2.3 秒
- 训练数据：数千小时真实机器人遥操作 + 策略部署数据

## Experiment
- WorldArena 排行榜第一（2B 参数），超越 Ctrl-World、DreamDojo、GigaWorld 等专用模型及 Sora、Veo 等通用模型
- 6 个长时间双臂操作任务（倒水、折叠、拔插头等）细粒度评估均优
- 闭环验证：模拟器内策略结果与真机结果一致性良好
- World judge 奖励信号与人类判断高度对齐
- 策略改进：用 world judge 过滤训练数据可提升下游策略性能
- 消融证实 state expert 和 world judge 各自贡献显著

## Value
工作完成度高，是视频世界模型作为机器人闭环模拟器的最完整实现之一。Proprioceptive state expert 从视频 latent 解码关节状态的思路值得关注。World judge 提供自动奖励的设计对 RL from world model 有直接启发。但整体以系统工程为主，单项技术创新有限。
