# Sensorimotor World Models: Perception for Action via Inverse Dynamics

## Insight
Observation：JEPA 式 latent world model 若只最小化 latent forward prediction，encoder 可坍缩到常数；同时，像素重建又会保留大量与控制无关的背景信息。

推论：用 inverse dynamics 预测两帧之间的动作，既能防止坍缩，又能迫使表示保留可控自由度。若 embedding 坍缩，inverse head 只能输出常数动作；任何低于常数预测器的损失都要求 embedding 含有动作相关信息。

## Motivation
论文解决从像素端到端训练 JEPA-style latent world model 的两个问题：表示坍缩和表示不对齐控制。

同行方法包括冻结预训练 encoder、SIGReg/方差协方差正则、EMA target encoder 等。这些方法可防坍缩，但正则形式更复杂，且未必直接偏向 action-relevant representation。该问题对 Dreamer/JEPA 类隐式世界模型很关键。

## Method
SMWM 包含三部分：
- encoder `fθ(o)=z`：把图像编码到 latent state。
- forward model `gφ(z_t,a_t)->z_{t+1}`：做 latent prediction。
- inverse model `hψ(z_t,z_{t+1})->a_t`：用相邻 latent 预测动作。

训练目标为 `L = L_fwd + λ L_inv`。inverse regularization 不规定 embedding 分布几何，只要求 latent pair 保留动作信息。架构上使用 ViT-Tiny encoder、小 transformer predictor、2 层 MLP inverse head。

创新程度：机制很简洁，但 insight 清晰；本质是把 perception-for-action 偏置嵌入 JEPA world model。

## Experiment
环境包括 TwoRoom、Reacher、Push-T、OGBench-Cube，使用离线、无奖励轨迹训练，再做 latent MPC/CEM 规划。

结果：
- probe 表明 SMWM 和 SIGReg 都能恢复物理状态；SMWM 在多数 MLP probe 上接近 1.0 R2，Push-T block orientation 较弱。
- 规划上 SMWM 在 2D 任务接近 SIGReg，在 3D contact-rich Cube 上明显更强：SMWM 约 84% success，SIGReg 约 59%。
- λ 需要按环境调参；TwoRoom 0.1、Reacher 5、Push-T 30、Cube 1。

## Value
对隐式世界模型有直接启发：防坍缩目标最好同时服务于控制，而不是只服务于 embedding 分布稳定。inverse dynamics 是低成本、可解释的正则。

局限：假设动作可从相邻观测恢复；对部分可观测、速度不可由单帧识别、多动作同结果的环境可能不足。实验规模偏小，尚未验证大规模视频/机器人数据。

## Strengths
亮点是对隐式世界模型有直接启发：防坍缩目标最好同时服务于控制，而不是只服务于 embedding 分布稳定。

## Weaknesses
