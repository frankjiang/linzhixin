# Cycle-World: Mitigating Error Accumulation in Long-term Video World Models via Reverse-Prediction Cycle Consistency

## Insight
核心 insight 是：长期视频自回归漂移不只是局部预测误差，而是缺少“时间可逆性”约束导致的历史上下文污染。作者形式化了 Cycle-Bounded Drift：若真实动态在局部可反推，且反向预测器满足 Lipschitz/可逆性条件，则前向生成漂移可由反向重建误差上界约束。也就是说，能被未来反向解释回过去的序列更不容易长期崩掉。

## Motivation
长视频世界模型常用自回归扩展，但小误差会不断进入历史上下文，造成结构漂移、物体消失和语义退化。已有方法多依赖更长上下文、位置编码或训练 tricks，缺少直接约束“当前预测是否仍与过去一致”的机制。这是视频世界模型的关键问题，尤其影响 60 秒级别生成。

## Method
Cycle-World 包含两部分。训练阶段加入 Cycle-Consistent Learning：前向生成器预测未来 latent，反向预测器从未来 latent 重建过去 latent，并用 cycle loss 约束前向模型产生可逆序列。推理阶段使用 Cycle-Guided Inference：冻结反向模型，在扩散采样中把反向重建误差作为梯度指导，修正尚未写入历史的 latent。方法创新点在于把反向世界模型同时作为训练约束和推理时 critic。

## Experiment
实验覆盖 VBench 5s/60s、物理一致性 PC/PACE 和多组消融。60s VBench 上 Ours Total 82.88、Quality 84.39、Semantic 76.86，优于 LongLive、Context Forcing 等长视频基线。物理一致性平均分为 75.66，高于 Self-Forcing，但略低于 Rolling Forcing。消融显示 CCL 明显提高 PC，CGI 提升整体质量，二者组合在长时一致性和物理指标上最稳。

## Value
对视频世界模型很有价值：它把长期漂移问题从“加上下文”转为“验证生成历史是否可被反向解释”，可迁移到机器人/驾驶视频 world model 的 rollout 稳定化。仍待解决的是推理时梯度修正的计算成本、反向模型失真时的误导，以及真实交互闭环中的效果。

## Strengths
理论动机清晰，训练和推理两端都能使用同一个反向一致性信号；实验直接瞄准长视频漂移，并有充分消融。

## Weaknesses
依赖反向预测器质量；推理时 cycle guidance 增加采样成本；物理一致性指标并非全部最优，且仍是生成评测而非动作条件闭环世界模型验证。
