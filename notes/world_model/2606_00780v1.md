# Behavior-Invariant Task Representation Learning with Transformer-based World Models for Offline Meta-Reinforcement Learning

创新度：3/5 | 相关度：1/3

## Insight

核心 insight：在 offline meta-RL 中，任务表征不应该依赖于数据收集时的行为策略，而应该只捕获与任务动力学和奖励结构相关的信息（即 behavior-invariant task representation）。

**Observation**：(1) 离线数据由不同行为策略收集，标准的 context encoder 会学到与行为策略相关的虚假关联（spurious correlations），导致 context distribution shift；(2) 学到的策略在 OOD 状态上可能产生 value overestimation，导致 policy distribution shift。

**推论**：从信息论角度，将 context variable X 分解为行为相关分量 X_b=(s,a) 和任务相关分量 X_t=(r,s')。理想的任务表征 Z 应最大化 primary causality I(Z; X_t | X_b)（任务动力学信息）而抑制 lesser causality I(Z; X_b)（行为策略信息）。

**证明**：Theorem 3.1 证明世界模型的动力学损失 L_dyn 可以被视为最大化 primary causality 的变分代理；Theorem 3.3 进一步证明当 L_dyn 足够小时 I(Z; X_b | M) 也被有界控制，即实现了 behavior invariance；Theorem 3.4 证明在此条件下不同行为策略产生的表征分布的 total variation 距离有界。

## Motivation

Offline meta-RL 面临两个耦合的分布偏移问题：(1) context distribution shift——元训练时 context 来自静态数据集，元测试时来自在线探索，二者分布不同；(2) policy distribution shift——offline 数据不覆盖全部状态-动作空间，critic 可能对未见区域过度乐观。现有方法（FOCAL、CORRO、CSRO、UNICORN）分别从不同角度处理这些问题，但都未利用世界模型来同时解决两个偏移。

## Method

**MetaSTAR** 框架包含三个核心组件：

1. **Transformer-based Stochastic World Model**：
   - VAE 编码器将观测 o_t 映射为随机 latent e_t
   - Transformer 序列模型处理 (e_t, a_t) 序列，输出 context embedding h_t
   - 动力学预测器预测下一步 latent 分布 p(ê_{t+1} | h_t)
   - 轨迹末尾附加可学习 task token，通过 self-attention 聚合全局任务信息，经 MLP 投影为 task embedding z
   - 训练损失包含：预测损失 L_pred、动力学 KL 损失 L_dyn（free-bits）、表征损失 L_rep、FOCAL 对比损失 L_FOCAL

2. **Contextual Imagination + Conservative Policy Learning**：
   - 从离线数据采样 context 前缀 τ_{1:L}，warm up 世界模型后进行 imagination rollout（长度 H）
   - 将真实数据 d 与 imagined 数据 d_φ 组合为 d_f
   - Conservative critic：主动降低 imagined 高值状态-动作对的 Q 值（类似 CQL），防止 value overestimation
   - 策略在 d_f 上优化，带熵正则

3. **理论保证**：
   - 世界模型动力学训练等价于最大化 primary causality（Theorem 3.1）
   - 动力学损失小 → behavior invariance（Theorem 3.3, 3.4）

**创新程度**：中等偏上。信息论分析提供了理论 grounding，将世界模型用于 offline meta-RL 的 task representation learning 是较新的思路。但整体框架是 Dreamer 式世界模型 + conservative Q-learning 的组合。

## Experiment

- **环境**：MuJoCo 连续控制（Ant-Dir、Cheetah-Vel、Hopper-Param、Walker-Param）+ 对应的 sparse-reward 变体 + Point-Robot-Sparse
- **基线**：FOCAL、CORRO、CSRO、UNICORN
- **协议**：offline test + online test（更重视 online test）；每个环境 40 个任务（30 训练 + 10 测试）
- **主要结果**：
  - Dense reward：MetaSTAR 在 Ant-Dir（230±42）、Walker-Param（139±27）上显著领先
  - **Sparse reward 优势更明显**：Cheetah-Vel-Sparse（260±34 vs. CORRO 169±59）、Point-Robot-Sparse（21±8 vs. FOCAL 5±3）
  - OOD 适应：MetaSTAR 在首个 episode 即可快速适应，稳定性优于所有基线
- **消融**：移除 L_WM 或 conservative policy optimization 均导致性能下降，尤其在 sparse-reward 环境下退化最严重
- **可视化**：t-SNE 显示 MetaSTAR 的任务表征聚类结构最清晰；欧氏距离矩阵在 Cheetah-Vel-Sparse 上呈现与任务参数一致的平滑结构

## Value

MetaSTAR 是一项扎实的 offline meta-RL 工作，ICML 2026 接收。其核心贡献在于：

1. 从信息论角度证明了世界模型天然适合学习 behavior-invariant 任务表征
2. 在 sparse-reward 和 OOD 设置下显著优于现有方法，验证了理论分析的实际效用
3. Contextual imagination（用真实 context 预热世界模型再做 rollout）解决了 offline meta-RL 中 MDP ambiguity 问题

**对我们的启发**：
- 世界模型的动力学建模本身就是一种 behavior-invariant 表征学习，这个理论视角可以迁移到视频世界模型中
- 但该工作限于低维 MuJoCo 环境，离视频/3D 世界模型有较大距离

**待解决**：高维观测空间（图像/视频）的扩展；计算开销（stochastic Transformer + imagination）较大。

## TL;DR

利用 Transformer 世界模型学习 behavior-invariant 任务表征用于 offline meta-RL，理论证明动力学建模等价于最大化任务相关信息，在 sparse-reward 和 OOD 场景下显著优于基线（ICML 2026）。可选读，与视频世界模型方向间接相关。
