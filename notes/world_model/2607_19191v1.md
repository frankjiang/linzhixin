# ABot-World-0: Infinite Interactive World Rollout on a Single Desktop GPU

## Insight
论文的 insight 是交互式视频世界模型不仅要会生成，还要在长时闭环里控制漂移、记忆角色和维持低延迟。作者观察到 teacher-forcing 训练的 causal video model 在长 rollout 中会累积失真，于是提出 LongForcing：用 teacher 监督学生的长时自回归轨迹，让模型直接学习从自身错误中恢复。

## Motivation
现有交互视频世界模型常在短片段或离线生成中表现尚可，但很难同时满足动作响应、长程稳定、角色一致性和单桌面 GPU 实时运行。本文试图把“无限交互世界 rollout”做成系统：数据采集、动作接口、训练、压缩和部署都服务于实时闭环。

## Method
系统使用多源数据，包括 AAA 游戏、仿真和互联网视频，并用 WorldExplorer 自动采集交互轨迹、质量检查、VLM 语义评估和动作/文本标注。动作接口采用原始键盘动作，帧级 WASD/IJKL 8 维，4 帧打包成 32 维 token。模型先训练 bidirectional teacher，再通过 teacher forcing 得到 causal student，并用 ODE distillation 和 LongForcing 降低自回归漂移。部署侧加入 LightVAE、SageAttention2、FP8/MXFP6/MXFP4 DiT、Fast-RoPE、bounded KV cache 和 memory scheduling。

## Experiment
WorldRoamBench 上与 Genie 3、HappyOyster、LingBot-World、HY-World 比较。ABot 5B 的 Strict 0.5266、Partial 0.7290、Trajectory 0.6752、Aesthetic 0.5039、Imaging 0.4651、Mechanics 0.5223、Memory 0.5041，整体竞争力强但非所有指标第一。系统优化后在 RTX 5090 上可达到约 720p 16 FPS、1.2s latency、约 19GiB 显存。长时 ablation 显示 LongForcing 能降低后段 saturation、blur 和 patch repeat。

## Value
价值主要是工程系统完整，把交互视频世界模型从“能演示”推进到“可单卡实时运行”。对我们启发在于：长程稳定不只是模型架构问题，也依赖数据闭环、长 rollout 训练目标和部署压缩。风险是 benchmark 自建成分较多，真实物理一致性和复杂因果交互仍难判断。

## Strengths
全栈设计扎实；动作接口简单直接；LongForcing 针对自回归漂移；推理优化细节丰富，落到单桌面 GPU 预算。

## Weaknesses
评测生态还不够外部化，和商业/闭源系统比较难完全公平；键盘动作适合游戏漫游，但不覆盖机器人连续控制；对物理因果和可交互对象状态的量化仍有限。

## Future Work
作者提出进一步扩展动作与语义事件接口、多尺度 LongForcing、持久场景记忆、更好的 decoding/context management，以及 quantization-aware training。

## Rating
创新度评分：4/5 - 系统级创新明显，尤其长时训练和单卡实时部署；但核心生成范式仍建立在已有视频扩散和蒸馏技术上。
相关度评分：3/3 (Core) - 直接是长程交互视频世界模型。

## TL;DR
ABot-World-0系统性打通长时交互视频世界模型与单卡实时部署，评测自建但值得精读。
