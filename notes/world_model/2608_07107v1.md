# MemWM: Memory-Augmented Text-Based World Model

## Insight
文本 next-state 的流畅度或词重合会掩盖决定后续动作的实体、位置、价格和设备状态错误；把历史失败整理为 transition rules、state caches 和 hard facts，并按当前状态检索，可显著提高结构事实保持。SSF 与盲审的相关性高于 exact match/Word F1，支持“世界模型应按行为关键字段评价”，但这一结论限于人工定义 schema 的文本环境。

## Motivation
LLM agent 用文本世界模型做 lookahead 时，单个事实错置会在规划中累积；常用字符串指标不是过严就是对事实交换过宽。外部记忆降低系统性状态错误是合理问题，但论文完全属于 NLP/text agent，不是目标视觉世界模型。

## Method
从训练轨迹、hard-negative 预测错误和已观察状态构造 keyed world memory：ALFWorld 存 action schema/正负 transition hint，ScienceWorld 存事实和测量 cache，WebShop 存页面/商品/选项。检索结果以软提示加入 next-state prompt，显式规定可见轨迹优先。SFT 后以 GRPO 训练带/不带 memory 的 world model；规划时冻结 policy，对候选动作想象下一状态并打分。另建 policy-side world skill，从正负轨迹提取任务技能和逐步纠错。SSF 用各 benchmark 的解析器比较行为关键字段。

## Experiment
三种 world-model backbone（1B/4B/7B）和 ALFWorld、WebShop、ScienceWorld 上，memory-augmented RL 在九个 SSF 单元均最佳，相对 SFT 最高提升 206.3%。冻结 Qwen2.5-7B/Qwen3-8B policy 后，ALFWorld 平均成功率分别由 WM 的 49.05/51.36 提至 MemWM+Skill 的 57.27/65.24；WebShop 为 41.57→46.44、50.00→53.41，ScienceWorld 收益不稳定。SSF 在 WebShop 盲审的 Spearman 0.874、AUROC 0.946，优于 Word F1 的 0.781/0.894。相关/随机/无检索、memory dropout 和固定 lookahead 消融支持检索确有作用；多数结果四次独立运行。

## Value
对文本 agent 最有价值的是将 next-state 评价从表面字符串转为结构事实，并区分 world memory 与 policy skill。对视觉世界模型只有间接启发：长期记忆应围绕可行动状态和已知失败组织，而非保存所有 token。

## Strengths
- 三个环境覆盖实体关系、数值科学状态和商品属性。
- SSF 经过扰动测试、盲审相关性和 extractor identity audit。
- 受控消融区分训练期记忆、测试检索、随机/无关记忆和 policy skill。
- policy 冻结，减少把收益误归因于额外 policy 训练。

## Weaknesses
- benchmark-specific schema、parser 和字段权重需要大量人工先验，跨域并非即插即用。
- 记忆来自同环境历史与 hard negatives，可能近似检索测试模板而非学习可泛化 dynamics。
- 加入 world skill 后系统同时改变 policy 提示，不能把所有任务收益归于世界模型质量。
- ScienceWorld 增益小且部分退化，状态 fidelity 到控制收益的关系不稳定。
- 纯文本/NLP，无视觉、3D、物理 latent 或真实交互。

## Future Work
可自动发现行为关键 schema、学习 retrieval uncertainty 与冲突处理、做跨环境迁移，并把错误驱动记忆扩展到视觉/多模态状态。

## Rating
创新度评分：3/5 - 错误驱动世界记忆与 SSF 评价组合完整，但核心是检索增强和领域规则工程。
相关度评分：0/3 (Noise) - 纯文本 LLM agent 世界模型，与用户关注的视频、3D、JEPA/Dreamer无实质关联。

## TL;DR
MemWM 用错误驱动检索和结构字段指标提升文本规划，但依赖领域 schema 且属纯 NLP，可跳过。
