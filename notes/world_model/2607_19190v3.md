# Agentic Real2Sim: Physics-based World Modeling with Vision-Language Agents

## Insight
有。论文的 observation 是：real-to-sim 不是静态重建问题，机器人交互 episode 还包含 actors、object states、contacts、physical parameters、camera/robot frames 和可回放轨迹。推论是要把真实交互转成“可仿真的 episodic twin”，需要 VLM agent 做模糊决策，确定性视觉/物理工具做可验证计算，并用 simulator-in-the-loop feedback 修正。

## Motivation
论文解决将真实机器人交互视频和轨迹自动转换为物理仿真资产的问题。已有 Real2Sim 多关注单物体扫描、场景重建或手工对齐；VLM scene generation 能造场景，但未必保留真实交互轨迹和物理参数。这个问题对 3D/物理世界模型和机器人数据再利用很关键，因为 scalable simulation twins 可以服务 policy learning、evaluation 和数据扩增。

## Method
核心表示是 episode twin `T=(O,A,G,S_1:T,Theta,B,M)`，包含观测、actor/end-effector、几何/外观资产、仿真状态、物理/对齐参数、仿真 backend 和评价 trace。DROID 管线包含四类 agent/stage：visual processing、physical-prior inference、scene preparation、simulator-in-the-loop grasp optimization。

具体流程：选择主相机并抽帧；VLM 做 object discovery/keyframe selection；SAM 3 分割，mask critic 可重试；SAM 3D / stereo depth 恢复 mesh 和 scale；FoundationPose 跟踪 6D pose；VLM 识别 manipulated object 和 ground reference；之后校准 robot base、ground plane、camera frame，把资产放入 MuJoCo；最后通过 object shift sweep 或 LLM-assisted refinement 根据 replay evidence 优化 grasp 成功。PhysTwin deformable 和 BFM-Zero humanoid adapters 复用同一 episode contract，但替换状态和仿真变量。

## Experiment
刚体实验在 DROID-100 上进行，覆盖 pick/place/push/insert、不同物体、视角和遮挡。指标是 replay success：从 sweep 中选择最多 5 个候选 replay，由三个不同 VLM judge 比较 real/sim keyframes，按目标物体、最终位置、动作相似和 gripper 位置打 10 分；8 分以上算 success，7 分 partial。

使用 Gemma 4 31B 后端时，100 个 DROID episodes 得到 48 successful、8 partial、44 failed，模型费用 $2.62。四种后端成功数：Gemma 48、Qwen 45、GPT-5.4 43、Claude Haiku 37；费用从 $2.62 到 $82.30，Gemma 约为 GPT-5.4 成本的 3%。作者还给出 deformable 和 humanoid 的定性 stress tests，没有 aggregate scores。

## Value
这篇对 3D世界模型和机器人仿真很相关：它关注的不是 neural rollout，而是把真实世界 episode 转成可执行物理世界模型。对我们启发是：可扩展 Real2Sim 需要清晰 artifact contract、agent 决策边界和可审计 replay metric。它也说明当前瓶颈更多在感知/仿真组件，而不只是 VLM 能力。

## Strengths
亮点是 episode-level problem formulation 清楚；把 VLM 限制在 schema-constrained decisions，降低成本且便于替换；DROID-100 有一定规模；展示 rigid、deformable、humanoid 三类适配，证明 contract 有扩展潜力。

## Weaknesses
刚体成功率仍低于 50%，说明离自动可靠 Real2Sim 还有距离；评价依赖 VLM judge，可能存在主观性和模型偏差；deformable/humanoid 只有定性展示；尚未证明生成的 twins 能实际提升策略学习或评估。

## Future Work
作者计划扩展自动转换到更多 deformable episodes，系统评估 agentic components 和 VLM backend 的可靠性、replay stability，并把 aligned episode twins 用于机器人 policy learning/evaluation。

## Rating
创新度评分：3/5 - episode contract + agentic pipeline 有实用新意，但主要是系统集成，成功率和下游验证仍有限。
相关度评分：3/3 (Core) - 直接面向 3D/物理世界建模和机器人 Real2Sim，是核心相关。
