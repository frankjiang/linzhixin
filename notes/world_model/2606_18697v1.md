# Stealthy World Model Manipulation via Data Poisoning

## Insight
世界模型 fine-tuning 数据本身是攻击面：少量 next-state target 被污染后，模型预测误差看似接近自然误差，但规划 rollout 会系统性走向低回报。关键推论是攻击应先找“有害但接近干净动力学”的 target world model，再用数据梯度匹配去实现。

## Motivation
现有 RL poisoning 多操纵 reward/transition 或目标 policy，不能直接套到深度 learned world model：高维 latent dynamics 会影响 long-horizon planning，且无法直接改部署策略。机器人和 model-based RL 适配流程越来越依赖本地 fine-tuning buffer，因此问题重要。

## Method
SWAAP 两阶段：Stage 1 用 transition-gradient theorem 和 first-order bilevel optimization 找低回报、低偏差的目标 world model；Stage 2 用 stealth-constrained gradient matching 修改有限比例 transition targets，让 fine-tuning 梯度逼近目标模型，同时 prediction-error regularizer 让 poisoned target 保持在 clean model 自然误差尺度内。评估 stealth 包括 data-level δ_d、model-level δ_m、CUSUM/PCA/TRIM。

## Experiment
主要 victim 是 TD-MPC2，补充 DINO-WM；预训练 1e6 clean transitions，fine-tune 5k transitions，主设置 poison ratio 0.1。DMControl、MyoSuite、MetaWorld、ManiSkill2 上 SWAAP 通常降低 return，例如 dog-run 637 到 478、soccer 1724 到 1479，同时 δ_d 接近 δ_d,ref。CUSUM 对高 stealth 设置几乎失效，TRIM 下仍有效；灰盒和 trajectory-consistent 版本有初步结果。

## Value
对“世界模型可靠性/安全”有价值，尤其提醒合成/在线适配 pipeline 需要数据完整性和 dynamics monitoring。它不直接推进视频/3D/JEPA 表征，但对机器人世界模型部署很相关。局限是主要白盒、TD-MPC2 小中型任务，foundation video WM 尚未验证。
