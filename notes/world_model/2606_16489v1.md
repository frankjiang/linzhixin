# BRICKS-WM: Building Reusability via Interface Composition Kinetics for Structured World Models

## Insight
核心观察：可复用 world model 不应只做 object-centric segmentation，而要在 latent transition dynamics 上做功能分解。把世界拆成 Agent module 与 Background module，中间通过 learned latent interface 通信，使 background dynamics 与具体 agent state 解耦，从而可冻结迁移。

## Motivation
MBRL/Dreamer 类模型强但单体化，换 agent 或相关任务时很难复用环境动态。对象中心方法多关注视觉分割，未保证动力学模块可复用。问题对结构化隐式 world model 有参考价值。

## Method
BRICKS-WM 因式分解 latent state：受控 agent dynamics 与外部 background dynamics；background 只依赖接口变量而不看 agent 具体状态。通过 interface regularization 形成标准化 interaction protocol。目标是从 scratch 训练仍能达到单体 world model 控制性能，并支持 frozen background transfer。

## Experiment
在 DMC Walker Walk/Run、Cheetah Run、Hopper Hop 上比较 DreamerV3、TD-MPC2 等单体基线；分析 interface perturbation，证明某些维度对应背景垂直位移等语义；做跨 agent/任务 background reuse。消融显示适中 interface penalty（如 0.01）关键，过强会损害高动态任务。

## Value
创新点在 dynamics-level modular reuse，和 Dreamer/MBRL 方向相关。局限是 toy locomotion/背景交互，离视觉世界模型和复杂 3D 物理还有距离。值得选读结构化建模部分。

## Strengths
亮点是创新点在 dynamics-level modular reuse，和 Dreamer/MBRL 方向相关。

## Weaknesses
不足是 toy locomotion/背景交互，离视觉世界模型和复杂 3D 物理还有距离。
