# Adaptive Compute in Latent World Models: When Depth Helps, Hurts, or Doesn't Matter

## Insight
有。Observation 是 adaptive-compute world model 默认假设“更深 predictor 单步更准，rollout 后也更好”，但 autoregressive composition 可能改变甚至反转深度收益。推论是是否加深计算不是 task 固有属性，而是 metric、horizon、encoder、architecture、训练数据分布和 planner 的联合属性；必须用 shallow penalty rho 先测。

## Motivation
解决 latent world model 中 early-exit/mixture-of-depths 是否真有可路由 tradeoff 的问题。世界模型规划会重复调用 predictor，如果深度收益不能在多步 rollout 中保留，adaptive compute 就没有意义，甚至有害。

## Method
提出预注册 instrument：rho = err(shallowest-exit rollout) / err(full-depth rollout)。rho>1 表示深度有益，约 1 表示 flat，<1 表示 shallow 更好。用 block-stacked latent predictor，exit depths {2,4,...,12}，K=1 single-step 与 K=4 latent overshooting matched twins，8 seeds，DMC 任务。另做 first-step-only deep supervision ablation、metric/horizon/encoder/backbone/data distribution/planning 测试。

## Experiment
9 个 DMC 任务三类：6/9 intrinsic，2/9 inversion，1 flat。acrobot-swingup K=4 rho 7.98，reacher 2.95，walker 1.95；cheetah-run 0.87，quadruped 0.89，humanoid 0.96。Gate B：只在第一步监督 early exits 可擦除 cheetah inversion，rho 从 0.869 到 1.147，说明 routability catch-22；但 quadruped 不擦除，机制非唯一。metric-space 可让 humanoid flat->inversion；horizon 增大使 cheetah 从 0.85 到 1.07；pixel/CNN、transformer、competent-policy data 都会改 regime。CEM planner 中 rho 预测部分 depth benefit：cartpole/acrobot 深度有益，cheetah shallow 在弱 planner 下优于 deep；强 planner 下 routing 在 inversion tasks 胜过固定深度。

## Value
很值得精读。它直接告诉我们 latent world model 的计算深度、评估空间和规划收益不能想当然，尤其对 JEPA/Dreamer/TD-MPC 类模型的 rollout 评估和 adaptive compute 设计很重要。

## Strengths
预注册、负结果透明；rho 指标简单可复用；不仅分类，还做机制、配置依赖、OOD regime predictor 和规划闭环验证；对“latent metric 可能误导”有明确证据。

## Weaknesses
主要是 state-based DMC，不是像素视频大模型；阈值经验化；planning 验证部分且依赖 reward head；on-policy distribution 只测 cheetah/cartpole 两个任务；尚未迁移到生产级 TD-MPC2/Dreamer。

## Future Work
作者认为最重要下一步是把 instrument 迁移到 TD-MPC2/Dreamer 等生产级 planner，并做更大规模 held-out task 和 on-policy 中间分布实验。
