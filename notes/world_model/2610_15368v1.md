# ANTE: Anticipate, Then Execute -- Learning Internal World Models for Coding Agents from Verified Beliefs

## Insight
观察：代码代理只用终局测试奖励时，早期编辑的副作用难获信用；事后记忆也不能在动作前预判。推论：先写可检验的执行结果预测，再把真实工具返回作为每步反馈，可训练有前瞻性的策略。论文给出基于预测分组的优势构造、预测损失的信息界及测试时选择界；实证显示预测命中率与任务通过率一起提升。这里的「世界」是软件仓库和终端，不是物理或视觉环境。

## Motivation
现有代码代理常对工具返回被动响应，已有代码世界模型或在 RL 前冻结，或只预测下一个工具输出。目标是把动作前预测、真实执行核验和逐步信用分配结合，用于减少错误编辑和无效行动；对软件工程代理重要，与本研究方向无直接联系。

## Method
每个工具调用前生成 belief：现状摘要、目标测试 PASS/FAIL/NA 与命令能否正常退出、以及 trust/abstain 决定。第一阶段用已执行轨迹的事后标签做 SFT；第二阶段在自身轨迹中用确定性核验器读取测试与退出结果，加入预测交叉熵、信任决策奖励及 BAPO 策略梯度。BAPO 按同一任务中预测的结果及信任决策分组，对执行回报计算组内/组间优势。测试时 ANTE-TTO 在模型弃权或预测失败时额外采样动作，按其自身预测排序，只执行一个候选。创新集中于代码代理的核验式信用分配。

## Experiment
SWE-bench Verified 上，Qwen3-32B 的 ANTE pass@1 为 57.2%，匹配的 Reactive-RL 为 51.0%，只保留 belief 而无 BAPO 为 54.2%；7B/14B 分别为 27.2%/46.2%。9B 在 Terminal-Bench 2.0 为 24.7%，Reactive-RL 为 18.0%。32B 代码核验预测命中率在 RL 中从约 44% 升至 69%；11 个分布外推理基准平均 83.3% 对 77.1%。ANTE-TTO 使 32B SWE-bench 57.2%→57.8%，在 7B 约多用 31% 推理 token。消融将 belief 和 BAPO 的贡献分开。

## Value
「预测可核验结果，再以真实反馈校准信任」可启发一般工具代理，但本文不提供视频、3D 或 JEPA/Dreamer 世界模型的表示、物理动力学或评测成果，研究方向上可跳过。

## Strengths
真实执行结果而非模型裁判作预测标签；有多模型规模、两套代理环境及 belief/BAPO 消融；区分预测正确与是否应信任。

## Weaknesses
预测标签主要是测试通过与退出码，属于粗粒度动作结果，并非完整仓库状态转移；只有可由工具核验的步骤得到强监督。SFT 使用事后标签，作者理论中也承认与因果在线分布存在差距；TTO 改善相对有限且需额外采样。

## Future Work
论文未明确给出视觉或物理世界模型方向的未来工作；其方法可进一步扩展到更细粒度、可核验的代码状态变化，但这不属于本文已验证贡献。

## Rating
创新度评分：2/5 - 在代码代理信用分配上有组合创新，但对视频、3D、隐式物理世界模型没有新技术贡献。
相关度评分：0/3 (Noise) - 「世界模型」仅指代码仓库工具结果预测，与所关注的物理世界建模无实质关联。

## TL;DR
让代码代理在操作前预测测试结果，并用执行反馈训练与选动作；与物理世界模型方向无关，可跳过。
