# PhysCoRe: Physics-Corrected Residual World Models for Material-Aware Deformable Dynamics

## Insight
有。Observation 是可变形物体动力学的关键不确定性来自不可直接观测的材料参数；纯物理模拟需要每物体慢速标定，纯学习模型又容易违反物理结构并泛化差。推论是以可微 MPM 为骨架，把未知材料和模拟误差交给小的 feed-forward 网络：一个从观测运动推断 per-particle material，一个在 MPM 内部加 bounded residual correction。置信度输出还可指示哪些区域已被有效识别，从而指导主动探索。

## Motivation
论文解决机器人操作中 deformable object dynamics prediction：给定 RGB-D 观测和 gripper/hand action，预测未来粒子状态。同行包括 PhysTwin 这类物理重建/优化方法、PGND 等学习式粒子动力学、EMPM 等 online refinement 物理模型。关键问题是材料参数不可见且空间变化，真实接触/摩擦/塑性与简化模拟器有 sim-to-real gap。

## Method
状态表示是 MPM particles，而非像素视频。输入为分割 RGB-D、多视角表面点跟踪、canonical filled particles 和 controller motion。Material from Motion (MfM) 用 Fourier features 编码 canonical position、tracked displacement、controller vector 等，经过 graph U-Net 和 temporal conv/GRU，输出每个粒子的 log Young's modulus、Poisson ratio、confidence，以及每 episode 的 elastic/plastic 概率。由于真实材料标签难得，作者从 14 个 PhysTwin real episodes 出发，用 Perlin noise 生成空间相关材料场，rollout 并重渲染，得到 1,260 个合成增强 episode 做 MfM 预训练。

Residual from Dynamics (RfD) 插入 MLS-MPM 的 grid update 与 G2P 之间。它读取 active grid cell 的速度、质量、stress、MfM 材料、confidence、接触和地面距离等特征，用 FiLM-conditioned sparse 3D U-Net 输出 grid velocity residual `delta v`，经 `tanh` 限幅并零初始化，避免一开始破坏解析模拟器。训练分两阶段：先用合成材料监督 MfM，再冻结 MfM，在真实 episode 上通过 Chamfer 和 tracked point L2 监督 RfD rollout。

## Experiment
真实数据包含 12 个 deformable manipulation episodes：rope、towel、plush bear、Play-Doh，三台 RealSense D455，动作包括 lifting、pushing、stretching、squeezing。评测设定是前 50% episode 做 material identification，后 50% rollout 预测。指标包括 Chamfer distance、tracked-point loss、IoU、PSNR、SSIM、LPIPS。

PhysCoRe 在 elastic objects 上 CD 0.00910、Track 0.02557，优于 PhysTwin 0.01617/0.03016 和 PGND 0.03420/0.13175；elastoplastic 上 CD 0.00541、Track 0.01670，也优于 PhysTwin 0.00778/0.01821。RfD 消融显示 MfM-only 的 elastic CD 0.01047、elastoplastic CD 0.00658，加入 RfD 分别降到 0.00910/0.00541。runtime 上材料识别/优化仅 11.4s，而 PhysTwin 930s、PGND 8280s。置信度实验显示高置信区域随被操作/变形区域增长；KUKA 探索中未被触碰区域保持低置信，可作为主动探索信号。

## Value
对 3D/物理世界模型有启发：不是把全部动力学黑盒化，而是用物理模拟器承载结构，用学习模块处理不可观测材料和系统误差。对视频世界模型方向的借鉴在于 latent physical state、uncertainty-guided exploration、residual dynamics 三者的组合。局限是任务非常专门，离通用视觉世界模型、生成式视频和大规模交互环境还有距离。

## Strengths
物理结构和学习残差分工明确；材料推断是 feed-forward，在线适配成本显著低于优化式 baseline。RfD 插在 MPM 内部而不是输出端修正，有利于保留模拟器结构。置信度可视化和机器人探索实验让不确定性输出有明确用途。

## Weaknesses
真实实验规模小，只有 12 个 episode 和有限物体类别；材料模型限制在 elastic/elastoplastic，不能处理 tearing、cutting、adhesion、fluid-like motion 或复杂接触。合成材料增强依赖已有 PhysTwin episodes 和 MPM 假设，跨类别 zero-shot 没验证。RfD 在更大、更复杂 dynamics distribution 上是否稳定未知。

## Future Work
作者指出需要扩展到更多材料行为和复杂接触，测试 zero-shot category-level transfer，并验证 RfD 在更广动力学分布上的可扩展性。confidence-guided exploration 也只是信号展示，未来可闭环接入主动探索策略。
