# Policy and World Modeling Co-Training for Language Agents

创新度：3/5 | 相关度：1/3

## Insight
核心观察：on-policy RL rollout 中的每一步 transition (h_t, a_t, o_{t+1}) 天然包含了 world model 的监督信号——action 带来的 next observation。标准 RL 只利用了 reward 信号而忽略了这个"免费"的 dynamics 监督。基于此，作者论证可以零额外交互、零额外模型地将 world modeling 嵌入 RL 训练。

进一步观察：直接用 CE loss 做 next-observation prediction 在 agentic 场景下表现差，因为环境观察包含大量噪声 token（ID、随机字符串等），CE 的 1/p 梯度放大效应会让模型过拟合这些不可预测的 token。作者通过梯度分析证明 MAE loss 的梯度是 bounded 的，从而更适合噪声场景。

## Motivation
- **问题**：LLM agent 的 RL 训练只优化 reward，不学习 action 的后果（环境动态），导致在长 horizon 任务中出现不可逆错误和延迟失败。
- **同行做法**：现有 world model 方法要么训练独立的 simulator/world model（额外模型+训练阶段），要么在推理时做 imagination/planning（额外推理开销）。
- **关键性**：是一个实际且重要的问题——能否以零额外成本将 world modeling 融入标准 RL 训练。

## Method
**PaW (Policy and World modeling co-training) 框架**：

整体思路：在 on-policy RL 的训练 loss 中增加辅助的 world model loss，共享同一个模型参数。

三个关键设计：
1. **Action-entropy-based WM data selection**：计算每个 transition 处 action token 的平均熵 H(a_t|h_t)，只保留 top-alpha 高熵 transition 作为 WM 训练数据。高熵意味着策略在该决策点有较大不确定性，对应的 environment transition 更具信息量。
2. **Clipped MAE (CMAE) loss**：用 MAE loss (1-p_{t,i}) 替代 CE loss (-log p_{t,i})，梯度不再被 1/p 放大；再加 confidence clipping mask m_{t,i} = 1[p_{t,i} <= rho]，已经预测好的 token 不再优化。
3. **Reward-adaptive loss balancing**：lambda_{WM,g} = 1 - R_bar_g / R_max，低 reward 的 rollout group 获得更大的 WM loss 权重（需要更多 dynamics 学习），高 reward 的 group 则更依赖 policy loss。

训练方式：单次 forward pass 内完成，action token 用 RL loss mask，observation token 用 WM loss mask，causal attention 保证互不干扰。推理时无任何额外开销。

## Experiment
- **任务**：ALFWorld（embodied 家务任务，6类子任务）、WebShop（网页购物）、Search-augmented QA（NQ/TriviaQA/HotpotQA等7个QA数据集）
- **基线**：GRPO、GIGPO、PPO、RLOO；以及 prompting 方法 ReAct、Reflexion、GPT-4o、Gemini-2.5-Pro
- **模型**：Qwen2.5-1.5B/7B-Instruct, Qwen3-1.7B/3B/14B, Llama3.2-3B
- **效果**：
  - ALFWorld: GRPO w/ PaW 比 vanilla GRPO 提升 +7.9 (1.5B) / +3.0 (7B) 成功率
  - WebShop: GRPO w/ PaW 提升 +8.0 (1.5B) / +4.0 (7B) 成功率
  - Search QA: 平均提升约 +1-3 分
  - 跨 RL 算法（PPO/RLOO/GRPO/GIGPO）和跨模型均有一致提升
  - Llama3.2-3B 上 GRPO 几乎训不动（4.0%），加 PaW 后 62.2%（+58.2%）
- **消融**：去掉 adaptive coefficient 或换成 CE loss 均有显著性能下降
- **开销**：仅增加约 2% 训练时间和 2.4% GPU 内存

## Value
- **优点**：方法极其简洁实用，零额外交互、零额外模型、零推理开销，仅需修改训练 loss。三个设计（数据选择、CMAE、自适应权重）都有清晰的动机和消融验证。在 sparse reward 场景（Llama3.2-3B）表现尤其突出。
- **启发**：对于视频/3D 世界模型领域，PaW 的核心思想——利用已有 rollout 数据做 dynamics 辅助训练——可以迁移到 model-based RL 的训练框架中。CMAE loss 对噪声 observation 的处理思路也值得借鉴。
- **局限**：仅做 one-step prediction，不建模长程依赖；仅在文本环境验证，未涉及视觉/连续控制。

## Strengths
亮点是优点：方法极其简洁实用，零额外交互、零额外模型、零推理开销，仅需修改训练 loss。

## Weaknesses
不足是优点：方法极其简洁实用，零额外交互、零额外模型、零推理开销，仅需修改训练 loss。

## TL;DR
在LLM agent的RL训练中复用on-policy rollout做辅助world model训练，通过熵选择+CMAE loss+自适应权重实现零额外开销的一致性能提升。可选读，方法简洁但场景限于文本agent。
