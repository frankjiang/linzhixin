# Reinforcement Learning for Laser Additive Manufacturing Scan-Order Optimisation: A Bilevel Proxy--FEA Diagnostic Framework for Reward and World-Model Diagnosis

## Insight

- 本文的"world model"指的是将扫描顺序决策映射到工艺质量指标的**任务级评估结构**（即代理指标体系），而非学习到的隐式动态模型（如JEPA/Dreamer），与CS视觉领域的世界模型概念完全不同
- 核心发现：扫描顺序优化是残余应力与变形之间的**多指标权衡问题**，而非单一单调优化目标；廉价代理指标主要捕获变形相关行为，与FEA复合参考分数的对齐度有限（pairwise agreement仅约0.6-0.67）

## Motivation

- 在激光增材制造中，扫描顺序影响热积累、残余应力和变形，适合建模为RL序列决策问题
- 挑战：完整FEA仿真计算成本太高，无法作为RL密集奖励；廉价的路径描述符（如跳跃距离、邻近间隙）虽快但仅捕获部分热-力学响应
- 需要诊断代理指标是否能保持FEA参考标签的偏好结构，避免奖励错误指定导致策略偏差

## Method

- **双层框架**：下层用廉价扫描路径描述符（路径间距、跳跃距离、热记忆代理等）快速筛选候选策略；上层对选中策略运行稀疏Abaqus FEA仿真获取残余Mises应力、U3变形范围、PEEQ塑性分数三个参考标签
- **Proxy-FEA对齐分析**：通过pairwise ranking agreement（公式6-7）检查代理指标与FEA复合分数的偏好一致性
- **基准**：简化LDED32条带基准（32离散扫描轨道、整轨加热抽象），评估10种预定义扫描策略

## Experiment

- 10种扫描策略的FEA排名显示center_out为鲁棒折中候选，raster_left_to_right和edge_in分别为低应力/高变形和低变形/高应力的端点
- 排名对权重方案敏感，验证了多指标权衡结构
- Proxy-FEA对齐结果：proxy_jump_mean与U3变形有中等负相关（Spearman -0.73），但与复合FEA分数仅弱相关（Spearman 0.25）；pairwise agreement最高约0.67，仍属定性诊断级别

## Value

- 对RL奖励设计有警示意义：仅依赖代理指标可能导致策略优化方向偏离真实多指标目标
- 但本文并未完成RL策略学习，仅是诊断性准备工作；基准规模极小（10个策略、32轨道），结论探索性较强
- 与视频世界模型、3D世界模型、隐式世界模型（JEPA/Dreamer）**无实质关联**——此处"world model"仅指制造领域的任务级评估函数结构
