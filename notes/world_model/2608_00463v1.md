# Scene2Sound: Auditory-Grounded Soundscape Generation for 3D Gaussian Worlds

## Insight

Observation：单视图生成的音频绑定在拍摄视角，用户在可导航 3DGS 世界中移动时无法保持声源身份和空间位置；而同一物体跨视图渲染会共享一组持久 Gaussian primitives。论文推论：无需训练 3D feature，只要把各视图分割 mask 对应的 Gaussian sets 用 Jaccard overlap 聚类，就可建立跨视图实例并锚定 3D 声源。held-out Cross-View Grounding Consistency 与 listener-motion 指标显示完整系统同时具有几何支持和随位置变化的音频响应；但 CGC 不检查“正确声音是否绑定正确物体”，因此只证明位置集合一致，不证明完整听觉语义 grounding。

## Motivation

3DGS 已能提供实时可漫游视觉世界，但通常静默。现有 image/video-to-audio 或 FOA/5.1 生成器按单一视角合成，难在任意 6DoF 监听位置复用；声场/RIR 方法又要求已知声音或现场声学监督。论文解决“给定静态 3DGS，自动决定什么物体发声、发什么声、位于哪里”的 authoring 问题。对沉浸式 3D 世界很实用，但不研究视觉世界动力学或 agent planning。

## Method

先假设 3DGS 表面围绕可行走的空心区域，从鲁棒场景中心沿 Fibonacci rays 生成 20 个候选相机，以 CLIP-IQA×距离加权可见 Gaussian coverage 贪心选 5 个全景视点。Qwen2.5-VL-32B 联合观察多视图，将事件分为不定位的 ambient bed 与带 source id、grounding query、audio prompt、响度的 point sources；Stable Audio Open 生成 30 s/44.1 kHz 音频。SAM3 对每视图 query 出 mask，gsplat tile metadata 找到贡献 mask 的 Gaussian 集，并用单侧相对深度 gate 去除背景。相同 source id 内，跨相机 Gaussian set Jaccard>0.15 的 mask 用 Union-Find 合并；Gaussian 中心按 tile 次数×mask confidence 加权成 3D 位置。同标签实例复用声音并按 `1/sqrt(n)` 能量归一，标准 object-based/HRTF audio engine 根据 listener pose 实时渲染。核心 GSM 简洁有效，但整条管线高度依赖现成 VLM、SAM 和 T2A。

## Experiment

主 testbed SoundscapePLY 仅 24 个由 FLUX.2+Marble 生成且人工策划的 3DGS；另以 D-SAV360 单位置 360° 图重建 81 个真实场景作迁移。对 11 个非空间/空间音频基线评 FAD、CLAP、ImageBind、双耳统计，并新建 LMC（近/远 listener 的 log-mel 距离排序，另报 responsiveness）和 CGC（留一视图重做 placement 后，投影点与 held-out masks 一对一匹配）。SoundscapePLY 上 Scene2Sound 的 FAD 83.8、CLAP 0.320、LMC 0.283、CGC 0.259/precision 0.441；SonoWorld 为 79.3、0.130、−0.214、0.065。CGC 相对 SonoWorld 差值 0.19，scene bootstrap 95% CI [0.10,0.29]。消融显示随机相机 CGC 0.060；去实例关联让实例数 21.0→66.9、precision 0.441→0.302，但 CGC F1 几乎不变；固定 scene/flat mix 的 LMC=0。19 位参与者各评 4/24 场景，Preference/Spatial/Semantic MOS 为 3.79/3.77/3.75，最佳基线约 2.68/2.48/2.75，九组 Bonferroni 配对检验均 p<0.001。全流程 A6000 平均 222 s/scene，VLM 与音频生成占 77%。

## Value

工作把静态 3D world representation 扩展为可重渲染的对象级听觉层，GSM 体现了 Gaussian primitive 作为跨模态持久索引的价值。对 3D 世界模型的启发是：场景 primitive 不只用于视觉渲染，也可承载声音、语义乃至物理属性；持久实体身份可成为多模态交互接口。不过当前只是离线静态 authoring，不预测世界状态，也未让声音随物理事件变化。

## Strengths

任务定义清晰且与单视图音频有实质区别；Gaussian set overlap 方案无需每场景训练或 feature matching，部署简单；专门设计并以位置扰乱、复制/删除声源、波形打乱和真实声场数据验证 LMC/CGC；基线、组件消融、后端敏感性、用户研究和运行时间较完整；明确区分 ambient 与 point source，避免把所有声音错误点化。

## Weaknesses

SoundscapePLY 只有 24 个生成且由作者按“声景特征”策划的场景，主统计效力和外部有效性有限；D-SAV360 只有单捕获位置，不能验证真正跨位置关联。CGC 是无标签位置集合指标，置换声音归属不变；LMC 也只测距离响应顺序，二者均不验证声源语义、响度物理性或声传播。用户研究使用更早 pipeline 配置，参与者以年轻研究生为主、远程个人耳机，且各系统的 6DoF cue 能力不匹配。静态 3DGS 无动态状态，因此风扇、碰撞等只生成“典型声音”；无遮挡、反射、混响/RIR，几何不参与声传播。20.2% VLM proposals 无法被 SAM ground，模块错误仍会级联。

## Future Work

作者提出把声音与动态/物理感知场景状态耦合，加入基于几何的 RIR 或 learned acoustic fields 以模拟遮挡和混响，并通过联合优化/迭代反馈缓解模块级联；还需建设含多视图真实捕获、环境声景和多实例 audio–object correspondence 的基准，并做 cue 匹配的用户研究。

## Rating

创新度评分：3/5 - 把 auditory grounding 表述为持久 3D 实例问题并提出训练自由 GSM，任务与评测有新意；整体仍是成熟 foundation modules 的管线组合。
相关度评分：2/3 (Related) - 直接增强 3D Gaussian 世界的多模态持久性，但不学习视频动力学、隐式状态转移或规划。

## TL;DR

用 Gaussian 集合重叠将生成声音锚到可漫游 3D 世界，评测新颖但属静态扩展，可选读。
