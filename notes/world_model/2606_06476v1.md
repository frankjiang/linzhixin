# Thinking with Imagination: Agentic Visual Spatial Reasoning with World Simulators

## Insight
Observation: 现有 VLM 在空间推理中受限于给定图像的固定视角，无法主动获取缺失的空间证据；而直接将生成模型接入 VLM 作为"世界模拟器"效果很差（Qwen3-VL 接 Bagel 甚至不如 direct answer）。推论：有效的"想象力增强推理"需要同时满足两个条件——(1) 世界模拟器必须具备空间一致性（而非仅视觉逼真），(2) VLM 策略必须通过 RL 学会何时调用、请求哪个视角、如何利用想象结果。论文通过 View Consistency Tuning 和 Two-Phase RL Curriculum 分别验证了这两点，消融实验清晰地证明了单独满足任一条件均不足够。

## Motivation
问题：VLM 的空间推理能力受限于观察到的图像视角，面对遮挡和多视角推理时表现差。同行做法大多在静态图像上添加推理链或几何工具，但无法主动获取新视角。Astra 将问题重新定义为"交互式证据获取"——VLM 可以主动向世界模拟器发出相机运动查询，获取想象的新视角图像用于推理。这是一个有意义的问题，因为它开辟了 VLM + 世界模型交互推理的新范式。

## Method
整体管线由两个组件构成：
- **Astra-WM**（世界模拟器）：基于 Bagel 多模态生成模型，通过 View Consistency Tuning 微调——使用 544k 来自多个 3D 场景数据集的 SFT 样本，训练模型根据上下文图像和自然语言相机运动指令生成空间一致的新视角图像。
- **Astra-VL**（推理策略）：基于 Qwen3-VL-8B，通过两阶段 RL 训练：Phase 1 鼓励探索和工具使用学习（加 tool-use bonus），Phase 2 引入选择性想象（比较 tool-use 与 direct answer 的增益，奖励有益的模拟器调用，惩罚有害的调用）。

关键创新在于将世界模拟器作为 agentic tool 而非固定管线，VLM 自主决策何时想象、想象什么。

## Experiment
- 评估基准：MMSI-Bench（1000 个多视角空间推理样本）和 MindCube-tiny（结构化 3D 环境）
- 对比基准：开源 VLM（Qwen3-VL、Bagel）、商业模型（GPT-4o、Gemini-3-Flash）、专用空间推理模型
- 三种工作模式对比：Direct Answer / Forced Tool-Use / Agentic Tool-Use
- 主要结果：Astra 将 Qwen3-VL-8B 在 MMSI-Bench 上从 29.8 提升至 38.8，MindCube 从 36.8 到 42.7
- 消融验证了 View Consistency Tuning 的必要性（off-the-shelf Bagel pose/content consistency 差）、两阶段 RL 的优势（单阶段容易坍塌或过度使用）、以及 Agentic Tool-Use 优于 Forced Tool-Use

## Value
工作价值较高，开辟了 VLM + 世界模拟器交互推理的新方向。核心启发：(1) 世界模型不仅可以用于生成训练数据或提供视觉先验，还可以作为推理时的"想象力工具"；(2) 有效利用生成模型需要训练策略来决定何时、如何使用。局限在于：性能绝对值仍不高（MMSI-Bench 38.8），world simulator 质量是瓶颈；目前仅限于室内场景的空间推理 QA 任务。
