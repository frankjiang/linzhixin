# CausalWAM: Learning the Causes of Actions in World Action Models

## Insight
视频预测需要场景全部变量，动作却通常只依赖其中一部分。论文证明：若观测编码可逆、动作机制非退化、拟合过程满足同噪声耦合，且估计动作雅可比的支撑不大于真实支撑，则动作相关变量块可在可逆变换下被识别，动作依赖结构可识别至变量置换；无需时间依赖或干预。证明是坐标块级而非单变量级。

## Motivation
联合预测视频和动作的 WAM 可能把背景等干扰变量带进动作表示，模仿数据拟合良好也不能排除这种纠缠。因果状态压缩能帮助决策，但已有可识别性结果常依赖时序、干预或完整潜变量恢复，机器人演示未必满足。

## Method
理论上在动作机制的雅可比支撑上施加稀疏约束，预测支路仍读取完整状态。实现上从 Cosmos 3 Nano 出发，在动作头前加入对干净视觉/任务 token 的注意力路由，以 top-32 注意力质量损失鼓励稀疏；维持原有视频与动作联合 rectified-flow 损失。注意默认模型仍保留稠密视觉到动作通路，token 稀疏只是理论约束的代理，理论结论不能直接套用到实际网络。

## Experiment
合成实验设 20 个潜变量、其中 4 个影响动作：稀疏模型选出 4 维后，动作相关线性探针 R²=0.9957，额外干扰信息 Δnuis=0.039；对照稠密读出 Δnuis=0.646。RoboCasa365 的 17 项任务平均成功率从 0.24 升至 0.43，13 项改善；真实 Franka 堆叠 50 次试验成功率从 0.46 升至 0.82。四个挑选的高表现任务中，仅保留路由 token 为 60.3%，等量随机 token 为 24.5%，完整模型为 71.3%；LIBERO 四套任务亦报告改善。

## Value
提示视频世界模型共享表征时应区分“预测所需”和“动作所需”信息；可借鉴为决策头加局部稀疏路由并用干扰信息探针评估。下一步要验证分布变化下的鲁棒性及真实因果可识别性。

## Strengths
给出明确的条件与块级可识别性证明；合成真值、机器人闭环和 token 保留干预相互补充；与同训练配方的 Cosmos 3 比较。

## Weaknesses
定理依赖可逆观测、精确支撑稀疏和强非退化条件；实际软注意力及保留的稠密通路不满足这些条件。路由 token 的充分性仅在表现最好的四个任务测试，跨任务和背景扰动的因果稳健性未验证。

## Future Work
作者指出需进一步研究单变量级可识别性，以支持更精确的干预；其他因果 WAM 问题仍待探索。

## Rating
创新度评分：3/5 - 块级可识别性分析与稀疏动作路由有新意，但实际系统只近似理论约束，性能收益的机制尚未完全隔离。
相关度评分：3/3 (Core) - 直接研究联合视频预测与动作生成的隐式世界表征。

## TL;DR
用稀疏动作路由分离视频预测与控制所需状态，并证明理想条件下的块级可识别性；理论与实现有落差，值得精读。
