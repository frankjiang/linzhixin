# RxBrain: Embodied Cognition Foundation Model with Joint Language-Visual Reasoning and Imagination

## Insight
论文的 insight 是：具身规划中语言和视觉想象不是冗余模态，而是互补的认知表示。语言负责动作分解、约束和时序逻辑，视觉负责每一步应达到的物理状态；只输出文字计划或只生成未来图像都不足以形成可执行意图。推论是让模型在同一 planning sequence 中交替生成 reasoning text 和 imagined state image，可以把任务逻辑与世界状态绑定起来。

## Motivation
该文解决 VLM 和 generative world model 的分离问题。VLM 擅长场景理解和语言决策，但目标物理状态通常隐式；视频/世界模型可预测状态变化，却缺少明确因果推理、约束检查和任务分解。对机器人而言，真正有用的是“下一步做什么”与“做完后世界应是什么样”的联合表示，因此是具身世界模型和 WAM 的关键问题。

## Method
RxBrain 基于 HY-Embodied-0.5，采用 modality-aware MoT。文本、视觉理解、视觉生成有专门 FFN expert，视觉理解 token 与视觉生成 token 共享 vision transformer 的 QKV，以减少理解/生成表征割裂。生成形式支持三种：文本自回归；4-frame future visual prediction，在 VAE latent space 用 flow matching 并行去噪；interleaved generation，按 `<text step><Image latent>` 左到右生成，每个生成图像再经 VAE decode 和 ViT re-encode 加回上下文。训练目标组合 text next-token、image flow matching 和 interleaved text-vision loss，并用 inference-aware visual state construction 减少训练/推理 mismatch。

## Experiment
数据构造管线从 50,177.2 小时、约 2,150 万 trainable segments 的具身视频中，通过 temporal segment annotation、quality verification、segment structuring 构建 L0-L3 supervision：单步状态变化、step-level planning、subgoal planning、final-state imagination。RxBrain-Bench 包含 EVQA、WorldPred、JointPlan 三轨。通用生成 GenEval 为 82.4，与 Bagel 82 接近；多视角/3D 理解中 3DRSBench 54.1、MMSI 35.8、MindCube 47.5、SITE 54.9 多项最佳。EVQA overall 72.7，低于 Qwen3.5-4B 78.1 和 Cosmos3 76.7，但 Success Detection 85.1、Simulation Planning 51.6 最好。WorldPred 上 Sgen 0.62，优于 Cosmos3-Nano 0.591 和 Wan2.2 0.429；JointPlan 上 Splan 0.68，优于 Cosmos3 agent 0.521、BAGEL 0.503、Qwen-Agent 0.431。动作扩展中，加入 Action MoT 和 gated expert fusion，在 3 个真实机器人任务上平均成功率 87%，高于 pi0 68% 和 pi0.5 82%。

## Value
价值较高，尤其是把“世界状态预测”放进显式语言规划循环，而不是作为独立 video generation 模块。对视频世界模型研究的启发是：未来帧评价不应只看视觉保真，还要看它是否与 subtask text、goal progress 和后续决策一致。对 WAM 的启发是可从 joint plan supervision 中迁移动作生成能力。

## Strengths
统一架构覆盖理解、生成、未来预测、joint planning 和 action；数据构造层级完整；自建 benchmark 正好评估文本-视觉联合规划而非单项能力；WorldPred/JointPlan 相比强模块化 baseline 有明显优势；真实机器人动作扩展结果强。

## Weaknesses
系统很大，很多组件来自已有 HY-Embodied、FLUX VAE、MoT 和大规模数据工程，单个算法创新边界不够清晰；WorldPred 的 temporal plausibility 只有 0.53，视觉想象仍是短板；EVQA overall 不如 Qwen/Cosmos；MLLM-as-judge 依赖 GPT-5.5，存在评测偏差；OOD embodiment 仍需 fine-tune。

## Future Work
作者提出扩大模型和训练数据规模，提升复杂推理、细粒度视觉想象和长程规划；增强 agentic autonomy，使模型能分解开放任务、监控进展、修正计划并与环境交互；还提到需用 RL 或 sequence-level optimization 缓解文本自回归与视觉 flow matching 的跨模态推理 mismatch。
