# NavWAM: A Navigation World Action Model for Goal-Conditioned Visual Navigation

## Insight
核心 insight 是：导航世界模型的 future-view prediction 若仍依赖外部 CEM 才能变成动作，闭环控制效率和鲁棒性都差；把未来视图、goal-progress value、action chunk 放进同一 latent canvas 共同去噪，能让 visual foresight 直接产生可执行动作。

## Motivation
解决 image-goal visual navigation 中“世界模型会想象但不会行动”的问题。NWM/Cosmos Predict2 类方法预测候选未来再用 CEM 搜索动作，开销大且容易漂；直接策略如 OmniVLA 能动作但缺少可解释未来预测。该问题对 embodied world model 很关键。

## Method
基于 Cosmos Predict2 2B 构建九帧 latent canvas：底部条件帧包含 blank、当前 state、goal image、当前 egocentric image；生成帧包含 action chunk、future state、两帧未来视图、goal-progress value。非图像变量广播到 latent spatial grid，动作/状态/标量从对应帧均值解码。训练有 policy/world-model/value 三种 conditioning mode，主推理只用 policy mode，无 CEM；可选 value-guided best-of-N。

## Experiment
离线用 GO STANFORD、SIT，真实部署在 Diablo 机器人 24 个 indoor image-goal episodes。GO STANFORD 上 fine-tuned NavWAM ATE/RPE 0.192/0.070，优于 NWM CEM。消融显示 image-only future prediction 不足，加入 action/state/value 后 ATE 大幅下降；去掉 future-view loss 后 h=8 ATE 从 0.192 升到 0.262。SIT 上 NavWAM 比 OmniVLA ATE 更低、SR 略高。真实成功率 NavWAM 19/24=79.2%，OmniVLA 58.3%，NWM 16.7%。成本上 NavWAM 单次约 205.7ms，而 NWM CEM N=120 约 233831ms/act。

## Value
对“世界模型如何变成 policy”很有启发：future prediction 既不能单独作为规划模块，也不应被完全丢弃；应和动作/value 共同训练。局限是 image-goal、室内、单机器人规模较小；语言/对象目标和 best-of-N 何时有用仍未充分评估。
