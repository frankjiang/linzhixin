# AGI Maze as a Benchmark Framework for World-Modeling Agents

## Insight
论文的 insight 是把 LLM “世界模型”能力从规则发现转向部分可观测状态表示：如果环境只给文本局部观察，agent 必须维护地图、位置、隐藏机制和不确定性，而普通 next-token inference 不会稳定形成可操作的内部世界状态。实验显示，允许模型把记忆写进 prompt 会改善强模型表现，但仍脆弱且低效。

## Motivation
许多 LLM reasoning/ARC-like benchmark 接近 fully observable 或只测规则归纳，无法区分模型是否构建 persistent world state。作者提出低带宽文本迷宫，剥离视觉感知，把瓶颈集中到状态跟踪、地图构造、belief update、长程规划。对用户关注的视觉/3D/隐式世界模型是间接相关，偏 LLM agent benchmark。

## Method
AGI Maze 是 grid maze API：agent 只能执行 up/down/left/right 等动作，接收文本或结构化 observation；地图不可见，包含墙、monolith 出口、钥匙、宝箱，扩展机制包括 river forced movement、pit teleport cycles、boat/grenade/flashlight 等。任务分为 Tutorial、Training、Classic、Extended、Hidden，Hidden 用未知机制防止硬编码。论文还定义 vanilla LLM agent 和 planning-agent-with-notes 两种 baseline。

## Experiment
Vanilla LLM 在 Training 小迷宫上测试，GPT-4o Mini、GPT-5 Mini、Gemini 3.1 Flash Light、MiniMax 等均不能可靠解决，5x4 复杂迷宫几乎接近或低于 random。作者补充强模型在 S3-03 doubled step budget 下 GPT-5.5 约 30%、Gemini 3.5 Flash 约 40%；加入“先写 notes 再行动”的 working memory 后分别提升到 60%/70%，但轻量模型仍无改善。

## Value
作为“世界建模等于可维护状态表示”的诊断 benchmark 有一定概念价值，尤其提醒不要把语言规则归纳误认为世界模型。但它没有视频、3D、动作连续控制或 learned dynamics，对用户研究方向技术参考有限。适合跳读 motivation 和 benchmark design，不建议深入。

## Strengths
亮点是作为“世界建模等于可维护状态表示”的诊断 benchmark 有一定概念价值，尤其提醒不要把语言规则归纳误认为世界模型。

## Weaknesses
不足是它没有视频、3D、动作连续控制或 learned dynamics，对用户研究方向技术参考有限。
