# PhysMani: Physics-principled 3D World Model for Dynamic Object Manipulation

## Insight
PhysMani 的 insight 是动态操作需要在 3D 几何中显式预测物体未来，而不是只用 RGB 视频或被动策略特征。Observation 是动态目标、移动容器和高速交互下，VLA/视频模型难以提供稳定的几何未来；3D Gaussian 可保留场景结构，但需要物理约束的运动预测。作者用 divergence-free per-Gaussian velocity field 表达未来动态，并把它接入 action policy。

## Motivation
论文解决动态物体操作中的未来建模和控制问题。同行包括 VLA、3D policy、Gaussian scene representation 和视频 world model；很多方法要么缺少 3D 未来，要么计算慢，要么物理一致性不足。该问题直接处在 3D world model + robot manipulation 交叉点。

## Method
PhysMani 学习 physics-principled 3D Gaussian world model。在线阶段基于 FreeGave 形式优化每个 Gaussian 的散度为零速度场，先 T=50 步优化 velocity field，再 T'=7 步细化 Gaussian 属性，可预测未来 RGB/D 约 10 步。Policy 使用 3DFA backbone，并通过 learnable token cross-attention 注入局部邻域速度和未来动态信息。

## Experiment
提出 PhysMani-Bench，含 16 个动态操作任务和 normal/high speed 设置。仿真平均成功率 PhysMani 45.9，高于 3DFA 37.8、3DDA 35.1、ManiGaussian 22.5。未来预测上，相比 FreeGave，next-1 PSNR 从 19.47 提到 26.90，next-10 PSNR 从 17.89 到 20.00，同时推理约 205ms/frame，快于 FreeGave 607ms/frame。真实 Astribot S1 实验 4 个任务平均成功率 62.5，高于 3DFA 45.3。消融表明去掉 future dynamics token 或 learnable token 都会降成功率。

## Value
价值很高：它展示了 3D Gaussian world model 如何真正为动态 manipulation 提供未来信息，而不只是做重建或渲染。对 3D 世界模型、物理先验和策略接口设计都有直接启发。

## Strengths
问题和指标都贴近动态操作；有仿真 benchmark、未来预测指标、真实机器人验证；3D 表达与物理速度场结合清楚，能解释为什么比纯视觉或纯策略特征好。

## Weaknesses
在线优化仍有计算成本；divergence-free velocity field 不覆盖所有接触/碰撞/非刚体物理；长时预测仍有限；benchmarks 是否覆盖开放世界动态还需验证。

## Future Work
作者没有展开太多未来方向，但自然延伸包括更丰富的物理约束、更长 horizon、接触建模、跨对象泛化和降低在线优化成本。
