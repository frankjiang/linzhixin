# A Control Theory of Predictability in Latent World Models

## Insight
论文最强 insight 是：latent world model 的验证集预测误差不是控制性能的充分指标，因为 planner 查询的是候选动作诱导的可达分布，常偏离数据分布。真正需要约束的是 predicted plan-cost 与 true plan-cost 在候选集上的 gap；planner suboptimality 可由该 gap 的上确界控制。

## Motivation
JEPA/Dreamer/DINO-WM 类 latent world model 常用一步或多步预测误差评估，但低误差模型仍可能让 MPC 选错动作。作者要回答“什么样的 predictability 对 control 有用”，这是隐式世界模型用于规划的关键问题。

## Method
论文建立控制理论分析：证明数据平均误差无法约束部署查询分布上的误差；危险在于 consequential holes，即模型低估真实代价高的动作。在线性控制前提下，gap 分为 on-manifold residual 和 off-manifold divergence；前者受 latent transition operator 的谱/非正规性影响，后者由 planner 可达 off-manifold 区域主导。作者提出简单干预：加入线性 state readout 减少 on-manifold metric tax。

## Experiment
Latent-MPC 在 TwoRoom 和 PushT 上验证，一步验证误差与控制成功率弱相关；TwoRoom success one_step 88.0、rollout_full 88.7，PushT one_step 84.7、rollout_full 91.3，但单步误差接近。跨任务 state readout 提升 Cube +7.8pp、TwoRoom +5.0、PushT +2.8、Reacher +1.2，收益与原始模型饱和度负相关。合成 operator 实验证实 spectral tax frontier 和 off-manifold rollout tax。

## Value
这是隐式/latent world model 方向非常值得精读的理论论文。它把“预测准不准”转为“对 planner 查询是否代价一致”，对设计评测、训练目标和安全 monitor 都有启发。

## Strengths
理论命题和实证对应紧；清楚解释了验证误差与控制失败之间的断裂；给出简单可测的 off-manifold amplification 和 state-readout 干预。

## Weaknesses
理论依赖线性控制前提；部分实验 seed 少，Jacobian amplification 只是 proxy；没有直接给出大规模视频/机器人模型上的训练算法。

## Future Work
作者展望包括推导更 sharp 的 extrapolation tax 常数，用 simulator counterfactuals 验证 `Lhat`，扩展 PushT 到 5 seeds，并结合线性 readout 与 counterfactual training。

## Rating
创新度评分：4/5 - 对 latent world model 的控制可预测性给出清晰理论框架和验证。
相关度评分：3/3 (Core) - 直接面向 JEPA/Dreamer 式隐式世界模型和规划。

## TL;DR
证明验证误差不能代表 latent world model 控制质量，关键是可达分布代价缺口，值得精读。
