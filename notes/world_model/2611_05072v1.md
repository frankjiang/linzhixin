# Trajectory Evaluation via Rollout-Free World Model for End-to-end Autonomous Driving

## Insight
观察：对每条候选轨迹逐步生成未来 BEV 场景，计算量随候选数和预测步数增长，递推误差也会影响打分。作者推论规划只需可查询的未来相关信息，因此让全部轨迹共享一份“未来可读”记忆。消融显示只加潜在模型而不加未来语义监督，PDMS 从 88.9 降至 88.4；加入未来监督后升至 90.5，支持“预测信息必须进入共享记忆”的判断。复杂度分析和延迟/显存实验支持其效率主张，但没有证明共享记忆足以表示所有动作引起的未来。

## Motivation
自动驾驶候选轨迹评价需要预见碰撞、越界和进度；WoTE 等方法为每条候选轨迹展开未来状态，开销与累计误差较大。论文解决的是世界模型服务决策时“预测什么、在哪里计算”的关键问题，对隐式世界模型尤有借鉴意义。

## Method
TransFuser 融合多视图图像、历史 LiDAR 与自车状态为 BEV，锚点分支细化出 1024 条候选轨迹。Transformer 把当前 BEV 编成一次共享场景记忆。训练时，以时间嵌入和 SE 式通道门控从记忆读出多个未来时刻，用共享解码器预测语义 BEV，并联合轨迹、模仿奖励、模拟器奖励损失训练。推理时丢弃未来解码器；各候选路点以当前自车坐标中的位置作查询，经可变形注意力稀疏采样共享记忆，聚合后预测模仿及安全/进度奖励，选最高分轨迹。相较动作条件逐步模拟，方法转向决策充分的隐式表示；技术组件多为成熟模块，主要创新是共享记忆与训练/推理分工。

## Experiment
NAVSIM-v1 用 PDMS（NC 碰撞、DAC 可行驶区、EP 进度、TTC、舒适度）评价 12,146 个测试场景；RFWorld 得 90.5，高于 DriveDPO 90.0、WoTE 88.3。Bench2Drive 的 220 条闭环路线中，成功率 31.36%、驾驶分 62.38，较 TCP 分别高 1.36 个百分点和 2.48 分。消融：基础版 88.9，仅未来监督 89.4，仅共享模型 88.4，两者结合 90.5；未来监督时刻从 0 增至 8，PDMS 88.4→90.5。1024 候选时单样本延迟 37.5 ms（WoTE 49.2 ms），训练显存 8.7 GB（33.9 GB）；可视化显示行人避让与车道保持改善。

## Value
提出实用的“训练时用未来目标塑形、推理时只读取潜在记忆”范式，可迁移到动作价值评估、Dreamer 类隐式规划和视频模型的轻量决策接口，值得精读。下一步需检验强交互场景中候选动作改变他车行为时，共享的候选无关记忆是否仍充分。

## Strengths
把预测式世界模型的计算位置讲清楚，并给出复杂度、显存和延迟实测；既有开环指标，也有闭环驾驶验证；未来监督与共享模型分别消融，避免把收益笼统归为“加了世界模型”。

## Weaknesses
共享记忆仅由当前观测构建，无法显式模拟不同自车动作诱发的其他参与者反应；空间查询只显式编码路点位置，未显式编码到达时刻，同地点不同时刻的风险可能难区分。NAVSIM 相对强基线仅高 0.5 PDMS，Bench2Drive 成功率仍只有 31.36%；视觉提升不能单独证明潜在记忆学到了准确动力学。

## Future Work
作者提出用稀疏场景 token 替代稠密 BEV 以扩展分辨率，以伪标签或自监督时间目标减少对未来语义标签的依赖；还需改善感知骨干及观测范围边缘的失效。

## Rating
创新度评分：3/5 - 共享记忆加训练期未来监督改变了候选评分的计算路径，结果稳定，但核心算子是现有 Transformer、门控和可变形注意力的组合。
相关度评分：3/3 (Core) - 直接研究用于规划的隐式世界表示与未来预测监督。

## TL;DR
用未来语义监督塑形共享潜在记忆，推理时稀疏读取而不逐条模拟；隐式世界模型设计值得精读。
