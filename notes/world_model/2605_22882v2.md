# GEM-4D: Geometry-Enhanced Video World Models for Robot Manipulation

## Insight
视频世界模型能生成视觉逼真的未来帧，但无法保证帧间3D对应关系(inter-frame correspondence)的一致性——同一物理3D点在相邻帧中的投影不遵循物理约束(深度、相机运动、场景流)。核心洞察：4D几何基础模型(如PAGE-4D、DUSt3R系列)的表示已经编码了决定帧间对应关系的所有因素(D, R, T, ΔX)。因此可以将几何基础模型作为"对应关系教师"，通过特征级蒸馏(而非输出空间修改)将几何结构注入视频backbone的中间表示。

## Motivation
- 问题：视频世界模型预测的视频虽然视觉逼真，但缺乏物理可执行性——刚体非刚性变形、接触漂移、深度不一致等破坏动作提取
- 同行方法：TesserACT/3DFlowAction等修改输出空间(显式预测深度/法线/流)，需大规模标注且约束模型容量
- GEM-4D的关键区别：不修改输出空间，而是将几何结构蒸馏到模型内部表示中，推理时保持单流架构零额外开销

## Method
- **Geometry-Enhanced Velocity Alignment**：
  - 视频流：Video DiT预测视频latent的velocity field(flow matching)
  - 几何流：Geometry DiT以Video DiT中间特征m_t为条件，预测几何latent的velocity field
  - 关键设计：几何DiT仅从m_t获取场景信息（不访问像素/相机参数/深度图），迫使m_t必须编码完整的几何因素
  - 联合目标：L = L_FM^vid + α·L_FM^geo，梯度通过m_t反传给视频backbone
  - 推理时丢弃几何分支，零额外成本
- **Adaptive Inverse Dynamic System (AIDS)**：
  - 3D场景定位：Qwen3.5-VL + SAM-2分割 + FoundationPose恢复末端执行器6-DoF位姿
  - 双准则置信度门控追踪器：分离渐进漂移(重锚定)和突变崩溃(VLM重定位)
  - 几何-运动学姿态回退：平移用深度反投影，旋转用球面线性插值
  - GraspGen生成抓取候选 → 逆运动学转换为动作序列

## Experiment
- 4D场景重建质量：Droid(真实)和RLBench(仿真)上PSNR/SSIM/LPIPS/深度误差/点追踪AJ均SOTA
- 机器人操作：真实Droid任务成功率61%→81%(+20pt vs TesserACT)，RLBench达63-82%
- 消融：几何蒸馏对深度一致性贡献最大(depth MAE降50%+)，AIDS的双准则追踪器比单一追踪器鲁棒
- 对比CogVideoX、WAN 2.2-14B、TesserACT等视频模型

## Value
工作价值很高——优雅地解决了视频世界模型的几何一致性问题，"几何基础模型作为对应关系教师"的思想富有洞察力。非对称蒸馏设计(训练时双流、推理时单流)在效率和效果间取得理想平衡。AIDS系统完成了从世界模型到机器人动作的完整闭环。对视频世界模型在机器人操作中的实际部署有直接推动。
