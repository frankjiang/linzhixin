# DSWAM: A Dual-System World Action Foundation Model for Fine-Grained Robot Manipulation

## Insight
论文借鉴 dual-system 思路：快速物理执行不应每步都依赖慢速语言推理，低层 WAM 应负责连续动作，高层 VLM 只在粗粒度指令分解时介入。这样可以同时保留语义泛化和低延迟精细控制。

## Motivation
现有 VLA 在复杂精细操作中常出现语义强、执行弱的问题；纯 WAM 又可能缺少长任务分解能力。尤其在折叠、整理等任务中，动作延迟、子任务切换和物体形变都很关键。

## Method
DSWAM 包含 System 1 WAM executor 和可选 System 2 VLM subtask planner。executor 通过 action prediction 和 video co-training 学习物理动作，推理时直接输出 action chunk，不生成未来视频。System 2 将粗粒度语言命令分解为子任务。系统还使用 TensorRT、异步执行和实时 chunking 降低控制延迟。

## Experiment
论文在 DeMaVLA 折叠 benchmark、RoboTwin 2.0 和真实机器人任务上评估。为公平比较，主要实机折叠实验关闭 System 2，仅比较 WAM/VLA 执行能力。真实折叠成功率 96.3，平均耗时 1'44，优于 DeMaVLA 和 pi0；RoboTwin 2.0 clean/randomized 均约 92。子任务监督在 sorting 等任务中提升明显。

## Value
工作价值在于把 WAM 放到真实精细操作里做公平评测，强调低层物理执行和高层语义规划的边界。对构建机器人 world-action model 有工程启发。

## Strengths
实机结果强；系统延迟优化务实；dual-system 分工清晰；对 VLA/WAM 比较相对公平。

## Weaknesses
技术上偏系统整合，单个模块创新有限；System 2 在主要公平比较中关闭，完整双系统收益展示不够；失败模式分析较少。

## Future Work
未来可增强高层 planner 与低层 WAM 的闭环交互，扩展到更多动态和接触密集任务。

## Rating
创新度评分：3/5 - 双系统设计和实机部署有价值，但方法创新偏组合。
相关度评分：3/3 (Core) - 直接研究机器人 World Action Model。

## TL;DR
双系统 WAM 将语义分解和物理执行分离，并做公平实机比较，机器人 WAM 方向值得选读。
