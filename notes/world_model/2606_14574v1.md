# SIMMER: Benchmarking Latent Failures in LLM Executable Planning with a World Model

## Insight
核心 insight 是：LLM 规划的危险错误不只是不满足前置条件的 immediate failure，更重要的是执行时不会报错、但经由隐式状态传播破坏最终目标的 latent failure。论文用厨房任务观察到污染、温度、遗漏步骤、设备未关闭等状态不会被现有 benchmark 捕捉，由此推论需要比 PDDL 前置条件更细的状态机世界模型。证明方式主要是构造 SIMMER 执行器并系统评测 100 个烹饪任务，而非理论证明。

## Motivation
现有 TextWorld/ALFWorld/VirtualHome 等环境可形式验证但状态简单；自然语言计划评测更灵活但只看文本相似或显式成功，无法发现“每步看似可执行但最终不安全”的错误。该问题对 household agent 和机器人规划有安全意义，但与视频/3D/隐式 latent world model 的技术主线间接相关。

## Method
SIMMER 包含三部分：厨房符号世界模型、失败分类、状态机执行器。世界模型定义 77 个动作、262 个对象及约 46,800 个语义交互，动作用参数、前置条件、effects 描述，对象有属性、状态、位置。执行器逐步解析 `[ACTION] <object> (id)` 计划，检查 immediate failure，更新污染/熟化/位置等隐式状态，最后做 post-execution audit 找 latent failure 和 irreversible failure。还提出 counterfactual foresight prompting，让 LLM 在每步行动前显式预测状态变化和风险。

## Experiment
数据是 100 个厨房任务，覆盖 12 类烹饪技术，平均 26.6 个动作、31.5 个对象。评测 GPT-5.4、Gemini 3 Flash、Claude Opus 4.6、Llama 3.3 70B、DeepSeek V3.2、Qwen 3.5 27B，温度 0。主指标是包含任意失败、immediate、latent、irreversible 的计划比例和每计划失败数。最佳模型也只有不到 17% error-free；latent failure 覆盖 29-56% 计划，irreversible failure 20-45%。Self-Refine 对闭源模型有效但不稳定；counterfactual foresight 在 GPT-5.4/Claude 上最多减少 72% latent failure、75% irreversible case。

## Value
价值主要在评测视角：把“隐性状态传播”和“不可逆错误”从普通执行成功率中分离出来，对 LLM planner/机器人任务验证有启发。技术贡献是符号规则和 benchmark，而不是可学习的视频/3D/latent world model。对我们更有用的是 failure taxonomy 和评测协议，可借鉴到世界模型 rollout 的安全审计。
