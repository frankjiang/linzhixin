# HGWM: Hierarchical Graph-Guided World Model for Zero-Shot Object Navigation via Graph Matching

## Insight
Observation：寻找未见目标时，“卧室可能有床”等语义先验有助于定向，但先验不能当作已观测地图。HGWM 将目标房间/锚点假设与 RGB-D 观测图分开，再把关系匹配分数纳入方向选择。HM3D v0.2 中移除目标先验或关系修正，SR 各由 `74.4%` 降至 `72.1%`；这支持组合设计，但由于缺少严格同成本、同配置的匹配独立消融，不能证明提升专由图匹配带来。

## Motivation
零样本 ObjectNav 需要在目标未可见时决定搜索方向，并记住已见过的房间与物体。WMNav 等利用全景 VLM 和价值地图，场景图方法保存关系，但类别目标通常缺少可用于方向评分的房间、锚点结构。这个问题与具身 3D 场景记忆有关；论文所谓“世界模型”是符号性假设及记忆，不是学习转移核或生成未来图像的模型。

## Method
- 输入目标类别、六方向全景 RGB-D 和平面位姿。Qwen2.5-7B-Instruct 生成房间、锚点、连通关系的目标先验图；在线将观察到的对象、房间和粗略深度投影写入持久空间语义图，假设节点与真实观察分离。
- Gemini-1.5-Pro 对六个候选方向给 `0–10` 粗语义分数；细阶段用房间、对象、空间关系、语义一致性、深度五种手工特征与目标图匹配，算 `0–1` 兼容度。LLM 可提议关系并推荐方向；匹配分数门槛将决策切换为探索、集中搜索、目标确认三阶段，按阶段权重融合粗分、细分和 LLM 建议，裁剪至 `0–10`。
- 融合分数更新继承自基线的好奇价值地图，由局部可通行区域和规划模型选动作；储存值采用 `min(旧值,新值)`，历史低估可能持续压制方向。方法创新集中于类别到目标图及其与观察图的显式评分接口，多数特征、阈值和权重为经验规则。

## Experiment
- Habitat 仿真的 HM3D v0.1/v0.2 与 MP3D；每集最多 40 次决策、到目标 1 米内算成功。指标为成功率 SR 和路径长度加权成功率 SPL。HM3D v0.1 对 WMNav 为 `62.6/31.5%` 对 `58.1/31.2%`，MP3D 为 `46.8/17.9%` 对 `45.4/17.2%`；SR 增益分别 4.5/1.4 个百分点，SPL 仅 0.3/0.7 点。
- HM3D v0.2：完整模型 `74.4/31.9%`；无记忆 VLM `67.8/29.3%`、体素记忆加直接评分 `70.9/30.1%`。去先验 `72.1/30.8%`、去关系修正 `72.1/30.4%`、去 LLM 仲裁 `72.7/31.1%`、固定细特征权重 `73.5/31.3%`。换 Gemini 2.0 Flash 后 HM3D v0.1 为 `59.2/30.8%`。
- 三次 HGWM 运行的 HM3D v0.1 SR 范围 `62.3–62.8%`、SPL `31.2–31.7%`；没有与 WMNav 的配对区间，SPL 最低值等于 WMNav 点估计。展示的轨迹不能量化“减少绕圈”。约 2.3 秒的 Gemini 单次调用未包含完整每步多模型调用成本。

## Value
可借鉴“把常识先验保持为可证伪假设，再与空间记忆中的观测证据融合”的具身导航设计。对真正 3D/视频世界模型，论文缺乏可预测未来状态的转移模型和精确 3D 场景生成，更多是关系记忆与决策启发；需要严格隔离图匹配、记忆和额外 LLM 预算的收益。

## Strengths
明确区分假设图与观测图；给出完整决策公式、失败回退、四种组件消融及两个场景数据集；诚实说明结果是汇总点估计、修复代码仅通过离线测试，未伪称统计显著性。

## Weaknesses
WMNav 等对照的模型、训练和推理成本不匹配；体素基线同时改变表示和评分，图匹配独立贡献没有可信的同成本配对实验。额外消融无每集重跑记录、置信区间与精确查询总数；修复后代码的历史成绩缺乏可核查轨迹。房间/对象投影只是视角级粗定位，先验和错误观测均可能污染记忆；仅仿真静态室内环境，VLM 延迟显著。

## Future Work
作者提出动态场景中的时间图更新、多目标搜索、主动感知和真实机器人试验；还需补同配置图/体素记忆、独立匹配通道、异常室内布局及深度/定位噪声的受控评测，并报告全链路时延。

## Rating
创新度评分：2/5 - 将已有 VLM 导航、图记忆和规则匹配组合为新接口，主要增益小且因果归因不足。
相关度评分：2/3 (Related) - 涉及 RGB-D 空间语义记忆与 3D 具身导航，但不学习生成式或隐式动力学世界模型。

## TL;DR
用目标先验图与 RGB-D 观察图匹配指导零样本导航，成功率略升而路径收益有限；做 3D 语义记忆可选读。
