# Think Once, Act Fast: Cost-Effective Recursive Self-Improvement for Decision Model Harness

## Insight
观察：文本任务中，较慢的 LLM 可以把一次推理所得的经验写成可复用程序，而较快的决策模型只需在执行时读取相关模块。论文的训练过程显示 System-2 的触发次数随模块积累下降（ALFWorld 前后半段 22→3 次）；这是成本摊销的经验迹象，不能单独证明模块会持续自我改进。

## Motivation
轻量决策模型在复杂任务上容易失败；每步调用大型 LLM 又昂贵且慢。已有快慢系统协作主要决定何时调用慢模型。本文尝试让慢模型异步编写和修订外部辅助模块，使后续快模型决策复用推理结果。问题是通用智能体工程问题，与视觉世界建模方向关联很弱。

## Method
JevRSI 以 Jev/StartLux 作 System-1，在文本环境中选择离散动作；LLM 作 System-2，低置信或预测失败后异步诊断轨迹，编写三类模块：文本过程规则、观测转移图的状态提取程序、预测每个候选动作下一步效果的 Python 程序。按适用条件与历史成功率检索模块，把历史、建议、预测附在 System-1 输入中；以反馈修订或屏蔽失败模块。所谓 world model 是文本游戏的一步动作效果程序，既无视频生成、3D 动力学，也无 JEPA/Dreamer 式潜状态预测。

## Experiment
ALFWorld、BabyAI、TextCraft 各取 200 训练回合，并分别在同分布/分布外任务评测 Success Rate@1。StartLux-27B+DeepSeek 在 ALFWorld 分布外为 85.82%，裸模型为 45.52%；在 BabyAI 分布外为 68.66%，裸模型为 40.00%。但 TextCraft 分布外仅 64.00%，低于 StartLux-27B+Qwen 的 70.66%。文中同分布 TextCraft 的 100% 成功以约 $0.36 达到，GPT 智能体为 $5.38；System-1 每步 0.08–0.58 秒，LLM 为 2.14–15.58 秒。移除状态记忆使 ALFWorld 同/分布外各降 15.7/17.9 个百分点；移除过程规则使 BabyAI 同分布降 17.3 点。案例展示规则、状态图和一步文本预测的作用。

## Value
对本团队的视频、3D 与隐式世界模型研究参考价值有限；可借鉴的是将预测能力封装成可检查的动作效果模块，以及以执行反馈更新模块，但无法据此推断视觉动力学性能。

## Strengths
同时报告成功率、调用成本、延迟和模块消融；训练、同分布、分布外划分清楚；附录给出程序沙箱约束和提示词，便于理解复现条件。

## Weaknesses
实验全为文本任务，无连续控制、真实视觉、空间几何或长时潜变量滚动。多个组合并非持续获益：Jev+GPT 在 BabyAI 同分布和 TextCraft 分布外低于裸模型。System-2 触发次数下降可能由任务学习曲线、置信阈值或模块覆盖产生；缺少更严格的因果隔离。一步程序预测准确率与整体决策收益的对应关系也未充分量化。

## Future Work
作者提出改进 harness 开发和快慢系统协作，并扩展到噪声观测、连续交互和不确定动力学的真实具身/驾驶场景；目前均未验证。

## Rating
创新度评分：2/5 - 将已有快慢系统、程序记忆、检索和反馈修订组合，世界模型部分是任务专用的一步文本程序。
相关度评分：0/3 (Noise) - 实验与方法均针对文本智能体，不研究视频、3D 或 JEPA/Dreamer 式世界模型。

## TL;DR
让大模型异步编写文本动作预测和记忆模块，供快速决策模型复用；对视觉世界模型研究可跳过。
