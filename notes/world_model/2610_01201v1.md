# iSEE: Object Permanence Through Self-Supervision

## Insight
通常的槽注意力把每个槽在每帧都强制更新，遮挡时会改写物体身份。论文观察到槽对图像块的注意力相对于自身历史可指示“可见证据”消失；于是遮挡时冻结外观、继续推进位置，重现时再恢复绑定。静态 LA-CATER 的逐部件消融表明注意力证据、去位置编码与位置 walker 缺一不可。

## Motivation
无标签物体中心表征适合做可预测状态，但长期遮挡会导致槽被其他物体占用。传统跟踪往往用框、身份、可见性标签，或要求干净背景。若从视频自身学会物体恒常性，有助于视频世界模型的遮挡记忆和对象级预测。

## Method
以冻结 DINOv2 NoPE 特征训练槽编码器，每槽分为 60 维外观与 4 维位置，分别读取图像特征和坐标特征。推理时的时间证据归一化 TEN 比较当前与该槽历史注意力，低于阈值时保持外观、高于释放阈值时重新更新；位置在遮挡期间由局部图像块随机游走模型推进。walker 以槽重新出现后的编码位置为自监督终点，另用可见片段构造伪遮挡训练。另把位置差作为动作输入对象槽动力学预测器，做简单潜空间规划演示。

## Experiment
LA-CATER 静止/运动镜头评估遮挡期 amodal box mAP 与重现同槽率 SAME；MOVi-C/KITTI 评估 FG-ARI、mBO、HOTA，另做 20 段 MOVi-C 的规划示范。静止 LA-CATER 隐藏帧 mAP 80.9，监督 RAM 约 85.0；大于 4.2 秒遮挡的 SAME 为 77.5%，SlotContrast 为 23.9%；KITTI 39 个汽车重现事件上 SAME 为 48.4%，SlotContrast 为 29.0%。消融中 TEN、双流与 NoPE、walker 逐步把隐藏帧 mAP 从 6.6 提升到 80.9。规划演示将对象中心到目标的误差从 25.1 降至 5.2 像素，但只是表征空间验证。

## Value
对视频世界模型，遮挡状态应拆成“身份/外观保持”和“位置继续演化”，且用重现作为无需标注的监督。可与显式 3D 记忆或对象级动力学结合。

## Strengths
把注意力证据、状态拆分和自监督轨迹终点串成可解释流程；在合成遮挡与真实 KITTI 上都有验证，提供运动相机、时长分桶及失败案例。

## Weaknesses
真实 KITTI 仅 39 个汽车遮挡重现事件，且性能明显低于合成集；固定槽数、相似物体误绑定、提前释放与错误初始绑定仍会失败。规划使用视频中位置差作“动作”，未证明机器人可执行控制或长期世界模拟。

## Future Work
作者期待把证据、外观/位置分离迁移到其他对象中心模型，并发展能够穿越遮挡的规划表征；其展示的误绑定与提前释放是直接待改进点。

## Rating
创新度评分：3/5 - 组件多来自槽模型与跟踪思想，但无标签遮挡学习和各组件衔接有实质方法贡献。
相关度评分：2/3 (Related) - 对视频/隐式世界模型的对象状态维护很有借鉴价值，主体仍是自监督跟踪。

## TL;DR
用注意力证据、外观位置双流和重现自监督维持遮挡物体身份与位置；对象级世界模型值得精读。
