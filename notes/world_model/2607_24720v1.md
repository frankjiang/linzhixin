# The Physics of Multi-Turn Long-Horizon Planning: From Pre-training to Post-training via Single- and Multi-Teacher On-Policy Agentic Distillation

## Insight
有。论文的 observation 是：长程 agent 规划不是一个单一能力，而可拆成 planning pattern（可跨任务复用的推理骨架）和 planning knowledge（任务特定过程知识）。推论是：预训练阶段需要显式内化状态转移，后训练更适合塑形低互信息的 pattern，而不一定能可靠注入高互信息的新知识。作者用受控多轮合成环境、互信息解释和 OPD/MOPD 实验来支撑这一点。

## Motivation
论文解决 LLM agent 的 multi-turn long-horizon planning 能力从哪里来、如何在 pre-training/RL/多教师蒸馏阶段被改善的问题。现有模型训练数据不可控，难以区分“学会世界转移”“记住动作序列”“后训练激活模式”等因素。该问题对 agent 很关键，但与视频/3D/JEPA 世界模型的关系是概念和训练机制层面的，不是直接研究视觉 latent dynamics。

## Method
作者构造一个可控多轮环境，把任务设为从初始 inventory 合成目标物品；skill graph 定义状态转移，任务按 short/middle/long 步数划分，并保留未见 item mapping 做泛化评估。

方法分三段研究：预训练比较 direct action prediction 与显式 CoT world modeling；数据分布实验比较只含短程 atomic skills 与加入少量长程 trajectory；数据质量实验混入 optimal/suboptimal planning pattern。后训练部分比较 multi-turn GRPO 与 OPD，用最终 binary reward 与 teacher token distribution 分别塑形。MOPD 部分采用 cascaded multi-teacher OPD，分析 shared/compatible/conflicting planning patterns 下的能力整合。

## Experiment
预训练结果显示，显式 world modeling 在长程任务上显著优于 direct answering；短程 atomic skill 不能自动组合成长程规划，100% short 训练在 long pass@8 几乎为 0，而加入 5% long trajectory 后 long pass@8 到 11.46%。混入 suboptimal trajectory 会让 long performance 近乎崩溃。

后训练实验中，OPD 在低质量数据和长 horizon 区域比 GRPO 有更大有效区间，原因是 teacher dense supervision 的更新方向更一致；但把 teacher 的 unseen multi-path procedural knowledge 强行蒸馏给 student，会损害原有 in-domain world modeling，且不能完全建立新知识。MOPD 实验显示多教师蒸馏会收敛到 shared planning pattern：兼容 pattern 支持跨环境泛化，部分共享支持持续学习，完全冲突导致遗忘和干扰。

## Value
价值在于把 LLM agent 规划训练中的几个常见直觉拆开验证：显式状态转移、长程样本、轨迹质量、OPD 和多教师蒸馏各有边界。对我们有启发的是：世界模型能力不仅由模型大小决定，数据中的 transition 格式、action/trajectory 质量和共享 pattern 分布会直接影响长程泛化。局限是环境是符号合成任务，离视频/3D 物理世界模型还有距离。

## Strengths
亮点是受控变量设计完整；区分 pattern 与 knowledge 的视角有解释力；MOPD 的 mode-seeking/shared-pattern 解释比“多教师融合更强”更具体；实验覆盖 pre-training、RL post-training 和 consolidation 三阶段。

## Weaknesses
合成环境过于规则化，planning pattern 也主要是文本模板；world model internalization 依赖 CoT 格式，未证明等价于真实 latent dynamics；与视觉、机器人、连续控制的关联主要是类比；理论部分更多是解释框架而非严格定理。

## Future Work
作者没有给出很具体的开放路线，但结论指向更真实 agent 环境中的 long-horizon 数据构造、suboptimal trajectory 过滤、OPD/MOPD 边界分析，以及 conflict planning pattern 的缓解。

## Rating
创新度评分：3/5 - 受控研究设计和 pattern/knowledge 拆分有价值，但技术上主要是实验归因和蒸馏分析。
相关度评分：2/3 (Related) - 研究世界模型式长程规划机制，但不是视频/3D/JEPA/Dreamer 的核心视觉世界模型。
