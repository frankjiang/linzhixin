# Esports World Model Dataset

## Insight
观察：多人游戏的画面差异可能来自视角、战争迷雾或不同时间，而非共享世界状态矛盾。推论：世界模型数据必须同时记录共同时间线、各玩家动作与其可见信息。论文以 SC2 共享单位标签交叉核验，以及 Dota 2 同帧序号最大 0.83 秒时间差的审计，说明按回放时钟联结和区分「当前可见/旧快照」的必要性；这是数据证据，不是模型性能证明。

## Motivation
单玩家视频数据难以分离其他玩家的决策与环境动力学；现有电竞数据常缺跨玩家同步、精确动作或明确可见性。为训练联合动作条件的多人世界模型，需要多个参与者的局部观测与同一底层事件配对。这是重要但基础设施性质的问题。

## Method
从人类对局回放用原生客户端渲染玩家视角，同时解析原生动作、结构化状态和事件，并以游戏 loop/tick 对齐。覆盖 SC2 私有迷雾、Dota 2 队伍共享视野与独立镜头、CS2 第一人称视角。SC2 每 loop 采集双玩家 RGB/小地图及实体记录，区分当前可见单位与记忆快照，依据单位 tag 对齐共见实体；Dota 2 提供十人视角和逐帧 tick 表；CS2 提供玩家状态、按键与回合事件，核心集按每帧四 tick 联结。贡献是多视角数据组织及观测语义，不是新世界模型算法。

## Experiment
数据共 3053 场/地图、约 4880 玩家视角小时，但 CS2 扩展部分的小时数和行数为估计值。SC2 有 2320 局索引、4628 个完成视角，2314 局可训练；Dota 2 有 303 场、十人视角；CS2 核心为 50 图、7623 回合视角片段，另有 380 图扩展集。审计：560 万次 SC2 镜头命令与同一步观测位置对齐；13 局中 520 万条共见敌方记录可由 tag 联结并比较类型、位置、生命和护盾；六场 Dota 2 中相同帧序号最多相差 0.83 秒。没有训练世界模型基线，也没有预测质量或控制效果指标。

## Value
适合研究多人动作条件生成、局部观测与共享状态一致性、隐藏状态推断，并提醒评测必须按回放时间联结而非按帧序号。对视频世界模型的数据和评测设计有直接参考价值；在完成固定任务定义和基线前，尚难量化实际建模收益。

## Strengths
三类互补观测机制和人类竞赛行为；SC2 提供当前可见与记忆状态的细粒度标记；时间对齐规则、样例和初步数据审计较透明。

## Weaknesses
Dota 2 与 CS2 尚无逐实体玩家可见性标签，也没有 RGB 到实体的可靠映射；CS2 死亡后视角缺失，扩展集规模部分为推算；审计只覆盖部分比赛，缺固定世界模型基线与统一评测协议。

## Future Work
作者提出扩展 CS2 覆盖、为 Dota 2 补玩家可见性、建立图像到实体映射，并制定观测预测、隐藏状态估计和跨视角一致性的固定划分及基线，扩大字段和时间对齐审计。

## Rating
创新度评分：3/5 - 多游戏同步数据及 SC2 精确观测语义有实质数据贡献，但没有新建模方法或性能验证。
相关度评分：3/3 (Core) - 明确面向多人可交互视频世界模型的训练与评测。

## TL;DR
提供三款电竞游戏的多玩家同步视角、动作与状态，尤其标注星际争霸可见性；做多人世界模型值得精读。
