# QuantWM: Temporally Consistent 2-Bit KV Cache Quantization for World Models and Video Generation

## Insight
观察：Key 的量化 MSE 小于 Value，却往往造成更大输出失真；VBench 近乎不变时仍可见闪烁。原因是注意力误差取决于 QΔKᵀ，而非仅 ΔK 大小。K/V 分离实验、token 选择漂移和 Query 能量谱提供实证，二阶矩推导解释敏感方向。

## Motivation
自回归视频的 KV 缓存占用巨大，已有2比特量化忽视注意力路由变化。降低缓存成本且保持时间一致性，是交互世界部署的实际瓶颈。

## Method
沿用 QVG 的质心+残差量化。QSAC 根据历史 Query 二阶矩的对角线筛选4个候选质心，再按残差范围和敏感度选择；PSAC 把残余 Key 误差投影到 Query 的前8个主方向，用 INT8 系数补偿。每块只量化一次，仅用历史统计，首块关闭补偿以保持因果性。Triton 解包后恢复 BF16 K/V 供原生 attention 使用；并非直接进行 INT2 attention。

## Experiment
- 五个视频/世界模型，480p、720p和一分钟生成；比较 QVG、KIVI、BF16，报告 PSNR/SSIM/LPIPS、VBench、token 漂移、缓存与延迟。
- 表3：LongCat 相对 BF16 的 PSNR **20.683→25.508**、LPIPS **0.0784→0.0332**（QVG→本方法）。这些是保真度，不能解释为真实视频预测准确率。
- 表4：HY-World 注意力 top-1 漂移 **61.36%→13.92%**；表5验证两模块互补；附录消融秩、候选数量、完整/对角二阶矩。
- 缓存最高压缩 **6.20倍**；表6两模型延迟增加约 **5%–6%**，LongCat 因降低卸载传输而减少 **17.78%**。

## Value
启发是按下游注意力敏感度分配精度，而非仅优化张量重建。对长上下文视频世界模型部署有直接价值。

## Strengths
诊断—推导—修正—消融链条清晰；无需训练；覆盖多模型并提供真实打包存储和因果冷启动细节。

## Weaknesses
历史 Query 统计在强分布变化时可能失效；主要评价相对 BF16 的画面保真，缺少动作响应和物理一致性测试。一分钟实验主要使用文中已指出不够敏感的 VBench；缓存压缩倍数不等于整机峰值显存降幅，仍需临时解码张量。
