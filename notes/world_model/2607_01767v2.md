# Repair the Amplifier, Not the Symptom: Stable World-Model Correction for Agent Rollouts

## Insight
论文的 insight 是：agent rollout 中看到的错误节点往往只是症状，真正需要修复的是会放大未来误差的子图。稳定修复应优先降低 world model 的 error amplification，而不是局部改正一个可见错误。

## Motivation
LLM/agent 世界模型常用图表示任务状态、调用链或资源依赖。一次局部预测错误可能通过依赖边扩散，导致后续规划持续偏离。简单让 LLM 修复当前错误既费 token，也不一定稳定。

## Method
WM-SAR 从失败 planning graph 中估计 node-edge error amplification，包括 GEAF、coupling 和 marginal residual spectral relief，逐步扩展 connected repair region。只把这个紧凑子图交给 LLM 修复。理论上，residual spectral radius 控制 rollout error 和 planning regret。

## Experiment
实验主要在 synthetic calling-tree graphs、benchmark-inspired topologies 和 LLM repair 设置。WM-SAR 平均修复约 8.3 个节点，可显著降低 spectral radius，并让 H=32 的 MSE 保持平稳；与更大邻域修复效果接近但节点数约少 3 倍。Oracle ground-truth region coverage 并不等于最大 spectral relief，说明定位错误和稳定系统不同。

## Value
对视频/3D 世界模型关联弱，但对“world model rollout error 会被结构放大”这个观点有启发。可借鉴其从动态系统稳定性而非表面误差做修复的思路。

## Strengths
问题定义清楚；理论和算法都围绕误差放大；token-efficient repair 有实用意义。

## Weaknesses
证据主要来自合成图和诊断环境；和真实 Web/Tool agent logs 的距离还比较大；不适用于连续视觉动力学。

## Future Work
作者建议接入真实 agent traces，并学习更准确的 spectral repair predictor。
