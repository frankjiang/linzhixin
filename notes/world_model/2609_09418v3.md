# Valerant: An Automatic Navigable Game Map Generator via Action-Conditioned World Model Exploration

## Insight
观察：动作条件视频模型提供可选动作的视觉未来，却不会自动形成可复用 3D 空间；SLAM 可以把选定分支的画面积累为持久地图。推论：把“生成未来—几何重建—选择动作—提交状态”做成闭环，能从单张图扩展游戏场景。四例可视化和三项模块的定性消融展示可行性，但尚未量化地图几何一致性或导航可靠性。

## Motivation
交互式游戏视频模型主要输出二维观察序列，难直接变成支持碰撞和移动的持久三维资产。作者尝试无需再训练，从单张游戏截图自动探索并构建三维地图；该问题与视频世界模型的空间记忆和 3D 化直接相关。

## Method
冻结 Matrix-Game 3.0，在同一 16 帧上下文下对 5 种前进/转向动作各生成候选视频；MASt3R-SLAM 为每支估计相机轨迹和点云。按新覆盖与前进距离给无碰撞分支打分，恢复预动作状态后只提交最优分支。局部地面平面用相机—地面距离归一化抗尺度漂移；点云占据与原始深度互补检测穿墙；停在死胡同时同步回退世界模型与 SLAM 检查点。最终输出点云，可选 video2world 后处理。

## Experiment
从 VALORANT 截图开始，最多提交 15 步，单张 H100 推断；4 个主案例展示生成帧与俯视点云，另外 3 个案例定性去除地面修正、碰撞检测和回退。与 HY-World 2.0 在共同 3DGS 渲染空间比较，VLM 强制二选一偏好为 80% 对 20%，人类偏好 83.33% 对 16.67%。没有报告点云误差、闭环碰撞率、可达面积、耗时或用户数/统计置信区间。

## Value
提供将视频世界模型转为持久 3D 场景的实用管线思路；“只提交一条反事实分支”有助于避免分支状态污染。但尚不能据现有实验认定产物是完整可玩的游戏地图。

## Strengths
把生成、主动探索与 SLAM 串成明确闭环；针对单目漂移、几何漏检和局部陷阱给出可操作的补救机制。

## Weaknesses
各核心模型均为现成模块，创新集中在集成与启发式；结果主要是少量图例和主观偏好，缺乏几何/导航量化指标。点云覆盖多为狭窄轨迹周围，未验证长时闭环一致性、编辑性及真正的游戏引擎碰撞行为；五分支视频生成可能很昂贵。

## Future Work
作者计划改善几何一致性，并把点云转换为更丰富、可编辑的游戏资产。

## Rating
创新度评分：2/5 - 训练免集成方案有应用价值，但方法主要是现成视频模型、SLAM 与启发式搜索的组合。
相关度评分：3/3 (Core) - 直接连接动作条件视频世界模型与持久三维场景构建。

## TL;DR
以视频世界模型生成候选路径并经 SLAM 累积三维地图，概念相关但验证偏弱，可选读。
