# Feat2Go: Visual Feature-Grounded Value Estimation for Embodied Reinforcement Learning

## Insight
VLA模型的RL微调面临稀疏奖励瓶颈——二值终端奖励严重遮蔽了长程操作中的信用分配。核心洞察：可以利用预训练视觉世界模型(V-JEPA 2)的特征空间来构建基于表示的细粒度价值估计目标，取代粗糙的Steps-To-Go时序距离度量。具体做法：(1)用V-JEPA 2编码器计算每帧patch级特征与终端状态的相似度；(2)基于趋势检测的滑窗算法将episode切分为语义阶段；(3)层次化价值分配结合宏观阶段进展和微观阶段内插值。

## Motivation
- 问题：VLA策略的RL优化受限于稀疏的二值奖励（成功/失败），长程操作任务的信用分配极难
- 同行方法：Steps-To-Go(时序距离)、SRPO(自参考奖励)——参数化反馈方式不同但都不是从完整episode中提取结构化价值目标
- 关键差异：Feat2Go从预训练世界模型和完整episode中导出结构化进展信号，而非设计手工奖励

## Method
- **阶段1：Fine-Grained Value Estimation**
  - V-JEPA 2编码每帧为patch特征 → 计算与终端帧的patch级复合相似度(cosine·exp(-β·L1))
  - 趋势检测算法：滑窗线性回归检测突变点，将episode自动切分为语义阶段(semantic clusters)
  - 层次化价值分配：V_t = 宏观阶段进展(已完成阶段数/总阶段数) + 微观阶段内进展(归一化相似度)
- **阶段2：Embodied Value Model**
  - 基于Qwen3-VL-4B-Instruct，从视觉观测+指令预测离散化的价值(201 bins)
  - DROID数据集预训练 + 任务特定微调
- **阶段3：RL集成**
  - 密集终端奖励: R_dense = I(success) + (1-I(success))·V_θ
  - 兼容PPO和GRPO

## Experiment
- ManiSkill3: OpenVLA-OFT OOD成功率从17.5%→82.9% (+65.4%)，ID保持96.9%
- RoboTwin 2.0: 双臂操作平均88.8%成功率，6个任务全部SOTA
- 消融：Feat2Go vs Steps-To-Go——Feat2Go在所有泛化轴上均优，Execution维度提升+6.5%
- 训练曲线更稳定，收敛更快

## Value
