# Wonder: Video World Model Done Better

## Insight
有。论文的 observation 是：实时可控视频世界模型不是单纯视频生成问题，而是 control、memory、distillation 三者耦合；抽象 camera pose 条件在 few-step AR distillation 后容易漂移，全历史 attention 又让延迟随 rollout 线性增长。推论是：把相机轨迹渲染成 pixel-aligned visual evidence，并用 sparse full-fidelity memory 只激活相关 KV chunk，可以同时保留控制、长期记忆和实时性。论文主要以系统设计和大量对比实验支撑，而不是形式化证明。

## Motivation
论文解决 image/video-conditioned world exploration：给一张图或一段视频，用户可以实时移动相机探索未见区域、重访旧区域，或给已有动态视频换相机轨迹。已有 camera-controllable video generation 多是 bidirectional fixed-length，慢且不适合交互；streaming video diffusion 虽快，但常缺精确控制和长期记忆；开放 world model 系统容易出现 camera drift、memory loss、long-rollout degradation。该问题是视频世界模型的核心问题。

## Method
Wonder 基于 Wan2.1-I2V-14B，采用 teacher-to-student pipeline。Stage 1 训练 camera-conditioned bidirectional teacher；Stage 2 蒸馏为 few-step autoregressive student；部署时做 streaming runtime 优化。

关键技术有三点。第一，Pixel-Space Coordinate Field：构造合成 camera space，包含 dense 3D lattice scaffold 和 colored environment map，用 OpenGL 按目标相机轨迹渲染成与视频帧对齐的条件帧，再经 VAE 与 noisy target latent 拼接。它比低维 pose/Plucker embedding 更直观，也比 point-cloud rerendering 不受已观测视野限制。第二，Sparse Context Forcing：全历史 KV 仍以 full fidelity 保存，但每步只用 pooled query-key summary 检索 top-k 历史 chunk，并固定保留 initial chunk 与最近 r=2 chunk；训练阶段随机 drop optional historical edges，让 student 适应 sparse memory inference。第三，distillation 改进：timestep-wise Mixture of Students 用 G1/G2/G3 分工 4-step denoising；GAN Control Regularization 在 frozen teacher 的低频 feature dynamics 上做 adversarial control consistency，缓解 DMD 训练中的 camera drift 和 blur。

## Experiment
I2V benchmark 使用 1000 张多样图像，每图 5 条相机轨迹；V2V benchmark 使用 500 个含动态主体的视频，每个 6 条轨迹。指标包括 VBench 五项视觉质量（imaging/aesthetic/dynamic/motion/flickering）和相机跟随误差 RPE，RPE 由 Depth Anything 3 与 ViPE 估计后经 Umeyama 对齐。

I2V 对比 HY-WorldPlay 1.5、RELIC、LingBot-World-Fast、SANA-WM-Streaming、DreamX-World。Wonder 平均视觉分 0.8558 最高，translation RPE 0.0132、rotation RPE 0.0784 均最低。V2V 对比 Inspatio-World，Wonder 平均视觉分 0.8527 vs 0.8374，translation RPE 0.0187 vs 0.0436，rotation RPE 0.1119 vs 0.2470。定性结果展示长时重访一致性、未见区域生成和动态视频 re-shooting。系统声称 16 FPS、分钟级 rollout、延迟随历史增长保持稳定。

## Value
价值很高，是视频世界模型从“可生成短视频”走向“可交互、可记忆、可重访”的系统性工作。对我们有启发的是：camera control 不一定要用抽象 pose token，渲染成视觉条件可能更容易被扩散模型和蒸馏 student 保留；长期 memory 不一定要压缩，可以存 full KV、只稀疏激活。

## Strengths
问题定义贴近真实 video world model；控制表示、记忆机制、蒸馏正则和 runtime 优化是协同设计；I2V/V2V 统一；定量指标覆盖质量和相机准确度；相比 point-cloud rerendering，synthetic coordinate field 对开放探索更自然。

## Weaknesses
系统工程规模很重：14B backbone、三 student、32 张 H200 训练，复现门槛高；训练数据大量依赖自收集/自渲染、VLM caption/filter 和 DA3 pose estimation，数据配方影响可能很大；没有充分的 component ablation 表格量化每个模块贡献；评估仍以视频质量和 camera RPE 为主，缺少几何/物理可交互真实性、agent task success 或可控动作语义评估；未给出明确 limitations 段。

## Future Work
作者没有系统列 future work，但从方法边界看，后续应包括更强几何/物理一致性评估、机器人或游戏 agent 闭环任务、减少大规模训练成本、更多 action modality、公开数据与模块消融。

## Rating
创新度评分：4/5 - 在实时视频世界模型上做了完整系统级创新，尤其是 pixel-space camera field 与 sparse full-fidelity memory。
相关度评分：3/3 (Core) - 直接研究可控视频世界模型和长时记忆。

## TL;DR
面向实时相机可控视频世界模型的强系统工作，控制和记忆设计有启发，值得精读。
