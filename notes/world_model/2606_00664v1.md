# SKIP: Sparse Keyframe Interpolation Paradigm for Efficient Embodied World Models

创新度：3/5 | 相关度：2/3

## Insight
Observation：机器人操作视频中，任务相关信息集中在少数离散事件帧（如夹爪闭合、接触、释放），大量中间帧是视觉冗余的平滑运动。但现有关键帧选取标准（均匀采样、外观聚类）与操作的事件驱动结构不匹配，会丢失关键接触事件。推论：只要选对事件关键帧并用 action-conditioned 插值恢复密集帧，就能用远少于逐帧生成的计算量获得高质量 rollout。证明：在 LIBERO 和真实 Franka 机器人上，SKIP 生成的视频可几乎完全替代真实示范训练策略（成功率仅下降 1.3-6.7 pp），而逐帧密集生成则崩溃 48-58 pp。

## Motivation
问题：视频世界模型用于机器人操作时，逐帧扩散推理代价极高（长 horizon 操作轨迹通常需上百帧），限制了其作为数据增强和行为验证工具的实用性。同行方案要么直接均匀丢帧、RDP 几何简化，或 hierarchical generation，但这些忽略了操作特有的事件结构（夹爪变化等），关键帧可能被丢弃导致下游策略训练失败。这是一个实际而重要的效率瓶颈问题。

## Method
SKIP 包含三个模块：
1. **SKIP-Selector**（训练时运行）：融合光流(V)、语义(S)、本体感觉(P)三模态的 RBF 核相似矩阵，用 Kernel Temporal Segmentation (KTS) 做最优时间分段，再显式保护夹爪事件帧，输出稀疏关键帧索引集 K。
2. **SKIP-Generator**：在 Wan 2.2-TI2V-5B 基础上微调，仅以初始观测和语言指令为条件生成 K_kf 张关键帧（action-free）。
3. **SKIP-Reconstructor**：先用 gap predictor 估计关键帧间的帧间隔，再用 AC-FILM（action-conditioned flow interpolator, 基于 FiLM 的递归中点插值 + action 子序列 FiLM 调制）恢复密集轨迹。

关键创新：多模态融合的事件感知关键帧选取 + action-conditioned 轻量插值，将扩散计算集中在关键帧上。

## Experiment
- **效率**：比 Wan 2.2 密集生成快 4.16 倍。关键帧生成约 35s/轨迹，gap 预测 + 插值仅加 ~3s。
- **视频质量**：PSNR 21.635、SSIM 0.856、FVD 458，全面优于密集基线（FVD 4177）和其他稀疏选择方法。
- **策略训练**：SKIP-Mix70（70%SKIP + 30%真实）在 LIBERO 仿真和真实机器人上仅比全真实训练低 ~1 pp；SKIP-Mix100 在仿真中也仅低 ~1 pp。Dense-Mix70/100 则大幅崩溃。
- **消融**：多模态融合各分支逐步叠加均有增益；AC-FILM 优于 action-free FILM；KTS 优于 Uniform/Spectral clustering 等替代分割。

## Value
这是一个面向机器人策略学习的实用工程贡献。核心价值在于证明了"少数事件关键帧 + 轻量插值"可以替代密集生成甚至真实示范数据。对于构建可扩展的机器人数据生成管线有直接参考价值。局限：仅验证了固定第三人称单臂场景；长 compound episode 中相变处可能累积误差。
