# Grow-Prune-Freeze Networks: Adaptive & Continual Learning Technique for Olfactory Navigation

> 创新度：2/5 | 相关度：0/3

> TL;DR：提出 Grow-Prune-Freeze (GPF) 网络，通过动态增长/剪枝/冻结隐藏层实现持续学习，应用于嗅觉导航任务达94%成功率；与视频/3D世界模型无直接关联，可跳过。

## Insight

论文的核心 insight 是：将网络结构的 grow-prune-freeze 三阶段操作与随机矩阵理论（RMT）结合，可以在持续学习过程中保持权重矩阵的谱不变性（spectral invariance）。具体而言，Pennington & Worah (2017) 证明了单隐层网络中数据协方差矩阵的特征值分布经过非线性激活后具有幂等性，本文将该结论扩展到 n 层持续增长的网络（Theorem 1: Depth-Limit under Composition），证明在层同质性假设下 Stieltjes 变换收敛到唯一不动点，从而保证逐层增长不会破坏已学到的谱结构。冻结稳定层进一步锁定谱分布，防止灾难性遗忘。

## Motivation

**问题**：嗅觉导航是一个部分可观测、非平稳的任务，机器人需要在湍流气味羽流中追踪化学源。训练数据稀缺且非标准化，环境动态变化，需要实时持续学习能力。

**同行方案**：Elastic Weight Consolidation (EWC)、Progressive Nets、Dynamic Sparse Training (DST)、MorphNet、DEN 等。这些方法要么缺乏理论支撑（如 DST），要么结构固定不能自适应增长（如 EWC）。

**是否关键**：对嗅觉机器人领域是有意义的问题，但并非 CV/NLP 主流社区的核心议题。

## Method

**整体流程**：
1. **Grow**：从单隐层 MLP 出发，当验证损失停滞（连续 rho_k 个 epoch 变化 < omega_l）时，添加新隐藏层
2. **Prune**：基于 belief value 机制追踪每个神经元的重要性，belief 低于阈值 omega_p 且权重绝对值低于阈值的神经元被剪枝（继承 LeCun 1989 的 magnitude-based pruning）
3. **Freeze**：当早期层的权重在 rho_f 个 epoch 内变化小于 omega_f 时，冻结该层防止遗忘

**关键细节**：
- Belief value h 通过累加更新（公式2），以 eta_h = 1/k_max 渐近趋近1但不到达
- 理论分析基于 Gram 矩阵 M^(l) 的 Stieltjes 变换，证明深度增长下谱分布收敛
- 使用 Expected SARSA（而非 Q-learning）作为 RL 策略，对稀疏奖励的部分可观测环境更稳定

**创新程度**：中等。Grow/Prune/Freeze 各自并非新技术，组合+RMT 理论分析是主要贡献，但理论假设较强（层同质性等）。

## Experiment

**设置**：20m x 20m 2D 气味羽流模拟器（Farrell-Murlis filament model），智能体携带双天线传感器，22维离散状态空间，6个离散动作。

**指标**：源发现成功率（success rate）。

**结果**：
- GPF + Expected SARSA 在训练集达 98% 成功率，held-out 测试达 94%
- 基线（固定单隐层 Expected SARSA）最佳 96%
- 训练过程中经历3次 grow 事件（episode 2000/3000/4000），每次 grow-prune 后性能短暂下降后恢复
- 补充实验涉及 Atari RL、图像分类、自回归语言模型，但未声称 SOTA

**不足**：仅在单一模拟环境测试，缺少与主流持续学习方法（如 EWC、PackNet）的直接定量对比。

## Value

**整体评估**：这是一篇面向嗅觉机器人这一小众领域的持续学习工作，有一定的理论深度（RMT 分析），但实验规模较小，且核心贡献（grow/prune/freeze 的组合）的通用性尚未充分验证。

**对我们的启发**：有限。论文中的 "world model" 指的是嗅觉导航的环境模型，并非视频预测或 3D 场景理解意义上的世界模型。GPF 的自适应网络结构思想理论上可迁移到任意持续学习场景，但与视频世界模型（如 Dreamer/JEPA）的架构范式差异较大。

**待解决问题**：更复杂的气体动力学模拟、多传感器融合、与主流持续学习基准的对比、联邦学习集成。
