# VISA: VLM-Guided Instance Semantic Auditing for 3D Occupancy World Models

## Insight
论文指出普通 VLM caption/embedding alignment 会优化 text-space 相似度，却不可靠提升 closed-set voxel semantic mIoU；VLM 更适合作为离线“语义审计员”，输出 class/confusion/reliability/attribute/evidence，再蒸馏到 3D occupancy logits。

## Motivation
3D semantic occupancy 是自动驾驶/机器人 world state 表示，但物体和稀有类语义错误会影响自由空间、碰撞检测和未来状态传播。现有 vision-language 监督多做开放词表特征对齐，与 nuScenes 这类闭集 voxel 评估目标错位。问题与 3D occupancy world model 核心相关。

## Method
VISA 不改推理架构，只在训练时加入 VLM 审计监督。流程：为每个物体选择代表性 crop，离线 VLM 生成结构化 audit tuple；沿 object track 传播；将 audit grounded 到匹配 3D object voxels；加入可靠性加权 taxonomy soft target、attribute-factor BCE、scene-level audit graph loss。dense occupancy label 仍是主监督，VLM 只是软约束。

## Experiment
在 nuScenes 16 前景类上套到 OccWorld 和 GaussianWorld，报告 occupied IoU、semantic mIoU、object mIoU、rare mIoU，三次均值。OccWorld mIoU 19.06→20.05，GaussianWorld 21.36→21.91；GaussianWorld object mIoU 18.18→19.16，rare 15.60→16.79。VLM 审计 51420 个 3D box，closed-set agreement 87.7%。消融显示 taxonomy/attribute/graph 组合最好，非 VLM 的手工邻类、GT attribute、dataset confusion smoothing 都不能同时提升 semantic/object/rare。未来 occupancy forecasting 和 open-loop planning 诊断也有部分收益，但不同 backbone/metric 不完全一致。

## Value
价值在于把 VLM 信号从“文本嵌入对齐”改造成“可靠性加权、实例级、voxel-grounded”的训练监督，对 3D world state 语义质量有直接借鉴。创新更多是监督设计，不是新 occupancy 架构；提升幅度中等但定位清晰。

## Strengths
亮点是把 VLM 信号从“文本嵌入对齐”改造成“可靠性加权、实例级、voxel-grounded”的训练监督，对 3D world state 语义质量有直接借鉴。
