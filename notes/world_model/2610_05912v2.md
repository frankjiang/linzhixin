# MiniCorp: The Last Mile to an AI Agent Corporation

## Insight
观察：静态企业档案只有已发生的决策轨迹，难比较相同局面下的其他决策；单个市场机制正确也不能保证整个仿真反馈合理。推论：可存档重放的企业/市场双系统可产生反事实经营数据，且须按真实市场响应路径做系统级验证。论文用定价、断货、广告等干预测试支持仿真方向，但未验证现实企业迁移。

## Motivation
长期自主经营代理缺少带上下文、结果和替代方案的企业数据，传统任务式代理基准也不覆盖持续组织与市场反馈。问题属于企业代理仿真和经济决策，与视觉/3D世界模型研究对象不同。

## Method
MiniCorp 把外部电商市场（消费者、竞品、搜索排序、广告拍卖、定价、库存等）与内部固定角色代理组织连接成按周推进的闭环。代理通过受限商业数据、邮件/聊天、SQL/Python 工具协商，CEO 批准动作目录中的提案；外部系统执行后生成下一周状态。完整消息和决策溯源，可在同一检查点分叉重放。市场响应以文献中的方向、时间顺序、参与者分配及权衡关系做验证；这是手工机制与 LLM 代理构建的模拟器，不是学习视频环境动力学的方法。

## Experiment
10% 降价/涨价的需求弹性绝对值 2.9/3.2；四周 20% 折扣使折扣期销量增 71%，恢复价后最初四周仍增 31%；两周断货后到第 26 周销量仍比对照低 36%。组织侧记录 30248 个工作项，58% 继承、31% 由消息/中断触发；10 类冲击各重复两次，20 次中 11 次完整采取预期动作。长期策略提示对比中，有提示组 26 周营收约 3.1 万美元，无提示组不足 200 美元，但只是同一初态的配对案例。

## Value
检查点反事实重放与响应路径验证可作通用仿真评测思路；论文具体贡献服务企业代理，不直接帮助视频、3D 或 JEPA/Dreamer 世界模型。

## Strengths
记录组织决策来源和外部因果链，设计系统级干预检验，展示多角色持续协作与失误。

## Weaknesses
市场规律由既定机制与参数设定，匹配少数响应模式不能证明整体真实性；跨独立初始化世界的稳健性尚未评估。策略提示对比单薄，且无真实企业代理成效验证。

## Future Work
作者提出扩展到更多企业类型、组织结构和行业；文中还指出需测不同独立世界的仿真响应稳健性。

## Rating
创新度评分：1/5 - 对目标视频、3D和隐式世界模型没有新技术贡献。
相关度评分：0/3 (Noise) - 企业市场仿真与多代理经营，和指定研究方向无实质关联。

## TL;DR
构建可反事实重放的电商企业代理模拟器并校验市场响应；本方向可跳过。
