# Back to Parsimonious Latents: Learning Task-Centric World Models from Visual Foundations

## Insight
Observation：视觉基础模型（如DINOv2）的embedding包含丰富的语义结构（物体、场景），但也编码了大量与控制无关的信息（纹理、光照、背景），当直接用作世界模型的latent时，模型会在无关维度上浪费容量，导致表征坍缩和规划低效。尤其在高维动作空间（如RoboMimic的43维本体感知）中问题更为严重。

推论：不应将foundation embedding当作最终状态空间，而应当作"语义脚手架"——在其之上通过线性投影+部分对齐提取紧凑的task-centric latent。关键设计是将latent分为z^s（与本体感知对齐的任务相关子空间）和z^c（吸收视觉结构的互补子空间），用对比学习主动强制分离。

理论证明（Theorem 1）：在contextual dynamics可辨识性条件下，该线性投影+部分对齐设计可以恢复真实世界状态至仿射变换，提供了可辨识性保证，不仅仅是经验有效。

## Motivation
问题：世界模型的表征选择至关重要。现有三种范式各有缺陷：(a) 生成式模型（pixel预测）计算昂贵；(b) 隐式模型（TD-MPC, Dreamer）从像素学习compact latent但语义结构有限；(c) 嵌入式模型（DINO-WM, V-JEPA）直接在frozen foundation embedding上建模动态，继承了过多与任务无关的信息。核心问题是如何将基础模型的通用语义能力与任务导向的可控性结合起来。

同行做法：DINO-WM直接在冻结的DINO特征空间预测动态；TD-MPC2/MuZero用reward信号塑造表征但离线无reward时受限。本文定位在(b)和(c)之间，提出"latent-in-embedding"新范式。问题关键性中等偏上——reward-free offline设定越来越重要，但实际部署中往往有reward信号。

## Method
整体管线（TC-WM）：
1. **Joint Embedding**：冻结DINOv2编码图像o_t，可训练线性层编码本体感知s^p_t，拼接得x_t
2. **Latent Encoder**：线性投影x_t→z_t，作为核心的降维抽象步骤
3. **TC Alignment**：将z_t分为[z^s_t, z^c_t]，通过InfoNCE对比损失将z^s与本体感知s^p对齐（投影头g_φ用带L1稀疏约束的线性映射，自动选择task-centric维度）
4. **Latent Dynamics**：ViT作为转移模型f_θ，输入历史z和动作序列预测下一步z
5. **TC Dynamics**：从历史直接预测下一步本体感知s^p_{t+1}
6. **Embedding Decoder**：线性解码器重建原始embedding x_t，防止latent坍缩

总损失：L = L^z_dyn + L^s_dyn + λ_align·L_align + λ_rec·L_rec

下游规划：低维动作空间用CEM（Cross-Entropy Method），高维操作任务用LDP（Latent Diffusion Planning + IDM），连续控制用SAC。

关键技术细节：
- 投影头选择线性而非MLP/VAE，因为frozen embedding已包含结构化语义方向，线性足以选择和对齐，更复杂的会扭曲几何
- 对比对齐将identifiability理论中的"被动假设"转化为"主动约束"
- 重建目标是foundation embedding而非pixel，提供更稳定的去噪监督信号

创新程度：中等偏上（3/5）。核心idea——将foundation embedding视为脚手架而非最终表征——直观且有效，部分对齐设计精巧，identifiability理论提供了严谨支撑，但整体框架并非颠覆性。

## Experiment
**实验设置**：9个offline visual control环境（Navigation: Maze, Wall; Manipulation: Lift, Can, Square, Push-T; Locomotion: Reacher, Cheetah, Hopper），与TD-MPC2、DreamerV3、MuZero、DINO-WM对比。

**世界模型质量**：
- Latent Prediction Loss：TC-WM在几乎所有任务上最低，尤其在操作任务（Lift, Can, Square）上优势明显
- Image Reconstruction：在Push-T/Cheetah/Hopper上略逊于基线（紧凑投影牺牲low-level细节），但在Lift/Square/Maze上持平

**规划性能**：
- CEM规划（低维动作）：与最强基线持平，Maze 100%, Wall 94%
- LDP规划（高维操作）：在Lift(60%)、Can(62%)、Square(40%)上显著超越DINO-WM，是唯一在所有LDP任务上超越DINO-WM的方法
- DMC连续控制：Cheetah/Hopper与基线竞争性

**表征质量**：
- 线性探测R^2：TC-WM在本体感知、物体状态恢复上显著优于DINO-WM和TD-MPC2
- Anti-Collapse：latent空间的有效秩更高，利用更充分

**消融实验**：
- 去除L_rec导致最严重坍缩（SR从60%→14%）
- 去除对齐/本体感知监督保持SSIM但降低SR
- 视觉编码器：DINOv2/v3最优，Cosmos稍弱
- 投影头：线性>VAE>MLP>ViT
- 鲁棒性：对Gaussian噪声和color jitter，SSIM下降比DINO-WM小（-2.5% vs -4.8%）

## Value
整体价值中等偏上。核心贡献是提出了一个清晰的设计原则：将foundation embedding用作脚手架而非最终表征，通过线性投影+部分对齐提取task-centric latent，并提供了identifiability理论支撑。实验覆盖面广（9个环境），消融充分。

对我们的启发：
1. Foundation model的embedding应被视为语义坐标系而非直接可用的动态状态——这一设计理念可迁移到视频世界模型
2. 部分对齐（partial alignment）的思想——将latent显式分为任务相关和互补子空间——在视频生成中也有潜在应用（如分离内容与运动）
3. 线性投影优于复杂投影头的发现值得注意，与REPA等工作的结论一致

局限性：依赖本体感知信号作为任务监督（无本体感知时需要替代信号）；仅验证了offline planning和control场景，未涉及视频生成；紧凑投影会牺牲低级视觉细节。

## Strengths
