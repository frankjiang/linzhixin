# Temporal-Distance JEPA: Plan-Aware Representation Learning for Latent World Model Predictive Control

## Insight
有。论文的 observation 是：JEPA/LeWM 学的是短期 latent prediction，但 MPC 需要多步 imagined future 的 goal progress 排序；LeWM 默认用 Euclidean latent distance 当规划 cost，这个几何并未被训练成 steps-to-go 或可达性 ranking。推论是：reward-free demonstration 里的时间顺序可以挖出 directed temporal cost，用来弥合 train-plan gap；但在接触任务中，该 cost 更适合作 representation shaping，而不是直接替代几何 cost。

## Motivation
论文解决 JEPA latent planner 的 cost mismatch。已有 LeWM 用 SIGReg + latent prediction 学可 rollout 的表示，但规划时把 terminal latent 到 goal latent 的 L2 距离当 cost；Value-guided JEPA、RC-aux、Temporal Straightening、SD-JEPA 各自引入 value、horizon reachability 或几何塑形，但 TD-JEPA 希望只用 reward-free logs 挖 temporal progress。该问题对隐式世界模型和 latent MPC 直接关键。

## Method
TD-JEPA 保留 LeWM encoder-predictor backbone、one-step latent prediction 和 SIGReg，新增 directed temporal-distance head `d_psi(z_s,z_g)`。head 采用 quasimetric/MRN 风格：一个 symmetric component 加一个 asymmetric residual，因此 `d(z_s,z_g)` 可不等于反向。

训练监督来自轨迹挖掘：同轨迹 `i<j` 的 temporal gap `tau=j-i` 作为 positive regression target，训练 `d_psi(z_i,z_j)` 近似 step distance；跨轨迹 goal pair 作为 heuristic negatives，用 hinge 防止 off-trajectory pair 低 cost；再加 horizon-aligned rollout consistency `L_roll`，让 open-loop 5-step predictor 与 planner horizon 对齐。完整目标为 `L_pred + λ_roll L_roll + λ_td L_td + λ_sig SIGReg`。

规划时对 topology-dominated 任务（Two-Room/Reacher）直接用 `d_psi` 做 CEM/iCEM terminal or trajectory cost；对 contact-rich manipulation（Push-T/OGB-Cube）则在同一个 temporally trained checkpoint 上使用 latent L2 规划，因为局部几何对接触更重要。

## Experiment
四个 LeWM 环境：Two-Room、Reacher、Push-T、OGB-Cube。主结果用 10 个 independent seed、locked manifests。TD-JEPA 在 Two-Room/Reacher 用 `d_psi`，在 Push-T/OGB-Cube 用 L2；LeWM 和 RC-aux 全部用 L2。结果：TD-JEPA 达到 100.0±0.0、97.0±2.4、86.0±4.2、82.2±2.9，匹配或超过 LeWM（97.4、96.0、83.6、68.0）和 RC-aux（98.6、96.8、81.4、81.6）。

组件消融在 Push-T 上显示 directed MRN head、cross-trajectory hinge、rollout consistency 均有贡献；去掉 directed residual 下降最大。plan-cost matrix 显示纯 `d_psi` 在 Two-Room/Reacher 最好或接近最好，但在 Push-T/OGB-Cube 明显弱于 L2。Push-T phase log 进一步说明 `d_psi` 的失败几乎集中在 post-contact alignment；尽管 `d_psi` 与 temporal gap 的 Spearman 相关高于 L2（0.914 vs 0.785），但时间排序不等于接触控制所需的局部几何。

## Value
价值在于把 JEPA world model 的“预测可行但不可规划”问题定位到 plan cost，并提出一个从 reward-free logs 中挖 progress ranking 的简洁方案。对我们有启发的是：latent world model 的训练目标要对齐 planner 真实消费的 cost；同时 cost form 不能一刀切，topological progress 和 contact geometry 需要不同 plan-time objective。

## Strengths
问题诊断准确；reward-free temporal mining 很自然；directed cost 的必要性有 ablation 支撑；对失败模式分析诚实，明确指出 temporal cost 在接触阶段不够；与 LeWM/RC-aux 做了 locked protocol 对比。

## Weaknesses
增量性较强，backbone 基本沿用 LeWM；temporal gap 只是 demonstration path length surrogate，不保证 shortest path 或 causal reachability；跨轨迹 negatives 可能有 false negatives；部署 cost 的选择仍依赖人工任务判断；实验仍限 LeWM 四个小型环境，没有真实机器人或复杂视觉 long-horizon。

## Future Work
作者没有展开很多 future work，但结论指向更自动的 cost selection、面向 contact-rich control 的几何/时间融合、更多任务和更强 OOD/real-robot 验证。
