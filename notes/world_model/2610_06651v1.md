# Considering Context: When World Models Need Context Encoders

## Insight
环境动力学随隐藏上下文变化，并不等于世界模型需要显式上下文编码器：策略访问的状态本身可能已暴露上下文。作者定义当前状态/动作条件下，获知真实上下文能降低多少一步预测对数损失，即预测余量 $I(\theta;s_{t+1}\mid s_t,a_t)$；在给定上下文后马尔可夫的假设下，严格分解为历史可恢复部分与历史后仍需真实上下文的残差，再把有限模型误差单列。已知转移核的 MiniGrid-Wind 中结构差异 0.871 nat，却仅剩 0.077 nat 访问分布下余量；重置状态后余量大幅回升，支持“行为隐式识别”解释。

## Motivation
Dreamer 等基于模型的 RL 为适应风力、摩擦、执行器强度等变化，常额外加上下文编码器、历史窗口或跨回合隐变量；但很少先检验现有状态及行为究竟缺少多少预测信息。这个判断影响模型结构与基准设计：上下文 MDP 的类别本身不足以说明编码器有用。

## Method
区分在固定查询上按先验混合转移核的结构差异，与策略诱导访问分布下的真实预测余量；用条件互信息/最优对数损失建立一步预测分解。提出 $\varepsilon$-预测充分性：由历史构造的上下文表征只需保留能区分访问区域内转移核的信息，无须恢复原始参数。按输入信息将方法分为无记忆、短历史、回合内循环状态、跨回合状态/链模型、真实上下文。实际评估用分折训练的 Gaussian 下一状态似然探针、上下文可解码度和打乱标签的零假设；不能将有限探针差直接当作精确互信息。

## Experiment
已知核的 MiniGrid-Wind/Resistance 与连续 Point-Mass-Attractor 检验定义，并用状态投影、部分重置干预验证隐式识别。Wind 的结构差异与余量为 0.871/0.077 nat；Resistance 为 0.062/0.055，说明前者差异大但访问状态已泄露上下文。然后统一 DreamerV3 骨干，比较无上下文、DALI-S 窗口、LILAC 风格跨回合隐变量、保留循环状态及真实上下文的 cRSSM-D；CARL Walker 的可识别风力设置余量近零，上下文从当前状态的 $R^2\ge0.93$；执行器强度设置余量仍在，但各方法回报接近。RWRL 漂移环境中中等变化率下窗口法改善开局预测，高变化率下链隐变量更好；附录用线性高斯系统校准探针，也显示估计余量相对精确值有明显衰减。

## Value
对 Dreamer 类世界模型的上下文建模和泛化评测很有用：先测自己策略的预测余量及历史可恢复量，再决定是否增设专用编码器或跨回合状态。仍需将一步诊断与长时域规划/视频表示误差联系起来，尤其是策略变化后的分布迁移。

## Strengths
将“动力学有变化”和“额外输入能降低预测损失”严格分开；含精确核对照、访问干预与统一骨干比较；清楚承认探针估计偏差和策略依赖。

## Weaknesses
假设上下文回合内固定且状态在给定上下文后马尔可夫；主要是低维状态控制，未检验视觉或 3D 世界模型。理论为一步对数损失，回报并不随余量单调变化；连续环境用有限 Gaussian 探针，附录校准显示数值并非精确互信息；不同方法的访问分布也不宜直接比较。

## Future Work
作者建议借可配对的反事实重置比较不同策略的访问分布，并构造必须主动执行信息收集动作才能识别上下文的环境。

## Rating
创新度评分：3/5 - 以访问信息和风险分解重构上下文编码器的适用条件，方法偏分析和诊断。
相关度评分：2/3 (Related) - 直接涉及 Dreamer 式隐式动力学模型，但实验不面向视频或 3D 表征。

## TL;DR
提出预测余量诊断上下文编码器何时真正有用，提醒 Dreamer 评测考虑行为隐式识别；值得精读。
