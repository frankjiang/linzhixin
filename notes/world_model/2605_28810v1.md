# Affective Music Recommendation: A Rollout-Based World Model for Offline Preference Optimization

## Insight
无。

## Motivation
解决情感音乐推荐中的伦理约束问题：目标是调节听众情感状态（valence/arousal），但不能对临床用户（痴呆症老人等）进行在线实验。现有推荐系统不预测情感反馈，仅建模行为信号。构建 rollout-based world model 作为离线模拟器来替代在线实验。问题对该领域有意义，但与视频/3D 世界模型无关。

## Method
- World model：因果 transformer，在用户历史序列上预测四个信号（engagement、binary rating、valence、arousal）
- Factorized transformer 架构：BOS token + 用户历史编码与下一首歌 embedding 拼接后轻量预测
- 推荐策略：先 behaviour cloning（Copycat），再用 DPO 基于 world model 打分的偏好对进行微调
- 偏好对构造：negative history sampling + corrective/exploratory sampling
- 安全机制：KL 约束、多样性监控、world model 压力测试

## Experiment
- 数据：LUCID 平台 939 用户、57K 交互，strict cold-start 验证
- World model：Factorized MERT (no-PE) 在多信号上综合最优，valence R² 42.6%，arousal R² 37.9%
- DPO 相对 Copycat 提升 valence 4.0%、arousal 3.7%，保持多样性不塌缩
- 消融证实用户历史和反馈信号是主要预测来源
