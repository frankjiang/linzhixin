# Pretrained Features as Teachers, Not States: Compact Latent World Models for Visual Planning

## Insight
观察：直接用高维预训练视觉特征当世界状态，能提供语义但拖慢潜空间规划；只训练小状态又易丢失任务信息。训练时蒸馏预训练模型的全 patch 特征、推理时丢弃教师，可让低维自监督状态兼顾可预测性和语义。消融显示 patch 蒸馏比全局特征更有效。

## Motivation
视觉规划需可预测且紧凑的潜状态。DINO-WM 等以预训练 patch 特征为规划状态，推理成本高；纯预测目标又可能表征塌缩或缺任务语义。论文试图将“语义教师”和“动态状态”分开。

## Method
从零训练 ViT-Tiny 编码观察至 192 维潜状态，以六层动作条件因果 Transformer 预测未来；损失为下一潜状态 MSE 加辅助蒸馏头重建冻结 DINOv2 ViT-S/14 的 196×384 patch 特征。部署去掉教师及蒸馏头，用 CEM 在紧凑潜空间按目标终态规划，300 候选、30 轮、30 精英，执行五步后重规划。与相关视觉表征蒸馏方法接近，创新在训练监督和规划状态的分离。

## Experiment
TwoRoom/Reacher/PushT/Cube，每任务五随机种子、每种子 50 次目标到达。成功率依次 99.6/82.4/84.8/72.0%，均值 84.7%；LeWM 均值 79.9%，DINO-WM 76.6%。长距离目标均值 71.1%，DINO-WM 67.8%；颜色分布外均值仅 61.9%，低于 DINO-WM 74.5%，PushT 33.2% 对 62.8%。单次规划约 1.1–1.4 秒，DINO-WM 为 32–171 秒。patch 对全局特征蒸馏在 Cube 为 72.0% 对 49.6%；训练期蒸馏对中间层对齐为 72.0% 对 50.4%。线性/MLP 状态探针仍有姿态弱项，不能仅凭成功率声称完整三维状态。

## Value
对 JEPA/隐式世界模型很直接：可把大视觉模型当训练教师，部署时规划在低维可预测状态中进行。需特别关注颜色 OOD 退化。

## Strengths
方法简洁且推理速度优势大；同时比较规划成功、耗时、长距离/OOD 与蒸馏设计消融。

## Weaknesses
仅四个模拟任务，无真实机器人或复杂三维交互；颜色 OOD 不稳；目标终态匹配无法处理多解及接触约束，动作序列质量只以少量任务成功率验证。

## Future Work
论文未提出明确大型路线；后续应强化 OOD 表征、接触/几何信息与真实机器人长时规划。

## Rating
创新度评分：3/5 - 训练期 patch 教师、推理期紧凑状态的设计有效，仍属现有蒸馏与世界模型的组合。
相关度评分：3/3 (Core) - 直接研究 JEPA 类隐式世界模型及视觉潜空间规划。

## TL;DR
训练时蒸馏视觉教师、推理时仅用紧凑潜状态规划，提速明显但颜色泛化不足，值得精读。
