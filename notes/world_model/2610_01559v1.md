# Completion Aware Guidance for World Action Models

## Insight
观察到世界动作模型生成的画面与动作可彼此一致，却反复推迟放下物体等完成任务所需的状态转换；同一视频骨干用较长生成时域能生成该事件，提示短段控制适配造成局部合理续写偏好。这是定性观察及有限任务的对照实验，而非因果证明。

## Motivation
现有 WAM 联合预测视频和动作，但短段滚动生成不保证任务阶段完成。若模型只是保持抓取或悬停，再逼真的视频也无助于机械臂达成目标。该问题对视频世界模型用于控制很重要。

## Method
- 冻结 DreamZero 或 Fast-WAM，在去噪时统计视频动作查询对指令 token 的跨注意力亲和度，稀疏选择当前较相关 token。
- 对被选 token 的 key 和 value 乘以有界系数 1+α（实验统一 α=0.15），让短段采样更强调当前指令。作者用最大化阶段完成概率、限制与原分布 KL 偏差的目标解释这一操作，但实际没有完成事件检测器或优化该目标。
- 属于无需训练的注意力引导，技术改动较小。

## Experiment
- DreamZero 的 3 个零样本仿真任务各 50 次 rollout，平均成功率由 69% 升至 75%；失败 rollout 中被判为「未完成想象」的比例由 79% 降至 40%。原生较长生成时域比 1.6 秒短段更易出现完成事件。
- Fast-WAM 在 RoboTwin 2.0 的 9 个未饱和任务各 30 次 rollout，平均成功率 64.4%→70.0%；9 项中 7 项提升、2 项下降，例如 Stack Bowls Three 67%→87%，Open Microwave 33%→30%。指标主要是任务成功率与失败类型占比，缺少注意力门控或 α 的系统消融。

## Value
提醒视频世界模型评测要检查关键状态转换是否发生，而不止画面真实性和动作一致性；推理期指令加强可作廉价基线。能否推广到真实机器人及复杂长时任务尚不清楚。

## Strengths
- 明确定义了视频与动作一致但任务仍不完成的失败模式，并跨显式、隐式 WAM 验证同一引导手段。
- 无需训练或任务级调参，容易用于已有扩散式世界动作模型。

## Weaknesses
- 注意力权重只是 token 相关性的代理，不能保证选中当前阶段或关键动作；理论目标并未直接求解。
- 仿真任务和样本规模有限，部分任务退化；没有报告置信区间、运行开销或与其他采样引导的充分比较。
- 未完成失败的归因标准和标注一致性不够充分；短时域机制的证据偏观察性。

## Future Work
作者明确提出把完成感知引导纳入 WAM 训练，而不限于采样期干预。

## Rating
创新度评分：2/5 - 指出有价值的失败模式，但方法主要是按跨注意力增强指令 token 的增量式采样技巧。
相关度评分：2/3 (Related) - 面向视频世界动作模型的控制可靠性，对视频世界模型评测有直接借鉴价值。

## TL;DR
识别短段世界动作模型的任务完成缺失，并用指令注意力引导改善仿真成功率；做控制评测可选读。
