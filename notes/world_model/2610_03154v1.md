# Does Physics Live in the Activations? Localizing Physical Quantities in Video Diffusion Models

## Insight
生成视频看似符合物理，无法说明模型内部如何表示物理状态。作者观察到速度、方向、动量、重力等量在视频 DiT 的残差流中可线性读出，且物体附近 token 的读出优于全局平均；单个潜帧也能读出需跨帧估计的重力。冻结模型、对照噪声潜变量、迁移探针和方向注入提供经验支持：DiT 聚合时序信息并将其局部存储，至少部分方向表征会影响生成。线性可读不等于模型遵守运动定律。

## Motivation
视频生成模型常被视作世界模型，但物理基准发现视觉真实感与物理正确性脱节；只评输出也无法区分内部状态表示与常见运动模式的拟合。既有探针多在视频编码器或粗粒度物理合理性上，此文转向视频生成 DiT 的连续、模拟器真值物理量。对于判断视频世界模型的物理能力，这一问题重要。

## Method
用 Genesis/解析轨迹生成滚动、弹性碰撞、抛体三类视频，各 200 条并记录物理量；冻结 Wan 2.1 14B、CogVideoX-1.5 5B、Open-Sora 2.0 11B。将真实视频编码后加不同噪声，单次前向捕获各层 token 激活，以视频级五折交叉验证的岭回归探针读出物理量；对照同样池化的噪声潜变量+首帧条件及干净潜变量。比较物体 ROI、全局、离物体区域和单 token；在背景、形状、视角、物体数变化下测试固定探针方向并用 10 条目标视频校准线性尺度。另训练保留全部 token 位置的方向探针，在生成早期用 SLERP 改写激活。贡献主要是较系统的定位、迁移与干预诊断，而非新世界模型训练方法。

## Experiment
0 dB 时，ROI 探针的重力 R² 为 Wan 0.92、CogVideoX 0.90、Open-Sora 0.61；速度分别 0.98、0.98、0.91，普遍高于匹配输入基线。单潜帧的干净潜变量读重力 R² 仅 0.07–0.12，DiT 激活达 0.41–0.81。物体 ROI 只占约 1–2% token，却优于全局池化；碰撞前后 token 帧更能预测自身阶段速度。跨场景仿射重校准后，Wan/CogVideoX/Open-Sora 中位 R² 分别 0.876/0.905/0.295；未经校准的迁移中位 R² 仅 0.16，说明精确标定不稳定。52 个原本向左滚动的种子上，向右探针注入后的翻转率为 0.45/0.35/0.31，定向提示对照为 0.30/0.017/0.04，反向探针均为 0。另有置换标签零假设、离物体 ROI、目标场景上限和探针尺度对照。

## Value
为视频世界模型提供比视觉质量更细的表征评测：需同时看输入基线、物体局部读出、跨场景迁移、校准依赖和实际生成干预。值得借鉴其「可读状态」与「能产生正确后果」分开的评价框架；对建立物理一致的交互式视频模型仍需检测定律与长时推演。

## Strengths
三个大型开源 I2V DiT、模拟器真值、视频级交叉验证和匹配潜变量基线；空间/时间/尺度消融较完整；识别出目标场景重校准与视角变化带来的性能落差；方向探针有同种子生成干预及反向对照。

## Weaknesses
只有少量物体的简单刚体合成场景；弹性碰撞和抛体主要用解析轨迹渲染。激活采自真实视频加噪后的单步前向，而非模型自身完整采样轨迹。ROI 中心由模拟器真值给出，跨帧位置选择本身可能向探针泄露轨迹信息；跟踪式离物体对照仍能读出部分方向。迁移结果依赖目标域 10 条样本的仿射校准，Open-Sora 表现弱。仅成功干预滚动方向，其他量的池化探针注入无效；物理量可线性读出也未证明模型掌握守恒或接触规律。

## Future Work
作者建议探测摩擦、恢复系数、刚度、黏度等须从运动推断的隐参数；研究物理状态之间的定律是否在模型内成立，以及为何可读状态仍伴随物理生成错误；探索物体跟踪和局部 token 门控来控制更多物理量。

## Rating
创新度评分：3/5 - 将连续物理量探针、空间时间定位、跨场景迁移与生成干预系统结合；此前已有视频表征探针和激活操控研究。
相关度评分：3/3 (Core) - 直接诊断视频生成世界模型的物理状态表示及其对生成的作用。

## TL;DR
三种视频DiT的局部激活可读出物理量，方向探针还能改变生成，但跨场景标定与因果性有限；值得精读。
