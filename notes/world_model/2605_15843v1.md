# WorldAct: Activating Monolithic 3D Worlds into Interactive-Ready Object-Centric Scenes

## Insight
现有3D世界模型（如Marble）生成的场景是整体化（monolithic）的3DGS表示，物体与背景融为一体，无法单独编辑或交互。WorldAct观察到这个gap，提出将静态3DGS分解为对象级可交互场景。

## Motivation
3D生成式世界模型虽然能创建视觉逼真的环境，但输出是不可编辑的静态整体资产，限制了在具身模拟、游戏设计等需要物体级交互的应用。现有方法要么组合式生成（依赖有限视角），要么整体生成（无法分解）。WorldAct提出后处理管线，将已生成的monolithic 3DGS转化为可交互场景。

## Method
四阶段管线：
1. **场景分解**：用VLM Agent（Qwen3.6-Plus）自动发现可交互物体，SAM3分割生成多视图mask，通过可学习soft assignment将Gaussian primitives分配给各物体
2. **背景补全**：移除物体后用DiffuEraser进行视频修复，DepthLab估计深度，Infusion将修复结果lift到3D，同时构建碰撞代理mesh
3. **物体重建**：用SAM3D从最佳视角生成高质量3DGS和mesh资产
4. **场景组装**：ICP+可微渲染对齐物体位姿（包含mask/contact/penetration loss）

创新程度中等，核心是工程管线的合理组合，各模块均使用现有方法。

## Experiment
- 在Marble生成的6个室内场景（MWM dataset）上评估
- Interactable Object Recall：有Agent引导从25.4%提升到83.98%
- ReMOVE/MANIQA感知质量指标：分解重组后与原始场景质量持平甚至略有提升
- MOS用户研究（20人）：场景级质量基本保持，物体级质量显著提升
- 支持具身模拟（机器人抓取）和3D编辑（添加/移动/删除物体）

## Value
工作定位清晰：解决3D世界模型输出的"最后一公里"问题。对3D世界模型生态有补充价值，但本身技术贡献有限，主要是现有模块的集成。不处理动态场景、铰接物体和物理属性，局限性明显。对视频世界模型方向关联度一般。

## Strengths
亮点是工作定位清晰：解决3D世界模型输出的"最后一公里"问题。

## Weaknesses
不足是对3D世界模型生态有补充价值，但本身技术贡献有限，主要是现有模块的集成。
