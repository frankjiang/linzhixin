# Learning Task-Sufficient World Models by Synergizing Agentic Exploration and Structured Modeling

## Insight
论文的核心 insight 是：通用 latent world model 不一定需要编码所有环境细节，控制任务更需要“最小且充分”的任务状态。通过结构化 mask 和主动探索，可以把 Dreamer 式 latent 分解为与任务相关/无关的部分。

## Motivation
Dreamer、TD-MPC 等模型常把视觉和动力学信息压进统一 latent，容易混入无关因素，影响样本效率和泛化。另一方面，探索策略如果不针对模型不确定因素，也难以收集能分辨任务因子的经验。

## Method
MIST-WM 基于 Dreamer-V3，引入 Minimal and Sufficient Task states。训练目标包含 sufficiency：从任务 latent 重构 reward/任务变量；以及 minimality：通过 mutual-information 约束和 L1 mask 抑制无关信息。系统还包含 agentic exploration、probing skills 和 adaptive curriculum，让 agent 主动采样能揭示任务结构的数据。

## Experiment
实验覆盖 DMControl、RoboSuite、Meta-World 和 Franka Kitchen。论文用 probing R2 评估任务因子恢复，并比较样本效率、泛化和回报。MIST-WM 在多数任务上优于 Dreamer-V3、DINO-WM、TD-MPC2，但在 Reacher-Hard 上不如 TD-MPC2。消融显示随机探索、无结构建模或无 curriculum 都会降低表现。

## Value
这篇对 Dreamer/latent world model 有启发：世界模型的目标不是“完整还原世界”，而是学习对任务闭环控制足够的状态。它也把探索和模型结构联合起来，而不是分开优化。

## Strengths
任务充分性定义明确；和 Dreamer 系统结合自然；探索、结构建模、curriculum 的消融较完整。

## Weaknesses
主要是仿真验证；“最小充分状态”由目标函数近似，不保证语义唯一；对大规模视频 diffusion world model 的适配仍未验证。

## Future Work
作者希望扩展到更大规模视觉世界模型、真实机器人和更复杂任务层级。

## Rating
创新度评分：3/5 - 结构化 latent 和主动探索组合有价值，但基于既有 Dreamer 框架。
相关度评分：3/3 (Core) - 直接研究 Dreamer/latent 世界模型的任务充分表示。

## TL;DR
MIST-WM 在 Dreamer latent 上学习任务最小充分状态并配主动探索，值得选读。
