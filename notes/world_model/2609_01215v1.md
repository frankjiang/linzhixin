# REFACTOR-VLA: Unsupervised Library Learning of Typed Motor Programs

## Insight
连续机器人轨迹不应按动作序列的表面相似性分组，而应按“从相同起点执行后，价值与未来状态分布是否相近”判断行为等价。论文据此定义片段级 BEK：世界模型滚动下的价值差与 (k) 步潜状态分布 Wasserstein 距离之和；在世界模型误差有界、类别有间隔且聚类数已知等假设下，给出 (\mathrm{NMI}\ge 1-O(\eta+\sqrt{\log(1/\delta)/n})) 的恢复率及单次抽象调用的回报损失界。

实验还观察到：固定训练目标时，把世界模型从 188M 扩到 430M 反而使四个 LIBERO suite 的 NMI 全部下降；加入按 `task_index` 监督的 InfoNCE 后则四项全升。因此潜空间的目标函数比裸参数量更直接地决定可聚类结构。不过这一结论主要测量任务标签 NMI，且训练和评测都使用同一标签语义，不能等同于证明无监督的动力学等价。

## Motivation
单体 VLA 直接输出短动作块，难以复用技能、解释行为或处理长时任务。AtomicVLA/AtomSkill 依赖门控或视觉语言表征聚类，BLADE/LRLL 借 LLM 判断技能等价，都未让等价关系服从机器人自身动力学。用世界模型定义行为等价、再把等价片段压缩成可调用程序，确实是长时机器人学习中的关键问题；但本文最终主要验证了表示聚类与离线程序重写，尚未验证它能提升长时闭环控制。

## Method
- Phase A 训练 DreamerV3 风格潜世界模型 (M_\phi)：冻结 DINOv2-base，因果 Transformer 建模图像、状态与动作，默认 188.16M 参数（101.58M 可训练）。LIBERO 无奖励字段，所以回报头权重为 0。
- Phase C 用 BEK 比较轨迹片段。显式版本包含价值头和确定性 (k) 步潜滚动；默认效果更好的 `legacy_cosine` 实际以世界模型末端潜向量的余弦距离作为核。2.4M 参数 Siamese Transformer 通过归一化潜向量 MSE 蒸馏该表示，再以已知任务数作为 (k) 做 KMeans。
- Phase B 的 Typed Program Emitter 在 Hindley-Milner 风格类型系统下生成 lambda 程序；约 10.9M 参数的 4 层 LCAD 以程序和状态为条件，经 rectified flow、10 次 Euler 步生成 16 步动作块。
- 睡眠阶段对聚类后的程序做语法反统一；候选需同时通过 BEK 一致性、32 次世界模型滚动的回报保持门和 MDL 增益大于 4 nats，最多接纳 8 个抽象。LIBERO 上没有奖励，因此回报保持门实际不工作。
- 系统整合有一定新意，但核心组件分别来自 Dreamer、bisimulation、Stitch/DreamCoder、类型推断和 rectified flow；尤其默认核并未直接实现论文主公式中的价值与 Wasserstein 两项。

## Experiment
- 使用四个 LIBERO 图像 suite；世界模型、wake 和 sleep 阶段各训练 4,000 步，8 张 H100、BF16。Phase C 使用 16 步片段和 1,024 个留出片段，以任务标签 NMI 为主指标。
- 188M + 监督 InfoNCE 的 NMI 为 object 0.462±0.021、spatial 0.867±0.025、goal 0.915±0.013、LIBERO-10 0.754±0.010，均高于各 suite 复现的最强基线，平均绝对优势 0.184。无 InfoNCE 均值仅 0.493；同 episode 自监督对比均值 0.713，并在长时 LIBERO-10 上退化。
- 固定无 InfoNCE 目标时，430M 相对 188M 在四项上分别下降 0.040、0.146、0.018、0.090；但附录的 430M+InfoNCE 又达到 0.921/0.921/0.934/0.892，说明容量并非无效，而是依赖先塑造好目标函数。
- 跨 provider 的 12 个种子对平均 NMI 为 0.7046，95% bootstrap CI [0.6826, 0.7294]，下界未过预注册的 0.70 门槛；各种子对 `task_index` 的 NMI 仅约 0.235-0.471，表明稳定分区不必与任务真值一致。
- 真实 LIBERO 数据仅在语言槽发现 3 个模板（总 MDL 增益 1,211 nats），其中 2 个被用于重写 256/256 条采样示范，离线速度误差变化 -0.0059。运动原语槽在所有 MDL 阈值及 DTW 预对齐下均发现 0 个抽象。
- RecursivePourEnv 上深度 2-4 的 NMI 不低于 0.86，五种子世界模型最大回报误差为 0.205±0.039；代入 (\gamma=0.99) 后回报界约为 46（奖励范围仅 [0,1]），理论界在当前实验中实际是空泛的。
- 没有报告 LIBERO 闭环任务成功率、长时规划收益或真实机器人结果。附录还称 OpenVLA-7B 仅完成 object suite、其余三项待补，而正文把 OpenVLA 数字放在 LIBERO-10，基线复现口径存在内部矛盾。

## Value
最有价值的是把“世界模型的动力学后果”提升为技能等价的原则，并明确展示表示目标会支配后续聚类质量；这对 Dreamer 式潜世界模型与机器人技能库的结合有直接启发。当前实现却尚未兑现题目中的 motor-program library：学到的是语言模板，所谓端到端只验证了离线重写和动作误差不变，而不是闭环成功。适合作为系统蓝图和负结果材料，不宜据此接受其长时控制或“无监督技能发现已解决”的强结论。

## Strengths
- 将片段级行为等价、类型化程序、MDL 和世界模型滚动连成完整系统，问题设定有启发性。
- 四个 suite、若干多种子与核/目标/容量消融较丰富，并主动报告容量扩张、显式核和 motor 抽象失败等负结果。
- 附录明确承认精确恢复条件不成立、回报界很松、跨 provider 的严格置信门未通过，证据边界相对透明。

## Weaknesses
- 标称“无监督”，最强结果却用 `task_index` 做 SupCon，并继续用同一标签算 NMI，存在直接监督泄漏；无标签替代在长时 suite 上失败。
- LIBERO 没有奖励，BEK 的价值项和回报保持门均失效；默认 `legacy_cosine` 又只是潜向量余弦距离，动力学等价主张弱于公式表述。
- KMeans 的 (k) 由真实任务数给定，主指标只衡量片段聚类；没有闭环策略成功率、规划质量、真实机器人迁移或因果干预验证。
- 程序库只压缩语言 token，运动原语始终为 0；“首次真实 LIBERO motor library”和“端到端”表述因此过强。
- 理论依赖不可测/不成立的分离、独立同分布和世界模型误差假设，实测回报界远大于奖励范围。
- 主要多种子规模仅 (n=3)，基线采用统一探针重实现而非原论文下游任务指标，且 OpenVLA 实验在正文与附录间不一致。

## Future Work
作者提出迁移到 RoboCasa/真实机器人、扩大跨 provider 种子规模，并以局部时间窗对比或 VLM 伪标签替代 `task_index`。附录还建议用连续 ACT 风格原型突破 motor token 反统一失败、补齐 OpenVLA/Octo/Diffusion Policy 的四-suite 对比、使用各 suite 世界模型，并为 HDBSCAN/DP-means 建立未知簇数的恢复界。最关键的下一步应是以闭环成功率验证学得抽象是否真正改善长时控制。

## Rating
创新度评分：3/5 - 将世界模型行为核与类型化程序库联合起来有组合创新，但主核、监督信号和下游证据均弱于论文宣称，尚非新范式。

相关度评分：2/3 (Related) - 使用 Dreamer 式潜世界模型支撑 VLA 技能发现，对隐式世界模型有直接借鉴价值，但研究核心是机器人程序库而非视频/3D/JEPA 世界模型本身。

## TL;DR
以 Dreamer 潜变量行为等价核编译 VLA 技能库；LIBERO 仅证实聚类和语言模板、无闭环成功率，可选读。
