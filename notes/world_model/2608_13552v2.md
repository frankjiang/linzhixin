# PlayWorld: Benchmarking World Models with Agent Players over Long-Horizon Objectives

## Insight

观察：不同视频世界模型的动作粒度和响应速度不同，同一固定按键序列可能到达完全不同的观察状态，因而不能公平测试同一能力。推论：跨模型评测应固定高层目标，而让 Agent Player 根据生成帧在线 Stop/Extend/Correct 低层轨迹。实验中 Preset+Agent 只修改约 12%–15% 的动作，却在人类偏好上明显优于纯预设和全在线规划；同时轨迹通过率与世界建模分数脱钩，说明“到达测试位置”不能替代空间记忆、物理交互和状态演化检验。

## Motivation

VBench 等只测画质/时序，已有世界模型基准虽加入几何、记忆或交互，仍多为样例预设固定轨迹，难以适配动作接口差异和 Genie 3 等网页闭源系统。论文解决的是交互式视频世界模型评测的关键问题：按相同长时 objective 比较，而非强求相同低层动作。

## Method

171 个样例各含初始世界、场景绑定目标、人工 basic action sequence 和专属 VQA rubric。Agent Player（报告使用 Claude Haiku 4.5）观察帧、场景、目标及动作历史，在 Keep/Stop/Extend/Correct/End 中决策；接口把 W/A/S/D、视角键和 WAIT 映射到各模型，最多 40 个交互 step，形成约 10–60 秒 rollout。

四个核心维度为：（1）环绕/重访后的 geometry consistency；（2）碰撞、接触、运动因果和视觉反馈的 interaction fidelity；（3）对象离开视野后是否保持身份并继续演化；（4）静止观察下长过程是否持续、有因果地推进。前三项先做 trajectory/reachability gate，失败记最低 1 分；Gemini 3.1 Pro 对 10 FPS 低分辨率与 0.5 FPS 高分辨率两路 contact sheet 回答加权 Yes/No rubric，映射到 1–5 分。另以七项视频质量和 VGGT 相机平移/旋转通过率组成 Basic Ability。

创新是 objective-equivalent、trajectory-adaptive 的 benchmark protocol，而不是新的世界模型。

## Experiment

- 评测 9 个闭源/开源系统，累计 1,400 余视频、820 余问题。Genie 3 的几何/交互/持续演化/视野外演化为 2.74/2.40/1.51/1.81，总分 2.12，虽第一仍远低于满分；Matrix-Game-3.0 总分 1.14。
- 所有模型在 insight/out-of-sight evolution 上普遍最低；重访会生成同一地标多个副本，隐藏过程常冻结、重置或回到错误位置。
- 轨迹门控揭示控制与建模分离：SANA-WM 总体 pass rate 80.4%，rubric 总分仅 1.48；HappyOyster 的 Basic Ability 最高 76.4，也不是长时能力最佳。
- Genie 3/HappyOyster 各 25 例中，Preset+Agent 轨迹分 1.08/1.12，人类偏好 65.6%/67.4%，均优于 Preset Only 和 Agent Only。
- 人类验证为 120 对、5 名参与者、600 个判断；VQA 与人类排序 Spearman ρ 总体 0.933，四维为 0.745–0.983；Fleiss' κ 总体 0.434。独立第二次 VQA 的模型级均值样本方差为 0.0112。

## Value

PlayWorld 把评测从低层轨迹对齐提升到高层目标对齐，并用门控分离“没到达”与“到了但世界错误”，非常适合作为长时视频世界模型 benchmark 设计参考。最重要的发现是：当前模型的主要瓶颈不是单帧画质，而是全局空间唯一性、视野外状态持续性和复杂交互因果。仍待解决的是 agent/judge 偏差、缺少 3D 真值、闭源版本漂移和分钟级以上评测。

## Strengths

- 评测协议贴近真实玩家，能统一网页闭源与本地模型的不同控制粒度。
- 先验证轨迹再问能力 rubric，避免未发生的交互被误判为物理正确。
- 同时报轨迹通过、核心 rubric 和基础画质，清楚证明三者不等价。
- 有控制策略、agent 选择、VQA 重复性和人类对齐验证，附录记录接口与阈值。

## Weaknesses

- 171 个网络图片场景没有可查询的 3D/物理真值；VQA 只能评表面证据，不能证明内部持久状态。
- 轨迹控制和评分都依赖闭源多模态模型，主结果每 rollout 只调用一次 Gemini judge，存在版本和系统偏差。
- 人类验证主要是模型级排序，不是逐 rubric 准确率；总体 κ=0.434 仅中等一致。
- 模型运行方式和有效样例不完全一致：HY-World2 会跳过不支持输入，Hunyuan-GameCraft 对 WAIT 也受限。
- 最长 60 秒/40 step，仍不足以代表持续游戏或长期具身任务；agent 策略消融也只覆盖两个模型各 25 例。

## Future Work

作者建议预算允许时多次独立 VQA 并平均，也指出 Agent Player 可随更强模型升级。更关键的后续是加入对象/3D 状态真值、judge 校准与置信区间，扩展到分钟级、多阶段目标和失败恢复，并固定闭源模型版本与交互日志。

## Rating

创新度评分：3/5 - 目标等价与闭环轨迹适配是有价值的评测创新，验证系统，但本质仍是 agent+VQA benchmark 组合。
相关度评分：3/3 (Core) - 直接评测交互式视频世界模型的长时几何、物理交互、记忆和状态演化。

## TL;DR

用 Agent 自适应轨迹公平评测长时视频世界模型，结果揭示状态演化短板，值得精读。
