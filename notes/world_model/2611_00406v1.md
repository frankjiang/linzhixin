# TAP-Out: Tracking Any Point in 360° via Outpainting

## Insight
出视野点跟踪必然要推断未观测区域；与直接回归球面方向相比，先生成可检查的 360° 视频、再做常规帧内跟踪，可把隐式猜测变成显式视觉假设。在已知相机姿态下，该组合显著优于 CoTracker360 与静态点重投影；相机估计误差则会迅速侵蚀收益。

## Motivation
常规 2D 点跟踪无法表达离开相机视锥的目标，3D 跟踪在完全看不见时又有深度歧义。TAPVid360 因而只预测目标相对相机的方向。作者想检验视频生成模型能否提供出视野区域的动态先验，而不为跟踪单独训练新世界模型。

## Method
估计相机旋转并把窄视野视频投到统一等距柱状球面；Argus 视频扩画补全未见区域，同时用原帧覆盖生成图中已观测像素。SAM2 在全景中找目标掩码/中心，据此合成逐帧物体居中的透视裁剪，再用 CoTracker3 跟踪细粒度点并投回原相机的单位球方向。整个离线流程组合 VGGT、Argus、SAM2 与 CoTracker3，无任务专用训练。

## Experiment
在去除与 Argus 训练重叠后的 8887 段 TAPVid360-TAPOut 上测角度阈值准确率与平均角误差，区分视野内/外；另用 LaSOT 展示重识别案例。已知相机时，出视野准确率 0.332，优于 CoTracker360 的 0.106 和静态重投影的 0.203，平均角误差 5.02°（CoTracker360 11.36°）。VGGT 估计相机时准确率仅 0.135、平均角误差升至 23.27°。相机旋转超过 30° 的组准确率约 0.21，低旋转组 0.90。单视频推理约 470 秒，而 CoTracker360 为 0.15 秒。

## Value
给出一种把视频世界模型当作“可见化”空间先验来检验场景持续性的下游任务，对视野外预测评测有借鉴；具体跟踪管线与用户的世界模型设计仅部分相关，可选读。

## Strengths
设置静态几何重投影对照，并同时报告真实与估计相机，清楚暴露生成先验和相机质量的贡献；模块化设计便于更换生成器或跟踪器。

## Weaknesses
已知相机结果与实际估计相机结果差距大，后者平均角误差甚至高于 CoTracker360；离线运行慢约三千倍。长遮挡出现身份漂移，Argus 要求与重力对齐；论文声称关注动态点，却未在主表单独给出动态点的分层数值，难判断三倍增益有多少来自背景。

## Future Work
作者提出把管线蒸馏成快速前馈模型、采样多个扩画假设表示不确定性，并发展在线版本。

## Rating
创新度评分：3/5 - “显式扩画后跟踪”的任务分解有新意，但全部核心模型均为现成组件。
相关度评分：2/3 (Related) - 将视频世界模型用于视野外动态推断，可作为持久性评测思路；研究主体是点跟踪。

## TL;DR
将窄视野视频扩成全景再追踪出视野目标，已知相机时效果显著但实用成本高；可选读其评测设计。
