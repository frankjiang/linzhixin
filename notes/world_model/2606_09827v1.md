# MemoryVLA++: Temporal Modeling via Memory and Imagination in Vision-Language-Action Models

## Insight
**Observation**: 机器人操作中的时序依赖分两类——对过去的记忆（如按钮是否已按过）和对未来的想象（如传送带上物体的运动方向），但现有VLA模型仅依赖当前观测。

**推论**: 结合认知科学的工作记忆-情景记忆机制（过去）与内部模型想象（未来），可以构建完整的时序建模框架。

**证明**: 在5个仿真benchmark和3类真机任务上全面超越baseline，尤其在长horizon memory-dependent任务（+26%）和imagination-dependent任务（+28%）上提升显著。

## Motivation
- **问题**: 典型VLA（如OpenVLA、pi_0）仅依赖当前观测，忽略时序依赖，导致长horizon任务表现差。
- **同行方案**: 拼接历史帧（计算昂贵、冗余严重）；或编码历史latent（仅覆盖短期、缺乏语义）；或用语言规划（非端到端、开销大）。
- **关键性**: 时序建模是VLA走向实用的关键瓶颈，尤其对长horizon操作任务。

## Method
**整体架构 (端到端框架)**:
1. **Vision-Language-Cognition Module**: 7B PrismaticVLM编码当前观测为感知token（低级视觉细节）+ 认知token（高级语义），组成工作记忆
2. **Perceptual-Cognitive Memory Bank (PCMB)**: 类海马体的情景记忆，双流存储低级感知+高级语义；通过cross-attention检索历史相关信息；门控融合机制自适应整合；冗余感知合并（Token Merge）压缩记忆
3. **World Model想象**: 用SVD视频扩散模型做部分去噪（非完整生成），提取中间latent特征作为未来想象token；通过Refine Former压缩，memory-guided integration选择性融合
4. **Diffusion Action Expert**: 以完整时序token（过去记忆+当前感知+未来想象）为条件，通过DiT去噪预测7-DoF动作

**关键技术**:
- PCMB的双流设计（perceptual + cognitive）比单流更有效
- 门控融合而非简单加法（+4%）
- Token Merge冗余压缩保持记忆紧凑
- World model冻结仅用于想象（不更新），1步去噪即可捕获有意义的未来语义
- Memory-guided integration抑制想象中的噪声/无关信息

**创新程度**: 系统集成度高，各模块设计合理。核心idea是将认知科学的记忆-想象框架完整映射到VLA中，但各子模块多为已有技术的组合。

## Experiment
- **仿真**: Libero 98.4%（+5.2 vs CogACT）、SimplerEnv 73.9%（+16.6）、Mikasa-Robo 44.4%（+15.0）、Calvin 4.29（+1.04）
- **真机**: 通用操作85%（+9）、长horizon memory 83%（+26）、长horizon imagination 77%（+28），跨3个机器人平台
- **消融**: 记忆长度、融合策略（gate vs add）、合并策略（Token Merge vs FIFO）、检索时序编码、记忆类型（双流 vs 单流）、想象步数、想象horizon、世界模型更新策略等全面消融
- **效率**: RTX 4090上延迟0.241s（baseline 0.187s），开销可控

## Value
- **工作价值**: 较高。提供了一个完整的VLA时序建模框架，实验全面（5仿真+3类真机），效果显著
- **启发**: 世界模型作为"想象模块"嵌入策略网络的范式值得关注；partial denoising提取语义特征而非完整生成是一个务实思路
- **待解决**: 推理开销增加约30%；世界模型质量对想象效果的影响未充分探讨；跨domain泛化能力有限
