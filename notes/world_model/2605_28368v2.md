# LEIA: A Learned World Model for Architected Materials Engineering

## Insight
观察：工程仿真（FEM）对复杂微结构材料极其昂贵（几十分钟到小时/样本），阻碍了设计搜索和实时控制。方案：将世界模型范式迁移到工程领域——Perceiver tokenizer将任意尺度网格（最高442K节点）压缩为固定长度latent序列，Transformer dynamics model做自回归状态预测。关键设计：FiLM conditioning注入action（边界条件），stress head直接从latent读出应力场（无需decode全mesh），仅+6% overhead。

## Motivation
- 问题：材料工程设计搜索需要大量FEM仿真，计算瓶颈严重
- 同行：GNN-based surrogates受mesh size约束；reduced-order models对复杂结构精度不足
- 关键性：100-300×加速使得on-the-fly设计优化可行

## Method
- Perceiver Tokenizer：cross-attention将变长mesh节点压缩为固定N个latent tokens，支持多分辨率和任意拓扑
- Dynamics Model：GPT-style Transformer，FiLM层注入action（loading条件/边界条件），自回归预测下一时刻latent state
- Stress Head：轻量MLP从latent直接输出全局应力统计或逐节点应力，避免full decode
- 训练：两阶段——先训练tokenizer（reconstruction loss），再训练dynamics（next-state prediction loss）
- MicroPlate Benchmark：2K+微结构板样本，含多种加载路径

## Experiment
- 速度：相比ABAQUS FEM加速100-300×
- 精度：displacement RMSE < 2%，stress误差 < 5%（大部分loading条件下）
- 泛化：对未见拓扑和loading路径有合理泛化
- 消融：Perceiver vs fixed-grid tokenizer → Perceiver在复杂结构上显著优势；stress head vs full decode → 精度相当但6%额外开销vs 100%

## Value
工程应用价值明确——将world model思路成功迁移到材料工程，展示了Perceiver+Transformer dynamics的通用性。对我们方向的启发：(1)Perceiver tokenizer处理变长输入的思路可借鉴；(2)轻量readout head设计有参考意义。局限：高度domain-specific，与视频/3D世界模型无直接连接。
