# An Agent Model Abstraction for Human-AI Teaming Cognitive Coupling

> 阅读依据：本地 PDF 全文（7 页）；下述页码均为 PDF 页码。

## Insight
无经实验检验的新 insight。作者认为只做任务分工不足以支撑人机协作，应显式表示感知、目标与评价之间的认知耦合；论据是既有认知架构的概念对应。

## Motivation
工业人机团队需要共享目标、相互理解状态并适应变化。ACT-R、Soar、LIDA 等主要描述个体认知，团队认知与系统架构研究则分散；本文尝试提供统一建模语言。问题对 HCI 有意义，与学习视觉动力学的瓶颈不同。

## Method
用 SysML 抽象八个模块：Input、Process、Output、State、Value、Memory、World Model、Goal。人和 AI 共用功能结构，通过环境的感知—行动影响、SharedGoalSpace 的目标更新、直接通信三条路径耦合。World Model 仅指内部环境/他者表征，未定义编码器、转移函数、预测损失或想象训练。

## Experiment
没有运行系统、数据集、用户实验、消融、性能指标或定量结果。第 2–3 页所谓验证是检查组件与文献认知功能的一致性及模块关系自洽；图 2–4 是结构与信息流示意，不能证明协作效果提升。

## Value
可作人机协作系统的术语与模块清单。对视频、3D、JEPA/Dreamer 的模型训练、状态表达或规划没有可直接复用的技术贡献。

## Strengths
区分外部环境、内部环境理解与自身状态；把共享目标和反馈路径画清楚；承认人的内部认知不可直接观测，也不能把人按软件架构重新设计。

## Weaknesses
概念较宽泛，与既有认知架构高度重合；共享目标空间不自动保证目标解释一致。缺少算法、接口约束、可测耦合定义和应用验证，难以判断新增抽象是否改善真实协作。

## Future Work
作者计划实现组件，在模拟或真实协作任务中评估绩效，并用于认知数字孪生；还需处理个体工作记忆等差异及隐认知状态的验证。

## Rating
创新度评分：1/5 - 主要是既有认知模块的概念重组，无新学习方法或实证支持。
相关度评分：0/3 (Noise) - 此处世界模型是一般认知表征，未研究用户关注的视频、3D 或隐式预测世界模型。

## TL;DR
以八模块和共享目标空间描述人机认知协作，未实现或验证预测世界模型，可跳过。
