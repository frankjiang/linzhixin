# EnvACE: Internalizing Environment Dynamics via World Rehearsal for Agentic Reinforcement Learning

## Insight
观察到常规 agentic RL 始终由外部环境/模拟器返回 observation，因而策略只学“如何响应反馈”，环境动力学没有进入 acting policy。作者据此推论，让同一个 LLM 轮流扮演 ACT 与 REHEARSE：先提出 tool call，再自己生成该动作会触发的响应，并用最终任务奖励共同更新两种输出，可将动作—反馈关系内化进参数。共享参数相对两套独立角色策略在 τ²-Bench 上由 35.5% 提至 36.7%，提供了弱支持；但论文没有直接测量生成响应与真实环境的一致性，故“学得世界模型”仍是间接推断。

## Motivation
可执行工具环境难以大规模构建和验证，独立 LLM simulator 又可能失真并仍需真实环境校准。EnvACE 试图完全取消训练 rollout 中的外部环境调用，由策略自我展开长时轨迹，降低 agentic RL 的环境瓶颈。对 LLM 工具调用训练是关键问题，但属于语言/软件环境建模，与视频、3D 或物理隐式世界模型无实质关系。

## Method
将工具任务表示为 POMDP。共享 Qwen3 policy 每回合先在 ACT role 下采样动作，再在 REHEARSE role 下根据历史与动作生成模拟工具/用户响应，追加到 history 后继续，最多 30 回合。每个指令采样 K 条自展开轨迹，以 verifiable evaluator 或 checklist LLM judge 给出整轨 reward；所有 token 继承该 reward，但 ACT 与 REHEARSE 分别计算 group baseline，再通过 clipped role-wise GRPO 联合更新同一参数。

测试时先私下执行 N 次 act–rehearse 想象：parallel 模式相互独立，sequential 模式读取先前轨迹与自评反馈；最终压缩为 rehearsal memory，再在真实环境仅执行一次。训练中所谓 tool simulator prompt 实际包含 whitelist/schema 校验，并在相似 few-shot 不存在时由模型“生成合理结果”，因此并非从无监督交互中发现一般环境动力学。

## Experiment
主模型为 Qwen3-8B，在 CM2 数据上训练 470 步，16 张 H20、每 prompt 四个 rollout，训练 reward 使用 Qwen3-30B-A3B judge。评测 BFCL-v4、τ²-Bench、VitaBench 和 FinMCP-Bench。EnvACE-8B 的前三者均值 Overall 为 32.91%，略高于 EnvScaler-8B 的 31.92% 和 AWM-14B 的 32.54%；FinMCP TF1 为 46.78%，高于 EnvScaler 的 43.68%。

控制实验在 τ²-Bench 上显示标准 GRPO 为 31.2%、分角色 policy 为 35.5%、共享 EnvACE 为 36.7%；1.7B 上 base/GRPO/EnvACE 为 10.4%/14.7%/15.3%。测试时 N=2 的 parallel EnvACE rehearsal 将 τ² + BFCL Multi-Turn 的 Overall 从 36.7% 提至 40.9%，sequential 为 38.5%；N=3 反而退化。作者还给出两个避免无效写操作/参数错误的个案。除 non-TTS 为四次运行均值外，TTS 仅跑一次；没有置信区间、显著性检验或真实 tool-response fidelity 指标。

## Value
对 LLM agent 的价值是把 environment simulator 变成共享 policy 的一个角色，并把想象用于 test-time action screening；“同一模型既行动又预测反馈”与隐式 world model 的思想相似。对我们的方向没有直接技术可复用性，因为状态、动作、观察全是文本/JSON，且模型没有视觉或物理动力学。更值得关注的普遍问题是：若 imagined observation 同时决定后续行动和奖励，如何防止自洽幻觉与 reward hacking。

## Strengths
- act–rehearse 训练循环简单清晰，不需要独立 simulator，测试时也能复用。
- 覆盖四个不同工具调用基准和两个模型规模，并包含 GRPO、独立角色与共享参数消融。
- 训练与测试时收益均有展示，案例能直观说明先想象后执行的安全价值。
- Prompt、主要超参数和角色优化公式披露较完整。

## Weaknesses
- 未直接验证 rehearsed response 是否匹配真实环境；任务得分提升不能证明模型学到正确动力学。
- 自生成 observation 配合 LLM judge 容易形成“方便完成任务”的闭环幻觉或 reward hacking，论文没有环境对齐约束与错误传播分析。
- role-wise GRPO 仍把整轨 reward 均匀赋给所有动作/响应，不能解决长时 credit assignment；其 baseline 定义按输出数计权，还可能偏向发言更多的轨迹。
- 与 EnvScaler/AWM 等基线的训练数据、预算、模型规模不完全一致，Overall 只是三个基准均值，领先幅度不足 1 个百分点。
- TTS 只报告单次运行；训练曲线和多项结果无误差条/显著性，N=3 退化显示扩展性有限。
- simulator prompt 严重依赖工具 schema 和 few-shot reference，所谓“不依赖外部环境”并不等于无需环境知识。

## Future Work
作者明确提出扩展到 8B 以上模型和工具交互之外的 agent 场景。更关键的后续应加入真实响应校准、模型不确定性与拒绝机制，分离 actor 与 world-model 的自证偏差，并评估长时 hallucination、奖励攻击及 test-time rehearsal 的成本—收益。

## Rating
创新度评分：3/5 - 共享 LLM 的 act–rehearse 自展开与 role-wise GRPO 是有辨识度的组合，但“world model”证据只来自下游分数，环境真实性问题未解决。
相关度评分：0/3 (Noise) - 纯 LLM 工具调用与文本环境训练，不涉及视频世界、3D 世界或 JEPA/Dreamer 式物理表征。

## TL;DR
共享 LLM 自演工具环境可提升 agent RL 与测试时规划，但属纯文本世界模型，建议跳过。
