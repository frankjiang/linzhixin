# Unified Driving Tokens: Representation- and Geometry-Guided Discrete Tokenizer for Driving World Models and Planning

## Insight
核心 insight：自动驾驶中的离散 token 需要同时服务两个下游任务——世界模型生成（next-token prediction）和规划（trajectory readout），但现有 tokenizer 只为像素重建优化，缺乏对规划可消费性的设计。论文观察到：
1. 纯重建优化的 token 语义信息不足以支撑规划
2. 加入 DINO 特征对齐后语义提升但面临容量瓶颈
3. 进一步加入几何监督（depth + pose）后 PSNR 下降，说明离散瓶颈容量有限
4. Multi-codebook 量化有效缓解了容量竞争

## Motivation
Token-based 自动驾驶世界模型（如 DrivingGPT）将驾驶场景压缩为离散 token 序列做 next-token prediction。但 tokenizer 通常继承自图像生成（如 VQGAN），主要为像素重建优化。这导致 token 语义与规划需求之间存在 gap：token 可能保留了丰富的纹理细节但缺乏几何/运动信息，或者语义表示不利于下游 planner 解码。现有工作（DrivingGPT、Orbis）未将 planning-consumability 作为 tokenizer 训练的一等目标。

## Method
整体框架包含三部分：
1. **Representation-Guided Tokenizer**（核心）：
   - Encoder：轻量 RGB detail branch + frozen DINO patch features → 拼接 → Pre-Norm Transformer (RoPE)
   - VQ bottleneck：EMA codebook (K=16384)，straight-through estimator
   - Decoder：shared Post-Transformer → RGB decoder (pixel + LPIPS + GAN) + DINO feature decoder (cosine + MSE)
   - 联合重建 RGB 和 DINO 特征，离散 token 被约束到同时近似强语义表示和外观

2. **Cross-Frame Geometric Supervision**（训练时使用）：
   - 相邻帧 token 经时空聚合器 → 解码 depth（DPT-style）和 relative pose
   - Depth loss + pose loss（含 sign-invariant quaternion loss）
   - 仅训练时使用，推理不需要

3. **Multi-Codebook Quantization**：
   - Attention-based splitter 将每个 token 分为 M=4 个 head，各自量化到独立 codebook（K_m=4096）
   - 合并后通过 learned projection 融合
   - 不改变空间分辨率，仅增加容量

下游评估：
- **Planning decoder**：frozen tokenizer → learnable registers → 轻量 trajectory decoder (20M) + scoring head
- **World model**：frozen tokenizer → GPT-style Transformer (1B) next-token prediction

- 对比 LlamaGen 和 Orbis，Ours-Rep 在 rFID(4.15)、PSNR(26.51)、SSIM(0.774)、DINO cosine(0.0453) 上全面最优

## Value
这是一篇扎实的工程导向工作，核心贡献在于为自动驾驶场景设计了"规划友好"的离散 tokenizer。方法设计清晰（DINO 对齐 + 几何监督 + multi-codebook），实验充分（重建/规划/世界模型三个维度 + 消融）。

对世界模型方向的启发：
1. Tokenizer 设计需考虑下游任务需求，不能只优化重建
2. 语义特征（DINO）对齐是提升 token 可用性的有效手段
3. 几何信息编码与外观重建存在容量竞争，multi-codebook 是一种解决思路

局限：仅在 NAVSIM 上验证，数据集和任务多样性不足；tokenizer 和世界模型/planner 是分开训练的，未探索联合训练；单视角设置。
