# MPCoT: Reward-Guided Multi-Path Latent Reasoning for Test-Time Scalable Vision-Language-Action

## Insight
Observation: VLA 策略的 one-pass action decoding 在长程任务中脆弱，显式 CoT 推理引入 token 开销和延迟；而 latent space 中的 deliberation 可以在不改变动作接口的前提下增加推理深度。推论：可以在 latent space 中引入 multi-path + multi-step 的推理机制，类似于 test-time compute scaling，但保持零 reasoning token。通过 reward-guided path preference 训练 scorer 来选择更好的路径。实验证明 depth K 和 width M 具有互补效果，且 reward supervision 显著提升 path consistency。

## Motivation
VLA 面临推理深度与控制效率的矛盾：显式 CoT 增加推理能力但引入延迟（110-160ms vs 38ms），纯 one-pass decoding 在长程高不确定性任务中脆弱。MPCoT 在 latent space 中做 multi-path deliberation，保持原始 8-step action interface 不变。同行工作如 Recurrent-depth VLA 仅探索单路径 latent refinement，MPCoT 增加了 width 维度和 reward-guided 路径选择。

## Method
1. **Backbone Interface**：在 OpenVLA-OFT 的 multimodal encoder 之后、policy head 之前插入 latent reasoning module
2. **Multi-Path Hypothesis Initialization**：从同一 grounded context 初始化 M 个 latent hypotheses（通过 learnable hypothesis codes + noise perturbation）
3. **Weight-Tied Multi-Step Refinement**：共享 refiner F_θ 对每条路径执行 K 步残差更新，条件于 context
4. **Soft Aggregation**：轻量 scorer h_ω 对 M 条路径评分，softmax 加权聚合
5. **Reward-Guided Path Preference**：训练时用 action consistency + world-model/VLM progress + success 三个 reward 信号训练 scorer；推理时不需要 reward，仅用学到的 scorer

仅增加 2.7% 参数量，推理延迟从 24ms 增至 38ms（K=5, M=4）。

## Experiment
- 基准：LIBERO（近天花板）和 CALVIN ABC->D（长程泛化）
- LIBERO：Average SR 从 96.8 提升至 98.9，Long SR 从 95.3 到 98.9
- CALVIN：5-step SR 89.4（vs AVA-VLA 84.1），Avg len 4.92（vs AVA-VLA 4.65）
- 消融：depth K 1->5 和 width M 1->4 效果互补；soft aggregation + diversity regularization 减少路径相似度；reward supervision 将 Path Consistency 从 68.5 提升至 84.3
- 效率：latent CoT 延迟远低于 textual CoT（38ms vs 110-160ms），零 token overhead

## Value
方法简洁有效，在 VLA 中引入 test-time compute scaling 是有价值的探索。但本质上是 latent ensemble + iterative refinement 的组合，创新程度有限。对世界模型研究的直接启发较少——world model/VLM evaluator 仅在训练时使用，推理时完全移除。工作更偏向 VLA 策略优化而非世界建模。

## TL;DR
在 VLA latent space 中引入多路径多步推理和 reward-guided 路径选择，以零 token 开销实现 test-time compute scaling。可选读。
