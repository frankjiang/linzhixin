# BadWorld: Adversarial Attacks on World Models

## Insight
视觉 world model 的攻击难点是没有真实未来视频标签、也不知道未来控制序列。BadWorld 的 insight 是直接攻击扩散早期 denoising dynamics，并通过 bi-level optimization 主动挖 hard controls，得到对用户动作更鲁棒的 context image 扰动。

## Motivation
交互式 VWM 从单帧生成动作条件 rollout，部署到机器人/驾驶等安全场景时需要知道是否会被不可见扰动破坏。普通 adversarial attack 假设标签或固定动作，不适合 autoregressive controllable VWM。

## Method
框架包含 self-supervised velocity attack：不依赖未来 GT，扰乱早期去噪速度/方向；trajectory-adaptive bi-level optimization：内层寻找使攻击失效的困难控制轨迹，外层学习 control-agnostic perturbation。攻击对象包括连续/离散控制 VWM。

## Experiment
在代表性 VWM 上，微小不可见扰动导致未来 rollout 去噪不完整、结构坍塌、控制不一致。评测关注视觉质量退化、控制一致性和跨动作泛化。实验说明 VWM 对初始 context image 的局部扰动有结构性脆弱。

## Value
对视频世界模型安全很相关，贡献是攻击设定而非生成模型本身。启发是 world model 评测必须包含 context robustness 和 action-conditioned stability。可选读。

## Strengths
亮点是对视频世界模型安全很相关，贡献是攻击设定而非生成模型本身。

## Weaknesses
不足是评测关注视觉质量退化、控制一致性和跨动作泛化。

## Future Work
作者未明确提出具体未来工作；从局限看，后续需要围绕“评测关注视觉质量退化、控制一致性和跨动作泛化”补充更大规模验证、跨场景扩展或方法改进。
