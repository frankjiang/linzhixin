# Twin: Playing an Unknown Game with a Test-Time Digital Twin

## Insight

观察：未知游戏中每次动作都提供动力学监督，但只有过关才提供目标监督；二者信息密度高度不对称。推论：不应把动力学与奖励联合成一个模糊假设，而应要求可执行转移模型硬性重放全部历史，再把目标作为可证伪假设主动探索。Twin 让 coding agent 在测试时编写 Python 数字孪生；每个真实转移不匹配都成为反例并触发修复，计划只在通过 replay validation 的孪生中执行。结果显示动力学可较快学会，而真正瓶颈是稀疏目标：首个目标假设在已完成关卡中 87.2% 正确，但细粒度 goal claim precision 仅 21.4%。

## Motivation

ARC-AGI-3 隐藏网格游戏的控制规则与胜利条件，直接反应式模型动作浪费严重。Dreamer/MuZero 等通常用多回合梯度学习 latent dynamics；WorldCoder/EWM 等虽合成程序模型，却缺少该工作强调的“完整历史硬校验、目标假设检验、逐动作 halt-on-mismatch”一体化约束。问题重要，但主要属于程序化模型推断与 agent harness，而非视频或 3D 世界模型。

## Method

每个游戏维护追加式转移日志和包含 `step(grid, action)`、`goal_reached(grid)` 的 Python twin。循环为：Validate 对全部历史逐格重放；失败时按动作/颜色上下文、错误率、效果多样性和支持度排序并让 agent 修复；模型干净但无计划时，Explore 在 twin 内搜索候选进展状态（颜色消失/出现、局部突变、全局变化、前沿），据此提出目标谓词；Plan 用 BFS（通常深度 8、20k 节点）找最短计划；ExecuteChecked 先提交预测哈希，再逐动作执行，首个不匹配立即停止并回写反例。候选目标必须拒绝所有历史帧，且到达后未过关的候选永久排除。

创新在于测试时生成、验证、修复和规划的可审计闭环，以及对“动力学全称一致性”和“目标存在性搜索”的显式分离；具体程序合成、CEGIS、BFS 与启发式本身并非新技术。

## Experiment

- 在全部 25 个公开 ARC-AGI-3 游戏、183 关上，Twin 得分 93.3，完成 23/25 游戏、179/183 关；同一 GPT-5.6 Sol 的 off-the-shelf Codex harness 为 61.1、148 关，直接玩为 7.8。
- 对共同完成的 13 个游戏，Twin 用 3,357 个真实动作，OPINE-World/EWM/人类分别为 5,367/5,381/7,485；在已通关的 23 个游戏中，21 个不超过首次人类动作数。
- 92.9% 动作来自 twin 中已测试计划，7.1% 为探测；20.1% 动作结果与预测不符。31 个已修复场景后来复现时全部预测正确。
- 在线首见 state-action 对精确预测率 79.0%，重复对为 94.8%。最终 twin 在 20,790 个邻近但未观察的动作分支上整帧精确率仅 70.1%，不同游戏从 9.9% 到 98.8%，说明 replay 通过不等于泛化。
- 代价很高：25 次运行共 2.60B processed tokens、91.4 小时、11,614 个动作，平均 224k token/动作；无 twin 消融仅 48k token/动作。模型/服务无随机种子，只做每游戏一次正式运行。
- 附录进一步比较 twin 与真实引擎中的 BFS、统计目标 claim（recall 77.1%、precision 21.4%）并展示部分可观测游戏依赖“每个新位置付费记忆”，不是推断未知地图。

## Value

对 agent 世界模型的核心启发是：把环境模型变成可执行、可反例驱动修复的显式假设，并在真实动作前进行机械验证，可显著降低交互成本。它也清楚揭示动力学学习与目标发现的监督不对称。但对视频/3D/JEPA-Dreamer 研究，仅能借鉴验证门、可审计状态和主动探测思想，不能直接迁移其精确离散重放假设。

## Strengths

- 同一基础模型的完整 harness 消融，效果差异大且评测覆盖全部公开游戏。
- 每个动作预测事前哈希、完整日志和可执行代码使结果高度可审计。
- 附录不只报分数，还测试未见分支泛化、真实引擎规划、token 成本和目标谓词误报。
- 明确区分已观察一致性、邻近泛化、目标发现和部分可观测性。

## Weaknesses

- 依赖确定性、离散、64×64 且可逐格精确比较的环境；连续视觉、随机动力学和真正隐状态均不适用。
- 核心消融一次性删除整个 harness，无法分离 Validate、Explore、Plan 和 goal discovery 的贡献。
- 与主要竞品使用的模型、预算不同；同模型只有 Codex/Prime Agent 间接对照，缺少多随机种子。
- 93.3 分以 2.60B token 和超长测试时计算换取，计算效率并不优于无 twin 消融。
- goal predicate 大量误报，两个未完成游戏主要卡在目标推断；部分可观测案例靠缓存已见地图而非推断潜在状态。

## Future Work

作者提出从确定性孪生扩展到概率模型，支持长时间上下文和不可见潜变量，并用更强先验缩短目标发现；当前搜索预算之外的目标和连续观察的近似校验也需要新机制。

## Rating

创新度评分：4/5 - 将测试时程序化世界模型、全历史验证、目标假设检验和受检执行整合成强闭环，结果突出；但建立在小型确定性网格与巨量测试计算上。
相关度评分：1/3 (Tangential) - 属于符号化 agent 世界模型与程序合成，和视频、3D、JEPA/Dreamer 仅有间接方法论联系。

## TL;DR

测试时编写并反例修复可执行游戏孪生，agent 方法新颖但本方向可选读。
