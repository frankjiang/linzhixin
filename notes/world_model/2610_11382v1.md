# PlanWAM: Planning-Shaped Future Representations for End-to-End Autonomous Driving

## Insight
未来表征若只按图像重建学习，可能保留大量与驾驶决策无关的细节。论文用未来真值训练“后见”表征，再让轨迹生成与候选打分的任务损失塑造它，最后蒸馏成只依赖历史的“预见”表征。受控消融显示规划塑形、蒸馏和将表征用于候选选择各有增益，但 NAVSIM 基线已高，绝对收益较小。

## Motivation
自动驾驶世界模型从像素生成转向未来特征预测，常把预定义 DINO/JEPA/BEV 特征当目标；预测目标未必匹配规划需求。任务相关的未来信息究竟是什么、怎样在推理时仅凭历史得到，是隐式世界动作模型的关键问题。

## Method
1. DINOv2 ViT-S 提取四相机历史帧的 scene register；Temporal Register Pyramid 对近帧分配更多查询，将 256 个历史寄存器压成 128 个 token。
2. 训练阶段的后验用未来 1–4 秒四相机真值 register 作查询，结合历史产生 256 个未来 token；64 条候选轨迹生成器与六维质量打分器的监督反传到这个表征，使其偏向规划所需信息，而非重建视觉特征。
3. 冻结后验教师，以历史为唯一输入的先验用对应时刻/相机/槽位查询预测未来 token，采用逐 token MSE 蒸馏并继续优化轨迹生成与评分。推理时去掉后验，先验表征同时供轨迹生成和候选选择使用。其“世界模型”输出是规划表征，不生成可检验的未来图像或显式场景。

## Experiment
在 NAVSIM navtrain 训练，NAVSIM-v1/v2 navtest 报 PDMS/EPDMS 及碰撞、可行驶区域、TTC、进度等子分数；HUGSIM 的 436 个场景做零样本闭环评测，报路线完成率和 HD-Score。主结果为 NAVSIM-v1 PDMS 93.8（最强列出基线 DrivoR 93.1）、v2 EPDMS 90.9（DriveFuture 89.9）；HUGSIM HD-Score 38.7、路线完成率 53.7，分别高于列出的 Latent-WAM 28.9/45.9。

逐项消融：基础模型 PDMS 93.1，加入历史金字塔 93.4、蒸馏 93.5、预测未来用于规划 93.8；通用未来特征监督为 93.5，规划塑形为 93.8；仅把未来 token 用于候选选择为 93.7。后验可见真值未来的 oracle 达 95.0。附录表明只最小化隐向量距离、冻结规划器时 PDMS 仅 93.0；规划器和打分器必须适应先验预测误差。NAVSIM 的提案评估是非响应式模拟，HUGSIM 才提供闭环检验。

## Value
值得参考的是让下游决策损失定义“该预测什么”，以及将训练期特权未来蒸馏给部署期预测器；也提醒不能只报告 latent 相似度。对隐式世界模型设计有直接借鉴，但仍需检验表征是否真正可在新动作条件下推演不同未来，及真实驾驶可行性。

## Strengths
- 将未来表征、轨迹生成、候选打分和蒸馏分别消融。
- 除开环榜单外还做零样本闭环驾驶评测，并分析碰撞/TTC 类失败。
- 结果揭示候选选择比单纯提升生成器或隐向量相似度更受益。

## Weaknesses
- 核心组件相对基础模型只提升 0.7 PDMS；近饱和榜单上的意义需谨慎解释。
- 先验从历史预测单个未来表征，缺少显式动作条件与反事实未来准确性测量。
- 计算需两阶段训练及未来多视角真值；HUGSIM 仍为模拟，真实车闭环尚未展示。

## Rating
创新度评分：3/5 - 以规划任务塑造未来 latent 并蒸馏到历史先验，思路清晰，但组件及训练范式多为已有技术组合。
相关度评分：3/3 (Core) - 直接研究隐式未来表征如何辅助世界模型规划。

## TL;DR
用轨迹规划损失塑造未来隐表征并蒸馏到历史先验，提升驾驶规划；任务对齐目标与候选选择值得精读。
