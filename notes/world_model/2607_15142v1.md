# Concept-Guided Spatial Regularization for World Models in Atari Pong

## Insight
论文的 insight 是：MBRL agent 表现好不等于其 world model 冻结后能作为可靠 simulator。Pong 中球只占少量像素，但决定动力学和奖励；普通训练目标会低估这类任务关键概念。推论是对关键概念区域施加额外重建监督，可以减少 rollout 中球消失、错误反弹等 exploitation-friendly 错误。论文没有深理论证明，主要是系统诊断加 controlled offline training 验证。

## Motivation
该文解决视觉 world model 的独立可靠性评估问题。同行通常报告 DreamerV3、DIAMOND、TWISTER、Simulus、STORM 的最终 RL 分数，world model 本身很少冻结后单独评测。作者发现这些模型原始 Dyna-style 训练能得到不错策略，但冻结模型让新策略在其中从零学习再迁移到真实 Pong 时表现崩溃，说明“可辅助在线训练”与“可作为 standalone simulator”不是同一能力。这是 Dreamer/Atari 视觉世界模型的关键问题。

## Method
方法分两部分。第一是诊断：用独立 PPO Pong policy 驱动冻结 world model 做 horizon-512 closed-loop rollout，人工检查视觉和动力学错误；再做 pixel-space zero-shot MBRL，即在冻结模型内部训练新视觉策略，再到真实 ALE Pong 测试。第二是 CGSReg：在原 world-model loss 上加入概念 mask 区域的重建损失，Pong 主实验用 SAM2 得到 ball mask，并按不同项目的 image loss 位置接入，不改模型结构。离线对照用固定 100k-step replay 数据、关闭 policy 学习，只比较 baseline WM 与 CGSReg WM。

## Experiment
诊断覆盖 DreamerV3、DIAMOND、TWISTER、Simulus、STORM。原 Dyna-style agent 可复现实验分数，但 frozen-WM RL-only 在真实 Pong 上大幅下降：DreamerV3 从 -5.45 到 -20.90，DIAMOND 19.70 到 -9.55，TWISTER 17.70 到 -13.30，Simulus 20.75 到 -11.60，STORM 18.70 到 -21.00。CGSReg 在统一 zero-shot 协议下改善 DreamerV3 -21.00 到 -11.90、DIAMOND -13.90 到 -5.80、TWISTER -21.00 到 -1.90、Simulus -15.80 到 -4.10，但 STORM 仍为 -21.00。rollout 质检显示 DreamerV3/DIAMOND/TWISTER 的球建模改善更明显，STORM 的主要瓶颈是 action response。

## Value
对视觉 world model 很有参考价值：评估 world model 不能只看绑定策略的最终回报，应冻结模型后检查闭环 rollout、action response、关键对象持久性和在模型内训练出的策略迁移。CGSReg 本身是简单启发，但诊断框架对 Dreamer 类模型尤其有启发。

## Strengths
复现并横向诊断 5 类代表模型；把 frozen simulator 能力和 Dyna-style agent 能力区分清楚；zero-shot MBRL 评估比只看视频更接近控制用途；CGSReg 改动小、可跨架构接入。

## Weaknesses
只在 Pong 验证，关键概念可手工指定且很易分割；CGSReg 依赖人类先验和 SAM2 mask，难推广到规则、关系或隐状态；改进后分数仍远未解决 Pong；人工 rollout 质检缺少更自动化、可扩展的动力学指标。

## Future Work
作者提出要扩展到更复杂环境和更多 world-model 架构，并减少对手工指定概念的依赖，自动发现 task-relevant concepts；还需要解释为什么弱 frozen model 仍能在持续更新的 Dyna-style 训练中支持强策略。

## Rating
创新度评分：3/5 - CGSReg 是增量正则，但 frozen world model 诊断和 pixel-space zero-shot MBRL 评估有实用价值。
相关度评分：3/3 (Core) - 直接研究 Dreamer/DIAMOND/STORM 等视觉世界模型的可靠性与修补。

## TL;DR
该文诊断Pong视觉世界模型冻结后不可靠，并用概念区域重建修补，值得精读。
