# Diffusion Transformer World-Action Model for AV Scene Prediction

## Insight
论文的主要 insight 是：自动驾驶 latent world model 若只用 distortion metric，会偏好模糊条件均值；扩散模型在 KID/FID 和动作可控性上更接近可用 world-action model。另一个观察是 V-JEPA2 的时序上下文显著提升 ego-action 表征。

## Motivation
解决 compact AV world model 的表示、目标、指标选择问题。大系统如 GAIA-1/Cosmos 难做可控消融；作者在小模型上诊断 encoder、DiT objective、anchoring、sampling 和 metric。与用户方向相关，但规模和任务较窄。

## Method
数据为 nuScenes 850 scenes，前视 camera + CAN bus steer/accel。先做六种 frozen encoder 的动作预测 probe：ViT、DINOv2、CLIP、V-JEPA2 rep1/rep64、VQ-VAE Tracker。世界模型用 frozen SD-VAE latent 32x32x4，patchify 后送 AnchoredVAE DiT，条件包含 timestep、当前 latent、Fourier action embedding；预测未来 H={4,8,16} latent。比较 x0 diffusion、direct regression、MLP residual；另做 1.7M chain-anchor jump model 逐段 re-anchor。

## Experiment
Encoder benchmark：V-JEPA2 rep64 steering RMSE 0.058，rep1 0.097，约 40% 降低；accel 差异较小。DiT 诊断显示 x0 objective 恢复 88.5% gap，epsilon objective 会近似 copy/collapse。SD-VAE world model 中 direct regression 在 CosSim/SSIM 等 distortion metric 好，但 diffusion KID 0.078 vs direct 0.375，FID 162.5 vs 370.8。动作可控性：diffusion steer-vs-shift Spearman rho=0.81，direct rho=-0.18；inverse-control probe diffusion 0.67x chance error，direct 1.24x。jump model 说明单一 anchor 限制多秒运动。

## Value
价值在于给 AV latent world model 的评估提出清晰警告：distortion metric 不能代表可规划性，应同时看分布质量与 action controllability。创新不是大模型能力，而是诊断扎实。局限是 2Hz 单前视、小模型、open-loop logged actions，离真实闭环驾驶还远。

## Strengths
亮点是给 AV latent world model 的评估提出清晰警告：distortion metric 不能代表可规划性，应同时看分布质量与 action controllability。

## Weaknesses
不足是 2Hz 单前视、小模型、open-loop logged actions，离真实闭环驾驶还远。

## Future Work
