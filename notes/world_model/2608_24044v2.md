# JEPA-x: Cross-Predictive Physics Grounding for Forecastable Latent Dynamics

## Insight

核心观察是“物理状态可解码”“潜在动力学可预测”“规划可用”是三种不同性质。逐帧 state regression 能把物体位置 R² 提到 0.991，却仍有 0.373 rollout drift 和 53.7% 控制成功率；JEPA-x 的位置 R² 仅 0.978，却达到 0.104 drift 和 78.2% 成功率。进一步地，错配物理轨迹的 SHUFFLE 仍有较低 drift 0.167，却只剩 16.6% 控制成功率。因此，可靠规划不仅要求潜在转移容易预测，还要求其几何由“同一动作下正确配对的物理后果”塑形。论文用 fresh-predictor probe、错配对照、对齐/蒸馏/共享预测器消融和 rank-matched PCA 较充分地支持了这条推论。

## Motivation

端到端 self-predictive JEPA 同时优化 encoder 与 predictor，二者可能共适应到“容易被当前 predictor 预测、却不忠于物理演化”的潜在转移；简单状态回归或跨模态对齐只约束单帧内容，未直接约束动作后的未来。论文关注的是隐式世界模型的关键问题：怎样利用仅训练时可见的物理状态，让部署时纯视觉 latent 更适合长程预测和规划。

## Method

1. 在 LeWorldModel 上保留视觉 encoder `f` 和 action-conditioned predictor `g`，增加仅训练使用的物理 encoder `h`。物理状态以统一刚体 schema 表示：每个物体 token 含 pooled SDF、半尺寸、旋转和位置，另有末端执行器与 table token；空槽通过 mask 支持不同物体数。
2. 视觉历史与物理历史都经同一个 predictor 在动作条件下推进，并同时匹配视觉未来和物理未来，形成 `o→o`、`o→s`、`s→o`、`s→s` 四项等权预测损失；两分支各自用 SIGReg 防坍缩。
3. 这既使同一时刻的视觉/物理表示对齐，也要求两种历史沿动作预测同一个未来几何；物理 target 不是冻结教师，两套 encoder 在线共同学习。
4. 部署时彻底丢弃物理 encoder，仅用视觉 latent rollout；候选动作以终端 latent 到目标图像 latent 的欧氏距离排序。多任务实验用无条件 action-VAE 的 32 维潜空间做 z-CEM，避免直接搜索不连贯的原始动作序列。

关键创新是把 privileged state 从“单点内容监督”改为“对应轨迹的双向跨预测约束”，并以统一物理 token 接口覆盖多种物体和交互；实现本身简洁，主要贡献在目标设计和性质分解。

## Experiment

- 单任务使用 Two-Room、OGBench-Block、Push-T、Reacher；多任务 Meta-World 套件含 22 个物体-任务配置、13 个资产、29,260 条 episode 和约 144 万 transition。每个训练 seed 评测六类共 300 个 held-out scenario，报告三个训练 seed，并做 episode-clustered paired sign-flip test。
- 为隔离 representation 与共训练 predictor，冻结各视觉 encoder、丢弃原 predictor，统一从头训练轻量 action-conditioned probe 并自回归 20 步；multi-task 相对 drift 从 VISUAL 的 0.361 降到 JEPA-x 的 0.104。四个单任务也全部降低，例如 Two-Room 0.503→0.221、OGBench-Block 0.507→0.269。
- 多任务平均控制成功率由 53.6% 升至 78.2%，六个家族均提升。每个训练 seed 在 300 个配对场景上做 episode-clustered Monte Carlo sign-flip test，均得 `p≤10^-5`；这是 10⁵ 次 assignment 的分辨率下限，不是跨 seed 的总体检验。单任务提升更有选择性：Two-Room 74.7%→94.8%、OGBench 64.9%→78.7%，但 Push-T 略低于 VISUAL（94.1% vs 94.9%），Reacher 只高 0.9 点。
- 关键消融：CROSS-ONLY 为 drift 0.101、控制 73.0%，说明共享 predictor 不是主要来源；ALIGN-ONLY 为 0.158/72.6%，显示对齐贡献大、直接跨预测进一步改善 forecastability；SHARE-ONLY 0.309/56.7%，增益很小；DISTILL 0.516/57.7%；错误配对 SHUFFLE 0.167/16.6%。SHUFFLE 较大的 Copy denominator（15.11，对比其他方法约 12）会压低 normalized drift，但其 raw error 2.09 仍低于 VISUAL 的 4.43。
- R²、fresh predictor、错误配对与 PCA 等控制实验较扎实；但所有控制均在 simulator 中，且主要多任务比较围绕同一 LeWM backbone 与自建数据/规划协议。

## Value

论文对隐式世界模型最有价值的启发是：评估 latent 不能只看 probing 是否能读出状态，也不能只看一步自预测损失；应独立测试更换 predictor 后的多步 forecastability，并验证 latent distance 是否保留动作选择所需的物理区分。对应轨迹的跨预测可作为训练时有 simulator state、部署时只有视觉的通用方案，适合机器人 sim-to-real 和视频 JEPA。

## Strengths

- 问题定义精确，把 decodability、forecastability、control utility 三者拆开，形成可复用的分析框架。
- fresh-predictor、state regression、alignment、distillation、shared predictor、错误配对和有效秩控制形成强证据链，不只靠最终成功率。
- 物理分支部署时删除，无额外推理开销；统一 rigid-body schema 避免逐任务标签接口。
- 覆盖四个单任务和较大的多任务交互套件，使用三训练 seed、配对场景和显式统计检验。
- 对结论保持克制：明确指出 forecastability 改善不保证每个任务都提升控制。

## Weaknesses

- 仅仿真验证，训练必须获得严格时间对应的 privileged pose/geometry trajectory；真实视频中的状态估计噪声和跨模态错配可能严重削弱方法。
- 状态 schema 限于固定刚体、最多六物体，不含速度、接触力、wrench、可变形体或未知物体；对复杂物理交互的外推尚未证明。
- 多任务主结论主要相对 VISUAL/REGRESS 等同源内部基线，缺少与更广泛 Dreamer、TD-MPC2、DINO-WM 或 concurrent privileged-world-model 方法的统一控制比较。
- CROSS-ONLY 的 drift 甚至略好于完整模型，SHARE-ONLY 几乎无益，说明“shared common transition rule”并非主要载荷；完整架构的必要性弱于标题叙事。
- planner 每 25 个环境动作才重规划，且 action-VAE/CEM 预算很大；尚未报告数据效率、规划延迟或模型/搜索预算变化下的稳健性。
- 代码与数据仅承诺后续发布，当前复现性尚未兑现。

## Future Work

作者明确提出扩展到真实世界观测、更广泛物理交互和不受固定刚体 schema 限制的场景。进一步可研究带噪/不完整 privileged trajectory、可变形与接触状态、更通用的物理 token、跨 embodiment 迁移，以及在更长 horizon 和不同 planner 中验证 forecastability 与控制收益的关系。
