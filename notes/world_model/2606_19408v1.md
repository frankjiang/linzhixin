# FlexLAM: Resolving the Bottleneck Trade-off in Latent Action Learning

## Insight
Observation：Latent Action Model 用固定容量 code 表示所有 transition，但 transition 复杂度不同。容量太小会丢失动作对齐线索；容量太大又把 nuisance variation 留给 translator，在少量动作标签下更难对齐。

推论：让同一个 latent action code 的多个 prefix 都能有效解码和对齐，可形成可变容量 bottleneck，使早期 token 承担通用动作信息，后续 token 补充细节。

## Motivation
论文解决 action-free video 到 executable action 的接口问题。动作标签少，而视频数据多；LAM 需要从 `(o_t,o_{t+1})` 学 transition code，再用小规模 labeled data 对齐动作。

同行多用 fixed-K latent action。FlexLAM 认为问题不只是调 K，而是固定容量接口本身不稳定。

## Method
FlexLAM 只改 latent-action bottleneck：
- 对 K-slot latent code `z_t`，随机采样 prefix length `k`。
- `j<=k` 保留 token，`j>k` 替换为共享 learnable null latent。
- decoder 用 null-filled prefix 重建 transition；translator 也用同样 prefix sampling 学动作。
- 推理时可用 `FlexLAM@k` 在同一模型中调整当前步 token budget。
- 下游用固定 latent-token sequence model 做 DMLab 评估。

创新点是 retained-prefix training，把 nested/dropout 表示思想用于 latent action interface。

## Experiment
DMLab 控制实验 + Ego4D/真实视频重建诊断。

结果：
- 在 DMLab scarce-label 设置中，同一个 FlexLAM 在 k=4/16/64 都优于分别训练的 Fixed-K baseline。
- 单一低回报任务作为窄动作标签源时，FlexLAM 比 Fixed-K64 更稳定。
- Ego4D transition reconstruction：villa-X-LAM PSNR 16.91、SSIM 0.5442、LPIPS 0.5473；FlexLAM k=80 达 PSNR 19.84、SSIM 0.6532、LPIPS 0.3216。
- 当前步预算权衡：k=16 达 27.3% normalized return，接近 k=64 的 28.8%，延迟 176ms vs 638.8ms。

## Value
对视频/机器人世界模型的启发：latent action 不是越紧越好或越松越好，而应支持按 transition/计算预算自适应。该接口可用于 action-free 视频预训练、机器人策略和 latent-action world model。

局限：主要是 representation-level evidence；DMLab 是主要受控下游，真实视频只做重建参考，尚未证明真实机器人策略迁移。

## Strengths
亮点是对视频/机器人世界模型的启发：latent action 不是越紧越好或越松越好，而应支持按 transition/计算预算自适应。
