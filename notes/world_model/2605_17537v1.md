# ResDreamer: Hierarchical World Model with Residual Connections

## Insight
核心洞察：层次化世界模型中，低层应专注于重建当前观测的残差（而非完整观测），高层通过残差调制（residual modulation）丰富低层的视觉预见能力。这借鉴了预测处理（Predictive Processing）理论：每层只需解释下层未能解释的残差信号，形成自底向上的残差传递和自顶向下的预测补充。

## Motivation
现有 Dreamer 系列（DreamerV3 等）使用单层 RSSM，表达能力受限。简单堆叠多层 RSSM 会导致梯度问题和层间冗余。需要一种有原则的层次化扩展方式，使多层 RSSM 各司其职、协同工作。

## Method
1. **Hierarchical Recurrent State-Space Model (HRSSM)**: 多层 RSSM 堆叠，每层处理不同抽象级别
2. **Predictive Processing Blocks (PPBs)**: 
   - 自底向上：低层残差观测 = normalize(raw - reconstructed)，向上传递未解释的残差
   - 自顶向下：高层将残差信息注入低层作为 imaginary hint，enriches 低层的视觉预测
3. **Residual Modulation**: 高层解码的残差与低层重建相加，逐层精化最终观测重建
4. **规模设计**: 50-200M 参数范围，2层结构

## Experiment
Minecraft 环境验证（DIAMOND benchmark）：
- 100M×2 变体是唯一能解决 Shulker 战斗任务的模型
- 在多个 Minecraft 任务上超越 DreamerV3、DIAMOND 等基线
- 消融实验：去除层次结构或残差连接均导致显著性能下降，证明两者缺一不可
- 层次结构使不同层学到不同抽象级别的表示

## Value
对 Dreamer 系列的有意义扩展，Predictive Processing 的引入为层次化世界模型提供了理论基础。残差连接的设计简洁有效，消融实验充分。ICML 2026 接收。局限在于仅在 Minecraft 环境验证，环境复杂度有限；是否能扩展到更复杂的视觉环境有待验证。对隐式世界模型（Dreamer 家族）研究有直接参考价值。
