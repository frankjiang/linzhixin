# QuantWM: Temporally Consistent 2-Bit KV Cache Quantization for World Models and Video Generation

## Insight
观察：2 比特量化的 Key 重建误差小于 Value，却更破坏视频画质；VBench 近乎不变时仍出现闪烁。推论是应控制 Query 与 Key 误差的内积，而非仅减小 Key 的均方误差，因为微小扰动会改写时空 token 的注意力排序。K/V 单独量化、输出误差和 top-1 token 漂移实验支持该解释。

## Motivation
自回归视频及交互世界模型随时空 token 积累巨量 KV 缓存；已有 QVG 可压至 2 比特，但其“近乎无损”VBench 分数漏掉局部闪烁和模糊。长视频部署需要兼顾缓存压缩与注意力选择的稳定性。

## Method
沿用 QVG 的 BF16 质心加 INT2 残差框架。QSAC 根据历史 Query 二阶矩的对角线筛出 4 个候选质心，再按残差组动态范围与通道敏感度选最终质心；PSAC 将剩余 Key 误差投影到历史 Query 的前 8 个主方向，用 INT8 系数补偿注意力 logits。首块以均匀权重启动且关闭 PSAC，此后只用历史统计，保持因果性。已完成的缓存块真实打包存储，读取时 Triton 融合解码成临时 BF16 K/V，继续用原生 attention，并非直接 INT2 attention。

## Experiment
- 五个自回归视频/世界模型，480p、720p、93 帧及一分钟生成；对照 BF16、QVG、KIVI，报告相对 BF16 的 PSNR/SSIM/LPIPS、VBench、注意力 top-1 漂移、缓存和延迟。
- 480p LongCat 的 PSNR 从 QVG 的 20.683 升至 25.508，LPIPS 从 0.0784 降至 0.0332；HY-World 的 top-1 漂移从 61.36% 降至 13.92%。消融显示 QSAC、PSAC 各自有效，联用最好；附录检验秩、候选数和二阶矩近似。
- 最多压缩 KV 缓存 6.20 倍；LingBot/HY-World 端到端生成延迟增加约 5%–6%，LongCat 因减少缓存卸载传输下降 17.78%。一分钟实验主要用 VBench，HY-World 均值 0.5949→0.6627（QVG→本方法）。

## Value
把缓存压缩目标从张量重建转向下游注意力保持，对长上下文视频世界模型部署有直接价值；指标显示的是相对 BF16 生成结果的保真度，不能视为物理预测准确率。

## Strengths
故障诊断、机制推导与两模块消融相互印证；无需训练，测试多个世界模型；提供真实打包、因果冷启动及延迟数据。

## Weaknesses
未检验交互动作响应或长期物理一致性；一分钟测试主要依赖文中承认不敏感的 VBench。历史 Query 子空间在强分布变化时可能失效；6.20 倍是持久 KV 缓存压缩率，attention 前仍生成临时 BF16 张量，不等同整机峰值显存缩减。

## Future Work
作者未列明确后续路线；可进一步测量长时查询分布漂移及量化对闭环交互的影响，这是笔记建议。

## Rating
创新度评分：3/5 - 对既有残差量化加入查询敏感选心与低秩误差补偿，改进明确但属量化机制增量。

## TL;DR
按历史查询敏感度量化并补偿关键误差，降低两比特缓存引发的视频闪烁；世界模型部署方向值得精读。
