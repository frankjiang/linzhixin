# PAWBench: How Far Are We from Probabilistically Aligned World Modeling?

## Insight

有。论文的 observation 是：单条视频的物理合理性、生成多样性甚至指定结果的可控性，都不能推出模型在同一初始观测与动作下给出了正确的未来分布。由此区分 support alignment（有效结果是否都可采到）与 probability-mass alignment（概率比例是否正确），并把视频生成器视为重复采样的 stochastic world model。作者通过11个模型、50个场景证明两类指标明显分离；匹配参考分布的 Monte Carlo null 平均 TVD 仅8.33、99%低于9.22，而模型平均31.2，说明差距不能主要归因于50次有限采样。进一步的因果/非因果干预显示模型对真实物理改变反应不足，却会被无因果文字线索带偏。

## Motivation

现有视频/世界模型 benchmark 多逐条评视觉质量、时序一致、prompt遵循或物理违规，无法发现“每条都像真的，但重复采样只落在少数模式或比例错误”。规划需要知道后果集合及其概率，而不只是拿到一个漂亮 rollout。相邻工作 CaliBench 也做随机物理校准，但只有9类场景；PAWBench 扩展为 calibration/coverage 双轨、50场景，并加入可读性门控、因果控制和 prompt/noise/training 三层干预。问题直接击中随机视频世界模型评测缺口。

## Method

令视频模型给出轨迹分布 `P_M(tau|x,a)`，用场景 rubric 将终态映射为有限结果 `g(tau)=y`，诱导出 `p_M(y|x,a)`。若有可由对称性、组合计数或可见物理状态推导的参考分布 `q`，PAW-Calibration 要求概率质量匹配；若只能列举合法结果集合 `Y`，PAW-Coverage 只检验支持集恢复。

基准含50个人工审核场景、八类机制：Calibration 的 tossing/rotation/routing/draw 与 Coverage 的 collision/stability/agent/material，各25个。每个模型对固定 source image 和原子 action prompt 独立生成 `K=50` 次。PAWEval 用冻结的 Gemini 3.5 Flash 场景 rubric 输出合法终态或 readout failure；至少20/50条可读且落入 schema 才计该场景，SPR 报通过场景比例。通过场景上，Calibration 用 conditional TVD，Coverage 用观测到的合法 outcome 比例。动作完成、物体连续和物理过程另做 trustworthiness audit，不改变主分数。

稳健性检查包括 `K=1...100` 的预算曲线、按每个模型实际可读样本数匹配的50,000次 Monte Carlo null，以及1,500条视频、每条7人标注的 PAWEval 对齐研究。作者还做三类干预：VLM/普通与 Oracle prompt engineering；保持单样本高斯边缘但让50个初始噪声负相关的 C2C；在200条铅笔视频池上用不同左右倒比例构造2,000样本数据，训练5个 rank-32 Wan2.2 LoRA。

## Experiment

主实验覆盖11个当前视频生成器。Calibration 中 Cosmos 3 Super I2V 的 TVD 最低20.5但 SPR 仅80%；Seedance 2 的 SPR 100%但 TVD 30.5。Coverage 中 LTX-2.3 最高71.7%但 SPR 72%；LingBot-Video-MoE 的 SPR 100%但 coverage 58.8%。没有模型同时做到低TVD、高coverage和全场景可靠。增加 rollout 主要提高 coverage，TVD基本不降；严格 `n_readout>=30` 时模型平均TVD31.8、null均值6.67/q99 7.44，结论保持，Monte Carlo `p=2e-5`。

人评中，双方都有明确标签的888/1500条视频上，PAWEval 与人类众数一致722条（81.3%）；人类仅3–4票一致时准确率58.7%，6–7票时91.7%。VLM直接采未来也失准，最佳 Calibration TVD 34.8、最佳 Coverage 46.6%。普通 prompt engineering 对四个生成器全部恶化 conditional TVD；Oracle 指定结果能改善TVD与coverage，但目标命中率仍只有37.6%–58.1%。C2C 对三模型均提高条件coverage并降低平均TVD，但 SPR 不稳定，只说明有限 gallery 探索更广。LoRA 中增加左倒训练比例会让直立和左倾铅笔都更常左倒，没有一个模型同时匹配前者50/50与后者100/0，说明学到的是全局频率偏置而非按物理状态调整的分布。

## Value

这项工作的价值在于把“世界模型是否随机”推进到“随机性是否校准”：今后视频 WM 应固定观测/动作做重复 rollout，同时报告结果支持、概率质量和不可读率；只展示最佳样本、FVD或单次物理打分是不够的。对规划尤其重要，因为 mode collapse 会漏掉风险，错误概率会扭曲期望回报。PAWBench 也提示 prompt steering、diverse noise 与 distribution learning 是三件不同的事。下一步需要把终态类别扩展到轨迹、状态和风险，并让评测动作真正对应可执行控制。

## Strengths

问题定义简洁且具有普适性；Calibration 与 Coverage 分开避免把多样性误当校准；固定输入、预先冻结 outcome set/q/rubric，降低看结果后调标准的风险。模型规模、场景类型和干预层次较全面；SPR、有限样本 null、人类审计、因果/非因果配对与失败案例共同构成较扎实的证据链。论文不把 C2C 的 gallery 增益误称为改变单样本分布，也明确限制人评结论只适用于可比较子集。

## Weaknesses

最根本的识别问题是 `x` 为单张图、`a` 为粗粒度语言动作；如“弹一次硬币”没有规定力、角度和微观初态。所谓50/50参考实际隐含了一个未定义的动作/隐藏状态分布，而经典动力学在完整状态和精确动作下近乎确定，因此指标可能测“是否复现人类约定俗成的随机先验”，不完全是真实条件转移概率。主TVD/coverage只统计可读且合法的终态；即使 spinner 以物理不连续方式落到蓝色仍计蓝色，动作缺失、身份断裂和物理违规只进旁路 audit，模型可在动力学错误时取得良好概率分数。按通过场景和有效样本做条件平均也有选择偏差，必须与SPR并读，无法形成稳健单排名。

人评的81.3%只覆盖888/1500条且仅29/50个场景，低共识样本一致率接近随机上方，不能验证所有主标签；因果控制主要靠分布条形图，缺少跨配对的效应量/检验。50个人工合成、短时、终态离散场景与长时交互式具身决策仍相距很远；LoRA因果结论只来自两个铅笔场景。大量闭源模型采用默认配置，算力成本高且版本漂移会限制复现。

## Future Work

作者明确提出从终态 label 扩展到更丰富的状态轨迹和中间物理过程；研究更高效、可靠的重复 rollout 估计器；扩展到长时、交互和具身环境；设计直接学习校准未来分布的训练目标。还应显式定义低层动作与隐藏状态测度，把物理可信度纳入联合分布而非旁路审计，并评估概率误差对规划、风险敏感控制和探索的实际影响。

## Rating

创新度评分：3/5 - 将重复视频rollout系统化为概率质量与支持集双评测并配套稳健性实验，贡献扎实；但概念有相邻工作，且终态条件指标存在重要识别边界。
相关度评分：3/3 (Core) - 直接评估随机视频世界模型的多未来分布、物理状态敏感性与采样/训练偏差。

## TL;DR

用重复视频rollout的TVD与支持覆盖检验概率对齐，揭示主流模型分布失真，评测思路值得精读。
