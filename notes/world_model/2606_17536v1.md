# OmniDrive: An LLM-Choreographed Multi-Agent World Model with Unified Latent Co-Compression for Multi-View Driving Video Generation

## Insight
论文观察到驾驶视频世界模型的两个失败源：多模态控制（语言、HD map、轨迹、相机）表示空间不统一；多相机视频通常先各自编码再后融合，导致缺少全局 3D 几何。推论是需要把语言、几何 layout、像素 latents 绑定到同一 position-aware token grid。

## Motivation
面向自动驾驶闭环仿真和合成数据生成，解决多视角一致性、控制注入和下游检测效用问题。同行多用 ControlNet/cross-attention 分支或 per-camera VAE + cross-view attention，容易出现跨视角 drift 和物体 teleportation。该问题与 3D/视频世界模型高度相关。

## Method
OmniDrive 使用三个 Qwen2.5-VL agent：Architect 将用户意图解析为 WorldScript JSON，Cartographer 生成空间锚定 layout tokens，Auditor 在训练时提供 cross-view critique tokens。核心 Latent Co-Compression 用 view-time permutation 将 N 个相机 × T 帧展平成 pseudo-temporal stream，让 RGB 和 sparse layouts 共同通过 3D VAE 编码；view-block-aware padding 防止卷积核跨相机边界混叠。MM-DiT 接收 visual/geometric/semantic/temporal/review tokens，用 rectified-flow ODE 生成。

## Experiment
nuScenes 上报告 FVD 45.7、BEV mAP 21.6，并在 multi-view consistency 和 downstream synthetic-data utility 上优于多种 baseline。仅用合成数据训练 detector 在真实验证集 NDS 提升 +2.4。附录给出 per-camera breakdown、天气/场景分层、human study、photometric correction 和 VBP 消融。VBP 可修复 view-boundary ghosting；跨视角一致性在人评中明显占优。

## Value
对用户的 3D/视频世界模型方向有直接价值：早期跨视角 co-compression 比后融合更契合几何一致性，LLM agent 可作为结构化场景条件接口。但方法偏驾驶生成系统，依赖 prompt/script/layout 管线，尚未形成可交互动作闭环。

## Strengths
