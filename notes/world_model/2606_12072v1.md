# World Model Self-Distillation: Training World Models to Solve General Tasks

## Insight
核心 observation：预训练视频生成器在详细 execution description 下能生成任务执行视频，但短 instruction + 初始图像接口难以直接规划。推论是可以让“Demonstrator”在详细描述条件下产生轨迹，再蒸馏给只看短指令的“Executor”，并用 VLM 反馈做 RL。理论上给出 on-policy teacher-student velocity matching 控制 terminal distribution drift 的 Gronwall 型界。

## Motivation
现有视频世界模型需要详细文本描述、外部 VLM 规划，或昂贵的 task-video supervision。论文想把 caption-guided generation 的执行知识转成 instruction-conditioned task solving，不依赖人工 task-execution 视频。问题重要，因为它面向视频世界模型从被动生成到可执行任务求解的过渡。

## Method
基于 conditional flow-matching video generator。Demonstrator 条件为初始图像 I + detailed solution D，Executor 条件为 I + short task T。VLM 从未标注图像生成 T,D。训练包括 on-policy self-distillation：在 student rollout states 上匹配 teacher velocity；把 teacher-student discrepancy 作为 distillation reward；再加 VLM task reward 和 consistency reward，用 AWM/GRPO 类 policy gradient 优化；anchor loss 防止 student drift。最终目标 L_RL + beta_d L_anchor。

## Experiment
构造 WorldTasks：约 20k 图像、146k task prompts；WorldTasks-Bench 200 image-task pairs，VLM 评估 task completion、agent correctness、physical consistency。On-policy distillation 优于 off-policy，加入 RL 后 student 可在 VLM-based benchmark 上超过 Demonstrator。表 1 中 LTX-2 8-step + WMSD Avg 0.726，高于 LTX-2 0.455 和 +VLM 0.598；HY1.5 +WMSD 也从 0.597 到 0.673。DreamGen robotics benchmark 上，WMSD 不用 task-specific supervision，Object 70、Behavior 57.4、Environment 58.6，接近/超过部分 SFT 模型。消融显示 beta_d 约 0.01 最好，consistency reward 可缓解 reward hacking。

## Value
对“视频生成世界模型如何变成 task-solving model”很有价值，特别是 teacher detailed-solution 到 executor short-instruction 的接口蒸馏。局限是评价强依赖 VLM reward，可能与真实物理成功不一致；机器人迁移仍缺具体平台动态，作者也承认 data-free setting 无法恢复 robot-specific dynamics。

## Strengths
亮点是对“视频生成世界模型如何变成 task-solving model”很有价值，特别是 teacher detailed-solution 到 executor short-instruction 的接口蒸馏。

## Weaknesses
不足是评价强依赖 VLM reward，可能与真实物理成功不一致；
