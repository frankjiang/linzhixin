# ReflectiChain: Epistemic Grounding in LLM-Driven World Models for Supply Chain Resilience

## Insight
无显著 insight 可迁移至视觉/3D world model 领域。论文核心观察是 LLM 理解自然语言策略但缺乏物理可行性验证，而 RL 优化物理流但对语义约束"盲目"——两者存在 epistemic gap。解决方案是将供应链网络编码为 6 维图隐空间，通过 MPNN+Attention 做 encoder、学习转移动力学、双头解码，再用 Double-Loop（KL trust region + LoRA）在测试时做策略适配。思路类似 model-based RL 中 learned dynamics + constrained planning 的经典范式，但针对的是供应链图结构而非视觉/物理环境。

## Motivation
供应链 AI agent 需同时理解自然语言政策约束（如 CHIPS 法案）和物理网络可行性。LLM 会提出语义合理但物理不可行的动作（grounding gap），RL 则对语义约束盲目。现有 verbal reflection 方法（ReAct/Reflexion）仅做文本层面反思，无法真正验证物理约束。这是供应链领域的关键问题，但与视觉/3D world model 无关。

## Method
- **SC-WM (Supply Chain World Model)**：MPNN + multi-head attention 将 10 节点 4 层供应链图编码为 6 维隐向量 $z_t$；学习 transition dynamics $T_\omega$（GELU + 残差）；双头解码器预测 reward 和 state delta。$H=5$ 步 rollout。
- **Double-Loop Learning**：(1) Reflection-in-Action：用 $C_{rule}$ 约束检查候选动作的物理可行性（质量守恒、容量、边存在性）；(2) Reflection-on-Action：KL trust region 约束的策略梯度 + LoRA 更新，$K=3$ 步。
- **Epistemic Mechanisms**：不确定性分离（KL trust region 处理认知不确定性 vs. 随机 rollout 处理偶然不确定性）、知识边界检测（所有候选得分为零时触发探索）、经验贝叶斯策略更新。
- 创新程度一般，是 model-based RL + constrained planning + LLM reflection 的工程组合，针对供应链场景做了定制。

## Experiment
- **环境**：Semi-Sim，10 节点半导体供应链，合成数据（3000 轨迹，2000 扰动场景，520MB）。
- **基线**：PPO、NoThinking、ReAct、ReflAct、LLM+TreeSearch，跨 4 个 LLM 骨干（DeepSeek-V3.2, Qwen2.5-7B, InternLM2.5-7B, GPT-4o-mini）。
- **指标**：RCS（Rationale Consistency Score, DeBERTa-NLI）、CCR（约束合规率）、TI（紧张指数）、TS（吞吐量得分）。
- **结果**：ReflectiChain RCS 88.5-93.1%，比最佳基线 +33.0%（$p<0.0001$, $d=2.78$）。消融显示 SC-WM 移除导致 CEE -49%，KL trust 移除导致方差 +81%。在对抗压力下展示反脆弱行为（$\rho \in [0.3, 0.5]$ 时 CEE +40.2%）。
- 实验仅在合成环境进行，无真实数据验证。

## Value
工作本身对供应链领域有应用价值，但对视觉/3D/隐式 world model 研究几乎无启发。"epistemic grounding"（语义理解与物理验证的对齐）的概念在 embodied AI 中有类似讨论，但本文的具体方法（图编码、约束检查、KL trust region LoRA）均为供应链定制，不具有迁移性。来自华中科技大学外语学院（非 CS 背景），发表于 EIML@ICML 2026 workshop。
