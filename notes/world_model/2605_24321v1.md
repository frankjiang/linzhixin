# Unified 3D Scene Understanding Through Physical World Modeling

## Insight
核心观察：将3D场景理解中的多个任务（NVS、物体操作、深度估计）建模为同一个概率图模型（PGM）上的不同推理路径，是一种比为每个任务单独训练模型更高效且更鲁棒的范式。关键设计洞察有二：(1) 光流可以作为统一的中间控制表面——NVS通过相机诱导的光流条件化、物体操作通过物体特定光流条件化、深度估计通过预测相机运动诱导的光流再反转——所有任务复用同一个RGB→Flow→RGB的因果链；(2) pointer-value的序列化方式打破了自回归模型的光栅扫描偏置，使得同一个GPT式transformer可以在PGM的任意节点上做条件预测，实现了"解码顺序即任务定义"的灵活性。

## Motivation
问题：3D场景理解包含深度估计、NVS、物体操作三大核心任务，现有方法各自独立训练在特定数据集上，存在三个层面的割裂：(i) 表征层面——各任务不共享表征，知识无法迁移；(ii) 控制层面——扩散模型在3D任务中难以实现精确的几何控制（ControlNet等方法的输出常偏离目标规格）；(iii) 泛化层面——窄域finetune导致真实场景鲁棒性差。需要一个统一框架兼顾灵活性和可控性。

## Method
**整体框架（3WM）**：将视觉数据建模为PGM Ψ，节点包括局部视觉变量（RGB patch、光流patch）和全局控制变量（相机位姿）。用一个7B自回归transformer学习该PGM的条件分布。

**三个关键技术**：
1. **Hierarchical Local Quantizer (HLQ)**：感受野严格局限于单patch的卷积自编码器，每个patch编码为4个由粗到细的离散码。严格局部性保证了patch级的条件独立性，使局部mask/重写/采样操作可预测
2. **Local Random Access Sequence (LRAS)**：将patch数据序列化为pointer-value交替序列 (p₀,v₀,p₁,v₁,...)，pointer是时空patch索引，value是码本编码。训练时随机打乱顺序，消除光栅扫描偏置。推理时通过选择哪些pointer作为条件、哪些pointer作为预测目标来定义任务
3. **光流作为控制表面**：序列因果顺序为 [RGB₀, C] → Flow → RGB₁。光流既可作为输入条件（NVS/物体操作），也可作为预测目标（深度估计）

**推理路径（零样本，无需finetune）**：
- **NVS**：用外部深度模型估计深度→反投影为点云→施加相机变换→重投影得光流→条件化3WM生成新视角
- **3D物体操作**：为目标物体生成3D变换对应的光流（背景flow=0）→条件化生成
- **深度估计**：给定RGB和向下平移的相机→预测光流→光流大小的倒数即为视差/深度
- **稀疏-密集光流补全**：给定稀疏flow种子→补全为密集flow→再用于RGB生成

## Experiment
**NVS（Table 1）**：在WildRGB-D和DL3DV两个OOD benchmark上全面超越MotionCtrl/ZeroNVS/ViewCrafter/SEVA。WildRGB-D: PSNR 18.02 (+2.92 vs SEVA), LPIPS 0.185；DL3DV: PSNR 19.02, LPIPS 0.252。SEVA benchmark五个数据集上也全面领先。定性上3WM保持物体和场景一致性，而baseline或扭曲物体（MotionCtrl）、或模糊（ZeroNVS）、或改变外观（ViewCrafter）

**3D物体操作（Table 2）**：在自建的3DEditBench（100对真实图像）上，PSNR 22.73, LPIPS 0.133, Edit Adherence 0.797，全面超越DiffusionHandles/LightningDrag/DragAnything。EA指标（衡量物体边界对齐度）优势尤其明显，说明几何变换精度高

**自监督深度估计（Table 3）**：从未用过深度标签训练。在NYUDv2/BONN/TUM三个数据集上大幅超越SC-DepthV2/IndoorDepth/MotionCtrl/SEVA。NYUDv2: AbsRel 0.078 (vs 次优0.116), δ₁ 0.940；动态场景（BONN/TUM含运动人体）优势更大，因为模型从无约束视频的光流中学习深度线索，不受静态几何假设限制

**涌现几何推理（Figure 6）**：(a) 组合物体操作+NVS：先移走障碍物再导航；(b) 复杂自我中心导航：多步相机运动探索走廊；(c) Amodal补全：逐个移除附着物体揭示被遮挡几何；(d) 深度不确定性：对透明/反射物体生成多个合理的深度解释

## Value
**工作价值**：这是一篇ICLR 2026论文，提出了将3D理解统一为PGM推理的优雅框架。核心贡献不在于单个任务的SOTA，而在于证明了一个统一模型可以零样本完成NVS、物体操作、深度估计，且都优于各领域专用模型。PGM+LRAS的形式化为自回归世界模型提供了一种有原理保证的多任务推理机制。

**对研究方向的启发**：
1. "解码顺序即任务"的思想与隐式世界模型（JEPA）中"不同探针对应不同下游任务"的思路有结构性对应，但3WM通过显式的PGM图结构使这种灵活性更可控
2. 光流作为中间表征的选择值得关注——它同时编码了运动和几何信息，比直接预测RGB或深度更适合作为世界模型的"动作空间"
3. 严格局部量化（HLQ）保证patch独立性的设计思路，对视频世界模型的token化方案有参考价值
4. 当前局限：仅处理图像对（两帧），非真正的视频序列建模；依赖外部深度模型和SAM进行NVS/物体操作的flow计算；7B规模的自回归模型推理速度可能受限

TL;DR：将NVS/物体操作/深度估计统一为概率图模型上的不同推理路径，用pointer-value随机序列化训练7B自回归transformer实现零样本多任务SOTA；建议精读Method部分的PGM形式化和LRAS设计。
