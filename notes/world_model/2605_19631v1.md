# HEAT: Heterogeneous End-to-End Autonomous Driving via Trajectory-Guided World Models

## Insight
观察到跨域联合训练时，不同域的分布差异引入冲突学习信号，驱动模型趋向次优折中方案。轨迹级组织训练可以捕捉域不变的驾驶意图表征。

## Motivation
端到端自动驾驶在单域数据上表现好，但跨异构域（不同城市、传感器、交通模式）联合训练时性能显著下降。实际部署需要单一模型适配多域。

## Method
三阶段流程：(1) 轨迹驱动学习——围绕规划轨迹组织训练，轨迹聚类 + 对比学习学习域不变表征；(2) 世界模型——预测条件于 ego 动作的未来潜特征，改善特征一致性并缓解域偏差；(3) 情景记忆模块——存储和检索多域经验。世界模型在此作为辅助正则化器。

## Experiment
nuScenes、NAVSIM、Waymo 三个基准上显著超越现有方法。单一统一模型在各域内保持强性能。消融验证了轨迹引导、世界模型和情景记忆的贡献。

## Value
将世界模型作为多域端到端驾驶的辅助模块，用于特征一致性正则化。思路实用但世界模型非核心贡献。对自动驾驶的多域泛化问题有参考价值。
