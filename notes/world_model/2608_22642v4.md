# Mol-JEPA: A multimodal Joint Embedding Predictive Architecture for Molecules

## Insight

观察是：分子性质存在 activity cliff，删原子/键等增强未必保持语义；只看结构又无法表达细胞、靶点和 ADMET 环境。论文据此推论，与其构造“同一分子”的可疑增强，不如随机遮掉整种模态，用其余生化/物理模态预测被遮模态的 latent，并用各向同性正则防坍缩。全模态相对 graph+ECFP 将 probe MAE 降低 13%–14%，实验模态改作直接监督也更差，支持跨模态 latent prediction 的价值；但这证明的是静态分子表征收益，不是时序世界动力学。

## Motivation

既有 molecular SSL 常依赖化学上无效的 graph augmentation、对负样本敏感的 contrastive learning，或只建模结构；多模态融合又可能忽略稀疏模态。Mol-JEPA 希望在数据稀缺的药物发现中吸收结构、量化化学、细胞表型、结合与 ADMET 信息。问题对分子性质预测重要，但把静态跨模态补全称为“world model”较宽泛，与视频/3D/动作条件世界建模仅有架构层面的间接联系。

## Method

- 汇总 ChEMBL、TDC、PCBA-1328、∇²DFT 与 Enamine REAL，去重后得到 466 万分子；构造 UMA、ChemGPT、CLOOME、BioXMol、Boltz-2、GNN、MOE、ECFP、xTB、DFT 及三类实验向量，共 14 模态，允许部分配对和缺失。
- atom/graph/vector encoder 把不同输入投到 512 维；按 masking ratio 0.3 遮盖可用模态，Transformer 以其余 token 预测目标 embedding，并以 CLS 作为全局读出。
- 目标是各模态 latent MSE 加 SIGReg（\(\lambda=0.7\)）；SIGReg 用 1,024 个随机投影约束 target embedding 接近各向同性高斯。对 predicted embedding 加正则会坍缩，对 target 加正则最稳定。
- 最终模型约 50M 参数。下游比较 CLS+线性/非线性/TabICLv2、按模态 token 的两层 Transformer，以及 rank-16 LoRA；“Best”结果会按数据集从多种 probe/embedding 方案中取优。

## Experiment

- 评测 9 个 ExpansionRx、7 个 ASAP/Polaris、PXR 和 6 个 Biogen ADME endpoint；用 ECFP4 Tanimoto=0.65 的 Butina cluster 构造 3 个 split，并另报官方 temporal/blind split。baseline 包括 RF、LightGBM、TabICLv2、Chemprop、CheMeleon 和 CLAMP，均在训练集内做五折调参。
- 三个 cluster split 的平均 MAE：Mol-JEPA Best 0.402、固定 Transformer probe 0.427，优于 CLAMP 0.576、CheMeleon 0.471、Chemprop 0.519、TabICLv2 0.453、RF 0.559、LGBM 0.468；平均截断后 \(R^2\) 为 0.42，次优为 Transformer 0.38、TabICLv2 0.37。
- paired Wilcoxon+FDR 的胜率中 Mol-JEPA 为 38%，低于 TabICLv2+AlvaDesc 的 47%；后者优势集中在较大的 ExpansionRx，而 Mol-JEPA 在小型 ASAP/Biogen 上更强。官方 temporal split 上 TabICLv2 的 MAE/Wilcoxon 胜率也更高，Mol-JEPA 只在 \(R^2\) 胜率领先。
- 100k 子集消融：JEPA 的线性/非线性 probe MAE 为 0.436/0.393，直接 semi-supervised 标签预测为 0.467/0.417，去掉实验模态为 0.449/0.407；512 维明显优于 256，增至 1024 无收益；projection head 会恶化结果。全量数据上全模态相对 graph+ECFP 降低 MAE 14%/13%。
- 模态数从 2/4/8 增加时，单 GPU、100k 分子、300 epoch 的耗时约 9/13/27 小时且平均效果上升；graph、MOE、ECFP 最重要，CLOOME 等个别模态可能伤害结果。完整训练用 12 张 RTX-6000 Ada、约 3 天，在 150 epoch 后开始过拟合。

## Value

对目标方向的启发在于：当自然增强不保语义时，可把异质传感/属性源当作 mask unit，用 latent completion 学共享表征；SIGReg-on-target 和稀疏模态训练现象也可迁移参考。但论文没有动作、时间、rollout、规划或物理状态演化，不能用其结果判断 JEPA 世界模型是否学到可预测世界动态。

## Strengths

- 数据规模大、模态类型广，并覆盖结构、表型、实验测量和量化计算，而非仅拼接同一分子的多种编码。
- 使用较新的盲测/工业 ADME benchmark、cluster/temporal split、经典与 foundation baseline，并报告显著性和 OOD 距离分析。
- 消融覆盖实验模态、正则位置、投影头、维度、数据/模态规模和表征相似性；代码与 checkpoint 声称公开。

## Weaknesses

- “世界模型”缺少时序转移与行动条件，实质是静态多模态 representation learner；生化相关性也不等于因果环境模型。
- 主表的 Mol-JEPA Best 按任务从多种下游方案取优，而多数 baseline 展示固定方案，可能放大平均优势；固定 Transformer 的收益明显较小。
- 公开 temporal split 上并未全面胜过 TabICLv2，Wilcoxon 胜率也落后；对 OOD 的论证主要是按相似度分箱的相关趋势，并非真正新分布干预。
- 大部分架构/模态消融只在 100k 子集进行；稀疏、维度和噪声差异使单模态贡献仍难解释，作者也观察到某些模态反而有害。
- 多个输入来自冻结 foundation model 与昂贵/商业工具，预计算成本高；预训练源、上游模型训练数据与下游 benchmark 的潜在重叠缺少系统审计。

## Future Work

作者建议显式建模“哪些模态可由哪些模态恢复”，设计依赖感知的 masking；扩展预训练化学空间并检验更强 OOD；系统研究稀疏度、维度、信息量与冗余对训练的作用，自动选择有效模态，并把框架扩展到材料、生物等科学领域。

## Rating

创新度评分：3/5 - 将多达 14 种稀疏分子模态纳入 JEPA 并配合 SIGReg，属有实证价值的新场景组合，但没有提出新的预测范式。
相关度评分：1/3 (Tangential) - 使用 JEPA latent prediction，可借鉴遮盖和防坍缩设计，但研究静态分子性质而非视频、3D 或动作条件世界动态。

## TL;DR

用整模态遮盖训练分子 JEPA，表征效果强但没有世界动力学；仅作方法旁证，可选读。
