# AppDeltaWorld: Transition-Grounded Delta Code World Model for Mobile GUI Agents

## Insight
移动 GUI 的下一帧并非任意图像生成问题：动作先把界面带到一个语义上可达的页面状态，再由当前页面与目标状态之间的“代码增量”决定具体外观。由此，作者把 app 内历史转移图当作硬约束，先预测并检索可达的 HTML 结构，再生成增量代码、局部补图并渲染；消融中去掉检索使总体分数从 73.51 降至 67.46，支持“转移约束比无条件视觉生成更能保证功能一致性”的判断。

## Motivation
真实手机交互轨迹采集昂贵且涉及隐私，直接用图像模型模拟界面又容易产生不可点击、状态跳变或文字失真的页面。已有代码式 GUI 世界模型虽可执行，但从零生成完整页面不稳定；纯图像模型视觉自然，却缺乏明确的控件结构。论文要构造一个可闭环滚动、能生成代理训练数据的 GUI 世界模型，这是移动代理的重要数据瓶颈，但不属于视频、3D 或物理隐式世界模型的核心问题。

## Method
当前截图先被解析为功能模板、页面描述、区域布局、槽位模式和页面类型。离线记忆库以 app、页面结构和转移关系组织 Level-1 HTML；动作按类型与量化位置索引，在源页面簇的可达后继中预测下一语义状态并检索结构参考。生成器再结合当前截图、动作、下一状态文本和参考 HTML，输出包含具体内容的 Level-2 增量代码；图像槽位由扩散模型补齐，浏览器负责最终渲染。生成页面回送给动作策略形成闭环轨迹，经解析、空白页、重复动作和主动终止等规则过滤后用于 SFT；另探索以多个想象后继的一致性作为测试时强化学习奖励。核心新意是“转移图约束的分层代码检索 + 代码/扩散混合渲染”，但其能力高度依赖已有 app 的真实结构和转移记忆。

## Experiment
世界模型用 100,149 条转移训练，其中 CMGUI 占 95.47%；在 500 条 CMGUIBench 样本上，以 Gemini-3-Flash 判断功能逻辑，结合元素/布局分数及 SigLIP、DINOv2 评估视觉质量。AppDeltaWorld 总分 73.51，高于 GPT-Image-2 的 72.34 和 Code2World-8B 的 56.64；不过作者人工检查也指出 GPT-Image-2 的元素对齐更好。去掉扩散、RAG、二者后总分分别为 70.91、67.46、65.68。用 33,133 条合成轨迹训练的 AppDeltaAgent-8B 在 AndroidLens 上低层/高层 AMS 达 90.28/82.53、ATP 达 46.63/33.05，均明显高于 Qwen3-VL-8B 基座；MobileGym 成功率由 10.2% 升至 14.1%，MobileWorld 的 GUI-only 成功率由 9.4% 升至 14.9%。合成数据约 12K 条时已取得最终增益的 75%，20K 后趋于饱和；但仅用 AppDelta 数据训练会比基座低约 1.2 ATP，混入真实数据才有效。测试时想象在四个 app 上带来 1.51--5.06 AMS 增益，但八路后继中只有 3.295 路平均支持多数簇，23.5% 样本没有唯一赢家，暴露了模型不确定性。

## Value
论文展示了 GUI 世界模型不必追求自由生成，而可利用可达状态、DOM 结构和浏览器执行器获得更可靠的合成监督；“先约束状态、再生成观测”对结构化环境有启发。不过这更接近带检索的 app 模拟器，不能证明一般化的视觉动力学学习，对目标研究方向直接价值很低。后续关键是减少对真实 app 转移图的依赖，并验证跨 app、长时序及真实可交互性。

## Strengths
- 把语义可达性、代码结构与视觉补全分开处理，工程管线完整且可执行。
- 同时报告世界模型保真度、静态动作预测和在线任务执行，并给出 RAG/扩散消融与数据规模曲线。
- 诚实披露长期滚动退化、数据过滤通过率仅约 10%，以及一致性奖励的不稳定性。

## Weaknesses
- 训练数据几乎由 CMGUI 主导，评测又来自同一基准的随机子集，未充分证明跨 app、跨分布泛化或排除结构记忆效应。
- 世界模型依赖 app 专属转移索引和已见 HTML，核心状态变化主要由外部记忆提供，不是从交互中学得的通用动力学。
- 功能分数依赖单一大模型裁判，视觉相似度也不能保证控件坐标、事件绑定和真实业务逻辑正确。
- 合成数据的下游增益与真实数据混合、过滤规则共同作用，难以独立归因；闭环成功率仍低，长轨迹画质和任务进度会快速劣化。

## Future Work
作者未给出独立的未来工作清单，但实验明确指向：提升长链路状态与视觉保真度、改进任务进度判断和轨迹通过率、让一致性奖励在无唯一多数后继时更稳健，并降低对上游 app 数据分布和检索库覆盖率的依赖。

## Rating
创新度评分：3/5 - 转移约束的分层 HTML 检索与混合渲染组合有明确方法贡献，但通用性受 app 专属记忆限制。
相关度评分：0/3 (Noise) - 研究对象是移动 GUI 与代理数据生成，并非视频、3D 或 JEPA/Dreamer 类世界模型。

## TL;DR
以动作可达约束检索 HTML 并混合渲染 GUI，能辅助移动代理训练，但与目标方向无关，可跳过。
