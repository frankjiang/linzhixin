# Prisma-World: Camera-Controllable Multi-Agent Video World Model

## Insight
核心观察：多智能体视频生成不等于对单智能体模型的简单重复调用。独立采样各智能体会导致共享场景区域的外观、布局不一致；简单拼接又无法区分智能体身份与时间同步关系。由此推论：需要将多智能体视频生成建模为一个联合几何感知去噪过程，让所有视角在同一 full-attention 序列中共同生成，从而自然产生跨视图一致性。

## Motivation
- **问题**：现有视频世界模型几乎全部面向单智能体/单视角设计，无法同时生成多个智能体对同一共享场景的观测视频，跨视图一致性无法保证。
- **同行做法**：Solaris、MultiWorld 等并发工作局限于特定游戏场景（Minecraft），无法利用相机参数，且智能体数量固定、泛化性差。
- **是否关键**：是。多智能体协作（自动驾驶、游戏、多机器人）的 world model 模拟需要跨视图一致性，这是当前视频世界模型向实际应用迈进的重要瓶颈。

## Method
**整体管线**：基于 Wan2.2-T2V-5B 预训练模型，将 N 个智能体视频拼接为一个联合 token 序列，通过 full-attention DiT 联合去噪。

**关键技术**：
1. **MA-RoPE（多智能体旋转位置编码）**：在标准 3D RoPE 基础上，将智能体索引 n 编码到空间坐标中（nH+h, nW+w），使不同智能体在位置空间可区分，同时保持时间帧对齐（temporal offset 为 0）。
2. **Camera-Aware Cross-View Consistency**：在 DiT 的 self-attention 旁并行一个 camera attention 层，将相对相机变换矩阵 P_i P_j^{-1} 注入 attention 的 query/key，使相邻视角产生更强关联。
3. **Overlap-Decaying Curriculum Training**：从高重叠的全景视频衍生样本开始训练，逐步降低视觉重叠度，让模型先学习对齐再泛化到不重叠轨迹。
4. **Dynamic Noise Shift**：随智能体数 N 增加线性调整 noise schedule，缓解变长序列带来的训练不稳定。
5. **Minimap Condition**：可选的俯视小地图输入，通过 VAE 编码后以 Gaussian 窗口提取局部特征注入各智能体 token，提供全局空间布局先验。

**创新程度**：较高。MA-RoPE 和 camera-aware attention 的联合设计针对多智能体视频生成问题提出了系统性解决方案。

## Experiment
- **数据集**：自建 PrismaDataset（UE5，96 场景全景 + 79 场景透视，620 小时视频），支持灵活的多智能体视频组合。
- **评测基准**：自建 MultiAgentBench，评测单/多智能体的跨视图一致性（revisit/synchronous/asynchronous）。
- **对比方法**：Lingbot-World（单智能体扩展）、MultiWorld（并发多智能体工作）。
- **指标**：FVD、PSNR、SSIM、LPIPS、Intra-RPE、Inter-RPE。
- **结果**：Prisma-World 在所有指标上大幅领先（FVD 134.9 vs 560/782；Inter-RPE 0.084 vs 0.219/0.190），且支持 N=1~4+ 灵活缩放。
- **消融**：MA-RoPE、curriculum training、dynamic noise shift、minimap 均贡献显著提升。

## Value
- **价值**：首个系统性解决多智能体视频世界模型跨视图一致性的工作，方法设计完整（位置编码 + 相机注意力 + 课程训练 + minimap），实验充分。
- **启发**：MA-RoPE 的设计思路（在位置编码中编码智能体身份）可推广到其他多实体生成任务；camera-aware attention 对需要几何一致性的视频生成有参考价值。
- **待解决**：仅在合成数据上验证，真实世界多相机数据的泛化性未知；动态物体交互建模较弱；长时序生成未充分探索。
