# LAWM-3D: Learning 3D-Aware Latent Actions from Human Videos for Generalizable Robot World Models

## Insight
把同步多视角视频直接加入 latent action model（LAM）并不会自动得到三维动作：不同相机的外观差异会增加噪声，而同时观看 $t,t+1$ 的编码器可能把未来 RGB 直接压进 latent，走“复原外观”捷径。实验中仅加入多视图反而使 LAM PSNR/SSIM 从 29.31/0.886 降至 28.97/0.872；只有以冻结 3D 模型的跨视角特征作几何锚点，并辅以深度重建后才提升。这支持一个实用推论：多视图是数据条件，不是三维归纳偏置；要获得视角不变动作，必须显式约束跨视角对应与减少像素捷径。

## Motivation
机器人视频世界模型需要动作标注，跨平台动作空间又不统一。LAM 可从无标注人类视频的相邻帧反推动作，再作为世界模型条件，但现有方法大多单视角、偏二维外观变化，难以迁移三维交互。已有 UniLACT 用单目深度，MVP-LAM 用合成或严格对齐的多视角重建；本文试图利用规模化真实人类多视角视频，学习可迁移到机器人控制的统一三维 latent action。这是 3D/视频世界模型的重要数据和动作接口问题。

## Method
第一阶段训练 24 层时空 Transformer VAE：同步视角的相邻帧带 view embedding，经随机视角丢弃后分别提取动作 token，并以 mean pooling 汇成 32 维共享动作；解码器以当前 RGB 与估计深度、latent action 重建下一 RGB-D。中间层 6--11 的特征同时对齐冻结 VGGT 的多视角几何特征，用余弦方向损失和归一化后的尺度回归注入 3D 先验。模型可混训单/多视角，推理退化为单视角。第二阶段用 LAM 给人类视频生成伪动作，条件化预训练 Cosmos-Predict2.5 DiT；第三阶段把机器人真实动作改成相对位姿，并重置动作 MLP 首层进行全参数后训练。额外 LAM/深度模块只用于离线训练，rollout 不增加推理延迟。

## Experiment
LAM 在 Ego-Exo4D、Assembly101、EgoDex 及多套机器人数据上训练 600K iteration，世界模型用 13 帧、640×480 视频训练 300K iteration；训练规模为 2B DiT，batch 256。LAM 在 EgoExo4D/Assembly101 的 RGB PSNR 达 33.38/35.76、深度 PSNR 达 35.62/35.85，均优于 DreamDojo-D。WorldArena 的 16 项视觉、运动、一致性、物理、3D、可控指标中多数最好，但相对 DreamDojo 常是小幅提升，例如 interaction 0.558→0.578、trajectory 0.322→0.350、depth 0.873→0.889、action following 0.087→0.095。三个 OOD 集上，2B 模型整体略优于 DreamDojo-14B；如 EgoDex LPIPS 0.197 vs 0.213。完整 LAM/世界模型在 In-Lab 达 30.56/0.933 与 21.68/0.797；无几何对齐的多视图+深度为 29.69/0.912 与 21.42/0.788，显示几何对齐是主因。人类+机器人预训练的归一化均值为 1.0887，高于无预训练 1.0。附录在 8 个 MuJoCo 任务报告想象回报与真实回报 Spearman $\rho=0.952$、Regret@1=0.040，并以 8 步想象从多个 BC checkpoint 选动作，使高方差策略组成功率由 53% 升至 70%；但未清楚隔离这些决策收益相对基线世界模型的增量。

## Value
论文把无标注人类视频、视角不变 latent action 与视频世界模型串成完整路线，证明冻结 3D foundation model 可充当动作空间的几何教师。对本方向的直接启发是：动作 token 的好坏应由跨视角可转移性、真实动作可线性恢复性和下游决策效用评价，而非只看未来帧重建。尚待解决的是去除同步多相机依赖，验证更强的跨本体/真实闭环泛化，并设计真正阻断未来外观泄漏的目标。

## Strengths
- 从“多视图为何不够”出发统一解释随机视角、几何对齐和 RGB-D 目标，方法动机连贯。
- 覆盖 LAM 重建、16 维视频质量、OOD 泛化、组件/教师/层范围/权重消融，以及离线评价和在线策略选择。
- 几何教师只在训练使用，详细报告参数、显存、训练开销与 rollout 延迟。
- 真实动作互信息、线性探针和跨视角迁移分析，比单纯 PSNR 更接近 latent action 的语义。

## Weaknesses
- 所谓“非注入式深度”仍让编码器看到未来 RGB，且 $\beta=10^{-6}$ 的 VAE 瓶颈很弱；RGB-D 重建只能抑制、不能证明消除了未来外观泄漏。
- 依赖同步、校准的多视角视频、VGGT 与单目伪深度；透明/反光/遮挡和尺度不一致会把教师误差传给动作空间。
- 2B 世界模型多数指标仅小幅优于 DreamDojo，16 个指标缺少置信区间或显著性检验，且存在多指标择优解读风险。
- “3D-aware”主要由深度重建、教师特征和感知指标间接证明，没有显式 SE(3) 等变性、几何状态恢复或严格反事实动作测试。
- 决策实验在自建仿真环境完成，未充分给出 LAWM-3D 与同规模基线在政策评估/选择上的直接对照；真实机器人闭环尚未验证。

## Future Work
作者提出研究 3D 教师误差的传播，利用未同步或单目视频（如视图合成/伪多视图）扩大数据，改用度量或多视角一致深度，验证 14B 以上缩放，并扩展到多本体、动态/可变形物体、长时组合任务和真实闭环部署。
