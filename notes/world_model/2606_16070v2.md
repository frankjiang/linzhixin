# Mind-Studio: Executable World Models with Lookahead Evaluation for Partially Observable Games

## Insight
论文指出只拟合 state-action-next-state 表面转移不等于获得可运行世界模型；在部分可观测 Atari 中，隐藏边界、碰撞优先级、敌人/物体机制需要以程序控制流形式显式表达。推论是 LLM 可以从 object-centric traces 综合出可执行 pygame-style transition program，并用 K-step lookahead fidelity 验证机制质量。

## Motivation
解决 symbolic/code-based world model synthesis：把交互经验转成独立运行的环境动态程序，用于 planner lookahead。同行有 PoE-World、WorldCoder、Text2World、PDDLGym 等，但常是局部规则、在线探索或文本世界。问题与隐式视频/3D世界模型不是同一路线，但对“可执行世界模型”和规划评估有直接借鉴。

## Method
Mind-Studio 从 OC-Atari 抽取 object-centric symbolic state，基于 entropy score 选择信息量高的 transitions，压缩为 static interface、action-conditioned deltas 和 game skill file。LLM 单次/少次生成 pygame-style Python transition program M，包含对象状态、碰撞、优先级、生成/死亡等机制。评估用同一状态下的 K-step branch previews，与 Real-ALE rollout 的 player coordinate 做 exact match；planner 只看世界模型预览并选择动作。

## Experiment
Montezuma’s Revenge 上 chosen-action NSP 从 PoE-World 0.3% 提升到 48.7%，验证 5/8 subgoals。Alien、Assault、Skiing 上 branch-level fidelity 通常优于 prior lookahead sources，且规划结果受 planner backbone 影响。错误集中在 rope/skull、ladder/platform overlap 等几何敏感组合。

## Value
对用户方向属于 Related：不是视频/3D/JEPA/Dreamer，但“生成可执行机制 + lookahead fidelity”是评价世界模型是否能用于规划的好思路。可借鉴其 branch NSP/chosen NSP 区分，而非只看生成质量。
