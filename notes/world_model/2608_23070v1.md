# From Generation to Simulation: How Far Are World Models from Being True Simulators?

## Insight
有。论文的 observation 是：若不用生成模型内部指标，而以传统模拟器的外部能力作标尺，世界模型的短板会从“画面不够好”转向“状态不可查询、物理不可验证、长程不可复现”。对 163 篇实现论文的接口审计显示，87 篇支持闭环交互，但仅 45 篇输出 RGB 以外的传感信息，20 篇给出 reward/termination，只有 6 篇暴露运行时可查询的实体或物理状态。由此推论：高保真视频可以替代渲染，却不能单独构成可编程模拟器；真正缺的是可消费、可验证、可复现的世界状态。这里的“证明”是文献编码与接口审计，而非形式定理或统一实测。

## Motivation
现有综述多按架构、功能或应用整理 world model，难以回答它离 physics/game engine 和 RL environment 还有多远。论文改用资产构建、物理引擎、交互、可控性、稳定性、状态反馈、多样性、评测八项能力比较 latent dynamics、autoregressive、diffusion、JEPA、显式 3D/4D 与 occupancy 路线。问题很关键：若目标是用生成式世界模型训练 agent、做规划或安全测试，仅看 FVD、画质和短时 action following 会产生错误结论。

## Method
作者从 Google Scholar、arXiv、DBLP、Crossref 以 20 余组布尔查询检索，并沿 6 篇综述及 World Models、DreamerV3、Genie、Cosmos 的引文网络扩展；截止 2026-06-30，筛出 200 项记录，其中 163 篇实现、18 篇 benchmark、16 篇综述、3 篇其他工作。正式发表状态再由 DBLP/Crossref 交叉核验。

每篇被编码为技术路线、action interface、1-3 个主要能力贡献及证据摘要；另对 163 篇实现逐篇标注 B1 ego state、B2 sensor output、B3 task signal、B4 runtime entity/physics annotation、B5 closed loop，并将 present/absent/unresolved 分开。最后逐能力归纳代表方法、相对进展、与传统模拟器的结构差距，再形成六项路线图。创新主要在外部能力标尺和 B1-B5 接口审计，不是新模型。

## Experiment
这是系统性能力审计而非模型实验。200 篇中仅 72 篇已正式发表、128 篇仍为预印本；实现论文按 latent 29、autoregressive 37、diffusion 63、JEPA 5、显式 3D/4D 25、occupancy 4 分组。以“主要贡献被讨论”计，可控性覆盖 125/200（62.5%）、交互与稳定性各 80/200（40%）；资产构建 38/200（19%）、物理引擎 34/200（17%）、状态反馈 45/200（22.5%）明显较少。

最有价值的是 Table 3：B1/B2/B3/B4/B5 的 confirmed presence 分别为 65/45/20/6/87（分母 163）。作者还用具体文献说明不同路线的互补性：diffusion 擅长视觉与交互，latent dynamics 擅长控制，JEPA 规划高效但输出不可读，显式 3D/4D 几何稳定但外观弱。论文谨慎声明这些计数衡量研究注意力而非能力成熟度，也没有把异构论文的性能数值强行汇总。

## Value
对我们的直接价值很高：它给视频、3D 与隐式世界模型提供了统一的“是否真能当环境”检查表。尤其应把 runtime state interface、closed-loop task utility、固定随机性的重复运行、千步尺度漂移，与视觉质量分开报告。其六项建议——形式化物理、统一 action interface、一等公民式状态反馈、长程稳定、下游效用评测、跨路线融合——可直接用于项目选题和评测设计。

## Strengths
外部标尺比按 backbone 罗列更能暴露系统缺口；覆盖视频、3D/4D、JEPA/Dreamer 等多条路线；完整公开查询、编码和脚本；把 sensor estimate 与真正的 runtime entity state 严格区分；对“视觉质量不等于模拟效用”、研究注意力不等于成熟度等边界表述克制。

## Weaknesses
检索结果按相关性截断后人工筛选，没有报告初始命中数、双人独立编码、分歧仲裁或 inter-rater agreement，因此八项标签仍带较强主观性。作者称全语料 evidence map，但对全部记录只保证读到 abstract level or above，难以支撑某些“absence”判断；虽然 unresolved 单列，漏报接口仍可能被误判。语料高度偏向 2025-2026 预印本，结论会快速过时。各能力的论文计数只是“被研究”，并非达到共同阈值后的能力测量；仅 5 篇 JEPA、4 篇 occupancy，也不足以比较路线成熟度。把无 action conditioning 的纯 representation learning 排除，会低估与隐式世界模型相关的表征进展。

## Future Work
作者明确提出六条方向：将可微物理或逐步守恒约束嵌入生成过程；打通显式、语言和 latent action；输出与画面一致的命名实体/物理字段；建立长程误差界与重复运行协议；以真实环境中的增量任务成功率替代纯画质指标；融合 diffusion、latent dynamics、JEPA 与显式 3D/4D，并解决其 pixel loss、latent energy、policy return 目标不兼容的问题。

## Rating
创新度评分：3/5 - 八能力外部标尺和 163 篇接口审计有明确新意，但本质仍是主观编码驱动的综述框架，不是新世界模型或统一实证 benchmark。
相关度评分：3/3 (Core) - 直接横跨视频、3D/4D、JEPA/Dreamer 世界模型，并聚焦其成为真正模拟器的核心条件。

## TL;DR
以传统模拟器八项能力审计200篇世界模型，揭示状态反馈等结构缺口，综述框架值得精读。
