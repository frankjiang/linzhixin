# Cinematize from Unreal: Agentic Choreography for Controllable World Simulation

## Insight
作者观察到影视级 3D 场景里，单个操作即使可执行，也可能因动画与位移不同步、镜头距离与焦距未联动而破坏整体时序；而重做整个项目会损失已有正确状态。由此提出“持久可寻址的场景状态 + 显式依赖 + 局部修复”的系统设计，并用组件消融与示例支持其工程效果。论文无关于学习世界动力学的新理论。

## Motivation
生成视频可给出丰富画面，但逐对象修改和精确镜头控制困难；Unreal 引擎能保留可编辑的 3D 实体、动作和轨道，却要求大量正确的资源选择、几何摆放和 API 操作。论文解决自然语言到可执行场景及镜头序列的转换与修复问题。对可控场景制作有意义，但与学习式世界模型的核心预测问题距离较远。

## Method
- 将文字需求分成环境、资产、摆放、动作、镜头等子任务依赖图；以 Unreal 项目里的 Actor、Transform、动画绑定和 Sequencer 轨道作为实际世界状态，由专门代理生成引擎操作。
- 先查 300 多个已验证资产的本地缓存，再查外部资源；用包围盒、支撑接触、相邻和碰撞约束确定摆放。60 多个经验证代码模板按代理能力分发；共用 Sequencer 时间轴联动动画、位移、焦距和切镜。
- 静态校验、执行追踪和引擎状态检查逐层定位失败；按依赖范围修改具体函数并保留已验证操作，支持有限回滚。创新主要是把已有多代理编排、模板代码生成和引擎反馈整合成可编辑的 3D 内容流水线；引擎提供动力学，并未训练预测模型。

## Experiment
- 评估复合场景构建、多镜头、材质/动画/实体局部修改、镜头控制，以及组件配置消融。指标为端到端任务成功率、首次生成程序正确率、修复轮次；另与 HunyuanVideo、Veo、Seedance、Wan 展示两个镜头任务的定性对比。
- 单代理成功率 **11.5%**；无知识库、统一知识库、按能力分发分别为 **18.4%、31.2%、47.8%**。同为专门知识配置时，无验证、单层验证、三级验证分别为 16.8%、29.5%、47.8%；局部函数修复为 47.8%，整段重生成为 38.1%，修复轮次 5.6 对 7.8。
- 图示展示广角到推镜、多镜头共享场景、替换材质/实体、以及联动动画与位移避免“滑步”。视频生成模型对比仅是选例展示，缺少统一量化质量或人工偏好评估；论文也未报告测试样本数和不确定性区间。

## Value
对 3D 世界模型研究，适合借鉴**可寻址场景状态、动作依赖图和执行后验证**，可用于构造可编辑的交互数据或严格评测相机/实体一致性。若研究重点是视频预测、3D 表征或隐式动力学，本论文不是直接方法参考。

## Strengths
把文字目标、实际引擎状态和执行证据分开；对跨轨道约束与修改依赖给出具体实现；消融显示模板分发、分层验证及局部修复各有贡献。

## Weaknesses
依赖资产库、模板和特定 Unreal 接口，迁移性未知；几何仅用轴对齐包围盒近似，镜头模型也有简化假设。成功率最高仍低于一半，定性视频比较难支撑优劣结论；缺少样本量、区间、运行成本和独立复现。系统调用已有引擎，不学习世界动力学。

## Future Work
作者提出把生成视频的丰富外观转换成兼容的引擎资产与可执行状态；也需扩展资产/引擎覆盖、改进复杂接触和视觉构图验证，并处理素材来源与授权。

## Rating
创新度评分：2/5 - 多代理、模板、几何约束和验证修复的工程组合有实用性，尚无新的世界建模机制或强量化证据。
相关度评分：1/3 (Tangential) - 与 3D 场景控制和可执行评测间接相关，核心是引擎编排而非视频、3D 或隐式世界模型学习。

## TL;DR
多代理把文字指令变成可修改的 Unreal 场景和镜头序列，验证与局部修复改善成功率；世界模型研究可选读。
