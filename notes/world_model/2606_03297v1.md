# SplitAdapter: Load-Aware Humanoid Loco-Manipulation via Factorized Adaptation

## Insight
将物体/负载适应与机器人动力学适应因式分解（而非压缩到单一latent），能显著提升重载条件下的sim-to-real操控鲁棒性。

## Motivation
人形机器人在不同物体质量和放置高度下进行loco-manipulation时，现有history-based adapter将所有因素（物体负载、动力学mismatch）压缩到单一latent表征，在重载操控下鲁棒性不足。

## Method
- 冻结预训练box manipulation policy
- 分离的 **object/load context encoder** 和 **dynamics context encoder**
- **Split world-model objectives**：各编码器有独立的预测目标
- **GRL (Gradient Reversal Layer) 跨对抗正则化**：防止两个编码器学到冗余信息
- **层级 FiLM (Feature-wise Linear Modulation)**：将上下文信息注入到冻结策略中

## Experiment
- Unitree G1 人形机器人真实世界部署
- 物体质量: 2/4/6 kg，放置高度: 0/30/60 cm
- Full-task 成功率 96.3%
- 重载条件下改进最为显著
- sim-to-sim和sim-to-real均验证有效

## Value
工程实现完整，真实机器人验证扎实。但核心问题（因式分解adapter）偏robotics工程优化，world model仅作为辅助训练目标使用，与世界模型研究主线关系不大。
