# Context Is King: How In-Context Specification Shapes the Geometry of Concepts

## Insight
有。论文的 observation 是：LLM 中概念几何不一定是固定存储的“世界模型”，而会被当前上下文的显式关系规范重写。推论是解释 probing 出来的几何时必须把上下文当作因果变量；即使同一组 token，也可以按声明形成 cycle 或 tree。作者用 RSA、拓扑变化和 activation patching 证明被上下文设定的 map 会影响输出。

## Motivation
论文回应 mechanistic interpretability 中“weekday/month 等概念在模型里形成环形/层级几何，是否代表模型存储了固定世界模型”的问题。已有工作多把几何视为预训练权重中的稳定结构；作者要测试当上下文规则与先验冲突时，模型到底使用哪一个结构。该问题对世界模型表征解释有间接启发，但不研究 action-conditioned dynamics。

## Method
作者给模型 declarative specification，例如重新定义 weekdays 的顺序、声明 adjacency 或 hierarchy。然后读取 generation 前最后 prompt token 的 residual stream，按 entity centroid 构建 representational dissimilarity matrix，用 Spearman RSA 比较 imposed order/tree 与 pretrained prior。

实验覆盖 Gemma、Qwen、Llama 多个尺寸。关键干预是 entity-substitution activation patching：把 prompt 中某实体位置的 activation 替换成另一实体的 activation，看输出是否按 donor entity 在当前上下文 map 中的 successor 变化。

## Experiment
冲突顺序下，Gemma-31B/Qwen-27B 的激活几何与 imposed structure 的 RSA 可到 0.6-0.9，而与原先 prior 近零。任意无意义 token 也能被声明成 tree，并形成 depth-stratified manifold；同一 weekdays 在 cycle specification 下保持环，在 tree specification 下转为深度结构。

activation patching 显示该几何不是 probe artifact：在 imposed context 中替换实体后输出 donor 的 imposed successor，在 natural context 中则输出 pretrained successor，形成双重分离。scale sweep 显示小模型能形成粗糙 geometry，但 clean causal crossover 主要在大模型出现。

## Value
对我们最有用的是提醒：latent geometry 的可解释性必须区分“存储结构”和“上下文临时构造结构”。如果未来研究视频/3D/JEPA 的 latent world model，也需要检查 representation 是稳定动力学结构，还是 prompt/任务条件诱导的临时几何。

## Strengths
问题设置清晰；不仅做 probe，还做因果 patching；用 topology type 改变排除了简单 relabeling；scale-gated 结论对跨模型解释迁移有警示意义。

## Weaknesses
任务是 LLM 概念顺序/层级表征，不涉及物理状态、动作或预测学习；实体规模小，主要是 7-12 个概念 centroid；与 JEPA/Dreamer 的联系需要读者自行迁移；不能回答这种上下文 map 的具体电路实现。

## Future Work
作者提出 future work 包括 manifold-axis steering、更复杂关系如 partial order/DAG，以及模型原生 reasoning 过程中几何如何变化。

## Rating
创新度评分：3/5 - 表征因果验证做得扎实，但贡献在 LLM interpretability，不是世界模型算法。
相关度评分：1/3 (Tangential) - 仅对“隐式表征是否固定”有间接启发，和视频/3D/JEPA/Dreamer 不直接相关。

## TL;DR
证明LLM概念几何会被上下文重设，对表征解释有启发，但世界模型方向可跳读。
