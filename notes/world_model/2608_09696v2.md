# Model Discovery Agent: LLM-assisted Bayesian experiment design for data-efficient discovery of mechanistic world models

## Insight
LLM 擅长提出开放式机制假设，却不适合独自定参和挑实验；Bayesian posterior/Occam penalty 可筛结构，VoI 主动选择最能区分模型的干预。v2 进一步把这一推论落实为嵌套 SMC：预测检查在 M-open 情形发现“现有假设都不对”后触发 LLM 扩容，posterior 过度集中时自适应增加粒子，从而形成 proposal—identification—residual discovery 循环。

## Motivation
被动拟合不能识别机制，也无法可靠回答未做过的干预；科学实验昂贵，纯 LLM agent 又常选信息量不足的实验并产出数值拟合但机理错误的公式。数据高效发现可干预 mechanistic world model 是重要科学 AI 问题，但不属于视觉/3D/控制世界模型主线。

## Method
外层 SMC 表示模型结构 posterior，内层 SMC 表示参数 posterior，并以 adaptive tempering 估计 evidence。确定性系统直接算观测 likelihood；随机或部分可观测系统用 particle-filter likelihood，也可用 synthetic/learned-summary likelihood 降低成本。LLM 按残差提出新模型，predictive check 触发 M-open 扩容；实验以 $I(M;Y_\xi\mid D)$ 最大化，可枚举或 CMA-ES。v2 补全了模型/参数/状态三层粒子算法、观测模型自动选择及自适应粒子预算，使实现定义明显强于 v1。

## Experiment
统一比较最多 8 次实验的 held-out interventional error。ForceBench 11 种力学世界中，MDA 数次实验即可把廉价 DeepSeek proposer 提升到接近 Opus；Yukawa 案例中 VoI 主动选长距离 probe 区分短程近似。ChemBench 36 任务×2 seeds，约 8 次实验达到 symbolic accuracy 约 56%，而 LLM-AutoSciLab 60 次约 42%。NeuronBench 六类 Hodgkin–Huxley 隐机制中 Bayes forecast 全面优于 ICL，VoI/LLM design 优于随机；随机动力学版 learned summary 将嵌套粒子计算加速约 $10^4$。v2 的新增 SMC 细节增强可复现性，但没有改变主要实证边界。

## Value
工作把开放假设生成与严谨 Bayesian experiment design 结合，强调“预测数值准”和“发现机制”不同，方法学价值高。对目标世界模型的间接启发是：真正的反事实能力需要可识别干预、显式不确定性和主动数据，而不是仅扩大神经预测器。

## Strengths
- 覆盖物理、化学、生物及确定/随机、完全/部分可观测设置。
- 同时评价数值外推与符号机制，揭示低误差的伪机制。
- M-open 检查、posterior Occam penalty 和自适应 SMC 使 LLM proposal 可校验。
- v2 给出较完整的算法伪代码、likelihood 分支和计算配置。

## Weaknesses
- benchmark 均为已知家族的合成/半合成系统，候选库、设计菜单和先验含大量领域结构。
- SMC 套 particle filter 计算昂贵；learned summary 可能丢失与新假设有关的信息。
- VoI 为 myopic，一步最有信息不保证全预算最优。
- 结果依赖闭源/特定 LLM proposer，开放假设质量及复现成本不稳定。
- 与视频、3D 或机器人 latent 世界模型没有直接实证联系。

## Future Work
可扩展多步 Bayesian design、自动学习假设相关 sufficient summary、真实实验室噪声/成本/安全约束，以及更开放的连续结构发现。

## Rating

相关度评分：1/3 (Tangential) - 研究 mechanistic causal world model discovery，原则相关但非用户关注的视觉/3D/JEPA/Dreamer方向。
