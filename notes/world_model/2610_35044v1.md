# DriveUniTok: A Unified Multimodal Tokenizer for Driving World-Action Models

## Insight
观察：驾驶世界动作模型若把 RGB、LiDAR 几何和自车运动放在独立 token 流，下游预测器还需学习跨模态对齐。推论：先在同一个可解码瓶颈中建立对应关系，能够以较少 token 同时改善未来场景和轨迹预测。等 token/DiT 预算的分流对照，统一编码的未来 gFVD 6.61 对 12.80、规划 PDMS 91.0 对 87.5，提供实验证据；并非证明每个 token 都融合了全部模态。

## Motivation
通用视频 VAE 注重外观，驾驶 BEV/OCC 表征常把 ego pose 留在外部；世界动作模型因此容易生成相互不一致的图像、深度与轨迹。对于驾驶视频世界模型，表示接口本身是关键问题。

## Method
DriveUniTok 以冻结 DINOv3 提取前视 RGB 和投影 LiDAR 深度特征，576 个图像查询和 8 个 ego 查询经共享自注意力、两次可变形跨注意力融合；每 5 帧经因果压缩和高斯瓶颈变为 584×16 连续 latent。共享解码器用不同 mask token 重建 RGB、有效 LiDAR 深度、自车相对位姿，并以训练期 DINO 语义头约束。冻结 tokenizer 后，用 Wan2.2 初始化的 DiT 在块因果注意力下做 flow matching，联合预测两段未来 latent，解码场景和轨迹；再对轨迹 PDM 奖励用 Flow-GRPO 微调 LoRA。创新在统一可解码表示和配套受控对照，模块本身多为已有设计。

## Experiment
NAVSIM navtest 的指标包括 RGB 的 LPIPS/PSNR/SSIM/FVD、深度 AbsRel/RMSE、轨迹 ADE/FDE，规划 NC/DAC/EP/TTC/PDMS。等预算分流对照：未来深度 AbsRel 0.1059 对 0.1850，轨迹 ADE 0.3816 对 0.4186，PDMS 91.0 对 87.5；自然预算分流用约双倍 token，PDMS 90.1。与原 Wan2.2 VAE 固定骨干对比 PDMS 87.9→91.0；RL 后 91.54。附录的遮盖/语义消融均降低重建质量，五种 DiT 骨干 PDMS 88.9–91.0；NAVSIM-v2 EPDMS 90.3。视觉重建在 PSNR/SSIM 上明显落后大型 RGB VAE。

## Value
统一表示可同时作为可视化模拟器和规划接口，对视频+几何+动作联合建模有直接参考价值。尤其值得看等表示预算的对照，而非只看不同传感器配置的排行榜。

## Strengths
分别控制相同传感器、token 数、DiT 序列长度和训练计划；报告重建、预测和规划全链路以及目标/输入模态消融；明确 RL 前后 tokenizer 固定。

## Weaknesses
仅前视图和投影的稀疏深度，并非显式完整 3D 场景；NAVSIM 为非反应式规划，缺乏闭环驾驶与跨数据集验证。统一与独立流同时改变了共享参数、跨模态连接和解码上下文，不能把全部收益单独归因于“单一 latent”；等预算下 tokenizer 参数也不同。RL 的 PDMS 增益仅 0.54。

## Future Work
论文未明确列出路线；需要闭环驾驶、真实传感器失效测试及多视角/稠密 3D 扩展，且要拆解统一 latent 中哪些连接真正带来规划收益。

## TL;DR
统一编码前视视频、投影深度和自车运动，提升驾驶世界动作模型预测与规划，表示设计值得精读。
