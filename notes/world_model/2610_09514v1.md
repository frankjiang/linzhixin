# STRIKE: Learning Visual State Transitions for Physical World Modeling

## Insight

观察：直接图生视频能产生连续运动，却可能先抬起物体、后才接触或抓住，破坏物理事件顺序。推论：先预测接触、附着、释放等**可见状态转移**及发生时间，再让视频模型填充过程，可给密集生成提供明确的事件结果约束。作者用状态模型消融与多个视频评测支持此推论；无物理定律或长期预测的形式保证。

## Motivation

大视频模型侧重画质和连续性，关键帧式方法已有但常缺针对单次相互作用结果的显式监督。接触关系、物体支撑状态等中间结果对物理视频世界模型有价值；此问题重要，但方法偏开放域视频生成，尚未形成动作控制闭环。

## Method

从训练视频抽候选帧，以 VLM 选事件状态、写相邻状态的局部变化描述并核对时序，再由 Qwen3-VL 检验图文一致性，构成约 35.4 万事件对。微调 Qwen-Image-Edit：输入当前状态图、局部事件、经过时间及初帧锚点，以相对时间 RoPE 与流匹配生成下一状态图。推理时预训练 VLM 只看初帧与任务，提出事件和时间；同一转移模型递归生成状态。另训 CogVideoX/Wan 视频骨干，把预测状态及绝对时间作为软记忆 token，联合生成完整视频。关键贡献是事件对齐的可组合视觉转移接口，组件多来自已有模型。

## Experiment

- Physics-IQ Verified：CogVideoX-5B 骨干 30.5→STRIKE 41.9；Wan2.2-5B 19.4→39.7。PhyGenBench 平均：CogVideoX 54.79→76.91、Wan 50.83→75.62。PISA 421 视频中 CogVideoX 版本 L2 0.1180→0.0949、Chamfer 0.3017→0.2495、IoU 0.1481→0.1753。
- RoboTwin2 val500 是 50 个**已知任务**的未见回合，不是新任务泛化。EWMScore-15：CogVideoX 58.04→60.51，Wan 59.16→62.53；轨迹指标分别 0.2301→0.3306、0.2372→0.3368。
- 预训练图像编辑器直接预测状态 vs 学得转移：验证状态 PSNR 17.90→24.88，Physics-IQ 32.60→41.93。去初帧锚点、时间、合成数据均退化；但训练混合与预算差异限制严格归因。加入 20B 转移模型使 CogVideoX 完整生成量 6.64→10.02 EFLOPs。

## Value

“先事件结果、后密集动态”是视频世界模型的有用分层：可单独评估状态是否正确、时序是否合理、过渡是否真实。对视频生成和物理一致性评测值得借鉴；面向控制仍需把语言事件接到可执行动作及闭环反馈。

## Strengths

训练监督来自视频真实帧而非 VLM 合成图；跨两种骨干、物理视频和机器人视频基准验证，并做转移模型与时间/锚点消融；附录明确数据拆分和评测指标。

## Weaknesses

事件由大 VLM 生成，标注与规划错误会层层传播；训练视频模型用真实状态图、推理改用递归预测图，存在条件分布偏移。额外 20B 图像模型与视频生成成本不低。输出是可见状态，不显式编码速度、隐蔽接触或守恒量；无动作条件闭环控制实验证据。

## Future Work

作者未给出具体后续实验路线；其限制暗示应减轻递归误差、标注依赖和计算开销，并检验长时域物理轨迹及控制有效性。

## Rating

创新度评分：3/5 - 事件对齐状态转移监督及定时记忆组合有效，但与已有关键帧/事件引导生成同属渐进式路线。
相关度评分：3/3 (Core) - 直接研究视频物理世界模型及其状态转移表示。

## TL;DR

显式学习事件对齐的视觉状态转移，再以定时关键状态约束视频生成，改善物理一致性；值得精读。
