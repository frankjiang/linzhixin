# ActionRoPE: Action as Coordinates for Spatially Consistent Control in Planar-Camera Game World Models

## Insight
俯视游戏里玩家动作近似决定相机平移，同一世界点虽换了屏幕位置却应保留相同空间地址。将累计位移写入 RoPE 坐标可把动作几何效果显式编码；初始视野内外再对应“已见”和“新生”内容。闭环往返测试的漂移和速度拟合支持这一推论，没有一般 3D 场景的理论保证。

## Motivation
游戏视频世界模型把动作当 token、特征或 AdaLN 条件，网络还需从数据学平面相机位移，因而速度控制不准、回访场景漂移。对于平面相机游戏，这是核心的几何控制问题。

## Method
对时空 token (k,i,j) 使用累计相机位移修正 RoPE 空间位置为 (i+Δy/s,j+Δx/s)，让同一世界点跨时共享地址；按其是否属于首帧世界坐标覆盖区构造已知掩码。CNS 对已知 token 在训练和采样中采用更早降噪的局部 shift，新区域仍按原 schedule，并以零初始化掩码通道输入网络。ActionRoPE 控制通道无新增参数，但需微调视频 DiT；CNS 另有约 0.015M 参数。先验几何嵌入是主要创新。

## Experiment
在《No Rest for the Wicked》约 18,528 段训练/982 段测试视频上，以 Wan2.2 骨干对照 prompt、线性、AdaLN、cross-attention 动作注入；比较位移斜率/R²、方向角、往返 PSNR/SSIM/NCC/DINO 相似及像素漂移。ActionRoPE＋CNS 斜率 0.981、R² 0.952、角误差 0.68°、漂移 7.8 px；最强漂移基线 AdaLN 为 22.6 px，下降约 66%。仅移除 CNS 漂移升至 11.7 px；附录显示 CNS 收益主要来自训练时噪声分配，不是单独换采样器。1.3B—33B 骨干和 50 张新风格首帧也有测试。

## Value
“能计算的动作几何直接写进位置编码”的设计可迁移到部分相机控制视频世界模型；往返一致性协议也有用，值得精读。

## Strengths
同骨干、同训练步数比较多类注入机制；同时测速度线性、方向和回访漂移；明确区分坐标接口与 CNS 贡献。

## Weaknesses
依赖标定的动作—相机位移，单一近刚性平面游戏验证；缩放、视差、运动物体不服从静态世界坐标。已知掩码只记首帧，后续新见区域回访仍当未知；跨骨干与风格测试没有新物理动力学。Prompt/Cross-Attn 基线把位移量量化掉，速度对比对其不等信息；部分无法 SIFT 测量的片段被排除。

## Future Work
作者未给具体路线；附录明确指出需处理缩放、视差、动态物体，并把已见地图从首帧扩展到累积历史。

## Rating
创新度评分：3/5 - 把动作位移转成 RoPE 世界坐标并联动区域噪声日程，构思简洁有效，但局限于可标定的平面相机。
相关度评分：3/3 (Core) - 直接改进动作条件视频游戏世界模型的空间一致性。

## TL;DR
把相机动作位移写入世界坐标 RoPE 并提前稳定已见区域，大幅降低游戏回访漂移；值得精读。
