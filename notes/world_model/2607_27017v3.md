# What Can Latent World Models Know? Physical Parameter Identifiability in Multimodal Predictive Representations

## Insight
这篇论文最重要的 insight 是：未来预测不会自动让 latent “学会物理”；输入只决定信息上限，预测 target 决定哪些信息被保留，而更多数据只能改善目标函数已经愿意获得的量。作者先用 raw-observation recurrent/physics estimator 给每个参数建立 recoverability certificate，再 probe latent，因此当 drag 可从观测恢复（证书 R²=0.89）但模型只有约 0.13 时，能把失败定位到训练目标而非环境不可观测。

受控干预给出四条机制链：触觉只作为输入时 stiffness 仍为 -0.02，作为预测 target 后升至 0.40–0.57；单步 vision-only JEPA 连可见物体位置都丢弃（0.04），跨模态 target 或多 horizon head 分别把它拉到 0.58/0.89，组合到 0.98；减轻 SIGReg 可单调提高物理 readout；慢且 ratio-type 的参数落入 deterministic point-prediction 的盲区。作者提出 conditional-mean collapse 解释：短窗口不足以锁定 episode 参数时，平方误差最优解是按群体平均预测，因而无压力维护 episode-specific belief。该解释有 Gaussian-NLL、loss reweight、坐标线性化和 supervised system-ID 等对照支持，但仍是限定模型族内的经验假说。

## Motivation
JEPA/latent world model 常宣称预测未来会内化物理，但通常只做 post-hoc probe，无法区分“传感器没有信息”“probe 不会读”与“objective 丢弃了信息”。对接触机器人，这一缺口很关键：质量、阻力、刚度等隐变量决定控制，却可能对短时平均预测误差贡献很小。论文解决的是世界模型表征内容的因果测量问题，而不只是再提高一个 benchmark 分数。

## Method
作者构建 PokeWorld：2D force-controlled finger 与外观完全相同、每 episode 重采样 mass、drag、stiffness 的物体交互；视觉、proprioception 和 7 维 sub-step touch 覆盖不同物理带宽。行为策略混合 push、strike–retreat 与 glide，确保参数可激发。certificate gate 先用 raw observation 的线性、MLP、GRU 或物理 estimator 建立经验下界，再用 episode-disjoint ridge/MLP probe 和功能性预测测试 latent。

X-JEPA 共享约 5M 参数 CNN+因果 Transformer+SIGReg trunk，factorial 改变输入模态、touch/proprio prediction target 与 Δ={1,4,16} horizon。附加实验控制传感带宽、flow input、数据接触覆盖、SIGReg λ、pixel reconstruction、Gaussian NLL、supervised parameter head、坐标变换和 loss share。最后把同一机制迁移到 RH20T 的 KUKA/Flexiv、896/4258 episodes，并以 held-out task 的 position/force readout、16-step prediction、future-force forecast 和 contact AUC 检验。

## Experiment
PokeWorld 中 V/VF/VXp/VXt/VX/VFX 的 stiffness R² 分别约 -0.02/-0.02/-0.02/0.40/0.46/0.50，certificate 为 0.87；mass 随 cross-modal pressure 从 0.15 增至 0.29，证书 0.86。multi-horizon 使 position 由 0.04 到 0.89，direct Δ=16 error 0.10 优于 16 次一步 rollout 的 0.19（static 0.21）。SIGReg λ 从 0.3 降至 0.005 时 stiffness 0.12→0.57、direct-16 error 0.128→0.095。

drag 在多类预测机制、线性/非线性 probe 和功能 glide test 上均接近盲区；同 trunk 加 system-ID head 可到 0.45，pixel reconstruction 仍仅 0.03–0.08。将 log-speed 作为输入使 drag 的线性证书升至 0.52、模型 readout 跟到 0.33，但功能位置预测仍未改善，细致地区分“可读”与“被模型使用”。相同 MPC 下，goal reach 从 V 的 20% 提到 VXt/VXp 的 38/44%，VFX 为 57%（random 1%）。

RH20T 复现 lazy equilibrium 与 target pressure：vision-only 16-step 误差 8.2 cm，差于 static 3.8；full VFX 为 1.5 cm，force readout 0.87、contact AUC 0.86。Flexiv 的 2×2 input×target scaling 中，缺信息或缺 target 的 arm 在 800→4258 episodes 基本不改善；只有 VFX future-force forecast 超过 persistence 且随数据从 0.39 增至 0.51。统计、对照与附录完整度很高。

## Value
这是本批最有方法论价值的工作：certificate-gated identifiability 可成为审计隐式世界模型的通用模板；“每个模态都应有预测压力”“按物理带宽采样”“直接多 horizon”“先设计 objective 再扩数据”都是可操作的设计规则。它也警告只看 average prediction loss 或线性 probe 会误判世界模型。下一步应测试显式 belief state、episode latent、stochastic objectives 与更大模型是否能突破慢参数盲区。

## Strengths
- 先证实 raw observation 可恢复，再讨论 latent 缺失，显著提高 null result 的解释力。
- factorial、dose–response、同 trunk objective control、非线性 probe 与功能测试相互印证，因果链完整。
- 主动报告 untrained encoder passthrough bound，避免把输入直通误称为学习所得表征。
- toy 环境提供参数真值，RH20T held-out task 提供现实机制复现，内部与外部有效性兼顾。
- 公开失败边界和被 certificate gate 否决的构造，研究透明度高。

## Weaknesses
- blind-region 结论只覆盖一个约 5M 参数 trunk 和 deterministic point prediction；无法外推到显式 belief、离散/概率 latent 或大型预训练模型。
- PokeWorld 是简化 2D 动力学，drag 还被构造为质量无关；参数属性可能受坐标和 simulator 设计影响。
- RH20T 没有真实 mass/stiffness 真值，只验证 observables 与机制，未直接复现实物参数 identifiability。
- linear/GRU certificate 都是所构建 estimator 的经验下界，不是结构可辨识性证明；“objective failure”的范围仍受 instrument 能力限制。
- closed-loop 只测位置目标，不能证明 stiffness/drag 内容会改善 force-limited 接触任务。

## Future Work
作者明确提出以 episode-level latent variable、belief state 等非 conditional-mean objective 检验盲区机制；构建带已知、变化物理参数的真实机器人 corpus；扩展更大模型与 force-limited manipulation。还可系统研究 stochastic predictive distributions、active excitation 与自适应传感频率。
