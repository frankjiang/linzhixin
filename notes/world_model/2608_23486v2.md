# GeoWAM: Visual Geometry World Action Models for Autonomous Driving

## Insight

论文的核心观察是：驾驶中的场景变化与轨迹都发生在同一 3D 坐标空间，而像素把几何、运动与纹理/光照纠缠在一起；直接预测未来 point map 后，4 秒几何误差和 NAVSIM 规划分数均优于视频生成再重建几何的方案。由此作者推论，**未来几何预测比未来像素生成更适合作为驾驶 world-action model 的预训练目标**。方法把预测几何作为观察与动作之间的中间变量，并用 stop-gradient 令动作监督只能读取而不能改写几何。这个设计有空间归纳偏置上的合理性，但现有对比并未在相同架构、数据和监督下严格证明优势来自“几何而非像素”。

## Motivation

现有驾驶 VLA 主要以动作监督学习策略，环境演化只隐含在表征中；视频 world model/WAM 则以未来帧生成学习动态，再接轨迹头，但 3D 变换在像素变化中是隐式的。Occupancy world model 虽显式表示 3D，却通常依赖体素 occupancy 标注。论文要解决的问题是：能否仅从 RGB 历史直接预测稠密、度量化的未来点图，并让该几何动态服务于 ego 轨迹预测。驾驶规划高度依赖距离、可行空间和运动，因此该问题关键且与 3D 世界模型直接相关。

## Method

GeoWAM 采用两阶段流程。

第一阶段是 visual geometry world model。DVGT-2 编码器把 `K=3` 帧、多相机历史图像变为多层 geometry tokens 与 ego/pose tokens。对未来 `F=8` 个时刻、每个视角和空间位置复制可学习 geometry query，并叠加时间、视角和 2D 位置编码；6 层 future-geometry decoder 先做沿未来时间的 causal self-attention，再 cross-attend 历史 memory，输出多层未来特征，Point DPT 解码为每像素 3D point map 和置信度。训练同时使用：预测/目标 patch 的 cosine feature loss、未来点图的坐标回归+置信度+多尺度法向损失，以及当前帧点图损失；未来图像只进入 stop-gradient target branch，推理时不可见。

第二阶段加入 action branch。Future ego queries 沿时间自注意力，并 cross-attend 历史 memory 与 **stop-gradient 的未来 geometry tokens**，以“由场景演化反推 ego motion”的 inverse-dynamics-like 方式产生未来 pose tokens。轨迹头融合历史和未来 ego tokens，经 temporal Transformer 与单个 trajectory query，直接回归一条 `(x,y,heading)` 轨迹；无 anchors、mode classification 或迭代采样。微调损失保留全部几何目标，再加 L1 trajectory loss 和历史相对 pose 辅助损失，两个权重均为 5。

创新在于把稠密度量 point-map forecasting 设为驾驶 WAM 的主要状态/预训练接口，并以单向几何→动作连接组织任务；组件本身主要来自 DVGT-2、query decoder、DPT 与标准轨迹回归。

## Experiment

几何预训练合并 OpenScene、nuScenes、Bench2Drive、Waymo、KITTI、Argoverse 2、DDAD，仅使用 RGB，动态采样 2–8 个相机；3 帧历史以 2 Hz 预测 8 帧（4 秒）。编码器/point head 初始化自 DVGT-2，AdamW 训练 161 epochs；未来 decoder 为 6 层、1024 维、16 头。规划在 NAVSIM `navtrain` 上用 8 相机微调 40 epochs，在 v2 `navtest` 和两阶段 pseudo-closed-loop `navhard` 测试。

几何指标为从 point map 转换的 ray-depth Abs Rel（低为好）和 `δ<1.25`（高为好）。基线包括视频模型 Epona、Cosmos 3 生成 RGB 后经 DVGT 重建，以及直接几何预测 VGGT-World。规划用官方 human-penalty EPDMS，聚合碰撞、可行驶区、方向、红绿灯、进度、TTC、车道保持与舒适性等九项，并与 Transfuser、DiffusionDrive、DriveVLA-W0、PWM、DriveLaW、DVGT-2、EponaV2 等比较。

- nuScenes 1/2/3/4 秒 Abs Rel 为 0.228/0.245/0.256/0.297，八帧均值 0.257；最强基线 Epona+DVGT 均值 0.274，VGGT-World 为 0.325。GeoWAM 的平均 `δ<1.25` 为 0.754，对比 Epona+DVGT 的 0.655；但 1 秒阈值准确率 0.708 低于 Epona 的 0.732。
- `navtest` EPDMS 为 90.2，表中最高；相对直接初始化基线 DVGT-2 的 89.6 只提升 0.6，领先 EponaV2 1.3、DriveLaW 1.6。单项并非全面最佳，例如 progress 87.0 低于 DriveSuprim 的 88.4，优势来自聚合分数。
- `navhard` 两阶段反馈评估中 EPDMS 为 36.6，高于 EponaV2 36.1、NavFormer 34.1 和 DVGT-2 31.7；相对 DVGT-2 的提升扩大至 4.9，说明在分布偏移/误差反馈下可能更有韧性。
- 定性图展示左转、直行、右转时聚合的未来点图与 ego poses，可见道路标线、树、杆和随行车辆，但只有三个成功案例，没有失败案例或不确定性展示。
- 论文没有关键消融：未比较无几何预训练、无 future branch、去掉 feature/point/normal loss、去掉 stop-gradient、不同历史/预测长度，亦无同架构同数据的 pixel-world-model 对照。因此模块贡献和“几何状态优于像素状态”的因果证据不足。

## Value

GeoWAM 提供了一个值得关注的 3D world model 方向：把可用于度量规划的 scene geometry 直接作为预测对象，而不是把 3D 理解寄托于逼真的视频生成。对研究的启发包括使用 point map/scene flow/occupancy 等显式状态、让 action head 读取预测动态，以及用长时几何质量和反馈式规划共同评价世界模型。但它不是可供规划器查询不同动作后果的标准 action-conditioned forward model：未来几何先由历史无条件预测，轨迹再从中反推，因而更像“预测示范未来→恢复示范动作”。若要成为通用规划世界模型，还需支持反事实动作条件与多模态未来。

## Strengths

- 状态空间与任务几何对齐，避免为规划生成不必要的纹理与光照，并输出可解释的稠密度量 3D 结构。
- 预训练覆盖七个驾驶数据源、不同相机数和 4 秒预测，兼顾多数据集规模与多视角变化。
- 同时验证未来几何、常规规划和误差会反馈到下一观察的 navhard，评价链条覆盖表征到动作。
- Future geometry→ego decoder 的 stop-gradient 明确保护几何能力，结构上比将两个 loss 无约束混合更可解释。
- 相比视频生成→几何重建 cascade，在中长时预测上的优势较稳定；navhard 相对 DVGT-2 的增益也比 navtest 更明显。

## Weaknesses

- 缺少消融和 matched-control 是最主要缺陷：各视频基线的架构、训练数据、计算量及监督不同，还额外经过 DVGT 重建，不能据此隔离“预测空间选择”的作用。
- Geometry encoder、point head 和伪 point-map target 都依赖已有视觉几何模型，论文未清楚说明 nuScenes 指标最终对何种几何真值计算；若仍依赖 teacher 生成目标，可能继承 teacher 偏差并使同族方法受益。
- 未来几何不以候选 ego action 为条件，却包含由数据采集策略产生的 ego-frame 变化；action head 可能主要从未来 pose/point-map 变换中解码示范轨迹，而不是真正理解可控环境动力学。模型不能比较“采取动作 A/B 后世界如何变化”。
- 只回归单条确定性轨迹和单一未来几何，无法表达其他交通参与者和 ego 决策的多模态不确定性；这在长尾驾驶中尤其关键。
- `navtest` 相对强初始化 DVGT-2 仅增 0.6 EPDMS，且没有多种子方差或显著性；很难判断增益是否稳健、是否来自额外参数/训练轮数。
- `navhard` 是 3DGS 重建的 pseudo-closed-loop，而非真实交互仿真或道路测试；动态参与者响应、控制执行误差和长期安全仍未验证。
- 没有报告参数量、训练样本规模、算力/时长、推理延迟与内存。稠密 8 帧×8 相机×每像素点图对部署成本的影响不明。
- 视觉结果只展示成功场景，缺少远距离、遮挡、动态物体、恶劣天气和几何漂移的分类型误差与失败分析。

## Future Work

作者结论未明确列出未来工作。优先改进包括：加入候选 ego action 条件以支持反事实 rollout；用 diffusion/latent-variable 表达多模态场景与轨迹；做严格的 pixel-vs-geometry 同架构同数据消融及各损失/stop-gradient 消融；使用 LiDAR/真实 3D 真值独立验证；报告尺度、延迟和不确定性校准；在可响应交通参与者的闭环仿真及真实车辆上测试长时安全与恢复能力。

## Rating

创新度评分：3/5 - 将未来稠密 point-map forecasting 系统化为驾驶 world-action model 的核心预训练目标，方向清晰且结果较强；但架构多为既有组件组合，关键因果消融和反事实世界建模能力不足。

相关度评分：3/3 (Core) - 直接研究多视角 3D 几何世界模型及其动作/规划接口，是用户关注的 3D 世界模型核心论文。

## TL;DR

以未来点图替代像素视频预训练驾驶世界动作模型，几何与规划均提升；缺消融但值得精读。
