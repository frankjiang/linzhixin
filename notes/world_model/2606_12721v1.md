# The Theory of Mind Utility: Formal Specification of a Mentalizing Mechanism

## Insight
论文把 theory of mind 中的 epistemic-state inference 形式化为 local epistemic world model：一个临时构造的有向类型图，用来表示他人的信息接触顺序、可信度和信念状态。这里“world model”更接近 mental model，不是 RL/视频世界模型。

## Motivation
现有 theory-theory、simulation theory、Bayesian ToM、POMDP 系方法常预设人能推断他人信念，但没有单独形式化 epistemic state inference。作者希望给出可产生失败模式预测的机制。与用户研究方向不相关。

## Method
ToM-U 的核心是生成并过滤离散候选 LEWM。LEWM 定义为 W=<A,O,E,BLS,obs,cred>：agent set、state nodes、epistemic edges、belief-like state、observability、credibility。Agent node 带 ordered information access history H、sophistication depth S、type t。递归 mentalizing 用 bounded branching tree 避免无限递归；失败 mentalizing 留下 residue 影响后续推断。

## Experiment
没有机器学习实验，主要是理论定义和例子。示例中 focal agent 建模 Sam：Sam 先收到可信朋友证词“袋中是爆米花”，后看到标签“巧克力”；LEWM 用有序 H=[证词,标签] 区分信念更新顺序。作者声称缺少有序历史会导致类似 LLM 的显著性默认失败。

## Value
对认知科学/社会推理建模有意义，但不是可训练世界模型、视频/3D/JEPA/Dreamer 方向。对本 survey 应判为噪声，除非需要讨论“world model”术语泛化。
