# BRo-JEPA: Learning Modular Arithmetic in Latent Space

## Insight
Observation: 标准 JEPA 模型能学会已见的算术操作（如 +1/-1），但无法零样本泛化到未见操作（如 +3/-5），即使使用 additive compositional embedding 也不稳定（先升后降）。推论: JEPA 的 MLP predictor 缺乏归纳偏置来捕获模运算的循环群结构，需要在 predictor 中显式注入与问题代数结构匹配的归纳偏置。证明: 提出 block-rotation predictor（受 RoPE 启发），将 latent dynamics 参数化为块对角旋转矩阵，显式编码 mod-10 循环结构，在 MNIST 模运算任务上实现 99.46% 零样本准确率。

## Motivation
- **问题**: 神经网络是否真正学习了代数规则而非记忆训练数据？在 JEPA 框架下，latent world model 能否学习符号化的状态转换规则并零样本泛化？
- **同行做法**: NALU/NAU 等专门算术模块引入结构先验但泛化能力仍不足; 标准 JEPA 用 MLP predictor 虽能拟合已见操作但无法外推。
- **关键性**: 这是一个关于 latent world model 表示结构的基础性问题——predictor 的归纳偏置如何影响泛化。但实验场景（MNIST mod-10）过于简化。

## Method
- **整体架构**: 标准 JEPA 框架（context encoder + EMA target encoder + predictor），使用 L2 loss + VICReg 防止 collapse
- **Additive Compositional Embedding**: 将操作 op(k) 表示为基向量 v 的标量倍数 k*v，编码线性组合关系
- **Composition Consistency Loss**: 强制 g(z, k*v) 约等于 g(g(...g(z,v)...),v) (k 次)，鼓励组合一致性
- **Block Rotation Predictor (BRo-JEPA)**: 核心创新。将 MLP predictor 替换为块旋转矩阵 R_block = diag(R(theta_1),...,R(theta_n))，预测 z_p = R_block(k*theta) * z。两种变体: SFR（所有块共享同一 theta）和 MFR（每块独立 theta_i）
- **固定/可学习角度**: 固定 theta=2pi/10 直接编码 mod-10 结构; 可学习角度从随机初始化收敛到 pi/5 及其谐波
- **创新程度**: 2-3。Block rotation 的想法直观且有效，但实验场景过于简化，且归纳偏置高度针对循环群结构。

## Experiment
- **消融**: 系统对比 supervised baseline（MLP/ResNet18）+ additive embedding、JEPA + additive embedding + compositional loss、supervised + block rotation、BRo-JEPA (SFR/MFR) 的各项指标
- **指标**: Train Acc、Seen Op Acc、Zero-Shot Op Acc、Unseen Op Rollout Acc、Unseen Op KNN Acc
- **关键结果**:
  - Supervised baseline: seen op ~97-98%，zero-shot ~2-6%（完全失败）
  - JEPA + additive embedding: seen op ~97-99%，zero-shot ~9-10%（有改善但不够）
  - BRo-JEPA (ResNet+MFR): seen op 99.45%，zero-shot **99.46%**，rollout **99.46%**，KNN 70.90%
  - Compositional consistency loss 提升 rollout 但属于 weak zero-shot（训练中间接暴露了组合操作）
- **可视化**: PCA 显示 BRo-JEPA 的 latent space 形成清晰的椭圆流形，10 个数字类均匀分布; 多步 rollout 轨迹稳定无漂移
- **可学习角度**: SFR 收敛到 pi/5，MFR 收敛到 pi/5 的多个谐波分量（类似 Fourier 分解）

## Value
- **工作价值**: 在一个受控环境中清晰展示了"predictor 归纳偏置与问题代数结构匹配"的重要性。实验干净、结论明确。但 MNIST mod-10 场景过于简单，距离实际视频/3D 世界模型应用很远。
- **启发**: (1) JEPA 类 latent world model 的 predictor 设计不应只用通用 MLP，应考虑任务的代数/几何结构; (2) 旋转矩阵作为 latent dynamics 的参数化方式在具有周期性/群结构的问题上值得探索; (3) MFR 的多频率分解思路可能推广到更复杂的变换群。
- **待解决**: 能否推广到未知群结构的场景？能否扩展到连续状态空间和高维视觉输入？与实际世界模型应用的差距巨大。

## TL;DR
创新度: 2
相关度: 1

在 JEPA 框架中引入 RoPE 启发的块旋转 predictor 学习 MNIST 模运算，实现 99.46% 零样本泛化，验证了 predictor 归纳偏置与问题结构匹配的重要性。可选读，对 JEPA predictor 设计有启发但实验场景过于简化。
