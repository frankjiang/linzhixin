# EPM-JEPA: Operator-Side Experience Modulation in JEPA-Family World Models

## Insight
论文提出的假设是：JEPA predictor 不应只把经验作为输入残差，而应让历史经验调制 predictor operator 本身。实验证明这个假设只有弱支持：EPM-JEPA 对 EI-JEPA 的预注册提升 4.74%，按作者阈值是 null result；真正有价值的是发现 buffer cycling、EMA drift、LoRA settling 三个动态过程控制峰值表现。

## Motivation
JEPA/V-JEPA 类 latent world model 的 predictor 通常静态，遇到 gravity/friction 等动力学 shift 时缺少在线适配机制。作者比较无记忆、输入注入经验、LoRA 权重调制经验三种路径。问题与隐式世界模型相关，但实验玩具化。

## Method
Moving MNIST 两世界：base world 无重力训练，shift world 有向下重力测试。Encoder 为小 CNN 到 64-d latent，EMA target 提供 k={5,10,20} stop-gradient 目标。Track A Vanilla JEPA 无记忆；Track B EI-JEPA 将聚合经验 eagg 加到 predictor hidden state；Track C EPM-JEPA 用 eagg 生成 per-sample LoRA delta 调制 predictor 两层权重。经验来自 boundary-event buffer，目标含 JEPA prediction loss + VICReg variance hinge。

## Experiment
主指标 Dshift n=50，越低越好。三轨结果：Vanilla 0.8089，EI-JEPA 0.8238，EPM-JEPA 0.7848±0.0078。预注册比较 C vs B 提升 4.74%，低于 5% 阈值，Outcome C/null；非预注册地比 Vanilla best 0.8000 好 1.90%。EPM 峰值在 step 10000 左右，之后退化到 0.826-0.843；freeze ablation 指向 buffer cycling 形成峰值、EMA drift 导致 post-peak divergence、LoRA settling 带来约 +0.021 transient。峰值处 sigma_embed 低于 0.5，显示预测最优与表示多样性有张力。

## Value
对 JEPA 方向的价值主要是负结果和机制分析：简单经验注入无效，LoRA operator modulation 有小收益但不稳定。作为严肃世界模型贡献偏弱，数据和尺度过小；可作为“在线适配 JEPA predictor”思路参考，不建议精读。
