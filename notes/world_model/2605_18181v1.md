# Scalable Environments Drive Generalizable Agents

## Insight
Position paper 提出一个关键观察：当前 agent 的泛化瓶颈不在于数据/轨迹量，而在于环境分布的多样性。Observation: 当底层交互规则（动作接口、转移动态、观测方式、反馈信号）发生变化时，在固定环境中训练的 agent 表现急剧下降。推论：需要 environment scaling（扩展可执行规则集的分布），而非仅 trajectory/task scaling。通过形式化定义三种 scaling 类型并给出判别标准来支撑这一论点。

## Motivation
解决通用 agent 在跨环境泛化上的脆弱性问题。现有 scaling 实践主要集中在固定规则集下收集更多轨迹或扩展任务集，但当底层交互规则变化时 agent 仍然脆弱。这是一个被广泛忽视但非常关键的问题——world-level distribution shift。

## Method
提出统一分类体系，按主要交付物区分三种 scaling：
- **Trajectory scaling**: 固定环境和任务，扩展交互轨迹 p(tau|E,x)
- **Task scaling**: 固定环境规则集，扩展任务分布 p(x|E)
- **Environment scaling**: 扩展可执行规则集分布 p(E)，改变 A/T/O/Y

两种环境构造范式：(1) 程序化生成器——可控可验证；(2) 生成式世界模型——覆盖广泛但需额外验证。提出评估标准：可执行性、信号质量、覆盖度、复杂度、效率。

## Experiment
无实验，纯 position paper。通过案例分析和形式化定义来论证观点。

## Value
对"什么才是真正的环境扩展"给出了清晰的概念框架，有助于厘清领域术语混乱。但作为 position paper 缺乏实证验证。对世界模型研究者的启发：生成式世界模型可以作为 environment scaling 的重要工具，但需要与程序化生成器互补，确保生成环境的有效性和可控性。与视频/3D 世界模型的直接关联有限，更多是 agent 训练视角。

## Strengths
