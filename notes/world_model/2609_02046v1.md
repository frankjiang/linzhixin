# Modeling What Changes: Sparse, Residual World Models for Object-Centric Manipulation

## Insight

有。论文的关键 observation 不是 sparse 模型“更会预测运动”，而是桌面推动中绝大多数物体不动，dense 全状态回归会无端扰动这些静态物体。由此推论：先判断哪个对象会变，再只对这些对象施加残差，能把“原样复制”写进模型归纳偏置，减少 rollout 漂移并给出可检查的 change mask。

证据形成了较完整的反证链：容量匹配 ladder 显示 gate 是最大单步增益；oracle gate 几乎不改善 changed-object L2，说明瓶颈已从检测转为 delta 回归；sparse 的总体误差接近 no-op，但 mover 误差也仅约等于 no-op。因此可靠结论是“检测变化并避免污染静态多数”，而不是“学到了准确物理动力学”。

## Motivation

传统 monolithic world model 每步重预测所有对象，既浪费容量，也会把小误差注入本应不变的状态，并在自回归中累积；单一回归输出还无法直接说明模型认为谁会动。对象中心模型虽共享实体计算，通常仍密集预测每个对象；条件计算虽有稀疏门控，却不直接约束世界状态的变化支撑集。

这是机器人/物理世界模型中真实而重要的问题，尤其适合接触稀疏的操作场景。不过本文只研究已知对象 pose/velocity 的小型 MuJoCo 推动，尚未处理像素感知、遮挡、对象发现和复杂接触，所以解决的是世界模型输出头中的一个局部问题。

## Method

状态包含 pusher 位置、每个物体的平面 pose `(x,y,theta)` 与速度、目标位置；动作是位置控制 pusher 的 delta-xy。dense baseline 为宽 256、3 层 MLP，直接用 L2 回归全部下一时刻 pose。

sparse/residual 模型为每个对象构造其 pose、速度、相对 pusher/goal、动作及其他对象 permutation-invariant aggregate 的特征；共享的 gate 与 delta head 均为 2 层宽 128 MLP。Gumbel straight-through gate 在推理时给硬二值 `g_i`，输出为 `p_i(t+1)=p_i(t)+g_i*Delta_i`，未开启对象被精确复制。损失由类别平衡 BCE change-mask、仅在真变化对象上的 residual L2、以及平均 gate 激活稀疏惩罚组成；预测实验 `lambda_s=0.2`，规划版为 0.05。共享权重且网络尺寸不依赖对象数，因此可直接跨数量运行。

MuJoCo 桌面含 N=3/5/8 个 5 cm box。每个 `(N, seed)` 收集 250x100 步 scripted episodes，并筛出真实运动超过 0.02 m 的 hard subset，按 80/10/10 划分且防止 configuration leakage。规划版改用 contact-aware、去 velocity 特征，并加入 200x80 scripted 与 350x60 random episodes，以覆盖 planner 会访问的状态。CEM 每步采样 256 条、重拟合 3 次、horizon 15、执行首动作，最多 60 步；成功阈值为目标物距 goal 5 cm。

## Experiment

指标包括总体、changed/unchanged object pose L2，change precision/recall/F1，参数/FLOPs/CPU 延迟，自回归 horizon-20 误差、跨对象数迁移和规划成功率。

- 三 seed 单步主结果：N=3/5/8 时 sparse F1 为 `0.867±0.021/0.802±0.024/0.829±0.008`；总体 L2 为 `0.136±0.046/0.101±0.004/0.071±0.016`，dense 为 `0.347±0.053/0.319±0.007/0.329±0.023`，参数少 11.1x/9.8x/8.6x。
- seed-0 ladder 在 N=5 的 dense、object-centric absolute、always-residual、gated sparse、no-op L2 依次为 0.318/0.194/0.171/0.104/0.107；N=8 为 0.354/0.187/0.159/0.081/0.081。N=3 的 unchanged-object L2 沿 ladder 从 0.211 降到 gate 后 0.001，说明总体优势来自静态对象。
- oracle-gate 诊断的 changed-object L2 在 N=3/5/8 分别为：预测 gate 0.312/0.426/0.466，oracle 0.314/0.432/0.474，no-op 0.348/0.446/0.470。完美检测没有救活运动回归，N=8 甚至略差于 no-op。
- horizon-20 rollout 中 sparse/dense/no-op 总体 L2 为：N=3 `0.373/1.241/0.277`，N=5 `0.293/1.097/0.180`，N=8 `0.182/1.170/0.108`。sparse 比 dense 好 3.4-6.4x，却在每个 N 都输给 no-op；mover-only 也大致处于 no-op 水平。
- 跨数量 transfer F1 为 0.827，对角线同数量为 0.832，即保留 99.4%；25% 数据约达到 full-data F1 的 90%。这两项只做 seed 0，且 8-object 布局边界/密度不同。
- 原预测数据下两个 learned model 规划均为 0。针对 planner 分布重训后，sparse 成功率 `0.23±0.06`、最终距离 `0.204±0.019 m`，dense 为 `0.00±0.00`/`0.318±0.021 m`；oracle 为 1.00、scripted controller 0.95、random 为 0.15。每 seed 20 episodes，sparse 最弱 seed 恰为 0.15，因此未显著优于随机，只能稳健声称与 dense 分离。
- 参数效率没有转成速度：FLOP 优势随 N 从 3.8x 降到 1.1x，sparse CPU 延迟约 0.19-0.20 ms，而 dense 约 0.04 ms。

## Value

对对象中心和隐式物理世界模型，最有用的启发是显式分离 change support 与 change magnitude：前者可用于可解释性、稀疏更新和误差控制，后者需要更强概率动力学模型。论文还示范了如何用 no-op、mover-only 和 planner-distribution 数据揭穿“总体 L2 很好”等同于“动力学学得好”的误判。

实际价值目前偏诊断而非控制：gate 确实学会谁会动，模型却没有可靠预测移动量，规划结果也未超过随机显著性。将它接到视觉 slot、视频 latent 或图结构 world model 后是否仍有效，是决定外推价值的关键。

## Strengths

- 方法简单、硬复制语义清楚，change mask 可直接检查，且共享 per-object head 自然支持不同对象数。
- 控制链完整：参数匹配、结构 ladder、稀疏权重 sweep、oracle gate、静/动物体误差、长 rollout、迁移、样本效率和 planner 均有诊断。
- 作者非常诚实地撤回过强表述，明确指出总体收益来自静态多数、no-op 在 rollout 更好、规划未显著胜随机。
- 代码、数据生成器、checkpoint 和机器可读结果公开，实验规模可在单台笔记本复现。

## Weaknesses

- 缺少同样在完整状态上预测 residual 的 dense MLP；作者承认这使“monolithic vs object-centric”与“absolute vs residual”归因混杂，是最关键基线缺口。
- changed-object 单步和 rollout 误差仅约 no-op 水平；模型本质上是好的 change detector，不是准确的 mover dynamics predictor。
- F1 对 ungated baseline 的定义有偏：以极小阈值切回归 delta 会强制 recall 约为 1；deadband/PR sweep 后差距仍在但缩小，故 F1 不能单独支撑主张。
- 规划只含 3 objects、单一 push-to-goal 与单一 CEM；`0.23±0.06` 不显著优于随机 0.15，且依赖为 planner states 重新造特征、补数据。
- 输入是已结构化 pose/velocity，而非 pixels；不含对象发现、遮挡和视觉误差。部分迁移/样本效率分析仅 seed 0，8-object 几何也未严格控制。
- 少参数并未更快，per-object 执行使 CPU 实测约慢 5 倍。

## Future Work

作者明确提出补齐参数匹配的 dense-residual baseline；用 distributional delta head 改善接触/旋转的不确定运动；用 DAgger 覆盖 planner 访问分布；加入 multi-step training；以 slot-based encoder 去掉人工结构化状态假设。进一步应在像素对象发现、更多交互任务和闭环控制上检验 gate 是否仍稳定。

## Rating

创新度评分：2/5 - 对象级硬 gate 加 residual 是合理但简单的增量设计；诊断很扎实，然而运动回归近 no-op、关键 dense-residual 基线缺失，技术贡献有限。
相关度评分：2/3 (Related) - 属于对象中心物理 world model 和 model-based planning，可借鉴其稀疏更新；但不是视频/3D 表征，也非 JEPA/Dreamer 式 latent 学习。

## TL;DR

以对象级变更门控和残差复制静态物体，显著抑制漂移却未学好运动动力学，相关方向可选读。
