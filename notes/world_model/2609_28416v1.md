# Agent-Editing World Model: Rethinking World Modeling for LLM Agents

## Insight
观察：即使工具返回真实反馈，语言智能体仍可能把未经证实的猜想、过时计划写入后续推理，形成“任务状态污染”。作者据此主张预测**当前推理／行动对任务进展的作用**，在执行前直接修订低价值续写；六任务结果与消融支持此干预有效，但未从反事实轨迹证明污染是收益的唯一成因。

## Motivation
既有语言世界模型预测搜索、终端等工具返回；这些反馈受实时环境影响且可直接调用，精确仿真价值有限。论文改为解决长链任务中的证据误读和计划漂移；对 LLM 智能体很重要，但问题与视频、3D 或 JEPA／Dreamer 式隐式环境动力学不同。

## Method
AEWM 读取历史及智能体拟提交的“推理＋工具调用”。Action Judge 将该决策判为关键、探索或噪声；只有噪声触发 State Revision，从同一已观测历史生成替代推理与行动。EditAct 执行替代行动，把真实工具反馈写回历史；AEWM-RFT 再用经验证的修订轨迹微调原智能体。训练先用搜索、终端、软件工程轨迹及合成标注做约 52.16B token 中训，再用 12 万条 Judge／Revision 样本 SFT。实质是带门控的过程判断和行为修订，没有学习环境状态转移或视觉潜变量。

## Experiment
- 3,000 决策的 Action Judge 基准：总体 macro-F1 **70.5%**，最强对照 DeepSeek-V4-Pro **59.9%**；但标签源于模型对成功轨迹的回顾，辅以另一模型审查，缺少独立人工金标准。
- 搜索、Terminal-Bench 2.0、代码任务共六基准、三种 Qwen3.5 智能体；EditAct 相对最强 Best@3 基线的六项均分提高 **6.7／5.2／3.2** 分（4B／9B／35B-A3B）。消融显示随机触发、重采样、只改行动或推理、提示式反馈均弱于完整方案。
- 无在线 AEWM 的 AEWM-RFT 相对同数量 Self-RFT 轨迹，在 BrowseComp、Terminal-Bench 2.0、Doc2Repo 分别再增 **2.2／2.6／2.5** 分；搜索和终端平均步数下降，Doc2Repo 步数反而上升。附录案例展示纠正搜索假设、诊断终端状态和维护代码契约。

## Value
对“观测真实却仍误更新内部信念”的失败模式有启发，可供设计语言智能体的验证／修订环节参考。对视频、3D、隐式世界模型没有直接的状态表征、动力学建模或规划方法贡献。

## Strengths
明确区分有用探索与噪声行动；修订后执行真实工具而非伪造反馈；跨三领域、六基准和三种代理规模评估，并控制 RFT 样本数与训练设置。

## Weaknesses
“世界模型”的预测目标是主观三分类，随后由语言模型改写行动，缺少显式未来状态／回报预测。训练和评测标签主要依赖模型回看单条已实现轨迹，存在标注偏差，不能估计同一行动的反事实价值。52B token 训练和每步额外判断／修订代价高，论文未报告统一的推理成本收益；搜索答案还使用 LLM 裁判。

## Future Work
作者未明确提出后续研究方向。

## Rating
创新度评分：2/5 - 门控判断、行动修订及轨迹蒸馏的组合有实证价值，但相对已有过程监督／自我修订属增量；对目标世界模型方向无方法突破。
相关度评分：0/3 (Noise) - 全文研究纯语言工具智能体，不涉及视频、3D 或 JEPA／Dreamer 式环境动力学。

## TL;DR
AEWM用动作判别与推理修订改善语言智能体长链任务，但不建模视觉或三维环境；本方向可跳过。
