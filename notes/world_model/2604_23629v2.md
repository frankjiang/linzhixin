# From Visual Synthesis to Interactive Worlds: Toward Production-Ready 3D Asset Generation

- **arXiv**: 2604.23629v2
- **Authors**: Jiafeng Wu, Zhuofan Lou, Jian Liu, Dazhao Du, Chunchao Guo, Song Guo (HKUST, HUST, Sichuan Univ, Tencent)
- **Date**: 2026-04-26

## Insight
3D内容生成已从生成视觉上合理的形状进展到构建可部署在实时交互环境中的结构化资产，但生成输出与production-ready标准之间仍存在持久的"assetization bottleneck"。

## Motivation
游戏开发、具身AI、世界仿真、数字孪生和空间计算都需要满足引擎级约束（拓扑、UV参数化、PBR材质、骨骼绑定、物理感知布局）的3D内容，但现有方法输出与此标准之间差距显著。

## Method
- 围绕资产制作管线（而非算法族）组织文献的综述
- 二维分类法：
  - 横轴（资产层级）：通用物体/道具、角色/化身、场景/环境
  - 纵轴（制作生命周期）：数据基础 -> 几何合成 -> 拓扑优化 -> UV展开 -> PBR外观 -> 骨骼绑定 -> 场景组装
- 定义Production-Ready的6项标准：流形网格拓扑、非重叠UV、解耦PBR材质、骨骼绑定/蒙皮、后生成可编辑性、物理元数据
- 综合评估指标和协议

## Experiment
无新实验，为综述论文。

## Value
全面的3D资产生成综述，按制作管线而非算法族组织。虽提及世界模型作为应用场景，但核心关注3D内容制作。与视频/隐式世界模型关系不大，对3D世界模型的资产供给有间接参考价值。
