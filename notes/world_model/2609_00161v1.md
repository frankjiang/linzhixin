# IMPACT: Attention Is the Interaction Map for Scalable Interaction-Aware World Model Training

## Insight

Observation：action-conditioned 视频世界模型用全局平均 MSE/flow-matching loss 时，梯度贡献取决于区域面积；静态背景占据大多数 token，真正承载接触、受力和状态变化的小型交互区反而被稀释。进一步观察到，预训练 DiT 的“被操作物体”文本 token cross-attention 已提供粗糙的时空定位先验。论文据此推论：无需光流、深度或分割标注，只需用当前局部预测误差校准该内部先验，再把有限监督预算重分配到交互区，就能提高物理交互质量。组件消融支持这一推论：在 Wan 2.2-AC 上直接加区域加权将 EWMScore 从 58.65 提至 61.54，attention sampling/calibration 再提至 62.46；但论文只展示一个定位案例，没有定量验证 interaction map 的召回率，因而是经验性证据而非严格证明。

## Motivation

现有 embodied video world model 能生成清晰视频，却常出现物体形变、接触断裂、动作与结果脱钩。同行通常额外引入 optical flow、point trajectory、depth、3D reconstruction 或 hand mesh 来约束动态，这些 dense representation 需要外部估计器或人工标注，成本和误差随数据规模增长。IMPACT 将问题从“还缺什么外部条件”改写为“标准 denoising objective 是否把监督放错了位置”。这是视频世界模型的关键训练问题：若交互区域在全局 loss 中长期欠优化，扩大数据和 backbone 也未必转化为更可靠的物理模拟。

## Method

基础模型是 latent video diffusion transformer：VAE 将视频压缩为时空 latent，DiT 预测 flow-matching velocity。训练前用冻结的 Qwen2.5-0.5B 仅根据指令抽取被操作物体 noun phrase，并对齐到文本 token；不读取图像，也不引入视觉标注。

Attention Distribution Sampling（ADS）在选定 cross-attention 层/头上聚合这些 object tokens 的注意力，detach 后以 `κ=0.65` temper；在 `5×8×12` 粗网格加入噪声，采样 `K=8` 个平滑候选，每个保留得分最高的 10% 时空位置。候选区以 detached 局部 denoising error 打分并 softmax 加权，汇成 interaction map。Interaction-Weighted Supervision（IWS）用 `w=1+(γ-1)G`（`γ=5`）重加权每个 latent token，同时按总权重归一化，保留全局监督而非只做 masked loss。

为避免 attention 为迎合自身产生的区域 loss 而塌缩，作者做梯度路由：cross-attention 参数只接收原始全局 MSE，其他 DiT 参数只接收 IWS，通过两次 backward 和 parameter hook 实现。ADS/IWS 均仅用于训练，推理架构不变。创新点是把模型内部语义 attention、在线误差校准和梯度解耦组合成 training-only 的监督分配机制；各组件本身不新，但问题重述和闭环设计较清楚。

## Experiment

机器人臂设置使用约 35 万段 RoboTwin 双臂模拟视频、17 帧和 14-DoF action trajectory，测试 Wan 2.2 TI2V 5B 与 Cosmos-Predict 2.5-2B；人手设置使用 EgoDex 约 25.6 万个 81 帧 clip、118 个任务，以渲染的 3D hand-pose video 为条件。两类模型均在 720p、8 GPU、有效 batch 32 下训练 1 epoch，IMPACT 超参数固定。

WorldArena 在 50 个任务的 500 个 held-out episode 上用 16 个自动指标组成 EWMScore，并报告视觉、运动、内容一致性、物理、3D 与可控性。Wan 2.2-AC 从 58.65 提至 62.46，其中 motion 48.23→53.28、physics 53.41→55.87、3D 86.16→92.56、control 54.40→60.00。Cosmos action 从 55.91 提至 62.53，motion 38.89→68.22、control 49.51→71.19；但 visual 57.87→56.32、content 68.73→57.90、physics 42.23→41.82、3D 82.53→77.99 同时下降，整体增益存在明显指标权衡。其 Action Following 从 0.0133 跃至 0.6260，对均值贡献很大。

EgoDex 上，相同 Wan 2.2-AC backbone 加 IMPACT 后 FVD 366.12→110.94、FID 44.71→5.79、CLIP-Hand 0.921→0.952、Hand IoU 0.693→0.772，均为表中最佳。定性图显示抓取/堆叠接触区更锐利、目标漂移更少。唯一主消融是 `baseline 58.65 → +IWS 61.54 → +IWS+ADS 62.46`；未报告随机种子、方差、超参数敏感性、梯度路由消融、训练额外算力，亦没有用真实 mask 衡量 interaction-map 定位质量或用生成 rollout 做策略学习/闭环控制。

## Value

IMPACT 提供了一个很实用的视角：world model 的瓶颈可能不只是数据和容量，而是 loss 在时空 token 间的预算分配。用内部 attention 做弱定位、用模型误差做难例校准、把估计器与被估计目标的梯度解耦，这套设计可迁移到游戏交互、驾驶和更长视频，也可与显式几何监督互补。当前证据证明的是更好的离线视频指标，不是更准确的可规划动力学；要成为可靠模拟器，仍需验证 rollout error、counterfactual action sensitivity 和下游控制收益。

## Strengths

问题定义具体，且不增加推理成本或外部 dense annotation；在两个 DiT backbone、机器人臂/人手两种交互、action trajectory/pose video 两类控制信号上都有同 backbone 对照。训练设置与数据构造披露较完整，WorldArena 还给出 16 个细分指标，能看出总分背后的收益与退化。IWS/ADS 消融明确表明主要增益来自监督重分配，attention calibration 提供额外但较小的收益。

## Weaknesses

“静态区域主导导致交互欠监督”没有通过区域梯度占比或真值交互 mask 系统验证，interaction map 也只有单例可视化。主消融不够：缺少 `K/ρ/γ` 敏感性、随机/误差-only/ground-truth region 对照以及梯度解耦的必要性测试。没有 seeds、置信区间和训练 wall-clock/memory overhead，故“scalable”主要是无需外部标注的推断。WorldArena 多数指标依赖 pretrained estimator 或 Qwen3-VL 判断；Cosmos 的内容、物理和 3D 分数下降却被 Action Following 大幅上升掩盖，单一均值可能高估整体改进。实验只评估短视频和离线生成质量，没有长时自回归、真实机器人、闭环 policy evaluation；方法还假设指令明确写出被操作物体，对多对象、隐式指代和非语言 action 的适用性未验证。

## Future Work

作者未单列未来工作，只强调方法可扩展到更多数据且不改变推理。最需要补充的是：定量评估 interaction-map 定位与监督分配机制；测试长时 rollout 和下游 planning/policy learning；加入多对象、遮挡、隐式指令及真实机器人；报告训练开销、统计方差与质量—物理—可控性 Pareto，而不是只看聚合分数。

## Rating

创新度评分：3/5 - 将 object-token cross-attention、局部误差校准和梯度解耦用于交互区 loss reweighting，问题重述有洞察且跨设置有效；核心仍是训练损失加权，机制验证和闭环证据有限。
相关度评分：3/3 (Core) - 直接研究 action-conditioned 视频世界模型的交互与物理一致性训练，是视频 world model 核心问题。

## TL;DR

用物体注意力和局部误差重分配视频世界模型监督，交互指标显著提升但无闭环验证，值得精读。
