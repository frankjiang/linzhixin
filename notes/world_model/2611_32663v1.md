# Economic World Model

## Insight
论文将经济系统形式化为局部观测的多主体策略与宏观状态转移的循环，指出微观行为拟合、宏观预测和政策反事实应分别评估；这是建模框架的主张，未给出与视频/3D/JEPA 世界模型相关的技术洞见。

## Motivation
传统宏观计量、DSGE/HANK 和主体仿真在行为异质性及政策反事实间各有取舍。作者试图用微观家庭数据和结构经济转移模型统一消费、劳动和宏观指标模拟。问题对经济学重要，但偏离用户的计算机视觉与隐式世界模型方向。

## Method
把经济建模写成部分可观测马尔可夫博弈：家庭等主体据局部观测选择行动，结构化转移函数依据联合行动更新经济状态。初版从美国消费者支出调查训练家庭消费与劳动策略，用宏观时间序列校准生命周期经济转移，并以微观误差、群体分布、宏观预测和借贷政策反事实做分层评估；还把仿真器供 LLM 政策代理预演。没有视频生成、3D 几何或 JEPA 式潜在预测算法。

## Experiment
家庭策略用 CEX 2014–2018 训练、2019 验证、2020–2024 测试；消费和劳动测试个体水平 NRMSE 分别 0.546、0.521，动态变化 NRMSE 为 0.883、0.942。家庭消费分布重叠率 94.9%；宏观部分用美国 2014–2025 数据，与 Gertler 生命周期模型比较 GDP 预测和政府借贷冲击的短期传播。疫情冲击下，使用 EWM 预演的 LLM 政策相对直接决策提高模拟 GDP 10.29%。这些指标不评估视觉世界建模。

## Value
仅有跨领域的“微观—宏观与反事实分层评估”类比价值；对视频、3D、隐式世界模型方法设计或评测无直接参考意义。

## Strengths
明确区分个体行为、群体分布、宏观预测和政策反事实，并报告跨年份测试与经济基准模型。

## Weaknesses
仅一个美国生命周期借贷案例；结构经济机制主导结果，不能据此证明通用经济世界模型已被学习；政策收益在模型内模拟，缺少真实政策外部验证。与用户研究范围不符。

## Future Work
作者建议加入更真实的经济机制、企业与银行等主体，跨国家和问题验证，以及更强的数据驱动行为与转移学习。

## Rating
创新度评分：1/5 - 对本研究方向无新技术贡献；主要是经济建模框架与既有方法的结合。
相关度评分：0/3 (Noise) - 经济系统建模，不涉及视频、3D 或 JEPA/Dreamer 类世界模型。

## TL;DR
用家庭行为策略和结构经济转移模型模拟宏观走势及政策反事实，属于经济学世界模型；与本研究方向无关，可跳过。
