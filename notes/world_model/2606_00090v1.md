# Silent Failures in Physical AI: A Literature Review of Runtime Action Authorization for Autonomous Systems

## Insight

**核心 Insight：** 模型置信度不等于安全性（Confidence Is Not Safety）。一个 Physical AI 系统可以在内部表征已经失效的情况下，仍然以高置信度输出看似合理但物理上不安全的动作——这种「静默失败」无法被传统的语义 guardrail 或模型置信度信号捕获。

**推论：** 需要一个独立于模型的 runtime action authorization 边界层，在模型输出与物理执行之间评估四个条件：(1) 世界状态是否可靠，(2) 动作是否物理可行，(3) 是否满足任务/操作约束，(4) 决策是否可事后审计。现有文献中的 11 个研究流（VLA、世界模型、安全 RL、CBF、OOD 检测等）各自覆盖了 authorization event 的部分维度，但没有任何一个提供完整的 runtime authorization 边界。

**证明方式：** 综述性证明——通过系统化文献分析，构建 guardrail 分类法（7 类功能：语义有效性、状态有效性、物理可行性、时空约束、时间有效性、fallback 权限、可审计性），并用 Table 2 的假设映射表揭示各文献流在接口假设上的结构性缺口。

## Motivation

**问题：** Physical AI（机器人、自动驾驶、无人机等）系统的模型输出日益直接转化为物理动作，但模型输出的「流畅」和「合理」不等价于物理安全。静默失败——系统在世界状态已失效的情况下仍继续操作——是一个跨领域的系统性安全问题。

**同行做法：** 安全 RL 和 CBF 假设已知动力学和显式状态；语义 guardrail 评估语言意图但不验证物理可行性；VLA benchmark 测量任务成功率但不评估 action authorization；OOD 检测标记分布偏移但不决定 fallback 动作。

**是否关键：** 对 Physical AI 部署安全性是关键问题，但对世界模型的模型设计/训练方法层面不是直接关键。

## Value

**整体价值：** 概念清晰度高，对 Physical AI 安全性研究提供了有用的概念框架和文献地图。但作为综述，不提供新方法或实验验证。

**对我们的启发：**
- 世界模型作为 Physical AI 系统的核心组件，其预测/状态估计的可靠性直接影响 action authorization 的有效性。论文指出世界模型和预测性架构在 state validity、uncertainty 和 formal guarantees 方面仍有显著缺口（Table 2）。
- 这提醒我们在设计世界模型时需要考虑状态估计的不确定性量化和可审计性。
