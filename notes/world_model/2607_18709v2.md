# RoboInter1.5: A Holistic Intermediate Representation Suite for Embodied World Modeling and Robotic Manipulation

## Insight
核心 insight 是 intermediate representations 不只是可解释标注，而是连接 embodied reasoning、action execution 和 future simulation 的双向接口：它们既能约束低层动作空间，也能约束世界模型的 latent rollouts。对长时程视频世界模型来说，语言太粗、低层 action 太 embodiment-specific，Seg+Trace 这类视觉化中间表示能提供更稳定的空间/时间 scaffold。

## Motivation
VLA 和 embodied world models 都需要从语义指令走向物理交互，但现有机器人数据集通常只有图像、语言和动作，缺少 per-frame 的对象、gripper、affordance、contact、trace、subtask 等结构标注。单一自动标注方法又容易分布外失效或时间错位。本文试图构建大规模、高密度、动作对齐的中间表示数据，并验证这些表示能提升 VLM reasoning、VLA execution 和 world model future prediction。

## Method
RoboInter-Data 汇集 DROID、RH20T、OXE 等 teleoperated videos，经过 RoboInter-Tool 半自动/人工校验，形成 230k manipulation episodes、571 scenes、6 robot arms、15 primitive skills，包含约 61M frame object grounding、70M frame gripper trace、190k affordance/placement proposals 和 760k language clip annotations。RoboInter-VQA 将这些标注转为 9 类 spatial 和 20 类 temporal VQA，用于训练 RoboInter-VLM Planner。RoboInter-VLA 使用 Planner+Executor plan-then-execute，包括 IC-E2E、EC-E2E 和 Modular 三种范式。RoboInter-World 是 latent video diffusion/DiT 世界模型，输入历史 latents、language、可选 action，以及由 segmentation/object points 和 gripper traces 渲染成黑底 control video 的中间表示，预测未来 RGB latent。作者还测试 world model predicted latents 是否能直接作为 VLA action head 的未来状态条件。

## Experiment
Planner 在 Where2Place、RoboRef It、RoboVQA 和自建 RoboInter-VQA 上显著超过 base VLM；例如 RoboInter-Qwen-7B 在 RoboVQA 达 74.4，RoboInter-LLaVAOV-7B 达 74.5。VLA open-loop 中，Vanilla mOLS 0.3086，IC-E2E 0.3218，EC-E2E 0.3340，Te-Modular 0.3543，Oracle+Executor 0.3861；中间表示消融显示 Trace 带来最大增益，完整组合 OLS@0.05 从 0.3608 提到 0.4640。真实 Franka TableTop 中，IC-E2E ID/OOD 平均成功率 77.3%/58.3%，高于 Vanilla 65.0%/38.3%；EC-E2E OOD 平均 60.0%，ID-to-OOD drop 更小。World modeling 中，14B LoRA action-only RoboInter-W 为 PSNR 18.26、SSIM 0.750、LPIPS 0.171；Seg+Trace 提升到 PSNR 21.05、SSIM 0.810、LPIPS 0.102。planner-control 虽低于 oracle-control，但 14B 仍有 PSNR 20.17，显著好于 action-only 18.26。VLA+RoboInter-W predicted latents 在 OLS 各阈值上稳定优于 no-WM 和 I2V-baseline，接近 GT latent 上界。

## Value
这是 embodied/video world model 方向的核心资料型工作。最有启发的是把中间表示视觉化为 control video，而不是仅用坐标 MLP 或语言 CoT；这对长程 action-conditioned video generation、机器人世界模型可控性和世界模型辅助策略学习都有直接参考价值。它也提示世界模型输出的 latent 需要“actionable physical priors”，否则给 VLA 可能只是噪声。

## Strengths
数据规模和标注类型丰富，覆盖 reasoning、control、simulation 三类下游任务；World 部分不只报告视频指标，还测试 predicted future latents 对 VLA action accuracy 的作用；oracle-control/planner-control/action-only 的比较比较清楚；真实机器人闭环给了 VLA 部分的实证支撑。

## Weaknesses
论文覆盖面很大，单个模块的机制分析相对浅。RoboInter-World 的评价主要是视觉生成指标和 open-loop action accuracy，缺少直接用生成未来做闭环规划的成功率。控制视频来自高质量标注或 Planner 输出，真实部署时 Planner 错误会累积。数据构建依赖大量人工/半自动流程，复现成本高。相比新架构，世界模型创新主要是中间表示控制方式。

## Future Work
作者没有单独展开未来工作，但从结论和实验可见后续方向包括：扩展更多中间表示和场景，提升 planner-control 的鲁棒性，把 RoboInter-World 更直接接入闭环 VLA/规划，并进一步验证跨 embodiment、长 horizon 和真实物理泛化。

## Rating
创新度评分：3/5 - 大规模中间表示数据和 control-video 世界模型很有价值，但世界模型方法本身偏工程组合。
相关度评分：3/3 (Core) - 直接研究 embodied world modeling、机器人视频未来预测和中间表示约束。

## TL;DR
RoboInter1.5用密集中间表示约束VLA与视频世界模型，核心相关，值得精读。
