# Testing Frontier Large Language Models' Physics Literacy in Parallel Physical Worlds

## Insight
论文 insight 是：物理理解不能只看答案准确率，要拆成 induction、formulation、prediction、review 四个 cognitive move。作者通过反事实物理世界发现，模型经常能说对定性方向，却在定量比例上回落到标准物理关系；自我审查也常过度声称自己无错。这说明 LLM 的“物理世界模型”更多是语言/模板层面的，而非可外化的形式理论。

## Motivation
现有物理 benchmark 多是题目准确率，无法区分真实理论归纳与训练集中相似题型的 recall。作者希望测试 LLM 能否从陌生现象归纳出可检查的理论系统，并做新情境预测。该方向与“world model 是否有物理理解”概念相关，但论文核心是 LLM 科学推理诊断，不是视觉/3D/隐式世界模型方法。

## Method
提出四阶段诊断：Stage 1 从观察归纳规则；Stage 2 转写为可操作 formulation；Stage 3 做定量/定性预测；Stage 4 自我 review。协议包括 locked pre-registration、阶段间 fresh sessions、dual-LLM judging 和人工 audit。测试三个 parallel physical worlds：单方程反事实 F=mv、历史 Aristotelian mechanics、四领域 Decay World，并为每个世界定义必要条件、失败触发、结构轴和 over-claim 轴。

## Experiment
模型包括 Claude Opus 4.7、GPT-5.5、Gemini 3.1 Pro，各世界每模型 5 次。F=mv composite PASS 6/15：Claude 3/5，GPT 2/5，Gemini 1/5；失败点各异，Claude 常 formulation 失真，GPT 规则正确但结构冗余，Gemini 常把 F=ma 带回。Aristotelian 也是 6/15，主要是 training-prior leak。Decay World 为 0/15，60 个 Stage 3 定性方向全对，但 23/60 定量比例泄漏到标准物理关系；Stage 4 failure-containing trials 的 over-claim 率高。

## Value
对世界模型研究的间接启发是：评估应拆解“状态/规则归纳、可操作建模、预测、错误自知”，而不是单一 accuracy。但它不涉及视频/3D生成、机器人控制或 JEPA/Dreamer 技术，且部分时代设定和模型名称需要谨慎看待。可跳读作为 evaluation methodology 参考。
