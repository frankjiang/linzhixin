# RubricWorld: World Model-Guided Rubric Optimization for LLM Graders

## Insight
观察：只看评分准确率会掩盖一次 rubric 修改同时纠正和引入的错误，而且同一修改在不同当前 rubric 下效果相反。推论：把评分边界上的纠错率/退化率作为状态条件编辑效果来预测，可更有效筛选候选修改；独立留出集再决定是否采纳。作者用编辑效果误差和分数消融验证这一点。

## Motivation
固定 LLM 的自动评分可通过改 rubric 提升，但每个候选都重新批改大量答案开销高，且多轮编辑可能累积坏影响。这是文本评分规则优化问题，并非视觉或物理世界建模。

## Method
将每个序数分数拆成相邻评分边界上的二分类决定；对同一答案编辑前后配对计数，得到各边界纠错率和退化率。状态含当前 rubric、历史编辑效果及当前答案评分摘要；由编辑文本嵌入和状态嵌入交互，五模型集成预测候选效果和分歧。每轮从五个局部编辑中选预期纠错高、退化低的一项做真实评分；独立逐轮留出答案用单侧二项置信界检查是否接受。拒绝的编辑也成为训练数据。此处“world model”预测的是文本评分规则变更，不是环境动力学。

## Experiment
三个教育评分数据集 EIR、ASAP2.0、ASAP-SAS，三种冻结 grader，5 轮、3 随机种子，并分析 20/100 轮。指标为准确率、QWK、macro-F1、预测纠错/退化 MAE、token 成本。27 个数据集-模型-指标组合中 20 个最佳；ASAP2.0 上 gpt-5-mini 准确率从原 rubric 的 18.20% 到 46.70%，QWK 从 13.55 到 45.10。去掉状态时三模型平均 QWK 38.43→33.16，去掉学习预测器为 24.85。置信界采纳相对经验门控使观测退化 7.8%→3.2%，QWK 略降 46.0→45.1。不同数据集收益并不一致，token 成本也不总是更低。

## Value
对一般顺序决策中的“预测效果+独立验收”有抽象参考价值，但与视频、3D、隐式世界模型的表示、动作或评测几乎无关。

## Strengths
区分纠错与新增错误；对多轮状态依赖和拒绝样本的学习有清晰设计；覆盖不同 grader、预算及长轮次分析。

## Weaknesses
依赖人工参考分数与足够多的各分数档样本；置信界仅逐编辑有效，跨多轮整体保证需额外分配显著性；教育评分数据不能代表其他任务，文本标签有效性和公平性未解决。

## Future Work
扩展到开放领域判断或持续更新任务，并检验稀有分数档下的可靠验收和跨轮次统计保证；作者没有提出与视觉世界建模相关的方向。

## Rating
创新度评分：1/5 - 对目标世界模型方向没有新技术贡献；只是将“世界模型”概念用于 rubric 编辑效果预测。
相关度评分：0/3 (Noise) - 研究对象是 LLM 评分规则的文本优化，没有视频、3D 或隐式环境动力学。

## TL;DR
学习预测 rubric 编辑对 LLM 评分的纠错与退化，再用留出集验收；属文本评分优化，与研究方向无关，可跳过。
