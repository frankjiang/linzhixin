# Successive Capacity Growth: Task-Complexity-Driven Width and Depth Expansion for Vision Transformer Encoders in JEPA World Models

## Insight
核心观察是：JEPA 的预测损失进入平台期时，未必需要一开始就部署大编码器；若扩容操作严格保持当前函数不变，就可以把“是否缺容量”变成一次可回滚的在线试验。SCG 先试加 attention head，再试加 Transformer block，只保留能在短窗口内降低预测损失的改动。作者用扩展权重的块结构说明新 head 的输出初始为零、投影器忽略新增维度，新 block 的 attention/MLP 残差初始为零，因此扩展前后映射相同；6 次验证中 loss、CLS 和 block 输出差异均为 0。这个“安全试错”思路成立，但“宽度对应低层语义、深度对应高阶语义”的进一步解释只由极少数 seed 的行为支持，并未被证明。

## Motivation
LeWorldModel 等 JEPA world model 通常固定使用 ViT 编码器：简单任务会浪费参数，复杂任务又可能容量不足。已有 progressive growing、Net2Net、bert2BERT 和 Transformer function-preserving expansion 分别解决预定扩展或安全初始化，却没有根据在线 world-model 预测误差决定何时扩、扩什么。按任务需求增长容量是有价值的效率问题，但本文尚未证明它对 world model 最终规划质量同样关键。

## Method
模型沿用 LeWM：图像经 ViT 得到 (z_t)，MLP predictor 由 ((z_t,a_t)) 预测 (z_{t+1})，训练目标为 next-embedding MSE 加权 SIGReg（λ=0.1）；SIGReg 约束投影表征接近各向同性高斯以防 collapse。SCG 从 1 head、2 layers、(d_{model}=64) 的 283K 编码器开始：若最近两个 epoch 的 prediction loss 相对前两个 epoch 改善不超过 2%，判为平台期。

扩容按固定顺序进行。width expansion 增加一个 64 维 head：复制首个 head 的 QKV 和部分 embedding/MLP 权重，把新 head 的 output projection 及 projector 新列置零；depth expansion 插入 output projection 与 MLP 第二层均为零的残差 block。每种候选训练 2 个额外 epoch，若 (L_{pred}) 攟善超过 2% 则保留并 cooldown 2 epoch，否则连同 Adam 状态回滚；width 失败后再试 depth，两者都失败即永久标记 converged。试验 epoch 不计入各配置共同的 50 个 effective epochs。

方法主要是 Net2Net 式扩容、loss plateau trigger、rollback 与 SIGReg 的组合，工程设计清楚，但不是新的 JEPA 目标或世界动态模型；固定 2% 阈值和 width-first 搜索也不是真正“无超参数”的容量选择。

## Experiment
实验仅含三个确定性合成环境：Two-Room（2D state）、Push-T（5D）和 30-Object Dynamics（60D），每个 200 episodes×200 steps、只用 30% 数据，比较 Fixed Small（283K）、Fixed Large（3 heads/12 layers，5.7M）与 SCG，3 个 seeds，主指标只有 latent prediction loss。

平均结果为：Two-Room 上 0.000547/0.000279/0.000362（Small/SCG/Large），SCG 比 Small 低 49%；Push-T 为 0.003775/0.003534/0.003059，SCG 仅改善 6.4% 且不及 Large；30-Object 为 0.008368/0.006666/0.005080，SCG 改善 20.3% 但仍不及 Large。所谓 56× parameter efficiency 比较的是每新增参数带来的 loss reduction，并非训练吞吐或总算力。扩展行为很不稳定：Two-Room 只有 seed 42 加宽，30-Object 只有 2/3 seeds 加深，Push-T 全部不扩；其余平均收益也包含“未扩容但随机训练结果更好”的 runs。

功能保持实验对两类扩展、两个数据集、三个 seeds 均得到 post/pre loss ratio=1、absolute/CLS/block difference=0。消融声称用 total loss 会因 SIGReg 波动产生误扩，而 (L_{pred}) 在 9 runs 中为 0 false positive；有效秩在 2D/60D 都约为 3，不能作为 trigger。论文没有报告方差、置信区间、规划成功率、真实视觉任务、扩展次序/阈值敏感性或实际 wall-clock/显存收益。

## Value
最可借鉴之处是把动态架构搜索做成“保函数候选变换 + 短期验证 + 完整优化器回滚”，可用于小型隐式世界模型的持续学习与预算控制。当前证据只说明某些 toy task 的表征预测误差可受益，不能推出任务维度决定 width/depth，也不能推出对规划或大模型有实用收益。若用于我们的方向，应优先在真实视频 JEPA、非平稳任务序列和下游 control success 上验证，并把搜索成本计入总预算。

## Strengths
- 扩容前后函数严格一致，且回滚模型与优化器状态，避免架构手术造成瞬时遗忘。
- 从 prediction loss 而非混有正则波动的 total loss 做决策，trigger 与任务目标较一致。
- 报告逐 seed 的扩展事件而非只给平均值，能看出策略的不稳定性。
- 参数、训练设置、代码和复现清单较完整。

## Weaknesses
- 全部证据来自三个小型确定性合成环境、每项仅 3 seeds；没有真实视频、随机动力学、迁移或大规模 ViT。
- 只优化并评估训练所用的 (L_{pred})，没有独立 validation/test loss，更没有 LeWM 的 CEM 规划成功率，存在 trigger 与评价同源的问题。
- 论文把 attention-map cosine similarity ≈0.0001 解释为“近乎相同、冗余”；按通常 cosine similarity 定义，近 1 才表示相同，近 0 表示近似正交。若作者实际使用 cosine distance，则术语和结论需更正。
- “width=独立低层语义、depth=高阶交互”仅从一个 width seed 和两个 depth seeds 事后解释；没有 ground-truth factor probe、替换搜索顺序或 matched-capacity 对照。
- 2% 阈值、2-epoch 窗口、width-first 顺序、cooldown 和永久停止均是会改变结果的超参数，称其 task-agnostic 不等于无需调参。
- SCG 的平均提升不能全归因于扩展：多次 run 根本没有扩容，却与单独训练的 Fixed Small 有不同终值；未报告 paired statistics。
- “56× 效率”只按参数增量/损失增量计算，忽略失败试扩、rollback、训练时长和扩宽后每层计算增加。

## Future Work
作者提出在真实复杂视觉数据上验证、接入完整 LeWM 规划管线、扩展到 ViT-Base、加入任务变简单时的 pruning，并结合 input-dependent 动态深宽机制。更关键的补充应包括独立验证集 trigger、阈值与搜索顺序敏感性、多任务连续变化，以及以累计 FLOPs 和下游控制收益衡量是否真的节省资源。

## Rating
创新度评分：2/5 - 保函数扩容、平台期触发和回滚的组合有一定实用性，但核心部件多源自既有方法，且 toy 实验、指标闭环和关键解释错误使贡献仍属增量。

相关度评分：3/3 (Core) - 直接针对 JEPA world model 的视觉编码器、抗坍塌表征和动态容量，属于隐式世界模型核心议题。

## TL;DR
以保函数试扩展和回滚按需增长 JEPA 编码器，实验过小且论证有误，可选读。
