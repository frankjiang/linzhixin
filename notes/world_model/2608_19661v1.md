# World-Model-Grounded LLM Planning for AUV and ASV Navigation Near Offshore Wind Farms

## Insight
LLM 擅长给出语义动作骨架，却不能判断动作持续时间和水动力后果；让 LLM 只调用一次生成 macro sequence，再用可微物理残差模型优化 duration，可把语言层与动力学层解耦。MPC 重规划的 trust-region guard 在最难 AUV slalom 中把到达率从 10% 提至 100%。

## Motivation
海洋机器人近风机导航受推力滞后、耦合、流/风漂移影响，纯语言规划易碰撞；同时希望一套规划结构覆盖 6-DOF AUV 与非完整 3-DOF ASV。问题实用，但与学习型隐式/视频世界模型联系有限。

## Method
world model 为 Fossen RK4 解析步加 residual MLP，分别学习两平台误差；Gemma 4 26B 生成无时长 macro，三阶段梯度优化 duration、路径和碰撞代价，执行时 MPC 式重规划并用 trust region 防止更新越界。ASV 另用 VLM 从卫星/海图/天气生成语义障碍图。

## Experiment
每平台 5 个任务，解析仿真中均到达且零预测碰撞；转移 GazeboSim 后相对无 grounding 基线，ASV 终点误差降低 70–82%，AUV 约 93%。residual fine-tune 使 rollout RMSE 降 60%/69%；VLM 地图 navigability accuracy 96%。样本任务和 trial 数很小，未真机测试。

## Value
可借鉴“高层生成器提出计划、快速可微 world model 校准连续参数、闭环 guard 执行”的系统分工；但方法主体是经典系统辨识和轨迹优化。

## Strengths
跨两种动力学/动作维数复用规划器；混合物理模型具可解释约束；有 Gazebo transfer、guard 消融和语义地图替换实验。

## Weaknesses
无真实海试；每平台仅五任务/约十 trial，统计支撑弱；LLM 贡献未和规则模板比较；环境障碍静态且依赖已知/外部地图；所谓 world model 主要是一步动力学 surrogate。

## Future Work
作者提到用公开卫星数据扩大地图精度；更关键的后续应是真机、动态海况/障碍、在线系统辨识和更大任务集。

## Rating
创新度评分：2/5 - 物理残差模型、LLM宏动作和MPC guard 的组合实用但偏系统集成。
相关度评分：1/3 (Tangential) - 是模型式机器人规划，但非视频、3D生成或JEPA/Dreamer世界模型。

## TL;DR
用混合物理世界模型校准LLM海洋导航动作时长，系统实用但方向偏离，可选读。
