# From World Models to World Action Models: A Concise Tutorial for Robotics

## Insight
无新算法 insight，主要贡献是概念整理：把 robotics world model 定义为 action-conditioned predictive model，并把 World Action Model 定义为把未来预测与可执行动作关联起来的 policy/模型族。它强调观测空间世界模型、状态空间世界模型和动作模型之间的差异，避免把所有视频生成器都笼统称为世界模型。

## Motivation
机器人领域“world model”用法混乱：latent dynamics、视频预测、物理仿真、action-conditioned generation、VLA 辅助预测都被混称。教程试图用设计空间澄清各类方法在预测目标、空间显式性、动作抽象、控制可用性上的 trade-off。问题是重要的，但这是 tutorial/taxonomy，不解决具体技术瓶颈。

## Method
论文先定义 world、embodied task、policy、world model 和 world action model。随后把 world model 分为 observation-space 和 state-space：前者直接预测 RGB/multiview/RGB-D/point cloud 等未来观测，按 spatial explicitness 和 action abstraction 分类；后者预测 latent、keypoints、symbolic predicates、physical states 等任务相关状态。World Action Model 部分总结四类范式：imagine-then-execute、video-feature-conditioned action prediction、joint video-action modeling、auxiliary video prediction for policy learning。

## Experiment
无实验。论文主要是图示、分类表和相关工作梳理，引用 Dreamer/TD-MPC、V-JEPA、Cosmos、DreamDojo、Enerverse、PointWorld、Fast-WAM 等近期工作，比较各范式在视觉保真、空间结构、物理解释性、控制可用性上的优缺点。

## Value
价值是作为快速索引和术语对齐材料，适合给组内统一 world model/WAM 概念。对研究没有直接技术贡献，但能帮助判断一篇论文到底是在做 observation prediction、latent dynamics、action inverse model 还是 policy pretraining。局限是覆盖广而浅，缺少严格定义、实验和定量比较。

## Strengths
亮点在于它把世界模型/世界行动模型的概念脉络梳理得很清楚，能帮助读者快速建立统一框架。

## Weaknesses
不足是对研究没有直接技术贡献，但能帮助判断一篇论文到底是在做 observation prediction、latent dynamics、action inverse model 还是 policy pretraining。
