# World-Model-Augmented Visual Locomotion for Humanoids on Foothold-Constrained Terrain

## Insight

有。论文的 observation 是：在踏石、沟隙、窄台阶等落脚点稀疏且错误难以恢复的地形上，只依据当前深度图做反应式落脚容易失败；策略需要把过去观测、动作和奖励压缩成可预测未来的记忆。由此作者推论，不必显式标注 foothold 或在部署时展开 imagination，只要联合训练 RSSM，并把其 deterministic memory 输入策略，就能提供前瞻信息。匹配 PPO 对照中，加入该分支后 gap/stepping-stone 从全难度 0% 提升到 78.2%-100%，支持“预测记忆与性能相关”；但论文仅测 posterior reconstruction，未直接测 prior/open-loop forecast 或完整消融，因此尚未严格证明提升一定来自未来预测而非额外 recurrent capacity/auxiliary representation。

## Motivation

常规强化学习步态多在连续地形上训练，可行接触密集；一旦落脚区离散，单次失误便可能终止。已有 BeamDojo、RPL、PLANC 或优化式 footstep planner 依赖分 critic、难度课程、privileged teacher-to-vision distillation、多阶段训练或显式模型规划；已有 world-model locomotion 工作又主要面向楼梯、粗糙地面或状态重构，没有系统检验双足机器人在稀疏落脚点上的预测收益。该问题对可靠视觉人形运动很关键，本文目标是用单阶段 RSSM+PPO 给策略隐式前瞻，而非显式几何地图和 foothold 标签。

## Method

策略观察为 `o_t=(p_t,d_t,c_t)`：`p_t` 是关节位置/速度、IMU 与上一动作组成的 5 帧本体历史，`d_t` 是头部单目深度，`c_t` 是机体坐标系速度指令。RSSM 含 deterministic memory `h_t` 与 128 维 stochastic latent `z_t`：transition 用 `(h_{t-1},z_{t-1},a_{t-1})` 更新记忆，posterior 从当前 proprioception/depth 推断 `z_t`，prior 仅从 `h_t` 预测 latent；decoder 重构 proprioception、depth 和 reward。损失为三项 MSE 加 `β KL(q||p)`，与 PPO clipped objective 端到端联合优化，梯度进入共享深度/本体 encoder。策略只接收 `f_t^WM=g(h_t)`，再与本体历史、速度命令、深度经 MoE actor-critic 融合；推理时不做 imagined rollout。

训练还加入地形奖励，但 WM-LOCO 与 PPO 在每个地形设置下完全共享：台阶侧边禁入区惩罚、防踢 riser 的 3D 体素穿透惩罚、带左右脚顺序和速度自适应时间窗的 tread contact reward，以及踏石顶面/中心和左右 lane 奖励。因而实验差异原则上只来自 world-model pathway，但这些任务特定 shaping 仍是系统成功的重要组成。

## Experiment

IsaacLab 中使用 Unitree G1、8192 并行环境和单张 RTX 5880 Ada 48GB。模拟 RealSense D435 深度为 `64×36`、裁至 `32×18`，范围 0.1-2.5 m、50 Hz。楼梯、gap、stepping stones 由程序生成，Easy/Medium/Hard 使用独立 held-out terrain；每个 method×terrain×difficulty 至少 50 episodes，45 秒内质心越过终点线算成功。评测关闭 push 与 domain randomization。baseline 与 WM-LOCO 共享奖励、视觉/本体输入、AMP motion prior、MoE actor-critic、训练轮数，只去掉 RSSM 与辅助损失。

- 楼梯成功率 PPO 对 WM-LOCO 为 Easy `87.0→94.2%`、Medium `91.4→95.7%`、Hard `91.3→92.0%`；差距不超过 7.2 点。
- gap 三档为 PPO `0/0/0%`，WM-LOCO `98/100/90%`；stepping stones 为 `0/0/0%` 对 `87.0/88.3/78.2%`。WM-LOCO 的踏石失败主要是 illegal foothold（跨难度 23.0%），fall 仅 1.9%；baseline 失败主要为 fall 61.0% 或无进展 36.0%。
- 楼梯上 WM-LOCO 的 stride length 从 PPO 的 `0.45/0.42/0.40 m` 提至 `0.52/0.53/0.54 m`，steps/m 从 `4.91/5.04/5.15` 降至 `4.45/4.26/4.07`；normalized energy 从 `1.01/1.21/1.43` 降至 `0.95/1.01/1.14`，pelvis acceleration 从 `6.96/8.26/9.89` 降至 `5.28/5.85/6.58 m/s²`，action-rate 也明显下降。
- posterior 重构在 warm-up 后 depth MSE 多为 `2-7×10^-4`，高起伏结构经过视野时短暂约 `1.2×10^-3`；proprioception 总 MSE 低于 `5×10^-4`，base angular velocity 约 `10^-3`。作者明确说明这只衡量 observation encode-decode fidelity，不是 open-loop forward prediction quality。
- 同一 policy 以 ONNX 运行在 Jetson Orin，输入实机 D435 与本体感知，无 offboard perception、地形图或额外状态估计。Unitree G1 每类 10 次：15 cm riser/25 cm tread 楼梯 90%，0.8 m gap 90%，25 cm 踏石顶面/45 cm 间隔 100%，平均 93.3%。

## Value

对 Dreamer/RSSM 方向的启发是，隐式世界模型不一定要在控制循环内 rollout；其 recurrent predictive state 本身即可作为部分可观测策略的前瞻接口。论文还提供了一个很干净的工程对照：奖励与 backbone 不变，只增加 world-model pathway，且在最需要预判的稀疏落脚任务上差异远大于普通楼梯。不过，要把结果发展为可推广的“世界模型为何帮助落脚”结论，仍需直接测 prior imagination、时间跨度、记忆容量和决策边界。

## Strengths

- 问题选择合理：gap 与踏石具有错误不可逆性，能够放大反应式策略与预测记忆的差别。
- 训练为单阶段联合 PPO+RSSM，不依赖 foothold 标签、privileged teacher、显式地图或部署时 rollout，实机链路简洁。
- PPO baseline 在奖励、感知、motion prior、actor-critic 和预算上匹配，simulation 覆盖三类地形与三个难度。
- 不只报成功率，还给出失败类型、能耗、步长、pelvis acceleration、action-rate，以及 30 次真实机器人试验。

## Weaknesses

- “forward-aware”机制证据不足：只展示 posterior one-step reconstruction，且作者明确承认不是 open-loop forward prediction；没有 prior rollout、reward prediction、KL 对齐或不同 imagination horizon 的结果。
- 没有 `RSSM memory only / reconstruction only / reward prediction only / 同参数 recurrent policy` 等消融，无法区分预测目标、额外循环容量与辅助表征各自贡献。
- 定量对照只有 matched PPO，没有与 BeamDojo、RPL、PLANC、WMP、PIM 或其他 world-model locomotion 在同地形协议下比较。
- 仿真评测主动关闭 push 和 domain randomization；实机每类仅 10 次、无实机 baseline 或置信区间，因而鲁棒性与统计强度有限。
- 作者限定于单一 Unitree G1 和单一 RSSM；连续窄支撑、不同高度踏石、户外非结构地形均未覆盖，复杂 terrain-specific reward 也削弱了通用性。

## Future Work

作者提出评估其他 humanoid morphology、替代 world-model architecture，以及更多 foothold-constrained tasks；连续 balance beam、同时含横向与高度变化的踏石和户外非结构地形是明确未覆盖方向。基于当前证据，优先实验还应直接评估 RSSM prior 的多步预测、做容量匹配的循环策略与损失项消融，并增加扰动/domain randomization 和更大规模实机对照。

## Rating

创新度评分：3/5 - 将联合训练的 RSSM predictive state 用于稀疏落脚人形运动并完成实机验证，场景与结果有价值，但核心架构是已有 RSSM+PPO 组合，机制消融不足。
相关度评分：3/3 (Core) - 直接研究 Dreamer式隐式世界模型如何辅助视觉控制和决策，虽场景是人形运动，仍属于用户关注的核心世界模型方向。

## TL;DR

联合RSSM与PPO让人形机器人借助预测隐状态跨越稀疏落脚区，实机效果强但机制消融不足，值得精读。
