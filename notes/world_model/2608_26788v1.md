# Decoupling Planning and Control for Instructable Agents

## Insight
论文的核心观察是 embodied planning 与 control 工作在不同时间尺度：VLM 适合低频、长上下文的语义决策，Dreamer 式控制器适合高频闭环动作，强迫一个模型同时承担两者会让推理延迟和动作精度相互牵制。由此得到的推论是：用自然语言作为稳定的中层接口，可以让 VLM 在后台异步维护计划，让 world-model controller 在前台持续执行，并允许不微调地替换 planner。作者通过 7 个环境中的 controller-only、direct-VLM 和 planner+controller 对照，以及 online/offline latency 测量支持这一系统结论；但没有证明语言是比 learned latent/options 更优的接口。

## Motivation
预训练 VLM 能把任务和观察转成计划，却难以持续输出 Minecraft、Atari 等环境所需的低延迟原子动作；Dreamer 控制器能从像素高频控制，却主要受单一 reward 指导，难以接受开放语言目标。已有分层 RL、SayCan/VLA 和异步 slow-fast 系统已采用类似分解，关键问题不是“要不要分层”，而是能否以自然语言训练一个 planner-agnostic world-model controller，并在单/多智能体异构环境中保持性能和吞吐。

## Method
Instruct-to-Act 将策略分成 VLM planner πp 与环境专用 controller πc。planner 读取视觉历史、任务、compact memory、partial plan 和 controller 的 completion signal，输出 6–18 token 的中层指令；controller 在每个环境步根据当前观察、RSSM latent 和 frozen MiniLM 指令 embedding 产生动作及 stop probability。二者运行在独立进程：planner 持续在后台更新 draft plan，收到 stop event 后只需短 token emission；多智能体时每个 agent 共享 controller 参数但保有独立 RSSM state，VLM planner 通过离散 chat round 协调。

控制器基于 DreamerV3-style RSSM，语言 embedding 同时条件化 posterior/transition、actor 和 value；模型重建 observation 并预测 reward/continuation，在 latent imagination 中用 15-step λ-return 训练 actor-critic。训练不使用专家 demonstration：从 controller 自身 on-policy replay 中采样不重叠的 1–20 步片段，把帧和已执行动作交给 GPT-4o 事后生成一条解释该行为的指令，再以原动作序列做 behavior cloning，并以区间末端监督 stop head。50% replay 被标注，其余以 null embedding 保留 reward-only 自主控制。总目标为 world-model、value、actor、BC 和 stop loss 之和。

方法的主要创新在训练和系统接口：事后语言 relabeling 让已有 world-model policy 变得可指挥，异步 planner/controller 将 VLM 延迟移出控制回路；RSSM、Dreamer imagination 和层级控制本身均为既有技术。主结果用每环境一个 800M controller，而不是跨环境统一控制器。

## Experiment
作者在 Atari、MineRL ObtainDiamond、Crafter、DMLab、Overcooked、Pico Park 和 MindCraft 共 7 个环境评测，通常每项 100 episodes（MineRL 等遵循官方协议）。主表混合各任务自己的分数，不能跨列平均；最可信的是同 observation/action space 下的消融。以 GPT-4o planner 为例，planner+controller 相比 direct GPT-4o 在 Atari 891 vs 670、Minecraft 11.7 vs 10.4、Crafter 14.1 vs 8.7、DMLab 76 vs 56、Overcooked 193.2 vs 180.4、Pico 70.1 vs 50.3、MindCraft 70.2 vs 50.2；也全面高于 controller-only 的 809/8.2/12.6/67/170.2/30.7/40.0。四种 planner 均可直接替换；与专用 Voyager/JARVIS、RT-2、QMIX/MAPPO 等比较的训练信息和适配程度不同，论文也明确把主要 claim 限于内部 matched comparison。

语言监督消融在 Minecraft 为：VLM 指令 11.1，模板 9.9，action cluster label 8.9，随机字符串 8.3，无指令 8.2，使用环境真值标签 11.4，说明语义标签有效但还未达到 privileged label。不同 annotator×eval planner 的分数为 9.2–10.2，显示措辞迁移较稳定。Controller 架构消融中 RSSM 11.0、Transformer world model 11.2、model-free RNN 9.7、value-only world model 10.2，支持 predictive controller 的价值但不支持 RSSM 独有优势。

异步 planning 在 Minecraft 达 37.5 steps/s、offline 为 13.4（2.8×），Overcooked 为 169.9 vs 92.7（1.8×）；代价是下一指令平均 stale 51.2/165.1 steps。人工单标注者在 Minecraft、Pico Park、Atari 三域各 200 条 held-out 指令上给出 86%–97% 执行准确率，API 模型与其一致 93.2%，没有多人工一致性。单个 800M controller 平均需 4×A6000 训练约 23 小时、约 5.5M environment steps；annotation 增加 17% GPU-hours 和 12% wall-time。联合七环境 controller 在 Minecraft 下降约 10%，尚未实现通用控制器。

## Value
这项工作说明 Dreamer 类隐式世界模型可作为 VLM planner 的实时“执行层”，自然语言则把可替换规划、人工指挥和多智能体沟通统一起来。对我们的启发主要在 system boundary：慢规划不应阻塞快控制，指令完成应由控制器自己预测，训练语言接口可用 trajectory hindsight relabeling。它并未改进 world dynamics 表征，也没有证明 imagined rollout 的准确性，因此更适合作为 world-model deployment/agent architecture 参考，而非世界模型本体论文。

## Strengths
- 把 planner 与 controller 的时钟、状态和 mailbox 语义写得具体，异步收益有 latency、throughput 和 staleness 测量。
- 横跨 7 个差异很大的单/多智能体环境，并明确区分 reproduced、domain-adapted 与 contextual baselines。
- 训练无需专家轨迹，利用自身 rollout 的 hindsight language annotation，planner 可跨 Gemma/Qwen/GPT/LLaVA 替换。
- 有 instruction source、controller architecture、timing、scale、planner transfer 和 instruction length 等多组消融。
- 主动披露单人工评测、专用 controller 与 baseline 可比性的边界。

## Weaknesses
- “轻量 controller”主配置为每个环境独立的 800M 模型，并需约 5.5M 交互步；跨环境联合训练反而下降，部署成本和通用性有限。
- 事后 annotator 看到了实际动作再写指令，得到的是对既有行为的解释，不是同一状态下不同指令的 counterfactual supervision；控制器可能更多依赖状态/reward policy，而非精确语言 grounding。
- direct VLM 与 planner+controller 的比较虽然 observation/action space 相同，却没有匹配环境训练数据、交互预算和专用 controller 的 4×A6000、约 23 小时训练成本，不能解释为单纯架构优势。
- 主表混合七种不同量纲指标；多项外部 baseline 经不同程度适配，只有内部消融可作严格归因。
- 人工 instruction-following 仅一位作者标注，API agreement 不是独立人类复核；没有按指令类型、反事实冲突或安全失败分层。
- 异步执行在等待新指令时继续旧指令，Overcooked 平均 stale 165 steps；论文主要报告吞吐，没有系统评估过时指令导致的风险。
- world-model 的 prediction accuracy、latent imagination calibration 与长 horizon model bias 均未评估，任务提升不能区分 dynamics model、BC 与 VLM planning 各自贡献。

## Future Work
作者提出将人类 planner 放入环路、支持非对称多智能体角色、训练跨任务通用 controller，并通过 prompting 或轻量 planner adaptation 改善接口对齐。进一步值得做的是 counterfactual instruction 数据、可撤销/安全中断语义、staleness-aware control、统一训练预算对照，以及检验 world-model accuracy 与指令执行成功的因果关系。

## Rating
创新度评分：3/5 - slow/fast 分解并非新概念，但 hindsight language relabeling、异步自然语言接口和广泛单/多智能体验证形成了扎实的新组合，仍受专用大控制器与归因限制。

相关度评分：2/3 (Related) - 核心执行器直接采用 Dreamer 式 latent world model 和 imagination control，但论文重心是 VLM 规划接口与系统解耦，而非世界模型本体。

## TL;DR
用事后语言标注训练 Dreamer 执行层并异步连接 VLM 规划，系统设计扎实，可选读。
