# False Prophets: On the Security of World Models in Agentic Systems

## Insight
有。论文的核心 observation 是：把 world model 当作 agent 的“安全模拟器”会引入新攻击面，因为近似模拟一旦错判，agent 可能执行真实世界中的危险动作。更重要的是，有些错判不是简单训练不足，而来自不可判定运行时间、非确定性、外部环境状态缺失等世界模型无法完美预测的因素。

## Motivation
论文解决 agentic system 中 text-based world model 的安全问题。近期 Qwen-AgentWorld/Code World Model 类模型尝试预测终端命令执行结果，用于规划或执行前检查；但若模拟器把有害脚本预测成无害，安全边界反而会被绕过。该问题不是视频/3D 世界模型本身，但对任何“用世界模型替代真实环境做决策”的系统都有警示。

## Method
作者定义 threat model：恶意用户构造输入，agent 用 world model 先模拟 action，再决定是否在真实系统执行。攻击目标按 CIA 分类：confidentiality（世界模型上下文保留敏感信息）、integrity（错误模拟允许恶意命令）、availability/wallet drainage（诱导高资源执行或高 token 输出）。

攻击向量分 7 类：computability、non-determinism、missing knowledge、external environment、token count、misleading patterns、prompt injections。前四类较基础，很多情况下无法完全由更强模型修复；后三类更像 LLM 传统弱点，可通过训练和 harness 缓解。作者构造 AgentWorld-Robust，共 700 个短 bash 脚本，每类 100 个。

## Experiment
评测 Qwen-AgentWorld 35B 和 Meta Code World Model 32B，要求预测 30 秒内脚本的 exit code 和精确输出；ground truth 在 Ubuntu 20.04 Docker sandbox、30s time limit、512MiB memory limit 下运行。

总体上 Qwen exit code accuracy 0.86、output 0.44；CWM exit code 0.77、output 0.23。Qwen 在 prompt injection/misleading 上较强（output 0.96/0.91），但 external environment output 只有 0.05，non-determinism 0.31，token count 0.25。CWM 在多类 output 上更低。资源相关脚本中，两个模型 95% 情况低估运行时间，且常把数十分钟任务预测为小于 1 秒。

## Value
对我们有启发的是：world model 用于 planning/evaluation 时必须被当作不可信组件，尤其不能把低预测误差等价为安全可执行。视频/机器人世界模型也有类似问题：模拟误差、未观测外部状态、非确定性和长尾动作可能导致 planner 选择危险动作。

## Strengths
安全问题切入新颖；把错误分为 fundamental 与 technical 两类很清楚；benchmark 可执行且可复现；定量和案例分析结合；建议覆盖 world model、agent harness 和 real system 三层。

## Weaknesses
范围限定在文本终端 world model，不能直接代表视频/物理世界模型；攻击样本是 adversarial short scripts，衡量 worst-case 而非真实分布；评测只含两个公开模型；不少建议属于工程安全常识，非模型层根治方案。

## Future Work
作者建议未来在世界模型层加入更多环境信息和 adversarial training，在 agent 层做代码预处理、固定随机/时间/网络值、多次 rollout，在真实系统层施加 token/runtime/memory/resource limits，并继续完善可靠 agentic system 设计。

## Rating
创新度评分：3/5 - 安全分类和 benchmark 有贡献，但不提出新的世界模型训练算法。
相关度评分：1/3 (Tangential) - 研究 text world model safety，对世界模型部署有启发，但与视频/3D/JEPA/Dreamer 不直接相关。

## TL;DR
证明文本世界模型作安全模拟器会被错判攻击，部署警示强，但方向偏安全，可选读。
