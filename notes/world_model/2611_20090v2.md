# Latent World Modeling for Point-Cloud Video Pretraining

## Insight
观察：RGB 的未来 patch 位置来自固定网格，而点云视频的未来 token 锚点由未来点云采样得到；把真实锚点坐标给预测器，就已泄露几何运动。随机时间遮罩还允许用目标两侧帧插值。作者把已有式目标的真实锚点换成最近已见锚点，预测技能相对“复制末帧”从 0.85（真目标坐标）降至 −0.07；消除泄露并改成因果预测后，PointWM 在同一无泄露查询下达 0.52。这个对照直接支持“完成任务≠预测动力学”的判断。

## Motivation
点云视频自监督常借 MAE 或 JEPA 遮罩预测，但输入坐标和时序遮罩可能提供捷径，导致表征无需建模真实变化。该问题直接影响 3D/隐式世界模型训练目标是否有效，属于关键方法设计问题。

## Method
P4DConv/P4Transformer 将点云视频编码为时空点管 token；取严格早于未来目标的上下文，中间留 1 帧间隙以避开 tokenizer 的时间感受野。EMA 教师编码完整片段，学生只看过去；预测器用“最后已见锚点坐标 + 目标时间”查询，联合预测未来隐特征和锚点位移，分别用 L1 与对称 Chamfer 距离监督。8 维潜动作由未来帧特征变化推断后验，并与只看过去的先验以双向 KL 耦合；训练 30% 时间改用先验均值，推理只用先验。逐帧池化 VICReg 防止纯因果任务表征坍塌。核心创新是明确切断未来坐标和双侧时间泄露，把点云预训练从补全改为预测。

## Experiment
HOI4D 预训练/动作分段、MSR-Action3D 跨数据集动作识别。无泄露预测探针中，PointWM 相对复制末帧的技能 0.52，解释未来特征变化的 R² 为 0.58；泄露模型用真锚点可到 0.85，改用末帧锚点则为 −0.07。P4Transformer 上 HOI4D 离线 F1@50 从无预训练 58.2 升至 83.1；严格因果在线从 46.3 升至 75.4，较泄露式预训练的 56.1 高 19.3。消融：仅移除坐标泄露使在线 F1@50 从 56.1 升至 68.6，继续加入逐帧 VICReg、位置头、潜动作到 75.4；纯因果但无抗坍塌项跌至 52.8。三随机种子和跨骨干结果增加可信度。

## Value
值得精读。最可迁移的原则是检查目标查询是否包含未来才可观测的几何信息，并用复制末帧、无泄露查询与纯因果测试来衡量预测任务的真实难度。可推广到 3D tokenization、动态物体轨迹和多视角表示学习。

## Strengths
发现明确、受控消融紧扣泄露机制；同时测隐空间变化预测与下游任务；测试严格因果在线推理；用一帧间隙处理卷积时间感受野，且检查了全片段归一化潜在泄露。

## Weaknesses
未来点云重采样使 token 同序匹配仅近似；模型主要由动作识别/分段验证，缺少动作条件反事实预测、长期滚动和机器人规划。训练潜动作后验读取未来，推理先验预测技能 0.45 仍低于 oracle 后验 0.61，未来多模态不确定性未解决；预训练数据集中于 HOI4D。

## Future Work
作者计划强化潜动作先验，并扩大到更多样、更大规模的点云视频预训练。

## Rating
创新度评分：4/5 - 揭示点云 JEPA 的目标位置泄露，并给出无泄露的特征加几何因果预测目标，受控实验证据强。
相关度评分：3/3 (Core) - 直接研究 3D 点云视频的隐式世界建模和 JEPA 式预测学习。

## TL;DR
发现未来点云锚点泄露运动答案，并以末帧锚点做因果特征与几何预测；研究三维隐式模型值得精读。
