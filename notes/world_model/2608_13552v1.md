# PlayWorld: Benchmarking World Models with Agent Players over Long-Horizon Objectives

## Insight

固定动作序列并不是公平的跨模型测试：不同世界模型的动作粒度、响应延迟和可控性不同，同一串按键可能到达完全不同的观察状态。PlayWorld 因而把评测对象从“执行同一轨迹”改成“完成同一长时目标”，让多模态 Agent Player 依据生成帧在线 Stop/Extend/Correct。实验中 Preset+Agent 只修改约 12%–15% 的动作，却显著优于纯预设或全在线规划；同时，轨迹通过率与世界建模得分明显脱钩，说明“能走到评测点”不能替代对空间记忆、状态演化和物理交互的检验。

## Motivation

VBench 一类视频指标只测画质和时序平滑，已有世界模型基准虽加入几何、记忆或交互，却通常为每个样例预设固定轨迹。对 Genie 3 等只能网页交互的系统，人工适配既昂贵又有主观偏差；对不同动作接口，固定轨迹还会因过冲/欠冲造成不可比。论文瞄准的是当前交互式视频世界模型评测中的关键问题：应在相同高层目标下比较，而非强求相同低层控制序列。

## Method

每个样例由初始世界、场景绑定的长时目标、人工基本动作序列和样例专属 VQA rubric 构成。Agent Player 接收当前帧、动作历史、场景描述及目标，以 Keep、Stop、Extend、Correct、End 五种决策适配执行；统一接口把 W/A/S/D、视角键和 WAIT 映射到网页或本地模型，最多交互 40 步。

评测分四个核心维度：（1）几何一致性，检查环绕/重访后的身份与空间布局；（2）交互保真度，检查可达性、接触、碰撞、因果运动和视觉反馈；（3）视野外演化，检查对象重现、隐藏状态推进及物理因果；（4）持续可见的 insight evolution，检查过程是否真实推进而非冻结或循环。前三项先做轨迹有效性门控，失败直接记最低分 1；Gemini 3.1 Pro 对 10 FPS 低分辨率和 0.5 FPS 高分辨率两路 contact sheet 回答加权 Yes/No 问题，映射为 1–5 分。另用 VBench/CLIP/Depth Anything/VGGT 等九项指标报告基础画质和动作可控性。创新主要是“目标等价、轨迹自适应”的评测协议，而非新的世界模型。

## Experiment

- 数据包含 171 个手工筛选场景、50 余种动作模式、820 余个问题，rollout 为 10–60 秒；九个模型共生成 1,400 余段视频，覆盖 Genie 3、HappyOyster、LingBot-World(2)、HY-World2、SANA-WM、Matrix-Game-3.0 等闭源与开源系统。
- Genie 3 四维得分为几何 2.74、交互 2.40、持续演化 1.51、视野外演化 1.81，总分 2.12，虽为最佳仍远离满分；Matrix-Game-3.0 总分仅 1.14。所有模型在持续/视野外状态演化上尤其薄弱。
- 轨迹门控揭示“可控但不会建模”：SANA-WM 总体轨迹通过率 80.4%，但 rubric 总分仅 1.48；基础自动指标也可能奖励静止视频，HappyOyster 基础能力第一却非核心能力第一。
- 在 Genie 3 和 HappyOyster 各 25 个样例上，Preset+Agent 的轨迹分为 1.08/1.12，人类偏好为 65.6%/67.4%，优于 Preset Only 与 Agent Only。三种多模态 agent 的结果差异较小，Claude Haiku 以较低延迟被采用。
- 人类验证使用 120 对视频、5 名有视频生成经验的参与者，共 600 个判断；VQA 与人类模型排序的 Spearman 相关为总体 0.933，四维为 0.745–0.983。总体 Fleiss' κ 仅 0.434，属于中等一致；VQA 双次运行的模型级样本方差为 0.0112。

## Value

工作把交互式视频世界模型的公平比较从低层动作对齐提升到高层目标对齐，并用门控把“没走到”与“到了但世界不一致”分开，适合作为长时视频世界模型评测设计参考。最重要的经验是：全局几何唯一性、隐藏状态持续演化和复杂交互必须用重访/遮挡/长过程主动触发，常规画质指标无法代替。尚未解决的是评测 agent 与 VQA judge 的系统偏差、闭源系统版本漂移，以及缺少真实状态或 3D 真值时分数的可解释性。

## Strengths

- 问题定义贴近真实使用，能处理网页闭源模型和不同动作粒度，覆盖面强。
- rubric 先做任务完成门控，再分能力提问，避免把未发生的交互误判成物理正确。
- 同时报告目标轨迹、核心能力和基础画质，清楚展示三者不等价。
- 有控制策略消融、agent 模型消融、VQA 重复性以及较大规模的人类排序验证。
- 附录公开记录字段、两路 contact sheet、阈值和模型接口差异，复现协议较完整。

## Weaknesses

- 171 个样例仍以网络图片和人工脚本为主，缺少可查询的 3D/物理真值；VQA 只能判断表面证据，不能证明模型内部存在持久世界状态。
- 轨迹控制和最终评分都依赖前沿闭源多模态模型，且主要由单次 Gemini 调用决定，形成 judge 偏差、版本漂移与成本风险；双次方差不足以估计完整不确定性。
- 人类验证只比较模型排序而非逐问题准确率，且总体 Fleiss' κ=0.434；较高 Spearman 可能部分来自明显的模型级质量差，而不能保证细粒度 rubric 正确。
- 不同模型通过网页或本地 chunk 运行，HY-World2 还跳过不支持的输入，Hunyuan-GameCraft-2 无法严格执行 WAIT，测试集合与接口并非完全同质。
- Preset+Agent 消融仅覆盖两个闭源模型各 25 例；尚未证明在更弱控制、开放式任务或更长闭环中仍公平稳定。
- 论文强调“长时”，但最长仅 60 秒、40 个交互步，距离可持续游戏或具身决策仍有明显差距。

## Future Work

作者建议在预算允许时对 VQA 多次独立采样并平均，也指出 Agent Player 可随更强多模态模型直接升级。更关键的后续应加入可验证的 3D/对象状态真值、judge 校准和置信区间，扩展到分钟以上、多阶段目标、失败恢复与真正闭环物理任务，并为闭源网页模型固定版本和可复现交互日志。

## Rating

创新度评分：3/5 - 目标等价与闭环轨迹适配是有价值的评测创新，验证较系统，但核心仍是 agent+VQA rubric 的基准组合而非新世界模型范式。
相关度评分：3/3 (Core) - 直接评测交互式视频世界模型的长时几何、物理交互、记忆和状态演化能力。

## TL;DR

以 Agent 自适应轨迹公平评测长时交互世界模型并揭示状态演化短板，值得精读。
