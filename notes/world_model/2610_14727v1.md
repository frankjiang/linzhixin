# MHWA: Multi-timescale Hierarchical World-Action Model

## Insight
观察到扁平自回归世界模型在开放环滚动中误差累积，单纯加入层级又可能让高低层训练信号互相干扰。若慢速上下文足够准确且真实慢变量变化小，跨步更新可降低上下文误差并减少传播；附录推导的条件是 `β_H+(k−1)ρ≤β_F`，只是与扁平模型的一步误差上界比较，未保证该条件在实验中成立。实验进一步显示隔离高层梯度与按高层上下文、当前状态联合路由专家能改善 Atari 表现。

## Motivation
JOWA 等离散 token 世界动作模型用统一 Transformer 预测视觉状态、奖励和价值，开放环误差随步数扩大，扩大模型又成本高。传统层级结构还可能因高层语义随低层能力漂移或共享低层参数冲突而不稳定。作者试图用计算量较低的分层结构改善多游戏动力学建模和离线控制。

## Method
沿用 JOWA 的 VQ-VAE 图像 token 与交织的动作 token，低层因果 Transformer 逐 token 预测下一观测、奖励、终止及分布式 Q 值，Q 学习用 TD/CQL。高层 Manager 每隔 `k=4` 个交织 token 抽样历史，用因果 Transformer 和跨步观测预测损失学慢速上下文；上下文在区间内广播，低层损失在 Manager 输出处 stop-gradient。低层 FFN 换成 4 专家 Top-2 MoE，门控看当前 token 和慢上下文，加负载均衡 KL。联合优化世界模型、价值、跨步预测和路由损失。创新是跨尺度上下文隔离与上下文条件 MoE 的组合；跨步是固定 token 间隔，并非学得的事件尺度。

## Experiment
14 款 Atari 游戏，rlu-atari 离线数据各取 10%，3 个训练种子；对比同数据/批量 JOWA-70M 与发表的 JOWA-150M，测 Human Normalized Score 的 IQM/中位数、视觉开放环 MSE/PSNR/SSIM 和训练 FLOP。77M 参数 MHWA 的 seed-by-game IQM 为 0.884，95% CI `[0.736,1.031]`；匹配的 JOWA-70M 为 0.529 `[0.459,0.602]`，发表的 JOWA-150M 为 0.833。每序列训练 48.199 GFLOP，对比 84.238/165.524 GFLOP。4 帧真实上下文后，5–8 帧及延伸到 54 帧的开放环重建优于 70M，接近 150M，但长程仍最终离开数据流形。6 游戏/44M 消融 IQM 完整 0.564；去 Manager 0.445、去 MoE 0.450、去当前状态门控 0.359、`k=1` 0.214、去跨步损失 0.503。未见低层预测精度与策略收益的严格因果分离。

## Value
值得精读其世界模型稳定性与结构消融：慢变量通道、梯度隔离和局部专家模块可作为视频/隐状态长程预测的设计参考。评价时应同时看视觉滚动质量、最终回报和实际训练成本，不能把理论上界当作模型稳定性保证。

## Strengths
和容量相近基线做三种子、同数据比较；开放环延伸到 54 帧并承认最终漂移；参数匹配消融覆盖跨步、高层、MoE、路由及梯度隔离；附录明确理论条件与适用范围。

## Weaknesses
只在离散动作 Atari 且复用预训练 tokenizer 验证，外推到真实视频/连续控制尚未证明。高层 `k=4` 是扁平 token 流间隔，不直接对应物理时间尺度；全模型综合效果与发表的 150M 基线不是同等重新训练对比。误差上界要求的慢上下文误差及变化率没有被测量，开放环误差仍长期累积。

## Future Work
作者提出学习自适应时间抽象，并扩展到连续控制和更广泛场景；实际应用还需处理不确定性和分布外预测。

## Rating
创新度评分：3/5 - 固定步长层级与上下文 MoE 的干扰隔离设计有效，但主要组合现有机制，理论保证有条件。
相关度评分：3/3 (Core) - 直接研究视觉 token 世界模型的长期动力学预测与基于模型的控制。

## TL;DR
跨步高层上下文结合状态条件 MoE，降低 Atari 世界模型开放环漂移及训练成本，值得精读。
