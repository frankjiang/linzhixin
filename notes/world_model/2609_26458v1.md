# Code Plans, Diffusion Renders: Open-Ended Generative World Modeling

## Insight
观察：像素历史只能记录“看见了什么”，难以保证离屏事件继续演化。推论：把持久状态和规则交给可执行程序，把视频模型用作观测渲染器。回访、离屏注水和双人交互案例支持该分工；没有证明生成程序本身具有可靠的物理泛化能力。

## Motivation
解决视频世界模型的长期记忆、可扩展动作及离屏动力学问题。同行主要扩展视觉上下文或检索记忆，但记住外观不等于持续推进隐藏状态。这是交互世界的关键问题。

## Method
用户概念→LLM 世界蓝图→编码代理构建 Three.js 白盒世界→MiniMax H3 渲染→观测颜色回写三维表面。Logical Spaces 用接口契约协调模块；Observation as World Registration 根据相机、深度及可见性将历史颜色注册到表面。Artist 以部分着色白盒、深度和语义为条件补全视频。Visual Cue Hacking 用边缘/深度引导生成训练目标，减轻白盒生硬外观；LoRA 微调主干、全量训练 ControlNet。贡献在系统分工与闭环注册，不能直接等同于从数据学得通用动力学。

## Experiment
- 正文表1：WorldScore 十项均值 **87.88**，LingBot-World **74.79**，Matrix-Game 3.0 **74.20**；包含相机控制、三维一致性和运动等指标。
- 表2：移除观测注册，VBench 主体一致性 **96.31→84.63**；移除 Visual Cue Hacking，WorldScore 主观质量 **69.08→49.05**。
- 图3–6展示转身回访、开门、离屏注水与共享射击结果；附录30份有效问卷支持主观偏好。
- 评测输入需先经分割、深度与 LLM 重建白盒，并非与纯视频基线完全相同的信息和计算条件。

## Value
值得借鉴“状态演化—感知渲染—外观注册”的边界。对需要可靠事件记忆的3D/视频世界尤其有用；下一步应检验代码生成失败率、状态与画面偏离以及真实环境动力学迁移。

## Strengths
持久状态天然支持离屏演化和多视角共享；动作逻辑可扩展；对注册和视觉适配均有消融。

## Weaknesses
基线与本方法的结构先验、基础模型和预处理不同，整体优势难完全归因于核心机制。开放交互主要依赖程序实现；未给出充分的构建成本、实时性和复杂事件成功率统计。约5,000帧后画质退化，手物交互和碰撞仍会失真（附录）。

## Future Work
作者提出长视频后训练、更有效时间记忆、改进几何/关节物体/物理交互，以及让 Artist 输出 Albedo、Normal、Roughness、Irradiance 等分解表征以增强注册和重渲染。

## Rating
创新度评分：3/5 - 可执行世界与生成渲染的组合及注册机制有价值，但尚不足以支撑“新范式”的强表述。
相关度评分：3/3 (Core) - 直接研究视频与3D世界的持久状态、交互和生成。

## TL;DR
以代码维护世界规则和离屏状态、用视频模型渲染并回写外观，适合研究持久三维世界，值得精读。
