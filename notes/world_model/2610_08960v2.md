# Directed Temporal Representations for Offline Visual Control

## Insight
JEPA 式视觉 latent 能预测未来，却未必把“到目标还需多久”编码成适合控制的几何。论文在冻结 LeWM 特征上学习有方向的时间准度量，用近程轨迹间隔校准尺度、长程 bootstrap 传播可达性，再以单步距离下降评价动作进展。准度量形式保证三角不等式；实验支持在部分任务上改善控制，但记录轨迹时长不等于最短到达时间，方向性也非每个任务都显著。

## Motivation
视觉世界模型规划常用 latent 欧氏距离衡量预测状态与目标的接近度，忽略动作可达性和方向不对称。仅让视觉表征预测相似帧不能保证正确排序可执行路径。将离线轨迹中的时间关系变为控制目标，对隐式/JEPA 世界模型有直接意义。

## Method
冻结 LeWorldModel 视觉编码器，训练控制表征头 `e=ψ(z)`；距离由对称欧氏项加顺序敏感的潜势残差组成，可表达 `d(s,g)≠d(g,s)` 且满足三角不等式。前 1–8 步真实间隔校准局部时间尺度，较长状态目标对用“已观察 n 步+目标网络估计剩余成本”的 bootstrap 目标及低分位 expectile 回归学习；另以动作条件转移头约束下一表征的一致性。

冻结的时间距离在记录轨迹上给出 `d(s,g)-[k+d(s',g)]` 优势，以指数加权条件流匹配训练直接输出动作 chunk 的目标策略。训练期可另采样候选动作，先用行为流模型和动力学集成分歧过滤离线分布外候选，再用预测时间成本较低者作额外监督；推理时无需 CEM 搜索。

## Experiment
四个 LeWM 任务加六个视觉 OGBench 任务，对照 LeWM 潜空间规划、GCBC、GC-IQL、HILP、GC-IDM；成功率基于五个评估种子。四个 LeWM 任务中 DTRC 相比 LeWM 在 TwoRoom/Reacher/Cube 高 14.7/24.0/30.0 个百分点，PushT 接近。六个额外任务在目标间隔 25 步的平均成功率为 45.9%，LeWM 43.2%；100 步时为 18.9% 对 10.7%。但 PointMaze 仅 11.3%，低于 GCBC 28.7%。

同条件流策略消融：Flow BC 在 PushT/Reacher/Cube 为 74.7/68.0/91.3%，加时间监督（不加模型辅助）为 84.0/100.0/97.3%。完整方法为 90.7/100.0/96.0%；Cube 上删除方向残差反达 98.7%，说明非对称项并非普遍增益。留出轨迹中四任务前 8 步时间误差均 <2 步，但 Cube 的 1–100 步相关仅 0.221、正反方向差近随机；PushT 则相关 0.845。没有真实机器人和跨任务表征迁移实验。

## Value
给隐式世界模型一个明确评估轴：latent 是否反映有方向的到达时间和局部动作进展，而不只是预测误差。值得借鉴同策略参数化消融、近程校准/长程结构分开评测及用任务成本塑造 JEPA 特征。应谨慎把记录轨迹时长当“最短可达性”真值，并检查不同任务是否真的需要方向残差。

## Strengths
- 距离结构具有可组合的准度量性质，并给出局部、长程、方向和进展的独立诊断。
- 同一流策略的行为克隆对照较清楚地显示时间监督贡献。
- 模型辅助候选先经行为支持与动力学分歧过滤，减少利用模型错误。

## Weaknesses
- 方向性与长程相关性强烈依赖任务，Cube 上方向残差甚至减分。
- 依赖冻结 LeWM 表征和离线轨迹质量；对不可逆、新颖目标或行为覆盖不足的可达性未知。
- 只有仿真视觉控制，未证明真实部署或跨环境共享准度量。

## Future Work
正文未给出明确后续计划；可依据结果探索任务自适应的方向分量、离线轨迹效率偏差校正及真实机器人/跨任务迁移。这是笔记推论。

## Rating
创新度评分：3/5 - 将已有准度量与时间 bootstrap 系统接到 JEPA 视觉控制，实验分析充分，理论构造并非新范式。
相关度评分：3/3 (Core) - 直接研究隐式视觉世界模型表征如何支持目标条件控制。

## TL;DR
给冻结 JEPA 视觉表征学习有方向的到达时间，并据此训练直接策略；隐式世界模型控制目标值得精读。
