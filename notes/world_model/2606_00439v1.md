# Physical Object Understanding with a Physically Controllable World Model

## Insight
Observation：世界模型学习了场景中变量之间的条件概率分布（外观、运动、深度等），但现有架构（如视频扩散模型）将这些变量全局嵌入，无法查询"特定位置的特定变量在给定其他观测时的分布"。推论：如果将世界模型重新定义为一个概率图模型（PGM）——对局部变量的任意条件概率做推断——那么可以用标准的自回归序列预测来高效实现。具体地，将场景状态序列化为"指针-内容"token 对，每个 next-token prediction 就等价于查询一个条件概率。证明：PSI 在物体发现、分割、3D 操控、物理关系推理（Visual Jenga）等下游任务上达到 SOTA，且均为零样本，不需要任务专属架构。

这个 insight 相当深刻——将 PGM 和自回归 LM 建立等价性，并用这个等价性构建了一个统一的物理可控世界模型。

## Motivation
视觉场景中的物理理解需要概率推理能力：一个变量如何影响另一个（如推一个物体对其他物体的影响）。现有世界模型用全局 embedding（文本/动作/场景 embedding）做条件生成，无法隔离或查询局部变量。物体发现、分割、3D 操控、物理关系推理等任务各自需要不同的专用方法。PSI 尝试用一个统一的概率世界模型框架解决所有这些问题。

## Method
**PSI (Probabilistic Structure Integrator) 框架**：
1. **概率世界模型定义**：世界状态由时空指针集 P（位置）和内容词汇 V 描述。模型 Ψ 接受部分观测 X（指针-内容对的子集）和查询位置 p，返回该位置内容的条件概率分布 Pr[v | X, p]。
2. **自回归实现**：将数据序列化为交错的指针-内容 token [p0, v0, ..., pk, vk]。追加查询指针 p 后，next-token 预测即为条件概率查询。训练时对空间顺序做随机排列以学习完整的联合分布。
3. **PSI 构建**：内容词汇包括 RGB token（外观）、Flow token（动态）、Camera token（视角变化），均通过浅层卷积量化器离散化。训练序列格式 X = r^0 ◦ [c] ◦ f ◦ r^1（两帧 RGB + 光流 + 相机），flow token 随机 mask 0-1。模型为 7B GPT transformer，3M 真实视频训练（~1.4T token）。
4. **推理路径**：支持并行（独立查询多位置）和顺序解码（逐 token 采样，捕获因果依赖）。

**应用**：
- 运动概率图/期望运动图（并行推理）
- 多样未来生成（顺序采样 flow 再生成 RGB）
- 可动物体分割（运动相关性分析）
- 铰接部件发现（Poke 后运动相关性）
- 3D 物体操控（flow 指定 6DOF 变换）
- 物理关系推理/Visual Jenga（运动传播图）

## Experiment
- **物体分割（SpelkeBench）**：Point-prompted mIoU 0.681 vs SAM2 0.623、FPT 0.566；Unprompted F1 0.38 vs ProMerge 0.20。
- **铰接部件发现（DragAMove）**：mIoU 0.410 vs FPT 0.287、MotionI2V 0.073。
- **3D 操控（3DEditBench）**：PSI 分割 + DaS 编辑的 EA 指标在多个方法上均优于 SAM2 分割。
- **消融**：flow token 的引入对分割性能提升显著（AR 0.541 vs PSI-RGB 0.412 vs CWM 0.158）；模型从 100M 到 7B 持续提升；顺序解码步数 64+ 后增益饱和。

## Value
这是一篇具有显著理论深度的工作。PGM 与自回归序列模型的等价性洞见非常优雅，构建了一个真正"可查询"的世界模型。对隐式世界模型（JEPA 等）方向有重要启发：世界模型不仅应该预测未来，还应该支持任意条件下的局部推断。当前局限：仅处理两帧间的预测，序列化效率受限于 patch 粒度，7B 模型的顺序解码较慢。
