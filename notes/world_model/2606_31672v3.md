# WorldRoamBench: An Open-World Benchmark for Long-Horizon Stability of Interactive World Models

## Insight
论文的 insight 是：交互式世界模型的长期稳定性不能只用视频质量或单步动作跟随评估，必须同时拆成 action、vision、physics 和 memory 四个维度。尤其是 revisit memory 和 controllability-gated physics 能暴露短视频指标看不到的问题。

## Motivation
Genie/Matrix/Game-like interactive world model 越来越多，但开放世界长 horizon 评测仍缺少统一协议。模型可能短时看起来合理，却在 10-60 秒后出现视觉漂移、物理失真、动作失控或场景记忆丢失。

## Method
WorldRoamBench 构建超过 600 个测试 case，覆盖 Nature、Urban、Indoor 以及第一/第三人称视角。Action 维度使用逐帧按键指标，避免语义 scale mismatch 和轨迹遮蔽；Vision 用 segment-based temporal drift；Physics 评估 mechanics、optics、3D consistency；Memory 使用 action-decoupled revisit protocol。

## Experiment
论文评估 10 多个开源/闭源 interactive world models，包括 Genie3、Happy Oyster、Matrix-Game、HY-World、LingBot 等。结果显示 action 分数普遍较高，但 physics 和 memory 明显拉开差距；没有模型在四个维度都稳定。总体排名中 Genie3、Happy Oyster 等领先，但仍离可靠开放世界交互有距离。

## Value
这是 interactive video world model 评测的核心参考。它提醒我们长时稳定性要拆维度，不能只看短片段审美或 action prompt 成功。

## Strengths
评测维度清晰；长 horizon 和 revisit 设计重要；覆盖开放世界多场景和多模型。

## Weaknesses
benchmark 依赖生成模型可访问性和人工/自动评估质量；第三人称控制等设定存在 confound；没有直接给出训练改进方法。

## Future Work
未来可继续扩展 leaderboard、增加真实交互任务，并把评测指标反馈到模型训练。

## Rating
创新度评分：3/5 - benchmark 设计扎实，但不是新模型。
相关度评分：3/3 (Core) - 直接评测长时交互视频世界模型。

## TL;DR
WorldRoamBench 系统评测长时交互世界模型的动作、视觉、物理和记忆，值得选读。
