# VisualPatchWorld: Code World Models as Latent Structured Representations for Planning

## Insight
有。论文的 observation 是：neural latent world model 可从数据扩展但 dynamics 不可检查，手写 physics engine 可解释但难扩展；现有 code world model 往往能拟合局部 transition，却未必选择了可用于 long-horizon planning 的正确 dynamical form。推论是：把 dynamics 表示成可执行代码，并把 induction 分成 qualitative sketch selection 与 parameter fitting，能得到更 planner-ready、可检查的 world model。

## Motivation
论文解决自动构建 simulator-style world model 的问题。Dreamer/LeWM 类模型在连续 latent 中学 dynamics，失败时难以编辑；PatchWorld、WorldCoder、PoE-World 等生成可执行程序，但多关注 next-step fit 或自由代码生成，容易在接触/运动学结构上选错形式。VPW 试图恢复“像简化物理引擎一样”的结构化代码 dynamics，并验证其对 MPC 的作用。它与 3D/视频世界模型不是同一路线，但对可解释世界模型和 planning 有直接借鉴价值。

## Method
VPW 将 pipeline 分四步。Stage 1 visual abstraction：把 observation 转为 object-centric scene graph，包含 object pose、distance、near-contact、relative direction 等；可用 oracle simulator state、工具式 CV extractor，或 VLM 语义 baseline。Stage 2 trajectory export：把 rollout 转成 `(g_t, a_t, g_{t+delta})` transition records，强调 action discretization 要与 frame stride 对齐。

Stage 3 是核心 two-level program induction。Level 1 用 active probing 通过黑盒 reset/step 选择 qualitative dynamical sketch，例如 contact vs free motion、linear navigation、grip-gated object motion、joint-space vs Cartesian kinematics。Level 2 固定 sketch 后，用 multi-step rollout error 和多次重启优化模板中的参数，输出 Python transition program。Stage 4 用 CEM-MPC 评估：induced scoring 用程序给所有候选动作序列打分；hybrid scoring 先用 induced model 搜索，再让 MuJoCo 重打分 top 30%；MuJoCo+CEM 是物理引擎上界。

## Experiment
使用 LeWM 四个环境：Two-room、Reacher、PushT、Cube。训练数据是 simulator-state traces，主表 50 starts、seed 42；planner 固定到 MuJoCo ceiling 至少 90%。对比 code baselines：PatchWorld、WorldCoder、POMDP-Coder、PoE-World、GIF-MCTS、CWM-Game。

VPW Oracle+Induced 四任务 success 为 96/72/22/86，mean 69.0%，超过最强 code baseline POMDP-Coder 45.5% 23.5 points；Tool+Induced mean 61.0%，显示 image-derived scene graph 有额外感知损失。相对 MuJoCo+CEM ceiling 100/100/96/94，induced model 在 Two-room/Cube 接近上界，在 Reacher 有差距，在 contact-rich PushT 仅 22%。Hybrid scoring 显著补齐：Oracle+Hybrid 达 100/100/96/84，mean 95.0%，接近 MuJoCo 97.5%；Tool+Hybrid mean 84.0%。PushT ablation 表明 parse success 和 one-step fit 不够，只有 L1+L2 的 contact PD/quasi-static block sketch 才有 22% planning success。

## Value
价值在于提出“code as structured latent representation”的路线：world model 不一定是神经 latent，也可以是自动诱导的可执行动态程序。对我们有启发的是：planner-facing world model 的关键不只是预测误差，而是 qualitative dynamics class 和 scoring landscape；混合式“induced model 搜索 + 真实/高保真引擎短名单验证”也是实用设计。

## Strengths
问题拆分清楚；active probing + rollout fitting 比自由 LLM 生成更可控；用相同 planner 和相同 traces 对 code baselines 做公平比较；明确区分 replan observation、search-time scorer 和 physics ceiling；对 PushT 接触失败分析诚实。

## Weaknesses
核心 dynamics 训练依赖 simulator-state traces 和手工小型 sketch family，离从 raw video 自动学习还有距离；Tool extractor 是 environment-specific CV，不是通用视觉模型；主结果多为 seed 42/50 starts，统计强度有限；PushT induced-only 仍很弱，接触物理难题没有真正解决；VLM path 只能给语义，metric coordinate 误差很大；真实机器人和 OOD dynamics 未验证。

## Future Work
作者明确提出从 visual scene-graph trajectories 直接诱导程序、扩大 sketch families、测试 OOD 和真实机器人设置，并进一步提升接触丰富场景下的 induced ranking。

## Rating
创新度评分：3/5 - 可执行代码世界模型和 two-level induction 有新意，但依赖结构化状态和手工 sketch，规模仍小。
相关度评分：2/3 (Related) - 研究可规划世界模型和结构化 dynamics，对 3D/隐式世界模型有方法借鉴，但不是视频/JEPA/Dreamer 主线。

## TL;DR
把世界模型表示为可执行动态代码并用于MPC，结构选择很有启发，适合选读。
