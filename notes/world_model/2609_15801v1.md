# When Should a World Model Move? Loss-Conditioned State Execution

## Insight
观察：变化事件预测准确，不代表改变状态预测能降低任务损失。作者构造事件概率、条件方差相同、但绝对损失最优决策相反的分布；证明“可预测变化”与“应该更新”不可等同。进一步用 Hoeffding 界与联合界证明接受组的平均有界损失优于保持原状态（§3、附录 A）。

## Motivation
常见方法以不确定性控制模型使用范围，未直接检验某次候选预测是否优于 persistence。稀疏变化场景确有此问题，但本文主要解决预测选择，尚非完整的世界模型闭环控制。

## Method
固定预测模型、可行性投影、损失及分组 → 独立校准集计算每组“保持原状态损失−候选损失” → 仅在同时置信下界大于零时采用候选，否则保持原状态。平方/绝对/非对称损失分别对应均值/中位数/分位数决策。贡献是损失感知的选择接口与清晰定义；统计工具沿用 learn-then-test。

## Experiment
- 覆盖合成数据、Monash/M4 时序、FourRooms、MuJoCo 和库存；报告 MAE、MASE、sMAPE、NMSE、覆盖率和配对 bootstrap 区间。
- M4 Monthly 的 28,684 条测试序列：覆盖率 14.0%；有界损失 0.588，优于保持 0.599、总是更新 0.621（表 11）。
- 关键反例：仅按校准均值正负选择可达 0.586，优于认证门控；FourRooms 门控 0.122 也逊于总是更新 0.094，闭环成功率与保持均为 2/30。
- MuJoCo 在长预测范围有效，但短范围过度保守；7 个被接受组的未截断损失反而变差，认证只覆盖声明的截断损失（附录 C）。

## Value
对 JEPA/Dreamer 的启发是按实际决策收益校准模型使用，而非把不确定性或表征可预测性当作价值。迁移到策略诱导分布、多步递归预测仍需额外验证。

## Strengths
概念边界和保证条件明确；公布不利结果；校准、训练、测试分离，并按完整 episode 处理内部相关性。

## Weaknesses
保证仅为同分布、预先固定组的平均有界损失，既非逐状态保证，也非控制安全保证；置信修正多次牺牲实际精度。主要预测器及基线较简单，缺少视频/潜变量世界模型上的有效闭环收益。

## Future Work
作者提出递归使用所选状态、在线重新校准，以及策略感知的候选构造（§5）。

## Rating
创新度评分：3/5 - 决策区分与反例有价值，方法主要整合经典统计决策和校准工具。
相关度评分：2/3 (Related) - 可借鉴于隐式世界模型的使用与评估，未直接推进视频、3D 或 JEPA/Dreamer 建模。

## TL;DR
以损失收益校准决定是否更新状态，揭示预测准确不等于决策有益；保证偏保守，方法与反例可选读。
