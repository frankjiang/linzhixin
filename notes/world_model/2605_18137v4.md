# Xiaomi Auto World Model: A Joint World Model Integrating Reconstruction and Generation for Autonomous Driving

## Insight
Observation：自动驾驶世界模型存在重建（Reconstruction）和生成（Generation）两大能力需求，现有方法大多将两者割裂——重建方法无法想象未观测区域，生成方法缺乏几何一致性。

推论：将两者深度融合可实现互补增益——重建提供几何锚点抑制生成漂移，生成填补重建的不可观测区域。Joint World Model = WorldRec的确定性几何约束 + WorldGen的生成想象力。

## Motivation
三大瓶颈：(1) 传统逐场景3DGS优化耗时数小时且泛化差，前馈方法依赖DPT head产生ghosting/重复；(2) 从零训练的causal diffusion模型生成先验弱、推理步数多（50→实时不可行）、有exposure bias；(3) 重建与生成的耦合停留在表面——大多数系统简单拼接而非深度集成。

这是自动驾驶世界模型的工程系统论文，代表了该方向的产业实践前沿（小米汽车团队）。

## Method
**WorldRec（世界表征）：**
- 稀疏3D Query初始化 → 投影到多视图多时间步特征图 → 可见性感知加权聚合 → MLP解码为3D Gaussian属性
- 与密集DPT方法相比：避免逐帧独立预测的ghosting和重复，Gaussian数量从百万级降至可控
- 支持增量重建：场景token通过cross-attention融合新观测

**WorldGen（世界生成）：**
- 骨干：DiT (Diffusion Transformer)，条件信号包括ego轨迹、相机参数、layout map、文本
- 两阶段训练：
  - Stage 1：双向预训练（全时序注意力），学习驾驶场景的联合时空分布
  - Stage 2：因果微调，三步渐进——Teacher Forcing → ODE蒸馏（50步→4步，12×加速）→ DMD（消除exposure bias）
- Rectified Flow formulation替代传统DDPM

**Joint World Model：**
- WorldRec增量重建维护全局4D场景 → ego projection渲染partial image → 作为WorldGen的额外条件
- WorldGen的生成帧反馈更新WorldRec的场景token（key frame update）
- 闭环：重建锚定几何一致性，生成补全不可观测区域

## Experiment
论文为技术报告形式（前10页主要描述方法），实验细节在后续页面。从方法描述可见：
- WorldRec：重建时间从小时级降至约10秒/clip，消除ghosting
- WorldGen：4步推理实现0.19s/frame的1分钟驾驶视频因果生成
- JWM：在生成稳定性、跨帧一致性、视觉保真度三轴协同提升

## Value
这是一个**大规模工业系统论文**，代表了自动驾驶世界模型的当前工程水平。技术贡献在于：
1. WorldRec的稀疏query设计是对DPT-head范式的有效改进
2. 双向预训练→因果微调+ODE蒸馏+DMD的训练pipeline完整且实用
3. 重建-生成的深度融合思路（rendered prior conditioning）有启发性

启发：(1) 将3D重建作为视频世界模型的几何先验/条件是有效的融合范式；(2) 步骤蒸馏（ODE distillation）+分布对齐（DMD）可以将扩散模型推向实时推理；(3) 稀疏scene query可替代密集的per-pixel prediction。

不足：作为技术报告，缺乏系统性的定量对比；单一应用场景（自动驾驶）的通用性有限。
