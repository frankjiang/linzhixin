# FlyMirage: A Fully Automated Generation Pipeline for Diverse and Scalable UAV Flight Data via Generative World Model

## Insight
无显著 insight。将生成式世界模型（3DGS）用于 UAV 飞行数据的自动化生成管线。

## Motivation
航空 VLN 数据集在规模、多样性和真实感方面受限。FlyMirage 利用 LLM 设计场景 + 生成式世界模型实例化为 3DGS 场景，构建自动化数据生成管线。

## Method
LLM 作为环境设计器促进场景多样性，Marble 1.1 Plus 生成式世界模型实例化为 3DGS 场景。自动化场景探索和语义信息获取，动态可行规划器生成 UAV 轨迹。生成 500 场景、50K 轨迹。

## Experiment
生成大规模光照真实的航空 VLN 数据集。定量评估数据集的多样性和质量。下游 VLN 任务验证数据有效性。

## Value
数据生成管线工作，使用世界模型作为场景生成工具。与用户关注的世界模型研究方向无直接关联。
