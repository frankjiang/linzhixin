# QuantWM: Temporally Consistent 2-Bit KV Cache Quantization for Video World Models

## Insight
视频世界模型量化 Key 时，重构 MSE 可比量化 Value 更低，却造成更大输出损伤；原因是 Key 的小误差经 QKᵀ 改变跨帧、跨空间的注意力令牌排序，产生闪烁。作者据此以历史 Query 的二阶统计量估计 Key 误差对 logit 的敏感度，并恢复主 Query 子空间中的残余误差。数据验证了令牌选择偏移下降；这属于缓存量化机制分析，不直接证明下游规划能力。

## Motivation
自回归视频世界模型需要保存不断增长的 KV 缓存；通用 2-bit 方法在 VBench 分数接近原模型时仍出现明显闪烁，说明部署评测不能只看常见视频质量综合分。

## Method
QuantWM 是免训练的 2-bit 缓存量化。QSAC 先用历史 Query 方差加权 Key 到候选质心的距离，再考虑残差分组动态范围，选更易量化的质心；PSAC 对 Key 量化误差投影到前八个主 Query 方向，以低秩 INT8 系数补偿 logit。完成的历史缓存块压成 INT2 残差+质心索引，Triton 融合按需重建，当前活跃块仍保持 BF16。创新集中在注意力敏感度驱动的 Key 压缩。

## Experiment
在 Matrix-Game-2、LingBot-World-v2、HY-World 1.5 三个视频世界模型及两个普通视频模型上，比较 BF16、QVG、KIVI；93 帧、480p/720p。480p HY-World 的 QVG→QuantWM：PSNR 16.118→18.449、LPIPS 0.2114→0.1082、Top-1 跨时空令牌偏移 61.36%→13.92%；五模型平均偏移 51.55%→15.31%。HY 消融：仅 QSAC 偏移 38.17%，仅 PSAC 22.90%，合用 13.92%。LongCat 的缓存 21.709→3.625 GiB，整体最高压缩 6.20 倍。HY 的生成延迟 112.17→118.75 秒（+5.87%），LongCat 因数据传输减少则快 17.78%。VBench Temporal 分数对可见闪烁不敏感；一分种视频附录仍有相似趋势。

## Value
若团队需要长视频世界模型部署或多分支采样，本工作对缓存压缩和时空一致性评测有直接价值。应同时测 BF16 参考逐帧质量、令牌选择偏移与交互行为，而非仅测 VBench。

## Strengths
Key/Value 分离定位问题；方法推导与消融互相支持；报告真实打包缓存、系统延迟和多模型/分辨率结果。

## Weaknesses
未测动作遵从性、长期物理一致性或规划成功率，视频质量改善不等同世界模型决策收益。压缩比含 BF16 质心、INT8 校正和活跃块开销，依赖具体缓存布局；部分 GPU 常驻模型有约 5–6% 延迟增加。

## Future Work
作者未列具体方向；可评估量化对长时交互控制、反事实动作排序及更长缓存的影响。

## Rating
创新度评分：3/5 - 对视频模型 Key 量化失真有针对性诊断和两项补偿，但属于已有缓存量化框架的增量改进。
相关度评分：3/3 (Core) - 直接服务长视频世界模型的低内存推理与时间一致性。

## TL;DR
以历史查询敏感度和低秩补偿稳定视频世界模型的两位缓存量化；部署与评测值得精读。
