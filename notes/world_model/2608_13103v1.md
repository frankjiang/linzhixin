# S2-HWM: Sparse Event-Structured Hierarchical World Model for Long-Horizon Surgical Robot Manipulation

## Insight

长任务不一定需要把 primitive world model 滚得更远；若从 latent dynamics 中学习“何时发生有意义的交互变化”，可在边界间直接预测下一 stochastic state、持续时间和累计奖励，以较少递归步覆盖更长物理时间。相同 sparse event evidence 同时决定 manager 何时换 latent goal、也构造 event transition，因而把时间抽象与控制对齐。消融显示固定 15 步换 goal、去 ETM、去层级 policy 都显著退化，且 ETM 的收益在重复任务/扰动中从 7.4 点扩大到 16.6/20.7 点，支持其长时 credit assignment 解释。

## Motivation

外科 PegTransfer 包含接近、抓取、运输、对齐、释放，阶段长度随状态而变且奖励稀疏。Dreamer 在 primitive step 上想象，手工阶段又难准确对齐接触边界。已有 Director/THICK 已研究层级 latent goal 与自适应时间抽象，本文要把 learned event boundary 同时用于 manager–worker 控制和跨事件 world model，以改善长时 sparse-reward 学习。

## Method

底层为 DreamerV3 RSSM，stochastic z_t、recurrent h_t 与持久 context m_t 组成 feature f_t。context network 从前态/动作提出 m̃_t 与逐维 gate ρ_t，直通二值化 g_t=ST(ρ_t) 作为稀疏 event evidence，并以正则限制频繁更新。接受规则把 g_t 转为不等长边界 τ_i。

manager 在边界 feature F_i 上采样离散 code c_i，经 codebook 得 latent goal η_i；worker 在该段内每步按 (f_t,η_i) 输出九元离散 primitive action。另一接受规则用同一 evidence 构造段 [τ_i,τ_{i+1})。Event Transition Model 以边界 state [z,m] 为输入，用 categorical transition mode 表达多模态，预测下一边界 z、duration Δ 和段累计 reward R；posterior 用真实下一边界推断 mode，prior 供 imagination。primitive RSSM rollout 给 B_short，再串联 K 个 ETM 事件并按 γ^Δ 折扣得到 B_event，两者加权为 manager bootstrap；worker 仍使用 primitive actor–critic。

## Experiment

- 仅用随机化 SurRoL PegTransfer 模拟任务，观察为 GAS 的 DSA4-depth 四通道 64×64，动作含六方向平移、两 yaw 和 gripper toggle。每种方法 3 seeds，每 seed 的 checkpoint 测 50 episode。
- 约 300k steps 的匹配 checkpoint 上，S2-HWM 单次 transfer 成功率 98.7±2.3%，GASDreamerV3 为 76.0±12.0；PPO、DreamerV2 均为 0。主对照共享 DSA frontend、DreamerV3 primitive backbone、动作和随机化。
- 两次连续 transfer（最多 800 步）为 91.3±6.1% vs 77.3±18.6%；第二次 transfer 人工 drop 扰动为 88.0±5.3% vs 65.3±14.0%。
- 固定 15 步 manager 更新、去 ETM、去层级 policy 的单任务成功率分别 80.7±28.3、91.3±5.0、68.0±20.3；扰动场景降至 63.3±55.1、67.3±30.0、46.0±30.0，三者均必要，但仅 3 seeds 导致部分方差极大。
- ETM 与 policy-conditioned RSSM 从同一事件边界起步，按各自 one-event MSE 归一化；ETM 在前三事件保持接近基准、之后均值增长更慢，但长 horizon 置信带重叠，且没有绝对误差。
- manager code 事后按语义 phase 分组后具有不同动作偏好（如 grasp-lift 的 z+ 占 41%），说明学到结构化行为；但标签来自 seed-0 policy 的后验解释，不能证明 code 等同真实阶段。

## Value

这篇对 Dreamer 类隐式世界模型很有启发：时间尺度不应固定，event boundary 本身可作为 latent world model 与 hierarchical policy 的共享接口；event model 还可用 duration-aware discount 直接延伸价值，而不生成所有中间态。它把 THICK 风格自适应事件预测落到 surgical manipulation 并与 manager update 强绑定，但只在单一简化仿真任务上验证，通用性尚弱。

## Strengths

- 同一 learned event evidence 贯通表示、goal schedule、训练 segment 与 high-level bootstrap，设计内聚。
- 与最强 GASDreamerV3 主对照尽量共享视觉前端、动作接口和 primitive backbone，较能隔离层级事件结构。
- 对 hierarchy、event timing、ETM 分别消融，并加入重复任务和外部 drop 压力测试。
- 报告 duration/accumulated reward 的 semi-Markov 式 event transition，而非只学固定 stride latent。
- 对 post-hoc phase 和归一化 ETM 曲线的证据边界表述较谨慎。

## Weaknesses

- 只评一个 SurRoL PegTransfer 任务、单物体/九离散动作，没有真实手术机器人、连续控制或跨任务迁移。
- 与 THICK 的核心机制高度接近；主要新增是与 manager–worker 控制共享 event evidence，方法原创性有限于组合与应用。
- 仅 3 seeds，多个消融 SD 达 30–56%，统计稳定性不足；未报告显著性、样本效率面积或超参数敏感性。
- PPO/DreamerV2 没有 DSA 前端，0% 结果不是严格公平基线；真正有意义的比较主要只有 GASDreamerV3。
- ETM 多步误差按各自 one-event MSE 归一化，掩盖绝对准确率；长 horizon 置信区间重叠，预测优势证据偏弱。
- event evidence 的稀疏率、边界与真实接触转移的 precision/recall、duration/reward 预测误差均未定量报告。
- repeated transfer 只是同任务重复，外部 drop 也是简单扰动，不足以证明一般长时规划或 recovery。

## Future Work

作者明确计划扩展到更多外科任务和真实物理机器人。还应评估连续/双臂控制、跨任务共享 event code、边界可解释性和绝对多步预测，加入更多种子及与 THICK/Director/options 的严格对照，并让 ETM 支持不确定性驱动的 replanning 与恢复。

以学习事件边界连接 Dreamer 世界模型和层级控制，单任务增益大但泛化未证，值得精读。
