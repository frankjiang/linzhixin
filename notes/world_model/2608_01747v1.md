# Ten Years of Deep Learning for Wireless Communications: From Learned Blocks to Deployable Wireless Intelligence

## Insight

本文是观点式综述，核心判断是无线深度学习经历了三次扩展：从替代信道估计、检测和资源分配模块，到端到端/语义通信重定义目标，再到在非平稳、低延迟、低能耗和标准化约束下追求可部署智能。作者据此推论，下一阶段不能只扩模型，而应明确 learned component 的功能边界、物理适用域与接口；“wireless world model”只作为未来设想出现，需要联合无线测量、感知和网络上下文，预测候选控制下的无线环境变化。全文没有提出或验证该模型，因此 insight 主要是领域路线图而非可检验技术结论。

## Motivation

无线系统中的信道、硬件、干扰和流量具有模型失配与非平稳性，深度学习能以离线训练换取快速在线推理，但任务专用模型常难跨部署泛化，训练、反馈和模型交换本身又消耗通信资源。文章试图总结十年演进并讨论标准化、基础模型、world model 和 agentic wireless intelligence。问题对无线通信有意义，但与视频、3D 或 JEPA/Dreamer 世界模型基本无关。

## Method

文章不是系统综述或新算法，而是按三个主题做叙述性组织：一是 learned functional modules，包括 OFDM 信道估计/检测、CSI 压缩、WMMSE 模仿和深度展开；二是端到端 transceiver、deep joint source–channel coding、语义/任务导向通信和无线联邦学习；三是少样本适配、无线 foundation model 与 edge efficiency。最后提出标准化元数据/有效范围、multimodal wireless world model 和受控工具调用的 agentic loop。

文献选择主要围绕作者观点列举 15 篇代表工作，没有搜索策略、纳入标准、定量汇总或方法比较表。所谓 world model 被定义为对无线传播和网络动作响应的物理约束预测表示，但没有架构、目标、数据或实验。

## Experiment

无新实验、消融或定量评估。文章只引用既有案例说明神经 OFDM、CsiNet、DetNet、DeepSC、无线联邦学习、meta-demodulation 和无线多任务基础模型等方向，图示均为概念架构。因而不能从本文判断任何 world-model 方法的性能、泛化或部署代价。

## Value

对无线 AI 入门者，它提供一条简洁的历史脉络，并强调模型成本应计入 pilot、反馈、信令、更新、能耗和协议时限，而非只看 FLOPs；“模型有效域、置信度与传统算法 fallback 应进入标准”也有一般系统价值。对本研究方向，仅能借鉴物理 grounding、action-conditioned radio dynamics 和接口标准化的抽象原则，不值得投入世界模型阅读时间。

## Strengths

- 历史结构清晰，把模块替代、目标重构和部署约束串成一条演进线。
- 强调模型推理成本之外的测量、通信、适配和协议系统成本，工程视角合理。
- 对标准化提出有效域、元数据、不确定性和 fallback 等具体关注点。
- 没有把无线 world model 包装成已有成果，明确其仍需动作条件动力学与不确定性。

## Weaknesses

- 属于选择性叙述综述，仅 15 篇参考文献，覆盖和证据不足以支撑“十年全景”的标题。
- 没有文献检索/筛选方法、分类统计、统一基准或批判性比较，无法复现综述结论。
- 对 foundation model、world model 和 agentic system 的讨论高度概念化，缺少技术定义和风险边界。
- “通信 anytime/anywhere/any means”等表述宏大，但没有可衡量目标或优先级。
- 不涉及视觉视频、3D 表征、latent imagination、JEPA 或 Dreamer。

## Future Work

作者提出三类未来方向：为 learned wireless component 标准化功能角色、有效范围和不确定性；构建物理约束、动作条件、含不确定性的多模态无线世界模型；让 agent 通过可信工具在显式权限、可解释轨迹和 fallback 下闭环控制网络。
