# EV-WM: Event-Verified World Models for Long-Horizon Robotic Manipulation

## Insight
核心观察：feature-space world model 可想象未来，但长时操作需要 predicate/event 级进展判断。把 latent future 解码成事件状态，再用 task progress、semantic consistency、physical feasibility、uncertainty 打分，比只优化视觉特征距离更贴近任务成功。

## Motivation
DINO-WM 等 pretrained-feature WM 能规划，但视觉相似不等于任务谓词满足。长时 manipulation 需要知道对象是否移动、抽屉是否打开、接触/放置是否满足。问题对机器人 world model planning 很关键。

## Method
EV-WM 包含冻结视觉 encoder/action-conditioned feature WM、simulator-derived event labels、event predictor/verifier 和 verifier-guided CEM。事件来自 simulator state、BDDL/task rules、check_success。Verifier 分数结合任务进展、语义一致、物理可行、置信度；规划时保留 base feature cost，同时奖励 verified event progress，也可 gating PPO proposals。

## Experiment
PointMaze random-state 从 DINO-WM 0.90 提到 EV-WM 0.94；feature weight 消融显示过低/过高都差。Deformable retrieval-initialized EV-WM-CEM 达 94%。Wall-Single DINO-WM 0.88，EV-WM-CEM final 0.92，archive top50 0.95。LIBERO-goal verifier AUC 0.993947；wine-rack PPO proposal + verifier hybrid 达 97/100。限制是事件监督依赖仿真状态/规则。

## Value
价值明确：给 latent/feature world model 加 predicate-grounded verifier。对机器人规划很实用，建议选读/局部精读。

## Strengths
亮点是价值明确：给 latent/feature world model 加 predicate-grounded verifier。

## Weaknesses
不足是限制是事件监督依赖仿真状态/规则。
