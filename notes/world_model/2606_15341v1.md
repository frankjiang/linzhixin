# CausalDrive: Real-time Causal World Models for Autonomous Driving

## Insight
核心观察：驾驶 world model 不能只做 open-loop 视频预测，还要对 ego action 产生反事实、多智能体反应，并实时运行。作者用 SocioDrive-Bench 去掉 oracle future layout，迫使模型从初始帧、ego trajectory、semantic prompt 学“driving sociology”。

## Motivation
现有驾驶视频 world model 画质强，但多作为离线数据引擎，闭环时易出现 ghost effect、action ignoring、延迟高。自动驾驶需要交互式 neural simulator，用于闭环评估、RL post-training 和 human-in-the-loop。

## Method
CausalDrive 是实时 interactive driving world renderer。基础模型用 Block Causal Attention 做 O(1) streaming；ego trajectory 通过 AdaLN 注入，sociology prompt 通过 cross-attention 注入。Stage 1 训练 continuous flow-matching AR teacher；Stage 2 用 Context-Forced DMD：student 自回归生成 flawed context，冻结 teacher 在该 context 上评估 DMD gradient，校正 exposure bias，压缩到 <=4 steps、>=12 FPS。

## Experiment
评估 closed-loop generation、ghost/collision artifacts、Video2Reward 驱动 RL post-training、human-in-loop simulation。报告 CausalDrive 可到 12 FPS，并使 RL in CausalDrive 训练的策略在真实/Bench2Drive 类指标上更有防御性，表中 RL in CausalDrive 达 DS 90.7，高于多个基线。未来工作是扩展到多相机 surround-view。

## Value
对视频 world model 和自动驾驶仿真核心相关，特别是 context-forced distillation 和 closed-loop 评估。需要注意论文像技术报告，部分 benchmark/数据构造可复现性需验证。

## Strengths
亮点是对视频 world model 和自动驾驶仿真核心相关，特别是 context-forced distillation 和 closed-loop 评估。

## Weaknesses
