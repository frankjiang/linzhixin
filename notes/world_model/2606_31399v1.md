# World-Model Collapse as a Phase Transition

## Insight
核心 insight 是长程语言 agent 的失败更像相变而非平滑退化。观察是在可控 grid 中，state cardinality 稍微跨过临界区域，成功率从 plateau 掉到 collapse floor；世界状态准确率先崩，随后动作有效性才崩。论文用 per-step gold state 证明失败源头是“agent 以为的世界”先坏掉，而不只是最后一步规划差。

## Motivation
论文解决长程 agent 评测只看最终成功率导致机制不可见的问题。同行常用自然任务 benchmark，但状态负载、依赖密度、horizon、branching 等因素纠缠。本文构造可控环境，把 state cardinality 和 dependency density 分开扫描，定位 world-model capacity boundary。与用户关注的隐式/视频/3D 世界模型不是同一技术线，但对“长程 rollout 崩溃”的概念有启发。

## Method
论文构建 GraphNav、ToolDAG、StatefulPuzzle 三个确定性模拟器，确认实验选 StatefulPuzzle。agent 用 Planner/Updater/Self-Diag 三调用 loop，并维护结构化工作记忆。主网格扫描 SC={5,10,20,40}、DD={1,2,4,6}，并做细粒度 SC-Fine、T-Fine、跨模型探测。关键不是建模新算法，而是建立可测的 phase diagram。

## Experiment
claude-haiku-4-5 在 StatefulPuzzle 上表现为清晰 plateau/transition/floor：SC=5 全解，SC=20/40 全崩，SC=10 随 DD 从 100% 降到 20%。SC-Fine 将临界点定位在约 SC*=14；T-Fine 没有类似临界，说明 horizon 是调制因素而非主驱动。跨模型 gpt-4o-mini/GPT-4o/Llama-3 70B 显示边界会移动但形状保留。per-step trace 显示 world-state collapse 领先 action collapse，median lead 约 2 步。

## Value
价值在评测思想：要单独扫描状态负载、依赖密度，并记录模型内部世界状态，而不是只看最终任务分数。对视频/3D 世界模型可类比到长程记忆、rollout drift 和临界长度评测，但没有直接算法或视觉实验，因此相关度有限。
