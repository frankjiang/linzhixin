# World-Task Factorization for Robot Learning

创新度：4/5 | 相关度：2/3

## Insight
核心 Insight：机器人策略的参数空间存在一个天然的**条件独立结构**——world parameters（运动学、传感器、几何、动力学）在不同 task 之间保持不变，而 task parameters（目标优先级、权衡策略、角色分配）在同一 world 约束下变化。这种不对称的条件独立性使得 world/task factorization 成为最简洁且原则性最强的策略分解方式。

理论论证：通过 **Bayesian model evidence** 框架证明，world/task factorization 在 tractable factorization 中最大化 marginal likelihood。关键推导：world/task 模型类的 log-evidence 相对于 end-to-end 模型类的优势为 log(V_e2e / V_world * V_task)，当 world factor 可以用解析模型表示时 V_world ~ 1，从而 Occam factor 显著优于 end-to-end 方法（后者 V_theta ~ |Theta_NN| 指数级大）。

## Motivation
- **问题**：机器人策略如何实现结构化泛化？现有方法要么依赖数据规模让结构自行涌现（foundation model），要么手动设计层次结构（skill library, hierarchical RL），但都没有从原则上回答"应该沿着什么维度分解"。
- **同行做法**：hierarchical RL 按时间尺度分解、skill library 按原语分解、modular network 按发现的专业化分解、foundation model 期望结构从数据涌现。这些方法要么缺乏理论依据，要么 entangle world 和 task。
- **关键性**：是一个根本性问题——在所有可能的分解方式中，哪种分解应该被优先采用？论文论证 world/task 分解应该先于其他所有分解。

## Method
**整体框架**：将策略分解为 world factor（解析的、可组合的物理模型）+ task factor（小型可学习的梯度调制器）。

**World Factor - AICON**：
- 使用 AICON (Active InterCONnect) 框架，将世界建模为有向图 G = (V, E)
- 每个节点 i 是一个 Recursive Estimator (RE)，维护一个世界量（物体位姿、接触模式等）的可微估计
- 每条边 j 是一个 Active Interconnection (AI)，编码物理约束（运动链、几何约束、传感器模型）
- 图天然可组合：新的物理实体只需添加 RE/AI 节点/边
- Cost function 通过图产生 gradient path，梯度沿链式法则传播到 actuator

**Task Factor - Learned Gradient Modulator**：
- 小型策略网络 pi(y_r; theta_task) 输出两个量：
  - kappa_r = softmax(z_kappa)：gradient path 的凸组合权重（选择优先哪些目标）
  - Xi_r = Exp(z_Xi)：Riemannian preconditioner（正定矩阵，决定沿每个梯度方向的步长）
- 动作规则：a^{t+1} = a^t - Xi * sum_p kappa_p * grad_a^p g_k(x^t)
- 策略输出维度为 |Delta^{|P|-1}| x S^{|a|}_{++}，与状态维度无关
- 训练：PPO (RL) 或 cross-entropy on expert gradient-path selections (LD)

**关键性质**（直接来自 factorization）：
1. 学习低维：策略只输出梯度组合权重，不输出 motor commands
2. 组合性：添加新 RE/AI 不需要重训 task factor
3. Sim-to-real transfer：只需替换 world factor 中的传感器模块

## Experiment
- **三个任务**：
  1. **Search**：四旋翼+地面机器人协同搜索目标（2D，combinatorial，类 TSP）
  2. **Handover**：两台 Franka Panda 机械臂协作递物+避障（高自由度连续控制）
  3. **Pressure Plate**：多机器人协作踩压力板+穿门（角色分配+部分可观测）

- **基线**：
  - 纯学习：MLP、RNN、Mamba、Transformer（全部接近零性能）
  - 纯解析：Max-Grad (AICON without modulation)、TSP planner
  - 本文：RL (sum reward) + LD (10 demonstrations)

- **效果 (Q1)**：所有 end-to-end 基线在三个任务中均崩溃（接近 0），世界-任务分解后的方法在所有任务中有效。RL 和 LD 均在仅 100-3000 次环境交互内收敛。

- **泛化 (Q3)**：
  - Search: 训练 2-6 targets，zero-shot 泛化至 10 targets（仅 -5% 性能）
  - Pressure Plate: 训练 3-4 robots，泛化至 6 robots
  - Handover: 训练 1 obstacle，泛化至 4 obstacles

- **OOD 组合性 (Q4)**：
  - Search: 插入从未见过的静态障碍物，保持高成功率
  - Handover: 变化机器人位姿、障碍物大小/形状/类型、物体位姿，保持高成功率
  - Pressure Plate: 不同障碍物配置下保持有效

- **Sim-to-Real (Q5)**：
  - Search: 8/8 成功（真实四旋翼+地面机器人）
  - Handover: 9/10 成功（真实 Franka Panda）
  - Pressure Plate: RL 4/4, LD 3/4

## Value
- **优点**：
  1. 理论基础扎实——Bayesian model evidence 的论证令人信服
  2. 实验设计精巧——三个任务分别 probe 不同维度（combinatorial, continuous dynamics, role assignment）
  3. 结果极其显著——end-to-end 方法全面崩溃 vs. 本文方法 sample-efficient + zero-shot generalization + real-world transfer
  4. 提供了"应该如何分解策略"这一根本问题的原则性回答

- **启发**：
  1. **World/task 条件独立假设**对于世界模型研究非常有启发——学到的 world model 是否也 entangle 了 task preference？如何在 latent space 实现类似的分解？
  2. **梯度作为 world-task 接口**的思想可以迁移到可微世界模型中——world model 提供可微 dynamics，policy 在梯度空间操作而非直接输出 action
  3. 对 JEPA/Dreamer 类方法的启示：隐式世界模型能否同样利用这种分解来提升 generalization？

- **局限**：依赖可解析建模的 world factor（AICON），当 world 本身需要从数据学习时（如视觉输入、未知动力学）假设不再成立，作者也承认这是最重要的 future work。

## TL;DR
从Bayesian model evidence出发论证world/task分解是机器人策略最优分解，结合解析world model (AICON) + 可学习梯度调制器实现sample-efficient学习和zero-shot sim-to-real transfer。值得精读，理论与实验俱佳，world/task分解思想对世界模型研究有启发。
