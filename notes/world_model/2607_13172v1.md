# Learning Safe Agent Behaviour from Human Preferences and Justifications via World Models

## Insight
论文的 insight 是：在安全关键任务中，世界模型不仅能减少真实环境试错，还能作为“可查询梦境”让人类偏好和安全理由更高效地塑造 reward。Observation 是纯偏好只能学到总体好坏，安全失败类型需要更细粒度解释；推论是把偏好 pair 和 justification 映射成带安全权重的奖励标签，再用模型预测控制部署，可在少量人类反馈下提升安全性。

## Motivation
论文解决无奖励、未知动力学且真实交互昂贵/危险时的安全策略学习。同行如 ReQueST、DROS、DRQV2 或偏好学习方法，要么需要反复生成查询，要么只学偏好不显式利用安全理由，要么依赖真实奖励。问题与 model-based RL 世界模型相关，但不是视频/3D 生成主线。

## Method
DROPJ 分四步：先从离线 reward-free 轨迹训练 VAE+RNN/MDN latent world model；用户在 dream world 中交互，故意探索安全边界；系统从 dream trajectories 采样 segment pairs，展示解码片段并收集偏好与安全理由；用 Bradley-Terry 风格 reward model 学习偏好，其中 safety justification 通过权重 ws、wdef 等改变标签强度，多个理由取最严重项；部署时用 sample-based MPC 在 learned world model 中规划，不训练单独 RL policy。

## Experiment
环境是 Car Racing 和带草地、坑洞、脚本车辆的 Obstacle Car Racing，输入为 RGB 和连续动作。离线数据约 600-800 条轨迹，dream trajectories 10-60 条。实验比较 one-shot 查询与 ReQueST/DROS、偏好 vs 标签、加入 justification 的安全权衡、世界模型数据量、分布偏移和反馈噪声鲁棒性。结果显示 one-shot dream-world feedback 降低计算成本，偏好可接近 oracle reward，加入 justification 后草地区域违规显著下降但 return 有 tradeoff。DROPJ 对 60% 非关键反馈污染仍较鲁棒，关键安全错误超过约 15% 会明显破坏效果。多 justification 实验显示权重能在草地、坑洞、车辆风险间调节。

## Value
对我们有两点启发：世界模型可以作为安全反馈采样器，而不仅是策略 imagination；自然语言 justification 可转成 reward shaping 的结构信号。但该工作关注 2D driving/RL safety，世界模型本身是经典 latent dynamics，不是现代视频/3D/JEPA 方向。

## Strengths
把偏好、解释和世界模型 MPC 连成闭环；强调安全反馈类型和权重，而非单一偏好；多组鲁棒性和反馈污染分析细致；避免在真实环境中大量危险试错。

## Weaknesses
世界模型架构较传统；实验域简单，离真实机器人/自动驾驶远；reward label 映射和安全权重依赖人工设定；解码 dream clips 的真实感和反馈质量可能成为瓶颈。

## Future Work
作者提出在真实硬件或实验室机器人导航中验证，扩展到更多领域，并用 evolutionary strategies 或软约束自动学习 justification weights。
