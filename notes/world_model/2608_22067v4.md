# DELE-w0.5: Inferring Action from Future Latent State for Robotic Manipulation

## Insight

论文提出的 observation 有价值：机器人控制只需预测与动作相关的端点物理状态，未必需要为每个中间时刻生成高维、外观敏感的视频；因此可把未来 endpoint latent 作为辅助监督，减少 video WAM 的 token 与去噪成本。DELE-w0.5 联合 flow-match 一个 60-step action chunk 和未来 observation latent，训练时让未来 token 读取动作，以迫使共享网络学习动作—结果一致性；推理时删掉未来 token，只生成动作。

但论文声称“从预测未来状态推断动作”的关键因果解释不成立。Fig. 3 与 Sec. 4.4 明确规定：action token 只读取语言、当前观察和 action group，**不能访问未来 observation**；只有 future token 读取 action，推理时 future group 又被移除。因此实现的条件方向是 action→future，策略仍为 $p(A_t\mid L,O_t,q_t)$，future-state loss 是多任务辅助目标，而不是动作生成的显式中间变量。实机结果只能证明这套联合训练系统很强，不能证明未来状态驱动了动作或视频预测是不必要的。

## Motivation

视频生成式 World-Action Model 把未来视觉轨迹和机器人动作共同去噪，能够注入时空先验，但 dense video latent 包含大量与控制无关的纹理/外观，增加训练成本和部署 latency；多步视频也不是执行动作所必需。纯 VLA 直接输出动作更快，却缺少“动作后世界会怎样”的辅助结构。

论文试图寻找中间路线：保留动作条件未来状态预测，但只预测一个 compact endpoint latent，不生成中间视频。这是具身隐式世界模型的重要问题；若因果接口成立，可把 WAM 的模拟能力压缩进实时 policy。然而本文的 mask 让 endpoint 只服务训练辅助监督，尚未建立作者所宣称的 future-state→action bridge。

## Method

输入为语言、proprioception 和三个 RGB 视图（头部+双腕）。Qwen3 编码文本，DINO-v3 编码当前及未来图像，经线性投影统一到 hidden dim 1024。action chunk 长度 $H=60$；单臂每步为 7-DoF（3D 位移、3D Euler rotation、二值 gripper），双臂为 14-DoF。

架构分 condition/noise 两条流。condition stream 将语言和当前视觉 token 送入 single-stream Transformer；noise stream 对 action 与未来 latent 分别做线性插值加噪 $x_\tau=\tau x+(1-\tau)\epsilon$。两流经 AdaLN 调制的 QKV 与 masked attention 融合，分别回归动作 velocity 和 endpoint-latent velocity，目标为 $\mathcal L=\mathcal L_a+\lambda\mathcal L_o$。

训练 mask 的精确语义是：语言与当前观察相互双向可见且不读取预测目标；action 可读 $\{L,O_t,A_t\}$，但不可读 $O_{t+\Delta t}$；future observation 可读所有 groups。推理直接删除 future observation groups，保留相同的动作可见关系。因而“无视频生成”的低延迟属实，但 future latent 没有在推理时被先预测或作为动作条件。

论文没有披露总参数量、预训练数据与步数、目标机器人数据集规模、optimizer、$\lambda$、flow integration steps 等关键训练细节。创新主要是 endpoint auxiliary target 与高效双流实现，而不是一个已验证的显式 inverse-dynamics 路径。

## Experiment

在同一 Astribot S1 双臂机器人和固定真实场景上评测 Door opening、Pepsi retrieval、Add ice、Microwave popcorn 四个长时任务。每项被分成严格有序的物理阶段，指标为最高连续完成阶段占比（normalized progress）和完整任务成功率。DELE 与 7 个 VLA baseline 均用同一 task data 微调约 3 epochs；每模型每任务 20 次，共 $8\times4\times20=640$ trials。注意 640 是所有八种方法的总和，DELE 自身只有 80 次。

- DELE 在 Door/Pepsi/Add ice/Microwave 的 progress 为 95.0/82.0/63.3/85.0%，success 为 80/65/45/60%，macro progress 81.3%，overall success 62.5%=50/80（Table 2，PDF 第 12 页）。最强 baseline progress 是 GWP0.5 的 61.3%，最强 success 是 XR0 的 30.0%；DELE 分别高 20.1 和 32.5 points。
- stage-reach 显示 DELE 的完整成功数为 16/13/9/12；Door 的协同旋转/推阶段 20/20 到达，Pepsi 在取出罐体后主要掉在交接/关门，Add ice 在取得/倾倒冰块处掉点，Microwave 16/20 关门、12/20 启动加热（Fig. 6，第 13 页）。这比只报最终成功率更能定位长时失败。
- RTX 4090 上 median core-model inference latency 为 87.5 ms，但明确排除了 network transfer、image decoding、action projection、IK、trajectory processing 与 robot execution（Fig. 5，第 12 页）。DELE 四任务成功轨迹的平均完成时间分别为 16.66/45.92/46.27/39.50 s，属于 success-conditional 指标。
- 额外干预案例中，微波门被中途关闭后策略会保留爆米花、重新开门，甚至用手中包装推开窄门。作者只给定性观察，并谨慎称为 early evidence，而非 emergence 的量化结论（第 14 页）。

论文没有报告 $\lambda=0$（无未来状态目标）、不同 endpoint horizon、仅 action head、或同 backbone 的 dense-video WAM 消融，因此核心主张没有被直接检验。

## Value

这项工作最值得借鉴的是把 dense future video 压缩成一个 endpoint representation，并用严格有序的 stage progress 评测长时操作。若辅助未来目标确实能改善 action representation，这是一种计算上简洁的隐式 world-model regularizer；80 次自身实机试验与四类接触/双臂任务也说明系统具有较强工程价值。

然而论文的命名与概率叙事比实现更强：动作既不读取预测未来状态，推理也不生成它。对我们而言，应把 DELE 视为“带动作条件端点预测辅助任务的 VLA”，而不是已证明“通过未来 latent 推断动作”的 WAM。阅读价值主要在 attention mask 的反例、实机协议和 endpoint auxiliary idea；核心机制结论需保持怀疑。

## Strengths

- endpoint latent 取代 dense video 是简洁、计算友好的设计方向，适合实时机器人策略。
- 四个任务涵盖关节机构、目标取回、双手交接、工具使用、受限插入和终态验证，难度不只是一拍抓取。
- 8 个模型、4 个任务、每格 20 次的真实机器人统一协议规模可观；成功条件是可观察的完整物理状态。
- ordered-stage progress 与 stage-reach heatmap 揭示“会开始但不能收尾”的差别，避免单一 binary success 丢失信息。
- 论文透明说明 640 trials 的构成、core latency 的排除项、completion time 只统计成功轨迹，并把 emergence 限定为 early evidence。

## Weaknesses

- 最严重的问题是 causal claim 与 mask 矛盾：动作 token 在训练中不能读取 future observation，推理还删除 future group；数据流只支持 action→future 的辅助预测，不能支持标题所称 future latent→action（第 9-10 页）。
- 没有 $\lambda=0$/去除 future branch 的消融，也没有相同 backbone、数据与预算下的 dense-video WAM；因此无法证明端点辅助目标带来增益，更无法证明视频生成“不必要”。
- 七个对照主要是 VLA；即便 GWP0.5 与世界模型相关，各模型沿用官方配置，预训练、参数量、action representation 和优化预算不同。“相同 task data、三轮微调”不足以形成方法级公平对照。
- 论文缺少模型规模、预训练语料/步数、机器人数据量、optimizer、$\lambda$ 与采样步数等基本信息，几乎无法复现实验或判断训练是否真的更便宜。
- 每任务只有固定 scene 下 20 次，无置信区间、随机种子、起始位姿范围或 OOD 环境；5% 的成功率步长使小差异不稳健。
- 87.5 ms 只是 core latency，排除完整 perception-to-control pipeline；completion time 又只在成功试验上统计，不能代表所有 rollout 的期望成本。
- 摘要的“640 real-robot trials”容易让人误以为是本方法样本数，实际 DELE 只有 80；没有训练成本或视频-WAM latency 的直接等硬件对照。
- 没有 limitations 小节；两条“涌现”行为只是不在示范中的选取案例，没有成功率、干预集合或 baseline，不能证明系统性组合泛化。

## Future Work

作者没有提出具体、可执行的 future-work 项目；结论仅笼统称 action-relevant future-state prediction 是通向 scalable/deployable robot intelligence 的 promising direction，并未说明下一步实验或局限。

我们的推断是：首先应让动作显式条件于先预测/采样的 endpoint state，或加入 inverse-dynamics head，从而使因果结构与标题一致；随后做 $\lambda$、horizon、endpoint/video target 的等容量消融，公开完整训练配方，并在随机场景、未见对象与外部干预集上测 OOD、uncertainty 和完整端到端 latency。

## Rating

创新度评分：2/5 - 用 endpoint latent 作为轻量未来辅助目标有一定工程新意，实机结果强，但没有核心消融，且“从未来状态推断动作”的主张与实际注意力路径矛盾。
相关度评分：3/3 (Core) - 直接讨论 World-Action Model、潜在未来状态和机器人动作生成，属于隐式/具身世界模型核心方向。

## TL;DR

用未来端点潜状态作辅助目标并省去视频生成，实机结果强但并非由未来状态推动作，可选读。
