# Multi-Agent Embodied Autonomous Driving: From V2X Information Exchange to Shared World Models

## Insight
论文的 insight 是综述式框架：V2X 不应只被看作信息交换，而应走向 Shared World Models，即跨车辆/基础设施维护可预测、可对齐、可用于协同决策的共享状态。作者把多智能体自动驾驶证据拆成三层：C1 cross-agent state alignment，C2 intent/plan alignment，C3 coordinated downstream action。

## Motivation
单车自动驾驶受限于遮挡、长程预测和密集交互；协同感知/V2X 能缓解，但很多系统只是交换检测框、特征或意图，未真正形成可驱动规划的共享预测状态。已有综述分别覆盖协同感知、V2X、MARL、E2E、foundation model 或 world model，缺少系统层视角来问“共享信息如何变成共享状态、意图对齐和协同行动”。

## Method
这是超过 380 篇文献的 survey，不提出算法。论文建立 MAEAD loop：local observation/V2X communication -> shared-state construction -> SWM-supported intent and plan alignment -> coordinated planning/action -> execution feedback。技术章节覆盖 early/intermediate/late collaborative perception、通信约束、语义知识和意图通信、MARL/生成式规划、端到端协同驾驶、LLM/VLM/VLA/world-model 方法、仿真与数据引擎。表格按 C1/C2/C3 对代表工作做保守证据编码。

## Experiment
无新实验。主要输出是 taxonomy、方法表和资源表。作者总结当前证据集中在仿真、离线协议和 curated benchmark；foundation-model coordination 缺少实时安全保证；闭环协同评测仍不足。未来方向包括可扩展通信预算、open-set coordination、trustworthiness/security、human/mixed traffic、可验证共享状态维护等。

## Value
作为综述，它对自动驾驶 shared world model 的概念整理有参考价值，尤其是 C1/C2/C3 证据标准能帮助读相关论文时避免把“通信/感知提升”误读成“协同世界模型”。但它不是方法论文，术语 SWM 也更像组织框架而非已成熟技术定义。对视频/3D/隐式世界模型的直接技术启发有限，适合用于构建自动驾驶世界模型阅读地图。
