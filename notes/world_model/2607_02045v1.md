# PWM-ArtGen: Part World Model for Articulated Object Generation

## Insight
论文 insight 是单张图像生成可动 3D 物体时，不能只预测静态形状或直接回归关节参数；需要把“部件视觉动态”和“运动学结构”联合建模。Observation 是静态图像缺少铰链、滑轨、旋转轴等可动线索，先生成视频再估计运动学会积累误差。作者据此提出 Part World Model，通过动作后的视觉变化来约束部件和关节。

## Motivation
论文解决 single-image articulated 3D object generation。同行包括 URDFormer、NAP、SINGAPO、Articulate-Anything，以及 DragAPart/Puppet-Master 等视觉动态方法；多数要么依赖图结构先验，要么对真实照片泛化有限，要么不能同时输出可执行运动学。该问题直接属于 3D world model/可交互对象建模。

## Method
PWM-ArtGen 共同建模 part-level visual dynamics 和 kinematic parameters。模型有动作/运动学分支与图像分支，采用解耦 diffusion timestep；Visual Dynamics Regularizer 将视觉 hidden states 与动作后观测的 DINOv2 patch features 对齐；训练时结合带动作标注的 PM 数据和 action-free 的 PM-R photorealistic pairs。输出包括 articulated asset、part graph 和 kinematics。

## Experiment
训练集 PM 含 473 objects/985 parts，测试 PM 77 objects/155 parts，并在 ACD 135 objects/455 parts 上零样本评估。对比 URDFormer、NAP、SINGAPO、Articulate-Anything 等。ACD 上 GT graph 设置 Ours 达到 RS-dgIoU 0.5693、AS-dgIoU 0.5790，优于主要基线；自动图设置下定位指标仍有优势，但 graph accuracy 只有 39.34%，AOR 也不总是最好。消融显示 IB、VDR、co-training 均有效；视觉动态任务中 full model PSNR 24.328、LPIPS 0.093。

## Value
对 3D world model 有直接价值：它强调通过可观察动态学习对象 affordance 和运动学，而不是只从静态几何推断。这对可交互 3D asset、机器人操作前的对象建模都值得参考。

## Strengths
任务定义清楚，结合视觉动态和运动学结构；有真实感数据增强和零样本评估；消融较完整，能看出 VDR 和联合训练贡献。

## Weaknesses
自动 part graph 仍明显不稳；对于训练分布外的非标准支撑、复杂铰链和不规则运动会失败；物理约束和碰撞合理性仍较弱。

## Future Work
作者未给出很具体的路线，但失败案例指向更强的结构先验、物理约束、开放类别 part graph 推断和异常关节模式建模。

## Rating
创新度评分：3/5 - 将部件动态、DINO 特征正则和运动学生成结合，有一定新意但仍是组合式改进。
相关度评分：3/3 (Core) - 直接面向可交互 3D/articulated world model，核心相关。

## TL;DR
用部件视觉动态约束单图 articulated 3D 生成，3D 世界模型方向值得精读。
