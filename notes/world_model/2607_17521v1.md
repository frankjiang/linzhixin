# GeoWorldAD: Geometry World Action Model for Autonomous Driving

## Insight
有。Observation 是自动驾驶中的未来规划不能只依赖语义 future state 或当前 BEV，显式 3D 几何既提供空间约束，又能通过未来几何 token 给出短期 anticipatory guidance。推论是把 present multi-scale geometry 与 latent future geometry 接入 action model，可以提升 progress 且不牺牲安全。

## Motivation
解决端到端自动驾驶规划中安全、效率和场景几何 grounding 的问题。同行包括 Epona、DriveLaW、DriveVLA-W0 等 future-state/world-model 方法，以及 DVGT-2 等 dense geometry 方法。关键问题是现有方法要么未来预测缺少几何约束，要么只有当前几何，不能预判短期场景演化。

## Method
三段式。先用 EgoStreamVGGT 从多帧视频提取 ego-aligned multi-scale geometry tokens，并用 camera/depth/point-map reconstruction 监督。再训练 geometry world model：learnable future tokens 通过 Q-Former 式 cross-attention 读取多层当前几何，causal self-attention 建模 2 秒未来，并预测未来深度。最后 action model 用 64 个 trajectory queries，经过 4 个 present-geometry aggregation stage 和 1 个 future-geometry refinement stage，输出 8 个未来 waypoint；训练同时优化 trajectory、score、4D reconstruction、future geometry loss。

## Experiment
NAVSIM v1/v2 closed-loop。v1 上 GeoWorldAD PDMS 91.0，优于 DVGT-2 90.3 和 EponaV2 90.4；NC 99.0、TTC 95.8、EP 85.9。v2 上 EPDMS 90.4，高于 DVGT-2 89.6 和 EponaV2 88.9，NC 99.0、TTC 98.6、EP 89.1。消融中仅当前几何的 GeoAD v1 PDMS 89.3、v2 EPDMS 87.6，加入 future geometry 后分别到 91.0/90.4，主要提升 ego progress。EgoStreamVGGT 深度估计也明显优于 StreamVGGT，OpenScene AbsRel 0.141 vs 0.236。

## Value
对 3D/video world model 很相关：它把几何 foundation model、latent future geometry 和 action planning 接起来，是自动驾驶 world-action model 的典型路线。值得精读方法和消融。

## Strengths
几何坐标系与 ego trajectory 对齐；当前几何和未来几何分工清晰；NAVSIM v1/v2 指标完整；消融能证明 future geometry 对 progress 的贡献。

## Weaknesses
提升幅度相对强 baseline 不大；planner 仍是固定长度 clip，未真正 streaming；没有真实车闭环；未来 geometry 主要以 depth/token 监督，行为因果建模仍有限。

## Future Work
作者明确提出把 KV caching 集成到 trajectory planner，实现高效 streaming inference。

## Rating
创新度评分：3/5 - 将视频几何 foundation model 与未来几何 world model 接入规划，组合扎实但不是全新范式。
相关度评分：3/3 (Core) - 直接研究 3D/几何世界模型与自动驾驶 action planning。

## TL;DR
GeoWorldAD用ego-aligned当前/未来几何token指导自动驾驶轨迹规划，是3D世界模型方向值得精读的工作。
