# Against the Monolithic Wireless World Model: Why NextG Needs Composable and Agentic Intelligence

## Insight
论证 6G 无线通信领域不应照搬 LLM 的"大一统模型"路线，因为无线数据（CSI 张量、IQ 采样等）缺乏类似文本/图像的自包含可复用 token 基础——其含义依赖配置、模拟器和任务。

## Motivation
批判无线通信领域盲目效仿 LLM 构建 wireless foundation model / wireless world model 的趋势。

## Method
论述性文章。提出 composable and agentic 架构作为替代：通用推理模型编排专用信号处理模型、经典算法、数字孪生和安全检查。

## Experiment
无实验，纯 position paper。

## Value
无线通信领域的 position paper，与视频/3D/隐式世界模型完全无关。
