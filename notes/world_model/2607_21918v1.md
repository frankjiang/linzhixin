# Action-Conditioned World Model for Goal Plane Probe Guidance in Robotic Ultrasound

## Insight
有。论文的 observation 是：超声探头导航的图像变化强烈依赖 6DoF 探头动作，但显式物理仿真难以覆盖接触、组织形变和声学伪影。推论是训练 action-conditioned latent diffusion world model 作为内部 simulator，再用它给目标平面导航策略提供 reward，可以减少对真实机器人试错的依赖。

## Motivation
论文解决机器人超声中如何从当前切面自动移动到标准诊断平面的问题。已有方法多依赖人工扫查、几何先验或直接监督动作预测；纯监督策略容易在偏离专家轨迹后失败，真实机器人 RL 又昂贵。这个问题对医疗机器人很关键，但对通用视频/3D世界模型属于应用型相关。

## Method
世界模型使用 frozen VAE latent 和 Conditional Diffusion Transformer，根据最近图像上下文、相对 6DoF action、时间 offset 与 diffusion step 预测未来 ultrasound latent。动作以归一化平移/旋转和 cosine embedding 表示。

策略部分是 goal-conditioned action predictor：目标库中为每个标准平面保存多个 latent goal samples；temporal transformer 读取最近图像/action上下文和目标，输出 active axis、5-bin motion magnitude 和 stop。训练分两步：先监督学习专家动作，再用冻结 world model 做 actor-critic RL，reward 包含向目标 latent bank 的距离进展、接近度、停止奖励、动作幅度和平滑项。

## Experiment
数据包含 20 名受试者的颈部超声序列：Carotid 184 条、Thyroid 150 条、Random sweep 17 条，按个体划分训练/测试。世界模型评估用 LPIPS/SSIM 和 inverse action recovery；策略评估看离散动作/轴预测准确率，并在真实机器人平台 RM65 + ultrasound S80 + force sensor 上做 20 次试验。

世界模型在结构化目标扫描上能保持较好的中短期预测；random sweep 长期预测明显退化。动作预测中加入 goal 明显提升 active axis 和旋转/平移 bin；RL finetune 进一步改善部分轴。真实机器人成功率：Carotid 两个目标整体约 70%，Thyroid 四个目标整体约 65%，失败多与局部视野、同时多轴调整需求和接触变化有关。

## Value
价值在于把 action-conditioned video/latent diffusion world model 用到真实机器人导航闭环，而不只是离线视频预测。对我们有启发的是，世界模型可作为 learned reward / rollout evaluator，而不是直接生成可视化结果。但任务强领域化，传感模态和解剖场景限制了泛化。

## Strengths
亮点是真实机器人验证；世界模型、goal bank、监督+RL 的闭环设计完整；实验区分不同扫查类型，并承认 random sweep 的难度。

## Weaknesses
数据规模和解剖范围小；世界模型没有显式建模力、接触和生理运动；策略动作是单轴选择，难处理需要多轴同时修正的情况；长期 rollouts 质量有限。

## Future Work
作者指向更大规模多部位数据、加入力/接触建模、支持多轴连续动作、提升长期预测和真实机器人鲁棒性。

## Rating
创新度评分：3/5 - 组合 latent diffusion world model 与机器人超声控制较完整，但方法本身偏应用集成。
相关度评分：2/3 (Related) - 是 action-conditioned 视频/机器人世界模型，但场景过窄，借鉴价值大于直接核心性。

## TL;DR
用潜扩散超声世界模型训练探头导航，机器人视频建模相关但场景较窄，可选读。
