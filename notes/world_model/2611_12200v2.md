# Learning to Act with World Models by Valuing What Comes Next

## Insight
观察：稀疏终局奖励难说明哪一步建立了成功前提，而下一观测文本变化大小也不能代表任务进展。推论：世界模型预测候选动作的后继状态后，可用当前策略的 critic 估计这些状态的成功概率，并把候选间差异转为训练信号。作者从二元终奖、无折扣设定下的 Vπ(s)=成功概率推得候选动作优势差等于后继价值差；再以真实分支结果检验预测排序：ScienceWorld 后期大价值间隔的偏好在结果不同的分支对上约 84% 正确。该恒等式成立于真实价值，单次生成观测加估计 critic 的近似仍会有误差。

## Motivation
文本环境的长任务只有 0/1 终奖。PPO 的 critic 只直接评估执行过的动作；纯观察预测辅助训练未判断变化是否有利；测试时用模型规划会增加部署成本。本文要让同一步未执行候选的预测后果进入 PPO 训练，使只部署策略也能学会先完成必要步骤。

## Method
WM-PPO 在每个训练状态采样四个动作并照常执行第一个；文本世界模型从真实转移学习下一观测，对每个不同候选作一次贪心预测；构造后继 prompt 并由 critic 评分。策略通道把得分最高候选转为组内零均值的 PPO 辅助优势；价值通道以候选后继价值均值作当前状态 critic 的辅助目标，同时继续用真实回报监督。每任务再从共同前缀执行三条真实分支，按过去四轮中不同价值间隔的预测偏好与真实终奖一致程度给两个通道共同门控。策略、critic、世界模型是同一冻结 Qwen3-4B 基座上的独立 LoRA；推理时只用策略。

## Experiment
ALFWorld 家务文本任务与 ScienceWorld 科学文本任务，40 步内完成给 1 分。对比 PPO、GRPO/GiGPO、多种 PPO 变体、直接 Q 值、固定世界模型、预测辅助损失和教师蒸馏；WM-PPO 与 PPO 等关键基线各三次训练运行，按实际执行的环境步骤对齐。ALFWorld 102k 步时 WM-PPO greedy 成功率 87.5%，PPO-160 的 105k 步为 63.5%；ScienceWorld 128k 步时为 52.9%，PPO-160 的 113k 步为 39.3%，最佳 PPO 改进 SO-PPO 为 46.5%。仅策略通道在 ScienceWorld 为 47.2%，说明价值通道另增 5.8 点；固定世界模型仅 38.7%。门控消融中首个运行在 ScienceWorld 为 54.9%，无门控 44.0%。训练墙钟时间为匹配 PPO 的约 1.3–1.6 倍、GPU 时约 2.7–3.8 倍；额外的 Sokoban 单次运行达到 87.0%。

## Value
对模型辅助强化学习的可迁移启发是：想象轨迹信号需以真实分支校准可靠性，并区分学习时模型成本与部署成本。但本文完全是文本行动环境，不提供视频、3D 或 JEPA 表征的实证。

## Strengths
把动力学预测与任务价值连接，分别验证候选排序、单次离线更新及完整训练；结构消融包含直接 Q 值、固定模型、双通道和门控；详细披露交互及 GPU 开销。

## Weaknesses
主实验只用一种 4B 语言模型及两个文本环境；分支需要可重放前缀，偏向确定性模拟器；预测只用单个贪心下一观测，忽略随机性和远期动力学；奖励与成功概率的关系依赖二元终奖、无折扣设定。不同方法的训练任务覆盖率与计算预算不完全一致，多数扩展基线仅单次运行，显著性检验未作多重比较校正。

## Future Work
作者指出需处理小间隔且不可靠的候选比较、预测不确定性和长程影响；推广到随机且不可精确重放的环境也待验证。

## Rating
创新度评分：2/5 - 将已有模型预测、后继价值与 PPO 组内优势结合并校准，文本智能体训练有效，但对目标世界模型方向技术贡献有限。
相关度评分：0/3 (Noise) - 实验和模型对象都是纯文本语言智能体，没有视频、3D 或 JEPA/Dreamer 式视觉潜在表征。

## TL;DR
文本世界模型预测候选动作后用 critic 和真实分支校准 PPO 训练，效果显著但属纯文本任务，可跳过。
