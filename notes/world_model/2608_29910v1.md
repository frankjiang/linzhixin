# Matrix-Game 3.5: Enhancing Real-Time Streaming Interactive World Models with Patch Memory

## Insight

作者将长时一致性拆成三个必须联立的问题：记住什么、在新视角的哪里重现、该内容应保持静态还是继续演化。其推论是，整帧记忆过粗、全局 3D 重建过硬，3D 对齐的 latent patch 可在显式几何约束与生成自由度之间折中；再把静态场景写入 patch memory、动态主体写入 reference tokens，避免把同一运动物体的多时刻状态融合成鬼影。论文以 one-minute camera-control 指标、同位姿重访指标和去除 reference token 的匹配定性样例支持这一设计，但没有完整数值组件消融。

## Motivation

实时交互视频模型是闭环自回归系统，误差会随 rollout 累积，有限上下文又使远期重访、跨视角几何、主体身份和实时速度相互牵制。已有 latent/KV 记忆隐式且难以定位；整帧几何检索只能从原视角整体取回；点云或 splat 约束强却难生成未见内容。该问题是可持续交互世界生成的核心瓶颈，而不是单纯长视频画质问题。

## Method

系统基于 Wan2.2-TI2V-5B，包含三条主线。第一，统一 pose-aware token sequence：anchor、历史 context、目标 noisy latent、patch memory 和动态主体 reference prefix 进入同一 self-attention；tiled-PRoPE 将 4×4 world-to-image 投影矩阵平铺并乘到完整时空 RoPE 通道，使一次 attention 同时编码时间差和相对相机投影，且 patch-memory/tiled-PRoPE 不增加可学习参数。第二，patch memory 用预测的 metric depth、内外参把历史 VAE latent patch 反投影到 3D，按目标视锥做 coverage-aware 至多五帧检索，经 z-buffer 去遮挡后散射到目标画布；空洞不入序列。YOLO track 加跨帧 3D 重投影区分静/动态区域，动态主体由四张因果可用参考图压缩成约一帧 token，并配合 context 替换和 subject-region auxiliary loss。第三，先用 InternVideo2 特征空间的 Perceptual Flow Matching 做 causal adaptation，再在学生自 rollout、在线记忆条件下做 curriculum DMD，得到三步因果生成器；INT8 DiT、GPU memory retrieval 与 75% 剪枝 MG-LightVAE 用于实时化。

## Experiment

主表在 SANA-WM one-minute Simple/Hard trajectory 上评测“蒸馏前”模型（PDF p.14）。Matrix-Game 3.5 的相机 R/T/CMC 误差分别为 Simple 1.63/1.10/1.11、Hard 2.70/1.25/1.33，均为表中最佳；次优 rotation error 为 4.50/8.34。VBench Overall 为 80.14/80.85，低于各 split 最佳 81.82/81.89；重访 SSIM 为 0.439/0.414（最佳），PSNR 14.56/14.14，LPIPS 0.439/0.474。末 10 秒 imaging quality 为 70.56/71.12，下降 3.24/2.40，并非最优。预蒸馏模型单 H100 占 77.0 GB、10.9 videos/hour。三步 INT8 学生在单 H100、1280×704、batch 1 下声称端到端最高 20 FPS，但只给 60 秒定性序列（pp.17, 19）。reference-token 去除实验在 300–400 帧处展示士兵装备、角色武器和车辆饰条的身份漂移改善（p.17），没有数值。训练细节包括 PFM 10k 步、self-rollout DMD 1k outer steps；论文未披露基础模型语料规模和完整训练步数。

## Value

这是一个覆盖表示、记忆、动态主体、蒸馏和推理优化的完整交互视频系统，patch 级 3D 检索与相机位置编码的统一尤其值得借鉴。它对“3D 记忆作为生成条件、而非硬渲染结果”的折中给出清晰范式。但目前更像高质量系统报告：缺少组件因果归因，且实时学生的质量未被主 benchmark 量化，故不宜仅凭 20 FPS 与预蒸馏主表推断完整实时系统全面领先。

## Strengths

- patch memory 的 3D lift、coverage selection、z-buffer、fractional RoPE 坐标和空洞丢弃描述具体，工程可复现性较强。
- 静态几何与动态身份分离直击长时 ghosting/identity drift，reference 只来自因果历史，避免未来泄漏。
- one-minute 评测同时覆盖相机精度、重访、视觉质量、时间退化和效率，camera control 提升显著。
- 训练语料覆盖 Unreal、开放世界游戏和互联网视频，并给出几何、语义、身份和质量筛选管线。

## Weaknesses

- 没有 patch memory、tiled-PRoPE、context memory、静动态分离、subject loss、PFM 与 self-rollout DMD 的数值消融；唯一去除 reference token 的证据是三组挑选的定性帧（p.17），无法归因各组件贡献。
- 主量化表明确评测蒸馏前模型，而 20 FPS 三步学生仅有定性结果；没有报告蒸馏前后相机误差、VBench、重访指标或退化幅度，实时质量主张缺少闭环证据。
- 评测主要是预设相机轨迹与视觉重访，prompt 事件还依赖异步 VLM 每段重写；没有键鼠动作成功率、物体交互、物理一致性或 agent planning 指标，距离通用交互世界模型仍远。
- 系统依赖 VGGT-Omega、Depth Anything 3、YOLO、VLM 和每段重注册；外部估计误差、离线标注成本与在线分段更新延迟未量化。作者也承认几何来自外部估计器（p.19）。
- VBench 和长期退化并非全面领先：Hard VBench 80.85 低于 81.89，Simple/Hard 的 $\Delta IQ$ 3.24/2.40 也弱于若干基线；“不牺牲质量”的表述应更克制。
- 基础训练语料的样本量、训练步数与重复种子未给出，且代码/权重链接不等于完整数据管线可复现。

## Future Work

- 作者明确提出：为离开视野的动态实体维护可演化的持久状态；让生成器联合预测自身深度和相机姿态；扩展到更丰富的 embodied action/物理交互、更大骨干和更长时域（p.19）。
- 我们推断：首要工作应是完整组件消融和蒸馏学生的同协议量化，并加入闭环用户动作、碰撞/物体状态持久性以及外部几何失败压力测试。

## Rating

创新度评分：3/5 - patch 级 3D 记忆、PRoPE 改造与蒸馏的系统组合扎实，但多数基础模块来自既有工作且缺少充分消融。
相关度评分：3/3 (Core) - 直接面向实时、长时、3D 几何一致的交互视频世界模型。

## TL;DR

该系统以3D补丁记忆、位置编码与渐进蒸馏实现分钟级交互生成；系统完整但消融不足，值得精读。
