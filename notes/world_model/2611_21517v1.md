# Lazy-MOSAIC: Accelerating Skill-Centric Manipulation Planning with Learned Skill-Effect World Models

## Insight
观察：在接触式操作中，推迟模拟一个技能，连它产生的状态也变成假设；普通 lazy search 只处理边的有效性。推论：应同时维护预测图与已认证图，并在预测失准时局部修复依赖。论文给出算法及相对于模拟器的健全性证明：返回路径的每个技能都从已实现的前驱状态模拟成功；廉价模型只影响搜索顺序。

## Motivation
长程操作要联合选择推、拉、抓取、移动等技能及参数。原 MOSAIC 每评估候选都运行物理模拟，模拟占规划时间的 83.4%；仅按学得分数排序仍需大量查询。问题是如何利用廉价预测加速搜索，同时保留可信的最终计划。

## Method
三模型集成的 Deep Sets 技能效果模型，输入技能参数、机器人状态与各物体姿态，输出成功率、机器人/物体状态残差及位置分歧不确定度；约 3.5 万条离线提案训练。批量预测候选，按技能成本、负对数成功率和不确定度在乐观图中搜索；只模拟候选路径上前驱已认证的技能。失败或状态不匹配时仅删除依赖预测状态的提案，保留独立分支和已实现状态；少量随机认证维持探索。创新点在「预测状态也是假设」的搜索与修复，而非新的高容量世界模型。

## Experiment
UR10e/ManiSkill3 的 3 类货架任务、8 个难度设置，各 20 次，600 秒限时；对比 MOSAIC、排序版、无不确定度版、纯预测版、Options、CEM、Roadmap 等。成功 104/160，原 MOSAIC 为 81/160；共同成功的设置中规划快 2.1–6.6 倍，模拟查询平均少 64%–69%。困难任务 3 成功 4/20，其余方法为 0。去掉不确定度后总成功降至 90/160；不认证的 WM-MOSAIC 仅 33/160 执行成功。指标含成功率、成功样本规划时间、技能数与模拟次数；另展示实体机器人案例。

## Value
适合研究「廉价世界模型筛选、高保真模型认证」的规划架构；对 3D 动态模型的可靠使用有借鉴价值。尤其应复用预测偏差的局部失效传播与验证预算设计，而非直接套用货架技能库。

## Strengths
把预测结果作为可撤销假设，保证返回计划在模拟器内成立；对排序、不确定度和免认证分别消融；报告查询成本及真实机器人演示。

## Weaknesses
只在固定工作空间和已知物体类型下训练/测试，未测跨场景泛化；认证仅保证相对于模拟器而非真实物理安全。极难设置仍仅 4/20 成功，维护大乐观图的开销上升；模型离线采样与训练成本未计入单次规划速度。

## Future Work
作者提出跨工作空间泛化、提高廉价模型精度，以及边规划边执行已认证前缀；非安全关键任务可探索取消昂贵认证并持续重规划。

## Rating
创新度评分：3/5 - 将 lazy search 扩展到状态也未知的技能图并设计局部修复，算法贡献明确，但建立在现有 MOSAIC 与小型效果模型上。
相关度评分：2/3 (Related) - 使用 3D 物体状态的学习式动态预测做操作规划，对世界模型可信规划有直接借鉴，重点不是视频/3D 表征学习。

## TL;DR
用技能效果模型搜索假设状态并逐步模拟认证，显著减少操作规划成本；研究世界模型可靠规划值得精读。
