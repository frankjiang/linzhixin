# Causal Object-Centric Models for Planning with Monte Carlo Tree Search

## Insight
论文的 observation 是：视觉控制环境由对象组成，但任一决策通常只依赖少数对象；把动作、动态预测和价值/策略估计都放在 object slot 空间中，可以提升样本效率和可解释性。所谓 causal attention 更准确说是 learned object relevance，不是严格因果识别。

## Motivation
Dreamer、MuZero/UniZero 等 latent world model 通常使用整体 latent，容易被无关背景、小目标、多对象交互干扰。对象中心 RL 能提供结构先验，但不少方法依赖监督 mask、分割质量或不适合 MCTS。论文要解决的是在 MuZero-style latent planning 中引入对象级动态和对象级决策注意力。

## Method
COMET 使用冻结的无监督 slot encoder 将图像编码为对象 slot 集合；transformer world model 在 slot 结构 latent 中预测下一步 slot 和 reward；MCTS 在 learned latent 中展开。关键设计是 action-slot fusion：把动作 embedding 与每个 slot 拼接，经共享 MLP 形成 slot-conditioned action embeddings，再由 transformer 预测每个 slot 的转移，避免把全场景对象动态压进一个动作向量。policy/value heads 使用 object-causal attention，通过每个 slot 的相关性分数调制 attention，使目标 token 更关注任务相关对象。训练目标包含 next-slot MSE、reward/value/policy cross entropy。

## Experiment
环境包括 Object-Centric Visual RL benchmark 的 Object Goal/Interaction/Comparison/Property/Reaching，ManiSkill Cube Pushing，Robosuite Block Lifting，VizDoom Defend The Line。对比 OCRL、OCDreamer、SOLD、UniZero。指标是成功率/累计奖励曲线和 mean normalized score。COMET 在平均 normalized score 上最好，尤其在视觉简单且目标对象明确的任务上收敛更快；在 Block Lifting、Cube Pushing 等复杂控制任务上只中等，OCDreamer 更鲁棒。限制主要来自 slot encoder 在复杂真实场景、遮挡、背景合并时不稳定，以及 transformer slot attention 的二次复杂度。

## Value
该工作是对象中心表示与 MuZero/MCTS 的合理组合，action-slot binding 是有价值的工程设计。创新度不算开创，但对“隐式/object-centric world model + planning”方向有直接借鉴，尤其适合研究如何把对象级结构先验注入 latent rollout。短板是依赖冻结 slot 质量，实验最终优势主要体现在平均早期样本效率，复杂操控下优势不稳定。

## Strengths
亮点是该工作是对象中心表示与 MuZero/MCTS 的合理组合，action-slot binding 是有价值的工程设计。

## Weaknesses
不足是短板是依赖冻结 slot 质量，实验最终优势主要体现在平均早期样本效率，复杂操控下优势不稳定。
