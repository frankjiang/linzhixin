# FedWorld: Scope-Aware Federation of Agent World Models

## Insight

论文观察到联邦场景中的“多数规则”不一定对少数客户端成立：同一抽象动作在不同业务政策、物体状态或环境约束下可产生不同 effect；直接 union 会把少数客户端原本正确的知识覆盖掉。由此推论，离散 transition rule 的联邦目标不是参数平均，而是先识别其 shared/cluster/private/unresolved 作用域，再只向局部知识缺口注入兼容规则。严格冲突上 NaiveUnion 相对 LocalWM 的 net transfer 为 −0.138/−0.222，FedWorld 则在保留兼容增益的同时恢复正净迁移，实验支持 scope filtering 的必要性。但它使用确定性、人工规范化的符号规则，并非学习视觉或 latent world dynamics。

## Motivation

LLM agent 常把交互经验存为轨迹、反思、记忆或规则，但单个客户端覆盖有限，跨客户端共享又可能遇到 policy/environment heterogeneity。传统 FedAvg 处理参数，语义检索只判断相似性，都不能判断某条状态转移在哪些客户端有效。安全地填补 agent 记忆缺口是实际问题，不过论文把“world model”宽泛地定义为持久化的符号 action-effect 知识，和视频/3D/JEPA 世界模型距离很远。

## Method

每个客户端保留详细 $(s_t,a_t,s_{t+1})$ 私有，只共享规范化的 $(action, prestate, conditions, effect, exception)$。M1 用 controlled vocabulary 形成抽象 identity key；M2 将跨客户端候选标为 match/compatible/conflict/unresolved；M3 统计支持/反驳观察与 eligible clients，用 Laplace-smoothed confidence 及客户端支持比例把规则判成 shared、cluster、private 或 unresolved；M4 采用 local-first compiler：已有可靠局部规则绝不覆盖，只在 key 缺失时按 relation、scope specificity 和 confidence 选择兼容规则，否则 fallback/abstain。

理论部分将 positive transfer 与 negative overwrite 写成 $(1-\beta)p_+$ 和 $\alpha p_-$，说明更严 scope filter 有益的条件是阻止的错误覆盖大于牺牲的正确共享。这个“定理”本质上是定义代入的权衡恒等式，不能证明实际 scope inference 的正确性。

## Experiment

τ-bench 被划成 11 个零售/航空政策客户端，ALFWorld 划成 12 个 household transition profile；每客户端按抽象 key 60/20/20 划分 local/validation/test，五个固定 partition seed。方法从无 world model、LocalWM、local abstract、NaiveUnion、只对齐不判 scope 到完整 FedWorld，并以可访问 pooled detailed records 的 CDR 作参考。

离线 exact match 中，FedWorld 在跨客户端 gap split S3 为 0.836/0.786，LocalWM 为 0.712/0.574；严格冲突 S4 为 0.722/0.681，NaiveUnion 为 0.556/0.431。固定 rule-conditioned controller 的 400/600 episodes 中，相对 LocalWM，FedWorld 将 state regression 从 0.218/0.247 降至 0.121/0.128、excess steps 2.37/3.46 降至 1.46/1.98、success 0.512/0.447 提至 0.624/0.593。结果跨 seed 方向稳定，但没有真实分布式系统、通信/隐私攻击、自动抽象或强 learned baseline。

## Value

可迁移的设计原则是“共享模型知识前先估计适用域，且局部已验证知识优先”，这对多环境 world model 组合、跨机器人动力学迁移和模型库选择有一般启发。当前实现只是符号规则表与阈值过滤，不能告诉我们如何联邦高维视觉表征、随机 transition 或 Dreamer belief state；对目标方向的直接价值很低。

## Strengths

- 清楚构造多数规则伤害少数客户端的 strict-conflict split，负迁移不是只靠平均准确率推断。
- local-first 与 unresolved abstention 为安全共享提供明确、可审计的规则。
- 同时评估离线 transition accuracy 和在线状态回退、重复动作、额外步数、任务成功率。
- 用 positive/negative/net transfer 分解收益，揭示 naive union 在兼容与冲突场景的两面性。
- 抽象 key 级划分避免同一规范化规则直接出现在本地存储和测试中。

## Weaknesses

- 依赖充分指定、确定性的手工/规则式抽象；最困难的 entity grounding、条件抽取、异常结构和规则对齐并未真正学习。
- τ-bench 与 ALFWorld 都是文本/符号环境，不能支持对连续、部分可观测、随机或视觉动力学的结论。
- 客户端 clusters、eligible set 和关系标签如何获得不够清楚；若这些元信息接近 oracle，scope inference 难度被低估。
- 所谓隐私只是不共享 raw trajectory，没有差分隐私、安全聚合、成员推断或规则反识别分析；抽象规则仍可能泄漏政策。
- 理论结果是基于理想化假设的代数权衡，不给 scope estimation 泛化界或错误率保证。
- 阈值在 validation 上选定但无敏感性、client 数/异质性扩展和通信成本实验。
- 正文引用 “Appendix ??” 和多项附录结果，但给定 PDF 中没有附录，复现信息不完整。

## Future Work

作者明确计划自动学习面向 web/software agent 的抽象，同时保留不确定证据下的可靠 abstention；也承认需扩展到部分可观测、随机 effect 和持续时间动作。若要连接本方向，还需研究视觉 latent transition 的作用域估计、概率冲突融合和跨 embodiment 验证。

## Rating

创新度评分：2/5 - 将 agent transition memory 的联邦化重述为 rule-scope identification，并构造 local-first 协议，有一定概念贡献；但方法高度规则化，理论较弱，未进入连续视觉世界模型。

相关度评分：0/3 (Noise) - 核心是 LLM/符号 agent 的规则联邦，属于纯文本记忆与工具环境，不涉及视频、3D 或 JEPA/Dreamer latent dynamics。

## TL;DR

以作用域过滤避免跨客户端符号规则负迁移，思路可借鉴但属 LLM agent，可跳过。
