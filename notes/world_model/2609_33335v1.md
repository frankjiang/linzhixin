# Does Learning to Predict the World Help Agents Act? Auditing World-Model Post-Training

## Insight
观察：在语言代理训练中把真实下一观察换成错配观察，预测准确率下降 15.3–61.6%，但 pass@1 仅差 0.51–2.75 点、pass@64 至多差 3 点；随机回报也能扩大可解任务覆盖。推论：事后训练收益不能仅归因于“学会正确世界动力学”。该因果对照结论限于所测文本/GUI 代理。

## Motivation
许多 LLM 代理论文将预测下一观察后的任务提升当作世界模型有效性的证据，却缺等训练量的安慰剂对照。正确归因很重要，但研究对象不是用户关注的视觉物理世界模型。

## Method
比较基座、真实观察奖励 GT、错配目标 MIS、随机奖励 COIN；RL 的提示、GRPO 优化和预算匹配，另在 OPSD 蒸馏中做 GT/MIS 对照。分别测下一观察准确率、pass@1/64、动作失败、CoT 候选搜索和循环率；VisualWebArena 进一步检验随机奖励。

## Experiment
ALFWorld、ScienceWorld 的 Qwen2.5-7B；1,200 个未训练转移测预测，任务每个 64 条轨迹。ALFWorld 有动作列表时 COIN 的 pass@64 从基座 56.20% 升至 87.23%；真实目标相对错配显著改善预测，任务差异很小。无动作列表时 GT pass@64 52.92%，COIN 74.09%；GT 动作失败率 65.32%，MIS 49.61%。VisualWebArena 的随机奖励训练使 pass@64 相对提升 14.3%。

## Value
可借鉴“正确目标—错配目标—随机回报”归因测试，提醒研究者不要把策略进步直接解释为动力学学习；具体模型和场景与用户方向无关。

## Strengths
严格安慰剂对照，同时测预测、单次成功和多次覆盖；行为分析解释部分训练收益。

## Weaknesses
全部是文本环境或网页 GUI，没有连续视觉视频、3D 物理动力学或 JEPA；结论不可直接外推。预测准确率依赖外部 LLM 裁判，随机奖励的训练效应也不代表可靠策略机制。

## Future Work
论文未列明确未来路线；将相同归因对照移植到真实视觉/控制世界模型可作为后续研究。

## Rating
创新度评分：3/5 - 归因实验设计扎实，但方法贡献主要是针对 LLM 代理的审计。
相关度评分：0/3 (Noise) - 实证全在文本/网页代理，非视频、3D 或 JEPA/Dreamer 世界模型。

## TL;DR
错配观察和随机回报对照质疑语言代理“预测促进行动”的归因；与目标方向间接性很强，可跳过。
