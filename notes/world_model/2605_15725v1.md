# DiLA: Disentangled Latent Action World Models

## Insight
核心insight：Latent Action Model中的predictive bottleneck（预测瓶颈）不仅是学习抽象动作的工具，更是驱动content-structure解耦的天然力量。解耦与latent action学习是协同演化的：预测瓶颈迫使模型将空间布局蒸馏到structure pathway，将视觉细节卸载到content pathway。这种协同打破了LAM中"抽象vs保真"的根本trade-off。

## Motivation
现有Latent Action Models面临LAM Trade-off：更强的信息瓶颈产生更抽象的动作但损害生成质量，放松瓶颈则动作混入无关视觉细节。现有方法要么用两阶段训练绕过（先训世界模型再训LAM），要么限制预测目标为光流。DiLA提出通过content-structure解耦在单一框架内同时实现高抽象动作和高保真生成。

## Method
- **Structure pathway**：Structure Encoder压缩token为structure embedding s，IDM从temporal difference推断latent action z（d_z=256），FDM预测下一步结构状态。通过3D Conv处理，空间核捕获平移不变特征，时间核聚合双向上下文
- **Content pathway**：Content Encoder提取temporal-invariant视觉特征，Mamba模块（慢特征分析原则）聚合长期内容记忆
- **Fusion Decoder**：dual cross-attention融合predicted structure和content memory，生成visual embedding，用预训练RAE decoder可视化
- 特色：在DINOv2 latent space中预测（类JEPA），无需pixel-level重建
- 训练：visual latent prediction + structure prediction + latent action consistency + regularization loss
- 正则化：前向/后向latent action的cosine相似性约束（群对称性）

## Experiment
- **Action Transfer**：在SSv2和RT-1上，cross-embodiment动作迁移（human->robot），action cycle transfer metric优于LAPA/Moto/AdaWorld
- **Video Generation**：16帧自回归rollout，SSIM/LPIPS超越所有LAM baseline（SSv2: SSIM 0.660, LPIPS 0.356）
- **Content-Structure解耦**：rebinding实验成功分离结构和内容；motion isolation实验确认content memory不编码运动
- **Latent Action分析**：OmniObject3D上，UMAP可视化显示latent action空间对translation/scaling/rotation形成拓扑同构的连续流形
- **Visual Planning**：VP^2 benchmark上，MPC规划聚合成功率41.44% vs AdaWorld 21.54%
- 消融：去掉IDM+FDM后trade-off重现；连续z优于VQ和VAE瓶颈

## Value
高质量工作，对LAM领域的核心问题（抽象vs保真trade-off）给出了优雅的解决方案。Content-structure解耦的insight深刻且被充分验证。与视频世界模型和隐式世界模型（JEPA系列）方向高度相关。局限：抽象动作牺牲fine-grained控制精度；未处理多物体动态分解；自回归累积误差。
