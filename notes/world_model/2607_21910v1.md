# TRW: TRACE-RealWorld---An Auditable Consistency Contract for World Models as Materialized Views

## Insight
有，但偏系统/数据库。论文的 observation 是：部署中的 world model prediction 更像“物化视图”，一旦物理世界变化，预测结果会 stale；仅定时刷新或仅事后补偿都无法在有限成本和不可逆动作下保证安全。推论是需要一个 auditable consistency contract：对预测声明、刷新条件、验证成本、行动后果和补偿链做显式记录与约束。

## Motivation
论文解决的是把世界模型接入真实行动系统后的一致性、审计和补偿问题。同行多关注模型预测准确率、校准或 planner 性能，较少把“预测何时过期、何时必须重新验证、行动失败如何追责”作为一等对象。问题对部署很重要，但不是视频/3D/JEPA世界模型的建模主线。

## Method
TRW 把世界模型输出封装为 typed claim records，记录 claim 类型、refresh condition、validity interval、provenance、模型版本、校准信息和依赖。系统包含 trigger taxonomy、value-of-information channel selection、consequence-scaled gate、commitment chain、SagaLLM compensation 和 append-only TRACE provenance。

理论部分给出三个负结果/界限：refresh-only 在非零物理延迟和行动义务下不能以有界成本把 stale execution 降到 0；compensation-only 不能修复不可逆 stale execution；同步验证加补偿可以给出包含 calibration slack、missed detection、dependency miss、invocation/restoration failure 的条件一致性界。

## Experiment
实验是 Flood-SAR 仿真搜索救援，使用透明 kinematic surrogate 和 isotonic calibration，不是 JEPA 或视频模型。评价校准、刷新策略、revalidation guard、localized repair、incident stream 上 stale/violation/cost 的权衡。

关键结果：OOF ECE 约 0.00477，held-out route ECE 约 0.00450。自适应刷新并不总优于固定刷新：某些设置降低 stale，但成本更高、coverage/完成率更低。incident stream 上 adaptive 相比 fixed 可降低 stale 与 residual violations。revalidation guard 可把高后果 unsafe clear 从 3.688 降到 0，但带来 hold/escalation 成本。localized repair 减少修复工作和恢复延迟，但并非所有指标都改善。

## Value
对我们有间接价值：如果视频/3D世界模型最终要驱动机器人或仿真资产更新，预测需要生命周期、刷新和审计语义。它提醒我们不要只看 rollout 质量，也要定义何时相信模型输出。直接建模贡献很少。

## Strengths
亮点是系统问题定义完整；形式化指出 refresh-only 和 compensation-only 的不可能性；TRACE 记录、后果分级和补偿链对部署工程有参考意义；实验没有简单宣称 adaptive 全胜，而是呈现成本权衡。

## Weaknesses
与学习世界模型关系较弱；评估只有 Flood-SAR 一个领域，预测器是透明 surrogate；没有验证视频/3D/JEPA 模型；大量机制更像框架协议，实际生产可用性和跨域泛化还未充分证明。

## Future Work
作者提到将引入 learned predictors（包括 calibrated / unqualified V-JEPA 等）、扩展第二领域、强化持久化和外部链锚定，并系统评估 replay/audit 与真实世界部署。

## Rating
创新度评分：2/5 - 系统一致性框架有想法，但对世界模型算法贡献有限，实验也不是核心建模。
相关度评分：1/3 (Tangential) - 讨论 world model 部署契约，和用户方向只有间接关系。

## TL;DR
把世界模型预测当物化视图做刷新与审计，偏部署一致性，主线可跳读。
