# ColonoWorld: Camera-Controlled Full-Procedure Colonoscopy Video Generation

## Insight
内窥镜首帧和相机轨迹仍不足以确定前方管壁位置，长序列视频会偏离导航方向或失去连续腔道。作者给定可编辑粗 3D 管道作为全局几何锚点，并将其视角渲染与相机射线一起条件化生成器；消融中去管道后完整流程 CamMC 从 5.81 升至 14.43，说明粗几何有实质作用，但不保证细纹理重访一致。

## Motivation
用于内窥镜导航训练或评估的世界模型须响应镜头动作、保持解剖连贯并能指定息肉/器械；普通相机控制视频模型易失去管状结构，内窥镜生成器多不能按 6-DoF 轨迹控制。属于特殊场景的视频世界模型问题。

## Method
从 REAL-Colon 真视频筛选片段，以人工点轨迹的极线一致性挑选 MegaSaM 估计相机位姿；沿轨迹拟合可编辑椭圆截面与褶皱的粗管道。冻结 Cosmos3-Nano 主干，以 LoRA 及相机编码器注入鱼眼 Plücker 射线，并将逐帧管道渲染及可选病变/器械掩码编码成 token；完整撤镜过程按 189 帧分块生成、共享边界帧。创新是将粗全局 3D 形状作为视频相机控制的显式约束。

## Experiment
训练用 28 个流程的 734 个基础窗口，测试用 4 名留出患者的 22 个片段。相机控制用 RotErr/TransErr/CamMC，视频质量用 FVD/FID/IS；CamMC 7.09、FVD 494，强微调对照 UCPE 为 10.38/695。六种新管道形状的完整流程共 183 段，CamMC 5.81、FVD 1277，UCPE 为 10.88/3147；这里没有与合成形状一一对应的真视频，FVD 只比较同解剖段真实片段分布。去管道/相机条件的消融均损害控制；附录以生成视频点轨迹的 Sampson 距离另行检查，降低对位姿重估器的依赖。

## Value
可借鉴“低成本粗 3D 几何 + 相机轨迹 + 视频扩散”的长程结构控制方式，以及用真实点轨迹检查相机服从性的评测。对通用视频/3D 世界模型有方法参考。

## Strengths
按患者划分数据；对几何条件和相机条件分别消融；包含完整流程生成及不经生成视频位姿估计的补充验证。

## Weaknesses
管道假设窗口内形状不变，难处理蠕动等形变；重访同一位置的纹理/血管未保持严格一致。没有用生成环境训练导航策略或验证安全性；完整流程的 FVD 无配对真值，且采样成本高。

## Future Work
作者明确提出动态变化的管道、重访时精细纹理一致性，以及在生成环境内训练并评估导航/干预策略。

## Rating
创新度评分：3/5 - 用粗三维管道约束特定场景的视频世界模型，方法有效但主要建立在预训练生成器上。
相关度评分：3/3 (Core) - 直接研究几何和相机控制的视频世界模型，虽应用于医学场景。

## TL;DR
以可编辑三维管道约束内窥镜视频的相机轨迹与长程结构，评测方法可迁移；值得精读。
