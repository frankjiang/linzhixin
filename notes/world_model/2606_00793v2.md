# MBench: A Comprehensive Benchmark on Memory Capability for Video World Models

## Insight
核心观察：现有视频世界模型评测（VBench、WorldScore等）聚焦视觉质量和文本对齐，但忽略了世界模型的核心能力——长时记忆。一个世界模型不仅需要生成视觉上逼真的帧，更需要在实体离开视野后保持其属性、在相机返回后恢复3D空间布局、在离屏事件发生后维持因果链条。作者进一步观察到，一些模型通过生成过于保守/静态的内容来回避记忆挑战，获得虚高的一致性分数。基于此提出 Trigger-Conditioned Scoring：用 trigger coverage 和 memory reliability 的调和平均来同时惩罚回避挑战和记忆失败。

## Motivation
- 问题：如何系统量化视频世界模型的长时记忆能力？现有 benchmark 缺乏对实体一致性、环境空间一致性、因果一致性的联合评估，且不支持 action-conditioned 模型。
- 同行做法：VBench/VBench++ 关注视觉质量；WorldModelBench/WorldScore 关注物理规律但不测记忆；MIND/STEVO-Bench 测部分因果但不全面；无一 benchmark 同时覆盖 entity+environment+causal 三个维度并支持 text 和 action 两种条件。
- 关键性：记忆是区分"视频生成器"和"世界模型"的核心能力。当前模型在此方面表现很差，急需标准化评测推动进展。

## Method
**三层分类体系（3维度 x 12子维度）：**
1. **Entity Consistency**：Object（Geometry + Texture）+ Human（Identity + Appearance）——使用 SAM2 分割 + DINOv2/ArcFace 特征，基于 departure-return 轨迹评估
2. **Environment Consistency**：Spatial（Epipolar Geometry + Reprojection，用 DA3 估计位姿后计算极线误差和重投影误差）+ Rendering（Lighting + Style，用 CIELAB 光照一致性和 Gram Matrix 风格距离）
3. **Causal Consistency**：Self-evolution（State Evolution + Evolution Correctness，用 VLM 评估离屏事件是否正确触发和演化）+ Interaction（Text Interaction 用 OpenCLIP 对齐 + Action Interaction 用 DA3 提取 6DoF twist 计算方向余弦相似度）

**关键设计：**
- **Trigger-Conditioned Scoring (M-Score)**：先用 VLM (Seed 2.0) 验证是否成功触发了记忆挑战（如实体离开视野），只对触发成功的样本评估一致性。最终分数 = 2 * S_rel * C_trig / (S_rel + C_trig)，防止保守模型通过回避挑战得高分。
- **数据构建**：从 DL3DV、Tanks and Temples、OpenHumanVID、SpatialVID、Physics-aware-video 5个数据集聚合真实长视频，用 VLM 筛选具有记忆挑战的片段。Text-conditioned 模型用多粒度 caption 分段续生成；Action-conditioned 模型用 Exit-and-Reenter 范式（离开-等待-返回）。
- **规模**：1040 标准化评测样本，覆盖 14 个视频世界模型（8 text-conditioned + 6 action-conditioned）

## Experiment
**Text-conditioned 模型（8个）：**
- Self Forcing 和 LongLive 综合最强但各有短板
- Helios 在 object geometry/texture 上最好
- 所有模型在 style consistency 和 spatial 上普遍很弱（风格遗忘、3D 空间恢复差）
- Causal 维度虽 prompt interaction 分数尚可，但 state evolution 普遍低，说明文本对齐不等于因果记忆

**Action-conditioned 模型（6个）：**
- HY-WorldPlay 在 entity 和 rendering 上最强，spatial（epipolar/reprojection）也最佳
- 关键发现：HY-WorldPlay 和 Infinite-World 空间/渲染好但 state evolution 极低，说明这些模型通过"冻结"场景保持几何一致性，但无法模拟离屏物理过程
- Yume-1.5 的 state evolution 反而最高（97.90），暗示不同架构在记忆能力上有根本差异

**人类对齐验证（2362条标注）：**
- Geometry Consistency 与人评相关性最高（rho=0.97）
- Lighting Consistency 与人评相关性最低甚至负相关（text-conditioned 上 rho=-0.49）
- 整体指标体系可信但仍有改进空间

## Value
- **工作价值高**：填补了视频世界模型评测的重要空白，提出的三维度 x 12子维度分类体系和 Trigger-Conditioned Scoring 都是有意义的设计。实验覆盖 14 个模型，揭示了当前世界模型在记忆能力上的系统性短板。
- **对我们的启发**：
  1. 记忆是世界模型的核心瓶颈——当前最好的模型也会在离屏后遗忘因果链条
  2. Action-conditioned 模型倾向"冻结"场景来回避记忆挑战，需要 trigger-gated 评估来识别
  3. Spatial consistency（3D几何恢复）是所有模型的共同短板
  4. State evolution（离屏因果演化）是最难的维度，可能需要架构层面的创新
- **局限**：评测依赖 VLM 打分（部分维度人类对齐不理想）；不支持非视频模态（如3D重建后的一致性）

## Strengths
亮点是工作价值高：填补了视频世界模型评测的重要空白，提出的三维度 x 12子维度分类体系和 Trigger-Conditioned Scoring 都是有意义的设计。

首个系统评估视频世界模型长时记忆能力的benchmark，分entity/environment/causal三个维度定义12个指标，揭示当前模型在离屏因果和空间恢复上的严重不足，值得精读。
