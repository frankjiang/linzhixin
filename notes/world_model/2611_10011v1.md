# When the Plan Changes: A Strategic World Testbed for Dynamic Multi-Agent Coordination

## Insight
观察：目标更新的发出、收到、确认、采纳、转发与实际执行是不同事件；仅看最终完成率和确认数，会把「未获通知」「收到后仍做旧任务」「被拦截的违规意图」混为一谈。论文用三条同终局轨迹的构造例和事件重放展示这一不可辨性，不涉及视频或潜在动力学预测。

## Motivation
LLM 多智能体在动态任务中会继续执行旧计划、漏转发新目标或采纳伪造指令。现有完成率难定位失误发生在哪一步；这对 agent 协作有意义，但与用户研究的世界模型概念不同。

## Method
Strategic World 是带权威目标、局部计划、任务所有权、延迟通信和可重放事件记录的离散工作流模拟器。六类干预涉及目标替换、保留约束、条件变化、伪造权限、成员变化和通信分区。按行动者所知信息标记旧目标工作、越权采纳、被阻止的违规尝试。针对发现的漏转发问题，增加待发送收件人队列保护：合法通知未提交给所有同伴前，优先发通知而非继续本地工作。

## Experiment
五个脚本控制器×六类场景×六种时序，共 180 个主实验；正控制器在 36 tick 下 36/36 完成，证明设计场景可解。原始 qwen3:4b 的静态、替换及伪造权限各 3 次均 0/3 完成，表明基础执行能力不足。另以经过辅助校准的控制器和两名固定同伴，在四个保留场景比较：待发送队列保护 4/4 完成，校准基线 1/4，泛化提醒与路径建议均 0/4；授权工作量 39/39 对 33/39。指标还有通知覆盖、旧任务工作、接收至采纳/执行延迟及删失率。论文明确这只是四个设计场景、一名 LLM 行动者的工程干预。

## Value
「按接收状态追踪行动」适合评测多智能体系统；对视频、3D、JEPA、Dreamer 世界模型没有直接研究价值，可跳过。

## Strengths
严格区分环境权威状态与行动者局部信息；用重放验证事件标签，并设脚本正控制器和静态能力门槛。

## Weaknesses
环境是简化任务流程，地理、物理和其他现实机制未验证；消息持久与所有权仲裁由模拟器保证。核心 LLM 静态任务都无法完成，后续效果来自候选过滤和显式队列规则，非自发协作能力；仅四个定制测试情形。

## Future Work
作者指出需扩展到多 LLM 团队、更多模型与组织配置，并检验当前被简化的通信、权限和任务依赖机制。

## Rating
创新度评分：1/5 - 对目标变更的事件级评测有工作流价值，但相对视频/3D/隐式世界模型无技术贡献。
相关度评分：0/3 (Noise) - 此处「World」是战略多智能体仿真平台，非研究方向所指预测式世界模型。

## TL;DR
构建目标变更下的 LLM 多智能体协作测试台，区分通知与执行失配；与目标世界模型方向无关，可跳过。
