# MAD: Mapping-Aware World Models for Agile Quadrotor Flight

## Insight
核心insight：传统Dreamer用raw observation重建作为自监督目标，但对于需要空间推理的四旋翼避障任务，用occupancy grid map (OGM) + visibility grid map (VGM) 重建替代raw depth重建，可以迫使latent state编码更多与安全相关的几何结构信息（哪些区域被占据、哪些已观测、哪些未知）。实验证明这种替代目标不仅提升了地图重建质量，还意外地改善了速度和姿态估计精度，说明空间结构监督为latent state提供了更丰富的几何信号。

## Motivation
问题：端到端RL四旋翼策略缺乏可解释的空间记忆，难以跨任务迁移；传统模块化导航栈（SLAM+规划+控制）接口复杂且累积误差。世界模型（如Dreamer）是两者的中间路线，但现有航空世界模型仅强调时序预测或任务奖励，没有显式地将局部几何结构（occupied/visible/unknown）注入latent state。这是四旋翼在杂乱环境中安全飞行的关键信息。

## Method
整体框架基于DreamerV3的RSSM，做了以下关键修改：

1. **Grid Map重建目标**：解码器重建robocentric OGM和VGM（4000体素，0.4m分辨率），而非raw depth image。OGM标注占据，VGM标注可见性。仅在VGM=1的体素上监督OGM，避免惩罚未观测区域的幻觉。
2. **GPU并行OGM/VGM构建**：扩展DiffAero仿真器，实现4.84e8体素/秒的高吞吐量ground-truth生成
3. **三种策略学习模式**：MAD-Dreamer（imagination-based）、MAD-PPO（frozen encoder + PPO）、MAD-SHAC（frozen encoder + SHAC）
4. **任务无关表征**：PPO/SHAC模式下禁用reward decoder，将target velocity直接传给策略网络，使MAD学到的表征可迁移到其他任务（如竞速）

创新程度：中上。OGM/VGM作为世界模型的辅助监督目标是领域特定但有效的创新，GPU并行grid map构建是有价值的工程贡献。

## Experiment
- **训练效率**：MAD-based方法最终成功率高于对应baseline（MAD-PPO vs PPO, MAD-SHAC vs SHAC），但需要更多环境交互来学习空间表征
- **重建质量**：OGM+VGM目标比单OGM和raw depth目标在速度估计误差和姿态估计精度上都更优
- **Gazebo仿真**：MAD-Dreamer在不同障碍物密度和速度条件下全面优于EGO-Planner、YOPO、PPO baseline，在dense forest中保持稳定
- **任务迁移**：MAD在导航任务训练后，frozen encoder迁移到竞速任务，学习曲线超过PPO-Vision baseline
- **真实飞行**：Intel RealSense D435i，室内走廊和户外树林，最高达9.66 m/s（仿真）和5.05 m/s（真实森林）
- 可视化展示了prior/posterior重建的depth、OGM、VGM与ground truth的对比

## Value
工作价值较高。展示了如何通过领域特定的辅助监督目标（空间占据+可见性）来增强隐式世界模型的空间推理能力，这个思路可以推广到其他需要空间理解的机器人任务。对于隐式世界模型（Dreamer系列）的研究者，MAD提供了一个很好的案例：latent state应该编码什么信息取决于下游任务需求，而不一定是raw observation重建。真实飞行部署也增强了说服力。

## Strengths
亮点是展示了如何通过领域特定的辅助监督目标（空间占据+可见性）来增强隐式世界模型的空间推理能力，这个思路可以推广到其他需要空间理解的机器人任务。

## Weaknesses
不足是仅在VGM=1的体素上监督OGM，避免惩罚未观测区域的幻觉。

## TL;DR
将OGM/VGM空间结构重建替代raw depth重建作为Dreamer的自监督目标，使latent state编码几何信息用于四旋翼避障，仿真和真实飞行效果优异，值得精读（Dreamer改进方向参考）。
