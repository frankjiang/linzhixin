# DREAM-Chunk: Reactive Action Chunking with Latent World Model

## Insight
action chunking 的弱点是 chunk 内 open-loop；如果一次采样多个候选 chunk，并用轻量 latent world model 预测各自未来，真实观测可在执行过程中匹配到更接近的 dreamed state，从而切换到更合适的 chunk 动作。收益依赖 policy 分布里是否含纠错行为。

## Motivation
VLA 为实时部署常输出 action chunk，降低推理频率但牺牲反应性。现有 frequent replanning、自引导、adaptive chunking 或 residual module 要么计算重，要么改 policy。论文希望不微调 base VLA，仅用测试时计算提高随机动力学下鲁棒性。

## Method
DREAM-Chunk 固定 VLA，测试时采样 N 个 action chunks；用 decoder-free latent dynamics（R2-Dreamer/RSSM、LeWorldModel、EB-JEPA 等）rollout 每个 chunk 的 latent future。每步将新观测编码成 latent，与 phase-aligned dreamed latents 比较，执行最相似候选 chunk 对应动作。世界模型只做 latent matching，不负责像素重建。

## Experiment
Kinetix 仿真中，随机性越强、候选数越大，DREAM-Chunk 相对 naive async/BID/RTC/AC 越有优势；专家示范含高噪声纠错行为时 scaling 更有效。latent 表征消融显示 LEWM/RSSM 较稳，EB-JEPA 长 horizon 误差积累，policy encoder 接近 random switch。硬件上 SO-101 三任务 SmolVLA 成功率：USB 75% 到 95%，moving object 60% 到 80%，toy insertion 35% 到 45%；Franka π0.5 can insertion local open-loop 10% 到 DREAM-Chunk N=5 65%，但远程大 N 延迟会抵消收益。

## Value
对 latent/隐式世界模型在机器人执行层的落地很有启发：无需生成视频，latent dynamics 也能作为 test-time reactive module。创新不是基础模型级，但工程价值高。局限是高层 mode switch 少，主要是局部纠偏；依赖 demonstration 中已有 recovery options。

## Strengths
