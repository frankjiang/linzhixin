# PhiJEPA: Denoising Latent Predictions for Visual Representation Learning

## Insight
观察：只给 JEPA 输入加光度扰动、让单级预测器猜清洁或独立扰动的教师特征，都没有提高稠密语义；先预测另一扰动视图的隐藏 token，再由逐 token MLP 预测清洁教师特征，VOC mIoU 从单级 65.9 升到 69.2。推论：第二阶段的清洁目标可训练更可用的隐藏表征；证据为控制消融、隐藏区域语义和遮挡规划实验，但尚未完全隔离额外参数与目标设计的作用。

## Motivation
JEPA/潜空间世界模型依赖冻结视觉编码器，局部遮挡或模糊会使代价函数与真实物态不符。I-JEPA 的隐藏预测器训练后常被丢弃，能否同时提升特征并用于规划时补全，是与隐式世界模型直接相关的问题。

## Method
以单学生 Simple I-JEPA 为基础：224² 图像分 196 patch，学生仅看 49 个上下文 patch，目标为 9×9 连续块加 17 个散点；EMA 教师看全图。学生和教师各采独立光度扰动，单层 Transformer 预测教师另一扰动视图的隐藏 token（CA3），逐 token MLP 将其映射到无扰动教师 token（CA1），两个余弦损失联合训练。预训练后世界模型使用 EMA 编码器；在 DINO-WM 中识别遮挡格，用保留下来的预测器补全缺失 token 再做 CEM 规划。该工作主要是视觉自监督预训练与测试时补全，动作动力学仍由 DINO-WM 学习。

## Experiment
ImageNet-1K 预训练 ViT-B/16 400 epoch；冻结线性 VOC/ADE20K 分割：69.3/30.7 mIoU，Simple I-JEPA 为 66.2/29.2，所测 I-JEPA 为 61.4/25.4；训练成本约 56×10¹⁸ FLOPs，对比 Simple I-JEPA 36、I-JEPA 75。VOC 隐藏区域预测 49.1 mIoU，对比 Simple I-JEPA 44.3；加扰可见部分后为 44.5 对 35.8。PushT 的 DINO-WM 用统一训练预算、每条件三规划种子×50 回合：清洁输入 PhiJEPA 成功率 0.80；仅遮挡 0.33，预测器补全至 0.59；σ=2 像素模糊加遮挡 0.33→0.65，Simple I-JEPA 预测器仅 0.25。σ=4 时 PhiJEPA 补全 0.33，低于 iBOT 加 MAE 修图 0.38；冻结特征大遮挡分类亦低于 Simple I-JEPA 47.1 对 50.9。

## Value
值得精读：展示“预训练预测器不丢弃”如何直接成为隐式世界模型的观测补全模块，并明确区分遮挡、光度扰动和二者叠加。下一步可在连续视频信念状态中加入补全不确定性，而非把单一猜测当成真实状态。

## Strengths
有相同预训练设置的关键消融、隐藏位置语义测量、状态检索和规划任务；同时报告失效条件、训练 FLOPs 与 GPU 小时；与不同视觉编码器共用 DINO-WM 训练预算。

## Weaknesses
只测 PushT、人工固定遮挡且测试时已知遮挡位置，规划每回合只执行一次开环计划；编码器预训练各设置仅一次，误差条仅覆盖回合抽样。不同外部检查点训练资源不等，不能把全部差距归因于目标函数；强模糊、颜色纹理类任务及大面积遮挡并非稳定占优。

## Future Work
作者提出自然移动遮挡、闭环重规划和真实机器人验证；同时预测补全不确定性、自动定位不可靠观测；增加预训练重复种子、匹配成本比较及更大模型的系统扩展。

## Rating
创新度评分：3/5 - 将既有 PhiNet 双级思想落实到遮挡 token JEPA 并复用预测器，实验充分，但非新范式。
相关度评分：3/3 (Core) - 直接研究 JEPA 表征及其在潜世界模型规划中的作用。

## TL;DR
双级去噪式 JEPA 改善隐藏 token 语义，并复用预测器修复遮挡观测以支持潜空间规划；值得精读。
