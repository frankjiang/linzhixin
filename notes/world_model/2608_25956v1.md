# 4DGS-WAM: Bridging Past and Future with an Object-Centric World Action Model based on 4D Gaussian Splatting

## Insight

观察是连续视频的大部分静态背景高度冗余，而真正随动作变化的是少量动态物体。由此可推得：若先把历史观测提升为持久、可渲染且动静分离的 4D 状态，未来预测只需搬运动态物体，背景可直接复用。论文以 KITTI-MOT 的短期预测和重建结果作初步验证，但没有直接测量节省的计算量，也未证明该分解能处理接触或新显露区域。

## Motivation

主流 World Action Model 在 2D 图像/视频空间联合生成动作与未来帧，反复生成不变背景，且物体的 3D 结构与运动是隐式的；点云虽显式，却稀疏、难跨视角累积和高质量渲染。论文试图把 WAM 改写为显式 4D 场景状态上的“策略预测动作 + 世界模型推进状态”，这是 3D 世界模型中的关键表示问题，但当前验证仍限于非接触驾驶短视野。

## Method

1. 对历史 RGB 运行 NeoVerse 4DGS 重建，并借助 SAM 3、Depth Anything 3/VGGT、WAFT 等模型获得分割、深度、相机位姿和光流；在统一世界坐标中形成静态高斯库、动态物体高斯、物体中心轨迹和 3D 流对应。
2. 策略网络读取最近 8 步物体/自车中心状态和查询 horizon，经 causal temporal attention、actor kNN attention 与 memory token，一次性预测目标时刻的 SE(3) 动作，不递归生成中间动作。
3. 世界模型以动作和 horizon 为条件，用 GotenNet 风格几何张量网络处理 splat 与类别相关 part token；part 节点预测残差 SE(3) twist，按注意力混合到各 splat，再与刚体动作复合，同时残差更新颜色、透明度和尺度。
4. 训练以 3D 流 transport、物体中心位移、目标掩码内 photometric loss，以及 missing-alpha 和参数 anchor 约束几何与外观；推理时组合预测的动态高斯与不变静态库并渲染。

核心新意是“持久静态库 + 逐物体动作条件 4DGS 转移”的 WAM 结构；各组件多取自现有 4D 重建、VFM 和等变图网络，属于有意义的系统组合而非全新动力学范式。

## Experiment

- 数据仅为 KITTI-MOT 三个序列。未来预测报告 horizon 1、3 的三个序列均值，共每方法 6 个目标帧，指标为 PSNR/SSIM/LPIPS；比较 Epona、DriveDreamer-2、Envision4D。
- 给定真实未来相机时，4DGS-WAM 为 18.80 PSNR、0.596 SSIM、0.161 LPIPS，优于最强视频基线 Epona 的 17.46/0.482/0.203；使用自车策略预测相机时为 16.47/0.482/0.245，PSNR、SSIM 低于 Envision4D 的 17.19/0.514，但 LPIPS 更好。
- 历史输入视角重建中，4DGS-WAM 报告 27.63 PSNR、0.888 SSIM、0.053 LPIPS，动态区域为 25.53 PSNR、0.025 LPIPS；最强 3DGS 基线 MonoGS 为 20.42/0.652/0.236。不过其全帧结果用冻结的 NeoVerse fusion underlay 填洞，而基线使用原生输出，比较并不完全同条件。
- 有未来预测与重建可视化，但无组件消融、长期 rollout、动作误差、速度/显存、跨数据集或真实控制实验；显著增益的统计基础只有三个序列。

## Value

论文把“不要重复生成已观察背景”落实为可渲染的显式状态，对 3D 驾驶/机器人世界模型很有启发：世界模型可围绕可持久化实体和状态转移设计，而非默认生成整帧。当前工作更像 proof of concept；真正有价值的下一步是加入遮挡补全、对象交互与不确定性，并在无 underlay、长 rollout 和闭环规划下验证。

## Strengths

- 动静分解、对象关联、策略和 4DGS 转移之间的职责清晰，状态可解释且可直接渲染。
- 以 SE(3) 等变 part-token 网络处理非刚性残差，比整物体刚体搬运更灵活。
- 明确区分给定相机与预测相机，也主动披露 fusion underlay 和短视野限制。
- 附录给出动作约定、图结构、损失和训练参数，方法复现信息较完整。

## Weaknesses

- 仅三个 KITTI-MOT 序列、6 个未来目标帧，样本和 horizon 都太小，无法支撑泛化或长期动力学结论。
- 世界模型按物体独立分解，不能表示碰撞、接触、物体生成/消失和可变形体；这正是机器人世界模型的核心难点。
- 依赖多套冻结 VFM 和 4DGS 重建器，误差会级联，尚未做到端到端学习。
- 静态库不能补全未观察表面或新显露背景；全帧未来预测与全帧重建借助只给本方法使用的 frozen underlay，可能放大优势，但动态区域指标来自 no-fusion 评估。
- 无效率对比，因而“避免背景重复计算”的核心动机没有被计算量或延迟实验验证。

## Future Work

作者指出仍需建模物体碰撞和接触、支持可变形体、补全未观察物体表面与新显露背景、开展长视野 rollout、降低 VFM 误差传播并统一为端到端模型；同一对象中心 WAM 也可实例化到 voxel、mesh 等其他 4D 表示上，并扩展到机器人操作。

## Rating

创新度评分：3/5 - 显式动静分离 4DGS 状态与对象级 WAM 的组合有清晰新意，但基础组件已有且实验仍是小规模初步验证。
相关度评分：3/3 (Core) - 直接研究可行动、可渲染的 3D/4D 世界模型，和 3D 世界模型方向核心相关。

## TL;DR

以动静分解的 4D 高斯状态重用背景并预测物体演化，但短视野小规模实验偏初步，建议可选读。
