# World Tokens: Enhancing Embodied Policies with Training-Time World Modeling

## Insight
辅助世界模型只有在策略被迫消费同一受监督表征时才有用：若 action head 可绕过 world tokens 直接读 VLM，视频目标甚至伤害控制。训练期共享 world tokens、部署期删除视频分支，能把预测梯度“蒸馏”进策略而不承担在线生成成本。

## Motivation
VLA 闭环快但不显式学习场景演化，WAM 有动态表征却在线视频采样昂贵。关键问题是能否只在训练时使用 world modeling，并确保其信息真正进入动作策略，而非成为可忽略的辅助头。

## Method
Qwen3-VL-2B 编码多视图与语言；Perceiver-style World Adapter 用 256 learned queries 压缩为固定 world tokens，作为 DiT action expert 唯一视觉语言上下文。训练期 Cosmos Predict2.5-2B denoiser 同时以 tokens 条件预测 8 帧未来；首帧只给 Canny edge anchor，抑制靠 RGB 外观复制的捷径。action flow matching 与 video denoising 联合微调，部署时删去 VAE、projection 和完整视频模型。

## Experiment
LIBERO 40 任务单策略平均 98.2%，Long 97.0%；chunk latency 61.85 ms，接近 $\pi_{0.5}$ 56.32，远低于在线 WAM。匹配 Qwen-GR00T 为 96.9/Long 92.8；去视频监督为 97.4/95.0，允许 VLM bypass 反降至 97.2/94.1，FFN adapter 97.0/93.4，RGB anchor 96.2/91.5。SIMPLER WidowX/Google 平均 71.5/82.1%。R1 Pro 四物体各 24 trials，World Tokens 76.0%，匹配 baseline 59.4%；但 embodied-pretrained $\pi_{0.5}$ 为 100%。注意力熵从无 WM 的 5.22 bits 降至 3.29。

## Value
这是一种实用的“训练时世界模型、部署时纯策略”范式，尤其强调梯度路由与避免捷径，比简单辅助预测更有普适性。它降低推理成本，但没有保留可显式 rollout、规划或反事实查询的世界模型能力。

## Strengths
- 训练/部署计算图设计清楚，exclusive routing 的机制消融有说服力。
- LIBERO、SIMPLER、真机均有匹配 action-only baseline。
- 主动展示强 embodied-pretrained 模型仍更强，结论较克制。
- latency 与长期任务列揭示世界建模收益集中在何处。

## Weaknesses
- LIBERO 多数任务已饱和，绝对平均增益仅 1.3 点，机制结论主要依赖 Long。
- 视频分支训练成本巨大却未量化；部署效率以更高训练预算换得。
- Canny anchor 是手工捷径控制，可能不适合纹理/状态变化关键的场景。
- 真机仅简单 pick-and-place，96 trials，未验证长程、接触丰富或跨 embodiment 泛化。
- tokens 是否真的编码可预测动力学主要由注意力图间接支持。

## Future Work
作者计划学习更轻的结构 anchor/视频监督，并跨数据集、embodiment 和任务做大规模 World Adapter 联合训练。

## Rating
创新度评分：4/5 - 通过强制共享 tokens 与训练后裁枝解决世界模型推理成本，机制新且验证完整。
相关度评分：3/3 (Core) - 直接研究世界建模如何塑造高效具身策略。

## TL;DR
World Tokens 强制策略消费预测表征并在部署删除视频模型，低延迟且真机有效，值得精读。
