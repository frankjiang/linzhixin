# Guess and Send: World-Model-Guided Semantic Packet Transmission for Robust Video Perception

## Insight
观察：接收端已有随时间积累的场景特征，发送端的“变化大”或“置信度高”未必意味着此刻值得传输。推论：先预测接收端缺包后的特征，再比较“全更新”和“仅预测”的任务输出，可将带宽优先给预测无法补足的区域。KITTI/VisDrone 的低信噪比结果及去预测消融支持这一通信决策原则；并未证明预测器学到了通用场景动力学。（正文 §IV–VI）

## Motivation
无线视频感知受带宽和丢包限制，传统图像编码、发送端特征变化或置信度驱动的选包，未同时考虑接收端当前记忆、可预测运动及具体任务影响。本文重点是**语义通信和分布式视频感知**，世界模型只是维护接收端缓存的一个子模块。

## Method
- 冻结 DINOv2 特征并经 PCA 降至 128 维；每个 2×2 网格块成包，以 3-bit 特征载荷覆盖更多空间。发送端根据 ACK 保有接收端状态副本，估计全局仿射运动并传参数；共享的 4 层时空 Transformer 根据缺包历史预测残差位移和“预测/保留旧值”门控。发送端用当前帧验证每块预测误差，决定预测是否可用。（正文 §III–IV）
- 在同一接收端记忆下运行任务头两次，比较全量新特征与全靠预测的输出，给每包一个任务影响分数；带跳过选项的拉格朗日分配器按分数和信道误码率选择 LDPC 码率，成功到达的包覆写缓存。整帧无包时复用上次运动估计或保守回退。（正文 §IV）
- 方法是缓存预测、接收端副本、任务选包与信道保护的系统组合；预测模型主要做特征空间运动补偿，非可交互视频/3D 世界模型。

## Experiment
- KITTI-MOTS 80 段、VisDrone 68 段各约 3.2 秒，模拟 Rayleigh 衰落/AWGN 码字擦除；以 J&F 衡量目标分割，另在 KITTI 测 mAP@0.5 检测。比较 H.264/H.265+LDPC、DeepJSCC、特征变化、发送端置信度、周期刷新等，预算为完整 6-bit 数字参考的 4.13% 或 12.5%。（正文 §V；附录 A）
- KITTI 4.13% 预算、0 dB Rayleigh：J&F **47.5%**，H.264 **36.2%**；去世界模型为 **41.0%**，−5 dB 时去模型从 **39.5%** 降至 **30.8%**。VisDrone 同预算 0 dB 为 **39.8% vs H.264 34.1%**。高信噪比优势消失：KITTI 20 dB 为 51.6%，H.264 54.5%。（正文表 III；附录表 V、VII）
- 3-bit 相较 6-bit 在满预算 AWGN 的 J&F 仅下降 **1.24 点**；选包检测迁移在 4.13%、0 dB 下为 36.2% mAP，略低于 DeepJSCC 的 36.9%，叠加 DeepJSCC 后升至 45.1%。组件耗时中位数之和约 **93.2 ms/帧**，但不含端到端无线系统。（正文表 II、IV；附录表 IX）

## Value
若研究分布式视频模拟/远程感知，可借鉴“同步接收端状态→预测→按任务增益选择更新”的闭环思想；对视频/3D/JEPA-Dreamer 世界模型的表示或动力学设计参考较有限。

## Strengths
把预测与实际接收缓存及丢包历史连接；有预测/仿射/选包等受控消融；比较两类信道、两套视频数据，并报告预算与计算开销。

## Weaknesses
只做短视频的感知缓存维护，不能预测新显露内容或动作后果；丢包为校准误码率的码字级仿真，缺少真实无线部署；仿射参数、包 ID 和 ACK 不计入报告的正向带宽，预算解释需谨慎；VisDrone 的 J&F 来自填充检测框代理掩码；检测迁移不是始终优于 DeepJSCC；高信噪比下输给常规编码。（正文 §III–VII）

## Future Work
作者提出自适应载荷精度、数模混合传输、利用反馈的状态刷新、更长时间尺度选包，以及预测新显露场景内容。（正文 §VII）

## Rating
创新度评分：2/5 - 对通信系统的组合与工程验证扎实，但世界模型本体是轻量运动补偿，面向本研究方向的方法新意有限。
相关度评分：1/3 (Tangential) - 仅间接涉及视频特征预测，主贡献为语义包传输。

## TL;DR
用接收端特征预测和任务影响评分选择无线视频包，低信噪比感知受益；世界模型方向可跳过。
