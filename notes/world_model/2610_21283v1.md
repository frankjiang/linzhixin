# Mallea: Building, Steering, and Memorizing Worlds with Coding Agent

## Insight
论文主张：若对象的几何、属性、转移规则和纹理由同一稳定身份组织，运行时修改材质或规则后，就能只更新受影响的外观，保留未改对象及其先前纹理。例子是回访时花瓶纹样可复用、改材质方块需刷新。该推论在文中主要由系统设计与示意图阐述；尚无定量回访或消融实验证明。

## Motivation
纯视频生成器难保证长程物体身份、物理行为及编辑后状态一致；既有代码世界模型和几何缓存系统已把可执行状态与生成渲染结合，但对象表征、可编辑规则及外观记忆常分开处理。关键问题是：每个对象究竟需显式保留哪些交互信息，又如何让外观记忆随对象状态变化。对持久视频世界有意义，但本文验证尚早。

## Method
文本输入后，编码代理为各对象推断所需交互，联合选择简化碰撞盒、关节代理或局部网格，定义带类型/单位/写入者的属性及事件-条件-更新规则；若局部接触或运动检查失败才细化表征。可执行代码按 S(t+1)=F_M(S(t),u(t)) 推进世界，用户可插入动作或文字编辑。编辑先在状态副本上核对类型、依赖、相关行为和未受影响状态，再在仿真步边界提交。纹理记忆只对显式 whitebox 对象按 ID 和表面存储，依据材质、损伤、视角及可见性决定复用或失效；生成渲染器结合当前状态、几何控制和有效纹理产生视频，再把可靠区域注册回对象。创新是把这三环以对象身份联动，底层代码世界模型、代理几何及纹理注册均有先例。

## Experiment
仅展示 12 个场景的定性帧，涵盖光学装置、战术场景、磁性材质、火控链、零重力等；帧按各片段 0/25/50/75/100% 采样，未按事件对齐。图中可看到生成视频和 whitebox 对照，但左列第 2–4 行 whitebox 是**视频生成后调整**的；图 5 的纹理记忆画面明确是 AI 机制示意，不是实验结果。没有交互正确率、长程回访一致性、运行成本、基线对比或记忆消融；作者称相关定量结果将来发布。

## Value
对视频/3D 世界模型有可借鉴的模块边界：以对象身份连接可执行状态、最小足够几何和外观记忆；材料与损伤编辑应使局部纹理失效，而姿态变化可复用物体坐标系纹理。当前更像系统方案，不能据此判断实际时空一致性或优于既有方法。

## Strengths
明确区分物理状态和外观记忆，并给出运行时编辑时保持无关状态的检查流程；按交互复杂度选择对象表征，避免所有物体一律高精度建模。

## Weaknesses
缺少任何定量评测或关键消融，短片演示无法验证长期持久性；部分 whitebox 在视频生成后改动，使结构和视频的一致性证据更弱。编码代理、渲染器、纹理缓存预算与失败处理的具体实现不足，系统复现及计算代价不清楚。背景等非 whitebox 内容不进入对象纹理记忆，仍可能漂移。

## Future Work
作者明确计划发布交互忠实度、运行时能力扩展、长程一致性、记忆消融和计算成本的定量评测。

## Rating
创新度评分：2/5 - 对象表征、可编程规则和纹理记忆的联动有设计价值，但与现有代码世界模型接近，缺乏可验证结果。
相关度评分：3/3 (Core) - 直接研究由可执行 3D 状态和生成渲染共同组成的视频世界模型及其记忆。

## TL;DR
Mallea按对象身份联动可执行几何、规则编辑与纹理记忆，瞄准持久视频世界，但只有定性演示、无定量证据；可选读。
