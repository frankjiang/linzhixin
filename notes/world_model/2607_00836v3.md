# From World Models to World Action Models: A Concise Tutorial for Robotics

## Insight
这篇教程的核心 insight 是：机器人里的 world model 不应只被理解为“预测未来观测”，还要和可执行动作连接起来，形成 World Action Model。WAM 的重点是把未来预测、动作条件和策略执行放进同一个决策闭环。

## Motivation
近期视频生成、VLA、robot foundation model 都在使用 world model 术语，但定义混杂。机器人读者需要一个简洁 taxonomy，区分 observation-space、state-space、action-conditioned prediction、imagine-then-act 和 joint video-action modeling。

## Method
论文给出概念整理：world model 是 action-conditioned predictive model，预测 future observation/state；可按 observation spatial explicitness 和 action abstraction 分类。WAM 则强调从预测未来到执行动作的接口，包括 imagine-then-execute、video-feature-conditioned action prediction、joint video-action modeling 和 auxiliary video prediction 等范式。

## Experiment
这是 tutorial，没有新实验。价值主要在框架、术语和代表性工作梳理。

## Value
适合作为进入机器人 world/action model 文献的路线图。对我们整理论文和判断相关度很有用，但不应当作技术贡献论文精读。

## Strengths
定义清楚；覆盖机器人 WAM 的主要范式；帮助统一 world model 与 policy 的关系。

## Weaknesses
没有新方法和实验；部分 taxonomy 仍较高层；对具体模型训练细节、评价指标和失败模式讨论有限。

## Future Work
教程指出未来需要更强的长时预测、闭环评估、多模态感知和可执行动作接口。

## Rating
创新度评分：2/5 - 主要是教程和 taxonomy，而非新算法。
相关度评分：3/3 (Core) - 直接聚焦机器人 World Model / World Action Model。
