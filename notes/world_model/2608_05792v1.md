# When Agentic AI Meets Integrated Sensing and Communication

## Insight
论文最有用的判断是：用了 RL、联邦学习或多智能体优化，并不等于系统具有 agency。作者据此把无线系统拆成观测、语义化、预测/推理、规划/编排、执行/协作、反馈/韧性六阶段，并以显式目标、记忆、多步计划、工具调用和结果反馈作为更高成熟度的必要条件。对代表性文献按九类 agent 指标审计后，没有系统报告超过一两类指标，说明“agentic ISAC”的命名明显领先于可验证证据。

## Motivation
集成感知与通信（ISAC）、RIS、边缘智能、UAV、联邦学习和网络智能体等文献彼此割裂，且常把单任务自适应控制泛化成“Agentic AI”。本文试图为二者结合的 AISAC 统一术语、架构和评价尺度。对 6G 网络研究这是及时的系统化问题，但与视频、3D、JEPA/Dreamer 世界模型只在“预测环境状态”这一抽象层面相交。

## Method
这是一篇 35 页综述而非算法论文。作者提出六阶段闭环，以及 L0 物理 ISAC 原语、L1 AI 辅助组件、L2 自适应控制器、L3 上下文感知 agent 组件、L4 完整闭环 AISAC 五级成熟度；再按主要阶段、ISAC/AI/接口贡献、成熟度重组相关工作。架构采用三时间尺度：快速物理控制，中速资源编排，慢速意图理解、世界模型更新与持续学习；高层 agent 调用波束成形、RIS、调度器、数字孪生等受限工具。后半部分覆盖分布式协作拓扑、角色分配和全链路安全，并提出九维评价框架。

## Experiment
论文没有实现系统或开展受控实验，证据来自文献表格化归类。其主要“实证”是抽查代表性 AISAC 研究是否报告上下文正确性、不确定性校准、目标完成率、规划延迟、约束违例、工具调用成功率、协作开销、恢复时间和人工干预频率；结果是每项工作最多覆盖一两维，agent-oriented 架构甚至多为定性案例。该审计方向合理，但未交代系统检索协议、纳入排除标准、完整样本规模或多标注者一致性，不能视为严格系统综述或 meta-analysis。

## Value
文章适合作为 agentic 6G/ISAC 的概念地图，尤其能提醒研究者区分固定奖励的控制器、可调用工具和真正闭环 agent，并把安全问题沿决策链定位。对本研究方向仅有间接启发：世界模型若服务于实时物理系统，应暴露不确定性、支持多时间尺度控制并接受执行反馈；但文中没有视频/3D/隐式世界模型的方法或结果。

## Strengths
- 六阶段闭环与五级成熟度定义清晰，能抑制把任意 AI 模块包装成 agent 的概念膨胀。
- 把物理层、语义层、规划、工具执行和反馈安全放在同一体系中，覆盖面广。
- 明确指出高层推理与毫秒级物理控制的时标错配，以及安全工具调用、恢复与端到端评价缺口。

## Weaknesses
- 主要贡献是作者综合出的 taxonomy，缺少可复现的检索流程、定量综述方法和真实系统验证。
- 引用范围极广但逐项讨论较浅，很多传统优化、FL、DRL 工作只是被重新解释为未来 agent 的“工具”。
- L4 成熟度与九个指标由作者规范性定义，尚未证明这些维度充分、彼此独立或能预测部署价值。
- “预测世界模型”只是开放挑战之一，未涉及视频生成、3D 表征、JEPA 或 Dreamer 的技术细节。

## Future Work
作者提出物理信号到语义状态的 grounding、无线—物理预测世界模型、实时 agent—PHY 接口、安全且可验证的工具调用、异构 agent 协商、端到端隐私与韧性保证、激励机制、资源高效自治，以及同时包含物理动态和任务目标的统一基准。

## Rating
创新度评分：2/5 - 六阶段与成熟度 taxonomy 有整理价值，但主要是宽泛综述和概念综合，没有新算法或实证系统。
相关度评分：0/3 (Noise) - 核心主题是 6G 集成感知通信与网络 agent，未研究目标中的世界模型范式。

## TL;DR
以六阶段闭环梳理 agentic 6G 感知通信并揭示评测缺口，但无目标世界模型技术，可跳过。
