# WALDO: One-Shot Exemplar-Conditioned Object Detection in Cluttered Scenes

## Insight

观察是开放词汇检测器只能回答“哪一个属于该类别”，不能仅凭文字指出同类中的特定实例；而直接比较冻结 V-JEPA/DINO 的 exemplar 与同场景 crop，top-1 仅 15.9%/14.3%，接近 9 选 1 的 11.1% 随机水平。作者据此推论：实例对应和“目标不存在”都必须显式监督，不能靠通用 embedding cosine 或置信度阈值自然涌现。

论文进一步用匹配网格的 backbone 替换实验支持一个较窄结论：V-JEPA 2.1 相比 DINOv3 更有利于精细框定位与同类缺席判断，但并未提供实例身份。V-JEPA 的 instance Success@1 为 0.190，恰好等于由 category 命中率推导的随机选同类实例 floor；因此这里的“world-model feature transfer”只覆盖 spatial precision/presence estimation，而不能被解读为对象持久身份表征。

## Motivation

机器人拣取、跨相机重识别和库存审计常需从一张参考图与一句描述，在拥挤场景定位“这一件”对象，并在它不在场时拒答。open-vocabulary detector 做类别检索，referring-expression benchmark 默认目标存在，one-shot detector 又通常不带文字与显式 absence head。WALDO 研究冻结世界模型预训练表征能否用一个小头补齐该能力。

问题本身是目标检测而非世界建模，但它直接检验 V-JEPA 2.1 的 dense feature 对下游实例匹配、定位和 presence 的迁移，因此对隐式世界模型表征诊断有借鉴价值。

## Method

1. 从 220 个密集停车场/飞机坪场景的 763 个 instance boxes 合成 episode。positive 用目标框增强 crop 作 exemplar；within-category absent 使用排除该实例但可保留同类干扰物的 region；cross-category absent 用另一类别 exemplar。每 epoch 每实例一个 episode，比例约 66%/19%/15%。
2. 为避免“crop 大小预测是否存在”的捷径，先从所有 episode 共享的尺度分布抽 region，再决定 label；作者的错误 sampler 曾仅靠区域面积达到 0.9998 absence AUROC。修正后 area/width/origin-x/aspect 的单变量 AUROC 为 0.529/0.529/0.442/0.491。exemplar 每 epoch 随机旋转、缩放、光照、blur/noise 与 JPEG 退化；25% 混入 catalogue photo。
3. 冻结 V-JEPA 2.1 ViT-L/16 将 query 编码成 $24\times24=576$ 个 1024-D tokens，将 exemplar patch mean-pool 成向量；still image 被复制为一个 tubelet。冻结 SigLIP2 text tower 编码描述。每个 query patch 与 exemplar 的 cosine correlation 作为额外通道，在 learned projection 前拼接。
4. exemplar 与 text 投影后经零初始化 FiLM 全局调制 query tokens，再经 3 个 pre-norm Transformer blocks（$d=256$、8 heads、MLP ratio 3、dropout 0.1）。三个 head 分别预测 patch objectness、相对 patch center 的 box，以及 attention-pooled scene presence；总可训练参数 3.39M，所有 encoder 均冻结。
5. 训练以 focal loss、$L_1$、GIoU 和 presence BCE 联合优化，权重 5/2/1；AdamW peak lr $3\times10^{-4}$、batch 8。推理输出 576 boxes 与 presence，不内部 threshold/NMS；统一 scorer 以 IoU 0.5 NMS。另有 hand-designed coarse-to-fine multi-look，但主结果均为 single-pass。

方法创新主要是 exemplar correlation、text FiLM、joint presence head 与防捷径 episode mining 的组合；核心检测头与损失均较标准，贡献更偏向任务定义和受控负样本构造。

## Experiment

- 数据只含一个深红 Toyota Highlander 与一个白色 Boeing airliner 两类目标，共 220 scenes、763 boxes；按场景划分 150/35/35 scenes、523/124/116 instances。test exemplar 是目标从待检同一图像中裁出的未增强 crop，因此比跨视角 re-identification 更容易；median crop 约 $87\times108$ px。
- backbone ablation 保持 head、episode、loss、split、seed 不变，并统一成 576-token grid：V-JEPA 输入 384 px/1024-D，DINOv3 输入 336 px/768-D，SigLIP2 输入 384 px/1152-D。grid 相同但像素、容量、预训练分辨率和 embedding width 并未完全匹配。
- 主表（Table 2，PDF 第 6 页）：catalogue AP@50 为 V-JEPA 0.461、DINOv3 0.428、SigLIP2 0.481，Success@1 为 0.629/0.600/0.743；$n=35$ 下最优-最差差值 0.143 仍在作者估计的约 $\pm0.15$ 噪声范围。V-JEPA 对 category-prompted Grounding DINO 的 AP@50 为 0.461 对 0.306，但后者完全冻结而 WALDO head 已训练，监督不匹配。
- 核心负结果：instance Success@1 为 0.190/0.190/0.224，对应 category-chance floor 为 0.190/0.181/0.224，ratio 1.00/1.05/1.00；exact one-sided test $p=0.55/0.44/0.55$。V-JEPA 有 79/116（68.1%）查询的 top-1 对正确实例 IoU 恰为 0。多视图 refinement 的 12 个 paired McNemar tests 均不显著。
- hard absence（46 negatives，其中 78.3% 仍含同类实例）AUROC 为 V-JEPA 0.880、DINOv3 0.726、SigLIP2 0.831；easy cross-category negatives 三者均 1.000。V-JEPA 的 positive/hard-negative mean presence 为 0.862/0.456，DINOv3 为 0.667/0.536。样本仅 46，第三位小数不应过读。
- V-JEPA 的优势主要在严格定位：catalogue AP@75 为 0.168，对 SigLIP2 0.063、DINOv3 0.021；AP@[.5:.95] 为 0.208/0.189/0.139。类别差远大于 backbone 差：aircraft AP@50 约 0.874-0.879，car 仅 0.150-0.210，反映小目标只占 3-4 patches 与更高密度。
- 统计上训练仅主配置独立重训一次；作者估计 catalogue/instance Success@1 小于约 0.10-0.15/0.07-0.09 的差异可能只是 run variation。best-F1 threshold 又直接在 evaluation set 取最大值，存在乐观偏差。

## Value

这项工作最值得借鉴的是两类负证据：合成 absence supervision 必须系统审计几何 shortcut；冻结 JEPA 表征的“找到类别/判断在场”不能自动等同于追踪实例身份。对 JEPA 研究，建议把同类干扰、absence 和 identity floor 加入 dense-feature probe，而不只报告 linear probe 或 category retrieval。WALDO 本身没有学习未来、动作或状态转移，因此不是新的世界模型方法。

## Strengths

- episode sampler 主动暴露并修复 0.9998 AUROC 的 crop-size 捷径，且给出四个 negative controls 与单元测试。
- 清楚分离 catalogue、instance 与 absence 三种任务，使用 category-chance floor 和 exact test，未掩盖实例失败。
- backbone 对照统一 token grid、head 和训练配方，并同时报告 AP@50、严格 IoU、Success@K、presence AUROC 与 matched/top-1 IoU。
- 对 baseline 的 interface 限制、提示信息不对等、样本噪声和多 look 个案均有克制说明。
- 3.4M trainable head、冻结 backbone 的设计使结果可视为表征 probe，而不是大规模微调收益。

## Weaknesses

- 最强反例就是论文自己的主结果：instance Success@1 与“先找对类别再均匀猜实例”的 floor 无差异，故标题所称 exemplar-conditioned instance detection 的核心能力并未实现。
- 数据极小且狭窄：仅两个指定对象/类别、35 test scenes、116 instance queries；同类 absence 只有 46 个，跨类别 easy negatives 又饱和，泛化到开放类别或真实机器人场景未知。
- test exemplar 来自同一待检图像而非不同相机/时间，即使如此仍无法识别实例；这对跨视角 one-shot 使用是强负面边界。
- V-JEPA 与 DINOv3 并非容量、输入像素或预训练分辨率匹配，embedding width 也使 head 为 3.26M-3.45M；不能把差异干净归因于“world-model objective”。
- WALDO 是监督训练头，而 Grounding DINO/OWLv2 完全冻结且不能表达 instance/absence；0.461 对 0.306 只说明该定制头在此协议有效，不是公平架构优越性比较。
- 主要结果缺多 seed 均值/置信区间，best-F1 在 test 上选阈值；car/aircraft 的约 5 倍性能差说明分辨率和数据构成比 backbone 选择更主导。

## Future Work

作者没有提出具体、分阶段的未来方案，只明确指出实例身份仍未解决，当前 box-tightness、低分辨率小目标与 exemplar upsampling 是主要边界，并把 cross-view re-identification 排除在现有结论外。

合理推断的后续方向是：使用跨视角/跨时间 exemplar 和多类别大规模 instance benchmark；引入 higher-resolution/multiscale tokens、局部 correspondence 或 track-level contrastive supervision；做容量与像素严格匹配的 V-JEPA/DINO 对照、完整多 seed 统计，并增加真正能接收 exemplar 且支持 abstention 的 one-shot baseline。

## Rating

创新度评分：2/5 - presence-aware episode mining与严格 shortcut 审计有实用贡献，但模型是标准相关通道、FiLM 与小型 Transformer 的增量组合，且核心实例能力未超过随机 floor。
相关度评分：2/3 (Related) - 本质是下游目标检测，但直接检验 V-JEPA 2.1 dense world-model features 的定位、缺席与实例身份迁移，对隐式 JEPA 表征有直接诊断价值。

## TL;DR

WALDO探测出V-JEPA擅长定位与缺席判断却不具实例身份，结论坦诚，建议选读。
