# SCOPE: Spatially-Selective Per-Pixel Action Conditioning for FPS Game World Models

## Insight
观察：FPS游戏的动作具有空间选择性——开火/换弹仅影响武器区域（约10%画面），而视角转动影响全局。推论：全局统一的action conditioning（如AdaLN/concatenation）会稀释离散事件的局部效果或让连续控制过度干扰非相关区域。方案：双通路per-pixel conditioning——discrete events通过cross-attention仅注入scope mask内区域，continuous controls通过temporal self-attention全局传播。

## Motivation
- 问题：现有游戏世界模型（GameGen/Oasis/DIAMOND等）使用全局action conditioning，在FPS场景下对离散事件（开火、换弹、受伤）的可控性差
- 同行：GameGen-X用ControlNet方式注入，Oasis简单concatenation，均无空间选择性
- 关键性：FPS是交互式视频世界模型的重要应用场景，精确动作可控是关键需求

## Method
- SCOPE Module（嵌入每个DiT block）：
  - In-Scope Pathway：discrete events → cross-attention → 仅在scope mask标记的像素区域生效
  - Out-of-Scope Pathway：continuous controls → temporal self-attention → 全局影响
  - Scope Mask：从数据中自动提取（weapon region固定mask + 受伤全屏mask）
- Backbone：Wan2.2-TI2V-5B
- CrossFPS Dataset：69K video clips，7款FPS游戏，10-DoF action space（4连续+6离散），统一action schema
- 训练：LoRA微调Wan2.2 backbone + 全量训练SCOPE modules

## Experiment
- 零样本动作可控性（unseen scenes）：71.5% vs 38.3%（最强基线GameGen-X）
- 离散事件准确率：开火86.2%、换弹79.1%
- 跨游戏泛化：训练7游戏，在held-out游戏上action following仅降~5%
- 消融：(1)双通路 vs 仅cross-attention → 连续控制可控性从62%降至41%；(2)scope mask vs 全局mask → 离散事件准确率降15%；(3)数据量scaling有效
- FVD/FID等视觉质量与基线持平

## Value
研究贡献明确：(1)识别了FPS action conditioning的空间选择性问题；(2)提出了简洁有效的双通路方案；(3)构建了大规模标准化数据集CrossFPS。对视频世界模型的启发：action conditioning需要考虑动作的空间影响域，不应一刀切全局注入。局限：scope mask目前是预定义的，未来应学习自适应mask。

## 创新度：3⭐
空间选择性action conditioning概念新颖且验证充分，双通路设计简洁有效，但各组件技术（cross-attention/temporal self-attention/scope mask）均为已有技术。

## 相关度：3 (Core)
直接构建交互式视频世界模型，空间选择性action conditioning是有价值的设计思想。

## TL;DR
提出per-pixel空间选择性action conditioning用于FPS游戏世界模型，离散事件通过cross-attention局部注入，连续控制全局传播，零样本可控性71.5% vs 38.3%基线。值得精读。
