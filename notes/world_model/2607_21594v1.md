# Streaming Multi-Agent Autoregressive Diffusion Model with World State Registers

## Insight
有。Observation 是多智能体视频世界中，每个 agent 只看到共享 3D 世界的局部 2D 投影，但世界状态会跨视角、跨时间持续演化；仅把历史帧作为条件，会让模型反复从像素上下文中重推隐含状态，难以保持未观测区域和跨 agent 关系。推论是应在生成器内部维护一个可持久、可更新、可监督的 world state。作者用 World State Registers (WSR) 承载该状态，并通过 agent stats、BEV、scene text 三类监督和消融证明：显式状态槽与语义/几何 grounding 能提升逻辑一致性。

## Motivation
解决 multi-agent interactive world model 中跨 agent 一致性和长期状态记忆问题。已有 autoregressive video diffusion、Self-Forcing、Solaris 等方法能流式生成视频，但主要依赖局部帧窗口、KV cache 或跨玩家 frame attention，世界状态仍与视觉 token 纠缠。这个问题对视频世界模型很关键：交互式世界不只是生成看起来连续的帧，还要让共享环境、相对位置、agent 行为在不同观察者之间保持一致。

## Method
整体是三阶段训练的两玩家 Minecraft latent video diffusion。Stage 1 将单人视频扩散模型扩展出 player axis，在同步双人数据上训练 bidirectional teacher，学习跨 agent 场景结构。Stage 2 从 teacher 初始化 causal student，采用 Diffusion Forcing 式 block causal mask 和滑动窗口，并把帧 token 与 register 交替排列为 `[x0, r0, x1, r1, ...]`；每个 register attend 到最近 W 帧和上一 register，生成后被 commit，作为下一步条件。WSR 是 K=256 个 learnable tokens，训练时接三个辅助 head：agent 状态回归 position/velocity/orientation，BEV 预测 DINOv2 dense feature，scene text 通过 frozen Llama scorer 做 prefix supervision。Stage 3 用 Self-Forcing/DMD 在学生自生成上下文上训练，同时继续施加 register loss，暴露 frame drift 和 register drift。

架构上引入 Mixture-of-Transformers：frame token 和 WSR token 走不同参数分支，但在同一交错序列中 joint attention。创新点不在某个 head，而在把“可提交的隐式世界状态”放入流式扩散 rollout，并用可验证的物理/语义信号约束它。

## Experiment
数据来自 SolarisEngine，约 126 小时 832x480、20fps 的同步双人 Minecraft 视频，带 agent 状态、顶视角和 Qwen2.5-VL 生成的 4-frame scene text。评测在 Solaris test split，输入两位玩家首帧和完整 action sequence，生成后续视频。指标包括五类 VLM accuracy、FID，以及辅助 WorldScore。

主结果：WorldWeaver 的 WorldScore 105.1，高于 Frame concat 49.1 和重训 Solaris 81.0；相对 Solaris，Grounding VLM 81.3->93.8，Building 9.4->28.1，Consistency 57.8->76.6，说明收益主要来自状态敏感任务。监督消融显示 registers only 已把 WorldScore 提到 93.8；单独 scene text 达 103.2，BEV 达 102.4，三者合用达 105.1。MoT 消融显示没有显式监督时 MoT 不一定更好，但在 scene text supervision 下 Dense 只有 91.3，MoT 到 103.2，说明语义化 register 与视觉生成共享参数会产生冲突。半监督实验中固定 1K labeled BEV clips，加入 10K unlabeled clips 将 WorldScore 从 63.2 提到 90.3。

## Value
这是本批中最贴近视频世界模型核心问题的工作。启发是：跨视角一致性不能只靠更长 context，应该引入“可持久、可更新、可监督”的隐状态槽；监督信号可以是 low-level 3D/状态、allocentric view、语言语义的组合。待解决的是真实世界状态标注难得、Minecraft 双人场景规模有限，以及 WSR 是否能扩展到开放世界、多 agent、多对象和真实物理。

## Strengths
问题定义清楚，直接击中 multi-agent world model 的共享状态瓶颈。WSR 的设计与流式 autoregressive diffusion 结合自然，训练和推理闭环一致。三类 register supervision、MoT、半监督都有消融支撑，且可视化让隐式 state 更可检查。

## Weaknesses
实验域单一，集中在双人 Minecraft；关键收益依赖 simulator 提供的 agent stats 和 BEV，真实数据中很难完整获得。WorldScore 是作者定义的辅助指标，且 Building 类 VLM accuracy 虽提升明显但绝对值仍低。register head 推理时丢弃，实际生成质量对 register 语义的可控性仍有限。

## Future Work
作者指出未来应走向更复杂的真实世界状态，包括低层 3D 一致视觉细节和高层跨 agent/player 语义关系；半监督设置也暗示可用少量显式状态标注锚定大量未标注视频。

## Rating
创新度评分：4/5 - 在流式多智能体视频扩散中显式引入可提交的 world state registers，并系统验证监督与架构设计，属于显著创新。
相关度评分：3/3 (Core) - 直接研究多智能体视频世界模型、隐式状态记忆和跨视角一致性。
