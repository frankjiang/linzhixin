# PhyCheck: Fine-Grained Evidence-Grounded Dataset for Physical Law Understanding in Video-LLMs

## Insight
有，但证据较弱。Observation 是 Video-LLM 对“符合物理”的样本 recall 高、对 violation 的 recall 很低，说明高总体准确率可来自默认接受视觉现象的偏置；同时，细粒度视觉线索若单独训练几乎无效，但先 fine-grained、再 coarse verdict 可把准确率从 50.93 提到 81.00。作者据此推论先学习局部证据、再学习总体物理判断可能形成更好的 curriculum。另一个 50-pair pilot 显示模型看到隐藏原因的文本后仍难修正判断，提示“发现异常”不等于“整合因果上下文”。这些都是经验观察，且缺少严格控制和随 PDF 发布的附录结果，不能证明模型获得了物理机制。

## Motivation
现有物理 benchmark 多评生成视频是否逼真，或以粗粒度/多选题测试 VLM 常识，较少同时问“违反哪条定律、画面证据是什么”。若要用 Video-LLM 评审视频世界模型或服务 embodied AI，仅判整体合理性不足，还需识别具体异常并对隐藏条件更新判断。问题有直接的 evaluator/data value，但论文研究的是视频理解模型，不是生成式 world model 本身。

## Method
PhyCheck 复用 VideoPhy2 train/test 中由 Luma Ray2、CogVideo、Cosmos、Hunyuan、VideoCrafter、Sora、Wan 生成的 6,399 段、8.61 小时视频。保留 VideoPhy2 标为 followed/violated 的 rule-video pair，丢弃 undetermined；用 consistency/violation 两类模板反转 yes/no 极性，构造 coarse binary VQA。

fine-grained 流程先让 Gemini-3 描述现象并基于原 physical-law label 生成可能的 negative physical details，再由 GPT-5 改写为可回答的局部证据问题。两名标注者独立判断，冲突交第三人多数表决，并核查可见性和物理相关性；初始标注 raw agreement 99.74%、Cohen's κ 0.9959。最终共 69,825 个 QA，平均每视频 10.9，覆盖 mechanics、conservation、material、fluid/interface、optics、thermal 六类。另手工裁掉真实视频中的可见原因，做 50 对 context-sensitive pilot，并附隐藏原因文本。

## Experiment
直接评测 Qwen3/3.5/3.6、LLaVA-OneVision2、UniVid、UniVideo、Gemini-3.5-Flash 和专用 Skyra，报告 overall accuracy 及 Conform/Violate precision/recall/F1。多数准确率约 58–63%；LLaVA-OneVision2 最高 63.11，但 Violate recall 仅 14.07，Qwen3-Instruct 的 Conform/Violate recall 为 84.68/20.24，说明明显正类偏置。Skyra 的 Violate F1 约 34.9，并未全面超过通用模型。

Qwen2.5-VL full fine-tune 12 epochs：原始 50.93%；fine-only 51.43，coarse-only 66.83，coarse→fine 51.89，fine→coarse 81.00，后者 Conform/Violate F1 为 86.69/66.78。论文未报告多 seed、方差、学习率、batch size 或各阶段等预算。generation-source failure 分析显示原模型跨七个生成器失败率相对稳定，微调后大幅降低。50-pair pilot 仅在正文口述：Qwen3.5-27B video-only 0.96 但难随 context 更新；微调模型 video-only 0.18、context 后 0.98，缺少正文表格所引用的 Appendix C3。

## Value
可作为训练/校准视频世界模型自动评审器的候选数据源：特别是把 overall verdict 与 evidence question 分开，并显式暴露“总说物理正确”的类别偏置。对我们更重要的不是用其准确率直接证明 world model 物理性，而是借鉴同一视频的规则级、多证据评测设计。当前数据高度依赖合成视频和既有 VideoPhy2 label，适合作为 diagnostic/SFT 资源，不足以作为物理理解的最终 benchmark。

## Strengths
6,399 视频、近 7 万 QA 和 556 人时验证，规模与人工检查较充分；问题极性翻转降低固定 yes/no 模板偏置；同时报告 class-wise precision/recall/F1，揭示总体准确率掩盖的 Violate failure；覆盖多种开源、闭源和专用模型；对 fine/coarse 监督顺序做了初步消融，并坦承 context pilot 规模很小。

## Weaknesses
数据并非新采集物理实验，而是对 VideoPhy2 合成视频和原标签的再包装；生成模型特有 artifact 可能成为 shortcut，不能支持“true physical causality”的强主张。fine questions 由 Gemini/GPT 基于已知 label 生成，再由人判 yes/no，高 κ 可能反映问题简单或模板化，未报告抽样审计、标注者背景、law-level coverage 和 train/test 去重。论文前文称约 50k human-verified，overview 又给 69,825，统计口径未解释。SFT 顺序对比可能混入总训练步数、catastrophic forgetting 或同视频记忆，且没有 seed/显著性/跨 benchmark transfer。实现仅写 12 epochs+A100；正文引用 Appendix C3，但 15 页 PDF 没有附录。context 模型 video-only 0.18 更像严重误判，称为 epistemic caution 缺乏依据。物理问题均为 binary statement verification，不等价于构建可 rollout 的物理模型。

## Future Work
作者没有给独立的 future-work 段，只将 context-sensitive subset 定位为需扩大的 pilot。后续应扩充真实与程序可控 counterfactual 视频，做 minimal-pair/生成器外测试，严格平衡训练预算，公开缺失附录和完整 split，并验证训练后的 evaluator 是否能可靠排序视频世界模型或改进生成。

## Rating
创新度评分：2/5 - 细粒度证据、粗粒度判断和 context pilot 的组合有实用性，但核心是对既有 VideoPhy2 的 VQA 扩注与监督实验。
相关度评分：2/3 (Related) - 不训练世界模型本身，但与视频世界模型的物理一致性评审和 reward/evaluator 构建有直接借鉴价值。

将合成视频改造成细粒度物理VQA监督数据，适合训练视频评审器，可选读。
