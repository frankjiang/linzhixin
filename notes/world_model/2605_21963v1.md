# ChronoMedicalWorld: A Medical World Model for Learning Patient Trajectories from Longitudinal Care Data

## Insight
无显著 insight。将 action-conditioned 潜世界模型框架应用于医学时序预测（CKD 患者 eGFR 轨迹），是已有范式在新领域的应用。

## Motivation
长期临床仿真（多年患者轨迹预测）是慢病管理的核心需求。现有 EHR 模型多为判别式，通用 LLM 在反复干预下会漂移。论文用 action-conditioned 潜世界模型框架来学习患者轨迹。

## Method
联合嵌入状态编码器 + 宽动作编码器（结构化干预 + 自由文本嵌入）+ 循环潜转换模块。六项训练目标：下一步观测监督、下一潜状态预测、SIGReg 潜正则化、三个生理感知形状先验（斜率、连续性、大跳惩罚）。闭环 rollout-prefix 训练协议。

## Experiment
2232 例 CKD 患者肾科队列。动态 50% 历史 rollout 测试 MAE 7.384 / RMSE 10.256，优于 GPT-5.5 基线的 7.964 / 11.069（-7.28% MAE, -7.35% RMSE）。对话部分贡献最大。

## Value
世界模型在医学时序预测中的应用。虽然框架设计合理，但与用户关注的视频/3D/隐式世界模型方向完全无关。技术贡献局限于领域应用。

## Strengths
亮点是世界模型在医学时序预测中的应用。

## Weaknesses
不足是虽然框架设计合理，但与用户关注的视频/3D/隐式世界模型方向完全无关。
