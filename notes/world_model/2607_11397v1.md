# WALA Learning Executable Latent Actions from Action-Labeled Demonstrations and Action-Free Videos

## Insight
核心 insight 是：无动作视频不能直接给机器人动作标签，但可以提供“未来语义-几何变化”的 latent action 监督。作者观察到像素重建容易被外观细节干扰，而 DINOv3 特征差分和 dense depth 差分更接近任务相关状态变化；因此 latent action 可以从 action-free videos 中学习，并在有动作示范中对齐到可执行控制。

## Motivation
通用机器人策略依赖 action-labeled demonstrations，但采集贵且难扩展；大量人类/机器人视频包含物理交互却没有可执行动作。已有 latent action 或 video pretraining 方法常缺少可执行性约束，或只学视觉预测。WALA 要解决“无动作视频如何转化为机器人可用监督”的关键问题。

## Method
两阶段。第一阶段预训练 semantic-geometric LAM：输入当前观测和稀疏未来观测，编码器推断 latent action token，解码器预测 DINOv3 feature delta 和 dense depth delta。第二阶段把 Qwen3-VL-4B 训练成策略：冻结 LAM encoder 生成 latent action target，decoder 作为 trainable latent world model；策略同时受机器人动作预测、latent target matching 和未来 dynamics prediction 监督。推理时只保留 VLM backbone 和 action head。

## Experiment
RoboTwin 2.0 上 WALA Clean 90.6、Random 92.8，随机场景优于多数组具身基线。RoboCasa-GR1-Tabletop 24 任务平均成功率 75.2，高于 DIAL 70.2 等。数据缩放中，10% 有标签 + 90% 无动作视频可到 67.8，超过 100% labels 的 Base 54.2。消融显示 Base 54.2，加入 world/LAM/语义几何监督逐步到 Full 75.2。真实四任务中，WALA 200 demos+400 human videos 平均 83.3，高于 pi0/pi0.5。

## Value
这篇对隐式/latent world action model 很有价值：它把无动作视频引入可执行机器人策略的方式比较清楚，且推理端不增加 world decoder 成本。启发是可以把世界模型训练信号设计为语义-几何未来变化，而非像素。

## Strengths
充分利用 action-free videos；LAM 的语义+几何目标比像素重建更贴近控制；仿真、数据缩放、消融和真机实验都较完整。

## Weaknesses
依赖 DINOv3 和深度估计器质量；latent action 的可解释性有限；真机 OOD 验证仍较小；大规模视频预训练的边界还未证明。

## Future Work
作者明确提到 LAM 预训练数据规模有限，需要更大、更丰富的视频数据；真实世界 zero-shot 只验证了一个 OOD 任务，未来应扩展评估。

## Rating
创新度评分：4/5 - 把无动作视频通过语义-几何 latent action 转为可执行监督，方法和实验都较强。
相关度评分：3/3 (Core) - 直接研究 latent/world action model 和机器人世界模型学习。

## TL;DR
用 DINOv3 与深度未来差分把无动作视频转成可执行 latent action 监督，值得精读。
