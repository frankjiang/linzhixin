# TriO: Tri-Modal Unsupervised Occupancy World Model for Anything Perception

## Insight
开放类别语义模型依赖已知词类，对路面罕见障碍可能漏检；“是否高于可通行地面”的几何判断更贴近驾驶风险。作者在 STU 的伪标签对比中发现，图像深度/法线与 LiDAR 地面片融合的标签 mIoU 44.6、召回 79.9，优于所测开放词汇分割基线；蒸馏到连续 4D 占据模型后，零样本障碍分割 mIoU 达 54.9。

## Motivation
既有 3D/4D 占据预测常依赖昂贵人工标注或单一 LiDAR 自监督，远距、恶劣天气及长尾障碍易失效；开放词汇伪标签同样受类别提示限制。论文要从相机、LiDAR、RADAR 的互补物理信号学习未来空间占据、运动与路障，这是 3D 世界模型的重要问题。

## Method
历史相机图像经 ResNet50，LiDAR/RADAR 点经各自 MLP、稀疏体素卷积，再由图像到体素的可变形注意力融合；连续查询 `(x,y,z,t)` 由隐式解码器输出占据率、障碍概率、3D flow。训练伪标签分别来自 LiDAR 射线空闲/命中区域、Metric3Dv2 深度及法线与 Patchwork++ 地面片的置信度融合、RADAR Doppler 径向速度；用占据 BCE、置信度加权软 focal、径向速度 L1 联训。真正的贡献在几何障碍伪监督及三传感器融合，基础解码器和大量模块沿用前作。

## Experiment
AV2、STU、私有 LRR 上评测零样本路障、LiDAR 预测及标注微调，指标含 mIoU/F1/召回/AP、深度 L1/AbsRel、Chamfer、占据 mAP/SoftIoU、flow EPE。STU 上融合伪标签 mIoU 44.6、召回 79.9；蒸馏 TriO 后 mIoU 54.9、AP 81.6、F1 77.7。AV2 LiDAR 预测 L1 1.82m、AbsRel 10.63%，但 NFCD 0.93 不及 UnO/DIO 的 0.86/0.85；微调 AV2 mAP 63.3，LRR 200m+ mAP 42.6（DIO 36.2）。LRR 消融显示去 RADAR 输入远距 mAP 降至 34.5，去 RADAR 损失 EPE 从 4.01 升至 6.02。定性图显示鸽子、球、书包等长尾障碍；附录也示雪/尾气误报、泡沫物漏检。

## Value
对 3D 世界模型值得精读：把占据、地面可通行性和运动预测放在同一连续 4D 表示内，几何伪标签比固定语义类更适合长尾安全评测；多传感器自监督的损失设计有直接借鉴价值。

## Strengths
跨域 STU 零样本和远距 LRR 评测较有说服力；不仅比较占据精度，还验证伪标签质量、监督强弱、流场及传感器消融；主动展示失败案例。

## Weaknesses
“无监督”仅指 TriO 本身无需直接人工标签，伪标签依赖预训练 Metric3Dv2，后者部分训练数据含人工处理。AV2 没有 RADAR，三模态优势主要靠不可公开的 LRR 验证。完整模型在 20k 查询点上约 489ms、约 9.9GB，远慢于去相机版的约 61ms；相机对 LRR 占据增益很小且会恶化 EPE。径向 Doppler 难唯一确定切向流，流场与占据预测也会不一致；缺少闭环驾驶规划验证。

## Future Work
作者提出用 RADAR/相机补充占据自监督，改善雪和尾气等伪障碍、切向 flow 与占据流一致性；采用更高效相机编码或早期融合，并建立更大长尾障碍基准及闭环规划评测。

## Rating
创新度评分：3/5 - 三模态自监督和几何障碍伪标签形成有价值组合，强结果明确，但结构上大量使用现有编码与隐式占据方法。
相关度评分：3/3 (Core) - 直接预测连续 4D 占据和运动，属于 3D 世界模型。

## TL;DR
用相机、激光和雷达的几何伪监督预测连续4D占据及长尾障碍，跨域表现强但代价高；研究3D世界模型值得精读。
