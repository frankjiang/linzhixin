# SurgVista: Long-Horizon Surgical World Modeling with Plausible Instrument-Tissue Dynamics

## Insight
Observation：手术世界模型的主要失败不是普通视频不清晰，而是器械接触后组织形变不一致，以及自回归长 rollout 中亮度/颜色/结构逐步漂移。

推论：需要分别约束局部交互动力学和长时条件分布漂移：前者用跨帧 scene-point trajectory 做 latent contrastive consistency，后者用在线预测残差和光度扰动模拟推理时退化。

## Motivation
论文面向 autonomous surgery 的安全仿真：真实探索风险高、专家数据贵，因此需要 action-conditioned surgical world model 生成未来内窥镜视频。

同行多把视频 DiT 迁移到手术域，或加入文本/分割/flow/depth 等 action control，但短视野、短 horizon 下评价，未充分解决 tissue response fidelity 和 long-horizon drift。

## Method
SurgVista 基于 latent video DiT / flow matching：
- 输入初始帧和器械 action sequence，action 表示为 instrument keypoint trajectories。
- Latent Action Encoding：把首帧 latent feature 复制到轨迹目标位置，形成 action latent，与 noisy target latent 拼接。
- DCR：从训练视频抽取 dense scene-point trajectories，覆盖器械和组织，在 latent manifold 上做 contrastive coherence，强化接触诱导的组织运动一致性。
- DAT：先用当前模型 online probe 产生预测残差，再叠加对比度、亮度、锐度、噪声等光度扰动，训练模型适应自回归 rollout 的条件退化。
- SurgWorld-Bench：多过程、多 horizon，解耦器械运动准确性和组织响应 fidelity。

## Experiment
评估视觉质量、时间一致性、交互 fidelity，并与 surgical/video world model baseline 比较。

结果结论：
- SurgVista 在短/长 horizon 上均优于 SOTA，且 horizon 越长优势越明显。
- DCR 改善器械接触附近的 tissue deformation coherence。
- DAT 抑制长时过曝、颜色漂移和结构腐坏。
- benchmark 用 decoupled metrics 区分 instrument-motion accuracy 与 tissue-response fidelity，避免 PSNR/LPIPS 这类整体指标掩盖交互错误。

## Value
对视频世界模型有两个可迁移启发：一是 action-conditioned world model 需要面向交互对象的局部动态一致性，而不只是全局重建；二是长 rollout 应显式训练“模型自身错误分布”下的鲁棒性。

局限：领域强依赖手术视频和器械轨迹；DCR 依赖 trajectory extraction 质量；物理接触仍是视觉约束，不是真正力学模拟。

## Strengths
