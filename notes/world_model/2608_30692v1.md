# Can Video World Models Track Unobserved World States?

## Insight

有。核心 observation 是：视频看起来正确，并不意味着模型维护了决定未来的不可见世界状态。视觉 Shell Game 在交换期间让球完全不可见，像素/flow-matching 目标只监督杯子的可见运动，因此生成帧不能像语言 CoT token 那样被自由改写成隐藏状态草稿；增加扩散去噪步也不会增加随序列长度增长的串行状态更新深度。结合固定深度 Transformer/SSM 属于 $\mathrm{TC}^0$、而 $S_5$ 置换复合为 $\mathrm{NC}^1$-hard 的理论，作者推论：可靠外推需要跨 chunk 携带一个可原位改写的状态，且单步更新必须能表示 swap。

论文用两类证据支持该推论：一是把 DeltaNet 写成 $S_t=(I-\beta_t k_tk_t^\top)S_{t-1}+\beta_tk_tv_t^\top$，将 $\beta$ 从 $[0,1]$ 扩到 $[0,2]$ 后，转移特征值覆盖 $[-1,1]$，可实现 swap 所需的 Householder reflection；二是 LaCT 以在线更新的 SwiGLU fast weights 作为跨 chunk 状态，只有更新特征映射 $W_0,W_2$ 时才外推，冻结它们、只更新读出 $W_1$ 会退化为固定核线性注意力并失败。像素无关的 $S_5$ 实验、视觉 Shell Game、内部状态 probe 和消融形成了较完整的证明链。不过作者也明确承认，需用观测纠错或会自主演化的真实世界状态不再是纯 action-only 置换，结论尚不能直接推广。

## Motivation

论文解决视频世界模型评测中的关键缺口：PSNR/SSIM/LPIPS 或主观可视质量只能判断“画得像不像”，不能判断模型是否记住遮挡物、相机视野外物体或动作作用下的隐藏排列。现有长视频工作通常扩展上下文、KV cache 或视觉记忆，状态追踪理论则多停留在符号序列；两者缺少一个能分离渲染与隐藏状态复合的共同测试床。

这是视频世界模型的核心问题：若模型在隐藏状态错误时仍可生成高保真视频，它作为交互模拟器或规划器就会给出貌似合理但因果错误的未来。论文用可控 Shell Game 将问题约化到 $S_5$，同时检验 Transformer、Mamba、线性注意力、RNN、TTT 与显式 memory token，定位“有没有持久状态”和“更新规则够不够强”两个独立瓶颈。

## Method

视觉 Shell Game 使用 5 个相同杯子：先 reveal 球、lower 杯子，执行 $N$ 次两两交换，最后 reveal；一个 swap 对齐一个含 5 个 latent frames 的自回归 chunk。视频为 $256\times192$，冻结 Wan2.1 VAE 做 $4\times$ 时间、$8\times$ 空间压缩，每 chunk 960 tokens。各模型约 200M 参数、宽度 1152，基本 block 为 temporal mixer + SWA + FFN，并以 action/timestep AdaLN 调制；纯 DiT 去掉 temporal mixer。

比较对象包括双向/因果 DiT、RNN/GRU/LSTM、Mamba2、GDN/GDN2/GDP3/KDA、LaCT 和 per-layer scratchpad。线性注意力的关键改动是允许负特征值；LaCT 每层维护多头 bias-free SwiGLU fast-weight MLP，按 clean chunk 的 key-value binding loss 在线更新，再用于下一 noisy chunk；scratchpad 则把 $M$ 个 memory tokens 以 $M\leftarrow M+\Delta M$ 跨 chunk 携带。

作者还从每层当前 readout 与固定 Gaussian query 对 KV/矩阵/fast-weight 状态的 readout 训练线性 probe，分别预测可见 swap 与隐藏球位置，用于区分“为渲染服务的当前特征”和“真正持久的隐藏状态”。附录进一步从线性 TTT 推导 dot-product loss 对应 additive linear attention、MSE 对应 DeltaNet，并在 Memory Maze 与动态 3D Block World 中测试更一般的局部动作、碰撞纠错和视野外自主运动。

## Experiment

Shell Game 在 30,000 条 $N=5$ 交换序列上从零训练 200K steps，batch 16、学习率 $2\times10^{-4}$、NorMuon、diffusion forcing；测试 64 episodes，外推到 $N=30$，用 50 个采样步。指标为最终球位置准确率（chance 0.2）以及 PSNR/SSIM/LPIPS。

主要结果如下。

- 双向/因果 DiT、Mamba2 和非负特征值线性注意力多能拟合 $N=5$，但随长度增加跌向 chance；$N=10$ 时把去噪步从 4 增至 50 不提升状态准确率，PSNR 仍可保持约 29-41，直接证明视觉保真与隐藏状态正确性脱钩（Fig. 4，PDF 第 6 页）。
- 因果 DiT 至少需 SWA5 才能在最终 reveal 看到五个 swap chunk 并拟合训练长度，但所有窗口在 $N=10$ 失败。固定-bank probe 中，LaCT 的隐藏球可解码准确率为 $0.87/0.78$（$N=5/10$），GDN-neg 为 $0.70/0.46$；其他模型明显更弱，而各模型当前 readout 都能以 1.00 解码可见 swap（Fig. 5，第 7 页）。
- 负特征值对多种线性注意力一致有效；GDN-neg 在 $N=30$ 达 0.95。LaCT8 在 $N=5/10/20/30$ 为 $1.00/1.00/0.98/0.69$；换成单层线性 inner model 后变为 $1.00/0.23/0.23/0.13$，冻结 $W_0,W_2$ 为 $1.00/0.14/0.30/0.16$，而冻结 $W_1$ 仍有 $1.00/1.00/0.97/0.64$（Table 1，第 9 页）。
- 一个 scratchpad token 即可从 chance 提升到训练长度满分并外推至 $N=10$，但 1-1024 tokens 均在 $N=20$ 跌回 chance，伴随 memory norm 爆炸（Fig. 6，第 8 页）。
- 在 deterministic Memory Maze 无碰撞、800-frame local-action 条件下，LaCT8 达 SSIM 0.952、PSNR 33.57、LPIPS 0.066；加入碰撞后降至 0.906/28.24/0.116，说明依赖视觉纠错的更新更难（Table A4，第 24 页）。3D Block World 的 320-frame rollout 中，LaCT8+SWA1 为 PSNR 29.36、LPIPS 0.0288，优于 Mamba2+SWA1 的 21.32/0.1060；但仅把 Mamba2 窗口扩到 SWA10 即达 32.29/0.0167，表明局部上下文仍是强混杂因素。

## Value

这项工作的主要价值不是再提高一个视频指标，而是给出一个可操作的诊断原则：世界模型必须把“可见视频历史”与“可持续原位更新的世界状态”分开评测。对我们最直接的启发是，长上下文或更漂亮的扩散采样不能替代状态更新；设计隐式世界模型时应显式检查状态载体、转移代数、write-to-use 梯度路径，并加入隐藏状态 probe 与长度外推。

更一般的开放问题是：真实状态既受动作影响，也需从观测纠错，还可能在不可见时自主演化。负特征值只解决特定置换代数，LaCT 在复杂任务中的优势也可能来自容量、优化或更长有效计算。后续需要把该诊断扩展到不确定、多对象、连续 3D 动力学，并用任务状态或闭环规划而不只用视觉指标验证。

## Strengths

- 问题定义锐利：用“最后球在哪”把视觉渲染质量与不可见状态正确性干净解耦。
- 从复杂度理论、像素无关 $S_5$、视频生成、状态 probe 到消融形成多层证据链，而不是只报告一张成功率表。
- 对两种成功机制给出机制级验证：负特征值对应 reflection；LaCT 的关键在在线特征映射更新而非单纯增加内存容量。
- 报告 denoising-step、SWA window、fast-weight heads、inner model/loss、冻结矩阵与 scratchpad token 数等针对性消融。
- 主动把结论带到碰撞 Memory Maze 和动态 3D Block World，并诚实展示负特征值不再稳定获益、扩大 SWA 甚至更强的边界条件。

## Weaknesses

- 核心证据仍来自固定相机、同质杯子、确定性动作的合成任务；作者在限制部分承认只验证约 200M 单一规模与一种 flow-matching recipe，尚未测试真实视频或现代大模型尺度（第 27 页）。
- 每个长度仅 64 episodes，未报告多训练 seed、置信区间或训练方差；0.95、0.69 等单点准确率不足以量化不同机制的统计稳定性。
- 不同架构虽约 200M，但层数、状态大小、clean/noisy packing 和训练串行性不同；LaCT 还因交错 clean/noisy copy 将有效序列长度翻倍，计算量并未严格匹配。
- 论文证明的是“在当前 pixel-only diffusion-forcing 协议下”生成 chunk 不会学成 scratchpad；full rollout BPTT、结构化状态 target、自身 rollout 训练或任务奖励均未测试，因此不能概括为所有视频训练目标都无法形成隐状态。
- Memory Maze/Block World 只用 SSIM/PSNR/LPIPS 间接判断状态，缺少真实 pose、对象位置或任务成功率等状态级指标；Block World 中 SWA10 明显超过 LaCT8+SWA1，也削弱了“递归机制是主要原因”的一般化结论。
- LaCT/scratchpad 的训练更慢且跨 chunk 串行；chunk size 的受控视频消融因不稳定和成本未完成，实际可扩展性尚不清楚。

## Future Work

作者明确提出：研究能同时融合动作和观测纠错、处理无动作自主演化的状态表示；改进视频 tokenization、stateful architecture 与超越可见内容的训练目标；在真实视频、更大模型尺度和更多 flow-matching 配方上验证；解决局部动作下物理状态恢复与长期漂移校正；探索 fast-weight inner architecture、loss、normalization、update schedule 与 chunk granularity。

我们的推断是：下一步应建立带可读 ground-truth state 的动态 3D/机器人基准，加入 full-rollout 或辅助状态监督的公平对照，按等训练 FLOPs/推理延迟比较 TTT、线性注意力与显式 belief state，并测试随机转移、多物体遮挡、观测纠错及闭环规划收益。

## Rating

创新度评分：3/5 - 将 $S_5$ 状态追踪理论系统引入视频世界模型并做出机制级实验很有洞察，但负特征值线性递归、LaCT 与 scratchpad 均为既有机制，主要创新是新基准、诊断框架和跨领域验证。
相关度评分：3/3 (Core) - 直接研究视频世界模型如何携带与更新不可见状态，是视频/隐式世界模型的核心问题。

## TL;DR

用视觉壳牌游戏揭示视频世界模型的隐藏状态失忆，并验证可原位改写状态的递归机制，值得精读。
