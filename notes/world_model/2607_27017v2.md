# What Can Latent World Models Know? Physical Parameter Identifiability in Multimodal Predictive Representations

## Insight
论文从一个常被默认、却未被验证的命题出发：预测未来是否必然迫使 latent 学到环境物理？作者先用 raw-observation estimator 证明参数确实可恢复，再检查 frozen latent 是否包含、预测是否实际使用该参数，由此把“环境不可观测”与“目标函数不愿学习”分开。

核心推论有三层。第一，input 只规定“最多能知道什么”，prediction target 才决定“最终保留什么”：touch 仅作输入时 stiffness 为随机水平，要求预测 touch 后才升至 \(R^2\approx0.50\)。第二，单步 joint-embedding prediction 可形成 lazy equilibrium——即使物体位置清晰可见且可预测，只要静态捷径足以降低损失，latent 仍可丢掉它；跨模态 target 或 direct multi-horizon head 都能打破该平衡。第三，确定性平方误差的 conditional-mean optimum 存在 blind frontier：drag 可从轨迹恢复到 \(R^2=0.89\)，但它每步效应慢、读取需时间门控和比率运算，所有 tested predictive objectives 都停在约 0.13；直接 system-ID supervision 可到 0.45。属性矩阵、loss dose-response、坐标线性化和功能预测共同支持“fast 参数可按需习得，slow 参数只保留线性 trace，slow×ratio 参数易被均值化”的经验假说，而非形式化定理。

## Motivation
JEPA/Dreamer 类方法常以“预测驱动物理理解”为动机，但现有工作多做 post-hoc probe，无法判断 probe 失败来自传感器、数据覆盖、probe capacity 还是 representation objective。机器人接触任务尤其需要 mass、stiffness、drag/friction 等隐变量，因此逐参数建立可辨识地图是关键科学问题。本文不是追求更大 benchmark 分数，而是回答预测表征能学到什么、为何学到或学不到，并给出可复用诊断协议，问题重要且直接触及隐式世界模型的基本假设。

## Method
作者构建 PokeWorld：2D force-controlled finger 与外观完全相同、每 episode 重采样 mass \(m\)、drag \(\gamma\)、contact stiffness \(k\) 的物体交互；64×64 vision、proprioception 和含 sub-step peak/mean/end force 的 7D touch 分别承载不同物理证据。behavior policy 混合追逐、撞击-撤回、自由滑行以覆盖 contact/impact/glide。

certificate-gated protocol 分三步：先用 raw observation 上的 GRU、物理 estimator 等给每个参数建立 recoverability lower bound；再对相同数据训练 X-JEPA 变体；最后用 episode-disjoint ridge/MLP probe、模型自身预测和 closed-loop MPC 区分 decodable 与 functionally used。X-JEPA 基于 LeJEPA/LeWM：frame encoder、action-conditioned causal transformer、\(\Delta\in\{1,4,16\}\) direct prediction head 与 SIGReg。factorial 逐项改变 vision/all-modality input，以及 latent、touch、proprioception target。

关键 intervention 包括：touch input vs. target、target modality 替换与组合、single- vs. multi-horizon、SIGReg 60× sweep、sensor averaging/sub-step statistics、contact-poor data、linear/nonlinear probe、latent/pixel reconstruction/Gaussian-NLL/system-ID objectives、glide loss 30× re权重、log-speed 坐标线性化，以及 RH20T 上 input×target×data-scale factorial。方法学创新强，尤其是先过 recoverability gate 再允许解释负结果。

## Experiment
PokeWorld 的 raw-observation certificate 为 mass/stiffness/drag \(R^2=0.86/0.87/0.89\)。在 single-horizon target factorial 中，vision-only 的 position 仅 0.04；touch 作 input 的 VF 对 stiffness 为 −0.02，而 touch 作 target 的 VXt 为 0.40–0.43，完整 VFX 为 0.49–0.50；proprioception target 不提升 stiffness。touch 与 proprioception target 分别只给 position 0.17/0.09，组合后为 0.58。multi-horizon vision-only 将 position 提至 0.89，与跨模态 target 组合为 0.98；direct-16 error 为 0.10，优于 autoregressive composition 的 0.19 和 static 0.21。

SIGReg 从 0.3 降到 0.005 时 stiffness \(R^2\) 从 0.12 单调升至 0.57，direct-16 error 从 0.128 降至 0.095，说明 anti-collapse 强度会牺牲低维物理流形的 metric precision。contact-poor 数据使 stiffness 0.50→0.05，验证覆盖度仍是必要条件。drag 在 linear/MLP/function test 与多种预测 intervention 下均接近盲区；system-ID head 提至 0.45，pixel reconstruction 仍仅 0.03–0.08。把输入改为 \(\Delta\log |v|=-\gamma\Delta t\) 后，drag linear certificate 变 0.52、latent readout 跟到 0.33，但真实 position forecast 未改善，进一步区分“可解码”与“被使用”。

同一 CEM-MPC 下 goal reach 从 vision-only 的 20%，升到单种 target 的 38–44% 和完整 VFX 的 57%（random 1%），说明控制收益随 state content 变化，但任务只考位置，未验证 stiffness 的控制价值。

RH20T 覆盖 KUKA 896 episodes、Flexiv 4,258 episodes。KUKA 上 VFX 相对 camera-only 将 16-step error 从 8.2 cm 降至 1.5 cm（static 3.8），contact anticipation AUC 从 0.70 升至 0.86，并保留 force；远景/近景分别偏 pose/contact，两视角取并集。Flexiv 800→4,258 episodes scaling 中，缺输入或缺 target pressure 的三条曲线基本不随规模改善；只有 VFX 的 held-out 0.4 s force forecast 从 0.39 升至 0.51且持续优于 persistence，支持“structure first, scale second”。不过真实数据无已知物性标签，只验证机制和 observable forecast，不是物理参数 identifiability 的直接复现。

## Value
这是对隐式世界模型很有价值的机制研究：它把“predictive representation 会自然学物理”的泛化口号改写为可检验条件，并提供 input、target、horizon、regularization、bandwidth、coverage 六个设计旋钮。对我们的直接启发是：评测 latent 不能只看平均 rollout error，应先做可恢复性证书，再同时检查 linear/nonlinear decodability、counterfactual prediction 和 control use；multimodal sensor 最好既输入又成为预测目标。blind frontier 还提示 Dreamer/JEPA 需要显式 episode-level belief、system-ID latent 或非 conditional-mean objective 来表示慢速隐参。

## Strengths
- 问题基础且明确，certificate gate 使负结果具有可归因性，优于普通 post-hoc probing。
- factorial、dose-response、坐标变换、objective control 和功能测试形成较完整因果证据链。
- 明确区分 recoverable、decodable、functionally used，避免把 probe 分数直接当“理解”。
- 同时发现正机制、lazy equilibrium 和 blind frontier，不只汇报提升。
- toy environment 物理量可控，RH20T 又验证了 target pressure、fusion、viewpoint 和 scaling 机制。
- 多个结果可转化为具体设计规则，且模型小、实验协议可复现。

## Weaknesses
- “blind region”只适用于约 5M 参数、短 history 的确定性 latent/pixel point-prediction family，不能外推到大规模视频模型、Dreamer stochastic state 或 generative density objective。
- certificate 是构造 estimator 的经验下界，不是经典 structural identifiability；不同 probe/坐标仍可能改变结论。
- conditional-mean collapse 是与证据一致的解释而非严格证明，关键替代方案如 episode latent、belief state、contrastive system-ID objective 尚未实验。
- PokeWorld 为简化 2D、单物体、已知动作和人工激励策略，物理复杂度与真实接触差距较大。
- RH20T 没有 ground-truth mass/stiffness/drag，且 10 Hz 本身删除 stiffness transient，因此只能验证 observables 和机制迁移。
- control task只要求位置，无法证明更高 stiffness/mass readout 能改善 contact-rich control 或安全性。
- 许多 readout 使用 linear probe；虽有 MLP 和功能测试补充，但 representation 可通过更复杂 downstream inference 利用多少仍未知。

## Future Work
作者明确提出以 episode-level latent variable、belief state 等非 conditional-mean optimum 的目标检验 blind-region 假说；在含已知、变化物性的真机数据上直接验证参数 identifiability；并扩展到更大模型。自然延伸还包括 force-limited/contact-rich planning、主动信息采集、显式 uncertainty posterior，以及为 friction、viscosity、damping 逐一设计 parameter–sensor certificate 与适配坐标。

## Rating
创新度评分：4/5 - certificate-gated identifiability map、严格 intervention 与 blind-frontier 机制构成显著方法学贡献；但结论仍是受限模型族上的经验假说，尚未建立新训练范式。

相关度评分：3/3 (Core) - 直接研究 JEPA 式 action-conditioned latent world model 的物理表征、目标设计、规划价值与失败边界，是隐式世界模型核心问题。

## TL;DR
用可恢复性证书揭示 JEPA 物理表征由预测目标而非输入决定，并定位慢速隐参盲区，值得精读。
