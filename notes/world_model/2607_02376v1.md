# Hardware-Enforced Semantic Coordination for Safety-Critical Real-Time Autonomous Systems

## Insight
论文的 insight 是把多智能体安全协调中的“语义约束”下沉到 FPGA/硬件层，而不是完全交给软件调度。Observation 是安全关键实时系统中，软件层 LLM/agent planning 的语义决策可能延迟、漂移或被绕过；作者据此提出用 token/Petri-net 风格机制在硬件中强制同步、授权和时序门控。

## Motivation
论文解决安全关键 autonomous systems 的实时语义协调问题。同行多在软件中做 mission planning、formal verification 或 runtime monitor；作者认为这些机制缺少确定性硬件约束。这个问题和机器人/agent 安全相关，但不是视频世界模型、3D 世界模型或 JEPA/Dreamer 式隐式世界模型问题。

## Method
方法是概念架构：上层软件做语义推理，中间 FPGA semantic coordination layer 执行 TB-CSPN token/Petri-net 语义，底层 physical safety layer 负责硬件保护。语义 token 包含 topic、agent id、confidence、timestamp、TTL、priority 等字段；硬件层实现同步、temporal gates、authorization barriers、公平性和 bounded mission release。论文没有给出可复现原型。

## Experiment
没有真实 FPGA implementation、synthesis result、latency/power 表或系统 benchmark。文中主要通过无人机群、防务、应急管理、农业和能源等场景说明潜在用途，属于设计论证而非实验验证。

## Value
对当前研究方向价值很低。唯一可借鉴点是“语义约束应有可执行的低层 guard”，但它没有处理视觉预测、3D 几何、latent dynamics 或 world model rollout。

## Strengths
问题意识明确，强调安全关键系统中语义协调的硬实时约束；token 字段和分层架构给出了一定工程想象空间。

## Weaknesses
缺少实现和实验，论证停留在概念层；没有证明 FPGA 映射可行性、资源开销或时序收益；与现代 world model 的训练、推理、规划接口关系很弱。

## Future Work
作者提出未来需要形式化规格、FPGA realization、verification/evaluation，以及自适应 mission-level reconfiguration、token compactification、公平性和动态重配置等。

## Rating
创新度评分：1/5 - 当前更像概念提案，缺少实证和关键技术细节。
相关度评分：0/3 (Noise) - 不研究视频/3D/隐式 world model，基本无关。

## TL;DR
硬件语义协调的概念架构，缺少 world model 内容和实验支撑，可跳过。
