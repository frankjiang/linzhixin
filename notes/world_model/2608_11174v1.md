# VIScore: Diagnosing Planning-Relevant Quality in Latent World Models

## Insight
仅检查 latent 是否“好看”不足以预测规划：成功还要求预测滚动误差落在任务容差内、动作对未来有足够但无需无限大的影响，并且搜索器不会利用模型局部幻觉。由此作者提出 Veracity、Influence、Sobriety 三个必要条件的乘积，并用与训练 run 隔离的 checkpoint、方法、任务和规划器验证其与成功率的联系。

## Motivation
JEPA 类 latent 世界模型常用防坍缩正则、线性探针、轨迹直线性或 empowerment 评价表征，但这些量忽略真正执行规划的 predictor 与 planner，低预测损失也不必然带来高控制成功率。诊断训练 checkpoint、减少昂贵闭环评估是直接且重要的问题。

## Method
论文先将 LeWorldModel 的 SIGReg 替换为可分解 center/scale/shape 的 VISReg，分析同一高斯目标下正则性质对规划的影响。核心 VIScore 为三项乘积：Veracity 用任务成功容差与 $H$ 步 rollout 误差之比衡量可达真实性；Influence 将局部线性高斯 empowerment 截断在共享阈值 $\tau=82$，把容量视为满足即可的条件；Sobriety 在 64 个专家锚点上用小型搜索寻找“比真实专家动作更优”的想象动作，以其未被搜索利用的比例刻画幻觉。该分数是诊断量而非成功率回归器。

## Experiment
VISReg/SIGReg 部分在 PushT、Reacher、OGBench-Cube、Two-Room 上测试短程、长程和 OOD 形状；VIS-WM 短程表现有竞争力，但 fresh-seed 后优势缩小，权重可调并未稳定改善规划，较大 batch 的更精确分布匹配有利 OOD。VIScore 在按训练 run 划分的开发/留出池上，与 straightness、物理状态线性探针、原始 empowerment 比较 Spearman 相关及跨任务校准误差：留出 checkpoint 达 pooled $\rho=0.91$、误差 7.0（常数基线 18.2）；留出方法为 0.75/8.3，未见 MAZE 任务为 0.87/11.5。因子消融表明没有单项在所有迁移下占优；六类规划器实验显示 18 个 planner-task 单元内相关均为正，但弱且任务选择性失效的 predictive sampling、single-start gradient 跨任务校准明显下降。

## Value
工作把 latent 质量评价从 encoder 推进到 encoder-predictor-planner 整条链，且明确诊断轴的物理含义，对 JEPA 世界模型的模型选择和失败定位很有参考价值。其更重要的提醒是：单 seed、同环境短程基准会掩盖诊断失真，OOD、长程和多 seed 应成为标准配置。VIScore 尚不能替代闭环评估，也不能覆盖离散模式与 amortized policy。

## Strengths
- 诊断分解对应三种不同失败：不可达、不可控和搜索利用幻觉，解释性强。
- run-level 隔离、cluster bootstrap、留出方法/任务及多规划器验证较严谨。
- 与强基线比较并主动报告 Cube 反例、阈值饱和和跨规划器失效边界。
- 计算约 7 秒/checkpoint，较 50 回合规划评估便宜至少 20 倍。

## Weaknesses
- 三项相乘及 erf/共享阈值仍带较强启发式色彩；成功率相关性不能证明三项是因果必要条件。
- Sobriety 依赖专家锚点与一个小型搜索器，诊断成本和含义随 action label、planner family 改变。
- OGBench-Cube 的抓取离散状态未被任何因子覆盖，且 Influence 在容量饱和任务上失去分辨率。
- 留出方法仅 23 个 checkpoint、未见任务仅两次训练，跨架构和大规模视频 JEPA 的外部效度仍有限。
- 不适用于不显式调用 predictor 的 amortized planner，也未处理多任务规划。

## Future Work
作者指出需建立 IDM/amortized planning 的诊断工具，推进多任务规划、无动作标签训练，并采用更复杂数据集及强制 OOD、长程、多 seed 评估。还可扩展离散模式条件因子并减少对专家动作的依赖。

## Rating
创新度评分：3/5 - 提出有解释力且验证充分的新诊断框架，但组合形式偏启发式、适用边界较窄，尚未形成通用评价范式。
相关度评分：3/3 (Core) - 直接面向 JEPA/latent 世界模型的规划质量诊断与评估。

## TL;DR
VIScore 联合真实性、影响力与抗幻觉性诊断 latent 世界模型，验证扎实但边界明显，值得精读。
