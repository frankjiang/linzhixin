# Validate the Dream Before You Trust Its Verdict: Admissibility for World-Model Simulators

## Insight
核心 insight 是“世界模型作为测试 oracle 时，首先要被认证”。Observation：视频世界模型的 FVD/视觉真实度只评估 marginal visual fidelity，不能保证模型会正确响应被测 policy 的动作；而闭环评测恰恰把世界模型的 verdict 当成真实证据。推论是应把 generative WM 从“被默认信任的 simulator”改成“待验证 artifact”，并建立 L0-L4 admissibility ladder。论文用 Vista/Epona 的反例说明：视觉质量排名和 action-robustness 排名可以反转。

## Motivation
机器人和自动驾驶越来越用 generative world model 作为 closed-loop simulator 来评估策略是否成功或安全。但传统仿真认证默认 simulator 可被工程验证，而 generative WM 本身是学习出来的、缺乏物理 ground truth 的模型。若不先验证 WM 的 action-conditioned fidelity，它给出的安全/成功 verdict 不能作为 assurance evidence。这个问题对视频世界模型评估非常关键，尤其是面向机器人/自动驾驶的“世界模型即环境”路线。

## Method
论文主要贡献是框架而非新模型。它从 VV&A、SOTIF、scenario-based testing 中抽象出两个原则：fidelity sufficiency 和 explicit operating envelope，然后定义五级可采信性：

- L0 Generation quality：视频看起来合理，只证明能生成，不支持 verdict。
- L1 Action-robust：不同动作导致系统性不同 rollout，证明模型不是忽略动作。
- L2 Envelope-declared：声明训练/适用 envelope 和有效 rollout horizon，能检测并拒绝 OOD。
- L3 Failure-attributable：能区分 failure 来自 simulator 还是被测 policy。
- L4 Verdict-transfer-validated：在 envelope 内 sim verdict 与真实结果相关，可作为证据。

作者把 action-coverage gap 形式化为 off-policy evaluation 问题：训练日志里的 behavior policy 覆盖不了被测 target policy 会查询的动作，因此 WM 对 target action 的估计可能是无证据外推。

## Experiment
附录把 lower rungs 应用于两个自动驾驶生成式 WM：Vista 和 Epona，在 nuScenes/ACT-Bench 设定下评估。

L0 指标包括 FVD、CD-FVD、FTD；Vista 的 FVD 151.3、CD-FVD 51.6 优于 Epona 的 159.4、86.1，但 Epona FTD 略好。L1 用 ACT-Estimator 衡量 instruction-execution consistency、ADE、DTW、success；Epona IEC 0.54、ADE 2.35m、success 0.28，优于 Vista 的 0.33、4.56m、0.08。L2 horizon 用 ADE(h) <= 1.8m 的持续时间衡量，Vista h*=1.6s，Epona h*=3.2s。结论是视觉质量不能预测动作跟随能力，世界模型作为 closed-loop oracle 需要分层证据。

## Value
这篇对模型设计贡献不大，但对评估范式有价值。它提醒我们：如果用视频/3D 世界模型评测 agent 或 policy，不能只报告视频质量和短时可控性，必须报告动作覆盖、OOD envelope、rollout horizon、failure attribution 和 sim-real transfer。对世界模型 benchmark 设计非常值得借鉴。

## Strengths
- 明确指出“trusted simulator”到“unverified learned simulator”的信任倒置。
- L0-L4 ladder 简洁，能把视觉指标、动作响应、适用范围和真实迁移分开。
- 用 Vista/Epona 展示视觉质量与 action robustness 可反转，论点有实证支撑。
- 与安全关键仿真认证体系连接紧密，适合指导自动驾驶/机器人 WM 评测。

## Weaknesses
- 主要是概念框架，L2 的 OOD 检测、L3 failure attribution、L4 sim-real correlation 没有完整实现。
- 实证只有两个自动驾驶 WM，且模型、训练数据、接口不完全对称。
- 下层指标依赖 ACT-Estimator，估计器本身有误差和类别边界问题。
- 不是模型训练方法，不能直接提升世界模型能力。

## Future Work
作者提出三个方向：检验 L0-L4 是否充分、互斥且顺序合理；发展跨 embodiment 的 L2 envelope/OOD 检测协议；收集真实 failure 数据并建立 attribution protocol，使 L3/L4 可操作。

创新度评分：3/5 - 提出了有用的评估/认证框架，并有小规模实证反例；不是模型技术突破。
