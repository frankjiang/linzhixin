# ABot-M0.5: Unified Mobility-and-Manipulation World Action Model

## Insight
ABot-M0.5 的 insight 是：移动操作需要同时解决时间粒度、动作空间和训练/推理一致性三种对齐问题。intermediate latent action 可以桥接视频 latent 的局部状态变化和真实控制动作，使 mobility 与 manipulation 在统一 WAM 中对齐。

## Motivation
现有 VLA/WAM 多聚焦固定机械臂或短程操作，移动操作要求底盘和机械臂协同，动作空间异构且 horizon 更长。简单拼接 base action 和 arm action 会让模型难以学习统一动力学。

## Method
模型基于 Wan2.2 类视频 diffusion backbone，构建 generation cascade：未来视频 latent `z_{t+1}`、latent action `m_t`、可执行动作 `a_t`。Dual-level MoT 同时分离多模态表示和异构动作子空间。Dream-forcing 用模型自生成视频/latent 训练 inverse dynamics，以减轻训练时真实视频和推理时自回归想象之间的 mismatch。

## Experiment
论文在 RoboCasa365 等移动操作任务上评估，并与 Diffusion Policy、pi0、pi0.5、GR00T-N1.5 等基线比较。结果显示 ABot-M0.5 在整体成功率上明显领先，增强 memory 后进一步提升。消融表明 latent action、dream forcing 和 MoT 都是关键组件。

## Value
这是机器人 WAM 里比较重要的统一 mobility-manipulation 尝试。对我们最有价值的是 latent action 和 dream-forcing：它们分别处理异构动作对齐和 rollout 分布偏移。

## Strengths
问题难度高；方法针对移动操作的核心对齐问题；把视频世界模型和 action model 结合得较紧。

## Weaknesses
系统复杂，训练稳定性和数据需求较高；细粒度失败分析仍不足；真实长期开放任务能力还需更多验证。

## Future Work
作者提到未来要加强 memory 机制，并扩展更长时、更开放的移动操作场景。

## Rating
创新度评分：4/5 - latent action、dual-level MoT 和 dream-forcing 组合对移动操作 WAM 有明显贡献。
相关度评分：3/3 (Core) - 直接属于机器人世界动作模型。
