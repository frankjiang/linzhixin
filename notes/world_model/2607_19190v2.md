# Agentic Real2Sim: Physics-based World Modeling with Vision-Language Agents

## Insight
核心 insight 是 real2sim 的基本单位不应只是静态资产或场景，而应是可重放的 physical interaction episode twin：包含观察、机器人/物体、几何、状态轨迹、物理参数、相机和评估痕迹。VLM agent 不直接“做物理”，而是在分割、深度、pose tracking、MuJoCo grasp sweep 等确定性工具之间做有边界的决策和修复。

## Motivation
机器人真实交互数据很难直接用于仿真，因为还需要恢复 object state、geometry、物理参数、坐标系、相机、机器人初始状态和轨迹。现有 Real2Sim 多关注单独物体、静态场景或特定 pipeline；VLM scene-generation agent 又往往缺少 episode-level physical replay。本文试图用 agentic workflow 把真实机器人交互录像转换成可执行仿真 twin，为后续 policy learning/evaluation 提供物理 world modeling 资产。

## Method
Agentic Real2Sim 定义 episode twin T=(O,A,G,S_{1:T},Theta,B,M)。DROID 刚体 manipulation 流程分四段：visual processing agent 从视频中做对象发现、关键帧选择、SAM 3 segmentation、SAM 3D mesh recovery、FoundationStereo depth、FoundationPose 6D pose tracking，并用 critic 触发有限重试；physical-prior inference agent 推断 object identity、material class、mass hints；scene preparation agent 对齐相机、地面、机器人 base pose 和物体 pose，加载 MuJoCo；simulator-in-the-loop grasp optimization 做 object shift sweep 或 LLM-assisted refinement，挑选能成功抓取/移动的配置。PhysTwin-style deformable 和 BFM-Zero-style humanoid 作为适配器复用 episode contract，但替换状态变量和 simulator feedback。

## Experiment
刚体部分在 DROID-100 上评测 replay success。评价器选 real/sim start/middle/end keyframes，对候选 replay 用三个 VLM judge 评分，8/10 以上算成功，7 算 partial。Gemma 4 31B backend 得到 48 成功、8 partial、44 失败，总模型费用 $2.62；Qwen 3.6 35B、GPT-5.4、Claude Haiku 4.5 分别为 45/43/37 成功，但 GPT 成本约为 Gemma 的 31.4 倍。作者认为 VLM 只做 schema-constrained decisions，因此 open 31B backend 足够。deformable 和 humanoid 只给 qualitative stress tests，展示 PhysTwin-style 变形叠加和 Unitree G1 motion retargeting。

## Value
对 3D/物理世界模型方向直接相关：它强调从真实视频构建可执行仿真 world，而不是只追求重建视觉外观。对我们有启发的是 agentic real2sim 可以作为数据放大、离线策略评测和世界模型监督的上游管线；同时也暴露了物理 episode conversion 目前仍主要受 perception、pose tracking 和 simulator feedback 限制。

## Strengths
episode contract 抽象清楚，能覆盖刚体、可变形和 humanoid 三类场景；VLM 与确定性工具解耦，便于替换 backend 和定位成本；DROID-100 规模虽不大但比单例 demo 更有说服力；成本分析说明 open-weight VLM 在有边界决策中可行。

## Weaknesses
绝对 replay success 不到 50%，说明离“可规模化自动转换”还远。评价依赖 VLM judge，仍可能把视觉相似与物理可用性混合。deformable/humanoid 只是定性结果，没有系统成功率。没有真正展示转换出的 twins 能提升 policy learning 或 evaluation。pipeline 依赖 SAM/FoundationPose/MuJoCo/grasp sweep，多处误差会级联。

## Future Work
作者提出未来扩展自动转换到 deformable episodes，系统评估 agentic components 和 VLM backend 的可靠性/replay stability，并将生成的 twins 用于机器人 policy learning 和 evaluation。

## Rating
创新度评分：3/5 - episode-level agentic Real2Sim 集成有价值，但主要是现有感知/仿真工具的工程化编排，成功率仍有限。
相关度评分：3/3 (Core) - 直接研究 3D/物理 world modeling 和机器人 real2sim episode twin。
