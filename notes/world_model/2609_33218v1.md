# Scope-WM: Scoped Computation for Efficient Visual World Models

## Insight
观察：稀疏世界模型的计算瓶颈同时来自视觉 token 传播和 MPC 大量候选滚动；被跳过的背景 token 也会随前景动作而变化。推论：应把计算分别分配给预测相关 token、廉价背景更新和早期优质动作搜索。Push-T 32-token 消融显示只选 token 并复制背景成功率 **56%**，加入前景条件背景更新升至 **88%**；说明选择与更新必须共同设计。

## Motivation
DINO-WM 等 patch 潜状态模型在 CEM 规划中反复传播全部 token，推理时间与显存大。已有随机稀疏法可能丢掉决策相关位置，复杂定位器又增加训练与推理成本。该问题直接关系到视觉世界模型的在线控制。

## Method
先用稠密教师的预测损失对输入 token 求梯度×输入重要度，蒸馏成轻量、动作条件的 Top-K 选择器。仅对选中 token 运行主要 Transformer 动力学；未选 token 用前景预测状态及位移的池化摘要，经逐 token 门控残差更新，全网格潜状态仍接受预测监督。规划端采用 Elite-Bank CEM：首轮 300 条候选，后续每轮 100 条，持续复用初始高分轨迹。训练需一次选择器蒸馏，再联合训练稀疏预测器与背景更新器。

## Experiment
五项视觉规划任务，指标为成功率或 Chamfer 距离、FLOPs、累积规划时间、峰值显存。Push-T 中稠密 DINO-WM 为 **90% / 240.96 秒 / 18,436 MB**；98-token 版为 **94% / 93.06 秒 / 7,088 MB**，32-token 版为 **88% / 34.56 秒 / 3,334 MB**（6.97×）。32-token 下去选择器成功率 76%，去背景更新 56%，去 Elite-Bank CEM 82%。但 Rope 的 Chamfer **0.71–0.87**，明显差于稠密的 **0.41**；Wall 的峰值显存反而为稠密版的 125.8%。附录证实 98 与 32 token 需分别训练，训练后切换 K 会把 Push-T 成功率降至 14% 或 54%。

## Value
对规划型隐式视觉世界模型的计算预算设计很实用，尤其是选择 token 后不能静止背景、以及降低单轨迹成本后仍需重新分配搜索预算。需按任务机制检验稀疏化对柔性物体的损害。

## Strengths
统一比较相同底座、目标与规划约束；模块交互消融明确，报告时间和显存而非只报 FLOPs；揭示固定 token 预算与训练耦合。

## Weaknesses
显著收益主要在 Push-T 等刚体任务，绳索表现退化；Elite-Bank CEM 对稠密模型反而降低成功率且增加耗时。不同预算不能测试时自由切换，需要重训；峰值显存不总下降。未提供真实机器人闭环延迟与效果。

## Future Work
作者未给出具体后续方案；开放问题是适应不同任务的动态 token 预算、柔性物体表征与实际部署验证。

## Rating
创新度评分：3/5 - 把教师蒸馏选区、轻量背景传播与 CEM 预算重配组合得较有效，但核心部件以工程整合为主。
相关度评分：3/3 (Core) - 直接研究视觉潜空间世界模型及其 MPC 推理效率。

## TL;DR
稀疏预测关键视觉 token、轻量更新背景并重配 MPC 搜索，显著加速刚体规划；视觉世界模型值得精读。
