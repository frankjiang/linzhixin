# WAM-RL: World-Action Model Reinforcement Learning with Reconstruction Rewards and Online Video SFT

## Insight
关键 insight：World-Action model 的能力瓶颈不只在 actor，长时程任务里 actor-only RL 受限于 world model 预测误差；世界模型和动作模型必须在线共同适配。实验观察支持：actor-only 在短任务有提升，但长任务收益不明显，加入 world model video SFT 后出现失败恢复行为。

## Motivation
现有 WA/VLA 多依赖专家轨迹监督，难以通过真实交互持续改进。机器人 manipulation 中，示范分布之外的细粒度控制和失败恢复很重要。同行 RL VLA 主要优化 policy/action head，较少更新 world model。问题相关但范围偏机器人策略后训练。

## Method
WAM-RL 将 WA model 分为 world model 和 actor。world model 用在线成功轨迹做 video self-supervised fine-tuning，并加 KL regularization 稳定 latent 分布；actor 用 reconstruction-based reward 做 RL，奖励比较 imagined outcome 与 executed outcome 的一致性。重建相似度尝试 Pixel MSE、Optical Flow MSE、DINO、V-JEPA2 等。

创新是把 world model 在线 SFT 和 actor RL 协同起来，工程上较直接。

## Experiment
LIBERO-Object 从 Base 68% 提到 WAM-RL 82%，actor-only πRL 为 78%。RLBench Water Plants 从 Base 19% 到 22%，πRL 为 18%。奖励消融中 Pixel MSE 21% 最好，Optical Flow 虽区分成功/失败更强但不提升成功率；DINO/V-JEPA2 更低。定性展示 video SFT 后模型在失败抓取后会预测 reposition/retry。

## Value
启发在于世界模型不能只作为冻结 imagination module，在线交互中应让 dynamics representation 适配失败/恢复分布。对用户方向属于隐式/机器人 world-action model 的相关工作，但不直接推进视频/3D世界模型表示本身，实验规模也较小。

## Strengths
亮点是启发在于世界模型不能只作为冻结 imagination module，在线交互中应让 dynamics representation 适配失败/恢复分布。

## Weaknesses
