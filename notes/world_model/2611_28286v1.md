# Scalable Beckmann Maps Improve One-step Generation

## Insight
Beckmann 端点映射的概率流可写成自治去噪方向的正倍数，从而可在训练时把条件与无条件预测之差用于引导，而采样仍只调用一次网络。作者在理想总体目标下证明与引导后的守恒方程相容，并用双模态例子解释引导如何移动吸引域边界；实际用映射自身替代真去噪器会产生偏差。

## Motivation
多步扩散生成质量高但视频世界模型逐帧推演成本重；既有单步模型常需蒸馏或外部特征损失。原 Beckmann 模型单步直接训练但质量及条件控制不足。

## Method
在直接学习噪声到数据端点映射的 BTM 目标上，提出训练期条件/空条件映射校正、损失归一化和可扩展训练配方。图像生成使用 CFG 式引导；机器人视频世界模型部分**不使用引导**，只移植训练配方：给定四帧和动作，单次网络调用预测下一帧，逐帧自回归。

## Experiment
ImageNet 256² 单步 FID 1.61，文生图 GenEval 0.856；与本文方向直接相关的是 Bridge-V2 与 RT-1 的动作条件视频预测。Bridge-V2 相比 DriftWorld：PSNR 22.69→24.80、LPIPS 0.091→0.060、FVD 46.05→18.1，训练计算约减半；RT-1 短训 FVD 62.8→28.3。指标含 SSIM、PSNR、LPIPS、FID、FVD；消融显示图像生成中引导是主要增益源。

## Value
单步端点映射有望降低视频世界模型每步采样开销，适合研究实时交互生成；视频改善来自训练配方，不能归因于新引导公式。

## Strengths
有明确的理论边界和跨图像、文本、动作条件视频的实证；视频比较报告计算量与多个质量指标。

## Weaknesses
最强图像结果依赖预训练表征自编码器；世界模型每 8 帧重置真实历史，长滚动仅定性展示，未测试下游控制；单次训练运行限制稳定性判断。

## Future Work
作者提出研究其他插值/耦合、端点映射选择机制、奖励或物理约束引导，以及跨帧耦合以支持长时滚动。

## Rating
创新度评分：3/5 - 单步映射的引导理论较新，但视频世界模型增益主要来自训练配方而非核心引导方法。
相关度评分：2/3 (Related) - 在机器人动作条件视频预测上直接验证，可借鉴高效生成方案。

## TL;DR
提出单步 Beckmann 映射的训练期引导，未引导的视频版本也改进逐帧预测；重视效率者值得精读。
