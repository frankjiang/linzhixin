# Alaya-EVOKE: From Linear-Scaling Supervision to Endless World

## Insight

论文把“长时世界一致性”拆成两个机制不同的问题：未观测内容如何随时间合理演化，应由更长监督窗口约束；已经看过的空间在重访时如何恢复，则应从相机位姿寻址的外部几何记忆直接取回，延长 denoiser 历史并不能替代缺失观察。第二个关键观察是，部署端的三步 student 不可能获得 teacher 从未表达过的长时/动态条件能力，因此 distillation teacher 本身也必须按长时交互目标重构。匹配实验只证明长 teacher 显著改善曝光等光度漂移，未显著改善内容 descriptor；作者据此谨慎把证据限定在光度稳定性，而未宣称全面解决长期身份一致性。

## Motivation

交互视频世界模型需要同时具备持久记忆、提示/相机即时响应和低延迟长生成，但把所有历史帧或 KV cache 留在 denoiser 中会让每步成本随会话增长；简单滑窗/淘汰又丢失重访信息。少步生成通常靠慢 teacher 蒸馏，而短片段、固定 prompt、双向二次注意力的 teacher 无法监督长期内容漂移和会话中途事件。这个“状态容量、监督跨度和推理延迟”的三方冲突是开放世界视频模型的核心问题。

## Method

Evoke 将会话建模为固定形状的递归生成：每步产生 9 个 latent 帧（36 像素帧、1.5 秒），条件为约 3.2 秒局部历史、当前相机轨迹、分段文本提示，以及由外部 world state bank 渲染的视角对齐记忆。

- Teacher 基于 Wan2.2 A14B 14B DiT，把长序列切为 9-latent-frame chunk；每个 query 只看首帧 sink、重叠局部块、压缩近帧、少量重要远帧和 linear-attention 全局状态，使注意力随时长近线性增长。每个 chunk 有独立文本条件。
- Student 先做相机控制和少步蒸馏，再从 long teacher 做 self-forced full-window DMD：1 个真值前缀后递归生成 20 chunk，共约 31.4 秒/189 latent 帧；teacher/critic 联合评分全窗口，但 chunk 间停止梯度，使“监督跨度长、反传跨度短”。另保留 warp 监督以稳定相机控制。
- World state bank 对每个生成块抽取 12 帧单目深度并按已知相机反投影，按共视性选至多 8 个源视图、z-buffer 渲染；可见性低于 0.5 的区域不提供视觉条件，并裁掉不支持的 token。小时实验只保留 90 秒几何、至多 720 源帧，因而每步存储与计算有界。
- 推理采用 12×20、24×40、48×80 三层 latent 金字塔，每层一次、无 CFG；几何条件只注入最粗层。局部位置索引每个 chunk 重用，避免会话越长越超出训练位置范围。

## Experiment

- WBench navigation 158 例上，Evoke 的 Quality/Setting/Consistency/Physical 组均值为 82.79/83.76/86.87/72.06，公开榜五组平均 80.8，比第二名 80.7 仅高 0.1；Navigation 78.63 和 Perspective 69.74 并非最佳。
- 三步无 CFG 的 Evoke 在 VBench-2.0 得 66.77（所列 top-10 第一）和 VBench-Long 85.11（第七）。但比较未对齐采样步数，且分别存在单样本、短视频、分辨率和 prompt augmentation 等协议偏离；作者明确提醒 0.05–0.1 的榜单差距不可过度解读。
- 长会话测试为 8 条连续 65.5 分钟 rollout，每条 2,619 chunk、94,281 帧，另展示 7 条两小时轨迹。光度统计在初始过渡后稳定，内容相似度下降后趋缓且与真实长视频去相关相近；这只支持“无失控漂移”，不证明永久保持初始场景。
- 匹配短/长 teacher 的 8 个 clip 中，长 teacher 使 7 个光度漂移改善（Wilcoxon p=0.016），短 teacher 最终亮度约为开头 74%，长 teacher 为 101%；内容 descriptor、sharpness 和继续训练 checkpoint 未显著改善。13 种扰动及 5,749 步日志也表明收益不能简化为单一评分窗口阈值。
- 几何重访中，保留窗口覆盖离开时长后，21 个比较有 20 个出现预期跃迁，PSNR 提升 2.3–3.2 dB，但平台仅 15.4–17.8 dB，属于可辨认而非像素级回忆。
- 48 个定时提示日程中，未被几何锚定的新内容实现率 67%（上限 83%），试图覆盖已锚定内容时仅 4%（上限 17%），显示文本可塑性与几何持久性存在明确冲突。
- 单 H200、384×640 下 denoising 每 1.5 秒 chunk 为 2.11 秒；完整路径约 4.01 秒。几何路径增加 1.84 秒，约为无几何完整步成本的 93%，因此尚非实时。

## Value

这项工作最有价值之处是把长时能力的三个容量放在正确位置：短时生成留给固定上下文 student，已观察空间交给显式几何库，长时分布行为交给专门 teacher。对视频/3D 世界模型而言，它给出“有界递归 + 外部可寻址状态 + 长监督/短反传”的清晰系统范式，并用较克制的实验区分了无失控漂移、几何回忆和内容身份一致性。待解决问题包括动态对象状态、细粒度身份、单目几何误差和真正实时运行。

## Strengths

- 问题分解合理，明确区分时间演化与空间重访，不把更长上下文当万能解。
- Teacher、distillation、外部几何和推理预算形成闭环设计；每步上下文、位置范围和状态容量均有明确上界。
- 既有小时级压力测试，也有短/长 teacher 配对、保留窗口跃迁、锚定/未锚定提示等机制消融。
- 对证据边界表述谨慎：主动承认内容指标无显著改善、PSNR 仅可辨认、榜单协议不完全一致。
- 三步无 CFG 仍有较强公开基准成绩，工程效率和长时稳定性结合得好。

## Weaknesses

- “Endless World”容易误导：world state bank 仅保留最近 90 秒，早期地点会被淘汰；小时级指标主要证明光度和计算不发散，不证明全局世界长期不忘。
- 几何库以逐 chunk 单目深度独立写入、避免跨块融合，无法建立统一尺度的完整 3D 地图；重访 PSNR 15.4–17.8 dB 说明细节和身份保持仍弱。
- 当前 memory 基本是静态表面缓存，不表达对象轨迹、交互、遮挡关系和隐藏状态更新；动态世界可能把旧几何错误钉死。
- 长 teacher 的因果证据局限于 8 个 clip 的光度稳定性，内容 descriptor 无显著差异；“30 秒足以支撑小时级内容稳定”的机制仍未被证明。
- 定时事件只有 48 个 schedule，且锚定内容几乎不可改写，显示两条控制路径尚无冲突解析或状态版本机制。
- 完整生成 1.5 秒需约 4.01 秒，几何本身增加 1.84 秒；论文摘要强调的 2.11 秒只是 diffusion wall clock。
- 训练使用 Sekai 加未公开内部视频，14B teacher、48 GPU 蒸馏代价高；数据、训练预算和最终模型的完全复现受到限制。

## Future Work

作者明确提出用对象级或语义状态增强细粒度身份一致性，令 world state 表达并持续更新对象运动和状态转移，而非只保存静态几何；还需通过高压缩 VAE、更高效少步生成器和低成本几何条件实现真正实时。进一步可研究带置信度和版本的 4D 场景状态、动态/静态分层记忆、冲突写入与淘汰策略，以及对长时任务成功而非仅视频统计的评估。

## Rating

创新度评分：4/5 - 将有界递归、相机寻址几何记忆和长时 teacher 蒸馏系统化结合，机制设计与长时验证均较强，但各组件有明确先例且尚未解决动态持久世界。
相关度评分：3/3 (Core) - 直接研究交互视频世界模型、外部 3D 状态、长时生成与少步蒸馏。

## TL;DR

以外部几何记忆和长时教师蒸馏实现有界长生成，证据扎实但非真正永不遗忘，值得精读。
