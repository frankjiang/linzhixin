# Qwen-RobotWorld Technical Report: Unifying Embodied World Modeling through Language-Conditioned Video Generation

## Insight
论文的核心判断是自然语言可作为跨 embodiment、跨场景的统一 action interface：低层关节/waypoint 异构，但任务意图、动作过程和物理反馈可用语言统一表达，从而把 manipulation、driving、navigation、人到机器人迁移放进同一 video world model。

## Motivation
通用视频模型有视觉 prior 但 embodied physics 弱；专用机器人/驾驶模型依赖结构化动作，跨平台差。Qwen-RobotWorld 试图用 language-conditioned video generation 统一 synthetic data、policy evaluation、planning signals。

## Method
架构是 Double-Stream MMDiT：冻结 Qwen2.5-VL 作为 action/semantic encoder，视频 VAE latent 作为状态，60 层双流 diffusion transformer 在每层 joint attention 融合；用 3D RoPE 编时空位置。数据是 EWK：约 8.6M video-text pairs、200M+ frames，覆盖 20+ robot embodiments、500+ actions、manipulation/driving/navigation/human-to-robot。训练分 general pretraining 与 embodied SFT，后者 70% embodied/30% general，逐步加入单视角、多视角、复杂任务和跨域数据；Scene2Robot 用 scene condition + robot reference + generation 三段条件做人到机器人视频合成。

## Experiment
EWMBench Overall 4.60 第一，SceneC 0.914、HSD 0.566、nDTW 0.671；DreamGen Bench Total 4.952 第一；PBench Overall 0.804，开源第一；WorldModelBench Total 8.99，开源第一/总第三，physics adherence 4.94。定性展示细粒度语言 grounding、多 embodiment、多视角一致性、RoboTwin-IF zero-shot、人到机器人迁移、驾驶和室内导航。

## Value
高相关，但更像大规模系统/数据/训练报告，而非单一算法突破。启发是 language action mapping 与层级 caption 对跨 embodiment world model 可能很关键；多视角通过拼接训练而非显式几何，和 PAIWorld 形成对照。局限是许多结果依赖 VLM-as-judge、数据/算力不可复现，真实闭环机器人收益展示少。
