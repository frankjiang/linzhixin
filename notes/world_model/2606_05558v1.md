# Autoregressive Diffusion World Models for Off-Policy Evaluation of LLM Agents

## Insight
核心 observation：现有基于扩散的 OPE（Off-Policy Evaluation）方法假设 states 和 actions 都是连续向量，可以在单次联合扩散中生成完整轨迹。但 LLM agent 场景下 actions 是离散文本（由 LLM 在观察环境后采样），无法参与连续扩散过程，且存在 step-by-step 因果依赖（必须先生成 observation 再采样 action）。

推论：可以将全局 policy-guided 轨迹法则精确分解为一系列 single-step conditionals（Theorem 1），每个条件分布是三个因子的乘积：prior（无条件环境转移）、action-posterior（当前 action 一致性）、policy continuation（与评估策略的长期兼容性）。这三个因子恰好对应 guided diffusion 中的三个 score term，可以逐步自回归地运行。

证明：ADWM 在 6 个 (pi_b, pi_e) 配置上是唯一一个 Spearman rho 全部为正的估计器（mean +0.82），而所有经典 OPE baseline 至少在 3 个 cell 上失败。

## Motivation
- **解决什么问题**：LLM agent 的离线评估（OPE）——不执行 LLM agent 就能估计其在环境中的表现。
- **同行做法**：(1) Importance Sampling 类方法：在长 horizon 文本场景下 importance weight 爆炸；(2) 直接方法（DM/FQE）：不 condition on evaluation policy，估计 behavior policy 的值；(3) 自回归 transformer world model：token-by-token 误差累积。
- **是否关键**：LLM agent 评估确实是一个实际需求（部署前测试），但这是 NLP/agent 领域的问题，非视频世界模型的核心关切。

## Method
整体管线：

1. **Latent Encoding**：文本 observation 通过学习的 encoder E 映射到结构化隐空间 z_t；projector G_psi 将 z_t 转为 soft tokens（对齐到 LLM embedding 空间），使 pi_e 可以读取。
2. **Diffusion World Model**：在隐空间学习环境转移 p_theta(z_{t+1} | h_t, a_t)，每个转移是独立的 K-step 去噪过程。训练目标为标准 DDPM loss + random action masking（实现 classifier-free guidance）。
3. **Policy Guidance**（三个 score terms）：
   - **Prior score**：无条件去噪方向。
   - **Action-posterior score**：有/无 action conditioning 的差异（CFG），确保生成的 observation 与当前 action 一致。
   - **Continuation score**：前向 rollout world model 并通过 pi_e 的 log-likelihood 梯度引导，确保生成的 observation 有利于 pi_e 的长期决策。
4. **Value Estimation**：通过 Monte Carlo rollout，每步 pi_e 采样 action，world model 生成下一个隐状态，reward head 预测 reward，累加得到值估计。

关键理论贡献：
- **Proposition 1**：将全局 policy-guided trajectory law 分解为 autoregressive single-step conditionals。
- **Theorem 1**：每个 single-step conditional 精确等于 prior * action-posterior * continuation 的乘积。

创新程度较高：理论分解优雅，解决了扩散 OPE 方法无法处理离散 action 的根本问题。

## Experiment
- **环境**：HotpotQA（dense F1 reward）、ScienceWorld（partial reward）、ALFWorld（sparse 0/1）、WebShop（continuous partial）。
- **评估策略**：DPO/PRM checkpoint（HotpotQA）、ETO（ScienceWorld）、LEAP iterations（ALFWorld/WebShop）。
- **实验设计**：epsilon-greedy 混合构造一系列不同质量的策略，比较各估计器的 Spearman rho（估计值排序 vs 真实值排序的相关性）。
- **结果**：
  - ADWM：mean rho = +0.82，min rho = +0.67，所有 cell 严格正相关。
  - IS/WIS：importance weight 爆炸，rho 可低至 -0.90。
  - FQE：部分有效（ALFWorld-iter1 rho=+0.82），但多数场景失败或反转。
  - DM/DR：几乎不区分策略质量。
- **消融**：去掉 local CFG -> WebShop 崩溃；去掉 continuation -> WebShop 降至 +0.30；去掉 psi adapter -> HotpotQA/ScienceWorld 大幅下降。三个组件互补，缺一不可。

## Value
- **整体价值**：理论贡献扎实（trajectory law 的精确分解），实验在 LLM agent OPE 这个新兴领域表现出色。是一篇高质量的方法论工作。
- **对我们的启发**：(1) 将 guided diffusion 用于 world model 的 policy-conditioned rollout 的框架有参考价值；(2) 三因子分解（prior/action-posterior/continuation）的思路可推广到其他 world model + planning 场景；(3) 独立去噪（每步一个扩散过程）避免误差累积是有价值的设计选择。
- **待解决问题**：目前仅在文本环境验证；latent space 的表达能力对复杂环境可能不足；continuation score 的 MC 估计计算成本较高。
