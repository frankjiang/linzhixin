# Understanding Rollout Error in Graph World Models

## Insight
论文的 insight 是：图世界模型的 rollout error 会被图拓扑谱半径和模型 Jacobian/spectral norm 放大；当边也会变化时，节点误差和边误差耦合，必须用联合 node-edge error operator 分析。

## Motivation
在交通、社交、任务依赖等图动态中，world model 常要多步 rollout。单步误差小不代表长期稳定，尤其高连接或动态边图会放大误差并影响规划 regret。

## Method
作者提出统一的 Graph World Model rollout error 框架。固定边图中，误差由 topology factor rho(A) 与模型谱范数乘积控制，形成 GEAF；动态边图中，引入联合误差算子 B。基于理论，提出 Error-Aware GWM 目标：spectral regularization、rollout consistency 和 critical-node weighting。

## Experiment
实验包括合成图拓扑和 agent-graph testbeds，展示 horizon 增加时误差和 planning regret 增长，高 rho 图更易发散，动态边预测是必要项。Error-Aware GWM 比 vanilla GCN 稳定，但跨拓扑迁移仍差；Cora/Bitcoin 等任务上也没有成为通用 SOTA。

## Value
对我们有间接价值：它把 rollout error 和结构放大联系起来，可类比到场景图、对象图或多智能体 world model。但不是视频/3D/JEPA 主线。

## Strengths
理论分解清晰；区分固定边和动态边；把误差分析连接到训练正则。

## Weaknesses
最强证据来自合成图；真实图任务覆盖有限；critical-node weighting 常接近 degree heuristic；对视觉世界模型迁移不直接。

## Future Work
未来需要更真实的 graph dynamics、uncertainty-aware priority 和与大模型 agent/场景图的结合。

## Rating
创新度评分：3/5 - 图 world model rollout error 理论化有价值。
相关度评分：1/3 (Tangential) - 图动态世界模型与目标视频/3D/隐式方向关联间接。

## TL;DR
图世界模型 rollout 误差理论解释拓扑放大和边预测耦合，方向间接可略读。
