# DWM: Separating World Effects from Actions in Latent World Models

## Insight
核心 insight 很清楚：latent world model 的 next-latent 监督把 action effect 和 action-invariant world effect 混在一起，导致模型在有重力、惯性、漂移等自发世界变化时错误归因给动作。作者用 counterfactual null action 定义 world effect，把 action effect 作为 residual，并通过训练辅助 head 让两者解耦。

## Motivation
Dreamer/LeWM 类 latent world model 用视频或状态 latent 做预测和 CEM planning，但在 PushT-W、Reacher-W、TwoRoom-W 这类有世界自发动力学的任务中明显退化。单纯加入 zero-action 数据不能解决，因为问题来自监督目标本身：模型不知道哪部分变化由世界自身导致，哪部分由动作导致。这是隐式世界模型中的关键归因问题。

## Method
以 LeWM 为 baseline，编码器 phi、transformer predictor g 和预测头 hp 预测完整下一 latent。DWM 额外加入训练期 world head hw，从同一个 rollout state 预测 action-invariant world component。world head 用 world-contrastive InfoNCE 训练：相同历史但当前动作扰动的样本为 positive，不同 state 为 negative；action component 定义为 full prediction 减 world prediction，并加正交损失约束两者不重叠。推理时仍只用原完整预测头，不增加规划接口复杂度。

## Experiment
任务包括 PushT-W、Reacher-W、TwoRoom-W、对应 flat 版本和 Ball-in-Cup。LeWM 在 PushT 94% 但 PushT-W 仅 32%，加入 30% zero-action frames 仍约 30%，说明不是数据覆盖问题。DWM 在 W variants 中成功率提升：PushT-W 32->44、Reacher-W 60->70.7、TwoRoom-W 60->76.7，平均 +13.1pp；flat 任务基本持平。预测误差大幅降低，例如 PushT-W offline MSE 0.372->0.038，rollout@20 1.034->0.344。OOD gravity 中 DWM 44% 对 LeWM 30%。消融显示 contrastive 和 orthogonality 都有贡献。

## Value
对隐式/latent 世界模型很有价值：它指出 dynamics supervision 的归因问题，并给出轻量训练目标，不改变推理接口。启发是未来视频/机器人世界模型可以显式区分 exogenous dynamics、agent action 和其他对象行动。问题是 benchmark 仍偏小，提升幅度中等，物理分解假设在复杂场景中未验证。

## Strengths
问题定义扎实；诊断 zero-action 数据无效很有说服力；方法轻量且可插到现有 latent world model；预测误差和控制成功率都有改善。

## Weaknesses
只在低维/小规模视觉控制环境验证；world/action additive residual 是 latent 层面的操作性定义，不保证语义可解释；没有与更强 Dreamer 系列或大视频世界模型结合。

## Future Work
作者没有展开具体 roadmap，但结论指向更真实控制场景、复杂 exogenous dynamics 和更大规模 latent world model 的验证。

## Rating
创新度评分：3/5 - 提出清晰有效的监督分解，但实验规模和性能提升还不足以给 4 分。
相关度评分：3/3 (Core) - 直接研究 latent/implicit world model 与规划，和 JEPA/Dreamer 方向高度相关。

## TL;DR
DWM把latent transition分解为世界自发变化与动作残差，直接改进规划，值得精读。
