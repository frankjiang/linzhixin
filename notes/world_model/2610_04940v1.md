# Software World Models: From Consequence Prediction to Decision Value

## Insight
观察：代码修改通过依赖图可传播，却不一定真正破坏下游；图漏掉的隐藏耦合又会造成静态分析漏报。由此推论，需在可复位软件系统里执行同状态候选变更，学习变更后的故障集合，并根据损害成本衡量预测价值。实验显示模型与静态可达性分别擅长隐藏和显式通道；相同故障集合 F1 也可能产生不同的迁移决策质量。

## Motivation
编码代理的本仓库测试通过，不代表下游服务、库和数据库仍工作；逐次跑全系统测试太贵。已有代理世界模型多预测工具反馈，静态影响分析只判断可能传播的区域。论文关注软件工程代理对跨仓库修改后果的预测，与视频、3D 和 JEPA/Dreamer 研究方向无实质关联。

## Method
Explore 从可复位训练状态并行执行多个候选变更，并优先采集过去执行结果与依赖图可达性矛盾的区域；Learn 将变更、类型化依赖邻域与已观测健康状态序列化，微调语言模型输出受影响组件、故障类别和检查反馈，采用监督热身及可验证结果打分的 GRPO；Act 对每个候选采样故障集合，估计下游组件故障概率，用其排序改动、按成本阈值预防性迁移并决定是否购买额外测试。另研究图 token 和结构耦合训练。方法是软件变更后果学习与决策规则的系统组合。

## Experiment
在合成可执行软件世界的相同 40 项任务、三训练种子，以及独立真实库上比较 3B 编码代理、CWM 和 Qwen-AgentWorld 适配模型。合成训练后代理 return 由 0.721 升至 0.773，候选故障组件召回 0.444→0.586，遗留故障 0.600→0.363；真实库 return 0.453→0.613。另在 90 项合成预测上，故障集合 F1 相比静态可达性 0.431 提升到约 0.57–0.61（取决于训练配方）；100 条执行记录时目标化采集 F1 0.529，随机采集 0.399。消融显示更多图上下文受输入长度限制反而可能降分；独立的风险监督器在某些显式信念规划设置更强，低价全面检查也能优于模型决策。

## Value
对编码代理的修改风险预测有价值，但与用户关注的视觉/隐式物理世界模型无直接参考，建议跳过。仅“同状态干预数据”和“预测误差按决策损失评价”的抽象原则可迁移。

## Strengths
有可执行的反事实数据采集，覆盖真实库故障；把预测、候选排序和迁移成本分开评测，并报告结构模型和检查策略可胜出的边界。

## Weaknesses
主结论依赖合成系统、可复位训练环境和特定成本函数；真实库任务规模及与合成世界的分布差异限制外推。主代理改进尚缺一般微调对照来单独证明训练目标的贡献；显式信念实验说明其预测器不是所有决策条件下最优。

## Future Work
论文结论主要倡议让编码代理提前推测跨系统后果；未明确给出针对视觉世界模型的后续方向。

## Rating
创新度评分：2/5 - 软件代理中有完整的后果学习与决策管线，但对目标物理世界模型方向无技术创新。
相关度评分：0/3 (Noise) - 研究软件依赖变更与编码代理，非视频、3D 或隐式物理世界模型。

## TL;DR
用可执行软件系统学习代码变更的下游故障并辅助迁移决策；属于软件代理研究，与目标方向无关，可跳过。
