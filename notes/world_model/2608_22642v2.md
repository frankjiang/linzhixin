# Mol-JEPA: A multimodal Joint Embedding Predictive Architecture for Molecules

## Insight

观察是分子性质存在 activity cliff，删原子/键等常见 augmentation 可能改变语义；同时仅看分子结构无法完整表达细胞、靶点和 ADMET 环境。由此可推得：与其构造“相似分子”正样本，不如随机遮蔽整种模态，用其余生化视图预测被遮蔽模态的 latent。论文通过全模态相对 graph+ECFP 的 13%-14% MAE 改善、去除实验模态消融和低数据/OOD 下游结果支持这一推论；但这证明的是静态多模态表征学习，不是环境随时间演化或动作干预的世界模型。

## Motivation

分子 SSL 常依赖可能化学无效的结构扰动，contrastive 方法又需负样本并可能出现 false negatives；简单多模态 fusion 还会 modality collapse。Mol-JEPA 试图把 JEPA 改造成可处理稀疏、部分配对的 14 模态分子模型，吸收结构、量化计算、细胞表型、结合亲和力和实验标签。该问题对药物表征很重要，但与用户关注的视频、3D 或用于控制的隐式世界动力学没有实质关系。

## Method

1. 预训练集去重后含 469 万分子，来自 ChEMBL、TDC、PCBA-1328、Nabla2 DFT 和 Enamine REAL；统一 canonical SMILES、pH 7、立体化学和低能构象。
2. 14 种模态包括可训练 graph Transformer、UMA 原子 embedding，ChemGPT/CLOOME/BioXMol/Boltz-2 等冻结模型 embedding，MOE/ECFP/xTB/DFT descriptors，以及 ChEMBL/PCBA/TDC 稀疏实验向量。atom、graph、vector 三类 encoder 将不同输入投到同一维度。
3. 对每个样本按 masking ratio 遮蔽可用模态，同时把真实缺失模态也换为各自 token，并确保至少保留一种 context；调参选中 0.3，但作者未观察到 masking ratio 与下游性能的一致关系。约 5000 万参数的 Transformer 加 modality position 和 CLS token，从剩余模态预测每个 masked target embedding，以逐模态 MSE 训练。
4. 为防 collapse，在 target embeddings 上施加 LeJEPA 的 Sketched Isotropic Gaussian Regularization：沿 1024 个随机一维方向计算 Epps-Pulley 正态性统计，使 latent 接近各向同性高斯；总损失为各模态 prediction loss 与 lambda=0.7 的 SIGReg 之和。
5. 下游既可用 512 维 CLS 做线性/非线性 probe 或 TabICLv2，也可用 2 层 Transformer 聚合各模态预测 embedding，或 rank-16 LoRA 微调。模型在 12 张 RTX 6000 Ada 上以总 batch 1024 训练约 3 天、150 epochs。

方法本质是 modality-masked JEPA 加现成 LeJEPA 正则及大量预计算 teacher features；将稀疏实验 label vector 也视为模态较实用，但没有学习状态转移、因果干预或分子动力学。

## Experiment

- 评测覆盖 ExpansionRx 9 个 endpoint、ASAP/Polaris 7 个、PXR 1 个和 Biogen ADME 6 个，共 23 个回归任务；用 ECFP4 Tanimoto 0.65 的 Butina cluster 构造 3 个 split，并另测官方时间 split。对比 RF/LGBM、TabICLv2、Chemprop、CheMeleon、CLAMP，所有可训练基线在 train split 做 5-fold 调参。
- 三个 cluster split 上，Mol-JEPA Best 的平均 MAE 为 0.402，优于固定 Mol-JEPA Transformer 0.427、TabICLv2+AlvaDesc 0.453、CheMeleon 0.471、Chemprop 0.519；平均 R2 为 0.42，对 TabICLv2 的 0.37。代表性结果如 Biogen HLM clearance MAE 0.33，对 TabICL 0.37；但 ASAP MERS potency 0.59，不及 Chemprop 0.52。
- “Best”会为每个数据集从 probe 与 embedding 变体中选最好结果，带有 oracle 式乐观偏差。按 paired Wilcoxon 显著性胜率，Mol-JEPA 为 38%，低于 TabICLv2+AlvaDesc 的 47%；官方时间 split 上 TabICLv2 的 MAE/Wilcoxon 胜率也更高，Mol-JEPA 只在 R2 胜率领先。
- 按测试分子到训练集的 Tanimoto 相似度分箱，Mol-JEPA 在低相似度区总体优于基线；但附录同时显示离完整预训练语料越远误差越大，泛化仍主要依赖 chemical-space coverage。更多预训练数据持续改善 1-MAE。
- 100K 子集消融中，全模态线性/非线性 MAE 为 0.436/0.393，直接 semi-supervised label prediction 为 0.467/0.417，去掉实验模态为 0.449/0.407；SIGReg 放在 target 优于 CLS，放在 prediction 会 collapse；512 维基本饱和，1024 维无稳定收益。全数据只用 graph+ECFP 时，相对全模态 MAE 恶化 14%/13%。
- Leave-one-out 显示 graph、MOE、ECFP 最重要，移除单模态时差异又较小，表明信息高度冗余；CLOOME 等个别模态甚至降低下游表现，稀疏模态的 loss 信号也更难优化。

## Value

对科学多模态 SSL，本文提供了一个无需分子结构 augmentation 或负样本的可扩展配方，尤其说明“预测别的测量视角”可比直接多任务监督更稳。对我们唯一的间接启发是：JEPA target 可以定义为同一对象的另一种观测，而不必是未来帧；但它没有时序、动作、规划或可视世界状态，因此不应仅因名称含 JEPA/world model 就归入隐式世界模型主线。

## Strengths

- 数据整理规模大，14 模态覆盖结构、量化、表型、结合与实验属性，并能处理部分配对/缺失数据。
- 同时比较经典 descriptors、tabular foundation model、GNN 和分子 foundation models，且使用 cluster 与官方时间 split。
- 报告 Wilcoxon 显著性、OOD 相似度分箱、data scaling、modality dynamics、CKA 和多组架构消融，分析较完整。
- 公开代码、checkpoint 和 Hugging Face 接口，训练超参数与算力也给得具体。

## Weaknesses

- 任务是静态分子属性回归，所谓“molecular world model”没有状态演化、动作或因果环境；与 Dreamer/视频 JEPA 的核心问题不同。
- 大量输入本身是 UMA、ChemGPT、CLOOME、BioXMol、Boltz-2 等强模型的冻结 embedding，提升部分来自 teacher ensemble 和昂贵预计算，而非 Mol-JEPA 独立学到的新知识。
- 主表的 Mol-JEPA Best 对每个任务选择最佳 probe/representation，不是单一固定部署方案；更公平的 fixed Transformer 虽仍强，但优势缩小。
- Wilcoxon 胜率和官方时间 split 的 MAE 胜率不及 TabICLv2+AlvaDesc，说明“全面超过基线”并不成立；若干 ASAP 测试 split 仅 13-55 个样本，方差很大。
- 模态稀疏度极不均衡，例如 Boltz 仅约 10.2 万样本而基础结构模态近 469 万；训练曲线存在 instability，个别模态会伤害性能，现有均匀 MSE/SIGReg 未建模可预测关系的非对称性。
- 多数关键消融只在 100K 子集完成，作者也承认可能影响结论；没有证明 latent 对分子动力学、生成设计或真实实验决策有用。
- 论文未说明 469 万预训练分子是否与全部下游测试分子做精确去重；因此所谓 OOD 只是下游 train/test split 的 OOD，不能排除预训练覆盖带来的污染风险。

## Future Work

作者明确提出建模“哪些模态能预测哪些模态”的依赖关系并设计更高级 masking，测试对新分子/新任务/新分布的 OOD 鲁棒性，理解 sparsity、维度、信息量与冗余对训练的作用，并优化模态选择；同时可继续扩大预训练覆盖并迁移到材料、生物等科学域。对其“世界模型”主张而言，合理但未提出/未完成的关键一步是加入时序分子动力学或干预结果，验证 latent 是否支持预测和规划，而不只是 property probing。

## Rating

创新度评分：2/5 - 将 modality masking、JEPA 和 SIGReg 应用于大规模分子多模态数据有实用贡献，但核心算法是现有方法组合，且不涉及目标方向的世界动力学。
相关度评分：0/3 (Noise) - 纯分子属性表征与药物发现，没有视频、3D 场景或用于控制的时序隐式世界模型；JEPA 同名不足以构成相关性。

## TL;DR

用模态遮蔽JEPA融合分子多源表征，虽下游性能强但非目标世界模型，可跳过。
