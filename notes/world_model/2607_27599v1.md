# World Action Planner: Generalizable Decision-Making with Action-Conditioned World Models

## Insight
作者观察到 imitation policy 往往记住训练轨迹而非任务机制：组合任务完成第一子任务后停滞，布局改变后仍抓旧坐标。VLM 能提出语义动作，却不擅长度量坐标和物理后果。由此推论，应让 VLM 提案、action-conditioned world model 预演，再由 VLM 对 rollout 做碰撞反馈和候选排序。实验表明系统性局部错误不会因 best-of-N 随机采样自然消失，而围绕一个动作做有结构的全局修正与局部网格搜索更有效。

## Motivation
端到端 VLA/WAM 受 demonstrations 分布限制，难以组合已学技能或适应新布局；经典 model-based planning 可通过共享动力学重组动作，但现代 VLM proposal 缺乏物理 grounding。如何把 foundation-model reasoning、可执行低层控制和视频 world model 的想象结合，是机器人世界模型的重要问题。

## Method
世界模型用 forward kinematics 把候选 action 转成未来 robot joint，按对应相机渲染 pose-skeleton image；pose frame 经视频 VAE 编码，与多视角 wrist/third-person video token 拼为统一序列，由 diffusion-forcing flow-matching DiT 预测未来视频。视觉姿态接口绕开不同机器人 action dimension，支持跨 embodiment。

WAP 的 coarse-to-fine 流程为：VLM 从多视角图像产生 MOVE/ROTATE/GRASP/RELEASE primitive，并三角化 2D 点为 3D target；低层 controller 展开 action chunk；世界模型生成结果，VLM 给出如“抬高避开篮沿”的 semantic delta；再围绕动作做 grid search，生成各候选 rollout，由 VLM 排序。必要时继续想象 diffusion policy 从候选状态执行，以选择能重新进入 policy 分布的状态。现有 VLA/policy 被视为可调用工具，而非全程决策器。

理论部分在共享 dynamics、任务特定 reward 的 contextual MDP 以及 linear MDP 假设下比较 model-based exploration 与 imitation learning，说明前者可复用动力学到新任务而后者存在多任务样本复杂度下界。它支持总体动机，但与具体视频模型/VLM planner 的误差、计算和鲁棒性没有紧密连接。

## Experiment
Pose-image WM 在 LIBERO-90、DexMimicGen、LIBERO-Long/Spatial 和 MimicGen-Robot 上以 PSNR/LPIPS 比较 WPE、IRA-Sim、Ctrl-World。相对次优方法，ID 平均提升 11.4%，泛化设置平均提升 16.8%；混合 RoboCasa/MimicGen/DexMimicGen 的跨 embodiment 也优于 unified action space、embodiment encoder 和 soft prompt。

Planner 在模拟器中每任务 50 次。四个由 LIBERO-90 原子任务组合的 LIBERO-Long 任务上，WAP 成功率 68–78%，VLM planner 为 28–56%，π0.5/cosmos-policy 几乎为零。六个新布局任务中 WAP 为 66–90%，VLM planner 16–64%，其余 policy 多接近零；但 WAP 的 policy 用 5 条 expert 加每任务 10 条扰动轨迹训练 WM，基线使用完整原布局数据，比较的是不同系统归纳偏置。

无 expert demonstration 的 PickPlaceCan/StackCube 中，先用 50 条探索轨迹微调 WM，WAP 为 80/76%，VLM planner 为 58/22%。组件消融从 VLM planner 逐步加入 global optimization、local search、policy rollout imagination，四组合任务均单调提升。Ketchup 上一次结构化 global optimization 成功率 60%，即使用真实环境 reward 选 best-of-8 也只有 42%；StackCube 六次局部搜索为 70%，best-of-10 为 62%。

代价很高：单候选 20 帧生成约 17 秒，global optimization 连 VLM 约 30 秒，local search 需 2–3 分钟，只能在关键节点调用。全部控制实验都在仿真，没有真机验证。

## Value
论文很好地展示了 world model 不只是 policy representation，也可作为 VLM 的视觉反事实评估器；pose image 还是可扩展的跨 embodiment action interface。对后续研究最有启发的是把“语义修正”和“度量搜索”分开，并让已有 policy 作为局部技能工具。实际落地需更快的 causal rollout、显式不确定性和安全约束，以及对 world-model hallucination 的闭环校正。

## Strengths
- pose-image conditioning把 action 与视觉几何对齐，跨 action space/机器人接口直观且有效。
- proposal—global feedback—local search—policy rollout 的层级职责清晰，对典型泛化失败有针对性。
- 覆盖 compositional、layout shift、zero-shot 和 cross-embodiment，多场景提升显著。
- 与 best-of-N 的对照说明结构化搜索可修复 VLM 的系统性物理偏差。
- 50 trials/task、组件消融和 runtime 报告使系统效果与代价较透明。

## Weaknesses
- 所有规划实验在模拟器，未验证 perception noise、kinematic calibration、延迟和安全对真机的影响。
- planner 依赖 Gemini、手工 primitive、三角化、grid-search 范围、硬编码 gripper logic 和低层 controller，性能不能归于 world model 单一组件。
- 世界模型按给定 pose 生成视频，却未显式量化 contact/碰撞预测准确率或错误 rollout 导致的规划风险。
- 新布局比较中训练数据量和系统输入不对等；端到端 baseline 没有 VLM 高层先验，属于 system-level 而非纯模型公平比较。
- 2–3 分钟局部搜索离实时控制很远，候选数增大时计算线性增长。
- 理论依赖共享准确 dynamics、tabular/linear MDP 等强假设，没有纳入 learned model error 与 VLM ranking error。
- zero-shot 仍需 50 条新环境 exploratory trajectory 微调 world model，不是严格意义上的零数据迁移。

## Future Work
作者明确把真机实验、few-step sampling、autoregressive world model 与 KV-cache 加速列为后续，并提出可学习更高效的 candidate ranking。还应加入 uncertainty-aware rollout、独立物理约束/安全 shield、端到端误差归因，以及跨新 embodiment 的零/少校准真机测试。

## Rating
创新度评分：4/5 - 跨 embodiment pose-image world model 与 VLM 驱动的分层想象优化形成完整新系统，泛化提升强；但手工组件多、计算昂贵且只在仿真验证。

相关度评分：3/3 (Core) - 直接研究 action-conditioned 视频世界模型、想象规划、机器人控制与跨 embodiment 泛化，核心相关。

## TL;DR
以姿态图条件世界模型预演并让 VLM 分层修正搜索动作，仿真泛化强，值得精读。
