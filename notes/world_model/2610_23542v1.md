# Execution Before Memory: Diagnosing Memory Failures in Video World Models

## Insight
观察：视频记忆评测的低分可能因模型根本没有执行动作或返回目标视角，此时尚无可观察的状态可供判断遗忘。推论：必须分开测场景建立、隐藏期泄漏、动作揭示和末帧状态。MIST 中 43 例有 41 例基线从未打开容器；定向改写把单条保留视频的揭示均值由 0.147 提至 0.492，却仍有 10 例“打开但内容错误”。实验定位失败阶段，并不能证明内部记忆真实存在。

## Motivation
WRBench/MBench-T 等把场景、状态变化与重访结果折成单一记忆分数，容易把“没有执行变化”误报为“忘了变化”。这是视频世界模型评测的关键混杂因素；传统长时记忆模块未必针对执行瓶颈。

## Method
MIST 把每例分为建立场景、遮挡变化和揭示结果三段，固定前两段，分别用视觉判读器评估 setup、leak、reveal、inside，区分没打开与打开却错。M3-Agent 根据任务卡和已生成末帧诊断“动作缺失、绑定错误、未离开/返回”等，只改失败动作及末帧证据描述，再用冻结生成器生成候选。部分揭示提示可直接写目标状态；候选选择使用与报告相同的评测分数，原视频也可保留。贡献重心在阶段化诊断与受约束的测试时改写，非新的模型记忆模块。

## Experiment
Internal MIST：Wan TI2V-5B、43 例、每例 3×5 秒，setup 0.852→0.851 不变，reveal 0.147→0.492，inside 0.047→0.442，从未打开 41→20；五次候选的最优揭示 0.763，单给答案 0.684，隐去目标的同类改写仅 0.174。Official WRBench：Wan T2V-A14B、40 例，T 0.452→0.570（+26.1%），主要来自离开和返回门控；Official MBench-T：30 例，U 0.292→0.446（+52.7%），23 例保留原视频。附录独立的 43 例 MiniMax-H3 连续片段中，原始“未打开”仅 3 例，失败形态会随生成器和拼接方式改变。

## Value
建立“先确认更新发生、再考核持久性”的评测纪律，特别适合设计视频世界模型的遮挡、重访和隐藏状态基准；值得精读。当前结果更适合作为故障诊断和可达上界，不能当作已解决世界状态记忆的证据。

## Strengths
明确隔离 setup、leak、动作与结果；答语、同句重采样、无答案改写和官方评分审计提供有用的反事实；作者在正文和附录主动区分评测器、生成器、单条结果与 best-of-five，并指出提示泄漏及 oracle 选择。

## Weaknesses
样本仅 43/40/30，关键指标依赖自动视觉判读、缺少 43 例末帧人工标签。最好候选直接按报告分数挑选且可把目标答案写入提示；附录中不看评分器的选择器在 WRBench/MBench-T 均未显著优于基线，因此官方提升不能视为可部署收益。末帧可见结果也不能证明隐状态被保存；三段拼接的失效模式不普适。

## Future Work
作者指出需要目标盲选择器、未见测试案例和对显露状态的人工标注，才可能进一步检验真正的记忆能力。

## Rating
创新度评分：3/5 - 阶段化记忆诊断很有价值；测试时提示改写已有先例，且 oracle 选择限制方法结论。
相关度评分：3/3 (Core) - 直接针对视频世界模型的隐藏状态变化和重访记忆评测。

## TL;DR
拆开视频记忆测试中的动作执行与状态保持，发现低分常发生在揭示之前；评测设计值得精读。
