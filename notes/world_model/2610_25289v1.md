# The Explainability Illusion: Must ViTs Exhibit Patch-Decoding Interpretability?

## Insight
把分类头直接施于 ViT 中间 patch token，并不保证“物体 patch 得分高”。作者观察到许多分类 ViT 对齐、CLIP 等对比模型反向；在单层玩具 Transformer 上构造相同最优分类 logits、却有对齐或反向 patch 图的不同权重，证明分类最优性本身不决定这种零样本解码解释性。证明仅针对特定模型和指标，不说明真实模型为何选择某种模式。

## Motivation
直接解码 token 是廉价且常用的视觉表征解释方法，若误把其热图当成语义定位，将导致错误分析。该问题可能影响视频 JEPA 骨干诊断，但论文不研究世界模型的状态转移。

## Method
定义物体掩码内外平均类别分数差及对齐图像比例 A；以 A≥66.7%、33.3%–66.7%、<33.3% 分成对齐、无明显解释性和反向。对预训练 ViT/CLIP 做无训练解码，另在可控“物体 patch＋噪声背景”数据上改变目标/背景方差与训练种子。理论部分推导高斯混合任务的 Bayes 分类器，构造单层注意力的不同参数化，使 class token logits 相同而 patch 解码符号不同。贡献是诊断与反例，不是新的世界模型。

## Experiment
PartImageNet++ 上，普通 ViT-B/16 的 A 约 98%，但 SAM 训练 ViT-B/16 仅 6.4%，CLIP-B/16 约 2%；部分 DINOv2 层和类别也不同。合成实验覆盖 66 种分类与 81 种对比设置、各三种子，物体/背景噪声比例变化可让同架构偏向对齐、反向或无解释性，同设置不同种子也可能不同；性能相近不保证热图相同。附录给出玩具定理的完整证明与现实模型各层/缩放检查，但没有检验视频世界模型中的动力学解释。

## Value
若用 patch 解码热图分析 JEPA/ViT 视觉特征，应先验证热图与真实对象掩码/时序事件的对应关系；不能仅凭分类表现或热图外观认定表征含义。

## Strengths
大范围真实模型调查、受控数据实验和明确的理论反例互相支持；指出解释指标依赖输出头并区分中间层/类别。

## Weaknesses
只研究无训练 patch 解码，不覆盖梯度解释、因果归因或训练探针；掩码内外均值可能忽略复杂空间语义。玩具证明要求简化架构和特殊输出头，不能解释真实模型的优化机制，也未直接测试视频/3D 世界模型。

## Future Work
作者建议扩展到梯度解释方法、较窄嵌入的理论模型及更复杂网络。

## Rating
创新度评分：3/5 - 系统性反例与最优模型的解释不唯一证明有价值，但属于 ViT 可解释性方向。
相关度评分：1/3 (Tangential) - 可提醒 JEPA 视觉表征分析的陷阱，与世界模型动力学仅间接相关。

## TL;DR
ViT 的 patch 解码热图可在相同正确预测下对齐或反向；若用热图分析 JEPA 视觉表征，应先验证其含义，可选读。
