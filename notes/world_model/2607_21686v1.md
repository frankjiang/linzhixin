# Persistent Computational State: A Session-Centric Runtime for Generative World Models

## Insight
有。论文的 observation 是：很多“视频世界模型没有持久世界记忆”的失败，可能不是模型能力本身缺失，而是 request-centric serving 把非可重算的计算状态丢掉了。推论是需要定义并持久化 Persistent Computational State（PCS）：只要 snapshot observation、RNG、memory bank、KV context 等最小状态，restore 后能字节级或语义级复现 never-left continuation，就说明运行时保存了世界模型继续演化所需的状态。

## Motivation
论文解决生成式世界模型在交互、fork、backtracking、planning 时的会话状态问题。现有服务通常把每次生成当独立请求，依赖 prompt/观测重新构造上下文；但长程世界模型、WorldMem、MCTS planning 等需要保留不可由当前 observation 完全恢复的状态。这个问题对视频世界模型很关键，因为“世界一致性”不只来自训练目标，也来自部署 runtime。

## Method
作者定义 PCS 为满足 `D(continue(restore(S)), oracle) <= epsilon` 的最小非可重算状态集合，并提出 checkpoint/restore/fork/delete API。系统不假设哪些张量是状态，而是用 fingerprint procedure：逐个 ablate runtime components 验证必要性，再 snapshot 必要集合验证充分性，并用错误替换作为 load-bearing control。

实验覆盖三类系统：Cosmos3 flat model 的 PCS 是 observation + RNG，约 1.38MB；WorldMem 的 PCS 是 memory bank + pose + RNG，约 185KB 且随保留帧线性增长；Matrix-Game 2.0 的 PCS 是 KV context、position indices、RNG，约 1.67GB。runtime 采用 session-centric 管理，把 inactive PCS 放到 host memory，GPU time-multiplexed。

## Experiment
作者评估 bit-exact restore、跨进程恢复、显存/主存扩展性、checkpoint 开销、eviction policy、arrival-order replication、trace workloads 和 MCTS planning。

关键结果：在 A800-80GB 上，S=1 到 1024 session 的 device memory 基本恒定约 4.714GB，host memory 随 session 线性增长约 0.0373MB/session。checkpoint/restore 约 0.012ms，相比单步生成 1.852s 可忽略。PCS-aware eviction 在小预算下显著优于 LRU/FIFO，例如 4MB 时 return consistency 约 0.9531，而 LRU 约 0.4110。MCTS 场景中，12MB 预算下 anchor/PCS-aware 能保持约 0.8683，一般 LRU 直接失败为 0。

## Value
这篇对我们有较强启发：世界模型研究不能只看网络结构和训练数据，交互式世界建模还需要会话状态抽象。对于视频/3D世界模型，PCS 让回滚、分支、长期记忆、闭环规划有明确系统接口。它不是新模型，但可能影响模型如何被部署和评测。

## Strengths
亮点是把“记忆丢失”从模型问题拆成 runtime 可测试问题；PCS 定义操作化，fingerprint 方法可复用；实验覆盖视频、记忆增强和游戏规划；同时承认有些模型在 recency-dominated metric 下不区分 PCS。

## Weaknesses
PCS fingerprint 不是严格定理；只覆盖三个模型族和单 GPU time-multiplexing；评估指标依赖具体任务；系统只能保存模型已经学到/暴露的记忆，不能创造缺失的世界状态；尚未展示真实大规模在线服务。

## Future Work
作者指出未来要扩展更多模型族、多 GPU/调度、自动 PCS 识别、更复杂 eviction/admission、与真实规划器和长程交互任务结合。

## Rating
创新度评分：4/5 - 系统视角新颖且证据充分，虽非模型架构但对交互式世界模型范式有重要影响。
相关度评分：3/3 (Core) - 直接面向生成式视频/世界模型的持久状态、分支和规划。

## TL;DR
证明部分视频世界模型记忆失败来自服务层丢PCS，系统 insight 强，值得精读。
