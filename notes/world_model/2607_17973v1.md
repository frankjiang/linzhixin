# SAGE: Subgoal-Conditioned Action Generation for Latent World Model Planning

## Insight
有。Observation 是冻结 latent world model 在长程规划中预测器未必是最大瓶颈，候选 action proposal 才是：随机 CEM 在固定预算下很难覆盖长 horizon 的可达路径。推论是先预测可达 latent subgoal，再生成 subgoal-conditioned action prior，可把搜索分解成更短、更可控的局部规划。实验通过 generator-only、SAGE+CEM、SAGE prior top 等消融证明：action prior 提供覆盖，world model refinement 提供筛选。

## Motivation
解决 latent world model 长程规划候选不足的问题。同行常用 CEM/random shooting 或 PRISM 类 proposal，但长 horizon 下采样效率低，候选预算固定时成功率快速下降。这是视频/机器人 latent world model 真正落地规划的关键问题。

## Method
冻结已有 LeWM/encoder/dynamics/cost。SAGE 增加两块：可变长度 latent subgoal generator，根据历史 token、低维状态、远目标 latent、剩余 offset 和局部 duration 预测可达局部目标；subgoal-conditioned action generator 用 Transformer decoder 和 learned action queries 输出 8-mode GMM action trajectory。生成样本作为 CEM 初始化，再由冻结 LeWM 评估和 refine，默认 300 candidates、30 rounds，支持多个 duration schedule。

## Experiment
在 PushT 和 OGBench Cube 上做 held-out goal pairs，horizon 25 到 150，对比 Base LeWM-CEM 和 PRISM，保持同一 LeWM、预算和 CEM。H=150 时 PushT 成功率 64.7%，Base 12.7%，PRISM 17.3%；Cube H=150 为 67.3%，Base 26.7%。短 horizon 也明显提升。消融显示 generator-only 已有收益，但只用 SAGE prior 不经 LeWM/CEM 很差，说明 prior 与世界模型筛选互补。schedule 消融表明更多短 replanning stage 往往更好。

## Value
对我们很有价值：它不是重新训练世界模型，而是在冻结 latent model 外加“可达子目标+条件 action prior”提高规划搜索效率。适合精读，尤其是研究长程视频/机器人 world model planning 时的 proposal 设计。

## Strengths
问题抓得准；方法和现有 latent WM 解耦；实验预算公平；消融能解释为什么 subgoal、prior 和 CEM refinement 都需要。

## Weaknesses
任务规模仍小，主要是低维/桌面操作；subgoal duration 还靠离散 schedule 和手工选择；没有展示复杂视觉长视频场景或真实机器人闭环。

## Future Work
作者提出学习 state/horizon-aware duration policy，并扩展到更多任务和 world model。

## Rating
创新度评分：3/5 - 属于 latent WM 规划中的有效 proposal 改进，思路清晰但不是全新范式。
相关度评分：3/3 (Core) - 直接研究 latent world model planning，与用户关注方向核心相关。
