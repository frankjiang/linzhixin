# Beyond Visual Fidelity: Comparing Categorical and Continuous World Models

## Insight
观察：像素或视频指标无法区分「随机未来不同于参考轨迹」与「违反环境规则」，且高动态有效性也未必意味着正确的结果概率。论文在已知规则的 Pac-Man 环境中，用无损类别编码排除量化误差，交叉比较类别/连续输出与逐 patch/整帧生成，并直接检验合法状态转移及真实条件分布。结果是类别模型以较少训练算力保持较高长程有效性，差距主要来自随机幽灵；但采样的类别迭代模型比连续模型校准更差。这是受控实验支持的经验结论，并非对所有视频世界模型的普遍证明。

## Motivation
主流视频世界模型常以视觉保真度、FVD 或单一真值轨迹衡量生成质量；前者不能保证动作响应和动力学合法性，后者会误判合理的随机分支。离散自回归与连续 flow 通常还同时改变 tokenizer、架构和算力，难定位差异来源。可信长程预测是规划与策略训练的关键问题，本文旨在拆开这些变量，并将「可能发生」与「发生概率」分别评测。

## Method
构造 2×2 比较：Cat-NT 用交叉熵逐 patch 生成 token；Cont-NT 用条件流匹配逐 patch 从噪声生成 RGB；Cat-Iter 用 MaskGIT 置信度逐轮揭示整帧 token；Cont-Iter 用 DiT 式整帧流匹配。四者共享数据、训练日程，骨干容量近似匹配，以累计训练 PFLOPs 对齐；推理时把预测帧递归送回上下文。Pac-Man 的 8×8 四通道状态按 2×2 格编码成 2401 类 token，类别编码无损；连续 RGB 输出先映射到合法调色板。另以部分可观测 3D 迷宫比较无损字典 token、VQ-VAE 有损 token 与连续 64×1 RGB 条带。创新主要在正交对照和可核查的动力学评测，四类生成器本身大体沿用既有方案。

## Experiment
Pac-Man：三训练种子、每个检查点 512 个上下文；比较 64 步 rollout 的转移/整段有效性，分幽灵、主角和棋盘检查，并以已知幽灵条件分布的经验总变差检验校准。主实验 1/3/5 个随机或逃离幽灵。仅查确定性成分时，各模型约从 2 PFLOPs 起即接近完美；随机幽灵拉开差距。Cat-NT 贪心解码在仅 2 PFLOPs 训练后，第 64 步仍约 86% 整段有效。10 PFLOPs 时，采样 Cat-NT/Cat-Iter 的幽灵分布 TV 分别为 0.30/0.67，Cont-NT/Cont-Iter 为 0.33/0.34，表明高有效性和高校准不可互代。附录 1/3/5 个随机幽灵的 64 步平均有效性 AUC：贪心 Cat-NT 为 98.45/97.34/95.80%，Cont-Iter 为 60.20/18.61/9.82%；逐步转移检查显示连续模型在早期失败后仍持续产生局部违规。推理步数消融显示连续模型从 20 增至 50 步有改善，之后收益较小。

3D 迷宫：64 步语义像素准确率、FVD 与下一帧 RGB 精确匹配；有损 token 的下一帧 RGB 更差，但语义与 FVD 未稳定变差。类别模型在低训练算力时长程指标更强，连续模型到 30 PFLOPs 缩小差距；类别采样改善 FVD，而贪心更利于 Pac-Man 有效性。3D 结果只用一个训练种子和 512 个评测样例，图中误差带是样例 bootstrap 区间。

## Value
值得精读其评测设计：用规则验证整段轨迹，同时报告随机结果的校准；视频模型选型应按规划任务所需的合法性、概率质量及推理成本分别比较。对团队有直接启发：在可控仿真器中设计合法状态空间与条件分布基准，避免用视觉分数替代动力学测试。将结论迁移到真实 3D 操作、复杂碰撞和高分辨率视频仍待验证。

## Strengths
2×2 因子实验拆分输出类型与帧内生成方式；无损编码使 Pac-Man 动态对照不受 tokenizer 误差干扰；完整历史一致性检查处理遮挡 pellet、重置与随机转移；同时报告有效性、校准和多种解码设置，揭示指标之间的真实取舍。

## Weaknesses
环境仍是极简游戏：3D 场景为纯色迷宫，球不与智能体交互，也没有真实 3D 物理或机器人操作。3D 只有一个训练种子，难判断模型间差距的训练方差。四组模型的骨干、头部、输入编码不同，所谓受控比较并未完全隔离输出分布；训练算力近似按骨干参数×token 数计算，排除了 tokenizer 训练，且未等价比较推理开销（Cont-NT 在 Pac-Man 每个 patch 需 50 次 Euler 求解）。Pac-Man 的 RGB 输出被投影到合法调色板，评测因此只检验投影后状态；贪心提高合法性却不代表能用于随机预测或风险规划。

## Future Work
作者明确提出进一步研究 Cat-Iter 的有效性、校准与推理速度取舍；同时提醒细节决定动力学的场景可能更受有损编码影响。向真实复杂场景及规划收益推广属于本文尚未解决、值得继续验证的问题。

## Rating
创新度评分：3/5 - 受控因子设计与「合法性和校准分离」的实证有价值，但模型组件非新范式，验证局限于简化环境。
相关度评分：3/3 (Core) - 直接比较视频/3D 世界模型的动态预测表示、长程一致性和评测方法。

## TL;DR
在受控2D/3D环境中，类别预测以较低训练算力保持更高长程动态有效性，同时揭示有效性与校准分离；值得精读。
