# Planning-Oriented End-to-End Autonomous Driving: Architectures, Evaluation, and Emerging Paradigms

## Insight
综述的核心判断是：现代 E2E 驾驶的关键不在“是否保留中间结构”，而在结构、监督和评测是否共同服务安全可行规划。进一步区分世界模型四种角色——表征预训练、生成未来、轨迹后果评估、闭环模拟器——并指出视觉逼真、规划有效和模拟忠实是不同命题，必须分别验证。

## Motivation
E2E-AD 已从像素到控制回归发展为 BEV/vector/latent/VLA 等结构化规划，但文献常跨 open-loop、非反应 real-log 与 closed-loop 指标混报，导致架构进展难解释。该综述试图以 planning claim 为中心统一方法和证据，对驾驶世界模型评测很重要。

## Method
作者按 input representation、planning output、supervision signal、evaluation protocol 四轴整理从 BC、privileged distillation、统一感知预测规划到 world model/VLA 的谱系；专表比较 MILE、GenAD、DriveWorld、Drive-WM、LAW、WoTE、World4Drive、Bench2Drive-R、WorldDrive，并给出 benchmark、runtime safety 和 reproducibility 清单。检索含关键词、前后向引用追踪及“必须支持 ego planning”的纳入条件，但不是系统综述。

## Experiment
无新实验或 meta-analysis。证据主要是方法/数据集/指标对照表和论证：open-loop L2 测 imitation fidelity，NAVSIM 类分数是安全感知 proxy，Bench2Drive/CARLA 测反应式闭环但仍有 sim-to-real 限制。作者建议至少三角验证 real-log proxy 与 reactive closed-loop，并对 world model 额外报告校准、稀有事件、候选轨迹排序和分布移位。

## Value
对筛读驾驶世界模型很实用：提醒不要用 FID/视频观感替代 action-conditioned consequence quality，也不要把所有 “world model” 论文放同一榜单。可直接借用其四角色分类和 claim-aligned evaluation 框架。

## Strengths
覆盖架构、监督、评测、安全与复现而非只列模型；world model 角色边界清楚；系统讨论指标失配和 runtime assurance；对新近方法保持“frontier signal”而非定论。

## Weaknesses
检索与筛选没有 PRISMA 式完整记录，可能有作者选择偏差；没有定量文献统计、质量分级或跨 benchmark 原始复算；主题很宽，world model 章节只占一部分；大量 2025–2026 工作未独立复现。

## Future Work
提出跨协议相关性、因果/反事实评测、不确定性与偏好感知规划、world-model 校准、language-action grounding、正式/经验安全、算力归一化和可复现公共基线。

## Rating
创新度评分：2/5 - 四轴和四类世界模型角色的整理有用，但属于宽域叙述综述，无新方法或定量综合。
相关度评分：2/3 (Related) - 驾驶视频/latent world model 是重要子主题，但论文主体覆盖更广的 E2E 规划与 VLA。

## TL;DR
以规划证据重整E2E驾驶并区分四类世界模型角色，评测框架值得选读。
