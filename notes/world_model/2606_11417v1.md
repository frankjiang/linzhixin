# Signed Compression Progress on a Sealed Audit is Goodhart-Resistant

## Insight
核心 insight 很清楚：compression progress 只有在“固定 sealed audit loss 上计有符号进步”时才是可信 intrinsic reward。因为 r_t=E(theta_{t-1})-E(theta_t) 会 telescope，累计奖励正好等于 endpoint audit improvement；有限 audit panel 下，只会多出 2 Delta_n 的 false-positive budget。该证明把 Goodhart resistance 变成测量框架问题。

## Motivation
compression progress 常被用作 curiosity/world-model learning 的内在动机，但 prediction error、stream scoring、clipped progress、reusable holdout 都会被 Goodhart。论文要精确定义什么时候“奖励模型真正变好”成立。问题与 Dreamer/JEPA 不是直接同类，但对世界模型自我改进和 intrinsic reward 有理论参考价值。

## Method
定义 sealed audit distribution Q 和 audit loss E(theta)。signed audit compression progress 为 E(theta_{t-1})-E(theta_t)。定理 1 给 exact audit telescoping；定理 2 给 finite panel uniform deviation 下经验 audit-CP 不超过真实进步 +2Delta；定理 3 用 proper log-loss 的 entropy floor 解释 noisy-TV 随机成分不能无限给奖励。Lean 4 形式化了 telescoping、finite audit bound、finite Gibbs、entropy floor 等核心。

## Experiment
实验用 ARC-TGI grid-transformation generators 和多种 curiosity reward。Audit-CP 在 active-cell accuracy 上优于 prediction error、ICM，接近 oracle，同时 distractor allocation 仅 21.9%，prediction error 为 50.4%。边界实验显示 clipped reward 可循环刷分，stream-scored CP 与 sealed audit CP 分离，高容量 reusable panel 可过拟合。adaptive scalar-feedback holdout attack 中 naive reusable release gap 3.24 大于 2Delta=1.64，fresh subsample/ladder/rounded/one-shot 等防御压低到阈值内。

## Value
理论价值高于方向相关性。对用户方向的启发是：若用预测/压缩进步做世界模型内在奖励，必须保留负进步、使用保护的 audit distribution，并把探索调度与可信奖励分开。但它不是视频世界模型或 3D 模型论文，阅读优先级中低。
