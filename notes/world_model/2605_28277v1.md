# MentalMap: Towards a Comprehensive Benchmark for Evaluating Spatial Reasoning in Large Language Models

## Insight
无。是一个评估 benchmark，不产生新方法论洞察。

## Motivation
现有 LLM 空间推理 benchmark 局限于英语、规模小、覆盖的推理类型少。MentalMap 旨在系统性评估 LLM 在多语言、多层次空间推理上的能力。

## Method
- 定义5层空间推理层次：L1 空间术语理解 → L2 空间关系识别 → L3 心理旋转与空间变换 → L4 空间规划与导航 → L5 空间-语言整合
- 8种语言、5000+ 测试样本
- 评估 20+ LLMs（GPT-4o、Claude 3.5、Gemini 2.0 等）

## Experiment
- 所有 LLM 在 L3（心理旋转）出现断崖式下降，跨语言普遍存在
- GPT-4o 总体最优但 L3 仍低于 60%
- 发现语言间一致性高：空间推理瓶颈与语言无关

## Value
作为 NLP 评估工作有参考价值，揭示了 LLM 空间推理的系统性弱点。但属于纯 benchmark 论文，与视频/3D 世界模型研究无直接关联。

## Strengths
亮点是作为 NLP 评估工作有参考价值，揭示了 LLM 空间推理的系统性弱点。
