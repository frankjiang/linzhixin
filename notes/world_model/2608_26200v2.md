# GameWAM: A World Action Model for Video Games

## Insight
- **训练需要预测未来，不代表执行时需要生成未来视频。** 默认模型让视频与动作共享已观测历史的特征，但不互读当前带噪未来变量；相较直接耦合两模态，控制成功率和速度反而更好。消融支持视频监督有用，但未证明收益具体来自哪种动力学知识。
- **生成噪声可成为持续控制偏置。** 作者观察到复用同一动作噪声会让相机反复原地转动，提出 LASI：噪声的低频分量系统性传入动作。固定条件后替换、置零噪声的 DCT 0–2阶分量，能改变相应相机运动，提供干预证据；单次前向已有该效应，迭代去噪进一步放大。它不是完整机理解释，也不能把一切采样多样性都视为错误。

## Motivation
游戏策略通常只预测动作，交互世界模型则需外部提供动作；WAM 尝试联合学习视频未来与行为。游戏还存在相机/GUI鼠标语义冲突、快速视觉变化及跨多次重规划的记忆需求。这些是视频世界模型走向闭环控制的实际问题，但本工作定位仍是低层控制器。

## Method
- 数据：同步 VPT 视频、状态与22维键鼠动作；围绕采矿、交互等事件构建20万段轨迹并密集采样事件邻域，另加入脚本 GUI 示范。Minecraft 训练采样比例为事件80%、常规5%、GUI 15%；ViZDoom 使用 APPO 专家轨迹和9维动作。
- Wan2.2-5B Video DiT 配1B Action DiT，以流匹配训练视频、连续/二值动作；二值坐标也连续生成，再阈值化。每个动作步的路由器选择 gameplay/GUI 预测头，连续量分别归一化。输入除画面、指令，还包括视角、光标或生命值等环境状态。
- 默认沿用 Fast-WAM 式模态解耦掩码：两分支只共享干净视觉前缀的逐层 KV，不交换当前带噪未来。**在线仍编码已观测画面，但省去未来视频去噪，只采样动作。** 因而并非运行时搜索想象视频的规划器。
- 每次预测16动作、执行8动作，再基于实际反馈重规划；3个执行块构成一周期。周期内保留 KV，跨周期用 Conv3D 保存最近两段、门控注意力压缩更早历史，最多40个记忆 token；辅助目标使历史预测当前视觉特征。
- 总损失含视频/动作流匹配、模式分类和历史预测。推理10步去噪，每次重规划重新采样噪声，缓解 LASI 的持续累积；骨干、流匹配、短执行及模态解耦均有前作基础。

## Experiment
- 阅读范围：PDF 全44页，含附录 A–E，并核看奖励图及 GUI 纠错序列。
- MCU 超800任务：完整集每任务5次，Mini 30任务每任务10次。平均成功率 **46.6% / 50.7%**，同数据复现 Fast-WAM 为 **25.2% / 40.0%**；Game-TARS 完整集42.5%。优势主要来自 GUI，完整集 GUI **60.0% vs 39.1%**，但具身/战斗47.5%/32.2%仍低于 Game-TARS 的50.4%/38.1%。
- 具身/GUI/战斗的成功轨迹平均执行步数 **138/155/203**，Fast-WAM 为165/234/261。该指标仅统计成功样本，不是所有回合的平均成本；表中标准差是跨任务差异，不能解释为训练种子置信区间。
- 消融 Mini 成功率：完整50.7%，去视频监督35.7%，降低视觉采样密度36.7%，去事件采样38.0%，统一动作分布38.3%，预测/执行等长41.3%，去跨周期历史46.7%。其中去历史后具身项反而70%→75%，收益有任务依赖。
- 直接耦合视频/动作的变体完整集39.6%、单 H200 **8.12Hz**；默认解耦46.6%、**12.51Hz**。计时排除环境仿真和执行，不等同完整系统响应频率。视频质量主要定性检查，没有独立预测保真度指标。
- ViZDoom 四图各50回合，平均奖励为 **43.12/19.02/23.52/15.36**，均高于图中 Game-TARS。Minecraft 模型无微调迁移到相近的 VoxeLibre，6种基础任务 **71/120成功**，但不含 GUI 或更广泛跨游戏验证。
- LASI 使用24固定条件×16噪声样本：yaw-DCT0 相关系数 **0.890**，低频替换后输出跟随 donor 的比例 **94.8%**，置零去除 **99.25%** 的源噪声引起的方差。另有300条闭环轨迹支持噪声/动作对齐；成功演示包含 GUI 放置错误后的纠正。

## Value
最值得借鉴的是用控制消融区分“预测训练的价值”和“在线想象的价值”，以及将随机种子细化到频域做策略诊断。可将 LASI 检查迁移到视频条件动作模型：固定观测，替换特定噪声频段，再检查闭环累积，而不只比较平均成功率。

## Strengths
- 世界模型监督、时间采样、动作模式和记忆均有闭环消融，并提供同数据 WAM 基线。
- LASI 从失败观察推进到固定条件干预、频率对照和闭环统计，证据链比单纯相关性充分。
- 区分已执行历史与未执行预测，避免将想象状态误当真实反馈；附录明确多项结论边界。

## Weaknesses
- 方法主体是已有 WAM 与游戏接口、数据处理的组合；未验证可靠的反事实动作条件预测或物理世界迁移。
- 除 Fast-WAM 外，多数基线来自各自报告，数据、状态输入与训练设置不同；2.79B训练 token 的比较也不等于计算量优势。
- 基准多为原子任务，长期规划、配方推理和记忆检索能力有限；预测16动作的“看得远”是相对8动作执行块而言。
- LASI 定量诊断集中于一个最终检查点和连续相机控制；噪声重采样只是缓解。训练期抑制尝试存在控制性能取舍，未提供可靠根治方法。

## Future Work
作者建议接入高层规划和结构化流程知识，引入任务/动作感知记忆、检索监督和跨周期信用分配，构建更长的连贯交互数据；进一步解释模态耦合的优化干扰，并抑制 LASI 而保留正常平滑动作与合理多样性。

## Rating
创新度评分：3/5 - 游戏 WAM 的系统组合和闭环验证扎实，LASI 诊断有启发，但主体继承既有框架，故障机制与解决方案尚不完整。
相关度评分：3/3 (Core) - 直接研究视频预测与动作生成联合训练、闭环控制和长时记忆，核心相关于视频世界模型。

## TL;DR
以视频预测监督游戏动作策略，并揭示低频生成噪声引发控制偏置，训练与推理解耦及故障诊断值得精读。
