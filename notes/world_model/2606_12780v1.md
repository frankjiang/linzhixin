# ProPlay: Procedural World Models for Self-Evolving LLM Agents

## Insight
论文 insight 是 LLM agent 的“世界模型”不应是低层 action rule，而应是 procedure graph：节点为可复用任务阶段，边为观察到的过程转移，并用 reliability record 记录在相似任务中是否稳定带来成功。

## Motivation
解决 LLM agent 在多 episode 交互中如何积累和使用环境经验。Memory 方法存反思/规则，planning 方法搜未来动作，但两者未形成统一环境动力学模型；action-level world model 又过于局部。该问题属于 LLM agent，不属于视频/3D/JEPA 世界模型。

## Method
ProPlay 维护有向 procedure graph G=(P,E,C)。每条 procedure transition 的 reliability record 是历史成功任务描述 embedding 的加权和。每个 episode 前，LLM 根据当前任务描述、procedure graph、相似失败经验构造 procedure trajectory preplay plan，作为软提示而非硬约束。执行后，从成功前缀归纳新 procedures/edges，失败后缀存为 failure experience，并更新 reliability。

## Experiment
评估 ScienceWorld 270 tasks、tau-Bench retail/airline、PlanCraft 187 tasks，backbone GPT-4.1-mini。对比 ReAct、Reflexion、ExpeL、LATS、Wall-E、WorldCoder。ProPlay 平均排名 1.6；ScienceWorld SR/Avg Score 37.4/70.2，优于 ExpeL 36.3/67.9、Reflexion 32.2/65.0；tau-Bench overall 85.5；PlanCraft overall 44.4。消融显示随机/检索替代 preplay、硬约束、去 graph/transition/reliability 或 action-level world model 都会退化。

## Value
如果研究 LLM agent memory/planning 有参考价值；对用户关注的视频、3D、隐式世界模型几乎无直接技术价值。这里的 world model 是程序知识图谱，不是可学习环境 dynamics 或视觉世界模型。
