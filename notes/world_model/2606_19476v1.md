# Can In-Context Learning Support Intrinsic Curiosity?

## Insight
Observation：经典 intrinsic curiosity 要奖励“新数据让世界模型学到了多少”，但通常需要在轨迹内反复更新 world model，计算代价高。

推论：如果 in-context learner 可作为 amortized Bayesian world predictor，就能用 prediction error 和 context masking 近似某些 curiosity reward；但在一般 MDP 中，有限 horizon 下这些 reward 不能无偏识别 Bayesian information gain。只有在 Bayesian Experimental Design 等非时间/结构受限设定中，特定 reward 才能渐近逼近 BIG。

## Motivation
论文解决自动数据采集/探索：如何不用内循环梯度更新，快速计算 intrinsic reward。

同行包括 surprisal、learning progress、Bayesian information gain、NDIGO 等。核心难点是 BIG 难算，learning progress 需要在线更新模型，而 surprisal 会被 noisy-TV 误导。

## Method
把 frozen sequence model `ρ` 形式化为 Bayes posterior predictive。

研究 reward：
- `r_sur = -log ρ(s_t|h_t)`：预测惊讶度。
- `r_dl`：description-length/learning-progress 类 reward。
- `r_sum`：论文提出的对未来轨迹的 masked-context log-likelihood 差求和，衡量当前观察对未来预测的贡献。

理论：
- 一般 BAMDP 中，prediction-based reward 对 BIG 有不可消除的 nuisance bias；经典 learning progress 还不能直接由 ICL prediction error 实现。
- BED 设置中，`r_sum` 和 `r_dl` 可 bound 并渐近收敛到 BIG。

## Experiment
实验覆盖 Gaussian Process、Mastermind、Alchemy。

结果：
- GP 中 surprisal 会偏向 aleatoric noise，验证 noisy-TV 问题；`r_sum`/`r_dl` 更接近 BIG。
- Mastermind/Alchemy 标准设置下多种 reward 都能表现较好；在含无效动作/噪声的设置中，`r_sum`/`r_dl` 更稳。
- 训练 PFN/ICL predictor 与 oracle Bayesian predictor 的结果接近，说明 ICL reward 计算有实际可行性。

## Value
对世界模型方向的价值是理论性的：如果想让大序列模型成为“无需梯度更新的探索评估器”，必须注意一般 MDP 中的偏差边界。它更适合主动学习/实验设计，而不是视频/3D世界模型本身。

局限：主要实验是 toy/符号/低维环境；reward 在连续在线控制中仍可能计算昂贵；对大规模视觉世界模型没有直接验证。

## Strengths
亮点是它更适合主动学习/实验设计，而不是视频/3D世界模型本身。
