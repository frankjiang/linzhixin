# WorldSample: Closed-loop Real-robot RL with World Modelling

## Insight
主要 insight 是不要把 world model 当成完全离线的想象环境，而应放进真实机器人 RL 的闭环中持续校准。Observation 是纯真实 RL 样本昂贵，纯模型 rollout 又会因分布偏移和虚假高价值样本误导策略。作者的推论是：从真实动作附近采样局部反事实轨迹、用持续更新的世界模型生成观测，再用不确定性和 Q 值筛选样本，可以把 synthetic experience 控制在“有用但不失真”的范围。

## Motivation
论文解决真实机器人 RL 的样本效率问题。同行包括 imitation learning、human-in-the-loop RL、世界模型策略优化等；IL 受演示覆盖限制，在线 RL 真实交互代价高，直接用生成模型 rollout 容易幻觉。该问题对 embodied world model 重要，因为世界模型若不能减少真实试错，就很难证明其控制价值。

## Method
WorldSample 从真实 rollout 中截取 action trajectory segment，在真实动作附近生成局部 counterfactual actions；动作条件世界模型基于 Cosmos-Predict2.5 生成对应未来观测，reward model 打标签。随着真实 rollout 增加，持续 post-train 世界模型。PPL 模块包含 Q-aware sample selection 和 uncertainty-guided scheduling：高价值样本优先进入训练，策略不确定时增加合成比例，避免过早被模型偏差主导。生成过程异步，不阻塞真实采样。

## Experiment
在 Galaxea A1X 上评估 Pushing、Insertion、Sorting、Pick&Place、Assemble，初始化仅 20 条演示。对比 VLAW、WMPO、HIL-SERL。主表中 WorldSample 平均成功率 82%，平均真实步数 23K、时间 64 分钟；HIL-SERL 为 56%、56K、83 分钟；WMPO 成功率 69%但训练时间约 547 分钟。世界模型适配实验显示 Demo+Rollout+双视角可达 PSNR 29.89、SSIM 0.925。Insertion 消融中，完整 PPL 成功率 95%，去掉 scheduling 降到 61%，去掉 Q-selection 降到 76%。

## Value
价值在于把视频/观测世界模型真正接到真实机器人闭环 RL 中，而不是只展示预测视频。对我们有启发的是：世界模型采样必须局部、异步、带风险调度，并且需要随真实数据在线校准。

## Strengths
真实机器人实验覆盖多个任务；闭环数据更新、反事实采样和样本调度形成完整系统；用效率、成功率、世界模型预测质量和消融共同支撑结论。

## Weaknesses
世界模型结构本身创新有限，贡献更偏系统整合；任务和场景分布仍较固定；reward model 和世界模型偏差在更开放场景下可能放大。

## Future Work
作者提出未来要增强 instance、task 和 scene generalization，验证在更宽场景分布中的闭环稳定性。

## Rating
创新度评分：3/5 - 闭环真实机器人 RL 系统设计扎实，但核心模型方法更多是有效组合和调度。
相关度评分：3/3 (Core) - 直接使用世界模型提升机器人控制和真实交互效率，核心相关。

## TL;DR
用在线校准世界模型生成局部反事实样本，大幅提效真实机器人 RL，值得精读。
