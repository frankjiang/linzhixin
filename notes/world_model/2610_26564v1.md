# PrismWAM: Decoupling State Representations in World Action Models

## Insight
观察：把外观、物理状态和动作全压在视频潜变量中，容易让动作头依赖颜色等非物理线索。作者推论应由 RGB 表示目标语义，深度序列承载几何演化，再从深度生成动作；去深度消融中 RoboTwin 随机环境成功率由 54.1% 降至 2.4%，支持几何通道重要，但不等于证明其已学到真实物理因果。

## Motivation
既有 WAM 往往直接共享预训练视频特征来预测世界与动作，表观变化和可执行运动纠缠。操作任务真正需要能随动作演化的物理状态；跨外观扰动时尤为关键。

## Method
以共享视频主干加分支实现“语义规划→深度推演→可执行动作”：RGB 分支受最终目标帧监督，推理时复用观察 RGB 特征；深度分支在 RGB 引导下逐帧生成未来深度；动作分支读取未来深度特征联合去噪。通过定向链式注意力限制捷径，三路使用 flow matching 损失。先用约 2300 小时数据预训深度 VAE，再做深度适配和联合训练；主模型约 6B，另有约 15B 扩展版。推理仍需要当前深度，不能理解为仅凭初始 RGB。

## Experiment
RoboTwin C2R 主模型干净/随机成功率 87.98/53.16%，均值 70.57%，FastWAM 均值 39.85%、OpenWAM-α 69.05%；扩展版均值 83.67%。RoboDojo 主/扩展版成功率 18.55/29.30%，但扩展版开放类别仅 4.42%。LIBERO/Plus/Pro 主模型 99.35/79.44/54.48%，Pro 低于 π0.5 的 57.16%。真实三任务 ID 24/27、OOD 24/35，OpenWAM 为 20/27、17/35。RoboTwin 消融：完整模型 87.4/54.1，去 RGB 79.1/40.1，去深度 83.0/2.4，RGB 直接到动作 89.1/40.3，去深度预适配 89.3/24.7。真实对比使用的动作参数化不同；深度损坏鲁棒性实验训练和测试均加入对应损坏。

## Value
将任务语义和几何运动拆开，为 3D/视频 WAM 的状态设计提供直接参考；深度消融说明几何中间变量对外观随机化有帮助。未来可比较占据、光流、触觉和本体感知等状态通道。

## Strengths
管线与信息流设计明确；跨仿真、真实机器人及外观扰动验证；多项消融检验各通道作用。

## Weaknesses
依赖推理时深度和大规模深度 VAE 预训练；深度无法可靠表达遮挡背后几何或接触力。RoboDojo 开放类别很弱，真实实验样本少，动作参数化不一致削弱基线比较。

## Future Work
作者建议拓展物理状态为占据、光流、触觉及本体感知；尚需检验跨场景几何泛化和更可靠的接触建模。

## Rating
创新度评分：4/5 - 以深度推演隔离语义和可执行动作，结构有明确新意且随机化收益明显，但组件基于现有生成主干。
相关度评分：3/3 (Core) - 直接研究三维几何中介的视频世界动作模型。

## TL;DR
以目标语义、深度推演和动作生成分路构建世界动作模型，外观扰动收益明显，值得精读。
