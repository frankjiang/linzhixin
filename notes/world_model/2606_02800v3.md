# Cosmos 3: Omnimodal World Models for Physical AI

## Insight
Cosmos 3 的核心 insight 是把 understanding 与 generation、language/image/video/audio/action 统一到一个 omnimodal world model 中：reasoning 需要未来模拟，generation 需要结构化世界表征，动作 token 则把物理控制接入同一 token 空间。

## Motivation
Physical AI 目前常拼接 VLM、视频生成器、forward dynamics、inverse dynamics、VLA/WAM，接口碎片化且训练信号割裂。Cosmos 3 试图提供一个可 post-train 到合成数据、策略、环境生成等任务的通用 backbone。

## Method
架构是 Mixture-of-Transformers 双塔：AR reasoner tower 处理语言/理解 token，DM generator tower 处理连续视觉/音频/动作 diffusion token；两者有独立 LayerNorm/MLP/投影，但通过 joint attention 让 diffusion token attend AR context，AR 保持 causal。使用 3D MRoPE 的绝对时间调制对齐 video/audio/action；视觉、音频、动作各有编码器。训练包括 reasoner/generator 数据 curriculum、action data、synthetic data generation、post-training 到 T2I/I2V/policy/forward/inverse dynamics。报告还包含大规模 data/training/serving/eval infrastructure。

## Experiment
总览显示 Cosmos3-Super/Nano 在 Physical AI 多项任务超过开源专用模型。T2I：Cosmos3-Super-Text2Image UniGenBench 91.36，开源第一。视频：PAIBench-G T2V/I2V Super 80.0/82.8，开源最佳；RBench Nano 58.4。Physics-IQ：Super I2V 43.8，WMReward+BoN 48.9；V2V 59.7，BoN 63.4，均 SOTA。HUE/HWB 人评中 Super T2V 89.3、I2V 89.6、HWB 71.9，开源领先。动作/机器人部分显示同一 foundation model 可适配 camera/AV/egocentric/robot FD、ID、policy，action co-training 有迁移收益。

## Value
极高相关，但更像平台级技术报告。对研究的启发是：未来 world model 可能不是单纯视频预测，而是 reasoner-generator-action 的统一接口；action co-training 与绝对时间位置编码值得重点关注。局限是体系庞大、很多评估依赖内部 benchmark/人评/VLM judge，消融分散，普通实验室难复现。
