# Qantara: Bridge-Flow Training for Multi-Paradigm JEPA Control

## Insight
论文观察到同一个 latent world-action model 如果训练目标设计得当，可以同时支持 planning、behavior cloning 和 video-inverse 三种推理范式。关键不是把三种模型拼起来，而是在 state transition 和 action generation 之间建立统一的 bridge-flow。

## Motivation
JEPA 控制模型常被固定为某一种用法：要么做 latent planning，要么做 inverse dynamics，要么做 policy imitation。这样导致训练和部署范式割裂，也难以比较不同推理方式。Qantara 试图让一个 checkpoint 覆盖多范式控制。

## Method
Qantara 使用 joint bridge-flow objective：状态轴用 Brownian-bridge interpolant 连接相邻干净 latent，动作轴用 noise-to-data flow matching 生成 action。训练时在 noise square 的四条边和对角线采样，形成 edge-aligned 的 `(tau_a,tau_z)` 训练，并用对角 co-regularization 对齐范式。state head 使用 residual zero-init，保证早期训练稳定。

## Experiment
实验在 LeWM suite，包括 Two-Room、Push-T、OGBench-Cube、Reacher。作为 planner 平均成功率 91.2，Cube 93.7，超过 DINO-WM 和 LeWM。一个 checkpoint 还能在 Push-T/Cube 上以 BC 或 video-inverse 模式取得可用成功率，计算成本比 planner 低 15-65 倍。消融显示 uniform sampling 会显著伤害 CEM 和 video-inverse；去掉 residual state head 后 Push-T 表现大幅下降。

## Value
这篇对隐式世界模型控制很有价值：它把“预测未来”和“生成动作”放在统一 flow 空间里，避免为不同控制范式重复训练模型。

## Strengths
目标函数设计简洁；同一模型跨范式验证充分；消融直接指向关键训练细节。

## Weaknesses
主要是仿真和近专家离线数据；模型规模仅约 21M，尚未证明可扩展到真实视频/机器人 foundation model；每步一个 block 的结构对长时复杂任务仍有限。

## Future Work
未来应验证真实机器人和大规模自然视频预训练，并探索更长 horizon 的 latent rollout 与不确定性建模。

## Rating
