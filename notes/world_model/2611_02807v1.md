# Creating Hybrid Interactive Narrative Systems with LLM: From Formal Description to Evaluation

## Insight
观察：不同交互叙事管理器绑定各自故事，难以比较。推论：让它们共享符号状态、操作前置条件与效果，便可把每次会话当作状态转移路径，用统一指标比较。作者在单一“小红帽”场景的模拟玩家实验中展示三个管理器各有取舍。

## Motivation
交互故事需要同时容纳玩家自由行动与作者预设剧情；LLM 扩展了可生成动作，却使管理决策难以检查。已有架构框架偏重模块互操作，缺少跨管理器的行为评测尺度。问题属于交互叙事与 LLM 智能体，不涉及视频/3D 世界建模。

## Method
将世界表示为主体-谓词-客体事实集，操作带前置条件、增删效果；玩家文本经 LLM 匹配已有操作或动态生成操作。比较三种经验管理器：开放生成；仅在无可用操作时调用 MCTS 搜索修复事件序列；NPC 多智能体每回合自主发起事件。把会话映射为状态转移路径，以玩家能动性、管理器控制、作者意图和鲁棒性四类指标评价。核心是共享符号接口和评测设计，非视觉预测模型。

## Experiment
同一小红帽场景，GPT-5 mini 模拟玩家，每种管理器 100 次会话。MCTS 相比开放生成把完成率从 0.52 提至 0.80、鲁棒性从 0.58 提至 0.76，但玩家能动性从 0.44 降至 0.27；多 NPC 管理器能动性 0.68、控制性 0.52，作者意图仅 0.04。无真人参与或跨故事测试；指标来自系统记录，未检验与人的体验是否一致。

## Value
对符号智能体评测可参考统一状态转移日志和多维取舍指标；对视频、3D 或 JEPA/Dreamer 世界模型没有直接方法或实验价值。

## Strengths
三个异构管理器在同一场景、同一状态接口下比较；操作的前置条件与效果可检查，指标计算透明。

## Weaknesses
单一故事、LLM 模拟玩家，泛化和主观体验效度未知；玩家能动性只看动作接受率，未衡量真实状态影响；动态生成操作质量和搜索成本缺少充分分析。

## Future Work
加入真人玩家与多种故事，细化指标并扩充管理器；利用共享状态在不同回合动态切换管理器。

## Rating
创新度评分：1/5 - 面向叙事系统的符号接口和评测组合，对目标世界模型方向无新技术贡献。
相关度评分：0/3 (Noise) - 文中“世界模型”是文本故事事实状态，不是视频、3D 或隐式物理环境模型。

## TL;DR
用符号故事状态统一比较三种 LLM 叙事管理器；与视频和 3D 世界模型无实质联系，可跳过。
