# Diagnosing JEPA World Models with Action-Conditioned Predictive Consistency

## Insight

JEPA 在像素上不重建噪声，并不自动意味着视觉不变性；关键是扰动后的表示在相同动作下滚动后是否仍具有相同后果。ACPC 用 clean/perturbed history 在同一 action sequence 下的多步 rollout 距离衡量这一点。仅追求小距离又会奖励 representation collapse，因此 checkpoint 级诊断必须同时满足低 Invariance Radius（同状态两视图接近）和高 Separation Rate（不同任务状态仍分离）。实验中无 SIGReg 的坍塌模型 raw IR 最低 0.048，却 SR=0.066、成功率 33.3%，验证了双指标必要性。

## Motivation

encoder distance 或 one-step prediction 无法显示视觉扰动如何被 action-conditioned dynamics 放大/收缩，也难判断 robustness 是否以丢失控制相关状态为代价。Bisimulation 要求等价状态在相同动作下后果一致，但现有 JEPA world model 缺少冻结后、无需重训的 rollout-level 诊断。该问题直接关系到 LeWM/PLDM/Dreamer 类隐式模型的 checkpoint 选择与鲁棒规划。

## Method

给 clean history h、扰动 h̃ 和相同动作 a_0:H−1，分别编码并由冻结 predictor 自回归；ACPC 是投影 latent 中 H 个预测态的加权拼接距离，默认 H=8、均匀权重，CEM 分析用 H=5。由 reverse triangle inequality，ACPC sample-wise 上界两条 rollout 相对同一真实未来的 prediction-error 差。对 squared latent goal cost，终态位移还给出 candidate cost-change bound；若 clean winner 与所有竞争者 cost gap 大于相应两项 bound，winner/elite set 不变。

checkpoint 级 IR 用 100 个 anchor、每个 5 次扰动，将 ACPC 除以该 history 的典型 clean one-step motion，再取 anchor 均值的 q90。SR 为附近不同 endpoint-state label 的 history 在相同 anchor action 下滚动后，距离超过 raw IR+0.10 的比例。跨 checkpoint 用相对未增强 reference 的 IR；screen 要求 IRrel≤tIR 且 SR≥tSR，并取两个 threshold margin 的较小值。

## Experiment

- LeWM 与 PLDM，各在 TwoRoom、PushT、Reacher、OGBench-Cube 上训练无增强+8 个 Gaussian-noise 强度，每条件 3 个独立训练 seed；planning 每 checkpoint 用 3 evaluation seed×100 episode，CEM horizon=5。另测 blur k=15 与 resize 0.25。
- LeWM 从无增强到最佳增强时，噪声下成功率 TwoRoom 68.8→97.1、PushT 7.2→86.8、Reacher 18.2→83.3、Cube 43.1→66.0；对应 IRrel 大幅降到 0.03–0.26，SR 从 0.07–0.37 升至 0.98–1.00。
- 对 unaugmented checkpoint，跨 trajectory group ridge 预测 perturbation-induced error drift：加入 recorded-action ACPC8 相比 encoder distance+ACPC1 的 MAE 下降 55.9±4.7%，相比从 zero/swap/shuffle 中为每 cell 挑最优的同 horizon control 仍下降 51.3±3.5%，12/12 task-run cell 最优。
- 在 paired adaptive CEM 中，加入 five-step candidate ACPC q90 后，对 clean-model selection regret 的跨任务预测 MAE 降 15.2±2.0%，12/12 case 改善；但目标只是模型 cost，不是环境 return，也未用 ACPC 改 planner。
- 用其他任务选 threshold 时，主规则 IR≤0.3、SR≥0.95；两/三 source task 的 test balanced accuracy 0.900、precision/recall 0.913/0.953，恢复起点最多偏一个 augmentation grid。仅 Reacher 选阈值时 BA 0.723，最多晚 5 level。
- PLDM 重现低 IR/高 SR 与噪声成功率同步的定性趋势。blur/resize 的 24 对 checkpoint 中 22 对 joint score 符合预设 recovery criterion，score change 与成功增益 Spearman ρ=0.835；两例都是 +4pp 而阈值要求 +5pp 的边界。

## Value

ACPC 把“JEPA 是否忽略视觉 nuisance”从静态表示问题改成 action-conditioned downstream consequence 问题，且把 invariance 与 state separation 显式配对。对我们很实用：可在不跑完整 planner 的情况下筛 checkpoint，也能定位 encoder-only 指标遗漏的多步敏感性。理论上界很基本但让适用边界清楚；真正下一步是让 ACPC 参与训练/规划，而不只是相关诊断。

## Strengths

- clean/perturbed 使用同一动作，能隔离视觉扰动经 dynamics 传播的影响；destroyed-action controls 进一步验证动作信息。
- IR+SR 设计能明确排除 collapse，并用 SIGReg 权重消融做实证。
- 四任务、两个架构、三训练 seed、三类视觉 shift，覆盖比单一 JEPA case 更广。
- threshold 在 source task 选择、target task 测试，避免完全同数据调阈值；附录公开 pairing、state labels、grid 与 protocol hash。
- 对 theorem 和 experiment 的边界表述克制：上界不等于准确性、fixed-pool certificate 不自动覆盖 adaptive CEM、selection regret 不是 return。

## Weaknesses

- Proposition 1 主要是 reverse triangle inequality，Proposition 2 也是 squared-distance 代数界；理论新颖性有限且 bound 可能很松。
- IR 需要 unaugmented reference 和 observed future motion 作归一化；SR 需要 simulator/dataset state labels，难直接用于真实无标注视频。
- SR label 是任务坐标的中位数切分，未必等于 action/value-relevant bisimulation distinction；对 label 外的 collapse 无检测力。
- checkpoint recovery 主要来自与测试同类 Gaussian-noise augmentation，blur/resize 只各一个严重度、比较两个 checkpoint。
- 阈值 0.3 位于 tested grid 上界，边界尚未识别；Reacher-only transfer 失败说明跨任务普适性有限。
- ACPC 计算需对每个扰动/候选额外双 rollout；在大模型 CEM 中可能昂贵，论文未报告诊断成本。
- 尚未证明把 ACPC 用于 planner 或训练能提升任务成功，也不处理自然语义 distractor、遮挡或动力学 OOD。

## Future Work

作者提出直接测试 ACPC-guided planning，扩大扰动严重度、different-state pairs、robustness training 方法和其他 JEPA 架构。进一步可把 SR 的人工 state label 换成 value/reward/action disagreement，研究无 reference 的绝对校准、训练期 ACPC regularization，以及针对真实机器人自然扰动的成本–收益。
