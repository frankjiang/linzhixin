# 4D-WAM: Infusing Spatiotemporal Awareness into World Action Models through Trajectory Fields

## Insight

作者发现，WAM 的 DiT 中间特征与 4D foundation model 的绝对特征常为低相关甚至负相关，直接 feature matching 会引发优化冲突；但两者相邻帧特征差分的相似度明显更高，因为即使表示空间不同，也应描述同一底层运动。由此得到两层监督：用 token-wise temporal difference 对齐局部运动，用首帧到末帧的 token correspondence distribution 对齐长时目标。训练后移除 teacher 和 projector，仍能提升 OOD 控制与视频预测，说明轨迹级知识可通过表示变化而非绝对表示注入。

## Motivation

现有 World Action Model 联合预测视频和动作，却主要在 2D pixel/latent 中学习，而机器人动作发生在动态 3D 世界。已有 3D WAM 多逐帧预测 depth/normal/point map，容易关注低层重建且未显式表达连续 3D 演化；另一些方法增加专用模态、头部和推理成本。论文目标是用训练期辅助监督、零推理开销的方式给现有 WAM 注入 4D 轨迹意识。

## Method

以冻结的 Trace Anything 从训练视频提取 3D trajectory-field token，选取 WAM DiT 第 20 层视觉 token，并用两个两层 MLP 投到共同维度；teacher 投影支路冻结。

- Motion Alignment：对每个空间 token 先归一化，再计算相邻帧 projected feature difference，以 cosine distance 对齐 WAM 与 teacher 的运动方向，避免强迫绝对特征一致。
- Destination Alignment：以第一帧 token 为 query、末帧 teacher token 为 destination，构造 source-to-destination similarity distribution；用 KL 让 student-source 分布匹配 teacher 分布，提供 episode-level 目标对应。
- 总损失为原 WAM 的 latent denoising + action prediction，再加两项小权重（均建议 <0.1）的 alignment loss。Trace Anything 特征可离线缓存，训练后 teacher、projector 和辅助 loss 全部删除。

该 recipe 分别接到 FastWAM-Joint 与 Lingbot-VA，强调模型无关性。

## Experiment

- ID：RoboTwin 2.0 共 50 tasks（每 task 500 random + 50 clean demonstrations），LIBERO 40 tasks（每 task 100 demonstrations）。相对 FastWAM-Joint，RoboTwin clean/random 平均由 90.58% 升至 91.34%，LIBERO 由 98.2% 升至 98.6%，提升较小。
- OOD LIBERO-Plus：七类 camera/robot/language/light/background/noise/layout 扰动平均成功率由 62.21% 升至 71.01%，camera 增益 17.26 points；每类均提升。
- OOD RoboTwin Clean2Rand：在 Lingbot-VA 上 clean/random 为 80.7/34.6，4D-WAM 提升到 81.5/41.8，平均 57.7→61.7。
- 视频预测：LIBERO-Plus 100 episodes/perturbation，PSNR 19.22→21.44，SSIM 0.75→0.83；可视化显示动态物体、遮挡后的门和目标位置更连贯。
- 消融：仅 motion 或仅 destination 都从完整模型 98.6% 降到 98.0%；第 20/22 层较好，但差距很小。Frozen representation probe 在 LIBERO/Plus 的 frame-to-frame 和 destination token 位置预测上均有一致但有限提升。
- 真实机器人：4 个长时任务、共 550 demonstrations，每任务 50 trials。平均 progress 20.3→31.8，但完整成功率仅 1.0%→5.5%；单项成功率最高为 toolbox wrench localization 的 12%。
- 成本：离线缓存 teacher feature 时，训练 step 7.3→7.5 秒，8-GPU 训练 51→52 小时，显存 77.3%→82.7%，增加 56 MiB 参数；推理零额外参数/时延。在线提取则需 59 GPU-hours、96% 显存。

## Value

该工作提供一种实用的 4D distillation 方式：不要求 WAM 输出显式几何，也不增加部署成本，且 OOD 提升明显。对视频/3D 世界模型的启发是：跨模型 absolute latent 不可比时，可对齐时间导数、关系分布或轨迹结构；局部 motion 与全局 destination 应同时约束。不过证据更能支持“轨迹 teacher 提升鲁棒性”，尚不足以证明模型获得通用 4D 物理理解。

## Strengths

- 先诊断直接绝对特征对齐失败，再据此设计 temporal-difference alignment，方法动机连贯。
- 同时提供局部运动和长时目的地监督，且可插入两类不同 WAM backbone。
- OOD、视频预测、线性 probe、组件/层位消融和真实机器人实验形成较完整证据链。
- teacher feature 可缓存，推理架构完全不变，工程代价低。
- OOD 增益远大于已饱和的 ID 增益，符合方法目标。

## Weaknesses

- 本质是用强 4D teacher 做辅助蒸馏，创新建立在已有 representation alignment 与 Trace Anything 上，未提出新的生成动力学架构。
- ID 提升只有 0.4–0.8 point 左右，LIBERO 已严重饱和；layer/objective 消融差异也很小。
- 真实机器人完整成功率只有 5.5%，绝对可用性仍弱；部分任务无改善或略降（rotating light progress 25.0→23.8）。
- OOD 两个 benchmark 使用不同 backbone（FastWAM-Joint 与 Lingbot-VA），跨表比较不能完全归因于同一基础模型。
- 缺少与同训练预算、同 backbone 的显式 3D/4D WAM 方法直接对照，难判断辅助对齐是否优于 depth/point reconstruction。
- PSNR/SSIM 只测视觉相似度，不能验证 3D geometry、contact dynamics 或物理一致性；probe 目标本身来自同一 teacher，存在循环验证倾向。
- destination loss 依赖完整未来视频，适合离线示范训练；对无对齐视频、稀疏观测或多模态目标的扩展未讨论。

## Future Work

作者未明确单列未来方向。值得继续研究：teacher-free 或在线自举的 trajectory representation；显式几何/接触与多模态未来评估；更难、未饱和的真实机器人长时任务；与 3D reconstruction/point trajectory baseline 的同骨架比较；以及处理相机运动、遮挡、非刚体和多对象交互的 correspondence uncertainty。

## Rating

创新度评分：3/5 - 将时间差分与首末帧目标分布用于 4D teacher 对齐，设计合理、OOD 效果好，但属于表示蒸馏的增量创新。
相关度评分：3/3 (Core) - 直接研究视频世界动作模型、4D 轨迹表示、机器人控制与视频预测。

## TL;DR

用轨迹场对齐局部运动与长时目标，低成本增强WAM的4D与OOD能力，值得精读。
