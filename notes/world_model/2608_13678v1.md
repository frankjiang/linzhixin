# hint²: Hierarchical World Models for Inference-Time Temporal Logic Guidance

## Insight

观察：现代 diffusion policy 每次只生成短 action chunk，而 LTL 是否满足取决于长时、非 Markov 历史；用低层 world model 展开完整任务会累积误差，只在短 horizon 算 STL robustness 又退化成局部安全过滤。推论：长时活性与局部安全应在不同抽象/时间尺度处理。hint² 用高层模型预测动作导致的原子命题转移，让 LTL automaton 跟踪长时进度；低层 dynamics 只预测近期连续状态，以 robustness 梯度处理几何安全。

论文进一步证明：若公式对环境可达 label 满足 stutter invariance，连续重复同一 label 的持续时间不影响 automaton 状态，因此只预测未来“不同 label segment”即可精确传播 automaton-state distribution。该证明支撑了慢变量抽象，但仍依赖命题独立假设与固定可达 label 集。

## Motivation

语言条件机器人策略难以组合训练中未出现的长时任务，也无法可靠接收部署时新增安全约束。现有 LTL-guided diffusion 多一次生成完整 state-action trajectory，受固定 horizon 和模型误差限制；goal image/3D point guidance 只能表达单目标。问题对基于 world model 的规划很关键：如何让短时行为 prior 在不重训策略的情况下满足运行时长时逻辑。

## Method

基策略为无条件、多模态 diffusion policy。LTL 公式转成 deterministic Büchi automaton（DBA），automaton state 提供最小任务历史；potential 由到接受状态的最短距离定义。

高层 `f_hi(s, a_{t:t+H})` 预测下一批原子命题概率，假设命题条件独立后构造各 automaton 转移矩阵，递推状态分布 `α_k`，最大化累计期望 potential 以偏向更早进展。低层 `f_lo(s,a)` 预测短时连续状态轨迹，对 LTL 的 safety 部分计算可微 robustness。二者对 action chunk 的梯度近似 `∇ log P(φ|s,q,a)`，用于 diffusion guidance；无安全约束时可对 32 个候选 chunk 直接按高层 potential 选择。

CALVIN 中高层模型是预测 horizon N=1 的 MLP，输入 robot/scene state、当前 label 和 8-step action；低层是 4 层宽 512 的单步 delta MLP。创新是用 specification-induced automaton abstraction 分拆两层 guidance，而非新视觉表征或生成式 world model。

## Experiment

- Toy Squares 使用同一单目标演示训练；TeLoGraF/LTLDoG 生成 64/128 步完整轨迹，hint² 每次只选 8 步。随 automaton distance 1→5，hint² 全部 100% 满足，基线随距离快速退化；复杂 unordered/branch/sequence/safety 组合也报告 100%。
- CALVIN-D 六小时 play data、8 个行为命题上，单行为选择平均成功率约 91%，优于 DynaGuide、ITPS 和无引导策略。
- 复杂 selection/unordered/conditional/chained/branched/cyclic 与三类 safety 任务上接近满分；闭环 LLM planner 在活性任务可接近 hint²，但推理时间随 automaton distance 明显更高。FLOWER+GPC 只对候选安全打分，弱于通过梯度主动引导的 hint²。
- 真机 UR5e 用 130 条 Cheez-Its 操作示范，测试左右倾倒、区域/角度安全和两轮 cyclic；图中 hint² 均成功，cyclic 明确为 5 次运行 100%。样本数很小，其他柱状结果未给置信区间。

## Value

工作提供了一个有说服力的分层 world model 原则：高层预测慢变、任务相关的逻辑状态，低层只负责需要精确几何的短期动态。对 Dreamer/隐式 WM 的启发是让 planning state 由任务规格诱导，而不是要求单一 latent 同时承担长时语义和局部物理。后续关键是自动发现原子命题、从视觉而非低维真值建模、处理非 stutter-invariant/非确定 automata 和模型不确定性。

## Strengths

- 把 horizon mismatch 解释清楚，活性/安全分层与各自 world model 的尺度匹配自然。
- 对 stutter-invariant 情形给出正式定义、命题和证明，不只依赖经验直觉。
- 从 2D、CALVIN 到真机逐级验证，并与 LTL、goal-guidance、VLA/LLM planner 在各自适用场景比较。
- 推理时不改基策略，运行时可组合未在训练中完整出现的逻辑任务。

## Weaknesses

- 高低层模型都依赖低维真实 state 和人工命题/阈值，未证明从原始视觉学到可靠抽象。
- “精确”传播假设命题独立且公式相对环境 stutter-invariant；累计 potential 是软启发式，并不提供闭环满足保证。
- CALVIN 高层实际只预测一个未来 label，所谓层级长时能力主要由反复重规划和 automaton memory 提供。
- 复杂任务成功率缺少详细 trial 数、方差和强消融（高层-only、低层-only、模型误差敏感性）。
- 真机仅 130 demonstration、小规模展示；cyclic 只执行两轮，不代表真正无限时 LTL。

## Future Work

作者计划自动学习离散、慢变的高层特征，支持更一般 LTL（含非确定 automata），并扩展到 multi-agent。还应研究视觉 grounding、命题相关性、模型不确定性和形式化安全界限。

## Rating

创新度评分：3/5 - 以 automaton 诱导高层抽象并联合低层安全 guidance 的组合有明确新意和理论支撑，但依赖人工低维命题，实验规模与保证范围有限。
相关度评分：2/3 (Related) - 核心使用分层预测 world model 做闭环规划，对隐式模型有直接借鉴价值，但不是视频/3D/JEPA-Dreamer 主线模型。

## TL;DR

以高层逻辑模型管长时活性、低层动力学管安全，方法巧妙，值得精读。
