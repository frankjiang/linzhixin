# ACWM-RM: A Reference-Free Reward Model from Complementary Mismatch Preferences

## Insight
观察：逆动力学模型（IDM）在真实视频上能识别动作错配，却可能把生成视频的形变、穿模误判为动作信号。四种 IDM 在真实视频动作错配上的最高准确率为 86.1%，同一模型在生成视频错配上仅 70.0%。由此推断，奖励模型必须同时接触真实动作错配和生成视频质量差异；作者通过 AVM-Eval 与消融提供实证支持，没有理论保证。

## Motivation
动作条件机器人视频模型经 Flow-GRPO 微调时，需要给同一初帧、动作下的候选视频排序。现有全参考 PSNR/LPIPS 奖励依赖真实未来且不直接测动作遵循；IDM 奖励免参考，却只约束动作，且在生成视频上有分布偏移。两者兼顾直接决定模型能否用于可信的策略评估，是核心问题。

## Method
- 构造 AVM-Eval（6.72 万对）：真实视频固定画面、扰动动作来测动作忠实度；生成视频固定动作、按 nDTW 排序并过滤视觉质量差异，测生成域上的动作评分可靠性。
- 构造 AVM-Pref（50.63 万对）：15.63 万真实视频动作错配对提供动作监督；35 万生成视频错配对按相对真值的全局/运动区域 PSNR、LPIPS 一致排序，提供质量监督及生成域适应。**免参考只针对推理时打分，训练标签仍使用真实未来视频。**
- 冻结 V-JEPA 2.1 编码器，先用真实机器人片段预训练双臂动作条件潜特征预测器；再联合微调预测器与 patch 加权分数头，用 Bradley–Terry 损失学习成对偏好。打分时仅用候选视频自身历史、初始状态和动作积分状态，比较预测与编码的各 patch 特征，不用真实未来。最终奖励可直接用于 Flow-GRPO。
- 创新在于用互补偏好把前向动力学残差转为生成域可用的双目标奖励，属于有针对性的模型/数据设计，而非新的世界模型生成架构。

## Experiment
- AVM-Eval 比较四类 IDM 与本方法的成对准确率；本方法在真实动作错配/生成视频错配上达 **91.6%/88.6%**，最佳 IDM 为 **86.1%/70.0%**；跨具身/场景测试本方法 **66.5%**，最佳 IDM **61.6%**。
- 用 AgiBotWorld 的 AgiB 训练集与 AgiC 未见任务评测 DreamDojo-2B 的 Flow-GRPO。对比 IDM、全参考指标和 VLM 奖励，五个生成种子报告 PSNR/LPIPS/SSIM/MSE/FVD、轨迹 nDTW 和 VLM 评估的物理一致性。本方法 nDTW **14.84→16.41**、PSNR **23.13→24.34**、FVD **18.31→17.10**；IDM 奖励使 nDTW 降至 **13.21**。物理一致性综合分 **4.00→3.93**，基本保持但没有提升。
- 消融：仅动作对使生成视频准确率 **71.8%**，仅视频对 **77.3%**，合用 **88.6%**；随机初始化预测器为 **62.0%**，冻结预训练预测器为 **79.0%**，说明动力学预训练与生成域适应都有效。图示比较了不同奖励下的机器人视频质量。

## Value
对视频世界模型的后训练及评测很有借鉴意义：奖励先在**生成域**验证，再联合检查视觉质量和动作遵循；前向潜特征预测也可用来替代易受伪影干扰的逆动力学误差。待解决的是更可靠的物理一致性奖励、跨生成器迁移与真正闭环任务效用。

## Strengths
明确量化 IDM 的真实域—生成域落差；区分训练标签与推理免参考；覆盖异构 IDM、匹配训练样本量，并用同骨干 JEPA-IDM 排除单纯偏好数据带来的解释；消融较完整。

## Weaknesses
生成域 AF 标签依赖由真实轨迹计算的 2D nDTW，不能完整反映三维姿态、接触和任务成功；VQ 偏好仍依赖参考视频及 PSNR/LPIPS，可能继承像素指标偏差。RL 收益仅在 DreamDojo-2B/AgiBotWorld 验证；物理一致性依赖 VLM 裁判，未直接监督穿模；模型含大型冻结编码器，实际算力成本不低。

## Future Work
作者提出加入物理一致性监督，并在更多动作条件世界模型上测试该奖励用于 RL 优化的效果。

## Rating
创新度评分：3/5 - 互补错配偏好、生成域评测与前向特征评分的组合有明确新意，但建立在现有 JEPA、偏好学习和 Flow-GRPO 上。
相关度评分：3/3 (Core) - 直接改进动作条件视频世界模型的奖励与评测，且使用隐式动力学表示。

## TL;DR
用互补错配偏好训练免参考奖励模型，提升机器人视频世界模型的画质与动作忠实度，值得精读。
