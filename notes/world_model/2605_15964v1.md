# WorldVLN: Autoregressive World Action Model for Aerial Vision-Language Navigation

## Insight
将航空 VLN 形式化为预测驱动的 world-action 问题：agent 应预测潜在世界演化并根据预测后果行动。不同于全序列视频生成世界模型，WorldVLN 适配潜在自回归视频骨干预测短 horizon 世界状态转移，并直接解码为可执行 waypoint 动作。

## Motivation
航空 VLN 需要在 3D 环境中遵循自然语言指令的闭环感知和行动。现有 VLA 方法缺乏对世界演化的预测能力。

## Method
1. **Latent Autoregressive World-Action Model**: 基于潜在自回归视频骨干，预测短 horizon 世界状态转移并解码为 waypoint 动作
2. **闭环 world-action prediction**: 每段动作执行后，新观测编码回自回归上下文
3. **两阶段训练**: Stage 1 在指令条件化导航动态中 ground 视频先验；Stage 2 开发 Action-aware GRPO（首个面向自回归 WAM 的 RL 方法）
4. 支持零样本迁移到真实无人机部署

## Experiment
公开室外和室内 benchmark：成功率比 VLA 基线 +12%+，困难情况优势更大。零样本迁移至真实无人机。

## Value
将自回归视频模型适配为导航 world-action model 的思路有趣。Action-aware GRPO 是面向世界模型的 RL 训练方法创新。但应用场景（航空导航）与视频/3D 世界模型的核心方向有距离。

## Strengths
