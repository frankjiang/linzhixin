# TERRA: Task-Embedded Reasoning and Representation Architecture for Cross-Domain Applications

## Insight
Observation: I-JEPA、V-JEPA、V-JEPA 2-AC、DINO-WM 等 action-conditioned latent predictor 各自在单域内表现良好，但"同一个预训练 core 能跨域迁移"的直觉从未被理论或实验验证过。推论: 跨域迁移的强度受 lax bisimulation discrepancy 控制，且存在由 Gromov-Wasserstein 距离给出的不可逾越下界——当两域结构差异太大时，迁移无法带来收益。证明: 提出 Structured-State Transfer Hypothesis (SSTH)，给出 predictive transfer bound（Proposition 2）将误差分解为源模型拟合误差和结构不匹配项，并通过 Corollary 1 将 latent 预测误差映射到决策 regret。纯理论推导，无实验验证。

## Motivation
- **问题**: Latent world model（如 JEPA 系列）在驾驶、机器人、导航等单域任务中有效，但"跨域迁移"（如从驾驶场景迁移到金融订单簿预测）的可行性缺乏理论支撑。
- **同行做法**: DeepMDP、deep bisimulation 等工作研究单域内的状态抽象和表示学习，但未涉及跨域迁移; 连续 MDP 同态的理论扩展也未应用于高维 latent predictor。
- **关键性**: 如果跨域迁移确实成立，将极大提升 world model 的数据效率和泛化能力。但这是一个开放问题，本文将其形式化而非解决。

## Method
- **形式化框架**:
  - 将每个域建模为 structured-state decision domain（Polish 状态空间 + graded grid 表示 + 离散动作 tokenization + 转移核 + 奖励）
  - 将任意实例分解为 domain-specific adapters（encoder + tokenizer）和 domain-invariant core（context encoder + target encoder + predictor）
- **跨域对应**: 定义 cross-domain correspondence 为 approximate Markov decision process homomorphism，用 lax bisimulation discrepancy 量化质量
- **迁移 bound**: Proposition 1 将单步迁移误差分解为 source fidelity 和 structural mismatch; Proposition 2 给出 H 步 horizon bound（几何增长，受 Lipschitz 常数 L 控制）; Corollary 1 将 latent error 映射到 value gap
- **不可逾越下界**: Proposition 3 通过 Gromov-Wasserstein 距离给出结构性下界
- **SSTH**: 迁移收益是 lax discrepancy 的递减函数，GW 距离给出零迁移的阈值
- **预注册实验方案**: 4 阶段（域内验证 -> 近域迁移 -> 远域迁移 -> discrepancy 标定），明确了证伪条件
- **创新程度**: 3。将 bisimulation metric、MDP homomorphism、GW 距离等工具组合到跨域 latent world model 迁移场景，理论推导完整，但无实验。

## Experiment
无实验结果。论文明确声明这是一个 research proposal，附带预注册实验方案和证伪条件。计划在 CARLA/Habitat（域内）、nuScenes/KITTI -> Open X-Embodiment（近域）、驾驶 -> 金融订单簿（远域）上验证 SSTH。

## Value
- **工作价值**: 将一个长期被当作"直觉"的 claim（latent world model 可跨域迁移）形式化为可检验的假设，理论推导严谨。但缺乏任何实验支撑，SSTH 是否成立完全未知。
- **启发**: (1) 为 JEPA 类世界模型的跨域迁移提供了理论分析工具; (2) GW 距离作为域间结构差异的度量有参考价值; (3) horizon bound 的几何增长提示远程预测的迁移可能很快失效。
- **待解决**: 全部实验待做; lax bisimulation discrepancy 的实际估计可能很困难; admissibility 条件（grid-structured state）限制了适用范围。
