# MORE: Learning Motion-Oriented Registers for Driving World Models and Planning

## Insight
观察到视频预训练的密集 patch 特征虽信息丰富，给下游驾驶世界模型和规划器时仍需再学习“状态接口”，且预测成本随网格分辨率增长。若预训练时强制所有被遮挡 patch 只能由少量、注入自车运动的 register 预测，并直接遮挡预测 register，则密集监督会塑造紧凑、可预测、与运动相关的状态。消融显示仅加 register 提升有限，register 信息瓶颈、遮挡目标和运动条件各有贡献；这是经验性推论。

## Motivation
现有 V-JEPA/驾驶隐世界模型常把一般视觉特征继承为未来状态，运动敏感性与规划相关性主要留给下游训练；BEV/patch 网格还增加未来预测开销。关键问题是预训练阶段就建立可供世界模型和决策共用的紧凑表征，以同时提高性能和效率。

## Method
两阶段流程。预训练在每个双帧 tubelet 放 8 个可学习 register，将局部自车位姿增量 `(Δx,Δy,Δψ)` 投影注入。在线编码器看未遮挡 patch；其 patch 输出被丢弃，预测器仅用 register 还原 EMA 编码器的遮挡 patch 隐目标；另一分支遮挡连续 register 块、从余下 register 预测完整编码器的 register 目标，均用 L1。下游用 4 帧观察形成 16 个 register，非自回归一次预测未来 8 帧对应的 32 个 register，再以“已观测+预测”共享记忆生成 64 条候选轨迹，并用场景评分器选优；训练合并未来 register、最小候选轨迹及导航评分监督。结构创新在预训练阶段强制紧凑状态承担密集视频预测，并原样复用为世界模型与规划接口。

## Experiment
OpenScene 约 120 小时视频预训练，NAVSIM 训练；NAVSIM-v1/v2 的 PDMS/EPDMS 及其安全、舒适、进度分项，HUGSIM 436 场景零样本闭环，另有模块、register 数量和效率消融。NAVSIM-v2 更正评估器下 EPDMS 92.5，优于最高所列对手 NTR 90.9；v1 PDMS 93.2。HUGSIM 平均路线完成率/HD-Score 为 51.6/39.4，优于 Latent-WAM 的 45.9/28.9，但极难场景 HD-Score 仅 11.1。单前视消融中基线 EPDMS 84.9，仅加 register 85.6，register 承担 patch 预测 88.5，再加遮挡预测 89.1，完整方法 91.8；移除未来预测降至 91.1。RTX 4090 单样本推理 110 ms，对比 DriveLaW 1167 ms，但输入、模型和视角不完全相同。

## Value
值得精读。其可迁移启发是让预训练损失真正经过下游会使用的状态瓶颈，避免“训练 patch、推理 register”的目标错位；也提供世界模型未来状态是否真的帮助规划的直接消融。

## Strengths
把紧凑表征、未来预测和规划联成明确的数据流；多基准与闭环评价，消融能定位各设计贡献；报告延迟、显存和可视化失败样例。

## Weaknesses
主要面向驾驶，未验证更一般的视频世界；未来运动在推理时置零、一次性预测，因此不能按候选动作做反事实滚动，更接近规划辅助的未来上下文。安全上仍会在遮挡或停车歧义时多驶 9.9–11.7 m；跨方法延迟对比的输入视角、分辨率和模型规模不同。

## Future Work
作者在失败分析中提出延长观测时间窗，并对未来预测引入不确定性，以处理遮挡、停留时间和路线分支歧义。

## Rating
创新度评分：3/5 - 将运动条件和双重预测损失用于预训练紧凑状态接口，有明确增量与强实证，但由已有模块组合而成。
相关度评分：3/3 (Core) - 直接研究 JEPA 视频预训练、隐状态未来预测与驾驶世界模型规划。

## TL;DR
用运动条件 register 贯通视频预训练、未来隐状态预测和驾驶规划，性能与效率均强，值得精读。
