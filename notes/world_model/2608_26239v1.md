# WALL-SS: Scaling Long-horizon World Models via Next-Scale Autoregression

## Insight

论文的核心观察是：长程自回归世界模型的“预测方式”和“记忆方式”不应彼此独立。若每个未来先从粗到细构造，那么过去也可按时间距离反向分配尺度——近期交互保留细粒度 KV，远期状态只保留粗粒度 KV，并让动作历史同步压缩；这样在固定预算下仍能追溯动作造成的状态变化。作者以 60 秒递归 rollout 中的轨迹误差、跨片段边界误差和状态一致性曲线，以及去除 dream forcing/远期记忆的对照支持该推论。进一步把显式 next-scale 概率当作视觉策略，在固定动作下用动作一致性和长程一致性奖励做 on-policy alignment；对齐后 Action Following 0.264→0.290、Trajectory Accuracy 0.512→0.539、边界误差 0.118→0.104，说明生成分布可针对自回归失效模式被直接校正。

## Motivation

传统视频扩散多预测固定长度 clip；即使加入机器人动作，也常把动作当全局条件，缺少可复用因果状态、可变时长生成与显式序列概率。递归生成则会累积视觉漂移、物体身份错误、接触状态丢失和动作历史错配。WALL-SS 试图用一个 next-scale 自回归框架同时解决动作可控、分钟级流式生成、固定预算记忆和奖励优化。该问题直接关系世界模型能否从“好看的视频生成器”变成可用于策略评估的交互模拟器，重要性高。

## Method

- **数据**：以完整 AgiBotWorld-Beta（1,003,672 条轨迹）为主要公共源，处理后得到 987,508 个语义片段、来自 165,560 个独立视频；另含 ManipArena、私有 X2-Robot 双臂数据、便携 UMI，以及策略干预/失败恢复轨迹。所有数据切成 10 FPS 语义片段。只有通过时间同步、内外参和运动学检查的数据进入 action-conditioned pool，其余有效 RGB 留在 video-only pool；私有数据和失败数据规模未披露。
- **next-scale 表示**：从 InfinityStar 初始化，冻结 VideoVAE；每个未来多视角 observation 先预测粗 latent，再预测对累计重建的中/细尺度 residual。跨视角 adapter 只交换同一时刻已可见状态，避免人为设置相机生成顺序。
- **动作接地**：确定性 ActionBridge 将双臂末端位姿、朝向、深度和夹爪状态投影到各相机平面，形成与 RGB 同时间、同空间布局的 action video。因果 encoder 提取多尺度动作特征，视觉尺度只读取当前 clip、当前视角、对应或更粗的动作尺度，禁止邻近 clip、其他视角和未来动作泄漏。主目标是平衡各 clip/scale/residual 的自回归 NLL。
- **长程记忆**：固定保存仅由初始观测构成的 identity anchor；最近片段读取细尺度预生成 KV，越旧片段只读取更粗尺度 KV，并与同区间动作 bank 成对保存。记录在最后一次计划读取后删除，因此理论内存上界与已生成时长无关。scale-wise dream forcing 混合年龄相关的历史扰动和滞后模型生成的 detached suffix，仍以干净未来为监督，减少 teacher-forcing 暴露偏差。
- **动作分支**：flow-matching action expert 只读取已提交的视觉记忆、proprioception 和任务，预测下一动作块；外部动作和预测动作共用 ActionBridge。视觉与动作分支在 paired transition 上联合训练，但可独立用作模拟器或策略。
- **on-policy alignment**：固定初始帧、任务和动作，旧策略采样每组至少两个视觉 rollout；冻结的动作跟随 scorer 与长程一致性 scorer 给奖励，经 group-relative PPO/GRPO 更新视觉 token 概率。冻结 tokenizer、scorer、参考模型和动作模块，并用 reference KL 与真实轨迹 AR replay 抑制 reward hacking/外观漂移；奖励明确不含任务进度或成功。
- **闭环**：每个动作块后生成头部及双腕视角、提交 time-scale state，再让冻结外部策略读取生成观测产生下一动作；初始化后不再注入真实帧或动作。

把 next-scale 生成、动作条件、分层 KV、exposure-gap 训练和视觉 RL 统一起来，属于较强的方法创新；但组件分别承袭 VAR/InfinityStar、forcing、分层记忆及生成模型 RL，创新是针对机器人世界模型的结构性整合而非全新生成范式。

## Experiment

- **自建生成基准**：200 个 ID、100 个 OOD 任务，80% 有同步动作；按 WorldArena 报告 14 项视觉、运动、时序语义与物理条件指标。WALL-SS 的 Action Following **0.290**、Trajectory Accuracy **0.539**、Interaction Quality **0.546**、Instruction Following **0.471**，均为表中最佳；视觉美学 0.697 略低于 CogVideoX-5B 的 0.718。多数通用视频基线不接收动作，因此动作指标上的比较不能替代与同类 action-conditioned world model 的等条件对照。
- **反事实与长程**：固定初始观测，仅改变控制轨迹，生成不同末端路径；示例中接触密集的倒水阶段误差始终低于图像对角线 0.5%。60 秒递归 rollout 比较完整模型、无 dream forcing、仅近期 clip、全历史 KV；Figure 9 显示完整模型轨迹/边界误差最低、状态一致性最高，Figure 10 的 PSNR/FID/FVD 也优于 InfinityStar、Wan 和 Cosmos3。曲线未给样本数、误差条或数值表，且没有报告实际 KV 显存/延迟，证据主要支持趋势。
- **多视角**：以 3D linear probe error 和标定点 correspondence error 测头部/双腕相机一致性，WALL-SS 位于较优的左下区域；仍为自建评测。
- **RL 消融**：相同条件下，对齐使 Action Following 0.264→0.290、Trajectory Accuracy 0.512→0.539、边界误差 0.118→0.104，外观指标在评测噪声内不变；以相同流程重训 action expert 后，真实机器人 Task Progress 64.6→69.1。奖励与前两类评价信号接近，独立性有限，但真实控制提升是额外证据。
- **sim-real 策略评估**：6 个 held-out 任务×5 个 WALL-WM checkpoint×20 个匹配初态，共 **600 对**生成/真实 rollout，并由盲评者标注。30 个 task-checkpoint cell 的 SR MAE **0.062**、bias +0.028、相关系数 0.93；保留 89% 的 59 个无平局 checkpoint 排序，平均 Spearman ρ=0.88；episode balanced accuracy **0.88**，但对真实失败的假成功率仍为 **13.6%**，偏乐观主要集中在 contact/insertion。
- **真实控制**：7 个桌面任务上 action expert 平均 Task Progress **69.1**，高于 π0.5 49.6、DreamZero 44.1、LingBot-VA 34.0。论文称同时评 strict success rate，却没有给出对应数字、试验次数或置信区间。

## Value

这是少数把长视频生成质量、反事实动作可控性、分钟级状态保持和 sim-real 策略排序放在同一评测链条中的机器人世界模型工作。最值得借鉴的是“生成尺度即记忆尺度”的统一设计，以及把视觉生成器而非控制器视为可 RL 对齐的随机策略。其 600 对 sim-real rollout 明确暴露了 13.6% 假成功风险，比单纯宣称视频逼真更有研究价值。尚待解决的是更透明的规模/算力披露、同类 WAM 公平比较，以及接触物理和不确定性校准。

## Strengths

- next-scale 预测、动作条件和 bounded memory 在同一因果层级中定义，设计自洽。
- 有针对 dream forcing、记忆策略和 on-policy alignment 的受控对照，机制证据比单一 SOTA 表充分。
- 数据刻意保留失败、干预与恢复轨迹，缓解“动作即成功结果”的乐观捷径。
- 600 对 sim-real 闭环评测同时报告校准、排序、episode agreement、置信区间和具体失败偏差，证据边界清楚。
- 兼顾生成器与 co-trained action expert，验证预测表示对真实控制的迁移价值。

## Weaknesses

- 模型参数量、训练预算、关键超参数、私有数据与 intervention 数据规模均未披露，复现困难。
- 自建生成基准和冻结 scorer 的训练细节不足；主要基线多不是动作条件模型，Action Following 的横向优势部分来自输入能力不对称。
- 60 秒记忆曲线缺样本量、数值表和方差，也未实际报告峰值显存、吞吐或相对 full-history KV 的成本。
- RL 奖励 scorer 与动作/长程评测指标高度同源，存在评价循环；尚缺独立物理测量或第三方基准验证。
- 真实控制只完整报告 Task Progress，未给承诺的 strict SR 与统计不确定性；sim-real 在接触/插入处仍有明显乐观偏差。

## Future Work

作者明确提出：随环境、策略和人类期望变化做持续评测与 continual refinement；将不确定性和反馈纳入世界模型；扩大交互覆盖，并建立跨平台、同时连接预测、决策和真实物理结果的共享协议。结合实验暴露的问题，接触/插入的假成功校准应是最优先方向。

## Rating

创新度评分：4/5 - 首次将机器人 next-scale 自回归、尺度压缩记忆、dream forcing 与视觉生成策略 RL 形成完整闭环，且有较强机制与 sim-real 证据；但底层组件多有直接前序，复现披露不足。

相关度评分：3/3 (Core) - 直接研究动作条件视频世界模型的长程生成、记忆、对齐与闭环策略评估，是核心相关工作。

## TL;DR

以多尺度自回归、分层记忆和视觉RL实现分钟级可控推演，证据较扎实，值得精读。
