# DreamGuard: Efficient Runtime Guardrail for LLM Agents via Risk-Aware World Model

## Insight
工具调用风险不总在当前动作中显式出现：若把历史压进固定维度状态，并训练其预测动作后的 latent，再分别估计“当前动作立即危害”和“轨迹前缀累积风险”，就能比逐步内容审核更早阻断多步风险。DreamGuard 在 SafetyDrift 上以 96.3% 的 PHIR 平均提前 3.63 步干预；去掉循环状态会令 FPR 从 9.8% 升至 73.7%，去掉后继预测则使 F1 从 82.9% 降至 76.3%。这些干预支持“安全判断应针对预测后继，而非只检查当前文本”的推论，但其 latent 是风险判别导向的日志状态，而非通用环境模型。

## Motivation
LLM agent 可通过工具改变文件、凭据与外部服务，逐动作反应式 guardrail 会漏掉由多个表面无害操作累积出的风险；用 LLM 每步重读全历史并做 look-ahead 又慢且随上下文增长。论文要在执行前以固定成本预测多时间尺度风险，并控制误报。这对 agent 安全很重要，但研究对象是文本/工具轨迹，不是用户关注的视觉或物理世界模型。

## Method
冻结 Qwen3-4B-Instruct 提取任务、观测和动作 embedding；RSSM 用 GRU 维护确定状态、因子化 categorical latent 表示随机状态，并由拟合后验的 prior 预测执行动作后的 successor latent。第一阶段以未来观测 embedding 的余弦损失和 Dreamer 式双向 KL 学轨迹动力学；第二阶段固定 GRU、部分解冻其余路径，以 hazard step 和向前衰减三步的 prefix-risk 标签塑造风险状态。运行时融合即时 hazard、prefix EMA 和滑窗均值：hazard 超阈值 BLOCK，累积风险超阈值 HOLD，否则 PASS；两个阈值按安全轨迹最大分数做 split-conformal 分位数校准。

## Experiment
只在 SafetyDrift 训练和校准，零样本迁移到 AgentDojo、Agent Security Bench 与 ASSE-Security；主指标为轨迹 F1、安全率、FPR、调用延迟，以及首次危害前干预率 PHIR/提前步数 MAS。DreamGuard 在四基准的 F1 为 96.4/74.9/82.1/82.9%，相应 FPR 为 3.7/29.4/13.6/9.8%；平均延迟 25 ms，显著低于 LLM look-ahead 的数秒级。SafetyDrift 上强于 TRACES（F1 87.1、FPR 33.3），但 AgentDojo 的 FPR 仍达 29.4%，早期干预 PHIR 仅 16.8%。各组件消融显示循环 dynamics、后继预测、双风险头、时间聚合与两阶段训练都影响安全—误报平衡。在线实验用 100 个 ASSE 派生案例、GPT-5.1 agent、最多 6 步：安全率 72.92%，效用率 90.38%，优于所列基线；三次运行和配对 Wilcoxon 检验支持结果稳定。非原生 step 标签经双人复核，精确边界一致率为 79.6%--88.1%。

## Value
论文提供了一个比 LLM 审核器更像实时系统组件的风险预测器，核心思路可用于任何日志可观测、危害可标注的工具 agent。对隐式世界模型的间接启发是：预测表征应服务于决策相关属性，并在动作后继上监督；但它没有学习视觉、几何或物理动态，对目标研究方向没有直接方法价值。

## Strengths
- 将立即危害、长期前缀风险和时间证据明确分开，运行规则与校准过程可解释。
- 跨四基准评估，并报告时机、误报、在线效用、组件消融、重复运行与标签一致性。
- 固定维度循环状态避免重复处理增长历史，25 ms 延迟具有部署意义。

## Weaknesses
- 风险状态由 hazard/prefix 标签强监督，三步衰减前缀相当于把已知危害边界回填；它是否学到可泛化因果后果而非风险模式仍不清楚。
- 仅预测观测 embedding，不生成或验证具体环境状态；“world model”命名比实际能力更宽泛。
- 训练域和阈值均来自 SafetyDrift，跨域 AgentDojo FPR 高达 29.4%；split-conformal 保证也不能直接迁移到分布外数据。
- 在线测试只有 100 个派生 mock-tool 案例、最多 6 步，并依赖模型 judge，距离开放网络和不可逆真实工具操作仍远。
- HOLD/BLOCK 只中断，不提出安全替代动作；误报时会直接损害任务连续性。

## Future Work
作者明确提出用少量目标域数据轻量重校准，以应对大分布偏移，并生成安全替代动作而非只中断执行。还应扩展真实长轨迹、开放工具和动态策略对抗，检验校准覆盖率与风险 latent 的因果泛化。

## Rating
创新度评分：3/5 - 风险导向 RSSM 与多时间尺度校准 guardrail 组合扎实、效率突出，但依赖强风险标签且在线规模有限。
相关度评分：0/3 (Noise) - 属于纯文本工具 agent 安全，未研究视频、3D 或 JEPA/Dreamer 式物理世界建模。

## TL;DR
用轻量风险 RSSM 预测工具动作后继并提前拦截长期危害，安全贡献扎实但方向不符，可跳过。
