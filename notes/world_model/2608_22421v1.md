# Where World Models Break: Natural-Input Failure Discovery

## Insight
有。论文的 observation 是：平均预测误差可以很低，但合法 reset/action prefix 空间中仍可能存在小而连续的高风险“failure basin”，足以改变 planner 的动作排序。推论是：世界模型评测不应只随机采样或找一个极值，而应在有限预算内主动搜索环境合法输入，并在冻结搜索结果后用独立 seeds 和邻近合法编辑分别检验点复现性与局部持续性。作者以 PushT 的 held-out CVaR、radius-1 neighborhood 以及 MPC 排序差距建立了这条证据链。

## Motivation
现有 world-model benchmark 聚合一般输入上的画质、预测误差或闭环回报，容易掩盖稀有但可执行的灾难性预测错误；常规 adversarial perturbation 又可能制造环境不合法、不可解释的输入。论文解决“在昂贵且有噪声的 rollout 下，怎样用有限查询找到自然、合法、可复验的失败条件”。这是部署世界模型做规划和控制前的关键安全评测问题。

## Method
作者形式化 natural-input failure discovery：输入由带语义类型、合法域和编辑算子的坐标组成，风险是预测与环境未来的 discrepancy，经 mean/max/CVaR 聚合；搜索预算为 B，输出 top-k 具体条件而非推断整张风险面。

BASINLENS 先用 Gaussian-process UCB 从全局候选池探索，再从高风险 anchors 生成“替换一个同类型坐标且仍合法”的局部 frontier；合并 acquisition 包含标准化 UCB、parent score、anchor proximity 与 novelty。搜索结束后冻结 trace：在 disjoint seeds 上重测 shortlist，再对 radius-1 合法邻域用 fresh seeds 测局部持续性。记录保留稳定 candidate ID、typed values、每 seed loss、activity、完整 query trace，避免验证结果泄漏回 acquisition。

## Experiment
主实验是 LeWM-PushT：12,016 个合法 6D reset、64 个 paired restarts、每候选 8 个搜索 seeds，预算 16/32/64；风险为最后预测步 state-probe MSE 的 upper-tail CVaR，并以接触、路径和任务进展约束 activity。对比 random、GP-UCB，并另用 576 候选做 16 个独立 seeds 的点验证、3,510 候选做 fresh neighborhood；还有 DINO-WM PushT/Wall、JEPA-WM PointMaze、DIAMOND/IRIS Atari 四类接口检查。

在最大网格 B=64 时，越过风险 1.60 的概率为 BASINLENS 54.7%、GP-UCB 40.6%、random 10.9%；对 GP-UCB 的该单阈值差异仅 p=0.061，但 mean-best 为 1.572/1.547/1.512（对 GP-UCB p=0.0027），16 个阈值平均命中率为 0.572/0.474/0.255（p=0.004）。24 个完整 held-out selection 的 CVaR 为 1.311，对 default reset 为 1.186；top-anchor radius-1 CVaR 1.252，mid/random 为 0.608/0.546（p≤6.99e-4）。TwoRooms 仅改合法起点即令 future-position MAE 从 13.2 升至 89.0 px，而 probe MAE 仅 1.13→1.66。MPC 中 environment-oracle 排序比 model 排序的进展高 0.525，30/32 配对获胜。

消融显示结构并非总有利：单因子 PushT 上 GP-UCB top-2% hit 0.875、BASINLENS 0.867；组合网格需 interaction/beam 变体才达 0.961/0.963，标准 BASINLENS 0.803 还低于 random 0.828。JEPA-WM 有正收益，但 DIAMOND/IRIS 上 random 或 UCB 更强。

## Value
对我们最大的启发是把“failure case”升级为可审计科学对象：必须同时交代合法输入、查询预算、预测接口、独立种子、邻域行为与下游后果。该协议适合给视频生成式 world model、JEPA latent model 和 Dreamer-style model 增加 adaptive stress test，也提醒不能用平均 FVD 或平均 return 代替局部可靠性分析。

## Strengths
问题定义新且实际；严格区分 discovery、held-out point、local persistence 和 task consequence；预算、候选库和 seed ledger 透明；保留负结果，不宣称结构化搜索普遍占优；跨 state probe、visual feature、JEPA latent、generated frame 四种预测接口；代码与最小复现记录设计完整。

## Weaknesses
最完整的独立点/邻域验证只在 LeWM-PushT 上完成，跨模型主要是 replay 或小规模 scope check，尚不能证明普适性。LeWM 风险经过 learned state probe，测到的是 world-model-to-readout 整体失败；probe 仅在 48 个 held-out 样本上核查，不能完全排除 predicted-latent OOD 时的读出误差。有限、人工离散的合法库既不覆盖连续开放世界，也不能估计部署失败概率，各模型风险尺度不可比较。BASINLENS 超参数和结构变体较多，在简单/同质空间不优于标准搜索；真实机器人与大规模视频 world model 尚未验证。

## Future Work
作者未单列未来工作，但全文明确留下三条扩展：把独立 seed 与邻域验证推广到更多模型/任务；从有限离散库扩展到更大、连续或层级化的合法输入空间；在保持 prediction risk、search score、task consequence 分离的前提下，进一步估计部署分布中的失败频率与真实控制影响。

## Rating
创新度评分：3/5 - 提出有价值的新评测问题与严谨证据标准，BASINLENS 是 GP-UCB 加 typed frontier 的有效实现，但跨模型优势有限且不是普适搜索突破。
相关度评分：3/3 (Core) - 直接评测视频、JEPA 与 latent world model 的隐藏预测失败，对规划和闭环部署高度相关。

## TL;DR
把世界模型评测改写为合法输入上的有限预算故障搜索，并验证复现与局部持续性，值得精读。
