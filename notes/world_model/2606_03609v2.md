# A 3D Isovist World Model -- Revealing a City's Unseen Geometry and Its Emergent Cross-City Signature

## Insight
核心 insight 有两个：
1. **表示选择**：世界模型应预测 navigable geometry（负空间/可通行体积）而非外观（RGB）或扁平化的占用栅格（BEV occupancy）。3D isovist（球面深度图）直接编码代理感知的可通行空间，无光度纠缠、保留三维立体结构。
2. **涌现的空间签名**：一个 city-blind 的世界模型（从不告知城市标签）在其时序隐表示中自发地编码了城市身份（Manhattan vs Paris），线性可解码准确率达 89.3%，远超单帧外观基线（78.5%）。这说明预测性训练本身会诱导出有意义的空间结构表示。

## Motivation
现有 embodied world model 的预测目标存在问题：
1. Appearance-first（预测 RGB）：携带光照、纹理等与导航无关的信息，几何一致性是次要考虑
2. BEV occupancy：将 3D 环境压缩到 2D 地面平面，丢失了立面、多层结构等影响真实导航的垂直信息
3. 重建方法（NeRF/3DGS）：场景特定，不跨轨迹泛化

isovist 在建筑学/空间句法中已有 40+ 年历史，但从未被用作世界模型的预测状态。本文将其从描述性统计量转变为预测性世界模型目标。

## Method
1. **负空间表示**：球面深度图 D ∈ R^{64×128}，记录每个方向到最近建筑表面的距离，以自我为中心、heading-aligned
2. **数据生成管线**：OpenStreetMap → 建筑轮廓提取 → 高度填充 → 网格拉伸 → 交叉口锚定路径采样 → 光线投射生成 isovist 序列（Manhattan + Paris）
3. **模型架构**（13.1M 参数）：
   - Frame encoder：Depth CNN + Anchor MLP → 256-d token
   - PathTransformer：4 层 8 头 Transformer，弧长位置编码（非整数索引）
   - Action encoder：Fourier 特征 → MLP，5-DoF 动作
   - Residual depth decoder：预测深度变化量 δ，D_{T+1} = clamp(D_T + δ)
4. **Persistent latent BEV spatial map**：世界坐标下的 2D 特征网格，双线性读取/EMA 写入，提供跨路径几何一致性
5. **Self-rollout scheduled sampling**：用模型自身预测（而非 Gaussian 噪声）替换上下文末帧，保持在 isovist 几何流形上
6. **训练**：edge-weighted log-depth loss + Sobel gradient loss，多步 rollout（K=3）

## Experiment
- **单步预测**：MAE 3.57m vs copy-last 4.36m，Edge-F1 0.719 vs 0.689——在建筑边缘等结构性变化处显著优于 baseline
- **Cross-city spatial signature**：5-fold 线性分类 89.3%±3.0%，远超 raw pixel 78.5% 和 trivial frame statistics 69.4%。签名存在于时序隐表示中，不是单帧外观
- **BEV spatial map 一致性**：初步实验显示跨路径 latent 一致性有提升，但这部分分析尚浅
- 数据集开源（ODbL 协议），管线可复现

局限性：仅两个城市，Paris 的建筑高度有大量插补（65.8% imputed），可能是 cross-city signature 的 confound。

## Value
这是一篇角度独特的 3D 世界模型工作。用 isovist 作为世界模型预测目标的思路有启发性——直接建模可导航的几何空间而非外观，从表示层面就避免了 appearance-geometry 纠缠。Persistent BEV spatial map 提供了一种显式的跨路径几何记忆机制，值得在更大规模世界模型中借鉴。

但也有明显不足：仅 13M 参数的小模型，仅两个城市，评估指标和 baseline 都较简单。Cross-city signature 虽然是有趣的涌现现象，但由于 Paris 高度数据的大量插补，因果解释尚不充分。整体更像一个 proof-of-concept 而非成熟系统。

## TL;DR
以球面深度图（3D isovist）为预测目标构建城市导航世界模型，发现 city-blind 训练涌现城市空间签名，思路独特但规模和验证较初步，可选读。
