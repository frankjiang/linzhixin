# Exact Equivariance, Kept Through Training, Buys Zero-Shot Generalisation Across the Symmetry Group

## Insight
精确等变的世界模型（编码器+预测器）在整个对称群上具有数学证明的零样本泛化能力，且误差在多步rollout中不累积——这是数据增强和近似等变性无法达到的。

## Motivation
数据增强、暴力扩展规模和软等变性可以缩小跨群度量差距，但无法达到浮点精度的精确不变性。精确等变是否真正在训练后保持？保持的等变性能否带来可证明的泛化？

## Method
- **Proposition 1**: 当动力学具有群G对称、latent上为正交表示ρ(g)时，one-step relMSE在整个群上精确不变
- **Vector-Neuron / e3nn 架构** 实现精确 SO(2)/SE(3) 等变
- 完整流程：等变编码器E + 等变预测器f + 等变规划器
- 训练使用 Muon/AdamW + EMA + VICReg
- 在 PushT（2D/SO(2)）和 3D/SE(3) 任务上验证

## Experiment
- 训练后compose encode-then-predict残差 ~10⁻⁶（精确等变在训练后保持）
- **OOD因子**：等变模型 ×1.00 vs baseline ×13.8(2D) / ×17.2(3D) / ×157(full SE(3))
- 等变模型参数量减少 **4.5-7.4×**
- H步rollout误差保持 ×1.00（≤2×10⁻⁷），baseline误差随H累积
- 闭环控制：等变规划器的控制轨迹是ρ(g)变换后的已见轨迹，误差在群上不变
- Stress test: 数据增强/暴力scaling/软等变各自最多只能缩小跨群任务度量差距，但永远无法达到浮点精度的精确性

## Value
理论严格，实验验证clean。为世界模型设计提供了重要的结构性先验指导：精确等变 >> 数据增强/近似等变。但实验仅在小规模任务（PushT等）上进行，是否在高维视觉世界模型中成立未验证。
