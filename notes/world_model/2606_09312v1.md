# Toward Compiler World Models: Learning Latent Dynamics for Efficient Tensor Program Search

## Insight
核心观察：编译器中的 tensor program 优化本质上是一个序列决策过程（scheduling actions 逐步变换程序状态），与世界模型的"状态-动作-状态转移"范式天然匹配。现有 cost model 将候选程序视为静态代码快照进行评估，忽略了调度决策的上下文依赖性（同一 tiling 操作在不同前序决策下效果不同）和语法噪声敏感性（语义等价但语法不同的程序得到不同评分）。

## Motivation
- **问题**：Tensor program 自动调优中，候选程序评估是关键瓶颈。现有 cost model 基于最终代码快照做静态评估，无法捕捉调度决策之间的上下文依赖关系，且对语法变化敏感。
- **同行做法**：TenSet 等 learned cost model 直接在最终代码上学习 runtime 预测；Ansor 等搜索框架依赖大量硬件测量。两者都将候选评估视为静态问题。
- **是否关键**：该问题对编译器优化领域有实际价值，但与视频/3D/隐式世界模型的研究方向关联度低。

## Method
**三阶段框架**：
1. **TensorIR State Encoder**：基于 CodeBERT 的程序状态编码器，将 TensorIR 文本编码为稠密向量。使用对比学习训练（intra-file + inter-file negatives），使语义相似的程序状态在表征空间中接近。支持长输入的 chunking + masked mean pooling。
2. **Action-Conditioned Multi-Step State Transition**：基于 TransH 的轻量级转移模型，将初始状态编码逐步通过 scheduling actions 序列滚动更新，预测终态表征。每个 action 定义一个超平面上的变换方向。训练使用 multi-step rollout，结合 state-matching loss 和 margin-based ranking loss。
3. **Ranking-Based Cost Model**：基于 XGBoost 的排序模型，输入为预测终态表征 + 结构化 action 特征 + 硬件特征，输出候选排名分数。使用 LambdaRank 训练。

**集成方式**：替换 TVM AutoScheduler 的默认评估路径，作为在线搜索中的候选排序组件。

**创新程度**：中等。将世界模型思想引入编译器优化是新颖的跨领域迁移，但各组件（CodeBERT、TransH、XGBoost）本身并非新设计。

## Experiment
- **平台**：Intel Xeon Gold 6430 CPU + NVIDIA RTX 4090 GPU。
- **workload**：7 个代表性模型（ResNet-50, BERT, MobileNetV2, GPT-2, ResNet18-3D, OPT-1.3B, GPT-Neo-2.7B），共 103 个子图。
- **对比**：PyTorch / PyTorch-opt(cuDNN) / TensorRT / Ansor / TenSet。
- **结果**：
  - End-to-end：相比 PyTorch-opt 加速 3.67x (GPU) / 相比 PyTorch 加速 4.61x。
  - 同 budget 对比 Ansor：64-trial 下 GPU 加速 1.22x，CPU 加速 1.62x。
  - 1K-trial 搜索质量接近 Ansor-10K（仅差 2.2% geometric mean），即 10x 少的硬件测量。
  - 代表性子图分析：22 个子图中大部分优于 Ansor/TenSet。

## Value
- **价值**：将世界模型的状态转移思想引入编译器优化是一个有趣的跨领域尝试，实际效果显著（10x 少的测量达到相当质量）。
- **与关注方向的关联**：本质上是"世界模型"概念在编译器领域的类比应用，与视频/3D/隐式世界模型无直接技术关联。
- **启发有限**：方法组件（对比学习编码器 + TransH 转移 + XGBoost 排序）是领域特定的，对世界模型研究本身无太多方法论启发。

## Strengths
- 把调度过程建模成状态转移后，能在较少硬件测量下获得接近强基线的搜索质量。

## Weaknesses
不足是启发有限：方法组件（对比学习编码器 + TransH 转移 + XGBoost 排序）是领域特定的，对世界模型研究本身无太多方法论启发。
