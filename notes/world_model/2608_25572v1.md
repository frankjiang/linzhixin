# ConfAL-WM: Confidence-Guided Active Learning for Action-Conditioned World Models

## Insight

观察是：action-conditioned 视频世界模型跨域后的误差并非均匀分布，而集中在机械臂、被操作物体、接触、遮挡及长时累积区域。由此可推论，置信度不应只是整段视频的标量评分，而应同时承担“把数据预算投向难任务”和“把梯度投向难帧/难 patch”两种角色。论文以三层证据支持该推论：风险与 oracle error 的 patch/frame/task Spearman 分别为 0.540/0.590/0.595，top-5% error 检测 AUROC/AUPRC 为 0.761/0.146；固定预算重训优于多种标量打分；frame+patch 加权进一步改善重建、语义和运动指标。不过 top-5% 空间 IoU 仅 0.130，且探针在主要阈值附近过度自信，因此其可靠含义是“序数排序信号”，不是校准后的错误概率。

## Motivation

EVAC 等 action-conditioned 视频世界模型迁移到新任务、场景和机器人时需要昂贵 post-training，均匀加数据与均匀优化会浪费算力。RoboReward、GVL、Robometer、PRM-as-Judge、LRM 等标量 reward/progress/judge 能排序轨迹，却难以指出视频中具体何时、何处预测失败。论文试图用一个轻量稠密 confidence probe 统一数据选择与局部训练增强。该问题对大规模视频世界模型适配很实际，但它优化的是已有世界模型的训练流程，而非提出新的动力学表示。

## Method

- Backbone 为在 AgiBot World 预训练的 2.33B 参数 UNet latent-diffusion 模型 EVAC。冻结 EVAC，在可选 decoder feature 上接 8.2M 参数探针，依次做通道投影、spatial Transformer、temporal Transformer 和 patch 输出，并以 diffusion timestep 与误差阈值 embedding 为条件。
- 无需完整反向扩散：由 velocity prediction error 可闭式换算 clean-latent error；在通道和对应 latent 区域内平均得到 patch MAE，再以“误差低于阈值”构造 BCE 二值目标。每批误差的 10%/90% 分位数通过 EMA 更新上下界，前 300 步注入率 0.2、之后 0.002；每帧随机采样共享阈值，使二值监督的期望形成随误差单调下降的连续排序。
- 先用 6,248 条（约 25%）RoboTwin2.0 数据训练探针并 warm up EVAC-v1；对 50 个任务做代表 episode 预筛，按任务风险分配配额，再在任务内随机采样，从余下 18,244 条候选中选 7,298 条训练 EVAC-v2。后者是固定 V2 预算，占候选池 40.0%、全集 29.2%；与 warmup 数据合计才是全集约 54.2%。
- acquisition 可用 mean、tail 或 persistent risk；默认 mean risk。可选的额外 scoring 阶段对已选 episode 生成稠密图：α=0 为 frame 平均风险，α=1 保留 patch 残差，经分位归一化/裁剪后转为 `1 + λ·risk` 的局部 loss 权重，并在重训前期线性 warm up；confidence map detach，不反传探针。
- 创新主要是把已有稠密置信估计适配到 UNet decoder，并将同一信号同时用于预算分配与局部加权，属于主动学习与世界模型后训练的组合创新。

## Experiment

- 数据为 RoboTwin2.0 Aloha-AgileX 双臂的 50 个任务、24,992 段视频（98–578 帧）；主比较用 3 个随机种子，AdamW、4,000 步、两张 A800。评估遵循 EWMBench：PSNR、SSIM、Scene Consistency、Logics、Sem.-CLIP/BLEU、Traj-HSD/Dyn/nDTW，并汇总为 Reconstruction、Scene、Semantics、Motion。
- 置信有效性（Figure 5/Table 1）：latent 风险跨尺度相关性中等，时间上较稳定（相邻帧 top-region IoU 0.740、flicker 0.005，零时滞附近相关 0.602），但精确边界定位较弱（top-5% IoU 0.130）。附录校准曲线显示结果强依赖 operational threshold，主要工作点仍过度自信。
- 固定预算选择（Table 2）：Confidence 无额外加权在 selection-only 组的 9 项指标中 8 项最佳；相对 EVAC-v1，PSNR/SSIM/Scene 从 0.6446/0.7309/0.9047 升至 0.6746/0.7692/0.9196，三项运动指标由 0.1045/0.0721/0.1439 升至 0.1181/0.0812/0.1650。
- frame+patch 后 PSNR/SSIM、Logics、Sem.-CLIP/BLEU 分别为 0.6772/0.7758、0.6226、0.8925/0.2952，多数为加权组最佳；但 Scene Consistency 降至 0.8942，低于 frame-only 的 0.9143，也低于 EVAC-v1 的 0.9047。
- Table 5 将三个 seed 的 episode-level paired differences 池化后做 10,000 次 percentile bootstrap，并非以训练 seed 为统计单位：仅选择时 Reconstruction、Scene、Motion 的区间均为正，Semantics 为 [-0.002, 0.038]；frame+patch 时 Reconstruction/Motion/Semantics 的区间完全为正，但 Scene 明确下降 [-0.013, -0.008]。单种子消融中 mean risk 取得 9 项中的 7 项最佳，tail/persistent 各偏向不同语义指标。
- 附录给出三种子全表、6 个定性 episode 及最好/最差置信图；定性结果支持局部加权改善机械臂、抓取物和交互细节，但没有下游规划或真实机器人控制评估。

## Value

该工作对视频世界模型有直接借鉴价值：稠密不确定性可被视作世界模型的数据 curriculum 和空间梯度调度器，而不仅是部署时告警。更重要的启发是，排序质量、概率校准、边界定位和下游收益必须分开评估；此文只充分支持前者与部分下游代理指标。尚需证明该策略能跨 backbone/数据域迁移、在真实闭环控制中有效，并在计入额外推理打分成本后仍具数据/算力效率。

## Strengths

- 将 task、frame、patch 三个尺度贯通到同一风险图，方法流程完整，应用目标明确。
- 不仅报告相关性，还覆盖检测、时序稳定性、空间重合、校准、敏感性和最差案例，附录较透明。
- 主实验含三随机种子，并在这三个已训练模型内池化 episode-level paired differences 做 bootstrap；该口径能识别语义区间跨零、patch 加权损害 Scene 等非理想结果，但不能充分覆盖训练 seed 方差。
- EMA 随机阈值与 closed-form latent error 避免完整扩散采样，探针相对 2.33B backbone 较轻。

## Weaknesses

- 仅在 EVAC+RoboTwin2.0 上验证，探针依赖 UNet 内部 decoder feature，无法说明对 DiT、JEPA 或其他 latent world model 的可迁移性。
- 所谓 active learning 不是迭代查询闭环：主要在任务级分配配额，任务内 episode 仍随机采样；没有 episode 级稠密风险 acquisition。
- 25% 数据已用于 warmup，再加入 7,298 条后累计使用约 54.2% 全集；论文没有完整数据基线、预算曲线或额外 scoring 的总 GPU 成本，因而“效率”证据不充分。
- 没有规划成功率、策略收益或真实机器人指标，所有结论依赖视频代理指标；这些指标间已出现 Scene 与 Motion/语义冲突。
- 风险图并未被绝对校准，top-5% 边界 IoU 很低；同一模型内部误差训练出的探针也缺少独立可靠性标签或受控因果检验。
- 与通用标量 reward/judge 的比较不完全等价，且归一化指标遮蔽了原始量纲和实际视觉差异。

## Future Work

作者明确提出三条方向：用多种 world-model backbone 与多样 embodied 数据训练通用置信模型并设计统一输入接口；引入更直接的表征诊断与受控因果实验；将评估拆为机械臂运动、被操作物体动力学、交互区域和静态背景，以处理视觉保真与运动准确性的冲突。

## Rating

创新度评分：3/5 - 将 UNet 稠密置信探针、任务预算和帧/块加权系统整合到视频世界模型后训练中，实验扎实，但核心组件多为已有思想的有效组合。
相关度评分：3/3 (Core) - 直接研究 action-conditioned 视频世界模型的跨域后训练、误差定位与数据选择，属于视频世界模型核心问题。

## TL;DR

用稠密置信图同时做EVAC数据选择与帧块加权，改善跨域视频预测；方法扎实但泛化未证，可选读。
