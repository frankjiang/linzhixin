# Making Foresight Actionable: Repurposing Representation Alignment in World Action Models

## Insight
重要 observation：WAM 能生成看似合理的未来视频，但 action decoder 仍可能输出错误动作；attention 和 causal intervention 显示 decoder 关注背景/静止手等无关区域，而非手-物交互区。推论是视频重建优化出的 diffusion hidden states 不天然 action-readable，需要把 world-action interface 对齐到更语义、空间一致的视觉表征。AGRA 用 DINOv2 alignment 验证了这一点。

## Motivation
机器人 WAM 依赖视频生成模型做 foresight，再从中解码动作。同行常假设预测未来越好，控制越好，但论文指出“视觉合理性”和“动作可读性”之间有 mismatch。这个问题很关键，因为它直接挑战视频世界模型用于控制的核心接口。

## Method
baseline 是 dual DiT WAM：Cosmos-Predict-2.5 Video DiT 产生未来和中间 hidden states，Action DiT 通过 cross-attention 读取这些 states 并用 flow matching 生成连续动作。AGRA 构造与视频 latent 时空形状对齐的 DINOv2 patch targets，把选定 Cosmos 层投影到 DINOv2 feature space，用 negative cosine similarity 作为辅助损失：L = L_WAM + lambda L_AGRA。默认对齐第 8 层；不替代预测特征，而是正则化 action decoder 读取的中间表征。

## Experiment
IRON-R01-1.11 humanoid 上评估 Pick-and-Place 与 Open-Steamer-Transfer-Bun，包含 ID、Semantic、Instance-Level、Attribute OOD。AGRA-DinoL8 ID 成功率 80%，baseline WAM 34%；三类 OOD 分别提升约 27、32、32 点。attention mask ratio/centroid error 显示 AGRA 更聚焦交互区域；causal intervention 的 Matched Sensitivity Ratio 在 Mean/Zero/Swap 等扰动下均高于 WAM。进一步分析显示浅中层对齐优于深层；DINOv2 优于 SigLIP；只用 aligned semantic layer 替代多层 predictive bridge 会失败；加 EgoDex 人类数据时 AGRA 更能跨 embodiment 受益。

## Value
价值较高：它不是单纯刷成功率，而是给出了 WAM 控制失败的诊断工具和接口正则化方法。启发是世界模型表征必须面向 action grounding，视频重建 loss 不足以保证 control-relevant feature。局限是任务集较小，AGRA 只部分缓解 mismatch，尚无大规模多机器人验证。

## Strengths
亮点是价值较高：它不是单纯刷成功率，而是给出了 WAM 控制失败的诊断工具和接口正则化方法。
