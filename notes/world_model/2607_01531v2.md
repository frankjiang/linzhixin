# OPINE-World: Programmatic World Modeling with Ontology-error-Prioritized Interactive Exploration for ARC-AGI-3

## Insight
OPINE-World 的 insight 是：程序化 world model 的瓶颈不只是转移规则合成，而是先要学到合适的对象 ontology。Observation 是过早固定对象类型会把错误结构传播到所有规则，完全 model-free agent 又没有可复用模型；推论是应让交互探索优先攻击 ontology error 高的对象/上下文，并用 exact replay verifier 约束 LLM 程序。

## Motivation
论文解决 ARC-AGI-3 中从 raw 64x64 frames 在线学习 object-centric executable world model 的问题。同行包括 WorldCoder、TheoryCoder、PoE-World 和单 agent coding baseline；前者通常需要结构化状态或固定对象词表，后者不形成可靠可复用模型。该问题与 world model learning 相关，但不是视频/3D/JEPA 主线。

## Method
系统有两个 LLM agent：goal-directed action agent 玩游戏、读日志、提出假设；world-model synthesis agent 把假设写成 Python transition_function、reward_function 和 planner。模型必须通过 exact replay verification，逐条复现 replay buffer 中所有转移；任何 live mismatch 都变成 counterexample 触发修复。ontology error 是 Bayesian diagnostic：按 object type、action、local context 统计 effect signatures，用 Dirichlet row entropy 和 type posterior entropy 做 noisy-OR，标记当前类型划分解释不了的对象。模型通过验证且至少清过一关后，planner 做 bounded forward search，并在真实环境中逐步校验。

## Experiment
在 ARC-AGI-3 public 25 games 上评估，无 per-game training 或 demonstration。OPINE-World 得分 78.4，赢 20/25 games，平均 level cleared 0.90；baseline1 单 agent coding 为 63.8、14/25；Vision 预训练在评估游戏上仍只赢 12/25；WorldCoder 和 neural latent world models 均为 0。六个 baseline1 完全失败的 hard games 中，baseline1 花 10,874 actions 未通关，OPINE-World 用 2,578 actions 全部通关，约为人类动作数的 0.65 倍。作者承认不同 base model 比较不完全可控，组件消融留待未来。

## Value
对我们有两点启发：object-centric world model 的结构错误应有显式诊断；LLM proposal 必须由精确 replay verifier 约束。它对程序化/符号 world model 很有价值，但与连续视频/3D world model 的距离较远。

## Strengths
问题设置困难，未知对象、动作和目标且在线交互；exact verification 和 counterexample loop 扎实；ontology error 是有用探索信号；结果明显优于强单 agent 基线。

## Weaknesses
使用 Claude Opus 4.8 对比 baseline1 GPT-5.5，模型变量未控；组件高度耦合，缺少细粒度消融；假设 observable-Markov determinism，不适用于隐藏状态和随机环境；planner 是 bounded search，扩展性有限。

## Future Work
作者提出未来扩展到 stochastic/partially observed environments、raw-pixel perception 更强版本、engine-given object identities，以及更强 synthesized search。
