# Failure Detection for Surgical Robot Imitation Policies via Flow-Matching World Modeling

## Insight
作者观察到单帧视觉异常分数只判断“画面是否陌生”，而 policy uncertainty 只判断“动作是否犹豫”，两者都可能漏掉单帧正常、但动作与短期视觉变化不一致的故障。由此将失效定义为整段 visual-action transition 对成功动力学的 nonconformity：若把真实 endpoint 经条件 flow 逆传后落不到高斯 base distribution 的典型区，执行即偏离 nominal dynamics。四任务实验中 inverse-transport score 明显优于同一世界模型的 endpoint prediction error，支持“评价已发生转移的似然结构”比点预测误差更适合作故障信号。

## Motivation
手术机器人 imitation policy 部署时会受初始状态、接触动力学、遮挡和执行器偏差影响，但真实 failure data 稀缺且类型无法穷举。已有 unsafe-event classifier、VLA monitor 或 uncertainty detector 依赖预定义错误、失败样本、任务描述或间接动作信号。论文要解决的是：只用成功示范学习低层正常执行规律，并以低误报及时发现未知 visual-action inconsistency。这对安全关键机器人重要，但检测对象限于局部执行异常，不判断高层手术意图和任务进展。

## Method
FoMo-FD 对 fixed/wrist 两个视角分别用冻结 DINOv2 提取 patch feature，再训练带 channel-utilization regularizer 的 β-VAE，将其压缩为 \(16\times16\times8\) latent。给定长度 \(L=4\) 的视觉历史和未来 \(K=4\) 步 commanded action chunk，view-specific transformer flow-matching branch 预测 endpoint latent 分布；动作同时以 cross-attention token 和全局 adaptive modulation 注入。额外的一步 latent prediction loss 只用于训练正则化。

测试时不采样未来，而把实际观测 endpoint 作为 flow 终点，反向积分条件 ODE 至 base latent；其按 base variance 归一化的平方范数即 nonconformity score。每任务、每视角用 19 条成功 policy rollout 的 episode peak score 做 conformal calibration，\(\alpha=0.05\)，超过阈值即报警。核心创新是把 action-conditioned flow 的 inverse transport 变成 window-level monitor；DINOv2、VAE、flow matching 与 conformal calibration 本身均为已有组件，属于有针对性的组合创新。

## Experiment
实验覆盖四个手术相关 manipulation task：Isaac Sim 的 needle pickup、ring over post，以及真机 dVRK 的 tissue retraction、shunt insertion；共 20 种 failure mode，分为抓取、空间配置、场景扰动、感知/执行异常。每个模拟 failure 有 20 条、真机 failure 有 10 条，另有每任务 20 条 held-out success；总计 320 条失败和 80 条成功 rollout。指标为 rollout-level FDR/FAR：任一窗口越阈值即算检出/误报。

对比 observation-level logpZO、RND，以及同一世界模型的 prediction-error score（WM-PE）。wrist-view WM-NC 达 96.6% FDR、1.3% FAR，明显高于 logpZO 的 45.3%/3.8%、RND 的 42.8%/1.3% 和 WM-PE 的 52.2%/7.5%；fixed view 仅 45.9% FDR、10.0% FAR，说明近场视角是关键。动作条件消融中 wrist FDR 从无动作的 87.2% 增至 token+modulation 的 96.6%；预测间隔从 \(K=1\) 到 \(K=4\) 时由 42.2% 升至 96.6%。完整 pipeline 在 RTX 5090 上 13.98 Hz，高于真机 10 Hz control loop，但报告结果仍是离线回放，未真正触发在线干预。

## Value
工作说明 latent world model 可作为执行一致性检验器，而不必生成视频或直接规划；“对真实结果做逆流评分”对其他 action-conditioned world model 的安全监控也有直接借鉴价值。其证据在多类故障和两项真机任务上较扎实，但只证明 rollout-level detection，尚未证明报警足够早、在线干预有效或对新任务/新相机可迁移。后续应联合局部动力学、任务进展和风险等级，形成分层安全 monitor。

## Strengths
- 只用成功示范训练，避免依赖难收集且无法穷举的失败数据。
- inverse-transport nonconformity 与 commanded action、历史和真实 endpoint 联合建模，目标比单帧 OOD 更贴近执行故障。
- 同一世界模型下与 prediction error 对照，较好隔离了 scoring rule 的贡献。
- 包含模拟和真机 dVRK、20 种 failure mode、FDR/FAR、视角与 horizon 消融，实验覆盖较完整。
- wrist-view 低误报高检出，且推理频率达到控制周期要求。

## Weaknesses
- 每任务都需独立 policy、VAE、world model 和成功 rollout 校准，未证明跨任务、器械、组织或医院域泛化。
- conformal calibration 只有 19 条 rollout，且用 episode maximum 形成单阈值；有限样本保证、时序相关性和多次在线检验效应讨论不足。
- FDR 只要求整条失败 rollout 中报警一次，未报告 detection delay、故障前预警率或过早报警对任务完成的影响。
- 真机结果仍为 recorded rollout 的离线检测，没有闭环暂停、恢复或人工接管实验。
- fixed camera 性能明显较差，系统高度依赖 wrist camera 的局部可见性；遮挡、污损或相机自身故障下鲁棒性有限。
- baseline 主要是视觉异常方法，缺少强 action-uncertainty、VLA/task-progress monitor 及多视角融合对比。
- 方法只检测低层 transition inconsistency；“稳定地做错事”或语义/程序性错误可能符合已学动力学而不报警。

## Future Work
作者提出融合 fixed/wrist 多视角报警，以 progress-或 state-conditioned calibration 替代统一 episode threshold，并将 world-model nonconformity 与 VLA/task-progress monitor 结合。还应开展在线 intervention、检测延迟与安全收益评估，验证跨任务统一模型、持续校准，以及在 wrist-view 失效时的冗余感知。

## Rating
创新度评分：3/5 - 将 flow-matching inverse transport、动作条件短窗动力学和 conformal threshold 组合成有效的 failure detector，实验充分，但核心模块多为已有技术且未验证闭环安全。

相关度评分：3/3 (Core) - 直接使用 action-conditioned latent visual world model 学习机器人动力学并进行执行监控，对隐式/视频世界模型有直接借鉴价值。

## TL;DR
以动作条件流模型逆传真实视觉终点检测手术机器人失效，真机结果强但尚未闭环，值得精读。
