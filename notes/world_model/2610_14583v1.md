# Remembering What Matters for Long-Horizon Robotic World Models

## Insight
自回归机器人视频模型保留全部历史时，旧的生成状态可能挤占近期视觉动作状态的注意力。作者观察到近期注意力随推演衰减；丢弃旧块后长时预测改善，回插旧块又使误差增加。但回插也改变上下文长度和位置，故尚不能证明“记忆角色冲突”是唯一机制。

## Motivation
长时动作条件视频推演容易形态漂移、动作响应减弱，且 KV 缓存持续增长。以往多通过训练新结构或逐 token 缓存筛选解决；机器人一步包含成组视觉和动作 token，拆散会破坏对齐。论文尝试冻结模型，仅调整推理上下文。

## Method
ReCAP 持续保留真实初始场景锚点，同时保留最近 W 个完整视觉—动作块，逐步逐块淘汰更早的生成历史。测试配置为 1280 个场景 token、初始 93-token 块及 W=6 个最近 93-token 块，总上下文固定 1931 token；不训练参数，不增模型模块。方法简单，创新集中在机器人世界模型的块级上下文调度及机制分析。

## Experiment
在冻结模型上用 RT-1、BridgeV2、LIBERO-90、CALVIN 比较全历史、均匀抽样及仅近期上下文；指标 LPIPS、SSIM、轨迹一致性、VLM/人工判断和延迟/显存。64 帧时 RT-1 LPIPS 0.233→0.204、CALVIN 0.159→0.106、LIBERO-90 0.192→0.166；三者 LPIPS 曲线 AUC 分别下降 9.9%、28.3%、12.0%。BridgeV2 独立协议下降 63.3%。在 64 帧，逻辑 KV 254.25→67.89 MiB，p50 每帧延迟 312.95→292.57 ms；256 并发吞吐 4.28 倍。最近块注意力在 CALVIN 例子中由 15.6% 升至 70.4%。

## Value
对离散 token 视频世界模型的长时推演很实用：先检查上下文构成再增加模型容量；可作为低成本强基线。仍需明确何时初始锚点真正有用，并验证闭环控制。

## Strengths
无需再训练；跨四数据集有配对结果与置信区间；同时报告视觉质量、注意力和系统开销，且主动指出机制实验的混杂因素。

## Weaknesses
最近块相对均匀抽样的优势较小，去掉锚点后 LPIPS AUC 无显著变化。旧块回插同时改变长度、位置和注意力归一化；目前只有开环视频预测，不能推断机器人任务成功率。系统延迟收益远小于 KV 节省。

## Future Work
作者建议用长度/位置/缓存匹配的对照分离机制影响，探索自适应上下文分配和闭环机器人评测。

## Rating
创新度评分：2/5 - 训练外的锚点加滑动窗口思路较简单，但在结构化机器人视频 token 上验证充分。
相关度评分：3/3 (Core) - 直接改善动作条件视频世界模型的长期预测。

## TL;DR
冻结机器人视频世界模型，只保留初始锚点与近期完整视觉动作块即可改善长时推演并省缓存；值得精读。
