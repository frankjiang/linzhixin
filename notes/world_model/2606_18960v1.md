# Mem-World: Memory-Augmented Action-Conditioned World Models for Persistent Robot Manipulation

## Insight
关键观察：机器人腕部视角信息密度高但极不稳定，遮挡和回访会让仅依赖当前窗口/stride history 的视频世界模型遗忘物体。推论是 memory retrieval 必须绑定到“未来动作会看到哪些 4D surface elements”，而不是只看时间邻近或关节相似。

## Motivation
解决长时机器人 manipulation rollout 的 persistence。Ctrl-World 等多视角 action-conditioned world model 已能生成动作一致视频，但历史帧选择粗糙，遇到 gripper 遮挡和大幅 wrist motion 会 hallucinate 或丢失物体。这是 policy evaluation / synthetic data 的关键瓶颈。

## Method
提出 W-VMem：以 wrist-view 为中心的 4D surfel-indexed memory。初始多视角帧估计 point map 建 surfel；之后只用 wrist-view 更新，保留 surfel 的创建/更新时间、朝向、深度和 manipulated-object 标记。生成前根据未来 action 经正运动学得到平均未来 wrist pose，逐时间渲染 surfel 并按可见性、任务相关性、时间衰减打分，再用 NMS 取 top-K 历史帧作为 Ctrl-World 条件。

## Experiment
在 DROID 上训练，抽取 34 条遮挡/往返运动 replay 轨迹，20-step 约 20s 自回归评估。Mem-World 在 third-view PSNR/SSIM/LPIPS/ObjCon 为 25.30/0.878/0.054/0.619，优于 Cosmos Predict 2.5 和 Ctrl-World；wrist-view 也从 Ctrl-World 的 17.34/0.623/0.281/0.476 提升到 19.21/0.691/0.236/0.524。策略评估与真实成功率相关 r=0.97，高于 Ctrl-World 0.85；合成成功轨迹后训练使长任务平均成功率 58% 到 72%。消融显示 W-VMem 明显优于 short-term/stride memory。

## Value
高价值，直接命中“视频世界模型 + 机器人 + 3D memory”。启发是：长时一致性不能只靠更长上下文，必须让记忆检索具备几何可见性和任务对象偏置。局限是依赖初始视角质量、外部 point map/segmentation/VLM，且没有显式接触/物理约束。

## Strengths
