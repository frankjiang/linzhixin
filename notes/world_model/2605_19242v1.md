# PhyWorld: Physics-Faithful World Model for Video Generation

## Insight
观察到大型视频生成模型虽然能生成视觉真实的视频，但经常违反基本物理原则。仅靠数据驱动的 scaling 不足以保证物理一致性。论文提出用 DPO 对齐物理偏好来补充数据驱动训练。

## Motivation
视频生成模型作为世界仿真器需要物理忠实性——生成视频需保持条件输入暗示的物理状态，并按物理原则演化。现有模型在物理一致性上不足。PhyWorld 通过后训练提升物理忠实性。

## Method
两阶段后训练：(1) Flow matching 微调——video-to-video continuation，鼓励跨帧稳定视觉属性和连贯运动动力学；(2) DPO 物理对齐——基于物理偏好对构建正/负样本，引导模型生成物理更合理的输出。基座模型 Wan2.2-I2V-A14B。构建 250 提示的物理基准 + 9B 判断模型进行逐律评分。

## Experiment
VBench 0.769 vs 基线 <=0.756。物理忠实性基准 3.09 vs 最强基线 2.99。在视频一致性和物理合理性上双重改善。消融验证两阶段的各自贡献。

## Value
直接相关于视频世界模型研究。物理忠实性是视频世界模型作为仿真器的核心需求。DPO 对齐物理偏好是一个简洁有效的方案。物理基准和评分模型的构建也有独立价值。局限：DPO 依赖物理偏好对的质量；250 提示的基准规模较小；14B 模型的 DPO 训练成本不低。
