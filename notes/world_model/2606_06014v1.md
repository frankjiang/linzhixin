# PLAN-S: Bridging Planning with Latent Style Dynamics for Autonomous Driving World Models

## Insight
Observation: 现有 LWM-based 自动驾驶 planner 直接从纠缠的 BEV latent 中生成轨迹，场景动态和驾驶风格隐式耦合，导致 (1) 风格难以监督/检视/调制，(2) latent-to-planner 路径对不同 planner 家族不可复用。推论：应在 latent 和 planner 之间插入一个显式的、规划导向的中间表示——四通道语义 cost map（dynamic/off-road/static/drivability），条件于 ego state 和 driving style。这样做的好处是可解释性、风格可控性和跨 planner 家族的可移植性。实验通过在 ResWorld（regression planner）和 WoTE（anchor-score planner）两个不同架构上验证了可移植性。

## Motivation
自动驾驶 E2E latent world model 的"紧凑性-可控性困境"：BEV latent 紧凑高效但缺乏显式的风险、可通行性和驾驶偏好建模。现有方法要么在 latent 空间隐式耦合（难以检视），要么 cost/reward 设计与特定 planner 绑定（不可移植）。PLAN-S 提出统一的 cost map 接口，通过 attention-level fusion（回归 planner）和 reward-level fusion（anchor-score planner）两种方式适配不同 planner 家族。

## Method
1. **Style-Conditioned Cost-Map Decoder**：
   - Driving Style Encoder：从 ego kinematic history（GRU）或预设 style score 编码风格
   - Dual AdaFiLM：对 BEV feature 做通道级仿射变换，style code 和 ego state 分别调制不同通道子集
   - 四通道 Cost Map Decoder：输出 dynamic/off-road/static/drivability 四个语义通道
2. **Cost-Map-Guided Planning Interfaces**：
   - Regression Planner（ResWorld）：upstream prior-cost fusion（waypoint queries cross-attend to cost map）+ downstream cost-gated deformable attention refinement
   - Anchor-Score Planner（WoTE/NAVSIM）：沿锚点轨迹采样 cost，在 log-space 中与原始 reward 融合

关键创新：cost map 作为跨 planner 家族的统一接口；Dual AdaFiLM 分离 style 和 ego-state 的调制。

## Experiment
- **nuScenes**（regression planner）：L2 Avg 0.55m，CR@3s 从 0.43% 降至 0.25%（42% 相对降低）。消融验证 cost map + AdaFiLM 各自贡献，cost map 主要影响 collision reduction
- **NAVSIM**（anchor-score planner）：Rule-based cost 达 89.4 PDMS，learned cost 89.1 PDMS。Learned variant 在 hard scenes 上 +17.2 PDMS 优势，rule variant 在 easy scenes 更强
- 推理效率：仅增加 0.25M 参数，59.0ms（vs baseline 64.8ms）
- 风格可控性定性展示：不同 style code 产生空间一致但风格不同的 cost map

## Value
工作扎实，设计清晰。将 latent world model 的 BEV 表示显式解码为规划导向的 cost map，提升了可解释性和可控性。跨 planner 家族的可移植性验证有说服力。但本质上是在现有 LWM 管线中插入一个 bridge module，创新幅度适中。对隐式世界模型如何更好服务下游规划有启发。

## TL;DR
在自动驾驶 latent world model 和 planner 之间插入风格条件化的四通道语义 cost map，提升可解释性和跨 planner 可移植性。可选读。
