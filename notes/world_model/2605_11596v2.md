# HorizonDrive: Self-Corrective Autoregressive World Model for Long-horizon Driving Simulation

## Insight
Observation：自回归视频世界模型在长程rollout时不可避免地漂移（exposure bias），现有anti-drift方法（Self-Forcing等）受限于teacher的单次生成窗口长度。核心洞察：如果teacher本身能稳定地进行AR rollout（rollout-capable），就能提供无界长度的高质量监督信号。关键难点在于标准teacher在自身预测上会漂移——解决方案是训练teacher从corrupted history中恢复（Scheduled Rollout Recovery），使其具备自纠正能力。

## Motivation
问题：驾驶世界模型需要分钟级AR rollout用于闭环仿真，但当前方法在short clip之外快速退化。Self-Forcing等方法的监督范围受限于teacher的单pass窗口。本文提出"先让teacher rollout-capable，再蒸馏给高效student"的两阶段框架。

## Method
三阶段流水线（基于Wan 2.1 1.3B T2V）：

1. Stage 1 - Conditional Driving WM训练：
   - 标准video continuation设置（T帧条件+K帧生成）
   - 多条件控制：HD map（additive layout tokens）、3D boxes、ego action（AdaLN gating）
   - 得到base model G₀

2. Stage 2 - Scheduled Rollout Recovery (SRR)：
   - 目标：将G₀转化为rollout-capable teacher G_roll
   - 方法：先用G₀做N步AR rollout生成corrupted trajectory，再训练模型从corrupted history恢复clean future
   - 两个调度策略：
     - Local pred-to-GT transition：平滑blending窗口（w从0→w_max），从sharp切换过渡到smooth混合
     - Global boundary-decay sampling：从late rollout位置（严重语义漂移）开始训练，逐步decay到early位置（通用退化）
   - 效果：teacher能在自身预测上稳定rollout

3. Stage 3 - Teacher Rollout DMD (TRD)：
   - Teacher（frozen G_roll）用长chunk K^T=40做AR rollout
   - Student用短chunk K^S=10、4-step denoising对齐teacher分布
   - Distribution Matching Distillation + Noise-truncated CFG（delayed decay策略）
   - 每当student累积覆盖一个teacher-length间隔时apply DMD gradient

创新程度：中等偏高。"先稳定teacher再蒸馏"的范式设计合理，SRR的双调度策略有深度。

## Experiment
- 数据：nuScenes 700训练/150验证，~20s/clip
- 主实验：FID 13.82（-52%）、FVD 92.99（-37%）vs最强streaming baseline
- 时空一致性：ARE 2.60（-21%）、DTW 3.27（-9%）
- vs 交互式世界模型：visual fidelity远超Matrix-Game3/Helios/HY-WorldPlay等（FID 13.82 vs 30-50）
- vs 驾驶专用生成器：短视频FVD 84.53（最优），长视频FVD 92.99竞争MagicDrive-V2的94.84
- 消融：SRR初始化teacher最关键（FVD 141.88→107.54）；N=20 rollout步最优；Delayed CFG最优

## Value
扎实的driving world model工作。核心技术贡献：rollout-capable teacher + teacher rollout蒸馏的anti-drift框架。对我们的启发：(1) 自纠正训练（从corrupted history恢复）是解决AR漂移的通用策略；(2) teacher稳定性决定蒸馏上限；(3) boundary-decay curriculum设计精巧。局限：驾驶专用（非通用视频）；SRR离线进行。
