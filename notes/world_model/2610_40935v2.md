# Let LiDAR Decide Where to Look: Geometry-Measured Token Selection for Efficient Sparse Latent World Models

## Insight
驾驶规划的密集视觉 token 可能稀释关键目标的注意力：随机保留 25% token 已比密集基线降低轨迹误差。若利用编码前的 LiDAR/雷达几何选择区域，可同时减少视觉主干计算、保留危险车辆与道路信息；实验观察支持此任务特定结论，注意力熵下降本身不是因果证明。

## Motivation
六相机 DINO 类视觉主干每帧产生数千 token，世界模型与规划器都需处理大量天空/背景。多数 token 稀疏法在视觉主干之后决定保留项，无法削减主要编码成本。

## Method
投影多帧 LiDAR 和雷达到图像 patch，按障碍、道路、视觉保留三路评分并固定预算取前 K；障碍特征含高度、运动残差、雷达径向速度与自车路径距离。仅对保留 patch 运行稀疏 DINOv2；给每 token 附 LiDAR 中位 3D 锚点，跨镜头/时间对齐，以未来特征和伪匹配 3D 位移做自监督预测，再由轨迹头及预测碰撞代价选自车轨迹。稀疏主干另需 3+3 epoch 蒸馏。

## Experiment
nuScenes 25% token 时 3 秒轨迹 L2 为 0.520 m、密集融合 0.573 m；NAVSIM EPDMS 88.9 vs 85.9，总计算 66 vs 433 GFLOPs。10% token 为 0.537 m、87.9 分、24 GFLOPs。在 739 个按真实急刹/横移挖掘的场景中，危险车覆盖 95.8%，碰撞 0.09%（密集 0.34%）。去 3D 锚点使 L2 从 0.520 升至 0.958；去世界模型升至 0.574。报告运动 EPE、图像腐蚀鲁棒性和注意力熵；不同选择器的 EPE 因目标分布不同不能直接横比。

## Value
对 3D 锚定的稀疏潜世界模型有直接启发：先用廉价几何决定视觉预算，再对保留 token 做时空预测与规划；适用于高算力成本的多视角输入。

## Strengths
完整计算账本包含主干、世界模型和规划器，兼顾规划质量、危险覆盖与组件消融。

## Weaknesses
需要 LiDAR（nuScenes 另用雷达），相机单模态不适用；FLOPs 不是端到端实际时延。patch 粒度可能漏转向灯等细节；危险场景由真实未来行为筛出，非真实闭环频率估计。

## Future Work
作者提出对选中区域使用更高分辨率，并需验证不同硬件上的实际时延及相机单模态适配。

## Rating
创新度评分：3/5 - 编码前几何选 token 加 3D 锚点较有效，但三路规则和世界模型结构属渐进组合。
相关度评分：3/3 (Core) - 直接研究 3D 锚定的稀疏潜世界模型及规划效率。

## TL;DR
用 LiDAR 在视觉编码前挑选并锚定关键 token，以更低算力改善预测与驾驶规划；值得精读。
