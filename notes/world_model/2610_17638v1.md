# Acting Through Registers

## Insight
FastWAM 中少数空间 token 的范数约高一数量级、位置跨样本稳定；K/V 归一化后幅度异常消失，但逐 token 屏蔽仍改变动作，说明它们承担部分脱离原位置的动作相关表示。加入非空间 register 只压低中层异常，给观测 token 加流匹配监督才压低末层异常；两者组合将高范数响应集中到 register。作者以层级范数、K/V 与动作敏感性干预及对照训练支持这一解释，并谨慎承认未识别其语义内容。

## Motivation
视频生成骨干常向动作扩散器传输密集空间 token，潜在的非空间动作信息可能占用图像位置，且长上下文增加逐步去噪成本。现有 WAM 多追求更强生成或更快采样，很少解析世界表示如何组织动作信息。这是世界—动作接口的实质问题。

## Method
在 Wan2.2 视频 DiT 的观测/未来 token 中加入可学习 register；逐层将 register 的 K/V 缓存供动作 DiT 交叉注意力使用，视频 DiT 只运行一次。训练含动作 FM、干净观测 token 的 FM、纯噪声未来 token 的 FM，以及独立噪声观测恢复 FM；所有视觉损失均不监督 register。未来输入在训练与推理都是纯噪声，动作端迭代 10 步。结构借鉴 ViT register，创新主要在异常 token 诊断与观测侧监督组合。

## Experiment
LIBERO-Plus 10,030 回合、只用 LIBERO 训练：平均成功率 81.64%，FastWAM 51.5%、Faster-WAM 两版 75.0%/73.6%；RoboTwin 2.0 平均 93.0%，FastWAM 91.9%。真机双臂 6 设置各 20 次，分步任务均分由 0.3483 提至 0.5238，但蓝色桌布设置均为 0。20% LIBERO-Plus 消融：强基线 76.29%，加噪观测 FM 78.59%，再加 register 与干净观测 FM 82.52%；8 个 register 最优。迁移 ImageWAM：83.10%→85.42%。可视化表明中层/末层异常分别受 register/观测 FM 约束。

## Value
提供检查隐式世界状态是否把全局信息塞进空间 token 的诊断办法，也展示用少量潜 token 构造动作接口的可行性，值得作为世界—动作表示研究的设计参考。下一步应评估 register 保存了什么物理或任务信息，以及其对不同规模模型和环境变化的稳定性。

## Strengths
由层内异常观察出发，追踪归一化后的作用，再通过屏蔽干预和联合训练验证；真机、模拟与跨视觉骨干都有结果；作者没有把高范数 token 误称为唯一动作 token。

## Weaknesses
异常分析聚焦有限 WAM 架构，尚无 register 内容可解释或因果充分性证明；累计消融未完全析因，观测 FM、register 接口与损失权重的独立贡献仍可能混杂。LIBERO-Plus 与真机尚存显著 OOD 失败，且未报告完整推理速度收益。

## Future Work
作者在局限中指出，应厘清异常/register 编码的信息，并检验其对模型规模、训练目标及优化历史的依赖；未给出具体新算法。

## Rating
创新度评分：4/5 - 对 WAM 表示异常作逐层与干预分析，并将 register、观测去噪监督转为有效动作接口；组件并非全新。
相关度评分：3/3 (Core) - 直接研究视频世界模型内部表征及世界—动作耦合。

## TL;DR
识别世界动作模型的高范数空间 token，以寄存器和观测流匹配构造高效动作接口；表征诊断值得精读。
