# Safe, Persistent, and Evolving Agent Harness for Understanding Partially Observable Worlds

## Insight

观察：企业 API 返回“成功”可能隐藏跨记录副作用，基于旧状态的合规检查会出错。推论：须把带证据的动态状态和经主动试探验证的静态隐藏规则分开管理。GLM-5.3-Flash 上无静态规则时安全任务完成率由 75% 降至 40%；跳过假设验证则由 75% 降至 65%，是该系统内的实验证据。

## Motivation

企业代理既要完成长流程、多表记录任务，也要满足组织政策；ReAct 和普通代理记忆难同时处理隐藏副作用、状态持续性、审批约束。此处的“world”是数据库和工具调用环境，和视觉场景预测是不同问题。

## Method

E-Ledger 让任务代理提议工具动作并预测状态变化；政策上下文代理从动态账本绑定证据，代码审批层给出执行、查询、探查或阻止，状态跟踪代理按反馈更新账本。静态层记录带适用条件的隐藏动作副作用规则。WorldAbduct 从状态预测一致性、工具观察缺口、政策门控、目标判断四个角度诊断轨迹，产生规则候选或直接 harness 更新；验证代理在新环境设计试探动作，只把有证据支持的规则写入静态层。创新在“主动归因和验证隐藏规则”与合规执行的结合。

## Experiment

World of Workflows 按训练/验证/测试 2:1:2 分割，报告安全任务完成 STCR、完成 TCR、政策安全 PSR、步数、成本；还测 ScienceWorld 与 DiscoveryWorld。四种 LLM 上 WorldAbduct 的 STCR 为 65/70/75/80%，较最强演化基线高 5–15 个百分点；GLM 上完整方法 75/80/95%，无验证 65/80/85%（STCR/TCR/PSR）。54 条已采纳规则中人工审核 49 条完全正确、5 条部分正确；64 次验证检查中 50 直接通过、8 修订后通过、6 未解决。ScienceWorld 成功率 71.7%，DiscoveryWorld 93.8%。附录说明各配置只做单次运行。

## Value

对代理工程的可审计状态维护与隐藏规则验证有参考性；对用户的视频、3D、JEPA/Dreamer 世界模型没有直接技术联系，建议跳过。

## Strengths

把政策代码、状态账本、隐藏规则证据各自明确化；通过新环境试探减少误归因；同时报告成功、安全、步数与金额；有规则正确性人工审计。

## Weaknesses

强依赖环境可重置并可进行额外验证调用；单次运行且 WOW 测试任务规模有限，缺少方差。规则适用边界仍有 5/54 条不完整；试探有额外交互成本，表中测试成本未代表全部演化投入。没有视觉感知、视频预测或物理状态仿真。

## Future Work

作者未给出明确的后续研究计划；可由局限推及应测重复运行稳定性与验证成本，但这属于本笔记推论。

## Rating

创新度评分：2/5 - 在代理 harness 中加入有验证的隐藏规则管理，属于已有工具代理与演化流程的增量组合。
相关度评分：0/3 (Noise) - 企业数据库/工具代理论文，与指定视觉、3D 或隐式世界模型方向无实质关联。

## TL;DR

用状态账本、代码审批和主动试探提升企业工具代理的安全完成率；与视频、三维或隐式世界模型无关，可跳过。
