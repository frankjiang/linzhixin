# SG-WAM: Self-Guided World Modeling in Geometry-Aware Policy Space

## Insight

Observation：隐式 WAM 即使预测 latent，也可能因目标来自外部编码器而与动作策略错位；而直接使用策略 latent，又未必保留操作所需的局部几何。论文据此推论：未来预测目标应与动作头共享表征族，同时由几何教师约束其中的空间结构。作者用同一策略的 EMA 分支生成未来动态 token 目标，并以冻结 VGGT 对策略图像 token 做几何对齐；消融显示世界建模、几何监督分别带来 1.9、0.9 个 LIBERO 平均成功率百分点，二者结合最佳。该证据支持互补性，但尚不能证明 EMA latent 真正形成了可用于反事实规划的完整世界状态。

## Motivation

显式 WAM 预测像素、深度或视频，容量会消耗在纹理、光照等非任务因素上；既有隐式 WAM 虽减轻重建负担，却常用独立未来编码器、预训练特征或辅助条件空间，目标与动作头实际消费的表征可能不一致。操作还要求精细 3D 空间关系，仅追求动作相关压缩可能丢失几何。论文瞄准的是 WAM 中“预测空间是否既服务控制、又保留几何”的关键问题，方向核心且问题成立。

## Method

Qwen3.5-0.8B VLM 接收主视角、腕部图像、语言及 8 个可学习 dynamics tokens；完整上下文供条件流匹配动作头生成 8 步连续动作块。当前 dynamics states 经 projector 压至紧凑空间，SGWP 先在 token 间自注意，再以其为 query 对带时间位置编码的 8 步真实中间动作做交叉注意，预测未来 latent。未来观测由同构 EMA VLM、EMA dynamics tokens 与 projector 编码，作为 stop-gradient MSE 目标。冻结 VGGT-1B 从主视角提取 37×37 几何特征、池化为 8×8，以余弦损失对齐策略主视角 token。总损失为动作流匹配、几何对齐和未来预测之和；教师、EMA 与 SGWP 仅训练时使用，部署只保留 VLM、动态 token 和动作头。创新主要是把 EMA 自举预测和几何蒸馏共同落在策略内部 token 空间，组件本身均非全新，属于有针对性的强组合。

## Experiment

仿真在四个 LIBERO 套件联合训练 40k steps，并把同一 checkpoint 零样本评测于 LIBERO-Plus 七类扰动；指标为任务成功率。SG-WAM 在 LIBERO 平均 98.5%，与最强基线持平；在 LIBERO-Plus 为 73.0%，高于 OpenVLA-OFT 69.6%、VLA-JEPA 62.9% 和 Fast-WAM 50.0%，但机器人形态扰动并非最佳。真机 UR5e 上每项采集 100 条示范，三任务 ID 及背景、光照、新物体 OOD 条件下，相比 VPP 与 VLA-JEPA 均占优，例如 Pick-and-Place ID 为 75% 对 30%/35%；长程 Toolbox ID 为 50% 对 30%/20%。消融包括几何/世界建模 2×2、动态 token 数量（1/4/8/16）、真实动作替换全零动作，以及注意力可视化；全零动作令平均成功率由 98.5% 降至 97.6%，说明动作条件有贡献但效应不大。主要比较表中的很多仿真结果直接取自原论文，模型规模、预训练和训练协议并不完全同质；真机每条件仅 10 或 20 次，且未报告方差或显著性。

## Value

工作给隐式 WAM 一个实用设计原则：不要只问“预测什么 latent”，还要问“该 latent 是否就是控制路径的一部分，以及是否保留任务几何”。训练辅助分支可全部裁掉，部署成本低，适合轻量 VLA。启发在于将 JEPA 式自举目标、动作条件和 3D 几何教师统一到策略表征；待解决的是验证该状态能否跨更长时间、多动作分支滚动，是否支持显式规划，以及收益究竟来自未来动力学、几何蒸馏还是额外正则化。

## Strengths

问题定义清楚，预测空间与控制空间的错位分析有针对性；模型仅 0.9B、无大规模具身预训练却取得强仿真和真机结果；同时覆盖 ID、零样本扰动、长程及可变形物体，并用模块、token 数和动作置零消融检查关键设计；推理时无额外世界模型分支。

## Weaknesses

EMA 目标会随在线策略共同变化，缺少防坍塌与表征质量的直接诊断；动作置零只下降 0.9 点，暗示预测或主要利用当前状态和时间相关性。几何教师仅处理单帧主视角，所谓“几何感知动态”没有以 3D 状态/运动误差直接评测。仿真基线协议异质，真机样本量小且无置信区间；没有多步 open-loop latent rollout、反事实动作分支、规划收益或计算/训练成本分析。

## Future Work

作者提出扩展到更大策略骨干和更广的跨形态数据集，以支持多种机器人形态与操作任务。进一步应加入长时多步 latent rollout、动作反事实与闭环规划评测，并分析动态 token 的可辨识状态语义和不确定性。

## Rating

创新度评分：3/5 - 策略同构 EMA 目标与几何蒸馏的耦合设计扎实、效果强，但核心组件是现有 JEPA/BYOL、VGGT 与流匹配的组合，尚未形成新范式。
相关度评分：3/3 (Core) - 直接研究几何感知的隐式世界动作模型，与 JEPA 式 latent dynamics、3D 表征和机器人控制高度相关。

## TL;DR

在策略内以 EMA 未来目标和 3D 几何监督学习动作条件 latent，证据扎实，值得精读。
