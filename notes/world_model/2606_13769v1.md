# $μ_0$: A Scalable 3D Interaction-Trace World Model

## Insight
核心 insight 是：机器人世界模型不必预测 dense pixels，也不必直接预测 embodiment-specific actions；预测“语义交互点的 3D traces”能在视频规模数据与机器人控制之间形成更紧凑、跨 embodiment 的运动接口。Observation 是像素视频浪费容量在外观背景，动作标签稀缺且硬件绑定；3D interaction traces 则保留几何、接触区域和目标运动。

## Motivation
视频数据丰富但缺动作；VLA 动作监督昂贵且不可跨机械臂直接复用；像素生成世界模型难以把 metric geometry/contact motion 变成控制信号。已有 2D flow/3D flow/TraceGen 等方法存在小接触区域采样不足、局部/2D 坐标混入相机运动、episode-level caption 与局部事件不对齐的问题。论文要构建可规模化抽取 3D trace 监督的数据引擎和可冻结复用的 trace world model。

## Method
TraceExtract 从人类/机器人视频自动产生 `{observation, language, query keypoints, 3D traces}`：用 DINOv2 patch cluster 选择对象/工具/手/接触区域语义 keypoints；用 global sparse + local dense reconstruction 建全局 3D 坐标并跨 chunk 跟踪；用 trace acceleration 做 motion-centric chunking，再用 VLM/LLM 生成事件级 caption。μ0 使用预训练 VLM backbone 加 permutation-equivariant Trace Expert；每个 query 的未来轨迹用 B-spline control points 表示，并用 semantic flow matching 训练。下游时冻结 VLM 和 trace expert，action expert 读取 trace-denoising features、机器人观测/本体/语言，输出可执行 action chunks。

## Experiment
Trace prediction 上，μ0 在 3D ADE/FDE/DTW 全指标和 T=8/16/32 全 horizon 最好；例如 3D top5-DTW 为 0.127/0.187/0.223，优于 TraceGen 0.204/0.262/0.299，推理 0.29s。RoboCasa365 8 个任务中，μ0+action expert 平均成功率 30.25%，高于 π0 25.25% 和 TraceGen+expert 23%，低于 π0.5 的 42%。真实 UR3 三任务中平均成功率 91.7%，高于 VLM+expert 73.3、π0 71.7、π0.5 80、TraceGen 81.7。消融显示 B-spline、DINOv2、rigidity loss、historical traces 均有贡献；数据/模型 scaling 单调改善，2.59B 全数据 top5-DTW 最好；小 action head 下 trace features 增益更大。

## Value
这是本批最核心的 3D 世界模型工作。贡献不只是模型，还包括可扩展 trace supervision pipeline 和 action-free video pretraining 到机器人控制的接口。创新度高于一般组合式论文，尤其“3D interaction traces as world model interface”很值得借鉴。仍有局限：trace 质量依赖 DINO/VGGT/TAPIP3D/captioning 管线；未显式建模力、触觉、接触模式；真实实验任务和 embodiment 范围有限。
