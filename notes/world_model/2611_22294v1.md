# Perception into Imagination: Executable Memory for World Models

## Insight
观察：在部分可观测环境中，目标离开视野后仍有用，但动作会改变它相对智能体的位置；仅把旧记忆作为静态输入，会使想象中的奖励与可达性判断失准。推论：在 Dreamer 的潜状态滚动旁同步执行显式记忆转移，并让奖励头、价值头和策略读取更新后的事实。9×9 Memory Maze 中，固定记忆加奖励读取反而比不读取低 5.10 回报，动态演化加奖励读取提升；这一交互消融支持“记忆必须随候选动作演化”。

## Motivation
Dreamer 等隐式世界模型可以用想象轨迹训练策略，但循环潜变量或外部地图未必把失去可见性的感知事实正确传递到未来奖励目标。问题不仅是记住事实，还在于训练信号是否使用动作后的事实。该问题对部分可观测具身规划是核心问题。

## Method
EPM 在真实交互时用感知写入器更新稀疏目标、位姿或触觉状态；想象锚点从真实历史初始化局部显式记忆，随后每个候选动作同时推进 DreamerV3 潜状态和由预测位移驱动的记忆，读取相对方位、距离、年龄等。读出进入奖励头以及 actor、critic；真实奖励按产生它的动作从旧记忆前推后对齐，避免用下一观测或已切换目标“偷看”。另用记录动作做 15 步开环想象奖励损失，只更新奖励头。导航实例的更新规则由任务几何定义，并非端到端学出的通用世界状态。

## Experiment
DreamerV3 12M 参数，Memory Maze 9×9/13×13 各训练 100 万交互，MiniWorld 9×9 训练 200 万。EPM 回报分别 25.20/30.37/21.83；只让动态记忆进策略和价值的 Evolved 为 19.12/23.37/18.09。13×13 对仅观测编码记忆为 14.18，收益 16.19；直接奖励读取相对“Evolved+开环损失”在两种 Memory Maze 分别 +5.51/+11.39，但 MiniWorld 终点 +1.00 的区间跨零。记忆目标离视野后的奖励预期在 9×9 从 0.154 升至 0.587；这是模型预测质量诊断而非成功概率。辅助实验：Concentration 保留已翻卡身份的想象训练回报约 0.44，对重采样约 0.12；触觉失联后的路径选择较静态命令多推进 10.47 mm；真实 GelSight 32 次接触后 48 字节记忆数字识别率 0.417，无历史为 0.187，128 维 GRU 为 0.485。

## Value
值得精读“感知记忆→候选动作下的演化→奖励/价值训练信号”这一接口及其多臂消融。对 JEPA/Dreamer 类隐式模型的部分可观测规划有直接启发：仅在策略输入中拼接记忆不足以保证想象奖励一致。

## Strengths
同一视觉前端、参数量与初始化下比较静态/动态记忆、奖励接入和开环监督；提供奖励与记忆的时间对齐细节；用可见/不可见目标奖励预期探针检查机制，并报告部分未显著的结果。

## Weaknesses
视觉导航的检测器、里程计与朝向网络用模拟器标签离线校准，且读出只跟踪当前目标的局部几何，依赖任务先验，扩展到复杂物体交互未证实。13×13 的外部 Dreamer/R2I 对比训练预算和感知前端不同，不能当成纯算法优势。MiniWorld 终点奖励接入的边际收益不确定。触觉恢复与常起点航位推算对比无显著优势；真实触觉主实验用整轮 256 次接触的离线背景预处理，不是严格在线因果流程。

## Future Work
作者提出让局部记忆进一步覆盖想象中的新观测、目标切换及更丰富的接触转移，并把机制推广到更复杂物理交互。

## Rating
创新度评分：3/5 - 将可执行感知状态同步接入 Dreamer 的想象及奖励学习，接口和消融有新意，但状态结构依赖任务设计及离线校准。
相关度评分：3/3 (Core) - 直接改进 Dreamer 式隐式世界模型在部分可观测环境中的想象与控制。

## TL;DR
让显式感知记忆随候选动作演化并进入想象奖励，提升部分可观测控制；研究 Dreamer 接口值得精读。
