# Enfold: Folding World Model Imagination into Predictive Representations for Ultra-Efficient Embodied Control

## Insight

Observation：视频生成器在把受噪未来变成连贯轨迹时，不同 block/timestep 的中间状态分别组织外观、布局与交互；但这些状态依赖部署时不可见的真实未来和噪声。论文推论：让只看当前图像与指令的 encoder 回归 teacher-forced 生成器多层状态，相当于把随机 target 投影到当前信息可预测的条件中心，无法预测的未来/噪声残差自然被滤除。附录对平方损失证明 population optimum 是 `E[r_t^G|current,t]`，并明确指出确定性 representation 不会增加给定当前观测后的未来互信息。实验证实学生的光照敏感度仅为生成特征的约 1/8–1/10，长时变化区域预测反而更强，支持“内化可预测生成计算，而非复制所有 teacher variation”。

## Motivation

imagine-then-act 和统一 WAM 让控制依赖昂贵视频 rollout；Fast-WAM 等虽可跳过像素解码，仍在控制路径保留生成分支或与视频建模紧耦合。JEPA 预测未来 encoder endpoint，却未利用生成器沿深度与噪声轨迹构造未来的内部计算。论文要把生成器从在线 simulator 改造成训练时 predictive representation teacher，在不运行 generator 的前提下保留未来导向信息。这是视频 WAM 效率与隐式预测表征的核心问题。

## Method

当前视觉 context 与语言经 DINOv3 ViT-H+/16 predictive encoder 得到 `z`。G2R 对真实未来 latent 加噪，Cosmos-Predict2.5-2B 在 context、instruction 和 detached `z` 条件下做单次 teacher-forced pass；取 blocks {7,15,23,27} 的 spatiotemporal tokens 拼接、LayerNorm，timestep-conditioned 10-layer head 从 `z` 用 SmoothL1 回归该 stop-gradient target。R2G 让 detached `z` 条件化 Cosmos 的 flow-matching future generation；它训练 generator 更好使用 z，但生成 loss 不回传 encoder。动作 flow-matching head同样只读 detached z，任务梯度不塑造 encoder，因而控制性能检验 G2R 表征是否可读。部署只跑 encoder+10/16-layer action head；Enfold-Flash 再用 TensorRT。设计新颖之处是蒸馏多层“生成过程 state”，并以严格梯度隔离把 representation learning 与 task readout 分开。

## Experiment

LIBERO 四套件以 1712 demonstrations 训练、每任务 50 trials；Enfold/Flash 平均成功率 97.8/97.5%，Fast-WAM 97.6%，但最佳 Cosmos-Policy/LingBot-VA 为 98.5%。同 A100 上 latency 为 134/49 ms，对 Fast-WAM 493 ms 提速 3.7×/10.1×。RoboTwin2.0 50 双臂任务、27500 demos，clean/randomized 平均 91.77/92.02%，与 Fast-WAM 91.83 和 LingBot-VA 92.20 基本持平，作者正确承认无不确定性不足以排名。真机 AgileX 四任务、各 100 demos、每 method/task/setting 30 rollouts，Enfold ID/OOD stage-normalized score 89.7/76.6，高于 Fast-WAM 77.8/70.0，但 OOD 低于 π0.5 的 83.3。监督消融中 action-only/future-pixels/single-level/multi-level 为 94.9/96.0/96.3/97.8%；z 条件化视频生成使 PSNR 25.92→27.27、SSIM .885→.902、LPIPS .0550→.0483。100-clip 表征分析显示光照敏感度 0.020 vs teacher 0.157–0.208、effective rank 31.8 vs ≤10.7；most-changing patches 上未来 DINO 残差改善 t=1/16/32 为 4.6/18.1/18.2%。两次人工移动盘子/毛巾后，想象与动作均改道，但只做定性展示。

## Value

Enfold 给出很有价值的架构原则：世界生成器的作用不一定是每步产出视频，它也可作为训练时计算轨迹教师，把可预测的未来结构摊销到当前 representation。对 JEPA/Dreamer 的启发是监督目标可从“未来 endpoint latent”扩展到“生成/推理过程中的多尺度 states”，并用 detached readout 验证其任务无关可用性。它尤其适合计算受限机器人控制；待解决的是如何保留多模态/不确定未来，而条件中心回归倾向于平均化，并验证在真正需在线规划的任务上能否替代 imagination。

## Strengths

问题与信息流界定清楚，附录主动说明 z 不会凭空增加未来信息，理论表述克制；梯度路由使动作成功更能归因于预测监督；同时覆盖单臂、50 项双臂、真机及 OOD，报告训练资源和统一延迟；监督 target、生成反向可用性、表征稳定性、长时变化区域与可视化证据互补。效率收益大，且 Enfold-Flash 把架构收益与算子优化分开。

## Weaknesses

多层生成 state 与 future pixel/action-only 有消融，却缺最关键的同容量 VLA-JEPA/frozen future-encoder endpoint、随机/非生成多层 feature 教师对照，无法确定收益来自“生成计算”而非更丰富蒸馏 target。R2G 对 z 完全 detach，因此不会反向改善 representation/control；所谓双向 coupling 主要是 forward reuse，视频指标提升也可能来自额外重参数化/容量。z 只由当前 observation+language 决定，学习的是数据策略下可预测的平均未来，未显式接收候选动作，不能做反事实 action rollout。主仿真已饱和，差值很小且无 seeds/CI；多数基线数值来自各论文，训练协议可能异质。人工 intervention 仅两例且无冻结表征/无 intervention 对照或恢复率，不能支持强 counterfactual 结论。generator-state probe 仅 20 视频，层选择可能过拟合小样本趋势。

## Future Work

作者未单列未来工作，但明确承认训练仍需生成器、干预证据仅定性。后续应比较 endpoint-JEPA 与多层非生成教师，加入 action-conditioned、多模态/不确定 latent，量化大规模干预恢复和闭环 replanning，并探索只在高不确定/高价值时按需调用 generator 的混合控制。

## Rating

创新度评分：4/5 - 将视频生成器的多层去噪计算摊销为当前可读 predictive representation，接口与梯度设计有显著新意，效率和跨平台证据强；关键归因与反事实能力仍未闭环。
相关度评分：3/3 (Core) - 位于视频世界模型、隐式预测表征与 WAM 控制接口交叉处，对 JEPA/Dreamer 研究直接相关。

把视频生成器中间计算蒸馏进当前表征，显著提速控制且机制清楚，值得精读。
