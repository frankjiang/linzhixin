# SpatialCrafter: Single-Image World Modeling with Generative 3D Proxies

## Insight

作者观察到两类常用空间记忆都存在结构性缺陷：由单图重建的静态点云永远缺少遮挡区；让视频模型先 hallucinate 再把生成帧回灌增量点云，则会把视觉错误永久写入后续几何。由此推得，应在生成视频之前一次性形成全局 3D 假设，让显式几何负责跨视角状态，视频扩散只在该几何上恢复外观。论文通过 PaSS 锚点消融、81 帧大相机运动和 RPE/RVE 证实：与输入坐标对齐的生成式代理显著减少漂移，RGB-D 注入与代理缺陷增强进一步改善细化；但“全局完整”仍是模型生成的假设，而非几何正确性的证明。

## Motivation

单图可探索场景生成服务于游戏、VR、导航和具身智能。纯视频扩散缺少显式 3D，历史帧 memory 在复杂相机运动下容易出现透视、遮挡和 loop closure 错误；静态重建代理对未见区域无约束，增量代理又依赖待增强的视频模型自身，并累积深度和配准误差；单中心 panorama 不能提供大平移下的真实视差。论文解决的是 3D/视频世界模型的长期空间一致性问题，同时补足场景级 3D 训练数据稀缺，问题重要且与用户方向直接相关。

## Method

1. 输入单图 $I_0$、预测深度、初始相机位姿和用户相机轨迹。将可见 RGB-D 反投影并 voxelize 为稀疏锚点 $V_{cond}$。
2. Point-Anchored Sparse Structure（PaSS）Flow 基于 TRELLIS/SLAT：把 noisy voxel 与 $V_{cond}$ 按通道拼接，用条件 flow matching 将“无约束场景生成”改成与输入坐标对齐的稀疏体素补全；随后 SLAT flow 预测 active voxels 的特征，3D Gaussian decoder 得到一次性全局粗代理 $X_{scene}$。
3. 沿目标相机轨迹渲染代理，得到一致但低质的 coarse RGB-D video。Generative Deferred Refiner 基于 Wan2.1-Fun-Control：RGB 和 depth 由冻结 VAE 分别编码后沿宽度拼成 geometry latent，再与 noisy video latent 按通道融合；参考图 latent 以 token 方式加入。冻结预训练 Video DiT，只训练 LoRA，用 flow-matching 生成最终 RGB-D 序列。
4. Parallel Geometry Injection 尽量不破坏预训练生成流形；Proxy-Aware Corruption（PAC）在训练时随机施加自适应模糊、块噪声或局部深度擦除，使 refiner 学习何处服从代理、何处修补纹理和孔洞，缩小理想训练代理与推理生成代理的域差。
5. 数据引擎处理 57,431 个 SpatialGen 房间、65,683 个 RealEstate10K 视频和 10,510 个 DL3DV 视频，最终得到 115,295 对单图到场景数据和 87,115 对可控视频数据；其中 2.2K synthetic scenes 以十条连续轨迹重渲染为 22,421 个 RGB-D 视频。

整体创新是“原生生成的全局 3D proxy + 生成式 deferred refinement”的职责分解，并用 PaSS、并行 RGB-D 注入和 PAC 打通接口。TRELLIS、Wan、3DGS 和 LoRA 均为已有组件，创新属于有力的新组合与数据工程，而非新基础模型范式。

## Experiment

- 在 104 个 SpatialGen-Video 闭环场景、100 个 RE10K 测试场景和 DL3DV 标准测试集上，从单图沿相同轨迹生成 81 帧。基线包含 2D memory 的 DFoT、GeometryForcing，以及 reconstructive 3D proxy 的 ViewCrafter、GEN3C、Voyager；另将 Voyager 用本文数据微调为 Voyager†。外观指标为 FVD/PSNR/SSIM/LPIPS，几何指标为 RPE，以及仅闭环 synthetic 可算的 RVE（rFID）。
- SpatialGen-Video 上本文达 FVD 193.54、PSNR 14.775、LPIPS 0.416、RPE 0.093，优于次佳 ViewCrafter 的 339.04/14.098/0.471/0.125；但 RVE 38.69 不及 GEN3C 的 26.60。RE10K 上以 148.71 FVD、17.185 PSNR、0.266 LPIPS、0.078 RPE 全面领先。DL3DV 上 FVD 242.30、LPIPS 0.453 最好，但 RPE 0.149 略逊 ViewCrafter 的 0.147（Table 1，PDF 第 8 页）。
- Voyager† 的 synthetic FVD 从原版 801.04 降至 363.39，却仍远差于 193.54，说明新数据有价值但不能独自解释性能；然而生成代理、训练结构和算力仍同时变化，贡献无法完全解耦。
- PaSS 的端到端消融将 FVD 472.07→193.54、RPE 0.169→0.093、RVE 153.47→38.69。Refiner 消融使用 ground-truth coarse renderings：camera-only、RGB-only、RGB-D、RGB-D+PAC 的 FVD 为 178.47/136.27/114.13/107.03，RPE 为 0.107/0.066/0.062/0.057（Table 2，第 8 页）。因此 107.03 是理想代理条件，不能与部署时生成代理下的 193.54 直接横比。
- 定性图在快速、极端视角和长程轨迹上显示，Voyager 结构崩塌，GEN3C/ViewCrafter 有几何伪影，DFoT/GeometryForcing 易停滞；完整模型保持较稳定布局。Figure 4/7 也显示 PaSS 纠正坐标错位、PAC 能修复代理黑洞，但这些均为作者选择案例。
- Proxy generator 用 16 张 H20 训练 20K steps；refiner 用 32 张 H20，先以 $256^2$ 训练 12K steps、再以 $512^2$ 训练 4K steps，每段 81 帧。论文没有报告端到端代理生成和 81 帧推理的延迟、显存、吞吐或能耗。

## Value

最有价值的设计思想是把“记住历史图像”升级为“先形成可渲染的全局空间假设”，再把视频模型作为学习型 deferred renderer。对 3D 世界模型的启发是：显式 3D 状态可以承担跨视角一致性，生成模型承担未见区域和高频外观；训练时还应主动模拟几何代理的缺陷。目前它更接近静态场景的 camera-conditioned world renderer，而非能预测动作后物体状态和物理交互的通用世界模型。

## Strengths

- 问题分解直接针对单图生成代理最致命的坐标错位，而非简单增加视频上下文。
- 一次性 3DGS 代理约束完整 81 帧 RGB-D 轨迹，在大视角变化下兼顾外观和几何一致性。
- 建立 115K 级混合场景数据，并以 Voyager† 证明数据本身确有收益。
- proxy anchor、RGB/depth 条件和 PAC 均有消融，主要性能提升在 synthetic 与真实域重复出现。

## Weaknesses

- 最强反例是：SpatialGen 闭环 RVE 38.69 落后 GEN3C 的 26.60，DL3DV RPE 0.149 也略差于 ViewCrafter 的 0.147；因此“全局代理解决长期几何一致性”并非所有几何口径上都成立，外观综合优势不能等同于几何最优。
- 场景是静态的，控制量只有相机轨迹，没有物体动力学、agent action 或交互；标题中的 world modeling 能力边界较窄。
- “global complete 3D proxy”是生成假设，不是可验证的完整几何。论文主要评估最终视频，没有直接测代理的 3D 重建误差、遮挡拓扑或未见区域正确率。
- refiner 的四阶段消融使用 ground-truth coarse renderings，部署却使用生成代理；PAC/RGB-D 数字更像理想上界，没有完整反映两阶段误差耦合。
- SpatialGen、RE10K、DL3DV 同时提供训练来源和测试域；即使 split 独立，也缺少全新数据源、户外长距离和真实机器人轨迹的跨域验证。
- 训练成本高且不报告推理效率、多随机种子、置信区间或显著性；代码、权重和数据的可复现状态也未在论文中完成验证。

## Future Work

作者没有明确列出未来工作。基于证据边界，合理推断的优先方向是：直接监督并评估全局代理几何；在真实生成代理而非 ground-truth 代理上重做完整 refiner 消融；报告长轨迹 loop closure 与推理效率；验证全新数据源和机器人相机轨迹；进一步扩展到动态物体、动作条件和闭环 agent interaction。

## Rating

创新度评分：4/5 - 生成式全局 3D 代理、PaSS 对齐和 deferred RGB-D video refinement 构成完整新方法，数据规模与效果较强；但依赖现有基础模型，且动态世界能力尚未覆盖。
相关度评分：3/3 (Core) - 直接研究单图到可探索 3D 世界及长程跨视角视频一致性，是 3D/视频世界模型的核心问题。

## TL;DR

以单图生成全局3D代理再细化为一致RGB-D视频，显著减轻长程漂移；值得精读。
