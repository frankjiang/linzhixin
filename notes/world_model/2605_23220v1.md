# WMAttack: Automated Attack Search for Adversarial Evaluation of World-Model Agents

## Insight
Observation：世界模型agent的对抗鲁棒性评估面临准确性与效率的矛盾——弱攻击高估鲁棒性，穷举搜索代价过高（每个候选需闭环rollout）。核心发现：具有相似latent动力学的任务对相似攻击配置敏感，可以跨任务迁移攻击经验。

## Motivation
问题：世界模型作为决策agent日益普及，但缺乏系统的对抗评估方法。手动调参攻击不可靠，穷举不可行。本文将鲁棒性评估形式化为有限预算下的攻击配置搜索问题。是安全性研究中的实际需求，但非世界模型本身的核心研究方向。

## Method
WMAttack框架：
1. RGAR（表示引导攻击检索）：提取task-agent对的latent行为摘要，在攻击记忆库中检索相似任务的历史有效配置作为warm start
2. SCAS（自校正攻击搜索）：基于reward degradation、action instability、runtime cost、rollout variability的多维反馈，迭代更新攻击提案分布
3. 标量化utility函数综合评估攻击效果

攻击空间：攻击族（APGD-CE/DLR、FAB、Square、PhysCond-WMA）×扰动预算×优化步数×重启次数×分配规则

理论分析：证明反馈驱动的提案改进可在有限预算下增大发现有效攻击的概率。

创新程度：中等。本质是把AutoAttack思路推广到世界模型的闭环评估场景，加了跨任务迁移。

## Experiment
- 攻击对象：DreamerV3（26 Atari + 20 DMC）、DreamerV2、TD-MPC2、IRIS
- WMAttack在Atari上reward drop 1.034（vs Random 0.446, Claudini 0.497）；DMC上0.682（vs 0.352, 0.319）
- 跨模型泛化：DreamerV2 Atari 0.539、TD-MPC2 DMC 0.621
- 消融：RGAR+SCAS互补，RGAR改善初始质量，SCAS改善最终效用
- LLM backbone：Qwen2.5-3B最佳utility，更大不一定更好

## Value
对世界模型安全性研究有工具性价值，提供了系统化的对抗评估框架。但对世界模型本身的设计和改进贡献有限。对我们的启发：世界模型的鲁棒性是部署前需要考虑的问题，但这不是我们当前关注的核心方向。
