# ATM: Action-Consistency Transfer Matrix for Diagnosing and Improving Latent World Models

## Insight
Observation: 隐式世界模型（如 LeWM、DINO-WM）的评估通常依赖耗时的 simulator rollout + CEM 规划成功率，但这种评估是黑盒的（无法区分表征问题还是规划器问题），且计算开销极大（DINO-WM 单 checkpoint 评估可能需数小时）。

推论: 如果潜在转移（latent transition）能保持动作语义的可辨识性（action-identifiability），即从转移特征中能解码出引起该转移的动作，那么该表征更适合下游规划。可以通过训练轻量逆动力学探针（inverse probe）来快速诊断，而无需 simulator rollout。

证明: 在 OGBench-Cube 上，ATM 的 pairwise ranking 准确率达 98.81%（当成功率差距 > 5% 时），相比 CEM 评估加速超 100 倍（秒级 vs 分钟/小时级）。AITS 训练信号使 LeWM 在三个任务上分别提升 +5/+4/+10 成功率点。

## Motivation
- **问题**: 如何高效、可解释地评估隐式世界模型的表征质量，而不依赖昂贵的 simulator-based rollout。
- **同行做法**: 主流用 CEM 规划成功率评估，耗时且不可解释。部分工作研究 action reachability/consistency 约束，但停留在约束层面而非诊断工具。
- **关键性**: 随着潜在世界模型变体增多（不同编码器、训练策略、checkpoint），快速筛选好模型变得越来越重要。ATM 提供了一个轻量级诊断和排序工具。

## Method
**核心思路**: 构建 2x2 Action-Consistency Transfer Matrix。

1. **两个转移域**: 
   - True transition domain (T): 用编码器编码相邻真实帧 (z_t, z_{t+1})
   - Predicted transition domain (P): 用编码器编码当前帧 + 动力学预测器预测下一帧 (z_t, hat{z}_{t+1})

2. **转移特征**: xi = [z_t, z_{t+1}, z_{t+1} - z_t]（包含状态和差分信息）

3. **逆探针**: 训练两个轻量 MLP 逆动力学探针 h_T 和 h_P，分别在两个域上学习从转移特征预测动作。

4. **ATM 矩阵**: 交叉评估两个探针在两个域上的性能，得到 2x2 矩阵 [D_{T,T}, D_{T,P}; D_{P,T}, D_{P,P}]。
   - 对角线: 域内动作可解码性
   - 非对角线: 跨域动作语义迁移性

5. **分层诊断**: D_{T,T}（表征质量） -> G_{T->P}（真实到预测的一致性） -> L_{ATM-sym}（矩阵对称性/失败模式）

6. **Screening Score**: S_ATM = -D_{T,T} - lambda_1 |G_{T->P}|，用于模型排序。

7. **AITS**: Action-Identifiable Transition Supervision，在训练时加逆动力学辅助损失，鼓励转移保持动作可辨识性。

## Experiment
- **任务**: TwoRoom（2D导航）、PushT（2D操控）、OGBench-Cube（3D操控）
- **AITS 提升**: LeWM + AITS 在三个任务上分别 +5/+4/+10 成功率点
- **排序准确率**: OGBench-Cube 上 LeWM 变体间 pairwise ranking 82.84%，成功率差距 > 5% 时达 98.81%
- **效率**: ATM 诊断 3-5 秒 vs CEM 评估 3 分钟（LeWM）/ 1.4 小时（DINO-WM），加速 100 倍以上
- **跨模型**: LeWM-DINO 跨家族排序经过简单校准后达 89.90%

## Value
- **价值**: 提供了一个实用的隐式世界模型诊断和筛选工具。核心洞见——"action-identifiability"是规划相关表征质量的良好代理指标——简洁且有理论吸引力。AITS 作为训练信号也简单有效。
- **启发**: "转移特征是否保留动作语义"是评估隐式世界模型的一个好视角。ATM 可以作为超参搜索/checkpoint 选择的快速筛选工具。
- **局限**: ATM 是 within-task 排序工具，跨任务比较不适用；AITS-P（predicted domain 监督）有时会引入域特异性 shortcut；单模态逆探针可能不足以覆盖所有失败模式。

## Strengths
