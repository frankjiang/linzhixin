# Was the Model Given the Right Action? Auditing and Repairing Action Interfaces in Navigation World Models

## Insight
观察：NWM 使用相同冻结权重，仅把测试动作改为训练代码的编码，RECON 视频预测误差就降低 42%；只修正归一化偏置反而更差。推论：动作条件世界模型的评测首先依赖训练/推理动作接口的整体一致性，单项补丁可能被其他错误抵消或放大。作者对比两套代码的受控动作探针、配对生成和多模型故障注入验证这一点；相同路径若角度数值离开训练范围，也会严重损害预测。

## Motivation
视频世界模型通常比较给定动作后的帧预测，但默认评测动作与训练动作语义一致。NWM 训练与发布的 rollout 代码分开，现有动作遵循度基准关注模型响应，未检查送进模型前的坐标系、归一化、角度等编码。该问题会直接改变误差、模型排名，属于评测可信度的关键问题。

## Method
发现 NWM 三处相互作用的差异：训练逐段采用段起点的机器人坐标系，rollout 固定首段坐标系；训练每段加位移偏置 $(-1/3,0)$，rollout 仅首段添加；训练对每段偏航角 wrap，rollout 对相对首段的角度差分，可产生 $2\pi$ 跳变。修复直接复用训练编码器。另提出 ActRosetta：以静止、平移、转弯、跨 wrap 等探针查询训练/测试编码器；拟合可表达的动作接口约定，在候选合同全部一致且有实际见证路径时指认字段，仅在完整约定可确定时按位姿或可逆映射修复。方法是实用评测审计，借鉴 ActionABI 的约定识别思想。

## Experiment
NWM XL 在 150 个 RECON 片段上，1–16 秒平均 DreamSim 从 0.240 降至 0.139（42%），16 秒误差下降 51%；同时报告 LPIPS、轨迹 bootstrap 区间。自身动作在五个候选未来中被正确识别的片段由 15/50 增至 40/50。五个 NWM checkpoint 均改善，但 Ego4D 版本仅降 0.008；修复会改变 checkpoint 排名，缩小或逆转 EgoWM、RAE-NWM 的领先。给 EgoWM/RAE-NWM 注入错误均会加大 DreamSim；SCAND、Go Stanford 上修复仅改善 0.006/0.005，Habitat 决策无可检测增益。ActRosetta 在最终封闭的 240 对接口中检测 91/91 真实差异、无 53 个无差异误报，但仅准确归因 73/91，低于预设 95% 目标；可修复的 38 对误差近浮点精度。40 个公开仓库审计发现 5 个差异，第二层诊断对它们全部拒答。

## Value
对动作条件视频世界模型的评测非常有借鉴价值：在公布 rollout、跨模型比较或训练策略之前，务必做超过一个预测段的训练/推理动作接口一致性测试；同时测动作响应强度和真实决策收益。视觉误差改善不能自动解释为控制能力改善。

## Strengths
冻结权重的配对实验定位干扰因素；联合补丁与单项补丁、跨检查点、跨模型注入相互印证；公开负结果、置信区间和工具未达目标的情形，审计原则可直接复用。

## Weaknesses
主要效果集中在 NWM 与 RECON，Ego4D 模型训练编码无法核验；ActRosetta 只覆盖有限平面动作合同，在真实仓库中的字段归因覆盖率低，封闭测试仍由其合同家族生成；尚未证明修复提升下游规划/控制。

## Future Work
作者未给明确路线图；顺着局限应扩展到 3D/机械臂、离散 token、异步时间与非线性编码，并以真实闭环执行验证接口修复的决策收益。

## TL;DR
NWM 训练与测试的动作编码不一致导致视频误差虚高，完整修复可降 42%，并改变模型比较；评测设计值得精读。
