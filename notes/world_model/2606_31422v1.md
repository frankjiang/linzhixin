# Ask the World Before Acting: Budgeted Environment Probing for World-Model Calibration

## Insight
主要 insight 是长程语言 agent 的 world model 校准可以被看成有限预算探测问题。观察是错误常发生在行动前的信念状态，而不是最后一步动作；环境中有可查询证据，但查询会消耗同一个任务 horizon。论文用子模 belief repair 和 task-side displacement 推出 probe-action frontier：探测提高世界状态准确率，但会挤占完成任务的动作预算。

## Motivation
论文解决长程语言 agent 显式 belief table 漂移的问题。同行通常让 agent 继续推理、反思或依赖自信度，而本文主张在行动前主动询问环境某个 belief field，并写回世界模型。对语言 agent 有意义，但与视频/3D/JEPA 世界模型只有概念关联。

## Method
EnvProbe 维护结构化 belief table，每个 field 有 gold value 和 agent belief。每一步在 task action 和 probe 之间选择。probe score 由 criticality、staleness、uncertainty、dependency role 组成；Simple 版本超过阈值就 probe，Judge 版本用额外模型覆核。理论部分把 belief gain 建模为单调子模函数，分析 greedy selector 的边界；并证明 self-report 在 confident-wrong 情况下会漏查关键错误。

## Experiment
实验用三个可控语言环境：ObjectStateWorld、ToolDAGWorld、GraphNavWorld，度量 world-state accuracy、task success、useful-probe rate 和 collapse onset。ToolDAGWorld 上 EnvProbe-Simple 相比 Periodic-Probe 的终态准确率提升 +11.76pp；全环境提升 +6.45pp；空间类任务提升较小。结构项 c+d 的准确率最高，但任务完成率下降，展示 belief accuracy 与 task success 的 Pareto 权衡。消融显示 criticality/dependency 是主要贡献，uncertainty 有时是反信号。

## Value
对“世界模型校准”这一抽象问题有启发：信念状态需要主动与环境对齐，且信息收集有代价。但它不是视频、3D 或隐式世界模型论文，方法也依赖显式表格和可查询 API，对用户方向只能间接参考。

## Strengths
