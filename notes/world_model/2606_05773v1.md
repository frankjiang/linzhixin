# PiL-World: A Chunk-Wise World Model for VLA Policy-in-the-Loop Evaluation

## Insight
核心 observation：现有 world model 用于机器人策略评估时采用 open-loop prediction（沿预收集的动作轨迹预测），但 VLA 策略在真实部署中是 closed-loop 的（每步观察-决策交替）。这种评估接口的不匹配导致 imagined rollout 与真实执行严重偏离。

推论：需要一个 chunk-wise 的 world model，能在每个 policy checkpoint 接受 VLA 输出的 action chunk，生成对应的多视角未来观测，再反馈给 VLA 进行下一步决策，从而实现闭环 imagined rollout。

证明：在三个双臂操作任务上，PiL-World 将 real-imagined success rate gap 从 63.2%（Ctrl-World）降至 12.0%，Pearson r=0.94。

## Motivation
- **解决什么问题**：VLA 策略的评估依赖真实机器人执行，成本高且难以规模化。现有 world model 评估方案是 open-loop 的，无法匹配 VLA 的 closed-loop 推理接口。
- **同行做法**：SimplerEnv 用仿真评估；WorldEval/dWorldEval/WorldGym 用 world model 生成 rollout，但多为 open-loop；Ctrl-World 支持 policy rollout 但缺乏历史记忆和失败轨迹学习。
- **是否关键**：随着 VLA 成为通用机器人策略主流，低成本可靠评估确实是关键需求。

## Method
整体流程：
1. **Action-to-Control Projection**：将 VLA 输出的 joint-space 动作转为头视角的 visual control frames（通过机器人运动学投影末端执行器位置到相机画面，生成 gripper marker 图），作为视频生成的动作条件。
2. **Latent History Memory**：用 VAE encoder 编码最近多视角帧为 latent features，作为未来预测的时序上下文，防止多轮 rollout 中的漂移。
3. **Joint Multi-View Prediction**：基于视频扩散模型（初始化自 Wan2.1-14B），同时预测多视角的未来帧序列。
4. **Success/Failure Fine-tuning**：在 target-task 数据上微调时同时使用成功和失败的遥操作轨迹，使 world model 能更好地捕获多样化的策略执行结果。
5. **Closed-Loop Rollout**：每轮 world model 预测一个 chunk 的未来观测，将最后一帧反馈给 VLA 进行下一轮动作预测，循环往复。

关键技术细节：
- 预训练于 RealSource World 数据集（14M 帧，11K episodes），LoRA 微调于 target-task。
- 预测 K=15 帧，stride=3，每步对应一个 world model 推理。
- 新提出 Hallucination-Free Ratio (HFR) 指标衡量 rollout 可信度。

创新程度中等，核心贡献在于 closed-loop evaluation 的系统设计和工程实现，video generation 模块本身基于已有方法。

## Experiment
- **实验方法**：与 Ctrl-World 对比，在相同任务/策略下分别执行 real-robot 和 imagined rollout，比较 success rate 一致性。
- **指标**：|delta SR|（real-imagined success rate gap）、HFR（hallucination-free ratio）、LPIPS（单步视觉相似度）。
- **结果**：
  - |delta SR| 平均 12.0% vs Ctrl-World 63.2%
  - HFR 平均 70.1% vs 41.5%
  - 所有任务 LPIPS 均优于 Ctrl-World
  - Pearson r=0.94（跨多个 VLA checkpoint 的 real vs imagined SR）
- **消融**：去掉 latent history memory 后 LPIPS 显著恶化。
- **任务**：Sort Cubes, Stack Bowls, Stack Blocks（三个双臂操作任务）。

实验规模较小（仅 3 个任务），但在其范围内结果令人信服。

## Value
- **整体价值**：提出了 VLA 闭环评估的合理范式，实验证明 world model rollout 能较好地代理真实执行结果，是实用的工程工作。
- **对我们的启发**：(1) 视频世界模型用于策略评估是一个有价值的下游应用；(2) action-to-control projection 是一种巧妙的动作条件注入方式；(3) HFR 指标值得关注。
- **待解决问题**：仅验证 3 个任务、单一机器人平台；contact-rich 任务（Stack Blocks）效果仍有差距；HFR 依赖人工标注。

## Strengths
亮点是提出了 VLA 闭环评估的合理范式，实验证明 world model rollout 能较好地代理真实执行结果，是实用的工程工作。

## Weaknesses
不足是HFR 依赖人工标注。
