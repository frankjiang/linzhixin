# FutureWorlds: Learning Robotic World Models from Alternative Futures

## Insight
用生成轨迹作相对质量学习时，候选若几乎相同，奖励差异不足；候选分叉后若概率打分仍沿用错误历史，更新又失去依据。作者把多样搜索、每分支独立记忆和同历史策略打分连成闭环：初始 BridgeV2 批次中候选 token 两两差异由普通 beam 的 0.28% 升至 30.32%，200 次匹配更新后的质量也优于普通 beam。附录推导仅说明固定候选集的相对奖励梯度结构，不证明搜索必然改进。

## Motivation
动作条件机器人视频模型在真历史教师强制训练、自己生成历史推理时会累积误差；token 似然也不直接优化整段视频质量。已有 RL 奖励优化多重评价生成结果，但候选冗余和分叉历史不一致限制反馈；长时预测还需受限上下文中的状态记忆。这是视频世界模型训练的重要问题。

## Method
先以 iVideoGPT 风格的 FSQ 上下文/动态视觉 token 训练自回归模型，按参考帧、动作和可选 T5 语言条件预测后续视频。RL 阶段以 4 组×2 beam 多样搜索在同一动作序列下生成 4 条替代未来，跨组 token 频次惩罚平衡似然与差异；每分支保留初始场景、状态锚点和最近 6 帧及动作，分叉时同步复制/重排。冻结解码器把轨迹转回视频，用真实未来的 MAE+LPIPS（BridgeV2 主实验再加运动区域及帧差）算序列奖励；MemSPO 用组内标准化优势、裁剪概率比与参考约束更新预测器，当前/旧/参考策略均按候选真实生成历史打分。真未来只用于奖励，不刷新 rollout。

## Experiment
RT-1、BridgeV2、RoboCasa 各 128 条固定轨迹，比较 32 帧 PSNR、SSIM、LPIPS 及 RAFT 光流差、运动幅度差和 DINO 相似度。主表 LPIPS 分别 0.1551、0.1409、0.1833，相比每数据集最强对照下降 14.78%、20.84%、9.12%；但主表三数据集分别用了 500/200/400 次 RL 更新。统一 200 更新对照中，32 帧 LPIPS 对 GRPO 改善 9.98%、1.58%、2.17%；相对普通 beam，匹配 GPU 评测改善 7.37%、0.20%、1.51%。固定权重的记忆消融显示「最近历史」贡献最大，初始锚点增益很小；光流误差对 SFT 降低 12.40%、4.57%、16.68%。推理占 0.257B 参数、1.89 GiB 显存，但 32 帧 beam 推理 26.76 秒，慢于 iVideoGPT 的 4.14 秒。

## Value
对视频世界模型值得精读：把候选生成分布、历史一致性和相对奖励一起设计，特别适合有真实未来视频作离线反馈的后训练；记忆消融提醒长时状态预测不能只保留最近单帧。下一步关键是闭环任务成功率和计算成本。

## Strengths
三类机器人数据、广泛视频与世界模型对照；将 200 更新 SFT/GRPO/普通 beam 控制实验与主表分开报告；有候选多样性、长时记忆、运动误差、解码敏感性和实际显存/延迟分析。明确指出 beam 搜索产生有偏候选，理论推导并非性能保证。

## Weaknesses
训练奖励仍以配对真实未来的画素/感知距离为主，可能压制合理但不同的多模态未来；基准以开放环视频重建为主，政策反馈仅选例展示，未证明实体机器人任务收益。普通与多样 beam 比较同时改变分组/beam 分配，未单独隔离多样惩罚且未报告显著性。跨方法使用原生输入接口（如 Cosmos 单帧、本文双帧）与不同适配预算，主表不能视为完全同条件因果比较；beam 延迟较高。

## Future Work
作者明确提出加速解码，并在闭环规划和机器人控制中验证预测改进。

## Rating
创新度评分：3/5 - 把多样搜索、分支记忆和组相对 RL 结合成一致的后训练方案，效果扎实；核心组件源于现有方法。
相关度评分：3/3 (Core) - 直接研究动作条件机器人视频世界模型和长时预测。

## TL;DR
用多样候选、分支记忆与相对奖励优化机器人视频未来，长时画面和运动更准但推理慢；值得精读。
