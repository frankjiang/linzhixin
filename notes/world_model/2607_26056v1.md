# INTACT: Isomorphic Intent-to-Action Learning for Search-Free World Models

## Insight
有。论文的 observation 是：forward latent world model 学会了“动作会导致什么变化”，但部署时仍要用 CEM/MPPI 反复搜索“什么动作能导致目标变化”，说明 representation 与 control 之间缺少可直接查询的 inverse semantics。作者的推论是：离线 action-labeled trajectory 中每个 transition 本身已经给出 motion intent 与 action 的配对监督；若用同一个条件 action operator 同时解释 physical successor intent 和 deployable goal intent，就能把 latent intent family 映射到 action-law family。论文用 conditional action quotient、proper NLL 下的 supported quotient recovery，以及共享/非共享 actor、actor-disabled CEM、kNN/CKA 诊断来支撑这个机制。

## Motivation
论文解决 JEPA/LeWM 类 latent world model 的 test-time search 瓶颈。传统做法训练 forward predictor，然后在推理时随机采样动作序列、rollout、按目标 latent 距离打分；这在高频控制中慢，并且训练出的 latent 不保证能直接读出 action。已有 inverse dynamics、GCSL、learned priors 或 frozen-encoder controller 各自解决一部分问题，但要么只在 observed successor 上有效，要么不能端到端塑形 encoder，要么仍依赖搜索。该问题对基于 JEPA 的隐式世界模型和机器人规划非常关键。

## Method
INTACT 保留 LeWM 的 encoder、Forward Predictor 与 SIGReg，同时新增一个共享 INTACT Predictor：输入为 `[z_t, m_t, z_t ⊙ m_t, A(a_{t-1})]`，输出 action chunk 的 diagonal Gaussian。训练时同一 operator 被调用两次：local intent `z_{t+1}-z_t` 用 attached successor 提供物理可达性监督；goal intent `sg(z_g)-z_t` 用 stop-gradient future goal 提供部署时可用的目标条件。两条分支共享 feature grammar 和参数，但不强制 latent endpoint pointwise 相等。

推理时 Direct 模式递归计算 `m=z_g-z_t`，取 INTACT Predictor 的均值作为 action chunk，再用 forward model rollout 和真实观测 replan；无候选采样、无 terminal cost。可选 Guarded A 只在 Direct plan 附近做小规模 CEM 验证。多任务版本共享一个 visual encoder，四个任务使用 task-specific predictor/head，检验 action supervision 是否能在异构任务中共同塑形 latent。

## Experiment
任务使用 LeWM 官方 PushT、Cube、Reacher、TwoRoom。单任务一轮训练、零搜索 Direct 在四任务达到 85.78%、100.00%、97.67%、97.89% success，Direct macro 95.33%；Guarded A 用 128×3 local CEM 达到 96.86%，相对 pure CEM 300×30 提升 16.00 points，候选序列从 9000 降到 384。

多任务共享 encoder 的 E5 Goal-displacement INTACT Direct macro 为 89.39±0.77%，显著高于 matched shared LeWM + CEM 66.17±2.67%，四任务分别提升 5.66/32.23/12.56/42.44 points。actor-disabled pure CEM 从 LeWM 的 66.17 提升到 70.08，说明不仅 action head 变强，encoder-forward stack 也被塑形。机制诊断中 predicted-expert kNN/CKA 与 Direct SR 的相关性为 0.954/0.897，强于 pointwise action R2；共享 actor ablation 显示独立 actor 即使双倍容量也弱于共享条件 operator。

## Value
价值很高。它把 JEPA world model 的“预测世界”和“直接控制”之间的接口问题讲清楚，并用完整 ablation 说明 action-law family 的对应关系比单纯 latent rank、Euclidean geometry 或 goal-only BC 更重要。对我们有启发的是：隐式世界模型如果要用于控制，训练目标要让 latent 不只是可预测，还要能被 action conditional 读出；同时搜索可退化为 verifier，而不是主接口。

## Strengths
理论表述、训练结构和实验诊断相互对应；区分 local physical anchor 与 deployable goal intent；Direct/actor-disabled CEM/Guarded A 的实验设计能拆开 representation、readout、search 三个因素；延迟和候选数收益明确；多任务共享 encoder 结果有说服力。

## Weaknesses
实验仍局限于 LeWM 四个模拟任务和 expert offline trajectory；conditional quotient 只在 demonstration support 上可识别，无法保证任意 counterfactual goal；Direct Gaussian mean 可能掩盖多模态动作，接触或岔路口场景仍可能需要 verifier；三训练种子只能粗略估计 scaling；未验证真实机器人、OOD goal、distractor 或跨 embodiment。

## Future Work
作者提出可探索 mixture actor、从 INTACT Predictor 的不确定性采样、uncertainty-triggered verification、quotient-aware mode selection、更强跨任务对齐、真实机器人与分布外目标评测。
