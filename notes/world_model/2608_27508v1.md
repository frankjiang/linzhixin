# WM-R1: Training GUI Agents to Reason and leverage World Models with Reinforcement Learning

## Insight
作者的核心观察是，GUI RL 的真实环境交互慢、不可逆且带噪，而把 world model 只放在 inference-time 做 propose-simulate-select，并不会教会 policy 何时以及如何使用它。由此推论是：让 world model 同时充当 GRPO rollout 的全部 transition source 和 chain-of-thought 中可主动调用的“视觉草稿纸”，再用成功、轨迹长度和调用次数的组内相对奖励，可学习“先模拟、再修正、后执行”的策略。经验现象是每条轨迹的 WM 调用从约 4.2 次降至 1.8 次、episode reward 从 0.15 升至 0.52，且长程 benchmark 提升明显；但未系统测量 simulator error，因而这只是与该机制一致的相关证据，不足以证明提升确由真实可迁移的 world-model reasoning 导致。

## Motivation
现有 GUI agent 的 GRPO/PPO 依赖 Android 环境 rollout，设备 reset、延迟、错误动作导致的轨迹崩坏和非确定性都会增加成本。文本/DOM、pixel diffusion 和 renderable-code GUI world model 已能预测 action-conditioned future，但多数工作主要在推理时辅助预训练 agent。论文希望完全取消训练中的真实环境交互，并让 agent 内化调用 simulator 的习惯。问题与交互式视觉世界模型密切相关，也有工程价值；不过论文不训练新的 world model，而是消费冻结的 Code2World-8B。

## Method
Policy 为 Qwen2.5-VL-3B/7B（附录另测 Qwen3-VL-4B/8B），world model 是冻结的 Code2World-8B。给定当前 screenshot 和 action，Code2World 生成 renderable HTML，再由 headless browser 渲染成 $1080\times2400$ 的下一帧；训练 rollout 的全部 state transition 都来自该模型。

Agent 输出带 `<call_wm>` 的结构化 CoT：提出候选动作后可调用 WM，预测截图以 `System (WM)` 消息插回同一 reasoning block，agent 可继续修正，最终再输出真实 action。每个任务采样 $G=8$ 条轨迹，最大 15 步，按 GRPO 的组内标准化 advantage 更新。复合奖励为 $R=\alpha R_{success}+\beta R_L+\gamma R_{WM}$，权重 1.0/0.5/0.1；$R_{success}$ 由 GPT-4o 对参考轨迹、执行轨迹和最终模拟截图判二值成功，$R_L$ 相对参考长度和最大长度的动态预算惩罚冗余步，$R_{WM}$ 相对组平均调用数调节过度/不足使用。

训练集从 AndroidCode、GUI-Odyssey、GUI-R1 合并，剔除 zero-shot success 高于 80% 或低于 5% 的任务后随机取 2000 条。单张 H200、rollout batch 2、15 episodes、学习率 $10^{-6}$；GPT-4o judge 在 200 条、3 人标注的校准集上与多数票一致率 93.5%，两次 judge 间一致率 96.2%。创新在于把现成 GUI simulator 嵌入 rollout 和 reasoning 的联合训练框架，而非 world model 架构或学习目标本身。

## Experiment
长程评估为 AndroidWorld、GUI-Odyssey 及各自要求至少 5 个真值步骤的 Hard 子集，指标是 success rate；ScreenSpot-Pro/V2 mobile subset 测 icon/text grounding accuracy，AndroidControl 测 action type 与 coordinate grounding。基线包括 zero-shot Qwen、仅在推理时使用 Code2World 的 `+CW`、GUI-R1、UI-R1、UI-TARS、MobileGUI-RL、OS-Atlas 等。

Table 1 中，WM-R1-3B 在 AndroidWorld 为 29.5%，高于 UI-R1-3B 的 18.6% 和 +CW 的 20.6%；WM-R1-7B 达 39.8%，高于 UI-R1-7B 30.8%、UI-TARS 1.5-7B 34.2%，GUI-Odyssey 也为 31.6% 对 21.5%/25.6%。Hard 子集为 AndroidWorld 32.7%、GUI-Odyssey 24.1%。WM-R1-7B 在 ScreenSpot-Pro icon/text 为 48.6/58.2，ScreenSpot-V2 为 90.4/95.2，AndroidControl type/grounding 为 93.5/87.8。

AndroidWorld-7B 消融（Table 2）中，完整模型 39.8；去 CoT 为 34.6（-5.2），去长度奖励为 36.5（-3.3），去 WM-call 奖励为 37.2（-2.6）。参数敏感性显示 $\gamma=0.1$、$G=8$、KL=0.01、轨迹长 15、学习率 $10^{-6}$ 附近最佳，但没有“禁用 WM transition”“仅模拟训练、不在 CoT 调用”或“真实/模拟混合 rollout”的关键正交消融。训练曲线报告 WM-R1 15 episode 从 22.4% 升至 39.8%，UI-R1 至 30.8；文中称方差更低，但未给 seed 数、误差数值或显著性检验。

成本方面，WM-R1-7B 单 H200 训练 11.2 小时，UI-R1 offline GRPO 为 7.8 小时，MobileGUI-RL 为 36.5 小时；WM 生成占总训练时间约 45%，所以是无真实环境而非“零成本”。推理平均调用 1.8 次 WM，额外延迟 2.3 秒/轨迹。Qwen3-VL 复现实验中，WM-R1-8B 在 AndroidWorld/GUI-Odyssey 为 44.5/35.8，UI-R1-8B 为 35.2/25.8，说明增益不局限于单一 policy backbone。

## Value
论文最值得借鉴的是把 simulator usage 本身作为可学习 action：world model 不仅制造训练数据，也成为 policy 的显式认知工具。这对视频 world model 驱动的 agent training、想象 rollout 和 test-time planning 有直接设计启发。当前证据更像一个有潜力的 GUI 系统原型；由于 simulator fidelity 和真实环境迁移缺少严谨测量，不宜把 benchmark 数字直接解释为一般性的 world-model RL 结论。

## Strengths
训练与推理接口简单清楚，`<call_wm>` 使模拟—评估—修正轨迹可检查；同时覆盖 3B/7B 与 Qwen3 4B/8B、多类 GUI benchmark、组件消融、参数敏感性、judge 校准和成本拆解；冻结 world model 隔离了 policy learning 效果；相对 inference-only `+CW` 的提升表明训练 agent 使用 simulator 可能比临时外挂更有效。

## Weaknesses
最强反例是，整个训练 transition 和成功奖励分别由单一 Code2World 与 GPT-4o/reference trajectory 产生，模型可能学到的是 simulator/judge 的偏好，而非真实 Android 动力学。论文没有报告 Code2World 在 held-out action transition 上的像素、结构或任务级误差，没有按 WM 错误率分层，没有真实环境干预/在线 rollout 对照，也未清楚交代长程评估中真实设备与 simulator 的切换细节；因此无法排除“更适配同一模拟器”这一更简单解释。

此外，关键消融没有把“WM 生成训练 transition”和“CoT 主动调用 WM”正交分离；Table 1 多数外部 baseline 的训练数据与协议不完全同源，且主结果没有置信区间、seed 统计或显著性。论文称“massively parallel”却只用一个 WM instance、batch 2、单 H200，未做并行扩展实验；称“zero-cost training”也与 WM 占 45% 时间、相对 UI-R1 1.44 倍训练时长矛盾。相关工作一面承认 UI-Simulator/SimuRA 等用于 agent training simulation，一面又称既有工作均只在 inference-time，削弱“first”主张。离散动作、动态图/实时数据和第三方 widget 仍是 Code2World 的盲区。

## Future Work
作者明确提出提高 world model 对动画、实时更新和第三方 widget 的 fidelity，并把离散 click/type/scroll 扩展到自由光标、drag-and-drop 等连续控制；还建议结合更强的 foundation model。合理推断的必要后续是：做 simulator-vs-real transition 校准与不确定性估计，引入少量真实 rollout 的纠错 curriculum；正交消融模拟训练与 reasoning call；报告多 seed、同协议 baseline 和真实设备成功率；用 WM ensemble 或 disagreement 在高风险动作上触发真实验证。

## Rating
创新度评分：3/5 - 将冻结 GUI world model 同时用于 GRPO 环境和可调用推理工具，系统组合有新意且结果强；但没有新的 WM 学习方法，核心因果证据与真实性验证不足。
相关度评分：2/3 (Related) - 属于视觉交互世界模型驱动的 agent training，可直接借鉴 imagined rollout；但不是视频生成、3D 建模或 JEPA/Dreamer 表征主线。

## TL;DR
用 Code2World 替代真实 GUI 环境做 GRPO 并学习调用模拟器，方向新颖但验证缺口大，建议选读。
