# Discrete-WAM: Unified Discrete Vision-Action Token Editing for World-Policy Learning

## Insight
**Observation**：现有自驾系统将 world model 和 policy 分离优化，连续隐空间中视觉状态、动作、未来演化高度纠缠、缺乏显式组合语义对齐，导致 action-conditioned 因果推理和反事实比较困难。同时，驾驶策略本质上是层次化的（high-level decision 决定可行空间，low-level action 之间存在强时序依赖），全并行动作生成会遭遇依赖失配。

**推论**：(1) 将视觉观测和动作统一到共享离散 token 空间，可以用同一序列建模框架做 world modeling、world-policy modeling 和 policy modeling 的联合训练；(2) 引入稀疏的 decision skeleton 条件化 action token 生成，可以降低 action token 之间的残差 total correlation，使并行离散扩散更加可行。

**证明**：理论上推导了 decision conditioning 减少残差依赖的充分条件（residual mixing assumption 下 mutual information 指数衰减，Eq.4-5）以及 schedule-level KL bound（Eq.6）。实验上 NAVSIM v2 EPDMS 90.4 SOTA，FID 6.6 / FVD 80.0 在驾驶视频生成中最优，surprise 指标与 PDMS 强负相关验证了因果建模能力。

## Motivation
- **解决什么问题**：自动驾驶需要同时理解世界动态和生成最优策略，但现有方法要么做直接行为克隆不建模动态（UniAD/VAD），要么 world model 与 policy 弱耦合（Epona/DreamerAD），future prediction 和 policy learning 仍作为分离模块或辅助目标优化，存在 gap。
- **同行做法**：(1) E2E 行为克隆不显式建模未来；(2) 连续扩散 world model（DriveDreamer 等）生成视觉未来但与策略脱节；(3) VLA 方法受限于语言注释的低带宽接口；(4) AR 离散方法（DriveVLA-W0/VAVAM）有组合性但受前缀偏置和串行瓶颈限制。
- **是否关键**：是重要方向。统一 world-policy 学习有助于提升 generalization、可解释性和安全性，是 physical AI 的核心需求。

## Method
**整体管线**：四组件 + 三阶段训练 + RL 后训练。

**四组件**：
1. **Vision Tokenizer**：VQ-VAE 编码前视图像为离散 visual tokens，projector 对齐到 Transformer hidden dim。
2. **Action Tokenizer**：连续轨迹 -> cubic spline 拟合 -> 二阶差分得到 2D 加速度 (a_x, a_y) -> 网格化量化到 N_x x N_y 加速度词表。关键创新：**soft-label interpolation**——对每个连续加速度找四个邻近 bin 做双线性插值权重，训练用 soft target cross-entropy，推理用加权求和恢复连续值，消除确定性量化误差。
3. **Context Encoder**：注入 ego-state 和导航指令到 latent sequence。
4. **Token Edit Model**：decoder-only Transformer，统一支持三种训练模式：
   - **World Modeling**：给定 context + clean action tokens，离散扩散编辑 corrupted visual tokens -> 预测未来视觉。
   - **World-Policy Modeling**：action 和 visual tokens 交替排列（A_{t+1}, V_{t+1}, ..., A_{t+H}, V_{t+H}），联合预测。通过 task-specific attention mask 实现每步 action 条件于已有 context，visual 条件于 action+context，但不泄露 clean targets。
   - **Policy Modeling**：先预测 decision skeleton D_t（变道意图/目标车道/速度趋势等），再条件生成 action tokens。Action block 内部可双向注意力。

**层次化 Decision Skeleton**：
- 理论分析（Eq.3-5）：当 decision skeleton 解释了 action tokens 的低频组内依赖时，conditioning on D_t 能降低 residual total correlation，使剩余 fine action tokens 主要编码局部修正，更适合并行扩散编辑。

**训练三阶段**：Stage 1 视觉预训练（world modeling + world-policy，仅视觉 loss）-> Stage 2 联合 vision-action 训练（激活 action prediction loss）-> Stage 3 LoRA action finetuning。

**Post-training**：GRPO 强化学习。Token-edit planner 采样多条轨迹，用 EPDMS/PDMS 作 reward。支持两种 decision 采样：(1) group sampling 取最可能 decision；(2) parallel sampling 对 decision 全分布采样。

**推理**：置信度引导的并行 token editing。四种调度策略（full_replace / replace_confidence / replace_js_entropy / replace_js_freeze），其中 confidence-based 选择性替换效果最佳——高置信 token 冻结，低置信 token 在后续 round 迭代精修。

**Mode-aware decoding**：为避免多模态动作分布直接求期望导致 mode averaging，用 GMM 拟合离散分布后 top-p 采样选模态，单模态内求期望。

**创新程度**：较高。离散 token 统一 world-policy 框架是新颖的系统设计；soft-label 量化 + mode-aware decoding 解决了离散化的两个核心痛点；层次化 decision skeleton 有理论支撑。

## Experiment
**数据/基准**：nuPlan 训练集（200K steps pretraining），NAVSIM v1/v2 navtest split（12K scenes, 2Hz, 4s horizon），32x H20 GPU。

**Planning（NAVSIM v2, Table 1）**：EPDMS 90.4（SOTA），超过 SparseDriverV2 (90.1)、DreamerAD (87.7)、Epona (85.1)、WAM-Flow (84.7)。EP 90.5 最高，安全指标（NC 98.5, DAC 98.2）全面领先。

**Planning（NAVSIM v1, Table 2）**：PDMS 92.2（SOTA），超过 SparseDriverV2 (92.0)、iPad (91.7)。

**World Generation（Table 3）**：FID 6.6、FVD 80.0 均为最优，超过 Vista (6.9/89.4) 和 DrivingWorld (7.4/90.9)，但最大生成长度仅 4s/8 frames。

**消融实验**：
- **统一预训练效果（Table 4）**：LoRA-SFT > FT > From scratch，说明轻量适配保留预训练知识最有效（EPDMS 90.0 vs 89.7 vs 89.8）。
- **后训练效果（Table 5）**：SFT (89.1) -> SFT+D_t (90.0) -> RL (90.4)，decision 条件和 RL 各贡献约 1 点。
- **Decision modeling（Table 6）**：引入 D_t 使 EPDMS 从 84.7 提升到 87.2（+2.5），预训练阶段即有效。
- **Scheduling 策略（Table 7-8）**：confidence replace 在 R=3 时达到最优 compute-performance 平衡；full replace 增加 round 反而劣化。
- **推理延迟（Fig 4c）**：离散扩散 3 round ≈ 200ms，显著低于 AR decoder ~1000ms。

**分析亮点**：
- Attention map 分析发现 policy decoder 关注道路/车道线/车辆等语义区域，天空区域充当隐式 global anchor。
- Surprise 指标（factual vs counterfactual 世界模型生成的 KL 散度）与 PDMS 强负相关，验证模型捕获了 safety-critical 动态。
- Decision 数量 k=16 时性能最佳，过多 decision 引入低质量 anchor 增加优化难度。

## Value
- **整体价值**：系统性强的自驾 world-policy 统一框架工作，在规划和生成两个维度同时达到 SOTA。理论分析扎实，消融充分，工程设计（soft-label、mode-aware decoding、confidence scheduling）有实用价值。
- **对我们的启发**：
  1. **离散 token 统一建模**是 video world model 的一个有前景的方向——Discrete-WAM 证明了离散扩散可以在同一框架中同时做未来视觉预测和动作生成。
  2. **层次化 decision skeleton** 降低 action token 依赖的思路值得借鉴，可推广到通用 video world model 中的控制信号设计。
  3. **Soft-label 量化 + mode-aware decoding** 是处理连续控制信号离散化的有效方案。
  4. **Surprise 指标**作为 world model 质量的内在评价方式，可能比 FID/FVD 更有意义。
- **局限/待解决**：仅前视单摄像头 + 2Hz 低频；VQ tokenizer 重建质量限制上限；无真实闭环驾驶验证；生成长度仅 4s/8 frames，长时序生成能力未验证。
