# Predicting Closed-Loop Performance of Latent World Models: Offline Checkpoint Selection for MPC and Model-Based RL Under Non-Markovian Rewards in LunarLander

## Insight
论文指出：latent world model 的验证 loss 或 one-step RMSE 可能在闭环 MPC 性能崩溃后仍继续变好。尤其在 non-Markovian shaped reward 下，关键是 reward predictor 是否依赖 latent 中不可观测/不可重构的记忆因素。

## Motivation
模型式 RL 中常需要离线选择 world model checkpoint，但不能每次都做昂贵 closed-loop rollout。传统 validation loss 与真实 MPC return 不一致，会选到过拟合或奖励结构错误的模型。

## Method
作者提出 40 个控制论式 structural validation metrics，其中核心是 Reward Observability Fraction (ROF)：衡量 reward predictor 梯度与可观测子空间的对齐程度。CROF 综合 ROF、controllability/observability rank 和 open-loop observation error，用于离线 checkpoint selection。

## Experiment
主要在 LunarLander-v3 RSSM world model 上评估 100 个 checkpoints，并用 CEM-MPC return 作为 oracle。ROF 是最强单指标，平滑 Spearman 约 -0.71；CROF 能选到高 MPC plateau，而 validation loss 会选到闭环表现差的 checkpoint。model-based A2C 使用 CROF 选出的模型，比公平 model-free A2C 用约 65 倍更少环境交互达到更好结果。Reacher 对照说明 Markovian reward 下 ROF 作用减弱。

## Value
对 latent world model 评价有实际参考：checkpoint selection 应看闭环可控性、可观测性和 reward grounding，而不是只看重构误差。

## Strengths
问题很实际；指标与控制理论联系紧；展示了 validation loss 的误导性。

## Weaknesses
主要在 LunarLander 和 RSSM 设置；ROF 结论依赖 non-Markovian reward；指标较手工，泛化到大规模视频模型未验证。

## Future Work
未来可在更多连续控制、真实机器人和视觉 latent world model 上验证 CROF 类指标。

## Rating
