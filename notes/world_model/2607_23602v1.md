# Action from Adjacent Set in Physical Space Outperforms the Best Prediction in World Models

## Insight
有。论文的核心 observation 是：在基于 latent world model 的采样控制中，候选数变多不一定更好，因为残余预测误差会让不可行动作序列偶然获得最低 cost；proposal pool 越大，这类 lower-tail 错误越容易出现。推论是不要只选最低预测终端 cost，而应利用 proposal pool 中低 cost 动作前缀的局部密度来重构更稳健的动作。

## Motivation
论文解决 model-based planning 中的 conditional failure proposal overgeneration。同行常用 CEM/latent MPC：生成候选动作序列，用 world model 预测 terminal latent，再选择最低 cost。即使 cost 本身与真实目标一致，world model 的 endpoint prediction error 仍可能让 infeasible sequence 排第一。该问题对机器人世界模型规划非常关键。

## Method
作者提出 Adjacent Set Action Reconstruction (ASAR)。在候选序列已由固定 world model 和 cost 排序后，ASAR 不改 encoder、predictor、sampler 或 terminal cost。它先取低 cost 序列集合，再用标准化 early action prefix 距离计算每条序列邻域密度，找到 least isolated prefix center，从其邻近集合中对完整 action sequence 做局部加权平均，并混入少量最低 cost 序列作为 anchor。

理论分析包括：order statistic 解释 lower-tail selection risk；radius support statistic 描述 feasible/infeasible 前缀密度分离；在局部 feasible ball 条件下给出 sequence containment bound。它与 TRM 这类 terminal cost 改进互补，TRM 改 cost，ASAR 改最终动作输出规则。

## Experiment
环境是 OGBench Cube manipulation，使用固定 LeWM encoder/predictor/CEM generator。candidate execution audit 显示，proposal budget 从 72 增到 288 时，按 minimum latent cost 选择的 feasibility 在 position target 上从 0.375 降到 0.062，在 position+yaw target 上从 0.344 降到 0.031；但每个更大 pool 都含有 feasible sequence。

Carry and Release 75 queries 上，Kernel ASAR 相对 minimum latent cost 的 event completion success 提升：72/144/288 proposals 下分别 +28.0、+24.0、+18.7 个百分点；在 reachability cost 下分别 +18.7、+20.0、+17.3。targeted reconstruction test 中，least isolated existing sequence 成功率 0.493，Kernel ASAR 0.630，说明重构本身有价值。独立训练 world model 上也复现小幅收益。

## Value
价值高在于指出一个常被忽视的 planning failure：更多 sampling 会提高覆盖，也会放大模型误差下的错误极值。对我们研究世界模型规划有直接启发：评估候选动作时应报告 feasible presence、top-k feasible exposure、blocker count，而不只看最终 success；proposal pool 的几何结构可作为 uncertainty/robustness 信号。

## Strengths
问题定义很具体；不依赖改训练，方法可作为后处理插入现有 CEM/latent MPC；实验区分 terminal cost 质量和 residual prediction error；同时有 audit、matched closed-loop、独立模型复现实验。

## Weaknesses
ASAR 成立依赖低 cost feasible sequence 在 prefix metric 下形成局部密集邻域；若 infeasible 也密集、feasible 孤立或任务需要多个离散行为阶段，方法会失败。Reacher 中近似中性，Push-T 中中性或负面，说明 prefix metric 不通用。没有真实机器人硬件验证。

## Future Work
作者讨论了 medoid、graph filtering、bounded controller mixture 等变体，并指出硬件评测应测 sensing noise、failure recovery 和 safe reset 下替代控制器成本。

## Rating
创新度评分：3/5 - 方法是轻量后处理，但抓住了 latent WM 规划中的真实失效机制，实验扎实。
相关度评分：3/3 (Core) - 直接针对 latent world model + sampling/MPC planning 的控制问题。

## TL;DR
揭示候选越多越易选中预测误差动作，并用邻域重构修正，核心相关，值得精读。
