# CellCanon: An Agentic Cellular World Model for Prediction, Explanation, and Observation-Driven Updating

## Insight
观察：同一药物—细胞条件下，不同基因共享药物机制和细胞背景证据，但需要各自的响应读数。作者把条件级证据编译一次，再用基因级连续响应、差异表达和方向读头预测；以同药物在另一细胞中的新测量修正预测。SciPlex3 对比、消融与回顾式反馈实验支持效率和准确率提升；并非关于视频或 3D 环境动力学的证明。

## Motivation
单细胞扰动实验无法覆盖所有药物/细胞组合；传统数值模型难利用知识库，逐基因 LLM 推理昂贵，预测、解释与新测量更新又通常分离。论文解决生物扰动响应、证据溯源和增量修正的集成问题；对细胞生物学重要，与本方向关注的视觉世界模型不直接相交。

## Method
LLM 按药物—细胞条件汇编靶点、作用机制和 DMSO 对照证据，冻结文本嵌入与结构特征投影为条件表示；从训练药物响应图谱按化学/靶点/机制相似度及学习的兼容性检索，融合后由连续 MLP 与独立的差异表达（DE）及升降方向（DIR）分类头预测。概率和连续值共同引导从对照细胞生成扰动后单细胞群。Explain 对数据库证据、带符号通路和引用做规则校验，可回答支持/矛盾/证据不足。Update 使用同药物另一细胞的已测响应，通过固定的核岭回归和分类校正更新目标细胞预测，不更新父模型权重。属于知识检索、任务专门读头与规则验证的系统组合。

## Experiment
SciPlex3 三细胞系 339 个留出药物—细胞条件、2,000 基因主面板，对比 BioLORD、chemCPA、PRnet、STATE、VCWorld 等。生成群体的 DE AUPRC/Macro-F1 为 0.8067/0.8164，最佳基线分别 0.4938/0.6961；logFC Pearson 0.6944，对比最佳 0.4306。移除生物注释使预测头 DE F1 从 0.8077 降到 0.7117；用连续值阈值代替独立分类头降至 0.5278。模拟同药物跨细胞测量后，DE AUPRC/Macro-F1 为 0.9077/0.8261；解释基准 966 问中，561 个可回答问题有完整规则证据、405 个证据不足问题正确拒答。共享证据使 Predict/Explain 的 LLM token 相比逐基因 VCWorld 分别降 99.77%/98.41%。

## Value
对用户视频/3D/JEPA 方向价值很低。若借鉴，可考虑把共享场景证据与对象级预测分离，并使预测来源与后续观测更新可追踪；具体生物标签、检索图谱和表达生成管线不可直接迁移。

## Strengths
明确区分连续响应、事件发生与方向等不同预测目标；留出药物评测并用相同观测预算比较更新；证据与测量有可追溯状态；提供 token 用量和多个组件消融。

## Weaknesses
评价局限于 SciPlex3 的三个细胞系和回顾式测量揭示，没有真实主动实验闭环。解释题目由受控来源规则构建，完整符号参考同样得满分，不能说明开放式生物解释优于规则方法。附录中直接编码原始知识在部分预测指标上优于 LLM 汇编，后者的必要性未充分证明。没有视觉观测、物理空间建模或通用时序规划。

## Future Work
正文未给出明确的具体后续实验计划；自然延伸是检验新细胞/药物分布、真实主动测量反馈及开放证据下的解释可靠性，这些是据局限提出的推论。

## Rating
创新度评分：2/5 - 生物任务上的多模块集成与数值效果不错，但核心技术是已有检索、读头、规则校验和核回归组合。
相关度评分：0/3 (Noise) - 研究细胞扰动响应，不涉及视频、3D 或 JEPA/Dreamer 式隐式世界模型。

## TL;DR
融合生物证据、单细胞响应预测和观测更新，结果突出但与视觉及隐式世界模型无直接关联；可跳过。
