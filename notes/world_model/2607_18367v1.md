# AlayaWorld: Interactive Long-Horizon World Modeling -- Full Technical Report

## Insight
核心 insight 是交互视频世界模型必须同时解决 interaction、consistency、stability、efficiency，不能只提升短视频画质。作者观察到长时自回归生成会累积视觉漂移和空间遗忘，于是提出 bounded visual context：持久 sink frame、压缩 temporal history、geometry-aligned spatial memory、recent-frame conditioning 组合，保持常数成本同时支持长程记忆。

## Motivation
传统游戏世界依赖资产、物理、动画和程序管线，成本高；视频世界模型希望从文本/图像/视频和用户控制直接生成可探索世界。现有交互视频模型难以同时做到相机控制、prompt-driven action、离开再返回的一致性、长 horizon 稳定和低延迟。该问题是视频世界模型核心问题。

## Method
AlayaWorld 基于 LTX-2.3 去除音频后的约 13B/15B video DiT，在 VAE latent 中按 K=4 latent frames chunk 自回归生成。每 chunk 输入相机轨迹和可切换 text prompt，视觉前缀包含：固定的 sink frame 作为全局 appearance anchor；history encoder 压缩最近 6 个 latent frames；spatial memory 从缓存的 RGB/depth/camera pose 中选最多 10 帧，用 Depth-Anything-3 和 camera pose forward splatting 到当前视角；nearby frame 做 I2V 连续性。训练分三阶段：bidirectional full fine-tune、autoregressive full-stack finetune 加 camera control/memory/next forcing/anti-drift、4-step discrete distillation。抗漂移包括 Helios corruption 和 error bank 回放自身 rollout residuals。

## Experiment
训练数据 222,147 clips，含 real walking/indoor/RealEstate10K/DL3DV/MUGEN、GameVerse 和 GenEvent。iWorld-Bench 上与 Cosmos、HunyuanVideo-1.5、WAN2.2、YUME1.5、Matrix-Game2.0、HY-World1.5 比较。AlayaWorld 在 brightness consistency 0.9492、color temp 0.9379、sharpness retention 0.8361、motion smoothness 0.9924、trajectory accuracy 0.7985、memory symmetry 0.8871、trajectory alignment 0.7018 等多数指标第一。定性展示相机控制、prompt-driven actions、leave-and-return 一致性和 60s 长时 rollout 稳定。

## Value
这是本批里最相关的视频世界模型工作之一。它的价值在 full-stack design：空间记忆、抗漂移训练和少步蒸馏都对长程交互世界模型有直接借鉴。待解决问题是世界状态仍主要是视觉、深度和 memory cache，对对象状态、物理因果和任务结构理解有限。

## Strengths
问题拆解准确；bounded context 设计兼顾长程和常数计算；geometry-aligned spatial memory 直击 revisitation；抗漂移训练使用自身误差；4-step distillation 服务低延迟。

## Weaknesses
缺少细粒度 ablation 表来量化每个 memory/drift 组件；主要评测在 iWorld-Bench 和定性展示，真实交互物理能力仍有限；依赖大量内部数据和重模型，复现成本高。

## Future Work
作者把它定位为开源长期项目，未来方向是更强对象状态、物理因果、长程任务结构和更完整的 interactive generative reality foundation。
