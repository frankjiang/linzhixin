# Physics-IQ Verified

## Insight
核心 insight 是 benchmark 误差会改变“物理理解”结论：模糊 prompt、ground-truth artifact、dataset-level aggregation 会让分数混入非物理因素。改进后模型排名 Kendall τ 只有 0.46，说明原评测信号并不稳定。

## Motivation
视频生成模型被用作世界模型时，需要评估是否真的掌握物理而非生成好看运动。Physics-IQ 是重要 benchmark，但原版本存在 prompt 不清、artifact 激活、样本权重不均等问题，可能误导模型开发。

## Method
提出 Physics-IQ Verified：修正 34.8% 高歧义 prompts，使用 best-practice prompt templater；人工清理 ground-truth 中非物理现象导致的 spurious activation；把原 dataset-level 分数改为 sample-level score，使每个样本和指标等权并可追溯失败样本。

## Experiment
对 198 个视频样本系统审计，57.6% 样本被修改，29.8% 视频存在 artifact 修正。用 6 个 I2V 模型比较原版与 verified 评估：大多数模型因更好 prompt 分数上升，artifact removal 使 IoU 类分数下降；最终排名中 Grok Video、HunyuanV-1.5、Cosmos3-N、Sora2 等发生重排，Spearman 0.65、Kendall 0.46。表格给出 Cosmos3-N、Grok、Hunyuan、P-Video、Sora2、Wan2.2 的原始/verified 分数。

## Value
对视频世界模型评测很有价值，尤其提醒不要把 VLM/视频 benchmark 当作客观物理理解。它不是新模型方法，但对筛选和比较 world model 很关键。局限是仍依赖人工标注、VGM prompt protocol，并且只覆盖 Physics-IQ 的实验范围。

## Strengths
