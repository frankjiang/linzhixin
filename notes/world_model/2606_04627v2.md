# MIRAGE: Mobile Agents with Implicit Reasoning and Generative World Models

## Insight
**Observation**: 当前移动端 GUI Agent 依赖显式 CoT（将思考过程解码为文本），消耗大量 token 和推理延迟。但 CoT 的价值不在于文本本身，而在于中间推理计算。

**推论 1**: 可以将显式文本推理蒸馏到连续潜在空间（latent slots），保留推理能力但无需解码中间文本。关键难点在于训练——串行 latent CoT 需要 N 次前向传播。

**推论 2 (APLR)**: 因果注意力下 latent slot $z_i$ 不依赖 $z_{j>i}$，系统严格下三角，可用 Jacobi 迭代式的并行 refinement 替代串行展开。K 轮并行 refinement 后前 K 个 slot 精确恢复串行解，尾部 slot 保留结构化残差 $\delta^{(K)} \approx A^K \delta^{(0)}$。

**推论 3**: 尾部 slot 的近似误差影响环境预测（predict 字段），可通过 Q-Former world-model head 对齐下一帧视觉特征来提供直接梯度，弥补 action CE 无法监督的尾部误差。

## Motivation
**问题**: 移动端 GUI Agent 需要推理能力（观察屏幕、判断意图、预测状态变化）来决策，但显式 CoT 的长文本输出增加延迟（3-4s）、token 成本和上下文消耗，不适合实时交互场景。

**同行做法**: UI-TARS/MAI-UI 等显式输出 reasoning trace（~100 tokens/step）；Coconut 等探索 latent reasoning 但限于 NLP；GUI 世界模型（如预测未来截图/sketch）以像素生成形式实现。

**关键性**: 是一个有实际意义的问题——推理效率直接决定移动 Agent 的部署可行性。

## Method
**两阶段训练管线**：

**Stage 1 - Explicit CoT SFT**: 在结构化思维数据上做标准 next-token prediction。思维格式为 `<THOUGHT> [observation] [rationale] [predict] <ACTION_DESC> ... <ACTION> ...`。让模型学会动作空间和推理模式。

**Stage 2 - Latent CoT SFT**: 将 `<THOUGHT>` 文本块替换为 N 个连续 latent slots（共享学习的初始化 embedding $e_{lat}$），通过 APLR 并行 refinement K=3 轮，联合训练 action CE + world model loss。

**APLR (Approximate Parallel Latent Refinement)**: 
- 所有 N 个 latent slot 并行前向 K 轮，每轮用上轮值
- 数学上证明前 K 个 slot 精确恢复串行解
- 实现中前 K-1 轮可 detach 梯度，仅最后一轮回传

**Q-Former World Model Head**:
- 用可学习的 2D 空间 query（行/列 embedding）cross-attend latent CoT hidden states
- 投影到视觉特征空间，与 stop-gradient 的下一帧 VLM 视觉特征对齐（cosine 距离）
- 推理时丢弃，仅用于训练时塑造 latent 表征

**总损失**: $\mathcal{L} = \lambda \mathcal{L}_{ce} + (1-\lambda) \mathcal{L}_{wm}$, $\lambda=0.8$

**创新程度**: 较高。APLR 将 Coconut 的串行 latent reasoning 转化为并行版本并给出理论保证；Q-Former world model 作为辅助正则化器弥补并行近似的尾部误差，设计巧妙且有理论支撑。

## Experiment
**Backbone**: Qwen3-VL-4B-Instruct 和 8B 版本。

**基准**:
- **AndroidControl**: EM/Action Accuracy/token 数。MIRAGE-4B: Low-level EM 77.59(+13.3%), Action Acc 91.09(+21.2%), tokens 18.92(-83.6%)。
- **AndroidWorld**: 116 真实任务端到端 SR。MIRAGE-4B: 52.6%(+22.6%), tokens 31.0(-69.9%)。MIRAGE-8B: 57.8%(+21.3%)。

**关键对比**: 
- 与 size-matched Qwen3-VL baseline 比，性能显著提升的同时 token 量减少 3-5x
- 推理延迟 1.704s vs Qwen3-VL-4B 3.189s（近 2x 加速）
- 匹配 Explicit CoT SFT 的 52.6 SR，但 token 量远少

**消融**: 
- Action-only SFT: 31.0 SR（去掉推理有害）
- Serial latent CoT: 50.9 SR（串行参考）
- APLR only（无 WM）: 48.2 SR（尾部误差影响）
- MIRAGE-4B (APLR+WM): 52.6 SR（恢复到 explicit CoT 水平）
- Latent slot 数量: 9 slots >> 3 slots (52.6 vs 32.8)

**可视化**: t-SNE/UMAP 显示 latent slots 形成位置特异的子空间（slots 1-2 对应 observation, 3-4 对应 rationale, 5-6 对应 predict），且按动作类型可区分。

## Value
**较高价值**。将隐式推理 + 世界模型正则化引入移动 Agent，在性能不降的前提下大幅降低推理开销，具有明确的实用意义。

**启发**:
1. Latent reasoning 是 CoT 的可行替代——保留推理结构但不生成文本。
2. World model 作为辅助训练信号（而非直接生成）是一种轻量且有效的范式。
3. APLR 的并行化思路可能适用于其他需要串行 latent reasoning 的场景。

**待解决**: 仅验证了 supervised 设置（无 RL/在线学习）；world model 仅做特征级预测未做像素生成；需要下一帧截图作为训练 target（依赖数据格式）。
