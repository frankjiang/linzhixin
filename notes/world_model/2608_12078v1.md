# Better Slots, Better Worlds: Representation Quality & Robustness in Object-Centric World Models

## Insight

作者从两个反常现象出发：C-JEPA 使用的 VideoSAUR 槽位明显混叠却仍能规划，而更“像对象”的表示是否真能带来控制收益并不清楚。固定动力学架构与规划器、只替换不同训练阶段的 SlotContrast 编码器后，PushT 的规划成功率与 video FG-ARI、mBO 分别呈强正相关（Pearson 0.96/0.94），但高质量区间很快饱和。进一步消融说明：槽位绑定足够好时，proprioception token 与 masked-slot history objective 都不再必要；弱槽位上的 masking 收益主要依赖 proprioception 捷径，而非真正学到对象交互。OOD 对比又显示冻结预训练视觉特征本身贡献很大，因此“对象中心性”与“预训练表征”不能混为一谈。

## Motivation

Object-centric world model 通常把槽位编码器视为既定组件，用无监督分割指标选模型，并只报告同分布预测或控制结果。关键缺口有二：槽位分割质量是否对应下游规划能力；对象分解是否真的比 scene-centric 表示更抗分布偏移。问题重要，因为 OCWM 的样本效率、组合泛化与因果结构优势经常被当作默认前提，却缺少面向规划的受控验证。

## Method

基于 OC-JEPA/C-JEPA 的视觉 MPC 框架，将 VideoSAUR 换成采用 DINOv3 特征、具时序一致性的 SlotContrast；默认模型不使用槽位遮蔽和 proprioception。整体流程为：逐帧编码成固定数量的对象槽位，action-conditioned Transformer 预测未来槽位，CEM 在潜空间最小化预测状态与目标状态的 L2 距离。SlotContrast 保持槽位身份，可直接逐槽计算代价；VideoSAUR 需每步 Hungarian matching。

三组实验分别控制：（1）扫描 SlotContrast checkpoint，改变槽位质量但保持动力学模型结构与规划器不变；（2）在强/弱编码器上交叉消融 masked slots 数量与 proprioception；（3）改变颜色、背景、尺度、形状、相机与照明，比较 SlotContrast-WM、DINO-WM 和端到端 LeWM。创新主要在严谨拆解 OCWM 的收益来源，而非提出新的世界模型架构。

## Experiment

- 环境：2D PushT（18,500 条带动作噪声的专家轨迹）与 3D OGBench-Cube（10,000 条启发式轨迹）；每个结果 3 个随机种子，CEM 使用 300 samples、30 iterations、top-30 elites，评估 50 个目标。
- 指标：槽位质量用 video FG-ARI、video mBO；控制用 success rate。PushT 随槽位质量上升的 Pearson 相关为 0.96/0.94；OGBench-Cube 为 0.76/0.87，但因大机械臂主导分割指标而较早饱和。
- 机制消融：PushT 上 SlotContrast 无 proprioception、无 masking 达到 84.7±1.9%，与完整 C-JEPA 配方的 85.3±3.4% 相当；VideoSAUR 在 proprioception 存在时由 73.3% 提升至 85.3%，但无 proprioception 时 masking 从 74.7% 降至 52.0%/49.3%。
- OOD：PushT 外观变化下 SlotContrast-WM 通常最佳，DINO-WM 接近，LeWM 明显崩溃；几何形状改变会同时改变接触动力学，三者几乎都失败。OGBench-Cube 中前两者在多数 object/scene shift 下接近同分布表现，LeWM 对背景与相机变化更敏感。
- 定性可视化显示 SlotContrast 能稳定分离 PushT 的 agent/T-block/背景，以及 OGBench 的机械臂、方块和背景；VideoSAUR 出现 Voronoi 式混叠。

## Value

这是一篇对 OCWM 研究很有价值的“拆因”工作：它支持“表示质量先于复杂动力学技巧”的工程判断，也提醒不要把冻结 foundation feature 带来的鲁棒性误归因于对象分解。对我们最直接的启发是：应以规划相关、对象重要性加权的指标选择槽位编码器，并把 encoder pretraining、对象绑定、动力学结构分别做匹配对照。尚未解决的是复杂真实场景、多对象交互、长时滚动与组合泛化。

## Strengths

- 用同一动力学骨架扫描编码器 checkpoint，把“槽位质量—规划成功”关系做成可测的受控问题。
- 强/弱槽位与 masking/proprioception 的交叉消融能揭示捷径，而不只报告最终性能。
- 同时评估对象级、帧级和动力学级 OOD，并谨慎承认 DINO 预训练特征是重要混杂因素。
- 附录给出数据、成功条件、规划预算和完整 OOD 取值，复现实用性较好。

## Weaknesses

- 仅覆盖两个小型仿真操控环境、50 个目标和 3 个种子；PushT 结构简单，OGBench-Cube 随机策略成功率高达 48%，外部有效性有限。
- OOD 对比仍非完全同源：SlotContrast 使用 DINOv3 槽位，DINO-WM 使用 DINOv2 patches，LeWM 则端到端学习，难严格分离对象分解、预训练版本和训练范式。
- 相关性不能单独证明槽位质量是因果机制；每个 encoder checkpoint 都重新训练动力学模型，优化难度等因素仍可能介入。
- FG-ARI/mBO 按整幅场景聚合，会被大而非任务关键的对象支配；作者已在 OGBench-Cube 上观察到这一失败。
- 对真正改变动力学的形状偏移全部失败，说明当前鲁棒性主要覆盖视觉变化，尚未兑现因果/组合泛化承诺。

## Future Work

作者提出开发 task-aware 的槽位质量指标、联合训练 encoder 与 world model，并在更多对象、更多尺度、更丰富动力学的环境中检验鲁棒性与组合泛化。还应加入真实机器人、长时预测、遮挡与对象增删，以及严格匹配视觉 backbone 的对照。

## Rating

创新度评分：3/5 - 主要贡献是对 OCWM 表征质量、辅助机制和 OOD 鲁棒性的系统受控分析，结论有新意但不是新范式或全新模型。
相关度评分：3/3 (Core) - 直接研究对象中心隐式世界模型、潜空间预测、MPC 与 3D 操控泛化。

## TL;DR

受控实验证明高质量槽位提升并简化对象中心规划，但鲁棒性也来自预训练特征，值得精读。
