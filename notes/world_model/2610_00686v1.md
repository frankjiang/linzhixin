# SemanTok: Predictable Semantic Tokens for Efficient Autoregressive Video Generation

## Insight
可变长视频 token 的前缀若只靠扩散解码器早层的 DINO 对齐监督，解码器可从较干净的带噪 latent「抄答案」，token 本身未必含语义。作者让每个保留前缀独立预测冻结 DINOv2 特征；纯噪声解码输入下的表征对齐仍提升。再用前缀 teacher forcing 发现：固定前 16–64 个真 token 后，生成优势消失，支持收益主要来自更易预测的早期 token。

## Motivation
固定网格视频 token 长且昂贵，VideoFlexTok 以任意可解码前缀节省预测量，但早期 token 可能缺乏稳定的内容语义。视频世界模型需要既可预测、又能以少量 token 表达场景的状态；仅优化重建保真不保证自回归生成好。

## Method
沿用 VideoFlexTok 的时序因果编码器、每 latent 帧最多 256 个寄存器 token、64k FSQ 码本、2 的幂次前缀 nested dropout、rectified-flow 解码器和 decoder-REPA。SemanTok 将冻结 DINOv2-L 的 patch 特征拼入编码器输入，class 特征注入首 token；另以两个仅访问当前及历史保留 token 的交叉注意力头重建 DINO patch/class 特征，余弦损失各权重 0.5。冻结 tokenizer 后，AR 模型按时间优先、帧内粗到细预测离散 token，解码器渲染视频。创新集中在「每个前缀本身」的语义监督，非新码本或新 AR 架构。

## Experiment
Kinetics-600 类别条件及 uCO3D 文本条件生成，17 帧、128×128，AR 规模 49M–2.29B；对比同架构 VideoFlexTok。指标含 gFVD/gFID、ViCLIP、视频相似度 ClipV、类别准确率，以及重建 PSNR/rFVD、decoder-REPA 余弦和 token 交叉熵。Kinetics-600 在 201M AR、k=16 时 gFVD 217.2 对 272.9；uCO3D 同设置 gFID 21.33 对 22.52。201M 模型前 16 token 平均预测交叉熵为 8.8 对 12.9 bit/token，低约 32%；OOD 物体类别语义优势仍在。纯噪声解码和 teacher forcing 支持前缀机制，模型规模、训练时长和不同 k 的结果充分；但较小预算 k=1–4 的部分 uCO3D 保真指标会输。

## Value
对视频世界模型的紧凑状态编码值得精读：将语义压到便于预测的前缀，像素细节留给后缀/扩散解码器，可直接启发条件 rollout 的计算预算分配。下一步需验证动作条件下是否保留接触、位置和长期运动等决策信息。

## Strengths
在公平架构和训练设置下与直接前作比较；同时考察重建和生成，避免只凭 rFVD 选择 tokenizer；跨 AR 规模、token 预算、训练进度及 OOD 类别评测，并对早期 token 的可预测性做机制探针。

## Weaknesses
同时改动 DINO 编码输入、首 token 注入和两种前缀监督，正式结果未逐项消融，无法判定各部分贡献。低预算牺牲颜色和外观重建，k=1 效果不稳；仅验证 17 帧低分辨率的非动作条件视频，未证实交互预测或长时物理一致性。主结果多来自单次训练与采样，部分指标缺置信区间。

## Future Work
作者提出直接优化 token 可预测性，使用视频原生或语言对齐教师组织早期前缀，并把前缀作为动作条件世界模型的紧凑状态。

## Rating
创新度评分：3/5 - 对可变长视频 tokenizer 加入针对前缀的语义监督，机制清晰且效果稳定；仍是基于 VideoFlexTok 的增量方法。
相关度评分：2/3 (Related) - 视频世界模型可直接借鉴其状态 token 设计，但本文只做类别/文本条件生成，未建模动作条件动力学。

## TL;DR
让每个视频 token 前缀直接预测语义特征，使小模型更易生成内容稳定的视频；紧凑世界状态设计值得精读。
