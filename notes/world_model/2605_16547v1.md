# World Model-Enabled Causal Digital Twins for Semantic Communications in Physical AI Systems

## Insight
将世界模型用于语义通信中的因果数字孪生，通过 causal information value (CIV) 评估每个语义 token 对长期回报的边际贡献，实现基于世界模型想象 rollout 的语义 token 选择。

## Motivation
现有语义通信针对单次任务优化，无法支持闭环动态系统中的长 horizon 决策。需要在无线比特预算约束下最大化长期回报。

## Method
1. **Causal Information Value (CIV)**: 通过传输干预评估语义 token 的因果贡献
2. **WM-CDT Framework**: 世界模型捕捉闭环物理 AI 系统动态，支持反事实推理和长 horizon 想象 rollout
3. 基于想象 rollout 训练 actor-critic 策略 + CIV-per-bit 评估的语义 token 选择器

## Experiment
AirSim-Sionna UAV 导航仿真器验证，return-per-kbit 和导航成功率均优于现有 RL 方案。

## Value
世界模型在语义通信中的应用。核心创新在通信系统设计，世界模型作为辅助工具。与视频/3D 世界模型关联有限。

## Strengths
亮点是世界模型在语义通信中的应用。

## Weaknesses
不足是与视频/3D 世界模型关联有限。
