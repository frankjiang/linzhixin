# Memento 3: Model-Based Recursive Self-Improvement through Reflective Rulebooks

## Insight

观察：有限轨迹可由多套规则解释；代码准确回放已见转移，也不保证未见状态外推正确。推论：应显式保留可修订规则假设，并用预测失败更新；候选模型群可暴露单一模型无法触达的反例。论文给出版本空间/贝叶斯近似形式化，且在三个 ARC-AGI-3 游戏的规则书消融中总动作 677→617，但未证明一般环境泛化。

## Motivation

未知游戏中的代理须边交互边学习转移和目标。先前 Code World Model、ARC 代理已有可执行模型和回放校验，但易把偶然符合观测的程序误当普适规则。作者希望固定 LLM 参数，让外部语义记忆与程序模型持续更新并反过来指导探索，问题属于符号/程序化世界建模。

## Method

持久保存自然语言规则书 `ψ` 与 Python 可执行模型 `θ`，记录对象、动作、转移、目标和未决规则；每次观测后比较预测与实际，由冻结 LLM 选择保留、改规则或修代码，再编译。新模型须经 LLM 判定与规则书一致，并逐格精确回放全部 64×64 ARC 历史帧；接受后从历史重建隐藏状态，代码搜索到目标的最短动作路，逐步执行并遇预测错误即停。无可行计划时主动探查。扩展版维护多份模型，共享轨迹并按不同计划抽样探索。理论中的贝叶斯/POMDP 与最短路是框架解释，实际是 LLM 提议与点估计。

## Experiment

Claude Opus 5、Claude Code 高推理预算下，25 个公开 ARC-AGI-3 游戏的 183 个关卡全部通过，RHAE 均分触顶 100；总 7518 动作是人类基线 17135 的 44%，同为全通的 baseline1 用 8347 动作。去规则书只在易/中/难各 1 游戏比较：总动作 617 对 677、agent turns 678 对 830。双模型群只测 wa30：899→597 动作。Atari Pong 从 9504 模拟器帧交互学习后，冻结控制器在 3 个开局都以 21:0 获胜；作者说明 Pong 全帧重放仍有渲染/挡板运动误差。

## Value

对视觉世界模型可借鉴“规则假设—可执行预测—反例校验—主动探查”的学习回路，但本文的模型不是视频生成、3D 场景动力学或 JEPA/Dreamer 隐式表征，研究价值主要是间接的方法论。

## Strengths

把语义规则与程序实现区分，回放校验可追踪；统计真实交互动作成本；给出单模型群和去规则书消融，并明确承认同历史多模型可能仍不确定。

## Weaknesses

与已有 ARC code-model/规则记忆系统重合较大；规则书忠实度由 LLM 主观判断。25 个公开游戏已趋饱和，主要对比来自不同系统的公开 scorecard，模型和推理预算未完全统一；核心消融仅 3 游戏、模型群仅 1 游戏，缺少多次运行稳定性和持出游戏。无法直接映射到连续高维视频状态；LLM 与程序搜索算力不计入动作效率。

## Future Work

作者提出分析潜在模型的多样性与探索稳定性；正文相关工作也建议在持出任务、重复运行及统一推理预算下评估。可进一步将显式规则与视觉/连续动力学模型结合，但这是本文证据之外的延伸。

## Rating

创新度评分：2/5 - 规则书、编译模型和回放验证已有先例，主要是持续化整合与小规模模型群扩展。
相关度评分：1/3 (Tangential) - 研究程序化未知环境模型，只对目标视觉/3D/隐式世界模型的验证环节有间接启发。

## TL;DR

以可修订规则书和可执行程序反复校验未知游戏规律，公开关卡表现强但偏符号代理；对视觉世界模型研究可选读。
