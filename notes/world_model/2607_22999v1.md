# WCM: World-Cognition Model for Generalizable Human-Robot Interaction

## Insight
有但偏系统。论文的 observation 是：当前 VLA 和 world-model planner 主要优化“执行指令”，但真实 HRI 需要解释、纠错、教学和持续记忆。推论是把 sensing、logic、action、knowledge 显式分层，并用异步 runtime 和 CoT distillation，把人机交互过程变成可学习的推理监督。

## Motivation
论文解决机器人语言交互中可解释、可中断、可教学的问题。同行 VLA 多把语言当动作生成条件，world-model planner 多把 imagined rollout 当内部状态，用户很难理解、纠正或教机器人。该问题对 embodied agents 重要，但不是在训练预测世界模型，而是构建交互式机器人系统。

## Method
WCM 基于 SLAK：Sensing 负责把 RGB-D、IMU、力/扭矩、音频等转成含语义、局部部件、可交互属性的 scene state；Logic 是 CoT LLM，执行 plan-reason-validate loop，给出 reasoning、action、expected outcome；Action 层绑定低层技能库执行导航、抓取、放置、交接等动作；Knowledge 存储短期任务记忆、长期经验和 skill memory。

异步 runtime 让 reasoning、dialogue、execution 并行，执行前后用最新 scene/user/outcome 验证，过期动作会丢弃并重新推理。学习上记录每步 `(scene, instruction, memory, reasoning, action, expected outcome, realized outcome)`，把 autonomous rollout 和 human teaching episode 经更强模型 ensemble/refinement 转成 CoT training data；teaching 数据加权更高。

## Experiment
硬件是低成本移动机械臂：Mecanum 底盘、5-DOF arm、640x480 RGB-D，相机本体成本低于 2000 美元，推理用本地 RTX 5090。9 个真实 HRI 任务平均成功率 73.8%，包括取物、递交、工具、抽屉、垃圾桶等。具体任务成功率从 64% 到 86%，如 popcorn 85%、BBQ tongs 86%、water bottle 83%。

四个任务未进入 CoT fine-tuning 仍能迁移成功；最难任务 “Take the screwdriver to the drawer” 教学前低于 20%，human teaching 后 69%，CoT distillation 后 82%。消融显示去掉异步 runtime 使耗时增至 1.4-1.7 倍；把 interaction-aware Sensing 换成普通 VLM+2D grounding 会显著降成功率，screwdriver-to-drawer 从 69% 到 0。

## Value
价值在 HRI 系统集成，不在世界模型算法。对我们有启发的是：如果世界模型要进入真实机器人系统，用户纠错、状态记忆、执行验证和失败 trace 蒸馏很重要；但这篇没有学习 latent dynamics，也没有视频/3D predictive model。

## Strengths
系统目标明确，强调解释和中断；SLAK 分层便于工程替换；teaching-to-distillation loop 有实用意义；真实低成本平台评测覆盖多任务。

## Weaknesses
“World-Cognition Model”命名较大，实质是 LLM+感知+技能库系统；对照不充分，X-Square 比较非同平台且没有对方成功率；任务规模和 trial 数有限；CoT refinement 依赖更强模型，数据和 pipeline 细节不足。

## Future Work
作者没有详细展开未来方向，只指出当前受限于硬件和 case-study evaluation；自然后续是更严格跨平台对照、更大任务集、更透明的 teaching/distillation 数据，以及更强低层技能和感知模块。

## Rating
创新度评分：2/5 - 工程系统完整，但核心技术主要是已有 LLM/HRI/CoT distillation 组件组合。
相关度评分：1/3 (Tangential) - 与 embodied agent 相关，但不是视频/3D/隐式世界模型本体研究。

## TL;DR
构建可解释可教学的机器人交互系统，工程有参考，世界模型研究可跳读。
