# Ultrasound Operator Guidance Using World Modeling and Retrieval Based Action Planning

## Insight
若视频潜空间能把相似观察放在邻域，带动作/位姿记录的轨迹库就隐含了一个非参数世界模型：近邻检索找到与当前状态相似的历史帧，直接采用其真实后继和相对动作，不必拟合新的转移网络。作者在颈动脉超声上把该算子递归六步并闭环重规划，离线到达率 86%，高于一步/直接动作基线的 52%/43%；但离线环境把预测位姿投影到最近的已录制帧，结果依赖数据库覆盖。

## Motivation
超声图像获取依赖操作者，局部截面可能视觉相似但位置不同，一步动作预测容易迷失。已有指导系统多输出单步动作，或只在训练时内化结果；而实时自由手扫查通常没有探头位置追踪。论文要用视觉视频表征及历史扫查轨迹，在推理时从图像直接规划多步 6-DoF 探头移动。

## Method
以 4 帧窗口微调 V-JEPA 2.1，取最近双帧 tubelet、注意力池化为潜状态；训练时用视图分类、逆动力学、前向动力学头塑形表征，但推理不调用两个动力学头。另训专门视图分类器供目标概率。轨迹库保存潜状态、探头 SE(3) 位姿和视图概率；每步查 10 个余弦近邻，取该轨迹前/后一定步距的真实后继及相对位姿，递归检索形成可跨患者拼接的六步候选；按目标视图概率、动作惯性和跨次重规划反向惩罚评分，只发送第一动作后重新观测。历史位姿仅建库和回顾性评估时需要，部署端通过图像检索提供动作。

## Experiment
48 名志愿者的 247,827 帧按人划分训练 31/验证 4/测试 13；表征线性探测平衡准确率 0.81、近邻同视图纯度 0.69，高于 EchoJEPA/ImageJEPA。回顾性闭环在已录轨迹上按预测位姿匹配最近帧，六个目标视图平均到达率 86%，UltraSeP 风格 52%、Cardiac Copilot 风格 43%；六步规划在验证集 92%，一步 76%；只跟随单条近邻轨迹的版本约 82–86%。已采集患者专属目标帧复访成功 79%，成功时位移/旋转误差中位数 0.65 cm/4.5°。前瞻实验经 MobileNet 蒸馏在 CPU 实时运行，3 名健康志愿者、同一操作者，目标可达率 83% 对基线 72%；该指标按每目标两次尝试中至少一次成功计，且把规划深度降至 3。

## Value
展示“表征 + 真实轨迹库 + 在线检索”可以替代参数化动力学，适合数据丰富但转移学习困难的 JEPA 规划问题；值得关注检索半径、轨迹跨段拼接与目标概率误差对闭环稳定性的影响。临床结论仍属可行性阶段。

## Strengths
推理无需探头追踪或显式前向动力学网络；有按受试者分组的表征/导航评估、规划步长和代价项消融，以及小规模实时前瞻验证；支持任意患者专属目标帧。

## Weaknesses
所谓转移是近邻真实后继，不保证对查询状态执行同一动作会得到相同结果；历史轨迹覆盖和跨人解剖差异可能让候选拼接失效。离线“闭环”只能跳到最近录制位姿，不代表自由连续动作空间；前瞻样本仅 3 名健康志愿者和一名熟练操作者、单一超声系统，缺少新手及病变病例。

## Future Work
作者提出多标注者一致性、跨扫描仪泛化、更多志愿者与新手操作者评估、改进 6-DoF 动作指引的沟通形式，并迁移到心脏超声导航。

## Rating
创新度评分：3/5 - 把视频 JEPA 表征和真实轨迹检索组织成多步非参数转移规划，组合有启发性。
相关度评分：2/3 (Related) - 借鉴 JEPA 视频潜空间与规划，但应用集中于医学超声导航。

## TL;DR
将超声扫描轨迹库变为非参数 JEPA 世界模型，递归检索规划探头动作；做隐式规划值得精读。
