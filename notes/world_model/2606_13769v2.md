# $μ_0$: A Scalable 3D Interaction-Trace World Model

## Insight
核心 insight：像素预测浪费容量，直接动作预测受 embodiment 标签限制；3D interaction traces 是中间层表示，既保留接触/工具/物体运动，又可从多源视频自动提取、跨 embodiment 复用。

## Motivation
机器人 world model 需要可扩展训练信号。像素视频模型难抓关键接触，VLA 动作标签稀缺且专属机器人。已有 trace/flow 方法常固定网格、2D/local 坐标或 episode-level caption，无法聚焦 task-critical points。

## Method
TraceExtract 自动选择语义 keypoints（物体、工具、手、接触区），构建 globally aligned 3D traces，并给 motion segments 绑定层级语言 caption。μ0 使用 pretrained VLM backbone + modular trace expert，query 由 B-spline control points 表示，预测未来 3D traces。预训练后冻结 μ0，再与特定机器人 action expert 结合。

## Experiment
2D/3D trace prediction 中 μ0 优于 trace prediction models 和 tokenized VLM。RoboCasa 仿真与真实场景中，μ0 + action expert 成功率接近或优于带 action supervision 预训练的 VLA（如 π0）部分结果。消融验证 B-spline、DINOv2 feature、rigidity loss、depth input、history traces 等。限制是继承 keypoint/depth/perception stack 错误。

## Value
非常核心：提出 3D trace 作为 scalable cross-embodiment world model 表示，值得精读。对“预测什么”这个问题启发很强。
