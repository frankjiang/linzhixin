# CodeWAM: A Code World Action Model for End-to-End Autonomous Driving

## Insight
候选轨迹的终点价值会忽略车辆当前速度、转向以及上一决策尚在执行的运动；同一候选若从不同运动状态切入，舒适性与可行性不同。作者在固定 DrivoR 候选池中发现，候选数从 1 增至 64 时纯学习评分的两帧执行一致性由 45.2% 降至 40.2%，加入程序推演后升至 57.8%；这支持在选择候选前显式检查执行过渡，而非证明视觉预测更准确。

## Motivation
驾驶世界模型常以未来视频、BEV 或潜在奖励评估计划，却可能高估与当前运动不连续的轨迹。已知车辆运动可用控制器和运动学直接推演，而场景交互仍需从视觉学习。问题对驾驶规划有意义，但核心更像候选轨迹评分与执行连续性。

## Method
视觉侧将四路相机 DINOv2 特征几何投影至 BEV，沿候选轨迹和车身角采样后，经跨候选 Transformer 预测安全、道路合规和驾驶质量分数。程序侧用跟踪控制器和车辆运动方程从当前车态逐步执行每个候选，计算与上一计划及历史运动的加速度、jerk、偏航等差异。联合效用筛选候选，场景分数需超过验证集校准阈值才替换默认计划，并对已选计划做局部搜索；上一计划进入下一次决策上下文。场景模型在记录、扰动和规划器诱导状态上训练，程序推演无需学习。所谓“代码世界模型”主要是已知 ego 动力学加视觉后果评分，不生成完整场景未来。

## Experiment
NAVSIM v1 navtest 的 PDMS 93.6（最强列出基线 91.7），v2 修正单阶段 EPDMS 92.1（Latent-WAM 89.3）；NAVHARD 两阶段 EPDMS 50.6（WorldDrive 34.9）。冻结 DrivoR 候选与权重、无需重训时，加入执行项将 64 候选的 EPDMS 54.56→56.70、两帧执行一致性 40.2%→57.8%；Hydra-MDP EPDMS 41.16→43.35。NAVSIM 训练后零样本 nuScenes 轨迹平均 L2 0.64 m，逊于 ReAL-AD 的 0.48 m。比较方法相机数量和输入不尽相同；连续决策图为规划轨迹一致性展示，非真实闭环车辆结果。

## Value
对交互世界模型评测有启发：不能只测候选终点，应测试动作切换时的实际轨迹连续性，并区分已知物理执行与未知环境反应。对视频/3D 世界表示的直接方法贡献有限。

## Strengths
把可解析的 ego 运动与需学习的环境后果分开；冻结既有规划器的增益实验较好地隔离执行评分价值，并分析候选池增大带来的评分偏差。

## Weaknesses
执行模型依赖给定跟踪控制器和运动学；场景侧只输出候选分数，缺少交互场景的显式反事实未来。跨论文比较的传感器与训练配置不一致，NAVHARD 两阶段分数和单阶段分数不可直接对照，未展示真实车辆闭环泛化。

## Future Work
作者未提出明确技术路线；文中承认搜索式与单轨迹规划器的无重训迁移尚未验证。值得进一步评估未知车辆动力学、交互主体响应及真实闭环决策。

## Rating
创新度评分：2/5 - 将已有车辆运动学推演、跨计划舒适性与视觉候选评分组合，增益清楚但核心算法增量有限。
相关度评分：2/3 (Related) - 自动驾驶的视觉未来评分与动作后果评估有借鉴价值，世界模型表征本身不是重点。

## TL;DR
将可执行车辆动力学与视觉候选评分结合，显式检查连续规划的动作切换；评测设计可借鉴，可选读。
