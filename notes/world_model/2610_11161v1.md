# VGGTWorld-VLA: Intent-Conditioned 3D World Evolution for Autonomous Driving

## Insight

**观察**：仅凭历史几何的 VGGT-World 对同一场景只能给出弱动作条件的未来；把给定自车轨迹/转向与交通语义注入未来 token 后，换错动作会明显损害预测指标。**推论**：几何世界模型应显式接受动作条件，且离散机动与连续轨迹互补。固定历史和采样噪声的干预中，正确/错误动作的深度 RMSE 为 0.3678/0.3966，说明模型使用了动作；但只有实际未来伪真值，不能证明其反事实未来正确。

## Motivation

VGGT 及 VGGT-World 善于当前 3D 重建和未来几何 token 预测，却缺少驾驶意图条件，难评估同一观测下的替代动作。把 VLA 的语义、自车动作与几何预测接通，对可规划的 3D 世界模型很重要。现有工作多是观察驱动预测或直接规划，较少验证动作是否真正改变未来几何。

## Method

- 两帧历史单摄像头图像由冻结 VGGT 前半部分编码；两帧未来图像只在训练中供构造目标 token。给定 8 个自车轨迹点，组合 one-hot 左/直/右机动、位置、相邻位移和时间索引，经动作 tokenizer 形成条件。
- 条件时刻的三视角摄像头图像与驾驶提示进入 Qwen2.5-VL 的 VLA 分支；取第 22 层隐藏态，16 个可学习 query 通过交叉注意力压成语义 token。流匹配模型的 8 个双流块各自对未来流先注入动作再注入语义，随后 8 个单流块预测未来 VGGT token。
- 训练用 token 流匹配和冻结 VGGT 后半段解码深度的 log-depth Smooth L1；深度伪标签来自读取真实未来图像的冻结 VGGT。创新主要是条件桥接与逐层注入，流匹配和 VGGT 预测骨架沿用既有工作。

## Experiment

- NAVSIM 3,000 段平衡左/直/右转片段，10 步采样；对照原 VGGT-World 和只在 NAVSIM 上继续视觉训练的 VGGT-World-N。指标为 token MSE、余弦、深度 AbsRel/RMSE/δ1、点 EPE，参考均为 VGGT 对真实未来的伪真值。
- 本法 token MSE 0.010459，RMSE 0.367831、δ1 0.459124；原版为 0.011065、0.426050、0.418000。RMSE 改善 13.7%，但 AbsRel 从 0.385980 略退到 0.392457，且 NAVSIM 继续训练版的 AbsRel 0.376136 更好。
- 正确、零、打乱、错误动作的 Point EPE 为 0.3543/0.3563/0.3773/0.3913；联合离散+连续动作总体最好。加 VLM 语义后 RMSE 从 0.370929 小幅降至 0.367831，Point EPE 从 0.358067 至 0.354330。

## Value

直接给出“几何未来 token + 动作/语义条件”的实现与消融清单。对研究 3D 世界模型，值得借鉴动作干预、多个几何指标和语义增益单列；更关键的下一步是配真实深度、反事实轨迹及闭环规划检验。

## Strengths

明确区分历史输入与训练期未来监督；有同数据集视觉续训对照；动作零化/打乱/错机动干预及动作表示消融；同时报告变好的 RMSE 与变差的 AbsRel。

## Weaknesses

全部几何参考是 VGGT 伪标签，不是真实物理 3D；未证明预测的不同动作结果符合真实反事实。重点是两帧未来深度，缺少长期 rollout、他车行为、闭环规划或安全指标。VLM 增益小，额外推理成本未量化；图示中的多视角语义与单视角几何还可能形成信息利用不对等。

## Future Work

作者计划更有效的语义融合、轻量或异步更新语义特征，并研究多动作未来 rollout 和 imagine–evaluate–act 式闭环规划。

## Rating

创新度评分：2/5 - 在 VGGT-World 上加动作和 VLA 语义交叉注意力，属增量扩展，缺少反事实与规划验证。
相关度评分：3/3 (Core) - 直接研究动作条件 3D 几何世界演化。

## TL;DR

把自车机动轨迹和VLA语义注入VGGT未来几何预测，改善伪深度指标但未验证反事实；方法与评测缺口值得精读。
