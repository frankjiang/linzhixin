# Qwen-RobotWorld Technical Report: Unifying Embodied World Modeling through Language-Conditioned Video Generation

## Insight
论文的 observation 是 embodied world model 的数据和动作接口高度异构：机器人、驾驶、导航、人到机器人迁移都需要预测未来视觉轨迹，但动作形式不同。推论是用自然语言作为统一 action interface，可以把多 embodiment、多任务、多场景的物理经验联合训练到同一视频世界模型中。

## Motivation
解决通用视频模型缺 embodied physics、领域模型又接口狭窄的问题。目标应用包括合成数据生成、策略评估环境和语言引导规划信号。该问题对视频/机器人世界模型核心相关。

## Method
Qwen-RobotWorld 是 language-conditioned video world model。架构为 Double-Stream MMDiT：理解流用冻结 Qwen2.5-VL 编码 action language，生成流处理 video-VAE latents，60 层中逐层 joint attention。数据是 Embodied World Knowledge，约 8.6M video-text pairs、200M+ frames，覆盖 manipulation、autonomous driving、indoor navigation、human-to-robot transfer，20+ embodiments、500+ action categories。训练为 general+expert progressive curriculum：先 general visual priors，再逐步加入单视角 manipulation、多视角、concatenated multi-view、复杂任务和跨域数据。

## Experiment
EWMBench overall 4.60，优于 LVP 4.05；DreamGen Bench total 4.952 排名第一；PBench overall 0.804，为 open-source 最好；WorldModelBench total 8.99，在 open-source 中领先并接近闭源。定性展示 fine-grained language grounding、跨 embodiment、跨任务、多视角一致性和 RoboTwin-IF zero-shot。局限是技术报告式，很多指标依赖 VLM 评价，闭环控制和真实策略收益仍需更直接验证。

## Value
对用户方向价值很高：它代表“语言动作条件的视频世界模型”路线，强调跨 embodiment 统一接口和大规模 embodied data curriculum。启发是语言可以作为高层 action abstraction，但若目标是 Dreamer/JEPA 式隐式 planning，还需把生成视频转为可优化 latent state 和 policy interface。
