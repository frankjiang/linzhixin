# DynaWM: A Base-VLA-Guided World Foundation Model for Moving-Object Manipulation

## Insight
论文的 insight 是：面对移动目标，冻结 base VLA 的动作 chunk 本身可以作为强先验，但需要一个 world foundation model 根据视觉、proprioception 和 base action 重新生成 motion-aware action。也就是说，世界模型不是替代 VLA，而是动态场景下的动作校正器。

## Motivation
多数 VLA 在静态桌面任务上表现较好，但面对移动目标、避障、速度变化和多物体顺序操作时容易滞后。直接微调每个 base VLA 成本高，也难以统一适配不同 policy。

## Method
DynaWM 接收冻结 base VLA 的 action chunk，并用 Mamba-3 action encoder、V-JEPA 2.1 多视角视觉编码器、proprioceptive encoder 和 flow-matching DiT 重新生成动作 chunk。它不访问 base VLA 内部 token，也不微调 base model，因此可作为外接模块。

## Experiment
作者构建 DynaGrasp-32 benchmark 和 DynaGrasp-1600 数据集，覆盖 32 个场景、6 类动态 family、1,600 demos、约 51 万控制步和 153 万图像。DynaWM 改善全部 8 个 base/checkpoint 组合：fine-tuned 平均从 59.06 到 75.39，coarse 平均从 41.66 到 76.91，整体均值从 50.36 到 76.15。消融显示视觉编码贡献约 +27.50，去掉 action conditioning 会大幅下降。

## Value
这篇对移动物体 manipulation 的世界模型很相关。它提供了一种务实架构：让 VLA 提供粗动作，让 world model 根据动态视觉进行动作再生成。

## Strengths
问题场景重要；对多个 base VLA 都有提升；数据和 benchmark 针对动态操作；外接式设计便于部署。

## Weaknesses
主要验证在专门构建的数据和任务上；world model 生成的是动作而非显式未来视频/3D 状态，可解释性有限；长期多阶段动态任务仍需更多验证。

## Future Work
未来可扩展到更复杂实时动态场景、接触丰富任务和与 base VLA 更紧密的闭环交互。

## Rating
创新度评分：3/5 - base-VLA-guided 动作再生成有效，但结构上是多模块组合。
相关度评分：3/3 (Core) - 直接面向机器人动态操作 world/action model。

## TL;DR
DynaWM 用冻结 VLA 动作 chunk 引导动态目标抓取的世界模型，值得选读。
