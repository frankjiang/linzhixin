# RoboInter1.5: A Holistic Intermediate Representation Suite for Embodied World Modeling and Robotic Manipulation

## Insight
论文的 insight 是机器人世界模型和 VLA 不必只靠语言或低维动作条件；可把 object grounding、gripper trace、affordance、segmentation/control video 等中间表示作为更可迁移、更可解释的接口。观察是语言太粗、动作太 embodiment-specific，视觉中间表示能更直接承载未来交互结构。

## Motivation
机器人操作需要同时做空间理解、时间推理、动作执行和未来预测。已有 VLA 与视频世界模型常缺少统一的中间表示数据和评测，导致规划、控制和 world imagination 彼此割裂。本文试图构建数据、VQA、VLA 和 world model 的完整中间表示套件。

## Method
RoboInter-Data 含超过 230k episodes、571 scenes、6 种机械臂、15 primitive skills、61M object grounding frames、70M gripper trace frames、190k affordance boxes/placement proposals、760k language clips。RoboInter-VQA 包含空间/时间理解与生成任务。RoboInter-CV 把 object points/seg masks 与 gripper traces 渲染成 control videos，与 RGB、action、language、future latent chunks 对齐。VLA 有 IC-E2E、EC-E2E 和 Modular 三种形式。RoboInter-World 是 latent video diffusion transformer，输入 history latents、language、actions 和 control video，支持 oracle-control 与 planner-control。

## Experiment
Planner/VLA 上，RoboInter-Qwen-7B 在 Where2Place 65.8%、RoboRefIt 85.6%、RoboVQA 74.4；open-loop mOLS 从 Vanilla 0.3086 提升到 Modular 0.3543，Oracle+Executor 0.3861。真实世界中 IC-E2E ID 平均 77.3，高于 Vanilla 65.0；OOD 上 EC-E2E 更稳。World model 部分，14B LoRA action 条件 PSNR 18.26、SSIM 0.750、LPIPS 0.171；Seg+Trace 中间表示提升到 PSNR 21.05、SSIM 0.810、LPIPS 0.102。长 horizon H4P16 提升最大，planner-control 虽低于 oracle 但仍优于 action-only。

## Value
对 embodied video world model 很有价值，尤其是把中间视觉控制表示当成 world model 条件接口。它的启发是：世界模型未必直接吃 action token，先预测/规划 affordance、segmentation 和 gripper trace 可能更稳。待解决问题是系统庞大、贡献分散，World 部分依赖数据规模和 oracle/planner control 的质量。

## Strengths
数据规模大、标注维度丰富；覆盖 VQA、VLA 和 video world model；中间表示对未来视频预测的提升量明显；oracle 和 planner control 都有报告。

## Weaknesses
创新更偏数据与系统整合；各模块耦合复杂，复现成本高；中间表示预测错误如何级联到真实闭环仍不充分；benchmark 和数据集自有成分较大。

## Future Work
作者主要把 RoboInter1.5 定位为 suite/foundation，未来方向是扩展表示类型、数据规模和真实机器人闭环评估。

## Rating
创新度评分：3/5 - 中间表示体系和数据规模有价值，但方法上多是系统整合。
相关度评分：3/3 (Core) - 直接覆盖 embodied world modeling、机器人视频预测和 VLA。

## TL;DR
RoboInter1.5把中间表示做成数据、VLA和视频世界模型接口，World部分值得精读。
