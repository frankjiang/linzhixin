# LLM-IDEA: Identifiability-Driven Experimental Agent for Autonomous Discovery of Mechanistic World Models

## Insight

**观察**：自动科学代理拟合机制方程时，参数不收敛既可能因为搜索能力弱，也可能因为当前实验类别根本不能区分参数。**推论**：先看观测对参数的灵敏度矩阵秩与零空间，再判断退化方向能否被该类任意实验打破，可区分“继续搜索 / 换类内实验 / 换实验类别”。作者在常秩正则点用 Rothenberg 的常秩结论论证符号证书；例如 RC 电路三个常数仅以两个组合出现，任何允许的初始条件都不能恢复第三个自由度。局部一阶零方向在奇点不构成证明，数值采样证书也只对已采样设计提供证据。

## Motivation

现有 LLM 科学发现代理多在假说与实验之间循环，却不判断瓶颈来自模型能力还是观察不可辨识，因而可能在无解实验类别上浪费预算；科学发现基准甚至可能奖励数据无法区分的解释。问题对机制发现与评测设计重要，但不是视频、3D 或 JEPA/Dreamer 世界模型的直接方法。

## Method

- 五角色 LLM Council 提议假说/候选实验；确定性可辨识引擎独立计算模型输出对参数的灵敏度矩阵、秩、条件数及零方向。满秩时认为数据足以局部识别；秩亏时指出混淆参数；满秩但病态时提示实践不可辨识。
- 候选设计先按能恢复的秩排序，再按条件数打破平手；对符号模型，将设计变量保持为自由符号并验证零方向导数恒为零，且检查附近常秩，形成类级“不可再改进”证书。黑盒数值路线堆叠已采样设计的灵敏度，只是经验性检查。
- 在可解退化上运行新实验、重算秩；已达到类秩但仍不可辨识时报告可识别参数组合。算法贡献主要是把经典可辨识分析嵌入代理决策循环，而非新的世界表征。

## Experiment

- 教科书 ODE 和药代模型复现已知结论：口服药代的 F/V 混淆由静脉注射实验打破。ODEBench 有自由常数的 62 个系统中 60 个首轮可辨识；RC 电路 2/3 秩且类内证书判无解，harvesting 模型可由新初始条件改善病态。
- 自建 Alien Universe 中可辨识协议使达到发现深度 ≥3 的种子由 1/8 升至 8/8；但处理组同时改变任务文字与拟合工具，后续纠正电荷项/反馈后深度 ≥3 降至 3/8 或 2/8，不能把原差异全归于观测设计。
- 审计 DiscoverPhysics 公开世界：两世界的高分解释要求区分实验上等价的机制；这些世界中轨迹达标却解释失败为 15/15 个模型单元，可辨识世界为 5/9。实验准则对照显示其“秩优先+条件数”并不优于 A-optimal 的参数估计精度。

## Value

对世界模型评测有间接提醒：在要求模型推断隐藏物理参数或因果机制之前，应检查观测/动作接口是否允许识别这些量，避免用不可观测真值惩罚模型。对本团队的视频/3D/隐式模型架构借鉴较少。

## Strengths

严格区分局部符号证明与数值证据；报告预注册预测的失败、奇点反例、工具/种子泄漏等局限；审计外部基准暴露评分目标不可识别的问题。

## Weaknesses

主代理提升来自自建 ODE 环境，8 个种子且跨实验共享记忆，统计独立性受损；可辨识协议还改变任务文字/工具。符号路线需闭式预测和清楚定义的设计类别，数值秩受尺度与精度影响；真实视觉世界模型通常不具备这样的参数化接口。分数中的“世界模型”指机制方程，语义与本研究方向差异大。

## Future Work

作者提出固定任务文字、清空跨种子共享记忆后复现实验；让代理自由提出实验，而非二选一；在达到最大秩后用 A-optimal 改善精度，并扩展全局可辨识与非闭式模拟器的证书。

## Rating

创新度评分：3/5 - 将类级可辨识证书接入代理闭环并审计基准有方法价值，但核心数学工具已有且实证受混杂因素限制。
相关度评分：1/3 (Tangential) - 仅对物理世界模型的实验与评分可辨识性有间接启发，不研究视频/3D/隐式预测模型。

## TL;DR

以灵敏度秩和类级证书判断机制发现该继续搜索还是换实验，并揭示基准不可辨识项；偏离本方向，可跳过。
