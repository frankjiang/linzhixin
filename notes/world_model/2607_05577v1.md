# Narrative World Model: Narratology-Grounded Writer Memory for Long-Form Fiction

## Insight
Insight 是长篇小说记忆不能只存 chunk、摘要或普通实体图，而要显式建模叙事结构。Observation：作者/模型续写时常问“谁在第几章知道了秘密”“事件发生顺序与揭示顺序是否一致”“伏笔是否回收”等多跳问题；通用 RAG 或 temporal KG 往往没有这些叙事类型。推论是应将 focalization、epistemic state、event-vs-reveal order、promise-payoff、dramatic function 等作为一等状态，并用 query-conditioned graph retrieval 找证据。

## Motivation
长篇生成的痛点是已接受章节形成的 story state 难以被后续写作可靠使用。滚动摘要会丢细节，RAG 可能找错时间片段，GraphRAG/Graphiti 能表示实体和事实但缺少叙事语义。论文解决的是 writer memory 和 narrative QA，而不是物理世界模型。

## Method
NWM 的 publish flow 把已定稿章节 Cn 写入 typed memory，而不是存未来意图。每条记录带章节、证据 span 和有效区间，合并到 character、relationship、location、object、thread、promise、world fact 等 registry。Temporal KG 表示 knows、located_at、relationship polarity change、thread resolution、causation 等边，并保留 valid/invalid chapter range。

检索时严格 causal cutoff，只允许 chapter <= n。Query-conditioned hybrid retrieval 先用 BM25+dense+RRF 排名实体/seed nodes，再做 one-hop typed neighborhood expansion，最后组装固定预算 evidence packet。所有系统由同一个 Opus 4.8 reader 作答，以隔离 memory/retrieval 差异。

## Experiment
私有 5 本生产式 50 章小说构建 176 个多跳问题和 96 个单跳控制；公开 12 本公版书构建 576 问题及 110 个多跳子集。私有多跳上 NWM Graph Retrieval 达到 0.898，Graphiti 0.574，RAG 0.176，GraphRAG 0.188；McNemar 64-7，p < 1e-5。公开全量上 NWM 0.625，Graphiti 0.516；公开多跳子集 NWM 0.709，Graphiti 0.582。

消融表明 NWM State Memory 直接 dump typed store 只有 0.358，多数错误是证据在 store 中但被固定预算截断；query-conditioned retrieval 才是关键。reader-side 去类型标签不降精度，re-embedding untyped graph 甚至略升，说明优势主要来自“分解出合适叙事单元 + 查询时找对单元”，不只是标签名。

## Value
作为长文本记忆论文有价值，但对视频/3D/隐式世界模型没有直接价值。可借鉴的抽象思想是：世界状态应以任务相关的 typed state 单元表达，而不是无差别存储全部历史；同时检索策略比存储本身同等重要。

## Strengths
- 问题定义细，针对多跳 narratological QA，而不是泛泛长上下文。
- 评估协议控制 reader，一定程度隔离 memory/retrieval 贡献。
- 与 Graphiti extractor-matched 比较，并做截断、oracle、reader-family、typing ablation。

## Weaknesses
- 领域是长篇小说/NLP，不是物理世界模型。
- 私有语料和生产 NWM 后端不可复现。
- benchmark 有明显 narratology 倾向，虽然这是设计目的，但会偏向 NWM schema。
- 还没有验证 NWM-conditioned generation 是否真的改善续写质量。

## Future Work
作者明确提出下一步做 writer-loop 生成评估：让系统续写 10-15 章，评估矛盾、实体/关系一致性、复合 QA、作者修正负担和盲测偏好。还需量化故事长度超过上下文窗口后的 retrieval crossover。

## Rating
创新度评分：3/5 - 在叙事记忆和多跳检索中有明确结构创新与扎实评估，但与目标世界模型方向无关。
相关度评分：0/3 (Noise) - 纯 NLP/写作记忆系统，不涉及视频、3D 或物理 latent world model。

## TL;DR
NWM 用叙事类型图改进长篇小说记忆 QA，与物理世界模型无实质关系，可跳过。
