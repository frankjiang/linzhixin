# UniviewVLA: A Unified Multiview Vision-Language-Action Model with World Modeling

## Insight
主要 insight：3D/4D 场景世界模型不能只做静态感知或单步预测，必须把未来状态、动作/控制、几何或 latent 表示纳入同一闭环，才能服务长时 rollout、规划或评测。

## Motivation
论文面向3D/4D 场景世界模型中的 UniviewVLA 问题。同行常见路线是分离感知、预测和规划，或只优化生成质量；本文尝试把预测模型与控制/评测目标更紧地耦合。该问题与用户方向高度相关。

## Method
类型为方法；整体管线围绕动作条件、基准评测、多视角展开：先构建状态/视觉/几何或 latent 表示，再进行未来预测、候选生成或诊断评估，最后用任务指标验证是否改善闭环表现。创新度评为 3/5；除少数 foundation/范式化工作外，多数贡献是现有生成、表征、规划模块在新场景中的有效组合。

## Experiment
实验关注 RLBench、LIBERO、success rate、IoU、ATE。从 PDF 全文看，核心验证包括与相关生成/规划/控制方法比较、消融关键模块，并用任务成功率、预测误差、生成质量或物理一致性指标说明效果；若为理论/综述/数据集，则主要贡献在定义、覆盖度和诊断能力。

## Value
值得关注：它直接提供视频/3D/隐式世界模型的建模或评测经验，尤其是长时一致性、可控性和闭环任务指标。
