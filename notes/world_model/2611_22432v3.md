# Think Once, Act Fast: Cost-Effective Recursive Self-Improvement for Decision Model Harness

## Insight
把慢速 LLM 的经验写成可复用外部模块，快决策模型可在后续任务中低延迟地利用规则、状态图和一步后果预测。实验中的支持来自模块消融：在 BabyAI 上移除“世界模型”模块，StartLux-27B/Qwen 组合的训练分布成功率从 64.0% 降至 37.3%。这里的世界模型是 LLM 编写的文本游戏 Python 规则程序，并非学习得到的视频/3D 或 JEPA/Dreamer 式动力学模型。

## Motivation
小决策模型反应快但复杂任务成功率低，大 LLM 每步推理太慢。论文尝试让 LLM 异步诊断失败并修订外部工具库，摊薄后续决策成本；关注代理软件架构，而非目标研究中的视觉世界表征或生成。

## Method
System-1 是冻结的 Jev/StartLux 选择模型；System-2 LLM 读取低置信交互和预测错误，异步创建/修订三种模块：条件动作程序、状态–动作图的状态提取器、预测文本状态/奖励/终止的一步程序。按适用标签、文本相关性、历史成功率和连续失败过滤模块，给 System-1 提供历史、行动建议与候选后果。程序在回放与预测准确度检查后入库，模型权重不更新。创新主要是递归维护和检索外部 harness 的组合。

## Experiment
在 ALFWorld、BabyAI、TextCraft 三个文本交互基准上，每个训练集 200 个 episode，另设 ID/OOD 测试，指标为成功率、每步推理时间、代币成本及模块开发次数。StartLux-27B/DeepSeek 在 ALFWorld OOD 为 85.82%，裸 StartLux 为 45.52%；但 Jev/GPT 在 BabyAI ID 从裸模型 28.66% 降至 26.00%，并非所有组合改善。System-1 每步平均 0.08–0.58 秒，LLM 代理为 2.14–15.58 秒。TextCraft ID 中某组合达 100% 成功、估算支出约 0.36 美元，对比 GPT 代理约 5.38 美元。消融显示状态记忆对 ALFWorld、过程模块对 BabyAI、一步规则预测对 BabyAI 有帮助；System-2 开发触发随训练 episode 减少。

## Value
对软件代理的外部记忆与工具维护有参考意义；论文没有目标方向所需的视觉预测、3D 场景、动作条件潜状态学习或物理一致性评测。

## Strengths
将模块开发移出实时决策环，记录开发成本与运行时延；分别消融过程、状态记忆、一步预测程序和检索规则，并保留不利于论文结论的模型组合结果。

## Weaknesses
全部任务是文本游戏；“世界模型”是手工由 LLM 合成的可检查一步规则，无法证明学习到开放式世界动力学。模块效用按使用过的 episode 成功率归因，可能混淆任务难度与其他模块；异步开发时的资源占用和真实物理环境可靠性未验证。

## Future Work
作者计划改进 harness 开发及双系统协作，并承认真实具身/自动驾驶环境中的噪声观测、连续交互、不确定动力学与决策可靠性尚未测试。

## Rating
创新度评分：1/5 - 对目标世界模型研究是代理 harness 和文本规则程序的应用性系统组合，几乎没有模型方法贡献。
相关度评分：0/3 (Noise) - 不研究视频、3D 场景或隐式学习世界模型。

## TL;DR
用 LLM 异步维护文本游戏的规则、状态记忆和一步预测程序来辅助快决策模型；与视觉世界模型无实质关系，可跳过。
