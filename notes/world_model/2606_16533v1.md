# Kairos: A Native World Model Stack for Physical AI

## Insight
核心观点：Physical AI 的 world model 不只是视频生成器，而应原生支持异构经验学习、长时状态维护和低延迟部署。作者把 native pretraining、统一理解/生成/预测架构、hybrid linear temporal attention 与系统协同设计打包成 stack。

## Motivation
现有 world model 常被动生成、短视、部署慢，难以进入真实 observation-action-feedback loop。Kairos 试图定义“原生 world model stack”：跨开放视频、人类行为、机器人交互逐级学习，并在长时 rollout 中维持 memory。

## Method
Native Pre-training Paradigm 用 Cross-Embodiment Data Curriculum 组织开放世界视频、人类行为、机器人交互。Native Unified Architecture 同时做 world understanding/generation/prediction；Hybrid Linear Temporal Attention 用 sliding-window、dilated window、gated linear attention 分别处理局部、中程和全局记忆，并给出误差累积界的理论说明。Deployment-Aware Co-Design 追求低延迟 rollout。

## Experiment
报告 embodied world-model、long-horizon、action-policy benchmarks 上 top-level performance 和效率-能力权衡。由于是 90 页技术报告，实验覆盖广但许多结论依赖内部 benchmark、综合分和大规模工程细节，闭环可复现性需要谨慎。

## Value
与视频/机器人 world model 高度相关，系统视角有启发；但“stack”式论文创新密度不均，部分是数据、架构和推理优化的组合。适合选读 architecture/curriculum/attention 部分，不必逐页精读。
