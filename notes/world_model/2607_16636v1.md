# PhyAgentOS: A Self-Evolving Operating System for Embodied Agents with Decoupled Cognitive Planning and Physical Execution

## Insight
有。Observation 是 VLA、world model 和 agent planner 各自能工作，但组合后仍缺共享状态、语义验证、持久经验和安全执行边界；“动作执行完”经常被误当成“任务完成”。推论是 embodied agent 需要一个操作系统层，把 session、状态文件、验证、记忆和安全作为一等服务。

## Motivation
解决 embodied AI 从规划到物理执行之间的系统断层。ROS 提供通信，但不提供任务级调度、语义验收、跨 session 记忆和安全闭环。对 embodied world model 落地有系统价值，但论文不提出新的世界模型学习方法。

## Method
PhyAgentOS 的核心是 Session-Centered Runtime 和 State-as-a-File protocol。Agent 与 Runtime 通过 Markdown+YAML 文件交换 TASK、SESSIONS、ENVIRONMENT、LESSONS、KNOWLEDGE、SKILL 等状态；WatchdogSupervisor 负责 preflight、调度、heartbeat、结果写回；SessionVerifier 基于 evidence 给 success/failure/replan verdict；Epistemic Memory 把成功经验和失败教训固化为可复用知识。安全层包括 compatibility preflight、action bridges、SafetyGuard、heartbeat、target-local constraints。

## Experiment
三层验证。游戏层：Optimus-67 中 Wood/Stone 0.99/0.96，RedStone 0.30；StarDojo text-only 总成功率 22.0%，高于 SPIKE 18.0，Crafting 50.0%；DST-Dojo 生存天数从 1.02 到 2.10。仿真层：LIBERO 对 OpenVLA、π0、π0.5、X-VLA 均小幅提升；CALVIN full-chain π0 从 38.9% 到 45.6%，π0.5 从 85.3% 到 89.4%；RoboCasa365 overall 对 π0.5/RLDX-1/WorldDreamer 分别 +9.2/+7.2/+8.4。真实机器人层验证多平台 adapter 与安全机制，但大规模任务统计有限。

## Value
对我们可读系统架构部分：如果视频/3D world model 要接机器人执行，语义验收和 session memory 是必要 runtime 层。算法主线可跳读。

## Strengths
清楚指出 execution termination 与 semantic completion 的差别；同一协议贯穿游戏、仿真、真实机器人；对不同 VLA/policy backend 有一致恢复收益；安全和审计设计较完整。

## Weaknesses
论文很长且系统宣言成分重；真实机器人评估偏安全验证，缺大规模成功率；self-evolution 不更新神经模型，能力上限受底层 policy/agent 约束；文件协议 polling 延迟和长期记忆压缩未解决。

## Future Work
作者提出 Goal Graph/Session Compiler、把 world model 更深入接入 SessionVerifier 的 look-ahead、从 polling 改为事件驱动协议，以及大规模跨 embodiment transfer。

## Rating
创新度评分：3/5 - embodied runtime/协议层设计完整，有系统整合价值，但不是世界模型算法创新。
相关度评分：2/3 (Related) - 面向 embodied agent，可作为 world model 落地执行层参考。
