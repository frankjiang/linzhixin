# Agentic Real2Sim: Physics-based World Modeling with Vision-Language Agents

## Insight
论文的 insight 是把 Real2Sim 视为 agentic world modeling：不是端到端学习视频动力学，而是让 VLM agent 把真实交互记录拆成可仿真的 episode twin。观察是单个感知或仿真模块都难以自动闭环，作者推论需要由视觉处理、物理先验、场景准备和 simulator-in-the-loop 优化共同维护一个可执行世界状态。

## Motivation
机器人真实数据难以直接用于大规模策略训练和反事实评估，手工搭建仿真孪生成本高。同行常做离线重建、物体姿态估计或特定任务 simulator tuning，但缺少从真实 episode 到物理仿真 replay 的通用自动管线。该问题对 3D/机器人世界模型有直接借鉴价值，虽然不是 learned world model。

## Method
框架把一次真实交互表示为包含观察、动作、目标、状态轨迹、物理参数、物体和场景的 episode twin。流程包括：视觉处理 agent 做相机、关键帧、分割、SAM3D mesh、FoundationStereo 深度、FoundationPose 跟踪；物理先验推断物体身份、材质和质量；场景准备完成机器人基座、地面、物体和相机对齐；最后在 MuJoCo 中做 grasp/replay 优化，支持确定性 sweep 或 LLM 反馈循环。还展示了 deformable 和 humanoid 适配，但主要是定性。

## Experiment
DROID-100 上用最多 5 个候选 replay，由三个 VLM judge 按目标物体、最终位置、动作相似和夹爪位置打分，8 分以上视为通过。Gemma 4 31B 后端 48 成功、8 partial、44 失败，成本约 2.62 美元；Qwen、GPT、Claude 后端成功率相近，说明瓶颈更可能在感知/仿真闭环而非 VLM 本身。deformable 和 humanoid 结果主要是 qualitative。

## Value
价值在真实机器人数据到可执行 3D 仿真的自动化转换，可作为世界模型训练、评估和数据增强的基础设施。对我们而言，它提醒视频世界模型可以与显式物理仿真互补。但目前成功率仅中等，且“world model”更偏工具链和 symbolic/physics reconstruction。

## Strengths
问题实际；模块链条完整；成本、backend 对比和失败率都报告得比较透明；把 VLM agent 用在 Real2Sim 编排而不是只做文字推理。

## Weaknesses
主要覆盖刚体 DROID，通用性有限；评价高度依赖 VLM judge；仿真参数并未严格物理标定；deformable/humanoid 还没有系统指标。

## Future Work
作者希望扩展到 deformable 物体，系统评估各 perception/backend 组件，提升 replay 稳定性，并用于后续 policy learning/evaluation。

## Rating
创新度评分：3/5 - 将多模态 agent 编排成 Real2Sim 自动管线有新意，但核心模块多为组合，效果仍有限。
相关度评分：2/3 (Related) - 与 3D/机器人世界建模和仿真数据生成密切相关，但不是视频或隐式 learned world model。

## TL;DR
Agentic Real2Sim用VLM代理把真实交互转成仿真孪生，偏工具链与数据生成，可选读。
