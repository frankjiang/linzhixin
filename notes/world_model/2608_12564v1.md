# Scaling Automatic Research Agents via World Models

## Insight

论文从系统瓶颈出发：自动研究 RL 的语言生成可以批处理摊薄，而每条候选程序都要独占沙箱、真实 GPU 时间，执行成本随轨迹线性增长并最终支配训练。用语言模型预测执行结果可把奖励也变成可批处理推理，但预测奖励的系统偏差会造成不可消除的最优性误差底，随机噪声则增大梯度方差。作者推论：无需追求完美模拟器，只保留约 10% 的真实执行作为持续 anchor，便可在线校正 score scale 并按逆方差融合两种梯度。理论上，在偏差是关于真实分数的单调畸变、目标满足 smoothness/gradient-domination 等假设时，isotonic recalibration 令偏差项随训练收缩，逆方差加权令方差低于任一单流；实验也显示单用未校正 world model 明显变差，而两项校正互补。

## Motivation

AutoResearch 智能体为每个数据科学问题生成、执行和迭代代码，GRPO 需要海量在线轨迹。传统做法对每个方案真实训练模型，单次最长 1200 秒并占用约 40 GB GPU，扩展成本极高；简单的 learned reward 又可能被错误和 reward hacking 污染。如何用廉价预测替代昂贵环境，同时保留足够真实反馈以控制偏差，是模型式 RL 的重要通用问题。其主要应用是 LLM 研究智能体而非视频/3D 世界模型，但“薄真实流校正廉价模型流”的设计可迁移到真实机器人 rollout。

## Method

WMRL 在 GRPO 的 reward 侧替换环境：同一个未微调语言模型骨干读取任务和候选程序，模拟执行结果并输出预测分数。作者将其误差分解为 `r_hat = r + b + ξ`，分别处理系统 bias 与零均值 noise：

- 每步八组轨迹、每组八条；至少一组同时经过世界模型和真实沙箱，累计 `(r_hat, r)` anchor pair，其他组只用预测奖励。
- Online Debiasing 对累计 pair 拟合单调 isotonic regression，把预测分数重新映射到真实分数尺度；200 对后启用，每新增 64 对重拟合，以跟踪策略分布漂移。
- Inverse-Variance Denoising 分别聚合真实组与预测组的策略梯度，按估计方差倒数加权。预测噪声由近期校准残差估计，anchor 权重理论形式约为 `1 + η²/η_cal²`，工程上裁剪到 `[1,4]`。
- 当模型—真实分歧增大时，真实流权重自动上升，使方法退化回昂贵但可靠的标准 GRPO；适用前提是产物本身足以预测结果且能持续获得少量真值。

理论给出三种收敛界：真实奖励的标准项；纯预测奖励额外含不随训练消失的 `O(M²B²)` bias floor 和 `O(γV_WM)` 方差；WMRL 分别以约 `1+T/T0` 和 `1+V_WM/V_E` 缩小二者。但结论依赖目标的 gradient domination，以及关键的 Assumption 6——bias 必须是关于真实分数的非降单调畸变、噪声跨轨迹独立且有界；一般的语义误判并不满足该结构。

## Experiment

主实验在基于 Kaggle 的 MLE-Dojo 训练，并在未见任务的 MLE-Dojo test 与完全不相交的 DSBench 测 leaderboard percentile，报告每任务 avg@8；使用 Qwen3.5-4B/9B 作为研究 agent 和同骨干、冻结、仅 prompt 的 world model。对照未训练模型、大型 48B/120B agent、真实执行 GRPO、纯预测奖励 RL。另在 LIBERO-Long 上用 MiniVLA-1B 与 Robometer 密集进度奖励验证具身迁移。

4B/9B WMRL 分别用 286/349 GPU-hours，而真实 GRPO 为 883/1174，即约 3.1×/3.4× 节省；同时 MLE test 均值从真实 GRPO 的 15.2/18.8 提至 16.4/21.6，DSBench 从 25.7/31.2 提至 28.8/32.8。纯 world-model RL 只得 12.9/16.1 与 23.1/28.0，说明未校正替代确有性能代价。4B WMRL 超过 Kimi-48B，9B 超过 Nemotron-120B 的两个均值。消融中，朴素混合为 13.5/25.3（4B）和 16.8/29.5（9B）；仅逆方差、仅去偏均改善，两者结合再提升 2.9–4.8 点。

LIBERO 上 SFT/真实 GRPO/纯模型/WMRL 总成功率为 37.4/38.3/39.2/41.2，OOD 初始状态均值 WMRL 41.2，对真实 GRPO 提升 3.4 点。这证明 reward-side 配方能跨域，但只覆盖一个小型模拟机器人基准、40 个 RL step，不能代表真实具身世界模型。

## Value

工作最有价值之处是把“世界模型不必完美”具体化为可在线审计的校准问题，并同时计算真实执行预算、最终性能和理论误差项。对 Dreamer/机器人研究可借鉴双流训练：大量 imagined rollout 配少量真实 anchor，随模型失配自动提高真值权重。不过本文所谓世界模型只是对完整候选方案预测标量/执行报告的 LLM evaluator，不学习环境状态转移，也未做多步 imagination；与视频、3D、JEPA 主线的概念距离较大。

## Strengths

- 明确量化执行而非生成才是扩展瓶颈，并在同 GPU 配额下报告端到端 GPU-hours。
- 纯预测、真实执行、朴素双流和两项独立校正的对照闭环完整，能定位收益来源。
- 两个模型尺度、两个未见数据科学 benchmark 及一个 VLA benchmark 提供一定跨域证据。
- anchor 残差兼具校准与在线审计作用，模型不可靠时可自动依赖真实反馈，工程解释清晰。

## Weaknesses

- 理论最关键的单调 score distortion 假设很强：世界模型可能对某类方案产生非单调、结构化误判，isotonic regression 无法修复；主文的简化表述容易掩盖这一点。
- world model 与 agent 同骨干且只靠 prompt 预测，未评测 reward hacking、策略主动寻找评分漏洞或校准在严重分布漂移下是否崩溃。
- 仅报告 avg@8，没有多训练随机种子、置信区间或 anchor 比例/重拟合频率/权重裁剪的预算—性能曲线。
- 与超大模型的比较不是等计算、等 scaffold 的严格能力对照；只能说明 post-training 有效，不能单独证明模型规模不重要。
- VLA 迁移实验规模小、只在 LIBERO 模拟器，Robometer 也不是动力学模型，不能证明方法对真实、长时具身 rollout 同样成立。

## Future Work

作者主张把方法推广到所有“真实奖励昂贵、产物结果可预测且可保留少量真值”的领域。后续应重点研究非单调和条件依赖偏差、策略性 reward hacking、anchor 主动选择与不确定性触发执行，并在真实机器人/长时视频模型中比较固定真值比例和自适应采样；理论上也需放宽 gradient-domination、独立有界噪声及离散 score-level 假设。

## Rating

创新度评分：3/5 - 将预测奖励、持续真值 anchor、在线单调校准和逆方差融合组成高效 RL 配方，理论与系统实验较完整；但世界模型定义很弱，理论保证建立在强结构假设上。

相关度评分：1/3 (Tangential) - reward 校准和少量真实 rollout 可间接借鉴于 Dreamer/具身模型式 RL，也有一项 VLA 验证；主体是 LLM 自动研究和标量执行预测，不是视频、3D 或隐式动力学世界模型。

## TL;DR

以少量真实执行校准预测奖励，将研究智能体 RL 加速三倍，但非动力学世界模型，建议选读。
