# Agent World Model in the Wild: Computer-Use Agent Environment Synthesis

## Insight
这里的“world model”指可复位、可执行的数字工作环境，而非学习视觉动力学的预测模型。研究观察到单接口合成任务难覆盖真实电脑使用，于是合成横跨 GUI/MCP/CLI 的状态和任务，并以多代理实际执行及反事实挑战校验可解性、难度和验证器。

## Motivation
电脑代理真实在线训练面临环境难重置、成本及验证困难；已有环境合成常限于浏览器、工具或命令行单一接口。该问题对电脑代理训练重要，与视频/3D/隐式世界模型的技术议题基本无关。

## Method
开源模型先生成 36 个人设及逐日计划，编码代理把 15 个网站镜像、8 类 MCP 服务与本地文件物化为 640 个可重放世界状态。再生成跨三接口任务、参考解、检查清单与验证器，经过多样性、初态未完成、评判一致性、异构代理可解/难度、反事实误导等关卡，留下 341 个任务。代理训练先以 GLM-5.2 成功轨迹 SFT，再以检查清单部分奖励和自适应采样做 GRPO。属于合成训练环境与奖励工程，没有视频预测转移网络。

## Experiment
341 任务分为 100 SFT、208 RL、33 域内评测；在八个域外网页/电脑代理基准报告通过率或平均分。Qwen3.6-35B-A3B 的跨基准平均分 42.84→53.42（+10.58），4B 模型 21.83→30.04（+8.21）。去掉 SFT 暖启动后 35B 平均分 53.42→48.11，去掉清单奖励降至 51.17，显示教师轨迹仍是重要增益来源。验证器在 100 条抽样轨迹上与评判多数意见一致率 95%、Cohen κ=0.90；这衡量一致性，不等于无误的任务真值。

## Value
对本研究方向无直接方法价值；若未来构建可执行的具身环境基准，其重置、可解性与验证器压力测试流程可作间接借鉴。

## Strengths
可执行、跨接口、长时程环境与质量关卡较完整；在八个域外基准上检验模型规模和训练阶段的作用。

## Weaknesses
与视频/3D 世界模型无模型层面的联系。只有 341 个最终任务、域内评测 33 个；合成网站依赖已有 WebHarbor 底座。结果对教师 SFT 依赖明显，验证器可靠性仍主要由模型评判一致性支持。

## Future Work
作者泛称扩展合成世界与更强电脑代理；未提出与物理视觉世界模型相关的明确后续方向。

## Rating
创新度评分：2/5 - 对电脑代理环境工程有贡献，但从本研究方向看无新世界模型技术。
相关度评分：0/3 (Noise) - “world”是电脑环境状态，论文不研究视频、3D 或隐式动力学世界模型。

## TL;DR
合成跨 GUI、MCP 和 CLI 的电脑代理训练环境并提升代理分数；非视觉动力学世界模型，可跳过。
