# World Models for Robotic Manipulation: A Survey

创新度：2/5 | 相关度：2/3

## Insight
该综述提出了几个有价值的观察：

1. **预测保真度 ≠ 动作效用:** 视觉上逼真的视频预测可能对操作任务无用（不保持接触、力封闭等物理约束），反之，紧凑的latent模型虽不可视化但可能支持高效控制。世界模型的价值应按其预测的功能角色（而非架构类型）来评估。

2. **五种表征家族存在递增的结构归纳偏置谱:** 像素/视频 -> Latent -> 光流/运动场 -> 3D/4D几何 -> 物理约束，越靠右端归纳偏置越强、泛化性越好、但对标注和假设的依赖也越高。没有单一表征在所有操作场景下占优。

3. **世界模型正从任务特定的预测器演化为可复用的学习基础设施:** 在pretraining（预测先验）、post-training（数据引擎/模拟器/奖励信号）、inference（搜索/自校正/验证）三个阶段均可发挥作用。

## Motivation
**问题:** 机器人操作领域中"世界模型"概念被泛化使用——latent dynamics model、视频生成器、物理仿真器、VLA内的预测模块都被称为世界模型，但其设计选择对操作任务的影响缺乏系统分析。

**同行做法:** 已有综述侧重视频生成/自动驾驶方向，将操作仅作为附带讨论；或聚焦VLA/具身智能但将世界模型视为辅助技术而非核心分析对象。缺乏以"预测功能"为中心、统一覆盖RL/模仿学习/视频生成/VLA中世界模型的操作导向综述。

**关键性:** 机器人操作是世界模型最直接的应用场景之一，需要明确的设计指导。

## Method
**三轴分类框架：**

1. **表征轴（What is predicted，Section III）:** 五个家族——
   - 像素/视频表征：可解释但物理保真度弱（UniPi、DreamGen、Cosmos Policy）
   - Latent表征：高效但不可审计（PlaNet、Dreamer系列、V-JEPA 2）
   - 光流/运动场：直接暴露位移信号（FLIP、FlowVLA）
   - 3D/4D几何：空间一致性强（3D-VLA、TesserAct、GWM）
   - 物理约束：外推能力强但假设严格（PIN-WM）

2. **预测-动作接口轴（How prediction connects to action，Section IV）:**
   - Integrated prediction-action models（GR-1/2、WorldVLA、DreamVLA）
   - Explicit predictive planners：subgoal/trajectory/waypoint/hierarchical（SuSIE、UniPi、PIN-WM、VLP）

3. **基础设施角色轴（When prediction is used，Section V）:**
   - 合成经验生成（DreamGen、Cosmos Policy、WristWorld）
   - 候选动作过滤（Generative Predictive Control）
   - 搜索式评估（VLA-Reasoner、WorldPlanner、M3PC）
   - 学习环境（World4RL、WorldGym、GWM）
   - 结果评分与可行性验证（World Action Verifier、WoVR）

4. **生命周期轴（Section VI）:** Pretraining -> Post-training -> Inference三阶段世界模型角色演变。

**数据与评估:** 系统梳理34个操作数据集（Table II）和三层评估协议——预测保真度/下游任务性能/模拟器可靠性（Table III）。

## Experiment
综述论文无独立实验。关键总结：

- **34个数据集纵览:** 从BAIR pushing（2017）到PlayWorld/RoboCasa365（2026），按功能角色分为7类（视频预测先驱、仿真benchmark、模仿学习数据、大规模预训练语料、多模态数据、自主数据范式）。
- **评估痛点:** (1) 接触丰富交互的评估缺失——标准benchmark侧重pick-and-place/reaching，缺乏cable routing/tool use/deformable manipulation；(2) 指标碎片化——生成模型看FVD/LPIPS，latent planner看task success，learned simulator看policy ranking，彼此不可比；(3) 闭环exploitation评估不足——在学习环境中训练的策略可能发现simulator artifact而非真实技能。

## Value
**整体价值:** 组织结构清晰，以预测功能为核心的分类视角比按架构分类更有实用指导意义。对操作领域世界模型的设计选择（表征类型、动作接口、基础设施角色）提供了系统的decision tree。

**启发:** (1) "预测保真度 ≠ 动作效用"的观点提醒我们评估视频/3D世界模型时不能仅看视觉指标；(2) 世界模型作为learning infrastructure的五种角色分类（数据引擎/动作过滤/搜索评估/学习环境/结果验证）是有用的设计参考；(3) Table I对代表性方法按功能角色/表征/预测信号/生命周期阶段的对比非常有参考价值。

**待解决:** (1) 接触建模仍是最大的open challenge——摩擦/变形/多点接触的物理引擎假设与现实差距大；(2) 如何评估世界模型的"动作对齐"（action alignment）缺乏标准化指标；(3) 世界模型在closed-loop操作中的可靠性验证不足。
