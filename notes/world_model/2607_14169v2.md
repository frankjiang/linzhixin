# When a Verified World Model Still Loses: Play-Adequacy vs Prediction-Accuracy in LLM-Synthesized Code World Models

## Insight
有。Observation 是 planner 的搜索分布和随机验证 gate 的采样分布可以严重错位：随机 play 很少触发的规则，可能正是 competent planner 主动追求的关键状态。推论是 transition accuracy 100% 或 visited-state accuracy 98%+ 仍不能保证 play adequacy；危险程度服从 danger = play cost x (1 - rarity)^N。

## Motivation
解决 LLM-synthesized Code World Model 的验收标准问题。现有 CWM pipeline 通常用随机轨迹 transition accuracy 作为 gate，再交给 MCTS 规划。论文问的是：这个 gate 是否足以证明模型可用于规划？这是世界模型评估的核心问题，虽不是视频/3D。

## Method
构造和分析 perfect-information 与 imperfect-information CWM。perfect-information 中用 army5x5a + material-at-cap 罕见规则作为 instrument，比较完整/遗漏规则的 CWM 与 MCTS play。理论上证明 gate-miss probability 为 (1-rarity)^N，并给出 play cost 上界。imperfect-information 中扩展 observation/infer_states contract，证明 inference gate coverage bound，并用 Beacon 构造 verified-but-wrong belief witness。

## Experiment
小型 fully-specified games 上 gate 是 identifying：tic-tac-toe 可穷举验证零 mismatch。rare-rule instrument 中，rule-blind CWM 可 gate 1.0，gap truth 近 0，却在 4,800 games 中 rule-blind vs truth win rate 0.404 [0.384,0.424]，truth-vs-truth 0.495 [0.475,0.515]，play cost 0.091，seed-clustered CI [0.065,0.117]。真实 synthesis pipeline 中 incomplete-rules 只在 material terminal 缺席时 gate-pass，gate-pass 后 play cost 0.154。修复实验显示更多例子/DAgger/targeted transitions 也不能可靠推断遗漏规则；完整规则 spec 则 0 iteration 学会。Beacon 中 infer_states gate 0/8156 mismatch 但胜率 0.000 vs fair 0.500，policy-guided check 可拒绝。

## Value
很值得选读。它对任何世界模型评估都有警示：预测准确率必须按 planner/search/deployment distribution 审计，罕见但高价值区域要用策略引导或对抗式验证覆盖。

## Strengths
理论和 instrument 结合紧；区分 transition accuracy、state accuracy 和 play adequacy；danger law 简洁；v2 更清楚地区分 gate-miss 与 synthesis-residual 两个通道。

## Weaknesses
对象是代码游戏世界模型，不是神经视频/3D WM；构造性 instrument 可能离真实环境远；play cost 常数仍需经验测量；部分 synthesis 结论依赖 GPT-5.x family。

## Future Work
隐含方向是用 play/search distribution、policy-guided heldout trajectories、bounded adversarial search 或 specification completion 来替代单纯随机 transition gate。
