# Depth-Regularized JEPA World Models Learn More Transferable Representations from Real Outdoor Robot Data

## Insight
有。Observation 是 LeWM/SIGReg 让 latent 分布保持高熵和不坍塌，但在真实户外机器人视觉中，纯 isotropic latent 容易把外观杂波和物理结构混在一起。推论是训练期用深度作为几何 teacher，把 RGB embedding 对齐到 depth embedding，可得到“与场景几何一致的最大熵表征”，推理时仍只用 RGB。

## Motivation
解决 compact JEPA world model 在真实户外机器人数据上的迁移和物理表征问题。像 V-JEPA2 很强但大而复杂，LeWM 更轻但主要验证在仿真/简单场景。农业机器人户外视频有光照、阴影、叶片、运动模糊和地形变化，正好考验隐式 latent world model。

## Method
基于 LeWorldModel：ViT-Tiny encoder、6-layer predictor、history size 3、1-step prediction、embedding dim 192。baseline 用 latent prediction + SIGReg；本文加训练期 depth alignment loss，同一个 encoder/projector 处理 RGB 和 depth，depth branch stop-gradient，优化 RGB embedding 与 depth embedding cosine similarity。另加 predictor-side overparameterization：训练时给 predictor MLP 加 rank-16 RepLinear branch，训练后合并，不增加推理成本。

## Experiment
训练数据为 Aigen 农业机器人约 31K frames/85 episodes，验证 3,587 frames，OOD 为 TartanGround 15,608 frames/6 episodes。VO linear probe MSE 从 0.0022 降到 0.0015，优于 DINOv2 ref 0.0029。Surprise separation Aigen 从 0.067 到 0.120；TartanGround 从 0.035 到 0.099，准确率 87.5% 到 89.2%。OOD rollout h=10 goal similarity 从 0.716 到 0.745，h=20 从 0.458 到 0.537；trajectory similarity 也提升。深度先验还提升 brightness jump/color swap 的 surprise margin。

## Value
非常相关，尤其适合研究 JEPA/隐式世界模型和 3D 先验的人。它的价值在于：无需推理期深度，也不靠大模型，训练期几何先验就能改善迁移和长期 latent rollout。

## Strengths
问题场景真实且不干净；方法简单、推理零开销；VO、surprise、OOD rollout 三类指标互相支持；对 SIGReg 与 depth 的关系解释清楚。

## Weaknesses
仍是离线 latent metric，没有闭环机器人规划成功率；数据规模小、单平台、单农业域；主要对比 LeWM 变体，缺更大 pretrained world model；overparameterization 的独立贡献未消融。

## Future Work
作者提出做闭环规划评估、扩展数据/模型规模、加入更强 baseline，并做 capacity ablation。

## Rating
创新度评分：3/5 - 深度正则本身简单，但与 JEPA/SIGReg 结合在真实户外机器人数据上有明确价值。
相关度评分：3/3 (Core) - 直接研究 JEPA/隐式世界模型、几何先验和机器人视频迁移。

## TL;DR
Depth-Regularized JEPA用训练期深度先验提升户外机器人latent世界模型迁移，隐式世界模型方向值得精读。
