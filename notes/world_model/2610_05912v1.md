# MiniCorp: The Last Mile of the AI Agent Firm

## Insight
“世界模型”在此指手工构建的企业/市场模拟器，而非从视觉数据学习的动力学模型。作者的观察是静态企业档案只记录已发生决策，无法给多智能体提供长期反馈或反事实结果；因此把持续运行的公司角色、市场反馈与可重播检查点合在一起。论文通过价格、缺货、广告等干预检查模拟市场能否产生相应的时间链路，这是模拟器的经验验证，不是视觉世界模型的理论发现。

## Motivation
训练长期经营公司的 LLM 智能体需要带决策上下文与后续结果的企业记录，但真实档案稀缺且缺反事实；多数 agent 基准是有终点的单任务。论文解决办公/电商智能体的数据和评测环境问题，与视频、3D 或 JEPA/Dreamer 研究无实质重合。

## Method
外部世界以显式规则模拟搜索需求、商品匹配/排序、点击和购买、广告二价拍卖、库存、供应商及竞争对手；内部为有固定权限的 LLM 公司角色，按周查看脱敏数据、通信、提案并由 CEO 批准后改变下一周市场。持久日志记录任务和决策来源，状态检查点可在相同起点重放不同决策。所谓“模型”主要是市场机制和角色编排，未学习图像表示、时空预测器或物理动态。

## Experiment
外部市场用配对检查点干预测试：降价 10% 的需求弧弹性约 2.9–3.2；四周 20% 折扣后仍有销售延续；两周断货后的累计损失有 59% 出现在补货后；广告提高付费销量并延迟影响自然搜索。组织实验记录 30,248 个工作项，其中 58% 来自上周结转、31% 来自消息或中断；有长期广告指导的单条 26 周运行广告支出约 1,700 美元、销售额约 31,000 美元，无指导运行销售额不足 200 美元。10 个冲击情景每个重复两次，完全完成预期动作的为 11/20。作者承认跨独立市场初始化的稳健性尚未验证。

## Value
对用户当前世界模型方向几乎没有直接参考价值；若未来研究多智能体经营或反事实模拟基准，可参考持久日志与系统级响应链验证。

## Strengths
市场中间环节和角色权限显式、可追踪；检查点配对干预比仅观察利润更利于查错；同时报告未解决任务与逃避行动案例。

## Weaknesses
市场真实性只通过有限经验模式间接支持，部分路径来自设计规则本身；组织表现与单个 LLM/提示词和模拟器设定耦合，广告策略对比未见多随机种子稳健性；没有视觉/3D 输入、JEPA 表征或学习得到的世界动力学。

## Future Work
作者设想扩展至其他公司结构和行业，并指出需检验不同独立初始化市场下的保真稳健性。

## Rating
创新度评分：1/5 - 相对于视频/3D/隐式世界模型方向，主要是企业模拟规则与 LLM 角色编排，无新模型技术。
相关度评分：0/3 (Noise) - 纯企业/市场多智能体模拟，题名中的 world model 与目标研究方向无实质关系。

## TL;DR
构建可重放的企业市场模拟器供 LLM 公司智能体训练评测，与视觉世界模型无关；可跳过。
