# Hypothesis-driven Model Expansion under Uncertainty for Open-World Robot Planning

## Insight
Insight 是让 LLM 生成“可验证假设”而不是直接替代 planner。Observation：开放世界任务失败常因符号模型缺少对象、属性或动作效果；若把这些缺失知识直接当真会导致错误规划。推论是应把 LLM 输出纳入不确定模型扩展，并在计划中安排验证动作。证明主要是形式化 augmented belief state 和 optimistic determinization，再用仿真/真实机器人展示比确定性扩展更稳。

## Motivation
传统 PDDL/TAMP 规划依赖封闭、完备的世界模型；LLM planner 能猜缺失知识但缺少可验证性和可执行保证。论文解决的是开放环境中机器人如何在未知对象、属性、动作效果下规划。这个问题重要，但这里的 world model 是符号/任务模型，不是视频、3D 或 JEPA/Dreamer 式世界模型。

## Method
HUME 从初始符号模型 M 出发，包括 scene graph 和 PDDL domain。LLM 生成任务相关 hypotheses，类型包括 object_existence、object_attribute、action_effect，每个假设带 PDDL 内容、依赖条件和 verification_condition。系统把状态扩展为 S x belief(h)，belief 为 True/False/Unknown，并自动加入验证动作。

规划使用 all-outcomes determinization 和 optimistic branch cut：可乐观使用未知假设，但对未验证假设设高代价，鼓励先验证。执行时用检测器、scene graph 或 VLM 检查假设；确认则并入模型，否定则记录到 history 并提示 LLM 生成新假设后重规划。

## Experiment
实验包括 Block Processing World、AI2-THOR mobile manipulation 和真实 Fetch 家庭环境。对比包括无模型扩展、确定性扩展、不确定扩展，以及 formal planner/LLM planner。结果趋势很清楚：无扩展在需要隐藏对象/属性/动作效果时常失败；确定性扩展会因错误假设失败；uncertainty-aware expansion 在仿真和真实任务上成功率显著更高。

真实环境任务包括找无糖饮料、找红按钮遥控器、把笑脸杯放进冰箱、加热鸡肉汉堡、找蓝花碗并关灯等。论文报告不确定扩展在真实任务上明显优于无扩展和确定性扩展，同时 SPL 更高。

## Value
对我们的直接价值有限，但有一个可借鉴思想：世界模型可以显式区分“已知状态”和“待验证假设”，并把验证作为规划动作的一部分。若迁移到视频/3D 世界模型，可用于主动感知、场景假设维护和不确定 rollout 校验。

## Strengths
- 清晰地区分 LLM 生成知识、形式规划和执行验证。
- 假设类型、belief 扩展和验证动作设计完整。
- 有仿真与真实机器人实验，展示开放世界规划收益。

## Weaknesses
- 与物理/视觉世界模型关系弱，主要是符号任务模型扩展。
- 依赖 LLM 能生成有用且有界的假设与验证条件。
- belief 只有三值，不做概率风险和信息价值推理。
- 几何、接触、连续控制等机器人核心难点基本外置给 primitive skills。

## Future Work
作者方向包括 probabilistic/belief-space TAMP、geometry-aware verification、active sensing，以及从人类、手册、示范、记忆等多源生成假设。对本方向可扩展为用视频/3D 世界模型产生可验证几何假设。

## Rating
创新度评分：3/5 - 符号开放世界规划中有较完整的不确定假设机制，但不是视频/3D 世界模型技术突破。
相关度评分：1/3 (Tangential) - 仅在“世界模型=任务模型”的抽象层面间接相关。

## TL;DR
HUME 将 LLM 知识作为可验证假设纳入 PDDL 规划，对物理世界模型启发间接，可选读。
