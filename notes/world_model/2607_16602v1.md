# PAVXploreRL: Physical-Action-Visual World Model Reinforcement Learning with Action Exploration

## Insight
有。Observation 是 action-conditioned robot world model 不能只拟合 expert ID 视频，否则会对 OOD/suboptimal actions 过度乐观；同时 pixel reconstruction 无法直接优化物理合理性、动作服从和视觉质量。推论是用 domain-adapted latent world model (VJEPA-2) 作为奖励评估器，并加入无 paired video 的 OOD action exploration，可后训练出更可靠的策略评估世界模型。

## Motivation
解决机器人 action-conditioned video world model 的 PAV 目标：Physical plausibility、Action adherence、Visual fidelity。同行多用 ID expert action-video pairs 和 pixel/VLM reward，泛化到失败动作或次优策略时会高估成功率。这是 embodied/video world model 核心问题。

## Method
基于 Wan2.2-TI2V-5B 改成动作条件视频预测器：AdaLN 注入 action embedding，Framepack 压缩历史。SFT 后用 DiffusionNFT 做 RL，只更新 action encoder 和 LoRA。奖励分 ID/OOD：ID 用 pixel MSE/SSIM/LPIPS、VJEPA encoder latent similarity 和 no-reference visual fidelity；OOD 对 GT action 加 temporal shift、magnitude bias、smooth noise，无 GT 视频时用 action-conditioned VJEPA predictor reward + visual fidelity，并加 zero-action static regularization。VJEPA-2 在机器人数据上训练 raw 与 embodiment-focused frames。

## Experiment
Agibot Alpha 92K trajectories/590h、DROID 76K/350h。Agibot 上 RL 从 PT 的 PSNR 20.52、SSIM 0.793、LPIPS 0.133、EPE 0.346、COS 0.203 提升到 21.20/0.812/0.127/0.306/0.231；DROID 上提升到 PSNR 21.71、SSIM 0.828、LPIPS 0.092，超过或接近 Ctrl-World 等 baseline。消融显示全 reward 最好，static regularization 影响最大。作为 policy evaluator，比较 π0/π0.5 五个真实任务，PAVXploreRL 相比 Ctrl-World 减少成功率过估计，更能反映 loose grasp、碰撞等失败。

## Value
很值得精读。它把 JEPA-style latent predictor 用作 reward/evaluator，而不是只做表征；同时正面处理 OOD action，是世界模型作为策略评估器必须面对的问题。

## Strengths
PAV 目标定义清晰；ID/OOD reward 设计有针对性；机器人数据规模较大；既评估视频指标，也评估 policy evaluator 的 overestimation bias；消融解释充分。

## Weaknesses
RL 后训练成本高，5K steps 仍需多天 H200；base world model 无 multi-view consistency；OOD actions 是噪声扰动，不是真实失败策略分布；真实策略评估任务数量较少。

## Future Work
作者提出把该 RL 框架扩展到更先进的 pretrained world model，测试泛化和鲁棒性；也可补 multi-view consistency 与更高效 reward 计算。

## Rating
创新度评分：3/5 - reward-driven 后训练和 OOD action exploration 很有价值，但主要是组合已有 diffusion RL 与 VJEPA。
相关度评分：3/3 (Core) - 直接研究 action-conditioned video/robot world model 与 JEPA 奖励。

## TL;DR
PAVXploreRL用VJEPA奖励和OOD动作探索后训练机器人视频世界模型，策略评估方向值得精读。
