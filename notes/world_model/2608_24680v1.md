# Game2World Engine: Unlocking In-the-Wild Gameplay Videos for World Model Training

## Insight

Observation：网络 gameplay frame 不是纯世界观测，而是 game world 与 HUD、菜单、通知、直播层的合成；这些锐利、固定屏幕坐标且有自身时间规律的元素会成为视频生成模型的捷径。论文用同一批 5,442 个 clean clips 构造 clean/UI-overlayed 配对训练集，发现 clean 数据使 Wan2.1-T2V-1.3B 的整体 VideoReward 提升 6.83%，其中 motion quality +18.8%、video quality +2.7%，并使数据本身 aesthetic +8.59%、motion +4.36%。据此推论，先做 interface–world disentanglement 能提高网络 gameplay 作为 world-model 语料的价值。证据控制了底层视频差异，但只使用 text-conditioned video generation proxy，没有证明对 action-conditioned dynamics、规划或交互性能同样成立。

## Motivation

游戏视频数量巨大，覆盖多样 3D 环境、视角、任务和行为，是扩展视频世界模型的潜在廉价数据源；然而 HUD 的类别、位置、透明度与弹出动画跨游戏变化，直接训练会学习非物理 screen-space dynamics。现有 world model 通常把渲染帧视作世界观测，传统 video inpainting 又多针对自然视频物体、需要 mask，缺少 gameplay UI 语义和跨帧实例协议。论文解决的是重要的数据清洗和 benchmark 基础设施，而不是世界模型结构本身。

## Method

G2WEngine 先定义 21 类 GameUI-Taxonomy，覆盖 map/radar、player/weapon/ability status、objective、world context、subtitle/chat、watermark/stream overlay 等。它从 303 个游戏的 1,010 个代表帧中由模型提议 bbox/类别、人工核验，提取 5,132 个透明 UI assets 并保留来源、位置和渲染 metadata。clean corpus 把视频切成 5 s 窗口，用 CLIP ViT-B/16 spherical k-means 做 cluster-balanced sampling，并以相邻 cosine>0.94 去重、统一为 720p/30 FPS。

合成器按类别概率、空间 anchor、源坐标、尺度/透明度、碰撞阈值 0.14 和 seeded jitter 组织 persistent HUD；对 transient UI 采样时长、漂移及 fade/slide/pop/wipe/border-arc 等动画，并可分解 status bar 与 inventory icon。每例产生 clean/UI-overlayed 视频、逐帧 mask/bbox、taxonomy、instance track 和完整可复现 metadata。由此形成 Game2World-S 96K 配对视频，以及无 clean reference 的 Game2World-W：1,079 个 5 s clips、303 个游戏，逐帧更新动态 UI 标注。

GameCleaner 继承 Kiwi-Edit：冻结 pretrained MLLM 与 connector，用 learnable queries 对 source frames 和 removal instruction 做 cross-attention，条件化 video DiT；source VAE latent 通过 timestep-dependent residual 注入 noisy target。仅对 DiT 加 rank-64 LoRA，以 UI-overlayed→clean 的 flow matching 后训练，推理无需 mask；另有 reference-conditioned checkpoint 及训练时 20% reference drop 变体。核心模型创新较小，主要贡献在 taxonomy、数据引擎和任务化评测。

## Experiment

主评测比较 Aurora、Kiwi-Edit、LoomVideo、LTX-2、Lucy-Edit、OmniWeaving、VACE-1.3B/14B 与 EffectErase。视频按 2 FPS、统一 1280×720 评估；MLLM judge 对每个 UI 元素给 removal、artifact，对框外区域给 background preservation，得到 UI、Clean、Artifact-Adjusted Removal (AAR)、BG、uncertain，以及 frame/box/track 指标。judge 在 200 videos、6,150 个 element labels 和 2,000 个 frame labels 上，与人工达到 removal F1 87.78%、artifact agreement 85.96%、preservation agreement 78.00%、Cohen κ=0.820；五次聚合的 AAR ICC(A,5)=0.926。

Ref) 总分 93.34；synthetic AAR/BG 为 94.64/98.85，in-the-wild 为 80.05/99.80。经 reference post-training 但推理不提供 reference 的版本总分 85.97、wild AAR/BG 51.60/99.60；标准 GameCleaner 为 85.63，synthetic AAR 95.36、BG 99.00，wild AAR 48.56、BG 99.60。强 mask baseline VACE-1.3B 总分 69.37；EffectErase 在 wild raw UI removal 达 92.00，却因 artifact/背景变化只得 AAR 23.55、BG 74.55、Track-Clean 16.12，说明 AAR 的必要性。带 reference 的 GameCleaner wild Track-Clean 为 68.12。训练数据从 60% 增到 100% 时，reference-conditioned synthetic AAR 仅 +2.06 pp，但 wild AAR +25.09 pp；20% reference drop 最佳。附录给出 timestamp 对齐、box mapping、judge schema 与逐帧案例；视觉核验中，带 reference 的 Halo Infinite 案例为 82/82 元素、100% removal/preservation，而无 reference 的 Mass Effect 仅移除 16/56、AAR 28%，直观暴露复杂原生 HUD 的失败边界。

## Value

工作证明“清除 screen-space nuisance dynamics”可能是扩展 gameplay world model 数据的高收益预处理，并提供规模较大、监督精细的 paired corpus。对视频世界模型的启发是先显式区分可交互 world layer 与 presentation layer，再学习 dynamics；taxonomy/track metadata 还可辅助 latent action 或对象级建模。其直接研究价值仍是数据与视频编辑：没有恢复玩家动作，也没有训练动作条件世界模型，作者自己承认 inverse dynamics/latent action across games 才是下一道关键门槛。

## Strengths

从问题定义、21 类 taxonomy、真实 asset、可复现 temporal synthesis、paired/wild 双 benchmark 到 removal model 形成完整栈。pilot 使用同源 clean/overlay 数据，较好隔离 UI 的训练影响。评测不只看“UI 是否消失”，还惩罚 artifact 与框外改动，并做人工校准、inter-rater reliability、分辨率敏感性和逐轨迹指标。数据规模与跨 303 游戏的覆盖有实用价值，作者也明确区分 proxy world-model study 与真正 action-conditioned 验证。

## Weaknesses

最核心的 world-model claim 仅由 5,442 clips 上的 T2V proxy 支持，没有动作、闭环 rollout、可控性或下游 agent 指标；而 overlay 是自家合成器生成，不能代表真实 HUD 清洗误差。GameCleaner 基本是 Kiwi-Edit+LoRA，缺少 MLLM、source residual、taxonomy-aware training 等组件消融。MLLM judge 的 preservation agreement 只有 78%，每视频只做一次 stochastic judgment，且表 6 显示分辨率会显著改变 AAR/uncertainty；reference 变体还依赖 clean reference，真实网络视频通常不可得。论文实现记录存在矛盾：正文写 8×H100、3,000 steps，附录写 8×H200、1,400 steps，且 checkpoint 描述也不完全一致，削弱复现性。大面积不透明、快速变化或与场景视觉纠缠的 UI 仍难恢复；网络来源、许可与 clean corpus 真实性也需更清楚说明。

## Future Work

作者提出把数据扩至 1M、更多游戏/UI/录制条件；开发跨异构游戏的 action recovery，把 clean videos 转成 observation–action trajectories 并直接训练 action-conditioned world model；把 GameCleaner 蒸馏成 few-step 模型并做推理优化。还应在真实 HUD 去除输出上训练/评估 world model，加入 latent-action quality、长时交互和数据许可审计。

## Rating

创新度评分：3/5 - taxonomy、真实资产驱动的时序合成、paired/wild benchmark 和 artifact-aware 评测构成有分量的数据贡献；GameCleaner 技术增量较小，且 world-model 收益只由 T2V proxy 验证。
相关度评分：2/3 (Related) - 直接服务 gameplay 视频世界模型的数据构建，但不学习动作条件动力学、3D 状态或 JEPA/Dreamer latent transition。

## TL;DR

以 UI 分类、合成配对数据和 GameCleaner 清洗网游视频，数据价值明确但未验证动作世界模型，可选读。
