# How Many Exposures Does a World Model Need? Learning Unseen Game Mechanics at Test Time

## Insight
观察：逐像素整体预测准确率被大量不变像素主导，难反映世界模型是否真的学会新机制。作者用程序标注「某机制实际改动的像素」，量化首次接触后多少次曝光才能稳定预测；98.8% 的全像素持久性基线说明这种拆分必要。跨未见位置/方向的提升支持机制迁移，但不能证明模型形成了通用规则表征。

## Motivation
交互世界模型在部署时可能遇到从未见过的规则，固定测试集一步误差无法描述适应速度。与传统只评估训练后能力的做法相比，「曝光次数」是更贴近在线学习的关键指标。

## Method
MechEval 基于 ARC-AGI-3 的 20 个公开交互游戏，给 69 种重复出现的机制建立程序级像素标签，并收集 279 条人类操作记录、约 2.99 万状态转移。WARC 是 3500 万参数 ViT，输入最近 3 帧和动作，预测 64×64、16 色的下一帧；先在其他游戏预训，测试时每个新转移做 20 步梯度更新，混用新样本和回放。评测记录机制改动像素准确率及持续超过 80% 所需曝光数；另以固定图探索器结合预测新颖度作智能体。

## Experiment
机制改动像素准确率：WARC 69.1%，冻结版 18.4%，从零在线训练 35.0%，DreamerV3 25.9%；达到 80% 稳定阈值的中位曝光数 WARC 为 74，冻结版 114；永未达标比例 18.8% 对 85.5%。加预测模型的固定探索器，RHAE 从 0.149 升至 0.455，真实世界模型 oracle 为 1.392；L1 通关 31.6%→46.0%。反例是首次遇到受阻移动时，WARC 对「应保持不变」的判断仅 58%，冻结版 89%，显示过泛化。测试环境为确定性、完全可观测离散游戏；Kaggle 隐藏关卡公开榜得分约 0.20，尚非强通用体。

## Value
机制级曝光曲线是评估在线适应世界模型的有价值模板，可迁移到视频/机器人任务中的碰撞、遮挡或操作规则，但本工作还停留在像素游戏。

## Strengths
机制标签、持久性基线、冻结/从零对比与行为结果形成较完整证据链；公开失效例与计算开销。

## Weaknesses
机制标签依赖可访问游戏源码及人类记录；80%「之后一直保持」阈值受序列长度影响；在线更新计算较重，探索策略仍手工设计。

## Future Work
作者提出迁往连续、随机与部分可观测环境，改进探索决策并用更长序列验证机制迁移。

## Rating
创新度评分：3/5 - 机制曝光评测视角较新，模型主体仍是常规像素预测加在线微调。
相关度评分：2/3 (Related) - 研究视觉交互世界模型在线适应，可借鉴评测，但不是视频/3D/JEPA 主流设定。

## TL;DR
以机制改动像素和达标曝光数评估在线世界模型，揭示冻结模型缺陷与过泛化；做适应评测值得精读。
