# Cosmos 3: Omnimodal World Models for Physical AI

## Insight
核心观察：Physical AI agent 需要同时具备理解（understanding）和生成（generation）两大能力，但此前这两者由 VLM、视频生成模型、VLA/WAM 等碎片化管线分别处理，既低效又难以共享表征。Cosmos 3 的核心推论是：可以用统一的 Mixture-of-Transformers (MoT) 架构，将语言/图像/视频/音频/动作五种模态的理解和生成融合在同一模型中，通过双塔（Reasoner tower + Generator tower）在同一序列上并行处理 AR（自回归/理解）和 DM（扩散/生成）子序列。证明方式是在 48 个 Reasoner benchmark 和多个 Generator benchmark（T2I/T2V/I2V/Audio/Action/Transfer）上全面超越或持平专用模型。

## Motivation
- 问题：构建 Physical AI（具身智能体）需要统一的感知-推理-模拟-执行能力，但当前范式用 VLM+视频生成+VLA 多个模型拼接，缺乏共享世界表征。
- 同行做法：Cosmos-Predict 2.5 等仅做视频生成；Qwen3-VL 等仅做多模态理解；pi_0.5 等仅做策略模型。各自独立，无法相互增益。
- 关键性：对于真正可用的 Physical AI 基础模型，统一架构是必要条件，能让理解指导生成质量、生成反哺理解训练数据。

## Method
**整体管线：**
1. **多模态编码器**：视觉理解用 ViT 编码器（与 Qwen3-VL 对齐），视觉生成用 Wan2.2 的 Video VAE（时间 4x、空间 32x32 压缩），音频用 Audio VAE（25 tokens/s），动作用统一的 relative-pose pseudo-action 表征（Ego 9D + Effector 9D + Grasp），通过 domain-aware 投影层映射到共享空间。
2. **Token排列与生成模式**：输入序列 = AR子序列 + DM子序列。AR子序列包含语言和 ViT 视觉 tokens（因果自注意力），DM子序列包含 VAE 视觉/音频/动作 tokens（全双向注意力，可attend AR tokens）。支持 T2I、T2V(+Audio)、I2V/V2V、Video Transfer、Forward/Inverse Dynamics、Policy 等多种模式。
3. **MoT 双塔架构**：每个 Transformer 层包含两组参数（Reasoner tower 和 Generator tower），共享注意力但独立 LayerNorm/FFN。从预训练 VLM 初始化双塔，Generator 用 flow-matching 训练。
4. **3D MRoPE + 绝对时间调制**：扩展 3D Multimodal RoPE 使之对齐不同帧率的视频/音频/动作 token 到统一物理时间轴（FPS modulation）。AR/DM 子序列之间插入 temporal gap=15000 避免 artifacts。
5. **统一动作表征**：将自动驾驶、相机、机器人（单臂/双臂/人形）、人类自中心动作统一为 (ego_pose 9D, effector_pose 9D, grasp_state) 的结构化向量，通过 domain-specific 线性投影共享 backbone。
6. **模型规模**：Edge(4B)、Nano(16B, 基于 Qwen3-VL-8B)、Super(64B, 基于 Qwen3-VL-32B)。
7. **训练**：Reasoner 22M 预训练 + 2.2M SFT；Generator 分阶段（预训练 767M 图+348M 视频 -> 中训练引入音频/动作/Transfer -> 后训练特化 T2I/I2V/Policy）。数据清洗用语义去重 + AI-judge 质量过滤（Gemma-4-31B）。

**关键创新：**
- 双塔 MoT 统一 AR 理解和扩散生成，AR tokens 不受 DM 更新（保持因果完整性）
- 统一动作表征将多种具身控制空间映射到共享语义空间
- FPS modulation 解决多模态时间轴对齐
- Reasoner 作为 Prompt Upsampler 提升 Generator 质量

## Experiment
**Reasoner 评估（48 benchmarks）：**
- General：Super 平均 73.7，超越 Qwen3-VL-32B（72.8）和 Gemma-4-31B（68.9），略低于 Gemini 3.1 Pro（77.5 闭源）
- Robotics 17 benchmarks：Super 57.8 显著领先同规模开源模型
- Smart Infra / Driving：同样领先

**Generator 评估：**
- T2I：Cosmos3-Super-Text2Image 在 UniGenBench 得分 91.36（开源 #1），Artificial Analysis T2I 排行榜开源权重 #1（全球 #4）
- T2V/I2V：PAIBench-G T2V/I2V 均为开源最佳，超越 Veo-3.1 等闭源模型；RBench 机器人视频生成也是开源最佳
- Physics-IQ：I2V 43.8（SOTA），V2V 59.7（SOTA）
- Cosmos HUE 人评：T2V 89.3（开源最佳），I2V 89.6（开源最佳）
- 音频：语义对齐（SA/AVAlign）开源最强
- 动作：AV 逆动力学、相机/自中心 FD、机器人 FD/Policy 均超越专用基线
- Transfer：PAIBench-C 4 种控制模态全部匹配或超越专用 ControlNet

**消融（Appendix E）：**
- Reasoner Prompt Upsampler 显著提升 Generator 质量
- FPS modulation 对多帧率训练重要
- 音频预训练数据提升视听对齐
- 动作中训练跨域迁移有增益
- 视频-动作联合生成具有一致性

## Value
- **工作价值极高**：这是目前最全面的全模态世界模型，首次在单一架构中统一 VLM + 视频/图像生成 + 音频生成 + 动作建模（FD/ID/Policy），并在几乎所有开源评测中取得 SOTA。
- **对我们的启发**：
  1. MoT 双塔是统一理解/生成的有效架构选择，比简单混合好
  2. 统一动作表征（relative-pose pseudo-action）的设计值得借鉴
  3. Reasoner 作为 Prompt Upsampler 的思路说明理解-生成可互相增益
  4. FPS modulation 解决了多模态时间对齐，是实用技术
- **待解决问题**：闭源 Gemini 在部分理解任务仍领先；音频感知质量尚有差距；长时序一致性（如 MBench 所测）未见评估；Edge 模型尚未发布

## Strengths
亮点是工作价值极高：这是目前最全面的全模态世界模型，首次在单一架构中统一 VLM + 视频/图像生成 + 音频生成 + 动作建模（FD/ID/Policy），并在几乎所有开源评测中取得 SOTA。

## Rating

创新度评分：4/5
- 在统一架构层面有显著创新（MoT双塔、统一动作表征、FPS modulation），并在极大规模上验证了效果。但核心组件（AR+Diffusion混合、MoT）并非全新原创，而是对已有想法的大规模系统性整合。
