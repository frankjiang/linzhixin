# Toward Active Object Detection for UAVs in the Wild: A Large-Scale Dataset, Benchmark and Method

## Insight
论文的 insight 是：UAV 主动目标检测的泛化瓶颈不只是 DRL 策略训练，而是 state representation 对视角、遮挡和场景上下文不够稳健。JEPA 式下一步表征预测可作为 world model 约束，迫使策略网络编码动作-观测关系；再用 AOD-specific scene purification 去掉无关背景纹理，可进一步缩小 train/test policy gap。

## Motivation
UAV 图像目标检测常受遮挡和目标像素小影响。Active Object Detection 通过移动到更好视角改善识别，但现有 UAV AOD 数据集少、真实场景不足，DRL 策略泛化差。论文主要解决两个问题：构建真实大规模 UGAOD 数据集/benchmark；提出 AOD-JEPA/WMPL 改善主动观察策略的泛化。

## Method
数据集 ATRNet-LUDO：40 个真实区域、10 类白色车辆、121K 多视角全景图、1.21M local target patches，可构建 200 个多目标和 2000 个单目标 AOD 环境。UAV 轨迹由密集离散采样点组合模拟，记录 UAV/target 经纬度、相机方位和俯仰等信息。

方法 WMPL：在 Dueling DQN/MAP 类策略学习中加入 world model feature prediction loss。Memory encoder 将历史观测、bbox、角度、动作等序列经 MLP+GRU 融合为 state representation；Q-network 输出动作类型和动作幅度。训练目标为 `LRL + ζ LPR`。

AOD-JEPA：给定历史 state 和 action，预测下一观测的表征而不是像素。scene purification 用 SAM3 根据 bbox/类别 prompt 保留目标原像素，并将同类周围物体 mask 赋同一灰度，过滤背景颜色纹理，让预测目标更关注目标姿态和空间关系。

## Experiment
评估任务是单目标 UGAOD，指标为 return、recognition rate/accuracy、movement distance。对比 MAP、MTL、SSL-MAP、IBE-MAP、random、forward，并比较 CLIP encoder 和多种 SSL world model 架构：contrastive learning、reward model、inverse model、forward model、predictive coding、AOD-JEPA。

被动检测/识别实验证明遮挡明显降低性能，支持主动感知必要性。主动策略上，WMPL 在测试环境优于 DRL baseline：Split 1 测试 accuracy 0.634，高于 MAP 0.600、IBE-MAP 0.615；Split 2 为 0.592，高于 MAP 0.557。CLIP encoder 下 WMPL 测试 accuracy 0.636，也高于 baseline。AOD-JEPA 在 SSL 架构对比中测试 return 0.096、accuracy 0.634，优于 predictive coding 0.089/0.620 和 MAP 0.085/0.613。消融中 AOD-JEPA 相比 Vanilla 测试 return 从 0.071 到 0.096，accuracy 从 0.600 到 0.634。

## Value
价值主要在数据集和任务 benchmark；对 world model 方向的启发是 JEPA 表征预测可以作为策略学习中的辅助 world model loss，提升跨场景泛化。它不是通用视频/3D 生成 world model，方法贡献偏应用化，但对“world model + active perception”有参考价值。

## Strengths
真实数据规模大；任务定义、动作空间、奖励和评估指标完整；比较了多种 AOD policy 和 SSL world model pretext；消融较细，能看出 JEPA 与 scene purification 的作用；明确展示主动观察相对被动识别的收益。

## Weaknesses
核心算法增量有限，主要是 JEPA + SAM3 scene purification + DQN；world model 只预测下一观测表征，没有长期 rollout 或规划；只做单目标 benchmark，和更复杂多目标/动态目标仍有距离；提升幅度约 2-3 个识别率点，效果不算大；依赖 SAM3 和数据构造，现实在线部署成本未充分讨论。

## Future Work
作者提出未来将继续探索 UGAOD world model 的设计和训练，使 agent 通过 3D scene understanding 学到更可泛化的主动观察策略。
