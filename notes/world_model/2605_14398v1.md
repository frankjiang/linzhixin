# Coding Agent Is Good As World Simulator

## Insight
与其学习隐式的latent视频预测模型，不如让LLM Agent直接生成可执行的物理仿真代码（PyChrono）作为世界模型。代码即世界表示：显式指定物体、关节、接触、材料、传感器，物理引擎负责推进时间。

## Motivation
视频世界模型（Sora等）能生成视觉上plausible的视频，但不保证物理一致性（不稳定接触、变形物体、运动不连续）。原因是动力学以隐式latent state表示，缺乏显式物理约束。论文提出用代码生成替代帧预测，实现可检查、可修复、物理grounded的世界模拟。

## Method
- **多Agent框架**：
  - Plan Agent：文本/图像→结构化仿真计划（物体、拓扑关系、物理角色）
  - Code Agent：计划→PyChrono可执行代码（技能库+工具接口+API验证）
  - Visual Review Agent：VLM检查仿真视频的视觉一致性
  - Simulation Judge：综合日志/物理数据/视觉反馈判断是否通过
- **空间谓词系统**：位置/对齐/包含/朝向/流体等谓词，符号化描述场景关系
- **Asset Library**：外部3D资产 + PyChrono原生资产，CoACD凸分解用于碰撞检测
- **迭代修复**：失败时修复现有代码而非重新生成

## Experiment
- **WorldModelBench**：在FSI（流固耦合）场景上显著优于Wan2.2-TI2V-5B（p=0.0012）
- **指令遵循**：Instruction score大幅提升（+2.40, p=0.000059），代码能精确保留场景约束
- **物理定律**：Physical-laws score差异不显著，说明视频模型在简单物理场景下也还行
- **成本**：单次仿真24-30分钟，token消耗10^5-10^6级别
- 仅验证3个场景（室内机器人、室外车辆、流固耦合）

## Value
提出了一种有趣的"世界模型"替代范式：代码生成代替帧预测。对理解世界模型的本质（显式vs隐式物理表示）有启发。但与主流视频/隐式世界模型研究路线差异很大，更偏向仿真工程和LLM代码生成。实验规模小（3个场景），实用性有限。

## Strengths
