# MirrorComm: A Communication-Efficient Cooperative Perception Framework via Mirrored World Models

## Insight
若通信两端持有相同预测器与同步的重建历史，发送端可本地复现接收端对当前观测的预测，只发送预测误差最大的 BEV 位置，无需接收端反馈。论文在 OPV2V 上用任务精度与带宽的配对比较，证明大量帧级特征重复传输可由时序预测替代；断续通信时预测也能缓解特征过时。

## Motivation
车辆协同感知需要互传 LiDAR/BEV 特征，但逐帧压缩反复发送可从历史推测的信息。现有选择性传输方法大多按当前帧决定，缺少利用双方共享历史的残差通信机制。该问题对低带宽多车感知重要，对通用视频/3D 世界模型则是应用侧问题。

## Method
两端以四帧**重建的** BEV 特征为共同历史，按相对位姿对齐后由多尺度空间注意力、因果时间注意力预测当前特征相对上一帧的残差。发送端比较预测与本车真实 BEV，按 L2 误差挑选预算内的位置，并以四级残差向量量化传送位置和特征码；两端同样替换这些位置，未传位置保留预测，使下一时刻历史仍同步。接收端将重建的协作特征与本地特征融合做检测/分割。训练中展开预测、通信、更新循环，并对预测、重建、未传位置及下游任务联合监督。创新是**镜像预测器+稀疏残差通信**的系统组合。

## Experiment
使用 CARLA/OpenCDA 的 OPV2V LiDAR 序列（训练 6,374、测试 2,170 帧），指标为 BEV 检测 AP50/AP70、分割 mIoU 与含冷启动开销的 Mbps。每链路 1,024 字节更新预算时，MirrorComm 为 0.159 Mbps、AP50 96.84%、AP70 92.15%，对比 CoST 10.497 Mbps、95.78%/92.24%，约 66 倍带宽差；mIoU 75.51% 对比 CoST 74.62%。消融在同预算下加预测器使 RVQ 版本 mIoU 72.43→75.51；随机 2–5 帧更新间隔时 AP70 83.54%，高于逐帧方法 CoMamba 的 78.01%。

## Value
对分布式 3D 场景表征有可借鉴的**共同预测+局部纠错**思路，尤其可用于多视角/多机器人系统中传递潜状态增量。论文主要优化通信和感知精度，未验证可供规划的动力学或长时世界仿真；可选读其系统管线。

## Strengths
通信成本包含位置元数据与冷启动；同时评估检测、分割和间歇通信；RVQ 与预测器分别消融，闭环训练考虑历史误差累积。

## Weaknesses
仅在模拟车联网数据集验证，未报告复杂网络时延、丢包或端点模型失同步后的恢复；世界模型只预测短期 BEV 特征，缺少物理状态/行动条件建模。66 倍说法对应特定基线与精度点，不能视为对所有压缩方法的普适优势。

## Future Work
论文未提出明确后续研究计划；可延伸检验真实车路场景、通信失同步和更长时间的预测漂移。

## Rating
创新度评分：3/5 - 镜像预测与残差量化的整合有实用新意，组件本身较常规。
相关度评分：2/3 (Related) - 使用 3D LiDAR 的 BEV 时序潜特征预测，但目标是协同感知通信而非世界仿真/规划。

## TL;DR
在通信两端同步预测 BEV 并只传高误差区域，显著节省协同感知带宽；对分布式世界表征可选读。
