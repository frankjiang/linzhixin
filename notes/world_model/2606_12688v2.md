# M*: A Modular, Extensible, Serving System for Multimodal Models

## Insight
核心 insight 是系统层抽象：未来多模态/世界模型由 vision encoder、LLM、diffusion/flow head、audio/action/world-model predictor 等异构组件组成，服务框架应表示为 dataflow Walk Graph，而不是假设固定 LLM 结构。

## Motivation
vLLM 等 serving 系统主要围绕窄模型结构，难以支持 BAGEL、Qwen3-Omni、V-JEPA2-AC 等复合执行路径。问题是模型服务而非 world model 方法。

## Method
M* 用 Walk Graph 描述模型组件与请求遍历路径，把模型架构与 runtime 解耦。支持 modality-aware scheduling、组件放置、CFG/KV cache 管理、跨组件执行和分布式 runtime。模型作者定义 state machine 选择下一段 Walk。

## Experiment
BAGEL 文生图/图生图、Qwen3-Omni TTS、V-JEPA 2-AC robotic planning rollout。报告 BAGEL 端到端 latency 平均比 vLLM-Omni 低约 20%，TTS real-time factor 低至 2.9x、吞吐高 2.7x，V-JEPA2-AC rollout baseline 最高 12.5x。限制是未覆盖所有模型/硬件，部分 baseline 有正确性/性能问题未完整纳入。

## Value
对部署大型 world model 有工程价值，但不是视频/3D/隐式 world model 研究本身。若关注 serving 可选读，否则跳过。
