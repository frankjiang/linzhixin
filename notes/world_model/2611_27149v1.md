# Where Structure Enters a World Model: From Predictive Fit to Physical Rollout

## Insight
观察：一步预测好、辅助物理量可读，并不保证自主长程物理轨迹正确。推论：物理结构进入模型的**位置**很关键——直接决定状态转移，与仅作为训练监督，效果不同。视觉实验中匹配的 V-JEPA 潜状态预测完全相同，Physics-JEPA 靠监督机械头推进状态而改善轨迹；行星实验中角动量监督虽不用辅助头推理，仍将 NTP 位置 MSE 从 1.0755 降到 0.1437 AU²，表明监督也能改进生成器。这是两套独立任务内的对照，不可跨模型直接归因。

## Motivation
世界模型用于规划时必须从有限观测独立滚动，误差可能令摆停振、行星偏轨。已有物理归纳偏置常混合额外监督、容量和推理规则，难辨改善发生在表征还是转移。作者以受控模型与任务比较“结构在哪里起作用”。

## Method
两条互不相同的实验线：视觉线从两帧 64×64 图像训练 V-JEPA 特征预测及带位置/速度标签的解码；Physics-JEPA 额外学习势能与阻尼，按给定动能形式求加速度，再用 RK4 从初始解码状态滚动。行星线把坐标离散成 token 作自回归 NTP；比较力/能量/角动量辅助监督、星体相对坐标、对旋转反射等变的成对几何位移适配器，以及同一物体跨帧表示差 TDV。辅助读出仅在训练使用，成对适配器参与 token 预测。多数机械形式和真实状态标签已先验给定。

## Experiment
视觉：四种模拟机械系统，25 个初值、400 步；简单摆角 RMSE 0.8814→0.2212 rad，阻尼摆 1.1261→0.0446，弹簧 3.1486→0.6905（后两种原始对照部分仅一随机种子）。附录五种子同标签/RK4/初态匹配对照中，简单摆能量头相对自由加速度头角 RMSE 0.2147 对 0.2477；阻尼和弹簧主要改善能量一致性，轨迹差距不总明显。行星：16 个系统、32 帧输入/128 帧自主预测；角动量监督 MSE 1.0755→0.1437 AU²，相对坐标 0.2034，成对几何 0.0630；TDV 在相对模型降至 0.1395，却使成对模型升至 0.1439。稀疏力适配中相对+TDV 的平均方向余弦 0.544，对 plain NTP 0.337；偏心率/恒星质量变化测试保留部分优势。

## Value
很适合校准世界模型研究中的证据标准：区分预测表征、物理读出和实际执行的转移，并同时报告轨迹误差与守恒指标。对 JEPA 或具身物理模拟的实验设计有参考价值，尤其要警惕“可解码物理量”被误写成“物理上可靠的滚动”。

## Strengths
清楚标出监督、梯度与推理路径；有同信息/同容量对照、长期自主预测和参数偏移测试；承认 TDV 效应依赖表示，守恒改进未必伴随预测改进。

## Weaknesses
视觉系统简化为低维模拟，且用显式数值状态及加速度标签训练；视觉机械头依赖已知动能形式和 RK4，不能证明 JEPA 自行发现动力学。两条任务线架构和输入不同；多体、遮挡、真实视频与跨物体参数识别尚不足。原始部分结果种子少，附录补充后仍有不稳定条件。

## Future Work
作者提出研究物体数量变化、初始两帧下不可辨的物理参数、力幅值缩放及积分误差，并以匹配学习曲线检验数据/训练效率。

## Rating
创新度评分：3/5 - 贡献主要是细致的结构位置与对照分析，机械头、守恒监督、几何等变等单项技术并非新范式。
相关度评分：3/3 (Core) - 直接讨论 JEPA 式视觉世界模型及其长程物理滚动，并给出隐式模型评测方法。

## TL;DR
对照显示物理监督与显式机械转移改善长程预测的机制不同，可指导 JEPA 世界模型评测，值得精读。
