# Robust Dreamer: Deviation-Aware Latent Gaussian Memory for Action-Controlled AR Video Generation

## Insight
3D感知的自回归视频世界模型面临两个关键障碍：(1) **Latent-RGB Cycling**——生成latent反复解码为RGB再编码回latent，VAE量化误差逐步累积导致信号退化；(2) **Error-free hypothesis**——训练时使用干净的ground-truth历史记忆，推理时记忆却由模型自身预测填充，存在训练-推理分布偏移。核心方案：设计Latent Gaussian Memory在潜在空间直接进行3D记忆的读写（跳过RGB转换），同时通过Deviation Learning主动注入合成的误差模式训练模型的纠错能力。

## Motivation
- 问题：帧级动作控制的交互式视频生成中，如何在长程自回归展开下保持视觉保真度和3D一致性？
- 同行方法：WorldMem/WorldWarp等3D记忆方法存储RGB并重新编码，积累latent-RGB cycling误差；Self-Forcing等解决exposure bias但不涉及3D记忆
- 关键：需要同时解决记忆存储方式（避免VAE cycling）和记忆使用方式（适应推理时的不完美记忆）

## Method
- **Latent Gaussian Memory (LGM)**：
  - 将生成的diffusion latent直接锚定到Gaussian primitives上（位置/不透明度/旋转/缩放/latent特征）
  - 记忆写入：CUT3R风格的前馈重建backbone预测每像素3D位置和Gaussian参数
  - 记忆回忆：通过latent空间Gaussian Splatting渲染目标视角的view-aligned latent条件
  - 避免反复通过VAE编解码，保持高维latent的精细信息
- **Deviation Learning with Dynamic Deviation Archive**：
  - 动态偏差档案：按自回归阶段和去噪时间步索引存储合成的latent偏差
  - 单步偏差合成：对噪声latent做单步flow-matching预测，与GT对比得到偏差D_i
  - 训练时概率性注入偏差到历史记忆中，暴露模型于真实的推理时腐蚀状态
  - 多样性保留替换策略：替换最相似的偏差条目
  - 仅训练时使用，推理时误差自然累积

## Experiment
- ScanNet(短/长程)：PSNR 16.89/13.43, FID 16.82/38.42，全面SOTA
- DL3DV：PSNR 15.42, FID 22.15，跨域泛化优
- OmniWorldGame：动态场景PSNR 17.43, FID 21.92，处理运动物体能力强
- 消融：Latent vs RGB记忆(RGB记忆PSNR降1)、有无Deviation Learning(无则FID从16.82→48.20)、合成偏差vs高斯噪声(高斯噪声FID 47.50)
- 对比：显著优于MotionCtrl、CameraCtrl、Self-Forcing、WorldMem、WorldWarp、VMem

## Value
工作价值很高——同时解决了3D视频世界模型的两个核心痛点（latent-RGB cycling和train-test gap），两个方案设计互补且各自有独立贡献。Latent Gaussian Memory是将3D Gaussian Splatting引入潜在空间的创新尝试，Deviation Learning的偏差档案机制巧妙模拟了推理时的真实误差模式。对长程交互式视频世界模型有直接推动作用。
