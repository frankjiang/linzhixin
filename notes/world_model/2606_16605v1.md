# ARB4WM: An Adversarial Robustness Benchmark for World Models in Continuous Control

## Insight
核心观察：攻击 world-model agent 不应只扰乱动作输出，latent dynamics、value、policy 三类组件都可能成为脆弱点；时序暴露位置（早期、稀疏、半序列、全序列）会显著影响闭环性能。

## Motivation
Dreamer-style agent 已用于机器人/控制，但鲁棒性评测分散，缺少跨 policy/value/latent dynamics 的统一 adversarial benchmark。安全评测是关键问题，尤其对隐式 latent world model 有直接借鉴价值。

## Method
ARB4WM 定义五类 white-box loss objective，覆盖 policy、value、latent representation/RSSM dynamics；结合 single-step / multi-step perturbation 和 full-frame、half-sequence、sparse-frame temporal attack。评估四个 Dreamer-style agent，在 MetaWorld 与 DeepMind Control Suite 共 20 个任务上施加视觉扰动。还比较输入级防御在 adaptive attacks 下的恢复能力。

## Experiment
主要指标是攻击后任务回报/成功率下降、不同 loss objective 与 temporal exposure 的破坏程度。结果显示 value、latent representation、RSSM dynamics 攻击可与直接 policy 攻击同样严重；早期或高频扰动伤害最大；简单输入防御恢复有限。

## Value
价值在 benchmark 和诊断框架，技术创新不是新 world model，但对 Dreamer/latent agent 的可靠性评估很有用。启发是未来评测要把 latent dynamics 和 value consistency 纳入攻击面。
