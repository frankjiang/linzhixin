# Scalable Edge-assisted Fusion and Path Prediction for Connected Autonomous Vehicles

## Insight
**感知信息的边际收益必须连同时效性评价。** 路侧单元已覆盖多数区域，重复融合车辆既增加计算，又可能使整份共享状态过期。作者测得全量融合在17至19辆贡献车之间越过300ms的p95信息龄阈值；据此优先选择补足路侧盲区的车辆，并按风险刷新预测。消融显示主要收益来自减少融合输入，联合预测调度的额外延迟收益较小。

## Motivation
车端逐车协同感知重复计算；边缘统一处理虽能共享结果，但融合、跟踪、预测和网络传输共同决定规划器收到的信息是否过时。本文优化这一系统瓶颈。其“world model”明确指带时间戳的3D轨迹、运动状态和多模态路径预测，作者明确说明它不是学习式模拟器或生成模型（§III）。

## Method
1. 车辆用PointPillars提取BEV特征与空间置信图，发送约17KB压缩输入；边缘以RSU为共同坐标锚点执行Where2Comm式融合、3D检测、批量Kalman/AB3DMOT跟踪及MTR预测。
2. 按 `Σ 车辆置信度 × (1−RSU置信度)` 选择能补足盲区的贡献车。利用GPU实测分阶段成本，在0/2/4/8/12辆候选档位中分配融合与预测预算。
3. 缓存预测若位置/朝向偏离观测或过期则刷新；剩余预算按速度、距离、遮挡及预计接近程度的启发式风险分配MTR，其他轨迹复用缓存或线性外推。
4. 每周期向整个区域组播约13KB共享场景状态。规划器20Hz，协同融合10Hz；内部计算目标130ms，为端到端300ms信息龄留余量。

贡献是现有感知/预测模型的集中部署与运行时调度，无新世界模型学习目标。

## Experiment
- **设置：** A10 GPU、Multi-V2X离线回放与网络时延组合评估，另在CARLA/eCAV进行闭环测试；最多31辆CAV。比较全量融合、随机、Oracle、遮挡选择、仅筛选、仅预测调度及联合控制。
- **时效：** N=24时联合方法p95 AoI约234ms；密度扫描中报告100%样本合规。Locale A的边缘p95由全量242ms降至联合150ms；仅遮挡选择已达152ms，新增预测调度只节省约2ms（表III）。
- **检测：** 高遮挡Locale B选4辆时，遮挡召回率为0.354，随机0.283、Oracle 0.365，弥合约87%的差距；跨区域有提升空间样本的中位差距弥合率仅32%，两个区域弱于随机（§VI-H）。
- **预测：** 报告ADE/FDE；缓存和新MTR的5秒FDE为4.66/4.64米，但作用于不同轨迹子集。83%的预测对象静止，线性回退不足1%；MTR按6条候选中最接近真值者评分（表IV）。
- **闭环：** 左转、交叉、盲区超车三种遮挡高负载场景中，联合方案各9/10成功，全量融合各1/10，晚期融合3–4/10；成功同时要求无碰撞、无误刹和保持进度。图7–8关联了信息过期与失败，不能视为普遍安全保证。

## Value
对世界模型部署的间接启发是：应按信息增益和结果到达时效分配观测及预测算力，离线精度更高未必改善闭环。本文更适合作为协同感知/边缘调度资料，不宜归入生成式3D世界模型主线。

## Strengths
- 统计覆盖规划器消费时刻的信息龄，连接组件耗时与实际驾驶结果。
- 提供多组件消融、选择器上界、跨区域评估及额外冲突几何。
- 清楚声明共享场景记录的含义及感知误检、硬件和网络限制。

## Weaknesses
- 主要优势由削减融合车数解释；仅筛选也能达到相同AoI合规，不能将全部收益归于联合预测机制。
- 大部分是离线组合评估，闭环每单元仅10个种子；300ms是指定速度/几何下的经验阈值，非一般驾驶安全界。
- 组播以固定9ms解析模型为基础，虽有20/40ms及丢包敏感性分析，仍未验证真实NR-MBS部署。正文对所有车辆持续上传与筛选后减少活跃上传数的叙述不一致，实际通信节省需澄清。
- 预测缓存比较非同轨迹配对、数据以静止对象为主；启发式风险没有校准。尚未解决多区域争抢算力、动态网络预算和感知召回上限。

## Future Work
作者在讨论中指出需要跨区域调度、依据网络尾延迟调整计算余量、在不同GPU上重新标定成本，以及针对更高速度收紧AoI预算；这些是部署扩展方向，未给出已验证方案。

## Rating
创新度评分：2/5 - 有明确系统优化价值，但主要组合已有融合、跟踪和预测模块，对目标世界模型方法创新有限。
相关度评分：1/3 (Tangential) - 研究车路协同场景记录与轨迹预测，只有时效和算力分配思路可间接借鉴。

## TL;DR
按盲区信息增益筛选车辆并调度路径预测，维持共享场景时效；属边缘协同感知，世界模型研究可跳过。
