# Medical world models in healthcare: foundations, applications, and challenges for trustworthy clinical translation

## Insight
有。论文的 observation 是：医疗 AI 仍多停留在 static prediction，而临床决策本质上是纵向、干预依赖和部分可观测的动态系统问题。推论是：medical world model 应至少区分 patient state representation、temporal dynamics、intervention-conditioned simulation、clinician-supervised planning 四层能力，并且功能层级不能等同于临床证据成熟度。作者通过结构化 narrative review 和 evidence mapping 支撑这一框架。

## Motivation
论文解决“medical world model”概念边界混乱的问题：该词被用于 EHR trajectory、影像未来生成、treatment simulation、ultrasound/surgical interaction、clinical digital twin 等多类系统。同行常把 foundation model、causal treatment modelling、digital twin 和 world model 分开综述，导致 action semantics、causal validity、clinical evidence requirements 没被统一讨论。问题在医疗 AI 中重要，但对用户关注的视频/3D/JEPA/Dreamer方向主要是概念迁移价值。

## Method
这是一篇 review，不提出新模型。作者做 structured narrative review with reproducible evidence mapping：检索 PubMed、arXiv、IEEE Xplore、ACM DL，日期覆盖 2018-01-01 到 2026-07-19/20；初始 3528 records，经 ACM prescreen、dedup、两阶段 machine-assisted screening 和作者核验，最终 narrative corpus 98 sources，其中 14 篇满足 strict empirical medical world model 定义。

论文提出 L1-L4 功能层级：L1 temporal/latent state prediction，无显式 action；L2 action-conditioned transition/generation；L3 比较 alternative actions 的 predicted outcomes；L4 基于 internal rollout 的 closed-loop planning/control。系统层面分 state representation、transition modelling、action representation、causal/mechanistic constraints、planning、embodied interaction。核心强调：action-conditioned prediction 不等于 causal counterfactual；必须定义 intervention、estimand、confounder、follow-up window 和 validation。

## Experiment
无传统实验，主要是证据映射和案例对比。代表模型包括 Cardiac Copilot、EHRWorld、EchoJEPA、Brain-WM、CLARITY、Xray2Xray、EchoWorld、MeWM、SAW、ChronoMedicalWorld。应用域分为六类：medical imaging/future-observation simulation、longitudinal EHR trajectory、disease progression/treatment response、physiological/multimodal state、ultrasound/surgical embodied interaction、population/health-system simulation。

作者总结当前证据：多数学术系统仍是 retrospective、task-specific 或 preclinical；真正 L3/L4 能力很少，临床 outcome validation 更少。主要障碍包括 longitudinal intervention data 不完整、action semantics 不一致、causal identifiability 弱、long-horizon error accumulation、uncertainty estimation 不足、external/prospective validation 缺乏。

## Value
对医疗方向有综述价值，对我们方向的直接技术价值有限。可借鉴的是：它很清楚地区分 representation、dynamics、action-conditioned rollout 和 planning，不把“生成未来”轻易等同于“能做决策”；这种 evidence maturity 与 functional capability 分离的框架，也适合评价视频/3D世界模型。

## Strengths
概念边界清晰；强调 action semantics 和 causal validity，避免把视觉真实感或预测准确率误读为治疗效果；把 Dreamer、JEPA、diffusion/video generation、digital twin 放在统一功能框架下；方法部分记录检索和筛选流程，比普通观点综述更可追踪。

## Weaknesses
不是系统综述，最终 corpus 加入了 69 篇 directed contextual sources，选择带有 narrative 主观性；严格实证子集只有 14 篇且超过一半是 preprint；与 CS 世界模型最新技术的连接偏概念化；没有提出新的算法或 benchmark；医疗治理、因果、临床验证内容占主导，对视频/3D/隐式 world model 研究帮助有限。

## Future Work
作者提出未来临床转化需要：更完整纵向数据、更清晰 action definitions、外部和前瞻验证、calibrated uncertainty、临床 meaningful endpoints、accountability/governance、explicit stop/abstention/human handover。

## Rating
创新度评分：2/5 - 概念框架和证据映射有用，但技术创新有限。
相关度评分：2/3 (Related) - 借用 Dreamer/JEPA/latent rollout 等世界模型框架，但核心是医疗临床转化，不是视频/3D/隐式世界模型方法。

## TL;DR
医疗世界模型综述强调状态、动作、因果和临床证据边界，可借鉴评价框架，技术方向可选读。
