# AdaptiveLoad: Towards Efficient Video Diffusion Transformer Training

## Insight
关键观察：视频扩散 Transformer 训练中，传统"等 token 数"的 bucket 策略忽略了 self-attention 的二次复杂度 O(S^2)。实验发现训练延迟与总 token 数的相关性仅 R=0.35，但与 S^2 的相关性高达 R=0.92。长序列 bucket 成为"计算拖后腿者"，导致严重的 GPU 同步等待。

## Motivation
解决大规模视频 DiT/MMDiT 训练中异构序列长度导致的负载不均衡问题。现有方案基于线性 token 计数的 bucket 策略无法反映 attention 的二次计算特性，导致长序列 GPU 过载、短序列 GPU 空闲，同步开销巨大。

## Method
两个核心组件：
1. **双约束自适应负载均衡**: 同时限制内存（B*S <= M_mem）和计算（B*S^p <= M_comp），动态调整每个 bucket 的 batch size。通过 shape benchmarking 拟合经验复杂度指数 p，闭环监控 GPU 同步等待时间并实时调整。
2. **Fused LayerNorm-Modulate CUDA kernel**: 将 AdaLN 的 5-8 个离散算子融合为单一 kernel，采用 D-tile coalesced reduction 策略解决反向传播中 strided 内存访问问题，提升 HBM 带宽利用率。

## Experiment
基于 Wan 2.1 世界模型验证：
- 8-GPU 集群：吞吐量从 14,383 提升至 18,069 tokens/sec (+25.6%)
- 16-GPU 集群：吞吐量提升 27.2%，计算不均衡率从 39% 降至 18.9%
- Fused kernel：前向 3.2-3.4x 加速，反向最高 1.42x 加速，激活内存减少 61.9%
- 最大支持序列长度从 48k 扩展至 52.8k tokens
- 训练 loss 曲线与 baseline 高度一致，无精度损失

## Value
实用的工程优化工作，对视频世界模型的大规模训练有直接价值。双约束负载均衡思路简洁有效。但本质上是系统优化而非世界模型方法创新，对理解世界模型本身帮助有限。D-tile coalesced reduction 是针对 AdaLN 的有效 kernel 优化。

## Strengths
