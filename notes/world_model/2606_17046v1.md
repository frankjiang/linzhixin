# Geometric Action Model for Robot Policy Learning

## Insight
核心观察：机器人策略缺的不是语义，而是动作、相机、接触与物体在 3D 几何中的共同演化。作者把 pretrained geometric foundation model 从中间层切开，让浅层编码观测，在 split layer 插入 causal future predictor，再用深层传播预测 token，同时解码未来几何和动作。推论是：几何 backbone 不应只做特征蒸馏或最终特征读出，而应贯穿“感知-预测-动作”闭环。

## Motivation
VLA 依赖 VLM 语义，WAM/视频模型依赖 2D 时序先验，面对相机扰动、布局变化和接触任务时几何泛化不足。已有 geometry-aware policy 多是外接 GFM 特征或点云专用 encoder，不能把几何先验转成 temporal world modeling。问题对具身 world model 很关键。

## Method
GAM 将 GFM 浅层作为 observation encoder；在中间 token 空间接入语言、proprioception、action history，预测未来 latent tokens；再送入剩余 GFM blocks 做 feature propagation。训练包含动作回归、future feature/depth 等监督，推理一次 backbone forward 输出 action chunk 与未来几何。创新点在于共享几何 token 空间内同时做 future prediction 和 action decoding。

## Experiment
在 LIBERO 和更难的 LIBERO-Plus 上评估，标准 LIBERO 接近饱和，LIBERO-Plus 尤其 camera perturbation 提升明显（文中强调约 +9.7%p）。真实机器人实验中，在 out-of-distribution 视角/扰动下优于 Cosmos Policy 等大模型基线，并且参数更少、推理更快（报告 55x faster）。消融显示 pretraining 对鲁棒性关键，future depth/feature loss 在无预训练时尤其有帮助。

## Value
价值较高：明确把 3D 几何 foundation model 改造成动作条件 latent world model，而非只做 perception feature。启发是机器人 WAM 可以把“预测什么”从像素转成几何 token。局限是仍围绕 manipulation benchmark，长期多物体物理、遮挡和跨 embodiment 泛化还未充分证明。

## Strengths
亮点是价值较高：明确把 3D 几何 foundation model 改造成动作条件 latent world model，而非只做 perception feature。

## Weaknesses
不足是仍围绕 manipulation benchmark，长期多物体物理、遮挡和跨 embodiment 泛化还未充分证明。

## Future Work
作者未明确提出具体未来工作；从局限看，后续需要围绕“仍围绕 manipulation benchmark，长期多物体物理、遮挡和跨 embodiment 泛化还未充分证明”补充更大规模验证、跨场景扩展或方法改进。
