# Reasoning as Pattern Matching: Shared Mechanisms in Human and LLM Everyday Reasoning

## Insight
论文的 insight 是：日常因果推理中，人和 LLM 都会被表面内容显著影响，这种错误模式更像 pattern matching，而不是稳定抽象 world model。证明路径是行为实验 + LLM attention head 干预：导致模型输出的头对非关键内容高度敏感，并能预测人类错误。

## Motivation
讨论 LLM 是否“有 world model”的认知科学问题。同行常把 LLM 小扰动失败解释为缺乏人类式抽象模型，但作者反过来问：人类在同类任务上是否也有这些失败？这对 AI 认知辩论有意义，但不属于视频/3D/隐式世界模型技术路线。

## Method
构造日常场景因果/空间推理任务，分 target framing 和 context framing，覆盖地理方向、前后左右、状态变化、动作后果等类别。评估 142 名人类和 25 个 LLM；对 gemma-3-27b 做 attention head ablation，找出对答案 logit 最关键的 heads，再用这些 heads 的 activation entropy 预测人类准确率。另做最小内容替换实验，只改无关名词，检验是否改变人类表现。

## Experiment
人类整体准确率约 0.71，Deepseek-R1/GPT-5.2 准确率更高但不最像人；gemma-3-27b 与人类类别级表现相关 r=0.84。12 个模型能解释显著人类 item-level variance。关键 attention heads 在控制类别、prompt 格式、trigram frequency、GPT-2/BERT surprisal 后仍提升人类准确率预测。第三组 175 人的最小替换实验中，无关词改变导致明显准确率差异，head activation 继续解释额外方差。

## Value
对“world model”概念边界有参考价值：不要把语言推理里的 world model 讨论与可 rollout、可 action-conditioned 的世界模型混为一谈。对用户方向几乎没有技术借鉴；可跳过，除非关心认知层面对 world model 术语的争论。
