# Explainably Safe Reinforcement Learning

## Insight
无特别深刻的insight。核心想法比较直接：shield本身是大型查找表难以解释，可以用决策树层次化地分解——先分类状态风险等级，再解释动作安全性，最后展示不安全动作的执行后果。

## Motivation
问题：Shielded RL虽然提供安全保障，但shield的决策过程（大型查找表/非确定性策略）对人类不可解释，影响信任。现有方法要么关注解释策略为什么最优（reward角度），要么直接将整个shield转为决策树导致树过大。本文提出层次化决策树分解来解释shield的安全决策。这是safe RL领域的一个实际问题，但并非核心难题。

## Method
三层决策树架构：
- **Level 1 (TL1)**：将状态分为safe/critical/dangerous/unsafe四类，使用基于MDP value iteration计算的风险函数来标注训练数据，用标准DT学习算法拟合
- **Level 2 (TL2)**：对critical/dangerous状态，解释哪些动作安全/不安全，为每个L1叶节点构建局部DT
- **Level 3 (TL3/Execution Tree)**：对不安全动作，展示执行后果（最可能到达unsafe状态的traces），用k-shortest-path算法计算

输入：MDP M + CTL安全规约 phi，输出：shield + 层次化解释。需要一个abstract world model (MDP) 进行model checking。

创新程度：较低。决策树用于解释策略不是新想法，层次化分解是合理但简单的工程改进。

## Experiment
- **环境**：Frozen Lake（网格世界）、Highway Cruise Control（自动驾驶换道）、Boeing Taxinet（飞机滑行）
- **指标**：主要比较shield大小 vs 决策树大小（压缩比）
- **结果**：决策树比shield查找表小几个数量级（如HW3-c: shield 232,216 -> TL1仅57节点）；计算时间从0.1s到50s不等
- 无与其他可解释RL方法的对比实验；无用户研究验证解释的实际可理解性

## Value
工作价值有限。对safe RL的可解释性做了合理的工程贡献，但与视频/3D/隐式世界模型研究方向无关。这里的"world model"仅指形式化验证用的MDP抽象模型，不涉及学习世界模型。对我们的研究方向无直接启发。
