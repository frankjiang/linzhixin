# ForeAct: Geometry-Guided Action Learning from World Representations

## Insight
观测：视频生成模型的表示可用于动作预测，完整未来视频和多步去噪并非动作生成的必要条件；但纯视觉特征缺少明确的未来几何约束。推论：单次读取干净观测潜变量，并让预测下一帧深度的 token 与动作特征双向交互，可提升控制且省去推理时的深度模块。LIBERO 消融从 clean action-only 94.3% 升至 96.6%，单向注意力仅 94.9%；证据限于策略成功率，并未证明学到可靠的可滚动世界动力学。

## Motivation
视频式 world-action 模型推理需反复去噪，几何式策略则常加独立几何骨干且侧重当前空间结构。如何低延迟利用预训练视频模型的时空先验与未来几何监督，对机器人控制有实际意义。

## Method
冻结 Cosmos-Predict2 的 VAE/T5，把当前 RGB 的干净潜变量和语言送进视频 DiT，在固定扩散端点只前向一次；输出视觉 token 输入动作 DiT 做流匹配动作块。插入 8 个可学习几何 token，与视觉 token 双向自注意力交互；训练时用 MoGe-3 离线估计的下一帧相对深度，施加潜变量、像素和梯度损失（几何总权重 0.01）。部署时删掉几何读出，不输入深度。主要创新是视频骨干的单步表示利用与轻量未来几何辅助监督。

## Experiment
LIBERO 四套平均成功 96.6%，低于 Fast-WAM 97.6% 和 Cosmos Policy 98.5%，但高于不使用几何监督的同构版本 94.3%。SimplerEnv-Bridge 平均 63.5%，仅比 GR00T N1.5 的 61.9% 高 1.6 点，Stack Blocks 仅 12.5%。六项真机任务各 15 次，67/90 成功（74.4%），Fast-WAM 58/90；LIBERO 上 H20 单样本动作推理 168 ms、约 2.1B 参数。消融支持双向 token 和 t+1 深度优于当前帧或更远期深度。

## Value
对将预训练视频世界模型转为低延迟机器人策略有较大参考价值，尤其是“训练期预测几何、部署期只用表示”的设计；若团队关心世界模型到动作的迁移，值得精读。

## Strengths
单步推理节省视频合成；同时评估仿真、真机、时延和组件消融；不需部署深度传感器或额外几何骨干。

## Weaknesses
实际输出是动作策略，推理时不做未来状态 rollout；因此不能据此评价世界模型的多步预测或反事实准确性。深度目标来自 MoGe-3 伪标注，论文仅展示图像，缺未来深度定量精度与误差传播分析。实机每任务仅 15 次；LIBERO 总分仍低于主要视频式竞争者，SimplerEnv 的优势很小且堆叠任务表现差。

## Future Work
作者未明确给出具体后续实验；需要检验更长时距几何、伪深度质量、多步预测及跨机器人的闭环泛化。

## Rating
创新度评分：3/5 - 几何 token 与单步视频表示结合有效，但延续已有 world-action 表征复用方向。
相关度评分：2/3 (Related) - 直接借鉴视频世界模型表征做机器人动作，核心任务仍是策略学习而非世界模拟。

## TL;DR
用视频模型单步特征与下一帧深度辅助监督学动作，推理无需生成视频；研究模型到控制迁移值得精读。
