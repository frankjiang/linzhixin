# Looped World Models

## Insight
论文的 insight 是把物理/环境动态看作共享转移规律的反复应用，因此世界模型不一定要靠更深、更大的固定层数模型，而可以用参数共享的 looped transformer 在 latent 中迭代 refinement。理论部分借用谱约束/contractive residual dynamics，声称可保证 recurrent latent updates bounded。

## Motivation
目标是缓解长时域世界模型的计算深度、参数量和误差累积矛盾。同行如 Dreamer、IRIS、DIAMOND、EMERALD、视频世界模型等要么固定深度，要么长 rollout 成本高。问题本身重要，尤其对应 Dreamer/latent world model 方向；但本文实验落点与视频/3D world model 有明显距离。

## Method
LoopWM 用一个参数共享 transformer block 反复更新 latent environment state，配合 state-retention 矩阵的负对角参数化和 zero-order hold 离散化，让线性部分保持收缩。还引入 adaptive computation/early exit，让简单 transition 少循环、复杂 transition 多循环。文中强调 deferred decoding：在 latent rollout 中延后解码，避免中间 token 过早落入表面输出空间。

方法概念有吸引力，但论文实现细节和实验披露不够充分，很多“首个”“100x parameter efficiency”缺少与视觉/控制世界模型的直接严谨对照。

## Experiment
主要实验是 ScienceWorld 和 ALFWorld 的文本式 world modelling：连续给 5 个 action，预测最终状态，用 EM、Token F1、BLEU-4、Entity 分数评价。ScienceWorld 上 Overall EM 68.4%、F1 85.3%，高于若干 LLM baseline；ALFWorld 上 EM 51.6%、F1 80.4，与 Gemini/Claude 等相比各有优劣。消融重点是 deferred decoding 在多步 rollout 上的增益。

缺口：没有真正的视频、3D、机器人连续控制或像素状态实验；与“物理世界模型”的宣称相比，证据主要来自文本环境。

## Value
对用户的启发是“iterative latent depth”可以作为隐式世界模型的新 scaling axis，适合思考 Dreamer/JEPA 类 latent dynamics 的可变计算深度。但当前论文对视频/3D方向的直接参考价值有限，更像概念和架构提案。
