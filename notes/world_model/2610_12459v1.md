# WorldGuide: Goal-Directed Video World Model for Procedural Task Execution

## Insight

观察：开放式长流程视频中，一步生成失败会污染后续状态；只给规划器上一轮“想做什么”不足以判断“做成没有”。推论：动作选择、视频执行和完成判断应在生成结果上闭环。去掉逐步重规划后任务成功率从 33.33% 降至 11.71%；去掉规划器视觉反馈后降至 14.72%，为这一判断提供消融证据，而非形式证明。

## Motivation

折纸、烹饪等过程需要按先后关系执行原子步骤并在完成时停止。开放式视频生成固定提示词或完整动作序列；部分闭环方法用预训练视频生成器执行规划动作，规划正确仍可能生成失败。现有过程视频数据也缺少“步骤动作—视频片段—完成”配对监督，因此关键问题是规划与执行错位及反馈缺失。

## Method

给定初始图像和目标，ContextPlanner 从最近 3 个动作—生成片段对预测下一条自然语言原子动作或 DONE；Executor 据此从当前末帧及压缩视觉历史生成短片段，循环至 DONE 或 80 步上限。规划器以 Qwen2.5-VL-7B 监督微调；执行器为 HunyuanVideo-1.5 DiT，在同一批步骤示范上以动作嵌入和掩码流匹配微调，二者**先后训练，未联合优化**。借鉴 YUME/FramePack 的多尺度空间压缩：近帧细、远帧粗，最多 1366 个历史潜帧对应不超过 8 个全分辨率帧的名义 token 成本。新增 WorldGuide Bench，约 5.9 万条逐步标注视频、245 项任务、27 类过程。创新主要在同源步骤监督驱动的闭环管线与数据，而非新视频骨干。

## Experiment

WorldGuide Bench 留出 980 条、Video-CraftBench 294 条；用 Gemini 3.5 Flash 判视频任务成功、子目标、顺序、重复，用 GPT-5.2 另判文本计划，VBench 评画质，并有人工打分。WorldGuide Bench 成功率 33.33%，MiniMax-H3 为 29.90%（后者获完整参考动作序列）；Video-CraftBench 在仅给目标时为 47.69% 对 32.73%。无 Executor 历史记忆：27.56% 对 33.33%，在 Video-CraftBench 为 29.78% 对 47.69%；Oracle 动作规划升至 38.82%，表明执行仍是瓶颈。WorldGuide Bench 的 VBench 美学 49.36、整体一致性 31.13 较高；Video-CraftBench 成像质量 64.63，低于 MiniMax-H3 的 69.65。人工任务完成均分 2.750/5 对 MiniMax-H3 2.542/5。

## Value

对视频世界模型的启发是让下一次决策依赖**实际生成的视觉状态**，并同时测计划正确性、可见执行结果和停止时机。步骤级监督与目标达成度指标可借鉴；离真实可交互环境中的可靠纠错仍远。

## Strengths

自建动作—片段—终止配对数据；分离“仅动作历史”“无记忆”“Oracle 规划”等消融；对部分基线给参考动作仍能胜出，较有说服力；补充人评。

## Weaknesses

Task Success 主要依赖生成视频的 VLM 评审，无法等同真实操作成功。规划器与执行器顺序训练，失误片段可能无法逆转；记忆也会增加重复动作。较大训练资源开销（执行器 64 张 MI210、42 天）；测试任务仍与过程视频分布紧密，未证明环境交互泛化。

## Future Work

作者提出更丰富的状态有效性信号、对未完成步骤的显式恢复、规划与执行联合优化，以及在固定预算下选择性保留任务相关历史。

## Rating

创新度评分：3/5 - 闭环步骤监督和数据集组合有效，但规划器、视频骨干和压缩记忆主要来自已有技术。
相关度评分：3/3 (Core) - 直接研究目标驱动、长时程视频世界模型的闭环生成与评测。

## TL;DR

以同源步骤监督串起动作规划、视频执行和完成判断，显著提升过程任务成功率；对闭环视频世界模型与评测值得精读。
