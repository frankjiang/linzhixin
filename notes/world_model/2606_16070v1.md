# Mind-Studio: Executable World Models with Lookahead Evaluation for Partially Observable Games

## Insight
核心观察：部分可观测游戏的 world model 若要做 lookahead，不应只是 next-state 拟合，而应合成可执行的 object-centric transition program，显式编码隐藏变量和优先级规则。

## Motivation
LLM/符号世界模型常能解释局部转移，但不能独立运行完整机制；Atari 等部分可观测游戏同一可见状态可能对应不同隐藏条件。论文目标是把交互轨迹压缩成 pygame-style executable WM，用于 K-step branch evaluation。

## Method
Mind-Studio 从 OC-Atari objects（pixel/RAM）构建轨迹，用 entropy-based selector 选信息量高的 transition，压缩成静态接口和 action-conditioned deltas，再提示 LLM 生成 object-centric pygame transition program。skill file 编码布局、动作语义、domain conventions；生成程序用于 rollout 并与 Real-ALE 像素对齐检查。

## Experiment
在若干 Atari/部分可观测游戏上评估 branch-level fidelity，论文称在 Skiing 等上优于 prior learned lookahead sources。重点指标是 rollout 端点与真实环境的对象/像素一致。实验偏小，强依赖 LLM 代码合成质量。

## Value
与“world model as executable simulator”有关，但不是视频/3D/JEPA/Dreamer 主线。对符号/程序化 world model 有启发，可低优先选读。
