# World-Model Collapse as a Phase Transition

## Insight
论文把 LLM agent 的 world-model collapse 类比为相变：当状态规模和依赖密度越过临界区域，任务成功率会突然下降，而 world-state fidelity 的下降通常先于无效动作出现。

## Motivation
LLM agent 失败常被归因于 prompt 或工具调用错误，但作者认为更底层的问题是内部/外部 world state 维护能力在复杂度增加时突然崩溃。需要可控环境来分离状态基数、依赖密度、horizon 和可观测性影响。

## Method
作者构建确定性模拟器并保留 exact gold state，重点使用 StatefulPuzzle。控制参数包括 state cardinality (SC) 和 dependency density (DD)，order parameter 是任务成功率，precursor 是 world-state fidelity。agent loop 包括 Planner、Updater 和 Self-Diag 三次调用。

## Experiment
stress grid 覆盖 SC {5,10,20,40}、DD {1,2,4,6}、horizon T=40。结果出现清晰 boundary，fine scan 得到临界 SC 约 13.5/13.9；更强模型只是平移边界，不能消除崩溃。单轴消融显示 horizon、observation visibility 和 mutation 描述都会影响边界。

## Value
对我们有启发的是：world model failure 可能有复杂度阈值，而不是线性退化。但论文场景是语言 agent 的符号状态维护，和视频/3D 世界模型主线距离较远。

## Strengths
受控变量设计清楚；“fidelity 先崩、行动后崩”的诊断有价值；相变视角利于建立 stress test。

## Weaknesses
相变是有限网格的 operational 类比，不是严格物理相变；任务合成且 harness-specific；对连续世界模型无直接验证。

## Future Work
未来可把临界复杂度分析扩展到真实 agent 任务、多模态状态和不同记忆机制。

## Rating
创新度评分：3/5 - 用相变视角分析 agent 世界模型崩溃有新意。
相关度评分：1/3 (Tangential) - 主要是语言 agent 符号 world model，和目标方向间接。

## TL;DR
把语言 agent 世界模型崩溃刻画为相变，诊断有趣但方向间接，可略读。
