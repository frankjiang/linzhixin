# MoDDiT: Simple Token Routing in Diffusion Transformers

## Insight
观察：图像/视频潜 token 的去噪难度随区域、样本和噪声级变化，统一执行全部 DiT 注意力与 MLP 造成冗余。推论：注意力固定每样本 token 数以保持规则矩阵，MLP 则跨批次竞争并在单样本推理时使用学习阈值，可将算力集中于复杂区域。ImageNet 的质量/FLOPs 曲线和 1X 视频预测消融支持效率与质量收益；视频“运动区域多分配”只是相关性，不构成路由因果解释。

## Motivation
实时视频生成与交互式世界模型受多轮 DiT 去噪计算限制。已有 token 跳过、稀疏专家或路由工作常只改善训练或推理一侧，且稀疏注意力与逐样本弹性 MLP 有不同的并行约束。论文研究通用生成骨干提速，直接可借鉴于视频世界模型，但不提出世界状态/动力学机制。

## Method
- 在每个路由块用小 MLP 给 token 评分，训练时 Gumbel top-K 探索；被选 token 的注意力/MLP 输出经 sigmoid 门缩放后残差回填，未选 token 原样越过该块。注意力每样本固定 K 以维持张量形状，MLP 对整个批次做全局 top-BK，使不同样本与噪声步共享算力预算。
- 单样本推理为匹配训练时全局竞争，训练过程中跟踪路由分数阈值，并以该阈值决定 MLP 的可变 token 数；注意力和 MLP 独立路由。图像模型用更深但稀疏的 DiT 层控制 FLOPs；视频模型采用空间/时间分解注意力；Wan2.1 蒸馏实验则在后层逐渐增大稀疏度、保留部分密集块及完整 K/V。

## Experiment
- ImageNet 256²、各训 100 万步，512 次去噪：Dense DiT FID 5.069/165.38 TFLOPs；MoDDiT 50% 为 4.390/170.32，25% 为 4.795/129.89，12.5% 为 5.081/109.78。相同/更低计数 FLOPs 下质量竞争力较强；路由优于随机挑 token。
- 1X 机器人 POV 视频 400 个配对验证窗，12.5% 稀疏模型在 0.5/1/2 秒预测 PSNR 分别高 0.68/0.38/0.21 dB，三项配对区间均排除零；所计去噪 FLOPs 少 36.92%。但稀疏训练批量 256 对稠密 217，等更新步数并非等数据量。分配与相邻帧差正相关。
- 从 Wan2.1 蒸馏 81 帧自回归视频：Funnel20 相对密集 Self-Forcing 的 VBench 总分 82.07→77.69，Transformer FLOPs 950.39→722.53 TFLOPs（约降 24%）；加入共享文本编码/VAE 后整体计算仅降约 18.4%，多物体和空间关系指标损失较大。低批量实际延迟不一定下降，论文只在批量 32 的图像吞吐观察到小幅增益。

## Value
独立路由注意力/MLP 与训练阈值是可移植的生成骨干效率技巧；对高分辨率视频世界模型的算力分配值得可选读，实施前应实测墙钟延迟和空间关系质量。

## Strengths
同时报告训练与推理的计算预算；ImageNet 从头训练、动作条件视频预测和预训练模型蒸馏三种设置；视频 PSNR 给出配对置信区间；附录清楚披露 FLOPs 排除项和稀疏模型质量退化。

## Weaknesses
主要是生成架构改造，不建模动作后果或长期世界一致性；视频实验只有单训练种子且批量不同；路由选择、索引与数据搬运未计入 FLOPs，少量图像生成可能更慢；动态区域相关分析使用帧差而非光流，无因果证据；稀疏蒸馏的多物体及空间关系退化明显。

## Future Work
作者提出测试更多图像/视频数据与生成架构、优化稀疏 gather/scatter 内核、自动学习计算容量，并为注意力和 MLP 分别设置容量，而非共用一个比例。

## Rating
创新度评分：3/5 - 独立注意力/MLP 路由及单样本阈值机制有工程价值，但建立在已有稀疏 token 与 MoD 思路上，实际加速仍有限。
相关度评分：2/3 (Related) - 对视频世界模型骨干的生成效率有直接借鉴，但论文本身主要研究通用 DiT 计算路由。

## TL;DR
为DiT独立路由注意力和MLP token，在视频预测中省算力并增精度，但蒸馏画质退化；可选读。
