# PhyCheck: Fine-Grained Evidence-Grounded Dataset for Physical Law Understanding in Video-LLMs

## Insight

论文观察到 Video-LLM 对“物理合理”样本召回高、对违背物理样本召回极低，说明模型更像默认世界正常的模式分类器。细粒度证据题单独训练几乎无效（50.93→51.43），粗粒度结论题可到 66.83，而先学细节、再学整体判断达到 81.00；作者据此推断监督顺序应先建立可观察物理概念，再学习全局规律判定。不过所有训练和测试都源自同一 VideoPhy2 视频池，提升可能包含题式、生成器伪影和标签体系适配，尚不能证明学到了可迁移的物理机制。50 对 context pilot 也提示多数模型难以因隐藏原因改判，但样本极小且结果解释存在反常之处。

## Motivation

现有视频物理基准多评测生成视频是否合理，或只让 Video-LLM 做粗粒度常识/违规判断，难以训练和诊断“具体哪条物理证据导致结论”。对 embodied/world-model 系统而言，识别重力、惯性、守恒等异常有安全价值；但该问题属于视频理解与评测辅助，不直接学习未来动力学或生成世界状态。

## Method

PhyCheck 重用 VideoPhy2 的 6,399 个合成视频（8.61 小时，来自 7 个视频生成器）和已有物理规则/遵守/违背标签，去掉 undetermined。粗粒度 VQA 用一致性与违规两类模板平衡 Yes/No 极性，问现象是否符合指定定律。细粒度管线先让 Gemini-3 观察视频并提出应避免的具体异常，再让 GPT-5 转为可视觉回答的二值问题；两名人工独立核验，冲突由第三人多数裁决。最终报告 69,825 个问答、平均每视频 10.9 个，覆盖力学、守恒、材料、流体/界面、光学和热学六类。

另构建 50 对 context-sensitive pilot：从真实合理视频裁掉可见原因，使剩余片段看似违规，再用文字补回隐藏原因，测试模型能否从 video-only 的“异常”更新为 context-assisted 的“合理”。增强实验对 Qwen2.5-VL 全参数训练 12 epoch，并比较细→粗、粗→细的顺序监督。

## Experiment

作者评测 Qwen3 系列、Gemini-3.5-Flash、LLaVA-OneVision2、UniVid/UniVideo 和物理伪影检测模型 Skyra。现成模型总体准确率约 50.93–63.11%；多数模型 Conform recall 约 75.7–88.3%，Violate recall 仅 14.1–30.5%，显示强类别倾向。不同生成器来源的失败率相近；守恒定律和牛顿力学比惯性、反射、浮力更难。

训练消融中，fine-only 51.43、coarse-only 66.83、coarse→fine 51.89、fine→coarse 81.00；但没有同 epoch/样本步数控制说明、多 seed 或外部物理数据集迁移测试。context pilot 中，Qwen3.5-27B video-only 准确率 0.96 却难随上下文更新；微调模型 video-only 仅 0.18、context 后 0.98，作者解释为“epistemic caution”，但低 video-only 分也可能只是错误偏置。正文声称完整结果在 Appendix C3，PDF 中未见该附录或逐模型表。

## Value

可借鉴之处是把物理结论拆成可观察证据，并用 minimal/context pairs 检测视觉捷径；这类诊断可作为视频世界模型生成结果的外部 critic 或训练信号。当前数据更适合训练物理异常问答器，不能据其 VQA 准确率推断模型能预测行动后果、维持 3D 状态或进行 Dreamer/JEPA 式规划。最重要的后续是跨来源、跨题式和真实交互迁移。

## Strengths

- 正/反物理案例与问题极性都做了平衡设计，能暴露“默认合理”的预测偏置。
- 细粒度问题明确绑定可见异常，为错误分析和结构化监督提供比单标签更强的信息。
- 人工核验投入 556 小时，初始两人一致率 99.74%、Cohen's κ=0.9959。
- 同时报告总体与 Conform/Violate precision、recall、F1，并按物理类别和生成器拆解。
- context-sensitive 设计方向正确，试图用补充原因测试模型是否真正更新物理判断。

## Weaknesses

- 视频与粗标签都来自 VideoPhy2，所谓新数据集主要是再模板化和 LLM 扩注；训练/测试共享生成器、内容风格与规则体系，易学捷径。
- 细粒度候选由 Gemini-3、GPT-5 产生，再由人工判断存在性，并非物理专家从定律独立推导；极高一致率也可能反映问题过于表面。
- 没有给出 train/val/test 数量、视频级去重/划分方式、类别平衡和相同源视频的多问答泄漏防护细节。
- 81% 结果缺少多 seed、误差条、外部 benchmark 和真实视频验证，无法区分物理学习与域内格式适配。
- context subset 只有 50 对，正文缺少承诺的附录明细；0.18→0.98 的解释不充分，且没有 joint accuracy 表。
- 二值题直接给出物理定律名称，可能测试文本先验和伪影识别；不要求预测数值、反事实或未来轨迹。
- 文中“约 50k human-verified VQA”与总计 69,825 的口径没有清楚对齐。

## Future Work

作者仅把 context subset 定位为 pilot，隐含需要扩大规模并继续研究外部因果条件整合。更关键的未来工作包括严格视频级划分、真实/仿真物理 paired interventions、跨基准零样本迁移、开放式证据定位、数值/反事实预测，以及把理解分数与机器人或生成世界模型效用关联。

## Rating

创新度评分：2/5 - 细粒度证据链与 context pair 有一定数据设计价值，但主体建立在 VideoPhy2 复用、模板问答和 LLM 扩注上，域外证据与实验严谨性不足。

相关度评分：2/3 (Related) - 物理规律理解可用于诊断和训练视频世界模型，但论文核心是 Video-LLM 二值问答，不直接建模视频未来、3D 状态或 latent dynamics。

## TL;DR

把视频物理判断拆成证据问答并显著提升域内准确率，但迁移与因果性未证，可选读。
