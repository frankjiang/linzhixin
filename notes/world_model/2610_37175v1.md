# MLE-World: Predicting Machine Learning Experiment Outcomes with a Learned World Model

## Insight
观察：机器学习智能体反复运行候选程序，完整训练比一次模型预测贵；程序的代码、数据摘要和软件环境又能预示相当多的报错与验证结果。推论：把“执行结果”学成条件预测器，可用廉价的虚拟反馈筛选/修订程序，并按置信度决定何时真运行。作者用留出程序的输出匹配率、固定起点的候选实验和在线搜索验证，但主要结论局限于训练时已见任务。

## Motivation
MLE 智能体每一步运行候选代码以获得报错、日志和分数，消耗大量训练时间；既有剪枝/排序常不给可用于 Debug 的完整终端反馈。论文解决的是自动机器学习程序搜索的执行瓶颈，问题本身有价值，但其“world model”是语言化程序执行模拟器，与视频、3D 或 JEPA/Dreamer 世界模型没有实质方法交集。

## Method
- 基于 AIDE 的 Draft、Debug、Improve 搜索树，输入候选 Python 程序、可用库版本、数据文件/列概览与时间限制；全参数微调 Qwen3.5-4B，预测异常类别、终端日志、验证指标和是否生成提交文件。训练集为 17 个 MLE-bench Lite 任务上的 497,056 次去重程序执行，包含崩溃与超时。
- 首个输出 token 是 82 类异常标签，类别概率给出最高概率 `pmax`、正常运行概率 `pclean` 和不确定度 `1-pmax`。结构化字段使日志匹配率在小样本消融中由 59.4% 增至 62.8%。
- 每步预测四个候选，用 Best-of-N、顺序修订、两两判别、融合或带不确定度奖励的 UCB 选一个；低置信度才真执行，但新预测最优指标仍需实测，预测超时直接跳过。置信度门控按预测成功/失败设不同阈值。

## Experiment
- 17 项已见任务内、1,700 个近重复过滤后的留出程序：终端输出语义匹配 77.9%±1.0%，DeepSeek 提示基线为 41.1%±1.1%；异常类准确率 86.4%，验证指标相对误差 5% 内为 78.1%。训练需 8 张 H200 约 43 小时；推理 GPU 时间比提示基线少 13–1,061 倍。三项未见任务探索性测试中输出匹配 53.3%，但失败程序占主导。
- 17 任务×3 种子、每次 12 小时：AIDE 平均排行榜百分位 45.4，五种预测引导策略为 47.1–52.1，最高 UCB 52.1；成对任务 bootstrap 的增益约 6.7±2.5 点。门控减少 30–40% 真实执行时间，且平均性能大体维持；门控顺序修订达 55.4%。
- 固定任务状态消融：预测“可运行”筛选把有效提交率从随机候选的 26.1% 提至 41.9%；给 Fusion 预测终端输出，测试百分位由 14.0 提至 20.6。UCB 不确定度奖励的同设置消融从 38.58 升到 45.38。部分主表仅单次训练模型且策略间观察均值差未全部有稳健显著性。

## Value
可借鉴的是“仿真反馈加置信度门控真值验证”的一般思想；对本组关注的视觉/空间/隐式动力学建模基本无直接参考价值，应跳过。若研究代理式实验设计，才有选择性阅读价值。

## Strengths
同时预测故障、日志、指标与提交可用性，比只打分的筛选器更能支持修订；训练集含失败执行，做了去重、检索对照、固定状态诊断和随机门控对照；明确记录未见任务测试与统计不确定度。

## Weaknesses
主评测任务与训练任务相同，约 50 万历史执行带来较高数据门槛，未检验与同样可检索历史的 AIDE 公平对照；跨任务、跨软件环境与成功训练结果的泛化仍弱证据。终端日志用语言模型判分，含判别器偏差可能；超时预测最差。所谓 UCB 奖励只是异常类不确定度代理，并非目标性能的置信上界；部分搜索收益受任务选择与无效提交影响。

## Future Work
作者建议增加推理或扩大模型以增强未见任务泛化，改进超时与运行时预测；更广泛、预先选定的跨任务及训练族消融可检验迁移机制。

## Rating
创新度评分：2/5 - 在程序搜索中整合结果预测、结构化异常概率和门控，工程实证充分，但技术多为既有组件组合。
相关度评分：0/3 (Noise) - 模拟的是 ML 程序执行反馈，不涉及视觉、3D 或隐式环境动力学。

## TL;DR
用语言模型预测机器学习程序的运行日志与分数，按置信度减少真实执行；虽能改进搜索，但与目标世界模型方向无关，可跳过。
