# Causal Retention in Interactive Agents: Interface Factorization and Selective Adaptation

## Insight
任务成功或一步预测好，不代表冻结的内部状态还保有“哪个动作在何情境下、何时、把哪个直接目标改成什么”的干预机制。有限 SCM 中，若学习接口把探针答案不同的两个世界并为同一等价类，任何后处理解码器都有不可消除的 Bayes 探针误差；论文给出充要条件和证明。TD-MPC2 迁移时冻结模型对翻转执行器的效应符号仅 0.057，也支持源域预测与机制保留的区别。

## Motivation
常见世界模型、RL 和语言代理按回报、转移精度或动作排序训练，评估也常停留于这些指标；在局部机制变化后，它们可能不知道要改哪条记忆而破坏稳定机制。论文聚焦可查询、可局部更新的因果机制，是隐式世界模型迁移评测的相关问题。

## Method
评价者事先固定动作、情境、直接目标、结果值和延迟五元探针，学习后冻结状态再提问。理论把接口等价类与探针答案等价类比较，给出 Bayes 风险、预算内复测覆盖和准确更新的唯一支撑集。Causal Core 用干预对照才写入机制记忆：过滤同步读出变量、给延迟效应分配时序信用、主动设置隐藏情境；迁移时按惊讶度定位变化条目，只复测和编辑选中的机制。

## Experiment
有限 SCM、连续模拟器、官方 TD-MPC2 检查点及 Qwen2.5-7B。合成实验中潜世界模型一步 bit 准确率 0.905，但目标边 F1 仅 0.24；Causal Core F1 0.79 且无读出/隐藏情境误写。TD-MPC2 在 3 个控制任务共 9 次运行中，执行器符号翻转后冻结探针准确率 0.057；每执行器仅 5 个目标状态的选择性更新升至 0.948，稳定响应 NRMSE 保持 0.673，而全局更新升至 1.460。Qwen 末层线性探针源机制平衡准确率 0.958，变化延迟仅 0.583；证据门控后变化延迟为 1.000，读出误接纳率 0.056。

## Value
为潜世界模型增加一个值得借鉴的评测维度：冻结状态的动作机制可解码性，以及局部变化后能否只改该变的机制。理论与诊断可参考；若研究重点为视觉生成，可选读。

## Strengths
清晰区分行为充分性与探针机制充分性；有解码器无关的有限类结论，并用非线性探针、公开 TD-MPC2 及真实语言模型检验，迁移实验同时测更新与稳定保持。

## Weaknesses
精确充要结论依赖有限 SCM 类、固定探针语义和接口分布；构造的五元机制与干预对照需较强可观测性/可控制性。Causal Core 偏显式表格式机制，未在高维视频或 3D 潜状态上证明可扩展；一些实证是特制机制转移。

## Future Work
作者未列出明确路线；从适用范围看，还需研究在未知机制类、大规模视觉状态和有限真实交互预算下的探针与选择性更新。

## Rating
创新度评分：3/5 - 因果保留的接口判据和局部编辑形式化有新意，但实验域与显式机制假设限制了对视频世界模型的直接应用。
相关度评分：2/3 (Related) - 直接触及隐式世界模型的因果表征与迁移诊断，但非视频或 3D 建模方法。

## TL;DR
提出冻结状态的因果机制保留判据与选择性更新，用 TD-MPC2 展示预测好仍会丢失机制；视觉模型研究者可选读。
