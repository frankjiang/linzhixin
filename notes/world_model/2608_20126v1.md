# RMWorld: Task-Aware Radio World Models with Value-of-Information Guided Multi-Trial Learning for Multi-UAV Communication Control

## Insight
观察到全局 radio-map 误差不等于决策风险：同等 RMSE 的模型可能在用户关联边界产生完全不同后果。由此把高保真链路查询定义为“单标签对任务加权后验速率方差的精确减少”，并把反事实 policy trial 选择定义为可信度门控的 log-det 多样性。在线性高斯残差与局部速率线性化下证明风险等价，policy 选择则证明单调次模与贪心 1−1/e 保证。

## Motivation
多无人机通信控制既要用少量昂贵链路标签校准 radio world model，也要避免带偏差的反事实 rollout 污染策略；现有不确定性、覆盖率或乐观回报准则没有统一以任务风险分配两类证据。问题严谨但属于无线通信域。

## Method
用物理传播公式加 Bayesian residual ensemble 建模速率；按任务占用、速率敏感度与后验协方差计算 VoI，逐次更新后选查询。策略端生成多个反事实分支，以 ensemble 可信度和梯度方向 log-det 选互补 trial，再做冲突投影和固定 batch line search，限制辅助更新伤害 nominal objective。

## Experiment
100 个配对 3GPP 仿真中，RMWorld 的任务加权 RMSE 为 0.949 bit/s/Hz，对随机/空间 D-opt/ensemble variance/task variance/gradient D-opt 均有配对优势。30 个 severe-load DeepMIMO trial 中相对 Ensemble UCB 的 backlog 中位差为 −0.967，23/30 seeds 获胜，但多用 37.5% 离线 rollouts。神经特征试验仍是冻结随机 encoder；12 次更新的长时程压力测试无稳定优势，ASU 跨场景也不支持普遍迁移。

## Value
最可迁移的启发是用下游 decision geometry 定义世界模型数据采集与 rollout 信任，而不是追求全局预测精度。对视频/3D模型可类比为围绕候选动作后果和不确定性采样，但本文具体算法与无线链路结构高度绑定。

## Strengths
理论假设与结论边界写得克制；配对设计、CI、Holm 校正和 validity matrix 完整；主动报告无显著结果、跨场景失败和额外算力；区分 query efficiency 与 compute cost。

## Weaknesses
全部信道均为 3GPP/DeepMIMO 仿真，无实测、动态遮挡和大规模 fleet；线性高斯与局部线性化限制强；两层机制分开验证，未识别联合协同；神经世界模型并未端到端训练；对目标研究方向迁移需要大量重构。

## Future Work
作者计划测试实测信道、动态遮挡、更大无人机群和完整训练的 neural radio world model。

## Rating
创新度评分：3/5 - 任务风险一致的双层证据分配与严谨理论/审计有实质贡献，但依赖特定线性结构且计算昂贵。
相关度评分：1/3 (Tangential) - 是模型式控制和世界模型可信采样，但场景与表征均非视频、3D或JEPA/Dreamer。

## TL;DR
以任务风险而非全局误差校准无线世界模型，理论严谨但领域偏离，可选读。
