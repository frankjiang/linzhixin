# Security of World-Model-Based Embodied AI: A Lifecycle of Threats, Defenses, and Evaluation

## Insight
论文的核心观察是：世界模型不仅是被攻击的预测组件，也可能是合成数据源和 runtime safety checker；一旦内部状态、想象轨迹或风险估计被污染，模型会把危险动作呈现为安全，形成 predictive safety illusion。作者据此提出五类跨阶段失效：semantic-to-simulation-to-action gap、state/uncertainty-conditional risk、rollout-to-execution amplification、trajectory-level non-compositionality 和 predictive safety illusion。论证主要是跨 adversarial ML、VLA、视频生成、机器人和 safe RL 文献的概念映射，没有新的实证攻击。

## Motivation
现有安全综述常按感知、语言、规划或机器人模块分类，难以追踪一个攻击如何从数据/传感器一路传播到 imagined future、trajectory ranking、执行和反馈记忆。世界模型把预测变成决策信任边界：视觉上合理或单步安全都不能保证整条未来轨迹安全。为视频/具身世界模型建立专门的威胁对象、指标和日志协议是必要的，但本文更偏安全框架而非模型能力研究。

## Method
论文将生命周期划分为数据构建与预训练、模型训练与表征、state grounding、动态预测/想象、轨迹评估与动作选择、执行与反馈、agentic memory/tool extension。攻击按入口映射到七类 security object：state integrity、dynamics fidelity、affordance correctness、constraint compliance、trajectory-ranking integrity、uncertainty calibration、feedback provenance。

攻击面覆盖 poisoning/backdoor、对抗视觉与 LiDAR/GNSS/IMU spoofing、环境 prompt injection、物理条件扰动、视频 temporal attack、trajectory ranking manipulation、world-action drift、action-chunk attack、memory/RAG/tool poisoning 和供应链。防御按同一生命周期组织为数据 provenance/curation、robust multimodal grounding、physics/rule-aware imagination、ensemble/calibration、trajectory-level shield/CBF、fallback/human handoff、feedback audit、memory hygiene 与 middleware/update assurance。

作者提出四步评测协议：声明攻击入口与 security object；成对记录 imagined rollout、安全决策和真实执行结果；包含 adaptive/state-conditioned attack；攻击结束后继续测 persistence、detection 和 recovery。方法贡献是 taxonomy 和 reporting protocol，没有系统综述的检索式、纳入/排除标准或证据质量评级。

## Experiment
论文没有新实验。它用多张表汇总代表性 world model、攻击、防御和 benchmark，并对现有覆盖做 gap analysis。主要结论是：现有 benchmark 尚无标准协议直接测“受攻击的 imagined future”；缺少 predicted-safe-but-actually-unsafe rate；训练阶段 backdoor persistence、生成数据污染与 feedback poisoning 仍是各论文自建设置。

建议指标分七类：task utility；collision/forbidden contact 等 safety violation；targeted action/unsafe rollout acceptance 等 attack success；next-state error/rollout divergence/physical-law violation 等 prediction quality；false-safe certificate/intervention recall/calibration 等 predictive safety；stealth/persistence；以及 false block、recovery latency、compute overhead 等 defense cost。该框架全面，但尚未通过统一 benchmark 证明可操作性或指标间相关性。

## Value
对视频/隐式世界模型的直接启发是评测时同时保留“模型想象了什么、风险门控如何判断、最终执行发生什么”，避免只看最终动作成功率掩盖内部错误动力学。生成式世界模型用于数据增强和安全盾时尤其应设置独立于同一模型的冗余检查。本文适合作为安全检查清单和研究选题地图，不是世界模型架构主线论文。

## Strengths
- 以预测信任边界为中心统一原本分散的 VLA、视频、MBRL、传感器和 agent memory 威胁。
- 明确区分 state、dynamics、affordance、ranking、uncertainty 与 feedback 等受攻击对象。
- 同时讨论世界模型作为攻击目标、污染放大器和安全机制的三重角色。
- 评测协议强调 paired imagination/execution logging、状态条件攻击和攻击后恢复，具有可执行性。
- 开放问题覆盖 implicit WM 审计、生成预测验证、跨 embodiment transfer 与人类过度信任。

## Weaknesses
- 不是系统性综述：没有数据库、检索时间窗、筛选流程、覆盖率或 risk-of-bias，文献选择完整性无法判断。
- 对“implicit world model”的定义很宽，几乎把所有 VLA/LLM robot 安全问题都纳入，可能稀释世界模型特有威胁。
- 多个五类 insight 是合理的概念归纳，但缺少跨论文定量证据或统一实验验证其独立性。
- taxonomy 中不少攻击来自邻近系统，尚未真正攻击 action-conditioned latent/video rollout；映射有时是推断而非直接证据。
- 防御建议多为 provenance、ensemble、CBF、sandbox 等通用安全实践，缺少世界模型专属算法和成本分析。
- 声称评测协议“不需要新基础设施”偏乐观；记录并对齐 imagined rollout、真实轨迹、风险与反事实候选通常需要修改系统和 benchmark。

## Future Work
作者提出审计不可见 rollout 的 implicit world model、规模化验证生成未来与 action chunk、针对 safety checker 的自适应攻击、合成数据 provenance/trigger/下游污染测试、跨机器人与 sim-to-real 安全迁移、人类对生成未来的信任校准，以及带状态假设、拦截、回滚和事件日志的部署保证。首要实证方向是建立包含攻击后 imagined future 和真实执行配对日志的统一 benchmark。

## Rating
创新度评分：2/5 - 生命周期 taxonomy、五类失效与 paired evaluation protocol 有整理价值，但没有新攻击、防御或系统性证据，技术贡献有限。

相关度评分：2/3 (Related) - 直接讨论视频、latent、world-action 与具身世界模型的安全边界，对评测和部署有明确参考价值，但不推进核心模型方法。

## TL;DR
以全生命周期梳理具身世界模型攻击、虚假安全感与评测缺口，适合作安全清单，可选读。
