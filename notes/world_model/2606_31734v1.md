# MemLearner: Learning to Query Context Memory for Video World Models

## Insight
核心 insight 是长视频世界模型的 memory 不应只靠规则检索关键帧，而应让生成模型自己学习“该从历史里查什么”。观察是不同预测帧、不同 diffusion timestep 需要不同历史信息；早期需要全局上下文，后期需要局部对应。论文用 attention 相似性和 separate module 失败实验说明：从零训练额外查询模块很难被视频 DiT 使用，复用预训练生成模型内部 attention 更有效。

## Motivation
论文解决交互式视频世界模型长时生成中的场景一致性和遮挡后记忆问题。已有 Context-as-Memory、VMem 等用 FOV overlap、点云或规则选择历史帧，在静态场景可用，但遇到遮挡、动态物体、长程 revisit 会失效。这个问题对视频世界模型非常关键，因为世界模型如果不能记住被遮挡和离屏内容，就无法支持长时交互和探索。

## Method
MemLearner 在 latent video diffusion/DiT 中加入 query tokens。输入 token 分为 C(context)、Q(query)、P(predicted)，Q 作为桥从 C 中提取对 P 有用的信息。训练仍只对 P 的 diffusion noise 做监督，不需要显式 memory label。效率上做两点：只在浅层 Query Layers 中让 C/Q/P 交互，深层 Generative Layers 去掉 C；attention 只保留 Q->C/P、P->P/Q 等必要模式，避免 C 作为 query 的冗余计算。还收集 UE 渲染长视频数据，包含 occlusion、dynamic objects、revisit 和相机 pose，并提出 rendered/real/mixed 多数据集训练策略。

## Experiment
主实验基于内部 1B 视频 DiT，另在 Wan2.1 T2V-1.3B 上验证可迁移。指标包括 GT comparison 和 revisit comparison 下的 PSNR/LPIPS/FID/FVD，以及 fps。自建 occlusion/dynamic 数据集上，MemLearner 在 GT Comp. 达到 PSNR 21.23、LPIPS 0.2904、FID 112.75、FVD 835.98；Revisit Comp. 达到 PSNR 18.57、LPIPS 0.3230、FID 101.57、FVD 847.52，优于 DFoT、FramePack、VMem、CaM。消融显示 Q attending to P 是关键，5 个 query layers 性价比最好，给 C/Q 额外 camera pose 不是必须，真实数据提升真实感但单独训练记忆能力不足。

## Value
这是视频世界模型 memory 方向的高价值论文。它把 memory 从规则检索推进到可学习 context query，直接对应长时一致性、遮挡、动态对象和 revisit。局限是上下文仍近似线性增长，1B 规模下多角色复杂交互仍会丢对象；还没有解决压缩、更新、遗忘等更长程 memory 管理问题。
