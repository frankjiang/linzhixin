# What Matters for World Modeling in Vision-Language-Action Models?

## Insight
观察：世界表征的收益随接入方式翻转；V-JEPA 2.1 在 MoT 专家上带来强 OOD 收益，在外部预测器上却负迁移。推论：选择视频/3D/语义编码器时必须与策略信息通路共同设计，不能只按表征预训练指标排序。6 类表征×4 种范式、三种随机种子及输入/目标 2×2 消融支持此结论；部分翻转由预测目标而非当前输入主导。

## Motivation
已有 VLA 世界模型工作同时改变未来表示、集成架构与策略骨干，难以归因。论文统一动作专家、训练协议和未来监督，比较何种设计在长程、动态、分布外与少样本操作中有效。这是世界模型落地到决策的关键评测问题。

## Method
- 统一 Qwen3-VL-2B + 28 层 Cross-DiT 动作专家，以 t+4/8/12/16 帧的冻结编码器特征作未来目标，动作流匹配损失加余弦世界表征损失。编码器包括 ImageVAE、WanVAE、DINOv3、SigLIP、VGGT、V-JEPA 2.1；另检验预训练 π0.5 骨干。
- 四范式：WM-Align 用未来特征辅助监督 VLM 隐状态；WM-Query 在 VLM 内放未来查询 token 供动作专家读取；WM-MoT 并列未来专家与动作专家，在各层交互；WM-Ext 独立预测未来特征，再将其输入动作专家。前两者推理几乎无额外模型成本，后两者保留预测模块。
- 研究重点是受示范轨迹监督的未来视觉特征，尚未检验给候选动作做反事实预测。MoT/Ext 用所选编码器特征同时初始化当前 token 和构造未来目标，因此原始表征比较并非只隔离未来监督；附录另以交叉编码器实验拆分这两者。

## Experiment
- LIBERO-Plus OOD 成功率：动作基线 71.8%，WM-Align/Query/MoT/Ext 为 74.1/72.9/76.2/74.7%。三种训练种子下 MoT 为 76.4±1.0%，基线 71.4±0.4%。但 RoboTwin Clean2Random 的 Qwen 设置中 Align 14.8% 略高于 MoT 14.0%，无全局赢家。
- RoboTwin Clean2Clean 平均成功率基线 52.3%，四范式为 62.3/64.7/62.6/60.7%；长任务 WM-Query 57.0% 对基线 30.7%。DOMINO 动态任务 MoT 15.5% 对 10.6%。π0.5 上 MoT 的 RoboTwin OOD 49.7% 对基线 46.4%，而 Align 降至 41.0%。
- 真机 Franka 四任务、每任务 40 次：MoT 平均成功率 73.8% 对动作基线 45.0%，动态番茄抓取 75.0% 对 37.5%。世界监督消融：同用 DINOv3 当前特征的 MoT 无未来损失为 73.6%，加未来损失为 76.2%；25% LIBERO 数据下 Query 约 70.1%，低于基线 84.9%。
- 成本：MoT 推理端到端延迟 136.1 ms，基线 103.3 ms；Align/Query 约 103.0/105.4 ms。MoT 的额外专家与编码器使参数和计算成本不可忽略。

## Value
这是一份直接指导视频/3D/隐式未来表示接入 VLA 的设计与评测矩阵；尤其值得精读“表征×范式”交互、预训练骨干负迁移和控制消融，即便主要贡献是系统分析而非新基础模型。

## Strengths
跨六种表示、四条信息通路、两个骨干及仿真/真机多设置比较；报告三种子复现、额外输入/容量控制、表征输入与目标因子拆分，以及训练和推理成本。

## Weaknesses
四范式参数量和在线计算不同；不同骨干也同时改变容量、视觉编码器及动作头，不能把差异只归因预训练；未来目标来自示范，不证明模型能正确预测候选动作后果；多数真机任务仍较少，DOMINO 绝对成功率低；静态 2D 特征表现好不等于世界动力学建模充分。

## Future Work
作者主要给出设计原则，未提出具体后续算法；值得进一步做匹配算力和参数的比较、动作条件反事实评测、长期闭环预测校准及更广的真实机器人验证。

## Rating
创新度评分：3/5 - 大规模受控比较和关键因子消融有方法学价值，四种集成方式本身来自已有工作。
相关度评分：3/3 (Core) - 直接比较视频、3D 与 JEPA 表征如何进入世界模型辅助的 VLA 决策。

## TL;DR
系统比较六种未来表征与四种 VLA 接入方式，发现效果强依赖架构且解耦专家较稳健；方法选择值得精读。
