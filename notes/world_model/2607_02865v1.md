# DREAMSTEER: Latent World Models Can Steer VLA Policies During Deployment Without Any Finetuning

## Insight
论文的 insight 是：冻结 VLA 在部署时可以由 latent world model 做 action reranking，而不需要对目标环境微调。世界模型负责想象候选动作 chunk 的未来，语言条件 value model 负责判断哪条未来更接近任务目标。

## Motivation
VLA policy 面对分布外物体、背景或任务时容易输出错误动作。在线微调成本高、风险大；纯语言反思又缺少物理预测。DREAMSTEER 希望在 deployment-time 加一层世界模型 steering。

## Method
系统从 pi0 等基础策略和手工 primitives 中采样多个 action chunks。latent world model 根据当前观测和候选动作 rollout 未来 latent observation；language-conditioned value model 给每条 rollout 打分，执行最高分动作。基础 VLA、世界模型和 value model 均不在目标环境微调。

## Experiment
真实 Franka DROID-style 设置中，world model/value score 与真实成功有中等相关，Pearson 约 0.66、Spearman 约 0.69。OOD 操作成功率从 pi0 的 23.75 提升到 full system 的 66.25；instruction-following 也从 38.75 提升到 56.25。消融显示只用 primitives 或只随机选择均不够。

## Value
这篇对机器人世界模型很直接：它把 latent rollout 作为部署期 policy improvement 模块，而不是训练辅助 loss。适合思考如何让世界模型真正参与 action selection。

## Strengths
无需 finetune；真实机器人收益明显；把候选生成、世界模型想象和价值排序分工清楚。

## Weaknesses
受候选动作覆盖率限制；value ranking 错误会直接导致失败；推理额外开销不小；多视角聚合和长时任务仍待增强。

## Future Work
作者提出改进候选采样、多视角 value aggregation 和更长 horizon rollout。

## Rating
创新度评分：3/5 - deployment-time steering 组合有效，但依赖已有 VLA/WM/value 模块。
相关度评分：3/3 (Core) - 直接使用 latent world model 影响机器人动作选择。

## TL;DR
DREAMSTEER 用 latent WM rollout 在部署时重排 VLA 动作，实机提升明显，值得选读。
