# Population-Scalable Multi-Agent World Modeling

## Insight
多智能体视频世界模型的核心尺度变量不应是“固定数量视角的联合视频张量”，而应是可查询的共享世界状态。把静态环境和动态实体维护在 Spatio-Temporal Blackboard 中，各相机只投影当前可见实体并独立渲染，理论上即可让训练时未见过的 agent 动态加入/退出；实验中跨视角状态显著降低视角增加时的 FVD，支持共享状态是保持一致性的关键。

## Motivation
现有多视角生成常固定相机数量、联合注意所有视图，计算随群体规模迅速增加，也难支持 agent 运行时增减。开放多智能体环境需要数量无关、身份连续且跨视角一致的生成世界模型，问题直接且重要。

## Method
Khora 维护包含粗静态点云、agent 位姿和动态实体的共享 Blackboard。每个视图按相机几何查询/投影实体，栅格化 occupancy、depth、orientation、identity 等固定尺寸条件，再由同一视频生成器逐视角生成；实体动作先更新共享状态，任一相机随后可读取。昂贵渲染近似 $O(N_v)$，实体投影仍为 $O(N_aN_v)$，但避免把所有视角同时送入大模型。创新是显式共享状态、几何查询与生成渲染的解耦。

## Experiment
在 2/4/8 视角设置中，完整模型 FVD 为 36.55/38.68/53.61，移除跨 agent 状态后为 51.67/73.49/104.91。用户研究的动作一致性 3.57 vs 2.08、整体质量 3.89 vs 3.07，世界一致性提升较小（4.21 vs 4.07）。从 1 扩至 80 agents、每视图一张 GPU 时，延迟 107.16→116.73 ms、单视图 FPS 37.33→34.27，80 视角聚合达 2741 view-FPS；这证明单视图负载近恒定，但总硬件随视图数线性增长。主要结果仍偏模拟与定性。

## Value
该工作给多智能体视频世界模型一个清晰系统分解：可持久、可查询的共享状态负责一致性，生成器负责局部可视化。这对动态人口、多人游戏和交通仿真很有启发；下一步关键是减少对地图先验、结构状态与线性 GPU 数量的依赖。

## Strengths
- 支持训练时未见数量及 agent 在线加入/退出，任务定义新颖。
- 明确身份、位姿、动态实体与相机投影的数据流，具可解释性。
- 视角数消融显示共享状态能明显抑制一致性退化。
- 将延迟、显存、单视图和聚合吞吐分开报告。

## Weaknesses
- 每个视图一张 GPU，总计算/硬件仍线性增长，“population-scalable”主要指弱耦合并行。
- 依赖地图特定粗点云及结构化实体状态，不能从纯视觉自主建图，也未证明零样本新环境。
- 投影成本仍为 $O(N_aN_v)$，密集人口可能成为瓶颈。
- 长程漂移、遮挡交互、状态估计误差及闭环 agent 决策验证不足；用户研究规模报告不充分。

## Future Work
作者指出需增强跨域/新环境泛化和更长时评测；进一步可学习 Blackboard、稀疏化可见实体查询、共享批量渲染，并验证有状态 agent 与生成世界的真实闭环互动。

## Rating
创新度评分：4/5 - 共享世界状态与独立几何条件渲染有效解决动态群体规模问题，系统思想鲜明，但资源扩展仍依赖线性 GPU。
相关度评分：3/3 (Core) - 直接研究多智能体、多视角、可交互视频世界模型。

## TL;DR
Khora 以共享状态查询支持动态多智能体视频生成，跨视角一致性强但总 GPU 仍线性增长，值得精读。
