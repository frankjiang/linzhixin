# WorldCraft: From Camera Navigation to Object Manipulation in Interactive Video World Models

> 创新度：3/5 | 相关度：3/3
>
> TL;DR: 首个在自回归视频世界模型中同时支持相机导航与物体轨迹操控的框架，通过归一化世界轨迹解耦相机-物体运动、空间通路LoRA保留相机控制能力、轨迹锚定状态持久化处理离屏物体状态；工程完成度高，值得精读。

## Insight

现有交互式视频世界模型（Genie 3、WorldPlay）的动作空间仅限于相机导航，无法操控场景中的具体物体。而真实交互本质上是以物体为中心的。在自回归视频世界模型中同时支持相机控制和物体轨迹控制，面临三个耦合难题：(1) 相机运动会导致屏幕空间中所有物体位移，物体自身运动与相机自运动纠缠；(2) 新增轨迹控制不能破坏已有的相机控制器；(3) 物体移出视野后状态需要持久化。

## Motivation

- 视频世界模型已能生成可交互的像素级环境，但动作空间止步于视角控制，用户只是"被动观察者"
- 真实场景（机器人推杯子、自动驾驶预测行人、游戏中移动实体）都需要物体级别的动作
- 先前轨迹引导生成（DragAnything、Wan-Move）仅支持静态相机、非自回归，无法与相机控制组合
- 本文目标：在保留相机控制的前提下，为自回归视频世界模型增加物体轨迹动作

## Method

基于 WorldPlay（HunyuanVideo-1.5, 8B参数, DiT架构）构建，新增三个核心组件：

**1. Normalized World Trajectory (NWT)**
- 问题：屏幕空间轨迹 = 物体自身运动 + 相机自运动导致的视差，两者纠缠
- 方案：将用户指定的2D屏幕轨迹提升到归一化世界坐标系（以第一帧相机为参考），在每步生成时根据当前相机位姿重投影回屏幕空间
- 关键公式：先用第一帧内参归一化 q_t = (x-cx)/fx，再通过 pi(K_t, E_t * E_0^{-1}, lift(q_t, d)) 重投影
- 迭代深度精化：每个chunk生成后更新anchor帧和深度估计，形成闭环校正，减少长rollout的几何漂移

**2. Spatial-Pathway LoRA (SP-LoRA)**
- 观察：全参数微调后，权重变化集中在空间控制通路（action encoder + ProPE投影），比attention/FFN层变化大10-25倍
- 方案：仅对空间控制通路施加低秩适配（LoRA rank=32, ~50M参数），冻结其余所有参数
- 效果：保留预训练相机控制能力的同时获得轨迹控制，远优于全参数微调或常规Q/K/V LoRA

**3. Trajectory-Anchored State Persistence (TASP)**
- 问题：自回归记忆只存储物体最后可见位置，物体移出视野后再回来会出现在旧位置
- 两个机制协同：
  - 世界空间轨迹作为持久空间信号：即使投影超出可见帧，轨迹条件仍然有效，回视时投影到正确位置
  - 预退出记忆过滤：通过FOV相似度检测并mask掉物体离开视野前的记忆帧，避免旧位置信息干扰

**训练策略**：三阶段渐进训练
- Stage 0: 真实视频领域适配
- Stage 1: 静态相机 + BI attention 引入轨迹控制
- Stage 2: 动态相机 + AR attention 扩展到完整场景

**轨迹注入方式**：将首帧latent特征复制到目标轨迹位置，替换image-conditioning通道的32-64维，作为in-context条件输入模型。

## Experiment

**轨迹控制精度**（静态相机，50 clips, 61帧）：
- TE（轨迹误差）：WorldCraft 38.90 vs DragAnything 39.86 / Wan-Move 44.08
- 视觉质量全面最优：PSNR 17.23, SSIM 0.616, DINO 0.807

**相机保真度**（纯相机控制，50 clips）：
- 61帧 RPE_rot: 0.131（WorldPlay 0.120, GameCraft 0.252）
- 253帧长rollout: RPE_rot 0.123，优于所有baseline（WorldPlay 0.130）
- 说明添加轨迹控制不会损害相机控制能力

**组合控制**（相机+轨迹同时，45 clips）：
- 仅WorldCraft支持此设定，按相机旋转幅度分桶评估

**消融实验**：
- NWT vs 像素空间轨迹：世界空间+迭代深度在大旋转下 TE 从45.28降至34.65
- SP-LoRA vs 全参数/常规LoRA：~50M参数即达最佳TE-RPE权衡
- TASP记忆刷新：对离屏物体状态恢复至关重要

支持部件级控制、多物体同时控制、253帧长期生成。

## Value

- 首次在单一自回归视频世界模型中统一相机导航和物体轨迹操控两种动作模态
- NWT是一个优雅的解耦表示，将相机-物体运动分离问题转化为坐标系变换
- SP-LoRA提供了一个实用的发现：视频DiT中空间控制集中在特定通路，仅需适配该通路即可添加新控制维度
- TASP解决了自回归世界模型中被忽视的离屏状态持久化问题
- 局限：依赖用户手绘轨迹作为输入，未探索语义级/意图级物体交互；深度估计依赖单目深度模型的精度
