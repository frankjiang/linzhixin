# Lifecycle-Aware Dynamic Analysis for Secure ML Model Execution

## Insight
核心 insight 是把“模型文件”当作受限生命周期内执行的程序来监控：加载、推理、训练阶段的系统调用模式高度可预测，因此偏离阶段边界的 host interaction 可以作为恶意模型信号。证明主要是安全系统实证，而不是世界模型算法证明。

## Motivation
论文解决 ML model supply chain 安全：现有 scanner 多依赖 pickle/static signature/格式规则，难泛化到 Keras、TensorFlow、PyTorch 与未知漏洞。问题本身重要，但与视频/3D/JEPA/Dreamer 世界模型研究几乎无直接关系。

## Method
提出 MOAT/Re-MOAT：把 syscall 映射为 security-relevant actions，按模型生命周期定义 allowlist execution boundary，由 orchestrator 驱动不同阶段，tracer 在运行时捕获越界行为。优势是格式无关、框架无关，关注攻击对主机系统的实际效果。

## Experiment
评估包含 31 个 CVE/PoC、77,974 个 Hugging Face 实际模型 artifact、以及 PickleBall 使用的 334 模型数据集。Re-MOAT 在作者 threat model 下检测所有评估攻击，Hugging Face 大规模扫描标记 23 个模型且人工确认恶意；与 ModelScan、ModelTracer、weights_only、PickleBall、Fickling 比较，报告 0 FP/0 FN。局限是可能被 anti-dynamic-analysis 绕过，边界随框架演进需维护。

## Value
作为 ML 安全论文有实际价值；对用户关注方向的启发仅限于“未来开放世界模型/机器人模型下载执行也需要运行期边界”。不提供视频世界模型、3D 表征或 JEPA/Dreamer 方法贡献。
