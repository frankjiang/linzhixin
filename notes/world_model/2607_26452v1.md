# CG-World: A Large-Scale World-State Dataset and Protocol for World Models

## Insight
论文的 insight 是：世界模型数据不应只保存最终 RGB 视频或人工标签，而应保存生成观测背后的世界状态、关系、事件、动作和分支谱系。工业 CG 生产管线天然包含这些中间状态，因此可作为 3D/视频世界模型的结构化监督源。推论是，显式 world-state 数据能支持状态预测、受控生成和反事实学习。

## Motivation
现有视频、机器人和仿真数据集往往只覆盖状态-动作-观测链条的一部分，缺少统一时间轴、实体身份、物理缓存、事件和可干预分支。同行多从像素视频或真实机器人轨迹学习，难以获得完整 latent world state。这个问题对 3D/视频世界模型重要，但本文更偏数据协议而非模型算法。

## Method
CG-World 定义世界状态 `W_t`，观测函数 `O_t^m=g_m(W_t;C_t^m,epsilon_t^m)`，以及状态转移 `W_{t+1}=F(W_t,a_t,u_t;Theta_t)+xi_t`。数据单元包含 world-state 序列、多模态观测、动作、干预、分支谱系和元数据。协议分 L1 观测对齐、L2 动态状态、L3 因果干预三层；分支包括 factual、observation intervention、action intervention、mechanism intervention 和 strict counterfactual。

## Experiment
CG-World v1 约 850,000 个 1-5 秒 shot-level world-state segment，中位时长 2.6 秒；训练/验证/测试约为 637,500/127,500/85,000。实验一用 LTX-2.3-22B 做几何条件视频生成，Mixed Union 在 Depth 控制下 LPIPS/FVD 为 0.2785/326.3，优于 official union。实验二用 Cosmos3-Nano 做 16 步动作预测，CG-World-LoRA 相比 LIBERO-LoRA 将 Action MSE 从 0.08061 降到 0.05326，Gripper F1 从 0.8935 提升到 0.9573。实验三在 OpenVLA 仿真迁移中，PickCube 成功率从 RGB BC 的 4.0% 提升到 39.0%，StackCube OOD 从 0% 到 25.0%。

## Value
这篇的价值是数据基础设施：它说明 world-state、event、branch lineage 和多视角观测如何组织，适合参考其 schema 和数据分层。对我们做 3D/视频世界模型有帮助，尤其是如何构造可干预、可反事实的数据。但目前实验只说明数据有用，不能证明其足以学习真实物理规律。

## Strengths
亮点是协议覆盖实体、结构、动态、关系、事件和观测，且显式支持反事实分支；数据规模大；在视频生成、动作预测和 VLA 迁移三个任务上都给了初步收益。

## Weaknesses
不足是工业 CG 有生产偏差，包括镜头选择、风格化动作、引擎/solver 特异性和合成后处理；公开释放和权限细节依赖后续；实验中的提升可能混合了数据量、质量和控制信号差异，缺少更干净的因果归因。

## Future Work
作者计划构建严格配准的真实-虚拟场景对，用于测量观测、动力学和干预偏差；发展误差/不确定性模型；用少量真实数据校准 CG 机制；扩展长程因果链和动态覆盖，并通过社区插件扩展 schema。

## Rating
创新度评分：3/5 - 数据协议和规模有意义，但主要贡献是资源与组织方式，不是新世界模型算法。
