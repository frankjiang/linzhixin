# MomWorld: Momentum-Aware Latent World Model for Long-Horizon Autonomous Driving

## Insight
只滚动单一潜场景状态可能抹平持续运动，也可能在突然变道/刹车后保留过时趋势；作者同时滚动场景配置和潜动量，用保留、更新、重置门控控制动力学。nuScenes 6 秒平均预测碰撞率相对 MomAD 从 0.90% 降至 0.79%，消融显示去重置门控后 6 秒碰撞率升至 2.83%。证据是规划指标，而非对潜动量物理含义的直接鉴别。

## Motivation
已有长时驾驶规划延长历史输入或生成候选轨迹，但未来潜状态逐步预测会丢失动态趋势，长远预测又可能扰动可靠的近端计划。需要利用历史运动线索，并在突变时撤销过时趋势，同时控制长时修正对当前轨迹的影响。

## Method
多视角图像经场景 query 编码，当前与前一时刻 query 差初始化场景潜状态 z 和动量 p；递推中用保持系数 ρ、重置门 g 和新动量 u 更新 p，再以 p 的映射残差更新 z。未来 query 对齐、相邻 query 差的动量监督及未来自车/他车/存在状态辅助损失训练该滚动。各未来 (z,p) 构成 Future World Memory，供固定轨迹库的候选 query 注意力打分，选一条基础轨迹；MoFlow 用初始动量和未来记忆条件的流匹配，把基础轨迹向专家轨迹作少步残差变换，并以裁剪、近端小远端大的门控融合。NAVSIM 用 16,384 条候选、40 步/4 秒，4 步 Euler 积分。潜未来记忆对所有候选共享，**不是**逐候选动作条件的反事实世界滚动。

## Experiment
nuScenes 相机单模态 6 秒规划：平均 L2 1.17 m、预测碰撞 0.79%，MomAD 为 1.42 m、0.90%；6 秒端点为 L2 2.31 vs 2.45 m、碰撞 1.97% vs 2.13%。TPC 4–6 秒均值 1.19 vs 1.42 m。NAVSIM v1 navtest PDMS 90.2，DriveLaW 89.1；v2 navhard 官方两阶段 EPDMS 42.8，v2 navtest 单阶段诊断 90.1（后者非官方榜单协议）。闭环 Bench2Drive DS 74.07、成功率 50.00%，低于 HiP-AD 86.77/69.09 和 SparseDriveV2 89.15/70.00。累计组件消融中基线→完整模型，nuScenes 6 秒 L2 2.45→2.31、碰撞 2.13→1.97；MoFlow 加 8.4 ms，整体约 138.9 ms。NAVSIM 输入包括两帧相机和四次 LiDAR 扫描，不能视作纯视觉结果。

## Value
对隐式世界模型值得借鉴的是显式拆分潜场景配置与变化趋势、对趋势设计重置，以及将想象记忆作用于候选打分时限制对近端计划的扰动。更进一步应比较真正动作条件的世界滚动，以检验目前共享未来记忆能否处理候选之间的交互反事实。

## Strengths
未来状态、动量与轨迹修正均有较细消融；同时测试 nuScenes、NAVSIM 两版本和 Bench2Drive，涵盖开环、伪仿真与闭环；清楚报告额外推理成本及固定候选库的限制。

## Weaknesses
未来潜记忆不随候选动作重新滚动，交互规划的反事实能力有限；固定 16,384 条候选轨迹限制覆盖。nuScenes 碰撞是用记录的他车轨迹计算的预测碰撞，不等于真实闭环碰撞；NAVSIM v2 navtest 数字仅是诊断设置。Bench2Drive 与更强方案仍有较大差距，不同公开基线 FPS 硬件也不同。

## Future Work
作者明确提出以更灵活的轨迹候选生成替代固定词表，同时保留潜动量条件的稳定残差修正。

## Rating
创新度评分：3/5 - 双潜状态动量滚动与保守残差流规划有一定方法新意，主要是已知门控和流匹配的组合。
相关度评分：3/3 (Core) - 直接研究隐式潜世界模型及其长时驾驶规划。

## TL;DR
联合滚动场景与潜动量并保守修正长时轨迹，多基准规划改善；隐式世界模型设计值得精读。
