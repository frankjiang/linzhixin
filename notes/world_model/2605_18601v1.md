# Incantation: Natural Language as the Action Interface for Multi-Entity Video World Models

## Insight
核心 insight：现有交互式视频世界模型的控制表达力瓶颈不在模型架构，而在动作接口。三类传统接口（引擎动画标签、设备输入、场景级描述）都将动作语义绑定到特定实体或引擎，阻碍了跨实体和跨世界泛化。自然语言作为接口天然具备开放词汇语义和逐实体可寻址性，从构造上解决这两个问题。

## Motivation
多实体交互视频世界模型缺乏精细控制和跨实体/跨世界泛化。这是动作接口的结构性限制：离散动画标签 OOV 不可表达、设备输入无法指定哪个实体行动、场景级描述粒度太粗。Incantation 提出逐帧逐实体的自然语言动作接口。

## Method
基于 Wan 2.2 TI2V-5B 骨干。核心设计：(1) 逐帧语言条件化注意力——解耦文本交叉注意力仅限于当前 noisy target 帧，历史帧使用双向自注意力保留预训练先验，防止时序交叉污染；(2) Bounded RoPE 位置分配——滑动窗口 K_r + 位置上限 C 防止流式推理中 RoPE OOD；(3) 两阶段实时流式——ODE 初始化（flow matching 一致性对齐）+ Self-Forcing 蒸馏（2 步因果学生），RoPE 解耦的 KV-cache 滑动窗口。

## Experiment
128 小时游戏数据集（Elden Ring 30h + KOF 83h），逐帧逐实体动作标签。ACA (Action Control Accuracy)：NL 95% vs Action-Index 89%（域内）、89% vs 43%（跨实体）、90% vs 0%（OOV）。2 步学生 19.7 FPS @ 480p，2 小时 rollout FVD 稳定。KOF 仅换词汇即复现。

## Value
对视频世界模型研究高度相关且有重要贡献。自然语言作为交互式视频世界模型的动作接口是范式级创新：从构造上实现跨实体动作迁移和 OOV 覆盖。逐帧解耦注意力和 Bounded RoPE 的架构设计解决了实际工程难题。19.7 FPS 实时流式和 2 小时稳定 rollout 具有实用价值。局限：训练数据来自游戏引擎内存读取，真实场景需要 VLM 自动标注器等替代方案；仅支持离散语义动作，不支持连续控制信号。
