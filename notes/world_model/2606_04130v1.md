# CLAW: Learning Continuous Latent Action World Models via Adversarial Latent Regularization

## Insight
核心 insight：在联合训练 latent action model (LAM) 和 world model 时，信息泄漏是主要障碍——latent action 容易编码未来观测内容而非动作本身。CLAW 提出用**对抗性隐空间正则化**（gradient reversal）来解决：让 world model 仅凭 latent action（不给当前观测）做预测时效果要差，从而迫使 latent action 只编码动作信息、不泄漏未来观测。这比 VQ-VAE 离散化约束或 β-VAE 容量限制更直接地针对泄漏问题。

关键观察：连续 latent action 比离散 latent action 提供更细粒度的控制，且在下游规划中表现更好。

## Motivation
当前 world model 通常依赖显式动作标签（action-conditioned），限制了跨任务/跨 embodiment 的泛化和对无标签视频数据的利用。Latent action world model 从视频中自动推断动作表示，但面临两个核心挑战：
1. **信息泄漏**：latent action 编码未来观测内容而非动作信息
2. **表示坍塌**：latent action 退化为无意义表示

同行方法：AdaWorld 用 β-VAE + 两阶段训练；LAPO/LAPA 用 VQ-VAE 离散化。它们要么需要两阶段流程，要么使用离散动作限制了控制精度。CLAW 是首个端到端联合学习连续 latent action 和 world model 的方法。

## Method
整体架构：
1. **Latent Action Model (LAM)**：ViT backbone，输入相邻帧对 (o_i, o_{i+1})，输出 ℓ2-normalized 连续 latent action z_i
2. **Diffusion-based World Model**：UViT backbone，条件为初始帧 o_i 和 latent action 序列 {z_j}，预测未来帧序列。使用 causal attention mask 防止时间泄漏
3. **Adversarial Latent Regularization**（核心创新）：
   - 两组预测：一组用 (o_i, z_i) 做正常预测，另一组仅用 z_i（不给 o_i）
   - 对仅用 z_i 的分支加 gradient reversal layer：∂L/∂z ← -α·∂L/∂z
   - 效果：如果 z_i 泄漏了未来信息，仅 z_i 就能预测好，梯度反转会惩罚这种泄漏
   - 对抗强度 δ 按 sigmoid schedule 从 0 逐渐增到 0.999

LAM 和 world model 端到端联合训练，无需两阶段或预训练。

## Experiment
评估维度全面：
- **Imitation Learning from Observation (ILfO)**：Crafter（Wood Harvest 86% vs AdaWorld 43.5%）、OGBench（Open Drawer 13.5% vs AdaWorld 7.5%）——大幅领先
- **Visual Planning (VP²)**：Robosuite/RoboDesk 6 个任务，4/6 最优
- **Procgen**：Crafter/Climber/Jumper/Ninja，3/4 最优
- **Real-world Tabletop Manipulation**：Something-Something V2 预训练 → UR5 操作，Push-Cover Duck 综合得分 1.7 vs LAPA 1.3
- **Action Retrieval**：最近邻可视化显示 CLAW 的 latent action 空间语义一致（相似末端执行器运动聚集），而 baseline 混淆了非动作属性
- **Action Transfer**：光流验证 latent action 成功迁移

消融和定性分析充分。

## Value
这是一篇高质量的 latent action world model 工作，直接切中了隐式世界模型（Dreamer 线）的核心问题。主要贡献：
1. 首个端到端连续 latent action + world model 联合训练框架
2. 对抗性正则化解决信息泄漏的思路优雅有效
3. 跨 5 个 benchmark + 真实机器人的全面验证

对我们的启发：对抗性正则化是解决 latent representation 中信息泄漏问题的通用工具，可借鉴到视频世界模型中防止表示退化。连续 vs 离散 latent action 的对比也提供了有价值的设计指导。

待解决问题：仅基于最近帧预测（无显式记忆），在 partially observable 环境中可能不足；仍需少量标注动作数据做 latent-to-action 映射。
