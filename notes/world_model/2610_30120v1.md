# ALPS: Visual State Encoders for World Models

## Insight
观察：世界模型冻结视觉编码器后，其 token 是否保留物体状态、语言语义和可解码细节，决定后续预测、指令控制与可视化的上限。推论：先让同一 patch token 联合承担语言/重建/空间任务，再做有几何对应约束的跨视角自蒸馏，可提升状态信息而大体保留另两种接口。Stage 2 使 LIBERO 状态探针相对误差 **1.000→0.829**，Flickr30k 图文检索仅 **93.4→93.2**；对 CLIP、SigLIP 2 直接做同样蒸馏则显著损失语言对齐，说明初始化与读出结构很关键。（表 1；图 5）

## Motivation
自监督视觉编码器常擅长空间状态却无原生文字接口，图文编码器的局部状态较弱，重建型编码器又未必适合动作预测。单一潜表示同时支持世界模型预测、语言目标及像素检视，是隐式世界模型的重要接口问题。

## Method
- Stage 1 从零训练 ViT-B/16 与文字塔，在同一 patch token 上联合做图文对比、描述生成、像素重建和跨裁剪密集对应；图像/文字主要来自 DataComp 与合成描述。图像全局表示是 patch token 的**线性投影后平均池化**，有助于后续局部更新时保持语言接口。
- Stage 2 冻结 Stage 1 教师，从单张图像取干净裁剪 B 和增强裁剪 A；学生通过位置/相对尺度查询预测 B 中落在 A 内的标准化教师 patch token，最小化特征平方误差。推理时丢弃预测器，保留学生编码器和原文字塔。两阶段仅用静态图像/文本，未见视频或动作；总 Stage 1 处理约 **138 亿次图像样本**，计算成本很高。（正文 §3；附录 S1）
- 贡献主要是视觉状态编码器的训练配方与三接口评测，而非新动力学预测器。下游世界模型在冻结 token 上沿用 DINO-WM/LeWorldModel 配方。

## Experiment
- 比较 15 个公开编码器，以统一的 LIBERO 状态探针、Flickr30k/COCO 检索、ImageNet 零样本和轻量解码器评估。ALPS 在 ViT-B 中状态相对误差 **0.829** 最低，近似 3.5 倍参数的 V-JEPA 2-L；Flickr30k I→T R@1 **93.2**，重建 ℓ1 **0.120**。但 V-JEPA 2-L 当前状态读出更好，重建专用编码器 ℓ1 更低。（表 1；附录 S2）
- 下游 LIBERO 冻结视觉 token 的策略平均成功率：原生文字塔条件下 ALPS **85.5%**、SigLIP 2 **84.8%**；统一 BERT 条件下 ALPS **83.4%**。世界模型规划：PushT **90%**、Wall **92%**、Granular Chamfer **0.176**，领先或并列；Reacher **78.7%** 低于 DINOv3 的 86.0%，Rope **0.750** 劣于 C-RADIOv3 的 0.558。5 步预测的状态读出相对 Stage 1 在多任务改善，但并非各任务最优。（表 2–4）
- 10% 训练预算的目标消融显示：去重建改善状态误差却使像素重建 ℓ1 从 **0.113 恶化至 0.194**，存在明确容量取舍；去密集对应使跨视角 patch 匹配从 **37.4% 降至 31.4%**，但全局指标变化很小。（表 5；附录 S4）

## Value
说明世界模型视觉表征应同时评估可预测状态、语言检索和未来帧可渲染性，而不能用单一图像分类或重建分数选编码器。对设计 JEPA 式潜状态及多模态规划接口有直接参考，值得精读。

## Strengths
统一冻结编码器比较与多个下游任务；区分当前状态探针和真正的世界模型预测/规划；分析状态、语言、像素之间的取舍，并检验对现有图文编码器直接蒸馏的失败；提供中间层和强解码器控制实验。

## Weaknesses
预训练成本极高且仅 ViT-B，缺少规模效率分析；无视频/动作监督，细粒度时间动作识别仍弱（SSv2 55.6%）；机器人结果局限仿真；多任务规划收益不一致；轻量探针读数不能直接归因于世界模型长期预测质量；语言、状态、像素接口尚未在同一个端到端规划系统中同时验证。（正文 §5–6；附录 S2）

## Future Work
作者提出测试更大模型与真实机器人，把跨视角精炼并入单阶段训练，加入视频/交互数据改善时间敏感动作，并构建语言引导、像素可核验的统一规划器。（正文 §6）

## Rating
创新度评分：3/5 - 多目标预训练加几何自蒸馏的组合有实证价值，但技术组件多取自现有方法，且下游优势并不普遍。
相关度评分：3/3 (Core) - 直接面向潜空间世界模型的视觉状态表征、预测和规划。

## TL;DR
以双阶段静态图像预训练统一状态、语言和可解码像素表征，并验证世界模型迁移；表征设计值得精读。
