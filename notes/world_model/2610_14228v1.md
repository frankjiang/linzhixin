# Latent World Action Model for GUI Agents

## Insight
GUI 转移常导致屏幕大改，像素级下一屏生成既昂贵又容易复制当前屏幕形成“恒等捷径”；决策只需辨别动作后果。作者以潜在下一状态监督动作评分，并把当前屏幕和其他转移作负样本；AndroidWorld 中过渡头与对比损失各带来约 1.8、2.0 个成功率点。

## Motivation
现有 GUI 世界模型多先生成截图或 HTML，再交给智能体二次识别，计算慢且重建大量与选择动作无关的外观。目标是以轻量潜态预测让 GUI 智能体预估候选动作后果。

## Method
冻结 GUI 智能体提出三个候选动作；LoRA 微调 Qwen3-VL-8B 形成动作条件共享表征。动作头用标注动作交叉熵训练打分，转移头预测真实下一截图视觉嵌入，用 InfoNCE 拉近真实未来、排斥当前状态及负样本。推理时丢弃转移头，低置信门控才调用单次候选重排。创新主要是将预测监督对齐决策相关潜态，并用动作对比减轻恒等捷径。

## Experiment
离线 AndroidControl/AITZ 与在线 AndroidWorld 比较基础智能体、Code2World、Diffusion2Image；另测 GUI-Odyssey 分布外。AndroidWorld 上 Qwen3-VL-8B 总成功率 27.68%→40.18%，Code2World 28.57%、扩散 33.93%；运行时间 223.8s，对比扩散 789.9s。消融基础 27.68%、仅动作头 36.36%、加余弦转移 38.18%、加对比 40.18%。五种骨干在线均提升，但离线坐标 Grounding 改善不一致；表征 t-SNE 显示动作类型更可分。

## Value
“预测决策相关未来特征，而非重建所有像素”的取舍可启发隐式模型；但任务是手机 GUI，缺少自然视频、3D 物理与连续动作，研究相关性有限。

## Strengths
对像素生成的恒等捷径有明确观察；相同候选集比较且提供过渡/对比消融；在线任务和运行时间共同评价。

## Weaknesses
依赖基础智能体提出正确候选，潜态重排无法修复候选坐标；转移头推理时丢弃，因此实际规划仅一步排序，未验证多步动力学质量；GUI 结果难直接迁移到物理世界模型。

## Future Work
作者未列具体方案；可检验潜态预测的多步校准、候选覆盖不足与跨应用鲁棒性。

## Rating
创新度评分：2/5 - 潜态预测、候选排序与 InfoNCE 的组合有效，但技术增量有限。
相关度评分：1/3 (Tangential) - 隐式预测思想可借鉴，场景与视频/3D物理世界模型相距较远。

## TL;DR
用对比式潜态未来监督重排GUI候选动作，省去下一屏生成并提升任务成功率；本方向可选读。
