# NVIDIA OmniDreams: Real-Time Generative World Model for Closed-Loop Autonomous Vehicle Simulation

## Insight
基于大规模预训练扩散模型的视频世界模型可以实现实时、action-conditioned的自回归视频生成，构建闭环自动驾驶仿真器，并具备作为策略模型backbone的潜力。

## Motivation
重建式神经仿真器（如NeRF/3DGS-based）受限于初始捕获数据，难以泛化到高动态或新场景（如极端天气、不可预测的agent行为）。生成式世界模型可以合成超出训练分布的场景，但需要解决实时性和闭环一致性问题。

## Method
- 从 **Cosmos 扩散模型** mid-train 和 post-train
- **21k小时**驾驶场景数据
- **自回归因果生成**：每步生成conditioned on过去帧、当前仿真状态和驾驶动作
- **KV cache** 加速自回归推理
- **GB300 上 68 FPS** 单视角实时生成
- 与 **AlpaSim** 编排器和 **Alpamayo 1** 策略模型闭环集成
- 同时展示 WAM post-training：从OmniDreams出发训练world-action model

## Experiment
- 实时 68 FPS 单视角生成
- 可合成极端天气、不可预测动态行为等传统仿真器难以构建的场景
- 闭环仿真中驾驶策略能正确响应生成的场景变化
- **WAM variant** 在NuRec数据集上超越 Alpamayo 1.5 VLA，且参数量仅为1/5
- 工业级实现，展示了完整的从预训练到闭环部署的pipeline

## Value
工业级视频世界模型的标杆工作。实时性（68 FPS）和闭环集成是重要的工程突破。WAM post-training展示了世界模型作为策略backbone的方向。但论文更偏技术报告/系统描述，理论创新有限。
