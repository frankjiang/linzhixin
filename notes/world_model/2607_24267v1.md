# FeelWorld: Visuo-Tactile World Model for Hierarchical Contact Prediction and Planning

## Insight
有。论文的核心 observation 是：接触任务里视觉变化可能仍然“看起来合理”，但真实物理成败由接触、局部形变和滑移决定；触觉在 free-space 阶段又多是噪声。推论是世界模型应分层预测触觉状态，并只在预测发生接触时让触觉调制视觉 dynamics。

## Motivation
论文解决 contact-rich manipulation 中视觉世界模型缺少触觉物理约束的问题。Dreamer/V-JEPA 类模型可以在 latent 中想象未来，但纯视觉很难判断抓稳、插入、滑移等状态；已有 visuo-tactile 方法常把触觉当单一目标，缺少状态层次和选择性融合。这是机器人世界模型中的关键问题。

## Method
FeelWorld 输入多视角 RGB、3D tactile point clouds 和动作，冻结视觉 encoder 与 FG-CLTP tactile encoder，将未来预测组织为四类监督：visual latent、contact state、3D tactile latent、slip state。触觉状态是层级的：contact 决定是否融合，3D tactile latent 表示局部接触几何/力相关信息，slip 参与规划代价。

关键机制是 contact-gated asymmetric attention：tactile token 先 attend 到 visual token 以获得全局上下文；visual token 只有在 contact gate 打开时才 attend 到 tactile feature，避免 free-space tactile noise 污染视觉预测。训练包括 teacher-forcing loss、autoregressive rollout loss 和 context noise injection。规划使用 contact-aware CEM，对候选动作 rollout 计算视觉目标距离；接触后再加入 tactile latent 距离和 slip penalty。

## Experiment
平台是 Imeta-Y1 机器人，三路 RGB 相机和 DM tactile sensors；任务包括 chip grasping、fruit grasping、USB insertion。10-step 预测中，V-JEPA 2 visual-only 的 PSNR/SSIM/LPIPS/FVD 为 24.37/0.819/0.084/473.5，FeelWorld 为 28.89/0.884/0.058/289.9，contact F1 0.981、slip F1 0.834。去掉 hierarchy 或 contact gate 都退化。

长程 80-step autoregressive rollout 中，FeelWorld 的 LPIPS 从 0.055 到 0.062，较 visual-only 低 61%。接触转场阶段 LPIPS 0.055，显著低于 V-JEPA 2 的 0.127，contact onset error 0.44 帧 vs 1.17 帧。零样本 CEM 规划 40 次真实 trial：visual-only CEM 在 chip/fruit/USB 上为 40.0/70.0/37.5，naive VT 为 47.5/75.0/50.0，contact-aware CEM 为 82.5/87.5/75.0，平均 81.7%。

## Value
价值高：它把触觉从附加观测提升为世界模型要显式预测的物理状态，并给出可用于 model-based planning 的接口。对我们启发是，视频世界模型不应只优化视觉重建；应把任务关键隐变量作为分层 latent/state supervision，并设计条件融合避免无关模态干扰。

## Strengths
分层触觉状态建模合理；contact gate 机制简单有效；同时评估预测质量、长程 rollout 和真实机器人 CEM；消融能支持触觉、hierarchy、gate 的作用。

## Weaknesses
任务和平台规模有限；CEM 每轮采样 400 条、6 步 horizon，计算较重，不适合高频控制；触觉 encoder 和传感器依赖强；slip 正样本极少，F1 结果需要更多数据验证。

## Future Work
作者提出未来把 FeelWorld 与 policy network 结合，用于高效评估候选 rollout，并通过真实交互数据迭代优化，降低 CEM 规划开销。

## Rating
创新度评分：3/5 - 分层触觉世界模型和 contact-gated fusion 有实质贡献，但仍是现有 latent WM/CEM 框架上的组合改进。
相关度评分：3/3 (Core) - 直接研究机器人 action-conditioned visuo-tactile 世界模型和规划。

## TL;DR
将触觉分层纳入视觉世界模型并用于接触感知CEM规划，核心相关，值得精读。
