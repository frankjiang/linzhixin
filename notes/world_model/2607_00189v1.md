# VOCA: Visual Odometry with Codec Awareness

## Insight
无世界模型层面的核心 insight；主要工程 insight 是视频编码器的 motion vectors 虽然不是可靠 optical flow，但可作为 KLT tracking 的初始化 prior，尤其在压缩视频和大位移场景中能让优化落入正确收敛盆。压缩信息不是噪声副产物，而是可复用的视觉几何信号。

## Motivation
3D/空间世界模型和机器人系统需要相机位姿，但现实视频大多被 H.264 等压缩；传统 VO/SLAM 基准多假设未压缩图像，压缩 artifact 会破坏 photometric constancy。论文目标是在 compress-then-analyze pipeline 下恢复 VO 性能。与 3D世界模型基础设施相关，但不是世界模型论文。

## Method
VOCA 基于 Basalt 的 causal stereo VO/KLT tracking。作者先分析 block-based codec：P-frame 的 motion vector 指向参考帧中用于预测当前 block 的区域，取负后可粗略近似 forward optical flow。方法将 motion vector 初始化 KLT 的 SE(2) patch translation，旋转仍由 KLT 优化；I-frame 没有 motion vector 时复用最近 P-frame 的向量做 bridge。为避免错误 motion vector 或动态物体导致 outlier，同时运行有 MV prior 和无 prior 两种 tracking，若两者都成功但结果不一致则拒绝该点。

## Experiment
在 EuRoC、TUM-VI room、Monado SLAM Dataset 上评估压缩视频，主要指标为 ATE 和 RTE，并与 ORB-SLAM3、OKVIS2、MoV-SLAM、Basalt 对比。EuRoC 上相对 Basalt 平均 RTE 改善约 15%、ATE 改善约 10%；TUM-VI 上 Basalt 在 TR5 ATE 54.5cm，VOCA 7.7cm。MSD 最难，VOCA 相对次优方法 median ATE 提升 37%、median RTE 提升 40%、ATE success rate 提升 13 个百分点。消融显示并行 MV||OF 加 I-frame bridging 整体最好；500kbps 约 100x 压缩下仍较稳定。

## Value
对世界模型主线的价值偏基础设施：若要从大规模互联网压缩视频学习 3D/空间世界模型，codec metadata 可能能提升 pose/geometry estimation，减少存储带宽负担。但论文没有 learned dynamics、未来预测或生成建模，相关度较低。可作为构建视频数据管线和位姿估计模块的参考。
