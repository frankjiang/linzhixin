# Beyond Large Language Models: A Mental World Model Framework for Mental Modeling, Simulation, Evolution, and Interpretability

## Insight
无与视频、3D 或 JEPA/Dreamer 世界模型相关的核心 insight。论文的观察是同一事件因个人经历产生不同心理解释，于是显式保留多条主观解释分支和历史偏置；证据来自心智推理题准确率，而非视觉动力学实验或形式证明。

## Motivation
面向 Theory of Mind 与心理状态预测：直接用语言模型推断情绪、意图时，事件间的主观解释和历史影响不易追踪。对社会认知任务有意义，但不涉及用户关注的环境建模、视频生成、三维状态或视觉控制。

## Method
MMEA 从文本事件抽取事实，生成 Self Fix/Object Fix 组合，最多保留三条主观世界分支；各分支计算认知评价与 40 维心理因素，再按分支概率汇总行为候选。历史 Cognitive Bias 影响新事件的解释，Mental Inertia 用人工设定的衰减权重融合旧心理状态；整个框架仍依赖 LLM 执行主观世界构建与推理。主要是规则化心理推理流程及多分支汇总，不是从视觉序列学习状态转移的世界模型。

## Experiment
在 DynToM 1,420 题与 RecToM 400 题上报告准确率 96.48% 和 94.00%，相应最佳通用 LLM 为 84.35% 和 89.50%；DynToM 的 Why 子任务为 97.50% 对 43.75%。自建连续事件实验报告预测准确率 95.0% 对 73.8%、最长连续正确比例 92.9% 对 66.7%、全程正确轨迹比例 83.3% 对 16.7%；隐式心理状态 PWTS 为 81.92% 对 70.25%。去掉 Self Fix/Object Fix 后，连续事件预测准确率从 95.0% 降至 62.0%。这些指标均为语言与心理推理，非视频/物理世界模型评测。

## Value
可作为显式历史偏置与多假设推理的跨领域类比；对本团队的视频、3D 和隐式动力学建模几乎没有直接方法价值，无需投入精读时间。

## Strengths
将事件解释、心理因素、历史偏置与行为预测拆成可追踪的中间环节；公开心智基准与部件消融提供了初步验证。

## Weaknesses
“世界”指人的主观心理世界，不能据此判为视频或隐式世界模型。关键评分权重、分支截断和惯性衰减多为人工设定；自建实验的规模、标注可靠性、提示与计算成本交代不足，且没有证明中间心理变量真实可识别。仍高度依赖外部 LLM。

## Future Work
作者提出学习 Self Fix、Object Fix、Cognitive Fixation 和心理状态的神经表示及内部转移机制，减少对 LLM 推理的依赖与时延。

## Rating
创新度评分：1/5 - 对目标研究方向没有新技术贡献；总体上也是规则和 LLM 推理模块的组合。
相关度评分：0/3 (Noise) - 纯文本心智理论与心理行为预测，不研究视频、3D 或 JEPA/Dreamer 式环境动力学。

## TL;DR
以多分支心理状态和人工历史规则预测文本人物行为，与视觉世界模型方向无实质关联，可跳过。
