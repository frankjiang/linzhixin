# WAM-Sim0.1: World Anchored Memory Meets Online RL for Consistent and Realistic Driving Simulation

## Insight
观察到长时驾驶视频的道路、背景与车辆身份分别以不同时间尺度漂移；推论是单纯延长视频上下文不如维护具有不同读写规则的持久状态。作者把道路、地理场景、跟踪目标拆成三级记忆，并用消融验证：场景记忆将 Scene Similarity 从 0.852 提至 0.904，目标记忆将 Subject Coherence 从 0.646 提至 0.680；合用达到 0.910/0.681。这是经验支持，不是理论证明。

## Motivation
自回归驾驶世界模型依赖逐帧 HD 地图、3D 框或近期图像，长时生成时结构、身份及画质会累积退化；已有检索或对象注意力方法通常只处理一个层面。分钟级可控仿真需要同时保持道路拓扑、地点外观与交通参与者身份，是有价值的核心问题。

## Method
基于预训练 OmniDreams 的 3D DiT，以 93 帧为一个生成块。HD 地图编码为与姿态对齐的结构 latent 并加到视频 latent；按 GPS 与朝向检索地理参考帧，作为只读场景 token 通过分段 cross-attention 注入；按 track ID 存首次可见目标的外观 crop，写一次、后续跨遮挡用实例掩码注意力读取。随后 Drive DiffusionNFT 在自生成轨迹上以场景画质、目标可识别性、VLM 物理合理性三种奖励做在线 flow-matching 优化。创新在三级状态的持久性与读写语义，奖励优化本身更多是已有方法的适配。

## Experiment
nuScenes 验证集：FID 3.47、FVD 25.72、3D 检测 mAP 24.16、道路 BEV mIoU 71.23；该数据无地理参考库，因此**没有启用场景记忆**，各方法生成分辨率也不同。自采约 1000 小时数据的 350 条长片段中，FID/FVD 为 10.95/74.20，Scene Similarity 0.910、Subject Coherence 0.681，均优于表中对照。10→60 秒消融中，无场景/实例记忆的主体一致性 0.535→0.322，有记忆为 0.584→0.547；奖励消融使 Subject Fidelity 41.74→44.00、物理合理性 50.91→55.96。另有 60 个场景、15 名专家的主观评测与遮挡重现评测；后者的最长遮挡分组仅 3 个有效事件。

## Value
适合研究长时视频世界模型的“状态如何跨生成块保真”，尤其可借鉴按语义层级设计持久性与读取掩码。尚未证明无需地图、GPS、track ID、参考图时仍能维持同等效果，也未展示闭环驾驶收益。

## Strengths
将道路、背景、实例的存储规则和查询域明确对应；既测视觉指标也测下游感知、时间退化、遮挡重现和人评；将记忆与奖励项分别消融。

## Weaknesses
高度依赖 HD 地图、地理参考、3D 框和追踪 ID，成本高；主表跨模型分辨率及训练数据不同，因果比较需看消融；NuScenes 不含完整三级记忆；长遮挡样本很少，真实闭环物理有效性仍未验证；3.1B 参数比初始骨干的 2.0B 大。

## Future Work
作者提出将在线更新的 3D Gaussian Splatting/NeRF 纳入记忆以加强多视角及反事实几何；允许选择性更新目标状态；通过实例分组与压缩控制密集交通时的记忆开销。

## Rating
创新度评分：3/5 - 三级持久记忆设计有实用新意，但组件和在线奖励优化主要是组合。
相关度评分：3/3 (Core) - 直接研究长时、可控视频驾驶世界模型。

## TL;DR
以道路、场景和目标三级持久记忆配合在线奖励优化，缓解长时驾驶视频漂移；研究世界状态设计值得精读。
