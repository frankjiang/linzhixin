# IA-JEPA: Interaction-Aware Joint-Embedding Predictive Architecture

## Insight
标准JEPA的随机masking策略对所有区域一视同仁，但物理世界中物体间的交互区域（碰撞、接触）包含最丰富的因果信息。IA-JEPA提出以物理交互为中心的masking策略，优先mask交互区域，迫使模型学习物理因果关系。

## Motivation
V-JEPA在物理推理任务上表现有限，因为随机masking更多地覆盖静态背景而非关键交互区域。论文认为交互区域是学习物理直觉的关键，通过引导masking策略聚焦于这些区域可以显著提升因果推理能力。

## Method
- **Motion-centric masking**：利用光流计算运动热力图，优先mask高运动量区域（即交互区域）
- **Interaction scoring**：基于帧间像素差分的运动分数，加权采样mask位置
- **架构**：基于V-JEPA框架，使用Lightweight ViT（ViT-Tiny/Small）
- **预训练**：在CLEVRER数据集（合成物理场景，碰撞/滚动/遮挡）上自监督预训练
- **下游评估**：CLEVRER因果推理QA、物理事件检测

## Experiment
- **因果推理**：CLEVRER上14.26%准确率 vs V-JEPA baseline 3.22%（随机masking），提升显著但绝对水平偏低
- **物理事件检测**：碰撞检测82.1%，遮挡检测61.5%
- **Masking策略对比**：motion-centric > random > block masking，验证了交互聚焦假设
- 实验规模受限：96x96分辨率，Lightweight ViT，仅CLEVRER数据集
- 单作者工作，使用Gemini 3 Pro辅助

## Value
idea有意义：将masking策略与物理交互关联是合理的研究方向，与JEPA世界模型的发展相关。但实验规模太小（合成数据、tiny模型、低分辨率），convincingness不足。14.26%的因果推理准确率虽然相对提升大，绝对值仍然很低。需要在更大规模、更复杂场景上验证。
