# What Does World Modeling Actually Improve in Robot Action Learning?

## Insight
观察：在相同架构、初始化、训练数据与步数下，增加未来视频预测损失可大幅提升已见任务成功率；但任务和环境变化时收益显著缩小或消失。推论：预测监督能改善熟悉条件下的动作执行，却不能由此推出学到了可迁移的世界动力学。作者通过 FastWAM/OpenWAM 配对损失消融、轨迹簇内成功率和 Seen/Unseen×Clean/Randomized 评测支持；轨迹聚类是描述性分析，不能识别内部因果机制。

## Motivation
世界动作模型常把未来视频生成与动作学习联合训练，只报告总成功率，难辨预测损失本身、生成器规模和分布外泛化各自作用。Fast-WAM 等已有单系统消融，论文进一步以两模型家族和环境变化测量预测监督的适用边界，对 WAM/VLA 训练目标与评测很重要。

## Method
- 在 FastWAM 与 OpenWAM 内保持架构、参数数目、冻结方式、初始化、机器人演示和训练步数，比较 `L_action + λ_video L_video` 的 λ=0/1。λ=0 只关闭预测损失，世界模型架构仍在，故检验的是**监督目标增益**，不是删除世界模型的效果。
- RoboTwin 2.0 双臂数据训练；已见/未见任务、干净/环境随机化构成四格评测。对五项任务汇总数值轨迹特征，任务内合并两变体后 K-means 聚类，比较簇频率和簇内成功率，不把聚类直接解释为控制策略。
- 在 π0.5 上增设仅训练时使用的未来视频潜变量预测头：随机初始化六层 512 维 Transformer 以共享 VLM 前缀为条件，经冻结 Wan2.2 VAE 提供监督；另与可训练的预训练 Wan2.2-TI2V-5B DiT 预测头比较。预测损失更新视觉/共享前缀，动作专家只受动作损失更新；部署时移除预测头。

## Experiment
- 已见干净的十任务：FastWAM 无/有视频损失成功率 14.97%/39.34%（+24.38 点），OpenWAM 为 7.00%/79.91%（+72.91 点）；各配置 3200 次 rollout。FastWAM 在两项任务小幅退化，OpenWAM 十项皆升。
- 行为分析中，FastWAM `stack blocks two` 主簇占比约 90% 不变，簇内成功率从 50.2% 至 89.5%；说明收益不只来自粗轨迹类型频率变化。分布变化时，未见干净任务 FastWAM 仅 +0.28 点，OpenWAM +23.38 点且集中于少数任务；随机化条件下各模型成功率最高仅 3.22%，无稳定预测监督优势。
- π0.5 十项已见任务同一初始场景与动作噪声、各 3200 次 rollout：原版 82.94%，轻量预测头 89.19%，Wan DiT 头 86.97%；轻量对原版的配对 scene bootstrap 95% 区间为 +2.31 至 +10.31 点。轻量与 Wan 之差未达可靠显著性；两头的初始化、调度和损失权重也不同，不能归因于参数规模。

## Value
对团队最有用的是实验范式：用同架构只换预测损失，分别报告已见任务执行、未见任务、环境随机化、轨迹行为和训练代价；即使创新度不高也值得精读。设计上可考虑把轻量潜视频预测当训练期辅助目标，但需单独证明它带来真正鲁棒性或可规划动力学。

## Strengths
控制变量清楚，跨两种 WAM 复验；分布外四格表避免把已见任务增益误认作泛化；π0.5 配对场景 bootstrap 与完整逐任务数据较透明；主动说明视频大模型比较不构成严格规模消融。

## Weaknesses
每配置仅一个训练种子，大量 rollout 不能代替训练稳定性；随机化任务几乎全失败，地板效应使鲁棒性结论受限；轨迹簇可能捕捉场景几何而非控制机制，缺动作精度或接触指标。轻量头仍依赖预训练 Wan VAE，且未系统报告训练 FLOPs、显存与延迟；仅仿真双臂任务，未证真实机器人或其他具身泛化。

## Future Work
作者提出更细粒度的行为测量与针对性干预，以定位预测监督的作用机制；比较训练成本和部署效率，研究预测目标表征选择，并扩展至真实机器人、更多具身形态和更大训练规模，解决分布外泛化。

## Rating
创新度评分：3/5 - 主要是受控实证与轻量辅助头，方法增量，但揭示已见任务收益和迁移能力的关键区别。
相关度评分：3/3 (Core) - 直接评估视频世界建模监督对机器人动作学习的作用与局限。

## TL;DR
未来视频预测损失显著提升已见任务执行，却未带来稳定分布外收益；轻量训练期预测头也有效，评测设计值得精读。
