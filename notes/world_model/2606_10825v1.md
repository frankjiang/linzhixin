# MODIP: Efficient Model-Based Optimization for Diffusion Policies

## Insight
Observation: Diffusion Policy (DP) 因多步去噪生成动作，直接用 RL 微调面临两个效率瓶颈——(1) 规划时需要在每个终端状态调用 DP 计算 Q(s, pi(s))，推理代价高；(2) critic 训练时 TD target 依赖当前策略，需反复运行去噪过程。

推论：可以**绕开直接优化 DP 参数**，转而用 MPC 在 latent world model 中生成改进轨迹，再通过标准 BC loss 蒸馏回 DP。同时用纯状态价值 V(s) 替代 Q(s, pi(s)) 作为终端估计，将 critic 学习与策略完全解耦。

验证：消融实验表明 V(s) 比 Q(s, pi(s)) 在所有任务上更优且推理加速 2.9x；policy-independent critic 将总训练时间从 ~40h 降至 ~25h（1.6x）。

## Motivation
**问题**：Diffusion Policy 在模仿学习中表现出色（多模态动作分布建模），但受限于演示数据质量，无法超越数据本身。直接用 RL 微调 DP 困难重重：多步去噪使策略优化不稳定，且计算代价高昂。

**同行方案**：
- Diffusion-QL / EDP / DPPO：直接在 DP 上施加 RL 目标（Q-learning / policy gradient），但训练不稳定或开销大
- DSRL：在 latent noise space 做 RL，间接适配 DP
- PA-RL：用 critic 优化候选动作后蒸馏回策略，但基于单步 critic 而非轨迹规划
- TD-MPC2：强 model-based baseline，但使用高斯 MLP 策略而非 DP

**是否关键**：是工程/效率层面的实际问题，但非根本性科学问题。核心贡献在于"如何高效地将 model-based planning 的收益蒸馏进 diffusion policy"，属于方法组合创新。

## Method
**整体管线**（两阶段）：
1. **离线预训练**：用离线数据训练 DP（BC loss）+ latent world model（encoder h_eta, dynamics f_theta, reward R_xi）+ terminal value V_psi
2. **在线微调**：DP-guided MPC planner 在 latent space 中生成改进轨迹 -> 存入 online buffer -> 混合离线/在线数据用 BC loss 蒸馏回 DP，形成迭代改进循环

**关键技术细节**：
- **Hybrid MPC Planning**：MPPI 采样时，部分候选序列由 DP 生成（多模态 prior），部分随机采样；在 latent dynamics 中 rollout 并用 reward + terminal V(s) 打分
- **Terminal State Value V(s)**：替代传统的 Q(s, pi(s))，避免在规划时调用 DP 去噪（单次前向 vs 多步去噪），推理加速 ~3x
- **Policy-independent Critic**：TD target 用 V(s') 而非 Q(s', pi(s'))，完全去除 critic 更新对 DP 的依赖。借鉴 IQL/AFU 思路，用 value-advantage 分解恢复 Q 值
- **正则化**：在线训练时混合 MPC 轨迹动作和预训练策略动作的 BC loss，退火系数 lambda(t) 逐步减小正则项
- **混合比例 beta(t)**：在线数据占比随训练递增，初期锚定离线数据保稳定

**创新程度**：中等。核心思路（MPC 生成好轨迹 + BC 蒸馏）并非全新，PA-RL 已有类似框架；V(s) 替代 Q(s,pi(s)) 是针对 DP 推理特性的合理工程改进。贡献主要在于将多个已知技巧（TD-MPC 式 world model、MPPI、policy-independent critic、DP prior）有效整合。

## Experiment
**Benchmark**：D4RL MuJoCo（HalfCheetah/Walker2d/Hopper）、D4RL Kitchen（Complete/Partial）、RoboMimic（Lift/Can/Square）

**Baselines**：BC、DQL、DSRL、DPPO、PA-RL（DP 微调方向）、TD-MPC2（model-based 方向）

**主要结果**：
- MuJoCo：MODIP 在三个任务上均超过 TD-MPC2，HalfCheetah 上（13775）与 PA-RL（14254）接近
- Kitchen：MODIP 在 Complete（0.94）和 Partial（0.98）上均为最优，长视野稀疏奖励任务优势明显
- RoboMimic：与最强 DP baseline 竞争力相当（Lift 0.98, Can 0.92），Square 上不及 DSRL（0.90 vs 0.85）

**消融实验**（Table 2）：
- Hybrid planning vs policy-only：MPC 规划在 HalfCheetah/Kitchen 上带来显著提升
- V(s) vs Q(s,pi(s))：V(s) 在所有任务上更优（性能+效率双赢）
- DP prior vs MLP prior：DP 先验在所有任务上优于高斯 MLP
- 离线预训练：对 MuJoCo/Kitchen-Complete 提升大

**效率**（Table 3-4）：V(s) 推理加速 2.9x；policy-independent critic 总训练加速 1.6x

## Value
**工作价值**：提供了一个将 model-based planning 收益高效注入 diffusion policy 的实用框架。对于需要用 DP 做机器人控制且希望超越纯模仿学习的场景有参考意义。

**启发**：
- "不直接优化难优化的模型，而是用更强的 planner 生成好数据再蒸馏"是一种通用思路，可迁移到其他生成式策略（如 flow matching policy）
- World model 在此处仅作为 planner 内部的"评分器"，并非用于想象训练（Dreamer 式），是 world model 的一种"轻量级"使用范式

**局限**：
- 所有实验均基于低维状态输入，未验证视觉观测（像素输入）的效果
- World model 是简单的 latent MLP dynamics（TD-MPC 风格），未探索更强的 world model 架构
- 在线微调仍需大量环境交互
