# WoVR+: World Model as Reliable Simulator for Versatile VLA Policy Optimization with RL

来源说明：原始 PDF 当前不可用（arXiv 返回 404），依据 arXiv HTML 全文阅读。
## Insight
观察：把生成世界模型当 VLA 强化学习环境时，长时误差、动作分布漂移及后期任务阶段样本稀缺会相互放大。推论：世界模型需对多视角几何与动作响应可靠，训练宜从各阶段真实记录的入口开始做局部想象。四阶段打包任务中，均匀阶段采样使最终成功率从 SFT 的 30% 和全程想象的 50% 升至 75%；长前缀预测被观察到高估后期完成率。

## Motivation
现实机器人在线 RL 成本高，已有 WoVR 用动作条件视频模型做想象训练，但单视角、短任务和简单探索难支撑多视角双臂及长链条操作。世界模型是否真的可作策略优化的可靠模拟器，是具身视频世界模型的关键问题。

## Method
在 WoVR 的首帧锚定、关键帧重置和模型/策略再对齐上，新增三部分：其一，用正向运动学把绝对关节动作投影到各相机的末端位姿 action map，并直接在视频潜变量网格加入相机 raymap 和视角标识，以 Wan2.2/VACE 控制分支训练多视角流匹配视频模型；稀疏历史、局部模糊和时间步长采样增强自回归鲁棒性。其二，Flow-SDE 对同一动作块各时刻共享噪声，保持边缘噪声强度而减少高频抖动，以 GRPO 更新策略。其三，从数据支持的各任务阶段入口重置，配局部奖励和均匀阶段采样做短程想象；部署仍执行同一个完整策略。贡献以系统整合和交互训练协议为主。

## Experiment
RoboTwin 50 任务的留出视频中，5 步 WoVR+ 头视角 LPIPS 0.148、FVD 62.16；WoVR 三视角版为 0.231/109.33，腕视角也改善。实机六组策略的模型内/实机成功率相关性 Pearson 0.97；想象监督后固定重置成功率 71.0%→91.0%。块共享噪声在 RoboTwin 两任务比独立噪声更稳；六个实机任务经 50 次纯想象 RL 更新后平均成功率 39.2%→55.8%（每任务 20 次测试）。四阶段 Phone Packaging 的终局成功率：SFT 30%、全程奖励 50%、全程分阶段奖励 55%、均匀阶段重置 75%；局部训练每小时有效组数 47.6 对 30.1。

## Value
提出较完整的“预测质量→策略排序一致性→想象优化→真实执行”证据链，对视频世界模型作模拟器的评估极有参考价值；尤其值得研究多视角几何条件和阶段重置如何抑制模型误差。

## Strengths
比较动作诱发分布偏移下的预测，而不只看示教视频；实机验证模型排序与 RL 收益；将后期阶段样本访问、奖励稀疏和生成前缀误差分别拆开实验。

## Weaknesses
共享噪声改变动作块联合分布，但仍使用逐 token 高斯比率，论文承认其不是精确联合似然比；实机每任务仅 20 次评估。阶段边界与奖励需人工设计并依赖数据支持的重置状态；大骨干和多模块让单项增益的泛化边界仍不清楚。

## Future Work
论文未给出明确的后续议程；值得进一步研究精确相关噪声策略比率、自动阶段划分、模型不确定性门控，以及更长真实闭环任务中的模型偏差。

## Rating
创新度评分：3/5 - 多视角几何模型、块相关探索和阶段局部 RL 组合有效，但多依托已有 WoVR、VACE 与 GRPO 框架。
相关度评分：3/3 (Core) - 直接研究动作条件视频世界模型作为机器人策略优化模拟器。

## TL;DR
用多视角几何条件、连贯动作探索及阶段重置提高世界模型想象训练的真实机器人收益；评测链条值得精读。
