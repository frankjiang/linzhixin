# AdaJEPA: An Adaptive Latent World Model

## Insight
主要 insight 是：latent world model 不应在部署时冻结。观察是 MPC 每一步都会得到真实转移，如果世界模型预测偏了，下一轮规划仍基于错误 latent rollout；因此可以把执行后的转移作为自监督信号，在闭环中持续校准 JEPA。论文证明不是靠额外监督，而是同一个 latent prediction loss 做 test-time adaptation，少量梯度步即可改善规划。

## Motivation
论文解决 JEPA/latent world model 在测试分布偏移下规划失败的问题。同行通常离线训练 encoder/predictor，测试时冻结模型，只用 MPC/CEM/GD 在 latent 中找动作序列。这会在视觉扰动、物理参数变化、新形状/新布局下累积预测误差。问题非常关键，因为隐式世界模型若无法在线校准，很难进入真实闭环控制。

## Method
AdaJEPA 包含 sensory encoder、action encoder 和 latent predictor。测试时按 plan-execute-adapt-replan 循环：用当前模型做 MPC，执行第一个 action chunk，观测下一状态，把转移加入小 replay buffer，再用 JEPA 的 latent prediction loss 更新少量参数。默认只更新视觉 encoder 和 predictor 的最后层，buffer 保留最近 5 个样本，每次重规划只做 1 个梯度步。方法本身很简单，但把 JEPA 世界模型、MPC 和 test-time adaptation 合成一个闭环，概念上比较重要。

## Experiment
实验覆盖 PushT/PushObj 和 PointMaze。分布偏移包括 unseen shapes、blur/salt-pepper/dark/color shift、低质量/高阻尼 dynamics shift、unseen maze layouts。AdaJEPA 在 ID 和 OOD 下普遍提高 GD/CEM 规划成功率；unseen PushObj 上接近翻倍，PointMaze unseen layout 上 GD 从 53.3 提升到 66.0 或 78.7，CEM 从 49.3 提升到 55.3 或 70.7。跨不同 JEPA 实现的表格显示成功率稳定提升，而每次 replanning 只增加约 0.01-0.03s。消融比较了更新层、LoRA、学习率、步数、buffer，结论是简单 selected-layer update 已足够强。

## Value
这是隐式世界模型方向很值得读的工作。启发是：世界模型的价值不只是离线预测，还可以把“行动产生的数据”变成即时校准信号；对真实机器人、视觉控制、JEPA/Dreamer 类方法都有直接借鉴。待解决问题是适应能力受预训练表示覆盖范围限制，偏移太大时轻量更新无法补齐缺失特征；还需要研究长期 continual learning 和防止在线漂移。
