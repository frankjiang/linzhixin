# Real-Time Human-Centric World Modeling for Upper-Body Human-Object Interaction

## Insight
有。论文的 observation 是：上半身交互视频中，人的连续运动和人与物体的接触关系是两类不同控制变量；把二者都塞进自由文本提示会导致运动和交互语义纠缠。推论是用连续 human-state latent 控运动，用离散 interaction-state command 控接触状态，可以更稳定地产生人-物交互局部世界变化，并支持实时切换。

## Motivation
论文解决 human video generation 只复现人体动作、不显式建模物体交互和局部场景变化的问题。已有 motion-driven 方法偏人体动画，text-to-video 可生成交互但控制粗糙且不实时；interactive world model 多以视角控制为主，缺少细粒度人体和接触状态控制。该问题与视频世界模型相关，但更偏生成式人像/交互视频，而非机器人规划。

## Method
框架把生成条件拆成参考人物图、物体图、driving motion、离散 interaction state。Human State 模块用 multi-scale motion encoding，从上半身、左手、右手、脸部区域分别提取隐式 motion latent，再与 reference image patch 融合，得到身份对齐的连续人体状态 `s_h`。

Interaction State 模块把接触关系表示为固定短文本状态集合 `{no contact, grasp}`，用 T5 编码，不作为开放 prompt，而是离散状态命令。数据上作者用 Z-Image/Qwen-VL/Qwen3/Wan2.2 构造并过滤 30K+ synthetic human-object interaction samples。训练分两阶段：先用 300 万上半身视频学习 human-state representation，再冻结 motion encoder，在交互数据上学习 object/reference/state 条件生成。推理用 CausVid 和 Self-Forcing，把采样步从 20 降到 4，实现 512x512 25 FPS、约 1000 ms latency。

## Experiment
对比 Wan-Animate、Wan2.2-TI2V-5B、Humo、MAI、VACE。指标包括 FVD、tLPIPS、CLIP-I、Object Quality、HandSIM、FaceSIM、IdentitySIM，以及用户研究中的 text-following/action-following/motion consistency/visual quality。

表 1 中 Ours 的 CLIP-I 0.851、OQ 0.151、HandSIM 0.049、FaceSIM 0.041、IdentitySIM 0.829，用户研究 TF/AF/MC 为 4.08/3.94/3.88；FVD 154.1、tLPIPS 0.178，整体接近或优于最强文本基线。定性结果显示离散 state 能在相似 motion 下切换 no-contact/grasp；multi-scale human state 改善手和脸部细节。

## Value
对我们有两点启发：一是视频世界模型可把连续动态和离散交互状态分开控制；二是“局部世界模型”可聚焦人周围的可交互状态，而不是泛化到全场景。但它主要服务交互视频生成，缺少 action-conditioned physical prediction 或闭环控制验证。

## Strengths
连续/离散控制拆分合理；multi-scale motion latent 针对手和脸等细节；实时生成工程完整；交互状态可在线切换，适合应用系统。

## Weaknesses
“world model”定义偏宽，主要是条件视频生成而非可用于 planning 的动力学模型；交互状态只有 no contact/grasp 两类；交互训练数据大量由生成模型合成并过滤，真实性和物理一致性有限；实验偏视觉质量和用户评价，没有长期物理一致性指标。

## Future Work
作者未系统展开未来方向，但结论暗示可扩展更多 interaction state、更复杂对象关系和更高效的实时人中心局部世界模型。
