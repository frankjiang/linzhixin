# minWM: A Full-Stack Open-Source Framework for Real-Time Interactive Video World Models

## Insight
无特别insight。本文是工程框架论文，将分散的技术（camera control fine-tuning、Causal Forcing、few-step distillation、streaming inference）整合为统一可复现的pipeline。

## Motivation
- 问题：将双向视频扩散模型转换为实时交互式世界模型需要完整的pipeline（数据构建→可控微调→AR训练→蒸馏→推理），但现有技术分散在不同工作中，缺乏统一框架
- 同行方法：各自独立的Causal Forcing、DMD等工作
- 关键性：降低交互式视频世界模型的复现门槛，是有意义的工程贡献

## Method
- Phase 1：Camera-controllable fine-tuning，用PRoPE注入相机参数（投影矩阵→block-diagonal变换注入self-attention）
- Phase 2：Causal Forcing / Causal Forcing++ 蒸馏pipeline
  - Stage 1: AR diffusion training（teacher forcing + causal mask）
  - Stage 2: Causal ODE初始化 或 Causal CD初始化
  - Stage 3: Asymmetric DMD（用双向模型做teacher对齐质量）
- 支持Wan2.1-T2V-1.3B和HY1.5-TI2V-8B两种backbone
- 数据：3D重建+渲染（DL3DV）或WorldPlay生成带GT相机轨迹的视频

## Experiment
- 延迟：Few-step AR相比双向模型首帧延迟降低223.75×（HY1.5）/ 236.64×（Wan2.1）
- 消融：(1)训练数据——SpatialVid的estimated pose不可靠，需GT轨迹；(2)5K步开始出现可控性，8K步强可控；(3)batch size≥16才能稳定学习相机控制
- 无定量FVD等视频质量指标对比，主要是定性展示

## Value
工程价值明确——开源了完整的交互式视频世界模型构建recipe，降低了复现门槛。但技术创新有限，本质是已有方法的工程整合。实用发现：camera pose数据质量（GT vs estimated）是关键瓶颈。

## 创新度：2⭐
纯工程整合，无新方法贡献，但开源框架有实用价值。

## 相关度：3 (Core)
直接面向交互式视频世界模型的构建，核心相关。

开源全栈框架将双向视频扩散模型转为实时交互世界模型，延迟降低200×+，技术整合无新方法，重工程复现价值。可选读。
