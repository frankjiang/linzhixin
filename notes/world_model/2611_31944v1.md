# DraftKV: Protecting Persistent Worlds through Hierarchical Streaming Retrieval

## Insight
长时交互视频的回访记忆需要“同一空间位置”和“当前 query 相关”两个条件：只看姿态会带入无关区域，只看特征会把相似但位置错误的区域混淆。论文用消融验证两级检索皆有贡献；理论证明均值池化的草稿注意力分量与全分辨率均值完全一致，但选择效用上界依赖实测 Top-K 重叠，并不保证具体视频质量。

## Motivation
自回归视频扩散世界模型长期保留历史 KV 可缓解回访场景漂移，却造成历史越长，GPU 占用、CPU→GPU 传输与注意力成本越高。高质量持久世界需要按空间和内容检索、同时流式处理 KV。

## Method
训练自由的 DraftKV：先用双向视锥重叠选择有几何关系的历史 chunk，再在这些 chunk 中以 query 与双池化 key 描述符的草稿注意力挑选 Top-K 空间块，保护最近帧；全分辨率 KV 存 CPU pinned memory。SCG-Attention 把选中 KV 分 tile 异步搬运、施加时间位置编码、FlashAttention 计算局部输出，再用 log-sum-exp 精确合并；有限循环缓冲区使活跃 KV GPU 占用不随检索长度增长。主要创新是空间/内容分级检索与系统流水并用。

## Experiment
在 VBench-Long 60 秒视频及 ORBIA 480 条交互轨迹上测试 LongLive-1.3B、LingBot-1.3B/14B、SolarWM-33B；报告生成质量、持久性、3D 一致性、回访 PSNR/SSIM/LPIPS 和端到端延迟/显存。SolarWM-33B 的 ORBIA 持久性 72.86→78.78、整体分 78.04→80.10。另在 30 秒 WorldAtlas 系统负载下，相对 CPU 卸载的 WorldKV，延迟 1653.20→504.84 秒、显存 124.60→72.05 GiB；原生无检索推理则为 360.41 秒。LingBot-14B 持久性 57.72→65.60。去掉几何或草稿细选，整体分均下降。两套质量和效率数值来自不同工作负载，不能直接按帧对应。

## Value
对交互视频/3D 世界模型的长期记忆有直接工程价值：检索必须同时约束空间来源与内容，且要把内存传输纳入端到端性能评测。值得借鉴回访一致性指标与强原生基线。

## Strengths
跨三种规模的世界模型与多个任务验证；报告真实延迟和显存，单 H100 80 GiB 可运行 33B；包含检索正确性、消融及回访感知指标。附录区分质量评测与系统计时负载，避免把速度误归因于生成质量。

## Weaknesses
依赖可用且较准确的相机位姿；视锥重叠不理解遮挡，CPU pinned memory 成本未消失。33B 虽较 WorldKV 快，仍慢于原生推理；单 H100 可运行也非 DraftKV 独有。理论保证对理想静态共视规则成立，预算截断和真实场景不在保证内。

## Future Work
正文没有明确指定后续路线；动态/遮挡场景的几何候选质量、位姿漂移鲁棒性及长时 CPU 存储是待解决问题。

## Rating
创新度评分：3/5 - 已有姿态检索、草稿注意力和流式注意力的有针对性系统组合，跨模型实用增益明显。
相关度评分：3/3 (Core) - 直接服务交互视频世界模型的持久空间记忆。

## TL;DR
以几何约束加草稿注意力检索历史 KV，并流式搬运以保住回访一致性；值得精读系统实现。
