# Model What Matters: Decision-Guided Selective World Modeling for Language Agents

## Insight
文本代理的环境反馈包含大量与下一决策无关的内容，均匀预测整段反馈可能让辅助损失干扰策略学习。作者用反馈片段对已采样下一回复的似然作相关性代理，再按预测置信度加权；问答和购物成功率的提升支持「选择训练目标有益」，但似然关联不等于因果决策价值。

## Motivation
稀疏任务奖励没有直接监督动作后的文本反馈；ECHO 等策略与世界建模联合训练则预测完整观察，可能把容量耗在无关句子和网页块上。对语言代理训练是实际问题，与视频、3D 或 JEPA/Dreamer 世界模型仅有抽象层面的联系。

## Method
把检索反馈切成句子、购物页面切成语义 UI 块。对每个候选块，以采样时策略计算真实下一回复的教师强制平均 log-likelihood；保留高于本次观察均值加 $\kappa$ 倍标准差的块，拼接为动作条件下的下一观察预测目标。由目标 token 平均负对数似然求置信度 $q$，以 $(1-q)^\gamma$ 加权辅助损失，与 GRPO/PPO 等策略损失共同优化同一 LLM。推理不需筛选。创新主要是选择粒度从整次反馈细化到内部语义单元，并加入难例加权，算法组件较简单。

## Experiment
- 在 NQ、HotpotQA 训练，跨 NQ/TriviaQA/PopQA 与四项多跳 QA 测 Exact Match，WebShop 测购买成功率与 Score。Qwen3-1.7B：单跳平均 EM 45.77%，ECHO 44.32%、纯 GRPO 44.64%；多跳 22.06%，ECHO 17.71%、GRPO 18.88%；WebShop 成功率 43.20%，ECHO 40.40%。Qwen3-8B 对应为单跳 50.14%（ECHO 48.75%）、多跳 40.48%（38.15%）、购物 47.20%（45.00%）。
- 在 Qwen2.5/Llama 与 GRPO、PPO、RLOO、GMPO 的六种配置中，DGS-WM 的类别平均 EM 均高于各自 ECHO 和纯 RL 对照。1.7B 消融：去掉目标选择，多跳 EM 从 22.06% 降至 20.31%；去掉置信度加权降至 21.66%。案例显示选中约 7%–13% 的反馈单元，但缺乏选择质量的人工或因果标注验证。

## Value
「按决策价值分配世界模型辅助损失」可作为跨模态训练目标设计的间接启发；本文的实现和证据限定于文本代理，不提供视频生成、3D 状态或潜空间动力学方法，因此对本研究方向可跳过。

## Strengths
同一 RL 和模型条件下比较完整反馈辅助损失、纯 RL 与选择式损失；跨模型、算法和任务验证，且分别消融筛选与加权。

## Weaknesses
选择分数来自对已发生回复的似然，可能偏向支持当前策略的证据，缺少反事实因果检验；依赖任务特定句子/UI 切分。每个候选块需一次策略打分，未报告训练计算开销及多次运行方差。结果不能直接推断视觉世界模型的状态保真或规划收益。

## Future Work
作者建议在复杂非结构化反馈中学习自适应语义分段，并用反事实推理或因果干预确定真正影响决策的反馈。

## Rating
创新度评分：2/5 - 细粒度反馈选择和置信加权是合理的增量训练策略，但无新的世界状态表征或动力学模型。
相关度评分：0/3 (Noise) - 纯文本 LLM 代理训练，未研究视频、3D 或 JEPA/Dreamer 式隐式世界模型。

## TL;DR
DGS-WM 选择对下一回复有用的文本反馈训练语言代理，提升问答和购物表现；与视频及隐式世界模型方向无直接关系，可跳过。
