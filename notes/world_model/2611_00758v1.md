# Old Is Not False: Valid-Time Memory for Interactive Video World Models

## Insight
观察：固定生成器在其他输入不变时会跟随两张记忆帧的时间戳顺序，把“较新帧”视作当前事实；当动作被撤销、旧场景重现时，最新拍摄帧反而过时。推论：记忆应保留旧帧，并把其内容按动作日志中的**有效时间**重新定时，而非按拍摄时间排序或删除。作者证明仅靠拍摄帧而不读动作日志无法区分某些“持续新状态”和“已恢复旧状态”的历史，且正确的最新时间戳读取要求所有当前观察晚于过时观察；时间戳交换探针与多模型实验支持机制。

## Motivation
交互视频世界模型依赖外部帧记忆，在关门、拿走物体等撤销动作后重访，现有删除/过滤会丢掉唯一显示当前状态的旧视图；保留帧却沿用拍摄时间，又诱导模型复制过时内容。此问题直接影响长期持久世界、回访一致性和动作反事实评测。

## Method
ReDate 不训练生成器：用动作日志跟踪门、容器和物体位置等区域状态；检索时保留所有历史帧，把“曾显示旧状态、如今经动作恢复”的区域 token 时间戳移到恢复动作之后，把日志判定为过时的 token 移到当前检索窗口最早时间之前；其余保留拍摄时间。为覆盖回访，再召回目标视角及最近动作后的帧，逐 token 而非逐帧设时间戳。理论区分拍摄时间和内容有效时间，分析最新时间戳选择、软选择和跨区域混合帧，说明重定时何时优于删 token。创新是将有效时间语义具体接入冻结视频生成器的记忆读出。

## Experiment
FAR 冻结扩散生成器的 AI2-THOR 1309 个测试片段：在 seed 1 的 352 个撤销后回访步骤，自定义校准状态准确率从 0.36 提至 0.62，过时状态比例 0.27→0.09；目标视角已有当前状态的 219 步从 0.54→0.94，目标视角未见当前状态的 133 步仅 0.05→0.10。消融：仅有效时间 0.55，完整逐 token ReDate 0.62；与同日志删 token 比，PSNR 39.7 vs 35.0 dB、低质量占比 0.09 vs 0.36。197 个留出片段跨两 seed 为 0.58 vs 0.34；HY-WorldPlay 的固定阈值当前状态比例 0.003→0.188。另用时间戳倒置探针、10 类已有记忆规则、EPIC-KITCHENS 撤销动作统计和校准状态指标验证。新状态步骤几乎未降（0.43→0.44）。

## Value
值得精读：指出视频世界模型记忆中的“拍摄时间≠事实有效时间”，给出无需重训、可插拔的实现和直接评测撤销后回访的指标。这一思想可用于长期场景记忆、动作驱动状态更新和 3D 世界模型中的版本管理。

## Strengths
机制探针把时间戳效应与图像、权重、噪声隔离；理论清晰列出可行条件和不可辨识情形；跨生成器、留出片段、阈值与质量指标验证，并诚实报告未见视角的失败边界。

## Weaknesses
理论依赖“只有代理动作改变场景”和日志能识别状态恢复；真实世界其他演员、自发变化和不完整动作日志会破坏该条件。逐 token 状态定位仍不精确，目标视角未存现态时无法凭时间戳创造缺失视图；主要在室内有限动作和已知相机姿态上评测。

## Future Work
作者明确提出将其他视角观测的现态可靠地渲染/迁移到目标视角，并把其他行动者造成的变化写入日志；还需更复杂真实场景与不完整日志的验证。

## Rating
创新度评分：4/5 - 找到长期视频记忆的关键失效机制，提出有理论支撑且无需训练的有效时间修复，跨模型收益明显。
相关度评分：3/3 (Core) - 直接解决交互视频世界模型的持久状态与长时回访一致性。

## TL;DR
发现撤销动作后“最新拍摄帧”会误导世界模型，按状态有效时间重定记忆 token 明显改善回访；值得精读。
