# Visualizing the World Model in an Agent's Value Function

## Insight
即便 PPO critic 只优化回报，改动单一状态因素时其标量价值也响应游戏先决条件：可见钻石仅在有铁镐时显著增值。作者用符号状态反事实和人工预期排序测得钻石可采性 95.61%、铁矿 87.67%、成熟植物 99.31%；这证明 critic 编码了部分规则信息，但标量价值本身不能预测转移，称之为完整世界模型仍过强。

## Motivation
想理解无显式动力学训练的强化学习价值函数学到了哪些环境知识及危险捷径。以往多探查策略；Crafter 的可编辑符号状态适合对固定 critic 作局部反事实测试。

## Method
训练 Craftax-Classic PPO，取 100 亿步 checkpoint；对约 944 万转移的评估数据，固定其他字段、改变物品栏、可见资源或健康状态。用专家定义的价值大小顺序，计算 critic 在反事实组中满足顺序的比例，并随训练 checkpoint 追踪概念出现。方法属于事后解释，不学习新的预测模型。

## Experiment
1 万新回合，钻石达成率 35%；晚期物品栏在早/晚场景均压低价值的双条件满足率 89.1%。钻石+铁镐、铁矿+石镐与成熟植物的预期排序成功率分别 95.61%、87.67%、99.31%；低健康、低资源时水/食物价值排序分别 82.25%、83.24%。69% 回合以进入岩浆结束；作者加死亡惩罚后展示末端任务成功改善。实验以状态反事实、排序满足率和行为观察为主，无显式动态预测指标。

## Value
可借鉴反事实探针来审计隐式状态表征或 critic 的捷径；对 JEPA/Dreamer 类可生成潜态动力学仅有间接联系。

## Strengths
符号环境允许精确控制单一因素；对先决条件做交互式反事实，优于只看特征相关；揭示奖励设计引发的终止行为。

## Weaknesses
只有一个游戏和一个 PPO critic；状态可人为改成分布外组合，专家价值排序也未必等于真实折扣回报。未测试模型对下一状态的预测，因此“形成世界模型”主要是解释性措辞。

## Future Work
作者提出加入时空认知图、结构化向量价值表征，并让智能体在学习时主动生成和检验反事实，而非只在事后分析。

## Rating
创新度评分：2/5 - 反事实价值探针展示有趣现象，但方法简单、世界模型结论证据有限。
相关度评分：1/3 (Tangential) - 讨论隐含规则知识，未构建视频/3D或 JEPA/Dreamer 式潜态预测模型。

## TL;DR
反事实探针发现PPO价值函数编码部分游戏规则及有害捷径，但非显式动力学模型；可选读。
