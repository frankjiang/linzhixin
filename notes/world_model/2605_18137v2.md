# Xiaomi EV World Model: A Joint World Model Integrating Reconstruction and Generation for Autonomous Driving

## Insight
核心洞察：重建和生成是自动驾驶世界模型的两个互补能力，单独使用各有缺陷（重建无法想象未见区域，生成缺乏几何一致性），深度耦合可实现协同增益。观察到现有 feed-forward 3DGS 方法的像素对齐预测范式导致 ghosting 和分层重复；因果扩散模型从头训练缺乏场景先验、推理慢、存在 exposure bias。

## Motivation
解决自动驾驶世界模型中重建与生成割裂的问题。现有方法要么只做重建（无法外推到未见区域），要么只做生成（几何一致性差、长时漂移）。需要一个统一框架同时具备精确3D重建和可控视频生成能力，服务于闭环仿真和端到端训练。

## Method
三大模块：
1. **WorldRec**: 稀疏查询驱动的 feed-forward 3DGS 重建。在3D空间初始化 sparse query tokens，通过 cross-view cross-temporal 特征聚合（visibility-aware 加权融合），输出紧凑 3D Gaussian 场景表示。相比像素对齐的 DPT head，避免了 ghosting 和冗余。
2. **WorldGen**: 两阶段训练的 DiT 视频生成器。Stage 1 双向预训练学习全局时空分布；Stage 2 渐进式因果微调（Teacher Forcing -> ODE 蒸馏 4步 -> DMD 解决 exposure bias），实现高质量在线因果生成。
3. **Joint World Model (JWM)**: WorldRec 提供增量式场景重建（scene fusion 扩展已有表示），WorldGen 通过 rendered-RGB conditioning 利用重建结果作为几何锚点。形成闭环：重建抑制生成漂移，生成补偿未观测区域。

## Experiment
工业级技术报告，在小米自动驾驶数据上验证。重建质量和生成质量分别评估。JWM 在时序一致性、跨视图一致性、长时稳定性上均优于单独使用重建或生成。生成可达 0.19s/frame，4步去噪，支持最长1分钟驾驶视频。

## Value
工程完成度高的工业界技术报告，系统性地解决了重建-生成融合的工程难题。核心思路（重建提供几何锚点+生成补偿未见区域的闭环设计）对世界模型研究有参考价值。WorldRec 的 sparse query 设计避免了逐像素预测的冗余，值得关注。但创新点更多是已有技术的精心组合和工程优化，单独来看各模块缺乏突破性创新。

## Strengths
