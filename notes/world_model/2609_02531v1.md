# Spatially Aware World Action Model via Geometric Latent Diffusion

## Insight

有。论文的 observation 是：RGB-only World Action Model 继承视频预训练的动态先验，却缺少操作所需的度量几何；直接把无界深度交给冻结 RGB VAE 又会浪费 near-field 分辨率。作者据此推论，先用非线性函数把深度压到 tokenizer 的 `[-1,1]` 图像域，并把深度当作与 RGB 交错的 latent frames，就能在不训练 3D encoder 的情况下复用视频 backbone。线性、逆深度、log 的局部敏感度分别为常数、`1/z²`、`1/z`；实验显示 log 在近远距离间取得最好平衡：VAE round-trip 总 AbsRel 0.63%，且政策成功率 61.7%，优于 RGB-only 52.7%。此外，目标物体区域的未来 3D 预测误差可区分成功/失败 rollout（AUC≈0.88），说明 world prediction quality 不只是可视化指标，也可成为策略失效诊断信号；但该分析是相关性，不是因果证明。

## Motivation

VLA 多从静态图文模型初始化，而 WAM/UWM 将互联网视频的时序与物理先验用于统一生成未来观测和动作。现有 WAM 主要只处理 RGB；3D-aware VLA 虽已证明 point cloud、point map 或空间编码有用，却通常增加专用 3D module，尚未把显式几何无缝接入预训练视频 diffusion 的统一序列。本文要解决的是：如何保留 Cosmos 类视频模型的 pretrained prior，同时以最小结构改动共同预测 action、RGB 与 metric depth。这对机器人视频世界模型和 3D 世界模型的结合是直接问题。

## Method

SA-WAM 以 2B 参数 Cosmos-Predict2 DiT 初始化，Wan2.1 时空 VAE 始终冻结。输入包括任务文本、当前 proprioception，以及 wrist/left/right 三视角 RGB-D；输出是在同一 diffusion sequence 内联合去噪 action chunk 与时刻 `t+H` 的未来 RGB/depth latents。proprioception 和动作占专用 token 位置，每个 RGB latent frame 后插入同相机 depth latent frame；没有独立 action head、3D encoder 或 modality-specific loss，解码未来画面在推理时可省略。

对每个相机，从训练集有效深度取 `P2/P98` 为边界并 clamp；将 normalized depth 映射到 `[-1,1]` 后复制成三通道，送入同一冻结 VAE。比较三种可逆映射：linear `(z-a)/(b-a)`、inverse-depth 和 log `log(z/a)/log(b/a)`。log 强调近场而不像 inverse 那样严重损失远场。clean target sequence 含 action、未来 RGB 和未来 depth，EDM 噪声目标用一个 L2 denoising loss 统一监督。主模型 action horizon `H=32`，推理时 open-loop 执行前 16 步。

## Experiment

模拟覆盖 RoboCasa 24 个厨房原子任务、LIBERO 四套标准任务和含 7 类扰动的 LIBERO-Plus zero-shot 协议；后者只用原始 LIBERO demonstrations 训练。RoboCasa/LIBERO 分别以 effective batch 800/960 在 40 张 H100 上训练 45k/40k iterations。RoboCasa 报 3 seeds；深度归一化消融使用 8 个任务、每任务 50 demos、6k steps，policy SR 为 3 evaluation seeds×每任务 50 trials。

- **深度消融**：frozen-VAE round-trip 总 AbsRel 为 linear 1.47%、inverse 1.41%、log 0.63%。wrist `<0.3m/0.3-1m/>1m` 分段中，linear 为 `6.68/0.80/1.78%`，inverse 为 `0.62/4.16/13.19%`，log 为 `1.25/1.00/3.19%`。政策 SR 从 RGB-only 52.7% 升至 RGB-D linear 56.5%、inverse 59.5%、log 61.7%。
- **RoboCasa**：SA-WAM 仅用 50 demos/task 达 76.6%，高于同预算 Cosmos-Policy 67.1%（+9.5）；PnP 和 Turn/Toggle 分别提升 16.7 与 11.2 点。也超过 π0 62.5、VideoPolicy 66.0、UWM 60.8、FLARE 71.3、World2Act 72.6 等使用 300-1000 demos/task 的结果，但这些跨方法数据预算和训练栈并不完全匹配。
- **LIBERO**：标准 benchmark 已接近饱和，SA-WAM 平均 98.4%；LIBERO-Plus 七类扰动加权 SR 为 86.6%，高于 π0.5 的 84.6% 和 Cosmos-Policy 的 81.4%。
- **世界预测质量**：对 24 个 RoboCasa 任务，SA-WAM 相比 Cosmos-Policy 的 fixed/wrist PSNR 从 `15.78/14.64` 到 `15.97/15.16`，SSIM 从 `.525/.563` 到 `.528/.566`，LPIPS 从 `.167/.417` 降至 `.161/.354`；robot+gripper+target mask 内也全面改善。PnP 中利用 simulator target mask 回投预测/真实深度，object-centric 3D error 对失败检测 AUC≈0.88，在 13% FPR 时检测 80% 失败。
- **UR5 实机**：6-DoF UR5+RG6，固定 Orbbec Femto Mega RGB-D；10 个任务每个 20 demonstrations，action/state 为 8-D 末端 pose+gripper key-step，模型训练 2400 iterations、8 H100。评估四类复合任务，clean 与 randomized 各 10 trials/category，并按子目标给 partial completion credit。clean aggregate completion 为 SA-WAM 90.0%、Cosmos-Policy 75.0%、π0 21.3%；随机化后为 77.5%、48.8%、11.3%。

## Value

该工作给出一个非常直接的“视频先验+度量几何”接口：把新模态改写成 tokenizer 已理解的 frame，而不是为 3D 另起 latent space。对未来 WAM 很有启发：预训练 tokenizer 的输入分布匹配可能与网络结构同样重要；联合预测 depth 既能提高动作鲁棒性，也提供可量化的空间一致性诊断。方法尤其适合已有同步 RGB-D 的 manipulation，但它并未构建可持久查询的显式 3D 场景，也未解决长程、多步世界一致性。

## Strengths

- 只用相机相关归一化和 latent-frame injection 即把 metric depth 接入冻结视频 VAE，结构简洁、保留预训练 backbone，且推理可不解码未来画面。
- 深度 encoding ablation 同时测 tokenizer AbsRel 与 policy SR，清楚连接输入表示质量和下游行为。
- 以同预算 Cosmos-Policy 为关键对照，在 RoboCasa、LIBERO-Plus 和 UR5 clean/randomized 上均有一致增益。
- 不只报 rollout 成功率，还报告全图/掩码世界预测指标，并以 object-centric 3D error 量化预测与失败的关联。

## Weaknesses

- 核心技术主要是既有 nonlinear depth normalization 加 latent injection；没有新的 3D表示学习或几何约束，所谓“3D-aware”仍是逐像素 metric depth，而非跨视角一致的场景结构。
- 每相机 `P2/P98` 深度边界来自训练集并对超界值 clamp；论文没有评估更换相机、显著改变深度范围或 calibration error 下的稳定性。
- 作者承认未来动作与画面仍会不一致，也未做显式几何一致性训练/验证；预测只针对固定未来位置，缺少长程 autoregressive world rollout 评测。
- 2B DiT 的模拟训练需 40 张 H100，实机微调也用 8 张 H100；作者明确把 WAM inference efficiency 列为未解决问题。
- object-centric failure diagnostic 使用 simulator ground-truth target mask，不能直接视为部署时在线 verifier；AUC 仅证明相关性。
- 实机每条件每类只有 10 trials，使用可部分计分的 completion score，未给置信区间；大量 SOTA 对比的数据量与训练配方不同，最有说服力的仍是 Cosmos-Policy matched baseline。

## Future Work

作者明确提出用 geometry-consistent training 与 verification 缓解 action/future 不一致，并提高 WAM 推理效率。进一步应评估跨相机和跨深度范围泛化、无 simulator mask 的在线几何 verifier、长程多步 RGB-D rollout，以及把多视角深度升级为显式且跨视角一致的 3D state。

## Rating

创新度评分：3/5 - 首次把显式深度作为 latent frames 注入统一 WAM 并取得强结果，方向新且实用；但核心实现是已有 log-depth 编码与序列扩展，技术突破有限。
相关度评分：3/3 (Core) - 直接研究视频扩散世界动作模型与3D几何的统一建模，并关联未来预测质量和机器人决策，属于视频/3D世界模型核心方向。

## TL;DR

用对数深度帧扩展视频世界动作模型，显著提升操作与未来预测；方法简洁、实验扎实，值得精读。
