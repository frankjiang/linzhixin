# DeTrack: A Benchmark and Altitude-Aware Dual World Model for Drone-embodied Tracking

## Insight
核心观察：无人机跟踪存在高度-可见性-安全性的内在矛盾——高空视野广但目标小、低空目标清晰但障碍多。通过构建双高度世界模型（高空+低空）同时想象两种高度下的未来状态，为决策提供互补信息。

## Motivation
现有无人机跟踪 benchmark 基于被动 2D 视频，不涉及主动飞行控制和 3D 环境交互。定义无人机具身跟踪（DeTrack）新任务，需要在交互式 3D 场景中实时跟踪目标并控制飞行。提出双世界模型解决高度-安全性矛盾。

## Method
1. **DeTrack Benchmark**: 基于 Unreal Engine 4.27 + AirSim，11,368 条目标轨迹，4 种场景风格，多种渲染条件。评估指标：可见率 VR、mIoU、跟踪率 TR、轨迹成功率 SR
2. **ReDeT (Reinforcement Drone-embodied Tracking)**: 被动跟踪器 (OSTrack) + RL 飞行控制策略 (PPO)，作为基线框架
3. **Dual World Models (DWM)**: 高空世界模型 W^h 和低空世界模型 W^l，各含 RSAM + posterior/prior 网络。训练时用 prophet 高低空观测做监督，推理时仅用 prior 网络想象未来
4. **Altitude-aware Perception (AaP)**: 高度感知编码 + progress-aware masking 的 masked autoencoder，从单一自中心观测生成伪高空和伪低空表示

## Experiment
- 被动跟踪器在 DeTrack 上性能急剧下降（OSTrack VR 仅 9.34%），证明任务难度
- AaDWorlds 在所有指标上最优：VR 29.00%、mIoU 17.06%、TR 22.57%、SR 17.66%
- 消融验证 AaP 和 DWM 各自贡献独立且互补
- 3m/20m 高度组合最优

## Value
定义了无人机具身跟踪新任务并构建了大规模 benchmark，有一定开创意义。双高度世界模型的设计有针对性，但方法相对常规（RSSM + MAE）。与用户关注的视频/3D/隐式世界模型关联有限，更偏具身感知和控制应用。世界模型在此主要作为辅助模块而非核心贡献。

## Strengths
亮点是定义了无人机具身跟踪新任务并构建了大规模 benchmark，有一定开创意义。

## Weaknesses
不足是与用户关注的视频/3D/隐式世界模型关联有限，更偏具身感知和控制应用。

## Future Work
作者未明确提出具体未来工作；从局限看，后续需要围绕“与用户关注的视频/3D/隐式世界模型关联有限，更偏具身感知和控制应用”补充更大规模验证、跨场景扩展或方法改进。
