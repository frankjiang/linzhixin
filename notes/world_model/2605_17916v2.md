# PanoWorld: A Generative Spatial World Model for Consistent Whole-House Panorama Synthesis

## Insight
核心观察：VR看房产品使用的是节点式离散导航，而非连续6-DoF。由此推论：不需要生成完美的3D模型，而是生成一组高质量全景图 + 轻量3D记忆（3DGS cache）保证跨节点一致性。将几何引导（floorplan shell）和外观记忆（3DGS cache）解耦是关键设计。

## Motivation
从户型图+风格参考生成一致的全屋VR全景漫游。纯2D生成器可产出高质量单张全景但跨视点不一致；整体3D生成在多房间尺度下代价高且纹理质量差。需要兼顾2D生成质量和3D几何一致性。

## Method
自回归节点式全景生成管线：
1. **Global Geometric Proxy**: 户型图转粗糙3D shell（墙壁、地板、天花板），提供低频几何约束
2. **Room-Aware Panoramic LRM**: 前馈式全景3D重建模块，预测 3D Gaussians。使用 Circular PRoPE（环形位置编码）处理全景wraparound，Room-Aware Group Attention 限制跨房间特征干扰
3. **Topology-Aware Progressive 3DGS Caching**: 渐进式更新3DGS cache，仅融合同房间+门洞连接节点的局部更新，避免全历史重建。confidence-based fusion 策略保持局部锐利度
4. **Decoupled Conditioning**: shell proxy 作为几何条件，cache 渲染作为外观条件，cross-room depth filtering 防止跨房间纹理泄漏

## Experiment
训练数据：6,813 3D-FRONT场景 + 10K RealSee3D场景 + 2.5M私有2D全景。在自建 benchmark（7套户型/126张全景）上评估：
- Overlap PSNR 22.14（超越第二名 OmniRoam 5.75 dB），跨节点一致性显著优势
- 单节点美学质量 HPSv3=7.96，与 Nano Banana 2 竞争力接近
- LRM 重建在 PSNR/SSIM/LPIPS 上均超越 MVP/Adapt-Splat/WorldMirror 2.0
- 消融实验验证 VM、NV、CPRoPE、RAGA 各组件贡献

## Value
面向垂直场景（VR看房）的完整世界模型方案，在跨节点一致性上有明显优势。Room-Aware Group Attention 和 Circular PRoPE 是针对全景多房间场景的有效设计。对3D世界模型研究的启发：解耦几何与外观、渐进式3D记忆更新的思路可迁移。局限是场景较垂直（室内全景），泛化性有待验证。

## Strengths
亮点是面向垂直场景（VR看房）的完整世界模型方案，在跨节点一致性上有明显优势。

## Weaknesses
