# SANA-Robot: Efficient World Action Model with Hybrid Memory

## Insight
观察：世界动作模型的动作与视频可共享生成过程，但视频去噪成本高；短帧记忆又漏掉整段任务历史。作者发现动作主要通过当前预测视频读取历史：切断视频读记忆使动作 MSE 增 3.8 倍，切断动作读视频增 8.0 倍。推论：将全局压缩记忆与局部精细窗口并用，并确保当前观测只作因果条件，可在固定每段推理成本下保留长时信息；记忆与注意力的干预实验支持机制。

## Motivation
现有 WAM 多依赖当前帧或少量历史抽样，长时任务需要看见已遮挡事件，且连续视频预测难在边缘设备实时执行。论文同时解决统一视频—动作建模、分钟级记忆和部署延迟，直接面向可用的机器人世界模型。

## Method
4.5B Sana-Video 2 混合 DiT：每组 3 层 Gated DeltaNet 线性注意接 1 层 softmax，共 8 组。观察、机器人状态、未来视频与 32 个动作 token 共用物理时间坐标；按 token 分配噪声，可用同网训练 FDM（给动作预测视频）、IDM（给视频预测动作）、策略（联合预测两者）。跨动作段使用因果注意：GDN 固定大小状态压缩全历史，softmax 保留首帧和最近段 KV 滑窗；当前观测可被目标读但不写入记忆。训练以 23 数据集约 1.94 万小时、整集序列打包与均衡采样；部署用按执行相位分开的记忆进行异步实时分块，再加融合算子、CUDA graph、条件缓存和低精度 GEMM。模拟器另以真值/重采样历史训练，并做四步蒸馏与 Self-Forcing。

## Experiment
RoboDojo 五维平均分/成功率 34.31/27.09%，记忆维度成功率 52.33%，InternW0-Δ 为 34.00%；同数据初始化下记忆对照为 48.8%，稀疏帧方案 28.3%/31.4%。RoboTwin 2.0 Clean2Random 平均成功率 82.6%，LIBERO-Plus 94.0%、Pro 68.1%、Max 动态 76.1%。实机 20 回合/任务：三杯记忆 75% 对无记忆 30%；咖啡步骤完成率 87.1%，汉诺塔正确环比例 83.6%；异步空气曲棍球命中率 60% 对同步 45%。RTX 5090 每段 115 ms（NVFP4），Jetson Thor 288 ms；异步控制达到 30 Hz。WorldArena 四步模拟器 EWMScore-P 66.2，30 帧生成 0.3 秒；DROID 21 组策略—任务对的模拟平均成功率 58.3%，真实为 52.6%。

## Value
视频世界模型与策略的统一训练、混合记忆的固定成本推理以及用真实策略成功率评估模拟器，均有较高参考价值；值得精读方法、记忆消融和模拟器评测。

## Strengths
同一网络支持策略、逆/正向动力学；有记忆类型与注意路径的干预；既有模拟多基准，也有实机任务、端到端时延及政策在模型内闭环评测。

## Weaknesses
大规模预训练和 32 卡后训练使收益难与数据规模分离；实机每任务仅 20 回合，低精度空气曲棍球表现从 60% 降至 50%。WorldArena 动作/运动质量不是最优；DROID 模拟平均成功率仍高于真实 5.7 点，且由人工判定生成视频成败。分钟级之外的记忆稳定性未证明。

## Future Work
论文未明确列具体路线；更长时程记忆、模拟器的动作物理保真和跨设备低精度部署仍需验证。
