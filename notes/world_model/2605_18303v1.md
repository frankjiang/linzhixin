# PH-Dreamer: A Physics-Driven World Model via Port-Hamiltonian Generative Dynamics

## Insight
核心 insight："世界模型中的物理不是静态守恒约束，而是由控制驱动的能量流的动态账目"。现有 RSSM（如 Dreamer）端到端学习，不保证能量一致性或耗散机制。将 Port-Hamiltonian 框架引入可以同时处理保守系统和非保守（执行、耗散）动力学。

## Motivation
基于 RSSM 的世界模型（PlaNet, Dreamer 系列）提供高效潜想象，但潜转换物理上无结构，可能违反能量守恒和耗散原则。静态物理先验或解析约束方法牺牲可扩展性，且忽略执行时的能量注入。PH-Dreamer 将物理视为由控制驱动的能量流动态。

## Method
三个协同组件：(1) PH-RSSM——将隐式物理先验嵌入循环转换，将投影潜演化建模为动作控制的能量路由（流+耗散），确定性状态分割为 h_phys 和 h_env，投影到低维 PH 相空间，通过影子 PH 动力学正则化（课程几何积分 + 停止梯度）；(2) 运动学感知能量世界模型——从本体感知观测估计 Hamiltonian 和功率平衡（Cholesky 参数化质量矩阵保证正定，RK4 积分 PH 动力学）；(3) 能量引导 Actor-Critic——Lagrange 乘子优化，C_energy 惩罚增能动作，C_smooth 约束动作平滑性，对偶上升维护约束非负性。

## Experiment
DeepMind Control Suite（Cheetah Run, Reacher Easy, Hopper Hop, Walker Stand/Walk/Run）。以 R2Dreamer 为主要基线。平均回报 738.9 vs R2Dreamer 702.5。想象回报均值 957.7 更紧密对齐真实回报。Log Phase Volume 降低 4.18-8.41%。TEC 降低最多 7.80%，MSJ 降低最多 9.38%。

## Value
对 Dreamer/隐式世界模型研究直接相关。Port-Hamiltonian 框架为 RSSM 潜动力学提供物理结构化归纳偏置，是一个有理论基础的方向。三个组件的协同设计优雅。局限：回报提升幅度有限（modest），PH 约束是归纳偏置而非闭环保证；依赖本体感知信号进行显式能量估计，尚未实现纯像素级的物理发现。实验仅在 DMC 上验证。

## Strengths
亮点是对 Dreamer/隐式世界模型研究直接相关。

## Weaknesses
不足是Port-Hamiltonian 框架为 RSSM 潜动力学提供物理结构化归纳偏置，是一个有理论基础的方向。
