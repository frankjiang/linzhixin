# G-MAPP: GPU-accelerated Multi-Agent Planning and Perception for Reactive Motion Generation

## Insight
论文 insight 是实时反应式机械臂规划的瓶颈在感知-规划耦合：把多相机点云压成 GPU 上的球体占据 world representation，并并行运行多种 vector-field agents，可在复杂动态环境下保持低延迟与较高成功率。

## Motivation
传统 sense-plan-act 对动态人机环境反应慢，APF/MFI 等 reactive field 快但易局部极小，多 agent exploration 可缓解但计算重。作者目标是用 GPU 同时加速感知 world modeling 和 vector-field planning。这里 world model 是几何占据表示，不是学习式视频/3D 世界模型。

## Method
多 RealSense 点云融合成 PW，再转为球形 primitive 集合 SW={(pOj,rO)} 表示 occupied task-space。规划在 Spin(3) x R3 操作空间中计算 attractor force 和 repulsive fields，使用 APF/MFI 等 heuristic agent 并行 rollout。GPU kernel 计算 obstacle distance/repulsive force，cost function 综合 goal distance、obstacle distance、path length、smoothness，选择最佳 agent 给 100Hz 控制线程。

## Experiment
仿真四个场景 Trap/Opening/Cluttered/Passage 比较 CPU/GPU，GPU computation time 至少约 2x 更快，复杂 Passage 中 Nk=200 GPU 约 482ms vs CPU 2681ms，成功率 100% vs 70%。多 agent 实验 15 trials：Opening2 APF 0%、MFI 66.7%、MULTI 73.3%；Mobile Trap MFI/MULTI 100%；Complex MFI 80%、MULTI 93.3%。真实 Franka Panda + 两 RealSense 做动态避障定性演示。

## Value
对机器人 reactive planning 工程有价值，但与用户关注的学习式视频/3D/隐式 world model 只有很弱关联。可以作为几何占据 world representation + 实时规划系统参考，不是重点阅读对象。
