# WBench: A Comprehensive Multi-turn Benchmark for Interactive Video World Model Evaluation

## Insight
Observation：现有交互式视频世界模型在不同能力维度上表现极不均衡——没有任何一个模型能同时在视频质量、设定遵从、交互遵从、一致性和物理合规五个维度上领先。进一步发现几个关键的解耦关系：1) 导航能力与其他维度几乎独立（与视频质量r=-0.12，与物理r=-0.15），说明渲染/记忆/物理能力不能迁移到可控运动上；2) 相机运动控制与视角一致性是分离的能力——多个导航top模型在视角一致性上排名垫底（如HY-World 1.5导航第1但视角一致性第8）；3) 物理正确性主要继承自生成先验（与视频质量r=0.84），而非控制训练。此外，导航在多轮交互中退化最快（4轮后下降33分），因为姿态误差会跨步累积。

## Motivation
问题：交互式视频世界模型发展迅速，但评测碎片化——现有benchmark要么只评视觉质量（VBench）、要么只覆盖部分交互类型（WorldMark只有导航、MIND缺语义交互）、要么限定场景（WorldLens限自动驾驶）。没有一个benchmark能同时覆盖：(i) 开放域多场景、(ii) 第一/第三人称双视角、(iii) 导航+主体动作+事件编辑+视角切换四类交互、(iv) 多轮长程评估、(v) 统一的跨范式（文本/相机/动作）对比。这是一个重要的基础设施缺口——没有统一标准就难以诊断模型的具体短板。

## Method
整体设计：
- **数据集构建**：289个测试用例，1058个交互轮次。每个用例由"世界设定"（场景+风格+主体+视角）和"交互序列"（多轮动作链）组成。覆盖6类场景（自然/城市/室内等）、多种风格（写实/卡通/油画等）、4类主体（人/动物/车辆/机器人），平均3.7轮交互
- **统一导航接口**：将文本描述、6-DoF相机位姿、离散键盘动作三种控制范式映射到同一组导航动作，通过Action Router实现跨范式公平对比
- **五维评测体系**（22个子指标）：
  1. **视频质量**（6项）：美学、成像、闪烁、动态度、平滑度、HPSv3-Norm
  2. **设定遵从**（2项）：场景遵从（可见+不可见元素）、主体遵从（外观+运动）
  3. **交互遵从**（4项）：导航分数（MegaSaM估计位姿vs合成GT轨迹的nATE）、事件编辑/主体动作遵从（VLM五项检查）、视角切换（三重二分判定）
  4. **一致性**（8项）：空间/门控空间、片段连续性、视角/主体/背景/几何/光度一致性
  5. **物理合规**（2项）：因果保真度（两阶段VLM评分，含7个物理子维度）、视觉合理性（微调Qwen3-VL打分低级物理伪影）
- **评测协议**：20个模型分三类范式评测——文本驱动（9个，全289用例）、相机控制（5个，158导航子集）、动作条件（6个，158导航子集）

创新程度：中等。主要贡献在于系统工程——将分散的评测维度整合到一个统一框架中，设计了统一导航接口实现跨范式对比。评测指标多借鉴已有工作（VBench的视频质量指标、MegaSaM位姿估计等），但整体组合和物理维度的两阶段评测设计有一定新意。

## Experiment
**评测规模**：20个SOTA模型，含Seedance 1.5、Wan 2.7、Kling 3.0、YUME 1.5、Genie 3、Matrix-Game 3.0、Happy Oyster等

**关键发现**：
- 视频质量已趋于饱和（闪烁/平滑度指标接近天花板），文本驱动模型略优但世界模型也有竞争力
- 设定遵从：文本驱动模型大幅领先（Wan 2.7达91.4），差距集中在场景遵从而非主体遵从
- 交互遵从：原生控制接口模型优势明显，相机控制(76.0)和动作条件(77.7)比文本驱动(67.6)高约10分；导航和语义交互解耦
- 一致性多面性：LingBot-World总体最高(89.9)，相机控制模型几何一致性好但视角一致性差
- 物理合规：文本驱动模型(67.0)反而优于相机控制(64.2)和动作条件(61.7)，说明广泛生成先验比专用控制训练更利于物理正确
- 导航多轮退化最严重（-33分/4轮），视角切换最难（均分仅30.7）
- 开源模型有竞争力：HY-World 1.5导航全场第一(87.5)，Matrix-Game 3.0动作条件导航第一(83.5)

**人类对齐**：10个评测方面的Spearman相关系数均>=0.94，4个达到1.00

## Value
**工作价值**：作为benchmark论文，WBench的主要价值在于提供了迄今最全面的交互式视频世界模型评测框架。五维22指标的设计较为完整，统一导航接口解决了跨范式对比的痛点。20个模型的大规模横评提供了有价值的诊断洞察。

**对我们的启发**：
1. 导航与其他维度解耦的发现很重要——世界模型的"世界理解"和"可控生成"可能需要不同的技术路线
2. 物理正确性主要来自生成先验而非控制训练，这对隐式世界模型（JEPA/Dreamer）的设计有参考意义——单纯优化控制不能改善物理理解
3. 多轮导航快速退化说明当前模型缺乏持久的空间状态表征，这正是隐式世界模型应该解决的核心问题
4. 视角一致性和相机控制解耦的发现表明，3D世界模型相比纯视频世界模型可能在这方面有结构性优势

**待解决问题**：当前评测基于离散动作序列而非连续控制；物理维度部分依赖LMM评判，对细微效果可靠性有限；未涵盖实时交互评测
