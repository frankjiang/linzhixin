# TacForeSight: Force-Guided Tactile World Model for Contact-Rich Manipulation

## Insight
核心观察：在接触丰富的操控任务中，腕部力/力矩信号（全局、高频）的变化**时间上领先于**指尖触觉信号（局部、细粒度）的变化，存在一个从粗到细的时间依赖关系。例如在灯泡插入任务中，腕部力矩的突变约领先指尖触觉响应 200ms。

推论：可以用全局力信号作为条件，在潜空间中预测未来的触觉表征，从而实现对接触状态变化的**前瞻性感知**（proactive），而非仅仅被动反馈（reactive）。这一思路借鉴了人类感觉运动控制中"负载线索引导局部接触调整"的机制。

验证：(1) 消融实验表明腕部力矩条件在 MSE/Cos/KL 三个指标上均优于无条件、RGB 条件和机器人状态条件；(2) PCA 可视化显示预测触觉潜变量在接触状态转换前约 200ms 即出现变化；(3) 扰动实验中方法在接触恢复上显著优于反应式方法。

## Motivation
**问题**：接触丰富操控需要机器人持续感知动态接触变化（滑动、失对准、接触丢失），现有方法将力和触觉作为被动反馈信号融合到策略中，缺乏对接触状态演变的前瞻性建模。

**同行做法**：(1) FoAR/TacVLA/OmniVTA 等通过门控机制融合视觉-力-触觉模态，但本质上是反应式的；(2) 部分方法用力/触觉预测作为辅助损失学习表征，但不将预测结果显式用于策略推理；(3) Visuo-tactile world models (DreamTacVLA 等) 在像素空间预测触觉图像，计算代价高，不适合实时控制。

**关键性**：对于需要精确接触调节的任务（擦拭、插入、锁定等），反应式方法的延迟和鲁棒性不足是实际瓶颈，前瞻性接触推理是合理且重要的方向。

## Method
**整体流程**：两阶段级联框架。

**Stage 1 - TacForceWM（触觉世界模型）**：
- **触觉分词器**：CNN-Transformer 混合架构，将双指触觉场（35x20 的 3D 位移图）编码为帧级潜变量 z_t。共享空间编码器 + 位置/手指 ID 嵌入 + [CLS] token 自注意力
- **力编码器**：扩张因果 1D 卷积处理 120Hz 腕部六轴力/力矩序列，下采样对齐到触觉帧率（30Hz），提取多尺度时序力特征 c_t
- **潜空间动力学预测器**：力条件化的 Transformer，以力特征通过 AdaLN 调制，输入当前触觉潜变量 chunk，预测未来触觉潜变量 chunk（chunk-based forecasting）
- **训练目标**：MSE 预测损失 + 一阶时间差分动力学损失 + LeJEPA 启发的 SIGReg 正则化（防止表征坍缩）

**Stage 2 - 预测触觉条件化策略**：
- 冻结 Stage 1 的编码器和预测器，提取当前和预测的触觉潜变量
- **当前-未来触觉交互**：cross-attention（当前触觉为 query，预测未来触觉为 key/value）
- **自适应视觉-触觉融合**：触觉引导的通道级门控（sigmoid gate α），动态调节视觉和触觉特征的贡献
- **动作头**：条件流匹配（conditional flow matching）预测动作 chunk

**规模**：世界模型 11.8M 参数，策略 68.9M 参数。RTX 4090D 上实时推理 20Hz。

**创新程度**：中等。力-触觉跨模态预测关系的建模是合理的新颖点，但各组件（AdaLN Transformer、cross-attention、flow matching、SIGReg）均为现有技术的组合。潜空间预测而非像素预测是务实选择而非新贡献。

## Experiment
**实验设置**：
- 真实机器人（UFactory xArm7 + Robotiq 2F-85 夹爪 + 2x Xense 触觉传感器）
- 5 个接触丰富任务：花瓶擦拭、卡片滑动、管道调整与插入、灯泡插入与锁定、线缆插入
- 3 个过程中扰动设置：擦拭时高度扰动、滑动时角度扰动、调整时位姿扰动
- 每个方法每个任务 20 次独立试验

**基线**：DP、DP+Tactile+Force、KineDex、FoAR、RDP

**核心结果**：
- 标准任务平均完成率 79%，显著优于所有基线（次优 RDP 为 54%）
- 扰动设置下平均 86.7%，优势更明显（次优 RDP 约 33%）
- 最大优势体现在需要精确接触调节的任务（Adjustment 70% vs 次优 45%，Locking 80% vs 55%）

**消融实验**：
- 世界模型条件消融（Table II）：腕部力矩条件在 MSE/Cos/KL 上均最优
- 策略组件消融（Table III）：去除预测触觉、力条件、cross-attention、自适应门控均导致性能下降，尤其在扰动设置下

**可视化分析**：
- 触觉潜变量时序 PCA 可视化确认预测的前瞻性
- t-SNE 显示触觉编码器学到了按/扭/滑等不同交互模式的判别性表征
- 自适应门控权重随接触阶段动态变化

## Value
**整体评价**：一个工程上扎实、实验充分的工作。核心贡献在于明确建模了力-触觉的时间先后关系，并在真实机器人上验证了前瞻性触觉预测对接触丰富操控的价值。

**对我们的启发**：
1. **跨模态时间先后关系**的利用思路可推广：在 video world model 中，是否存在类似的"粗粒度信号领先细粒度变化"的规律可被利用？
2. **潜空间预测 + SIGReg**是 JEPA 系方法在具身智能中的又一成功应用案例，验证了 latent prediction 在非视觉模态上的有效性
3. 该工作将 world model 定位为策略的"感知增强模块"（提供前瞻性先验），而非直接用于规划/想象，这是一种轻量但有效的 world model 使用范式

**待解决问题**：
- 仅在潜空间预测触觉，无法生成可解释的触觉预测（如未来触觉图像）
- 世界模型和策略分阶段训练，未端到端优化
- 仅考虑力→触觉的单向预测，未建模触觉→力的反向影响
- 缺乏跨任务泛化实验，每个任务独立训练

## TL;DR
利用腕部力信号在潜空间前瞻性预测指尖触觉表征，以此条件化操控策略实现接触丰富任务的鲁棒控制；面向机器人触觉的领域特定 world model，可选读。
