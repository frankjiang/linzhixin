# WorldCycle: Self-Verifiable Reinforcement Learning for Long-Horizon Video World Models

## Insight
有，而且是本批最强。Observation 是任意动作序列没有 ground-truth future，长时漂移因而无法直接作为 RL reward；但对具有显式逆元的动作，`trajectory ∘ inverse(trajectory)` 的真实净变换必为 identity。由此推论：可逆动作闭环把未知长时未来转化为解析已知的返回状态，成为不依赖标注的 verifier。作者进一步论证只比较终点会造成稀疏 credit，于是比较所有正反镜像阶段；重复同一闭环还能检验“相同状态+相同动作应产生相同转移”。实验以 CoTracker reward、独立 RoMa evaluation 及多 horizon/composite action 证明，这两个约束能降低局部 residual 及其自回归传播，而不仅是记住何时反向。

## Motivation
交互视频世界模型的每个生成 chunk 会成为下一个条件，小误差沿长时 rollout 累积。现有 RL post-training 多优化单 clip 的动作跟随或视觉质量，WorldCompass 虽用 inverse-pose reward，仍没有整条轨迹的真实终态。状态返回是最小但关键的 simulator sanity check：前进再后退若不能回到起点，模型无法支撑可靠探索与规划。问题对长时视频世界模型是核心瓶颈，同时也缺少专门测量闭环、重复和组合动作误差的 benchmark。

## Method
把交互模型视为 action-induced transformation system。对正向动作块与逆序逆动作构成的闭环，在每个深度比较正向帧 `o_i` 与反向镜像帧 `o_{2m-i}`；用 CoTracker 有效点的尺寸归一化平均位移 `d`，取 `exp(-αd)` 平均为 spatial closure reward。再把闭环重复 K 次，以第一轮为 anchor，比较每一轮相同 phase 的帧，构成 temporal state-consistency reward，避免相邻 anchor 自身漂移。

训练先进行 300 步 spatial-only warm-up，随后 spatial+temporal 联合，防止未闭合时的 temporal target 成为噪声或后续遗忘；随机采样不同层级的 cycle length，减少按固定时间点反转的 reward hacking。总 reward 再加入 WorldCompass action score 与 HPSv3 quality，用 group size 16 的 DiffusionNFT negative-aware objective 更新尾部 chunk，前序 rollout 作为冻结上下文，从而控制显存。训练由 WorldPlay 8B AR checkpoint 起步，约 4,000 个 image-caption，最多 16 clips、8 个重复 cycle，8×H200 训练 3 天。

## Experiment
CycleBench 含 380 个首帧（236 个 4KLSDB 实景、144 个 GPT Image 2 合成）和 47 条 action trajectory。T1 比较正反镜像路径，T2 用非重走的矩形/多边形闭环测终点，T3 重复同一闭环，T4 串联不同闭环；覆盖 125/253/381 帧和 125 帧 OOD composite action。训练 reward 用 CoTracker，评估改用独立 RoMa，指标为 endpoint state closure (ESC)、reverse-path symmetry (RPS)、repeated-cycle stability (RCS)，并报告 action accuracy、HPSv3 和 VBench。

相对同源 WorldCompass，WorldCycle 在 125 帧将 ESC 0.038→0.026、RPS 0.034→0.019；253 帧为 0.048→0.038、0.039→0.028；381 帧 RCS 0.074→0.049。OOD composite action 上 ESC/RPS/RCS 分别 0.073/0.059/0.040→0.057/0.042/0.026，accuracy 0.499→0.553；相对原始 WorldPlay 则 0.136→0.553，约 4 倍。完整 schedule 各设置最好，spatial-only 对长时 ESC 为 0.212，temporal-only 为 0.268，full 为 0.163。HPSv3 及六项 VBench 未下降，长时 subject/background/imaging consistency 反而改善。

## Value
它为“没有未来标签时如何训练长时世界模型”提供了结构性答案：寻找 action algebra 中可解析验证的关系，而不是继续设计短时视觉 proxy。这个想法可推广到 identity、inverse、composition、conservation 和等价终态，是视频世界模型 post-training 与 benchmark 设计的重要方向。尤其值得借鉴的是训练 verifier 和评估 matcher 分离，以及把 closure 做成 dense path-wise signal。

## Strengths
问题真实且 insight 简洁；奖励目标不依赖外部真实视频，能直接利用模型 rollout；spatial 与 temporal reward 分工明确，warm-up/联合/单项消融完整；CycleBench 同时测终点、路径、重复和跨 cycle 污染，并用独立 matcher 降低 reward overfitting；与同 checkpoint 的 WorldCompass 比较较公平，长时、组合动作和视觉质量均有证据。

## Weaknesses
精确监督只适用于有逆元、近似静态的 camera ego-motion；遮挡、光照变化、随机角色运动、碰撞、形变和持久状态变化都使“返回同一像素状态”不成立。CoTracker/RoMa 的 2D correspondence 只是 observable proxy，可能奖励纹理复制而非真实 3D/语义状态闭合，也无法验证前进途中是否经过正确的世界状态。benchmark 与训练目标高度同构，尚未证明 closure 改善可转化为开放轨迹预测、规划成功或真实交互。论文未给多 seed、置信区间或人工评估，380 个首帧规模也有限；4,000 张图的 post-training 可能偏向静态场景。与两项并行 cycle consistency 工作概念相近，差异主要在将闭环作为 RL scalar reward。

## Future Work
作者提出扩展到 approximate reversibility、机器人操作和其他 action modality，并通过守恒律、等价终态等解析约束覆盖不可逆过程。还需要建立 3D/object-centric closure metric、动态场景中的对称性条件，以及验证闭环训练对真实开放任务规划的外部效度。

相关度评分：3/3 (Core) - 直接解决交互视频世界模型的长时漂移、动作组合和可验证 post-training。
