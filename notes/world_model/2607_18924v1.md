# Learning Explicit Physical Parameter Control and Benchmarking for Video Generation

## Insight
论文的 insight 是视频生成要走向 world simulation，不能只依赖隐式统计物理常识；需要实例级、可控的物理参数绑定。作者观察到现有 I2V 在长尾力、质量、摩擦、恢复系数和多物体交互中容易生成视觉合理但物理错误的运动，于是构造参数化模拟数据和 physical attention routing。

## Motivation
当前视频生成模型画质和时序连贯性提升明显，但对明确外力、材料属性、重力等物理参数的响应不稳定，且多物体时条件容易泄漏到错误对象。同行常用文本提示、外部 simulator trajectory 或简单 force condition，缺少大规模细粒度物理标注和专门 benchmark。这个问题与物理可控视频世界模型高度相关。

## Method
PhyParam-Dataset 用 Blender 构建 130K 物理模拟视频，覆盖 free fall、elastic/inelastic collision、inclined plane、external-force-driven dynamics，含力向量、质量、摩擦、恢复系数、重力、轨迹和 mask 标注。PhyParam 基于 Wan2.2-TI2V-5B，输入 first frame、对象 mask、局部 force/material token 和全局 gravity token。Physical Parameter Attention 让 mask token 只 attend 到对应对象的物理属性，避免实例条件泄漏；DINOv3 特征空间监督对齐对象 identity、shape、boundary 和 temporal displacement。

## Experiment
PhyParam-Bench 含 380 个测试，评估 temporal dynamics、spatial structural stability 和 semantic-physical alignment，指标包括 FVMD、OC、SC、IoU、VLM-QA。Ours-All 对 general models 达到 FVMD 355.5、IoU 17.8、OC 58.1、SC 96.4、VLM-QA 69.5，整体优于 CogVideoX、HunyuanI2V、Wan2.2。与 Force Prompting 比，Ours-Force 的 VLM-QA 74.4 略高，但 FVMD 较差。人工评估 temporal/spatial/semantic preference 分别为 74.48/68.97/75.17，Spearman ρ=0.80。消融显示 feature alignment 将 FVMD 801.9 降到 408.4，加入 temporal feature alignment 到 355.5；去掉 Physical Attention FVMD 355.5->473.4、IoU 17.8->11.9。

## Value
对视频世界模型有直接启发：显式物理参数、实例绑定和物理 benchmark 可以弥补大视频模型只学视觉分布的缺陷。局限是仍在紧凑刚体和合成数据中，离通用物理世界模拟还有距离。

## Strengths
数据、模型、benchmark 三件套完整；显式参数控制粒度细；实例级 routing 针对真实痛点；实验和消融比较充分。

## Weaknesses
以合成刚体为主，sim-to-real 只做初步验证；force 默认作用于质心，不建模扭矩；不覆盖 deformable、fluid、cloth、fracture、soft body 或 articulated dynamics；VLM-QA 物理评分仍有噪声。

## Future Work
作者计划结合 differentiable physics，并扩展到更丰富的交互类型，包括非质心力、deformable objects、fluids、cloth、fracture、soft bodies 和 articulated dynamics。

## Rating
创新度评分：3/5 - 数据和实例级物理控制扎实，但基本范式仍是视频扩散模型加条件与监督。
相关度评分：3/3 (Core) - 直接面向物理可控视频生成和视频世界模拟。

## TL;DR
PhyParam用显式物理参数控制I2V刚体运动，并给出数据和基准，值得精读。
