# Seeing Together, Acting Apart: Shared Environmental Understanding for Multi-Robot Navigation

## Insight
多机器人协作可以先共享环境表示，再由各自策略决策。作者把各机器人视角放入匿名记忆，并用时间/视觉相似度检索；导航成功率和潜在逆动力学动作恢复均提高，表明共享观测含有可用信息。但改善不全能归因于世界模型，因为检索和额外历史本身也增加了观测。

## Motivation
常规多机器人导航共享动作、轨迹或联合策略，难复用于异构策略；部分视角环境信息若能汇聚，可能帮助分散决策。与隐式世界模型有关，重点仍是导航协作接口。

## Method
SEER Pool 存时间戳和第一人称图像，按新近程度与特征 SSIM 加权抽取固定 8 条上下文。SEER-World 用 JEPA 式编码器、停止梯度目标编码器和动作条件预测器做一步潜在转移；针对前进/左/右枚举未来潜状态，投影为软 token 插入 StreamVLN 或 Qwen 导航模型。预测器冻结、下游策略单独适配。整体为现有检索、潜在预测和软提示的组合。

## Experiment
Habitat 的 R2R-CE/RxR-CE 未见场景，报告导航误差、SR、SPL、nDTW；双机器人配对另报个体成功 ISR 和共同成功 CSR。StreamVLN 的 R2R SR 56.9→58.1%，Qwen3.5-4B 为 40.3→44.9%；同场景交叉路线中 Qwen CSR 18.1→23.9%。潜在逆动力学探针在 R2R 上 95.4%，均匀检索版本 92.1%、V-JEPA2 78.2%。与共享历史/动作/观测/空间描述比较亦占优。附录描述两种真机平台的部署，但没有给出真机成功率或误差统计。

## Value
可参考把多机器人观测压为策略无关世界 token 的接口；对单体视频/3D 世界模型的方法贡献较有限。

## Strengths
同一世界表示接入不同下游代理；有不同场景重叠程度、共享信息类型和逆动力学探针的对照。

## Weaknesses
主双机器人评测是配对的独立导航任务，不涉及碰撞、任务分工或真正协调；真机仅部署描述，缺量化结果。未测潜在预测误差、通信带宽/时延或地图持久性；来自不同机器人且只按相似度排列的视图与当前机器人动作未必构成真实动力学序列。

## Future Work
作者将更强的学习通信、地图共享与集中式多机器人架构留作后续比较；亦需真正协调和真机量化评测。

## Rating
创新度评分：2/5 - 共享观测检索加 JEPA 潜在预测与提示接口主要是组合式改进。
相关度评分：2/3 (Related) - 涉及隐式世界表征，但主要贡献和指标是多机器人导航协作。

## TL;DR
把多机器人图像汇入可检索潜在世界表示并提示独立导航策略，增益温和；可选读。
