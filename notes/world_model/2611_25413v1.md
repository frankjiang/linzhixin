# WAMotor: Accelerating World Action Models via Speculative Inference under Dual Nonuniform Denoising Dynamics

## Insight
世界动作模型的流匹配速度并非全程同样平滑：首尾相邻步变化大，中段变化小；而同样的速度复用残差在大积分步长下产生更大的动作状态误差。作者测得首尾两段占相邻速度 MSE 总量的 66%–80%，据此先做一次正常 Euler 更新，再用新的速度作推测锚点。其 Lipschitz 推导给出终点路径误差由各复用残差、步长、传播因子及条件误差上界控制；这是同初噪声下的条件性路径界，未单独保证动作分布或任务成功率。

## Motivation
联合未来表征与动作生成的 WAM 常需多步流匹配采样，控制延迟高。训练额外小草稿模型不够即插即用；直接复用旧速度推测中间步，又忽略首尾速度剧变与非均匀步长。问题与实时机器人策略推理相关，对视频世界模型的采样调度可间接借鉴。

## Method
冻结原模型，不另训草稿。第 0 步先正常积分；随后以锚点速度外推多个候选动作状态，批量查询原模型速度，接受满足“速度残差平方 ×（当前步长/中位步长）平方 ≤ 阈值”的最长前缀，遇失败则校正并重选锚点。联合视频–动作 WAM 同步推测未来视觉状态与动作，但接受判据落在动作速度；另两种模型主要加速动作采样。创新为按速度非均匀性选锚、按步长分配验证容差。

## Experiment
RTX 5090 上比较 LIBERO、RoboTwin 2.0、LIBERO-Plus 的成功率和每次推理延迟，覆盖 Joint-WAM、Fast-WAM、Faster-WAM，并与 VLA-Cache、TeaCache、BAC、ParaStep、SpeCa、FlowCast 对比。LIBERO 三模型延迟分别从 660.83/387.54/275.85 ms 降至 216.44/92.57/90.10 ms，成功率 98.00/97.10/99.20%，接近原模型的 98.35/97.10/98.60%。LIBERO-Plus 的 Joint-WAM 为 67.30% 与 212.54 ms，优于 FlowCast 的 65.87% 与 245.45 ms；Fast-WAM 为 51.16% 与 91.51 ms。去掉锚点选择或步长验证均损失成功率或时延；附录测试不同积分日程和与特征缓存叠加。

## Value
适合需要减少流匹配采样延迟的世界动作模型，也提示视频生成器在做速度复用时应测量不同去噪阶段的残差并按步长约束状态误差。对 3D 表征学习与 JEPA/Dreamer 潜状态设计本身帮助有限。

## Strengths
跨三种 WAM 形态、三个机器人基准测试，含域外扰动；与最接近的训练外推测方法 FlowCast 正面对照，并提供锚点与验证两个组件的消融和步长敏感性分析。

## Weaknesses
理论界依赖未估计的 Lipschitz/条件误差项，难由所用阈值直接推出实际分布或控制误差；没有真实机器人时延/安全验证。只以动作成功率量化总体效果，联合模型生成未来视频的质量及长时一致性未单独评测。

## Future Work
作者未明确列出后续计划；可进一步把条件误差项纳入在线验证，并测量视频预测质量及真实设备上的延迟和闭环稳定性。

## Rating
创新度评分：3/5 - 将去噪阶段与非均匀积分步长纳入推测验证有明确增量，核心速度复用和批量验证沿用现有方法。
相关度评分：2/3 (Related) - 直接优化含世界预测的动作模型，推理策略可借鉴于流式视频生成，但主要评测是机器人动作。

## TL;DR
依据速度残差与积分步长调整推测式动作采样，显著降低世界动作模型延迟；若关注实时推理，值得精读。
