# Faster-WAM: Do World Action Models Need Deep Action Modules?

## Insight

论文质疑 MoT 式 World Action Model 的惯例：视频 DiT 已在 30 层中形成多层次动力学表征，动作模块不必逐层复制同样深度；真正需要的是让浅 head 能读取全部层。作者用单层动作头配合跨层 KV 融合，在 LIBERO 上反而略强于深动作头，并把延迟从 211.7 ms 降至 66.5 ms，支持“表示访问方式比 head 深度更关键”。LIBERO-Plus 中 final-layer-only 已明显改善，加入全层融合、RoPE 对齐和移除重复文本 cross-attention 后由 60.3% 逐步升至 75.0%，也说明浅头失效的部分原因是路由与位置基不匹配，而非容量不足。

## Motivation

WAM 将机器人动作预测接到预训练视频世界模型上，但 shared-backbone 需要完整视频去噪，MoT 又常令 action DiT 与 video DiT 一一对应，导致动作推理仍很重；Fast-WAM 即使跳过未来视频生成也需 211.7 ms，明显慢于 π0.5。低延迟是闭环控制的关键问题，且“视频 backbone 的动力学知识是否足以支撑轻量动作读出”也关系到 WAM 的架构定位。

## Method

DoT（Dock of Transformers）把视频 Transformer 视为 hub，任务 head 通过显式 docking interface 访问所有层的 KV，而不要求 head 深度与 hub 对齐。Faster-WAM 用 30 层 Wan2.2-TI2V-5B 做 hub，只接一个约 30M 参数的 action Transformer layer；约 20M 参数的 KV-Fusion 先用独立线性映射把视频 K/V 投到动作空间，再按 attention head 学习跨 30 层的聚合权重。

视频 token 使用 3D RoPE、动作 token 使用 1D RoPE，直接混合会让注意力依赖绝对的动作/时空坐标，失去一致的相对位移性质。作者先逆 3D RoPE 得到 canonical KV，在该空间融合，再归一化并施加动作侧 1D RoPE；附录给出矩阵推导。动作头用自身 KV 与融合视频 KV 做 mixed-context attention，文本只经语言条件的视频 hub 进入，动作侧 text cross-attention 被移除。训练沿用 Fast-WAM 的 flow matching 和 32 步 action chunk，联合微调视频 backbone、动作头、融合模块和 proprio encoder，VAE 冻结。创新主要是 hub–head 解耦和 RoPE 重新对齐。

## Experiment

LIBERO 使用 40 任务、2,000 条示范、每任务 50 次评估；RoboTwin 2.0 使用 50 任务、27,500 条示范，clean/randomized 各每任务 100 次；同一 LIBERO checkpoint 在 10,030 个 LIBERO-Plus 扰动实例上评测。Faster-WAM 在 LIBERO 达 98.5%，略高 Fast-WAM 的 97.6%；RoboTwin 平均 89.17%，低于 Fast-WAM 91.64% 和 LingBot-VA 92.20%。LIBERO-Plus 达 75.0%，相对 Fast-WAM 51.5% 提高 23.5 点，尤其 Camera 16.4→67.9、Sensor 37.7→82.3，但仍低于 π0.5 85.7%。

在同一 24GB 消费级 GPU 上，完整 32 步 action chunk 延迟 66.5 ms，优于 π0/π0.5 的 68.2/71.4 ms 和 Fast-WAM 的 211.7 ms；但文中承认不同方法包含的输入编码操作略有差异，Fast-WAM 的 T5 与模型延迟还是分开测量后相加。顺序消融显示基线 49.5、final-only 60.3、+KV-Fusion 66.8、+RoPE 71.3、-动作文本交叉注意力 75.0；缺少对每个组件的正交/反向消融和多 seed 误差条。

## Value

DoT 给出一个值得推广的原则：大型视频世界模型更适合作为分层表示 hub，控制、可供性和导航应由可替换轻头读取，而不是复制另一套深 Transformer。它对 WAM 实时部署和多任务复用有直接启发；但当前性能提升也可能来自架构正则化和联合微调，而不是已经证明视频预训练表征蕴含充分物理动力学。下一步需冻结/扰动 hub、比较非视频 backbone，并在真机闭环验证。

## Strengths

- 问题定位明确，单层动作头带来 3.2× 实测延迟加速，同时保住三套基准的较强成功率。
- KV-Fusion 让 head 自适应读取全层，层权重可视化显示信号集中于中层但遍布各层。
- 识别并形式化推导 3D/1D RoPE 混合的基不一致，修复不是纯经验技巧。
- 同时覆盖标准操控、双臂操控和七类 OOD 扰动，且无需额外 embodied pretraining。
- 对“深动作专家是必要组件”给出有力反例，架构结论清晰。

## Weaknesses

- 所谓表示 hub 并未冻结：约 5.05B 参数整体联合训练，因此不能证明预训练视频动力学可被固定的单层 head 直接读取。
- 主要对照来自不同论文，训练数据、预训练和实现并不统一；只有与 Fast-WAM 较接近，且其延迟测量方式也不完全一致。
- LIBERO 接近饱和，0.9 点提升缺少 seed、置信区间和显著性；RoboTwin 又确实低 2.47 点，存在容量折衷。
- 顺序消融不能分离组件交互，例如移除文本 cross-attention 的收益是否依赖 RoPE/KV-Fusion 未知。
- 没有参数量、显存、能耗、训练成本和动作质量/抖动的完整效率曲线；66.5 ms 只覆盖特定硬件与 10 次去噪。
- 仅仿真离线示范学习，没有真机、在线闭环、错误恢复或视频预测质量证据；“物理动力学表示”仍是间接推断。

## Future Work

作者明确计划在真实机器人上评测，并把 DoT 扩展到导航、affordance prediction 等任务。还需要探索多 head 共用 hub、冻结或参数高效微调、跨 embodiment 迁移、自动选择层及可校准的动作不确定性。

## Rating

创新度评分：3/5 - hub–head 解耦、跨层 KV 路由和 RoPE 重对齐组合完整，效率与 OOD 收益明显；但未证明冻结世界模型即可支撑浅头，实验比较与消融仍有混杂。

相关度评分：3/3 (Core) - 直接研究视频世界模型与动作预测耦合的 WAM 架构及实时控制，是视频世界模型用于机器人策略的核心问题。

## TL;DR

以全层 KV 对接单层动作头大幅加速 WAM，架构启发强但机制证据未闭环，值得精读。
