# Mem-World: Memory-Augmented Action-Conditioned World Models for Persistent Robot Manipulation

## Insight
Observation：机器人操作中的 wrist camera 高频运动且常被夹爪/物体遮挡；当前帧不足以预测未来视角，普通自回归世界模型会遗忘或幻觉先前见过的对象。

推论：历史帧检索不能只按时间邻近或关节相似度，应按未来 wrist viewpoint 下可见的 4D surfel coverage 来取回真正有信息的过去观察。

## Motivation
论文解决 persistent robot manipulation world modeling：多视角 action-conditioned video rollout 要在遮挡和回访中保持对象/场景一致。

同行如 Ctrl-World 用固定 stride 或 joint-pose similarity 选历史帧；导航里的 VMem/FOV overlap 假设场景静态。操作场景有动态物体、腕部视角和结构性遮挡，需要动态、任务相关的几何记忆。

## Method
提出 Mem-World，核心是 W-VMem：
- 初始化：从首帧多视角构建全局 surfel memory。
- Surfel 属性：位置、法向、半径、时间集合，以及 manipulated-object flag。
- Future wrist pose：由未来动作经 forward kinematics 和腕相机外参得到。
- Memory read：从未来 wrist camera pose 渲染 surfel，按可见 coverage、时间、任务相关性打分，选 top-K 历史帧作为 context。
- Memory update：自回归生成后，用 wrist-view 预测帧更新 surfel memory。
- World model：多视角 action-conditioned generator，条件为当前观测、检索历史帧和未来动作。

创新点在于 4D wrist-view-centered surfel-indexed memory，把几何可见性和操作动态结合。

## Experiment
DROID replay consistency、策略评估相关性、合成数据后训练。

结果：
- 34 条 memory-stressing trajectory，20 秒自回归 rollout。
- Third-view：Mem-World PSNR 25.30、SSIM 0.878、LPIPS 0.054、Obj.Con 0.619，优于 Cosmos Predict 2.5 和 Ctrl-World。
- Wrist-view：Mem-World PSNR 19.21、SSIM 0.691、LPIPS 0.236、Obj.Con 0.524，优于 Ctrl-World 17.34/0.623/0.281/0.476。
- 消融：W-VMem 明显优于 short-term memory 和 stride memory。
- 策略评估：Mem-World rollout success 与真实成功率 Pearson r=0.97，Ctrl-World r=0.85。
- 合成数据：长时任务真实成功率从 58% 提升到 72%。

## Value
这是本批次里对“persistent state/memory”最直接的模型方案之一。对视频/3D世界模型的启发是：持久性需要可查询的外部状态载体；仅扩大上下文窗口不够，检索应绑定未来视角和场景几何。

局限：依赖点图估计、相机/机器人标定和 forward kinematics；没有显式接触/力学约束，可能预测物理上不成立的抓取成功。

创新度：4⭐ — 针对持久操作世界模型提出清晰的几何记忆机制，并在评估、策略评价和数据生成上都有强结果。

相关度：3 (Core) — 直接研究 action-conditioned video world model 的持久记忆问题。

## TL;DR
用 4D surfel 几何记忆检索历史帧，显著增强机器人视频世界模型持久性，值得精读。
