# DreamMimic: Learning Visuomotor Whole-Body Loco-Manipulation via World Model

## Insight

观察是视觉人形 loco-manipulation 的单步动作模仿即使当前预测正确，也不会约束学生动作在部分可观测、接触丰富系统中的未来后果，误差因而累积。论文推论是无需让 Dreamer 负责规划：只需把 action-conditioned RSSM 作为历史表征，并从同一 posterior latent 分别用教师/学生动作展开短程 prior，拉近两条未来 latent 轨迹，就能为策略蒸馏加入“后果一致性”。移除三步 latent distillation 后 OMOMO 成功率从 92.2% 降至 70.6%，支持这一机制；但仍是仿真中的经验因果证据。

## Motivation

全身人形操作同时具有高维动作、视角遮挡、离散接触和长程协调，纯视觉 RL 很不稳定；现有方法又常依赖部署时不可得的物体状态、接触图或状态估计器。Dreamer 可从像素学潜在动力学，但在高维 humanoid benchmark 上直接规划/优化仍困难。论文瞄准的关键问题是：如何把有特权状态的强教师蒸馏为仅依赖机载视觉和本体感知的学生，同时减少长期漂移。

## Method

- 先按 InterMimic 的 specialist→generalist 路线训练可访问真值物体位姿、interaction graph 和 contact 的 privileged teacher。部署学生只接收非特权 proprioception、包含目标物体位姿与短程机器人轨迹提示的 goal，以及由视觉/历史推断的 world-model features。
- Dreamer-style RSSM 由轻量 CNN/MLP 编码 depth、segmentation、proprioception 和上一动作；GRU deterministic state `h` 加 stochastic state `s` 建模 posterior/prior。它重建视觉和本体感知，并预测 reward、privileged vector、contact 与 13-D object state；学生用 h 和这些预测值，而不用在线真值。
- 多步 latent distillation 从同一 posterior `zt` 出发，冻结 world model，分别以学生和教师 mean action 通过 prior 想象 H=3 步，并对 deterministic/stochastic latent 的距离求和。这是动作后果一致性正则，不是 imagined policy optimization。
- 学生主损失为 teacher action matching，加 latent consistency 与较低权重 PPO；world model 从 student replay 独立周期更新，避免表征目标与策略同时漂移。
- Performance-Conditioned Guidance 用教师/学生 shaped reward 的 EMA 相对比动态调节 teacher-driven environment 比例，模仿系数保持固定；另以失败窗口更新 reference buffer curriculum。
- 创新主要是把 RSSM 从规划器改造成蒸馏表征与多步监督度量，并和 PCG 组合，属于 Dreamer 在高维视觉控制中的新用法。

## Experiment

- 仿真数据：OMOMO 选 large table、wooden chair、plastic box、small box、suitcase；BEHAVE 选 backpack、plastic container、stool，重点为平均超过 300 步的长序列。指标为成功率 Succ.、持续步数 Time、机器人逐 link 误差 Er（cm）和物体误差 Eo（cm），另做物体质量 ×5/×2 stress test。
- OMOMO：DreamMimic 达 92.2%/184.18/5.4/8.8；直接视觉 DAgger+RL 的 ResNet-18 为 72.6%/169.49/7.8/9.7，Simple-CNN 成功率最高也仅 76.5%。×5 重物时 DreamMimic 为 41.2%/120.29/8.1/14.8，优势缩小。
- 关键消融：无多步 latent distillation 为 70.6% 成功率、Er/Eo 7.9/12.8；RecH-only world model 为 86.3%、7.5/12.7；加入 object-state prediction 后 Eo 降到 10.0；aux heads 只作 loss 而不输入 policy 时为 84.3%；仅 stochastic feature 为 74.5%；无 action conditioning 为 90.2%；无 recurrent deterministic state 为 88.2%。
- BEHAVE：naive annealing 与 PCG 成功率均为 72.7%，但 PCG 的 Time/Er/Eo 为 289.53/10.2/13.3，优于 naive 的 275.21/15.2/14.9；×2 重物时两者成功率仍同为 63.6%，PCG 主要改善误差而非成功率。
- RL-only ResNet-18 与 single-stage Dreamer 在 OMOMO/BEHAVE 均为 0% 成功，说明 privileged teacher distillation 而非 world model 单独承担了主要可行性来源。
- Unitree G1 morphology、Isaac Gym→Isaac Lab 和不同物体仅给出定性稳定性案例；失败分析显示遮挡/模糊接触、手部接触不精确和重物抬举仍会失败。

## Value

对隐式世界模型研究的启发很直接：world model 不一定必须承担规划；其 action-conditioned latent geometry 也可作为比较策略未来后果的监督空间。该范式适合复杂动作空间中“直接 Dreamer 不可训、强教师可得”的场景。真正落地仍需解决视觉输入的仿真真值依赖、真实机器人域差异和精细手物接触。

## Strengths

- 清楚区分 world-model representation learning 与 policy learning，避免把 RSSM、策略和辅助目标硬塞进同一漂移目标。
- 三步 teacher/student latent rollout 针对长期误差给出简单、可实现且消融效果大的监督信号。
- 主表同时比较视觉 encoder、RL/DAgger/DAgger+RL、Dreamer、world-model 组件、动作条件和 recurrent state，控制变量较丰富。
- 报告重物压力测试与失败模式，并克制地把 G1 和跨 simulator 结果称为定性 sim-to-sim 证据。

## Weaknesses

- 所有结果都在仿真中，视觉通道是 ground-truth rendered depth 和 segmentation，不包含真实传感噪声、分割误差或 sim-to-real；作者明确未做硬件实验。
- 没有多随机种子、误差条或显著性检验，且只选 OMOMO 五类、BEHAVE 三类物体；成功率差异的稳健性难判断。
- 主方法同时引入 RSSM features、多类 privileged auxiliary targets、三步 latent loss、PPO、PCG 与 reference buffer，虽然有多项消融，但缺少完全等算力的逐步组合表，贡献仍有耦合。
- teacher-guided distillation 是可行性的主要来源：单阶段 Dreamer 与纯视觉 RL 均 0% 成功；因此结果不能证明 world model 本身已能解决任务，更准确的结论是它改善强 teacher-student pipeline。
- PCG 在 BEHAVE 及重物版本没有提升成功率，只改善持续时间和 tracking error；“避免人工 schedule”也仍需选择 reward shaping、EMA 和目标 performance ratio。
- 学生训练需要 privileged object/contact/interaction annotations 作为辅助 target，部署虽不输入真值，但数据采集仍强依赖模拟器；goal 又提供目标物体位姿和短程人体轨迹提示，任务信息并不弱。
- 论文未充分披露网络规模、训练步数、超参数、算力和推理时延，复现信息不足。

## Future Work

作者在失败分析中明确提出更鲁棒的感知、触觉或局部手物控制、遮挡下 recovery behavior，并指出需要真实机器人验证。作者还把手部接触不精确归因于 retargeting，暗示需改进细粒度 hand-object dynamics。合理但非作者明确提出的后续，是多种子评估并用受控 factorial experiment 分离 PCG、auxiliary predictions 与 latent distillation 的贡献。

## Rating

创新度评分：3/5 - 将 RSSM 用作动作条件多步蒸馏度量有明确方法新意且消融增益大；但核心模块为既有 Dreamer/DAgger/PPO 组合，验证仅限仿真。

相关度评分：3/3 (Core) - 直接使用 Dreamer 式隐式世界模型学习视觉动作动力学，并研究其在控制中的作用，属于核心相关。

## TL;DR

把Dreamer RSSM改作多步师生潜空间监督，显著稳住仿真人形操作，方法相关，值得精读。
