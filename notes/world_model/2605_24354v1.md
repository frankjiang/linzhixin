# SparseWorld: Enhancing End-to-End Autonomous Driving via World Models with Sparse Scene Representation

## Insight

现有驾驶世界模型（图像生成型、BEV occupancy型）依赖密集场景表示，计算开销大且包含大量冗余信息。人类驾驶员实际上只关注关键实例（车辆、行人、地图元素），而非完整场景重建。因此可以用**稀疏实例级表示**替代密集表示来构建更轻量高效的世界模型。

## Motivation

- 密集世界模型（DriveWM生成图像、Drive-OccWorld生成occupancy）计算量大（UniScene 23.5GB/28s，Drive-OccWorld 20.5GB/398ms），难以实际部署
- 实例级预测对下游规划任务更直接有用——密集表示中大量背景信息对规划无实质贡献
- 现有端到端驾驶框架（SparseDrive, VAD）已采用实例感知架构，天然适合接入实例级世界模型

## Method

**框架三阶段**：
1. **实例感知端到端驾驶基线**：从历史传感器数据推断当前实例（agent + map）、动作条件和初始轨迹
2. **Sparse Dreamer 未来预测**：
   - Instance Memory Queue (IMQ)：缓存历史和预测实例
   - Global Instance Alignment (GIA)：通过自车运动补偿和速度调整，将实例anchor投影到未来位置
   - SparseWorld Decoder (SWD)：自回归Transformer，集成时序cross-attention（带相对位置编码）+ 动作条件注入（Fourier编码）
   - Future Motion Planner (FMP)：从预测的未来实例推断未来动作条件，形成自回归闭环
3. **Motion Planning Refinement**：
   - 用预测的未来实例替换历史实例输入运动预测器，获得更准确的运动预测
   - Safety-Critical Loss (SCL)：基于碰撞检测的安全损失，显式惩罚碰撞风险
   - Adaptive Trajectory Selection (ATS)：从基线轨迹、未来预测轨迹、SCL优化轨迹中选择最安全的

## Experiment

- **数据集**：nuScenes（开环）+ Bench2Drive（闭环CARLA仿真）
- **基线集成**：SparseDrive-S（稀疏感知）和 VAD-Tiny（密集BEV感知）
- **实例预测**：2s时3D检测NDS提升82.8%，在线建图mAP提升86.4%（vs copy&paste基线）
- **开环规划**：SparseDrive-S上碰撞率从0.08%降至0.05%（SOTA），L2误差也有改善
- **闭环规划**：Bench2Drive上Driving Score达48.95（+9.9%），Success Rate 18.23%（+9.1%）
- **效率**：仅4GB显存，70ms生成4帧未来实例（vs UniScene 23.5GB/28s）
- **消融**：Agent和Map实例均有贡献且存在协同效应；SCL主要降低碰撞率，FIF主要降低L2误差，ATS进一步抑制碰撞

## Strengths
亮点是创新度：3/5 — 稀疏实例级世界模型的思路清晰且有效，相比密集世界模型在效率和规划效果上都有明显优势。

## Weaknesses
不足是相关度：1/3 — 虽然是3D世界模型，但核心是面向自动驾驶规划的实例级预测，不涉及视频生成、通用3D场景建模或隐式表征学习，与视频/3D/隐式世界模型的研究方向关联有限。

## TL;DR
提出稀疏实例级驾驶世界模型SparseWorld，用自回归Transformer预测未来agent和地图实例并优化规划轨迹，效率远优于密集世界模型且碰撞率达SOTA；偏应用导向，与通用世界模型研究关联较弱，可略读。
