# How do World Models and Policies Compose in LLM Agents? A Joint Spectral and Behavioral Account

## Insight

核心观察是同一基础 LLM 上，world-model RL 与 policy RL 的参数更新并非简单覆盖：两者的右奇异子空间高度重合，即读取相似 input-feature directions；左奇异子空间却近正交，即把这些特征写向不同 output directions。ALFWorld 中 module-wise rank-1 overlap 左侧均值 0.04、右侧 0.63，$\tau^2$-Bench/Qwen3 复现为 0.04/0.81（PDF pp.7, 17）。投影干预进一步显示，移除 world-model 的主要输出方向几乎不损害 policy，而只保留其输入方向可恢复大量性能；顺序训练的 policy 还学到替代输入路径。证据支持“互补几何”这一经验机制，但作者承认尚不能把权重几何与行为差异建立因果链。

## Motivation

LLM agent 常先做 next-state world-model training，再用任务奖励做 policy RL，性能优于直接 policy RL；未知的是前者仅提供 warm start，还是留下结构性互补知识，以及 policy 阶段是否遗忘世界知识。弄清接口可指导阶段顺序、合并、辅助损失和世界模型保留。该问题与 Dreamer 式“模型—策略协同”概念相关，但实验对象是文本 LLM agent，而非视觉/连续控制 latent dynamics。

## Method

在 ALFWorld/Qwen2.5-7B 与 $\tau^2$-Bench/Qwen3-8B 上重训 base、world-model SFT、world-model RL（WMRL）、policy RL（PRL）和 WMRL→PRL。WMRL 用 GRPO 最大化预测 next state 与真实 state 的 frozen embedding 相似度阈值奖励；PRL 用 terminal success。相对共同初始化定义 $\Delta_X=\theta_X-\theta_0$，并以 $\Delta\Delta_{PRL}=\Delta_{WMRL+PRL}-\Delta_{WMRL}$ 隔离第二阶段。对每层 q/k/v/o/up/gate/down projection 做 SVD，分析 effective rank、rank-k 截断、幅度剪枝、左右子空间的 parallel/orthogonal/random projection 和 principal-angle overlap；重构 checkpoint 后端到端评测。行为侧测 next-state token entropy、成功集合、有效动作/状态覆盖与 turns。最后试验 TIES/KnOTS 的 U/V-basis 合并及 PRL 中在线 next-state SFT 辅助损失。

## Experiment

ALFWorld 3-seed AVG success：base 17.7±2.9，WMSFT 3.5±1.2，WMRL 32.7±3.3，PRL 78.3±0.9，WMSFT→PRL 60.8±1.5，WMRL→PRL 84.4±0.3；后者 OOD 为 81.8±0.7，对 PRL 的 71.9±2.6（p.3）。将 $\Delta_{WMRL}$ 截为 rank 1、保留完整 policy 后仍有 ID/OOD 77.6/79.7，完整模型为 87.0/81.8（p.15）。左侧从 $\Delta\Delta_{PRL}$ 去掉 WMRL top-500 directions 后为 91.7/84.9，反而略高于未投影模型；右侧只保留 top-500 directions 可达 83.6/79.7（pp.5–7）。行为上 PRL 与顺序模型的平均 unique states 为 8.1/9.7，turns 为 12.6/12.4；顺序模型在相近效率下恢复部分探索（p.8）。ALFWorld preservation 中，顺序 baseline 84.4；KnOTS-U/V 为 86.3/85.9，online WMSFT 为 85.0，但其 OOD 从 81.8 降到 79.5（p.9）。$\tau^2$-Bench 上 PRL 39.3±2.6、WMRL→PRL 45.0±1.6；训练免费 merge 最高仅 40.7，未超过顺序 baseline（pp.16, 20）。

## Value

论文提供一种拆解“隐式世界知识如何与策略能力共存”的可操作工具箱：同基座 task vectors、SVD 左右空间、功能性投影与行为 readout。最值得借鉴的是把 Transformer update 看成“读哪些特征”和“向哪里写出”的双侧接口，并据此设计 preservation/merge。其结论暂不能直接外推到视频或 3D latent world model，但对多阶段 world-model/policy post-training 有方法论价值。

## Strengths

- 不停留在 checkpoint 黑箱比较，而是用 projection、truncation、pruning 和重构后评测做功能性干预。
- ALFWorld 与 $\tau^2$-Bench 使用不同 Qwen 模型复现近零左重合、高右重合的几何模式。
- 同时报 success、OOD、探索、next-state readout 与保留干预，连接参数和行为两个层面。
- 明确报告反例和边界：WMSFT 虽低秩却崩溃，$\tau^2$ 行为投影效应较弱，merge 也未超过顺序训练。

## Weaknesses

- 仅有两个文本环境与 7B/8B Qwen；没有视觉 grounding、连续动作、随机物理动力学或显式规划，和视频/3D 世界模型的外部有效性有限。
- next-state 的 per-token entropy 被解释为 calibration，但低熵只表示更自信，不保证预测正确；正文没有同时给 next-state accuracy、NLL/Brier/ECE，可能把 confident error 误判为保留世界知识（p.8）。
- additive delta/SVD 依赖参数化与共同坐标；共享初始化虽减轻问题，但“左正交/右共享”的机制来源仍可能只是两阶段目标 token 分布不同，作者也未能隔离该混杂（p.9）。
- parallel rank-$k$ 与 orthogonal complement 维度和保留能量不对称；随机对照只匹配 rank-$k$ 子空间，没有匹配 Frobenius 能量，因此投影性能差异不能单独证明语义功能归属。
- success-set 非嵌套和探索覆盖是观察性相关，且 pass@1 受采样随机性影响；论文承认几何与行为之间没有直接因果证据。
- preservation 增益小且跨 benchmark 不稳：ALFWorld 最好只从 84.4 提到 86.3；online SFT 提高 ID 却损害 OOD；$\tau^2$ 的所有 KnOTS merge 都低于 45.0 顺序 baseline，在线方案未复现。

## Future Work

- 作者明确提出：在多模态 agent 上验证；解释左右子空间不对称的机制；扩展到 LoRA update；做 cross-module、layer editing、activation patching 或训练期 U/V 约束等更强因果测试；扩大模型/benchmark，并改进 scalable preservation（p.9）。
- 我们推断：应加入 proper next-state calibration/accuracy、能量匹配投影对照，并在视觉连续控制中检验该几何是否对应可复用的 latent dynamics 与规划收益。
