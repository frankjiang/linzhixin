# When Does Dynamics Randomization Test Context Inference?

## Insight
Observation：随机化动力学参数不等于当前状态、动作之外仍有可供上下文编码器利用的信息；不同参数在常访问状态可能产生近似转移，当前状态也可能已积累参数线索。论文将上下文带来的最优单步对数损失改善写成条件互信息 `I(θ; s′ | s, a)`，再用固定查询、访问查询、访问后验三种分布的核差异作诊断。MiniGrid 风力与连续吸引力实验显示，结构性差异很大时剩余信息仍可很小；重置状态后该信息上升，支持“状态隐含识别”的解释，但重置同时改变查询覆盖，不能完全归因。

## Motivation
模型式强化学习常用随机质量、外力等环境考查显式上下文推断；若观测状态已足够预测下一步，带上下文模型不占优并不能说明推断机制无用。论文要先量化基准本身留给上下文推断的预测空间。这是世界模型评测设计的有效问题，但与视频生成、3D 表示的直接联系有限。

## Method
- 设每集固定隐藏参数 `θ`、转移核 `Tθ(s′|s,a)`；以访问分布 `d(θ,s,a)` 计算预测余量 `I_emp = I_d(θ;s′|s,a)`，即知道真实上下文相对最优无上下文混合预测器的单步对数损失改善。
- `I_struct` 在固定、上下文无关的状态动作查询上用先验权重比较转移核；`I_match` 在实际访问查询上仍用先验权重；`I_emp` 在同一访问查询上改用访问条件后验。前两者差异反映查询覆盖影响，后两者差异包含状态携带的上下文证据及边际上下文频率变化；三量之间没有一般的大小界。
- 离散 MiniGrid 枚举转移核；连续 Point-Mass-Attractor 用已知高斯/反射核与交叉验证近邻后验估计。以状态分量重置干预检查信息是否积累于位置、速度。核心是评测诊断与信息论分解，不是新的世界模型训练法。

## Experiment
- MiniGrid Empty-8x8 的随机风力和动作失效概率，以及二维受四角吸引的点质量系统；每设置采集 5000 集随机动作轨迹，分别至多 256 和 50 步。指标为以 nat 计的单步预测余量及 bootstrap 区间，没有训练策略或比较任务回报。
- 代表设置中，风力的 `I_struct/I_match/I_emp` 为 `0.871/0.620/0.077±0.002`，吸引力为 `1.006/1.006/0.109±0.002`；两者大核差异并未转化为大访问余量。动作失效则为 `0.062/0.059/0.055±0.001`，主要是转移核本身相近。
- 风力每 10/2 步完全重置状态，余量由 `0.078` 升至 `0.411/0.723`；吸引力每 10 步重置位置和速度由 `0.112` 升至 `0.473`，仅重置位置升至 `0.143`。这表明速度保存了重要线索；重置实验未同时报告各自的 `I_match`，故覆盖与后验效应尚未彻底分开。

## Value
对 Dreamer 等隐式动力学模型设计环境随机化评测有借鉴价值：应连同随机参数报告查询覆盖、状态定义、上下文频率和实际可用预测余量，再解释有无显式记忆的模型差距。下一步需把诊断扩展到学习策略、图像输入及规划访问的分布外状态，并区分表示/优化误差与信息上限。

## Strengths
明确定义评测对象和数据收集分布；通过固定查询、访问查询和条件后验避免将“参数变化幅度”误当信息量；离散、连续环境及状态重置形成互补证据，主动指出估计偏差。

## Weaknesses
仅研究已知模拟器核下的单步预测及随机动作，无法直接判断长期规划或闭环控制收益。连续系统的上下文后验由近邻拟合，邻居数在计分折的标签上选择，bootstrap 未覆盖后验重拟合不确定性。重置同时改变访问区域和状态信息，且未给重置数据的匹配查询参照。

## Future Work
作者建议在不同重置协议下补报匹配查询差异，并在学习策略、真实机器人及各自控制分布上重新测量；还应评估规划所需的反事实状态动作覆盖与学习转移核的误差。

## Rating
创新度评分：2/5 - 条件互信息本身是已有概念，贡献主要是有用的评测分解和受控实例。
相关度评分：1/3 (Tangential) - 讨论世界模型的上下文评测，未研究视频、3D 或 JEPA/Dreamer 具体模型。

## TL;DR
用条件互信息检验随机动力学基准是否真正需要上下文推断；对隐式模型评测设计可选读。
