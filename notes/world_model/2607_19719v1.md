# Koopman Dreamer: Spectrally Constrained Latent Dynamics for Stable World-Model Imagination

## Insight
核心 insight 是 Dreamer 类 latent imagination 的长时程误差，部分来自 deterministic latent dynamics 没有显式 modal control。把 deterministic state 组织成 Koopman-style rotation-scaling blocks 后，spectral radius 可以直接调节误差衰减、持久记忆和近周期模式。作者的理论 bound 进一步说明：最小 contraction 不一定最好，过强会丢控制所需的慢变量；半径接近或超过 1 又会放大 rollout error。

## Motivation
DreamerV3 等 latent world model 在连续控制中依赖递归 imagined trajectories 训练 actor/critic，但普通 RNN/MLP transition 的 contraction、persistence、oscillation 都是隐式学出来的，难以诊断和调节。连续控制任务常有阻尼、周期、平滑动作响应和局部线性结构，Koopman operator 提供了用线性谱结构表示非线性动力学的视角。本文解决的是如何在 Dreamer-style RSSM 中显式约束 deterministic latent propagation，使长 horizon imagination 更稳定。

## Method
Koopman Dreamer 替换 DreamerV3 的 deterministic transition。latent state 分为 deterministic Koopman state phi 和 stochastic state s；phi 被偶数维拆成多个 2D rotation-scaling blocks，每个 block 有可学习 phase 和 bounded radius rho_i in [rho_min,rho_max]，因此 autonomous backbone 的 spectral norm/spectral radius 可控。控制项包括线性 action term、低秩 bilinear state-action interaction，用于表示 state-dependent action effect；stochastic-state modulation 把 posterior correction 注入 deterministic update。训练除 DreamerV3 base losses 外，还加 one-step Koopman consistency、multi-step teacher rollout、posterior-free rollout、open-loop observation prediction 和 operator regularization；teacher targets 用 posterior-conditioned EMA projection 降低 target drift。理论部分给出 controlled rollout-error bound，把 autonomous amplification、bilinear interaction、stochastic mismatch 和 modeling residual 分开。

## Experiment
DMC proprioceptive 9 个任务上，Koopman Dreamer 最终分数在 6 个任务最佳，并在 8/9 任务超过 DreamerV3；Acrobot 从 DreamerV3 131.7 到 292.3，Hopper Stand 从 650.4 到 859.1，Reacher Hard 从 948.6 到 987.0。Open-loop 64 步预测中，proprioceptive observation mean MSE 从 0.6256 降到 0.4802，reward mean MSE 从 0.9290 降到 0.7318，deterministic latent mean MSE 从 0.0379 降到 0.00403。UAV-LiDAR Forest 中，成功率从 DreamerV3 53.8% 提到 73.8%，失败率从 46.2% 降到 26.2%，median return 更高。spectral sweep 显示 learned radius 0.881 附近观测预测最好，0.849 虽 latent MSE 最低但可观测预测不最优，1.026 导致 horizon-64 latent MSE 爆到 2.2675。消融中去 spectral 会显著增加 rollout error 和 action variation；去 bilinear success 掉到 8.8%，说明 state-dependent control 很关键。

## Value
这是隐式 world model 方向的核心相关工作。它把“latent dynamics 是否稳定”从经验现象变成可调的谱结构问题，对 Dreamer、TD-MPC 类递归想象模型都很有启发。尤其值得借鉴的是：不只约束谱半径，还要配合 teacher/prior rollout/open-loop prediction，使结构化 transition 在 posterior training 与 prior imagination 两种模式下都工作。

## Strengths
方法对 Dreamer 的改动集中在 dynamics core，结构清楚；理论 bound 与 spectral sweep、open-loop prediction、closed-loop control 互相对应；UAV-LiDAR 提供了比 DMC 更接近机器人导航的补充验证；消融能区分 spectral、teacher 和 bilinear control 的作用。

## Weaknesses
主要实验是低维 proprioceptive/vector observations，不是像素视频或 3D 场景生成。部分 DMC baseline 来自公开 DreamerV3 benchmark，严格公平性依赖协议一致。谱约束只作用在 autonomous backbone，不是完整受控系统的全局稳定性证明。UAV ablation 场景有限，真实物理部署和安全约束仍未验证。

## Future Work
作者提出未来研究 adaptive spectral ranges、更广泛的训练运行和环境评估，并结合 safety-aware 或 risk-sensitive policy objectives，以提升自主控制可靠性。
