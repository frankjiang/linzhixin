# Beyond Instance Slots: Semantically Rich World Models for Physical Interaction Planning

## Insight

论文观察到：instance slot 只回答“场景里有什么”，却不回答“在当前任务中它扮演什么角色”；同一物体随指令可成为 target、goal 或 distractor，交换对称的实体表示会把任务绑定、关系保持和进度判断全部推给下游策略。由此将任务无关软实体 $E_t$ 与任务相关预测状态 $Z_t=\{z^{grip},z^{tgt},z^{goal},z^{rel},z^{phase}\}$ 分离，并让后者同时成为动作先验、动力学状态和候选选择证据。Candidate-0 成功率从 monolithic latent 的 45.5% 升至 62.8%，Oracle@4 从 68.0% 升至 89.5%，说明提升在 reranking 前已出现，支持角色状态改变了动作生成覆盖，而非仅做后处理。但渐进消融同时改变状态参数化及其专属监督，未做完全 factorial 对照，因而不能单独证明“角色结构”而非额外标签/损失是充分原因。

## Motivation

像素或 monolithic latent 的低预测误差不等于可规划：候选未来可能抓错物体、丢失抓取、破坏已满足关系或过早释放。已有 object-centric world model 用实例 slot 提高组合性，却通常不显式编码 task role、谓词建立/保持和阶段进度；标准 diffusion policy 或 value head 也不保证候选动作产生任务一致的状态转移。SR-WM 试图把轻量 JEPA/latent world model 变成面向多候选规划的语义接口。问题关键且与隐式世界模型直接相关，但方案依赖预定义任务本体和密集 simulator semantics。

## Method

- **输入与底座**：输入多视角 RGB history、proprioception 和语言。以 15M 参数 LeWM（5M ViT-Tiny encoder +10M predictor）初始化并保留 latent prediction/anti-collapse 目标；完整 SR-WM+FM 为 45.4M。
- **软实体**：LeWM patch token 加入归一化坐标、camera ID 和时间差，learned query 跨视角迭代注意，形成含 appearance/geometry/motion/confidence 的 $N$ 个 task-agnostic entity hypothesis。这里只做有限观测窗内关联，不声称全遮挡后的持久 identity。
- **可选分割先验**：Grounding DINO box 可提示 SAM/SAM2，proposal-to-patch affinity 仅作为 attention additive bias；保留全部 patch，并分别 dropout proposal set、单 proposal 和 bias strength，因此可令 $\lambda_{seg}=0$ 做无 mask 推理。训练 role footprint 监督与“oracle mask 作为输入”的诊断被明确区分。
- **任务角色绑定**：五个非交换 query 用 instruction/proprioception 从实体中绑定 gripper、target、goal；relation 汇聚 gripper-target/target-goal 几何与谓词，phase 汇聚 approach→grasp→transport→align→release→complete 历史。target/goal identity、footprint、中心或 fixture part 只作训练 target，部署输入仍为 RGB、状态和语言。
- **语义动力学**：把候选 action chunk 划成 $J$ 个子段；role transformer 交替做跨角色 self-attention 与 action cross-attention，通过 gated residual 预测每个边界的 role state。语义 head 预测 contact/stable grasp、新谓词建立、已有谓词保持、conjunction、fixture state 和 phase/合法转移。
- **生成、选择、修复**：role-conditioned flow-matching head 从独立噪声采样 $K=4$ 条 horizon-$H$ 动作。stage-aware selector 联合当前/预测 phase、contact、establishment、preservation、fixture 和 uncertainty 排序。若最优候选低于阈值或在 $j^*$ 首次违规，则固定此前有效 prefix，在每个 ODE step 重新钉住 prefix，仅 inpaint 后缀；随后只执行注册前缀，observe 并 replan。
- **训练**：共 11 项 loss：LeWM、role binding/geometry、role dynamics、contact/grasp、predicate/conjunction、preservation、phase、fixture、action FM、hard-negative ranking、suffix inpainting。hard negatives 在同任务/归一化空间内打乱时序、反转 approach-grasp、替换轨迹或扰动 release。训练后期混入 expert、model rollout deviation 和 repair 三类 pool，并以预注册 shuffle margin/短闭环 validation 选择 checkpoint。

架构的实质创新是把 task-conditioned role state 提升为世界模型接口，并将“建立新关系”和“保持既有关系”显式分离；FM、slot attention、semantic head、reranker 和 inpainting 本身均属已知技术。

## Experiment

- **范围与指标**：仅在 LIBERO Object、Spatial、Goal、LIBERO-10 四套仿真上评测；主要报告 closed-loop success、Candidate-0、Oracle@4、selected top-1、hard-negative ranking、role probe、迁移和单 A100 效率。论文没有给每格具体 rollout 数、任务/seed 数及“±”的聚合定义，只说这些应在 artifact manifest 中记录。
- **生成与选择**：monolithic LeWM+FM 的 Candidate-0/Oracle@4 平均 **45.5/68.0%**，instance-slot selector 为 55.8%；SR-WM prior 的 Candidate-0 **62.8%**、Oracle@4 **89.5%**。semantic selector 达 75.3%，full resampling 78.5%，violation-aware suffix repair **83.0%**，仍比 Oracle 低 6.5 点。随机选 4 候选为 61.8%，说明收益并非仅来自多采样。
- **角色/分割诊断**：无 mask SR-WM 的 binding/relation/phase 为 88.3/89.1/80.8，rollout SR **72.6%**；soft prior 75.1%，corrupt prior 70.8%，oracle masks 78.4%。这支持 inference 不硬依赖 SAM，但测试仍限于 LIBERO 视觉分布。
- **动作敏感性**：完整模型 shuffled-action gap **0.157**、pairwise rank **78.2%**；无 semantic head 60.8%，无 hard negatives 53.7%，无 preservation/phase 为 69.4/66.8%。评价 negatives 与训练负例构造同源，因此证明的是对注册扰动的区分能力，不等同于任意反事实因果预测。
- **状态组成消融**：五 instance slots 55.0%，+instruction 62.0%，target+goal 68.0%，+relation 73.0%，完整 gripper+phase **83.0%**。增益单调但每步同时加入新状态、监督 head 和 loss；作者在附录承认未做状态参数化×监督的全因子分离，正文“严格必要/结论性证明”的措辞过强。
- **迁移**：Object→Spatial 零样本/适配/从头为 58.4/72.1/72.8，适配无优势；Object→Goal 为 52.7/74.6/66.3，→LIBERO-10 为 27.9/58.7/50.6；joint→held-out 为 65.2/78.4/69.8。说明源 suite 预训练在部分目标上提高数据效率，但不是普遍优于 scratch，也不控制总历史数据/计算。
- **效率**：完整 45.4M 模型在 A100-40GB BF16 上 peak train memory **9.2±0.4 GB**，K=4 action generation **30.2±1.2 ms**、semantic scoring **7.3±0.5 ms**。没有训练时长、端到端 control rate、优化器或关键维度/阈值；附录明确把这些留给尚未提供的 checkpoint metadata。

## Value

SR-WM 提供了比“预测一个 latent 再接 value head”更可解释的规划接口：候选动作不仅预测是否更接近目标，还判断何时接触、何时建立关系、是否破坏前提以及应从哪里修复。对 JEPA/隐式世界模型尤其有启发的是：规划状态的设计目标可以不同于通用表征目标，少量结构先验能把预测空间对齐到决策所需变量。当前价值仍主要是概念与仿真 proof-of-concept；固定 ontology、密集标签、缺外部强策略基线和真实机器人验证限制了结论外推。

## Strengths

- 清楚区分 task-agnostic entity 与 task-conditioned predictive state，角色不是附加语言分类 head，而直接参与生成和动力学。
- 将 predicate establishment 与 preservation 分开，并用中间边界定位首个违规，适合长程组合任务。
- Candidate-0、Oracle@4、selector 与 repair 分开报告，避免把候选覆盖上界冒充可部署 top-1 性能。
- 有无 mask、corrupt mask、oracle mask 对照，并审计训练 target 与 rollout input，特权信息边界写得较清楚。
- 完整系统仅 45.4M，候选生成和语义评分延迟较低。

## Weaknesses

- 只在 LIBERO 仿真、同一底座的内部变体上验证；没有与强 diffusion policy/VLA/object-centric planner 做端到端公平比较，也无真实机器人结果。
- 固定五角色假设单一 gripper、target 和 goal，不适合双臂、多目标、工具、可变形物体或动态角色图。
- 需要 task specification、native predicate、collision、fixture joint 与 phase parser 的密集训练监督；现实数据上的标签成本和噪声鲁棒性未验证。
- 关键消融联合改变表示与监督，不能把 55→83 的增益严格归因于 role parameterization；hard-negative 指标也与训练扰动同源。
- 实验统计与训练配置披露不完整，K sweep、rollout 数、seed、训练时长、optimizer、horizon、loss weight 等均未实际报告；“artifact 应包含”不能替代论文证据。
- suffix repair 增加模型调用，仍依赖预测语义正确；缺碰撞检查/低层 safeguard 时不适用于安全关键执行。

## Future Work

作者提出将固定五角色扩展为适配双臂、多目标、工具和可变形对象的可变基数 state graph；为物理数据建立低成本 predicate/phase 标注或估计；改善严重遮挡下的实体关联，并加入更细粒度/触觉信号以避免 phase lag 和过早释放；最后按附录中的 shadow execution、canary、workspace/collision 限制等安全门进行真实机器人验证。高 Oracle@K 与 selector 间仍有 6.5 点差距，也是直接的改进空间。

## Rating

创新度评分：3/5 - 将功能角色作为隐式世界模型的预测与规划接口有明确新意，语义选择/局部修复也形成完整闭环；但固定 ontology 与多项监督共同变化，证据仍限于单一仿真体系。

相关度评分：3/3 (Core) - 直接建立在轻量 JEPA/latent world model 上，研究 action-conditioned 隐式动力学及其在候选规划中的使用，属于隐式世界模型核心方向。

## TL;DR

以任务角色替代实例slot，将隐式动力学接入候选生成、语义选择与局部修复；仿真证据有限，值得精读。
