# A Definition and Roadmap for World Models

## Insight
主要 insight 是把 world model 定义为“在有限计算资源下，对物理世界状态转移过程的压缩建模”。Observation：当前 world model 论文混用视频生成器、3D 表征、latent dynamics、planner 等概念，导致评估和路线不清。推论是应以 physical state transition compression 为核心，再按 renderer、simulator、planner 等功能以及 observation-level、latent-space、3D/object-centric 等架构分层讨论。

## Motivation
领域快速扩张，但“world model”定义过宽：有的强调像素生成，有的强调 RL latent imagination，有的强调 3D 场景，有的强调 action model。论文要解决概念混乱和 roadmap 不统一的问题。它不是提出新算法，而是试图建立术语、分类和未来路线。

## Method
论文给出定义、属性和 taxonomy。三个关键属性包括 omnimodal workscope、多维异步性、locality/POMDP。功能上区分 renderer、simulator、planner；架构上讨论 observation-level generative WM、latent-space WM、3D/object-centric WM、World Action Models 等。

对技术路线的梳理包括：视频生成世界模型擅长可视化但可能物理不一致；Dreamer/TD-MPC/JEPA 等 latent 模型适合长时规划但可能丢失接触/细小物体；3D/BEV/NeRF/3DGS/object slots 提供空间一致性但动态、affordance 和因果仍难；WAMs 把视频预测和动作生成耦合，但牺牲模块化和校准不确定性。

## Experiment
无实验，是定义/综述/路线图文章。它总结了 VBench、WorldScore、4DWorldBench、PhyGenBench、WorldModelBench、PhyWorldBench、WorldSimBench、RoboArena、EWMBench、WorldArena、WBench 等评估方向，并强调仅有视觉指标不足，需要几何、物理、交互、长时一致性、实时效率和真实物理验证。

## Value
作为速读入口有价值：能帮助定位不同 world model 工作到底在建 renderer、simulator 还是 planner。对我们最有用的是它反复强调“理解优先，预测服务理解”，以及“one state, many decoders”的统一物理状态路线。缺点是观点广、证据浅，不应当当成技术贡献论文来读。

## Strengths
- 定义和 taxonomy 对整理领域有帮助。
- 同时覆盖视频、latent、3D/object-centric、WAM 和物理约束学习。
- 对数据不对称、视觉真实 vs 物理正确、长时误差和评估碎片化的讨论切中问题。

## Weaknesses
- 没有新模型、实验或可复现证据。
- 涉及许多近期系统和路线，部分判断更像观点而非严格结论。
- 定义仍较宽，可能难以约束“什么不是 world model”。

## Future Work
路线图包括三点：统一 multimodal world model，整合 video、3D、action/state 和 semantics；统一物理表示，即一个 compact state 支撑 rendering、simulation、planning 多种 decoder；构建 foundation-scale interactive simulators，并用真实结果和物理约束做闭环验证。

## Rating
创新度评分：2/5 - 概念整合和路线梳理有用，但算法与实验创新有限。
相关度评分：3/3 (Core) - 直接讨论视频、3D、隐式和机器人世界模型的定义与路线。

## TL;DR
这篇给出 world model 的压缩式定义、架构谱系和评估路线，综述价值高，值得快速精读。
