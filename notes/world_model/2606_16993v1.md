# DreamX-World 1.0: A General-Purpose Interactive World Model

## Insight
核心观察：交互式视频 world model 的瓶颈是长期 autoregressive drift、相机几何控制、重访一致性和实时性。作者将 camera-aware encoding、memory retrieval、long-rollout self-generated context training、few-step distillation 与系统加速组合，推论是交互世界模型需要“生成模型 + 几何记忆 + 在线效率”共同设计。

## Motivation
普通视频生成器是被动合成，不能稳定执行相机导航、返回旧区域、触发事件。已有 WorldPlay/LingBot 类模型在长时一致和实时交互上不足。问题对可玩/可导航视频世界模型核心相关。

## Method
数据来自 Unreal Engine 精确相机渲染、游戏记录、真实视频相机恢复。方法包括 E-PRoPE（低成本 projective positional encoding）、causal forcing 把双向视频生成器转成自回归 world model、DMD distillation、long-rollout training、Memory-Conditioned Scene Persistence、residual recycling、event instruction tuning、RL alignment。系统侧用混精 DiT、residual reuse、VAE 解码剪枝和异步流水线。

## Experiment
自建 5s basic evaluation，报告 camera-control score 73.75、overall 84.76，超过 HY-WorldPlay 1.5 和 LingBot-World。还做长时生成、重访一致性、事件控制和速度评估，8 张 RTX 5090 可到 16 FPS。评价仍以自建/人评/视觉指标为主，缺少下游决策闭环。

## Value
对视频世界模型很有价值，特别是相机控制、场景持久性和实时交互工程。局限是许多组件是工程组合，自动评测不成熟；作者也承认长时几何/外观仍会 drift，事件与相机/文本可能冲突。

## Strengths
亮点是对视频世界模型很有价值，特别是相机控制、场景持久性和实时交互工程。

## Weaknesses
不足是许多组件是工程组合，自动评测不成熟；

## Future Work
作者未明确提出具体未来工作；从局限看，后续需要围绕“许多组件是工程组合，自动评测不成熟”补充更大规模验证、跨场景扩展或方法改进。
