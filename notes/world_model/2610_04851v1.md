# CURIO: Curiosity-Driven Test-Time Learning for Open-Ended Discovery

## Insight
观察：只按任务奖励更新的测试时 RL 易收敛到已有高分程序，低分但可能有潜力的分支难再被探索。推论：用策略隐藏状态转移的预测误差，选择性奖励非最高概率 token，可维持程序搜索的结构多样性；消融和任务结果提供经验支持，但预测误差并不等于语义新颖性。

## Motivation
冻结 LLM 的程序搜索不会通过任务反馈更新参数；测试时 RL 会更新参数，却可能因偏重当前高分样本而早熟收敛。这是开放式数学/程序发现中的探索问题，与视觉或物理世界建模的目标不同。

## Method
在按任务奖励更新的 TTT-Discover 上加 Intrinsic Curiosity World Model：用策略隐藏状态作“状态”、生成 token 的词嵌入作“动作”，MLP 预测下一隐藏状态。缓存预测残差、按训练轮次归一化，只在采样 token 不属于策略 top-k 时加入带退火权重的好奇心项；主策略以 LoRA 更新。此模型预测的是 LLM 内部表征转移，并不建模外部环境。方法主要组合既有预测误差内在奖励、选择性 token 探索和测试时 RL。

## Experiment
六个数学发现任务及单细胞去噪；Qwen3 8B、14B、235B，比较冻结搜索、其他测试时 RL 和去掉好奇心的匹配基线，每项报告三次运行均值。对匹配基线，五个数学目标提升、圆填充持平；235B Hadamard 相对提升 18.3%，8B Tabula 去噪 Score 相对提升 10.8%。消融显示好奇心权重过大可能退步，MLP 与更复杂预测器各有优劣。程序多样性指标仅比较代码长度、行数、字符集合，不能证明解法语义差异；主表没有方差或显著性检验。

## Value
对 LLM 测试时探索有参考价值，对视频、3D 或 JEPA/Dreamer 式世界模型没有直接可迁移的建模或评测贡献。

## Strengths
设置了去掉好奇心的匹配对照，并清楚区分预测误差、代码结构差异与语义新颖性；跨模型规模和任务检查效果。

## Weaknesses
“世界模型”只预测 token 级内部状态，缺少物理时空状态或环境转移；编码器与预测器联合优化存在常数表征坍塌可能。未独立消融非 top-k 掩码；代码多样性可被格式差异影响，主结果只给三次均值。

## Future Work
作者未给出明确后续方案；值得进一步验证掩码规则、语义多样性及表征坍塌对探索收益的影响。

## Rating
创新度评分：1/5 - 就目标领域而言，是将常见预测误差好奇心机制用于 LLM 程序搜索，几乎没有视觉/物理世界模型新技术。
相关度评分：0/3 (Noise) - 研究对象是 LLM 测试时发现与生物数据去噪，名称中的 world model 不对应视频、3D 或隐式物理世界模型。

## TL;DR
以 LLM 隐藏态预测误差奖励程序搜索中的探索 token，与目标世界模型方向无关，可跳过。
