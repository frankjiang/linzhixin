# ReactSim-Bench: Benchmarking Reactive Behavior World Model Simulation in Autonomous Driving

## Insight
核心 observation 是：自动驾驶行为世界模型的价值不只是复现 log，而是当 ego/AV 偏离 log 时，周围 agent 能否合理反应。由此推论，WOSAC 式 realism/log similarity 不能代表 reactive capability，必须把 AV 控制从世界模型中解耦。

## Motivation
现有行为仿真 benchmark 通常让模型同时控制 AV 和周围车，并以接近真实 log 为目标；这本质上接近自回归 motion prediction，无法测试外部 AV 策略导致分布偏移时的交互响应。对于闭环评测和 RL 训练，这是关键问题，因为 log replay 在 AV 偏离时会直接导致碰撞。

## Method
ReactSim-Bench 设计了 decoupled reactive protocol：AV 未来轨迹作为外部输入固定给定，行为 world simulator 只控制周围 agents，并在每个 rollout step 根据已实现的 AV 状态反应。偏离 AV 轨迹由 pipeline 生成：先筛选有交互潜力的 nuPlan 场景，用 Diffusion Planner 生成候选 AV 行为，再用规则过滤相似轨迹、出路、运动学不可行、无交互或主动碰撞样本，最后人工验证。偏离类型分为 lateral、directional、longitudinal。指标覆盖 Agent-AV collision/risky TTC、Agent-Agent collision、offroad、逆行、加速度/转向不可行率。

## Experiment
基于 nuPlan 构造 2,636 个测试场景，训练集 642,640 个场景，8 秒未来 rollout，10Hz。评测 MTR、CTG、VBD、SMART、CATK、TrajTok，统一迁移到 nuPlan。Log replay 的 Agent-AV collision count 为 0.9829，risky TTC 为 1.5380；学习模型显著降低碰撞，最好 collision count 约 0.1407-0.1457，risky TTC 最好 SMART 0.3976。重要结论是 realism 不等于 reactive performance：例如 CATK realism 指标优于 SMART，但 reactive 指标略差；CTG realism ADE 好于 MTR，但 reactive collision 明显差。replan rate 越高通常反应更好，但模型相关。

## Value
这是自动驾驶行为世界模型评测协议贡献，不是新生成模型。对视频世界模型/驾驶世界模型很有借鉴：闭环反应性应独立于 log 拟合能力评测，尤其要测 ego 偏离后的多 agent 反馈。局限是仍在轨迹行为层，缺少视觉/3D 场景生成评测；偏离轨迹依赖 planner 和人工过滤。
