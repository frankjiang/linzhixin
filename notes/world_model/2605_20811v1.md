# Demo-JEPA: Joint-Embedding Predictive Architecture for One-shot Cross-Embodiment Imitation

## Insight
核心 insight：将演示从"动作模仿"重新定义为"目标推断"——目标智能体应推断演示者试图实现什么状态，而非如何执行。这自然解决了跨形态的动作空间不匹配问题。JEPA 的联合嵌入预测架构天然适合这一框架，因为它在共享预测表征空间中工作。

## Motivation
跨形态模仿学习中，动作是形态特定的。传统方法需要共享动作空间、启发式重映射或大规模多形态联合训练。Demo-JEPA 将演示视为未来目标的隐式规格，在 JEPA 世界模型的潜空间中桥接异构形态。

## Method
基于 JEPA 世界模型，Demo-JEPA 通过 Dreamer Predictor 将源视觉演示翻译为目标兼容的潜轨迹。Conv3D-based 融合模块处理异构源演示。目标智能体将潜轨迹作为子目标，在自身学到的前向动力学下规划执行。避免动作级对应，仅需视觉演示 + 目标智能体自身交互经验。

## Experiment
RLBench 和真实世界操作任务。跨形态桥接平均成功率 0.45，零样本泛化 0.36。匹配专门的域内规划器性能，在先前方法失败的未见任务和形态配置上泛化。消融验证了 Dreamer Predictor 和 Conv3D 融合的贡献。

## Value
对 JEPA 研究高度相关。将 JEPA 的预测表征空间用于跨形态目标传递是优雅的思路。Dreamer Predictor 作为异构演示到潜空间目标的翻译器具有新颖性。局限：RLBench 环境相对简单，真实世界实验规模有限。潜空间中的目标质量高度依赖 JEPA 世界模型的表征质量。
