# EmbodiedWorld-200K: Toward Embodied World Agents via Embodied-Planning Dataset and Interactive World Models

## Insight
观察：跨游戏导航视频蕴含大量可迁移的视觉—动作先验，但静态监督难适配新场景的动作尺度。推论：可先从多游戏轨迹学习动作序列，再用视频世界模型产生目标场景的交互偏好数据。作者以数据规模消融和 GTA5 适配实验支持这一流程；证据主要是离线轨迹匹配，尚未直接证明真实闭环任务成功率提升。

## Motivation
具身代理训练通常局限于单一游戏、室内导航或特定机器人，缺少跨开放 3D 环境的统一轨迹数据与基线。真实游戏引擎大规模闭环采样成本高，已有视频世界模型可充当代理环境。问题对“用世界模型训练代理”有价值，但论文本身不改进世界模型的动力学或视频生成。

## Method
从覆盖 150 余款游戏的 OGameData 筛选约 26 万条视频，VIPE 恢复相机位姿，再按主运动方向切成 21.5 万条导航一致片段。将平移、旋转量化为统一 W/A/S/D/N 双流动作；Qwen3.5-27B 生成详细运动描述或经目标可辨识验证的高层导航指令，得到 `(首帧, 指令, 动作序列)`。基线用 Qwen3-VL-4B LoRA 监督生成 JSON 动作。第二阶段在 GTA5 取初始图及候选动作，用 LingBot-World-Fast 按对齐的动作幅度生成视频，VQA 打分构造偏好对，以 DPO 后训练代理。

## Experiment
数据平均动作序列长 9.98。离线评测用 token 匹配 TM、全局方向准确率 DirAcc、重构轨迹 nDTW 和终点导航误差 NE；相对原始 Qwen3-VL-4B，SFT 分别由 54.9/70.1/67.1/51.7 变为 62.0/72.0/83.6/35.6。三分之一训练数据已令 nDTW 达 83.0，全部数据主要继续改善 token 匹配。GTA5 目标场景上，世界模型偏好 DPO 后 TM 65.4→75.0、nDTW 66.1→92.7、NE 48.9→13.4，但 DirAcc 84.4→82.8。比较了 VLN 模型、游戏模型和通用 VLM；附录明确所有四项指标均基于预测动作与参考序列，而非真实环境中的到达或执行结果。

## Value
数据构建与统一动作接口可供开放 3D 场景世界模型及代理训练复用；“生成模型代理环境 + 视觉问答奖励 + 偏好优化”是实用训练范例。对世界模型本体研究，最值得参考的是如何验证代理环境与真实游戏的动作幅度、误差和闭环迁移，而本文尚缺这类验证。

## Strengths
数据规模和场景多样性较大；公开数据、检查点与评测协议；多层指令及动作标注可复用；附录明确指标的适用边界并做数据量消融。

## Weaknesses
评测本质是单图像输入后的开环动作序列复现，nDTW 与 NE 对参考路径/位移打分，不检验真实目标到达、避障或误差恢复。GTA5 阶段没有报告世界模型与游戏动力学的保真度，也未隔离 VQA 奖励偏差；DPO 提升不能直接证明生成环境中的策略能迁移回游戏。统一相机动作难涵盖物体交互，虚拟游戏与现实具身任务有差距。

## Future Work
作者指出需扩展到真实物理平台、复杂对象交互、细粒度控制、长期任务分解与部分可观测下探索；这些能力超出现有指标。

## Rating
创新度评分：3/5 - 大规模跨游戏导航数据及世界模型后训练流程有实用贡献，算法主要复用现有 VLM、视频模型和 DPO。
相关度评分：2/3 (Related) - 使用交互视频世界模型训练 3D 代理，但主要贡献是导航数据和策略，而非世界模型本体。

## TL;DR
发布跨游戏导航数据并用视频世界模型生成偏好样本训练代理，离线收益明显；关注代理训练可选读。
