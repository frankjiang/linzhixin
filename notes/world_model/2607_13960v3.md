# GigaWorld-Policy-0.5: A Faster and Stronger WAM Empowered by AutoResearch

## Insight
核心 insight 是 WAM 的未来视觉预测主要应作为训练时 dense supervision，而不必在部署时显式生成未来视频。Observation 是动作 token 远少于视频 token，test-time video rollout/denoising 会拖慢闭环控制；推论是用 action-centered causal mask 让 future visual tokens 训练动作表征，但推理时走 action-only path。0.5 版本进一步观察到 action generation 和 visual dynamics modeling 的计算需求不同，因此用 Mixture-of-Transformers 分专家降低动作推理开销。

## Motivation
论文解决 World Action Models 在机器人实时控制中的效率瓶颈。现有 VideoVLA、Motus、UWM 等把动作和未来视觉联合建模，能用未来场景演化提供物理 grounding，但很多方法推理时仍显式生成未来视频，导致延迟高、闭环部署困难。GigaWorld-Policy 已提出 action-centered WAM，0.5 版本目标是更快、更强、更易调参。

## Method
GigaWorld-Policy-0.5 输入多视角 composite image、robot state、language instruction，jointly 预测 action chunk 和未来 composite observations。训练用 flow matching，对 action tokens 和 future visual tokens 使用不同 shifted timesteps。Causal mask 允许 future visual tokens 看 action tokens，但禁止 action tokens 看 future visual tokens，防止信息泄漏并使推理时可省略未来视觉。架构上用 MoT：visual expert 处理当前/未来视觉 latent，action expert 处理动作去噪和 action chunk；两者通过 multimodal self-attention 交换信息。Visual expert 从 GigaWorld-1 初始化，action expert 由视觉权重截取/复制初始化。训练分 robot-data pretraining 和 target-robot post-training，并混合 AC-WM 和 WAM pretraining。部署侧加入 KV cache、torch.compile 和 C++ runtime。

## Experiment
真实机器人为 AgileX PiPER 6-DoF，评估 text following 和 long-horizon tasks，指标是 Success Rate。Pick the Fruit 平均 SR 0.85，高于 pi0.5 0.76、Motus/GigaWorld-Policy 0.80、FastWAM 0.78；Place Objects 平均 0.89，高于 Motus 0.83、GigaWorld-Policy 0.81；Food Heating/Tableware Arrangement 长程任务平均 0.80，高于最强 baseline 0.60。效率上，GigaWorld-Policy-0.5 在 A100 latency 189ms，RTX 4090 110ms，C++ 部署 85ms，同时 SR 0.85；比 GigaWorld-Policy 的 293ms RTX 4090 明显更快。消融显示混合 AC-WM+WAM pretraining 比单 WAM 收敛更快、最终达到 0.85；AutoResearch 在 pick fruit 上搜索学习率，选出 6e-5、batch size 16、30K checkpoint。

## Value
对机器人 WAM 和视频世界模型用于控制非常相关。它明确提出“训练时保留世界模型监督，推理时去掉未来视频生成”的实用路线，对低延迟闭环控制很有启发。更像工程增强版技术报告，而非全新范式，但方向契合度高。

## Strengths
问题面向真实部署延迟而非离线生成质量；action-centered mask 设计清楚，能解释为什么训练和推理目标可解耦；MoT 专家分离让 action-only path 更轻；真实机器人任务和边缘 RTX 4090/C++ latency 结果有实践价值；AC-WM 消融支持训练策略。

## Weaknesses
整体是 GigaWorld-Policy 的增量版本，很多关键设计继承自前作；真实机器人任务数量少、每项 10 次，统计置信度有限；AutoResearch 部分主要是超参搜索自动化，科学贡献较弱；缺少更复杂接触、多物体长程任务和跨机器人泛化评估。

## Future Work
作者没有长篇展开，但结论指向更快、更可部署的 WAM。自然后续包括扩大真实机器人任务、验证跨 embodiment 泛化、进一步压缩 action expert、研究是否可完全蒸馏 visual dynamics supervision，并把 AutoResearch 扩展到架构/数据配比搜索。

## Rating
创新度评分：3/5 - MoT和混合AC-WM/WAM训练改进了已有action-centered WAM，工程效果明显但属增量增强。
相关度评分：3/3 (Core) - 直接研究机器人World Action Model、未来视觉动态监督和低延迟动作推理。

## TL;DR
GigaWorld-Policy-0.5用MoT和训练/推理解耦加速机器人WAM，做实时控制值得精读。
