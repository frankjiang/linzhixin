# Schema-Adaptive Action-Conditioned JEPA for Cross-Machine CNC Transfer under Partial Sensor Overlap

## Insight
域内预测误差不能衡量潜世界模型的迁移和控制价值；尤其，改善均值预测的归一化可能破坏不确定性。相同 JEPA 加 RevIN 后跨机器 RMSE 改善，但恒定窗口的极小尺度经方差反归一化产生过度自信，NLL 急剧恶化。三种子配对实验支持这一具体失败机制，并未证明 JEPA 预训练优于监督学习（§6.1、6.6）。

## Motivation
源 CNC 有17传感通道，目标仅共享10通道，还存在动力学、单位与采样差异。普通时序预测偏重域内插值，本文考察缺传感器时动作条件 JEPA 能否迁移。是隐式世界模型的工业场景验证，而非非CS物理模拟。

## Method
- 显式 presence mask 区分缺失和零读数；先做通道轴 Transformer，再做时间轴 Transformer。1 Hz、32秒上下文，预测1/2/4/8/16秒后潜状态。
- 每个预测时距只接收该区间的平均动作，从共同上下文一次预测多个 horizon，**不做自回归 latent rollout，也未保留完整动作时序**。
- EMA 目标、latent smooth-L1、VICReg 方差/协方差、子通道视图一致性和动作恢复联合预训练；随后加全新高斯均值/方差头与 NLL 微调。EMA 目标已 stop-gradient，其 VICReg 项只起记录作用，直接梯度来自上下文项（§4）。
- 按 session 划分并仅用源数据拟合归一化；20配置搜索、领先配置确认至7种子后锁定，再评估目标。后续 RevIN 实验和锁定前 few-shot 曲线单独标为诊断证据。

## Experiment
- 源域五种子：scratch RMSE 0.811±0.022，JEPA 预训练加新头0.813±0.022，p=0.76，无增益。去防坍塌正则4/4种子失败；最大模型3/4失败（表2、附录A–D）。
- 锁定模型在目标2,457窗口、10共享通道上 RMSE 0.546、R² 0.012、NLL 0.52；优于 persistence 0.654，弱于官方 PatchTST 0.503、iTransformer 0.498。8/16秒 R² 已为负（表3）。
- 配对三种子 RevIN：目标 RMSE 0.555±0.015→0.495±0.004，但 NLL 0.89→20.6；90%区间覆盖0.953→0.874。改善点预测不代表得到更好的概率世界模型（附录H）。
- 锁定前模型在20%目标支持下0.612→0.520；5%因不足48步无有效训练窗口，不能视为真正 few-shot。尚无规划、策略学习或闭环机器控制实验。

## Value
最值得读的是负结果与评测协议：缺传感器、动作敏感性、表征坍塌、归一化和概率校准必须分开检查。对 JEPA 实验设计有价值，现有结果不足以支持通用跨机器控制。

## Strengths
报告失败搜索、无预训练收益及校准退化；明确区分诊断和确认性结果；数据单位审计、分组切分、多种子稳定性检查较细致。

## Weaknesses
一源一目标、仅7个独立目标 run，确认结果为单 checkpoint；部分源比较混用验证/测试切分。锁定模型的目标动作敏感性未测，旧模型打乱动作改变 RMSE <0.005，因果可控性未建立。few-shot 在同一 run 前段支持、后段评估，且尚未重测锁定版本；目标已再次读取，不能持续称为封存测试集。

## Future Work
多源机器训练；限制窗口尺度、低方差时回退或在全局空间预测方差以修复 RevIN 校准；改用尺度无关的坍塌指标；接入规划/模型式RL与离线策略评估，待有干预数据再研究因果表征（§7、附录F）。

## Rating
创新度评分：2/5 - JEPA、掩码一致性与动作恢复的应用组合，主要贡献是严格诊断和负结果，尚无方法优势。
相关度评分：3/3 (Core) - 直接研究动作条件 JEPA 潜动力学、迁移和校准，虽为非视觉工业时序，仍属于隐式世界模型。

## TL;DR
评估缺传感器下的动作条件JEPA迁移，发现预训练无增益且归一化损害校准；评测与负结果值得精读。
