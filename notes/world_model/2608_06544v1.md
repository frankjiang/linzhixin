# TaskSense: Focusing on What Matters in World Models

## Insight
若在 Dreamer 编码器之前用上一时刻 belief 预测随机空间掩码，并用逆动力学迫使掩码保留动作相关区域，世界模型可减少对独立背景的建模。极端动态背景下六项任务均改善，但标准环境平均性能下降，说明“动作可预测”并不等于“任务充分”。

## Motivation
像素世界模型会浪费容量重建背景、纹理等控制无关因素，视觉干扰会污染 latent 和 imagination。已有方法多在编码后做表示正则，作者选择在输入端主动筛选。问题与 Dreamer 鲁棒性高度相关，但属于已有注意力/逆动力学思路的增量组合。

## Method
在 DreamerV3 编码器前加入 8×8 Binary Concrete 随机空间掩码，掩码由上一时刻 latent belief 预测并阻断梯度；解码器只重建掩码后的观测，并显式条件化停止梯度的 mask。逆动力学头从相邻 latent 预测前一动作，引导注意可控区域，另加稀疏正则；actor-critic 和 RSSM 主体不变。关键风险是逆动力学也可能偏好可控但无奖励价值的因素。

## Experiment
在 DMC 与每步随机切换 DAVIS 背景的改造版 Distracting Control 上评估 6 个任务、500k 步、5 个种子。标准 DMC 中 TaskSense 平均 708，低于 DreamerV3 的 777：Cheetah Run 755 对 885、Walker Run 474 对 724，只有少数任务接近。干扰版平均 490 对 397，六项均提高，但 Hopper 仍几乎失败（1.9）。去掉随机注意、逆动力学或改成全图重建均使两项代表任务曲线退化；注意图定性集中于机器人肢体。未给全任务数值消融或统计显著性。

## Value
工作直观展示“编码前丢弃干扰”可增强 Dreamer 的抗背景能力，适合作为轻量模块参考；同时标准任务退化是重要警示：选择性瓶颈必须以奖励/长期可预测性校准，不能只靠动作互信息。

## Strengths
模块可插入现有 Dreamer，因果上避免直接窥视当前帧来生成 mask；同时报告无干扰和强干扰结果，没有掩盖明显负收益；定性注意图有助于理解机制。

## Weaknesses
改造后的逐帧独立背景比标准 DCS 极端，外部有效性有限；没有比较更强的 distractor-aware 世界模型。只覆盖六个低分辨率模拟任务，缺少真实视频、计算开销、全量消融和置信区间；标准 DMC 的大幅掉分削弱“聚焦关键因素”的主张。

## Future Work
作者建议把奖励与长期任务信息纳入注意目标，并扩展到更复杂真实视觉。进一步应允许软信息保留、处理可控干扰，并比较不同干扰强度下的性能—稀疏性曲线。

## Rating
创新度评分：2/5 - 是随机注意、稀疏重建与逆动力学的合理组合，但标准任务损失大、验证范围有限。
相关度评分：3/3 (Core) - 直接改造 Dreamer 类隐式世界模型的视觉表征学习。

## TL;DR
TaskSense 在编码前筛掉视觉干扰，强干扰下更鲁棒但标准 DMC 明显掉分，作为 Dreamer 增量可选读。
