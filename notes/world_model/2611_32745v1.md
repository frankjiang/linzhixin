# MemAnchorWorld: A Sparse World Model with Horizon-Conditioned Memory Retrieval for Autonomous Driving

## Insight
观察：稀疏 3D 占据世界模型靠循环状态保留历史时，初期遗漏和后续预测误差会传到更远时域；约四分之一的错分预测点可在旧帧找到正确语义证据。推论：把历史查询独立存放并在每个预测时距检索，再做受任务与时距控制的残差修正，可改善 4D 占据预测。作者用历史互补/错误修正统计与组件消融支持；不是证明长期误差必然收敛。

## Motivation
自动驾驶稀疏占据预测用少量查询节省体素计算，但 recurrent 场景状态难长期保留局部几何与语义。关键问题是让 1–3 秒的预测可直接取回旧观测，不完全依赖逐步传播。

## Method
冻结 SparseWorld-R50 的六相机感知与预测骨干，另存较早帧的稀疏查询及各自 3D 点。旧点先用自车位姿对齐，再按查询特征估计速度补偿到目标预测时距；查询级检索以几何相似与语义相容双路径选候选，点级注意力取相关“记忆锚”。点级适配器以当前查询、历史特征/语义、支持统计及时距为输入，对类别 logits、占据置信和位置分别输出带门残差；点到体素联合监督对齐最终占据指标。创新主要是对已有稀疏预测器增加分层、时距条件记忆检索与门控校正，属于增量结构设计。

## Experiment
Occ3D-nuScenes：700 训练场景、150 验证场景，观测当前及前 2 秒四帧，按 0.5 秒步长预测到 3 秒。指标为 17 类占据 mIoU、类无关占据 IoU、自车轨迹 L2 与 box collision。1–3 秒平均 mIoU 13.55% 对 SparseWorld 13.20%（+0.35 点），IoU 22.84% 对 22.03%（+0.81 点）；轨迹平均 L2 0.20 m 对 0.27 m，box collision 0.10% 对 0.29%。消融：只加记忆 mIoU 13.24%，只加时距门控 13.31%，两者合用 13.55%。在基础预测错误而历史正确的点中，仅 9.57%/11.12%/12.58% 于 1/2/3 秒被修正；基础正确而历史错时约 97% 仍正确。遮挡车辆可视化有局部改善。

## Value
适合参考 3D 占据世界模型的持久性设计：显式时距条件检索可作为 recurrent 状态的外部纠错来源。增益较小，若团队正在做长时占据预测可选读。

## Strengths
在同一冻结骨干上拆分记忆与门控贡献；同时报告历史证据可用性和实际利用率，避免只凭最终分数解释机制；指标含下游规划。

## Weaknesses
预测提升仅 0.35 mIoU 点，历史可用证据的修正率仍低；没有对象级跨时匹配，速度外推易受动态交互影响。仅一个数据集/骨干，其他模型数字取自原论文，缺少内存、检索时延及更多时间跨度消融。当前 PDF 引用了附录 B/C 的细节，但所给 11 页文件未包含这些附录，部分损失和规划定义无法核对。

## Future Work
作者明确提出建立更强的运动感知对象关联，改善动态场景的记忆锚检索可靠性。

## Rating
创新度评分：2/5 - 分层检索与门控残差是对现有稀疏占据模型的增量扩展，预测增益有限。
相关度评分：3/3 (Core) - 直接研究自动驾驶 3D/4D 占据世界模型。

## TL;DR
在稀疏三维占据世界模型中按预测时距检索历史点并门控纠错，小幅提升长时预测；相关团队可选读。
