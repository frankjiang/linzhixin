# SeerGuard: A Safety Framework for Mobile GUI Agents via World Model Prediction

## Insight
核心 insight 是 GUI agent 的安全判断不能只看用户指令，也不能等动作执行后再审计；真正关键的是在当前界面状态下预测候选动作的语义后果。Observation 是许多移动端风险来自 benign-looking instruction 在具体 UI 中触发支付、隐私泄露、删除或 prompt injection；推论是用 semantic next-state world model 做 pre-execution audit，比像素级未来屏幕生成更便宜也更贴近安全判断。

## Motivation
论文解决移动 GUI agent 的 proactive safety 问题。现有 LlamaGuard/WildGuard 等 instruction-level guard 看不到界面状态；OS-Sentinel、VeriSafe 等更多是 step-wise/post-hoc 或规则验证，难以在不可逆动作前阻断。GUI world model 相关工作如 MobileWorld/WebWorld/MobileDreamer 多服务规划和 task success，安全意识不足。问题对数字 agent 部署很关键，对世界模型研究则属于语义/文本化 GUI dynamics 分支。

## Method
SeerGuard 有两阶段：Ginst 先做 instruction-level screening，拦截显式恶意请求；通过后，agent 每提出一个动作 at，SAWM 根据当前 screenshot/UI state 和 action 预测 semantic next state s_hat，并输出 safe/unsafe 和 rationale，unsafe 则拒绝任务。SAWM 基于 Qwen3-VL-8B-Instruct SFT，训练数据 148K，包括 general textual safety、MobileWorld next-state trajectories 的安全重标注、小规模真实 risky GUI operations、合成 textual mobile risk data、Next-State-QA。关键设计是让模型同时学习 next-state prediction 和 risk assessment。

## Experiment
MobileSafetyBench 上，SeerGuard 降低多种 agent 的 Risk-Cost Score：GPT-5.1 0.301->0.145，Gemini-3.1 0.368->0.180，Qwen3-VL 0.347->0.130；Qwen3-VL 的 Safety-Utility Score 在 omega=0.8 从 0.191 提到 0.596。Instruction-level screening 在 Prompt Injection 上 F1=0.922，为表中最佳；Agent-SafetyBench F1=0.567，略低于 PolyGuard 0.578。Action-level MobileRisk 上 SAWM F1=0.723、Step Score=0.361，优于 OS-Sentinel、MobileWorld、GPT-5.1。Next-State-QA accuracy 0.762，超过 GPT-5.1 0.727、MobileWorld 0.714 和 Qwen3-VL 0.702。Case study 展示其能在 PhotoNote prompt injection 后阻止打开股票交易应用。

## Value
对视频/3D 世界模型不是核心，但对“semantic world model 足够支持决策/安全，而不必生成像素未来”很有启发。若研究隐式世界模型用于 agent planning，可参考其把 prediction 与 value/safety head 联合训练的方式；若只关注物理视频或 3D 动态，则可选读。

## Strengths
问题定义清楚，正中 pre-execution consequence-aware safety；双阶段 guard 能平衡显式恶意和上下文依赖风险；训练数据组合覆盖文本安全、GUI 轨迹和合成桥接；实验区分 instruction screening、action risk、next-state prediction，证据链较完整。

## Weaknesses
风险预测仍依赖 VLM 的语义判断和合成数据，真实高风险 GUI 数据少；二分类 safe/unsafe 较粗，未处理连续风险、可恢复性或人工确认策略；benchmark 规模较小，闭源 GPT-5.1/Gemini 日期和实现细节影响复现；不是像素/物理动态 world model。

## Future Work
作者提出进一步增强细粒度任务风险检测，降低 missed detections 和 benign false positives。

## Rating
创新度评分：3/5 - 将 GUI semantic next-state prediction 与安全风险评估联合训练，应用切入点明确，但方法主要是数据组合和SFT。
相关度评分：2/3 (Related) - 属于语义 GUI world model，对 agent 后果预测有借鉴价值，但不直接研究视频、3D 或 JEPA/Dreamer 式隐式物理模型。

## TL;DR
SeerGuard用语义GUI世界模型预判动作后果并拦截风险，做agent安全可选读，主线略偏。
