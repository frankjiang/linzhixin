# OverSeer: Multi-Agent World Models Beyond What Agents See

## Insight
观察：多智能体第一人称画面随自身移动剧烈变化，且各自看不到对方视野外的历史；固定相机画面变化则更接近局部世界状态变化。推论：共同生成少量固定辅助视角可充当共享场景记忆，提高重逢和离屏事件的一致性；相对固定首帧的残差潜变量可压缩这些近静态视角。去辅助视角消融、相机数趋势与重访基准支持前者；压缩在动态较快的 Doom 会损失部分一致性。

## Motivation
双智能体视频世界模型必须同时保持环境历史和多个视角里人物/事件一致。单纯串接两个移动第一人称流只在视野重叠时有共同参照，纯回忆式记忆也无法记录从未见过的区域。作者把“额外生成什么画面”作为设计变量，是多智能体视频世界模型的关键问题。

## Method
- 基于 Wan2.2-TI2V-5B，同时生成两名智能体的未来第一人称流和 6（Minecraft）/8（Doom）路固定辅助相机流。推理只给智能体初帧、双方动作和辅助相机位姿；无需真实辅助图像。相机位姿从与场景无关的先验采样，并按视锥几何覆盖贪心选择。
- 双方离散动作转英文短句、T5 编码后经交叉注意力注入；辅助相机位姿转 Plücker 射线，经 AdaLN 调节。所有视角用共享注意力交换信息，diffusion forcing 与因果时序掩码用于自回归滚动。
- δ-VAE 在普通视频 VAE 潜变量上再编码固定视角：保留首帧锚点，其后每两个时间步、2×2 空间块编码为残差码，重建损失、KL 与偏向变化区域的特征对齐共同训练；总体辅助 token 压缩 8 倍（864→108/帧）。

## Experiment
- Minecraft 的 Solaris 与新 MAC-Bench、Doom 两类重逢任务；VLM 逐事件问答准确率及帧级 FID。MAC-Bench 的“起点重逢/远处重逢/离屏事件”准确率，OverSeer 为 60.2/37.9/40.5%，最佳旧基线仅 0/6.2/12.5%；但 Solaris 的短程移动为 59.1%，低于 Solaris 的 68.8%。
- 去掉辅助视角使上述三项降为 25.0/16.7/20.8%；更多辅助相机对记忆任务有渐近收益。Doom 两项重逢从无辅助 12/0% 到完整模型 62/67%。无 δ-VAE 的全潜变量辅助流在 Doom 提升至 78/84%，显示压缩确有代价。
- 8× 压缩将每路辅助潜 token 降为八分之一；跨场景残差码移植显示运动主体与静态背景部分分离。真实多相机片段只有定性结果，未报告真实场景任务准确率。评审指标由 Claude Opus 5 判定，且每回合多问须全部正确。

## Value
给视频世界模型提供简单的共享参照方案，以及“固定视角 + 变化编码”以压低多视角成本的具体机制；对多智能体、持续世界与长时记忆设计值得精读。其固定相机是共享世界的视觉代理，并非显式 3D 状态。

## Strengths
离屏/重逢任务直击传统 FID 忽略的结构错误；有去视角、视角数和压缩率消融；明确推理时无真实辅助图像；跨 Minecraft、Doom 展示领域差异，并披露压缩的负面影响。

## Weaknesses
固定相机覆盖外仍易失真，远距离重逢准确率只有 37.9%；快速变化场景的残差压缩损害画质与一致性；主要量化结果来自游戏，真实视频仅定性；VLM 问答指标依赖评审器与预设脚本，缺少几何/物体状态的直接真值指标；每环境需 64 张 GB300 训练，推理仍生成多路视角；动作每帧只保留一个离散主项，组合动作表达有限。

## Future Work
作者提出让辅助相机自适应跟随探索区域、为无界世界重新设锚，以及扩大到更多智能体；也建议把输出视角选择作为世界模型设计核心变量。

## Rating
创新度评分：4/5 - 以共同生成固定辅助视角替代显式共享状态，并用首帧条件残差码控制多视角开销，方向鲜明且消融有说服力。
相关度评分：3/3 (Core) - 直接研究多智能体视频世界模型的跨视角、长时一致性。

## TL;DR
共同生成固定辅助视角并压缩其变化，显著改善多智能体离屏重逢一致性；视频世界模型研究值得精读。
