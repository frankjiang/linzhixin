# UniCanvas: A Diffusion-based Unified Model for Text-in-Image Joint Generation

## Insight
核心 insight：将文本不再视为离散 token 序列，而是直接在共享像素画布上以视觉模式（光学文字）渲染，从而用单一 diffusion backbone 统一文本推理与图像生成。这避免了传统统一模型中文本头与图像头分离导致的目标函数/表示/推理三重 gap。论文将 diffusion 模型视为 pixel-space 的状态转换器（world model of visual change），画布序列作为任务状态的外化轨迹。

## Motivation
现有统一多模态模型存在文本与图像生成的分离：自回归 VLM 擅长推理但生成质量差，diffusion 模型擅长生成但缺乏逐步推理能力。将两者统一在单一架构中是开放问题。现有方法（Anole、MvoT、MMaDA、BAGEL 等）要么依赖外部 VLM，要么使用 token-based text head，都无法实现真正的 native interleaved generation。

## Method
整体管线：
1. **Text-in-Image Generation**（Sec 3.1）：用 flow matching 将输入图像变换为包含光学文字标注的画布
2. **Two-Stage Generation**（Sec 3.2）：Stage 1 "写"文字推理到画布上（reasoning），Stage 2 将推理增强的画布变换为下一状态图像（execution）
3. **CLIP-Based Alignment**（Sec 3.3）：冻结 CLIP 视觉/文本编码器做对比学习正则化，确保渲染文字语义一致
4. **Pretraining with Perceptual Loss**（Sec 3.4）：用 VQA 数据训练文字渲染能力，LPIPS 损失稳定排版

基于 Qwen-Image-Edit-2509 + LoRA rank 32 微调，DiffSynth 框架，8xH800 训练约 10 天。

## Experiment
- **VSP Benchmark**：平均成功率 0.77，大幅超越所有统一模型 baseline（BAGEL-Interleave 0.24，MMaDA 0.08）
- **Recipe 生成**和 **RLBench 机器人操作**：展示多步 interleaved 生成的时序一致性
- 消融验证了 CLIP alignment 和 two-stage design 的必要性
- 但 VSP 是一个相对简单的 grid navigation 任务，实际复杂推理能力待验证

## Value
"像素即语言"的思路有一定新意，但本质上是一种工程巧妙的 diffusion model 应用，用于特定的 text-in-image 联合生成任务。与世界模型方向无实质关联——虽然论文试图将 diffusion 画布更新类比为 world model rollout，但这只是概念包装。对于视频世界模型/3D 世界模型/隐式世界模型的研究没有直接借鉴价值。
