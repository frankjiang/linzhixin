# Adaptive-WAM: Quality-Guided Early-Exit Planning from Intermediate Video-Diffusion Features

## Insight
作者分别扫描视频扩散 noise timestep 与 DiT depth，观察到固定 block 的规划分数对 5 个 noise index 几乎不敏感（range 仅 0.13–0.15 PDMS），却随深度明显变化，而且中间 block 15 优于最终 block 30。不同出口的高质量场景 Jaccard 仅 0.69–0.82，且任意两层都有一方在部分场景显著占优。由此推论：视频生成监督学到的规划信息在去噪早期、网络中层已出现，但最佳深度取决于场景；应按当前轨迹的预计质量自适应退出，而非完成视频生成或固定读某层。十随机种子的逐层/逐场景分析和 threshold sweep 支持该结论，但自适应相对最佳固定层的净收益很小。

## Motivation
自动驾驶 video world-action model 往往沿完整 DiT/多步 CFG 去噪并解码未来视频，但部署真正需要的只是低维 ego trajectory。Fast-WAM/DriveLaW 等已证明无需显式生成视频，却仍采用固定特征接口。论文要解决的关键问题是：一个 5B 视频模型究竟执行到哪里才足够作可靠决策，并把计算按样本难度分配。该问题对视频世界模型落地非常直接。

## Method
以 Wan2.2-TI2V-5B 的 30 层 video DiT 为骨干，训练时用当前帧加未来 8 帧（2 Hz、4 秒）保持原生视频扩散监督；规划时仅在固定 noise index 17 做一次 conditional forward，不运行 40 步去噪、unconditional CFG 分支或未来视频 VAE decode。在 blocks {5,9,15,18,22,30} 各接独立投影和 ReCogDrive 式 trajectory DiT，每个 head 以当前/历史 ego state 与导航指令为条件，经 5 次 DDIM 生成一条 8-pose 轨迹。

质量 scorer 以当前前视图的 DINOv2-Small 特征与候选轨迹为输入，预测 NC、DAC、DDC、TTC、EP、Comfort 六个官方子分数，再按 PDMS 公式组合。推理从浅到深累计候选；最高预测分超过阈值即返回，否则复用 cached hidden state 继续。训练阶段联合 LoRA 微调 Wan、视频 loss 和六个 trajectory imitation loss；scorer 对 detached 轨迹拟合 evaluator target。随后冻结 Wan/scorer，用 DiffGRPO 单独优化各 trajectory head。创新是把 early exit 从分类置信度推广到扩散轨迹的任务质量验证，整体为已有视频骨干、规划 head、scorer 和 RL 的合理组合。

## Experiment
NAVSIM v1/v2 使用单前视相机，输出 4 秒轨迹；训练转换 103,288 个候选 token 后保留 82,555 条完整 9 帧 clip。v1 报 PDMS（collision、drivable area、TTC、progress、comfort），v2 报扩展 EPDMS。Adaptive-WAM 单轨迹达 90.8 PDMS，略高于 DriveVA 90.5；固定 B22、64 proposals 的辅助模型达 92.6，但不使用 adaptive routing。v2 达 89.9 EPDMS，在列出的前视 world-model planner 中最佳。NAVSIM→nuScenes 零样本为平均 L2 0.88 m、collision 0.08%，略逊 DriveVA 的 0.84 m/0.06%。

逐层统一训练显示 IL/RL 的最佳 B15 为 86.56/90.62，最终 B30 仅 80.71/85.82。η=90 的 adaptive 得 90.79，比固定 B15 高 0.17，A100 batch-1 延迟由 190 ms 降至 170 ms；94.1% 样本在 B15 前退出。全深规划为 320 ms，而完整 40 步 CFG 视频生成 13.22 s。scorer 在 12,146 场景上 exact top selection 91.2%、5 分内 94.4%，但仍有 51 个 ≥50 分的严重误选。消融表明 joint Wan LoRA 比缓存特征高 5.67 PDMS，full tuning 只多 0.02；Wan 中层单轨迹也优于 ViT-L 1.74 分。

## Value
论文最重要的启发是把“视频预测作为训练表征目标”和“部署时渲染未来像素”解耦，并进一步表明 world-model compute 可按计划质量动态分配。它为大型视频模型服务实时控制提供了清晰可复用的分析范式：同时扫描 diffusion time 与 network depth，比较不同出口解决的样本集合，而非只报告平均分。尚需验证这种 early-exit quality 是否能在真正闭环、交互式交通和硬件限制下保持安全。

## Strengths
- motivating study 控制变量清晰，十随机种子、逐层分数、场景集合重叠和双向大差距统计相互补充。
- 规划、quality scorer 与完整视频生成的计算图和延迟口径区分明确，避免虚假加速比。
- 覆盖 NAVSIM v1/v2、nuScenes 零样本、质量 scorer、骨干和微调策略消融，证据较全面。
- 明确披露严重 scorer failure，并说明 threshold 不是安全证书。

## Weaknesses
- 自适应策略相对最佳固定 B15 只提高 0.17 PDMS、节省约 10% 延迟；核心工程收益有限，且阈值在验证集选择。
- 每个已尝试出口都执行 5 步 trajectory diffusion 和 scorer，较深退出会重复付出 head 成本；未与动态 token pruning/层跳过等效率方法比较。
- scorer 不看 ego state 或导航 command，只凭图像和轨迹估分；12,146 场景仍有 0.42% 的 ≥50 分灾难误选，安全任务不可忽略。
- NAVSIM v1 是 non-reactive simulation，背景交通沿记录未来，不足以验证闭环交互；v2 也只是近似两阶段评估。
- 92.6 headline 来自另一个固定 B22、64 proposal、使用 privileged evaluator 生成 pseudo-expert 的模型，不能证明 adaptive routing 本身。
- text condition 使用地图元数据和历史运动模板，跨域时其可用性与信息贡献未独立消融；代码尚未发布。

## Future Work
作者未单列未来工作；正文指出更严格 threshold 也不能保证安全。后续应在闭环仿真/实车上做 risk-aware routing，引入 calibrated uncertainty 与 fail-safe；联合优化退出顺序、head 成本和 backbone depth；验证更多视频骨干、noise schedule、视角和恶劣天气，并比较固定小模型蒸馏等真正部署基线。

## Rating
创新度评分：3/5 - 中层视频 DiT 的系统诊断和基于轨迹质量的多出口设计有实质新意，但主要是 early exit 与已有 WAM/规划组件的组合，自适应增益较小。
相关度评分：3/3 (Core) - 直接研究视频世界模型特征如何高效服务动作规划，是视频世界模型/隐式预测表征的核心问题。

## TL;DR
中层视频 DiT 已足够规划，质量驱动早退小幅提效；分析扎实，核心方向值得精读。
