# GameScrub: Learning HUD Removal from Real Gameplay with Recovered Targets

## Insight
观察：用合成 HUD 覆盖无 HUD 视频可得精确目标，却难覆盖真实界面外观；反过来保留真实带 HUD 输入、恢复近似无 HUD 目标，更利于学会识别真实 HUD。潜视频 VAE 会在 mask 边界传播 HUD 信息，因此先用光流修补输入再编码；消融中去掉预填使伪目标 AAR 从 85.69 降至 59.23，说明这一步是关键。本文未验证清洗数据能否真正提升下游世界模型。

## Motivation
游戏录屏含小地图、血条等遵循 UI 而非环境动力学的元素，会污染视频世界模型训练。现有 GameCleaner 依赖合成叠加配对，在真实素材上漏检大量 HUD；解决真实数据的配对监督有价值。

## Method
离线 GameScrub-Data：YOLO11n 定位 HUD，时间扩展掩码；对遮挡视频生成不含 HUD 的场景描述；ProPainter 先用光流估计背景，再以冻结 LTX-2.5 潜视频扩散仅重绘 mask 潜格，最后像素空间复制未遮挡源像素，获得真实输入/伪干净目标配对。在线 GameScrub：冻结视频 DiT/VAE，训练参考视频条件的 LoRA，目标 token 流匹配损失对 HUD 区域赋 1、其余赋 0.1；推理无 mask，以 8 步低分辨率生成加 3 步高分辨率修复。方法重点是训练数据构造和视频编辑，而非动力学建模。

## Experiment
训练约 8522 段真实游戏窗口；Game2World 的 100 段真实录屏为主要评测，指标含 UI 去除率、无伪影 Clean、伪影折算 AAR、背景保留 BG、Overall=(AAR+BG)/2、LPIPS/MAE。GameScrub 对比无参考图 GameCleaner：AAR 71.95 对 57.86，UI 90.06 对 59.07，但 BG 92.30 对 99.90；Overall 82.13 对 78.88，其配对 95% 区间 [−1.5,+7.9] 包含 0。预填、扩散、像素合成各有消融：去扩散 AAR 61.01；去合成 BG 87.15。固定 GameCleaner 架构只换成本文伪配对，AAR 47.98→69.55，较好分离数据贡献；5 秒片段 H200 推理约 27 秒，对比 57 秒。

## Value
对游戏视频世界模型的数据治理可选读，尤其是真实输入、伪干净目标的构造方式，以及如何避免 VAE 掩码泄漏。对模型架构和预测动力学没有直接贡献；下游世界模型收益只是研究动机，不能视为本文已证实的结果。

## Strengths
同架构换数据的对照支持真实伪配对确实改善 HUD 识别；附录公开数据流程消融、逐片段置信区间、已见/未见游戏划分；同时报告去除与背景保留的权衡。

## Weaknesses
核心质量指标依赖单次多模态模型判分，检测辅助指标与训练检测器共享偏差；伪目标依赖 HUD 检测覆盖与视频扩散，背景保留下降。训练对照还未覆盖“相同新骨干配合合成对”的反向组合；未做下游世界模型训练实验，原始训练集因版权不发布。

## Future Work
作者提出无显式推理 mask 的局部选择性生成、带不确定性估计的目标恢复，并检验 HUD 清除对世界模型动力学和交互行为学习的实际影响。

## Rating
创新度评分：3/5 - 真实污染输入配合恢复目标、编码前预填与局部伪标签是有效组合，底层编辑模型沿用现成技术。
相关度评分：2/3 (Related) - 面向视频世界模型训练数据，但不建模或评估世界动力学。

## TL;DR
从真实游戏录屏恢复伪干净目标训练无掩码 HUD 清除器，改善数据清洗；研究视频模型数据时可选读。
