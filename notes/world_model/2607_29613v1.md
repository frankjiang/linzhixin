# WCM: A World Critic Model for Vision-Language-Action Reinforcement Learning

## Insight
论文抓住了 VLA-RL critic 的一个状态表征错配：机器人控制是 POMDP，单帧 critic 看不到速度、接触进度等动态量；但简单堆叠历史帧也不够，因为稀疏标量 return 可以被模型用静态捷径拟合，未必迫使其学习跨时刻动力学。由此推论，历史信息必须配合显式未来预测目标，才可能形成更接近 predictive state 的 critic 表征。作者以同构历史 ViT（令预测损失权重 λ=0）为关键对照，显示“有历史、无预测”仍弱于联合预测与价值估计；λ 扫描、critic OOD 热图和训练后期掉点分析进一步支持预测压力可缓解 critic 过拟合。不过论文没有直接测量 value calibration 或建立“状态恢复更好→优势估计更准→策略提升”的完整因果链。

## Motivation
现有 VLA 的 RL 后训练依赖 critic 提供密集优势信号，主流 critic 却只输入单帧图像或单帧 VLM latent，难以处理动态接触、移动物体和长时任务。同行通常采用 MLP value head、帧堆叠或一般时序模型；前者违反部分可观测假设，后两者在高维视觉空间又缺少足够监督。该问题直接影响 VLA-RL 的样本效率、稳定性和 OOD 泛化，属于隐式世界模型在控制中的关键应用。

## Method
WCM 基于轻量 LeJEPA：编码最近 K 帧观测，并以 CLIP 指令 token 做 cross-attention；因果 Transformer 汇聚历史，两个 head 分别预测标量 value 与动作条件下的下一时刻 latent。world head 以 action encoder 和 gated-FiLM residual block 实现，训练目标为 return 回归、teacher-forced next-latent L2 以及可选 SIGReg 防坍塌。

WCM 可替换不同 VLA-RL 管线的原 critic：在线场景中接入 OpenVLA-OFT 的 PPO 或 π0/π0.5 的 Flow-SDE，以 GAE 更新策略；真实机器人采用含 SFT、失败 rollout 和人工纠正轨迹的 replay buffer，再以 AWR 或 RECAP 更新策略。核心创新是把 world-prediction objective 放进 critic 本身，而不是另训一个用于 rollout 的完整生成式世界模型；架构组件本身较常规，贡献主要来自问题重构与跨管线验证。

## Experiment
仿真覆盖 ManiSkill、MetaWorld、CALVIN、LIBERO-Plus 共 149 个任务，比较 Flow-SDE、Flow-Noise、π-stepNFT、PPO、GRPO 等，并使用 π0、π0.5、OpenVLA-OFT 三种 backbone。ManiSkill 上 WCM 分别达到 84.4/91.9/99.0% IND 成功率；对应 OOD 平均为 51.5/64.4/77.9%。LIBERO-Plus 从 one-shot SFT 出发，三种 backbone 的总分由 39.1/38.0/29.3 提高到 72.8/73.7/74.0，接近或超过 50-shot SFT。

真实 WidowX-250S 覆盖 7 个任务、两种 VLA；每任务先收集 100 条轨迹，再迭代 8 轮、每轮 50 条 rollout。WCM 在所有任务上高于 AWR/RECAP 的 Gemma critic，例如 π0.5 的炉灶清理从 SFT 4/50、RECAP 27/50 提到 33/50。消融比较 MLP、历史 ViT 与 WCM，只有加入未来预测后多帧历史稳定获益；K=3 平均最好。λ 在 0.3–0.5 最优，OOD 对该权重更敏感；WCM 还减弱 Flow-SDE 训练后期的 OOD 掉点。实验报告三次仿真运行和错误条，但真实机器人多为每条件 50 次计数，未给置信区间。

## Value
论文给出一个实用设计原则：若 critic 要利用历史，不应只扩大输入，而应增加与控制相关的预测压力。这对 Dreamer/JEPA 式隐式状态学习很有启发，也表明世界模型未必承担完整想象 rollout，作为 value representation learner 也能产生价值。后续最需要验证的是表征改进是否真正提高 value/advantage 估计精度，以及收益能否在相同 critic 容量、算力和数据预算下保持。

## Strengths
- 同时覆盖在线/离线式 RL、三种 VLA backbone、四个仿真 benchmark 与七个真实任务，外部有效性较强。
- “历史 ViT + 纯 value loss”对照较好地隔离了历史输入与未来预测目标的作用。
- 既报告 IND，也系统评估视觉、语义、执行等 OOD 扰动，并分析 critic 过拟合。
- 真实任务包含移动物体、可变形物和长时操作，不只停留在静态 pick-and-place。

## Weaknesses
- WCM 与原始 MLP critic 的容量差异很大；虽然 λ=0 的同构 ViT 消融缓解了该混杂，但缺少参数量/算力严格匹配及 throughput–performance 曲线。
- 主要证据是最终策略成功率，没有直接报告 value MSE、排序、校准、advantage 方差或预测 latent 的物理可辨识性。
- 下一 latent 的确定性 L2 预测可能平均化多模态未来，且只做一步 teacher forcing，不能证明可进行长期世界模拟。
- 真实机器人按任务分别训练 WCM，跨任务/跨机器人迁移能力未知；样本量和统计检验也弱于仿真部分。
- K=3 对应“二阶动力学”的解释只是直觉，尚无针对速度/加速度信息的干预验证。

## Future Work
作者未单列未来工作，但附录明确暴露出可继续研究的方向：更系统地处理 critic OOD 过拟合、研究仿真 RL 的 sim-to-real 迁移、在更长历史上避免信息冗余，以及寻找 world/value loss 的自适应权衡。还应扩展到不确定性世界预测、跨任务共享 critic 和直接的价值校准评测。

## Rating
创新度评分：3/5 - 将动作条件 latent prediction 内嵌到 VLA critic 的问题重构清晰，跨场景效果也强；但核心模块是 LeJEPA、时序 Transformer 与辅助预测的组合，机制证据仍不完整。

相关度评分：3/3 (Core) - 直接研究 JEPA 式隐式世界模型如何改善 VLA 强化学习 critic，与关注方向高度一致。

## TL;DR
以未来 latent 预测训练时序 VLA critic，显著改善仿真与真机 RL 泛化，值得精读。
