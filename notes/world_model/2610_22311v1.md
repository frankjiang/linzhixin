# Velox: Spatial Memory Makes World Models Efficient

## Insight
观察：长视频扩散模型必须记住旧视角，但当前画面的不同区域只需访问各自相关的历史；相机视锥与深度可定位这些区域。推论：用几何重叠软调制模型自身的注意力排序，能缩减历史 KV 读取而不强迫所有层采用同一路由。48 个 chunk 的时延曲线和 WBench 对比支持这一判断；这是实证证据，非质量保证。

## Motivation
自回归视频世界模型保留不断增长的 KV 缓存以维持重访一致性，后期注意力越来越慢。已有视野检索按整帧选历史，难以适配同一帧内不同区域；渲染记忆注入又常需改造生成器。长时交互中的速度与记忆兼顾是关键问题。

## Method
不训练原 LingBot-Fast-Cam：把已生成块的深度、相机和 token 区域压成带分位数深度范围的视锥薄层；用近期优先的多帧深度 warp 估计当前查询块深度，计算世界坐标系 OBB 重叠。覆盖可信时，以重叠分数乘性调制每层由池化 Q/K 得到的块重要性，选定额 KV 块；覆盖不足时退回模型自身排序。始终保留前一 chunk、局部邻域及参考帧。全局 Gilbert 排序、Triton 索引稀疏注意力和同卡异步建图实现可运行的块路由。创新在区域级几何记忆与稀疏注意力的融合，基础组件并非全新。

## Experiment
单张 H200、48 chunk 时延：第 48 块单次注意力 34.2→7.8 ms（4.36×），去噪 7.19→2.96 s（2.43×）；几何构建与去噪并行。WBench 导航全量 158 例：API-free 均分密集注意力 73.66、纯模型稀疏 73.11、Velox 73.51；19 指标总体均分 75.52、75.01、75.60，空间一致性 73.0、71.8、74.3。几何正重叠块的 top-80 召回由 0.602 升至 0.852，路由块集合平均改变 9%。有固定轨迹可视化和超参校准，但缺少随机、近期窗口及整帧视野路由的同预算比较。

## Value
对长视频世界模型很有直接借鉴价值：将显式几何当作注意力先验，同时给不可靠区域保留语义兜底。下一步应测试动态物体、深度漂移和多种相机路径，并报告包含重建/解码的完整端到端时延。

## Strengths
无需重训预训练生成器；稀疏 kernel 真正跳过 KV 块；同时报告长序列速度、全量基准质量与几何/模型注意力一致性，并区分不同评审模型下可比的 API-free 指标。

## Weaknesses
依赖外部深度/位姿重建及对齐，错误几何可能错误提升旧记忆；两块滞后带来新区域风险。WBench 中视角和主体一致性下降；主要验证单一骨干、单卡与导航场景，未给完整端到端墙钟时间，也未隔离多种同预算检索基线。

## Future Work
作者建议针对物体区域及深度/遮挡失效场景做更细质量评估，并与同大小随机路由、近期窗口、整帧视野路由比较；附录还提到可用第二张 GPU 减少流竞争。

## Rating
创新度评分：3/5 - 几何软路由和工程实现有明确新意及速度收益，但主要结合现有重建、块稀疏注意力与预训练骨干。
相关度评分：3/3 (Core) - 直接解决可交互视频世界模型的长期记忆与生成效率问题。

## TL;DR
用视锥深度重叠为长视频生成做区域级稀疏注意力，在近乎不损失质量下加速后期去噪；研究长期记忆值得精读。
