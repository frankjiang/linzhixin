# Why Does the Future Branch? Identifiable Closure Tests for Stochastic Physical World Models

## Insight

Observation：相同的观测条件未来分布，既可能来自观测把不同微观状态混为一谈，也可能来自固定完整状态后仍存在的过程随机性；两者总方差和 NLL 完全相同，却分别应采取“获取更细观测”和“保留多分支”。论文证明：仅凭 i.i.d. `(Z,A,Y)`，这两项在一族观测等价高斯系统中不可辨识。若对同一观测 fiber 采样多个兼容微状态，并对每个状态重复外生扰动，则 nested estimator 可无偏分解；若复用同一随机种子交叉全部状态×扰动，二因素 ANOVA 还能识别 state、noise 与 state–noise interaction，并把 interaction 正确计入 process。作者还证明嵌套观测分辨率增加时平均 aliasing 单调不增。证明简洁，且直接揭示“预测校准≠分支原因可知”。

## Motivation

随机世界模型通常只评 NLL、校准和样本分布，这些指标告诉我们未来有多宽，却不告诉宽度能否靠补充状态消除。传统 epistemic/aleatoric 划分也未针对“声明状态边界内的隐藏微状态 vs 固定状态后的环境扰动”。该区别会改变主动感知、规划分支和计算分配，是 stochastic physical WM 的关键评测缺口。论文目标是提供可识别 estimand 和干预协议，而非再造一个随机预测架构。

## Method

定义完整 simulator state `X`、粗观测 `Z=g_r(X)`、动作 `A`、外生扰动 `E` 和未来 `Y=F(X,A,E)`；`Valias=Var_X(E_E[Y|X,A]|Z,A)`，`Vproc=E_X Var_E(Y|X,A)`。独立 nested 版对 M 个兼容微状态各做 K 次独立扰动，以行内无偏方差估 process，并从行均值样本方差减去 `Vproc/K` 得 alias。可复用扰动版生成 M×K 完整交叉矩阵，以两因素 mean squares 估 `V_X,V_E,V_XE`，令 alias=`V_X`、process=`V_E+V_XE`；这避免非线性 interaction 被误归因。ClosurePairs 可只评冻结模型，也可给独立 attribution head/probe 监督；predictive branch 仍仅优化 NLL，参数分离或先冻结保证归因提升不偷换预测容量。决策上用可消除 alias variance 与传感成本比较，并在 matched-total-variance 环境中路由 REFINE 与 BRANCH。

## Experiment

解析高斯族固定总方差、改变真实 alias fraction，验证任意 observational split 在相同 NLL 下不可辨；paired 监督把 fraction MAE 从 0.240 降至 0.015（15.96×），NLL 差严格为 0。双阱 Langevin 的 18 个 horizon×分辨率×seed 条件中，ID fraction MAE 0.3716→0.0515、decision regret 0.01377→0.00030；OOD action 为 0.3711→0.0544、0.01390→0.00032。随机 Pendulum 跨 10 seeds 展示 horizon 100 的 interaction variance 0.05836 已超过 noise main effect 0.04331，说明 naive shared-noise 行均值会错分。32×32 像素→CNN/GRU/5-component MDN 实验中，冻结 shared-state probe 相对 deep ensemble 的 fraction MAE 为 ID 0.1304 vs 0.5840、OOD 0.1699 vs 0.6302；主动感知 regret 0.06354 vs 0.07043，但 Wilcoxon p=0.0977，仅作探索性结论。12 步 matched-variance router 五 seeds 下，总方差阈值准确率 66.48%±1.06%，ClosurePairs 99.99%±0.02%，selected NLL −2.087→−2.717。实验包含精确负控制、ID/OOD、失败/不显著结果及 34 个单元测试，但系统仍小且合成。

## Value

这是评估随机世界模型的高价值概念工具：把“多未来”从单一不确定度数值升级为相对于状态边界和扰动接口的可操作成分。对 Dreamer/JEPA/视频 WM 的启发是，模型需要同时报告 forecast calibration 与 closure curve；若不做 reset/fiber intervention，就不能声称 latent 已区分可消除部分观测性和不可消除随机性。它也提供 REFINE（加信息）与 BRANCH（加样本）路由的理论依据。实际价值取决于能否在复杂 simulator 中定义并采样合理的微状态 fiber。

## Strengths

核心不可辨识命题明确且构造性证明足够强；nested、crossed 两种协议覆盖可/不可复用随机种子的 simulator，且显式处理常被忽略的 state–noise interaction；估计量、假设和分辨率单调性都有证明。实验刻意冻结预测分支以隔离“新增信息”而非“更大模型”，包含 full-state 零 alias 控制、OOD 动作、多个决策后果、统计区间及不显著负结果，论证边界诚实。

## Weaknesses

ClosurePairs 要求 reset、兼容微状态采样及扰动重放/独立重复，真实视频或物理机器人通常无法满足；fiber 分布错配和 reset drift 会直接偏置估计。方差只描述二阶分支，无法刻画多峰拓扑、尾部风险或语义分支。像素实验仅 32×32、预测标量 `cos θ`，并非自由视频生成；近完美 router 在测试时直接读取 4×4 配对 rollout，既非被动在线路由也不节省计算。模型仍需先把总方差预测准；Pendulum 子集显示归因更准未必改善决策。尚未在公共大规模视频世界模型或真实控制任务上验证。

## Future Work

作者明确提出扩展到大型视频 simulator/预训练视频世界模型，并验证无需测试时 pairs 的表征蒸馏。还应推广到向量/轨迹及高阶分布分解，研究近似 reset、off-policy fiber importance weighting、结构化 latent 中的局部 closure，以及配对数据成本与路由收益的权衡。
