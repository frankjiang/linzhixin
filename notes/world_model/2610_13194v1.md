# JANUS: Enhancing Long-Horizon Autonomous Research with Co-Evolving World Models

## Insight
自动科研中实验执行昂贵且反馈滞后，先用历史实验预测候选假设价值，再执行并反思，可能提高单位实验的进展。论文以研究图和实验预算形式化这一观察，并通过去掉预测器或经验演化的消融支持其作用；所谓「世界模型」是 LLM 对研究提案结果的判断，并无学习视觉世界状态转移的证明。

## Motivation
AutoResearch、AIDE、MLEvolve、Arbor 等主要沿「生成方案→执行→反馈」迭代；研究方向分叉后逐个实测成本高。JANUS 试图在实验前分配预算，且让实验经验持续改进提案与筛选。该问题对自动科研代理重要，与视频/3D/隐式世界模型的核心问题不同。

## Method
维护有向研究图：开放节点存提案与预测价值，关闭节点补充代码和实测结果。协调代理从旧节点修改、扩展、组合新方案；LLM「世界模型」按预期即时收益、信息增益、后续探索价值对候选做稀疏成对比较，用 Bradley–Terry 拟合排序，动态调权并通过辩论修订候选；执行最优提案后，把成功/失败日志抽象为任务内、跨任务、预测策略及协作技能。POMDP 与信息增益公式提供概念框架，实际核心是结构化 LLM 打分、搜索和记忆的组合。

## Experiment
MLS-Bench-Lite 含 30 项任务、12 个领域，每项 5 小时 A100 预算，报告有效提交率、超越人工基线比例、Dev/Test 归一化分数。同用 DeepSeek-V4 Flash 时，JANUS 的 Test Score 为 41.07、Beat All 为 43.3%，高于 Codex 的 38.91/36.7% 和 Arbor 的 37.34/33.3%；接入 Codex GPT-5.6 Sol 后 Test Score 为 49.78。另在 nanoGPT、MinGPT 注意力核、基因型表型预测任务上评估 BPB、加速比、Pearson 相关；论文声称相对 Codex 平均实验样本效率 3.74 倍。仅利用即时收益、仅探索、关闭提案修订、关闭世界模型或技能演化都会降低三任务进展；另做跨语料/工作负载/群体分布迁移。主文多数曲线未给方差或显著性。

## Value
可借鉴的只是昂贵实验前先筛选、对模型预测做事后校准的研究工作流。其表示、预测目标和基准均不涉及视频、三维环境或 JEPA/Dreamer 潜状态动力学，对本方向的技术价值很低。

## Strengths
完整的候选生成、预算分配、执行反馈闭环；使用统一执行环境和多个消融，且为三个真实研究任务设置额外分布迁移测试。

## Weaknesses
「世界模型」主要是提示驱动的 LLM 评分与文本技能，无独立预测准确率/校准误差、长时转移误差评测；组件多，整体性能提升难以归因于某个独特算法。真实任务仅三项、曲线缺少重复运行的不确定性；性能对底座 LLM、代理实现和评测预算敏感。

## Future Work
作者未给出明确的技术路线；自然待解决问题是定量检验预执行预测的校准、跨任务迁移和不同预算下的稳定性。

## Rating
创新度评分：2/5 - 将提案预测、研究图搜索与经验反思系统集成，核心算子主要是既有 LLM 评估和搜索机制。
相关度评分：0/3 (Noise) - 研究对象是自动科研代理；文中的「世界模型」不模拟视频、三维世界或隐式视觉动力学。

## TL;DR
用语言模型预判研究提案并回收实验经验，提高自动科研搜索效率；与视频和三维世界模型研究无直接关联，可跳过。
