# VIScore: Diagnosing Planning-Relevant Quality in Latent World Models

## Insight

作者先观察到：VISReg 在自监督学习中可分解、可重加权的 center/scale/shape 优势，并不会自动转化为规划收益；真正改善 OOD 的是更大 batch 带来的更精确高斯分布匹配。这说明只检查 encoder 的潜空间统计不足以解释规划。由此推论，诊断必须覆盖 encoder-predictor-planner 整条链：rollout 是否在任务容差内（Veracity）、动作能否产生超过预测噪声的可分辨未来（Influence）、搜索是否会系统性利用局部模型误差找到“比真实专家动作更优”的幻觉动作（Sobriety）。三者乘积在多任务/多方法/多规划器上比单一表征指标更稳定地关联成功率。

## Motivation

JEPA 式 latent world model 的表示通常用预测损失、线性 probe、谱统计或 latent straightness 评估，但低损失或好表征不保证可规划。现有指标大多只看 encoder，最多覆盖 predictor 的 action capacity，忽略任务容差和 planner exploitation。VIScore 试图提供一种比完整 50-episode 控制评估便宜、又与规划成败直接相关的诊断工具。

## Method

第一部分将 LeWorldModel 的 SIGReg 替换为 VISReg，保持 ViT-Tiny encoder、action encoder 和自回归 Transformer predictor 不变。VISReg 将标准高斯匹配分成均值、尺度、形状三项，可独立加权；作者考察 loss weight 与 batch size 对 ID/OOD 规划的影响。

VIScore 定义为三项有界分数的乘积：

- Veracity：将 H=5 的 open-loop rollout RMS 误差与任务成功容差在当前 latent 中的距离 d_tol 比较，经 erf 映射到 [0,1]，因此对可逆 latent 尺度变化不敏感。
- Influence：用局部线性高斯通道估计 action-induced terminal covariance 相对 H-step residual covariance 的 latent empowerment；达到跨任务阈值 τ=82 nats 后截断为 1，把“容量越大越好”改为“达到任务所需即可”。
- Sobriety：在 64 个专家 anchor 上运行小型搜索；若模型认为未执行动作比实际到达目标的专家动作代价更低，则视为可利用幻觉，分数为 1 减去此类 anchor 比例。

常数只在按 training run 划分的 development pool 上选择，随后冻结并测试 held-out checkpoints、4 种未见 world-model 方法、未见 MAZE 任务和 6 类搜索规划器。

## Experiment

- 训练/控制：PushT、Reacher、OGBench-Cube、Two-Room，图像 224×224；VIS-WM 约 15M 参数、10 epochs、batch 128（OOD 另做 128/256/512 梯度），每配置 3 个训练种子。CEM 默认 300 candidates、top-30、5-block horizon。
- 性能分析：单 evaluation seed 会显著高估差异；使用 3 个新 evaluation seeds 后，VIS-WM 与 LeWM 的短时成功率基本相当。长时 d=50/75 时二者都明显下降。
- OOD PushObj 六种新形状：VISReg batch 128 为 77.4/59.7/41.8，SIGReg batch 128 为 79.1/61.8/44.3；VISReg 增大到 512 后为 82.0/62.0/45.6，说明 batch-dependent 分布近似而非 loss 可重加权性带来收益。shape-heavy reweighting 在 Reacher 甚至降至 12%。
- 诊断主结果：held-out checkpoints 上 VIScore 的任务内 Spearman 为 0.84/0.72/0.83，跨任务 0.91，校准误差 7.0；raw empowerment 跨任务仅 0.49、误差 15.6。未见方法池上 VIScore 为 0.75/8.3，未见 MAZE 为 0.87/11.5。
- 因子消融：单项在不同 pool 各有优势，Sobriety 常最强，但没有单项稳定覆盖所有 shift；固定乘积在所有 pool 的相关至少 0.75。
- 规划器迁移：CEM、MPPI、iCEM、多起点梯度搜索的 pooled correlation 仍高（0.81/0.81/0.87/0.86）；predictive sampling 与单起点梯度搜索因任务选择性退化而降至 0.51/0.12。
- 成本：单 H100 每 checkpoint 约 7 秒，至少比一次 50-episode 规划评估快 20 倍。

## Value

该工作把 latent WM 评估从“表征是否好看”推进到“模型是否可达、可控、且不被 planner 钻空子”，对 JEPA/Dreamer 类隐式世界模型的训练诊断很有价值。尤其值得借鉴的是 run-level split、cluster bootstrap、多 evaluation seed 和 planner transfer。VIScore 更适合定位瓶颈而非预测绝对成功率；实际使用应同时报告 V/I/S，而不能只报乘积。

## Strengths

- 指标与真实规划机制对齐，明确覆盖 encoder、predictor、planner 三层失败模式。
- 采用 run-disjoint development/test、2000 次按 run 聚类 bootstrap，避免把同一训练轨迹的多个 epoch 当独立样本。
- 不只在同方法 checkpoint 上验证，还覆盖 held-out methods、unseen task 和多类采样/梯度规划器。
- 坦率报告 Cube 的反例、单 seed 偏差、长时退化和 amortized planner 的适用边界。
- 诊断成本远低于完整在线评估，并提供因子级解释。

## Weaknesses

- VIScore 与成功率是相关而非因果；乘积形式、erf 映射、半容差和 τ=82 仍含设计选择，跨新领域需重新验证。
- d_tol 依赖已知任务成功条件与合适 probe pair；无明确物理容差或多目标任务中不易构造。
- OGBench-Cube 上相关方向相反且被排除出 pooled/calibration，暴露其无法表达抓取这种离散 mode transition；这不是边缘案例，而是机器人操控常见结构。
- unseen dataset 只有 MAZE 的 2 个训练 run；held-out method pool 也仅 23 个非 Cube checkpoint，外部有效性仍有限。
- Sobriety 需要 expert action 和一个小型 search；当数据非专家、planner family 改变或优化器任务选择性很强时，跨任务标尺会失效。
- 不适用于不显式调用 predictor 的 amortized/IDM planner，也未覆盖 stochastic multimodal dynamics、Dreamer actor-critic 或大规模视频生成 WM。
- Influence 的 H-step 噪声协方差只缩放 one-step 方向结构，作者也承认误差方向随 horizon 旋转时会产生偏差。

## Future Work

作者明确提出：建立 IDM/amortized planning 的诊断工具；将 OOD 与长时评估设为标准；研究 multi-task planning；采用更复杂、未饱和的数据集；解决无 action label 的训练。针对本文还应增加离散接触/抓取 mode 因子、stochastic rollout 校准、更多任务和方法的预注册验证。

## Rating

创新度评分：4/5 - 提出面向 latent WM 全规划链的可解释诊断，并以严格切分和广泛迁移实验验证，超出普通指标组合。
相关度评分：3/3 (Core) - 直接研究 JEPA 式隐式世界模型、latent planning、搜索规划器与评估。

## TL;DR

VIScore 联合可达性、动作影响与规划幻觉诊断潜世界模型，验证扎实，值得精读。
