# SC3-Eval: Evaluating Robot Foundation Models via Self-Consistent Video Generation

## Insight
世界模型作为 policy evaluator 的关键不是单纯视频质量，而是 action、multi-view、test-time 三种自一致性。若生成帧无法反推出原动作，说明 rollout 已偏离动作流形，应停止继续评分，避免 compounding drift 污染评估。

## Motivation
真实机器人策略评估昂贵，action-conditioned video world model 可替代 rollout，但会面临自回归误差、多相机不一致、OOD 策略行为。已有 Ctrl-World/IRASim/Cosmos-Predict 主要 forward generation，缺少 drift 约束和可靠 uncertainty。

## Method
基于 Cosmos3-Nano/UVA 式统一 video-action token backbone，联合训练三种模式：forward dynamics 从动作生成多视角视频；inverse dynamics 从视频恢复动作；cross-view inpainting 从部分视角补全其他视角。推理时 policy 给 action chunk，forward 生成帧，再用 inverse dynamics 计算 action reconstruction error U_chunk，超过阈值则 early terminate；训练预测 horizon l' 大于执行 horizon l，以保留预训练长视频 prior。

## Experiment
训练在 381 小时真实 table bussing 数据，评估 7 个 π0.5 VLA checkpoints，含 in-distribution 与 reverse bussing OOD。人工标注 language/lifting/placing 三类成功。SC3-Eval 在四种 split/mode 中 MMRV 全最佳，Pearson 三项最佳；in-distribution online r=0.984，OOD online r=0.870。总体 online closed-loop ablation full model Pearson 0.929/MMRV 0.119；去 inverse、cross-view、early termination、horizon decoupling 均下降。还能更好复现失败类型。

## Value
非常相关：它把视频世界模型从“看起来像”推进到“可用于机器人策略评估”。启发是评估型 WM 应有 inverse consistency 和 early stop，而不是无条件 rollout。局限是任务较短、推理慢（单 GB200 每 chunk 2.3s）、场景集中在 table bussing。
