# Failure Recovery via Belief Updates and World Modeling for Long-Horizon Agents

来源说明：原始 PDF 当前不可用（arXiv 返回 404），依据 arXiv HTML 全文阅读。
## Insight
观察：终端代理失败后若回滚代码状态，同时丢失先前诊断，会反复尝试无效修复。推论：持久保存“故障假设—证据—尝试”的关系图，并将执行资格和优先级分开，可改善恢复。113 个终端任务中完整系统相对原始继续执行提高最终得分 5.1 个百分点；这是软件代理实验，不涉及视觉物理世界的预测。

## Motivation
长时编程/终端代理需要从失败修复中保留经验。同行多用当前上下文重新规划，缺跨回滚的诊断信念。问题对软件代理重要，但与视频、3D 或 JEPA/Dreamer 世界模型几乎无关。

## Method
BeliefWeaver 将候选修复方向作为可检验假设；LLM 根据任务、源码和历史生成假设、运行诊断命令、判断证据，并估计修复进展和假设关系。持久图连接假设、尝试、观测、检查点，以简单因子化信念更新候选优先级；只有证据一致且目标未完成的候选可执行。失败则回滚环境，仍保留诊断图。将探针、证据判定、关系及条款核查等重复角色用 SFT 加 on-policy 蒸馏到 9B 学生。所谓“隐式世界模型”实为基于文本上下文的提示式故障推测，无学习环境状态转移或视觉潜在动力学。

## Experiment
在 Terminal-Bench 2.0/3.0 与 Long-Horizon Terminal-Bench 的 113 题上比较原生继续执行、结构化回滚、诊断 grounding 和完整系统，以最终通过分数、Step-AUC、Time-AUC 评估。完整系统最终分 +5.1 个百分点、执行耗时 −17.8%；但单加诊断 grounding 反而使最终分 −1.7 点。蒸馏后的 SFT+OPD 最终分 58.4%，比原生高 9.8 点；含学生假设生成时教师 API 费用约降 81.9%。

## Value
持久证据图和条件执行的思想可抽象借鉴到交互代理，但本论文对视频/3D/隐式物理世界模型的模型设计与评测没有直接参考价值。

## Strengths
把假设生成、诊断验证和回滚记忆拆开；消融显示单独诊断未必有益；报告执行资源与教师 API 的不同成本。

## Weaknesses
“世界模型”未学习未来物理状态，仅由 LLM 推测软件修复结果；信念因子是手工设计且非联合推断。实验只限终端任务，控制器组件的独立贡献没有完全隔离。

## Future Work
作者提出学习式、不确定性感知的信念更新，更细的控制器组件归因，以及稀疏反馈或回滚不可靠时的恢复。

## Rating
创新度评分：2/5 - 对终端代理是若干恢复机制的实用组合，对关注的物理世界模型无新技术贡献。
相关度评分：0/3 (Noise) - 任务是软件代理故障修复，名称相同但不研究视频、3D 或 JEPA/Dreamer 式世界模型。

## TL;DR
用持久故障假设图和证据门控改进终端代理回滚修复；并非视觉物理世界模型研究，可跳过。
