# TRACE: An Operational Reasoning Schema for Auditable Agentic Commitments

## Insight
本文的 insight 是：agent 的“承诺”不应只输出自然语言理由，而应写成可审计、可版本化、可被下游系统 fail-closed 消费的结构化记录。它把论证方案、证据、反驳、因果层级、修复动作和成本等字段显式化。

## Motivation
作者认为 LLM 的 chain-of-thought 或 RL 后训练不能保证真正的推理审计，尤其在 agent 做持久状态变更时，缺少可追踪的证据和因果约束。同行多做自然语言 CoT、debate 或工具调用日志，但这些日志难以严格检查推理责任。问题对 agent 安全和治理重要，但与视频/3D/隐式世界模型方向几乎无关。

## Method
TRACE 即 Typed Reasoning And Commitment Evidence，核心是 `TraceRecord` 和 `TraceCausalRecord` JSON schema，以及“没有记录就没有持久状态变更”的执行纪律。记录包含 claim、reasoning family、argument scheme、premise、warrant、evidence、defeater、causal rung、identifiability、bounds、missing evidence、failed gate、repair、provenance、revision 和 consumer action 等字段。作者还给出参考 writer pipeline：claim 检测、类型路由、scheme 问题检查、各推理族插件、门控 debate、settlement 和 score。

## Experiment
论文主要是 schema 和工作流设计，没有实证闭环实验。示例包括音乐课因果论证和洪水搜救路线决策，展示 TRACE 如何发现 rung collapse、证据不足和 OOD 风险。作者提出 TRACE-Bench 指标，如 DetectionF1、TypeAcc、EvidenceSupport、UnsupportedRate、OverclaimRate、RungCollapseRate、RegretReduction 等，以及若干 falsification criteria，但尚未给出真实 benchmark 结果。

## Value
对 agent 审计、因果声明检查和工具执行日志有参考价值；对视频世界模型、3D 世界模型、Dreamer/JEPA 类隐式世界模型没有实质技术借鉴。最多可作为“世界模型驱动 agent 决策时如何记录证据”的外围材料。

## Strengths
结构化字段覆盖面广，能把 Toulmin/Walton/Dung/Pearl 等推理概念落到可检查 schema；强调 consumer contract 和 fail-closed，比普通日志更有工程约束。

## Weaknesses
缺少实证验证；schema 很重，实际部署成本和标注一致性未证明；不能保证记录为真，只能保证字段存在和部分一致性。与目标研究方向偏离明显。

## Future Work
作者提出用 TRACE-Bench 和 ablation 检验 writer、gate、evidence ledger、attack graph、causal fields 是否真的降低错误承诺，并用闭环 record-gated agent 对比 ungated agent。

## Rating
创新度评分：2/5 - 主要是 schema 和系统规范整合，技术创新有限且缺少实验验证。
相关度评分：0/3 (Noise) - 不是视频、3D 或隐式世界模型论文。
