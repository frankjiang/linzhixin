# CausalNav: Reliability-Certified Causal World Models for Control under Physical-Parameter Shift

## Insight
结构 F1 或一步误差并不能证明世界模型会改善动作；真正可部署的组件需要在预测不可靠时 abstain。论文中 CartPole 图结构 F1 0.59，却与逐 seed 控制增益无相关；Pendulum 证书全部拒绝，而强制规划确实降低 return。这一负结论可靠，但 agreement gate 又严格禁止 planner 改变 greedy action，因此方法设计本身无法展示确定性决策改进。

## Motivation
物理参数迁移下，用错误模型覆盖已有 policy 可能比不用更危险；多数工作只报告预测 fidelity，不测世界模型对动作的边际贡献。显式 reliability certificate 和 fallback 是重要问题。

## Method
用 privileged identification loss 将 slots 对齐到 8 维模拟器坐标，再学习含一阶、二阶、action effect、自持久项的稀疏 signed transition graph。planner 对每个首动作枚举 constant/impulse/half-horizon 三种 8 步 intervention，按目标坐标误差生成 logits。最终 advice 同时乘以冻结校准的一步 normalized-error certificate、policy margin 和 argmax agreement；若 planner 与 policy 首选不同则归零。action 数大于 2 时 router 直接回退 base controller。

## Experiment
CartPole 与五档离散 Pendulum，训练 4,096 interactions，物理参数 shift 只在评测，十个 held-out seeds、十方法共 200 runs。系统平均排名 1.25，但 CausalNav 相对 routed expert 的 CartPole ID/shift 差为 -12.17/+11.95，95% CI 均宽跨零；Pendulum 因回退精确为零。CartPole graph precision/recall/F1 为 0.53/0.70/0.59，F1 与控制边际相关 $r=-0.15,p=.67$；NRMSE 反而与边际正相关。证书 CartPole 7/10 通过、Pendulum 0/10，开发期强制 planner 使 Pendulum return 再差 34–54。作者坦承排名主要来自三成员 ensemble，而非 causal planner。

## Value
论文最有价值的是审计范式：必须与相同 base controller 做 seed-paired 边际比较，并把 abstention 当作世界模型接口的一部分。当前 CausalNav 本身不是有效的“模型改变决策”证明，但诚实的负结果可避免用结构恢复指标包装控制贡献。

## Strengths
- 明确区分 routed system 排名与世界模型增量，并报告宽置信区间和全部 seeds。
- certificate、margin、agreement 的精确 fallback 性质有证明和实证。
- 物理 shift、训练预算和方法公共组件受控，复现材料较全。
- 主动披露参数不匹配、benchmark selection、privileged state 和失败任务。

## Weaknesses
- agreement gate 保证 greedy action 不变；确定性评测下 planner 从定义上不能改善决策，核心主张自我限制。
- action-count router 在仅两个 benchmark 上选阈值，Pendulum 回退近似 benchmark-specific routing。
- 只测低维经典控制、训练极少且方差巨大，无视觉、机器人或复杂 dynamics。
- 所有坐标由 privileged simulator state 识别，不是 causal representation learning。
- baseline 是受控“inductive-bias adaptations”而非原方法复现，平均排名意义有限；系统容量也不匹配。

## Future Work
需要在不锁死 argmax 的前提下给出风险约束 action override，使用概率校准与安全 fallback，预注册更大任务套件，并在视觉/连续控制和真实参数漂移中验证。

## Rating
创新度评分：2/5 - abstention 审计思想有用且报告诚实，但 planner 被设计成不能改变确定性动作，系统排名不来自世界模型。
相关度评分：2/3 (Related) - 面向基于世界模型的控制与分布迁移，但非视频/3D/JEPA，且模型贡献为负结果。

## TL;DR
CausalNav 证明生成质量不等于控制价值，但规划器无法改变贪心动作，谨慎选读。
