# MKD2World: A Typed Spatial MarkDown World Model For Web Agents

## Insight
观察：自由文本难保留完整页面布局，DOM/AXTree 常缺视觉语义和坐标，生成像素又容易错字。推论：将状态表示为可解析的元素类型、文本/语义、归一化边框、控件状态及层级，可让下一界面预测和候选动作比较更直接。作者用 OOD 元素匹配与 Web agent 成功率验证实用性；但系统同时改变训练数据、损失和 agent 适配，不能单独证明表示的因果贡献。

## Motivation
Web agent 需要在执行前预判点击、输入、滚动后的界面。既有页面状态表示在完整性、可定位性和生成代价之间取舍，影响规划。这是 GUI 世界模型的关键问题，却与用户的视频/3D/JEPA 世界模型只有抽象层面的状态表示关联。

## Method
Typed Spatial Markdown (TSM) 用 Markdown 层级列出 6 类块和 8 类原子 UI 元素、语义、控件状态及 0–999 归一化框。AtomBlock-WebUI 从真实截图参考生成带预注入类型标签的 HTML，补图后浏览器渲染并直接抽取标签节点边框；截图转 TSM 由 YOLO26、OCR 和小 VLM 组合。Qwen3.5-9B 先学习当前截图→TSM，再学习截图+动作→下一 TSM；第二阶段重加权新增/更新元素，并以 margin 损失约束真实下一状态比当前状态更符合变化动作。Agent 仅在不确定时查询候选动作，提炼预测变化的 digest 再选动作。主要创新是结构化 GUI 表示、合成标注与配套训练的系统组合。

## Experiment
标注集 9,683 页面、约 132 万框；状态重建训练 10 万例，下一状态训练 31,245 例；ID/OOD 各 1,000 转移，OOD 域与训练域隔离。自定义 EleF1 综合语义、类型、位置并做最大权二分匹配：OOD 为 26.50，最佳通用多模态对照为 15.94。Online-Mind2Web 从 300 任务筛出 109 个较稳定任务，Qwen3.5-35B 成功率 22.94%→37.61%，仅比最佳世界模型基线 35.78%高 1.83 点；VisualWebArena 的 Qwen3.5-9B 为 15.02%→20.60%。消融中加入焦点元素损失、margin、digest 后，成功率 22.94%→29.36%→32.11%→35.78%；TSM-aware 单独训练反降至 13.76%。在线任务由 VLM 判定，部分标注质量有人审校。

## Value
如果研究结构化状态或基于预测的动作选择，可参考“只突出动作改变的元素”的损失与元素级评价；对视觉物理世界建模的迁移价值有限。

## Strengths
状态格式同时保留坐标、类型、控件状态和层级；数据管线在渲染前注入标签，减少事后 DOM 语义推断；保留 no-op 转移并给出跨域预测与在线 agent 对照。

## Weaknesses
标注数据来自 VLM 生成的 HTML，并非真实站点的原生 UI 分布；通用模型只提示生成 TSM，而本模型专门训练，预测基线并不等训练预算。Online-Mind2Web 筛选后仅 109/300 任务，成功判定依赖 VLM；自定义 EleF1 绝对值仍低，导航类更弱。当前仅静态网页，不处理视频、动画或音频。

## Future Work
作者指出需提升像素级对齐，并加入网页音视频/动画的时间理解与变化预测。

## Rating
创新度评分：2/5 - TSM 与合成标注/损失设计具有应用价值，但核心是既有 GUI 解析、监督微调和候选动作选择的集成。
相关度评分：1/3 (Tangential) - 属于 GUI 领域的动作条件世界模型，仅有状态表示和预测选动作的间接借鉴。

## TL;DR
用类型、坐标和层级 Markdown 预测网页下一状态，可改善 Web agent；与视频物理世界模型距离较远，可跳过。
