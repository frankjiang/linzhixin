# Orchestrated Reality: From Role-Play to Living, Playable Game Worlds -- LLM-Driven World Simulation as a Parameterized-Action POMDP

## Insight
把 LLM 驱动游戏世界形式化为 Parameterized-Action POMDP：canonical JSON entities 是世界状态，玩家/NPC/RL policy 通过 validated parameterized actions 改写状态，LLM 只作为 transition validation/orchestration 的一部分。

## Motivation
LLM role-play 容易丢失世界状态、位置、事实和叙事一致性，难以变成真正游戏引擎。作者关注持久世界状态和动作验证，而非生成模型式视频 world model。

## Method
世界由 JSON state tree 表示；transition kernel 是 LLM-driven PDVA pipeline（parse/decide/validate/apply 类流程）；角色 agent 与 world agent 读写同一 canonical state。论文还计划扩展到多 NPC Markov game 和 RL environment。

## Experiment
目前主要是架构与计划中的玩家研究。计划 within-subjects 比较无状态 chat role-play 和持久世界循环，指标为 miniPXI、PAX、回访意愿和访谈。实证尚未充分完成。

## Value
对游戏 AI/交互叙事有意义，但与视频/3D/JEPA/Dreamer 方向弱相关。可跳过，除非关注符号 world state orchestration。
