# A Close Look At World Model Recovery In Supervised Fine-Tuned LLM Planners

## Insight
SFT确实能让LLM的内部表征线性编码世界模型信息（action validity、state predicates），即使输出概率无法反映这种区分。

## Motivation
SFT使LLM在经典规划任务（Blocksworld/Logistics）上表现良好，但其内部是否真正恢复了世界模型仍不清楚。已有工作受限于规划问题的复杂度，难以系统性地回答这一问题。

## Method
- 对 gemma2-9b-instruct 进行SFT，使用 Blocksworld 和 Logistics 两个经典规划领域
- 使用线性探针（linear probes）检测中间层表征是否编码了 action validity 和 state predicates
- 比较 expert trajectories 与 random walk 数据的训练效果
- 分析输出概率（generation probabilities）与内部表征的分离现象

## Experiment
- SFT后的LLM能够在内部表征中线性编码 action validity，即使输出概率无法可靠区分 valid/invalid actions
- Random walk 数据（更广的 state space 覆盖）比 expert 数据带来更准确的世界模型恢复
- 部分 state predicates 也可被线性解码，但覆盖率不完全
- 实验仅在小规模经典规划领域进行，未扩展到更复杂的任务

## Value
提供了一套完整的可解释性方法论来检验LLM是否通过SFT学到了世界模型知识。发现输出概率与内部表征的分离是一个重要洞察。但实验规模较小，结论的泛化性有待验证。

## Strengths
亮点是提供了一套完整的可解释性方法论来检验LLM是否通过SFT学到了世界模型知识。

## Weaknesses
不足是实验规模较小，结论的泛化性有待验证。
