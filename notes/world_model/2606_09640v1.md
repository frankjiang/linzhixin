# Physics-Aware Sparse Learning and Selective Online Adaptation for Euler-Lagrange Robot Dynamics

## Insight
无特别突出的insight。基本思路是将Euler-Lagrange动力学的residual分解为结构化的惯性修正+Coriolis修正+广义力修正，并用稀疏latent code控制在线自适应范围。

## Motivation
- **问题**: 标称Euler-Lagrange动力学模型在实际部署中因载荷变化、摩擦、气动效应等变得不准确，现有学习残差修正方法不保持EL系统的力学结构（对称性、正定性、惯性-Coriolis耦合）
- **同行方案**: 黑盒残差学习（DNN/diffusion）、结构感知神经网络（Deep Lagrangian/Hamiltonian）、在线自适应（meta-learning/GP）等
- **关键性**: 对model-based控制有意义，但属于传统机器人动力学建模领域

## Method
1. **结构保持残差分解**: 将残差拆分为惯性修正(Delta_M)、诱导Coriolis修正(Delta_C从Delta_M推导)、广义力修正(Delta_f)
2. **时序历史编码**: 轻量CNN编码最近K步状态-力矩历史为latent
3. **稀疏latent交互选择**: 用soft-thresholding提取稀疏结构码z^M和自适应码z^f
4. **正定惯性参数化**: 低秩+对角保证修正后惯性矩阵正定
5. **选择性在线自适应**: 固定惯性/Coriolis部分，仅对广义力分量做Bayesian线性回归在线更新

## Experiment
- **平台**: 5种机器人（移动机器人、6-DOF机械臂、四旋翼、移动操作臂、空中操作臂）
- **指标**: 归一化预测误差、归一化跟踪误差
- **对比**: vs SysID、PI-TCN、DMRAC、DNN、Diffusion、Meta-learn、Active MLP
- **结果**: 预测和跟踪误差在5个平台上均最低，尤其在强耦合系统（移动/空中操作臂）上优势明显
- **消融**: 稀疏阈值lambda的影响、数据效率、载荷扰动下的自适应速度

## Value
- **工作价值**: 在传统机器人动力学建模领域有扎实贡献，但与视频/3D/隐式世界模型方向几乎无关
- **启发**: 有限——结构保持的残差学习思路在其他领域或许可借鉴，但与用户关注方向距离过远
