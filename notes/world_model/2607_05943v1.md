# SearchEyes: Towards Frontier Multimodal Deep Search Intelligence via Search World Simulation

## Insight
论文的 insight 是把 typed knowledge graph 同时作为数据合成器、确定性搜索环境和 step-level reward anchor，从而让多模态搜索 agent 的训练闭环一致。Observation：若数据、环境和奖励分别构造，RL credit assignment 会很弱；如果问题路径和 gold entity chain 都来自同一个 KG，就能给 hop 级奖励。

## Motivation
多模态深度搜索需要图像、文本、网页/知识库检索、工具调用和多跳推理。现有 VLM agent 训练常缺少可复现环境和精细奖励。本文解决的是 multimodal search intelligence，不是物理世界模型。这里的 “world simulation” 是知识图谱搜索环境，与视频/3D/JEPA/Dreamer 方向几乎无关。

## Method
SearchEyes 构建自包含 KG 搜索环境：融合 Wikidata5M、Wiki6M、Wikipedia images，过滤视觉实体，移除 hub/predicate shortcut。工具包括 text_search、lookup、visual_search、summarize、python_interpreter。数据合成用 PKC：在图上做受约束 random walk，要求 P-K alternation、消歧、领域多样性、anti-shortcut、hidden entities 和信息隐藏式问题。

训练上先用 GPT-4o 专家轨迹做 SFT，再用 HaPO 做 RL。HaPO 使用 gold entity IDs 作为 hop-level anchors，混合 episode-level advantage 与 hop-level advantage，并有 fatal-aware masking、one-sided clamping、asymmetric sigmoid gate、observation token masking 和 KL。

## Experiment
评估在 SimpleVQA、VDR、MMSearch、LiveVQA、BrowseComp-VL、FVQA 六个 benchmark 上。SearchEyes-9B 平均 59.3，优于 Qwen3.5-9B Agentic 的 44.7；SearchEyes-27B 平均 68.1，优于 Qwen3.5-27B Agentic 的 51.1，也高于 OpenSearch-VL-32B 的 61.9。

PKC 消融中 full 平均 61.8；去掉 anti-shortcut 降到 54.1；无 P-K alternation 57.6；GPT-4o free-form 无图只有 49.2。HaPO full 比 GRPO 高约 4.0 分，hop anchor 是主要增益来源。

## Value
对搜索 agent 和 KG-RL 很有价值，但对视频/3D/隐式世界模型没有实质参考。唯一可借鉴的是“环境、数据和奖励共享同一结构化世界”的工程思想；不能把它当物理世界模型论文读。

## Strengths
- 数据合成、环境和 reward 统一，credit assignment 设计清楚。
- 多 benchmark 效果强，消融能解释 PKC 和 HaPO 的贡献。
- 自包含搜索环境提升可复现性。

## Weaknesses
- 与物理世界状态、动作动力学、视频/3D 预测无关。
- 评估依赖 GPT-4o judge，可能有 judge bias。
- KG 构造和高质量专家轨迹成本高。
- “world simulation” 命名容易与物理世界模型混淆。

## Future Work
可扩展到更开放的网页环境、更强工具集、更可靠的人类评估和更大规模多模态知识更新。对本研究方向无直接 future work。

## Rating
创新度评分：3/5 - 在多模态搜索 agent 训练中有不错的系统创新和奖励设计，但不是世界模型方向技术贡献。
相关度评分：0/3 (Noise) - 本质是多模态搜索/KG/RL，不涉及视频、3D 或隐式物理世界模型。

## TL;DR
SearchEyes 用知识图谱搭建搜索环境并做 hop 级 RL，非物理世界模型方向，可跳过。
