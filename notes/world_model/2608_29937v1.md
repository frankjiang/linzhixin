# AcrossWAM1.0:A Modular Latent World-Action Stack for Compact Robot Policies

## Insight

观察：LaWAM 已证明 latent visual subgoal 能辅助机器人控制，但其 world decoder、VLM 与训练态 checkpoint 在实现中紧耦合，小骨干替换和部署裁剪都难以验证。论文据此推论：若把骨干输出、32 维 latent action、DINOv3 tokens 与 action expert 之间定义为稳定接口，并显式区分训练/推理可达模块，就能在不改 latent-subgoal 算法的前提下缩小策略。作者通过相同 2,000 个闭环 episode 的配对比较、逐 tensor 导出校验和跨家族 smoke test 提供工程证据；这证明了 Qwen 家族内的可扩缩性与 checkpoint 状态等价，不证明跨家族性能等价（PDF pp. 2, 6–9）。

## Motivation

Pixel-space world-action model 生成未来图像，参数和延迟成本高；LaWAM 改为预测动作相关的 latent visual subgoal，但原始实现没有把世界模型、multimodal backbone、query 所有权和部署边界真正解耦。论文解决的是重要但偏工程的问题：小骨干能否在匹配闭环测试下保留控制效果，以及导出文件是否真的删除 teacher-only 状态，而非再次提出 latent world-action 学习算法。

## Method

- Stage 1 沿用 LaWAM：冻结 DINOv3，将当前/未来帧编码为 patch tokens；inverse-dynamics Q-Former 从二者提取 32 维高斯 latent action，12-block latent world decoder 以 AdaLN 注入该 latent 并预测未来 DINO 特征。训练同时使用 future-feature SmoothL1、可用 robot state 的位移回归和 KL 正则；Q-Former 随后只作 teacher（Figure 1, pp. 2–4）。
- Stage 2 将骨干封装成 adapter，固定返回 transition context、action context、8 个 ACT queries 与 8 个 flow queries；one-query mapper 预测 latent，并以 teacher latent 蒸馏，再由保留的 world decoder 生成空间化 visual subgoal。VLM、mapper、decoder 和 action expert 可训练，DINOv3 与 teacher 冻结。
- Flow-DiT action expert 同时 cross-attend 语义上下文和当前/预测未来视觉 tokens，以 flow matching 生成 50-step、1.2 s action chunk，推理用 10 次 ODE integration；总损失为 flow loss 加 0.1 倍 subgoal loss 和 0.1 倍 distillation loss。
- 部署导出从实际 inference-reachable graph 追踪参数，移除 inverse-dynamics teacher、state decoder、未用 VQ 状态并去重 alias；adapter 还负责 hidden-size、图像参数和 vocabulary 差异。

## Experiment

- 闭环主实验覆盖 LIBERO Long/Object/Goal/Spatial 四套件，每套 10 任务×50 trials，即每个 checkpoint 2,000 个完全配对 episode。Qwen3-VL-2B 为 98.00%（1960/2000），Qwen3.5-0.8B 为 97.45%（1949/2000），差 −0.55 pp；discordant counts 为 46 对 35，exact McNemar p=0.2664。分套件分别为 96.6/95.0、99.2/99.4、96.8/96.8、99.4/98.6（2B/0.8B；Tables 2、4, pp. 7、12）。非显著不等于等价，论文只声称满足预设的 ≤2 pp retention criterion。
- 参数/导出：2B raw 2,555.2M；0.8B raw 1,883.8M（−26.3%）；0.8B deploy 1,472.6M（−42.4%）。1,078 个保留 tensors bitwise identical；移除 321 个训练态 keys（411.1M 参数），718 个 alias keys 可由保留项逐位复现（Table 3, p. 8）。
- 定性 latent rollout 到第 33 步仍保留大体布局和任务运动，但长程自回归出现明显模糊；auxiliary RGB decoder 只用于可视化，不参与控制（Figure 2, p. 8）。
- MiniCPM-V 4.6 仅做 forward/backward adapter smoke test：query 注入使 hidden state 平均绝对变化 0.33；没有闭环迁移结果。左右指令诊断中，language-CFG 将遵从率从 52/190（27.4%）提到 93/185（50.3%，Fisher p=1.0×10⁻⁵），但非冲突指令 collapse 从 1% 升到 10%（pp. 8–9）。

## Value

价值主要在可审计工程边界：它示范如何把 latent world model 的训练 teacher、推理 decoder、VLM adapter 与连续动作头拆清，并用 episode pairing 和 tensor-level accounting 避免把“模型更小”停留在名义参数量。对我们最有启发的是三层证据分级——接口能运行、同家族闭环保真、跨家族冻结迁移必须分别验证。待解决的是跨家族控制、world decoder 是否能真正复用，以及参数减少能否转化为实测延迟/显存收益。

## Strengths

- 贡献边界克制：明确承认 latent subgoal、decoder 和训练目标来自 LaWAM，不把系统重构包装成新算法。
- 配对 episode、discordant counts、exact test 与非等价声明完整，统计措辞较严谨。
- 导出核验细到 reachable graph、重复 alias、bitwise tensor 和 production CPU loader，可复查性强。
- 同时给出 latent 长程模糊和 language-grounding trade-off，避免只报告聚合成功率。

## Weaknesses

- 核心 closed-loop 证据只有 LIBERO、Qwen 同家族两个单 checkpoint；episode pairing 不能覆盖 training-seed 方差，因而不能支持一般性的 backbone portability（作者限制，p. 9）。应补多训练种子及 MiniCPM-V 等异构骨干闭环实验。
- Compact run 仍微调 latent world decoder，所以没有证明稳定 world interface 或 frozen decoder 可跨骨干复用（pp. 5–6、9）。
- 参数下降 42.4%，但未报告端到端 latency、峰值显存、吞吐或 accelerator/simulator 导出运行；CPU loader 成功不等价于真实部署收益（pp. 7、9）。
- 与近期方法的 Table 1 来自各论文自报数字，训练数据、协议和参数口径不一致，只能作为背景；AcrossWAM 自身也没有完整 RoboTwin benchmark。
- 左右指令实验只覆盖两个 RoboTwin 任务，而且 language-CFG 提升遵从时扩大非冲突 collapse，尚不能称为通用语言 grounding 改善。

## Future Work

作者明确提出/由 limitations 直接指向：完成 MiniCPM-V 等跨家族闭环控制；测试不微调 decoder 的冻结迁移；增加每种骨干的训练种子；测量 latency、peak memory 与 accelerator/simulator export；扩展左右之外的语言 grounding。我们的推断：还应做 adapter/world-decoder/action-head 的逐项消融，并在真实机器人和分布外视觉条件下验证模块边界是否仍成立。

## Rating

创新度评分：2/5 - 主要是对 LaWAM 的接口模块化、紧凑骨干验证和精确导出，工程扎实但没有新的 latent world-action 学习机制，闭环范围也较窄。
相关度评分：3/3 (Core) - 直接研究 latent world-action model、latent future conditioning 与机器人闭环控制，对隐式世界模型部署高度相关。

## TL;DR

将LaWAM拆成可审计模块并以0.8B骨干保留97.45%闭环成功率，系统工程可选读。
