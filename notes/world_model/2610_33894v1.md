# WMEval: Evaluating Interactive World Models Grounded on Physical Simulations

## Insight
观察：视频可跟随动作方向、画面相似，却仍违背碰撞后动量、多阶段因果、跨物体光照方向。推论：交互世界模型须在相同动作下，对照物理模拟器的状态和事件，而不能仅以 LPIPS/主观画质代替动力学评测。作者构建 Unity 配对滚动、校准候选视频的测量器，发现 Project Genie 在 BeamDomino 仅保留 3/15 条完整因果链，Unity 参考为 13/15；该差距远大于审计的判题误差。

## Motivation
多数视频世界模型基准重外观、提示词一致性或笼统物理常识，难直接判定同一动作是否产生正确物理后果。对机器人、游戏引擎和 3D 场景生成，行动控制与因果演化是关键缺口。

## Method
- 九个 Unity 场景覆盖动作控制、物体/角色持久性、刚体运动与力学、密闭瓶液面晃动、因果链、光照阴影；每场景提供语义动作、渲染视频、精确状态与事件记录。给候选模型适配其原生控制接口、按物理时间对齐后，与 Unity 执行同一语义动作序列。
- 从生成视频用 RAFT、GroundingDINO、SAM 2、ByteTrack、DINOv2、VLM 判题恢复可比测量：光流、轨迹/速度/能量、液面角度和频谱、跨物体阴影方向、对象深度/身份、四阶段因果链；另报告感知相似与提示词一致性。
- 重要设计是给学习型评测器测 Unity 自身误差，并检查生成侧是否仍可测，必要时弃评；按模型接口只在支持的维度上评分。创新主要在物理模拟器锚定的多维基准与测量校准，未提出新生成模型。

## Experiment
- 评测 Project Genie、LingBot-World、Matrix-Game 2.0/3.0、HY-WorldPlay、Waypoint-1.5；多数单场景配置每模型 5 次生成，部分大效应做 3 次子采样与统计检验。各模型支持的动作接口不同，因此表格并非统一总排名。
- BallRoller 中 Project Genie 的命令方向光流余弦为 −0.33、LingBot-World 为 1.00；但后者在 MirrorRollingBall 与 Unity 的相对光流误差仍为 0.49。BeamDomino 完整因果链 Project Genie 3/15、Unity 13/15，虽然孤立因果问答约 90% 对 100%。
- BilliardGame 两模型最终球位置误差 0.83/0.45 米，但力学量稳健误差 26.8%/23.3%，Unity 自测 4.9%。液体中 HY-WorldPlay 的 LPIPS 0.300 优于 Genie 0.624，却把瓶子绘成约半个参考面积、液面倾角偏差并未更好。阴影跨物体推定日光方向差 60°–98°，局部阴影平滑不能说明全局照明一致。
- 附录承认深度估计的 Unity 自测误差在 WanderingGarden 可达 222%；液体 40 条视频有 15 条不满足有效跟踪门限，流场有效像素很少。故需按指标可信范围解释结果，特别不能把液体面积直接称为体积守恒。

## Value
对视频/3D 世界模型评测很有参考价值：固定初态和动作、拆分控制/状态/因果/跨视角光照、把测量器自身误差与无法测量的样本显式报告。可用于设计我们自己的“看起来真实但状态不对”压力测试。

## Strengths
有精确状态和事件真值，场景覆盖多个物理失败模式；对 VLM、检测追踪、液体分割等评测器进行参考侧与候选侧审计；同时提供定量、可视化和典型反例。

## Weaknesses
模型动作接口仅语义适配，并非严格相同的底层控制；每维可比模型少、每配置多为 5 次生成；大量指标依赖学习型视觉测量且部分自测误差很高，失效视频的筛除可能造成幸存者偏差；液体仅是单瓶参数化晃动模型，不能代表一般流体；一些场景的镜头机制也会影响物理量反推。

## Future Work
作者未提出成体系的新模型路线。文中界定的后续改进重点是扩大可严格匹配的动作接口与场景，并提升候选视频上的几何、液体和事件测量可靠性；这些是由报告的适用边界推得的方向。

## Rating
创新度评分：3/5 - 物理状态锚定和评测器校准较系统，但属于多场景、多现有指标的基准集成，模型技术创新有限。
相关度评分：3/3 (Core) - 直接评估交互视频与 3D 世界模型的动作、物理和时空一致性。

## TL;DR
用九个 Unity 场景和配对动作揭露视频世界模型的物理与因果失真，测量器校准尤有价值，值得精读。
