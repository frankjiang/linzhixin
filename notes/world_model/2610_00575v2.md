# Token-World: World Modeling in Vision-Language Model Token Space for Robot Manipulation

## Insight

观察：机器人策略消耗 VLM 视觉 token，先预测 RGB 再重新编码会把计算花在纹理上，并可能改变策略真正需要的表征；原始 VLM token 又太大、难以做动力学。推论：保留 token 空间位置、只压缩通道，在紧凑状态中模拟动作条件未来，可能同时提高策略相关保真与速度。受控表征消融中，压缩态的特征 NMSE 为 0.4892，原始 VLM 特征为 0.7851；更高维压缩虽然重建更好，动力学却变差，支持“可预测性不等于重建质量”。

## Motivation

RGB 世界模型作为 VLA 策略模拟器存在表示接口错位；直接拟合 $108\times2560$ 视觉 token 则昂贵。论文关注可供策略闭环调用的动作条件潜在模拟器，是隐式世界模型的核心问题。已有 DINO/JEPA 特征预测和压缩状态方法，本文强调保留 VLM token 的空间布局及策略接口。

## Method

冻结 Qwen3-VL 编码器，以独立训练的语义 VAE 将每帧 108 个 token 的通道从 2560 压至 16，使用 MSE、余弦和 KL 损失；编码器/解码器随后冻结。紧凑 token、机器人本体状态及动作输入因子化空间/因果时间 Transformer，辅以跨滑动窗口的 GRU 记忆。用预测干净端点的 flow matching 和 shortcut forcing 训练动作条件下一状态，滚动时只在紧凑空间自回归，策略调用时才解码回 VLM 特征；RGB 解码器仅用于可视化。创新在策略表征对齐的紧凑模拟接口和表征/动力学取舍，算法组件多为现成技术。

## Experiment

- RoboTwin 50 任务、5000 条轨迹及真实 Franka 六任务、600 条成功轨迹。动作回放下，RoboTwin 特征余弦/NMSE 为 0.7714/0.4892，最强列出基线 IRASim 为 0.7372/0.5685；策略动作余弦/NMSE 为 0.9439/0.1145（表 I）。长程 0/5/10/15 个 16 动作 chunk 的曲线较 Ctrl-World 退化慢。
- 三种同 Qwen3-VL 主干 StarVLA 策略在模型内闭环，模拟与参考任务成功率的 Pearson 相关为 0.794，Ctrl-World 为 0.583；单步耗时 0.359 秒，对 Ctrl-World 1.897 秒（图 6）。**速度对照中本文 16 次采样、RGB 基线 50 次**，所以不能把全部加速归因于 token 空间。
- 维度消融 $d=8/16/32/48$ 中，16 维的特征 NMSE 0.1517 最好；重建误差随更大维度下降，但动力学误差不随之下降。原始 VLM 和 SDXL-VAE 表征均弱于语义 VAE（表 II–IV）。

## Value

值得精读“直接预测策略读入状态”的设计与评测：除特征误差，还看策略动作偏移和模拟成功率排序。可进一步研究跨策略共享、策略不变性及失败概率校准，而非单靠视觉保真。

## Strengths

- 把模拟状态和策略输入接通，避免 RGB 往返；维度/表征消融对应核心假设。
- 同时报告开环表示误差、长时退化、闭环策略相关性与运行延迟。

## Weaknesses

- 闭环是在学习模拟器内运行并对照参考环境，真实数据来自离线轨迹；未证明真机器人上的闭环控制收益。
- 只测共享 Qwen3-VL 主干的策略与少量操纵任务；跨视觉主干、接触丰富场景及反事实动作可靠性未知。
- 成功率相关性不等于误差校准，且可视化/人工判断依赖额外 RGB 解码器；速度对照的采样步数不一致。

## Future Work

作者提出跨策略主干、更多交互数据和其他表征设计，并系统研究何种语义表示最适合学习未来动力学。

## Rating

创新度评分：3/5 - 紧凑策略 token 模拟的工程设计与评测扎实，但 VAE、Transformer、flow matching 均为已知组件。
相关度评分：3/3 (Core) - 直接研究 VLA 使用的动作条件隐式世界模型及闭环模拟。

## TL;DR

在压缩VLM视觉token中预测动作后果并回馈策略，改善模拟保真与速度；表征设计值得精读。
