# MemoBench: Benchmarking World Modeling in Dynamically Changing Environments

## Insight
核心 insight 是视频世界模型的 memory 不能只看目标在视野内是否一致，也不能只看静态遮挡；真正难点是目标离开视野期间仍在发生物理变化，重现时要恢复“更新后的状态”。论文用 disappear-and-reappear paradigm 把 object permanence、动态状态演化和相机控制同时纳入评测。

## Motivation
论文解决视频生成/world generation 模型的记忆一致性评测问题。已有 benchmark 多评估可见目标一致性，或让物体离屏但场景静态，无法测试离屏动态变化。这个问题对视频世界模型很关键：若模型无法维护离屏对象状态，就难以作为可交互世界模拟器。

## Method
MemoBench 构建 360 条 ground-truth clips：196 条 UE5 合成视频强调空间多样性，164 条真实视频强调材料/物理状态变化。每条视频标注 Visible、Disappear、Reappear 三阶段。自动指标包括 visual quality、motion smoothness、object identity consistency、Geo3D consistency、Object Reappearance Score、PSNR/SSIM/LPIPS、Camera Controllability、ImageReward。VQA 指标用 Gemini 生成并过滤 Yes/No 问题，覆盖 instruction following、object/background consistency、continuity of memory、physics adherence，并做人类一致性验证。

## Experiment
评测 10 个模型：CI2V、3D-based、I2V 三类。自动指标显示 Stable Virtual Camera 的 camera controllability 和像素 fidelity 强，HunyuanWorldPlay 的 ORS 最好但也只有 0.582；I2V 模型如 LTX-Video 因相机几乎不动而虚高 smoothness/consistency/ORS。VQA 显示 Instruction Following 中 LingBot-World 和 HunyuanWorldPlay 较强，但 Continuity of Memory 最高也只是约 57，且可能受静态相机虚高影响。论文结论是没有模型同时具备强 camera controllability、高 ORS 和高视觉质量。

## Value
这是视频世界模型 memory 评测的高价值 benchmark，尤其能揭示“相机不动导致一致性指标虚高”和“轨迹控制不等于对象记忆”。对后续模型设计的启发是需要显式 persistent state/memory-aware objective。局限是 VQA 依赖强 VLM judge，自动 ORS 也依赖 SAM-3 检测；benchmark 本身不提出训练方法。
