# 3D Point World Models: Point Completion Enables More Accurate Dynamics Learning

## Insight
核心 insight 是：点云世界模型的长程误差很大程度来自 partial observation，而不是 dynamics backbone 不够强；先补全物体几何，再学习 action-conditioned 3D dynamics，可以让模型对遮挡处的质心、碰撞和代价函数有更可靠估计。完整点云还允许用 point-to-point velocity 监督，避免 Chamfer/Hausdorff 的弱监督。

## Motivation
视频世界模型缺乏显式 3D 结构，长程 rollout 容易几何不一致，且生成视频到机器人动作还需 inverse dynamics。已有 3D point/particle/Gaussian world models 更适合规划，但真实部署只有单视角 partial RGB-D，遮挡导致状态缺失和累积漂移。论文要把 point completion 接入 3D world model，让真实部署也能使用 complete-geometry dynamics。

## Method
3DPWM 输入单视角 RGB-D 和关节角。先用 URDF forward kinematics 采样 robot/end-effector 点；用 SAM3 分割对象，把 depth back-project 成 partial object point cloud，再用 point completion 模型补成完整 object geometry，合并成场景点云。Dynamics 用 Point Transformer V3 encoder/decoder，点特征包含 xyz 和当前/上一时刻 velocity；action 经 MLP 后与 register token 一起作为 cross-attention 的 key/value，点特征为 query，再经 self-attention 传播动作影响。模型预测 per-point velocity，用 Huber loss 做多步 rollout 监督。规划用 MPPI，在 complete point cloud observation space 中写 task cost。

## Experiment
长程 rollout 覆盖 Franka parallel gripper 和 GT-1 dexterous hand，任务包括 PickCube、StackCube、PickYCB、MugCleanup、Box/DrawerCleanup。3DPWM 的 Chamfer 和 reward correlation 显著优于 ParticleFormer+ 与 Partial 3DPWM，例如 PickYCB Chamfer 0.028、reward r=0.85。MPPI 规划中 closed-loop PickCube 90%、StackCube 75%、PickYCB 65%，open-loop baseline 几乎失败而 3DPWM 仍有非零成功。未见长任务 CoffeePreparation 从训练短任务组合达到 45%。Sim2Real 在 Franka PickApple/PickDrill/PlaceApple 上，pick 任务明显优于 ParticleFormer+，place 两者相近。消融显示 register token 和较长 H=15 多步监督有效。

## Value
这是本批最核心的 3D 世界模型论文之一。它把“补全-动力学-规划”链条讲得很清楚，适合借鉴到 3D robot world model：显式几何、任务无关 dynamics、代价函数在 3D 空间直接计算。局限是管线模块多，SAM/point completion 错误会级联；completion 仍依赖对象先验和人工/文本 prompt；MPPI rollout latency 约 1s/action，离实时还有距离。
