# Inferring Action from Future Latent State for Robotic Manipulation

## Insight

论文主张未来观测潜变量比逐帧视频更紧凑，可作为“目标终态”帮助动作生成。但架构图与注意力掩码显示：训练时动作 token 只能读取语言、当前观测和动作自身，不能读取未来观测 token；未来 token 可以读取动作，推理时又被移除。因此实质上是“动作与未来终态的联合多任务学习”，而非从预测未来状态反推动作。实机成功率说明终态辅助损失可能改善共享表示，却没有证明题目所述的因果机制。

## Motivation

视频世界—动作模型通常先生成多帧未来再解码动作，算力和时延较高；纯 VLA 又缺少对任务结果的显式约束。作者希望只预测一个未来端点潜变量，以较低代价注入未来感知。降低世界模型用于操作的推理成本是关键问题，但是否必须让动作实际条件于未来潜态，需要严谨消融。

## Method

当前图像由 DINOv3 编码，语言由 Qwen3 条件化；双流 flow-matching 网络同时去噪 60 步、双臂 14D 动作块与未来端点潜变量，损失为动作流匹配加权未来潜态损失。推理仅保留动作流。论文在标题和模型名中使用 DELE-w0.5，而方法图、正文与结论多处又称 HeTu-1.0，命名不一致。技术上最大的缺口是动作流没有访问未来流，故未来分支只能通过共享参数和辅助监督间接正则化。

## Experiment

在 Astribot S1 双臂实机、固定场景的开门、取百事可乐、取冰和微波炉四个长任务上评测，每方法每任务 20 次，共比较 6 个方法、480 次试验。DELE 总成功率 62.5%（50/80），宏平均进度 81.3%，高于 π0.5 的 15.0%/50.6%；分任务成功率/进度分别为开门 80%/95%、百事 65%/82%、取冰 45%/63.3%、微波炉 60%/85%。还比较 LingBot 等 VLA，但各方法沿用官方配置。论文没有最关键的 λ=0/去掉未来损失消融，也没有与真正生成或条件化未来潜态的 WAM 对照；未报告训练数据量、参数量、吞吐、端到端延迟、置信区间或显著性。

## Value

实机结果提示“预测任务终态”可作为 VLA 的辅助目标，可能比完整视频生成便宜；这值得在隐式世界模型中继续验证。但当前实现和证据不能支持“从未来潜态推断动作”的核心叙事。对我们最重要的启发是审查信息流：联合预测不等于因果条件化，必须用掩码、梯度路径和去分支消融确认未来表征是否真正参与决策。

## Strengths

选择了四个多阶段双臂任务并报告任务完成进度，实机总试验量比纯演示更可信；端点潜态相对逐帧视频是合理的效率假设，整体网络也较简洁。

## Weaknesses

注意力掩码与论文标题的核心机制矛盾：动作看不到未来 token，且推理时未来 token 不存在。缺少无未来损失、不同权重、共享参数隔离和真正未来条件化的消融，无法判断 62.5% 成功率来自未来建模还是普通多任务正则。固定场景、每格 20 次且无误差条，不足以验证泛化；各基线训练条件可能不等价。参数、数据规模、算力和延迟均未报告，却反复强调低成本。DELE/HeTu 的命名混用也降低可复现性。

## Future Work

作者没有明确列出未来工作。合理推断应首先建立真实的“预测终态→动作”信息路径并与当前辅助损失版本等参数比较，补齐 λ 消融、视频 WAM 基线、效率测量和跨场景泛化，再研究不确定或多模态终态下的动作分布。

## Rating

创新度评分：2/5 - 终态潜变量辅助 VLA 有一定想法，但实现并未支持核心因果主张，且缺少决定性消融。
相关度评分：3/3 (Core) - 直接讨论隐式未来潜态与机器人动作生成的世界—动作模型。

## TL;DR

联合预测终态潜变量与动作且实机成功率高，但动作并不读取终态、关键消融缺失，可选读。
