# World Models as Adversaries: Multi-Agent Self-Play Fine-Tuning for Robust Motion Planning

## Insight
核心 insight 是：规划器已有的预测世界模型不仅能做 rollout，也能被角色条件化为“对手”，主动生成稀疏、合理、最能暴露 ego 弱点的交通交互。鲁棒规划训练因此可转化为受约束的 min-max 自博弈，而不是依赖外部攻击器或手写危险场景。

## Motivation
自动驾驶规划器需要应对罕见安全关键交互，但真实数据少，外部 adversary/simulator 与 tokenized planner 的表示不一致。论文要解决如何用同一个 world model 产生可信 adversarial traffic，并用它提升规划器鲁棒性。

## Method
两阶段 decoupled solver。Stage A 冻结 planner，把 world model 通过 role-conditioning 变成 adversarial world model，学习场景自适应攻击 coalition；通过 role switching 做 counterfactual credit assignment，比较 factual rollout 与把某个攻击者切回 background 的结果。Stage B 冻结 AWM，planner 对校准风险分布做 regret-aware robust best response，加入 CVaR/tail-risk 权重和 normal-retention/trust-region，避免牺牲正常场景性能。

## Experiment
在 nuPlan/InterPlan 规划任务上，decoupled AWM-Planner 的 Nom R 0.9818、Adv R 0.9756、Tail 0.8919、Hard NR 80.05、Random R 90.71，优于 planner-only 和 simultaneous alternating。目标消融显示去掉 CVaR 或 normal retention 会降低 tail/hard 或正常场景表现。定性案例展示原 PlanR1 出现碰撞/TTC 失败，而 AWM-Planner 更安全。

## Value
对 world model 方向的价值在于把预测模型用作训练环境和 adversary，而不是只做被动预测。对我们更偏“借鉴”价值：如果做驾驶/机器人 world model，可考虑用角色条件和 counterfactual credit 生成难例，但论文主体仍是规划鲁棒性。

## Strengths
问题设定清晰；利用同一 tokenized world model 保持攻击和规划表示一致；有风险目标、credit assignment 和训练范式消融。

## Weaknesses
核心贡献偏 motion planning fine-tuning，不是新的视频/3D/隐式世界模型；安全保证受限于 tokenized world model fidelity；缺少真实闭环和形式化安全覆盖。

## Future Work
作者指出局限包括 world model 保真度、场景覆盖不足，以及缺少闭环形式安全保证。未来应提高模型保真、扩大场景覆盖并引入更强验证。

## Rating
创新度评分：3/5 - 把 world model 角色化为 adversary 的自博弈训练有一定新意，但主要是组合式规划训练。
相关度评分：2/3 (Related) - 与世界模型训练和驾驶场景相关，但核心是鲁棒规划。

## TL;DR
把交通 world model 变成稀疏对抗体来训练鲁棒规划器，偏规划训练但值得选读。
