# LiveAct: Towards Real-Time Multi-Agent World Models with Heterogeneous Action Interfaces

## Insight
多智能体视频模型的动作失效有两种不同原因：动作流未绑定到画面中的正确实体，以及不同任务的同一向量维度语义冲突。LiveAct 分别在视觉查询端做语言条件的空间调制、在动作键值端把维度描述与同步数值结合；去掉任一端，控制与归属指标大幅下降（表 3、S5）。这说明单有动作编号或单有自然语言，都不足以稳定控制异构场景中的多个实体。

## Motivation
既有可交互视频模型多用单一控制流；多智能体方法常依赖测试时位置、身份裁剪或单一任务定义的动作向量。跨游戏与双臂操作，动作既要对准具体实体，又要保留离散按键/连续机器人数值含义。该问题对多人实时视频世界模型关键，但对纯隐式状态模型借鉴主要是动作接口设计。

## Method
基于 Wan2.2-TI2V-5B，输入首帧、场景文本、各智能体描述、每维动作语义文本及同步动作值。Agent-Aware Spatial Modulation 用冻结 umT5 的智能体描述与视觉 token 的交互生成软空间门，并为每个智能体单独调制查询；Schema-Guided Action Adaptation 为每个动作维度编码语义 token，再以该维的实时数值进行缩放/平移。各智能体查询仅关注自己的动作 token，经交叉注意力产生残差后汇入共享画面；输出投影零初始化（第 4–6 页）。

训练分三阶段：双向视频扩散教师；保留完整动作接口，用干净历史做块因果 teacher forcing；再以模型自身滚动历史做 DMD，将每块四个 latent 的采样缩到四步。Wan VAE 每四原始帧压成一个 latent，每个 latent 只读取对应物理时间窗的动作，缓存推进时用全局时间索引防止动作错位（附录 B）。主要贡献是异构多智能体动作接口及其流式迁移；扩散蒸馏本身沿用现有技术。

## Experiment
自建四款多人游戏和 RoboTwin/RoboFactory：17,951 段轨迹、119.54 小时原始视频；测试为留出轨迹的 108 段 81 帧片段（78 游戏、30 机器人）。报告 FVD、LPIPS、PSNR、SSIM、光流幅度误差、动作逆动力学 Act-F1/NRMSE、交换动作归属准确率 Attr-Acc 和吞吐。游戏 LiveAct 的 FVD 338.5、Act-F1 0.594、Attr-Acc 0.898；机器人分别为 270.2、NRMSE 0.558、Attr-Acc 0.942，均优于表 2 中所列基线。去掉空间调制，游戏 Act-F1 变为 0.172；去掉语义动作适配为 0.225，机器人 Attr-Acc 从 0.942 降至 0.484。把语义描述打乱而不重训，游戏 Attr-Acc 降至 0.504，支持确实使用了动作文字（表 S5）。

在单卡、512×448 下，第三阶段达到 17.70 FPS，较第二阶段 1.66 FPS 快 10.7 倍；但机器人 NRMSE 从教师的 0.430 退化到 0.558（表 S3）。附录仅以一条 241 帧序列展示超出训练窗的生成，未量化长时稳定性或闭环交互。

## Value
对交互式视频世界模型很有参考价值：将“谁控制谁”和“控制量是什么”拆开设计，并明确压缩 latent 与动作时间窗对齐。可复用的评测还包括动作执行、归属交换测试和吞吐的共同报告。待验证开放场景中无文本描述或外观变化时的绑定，以及动作驱动生成能否支撑闭环规划。

## Strengths
- 同一模型覆盖离散游戏与连续机器人动作、2–4 个实体，且不需测试时框、掩码或身份裁剪。
- 有移除模块、替换语义向量、打乱描述和扩展动作窗的消融，能区分语义与数值编码的作用。
- 附录公开数据来源、测试协议和三阶段速度/质量权衡；承认蒸馏损失机器人控制精度。

## Weaknesses
- 108 段测试片段、每条件单个生成种子；长时域仅定性展示，未测试真人交互、真实机器人或下游规划。
- 动作与归属主要由在真实片段上训练的逆动力学网络间接测量；该指标可能受视觉质量与识别器偏差影响。
- 基线并不完全等价：部分直接用发布权重，部分重训或自行复现，且 MultiWorld 被限制为单视角；绝对差距不应全归因于接口。
- 数据主要来自脚本化游戏策略和仿真机器人；泛化到新游戏、新语义或任意数量智能体缺少量化结果。

## Future Work
作者未明确列出后续路线。需要增加跨任务零样本动作语义、遮挡/同貌实体的身份保持、长时闭环控制与真实机器人检验。

## Rating
创新度评分：3/5 - 多智能体语义/数值动作接口组合完整且效果强，但空间门控、文本条件和流式蒸馏多为已有组件的系统化集成。
相关度评分：3/3 (Core) - 直接研究可交互视频世界模型及其动作条件生成。

## TL;DR
以语言空间门控绑定多智能体，以语义和数值联合编码跨任务动作并实现流式生成；视频世界模型接口设计值得精读。
