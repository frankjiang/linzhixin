# Auto-JEPA: A Latent World Model of Continuous Intent for End-to-End Autonomous Driving

## Insight
论文的出发点是：规划不需要重建完整未来世界，只需保留会改变 ego action 的场景信息。于是作者把未来 ego trajectory latent 作为预测目标，推论是若模型必须预测“我接下来应如何运动”，就会自动聚焦有决策影响的车辆，而忽略无关可见物。全验证集语义遮挡支持这一点：遮挡动态 agent 的平均 intent change 为 0.080，是等面积随机遮挡 0.027 的 2.97 倍，并在 71.1% 场景更大；个体车辆案例中，交互车辆遮挡显著改变 latent 与轨迹，非交互车辆影响很小。不过这证明的是模型敏感性与预测目标一致，不足以证明其形成了完整环境动力学或真正因果理解。

## Motivation
自动驾驶世界模型常预测未来视频、occupancy、BEV 或所有 agent 轨迹，计算昂贵且会把容量用在不影响当前规划的内容上。端到端 planner 直接回归或生成轨迹虽简单，却难覆盖多种可行行为。Auto-JEPA 试图用一个决策导向的隐式未来表征连接感知与非参数轨迹检索，避免密集未来重建、显式感知标注和 learned trajectory generator。问题重要，尤其适合研究“世界模型究竟应预测什么”。

## Method
第一阶段用 8 个二维未来 waypoint 训练 trajectory autoencoder，损失同时约束坐标、终点、速度和加速度；随后丢弃 decoder、冻结 trajectory encoder，以其 8×1024 token 序列定义 continuous driving intent。第二阶段输入 4 帧前视图像、4 个历史 ego position 和 route command：冻结 V-JEPA 2 提取视觉 token，history/command encoder 与 24 层 Transformer predictor 输出 8 个 intent token，并以 normalized Smooth-L1、token cosine 与 batch InfoNCE 对齐目标 latent。

推理时 predicted intent 在 110,335 条训练集真实轨迹构成的 memory 中做 cosine Top-300 检索；从 CLOVER 初始化并重训的 scene-conditioned scorer 评价候选，独立 DAC gate 过滤可能越出可行驶区的轨迹。系统是分阶段训练，intent predictor、scorer、gate 之间不反传梯度。创新主要是把 future ego-motion latent 同时作为 JEPA target 和检索 key，将 world modeling 收缩为 planning-relevant intent prediction。

## Experiment
NAVSIM v1 完整 navtest 12,146 场景上，Auto-JEPA 取得 91.3 PDMS（NC 98.4、DAC 98.3、TTC 95.0、comfort 100、EP 87.1），高于表中代表性世界模型/VLA。NAVSIM v2 原 evaluator 为 85.6 EPDMS，采用更新后的官方 human-behavior filtering 后为 89.1；与 CLOVER 90.4 接近，但评价版本差异需谨慎。

组件消融中，用固定 codebook medoid 代替 predicted intent 仅 52.6 PDMS；intent retrieval + gate 为 87.6，加入 scorer 增 3.7；移除 gate 为 91.0，说明 gate 对总分仅 +0.3、DAC +0.4。K 从 1/200/300 得 87.6/91.1/91.3，主要收益来自多候选评分。遮挡分析覆盖 15,364 个验证样本。所有 benchmark 数字来自所选 checkpoint 的单次确定性完整评估，不是独立重训均值；NAVSIM 本身是 non-reactive data-driven simulation，也没有真车或闭环交互验证。

## Value
论文最有启发的地方是预测目标选择：隐式世界模型可以不复原周围世界，而把“环境对未来自我行动的影响”作为最小充分状态。trajectory latent 与 retrieval memory 的共享空间也提供了可解释接口。代价是系统只能在固定 memory 覆盖的动作流形内选择，无法用于交互式仿真或任意反事实环境 rollout；更适合作为 planning representation，而非通用世界模型。

## Strengths
- 预测目标与下游规划接口直接一致，避免训练时辅助 loss 在推理时被完全丢弃。
- 不依赖 object box、occupancy、语义地图或周围 agent motion 标注，视觉 encoder 也保持冻结。
- 组件消融清楚区分 intent、scorer、gate 和候选池大小的贡献。
- 大规模配对语义遮挡为“关注决策相关视觉信息”提供了比注意力可视化更强的干预证据。

## Weaknesses
- 轨迹来自固定 memory；若可行 maneuver 未被检索，scorer 与 gate 均不能生成或修正它。
- 性能的大部分来自 scene scorer：intent+gate 为 87.6，而完整模型 91.3；scorer 又以离线 evaluator 标签训练，弱化“纯 JEPA intent”贡献。
- non-reactive NAVSIM 不能测试 ego action 改变其他交通参与者后的闭环未来，world-model 称谓需限于 action-oriented representation。
- 单 checkpoint、单评估运行，无独立训练 seed 或统计区间；表中其他方法多为 source-reported，协议可能不完全一致。
- updated v2 evaluator 将 EPDMS 从 85.6 提至 89.1，显示 headline 对评测实现敏感。
- 遮挡动态 agent 可能引入分布外黑块；随机等面积 mask 是合理对照，但仍未证明特定对象关系被因果建模。

## Future Work
作者明确提出扩大 trajectory memory、采用 adaptive retrieval，以及用 intent-conditioned trajectory generation 或局部 refinement 突破候选覆盖；还建议改进 scorer/gate 校准、hard-negative 训练和 uncertainty-aware scoring。更进一步应在 reactive closed-loop simulator 与真车上验证交互和安全。

## Rating
创新度评分：3/5 - 将未来 ego trajectory latent 变成 JEPA 预测目标与检索 key，设计清晰且结果强；但依赖固定轨迹库、强 scorer 和分阶段工程，尚非通用新范式。

相关度评分：3/3 (Core) - 直接研究 JEPA 式决策导向 latent 世界模型，是隐式世界模型如何选择预测目标的核心案例。

## TL;DR
以未来 ego 轨迹 latent 代替密集世界预测，规划效果强且解释清晰，值得精读。
