# RoboPhys-3D: A Comprehensive Embodied World Model Evaluation via 3D Reconstruction

## Insight

观察：视频 rollout 即使画面顺滑、VLM 判断合理或内部 3D 自洽，也可能没有保持真实对象状态，更无法解码成可执行动作。论文据此推论：必须让 generated/ground-truth 视频经过匹配的 reconstruction pipeline，先量化重建误差，再把 pixel、geometry、state 与 task execution 分层评估。实验证据显示 CogVideoX 的 3D geometry consistency（3.0919）可高于 ground truth（2.9145），却只有其 16.5% task success；Cosmos 的 object localization/trajectory accuracy 也仅保留 ground truth 的 61.2%/73.2%（Tables 2、54, pp. 7、64–66）。这证明各类指标不可互换，但不构成“高相关指标必然导致成功”的因果证明。

## Motivation

既有视频/具身世界模型 benchmark 多评视觉质量、VLM 物理常识或内部几何一致性，缺少在同一机器人场景中对齐 ground-truth 3D state 与可执行动作的统一协议；不同 benchmark 的 taxonomy 也不一致。这个问题关键：视频世界模型被当作 data engine、planner 和 simulator 时，感知得分不能替代对象轨迹与任务完成。RoboPhys-3D 试图用重建匹配、模拟器 privileged state 与 IDM replay 串起从画面到执行的误差链。

## Method

- 数据基于 RoboTwin 2.0 的 50 任务、四种 regime（单/双臂×有/无 target），每任务 100 episodes、每 episode 五视角，共 5,000 episodes/25,000 ground-truth videos；按任务做 70/15/15 episode split，所有视角与衍生物同 split（Table 8, p. 14）。
- 每 episode 有原指令、Physion-Eval caption 与 view-aware caption。后者由 Qwen3-VL 读取完整 ground-truth 视频，明确 gripper laterality、approach/grasp/execute/final state，再人工过滤 hallucination（pp. 5、16–17）。
- 四个 world models（Wan 2.2、CogVideoX 1.5、Cosmos 3、RoboDreamer）在训练集 post-train，从 initial frame+prompt 生成统一为 81 frames 的 rollout。Raw rollout 与四种 3D/4D substrate（VGGT、VGGT-Ω、4DGS、4C4D）共同构成 145,000 videos；每种 generated/ground-truth substrate 用匹配流程评分。
- DreamGen IDM 将视频解码为 7D 单臂/14D 双臂动作并在模拟器 replay；另以解码 synthetic data 训练 π0.5，分别衡量 Action Planner 与 Data Engine utility。DreamGen 相比 J-IDM/MIDM 的 MAE 为 0.0112 vs. 0.0744/0.0273（Table 7, p. 8）。
- 50 metrics 被分为 18 sub-dimensions、四 levels：pixel fidelity（20）、3D geometry（8）、state understanding（16）、task completeness（6）。AFS 先在 metric→sub-dimension→level 内平均，再等权平均四 levels，避免指标多的 level 自动占优（Eq. 2, p. 6）。
- RoboPhyscore 对每个非 task-success metric 分别计算与 Action Planner、Data Engine、VLM-2 的 Pearson r，要求三者最小值 >0.70，选出 FVD、JEPA Similarity、Semantics Consistency、Average Recall、nDTW、Physical Commonsense、Subject Adherence、Normalized Score 八项并等权平均（Eq. 3–4, p. 6）。

## Experiment

- 主结果（Table 2, p. 7）：RoboPhyscore 为 ground truth 0.6829、Wan 0.5359、CogVideoX 0.3363、Cosmos 0.6330、RoboDreamer 0.3492；Cosmos 达 ground truth 的 92.7%。AFS 分别为 2.8379、2.5714、2.2517、2.7797、2.1246（满分 4）。
- Execution 差距（Table 54, pp. 64–66）：Task-success aggregate 为 ground truth 2.4340/3，Cosmos 2.0910（85.9%）、Wan 1.5630（64.2%）、CogVideoX 0.4005（16.5%）、RoboDreamer 0.1515（6.2%）。CogVideoX collision safety 最高 0.9650，却几乎不完成任务，说明静止/保守行为可“安全”但无用。
- Reconstruction ablation：raw/VGGT/VGGT-Ω/4DGS/4C4D 上 Cosmos RoboPhyscore 为 0.6800/0.6649/0.6705/0.5530/0.5965；feed-forward reconstruction 保留 raw 的 94.7%–96.1%，4DGS/4C4D 仅 78.2%/85.4%（Table 4, p. 8）。Trajectory Accuracy 对重建尤其敏感：ground-truth raw 3.7295，VGGT-Ω 1.8261，4DGS 1.4393，4C4D 1.3311（Table 40, pp. 51–52）。
- Prompt ablation（Tables 6、55, pp. 8、65）：Wan 的 RoboPhyscore 0.4962→0.5474→0.5782（+16.5%），Cosmos 0.6519→0.6541→0.6800（+4.3%）；Wan task-success 1.4650→1.6575→1.8850，Cosmos 2.1400→2.1400→2.3275。
- Score sensitivity（Table 16, p. 29）：threshold 0.7 的 8-metric score 对 human Pearson r=0.9761、Spearman ρ=0.8962、R²=0.9528；0.8 只剩 JEPA Similarity 一项，反而对 Action Planner/Data Engine 有更高 r=0.9665/0.9616。AFS 对 human 的 r=0.9746、ρ=0.9715，且 MAE 0.0284 优于 RoboPhyscore 0.0317（Tables 18–19, pp. 32–33）。
- 人评招募 70 人、每 sample 至少三评，模型/重建身份盲化、顺序随机；但未报告总样本数、inter-rater reliability 或置信区间（pp. 30–31）。

## Value

这是视频/3D world model 评测的重要参考：最有价值的不是又一个总分，而是把 reconstruction-induced 与 generation-induced error 分开，并把 VLM plausibility 与 simulator execution 并列。对我们可直接借鉴：报告各层 raw metrics，不把 AFS/RoboPhyscore 当唯一结论；用 ground-truth substrate 校准 IDM 与重建器；重点关注 object localization、nDTW 和真实 replay。尚待解决的是独立验证 score construction、避免未来信息 prompt、真实机器人与跨 embodiment 泛化。

## Strengths

- 覆盖规模与诊断维度丰富：50 tasks、四 regimes、四 world models、四 reconstruction methods、三 prompts、三 IDMs，并提供到单 metric 的 66 页结果。
- Ground-truth 视频也经过同一 reconstruction/IDM 链，能显示 4DGS 等中间件本身造成的误差，而不把全部损失归给生成模型。
- 明确展示 geometry self-consistency、VLM plausibility、collision safety 与 state/execution 可能反向排序，结论对 benchmark 设计有实质价值。
- AFS 的层级等权规则透明，RoboPhyscore 提供 threshold sensitivity，并与三种外部 unified scores、人评和执行信号比较。

## Weaknesses

- View-aware caption 由完整 ground-truth rollout 生成，甚至要求描述 approach→grasp→execute→final state（pp. 5、17），向生成器泄露待预测的未来轨迹。其 prompt ablation 更接近“用更完整未来脚本重演视频”，不能直接证明从当前状态/任务推断动力学的 world-model 能力；应另报不看未来视频的 prompt 设置。
- RoboPhyscore 在同一批 model×reconstruction configurations 上按 task-success correlation 选指标、调 0.7 threshold，又在这些 task-success 信号上报告高相关，缺少 held-out model/configuration 或 nested validation，存在 selection overfitting。0.8 时单一 JEPA metric 对两项执行信号反而更强，也显示组成并不稳定（Table 16, p. 29）。
- “3D-grounded/shared reconstructed scene”表述强于实际 3D 指标：Appendix B 将四个 RBG 与 roundtrip 指标列为 reference-free，Perspectivity 为 VLM-grounded；3D level 甚至与 state/task 近零相关并让 CogVideoX 超过 ground truth（pp. 23–27）。当前协议是多信号间接 grounding，不是统一坐标中对 generated mesh 与 simulator geometry 的全面直接误差。
- Human-study 描述没有总样本量、每配置覆盖、annotator agreement、置信区间或显著性；正文/Appendix D 一处称 sample-level correlation，D.1 又称 configuration-level scores，统计单位需澄清（pp. 30–32）。
- AFS 的四 level 各 25% 和 RoboPhyscore 八项等权均为设计选择；不少 metrics 高度冗余（AP/AR r=0.992，Action Planner/Data Engine r=0.999），但没有去冗余或不确定性传播。
- 只覆盖单一 simulator/embodiment 与四个 post-trained models；不同架构的训练规模、参数量（0.34B–16.4B）和配方不完全可控，所有排行榜均缺 task/bootstrap error bars。Data Engine 的 π0.5 synthetic-data 数量、训练方差也未充分展开。

## Future Work

作者明确提出扩展 cross-embodiment、cross-dataset、sim-to-real，并与更多 VLA policy 比较（p. 9）。我们的推断：应加入不含未来视频信息的 prompt track；用全新 world models/tasks 留出验证 RoboPhyscore；直接对齐 simulator mesh/pose 的 3D metrics；公开人评样本与一致性统计；对 IDM、reconstruction、policy training 的误差做置信区间和方差分解。

## Rating

创新度评分：3/5 - 重建匹配的多层 EWM 评测协议与执行链有明显新意、规模也大；但核心仍是既有指标/模型的 benchmark 组合，score 选择和验证存在循环性。
相关度评分：3/3 (Core) - 直接评估视频世界模型的 3D 状态保持、动作可执行性与任务完成，是视频/3D世界模型核心评测工作。

## TL;DR

提出重建配对的3D具身视频世界模型基准，揭示观感与执行脱节；评测研究值得精读。
