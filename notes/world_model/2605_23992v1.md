# A World Model of Radiologist Reading for Medical Image Representation Learning

> arxiv: 2605.23992v1 | 2026-05-17 | Yiwei Li et al. (University of Georgia, NJIT)

## TL;DR

将放射科医生的眼动轨迹作为JEPA式世界模型的预测序列，自回归预测下一注视patch表征并补全未访问区域，实现胸片诊断SOTA；JEPA在医学影像的领域应用，非核心方向，可略读。

创新度：3/5 | 相关度：1/3

---

## Insight

"世界模型"概念的一次领域迁移：将医学图像视为"世界"，放射科医生的注视序列视为"轨迹"，用JEPA框架在表征空间自回归预测下一注视点。核心洞察是**专家阅片的时序结构本身就是强监督信号**——不仅编码了"看哪里"，还编码了"以什么顺序积累证据"。

## Motivation

- 医学影像标注昂贵，现有方法要么只用眼动热力图作为静态空间先验（丢弃时序），要么将扫描路径预测与诊断解耦
- 放射科医生的注视轨迹蕴含诊断推理的时序结构（搜索、比较、积累证据），但此信号未被充分利用
- 目标：用眼动轨迹的时序结构来定义预训练的预测顺序，同时服务于诊断分类和扫描路径解码

## Method

**GazeWorld** 架构（基于JEPA范式）：

1. **Patch表征与注视序列**：视觉编码器（MedCLIP-Swin）将图像映射为patch token；眼动数据映射为有序的唯一patch索引序列 S
2. **Next-Fixation Prediction（自回归分支）**：
   - 构建fixation token = 视觉特征 + 空间嵌入 + 时序rank + 停留时长
   - 因果Transformer自回归预测下一注视patch的**潜在表征**（非像素）
   - 目标来自EMA动量编码器，损失为SmoothL1
3. **Spatial Completion（空间补全分支）**：
   - 对未被注视的patch，用可学习mask token + 空间嵌入构建query
   - 通过cross-attention从注视上下文表征中预测其表征
   - 同样用动量编码器提供目标
4. **总损失**：L_pre = L_AR + lambda * L_SC（lambda=1.0）
5. **推理时不需要眼动数据**：自回归预测器从图像自身生成表征序列

## Experiment

- **数据**：MIMIC-EYE眼动数据集预训练（15 epochs），在CheXpert/RSNA/SIIM-ACR三个外部数据集评估
- **诊断分类**：冻结特征 + 线性探针，9个监督设置全部SOTA（1%/10%/100%标签），三个数据集零样本均最优
- **扫描路径预测**：冻结特征 + 轻量解码器，ScanMatch超LogitGaze-Med 16%+，SED降低22%+
- **消融**：
  - 注视顺序关键：换成光栅扫描或随机序列，零样本AUROC显著下降
  - AR分支贡献大于SC分支，两者结合最优
  - 可在MGCA/EGMA/MedCLIP等不同backbone上叠加使用，均有提升

## Value

- 将JEPA世界模型范式（LeCun 2022）成功迁移到医学影像预训练，证明专家行为的时序结构是有效的自监督信号
- 方法论上的启示：**用领域专家的行为轨迹定义预测顺序**是一种通用思路，理论上可扩展到其他需要专家交互数据的领域
- 局限：仅限胸片+单一眼动数据集，泛化性待验证
- 对JEPA/世界模型研究者的价值：提供了一个JEPA在序列预测任务中的具体实例化方案（注视序列 vs 视频帧序列），但领域差异较大
