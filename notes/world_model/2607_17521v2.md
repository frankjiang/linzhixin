# GeoWorldAD: Geometry World Action Model for Autonomous Driving

## Insight
有。Observation 是自动驾驶规划既需要当前 3D 空间约束，也需要短期未来空间演化；只有视觉/视频 action token 容易缺几何 grounding，只有当前几何又会在动态场景下保守。推论是把 present multi-scale geometry 与 latent future geometry 放到同一 ego-aligned 几何空间中，用未来几何 token 做 anticipatory guidance，可以提高 ego progress 且不牺牲安全。

## Motivation
解决端到端自动驾驶规划中“安全 vs 效率”的几何 grounding 问题。同行包括 Epona/DriveLaW/DriveVLA-W0 等 future state/video world model 方法，以及 DVGT/DVGT-2/LFG 等 dense geometry planner。现有方法要么未来预测偏像素/语义，几何约束弱；要么只用当前几何，缺少对动态 agent 和 free space 演化的预判。对 3D 世界模型方向，这是典型的几何 world-action model。

## Method
三模块。Video Geometry Model 基于 StreamVGGT，使用 DINOv2 encoder 和 24 层 transformer decoder，从层 {4,11,17,23} 取 multi-scale geometry tokens，并通过 DPT head 预测 depth/point map/camera。作者把原本 anchor-frame 坐标改成每帧 ego-camera 坐标，camera pose 表示相邻帧相对变换，称为 EgoStreamVGGT，以对齐规划轨迹的 ego 坐标系。

Geometry World Model 维护 K=4 个未来 chunk、每 chunk M=64 个 latent future tokens，覆盖未来 2 秒。ego velocity、steering、command 经 MLP 形成 ego embedding。未来 token 通过 Q-Former 式多阶段 cross-attention 读取多尺度当前几何，再用 causal future self-attention 保持时间因果；随后预测未来 geometry tokens，并共享 DPT depth head 解码未来 depth，用未来深度和梯度加 confidence loss 监督。

Geometry World Action Model 初始化 64 个 trajectory queries、8 步规划 horizon。queries 先经过 4 个 present-geometry aggregation stages，逐层 cross-attend 到不同尺度当前几何；再经过 1 个 future-geometry refinement stage attend 到 latent future geometry。每阶段输出 trajectory proposals，用 min-over-proposals L1 监督；最终 proposal scoring head 用 NAVSIM 的 NC/DAC/EP/TTC/comfort 组成目标分数训练。总 loss 为 trajectory、score、4D reconstruction、future geometry loss。

## Experiment
训练三阶段：先在 OpenScene、nuScenes、ParallelDomain、RealDriveSim 上预训练 EgoStreamVGGT 23K steps；再并行训练未来几何 world model 47K steps 和仅当前几何 planner GeoAD 32K steps；最后将两者合并，在 NAVSIM navtrain 上训练完整 GeoWorldAD 64K steps。

NAVSIM v1 navtest：GeoWorldAD PDMS 91.0，优于 DVGT-2 90.3、EponaV2 90.4、DriveVLA-W0 90.2；NC 99.0、TTC 95.8、EP 85.9。NAVSIM v2：EPDMS 90.4，高于 DVGT-2 89.6 和 EponaV2 88.9；NC 99.0、TTC 98.6、EP 89.1、EC 82.2。未来几何消融中，GeoAD 仅用当前几何时 v1 PDMS 89.3、v2 EPDMS 87.6；加入 latent future geometry 后到 91.0/90.4，主要提升 ego progress，同时 NC/TTC 小幅提高。几何表征消融显示 EgoStreamVGGT + 4D reconstruction supervision 的 PDMS 89.3，明显高于 scratch 84.2 和 vanilla StreamVGGT 84.8。深度估计上 EgoStreamVGGT 也显著优于 StreamVGGT，例如 OpenScene AbsRel 0.141 vs 0.236。

## Value
对 3D 世界模型方向很相关。它的启发是：自动驾驶 world model 不一定要预测 RGB 视频，未来几何 token 可能是更紧凑、更 action-relevant 的世界表征；同时，坐标系对齐是几何世界模型接入规划的关键工程细节。待解决的是它仍主要验证 NAVSIM，不是真实车闭环；未来几何只用 depth 监督，行为因果和动态 agent 交互仍较弱。

## Strengths
把 geometry foundation model、future geometry world model、trajectory refinement 串成统一管线。当前几何与未来几何的分工清晰，消融能说明 future geometry 主要提升 progress 而不损害安全。Ego-aligned 改造不是小细节，对规划坐标一致性很关键。

## Weaknesses
相对强 baseline 的绝对提升不大，且依赖大规模多源训练和 NAVSIM 打分。planner 仍处理固定长度 clips，尚非真正 streaming action model。未来深度监督能否覆盖复杂动态交互有限；缺少真实道路闭环和失败案例分析。

## Future Work
作者明确提出虽然 EgoStreamVGGT 支持连续视频流 4D reconstruction，但当前 trajectory planner 仍是固定长度 clip；未来需要引入 KV caching，实现高效 streaming planning inference。

## Rating
创新度评分：3/5 - 将 ego-aligned 视频几何、latent future geometry 和轨迹规划结合，设计完整但属于已有自动驾驶 world-action 路线上的组合创新。
相关度评分：3/3 (Core) - 直接研究 3D/几何世界模型与自动驾驶 action planning，和用户的 3D world model 方向核心相关。

## TL;DR
GeoWorldAD用ego-aligned当前/未来3D几何token指导自动驾驶规划，3D世界模型方向值得精读。
