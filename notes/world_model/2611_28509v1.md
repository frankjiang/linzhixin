# AlpaSafe: Risk-Aware Trajectory Selection for Vision-Language-Action Models in Autonomous Driving

## Insight
观察：多轨迹 VLA 的候选集合中可能有好轨迹，但部署时没有“事后选最优”的 oracle；生成候选的 VLA 隐状态可能已经编码足够场景信息，可供轻量风险判断。作者在固定候选池上训练选择器，使碰撞或离路合并事件率下降；不过把场景 token 置零后，排序 regret 与 top-1 差异无统计支持，说明场景状态对排序的贡献尚不清楚。

## Motivation
驾驶 VLA 一次给八条轨迹，常见 best-of-K 指标只衡量候选上限，不衡量真正执行的选择。在线世界模型评估每条候选成本高；论文研究能否复用冻结 VLA 前向中已有的特征，在不生成未来画面的条件下选较安全轨迹。问题是规划器选择，世界建模只属背景。

## Method
从冻结 Alpamayo-1.5 同一次 prompt prefill 捕获最后一层最后一个 4096 维 token，与每条 64 点轨迹分别编码融合。约 170 万参数的小头预测候选相对效用、碰撞与离路 logits，另外训练期辅助预测轨迹执行偏差、进度与组平均效用。推理时先按两个风险 logits 的帕累托支配剔除候选，再在未被支配者中选相对效用最高者；没有推理时未来展开或 VLA 微调。比较最后 token、全 prefill、零 token 三种场景输入。

## Experiment
AlpaSim 525 场景、1575 决策组、每组八条共 12600 个缓存闭环结果，按场景五折交叉验证并用场景 bootstrap。默认首条、随机、AlpaSafe 的选中 regret 为 0.0611/0.0586/0.0512，top-1 一致率 0.239/0.238/0.348；碰撞或离路事件率 6.41%/6.10%/4.93%。零 token 的 regret 0.0536、top-1 0.345，与最后 token 差异无统计支持；合并事件率则高 0.72 个百分点。完整选择路径在 GPU 上 0.75 ms；该速度比较不含 VLA 生成候选，且不与世界模型的选择质量等价。

## Value
固定候选、按场景留出和报告“执行所选轨迹”的后果，可借鉴到世界模型规划评测；但方法并未显式学习或推演环境状态，阅读建议可选读评测协议。

## Strengths
严格固定候选与缓存模拟结局，减少搜索差异混杂；同次前向抓取特征并验证来源；指出风险排序无绝对安全保证，公开事后规则选择带来的探索性局限。

## Weaknesses
规则根据同一批场景的早期分析后选定，比较非独立确认；多重比较未校正，安全事件较少。没有反复在线重规划，也没有对强世界模型选择器作质量等预算比较；场景特征对核心排序收益的增益不显著。

## Future Work
作者计划在在线重规划下评估选择器，并研究以最后 token 和候选轨迹为条件启动世界模型式未来展开。

## Rating
创新度评分：2/5 - 冻结 VLA 特征复用与小型风险头是实用增量，主要机制属于常规轨迹重排。
相关度评分：1/3 (Tangential) - 与世界模型候选评测相关，但本文没有视频、3D 或隐式动力学世界模型。

## TL;DR
复用驾驶 VLA 的最后隐 token 轻量重排八条候选轨迹，降低缓存风险事件；可选读评测协议。
