# Scale Buys Interpolation, Structure Buys a Horizon: Certified Predictability for Equivariant World Models

## Insight
核心 insight 是：平均预测误差不能回答“当前状态能信多久”；若 latent world model 具有真实动力学对称等变性，则 rollout error 在 symmetry orbit 上常数，并且可由 Lyapunov spectrum 给出逐通道可预测 horizon。近似等变的 horizon 上界是紧的，误差残差会按 exp(lambda T) 放大。

## Motivation
世界模型用于规划时需要 per-situation trust certificate，而不是平均 FVD/MSE。现有等变鲁棒性多是 one-step，缺少 multi-step horizon；大模型缩小插值误差但不能自动给可靠 horizon。该问题与隐式/latent world model 的可信部署高度相关，但偏理论。

## Method
设 encoder E、predictor f、群 G 作用在状态/latent/action 上。Theorem A：在 encoder/predictor/dynamics 等变且表示保范时，T-step rollout error 在生成 monoid 的 orbit 上常数。Lemma 2：orbit-constant error 对所有等变目标成立当且仅当 predictor 等变，说明证书是结构专属。Theorem B：近似等变时，通道 j 的误差 variation 由 residual 和 per-step error 乘 exp(lambda_j T) 控制，horizon 约 log(1/epsilon)/lambda_j；Proposition 6 给匹配下界。另用 conserved/invariant channels 给无界 horizon 方向。

## Experiment
大量小规模/审计实验：控制 latent 和 Lorenz/Henon/Rossler 的 staircase 与理论斜率吻合；40-D Lorenz-96 上 Z_N 等变模型恢复 Lyapunov spectrum R2=0.98-0.99，dense/GRU 失败。预算 re-observation 中等变证书在 knee budget violation 8-16%，dense 证书 61-65%。训练免费审计 TD-MPC2、LeWM、V-JEPA2-AC：在强扩张区 calibration 较好，弱扩张/contracting/bias-dominated 时 abstain 或 cross-check 失败；多任务 TD-MPC2 尺度增加不单调改善 calibration。

## Value
思想很有价值：把世界模型评价从“预测误差”推进到“结构保证的可预测 horizon”。但论文表述夸张、实验体系复杂且多为作者自建审计，离主流视频/机器人 benchmark 仍远。适合关注 latent WM 可信性/等变结构的人精读，工程读者可先读定理和 E2/E12/E13。
