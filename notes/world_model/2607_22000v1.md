# Music-JEPA: Learning a World Model of Sound from Action

## Insight
有。论文把音乐理解为 action-conditioned dynamical system：当前 2 秒钢琴音频是 state，下一段 MIDI pianoroll 和踏板是 action，未来音频 latent 是 next state。Observation 是音乐音频的未来变化很大程度由演奏动作决定；推论是 JEPA 预测目标 embedding 时加入 action，可以学到比 audio-only JEPA 更有物理/行为含义的 latent dynamics。

## Motivation
论文解决音乐自监督表示中缺少动作/控制变量的问题。已有音频 SSL 模型如 MERT 主要学习静态或上下文表征，audio-only JEPA 只根据音频预测未来，无法区分“系统自身延续”和“演奏动作驱动”。这是 JEPA 世界模型思想在音频域的迁移，对用户的视频/3D方向不是核心，但对 implicit world model 的 action-conditioned representation 有借鉴。

## Method
模型包含 state encoder `E_s`、action encoder `E_a`、state predictor `f` 和 action predictor `g`。输入是 2 秒 log-mel spectrogram 与 MIDI pianoroll/pedal；state predictor 通过 cross-attention 使用 future action tokens 预测 future audio latent；action predictor 建模 action prior。训练使用 EMA teacher encoder、LayerNorm，损失为 future state latent MSE 加 action prediction MSE。

下游转录不是直接解码世界模型，而是冻结模型后训练 inverse predictor，从 `s_t, s_{t+1}, a_t` 推断 action latent，再用 action decoder 输出 pianoroll，属于 amortized planning。

## Experiment
数据是 MAESTRO v3.0.0，约 200 小时钢琴音频/MIDI。模型约 19M 参数，在 A100 上训练 15-25 epochs。对比 AO-JEPA 和 MERT，评估包括扰动敏感性、节拍/作曲家/调性等 MIR 任务，以及自动转录。

动态实验中，Music-JEPA 对输入/目标时间扰动、随机扰动和 MIDI action 扰动更敏感，说明 action-conditioned latent 捕捉到可控动态。MIR 上 beat F1 优于 AO-JEPA 和 MERT；composer 任务 MERT 在 weighted F1/Top1 更强，但 Music-JEPA Top3/Top5 竞争力较好；key 任务 Music-JEPA 与 AO-JEPA 接近且优于 MERT。转录上 note F1 明显低于监督模型，但 pedal MAE 优于若干监督基线。

## Value
工作价值在于展示 JEPA world model 可以迁移到非视觉 action-sound 系统，并通过动作条件提升动态表征。对我们启发是：action 可以不是机器人控制，也可以是更抽象的“状态转移原因”。但场景是音乐，不直接服务视频/3D世界建模。

## Strengths
亮点是 state/action 划分清楚；实验不仅看下游分类，还检查扰动敏感性和转录；模型较小但能体现 action-conditioned JEPA 的收益。

## Weaknesses
创新主要是应用迁移，架构并不复杂；MAESTRO 是单一钢琴域，action 标注天然可得；转录结果不接近强监督系统；没有展示生成、规划或长期控制能力。

## Future Work
作者提出扩展到缺少动作标注的音乐场景、学习更抽象的 latent action，以及用于作曲、交互式音乐规划等任务。

## Rating
创新度评分：3/5 - JEPA/action-conditioned 思路迁移到音乐有新意，但不是世界模型方法上的大突破。
相关度评分：2/3 (Related) - 方法上与隐式世界模型/JEPAs 相关，场景与视频/3D主线较远。

## TL;DR
把钢琴音频-MIDI建成action-conditioned JEPA，方法相关但场景偏音乐，可选读。
