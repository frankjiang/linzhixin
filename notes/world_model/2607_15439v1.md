# Do Coding Agents Need Executable World Models, Simplification, and Verification to Solve ARC-AGI-3?

## Insight
论文 insight 是对编码 agent 来说，外显可执行 world model、模型简化和 replay verification 的价值不能只凭直觉判断，需要受控消融。Observation 是 ARC-AGI-3 中 agent 常能发现局部动作效果，却无法整合为可迁移的全局规则；推论是可执行模型和验证可能帮助，但也可能带来维护开销和错误模拟器误导。实验发现最稳定因素反而是模型能力和 reasoning effort；verification treatment 总是第一，但成本最高；单纯要求 flexible executable model 不一定优于 textual model。

## Motivation
论文解决 ARC-AGI-3 agent harness 中三个机制的归因问题：可执行世界模型、scheduled simplification、exact replay verification。之前系统把三者绑在一起，无法知道性能来自哪里。这个问题对交互式抽象环境、程序化 world model 和 coding agent 研究有意义，但不是视频/3D/隐式物理世界模型问题。

## Method
作者构造四个 nested Codex agents：twma_v1.2 只维护 textual world_model.md；ewma_v1.2 要维护可执行 world model 和 planner，但接口自由；ewma_s_v1.2 加入控制器定期发送简化/泛化 prompts；ewma_sv_v1.2 进一步固定接口，包括 world_model_engine.py、state reconstruction、renderer、main planner，并提供 verify_world_model.py 和 verify_main_planner.py。验证要求模型从初始状态重放所有已记录 attempts，rendered 64x64 ASCII frame 与真实观察逐格一致，并检查 planner 在已完成 level 能模拟到 LEVEL_COMPLETED。

## Experiment
主实验在 ARC-AGI-3 25 个 public games 上评估 4 个 variant x gpt-5.4/gpt-5.5 x high/xhigh，每个 block 一次全量 25 game。指标是 RHAE、未解 games/levels、cost tokens。结果：所有 variant 随模型和 effort 提升而提升；verification 在四种模型/effort 下都最高，例如 gpt-5.5 xhigh 为 74.78，高于 textual 72.51、executable 69.70、simplification 73.09；但 verification cost tokens 也最高，gpt-5.5 xhigh 222.06M。可执行模型本身效果混合，在 gpt-5.5 两档反而低于 textual。follow-up v1.6 + gpt-5.6-sol 接近 public set 饱和，verification xhigh/max 均解完 183 levels、RHAE 约 99，但作者强调存在训练污染和 public set ceiling 风险。

## Value
对我们有间接启发：world model 外显化不是免费收益，接口、验证工具和简化压力的组合比“要求写 simulator”更重要；精确 replay verifier 可以把错误模型转化为可操作 counterexample。若研究机器人/视频 world model 的评估闭环，可借鉴其 verification mindset；但技术本体和目标域偏离。

## Strengths
归因问题清楚，四个 variant 设计相对克制；对 harness 泄漏、技术失败、成本 proxy、public/private benchmark 边界写得诚实；结论不夸大，承认 verification treatment 是组合效应且 public saturation 不等于泛化。

## Weaknesses
每个 game 每个设置只跑一次，run-to-run 方差无法估计；最终 verification variant 同时改变固定接口、模板、工具和验证目标，无法隔离单一因素；使用未来闭源模型和 public ARC-AGI-3，有污染疑虑；与视觉/物理世界模型方法距离较远。

## Future Work
作者提出三点：在 held-out ARC-AGI-3 环境验证 public set 饱和是否泛化；补跑 textual+simplification 和 verification-without-simplification 两个缺失组合；把同样 ablation 扩展到 AGI Maze 等有隐藏测试集的交互环境。

## Rating
创新度评分：2/5 - 贡献主要是系统消融和实验归因，方法机制来自已有可执行模型、简化prompt和replay验证组合。
相关度评分：1/3 (Tangential) - 研究程序化/文本交互世界模型，对验证思想有借鉴，但不涉及视频、3D 或隐式物理表征。

## TL;DR
ARC-AGI-3消融显示可执行模型需配合简化和验证才稳定有益，做agent harness可选读，主线可跳过。
