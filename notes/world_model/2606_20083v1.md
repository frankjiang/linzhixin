# Holo-World: Unified Camera, Object and Weather Control for Video World Model

## Insight
Observation：现有可控视频世界模型通常把相机、对象、天气/环境状态分开建模；天气编辑还常依赖完整源视频，已经给定未来布局和运动。

推论：若从单张首帧出发同时控制相机、对象和天气，必须把“世界保持”和“状态转移”分离到不同条件/残差空间，否则天气增强会破坏结构，结构保持又会压制天气变化。

## Motivation
论文解决 first-frame source-to-state 视频世界模型：输入单张图，给定相机轨迹、对象控制和可选天气指令，生成保持原世界或转成目标天气状态的视频。

这是视频世界模型的关键工程问题：可控世界不只是相机/对象几何，还包括环境状态。相比纯天气编辑，这个设定更难，因为没有完整源视频提供未来时序。

## Method
三部分：
- HoloStateData：把真实视频、Unreal paired weather 视频和 V2V weather-transfer 视频整理成统一控制样本，包含相机 pose、几何 anchor、object boxes、scene text、weather prompt。
- Holo-World：基于 Wan2.1-T2V-14B，冻结 VAE/text encoder/backbone，只训练 Unified Scene Adapter。
- UniSA：World Adapter 和 State Adapter 分别学习世界保持与天气转移残差；使用 rendered RGB/depth/normal、G-buffer、object controls 稳定结构。
- SW-CFG：Scene-Weather Decomposed CFG，把 scene residual 和 weather residual 分开 guidance。

创新主要是统一控制接口与 adapter/guidance 的残差解耦。

## Experiment
Real subset 评估世界保持；Weather subset 评估天气迁移。

结果：
- Real subset：Holo-World VBench-I2V overall 89.05，优于 Uni3C 88.25、GEN3C 87.24、VerseCrafter 88.41、NeoVerse 88.00；camera/object control errors 也最低或接近最低，RotErr 0.719、TransErr 1.123、ObjMC 7.731。
- Weather subset：Weather Alignment 86.00、VLM Evaluation 68.51；人类偏好相对 Cosmos-Transfer2.5 为 83%，相对 Wan2.7-Edit 为 62%。
- 消融：无几何时 BG PSNR 13.20、Weather Align 51；加入 G-buffer/UniSA/SW-CFG 后到 BG PSNR 18.12、SSIM 0.624、LPIPS 0.245、Weather Align 86、VLM 68.51。SW-CFG weather scale 4 可进一步提升 Weather Align 到 96、VLM 78.42。

## Value
价值在于把“环境状态”纳入视频世界模型控制接口，并展示 scene/weather 残差解耦的重要性。对自动驾驶、机器人仿真中的天气/光照/环境状态建模有启发。

局限：天气状态仍是有限 taxonomy；主要是生成控制系统，不涉及深层物理状态演化。基于大视频 backbone 和构造数据，复现成本较高。

创新度：3⭐ — 数据和系统整合扎实，adapter/CFG 解耦有效，但核心技术多为已有控制/编辑范式组合。

相关度：3 (Core) — 直接是可控视频世界模型。

## TL;DR
统一相机、对象、天气控制的视频世界模型，工程完整、指标强，适合选读其控制接口和解耦设计。
