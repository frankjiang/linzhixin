# GAUGE: A Measurement-Grounded Benchmark for Physical Fidelity in Simulation Engines and Video World Models

## Insight
作者观察到视觉上逼真、甚至能被正确方程形式高拟合的生成轨迹，仍可能具有完全错误的物理参数。由此推论，物理世界模型评测必须把“law form”“parameter accuracy”“temporal stability”分开，并以真实重复实验而非主观/VLM plausibility 或模拟器真值为基准。实验给出典型证据：Wan-2.2/Genie 3 的摆动可达 R²=0.99，但周期约 1.9 s，真实仅 1.06 s；Cosmos3-Super 的落球 QFI 可降至 12.50，却推得重力加速度仅 0.088 m/s²。说明模型能复现抛物线/正弦外形，不代表学会物理尺度。

## Motivation
physics engine 和 generative video world model 正被用作机器人训练、评估和数据生成环境，但现有 benchmark 多关注像素相似、人工/VLM 合理性，或只覆盖单一物理类别，难定位究竟是摩擦、冲量、振荡还是形变参数错误。GAUGE 试图用同一套测量扎实的真实实验，同时诊断数值模拟器和视频生成模型。这是决定世界模型能否作为可靠物理模拟器的关键问题。

## Method
构建 22 个受控任务族：8 个刚体、1 个绳索、6 个纺织物、7 个体积软体（正文表中合计为 22），覆盖碰撞、摩擦、动量/能量传递、自接触、拉伸/弯曲/剪切及大形变。每条件用 16 相机、180 Hz 亚毫米 motion capture 做 20 次真实试验，并测质量、尺寸、摩擦/恢复系数、纺织物拉伸/剪切/弯曲刚度、Young’s modulus 与 Poisson ratio；总计约 1,560 trials。

数值引擎 track 将 Isaac Sim、Genesis、Newton 用测得参数重建 14 个任务，不做 task-specific tuning。刚体以 3D position、布料以 marker angle deficit（文中称 Gaussian curvature）、软体以 marker mesh face area 作为 generalized trajectory，计算 RMSE/DTW，并为 cradle/pendulum 加 LSD、MTE、period、energy loss。

视频 track 给六个 I2V/interactive 模型相同首帧和含物性/预期运动的 prompt，用 SAM3 分割并以 mask centroid 恢复 2D 轨迹，再按已知物体尺寸换成世界坐标。在 slope/free-fall/pendulum 等任务上分别计算 Newton-law dynamic error、方程拟合 R²、加入高阶项后的 QFI、加速度、MTE 和周期；还成对测试统一 negative prompt。核心创新在真实跨材料测量与“方程结构—参数—时间”诊断协议，而非新模型。

## Experiment
physics engine 结果表明没有统一赢家。Isaac Sim 在 slope/nonsmooth contact 和 turntable 较好，Genesis 在 slope slider、快速 cloth 与多数 soft-body 较好，Newton 只在部分形变任务领先。最难的 bounce 即使最佳 RMSE/DTW 仍为真实 trial 内波动的 15.63/5.58 倍；Newton’s cradle 的 MTE 仅 0.20–0.26，Genesis 无有效 rollout；cloth fling 的 Isaac Sim RMSE 达 128.26 倍 baseline；软体最佳误差通常仍高一个数量级。

视频 track 实际量化 5 个刚体任务（slope slider、turntable、bouncing ball、cradle、pendulum），比较 Cosmos3-Nano/Super-I2V、Wan-2.2/2.7、Seedance 2.0、Genie 3。不同材料的最佳模型不一致；落球最接近的生成加速度也仅 1.84 m/s²；10 个 model/prompt 配置中 6 个不能生成可测的 cradle，最佳 MTE 0.76；最接近真实摆周期的 1.83 s 仍慢 73%。negative prompt 有时大幅改善、有时恶化，方向不稳定。

## Value
GAUGE 对视频世界模型的价值很高：它要求生成模型不仅“看起来像物理”，还必须在可测尺度上给出正确参数，并明确把 tracking/reconstruction uncertainty 纳入未来 3D 评测。该 benchmark 也揭示把任何单一 physics engine 当作世界模型 ground truth 的风险。对我们可直接借鉴的是：建立小规模、可重复、强标定的 physical probes，比再加一个 VLM judge 更能定位模型失败。

## Strengths
- 真实 motion capture、重复试验和独立物性仪器提供了少见的测量级 ground truth 与不确定性。
- 同一套数据覆盖刚体、布料与体积软体，并同时评测数值引擎和视频世界模型。
- 区分方程形式与参数精度，案例清楚揭示高 R²/低 QFI 的“物理假象”。
- 附录详细给出材质映射、各引擎 solver、prompt、SAM3 tracking 与指标计算，失败模式可追溯。
- 不强行压成单一总分，保留任务特定 observables，诊断性较强。

## Weaknesses
- 视频模型只评 5 个简单刚体任务，尚未覆盖该 benchmark 最有价值的布料、绳索和软体部分，也没有真正的 3D 状态评测。
- 每个模型/条件似乎仅报告单条生成，未给生成随机种子、均值方差或 bootstrap 置信区间；随机视频模型的排名可能不稳。
- prompt 明确告知质量、摩擦、恢复系数和“应发生的运动”，测到的既是动力学能力也包含语言遵循；未做去除参数/运动描述的消融。
- 2D centroid、固定深度和已知尺寸的换算会把相机投影、物体形变、SAM3 跳动混入物理误差；不同模型分辨率/FPS 和 API 预处理亦可能构成混杂。
- 部分指标不充分：turntable DE 对几乎静止或错误同步轨迹也可为 0；QFI 对短轨迹/尺度敏感；没有统一 coverage/invalid-rate 处理。
- engine track 所谓 out-of-the-box 仍需将实测纺织参数映射成 solver-specific 有效参数，部分 fallback/engineering prior 会影响公平性。
- Energy Loss 公式以 0 为理想，但附录文字一处误称“越接近 1 越守恒”，存在定义表述错误。

## Future Work
作者明确计划扩充材料及摩擦、刚度、密度、恢复和阻尼范围；加入流体、fluid–rigid 与 fluid–soft coupling；把视频 track 扩展到 textile/volumetric deformation；通过 3D point cloud、mesh、surface tracking 测量 strain、area/volume、curvature、bending energy、geodesic distortion、自接触、模态与能量耗散，并显式建模对应和重建不确定性。

## Rating
创新度评分：4/5 - 真实跨物理域标定、双 simulator/world-model track 及 law-form/parameter 分解形成显著的新 benchmark；但视频评测仍窄且统计协议不成熟。
相关度评分：3/3 (Core) - 直接评估生成式视频世界模型的物理保真度，是视频世界模型核心评价问题。

## TL;DR
用真实标定实验拆分视频模型的方程外形与物理参数错误，诊断价值高，值得精读。
