# Pre-VLA: Preemptive Runtime Verification for Reliable Vision-Language-Action and World-Model Rollouts

## Insight
观察到 VLA 模型和世界模型在实际部署中会生成低质量动作，导致物理执行失败或世界模型 rollout 中的误差累积。关键 insight：在执行前进行预验证比事后修复更高效。

## Motivation
VLA/WM 模型的动作生成存在不确定性，低质量动作会导致执行失败和渲染浪费。现有方法缺乏执行前的质量评估机制。Pre-VLA 在物理执行或世界模型想象之前进行动作有效性评估，属于安全层面的辅助工具。

## Method
多模态骨干网络 + modality-aware pooling + 轻量双分支头（safety confidence + critic advantage）。训练目标组合 Focal 分类、advantage 回归和软阈值校准。部署时使用双模式抢先重采样调度器，在有限计算预算下过滤低质量动作并触发自适应重采样。

## Experiment
LIBERO 基准测试：平均闭环成功率从 30.79% 提升至 37.62%（基于 RynnVLA-002）。前向验证时间 183.9ms/chunk。减少任务执行步数，缓解世界模型 rollout 中的误差累积。提升幅度有限。

## Value
实用的安全验证组件，可作为 VLA/WM 系统的即插即用模块。但本身不是世界模型研究，而是世界模型的下游应用。对视频/3D/隐式世界模型研究启发有限。

## Strengths
亮点是多模态骨干网络 + modality-aware pooling + 轻量双分支头（safety confidence + critic advantage）。

## Weaknesses
不足是对视频/3D/隐式世界模型研究启发有限。
