# Phys-JEPA: Physics-Informed Latent World Models for Multivariate Time-Series Forecasting

## Insight
核心 insight 与 JEPA 相关：物理约束不应只作用于 decoded forecast，而应塑造 latent predictive state。作者把 latent 拆成 physical component 和 residual component，并对 state alignment 与 transition alignment 同时约束。

## Motivation
多变量时间序列预测常有物理/运行约束，但输出层 physics loss 不能保证隐状态动力学有物理结构。JEPA-style representation prediction 适合 latent world model，但目标空间通常由神经 encoder 自定义，缺少可解释物理变量。

## Method
Context encoder 得到当前 latent，target encoder 得到未来 latent，predictor 预测未来 latent，decoder 生成未来序列。Latent 分为 physical/residual；physics projector 从 physical latent 读出选定物理变量。损失包括 JEPA latent alignment、static physical state consistency、dynamic transition consistency、residual regularization，避免 collapse。

## Experiment
Traffic、Electricity、Jena Climate 等 forecasting benchmark。报告 Traffic 全 horizon aggregate MSE 优于 supervised baseline，H=192 从 0.800784 降到 0.773873；Electricity 中 static 在 H=24/48 强，full Phys-JEPA 在 H=192 aggregate/target MSE 最好。消融显示 output-level physics 较弱，latent static/dynamic 作用依赖 descriptor 质量。作者承认 single-seed 和强基线不足。

## Value
与隐式/JEPA world model 概念相关，但任务是时间序列，不是视频/3D/机器人。可借鉴“latent physical decomposition”，优先级中等偏低。
