# DuoWM: Integrating Dual 6-DoF Visual Flows into Action-Conditioned Drone World Model

## Insight
观察：仅用相机位姿条件的视频扩散模型难把逐帧指令落实为正确视点，而首帧 warp 加局部坐标轴能提供可见的几何对应。推论：相机动作需与初始画面的表面运动联合编码。作者用删去 Action/Object flow 和几何预训练的消融验证：两条流分别改善轨迹跟随与视频质量，联合更好。

## Motivation
无人机视频世界模型要求按指定 6-DoF 相机轨迹生成未来视角。现有潜动作、点轨迹或相机条件常出现视点漂移，局部刚体转动表示不足。问题直接关系可控视频模拟，但论文聚焦视点变化，尚未覆盖无人机对环境的物理作用。

## Method
从首帧、文本及目标相机位姿出发，在每个目标视角投影未来相机中心与红绿蓝姿态轴，构成逐帧 Action flow；用首帧深度按目标相机前向投影、深度缓存补出覆盖图，再由冻结 MoSE3 在 warp 序列上估计局部 SE(3) 轴和短轨迹，构成 Object flow。两流经冻结 VAE 编码，连同覆盖掩码拼接到 Wan2.2-5B 的视频潜变量，训练新输入列和 LoRA，原相机 Plücker 编码继续保留。先重建带局部轴标记的视频，再训练自然 RGB；推理无需未来帧。创新为双视觉条件和配套预训练的工程组合，局部几何由现有估计器提供。

## Experiment
Sekai-game-drone（474 测试视频）与 Sekai-real-drone（402）生成 121 帧、1280×704 视频；对照 Wan2.2 原模型/相机模型、Captain Safari 等。指标 FVD、LPIPS、MEt3R、重建相机轨迹 AUC@15/30 与 CosSim。游戏域 FVD 65.99、AUC@30 0.5719，Captain Safari 为 69.83/0.5003；真实域 FVD 191.77 对 231.67，LPIPS 0.1250 对 0.1594。去几何预训练时游戏域 FVD 回升至 70.33；逐步添加 Action/Object flow 将 AUC@30 从 0.5116 提至 0.5324/0.5537。还消融了 warp、局部轴/轨迹、动作标记数量和预训练标记类型；可视化显示视点和场景布局更稳。

## Value
对相机控制视频世界模型的 6-DoF 条件设计有直接参考价值，值得精读双流构造与消融。需要进一步研究跨长时段生成、动态物体及真正闭环飞行控制。

## Strengths
同时评估合成与真实无人机视频；将相机位姿、首帧外观和局部几何显式对齐到每帧；消融覆盖各条件分量和预训练阶段。

## Weaknesses
Object flow 是首帧 warp 及 MoSE3 推断，无法知道未来独立物体运动；相机轨迹只在 SfM 成功的样本上计算，可能有选择偏差；补充材料承认 MEt3R 在此是与真值逐帧的几何一致，而非生成视频跨帧自洽性的直接指标。尚无下游策略收益。

## Future Work
作者计划做更长时程自回归生成，并与飞行策略闭环交互。

## Rating
创新度评分：3/5 - 将双 6-DoF 可视条件及带轴目标预训练组合到既有视频骨干，效果明确但基础组件并非原创。
相关度评分：3/3 (Core) - 直接研究可控视频/3D 世界模型中的相机动作与几何一致性。

## TL;DR
双视觉流把逐帧相机位姿和首帧表面几何注入无人机视频模型，改善视点跟随；值得精读其条件设计。
