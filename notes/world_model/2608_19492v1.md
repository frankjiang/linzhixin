# Beyond Multimodal Alignment: Certifying Physical Language through Response Substitution and Ordered Execution

## Insight
同一对象的多模态 embedding 靠近并不证明它们有相同可执行意义；只有把独立训练的 modality compiler 互换送入冻结 response chart，并在未见对象/动作顺序上产生同一物理响应，才能区分 attribute access、response substitution、fusion closure 与 ordered execution。非可识别性结果进一步说明压缩和融合本身无法确定未见组合律。

## Motivation
“physical language”常用 probe、对齐或重构自证，但这些指标可能来自共同训练目标而非物理语义。论文要建立操作性 certificate，问题对多模态隐式世界状态的语义和组合性重要。

## Method
DBOSC 用互斥 evidence panels 独立训练 audio/acceleration compilers，再跨源替换进冻结 rank-3 response decoder；ordered gate 先用 oracle coordinate 检查 executor 是否有能力执行未见 AB/BA，再评估单模态/融合 belief。shared per-step executor 与 whole-program predictor 对照定位组合性的来源。

## Experiment
Cluster Haptic 的 19 个 held-out surface 上，同物跨模态 response 距离比错物配对近 4.5×，19/19 通过；解封真实响应后均优于 population chart。受控弹塑性系统在预注册预算因 oracle gate 失败而拒绝认证，25×预算后 oracle NMSE 0.18、14/16 checks 通过；whole-program executor 比 entity-blind step predictor 差 38×。

## Value
提供一种比 latent probe/CKA 更严格的物理语义审计思路，尤其适合检验多模态 world model 是否真能替换传感器、组合动作；目前更是评测框架而非模型方法。

## Strengths
能力层级和 prerequisite gate 设计严谨；失败结果不被包装成成功；有非识别理论、预注册门槛和完整 check 表。

## Weaknesses
正面证据仅一个 rig、音频/加速度与19表面；ordered system 为人为可控低维装置；训练预算变化巨大，certificate 对 executor 能力敏感；尚未验证视频、机器人或大模型 latent。

## Future Work
扩展第二种接触几何、更多模态和真实机器人，并研究 belief-valued physical words 与复杂程序组合。

## Rating
创新度评分：3/5 - 操作性证书和能力分层有独到之处，但实验高度受控、尚未证明通用性。
相关度评分：2/3 (Related) - 直接审计多模态隐式世界表征的物理语义与组合执行。

## TL;DR
