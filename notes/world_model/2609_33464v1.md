# VIDEAS: Distilling Explicit Action Semantics from Demonstration Videos for World Models via Prior-Guided Simulation

## Insight
观察：只从成功示范抽取动作规则，模型很难判断未满足前提的反事实动作。推论：删除依赖动作构造负轨迹，并用已知成功／失败结果校验教师 VLM 生成的前提与效果，可改进文本状态模拟。Qwen3.5-9B 的 BTSIMBENCH 反事实准确率在去负轨迹后从 96% 降至 48%；这证明负例有用，但不证明模型掌握连续物理因果。

## Motivation
视频或潜空间世界模型的输出不易直接解释“动作何时可执行、会改变什么”。作者转向高层符号前提和效果，面向机器人行为树仿真；这与视频／3D／JEPA 世界模型仅间接关联。

## Method
从 AgiBot-World 中去重筛出 1078 条操作示范、215 项任务，切成文字动作序列；教师 Gemini 3.1 Pro 借助视频首末帧把初始场景写成 JSON，逐动作提出前提、判可行、更新文本状态，再用已知示范成功的先验反复校验。删除“开门”等前置动作生成指定步骤失败的负轨迹。最终约 3.4 万条文本监督样本，用 LoRA 微调 8B/9B LLM 的前提推断、前提检查、状态增量预测。成品实际是文本语义模拟器，不能预测连续视觉或几何状态。

## Experiment
BTSIMBENCH 75 个行为树、LogicEnvEval 100 个策略的文本模拟准确率：VIDEAS-WM-9B 分别 **94.67%/95.0%**，Gemini 3.1 Pro 为 **84%/88%**。去先验校验或去负轨迹在 BTSIMBENCH 明显退化；人工抽查 135 条蒸馏动作，前提／效果判定约 **97.78%/98.52%**。WorldPrediction-WM 只用可访问的 637 条样本，9B VLM 总体 **58.33%**，高于部分开源 VLM；没有闭环机器人任务或连续物理误差指标。

## Value
可借鉴“成功轨迹校验 + 依赖删除负例”来构造动作可行性评测，但对目标研究的模型结构借鉴有限。

## Strengths
数据构建有成功／失败先验检验、负例和少量人工审核；跨三个基座微调并对不同训练配方做消融。

## Weaknesses
文本状态抽象丢失运动学、碰撞、流体等连续约束；物理正确性仍取决于教师 VLM 与自生成 JSON，成功先验可能只校验最终任务是否通过。评测主要是小规模符号模拟和逆动作选择，无法支持“真实物理世界模型”或机器人闭环可靠性结论。

## Future Work
作者未提出具体方案；附录明确需突破文本离散化与教师幻觉限制，才能扩展到连续物理模拟。

## Rating
创新度评分：2/5 - 主要贡献是教师模型驱动的数据蒸馏与负例构造，底层预测器是常规文本微调。
相关度评分：1/3 (Tangential) - 由视频提取符号动作规则，未研究视频、三维或 JEPA/Dreamer 式世界状态预测。

## TL;DR
从操作视频蒸馏动作前提和文本状态变化，负轨迹改善反事实判断；偏符号模拟，与本方向仅可选读。
