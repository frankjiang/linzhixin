# Riemann-1.0: An Embodied World Action Model for Physical AI

## Insight

论文观察到：机器人交互天然遵循“先依据历史产生动作，再观察动作后果”，而现有 WAM 的联合去噪、先视频后动作或双模型解耦都与在线闭环存在不同程度的时序错配。由此把轨迹分解为 $p(a_t\mid z_{<t},s_{<t},a_{<t},c)\,p(z_t\mid z_{<t},s_{<t},a_{\le t},c)$，并让同一动作块既是策略输出又是视觉动力学条件；真实执行时以环境观测替换预测 latent，模拟时则递归生成 latent。该设计在机制上形成了统一的策略/模拟器接口，但论文只以整体性能和定性视频佐证，没有用等规模消融证明优势确由因果次序而非数据规模或训练配方带来。

## Motivation

目标是同时解决两类错位：一是人类第一视角视频、UMI/外骨骼和多机器人轨迹在视角、动作空间与监督质量上的异构；二是 WAM 训练形式与“观测-动作-新观测”的在线执行过程不一致。同行分别采用动作/视频联合生成、先生成视频再读出动作、或两个 DiT 解耦建模，往往只能偏重策略效率或视觉模拟。问题对可扩展机器人世界模型很关键，但本文也把“统一建模”与超大私有数据基础设施绑定，二者贡献难以拆开。

## Method

- **数据**：构建 23 万小时以上语料，包括 20 万小时以上 egocentric human video、1.2 万小时以上 UMI/可穿戴示范和 2 万小时以上异构机器人轨迹。VLM 将长视频分成任务/动作片段并生成语义标签；MANO 与 VGGT-Ω 重建 3D 手和相机轨迹；机器人数据做时序对齐、动作归一化、静止/异常过滤，再按场景、技能、物体、embodiment 做语义均衡采样。
- **表示与架构**：Wan VAE 编码拼接后的多视角画布，T5 编码任务、embodiment 与视角描述；状态和动作按 embodiment 规范化、填充，并使用类别专属投影与动作 head，共享 Action/Video DiT 主干。序列交错放置 context latent、state、action 与 future latent；结构化 mask 允许历史 clean token 和同一 noisy block 内交互，禁止窥视未来。
- **目标**：视觉 latent 与连续动作分别做 flow matching，联合损失为 $(1-\lambda)L_z+\lambda L_a$，并对无效帧、动作步和填充通道做 loss/noise mask。机器人 state 只作为观测条件，不由模型预测。
- **渐进训练**：Stage I 用相邻帧 VAE 式 Latent Action Model 生成 32 维伪动作，以人类视频训练视觉动力学（$\lambda=0.1$）；Stage II 混合 3D 手、UMI 与机器人真实轨迹做跨 embodiment 对齐（0.5）；Stage III 仅用高质量机器人数据强化可执行动作（0.9）；下游联合微调四个真实任务时升至 0.95。
- **闭环**：每轮从 KV cache 生成动作块并执行，环境返回新多视角观测/state 后写回 cache；窗口满时以最近观测重置。作为模拟器时，可外部给定候选动作并递归生成视觉后果。

核心架构是合理的动作优先因果分解与共享主干，训练/数据系统工程规模很大；但 flow matching、LAM 伪动作、专属 head 和三阶段课程均属已有组件的系统化组合，创新更多在统一接口与规模化落地。

## Experiment

- **真实机器人**：Tianji Marvin 双臂平台，四项长程任务（四色方块堆叠、衣物折叠、桌面整理、厨房整理），每任务 15 条遥操作示范；比较 DreamZero、τ0-WM、LingBot-VLA、π0.5、LingBot-VA、G0.5。指标为最终成功率 SR 与里程碑进度 PSR。Riemann 平均 **85.0% SR / 94.43% PSR**，G0.5 为 70.0/80.18；最大差距来自厨房整理（90% SR 对 35%）。论文未明确主实验每任务试验次数或置信区间。
- **泛化**：四个未参与后训练的真实任务各 10 次。组合泛化平均 65%，OOD 物体/场景平均 85%，整体 75%，高于 π0.5 的 47.5% 和 LingBot-VA 的 22.5%；样本量很小。
- **仿真**：RoboCasa-365 Target-50 为 **62.6%**（ABot-M0.5 54.2%，主要提升在组合任务）；RoboTwin2.0 50 个双臂任务平均 **94.3%**（ABot-M0.5 94.1%，优势仅 0.2 点）；LIBERO 四套件平均 **99.0%**（G0.5/Being-H0.5 98.9%，接近饱和）。指标均为 task success rate。
- **世界模拟**：仅展示跨多种机器人和相机布局的 action-conditioned rollout，声称场景结构与动作-物体运动一致；没有 FVD、动作敏感度、反事实一致性或用 rollout 做规划的定量结果。
- **消融边界**：全文没有因果 mask/动作先行分解、三阶段训练、不同数据源、数据量、$L_z$ 或 cache 策略的消融，也未报告参数量、训练算力、优化器等关键复现信息。因此结果能证明完整系统很强，不能分辨机制创新与 23 万小时数据/工程投入各自贡献。正文还出现“每任务三小时数据”和“每任务 15 条示范”的口径不一致。

## Value

价值主要在把大规模弱监督视频、跨 embodiment 动作监督、可执行策略和视觉模拟器整理成同一因果 WAM 接口，并给出强机器人结果；对研究者最有启发的是动作块作为“策略输出/动力学输入”的双重语义，以及逐步提高动作损失权重的监督迁移路径。证据尚不足以支持其更强的宣传命题——尚未证明统一视觉预测对策略成功是必要的，也未证明生成 rollout 足以用于可靠规划。后续关键是等数据等参数对照、定量反事实模拟评价和更透明的训练/数据说明。

## Strengths

- 动作先行的概率分解与真实闭环顺序一致，策略和模拟器接口清楚统一。
- 数据管线覆盖人类视频、机器人兼容示范和真实机器人轨迹，并针对异构动作空间设计有效 mask 与专属接口。
- 同时覆盖真实长程操作、组合/OOD 泛化及三类常用仿真基准，完整系统性能强。
- 真实任务不只报告终局 SR，也报告阶段性 PSR，能观察长程失败前的进展。

## Weaknesses

- 无关键机制和数据规模消融，无法把提升归因于因果 WAM、训练课程或 23 万小时私有数据。
- “世界模拟器”仅有定性样例，没有视频质量、动作可控性、长程漂移或下游规划收益的量化证据。
- 模型参数、算力、训练步数、优化细节和数据组成均披露不足，难以复现与公平比较。
- 真实实验规模小且缺少方差/置信区间，主任务试验次数未说明；训练数据时长与示范条数表述不一致。
- RoboTwin 与 LIBERO 已接近饱和，0.1-0.2 点平均优势不足以单独支撑显著 SOTA；基线是否完全等数据等预算也不清楚。

## Future Work

作者没有单列未来工作，只提出模型可用于 rollout 检查、候选动作比较和未来状态想象。更直接的后续应是：把视觉 rollout 真正接入规划并测量收益；做等规模架构/课程/数据源消融；评估反事实动作敏感性与分钟级误差累积；披露模型、算力和数据细节，并在更多平台上验证跨 embodiment 迁移。

## Rating

创新度评分：3/5 - 动作优先的全因果 WAM 与渐进异构监督形成有价值的统一系统，但大多数组件已有，且缺少消融将架构贡献与超大规模数据分离。

相关度评分：3/3 (Core) - 直接研究视频式机器人世界-动作模型，同时覆盖 action-conditioned rollout、闭环策略与跨 embodiment 动力学。
