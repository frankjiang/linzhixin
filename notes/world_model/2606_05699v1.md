# DexFuture: Hierarchical Future-State Visuomotor Targeting for Bimanual Dexterous Tool Use

## Insight
核心 observation：灵巧操作中，target-conditioned policy 需要未来的 privileged demonstration targets 才能工作，但部署时无法获取这些 targets。Action-conditioned world model 可以通过 CEM planning 生成未来状态，但在高自由度灵巧手场景下计算成本极高（仅 0.24Hz），无法满足 60Hz 的控制频率要求。

推论：与其做 action-conditioned planning（需要搜索动作空间），不如直接从视觉运动历史预测未来 target states（action-free prediction），将"想象未来去哪"与"如何执行动作"解耦为两个时间尺度的层次化系统。

证明：DexFuture 达到 privileged oracle 约 90% 的性能，同时以 60Hz 运行，比 DexWM 的 CEM planning 快约 250 倍。

## Motivation
- **解决什么问题**：双手灵巧工具使用（cutting/wiping/shearing 等）中，target-conditioned policy 依赖 privileged future targets，部署时不可用。
- **同行做法**：(1) 直接用 no-target policy 只看当前状态 -> 几乎无法完成任务（SR 约 4-20%）；(2) DexWM 学 action-conditioned world model + CEM planning -> 能 work 但太慢（0.24Hz）。
- **是否关键**：对灵巧操作是实际部署中的关键瓶颈，但问题域较窄。

## Method
整体流程（两层层次化架构）：

**High-level: Future-State Visuomotor Target Predictor**
1. **Structured Visuomotor Tokenization**：将每帧的 RGB + 本体感觉信息编码为结构化 token，而非全图 patch。每个 hand link 投影到图像上，cross-attend 局部视觉 patch 得到 link-level embedding；工具和物体通过 anchor-aligned 采样构建 embedding。
2. **Horizon-Conditioned Target Transformer**：以历史 structured embedding 为 memory，通过 AdaLN-Zero Transformer（类似 CDiT）预测未来多个 horizon 的 target embedding。每个 horizon 有独立的 Fourier embedding。直接回归（非扩散去噪），输出未来手-工具-物体的几何状态。

**Low-level: Target-Conditioned Structured Dexterous Policy**
- 基于 per-link transformer 的策略网络，输入当前状态 + 预测的 target，输出双手动作分布。
- 用 PPO 训练（tracking reward）。

**Inference: Receding-Horizon Execution**
- 高层以较低频率运行（每 16 个 policy step 预测一次），低层每步执行。
- 中间步的 target 通过线性插值获得。

创新程度中等。核心思路（预测 future state 而非 planning over actions）虽然直观但在灵巧操作场景下是新的。Structured visuomotor tokenization 设计较精巧。

## Experiment
- **实验平台**：OakInk2 双手灵巧工具使用任务（切/倒/擦/剪）。
- **对比方法**：ManipTrans (GT target)、PhysGraph (GT target)、PhysGraph (No target)。
- **指标**：Success Rate (SR)、Tool/Object Translation Error、Hand Joint Error、Fingertip Error。
- **结果**：
  - DexFuture (Pred target) 平均 SR 约 59.69%，vs PhysGraph (GT target) 66.52%，达到约 90% 的 oracle 性能。
  - 在 fruit-knife cutting 任务上甚至超过 GT target baseline（SR 89.79% vs 87.87%）。
  - No-target 变体 SR 极低（4-20%），证明 future target 的必要性。
  - 与 DexWM CEM planning 对比：DexFuture 在 60Hz 运行，DexWM 仅 0.24Hz。
- **消融**：
  - Future target prediction 准确度评估（3D/UV error, PCK）。
  - Receding horizon 长度消融（h16 最佳）。
- **定性可视化**：DexFuture 的 rollout 与 oracle policy 视觉上高度一致。

## Value
- **整体价值**：在灵巧操作这一细分领域提供了实用的解决方案，将 world model planning 的思路简化为直接的 future state prediction，大幅提升了推理速度。
- **对我们的启发**：(1) "预测 future state"与"在 world model 中搜索动作"的 trade-off 值得思考；(2) structured tokenization 是处理复杂多体系统的有效方式；(3) 层次化时间尺度解耦是机器人控制中的通用设计模式。
- **待解决问题**：contact-rich 场景（narrow contact region）预测仍困难；仅在仿真中验证，未部署到真实机器人；predictor 需要更好的不确定性估计。
