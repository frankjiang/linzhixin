# HGWM: Hierarchical Graph-Guided World Model for Zero-Shot Object Navigation via Graph Matching

## Insight
观察：零样本目标导航的类别名称并未给出房间实例和搜索路径；仅靠当前视图分数易忽略跨视角证据。作者推论：将目标类别展开为“可能房间—锚点物体—关系”先验，并与持续积累的观测图匹配，可更好选择搜索方向。HM3D/MP3D 成功率及组件消融支持完整系统的收益，但既未证明先验为真，也未严格隔离图匹配本身的闭环因果效果。

## Motivation
VLFM/WMNav 等用 VLM 语义分数与地图找物体，UniGoal 等已有图匹配；单目标类别缺少可用于关系搜索的丰富图结构。HGWM 解决的是室内导航中“用先验组织探索”的问题。其所谓世界模型是符号先验加空间语义记忆，不学习环境状态转移或未来视频，故与视频/3D/JEPA 世界模型方向仅间接相关。

## Method
- 用 Qwen2.5-7B 为目标类别生成可能房间、相邻房间、锚点物体和关系图；RGB-D、位姿及 Gemini-1.5-Pro 对六个方向的描述形成持久图记忆，预计物体与真实观测分开保存。
- 粗阶段由 VLM 对六个方向打 0–10 分；细阶段以房间、物体、空间关系、语义及深度五类符号特征计算兼容分，并可用 LLM 修订关系。按细分阈值切换“前沿探索／集中搜索／目标核验”系数，再与 LLM 推荐方向合成分数，更新保守的好奇度地图，由局部导航器执行。
- 图匹配是名称/集合/关系的启发式比较，位置来自视线与深度的粗投影；没有学习图嵌入或可滚动的动力学模型。创新主要是类别到关系图、方向兼容分与阶段融合的系统集成。

## Experiment
- Habitat 模拟的 HM3D v0.1/v0.2、MP3D，以成功率 SR、路径加权成功率 SPL 评估；每回合最多 40 个决策步。HM3D v0.1：62.6/31.5%，WMNav 为 58.1/31.2%；MP3D：46.8/17.9%，WMNav 为 45.4/17.2%。SPL 增益分别仅 0.3 和 0.7 点。
- HM3D v0.2 完整系统 74.4/31.9%；去目标先验降至 72.1/30.8%，去关系修订为 72.1/30.4%，去 LLM 仲裁为 72.7/31.1%。只用体素记忆与直接 VLM 分数为 70.9/30.1%，但此对照同时改变记忆形式和决策规则。更换 VLM 后 HM3D v0.1 SR 从 62.6% 降至 59.2%。

## Value
可借鉴将“尚未观测到的房间/物体假说”与观测记忆严格分离，以及方向特定的关系匹配；对导航场景图或 3D 语义记忆有启发。对核心预测式世界模型研究参考有限，可跳过。

## Strengths
明确区分假说和观测，详列融合系数、失败默认值与组件干预；同时报告 SR 与 SPL，承认后者收益小；附录公开评分细节与案例日志。

## Weaknesses
方法依赖多次外部 VLM/LLM 调用，单次 VLM 约 2.3 秒且未报告完整端到端时延；先验可能压制不典型却正确的布局，错误观测会积累在地图。主对比取自不同论文和设置，缺配对置信区间与等推理成本比较；消融的系数变化、图记忆变化与匹配效果耦合。无动态场景、传感噪声和真实机器人验证。

## Future Work
作者提出匹配固定状态回放及等尺度对照、图/体素记忆在同一决策规则下的比较、深度与定位扰动、动态场景、物理机器人、多目标搜索和时间更新图记忆。

## Rating
创新度评分：2/5 - 已有场景图、LLM 先验和 VLM 导航的启发式组合，单组件增益有限。
相关度评分：1/3 (Tangential) - 有空间语义记忆，但不学习视频、3D 几何或隐式潜变量动力学。

## TL;DR
以房间关系先验和观测图匹配引导零样本找物，提升导航成功率但不建模动力学；世界模型研究可跳过。
