# ABot-M0.5: Unified Mobility-and-Manipulation World Action Model

## Insight
核心 insight 是移动操作的 WAM 不能把视频块、导航动作和手臂动作混在同一粒度里学习。作者把问题分成三种 alignment：时间粒度对齐（粗视频到细控制）、动作空间对齐（base 与 arm 等异构动作解耦）、训练-推理对齐（部署时动作基于模型 dream 的未来，而非 GT 未来）。Dream Forcing 与 RoboWorld 的 Step Forcing 思路相近，都是让动作预测在训练时见到自生成上下文。

## Motivation
VLA 通常是反应式策略，缺少显式未来建模；现有 WAM 多在静止桌面操作或粗视频 chunk 上工作，移动操作要求长程导航、视角变化、精细接触和多动作空间协同。直接把世界模型生成的未来视频接 inverse dynamics 会有训练/推理分布差，长程 rollout 容易累积误差。因此这是机器人世界动作模型中的关键问题。

## Method
ABot-M0.5 采用 Video -> Latent Action -> Action pipeline。中间 latent action 捕获局部视觉状态转移，作为视频 latent 和 embodiment-specific control 之间的桥。Dual-Level Mixture-of-Transformers 同时做 modality-level 和 action-subspace-level 解耦，让 base movement、arm manipulation 等走不同专家/路由。Dream Forcing 分两阶段：先用 world model 产生 self-dreamed future latents，再让 inverse dynamics/action head 在这些 imperfect dreamed contexts 上预测动作，而不是只在 GT future 上 teacher forcing。训练分为大规模 world model pretraining、latent action pretraining、progressive SFT，数据来自 OXE、Agibot、RoboCasa/RoboTwin/LIBERO 等。

## Experiment
RoboCasa365 pretraining/target、RoboTwin 2.0、LIBERO/LIBERO-Plus 和真实 Agilex Piper 任务评估，主要指标为 success rate 和 real-world process score。RoboCasa365 pretraining 平均 40.4%，加 condensed memory 46.6%，优于 GR00T、pi0.5、Qwen-RobotManip 等；target 100% 设置平均 54.2%。真实任务中 Peg Cylinder 70% success/96% process score，高于 pi0.5 和 Fast-WAM；多步整理水果/杯子/花等任务 success 约 60-80%。论文含多项消融支持 latent action、MoT、Dream Forcing 的贡献。

## Value
这篇是高相关 WAM 系统论文，重点不是单个新网络层，而是把移动操作中的时间粒度、动作异构和 rollout distribution shift 系统化处理。对我们有启发：世界模型若要变成可执行策略，中间 action abstraction 和 train-test aligned inverse dynamics 很重要。局限是工程系统庞大、数据和细节复杂，部分结果依赖未充分展开的 condensed memory，复现成本高。

## Strengths
