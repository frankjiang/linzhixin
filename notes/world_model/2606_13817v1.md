# FlowMo-WM: A World Model with Object Momentum and Hidden Ambient Drift

## Insight
关键 insight 是：很多机器人系统的未来状态不是当前动作立即决定的，还受对象动量和隐藏环境漂移影响；单帧或短历史 action-conditioned world model 会把这些慢变量混在 latent 中。论文用短历史状态表示 object momentum，用长历史 context 表示 ambient drift，并通过 zero-context residual transition 使漂移项可消融。

## Motivation
Dreamer/TD-MPC/LeWorldModel 等视觉 latent world model 常在动作主导的环境中评测；水面机器人、浮动物体、飞行器在水流/风场中会持续漂移，且流场不在图像中显式可见。问题是：仅凭干净 top-down 图像和动作历史，如何推断隐藏动量与外部漂移，并做长 horizon rollout/planning。

## Method
FlowMo-WM 是端到端视觉 latent 世界模型。输入 32 帧图像-动作历史，CNN 编码图像；短分支 GRU 看最近 8 步，输出 z_t 表示姿态、速度样动量、执行器滞后；长分支 GRU 看 32 步 stride-4 历史，输出 8 维 c_t 表示慢变漂移 context。转移为 `z_{t+1}=z_t+F(z_t,a_t)+R(z_t,a_t,c_t)-R(z_t,a_t,0)`，因此 c=0 时残差漂移项严格为零，便于解释性消融。预测目标是未来 60 步 normalized pose，而非重建图像。

## Experiment
二维水面机器人模拟器，工作区 [0,10]^2，两种船体：双推进欠驱动船和三推进近全向船；10 类静态流场；任务包括 reach、station keeping、square waypoint、zigzag waypoint。训练 2,400 episode、720k transitions，测试 480 episode。对比参数匹配的 LeWorldModel-style、PlaNet/RSSM-style、TD-MPC2-style latent predictor。FlowMo-WM open-loop 误差最低：pos@20=0.151 vs TD-MPC2 0.223，pos@60=0.344 vs PlaNet/RSSM 0.426。context 消融非常强：zero context 使 pos@60 到 0.840，shuffled context 到 1.100。规划上 FlowMo-WM 3940/4000 成功，整体 98.5%，高于其他 learned models 的约 91.0-93.1%。

## Value
这是很干净的隐式视觉世界模型论文：问题设定明确，factorization 简单有效，zero-context residual 让“隐藏漂移 context 是否被用到”可解释。创新度是针对隐藏外部动态的结构化 latent 设计，非大规模通用模型。局限是简化 2D clean top-down 仿真，未处理真实视频噪声、遮挡和 3D 流体扰动。对研究 JEPA/Dreamer-style latent dynamics 有直接启发。
