# World-Language-Action Model for Unified World Modeling, Language Reasoning, and Action Synthesis

## Insight
Observation: 现有 WAM（World Action Model）基于 DiT 生成未来视觉状态，擅长物理动态建模但缺乏语言推理和长程规划能力；VLA 擅长语言理解和动作生成但缺乏世界动态建模。推论：下一状态应该由两个互补表示构成——高层的 textual intention（语义级子任务描述）和低层的 physical dynamics（视觉特征变化）。前者可借助 VLM 的语言能力获得，后者通过专用 diffusion module 预测。关键设计洞察：world modeling 通过 implicit parameter conditioning（共享参数学习）而非 explicit visual conditioning 来影响 action generation，因此 World Expert 可在推理时完全禁用，实现 ~40ms 实时推理。

## Motivation
WAM 和 VLA 各有短板：WAM 基于 DiT 缺乏原生语言能力，无法进行语言引导的规划和记忆；VLA 缺乏世界动态建模，难以提供物理先验。WLA 提出用 AR Transformer（继承 VLM 语言能力）替代 DiT 作为骨干，同时保留世界建模能力，统一三者。这是一个关键问题——如何在保持效率的同时融合世界模型和语言推理。

## Method
**架构**（WLA-0, 3.4B total / 2B active）：
- **AR Transformer Backbone**（RynnBrain-2B, 2.1B）：处理视觉观测、指令、memory，输出 textual intention 和 physical dynamics
  - Textual Intention：将高层指令分解为当前时间步的子任务文本（cross-entropy loss）
  - Physical Dynamics：通过 meta-queries 聚合上下文信息，输出隐式的动态表示 h_t
- **World Expert**（SANA-600M diffusion transformer, 900M含VAE）：接收 h_t 和当前观测 o_t，预测未来 VAE 特征 o_{t+n}（flow-matching loss）
- **Action Expert**（390M flow-matching head）：接收 h_t 和 proprioceptive state q_t，生成 action chunk a_{t:t+n}

**关键设计选择**：
1. 仅预测单帧未来（而非全视频），实验证明预测全序列反而降低性能
2. World Expert 通过隐式参数共享影响 action generation，推理时可禁用
3. 支持 test-time scaling：生成多个 action chunk 候选，World Expert 预测对应未来帧，Value Model 选择最优
4. 可从无动作标注的跨 embodiment 视频中学习新技能

**训练目标**：L = L_act + alpha * L_wm + beta * L_lang

## Experiment
- **RoboTwin 2.0**（50 task bimanual manipulation）：92.94% Clean（仅 2B active params, 无 embodied pretraining），大幅超越需要 pretraining 的方法
- **LIBERO**：98.6% Avg SR，与 SOTA 持平
- **RMBench**（长程记忆依赖）：56.5% Avg（vs Fast-WAM 13.3%, Mem-0 28.5%），近乎翻倍最优 baseline
- **真实世界**：4 个长程任务上与 pretrained baselines（pi_0.5, Motus）可比，推理延迟仅 37.7ms（vs Motus 1529.8ms，40x 加速）
- **跨 Embodiment 视频学习**：仅从视频（无动作标注）即可学会新任务（如 Beat Block Hammer），cross-embodiment 视频也有效
- **消融**：去除 L_wm 导致 RoboTwin Clean 从 92.94 降至 90.98；去除 L_lang 导致 RMBench 从 56.5% 降至 17.25%

## Value
这是一篇高质量的工作。核心价值在于：(1) 提出了 WLA 这一新范式，用 AR Transformer 统一世界建模、语言推理和动作生成；(2) implicit world modeling 设计使 World Expert 可在推理时关闭，实现实时控制；(3) 能从无动作标注视频学习新技能，具备数据扩展性；(4) 在 RMBench 上的突破性结果验证了语言推理对长程任务的关键作用。主要局限：真实世界实验仅限双臂平台 4 个任务；视频学习仅用模拟环境验证。

## TL;DR
提出 WLA 新范式，用 AR Transformer 统一世界建模（隐式物理动态）、语言推理（文本意图）和动作生成，2B 参数即达 SOTA 且支持从纯视频学习新技能。值得精读。
