# DriftWorld: Fast World Modeling through Drifting

## Insight
论文的 insight 是：机器人 planning 需要大量候选动作 rollout，diffusion world model 的多步采样把大部分控制周期耗在生成上。Observation 是 diffusion rollout 占 generative predictive control 运行时主要部分；推论是若训练阶段直接学习从噪声到条件未来视频的 drifting field，就能在推理时单前向生成，速度优势会直接转化为更多 action search 和 policy ranking 能力。

## Motivation
该文解决 action-conditioned visual world model 在机器人控制中太慢的问题。同行如 IRASim、Ctrl-World、GPC diffusion model、VDM/LVDM 等以多步 diffusion 或视频生成方式预测未来，质量高但每帧/每 rollout 成本高。机器人在线 MPC/GPC 需要在短时间内评估几十到上百个动作候选，速度是关键瓶颈，因此这是视觉机器人世界模型的核心问题。

## Method
DriftWorld 把 drifting generative model 改造成 action-conditioned video predictor。输入历史观测和未来动作序列，U-Net 从高斯噪声单步输出未来帧或 chunk。训练时对模型生成分布 q 与真实条件视频分布 p 之间构造 drifting field：正样本是唯一真实未来 chunk，负样本是多个模型生成 chunk，loss 将当前生成结果推向 x + Vp,q(x)。为适配机器人视频，作者加入三项关键改造：action-accentuated drift，把 no-action 真实样本混入负样本以强化动作跟随；在复杂真实数据上用 DINOv2/v3 feature space 计算 drifting loss；按运动幅度给空间位置加权，避免模型只复制静态背景。架构上用 frame-wise FiLM action conditioning 和时空卷积，可单帧或 chunk-level 生成。

## Experiment
实验覆盖 Push-T、Robomimic、Bridge-V2、RT-1、Language Table。视觉指标包括 MSE、SSIM、PSNR、LPIPS、FID、FVD 和生成时间。Push-T 64-frame rollout 中 DriftWorld MSE 0.0007、SSIM 0.9925、LPIPS 0.0050、0.0037s/frame，优于 GPC、AVDC、Ctrl-World 和 MSE baseline；Bridge-V2/RT-1/Language Table 上大多指标优于 IRASim/LVDM/VDM，速度约 0.026-0.030s/frame。GPC-RANK 中用 DriftWorld 评估 K=50 动作候选，把两个 Push-T policy IoU 从 0.635/0.612 提升到 0.781/0.734，耗时 0.912s，优于 GPC diffusion 的 0.698/0.614 和 2.241s。离线 policy ranking 上与 ground truth 相关性 Push-T 0.9515、Robomimic Lift 0.9916、Can 0.9250。消融显示 DINO feature 显著降低 FVD，motion weighting 和 self-forcing 对 RT-1 autoregressive 生成重要。

## Value
对机器人视频世界模型很有价值。它把“世界模型质量”与“规划可用速度”放在同一目标下优化，说明单步生成如果质量足够，可以直接改善 inference-time control 和离线 policy evaluation。对想做 real-time visual imagination 的系统很有启发。

## Strengths
速度目标明确且与控制收益闭环验证；覆盖真实和模拟机器人数据；同时评估视觉质量、在线 action search 和离线 policy ranking；消融能解释 DINO feature、motion weighting、self-forcing 的作用。

## Weaknesses
训练时需要大量负样本，显存高于标准 diffusion；长程 temporal consistency 仍受 context/generation window 限制；复杂场景依赖强 DINO feature extractor；动作规划实验主要是 ranking/action selection，尚未展示更长闭环任务中的稳定性。

## Future Work
作者提出增加 context 和 generation window 以提升长程一致性，可借助 sparse history 或带时间压缩的视频 VAE。后续还可探索更少负样本的 drifting 训练、更强不确定性估计，以及与策略学习端到端结合。
