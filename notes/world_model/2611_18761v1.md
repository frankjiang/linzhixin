# Frame First, Decode Once: Object-Centric Coordinates and Single-Pass Decoding for System-1 World Models

## Insight
观察：同一推物体任务中，世界坐标把无关的初始位姿变化混入动作后果预测，逐坐标输出又会产生非刚体形变。推论：先在物体初始 SE(2) 坐标系预测，再对关键点作刚体投影，比单纯更换解码头更能稳定快速决策。作者用统一数据/骨干的 2×5 坐标系与解码器实验验证：五类解码器的决策 regret 均下降约 1.9–2.2 倍；Kabsch 投影使刚体误差按构造归零。文中还证明四个平面关键点的投影雅可比秩为 3，五个非刚体方向不会影响投影结果；该命题并不保证端到端训练一定更优。

## Motivation
动作条件世界模型要在控制时限内比较候选推力的后果。VFlash 式并行几何 token 解码虽快，但坐标系、监督损失、刚体约束对决策的影响不清楚；自回归/扩散解码有迭代延迟。问题对几何状态世界模型设计重要，但本文只覆盖平面单物体推动。

## Method
输入 128×128 图像、四步物体关键点与推杆历史、目标和候选动作；小型 Transformer 一次预测未来十步的 100 个坐标槽，并用预测轨迹的任务效用选动作。把状态、动作和输出变换到物体初始位姿坐标系；从离散 token 概率取连续坐标期望，以 Smooth-L1 训练；再用二维 Kabsch 将四个关键点投影为刚体运动。比较只在推理时投影的 Pre-L1 与穿过投影训练的 E2E-L1，以及直接 SE(2) token、CE、MDN、扩散和自回归头。方法是已有坐标归一化、软 token 与刚体投影的有效组合，主要贡献是受控比较。

## Experiment
ManiSkill3 PushT-v1：512 个训练/512 个测试任务族、8192 次测试 rollout，以动作 regret、Top-1、轨迹 MAP-ADE、刚体误差和延迟评估；LeRobot PushT 的 2384 个测试窗口只评估轨迹，不能测动作排序。匹配骨干与 checkpoint，采用分层 bootstrap、Holm 校正，并修正原扩散基线的归一化错误。物体坐标下 E2E-L1 regret 0.0203、MAP-ADE 11.35 px、每四候选动作 1.62 ms；10 步 DDIM 为 0.0460、27.84 px、10.32 ms，自回归为 0.0592、28.32 px、12.89 ms。单次解码头彼此的 regret 差异不显著；物体坐标用 128 族训练的 regret 0.0435，接近世界坐标用 512 族的 0.0423。作者预注册的“坐标系效应大于解码器差异”假设未获支持。

## Value
值得借鉴的是控制变量、以决策 regret 而非仅轨迹误差评估世界模型，以及先处理坐标对称性再考虑复杂生成器。对视频/3D 世界模型的直接迁移仍需在多物体、遮挡、三维接触与闭环控制中验证。

## Strengths
统一骨干和数据比较坐标系/解码器；报告统计区间与多重比较校正；公开承认并修复扩散基线实现错误；明确区分预注册结果与后验探索。

## Weaknesses
仅二维仿真单刚体，缺真实机器人与闭环成功率；部分物体坐标结果在见过测试集后探索，再于同测试族复验；扩散模型未针对少步采样蒸馏或重调参，跨范式优劣不能泛化；VFlash 是重实现的小模型而非原系统。

## Future Work
作者建议检验多物体、可变形物体、完整 3D 位姿及大型预训练骨干上的坐标系效应，并比较一两步蒸馏扩散模型；真实机器人闭环测试也是明确缺口。

## Rating
创新度评分：2/5 - 坐标规范化、并行解码和 Kabsch 均非新技术，价值主要来自严谨组合与受控实证。
相关度评分：2/3 (Related) - 研究动作条件几何世界模型的快速决策，但限定于二维关键点而非视频、3D 或 JEPA 式隐式建模。

## TL;DR
物体坐标加单次解码显著降低推物体决策误差，刚体投影保证几何一致；世界模型设计与评测值得精读。
