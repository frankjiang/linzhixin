# ReFract: Benchmarking Perspective Awareness in Language Model Agents with Text World Models

## Insight
同一句设备维护请求由不同角色提出时，合规目标、可执行工具及转交对象可能不同。作者将角色能力/知识边界编码为可执行文本状态转移，用终态达成和轨迹越界同时检验 LLM 智能体；扩大工具集后所有模型成功率下降，显示角色判断与工具选择相互影响。这是受控基准的经验观察，并非关于视频或隐式世界模型的结论。

## Motivation
现有工具使用基准多重视任务是否完成，较少检查同一请求下，智能体是否依用户身份限制动作、在权限不足时转交合适的人。工业维护中错误动作可能有实际后果，因此作者设计可复现的离线模拟评测。问题对智能体安全有意义，对本项目的视频/3D/JEPA/Dreamer 研究仅有术语上的关联。

## Method
由专家定义一个工业维护 PDDL 式领域文件：事实与状态、81 种工具、8 类能力权限及 6 类知识门槛；工具有前置事实、输入/输出依赖、状态效果，Python 执行器检查其可用性。基于匿名支持对话，Claude 模型筛选问题、提议角色相关目标和行动轨迹，经确定性执行/规划检查、三位领域专家审定，形成 40 个会话衍生的 150 个「角色×任务」条目。评测时给定角色，智能体在问题专用工具集（QTS）或完整工具集（FTS）中逐步调用工具；比较 Function Calling 和 ReAct。这里的 Text World Model 是**人工编写的符号环境**，不是从视频学习的预测模型。

## Experiment
对 Qwen3、Gemma-4、GPT-OSS、GPT-5.5/5.6 等模型各重复运行 5 次。指标为终态 Pass Rate、整条轨迹 Persona Compliance、越权 Over Reach、过度保守 Under Reach、相对参考轨迹的效率，另分析偏离目标的动作。最优 GPT-5.6-Sol+ReAct 在 QTS 的通过率 0.685、合规率 0.559，FTS 通过率降至 0.466；Function Calling 的最高通过率从 QTS 的 0.625 降至 FTS 的 0.473。知识门槛的平均违例 0.098，高于能力权限门槛的 0.064；需要跨角色求助的任务中，正确求助比例从 QTS 的 67–71% 降至 FTS 的 17–42%。作者还按角色、工具集和脚手架分析过度保守及越权行为，没有训练新模型或验证真实工厂行动。

## Value
其贡献在于将用户角色约束落实到可执行轨迹，而不是只看最终回答；若研究工具智能体可借鉴双门槛和过程指标。对视频、3D 和隐式世界模型没有直接方法、数据或评测价值，不能因为题名中的 “World Models” 就归入本方向。

## Strengths
- 同一领域、同一问题对照不同角色，减少场景变化对角色能力评估的混淆。
- 工具前置条件、数据依赖和目标状态由执行器检验；区分完成任务、越界及无谓退让。
- 给出 QTS/FTS 两种难度、多个模型和附录中的数据构造/推理提示，便于理解失败类型。

## Weaknesses
- 仅一个工业维护领域、150 个角色任务条目；真实环境的随机转移、传感器噪声、动态权限及多轮澄清均未覆盖。
- 状态转移单调地添加事实、不会撤销；对真实设备状态改变和不可逆失误只是符号近似。
- 数据筛选、目标和可行轨迹很大程度依赖 Claude 系列模型，虽经专家审核，仍可能有生成器偏差；角色在推理时已明确提供。
- 主要结果是智能体在人工环境内的行为，不证明其部署安全性，更不涉及视觉物理动态预测。

## Future Work
作者拟扩大领域、角色体系、标注规模和模型/智能体框架；加入更细的跨角色转交分析、随机且部分可观测的环境，以及从对话推断身份和主动澄清。

## Rating
创新度评分：2/5 - 角色边界轨迹基准有针对性，但核心是人工符号环境与现有 LLM 工具调用的组合，对世界模型技术贡献有限。
相关度评分：0/3 (Noise) - 文本工具智能体评测，不研究视频、3D 或 JEPA/Dreamer 式隐式世界模型。

## TL;DR
用可执行文本环境评测维护智能体的角色权限和转交行为，与视频及隐式世界模型研究无实质交集，可跳过。
