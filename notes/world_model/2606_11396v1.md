# PLUME: Probabilistic Latent Unified World Modeling and Parameter Estimation for Multi-Finger Manipulation

## Insight
核心 observation：多指精细操作对摩擦、物体形状、初始姿态等隐藏物理参数高度敏感；仅靠 domain randomization 学一个参数无关策略不够。推论是世界模型应在线维护对隐藏参数的 belief，并用该 belief 条件化 dynamics rollout 和 planning。实验证明 belief-conditioned rollout 在 screwdriver/valve/bucket 等任务明显优于隐式历史建模。

## Motivation
解决 sim-to-real 多指操作中物理参数不确定导致策略失效的问题。同行的 world model/BC/offline RL 多用固定历史隐式吸收动态变化，不显式估计参数，也少用于精密多指任务。该问题关键，因为 contact-rich manipulation 的成功常取决于具体摩擦、形状和接触状态。

## Method
PLUME 学一个统一 latent 表征 z，编码摩擦、shape descriptor、reward 等异质参数；用 Wasserstein autoencoder 使 latent 服从标准正态，便于部署时初始化 particle belief。History 用 Mamba-2 encoder 压缩长期轨迹。核心是一个 flow matching transformer，通过 conditioning mask 学多个条件分布：参数 belief update、rollout generation、inverse dynamics/transition likelihood。部署时维护 K 个 latent particles；planner 并行自回归 rollout 候选轨迹，用 decoded reward 和 transition likelihood 加权评分，执行首个动作；观察新状态后再用 world model 更新 belief。

## Experiment
任务包括 Isaac Lab screwdriver turning、valve turning、disk flicking、SAPIEN DexArt bucket，以及真实硬件 screwdriver zero-shot。对比 UWM、Flow Q-Learning、Decision Diffuser。PLUME 在模拟 screwdriver validity 81.3%，UWM 70.7%；硬件 screwdriver validity 93.3%，UWM 86.7；valve goal distance 0.59 vs UWM 1.29；disk 6.5cm vs 8.1cm；DexArt bucket success 71.3%，其他几乎 0-5.3%。消融显示 likelihood 对 screwdriver validity 很重要；single particle/no belief/detached 在不同任务下降，整体不如 full PLUME。

## Value
对隐式/latent world model 和机器人 planning 很有价值：把 system identification、belief update、world rollout 和 planning 统一进一个生成模型。局限是训练依赖仿真 ground-truth 参数；transformer token 数随 particles 增长成本高；真实实验主要是 screwdriver，任务覆盖仍有限。
