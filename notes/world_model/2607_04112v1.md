# DynaVieW: Schema-Guided World Modeling for Understanding Hierarchical Visual Dynamics

## Insight
DynaVieW 的 insight 是：开放视频动态不仅是像素变化，也可以被组织成层级 state-transition schema。显式 schema 能把活动、状态变化、贡献关系等结构注入多模态生成模型，从而提升跨状态一致性和可控性。

## Motivation
视频生成/理解模型常能生成局部合理帧，但对长时层级事件、人物/地点一致性和因果转移缺少可解释结构。已有 story/video model 多依赖自由文本提示，难以约束动态过程。

## Method
论文将 Ego4D、AgiBotWorld-Alpha、ShareGPT4Video 等视频转成 interleaved state-transition 序列：state 是关键帧，transition 是由 VLM 标注的层级 JSON schema。模型初始化自 BAGEL-7B-MoT，包含理解和生成专家，并用选择性 attention mask、schema token reweighted CE、以及 diffusion MSE 训练 state simulation。

## Experiment
实验先用 GPT-4o rejection rate 检查 schema 数据质量，再在 VinaBench 上比较 narrative generation 和 controllability。DynaVieW 在 SFT 后达到约 0.726 平均分，略高于 BAGEL；schema 控制下相较 BAGEL 在角色、地点和转移一致性上提升明显。人类偏好中 DynaVieW 也更常被选择。

## Value
这篇更偏“视觉叙事世界模型”，不是物理控制世界模型。对我们有启发的是结构化 transition schema 可作为长视频 latent 的显式中间层，但其物理可执行性较弱。

## Strengths
状态-转移建模形式清楚；schema 提升可控性的证据较直接；适合长视频理解/生成。

## Weaknesses
依赖 VLM/LLM 标注和 judge；任务偏 narrative，不检验动作条件物理一致性；token budget 和视频长度仍受限。

## Future Work
未来可把 schema 从叙事活动扩展到可执行动作、物理接触和 3D 状态变化。
