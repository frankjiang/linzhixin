# Underwater C3-JEPA: An Object-Centric Cross-View World Model for ROV Salvage

## Insight
纯潜预测可能压掉接触任务需要的对象位置和夹爪细节；弱对象绑定、跨视角补全和少量特征重建可让潜状态保持可读。相同记录训练的 LeWM 无重建对照，关节角/目标相对位置/朝向探针误差为 9.81°/0.79m/13.82°，C3-JEPA 降到 4.90°/0.60m/6.50°；潜 MSE 与决策所需信息应分开检验。

## Motivation
水下 ROV 抓取时目标被遮挡、相机视角不全、推进器响应滞后，接触传感器难装；重建完整 3D 地图在近场操作可能成本高且不稳定。论文针对目标—夹爪关键对象，构造轻量动作条件潜世界模型服务短时规划。

## Method
冻结 DINOv3-L 提取多相机 patch 特征；6 个 slot 中弱绑定目标、夹爪和 ROV 框架，另 3 个存自由上下文。训练时遮住目标相机，用其他视角的交叉注意力恢复目标对象特征与掩码，配合 SIGReg；动作条件 Transformer 读取约 1 秒历史视觉/控制，预测未来对象潜状态并递归滚动。预测状态可供 MPC 排序候选命令，也用于想象滚动训练带行为克隆正则的策略；预测器约 1.33M 参数。

## Experiment
模拟记录与两次水池实测。模拟同预算消融中，弱绑定使目标/夹爪组 Dice 约 0.90/0.88，未绑定约 0.09/0.12；held-out 跨视角注意力使特征 MSE 0.0231→0.0200、目标解码 Dice 0.713→0.820。229 段交互记录中，终端相对运动误差相较持续预测从 39.1 降至 25.7 cm；90 组四选一候选的最优首选率 53.3%，随机 25%。水池两次部署隐藏相机 token 误差分别 0.615→0.147、0.962→0.332，五秒预测误差比持续预测低 23%/31%。实测仍是开环回放，无海上抓取成功率；实测滚动 token 误差改善时掩码 IoU 未必改善。

## Value
对多视角对象中心 JEPA 很有参考价值：可用弱锚固定任务对象、留自由上下文，并以冻结探针、动作置零、候选排序逐层验证表征到控制的链条；值得精读。

## Strengths
对弱绑定、跨视角融合、SIGReg、控制条件分别有诊断；比较同数据纯潜基线；同时报告模拟与真实水下录像，并明确开环证据不等于闭环成功。

## Weaknesses
实地只在水池两次部署、未给闭环作业成功率或嵌入式设备延迟；部分跨视角实验用固定随机窗口而非按记录独立划分。模拟相机退化简化了真实水下光学，目标和夹爪弱锚仍需人工审核；想象训练收益使用同一冻结 critic 衡量，缺独立成功指标。

## Future Work
作者指向海上闭环作业验证、预测器嵌入式移植，以及把任务对象接口扩展到水下检查、连接器对接等近接触任务。

## Rating
创新度评分：3/5 - 对象弱绑定、留一视角融合与动作条件 JEPA 的组合扎实，但核心模块已有先例且缺闭环实证。
相关度评分：3/3 (Core) - 直接研究多视角对象中心的隐式世界模型与动作条件潜预测。

## TL;DR
用弱绑定对象槽和留一视角融合训练水下动作条件 JEPA，潜状态更可读且预测更准；值得精读。
