# Discrete-WAM: Unified Discrete Vision-Action Token Editing for World-Policy Learning

## Insight
核心 observation：现有端到端自驾系统在连续隐空间中操作，表征高度纠缠，视觉状态、动作和未来状态之间缺乏显式的组合语义对齐，限制了 action-conditioned 因果推理和反事实比较。连续扩散模型虽然能生成全局一致的未来，但语义不显式；自回归模型支持离散组合生成但受限于前缀偏置。

推论：将视觉观测和自车动作统一为对齐的离散 token，在共享的离散空间中通过离散扩散进行联合建模，可以实现 world modeling、world-policy modeling 和 policy modeling 的统一，支持双向推理和可编辑的反事实生成。

证明：在 NAVSIM v2 上达到 90.4 EPDMS（SOTA），同时支持可控未来生成、反事实推理和安全感知评估。FID 6.6/FVD 80.0 在驾驶视频生成中也接近最优。

## Motivation
- **解决什么问题**：自动驾驶中需要同时建模世界动态和驾驶策略，现有方法将 world model 和 policy 作为分离模块优化，难以建立状态-动作-未来之间的一致因果对应关系。
- **同行做法**：(1) E2E 行为克隆（UniAD/VAD 等）直接 state-to-action 映射，不建模动态；(2) 连续扩散 world model（DriveDreamer 等）生成视觉未来但语义不可组合；(3) AR 方法（DriveVLA-W0 等）有组合性但受前缀偏置限制。
- **是否关键**：统一 world-policy learning 是自驾领域的重要研究方向，有助于提升可解释性和安全性。

## Method
整体架构（四个核心组件）：

1. **Vision Tokenization**：VQ-VAE 将前视相机图像编码为离散视觉 token（codebook size K_V）。
2. **Action Tokenization**：将连续轨迹转为自车 2D 加速度序列，量化到网格化加速度词表。使用 soft label（双线性插值权重）代替 hard quantization，训练时对 soft target 做 cross-entropy，推理时通过加权求和恢复连续加速度。
3. **Unified Token Edit Model**：decoder-only Transformer，在统一的离散 token 空间上支持三种训练模式：
   - **World Modeling**：给定 context + action tokens，通过离散扩散编辑/预测未来 visual tokens。
   - **World-Policy Modeling**：交替生成 action 和 visual tokens，联合学习策略和世界动态。
   - **Policy Modeling**：先预测 high-level decision skeleton (D_t)，再条件生成 action tokens。
4. **Task-Specific Attention Masks**：三种训练目标使用不同的注意力掩码控制信息流。

**层次化策略**：
- Decision skeleton 捕获粗粒度驾驶意图（变道/车道选择/速度趋势等）。
- Action token 在 decision 条件下生成细粒度轨迹。
- 理论分析表明 decision conditioning 降低 action token 间的残差 total correlation。

**Post-training**：
- 用 GRPO（Grouped Relative Policy Optimization）进行 RL 后训练。
- 通过 token-edit planner 采样多条候选轨迹，用 PDMS/EPDMS 作为 reward。

**Training Schedule**：三阶段渐进训练 -> visual pretraining -> joint vision-action -> LoRA action finetuning。

创新程度较高：(1) 离散 token 空间的统一 world-policy 建模是新的；(2) 离散扩散 + token editing 的推理框架有新意；(3) 层次化 decision skeleton 有理论分析支撑。

## Experiment
- **基准**：NAVSIM v1 和 v2（12K 驾驶场景，2Hz，4s horizon）。
- **指标**：PDMS、EPDMS 及其子指标（NC/DAC/DDC/TLC/EP/TTC/LK/HC/EC）；FID、FVD（视频生成质量）。
- **Planning 结果**（NAVSIM v2）：
  - EPDMS 90.4（SOTA），超过 DreamerAD (87.7)、SparseDriverV2 (90.1)、DrivingWorld 等。
  - 各子指标全面领先或接近最优。
- **视频生成**（Table 2）：FID 6.6（最优）、FVD 80.0（最优）。
- 还展示了可控生成、反事实推理、安全感知预测等定性结果（需读更多页面确认）。

## Value
- **整体价值**：高质量的自驾 world-policy 统一建模工作，将离散表征的优势充分发挥，在规划和生成两个维度都达到 SOTA。理论分析也较扎实。
- **对我们的启发**：(1) 离散 token 空间的统一建模是视频世界模型的重要方向，Discrete-WAM 的 token editing + 离散扩散框架值得借鉴；(2) 层次化 decision skeleton 减少 action correlation 的思路可推广；(3) soft-label 加速度量化是处理连续动作离散化的好方法；(4) 统一 world/policy pretraining 的设计理念对其他 embodied AI 场景有参考价值。
- **待解决问题**：仅在前视摄像头+2Hz 场景验证；VQ tokenizer 的重建质量可能限制上限；真实闭环驾驶验证缺失。

## TL;DR
小米自驾统一离散 vision-action 世界-策略模型，通过离散扩散 token editing 联合建模世界动态和驾驶策略，NAVSIM v2 EPDMS 90.4 SOTA。值得精读。
