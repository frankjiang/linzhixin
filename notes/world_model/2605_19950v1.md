# AffectVerse: Emotional World Models for Multimodal Affective Computing

## Insight
将世界模型的"预测未来状态"思路应用于情感计算：通过预测未来的情感表征来迫使当前信念状态编码情感转变线索。未来预测作为过去条件化的自监督信号。

## Motivation
现有多模态大语言模型将情绪识别视为对完整视听文本输入的静态融合，忽略了情感动态。AffectVerse 用 Emotion World Module (EWM) 引入短时域潜情感预测。

## Method
基于 Qwen2.5-Omni，EWM 包含三个模块：(1) Cross-Modal Temporal Imagination：从过去 token 预测未来视频/音频表征（多步 rollout）；(2) MAMA (Modality-Aware Multi-step Attention) Belief Aggregation：将想象 token 压缩为模态感知的信念 token；(3) Belief Injection：将信念 token 注入 LLM 用于情感推理。

## Experiment
9 个基准测试上至少 2.57% 提升。受控消融显示时间想象、跨模态 rollout 和信念聚合的叠加增益。

## Value
"世界模型"思路在情感计算中的新应用。但与用户关注的视频/3D/隐式世界模型方向几乎无关。EWM 的设计更接近时序注意力增强而非真正的世界模型。

## Strengths
亮点是"世界模型"思路在情感计算中的新应用。

## Weaknesses
不足是与用户关注的视频/3D/隐式世界模型方向几乎无关。

## Future Work
作者未明确提出具体未来工作；从局限看，后续需要围绕“与用户关注的视频/3D/隐式世界模型方向几乎无关”补充更大规模验证、跨场景扩展或方法改进。
