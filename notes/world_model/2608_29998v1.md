# The Intervention Gap in Latent World Models

## Insight

观察到：任务变量可从真实 latent state 中被 probe 解码、reward prediction 误差很小、整体 feature change 也与真实变化对齐，并不意味着模型能正确预测动作对该任务变量的影响。由此论文将 **capture（当前状态是否含有信息）** 与 **propagation（模型转移是否正确搬运信息）** 分开，提出“planning-time intervention fidelity”应被单独审计。式 (2) 的有限时域误差分解说明 capture error 与逐步 operator error 是不同项；随后用合成校准和匹配环境干预实证展示“可读但传播错误”的情形。

## Motivation

潜世界模型通常用 one-step loss、reward/value fit、return 或整体 feature similarity 评价，但 planner 实际消费的是模型自身的 open-loop transition。前述指标可能掩盖一个关键故障：模型知道当前任务状态，却错误预测候选动作会怎样改变它。该问题直接关系 Dreamer、TD-MPC、JEPA 等隐式世界模型是否适合规划，重要性高；现有 action-sensitivity 指标也多比较模型自身的不同 rollout，而非与环境中执行同一干预的结果匹配。

## Method

- 先固定任务 query 集合 $Q$、物理时域 $H$、root/action 支持分布 $\nu$ 与模型原生 planning interface，避免事后挑选 estimand。
- 粗粒度 **operator-error audit**：在真实编码状态上训练 grouped-CV ridge probe，再让模型按原生方式 open-loop 推进；将 probe 解码的终点任务变量与环境执行同一动作后的真值比较，并把 probe quality 单列。
- 细粒度 **capture-gated matched-intervention audit** 分三关：Gate 1 检查 root capture；Gate 2 检查冻结 readout 能否分辨真实环境中的匹配干预效应；仅当前两关通过，Gate 3 才比较 imagined effect 与真实 effect、零效应/持久性基线及 environment-endpoint oracle。
- target construction、probe、calibration、evaluation 按 environment family 隔离；以完整 family 为不确定性单位，采用 grouped nested CV、whole-family bootstrap，以及 shuffle、wrong-action、action-null、horizon-zero、probe-capacity 等控制。
- 在 TD-MPC2、LeWorldModel、PreJEPA、DreamerV3 上分别研究 value-channel mismatch、效应几何、支持外不确定性和可读接口。

整体上是新的评测/诊断框架，而非新的世界模型训练法；创新点在于把“信息存在”与“干预传播正确”做成有停止规则、oracle 和支持边界的可操作协议。

## Experiment

- **TD-MPC2 size sweep（Cheetah）**：5 个依赖 checkpoint 上，episode return 与 operator error 的 Spearman 为 $-0.90$，控制 reward error 后 partial rank correlation 为 $-0.89$；reward-prediction error 却仅在 $[0.03,0.09]$ 内近乎平坦。样本很小，作者明确仅作相关性警报。
- **task anchoring 对照**：3 个自监督 LeWorldModel seed 的 operator error 为 $0.384\pm0.009$，单任务 TD-MPC2 为 $0.840$，误差比 $0.457\pm0.011$；well-probed coordinates 与 MLP probe 控制仍保留差距。
- **Cheetah 匹配干预**：每个候选用 96 个 evaluation families、每 family 3 roots×6 action contrasts、5-step horizon，并做 4,096 次 whole-family bootstrap。3 个 LeWorldModel 的 root $R^2=0.579$–$0.609$、真实效应 $R^2=0.127$–$0.198$，但 imagined effect $R^2=-6.33$ 至 $-3.36$；完整 feature-change cosine 仍达 $0.85$–$0.89$，而任务方向近乎正交且 gain 高 $1.7$–$2.6$ 倍，支持“旋转+过增益”而非 feature collapse。
- **边界验证**：5 个 PreJEPA seed 均通过 capture 且均劣于 oracle，但 predicted-effect $R^2=-0.005$ 至 $0.064$，不复现严重负 $R^2$；Finger Spin 的 3 个 LeWorldModel seed 均有 oracle deficit，仅 1 个达到 severe，说明故障依赖模型、任务、seed 与 support。
- **接口与不确定性**：DreamerV3 四个 checkpoint 中，只有 centered posterior logits 在所有设置通过当前-query gates，sample/mode/recurrent state 均失败；PreJEPA ensemble disagreement 在 task-policy support 上与误差相关 $\rho=0.678$，在 environment-random support 上仅 $0.027$。冻结的 support-aware 加法分数跨家族迁移反而弱于原生 disagreement（TD-MPC2：$0.756<0.776$；LeWorldModel：$0.388<0.417$）。

## Value

这项工作的价值不在于给模型排总榜，而在于提供一个能定位失败层次的审计框架：先问任务变量是否存在，再问真实干预是否可测，最后才评价 imagined transition。它提醒我们，JEPA/Dreamer 的 representation probing、reward fit 或全局 latent alignment 都不能替代 action-effect fidelity；未来选 checkpoint、构建 planner 或训练 loss 时，应直接加入 matched-intervention 诊断。

## Strengths

- 概念切分清楚，并由误差分解、10 个合成接受案例和严格 gate 顺序共同支撑。
- 对负面结论保持克制：候选、seed、task、support 分开报告，不把非复现包装成架构优劣。
- 控制实验完整，尤其是 persistence/zero/oracle、probe capacity、完整 family bootstrap 与 held-out 双向迁移 falsifier。
- 不只发现误差，还定位到 task-direction rotation、attenuation、posterior interface 等具体故障形态。

## Weaknesses

- 主要实证仅覆盖 Cheetah、Finger Spin、单一标量 query 与 5-step horizon；32 个系统的资格筛查后，只有 PreJEPA 家族满足全部原始主检验条件，外推范围很窄。
- TD-MPC2 size sweep 只有 5 个相关 checkpoint；task-anchoring 比较跨模型输入模态与原生预测方式不同，且 anchored 方每变体只有一个 seed，不能支持架构排名或因果机制。
- probe 成功/失败依赖固定 readout family；论文既未证明 planner 实际使用可读信息，也未证明审计分数能改善 checkpoint selection、return 或 regret。
- 协议需要预先确定 query、support、horizon、readout 与环境端 oracle，工程成本高；首个 TD-MPC2 matched-shell model audit 甚至在 capture gates 即停止，显示可用性也受测量工具限制。

## Future Work

作者明确留下两项核心问题：解释为何某些模型产生“任务方向旋转+过增益”、另一些产生 attenuation；验证审计排序是否对 checkpoint 选择和实际 return 有决策价值。另有 Walker continuation 尚未完成。自然延伸还包括更多任务变量、时域、支持分布与非线性 readout，但这些属于由局限推导的方向。

## Rating

创新度评分：4/5 - 将 latent world model 的 intervention fidelity 独立成 capture-gated、环境匹配且有严格停止规则的审计对象，方法新且证据链扎实；但尚未形成训练新范式，外部有效性与决策价值未证。
相关度评分：3/3 (Core) - 直接审视 JEPA、Dreamer、TD-MPC 等隐式世界模型的状态表示与动作传播是否可用于规划。

## TL;DR

提出捕获门控的匹配干预审计，揭示奖励拟合不保证潜世界模型的干预保真；证据严谨，值得精读。
