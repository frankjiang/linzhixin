# Mamba-VGGT: Persistent Long-Sequence Video Geometry Grounded Transformer via External Sliding Window Mamba Memory

## Insight
核心观察：3D foundation model（如 VGGT）在长序列视频上面临"几何遗忘"和累积漂移，根因是全局 attention 的二次复杂度迫使模型使用截断的时间窗口。关键设计：将 3D 空间记忆与时间传播解耦——用 Mamba SSM 维护线性复杂度的外部记忆流，通过 Zero-Init 注入器将长程几何先验无损融合回预训练的 VGGT 空间特征中。

## Motivation
VGGT 等 3D foundation model 在短序列上表现优异，但长序列（数百帧）时由于 attention 窗口限制导致几何累积漂移。需要一种线性复杂度的记忆机制来维持长程几何一致性，同时不破坏预训练模型的空间 grounding 能力。

## Method
双流架构：
1. **Original Patch Token Stream**: 保持 VGGT 原有的空间特征提取能力
2. **External Memory Stream (SWM)**: Sliding Window Mamba 模块维护显式外部记忆 token。每个窗口处理完后，Mamba 将当前窗口的几何精华蒸馏到记忆 token 中，通过 SSM 的选择性状态更新传播到下一窗口。FIFO 缓冲区保持固定内存占用
3. **Zero-Init Spatial Memory Injector**: 零初始化 1x1 卷积层将 Mamba 记忆注入到 VGGT 的 KV token 中。训练初期输出为零，保护预训练权重不受干扰，渐进学习长程记忆的利用
4. **两阶段训练**: Stage 1 冻结 VGGT 只训练 SWM + Injector；Stage 2 全局联合微调扩展序列长度

## Experiment
- DTU/ETH3D 点云重建：在 streaming 设置下全面超越 ZipMap、VGGT(windowed) 等基线
- Sintel/Bonn 深度估计：AbsRel 最优
- RealEstate10K/Co3Dv2 相机位姿：AUC@5/15/30 显著领先
- 7-Scenes 重建：在 sparse 和 dense 设置下均达到最优
- 长序列（50-300帧）：性能随帧数增加保持稳定，而基线显著下降
- 运行时间线性增长，优于二次复杂度基线

## Value
用 Mamba 记忆扩展 3D foundation model 到长序列的优雅方案。Zero-Init 注入器是保护预训练模型的有效设计模式。对 3D 世界模型的持久化记忆问题提供了实用解决方案。与视频世界模型的关联在于：长序列 3D 一致性是世界模型的核心需求，Mamba 外部记忆的思路可迁移。但本质更偏 3D 重建而非世界模型生成。
