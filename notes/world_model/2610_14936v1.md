# CFG-Policy: Unified Diffusion Policy Learning Framework via Classifier-free Guidance

## Insight
观察到在线 RL 优化扩散策略易丧失多模态探索，而预训练策略直接微调易破坏原能力。分别保留一个冻结分支和一个可训练分支，在每一步去噪中按 `(1-w)v_A+w v_B` 合成生成场，可把探索与利用的影响分开。论文证明固定噪声层的得分场等于两密度几何组合的得分；终点分布解释要求额外路径一致性假设，熵随权重下降的结论也依赖“利用策略是探索策略的幂锐化”假设，并非普遍保证。

## Motivation
QSM/QVPO 等在线扩散 RL 单策略学习可能过早集中，VLA 策略的 RL 后训练则需要保留预训练技能。动作空间残差/线性混合可能无法表达多模态改变。研究目标是控制策略的探索与保留能力，并非学习视频或 3D 环境转移。

## Method
在线学习中冻结另行预训练的 RND 探索扩散策略，训练任务利用分支；交互用两分支逐去噪步合成，评测可仅用利用分支。离线到在线后训练中冻结预训练 π0/π0.5 动作头，复制一支训练，通过合成流场输出动作；QSM、QVPO 或 Flow-SDE+PPO 的原损失不变。可用 critic 预测的 Q 值更新全局引导权重，同时约束与纯利用策略的路径差异下界。创新是把 CFG 用作双生成策略的可插拔动作采样器，结构简单，依赖先前 CFG 思路。

## Experiment
5 个 MuJoCo 运动任务、QSM/QVPO 各 5 个随机种子，以回报及学习曲线比较；4 个 RoboTwin 操作任务，比较 Flow-SDE+PPO 成功率，并消融固定权重和最终动作插值。HalfCheetah 回报 QSM 5020→6218、QVPO 11166→12990；Ant 的 QSM 从 -24→1425。π0 在 Adjust Bottle 成功率 82.81%→98.44%，Pick Dual Bottles 43.75%→57.81%；π0.5 在较难双瓶任务仅 12.50%→15.62%。HalfCheetah 上动作插值弱于原 QVPO，动态权重优于所测两个固定权重。附录测得 QSM 每 1000 步训练时间 2.42→2.94 秒、显存 507→577 MiB。

## Value
如果团队需要为视频/3D 世界模型配套多模态动作规划或机器人策略，可选读双分支采样设计；它不提供环境状态预测、动力学建模或世界模型评测，因此对核心研究只有间接价值。

## Strengths
同一组合机制覆盖在线探索和预训练后适应；跨两类 RL 骨干、多个任务测试，并有动作空间插值消融；理论部分明确写出固定噪声层结论与终点近似之间的条件。

## Weaknesses
有效性依赖独立训练或复制第二策略，推理需双分支；熵与分布解释假设很强。权重仍需任务调节，作者承认手调可超过自适应方案；机器人提升有些任务幅度小，未证明预训练能力在未训练任务上得到保留。环境均为控制基准，没有世界模型组件。

## Future Work
作者建议设计更有效的任务感知引导权重自适应策略。

## Rating
创新度评分：2/5 - CFG 双策略组合是合理增量，但沿用现有生成场组合思想，未推进目标世界建模方法。
相关度评分：1/3 (Tangential) - 仅可间接借鉴动作生成与规划策略，不研究视频、3D 或隐式世界模型。

## TL;DR
逐步合成冻结与可训练扩散动作策略以改善探索和后训练控制；对世界模型仅有间接参考，可选读。
