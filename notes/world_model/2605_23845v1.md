# Learning a Particle Dynamics Model with Real-world Videos

## Insight
Observation：现有粒子动力学模型依赖仿真数据（需完美状态标注），sim-to-real gap 限制实际应用。而可微渲染（GS）可以桥接2D观测与3D状态，使得从真实视频学习成为可能。推论：将GS粒子作为动力学模型的状态表示，通过渲染监督直接从多视角真实视频学习碰撞动力学，无需粒子级标注。

## Motivation
问题：学习多物体碰撞动力学通常需要仿真环境的完美3D状态标注，真实世界中无法获取。同行工作要么局限于仿真数据，要么仅处理单物体/单个cube场景。核心瓶颈在于如何获取真实场景中的可靠3D监督信号。本文提出首个从无标注真实视频学习多物体碰撞动力学的框架。

## Method
整体管线：
1. 用GS从单帧重建3D Gaussian粒子（含位置、旋转、尺度）
2. 通过多视角分割mask + 投票机制为每个Gaussian分配object ID
3. 基于PointConv的U-Net预测粒子下一步位置/旋转变化（区分Object/Relational卷积）
4. 训练用渲染损失（L1）+ 位置回归损失（Huber），自回归rollout K=3步

关键设计：
- 用ICP + 2D point tracking获取per-object 6DoF伪标签作为辅助监督
- 多视角渲染一致性约束
- Hard example mining采样策略

创新程度：中等偏上。核心贡献是工程整合——将GS表示与粒子动力学模型结合，通过渲染监督避免3D标注。技术组件（PointConv、GS渲染）均为已有方法。

## Experiment
- 消融：验证了object-centric建模、离散ID vs 软ID、位置损失+渲染损失组合、hard example mining的贡献
- 指标：PSNR/SSIM/LPIPS（渲染质量）、CD（Chamfer距离）、δ_avg（位置精度）
- 与GS-Dynamics*对比：性能相当，无统计显著优势
- 数据集：~500个多视角视频（210 cube stack + 292 bowling）
- 局限：渲染指标区分度不足，缺乏物理合理性的直接评估

## Value
工作价值：开创了从真实视频学习多物体碰撞动力学的新范式，但当前实验规模有限（桌面场景），且评估指标不够直接反映物理合理性。对我们的启发：GS作为物理世界模型的中间表示有潜力，渲染监督是弥合sim-to-real gap的有效手段。待解决：更复杂场景、更好的物理评估指标、长时rollout稳定性。
