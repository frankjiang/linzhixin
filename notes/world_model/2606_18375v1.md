# PAIWorld: A 3D-Consistent World Foundation Model for Robotic Manipulation

## Insight
多视角机器人世界模型的 3D consistency 需要两个条件同时存在：跨视角通信路径和几何监督信号。只有 cross-view attention 会学纹理复制捷径；只有 3D prior 没有路径又无法传播约束。消融显示组合有超加性提升。

## Motivation
机器人 manipulation 天然依赖 wrist/ego/external 多相机。现有 video WFM 多为单视角，多视角方法常把 token 拼接后让模型隐式学习对应关系，导致 object drift、depth inconsistency、texture misalignment，影响 planning/control。

## Method
基于 Cosmos-Predict2.5 14B DiT/flow matching。PAIWorld 加三组件：Geometry-Aware Cross-View Attention 在同一时间跨 view 交换 token；Geo-RoPE 将像素 ray direction、camera extrinsics/pose 编进 Q/K；Latent 3D-REPA 用 frozen Depth Anything 3 的 3D-aware features 做 token relation distillation，包括 intra-frame 和 temporal sampled anchor similarity。总 loss 为 flow matching + 0.5 REPA。

## Experiment
用 2.5M 多视角机器人视频训练，200 H200 约 7 天。在 WorldArena action-conditioned benchmark 上 EWMScore 70.67 第一，Motion Quality 79.66 第一；AgiBot-Challenge2026 EWMScore 0.8245 第二，Scene Consistency 0.9041 第一；AgiBot-World text-conditioned multi-view 上 SSIM 0.7683、LPIPS 0.1844、FID 45.04、FVD 175.78、MEt3R 14.20，多数指标最佳。消融：backbone MEt3R 16.84，CVA only 15.91，REPA only 16.12，二者结合 14.20，支持互补性。

## Value
核心相关，尤其适合研究 3D-consistent video world model。方法清晰、消融对问题假设有支撑。局限是大规模算力/数据依赖强，物理接触、deformable/fluid 和长 horizon consistency 仍未解决。
