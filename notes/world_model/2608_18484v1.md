# Partition the Support, Reconstruct the Residual: Training-Free Sparse Attention for Video Generation and World Models

## Insight
单行 attention mass 集中不等于可执行 block sparsity：共享 route 的 queries 支持可能不重合，保留质量也不决定 softmax 后输出误差。分区几何不仅影响要算哪些块，还决定被跳过残差能否从 sparse output 线性重构；因此需同时做 response-coupled partition 与 exact-row probe repair。

## Motivation
视频 DiT/物理世界模型的长时空 token 使注意力成为瓶颈，现有 training-free sparse 方法常只优化支持估计，忽视共享路由和 post-softmax residual。

## Method
SparsePR 用采样 query 的 key responses 联合划分配对 K/V，再由 key centroid 构造 query-response 坐标用于共享 routing；每次 attention call 精确计算少量分层 probe rows，拟合 sparse output 到 residual 的仿射映射，并投影到 probe-residual 子空间。无离线训练。

## Experiment
HunyuanVideo、Wan2.2、Cosmos-Predict2.5、Cosmos3-Nano 四模型，执行 pair density 22–26%，端到端加速1.48–2.61×且基本保持 VBench/PBench质量。四模型 attention mean/p99 error 均下降，probe fitting贡献最大；Wan全生成1650s→917s，repair仅占1.1%延迟。密度、partition、probe采样和 estimator均有消融。

## Value
这是直接可用于大型视频世界模型推理的系统方法；尤其强调按真实执行密度和完整在线开销评测，适合关注视频WM效率者精读。

## Strengths
跨生成/物理世界模型与异构架构；匹配硬件复现实验；精确核算 probes 与 routing 开销；机制消融细致。

## Weaknesses
仍需 dense probe rows 和每call在线聚类；效果依赖 attention 结构，Cosmos3质量最接近边界；只做推理、无训练稀疏或长视频一致性专项评测；实现复杂度与显存峰值讨论不足。

## Future Work
自适应 probe/密度、kernel融合、训练期稀疏、跨step复用及更长/更高分辨率世界模型。

## Rating
创新度评分：3/5 - 支持分区与残差重构的联合视角扎实，显著工程增量但非世界模型新范式。
相关度评分：3/3 (Core) - 直接加速视频生成与物理视频世界模型。

## TL;DR
联合响应分区与探针残差修复实现视频世界模型稀疏注意力，效率方向值得精读。
