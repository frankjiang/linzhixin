# IntactWorld: Joint World Modeling with Intact Features

## Insight

观察：多种专家特征先经 PCA 压缩可能损失空间和运动结构；直接在高维特征上回归流速度也难优化。作者据“干净特征位于低维流形”的启发，让中间层预测干净特征 `x0`，再换算为速度空间损失。其 VBench 消融中 `x0` 总分 81.45 对速度预测 80.63，属于经验支持；没有给出一般性流形理论证明。

## Motivation

普通文本生成视频模型的外观质量不能保证物理/空间合理；前作 DreamWorld 注入 DINO、VGGT、运动等专家知识但需要压缩和多分支推理。目标是在训练中保留密集结构信息，同时降低推理时多源条件的成本，是视频生成模型朝世界建模靠拢的工程问题。

## Method

以 Wan2.1-T2V-1.3B 为骨干。第一阶段提取完整 DINOv2 语义、VGGT 空间及光流转 RGB 后经 3D VAE 的运动特征，做时空对齐与通道标准化，并与视频 VAE 潜量联合送入扩展、零初始化的输入投影；视频潜量预测速度，专家特征在中间层预测 `x0`，以换算速度误差和随训练衰减的权重监督。第二阶段用每时刻 DINO/VGGT CLS 与运动特征空间平均池化 token 代替稠密特征，并用不赋时空位置的 RoPE 加入 token 序列。推理用文本 CFG 加单个紧凑世界条件分支，共 3 次前向，少于 DreamWorld 5 分支。这里的“世界知识”是冻结专家特征，并非可交互动作动力学模型。

## Experiment

WISA-80K 中选 3 万视频：2.4 万供完整特征阶段，6000 供紧凑 token 阶段；评测 VBench、VBench 2.0、VideoPhy 的官方文本提示。VBench 总分 81.45，对 DreamWorld 80.97、同数据微调基线 78.71；VBench 2.0 为 53.64，对 DreamWorld 52.97、基线 51.18（摘要“高 2.46 分”相对的是后者）。VideoPhy 总语义遵循 55.2、物理常识 27.6，对 DreamWorld 52.9/26.2。相对 DreamWorld 单视频延迟 237→133 秒，显存约 31.7→28.1 GB。去完整特征、去 CLS、预测速度的 VBench 总分分别为 81.24、81.31、80.63；22 层中间预测最好。图示案例显示部分快速运动的形变更少，但缺少真实物理轨迹误差测量。

## Value

对生成式视频世界模型可借鉴“双阶段密集特征蒸馏到紧凑 token”和中间层目标选择；论文更能说明如何改善视频物理感指标，不能据此认定已学到可供规划的世界转移规律。

## Strengths

明确剖析全特征训练与紧凑推理的成本矛盾；有预测目标、训练阶段及层位置消融；同时报通用画质和物理常识指标以及实际显存/延迟。

## Weaknesses

收益相对 DreamWorld 较小（VBench 2.0 仅 +0.67），主要是文本到视频与感知指标，没有动作干预、长程一致性或 3D 状态验证。“完整特征”仍经时空插值/池化，严格说并非无损；流形解释偏启发性。第二阶段仅 6000 视频，且部分维度不领先（如 VBench 2.0 人类保真低于 DreamWorld）。

## Future Work

作者没有明确提出下一项研究；可从当前实验缺口推及验证动作条件预测和长时物理一致性，这属于本笔记建议。

## Rating

创新度评分：2/5 - 现有视频骨干与专家特征注入上调整预测目标、两阶段压缩和引导，主要是增量优化。
相关度评分：2/3 (Related) - 服务视频世界模型质量，但实证仍是文本生成视频，没有交互式世界动力学。

## TL;DR

用完整专家特征训练、紧凑标记推理提升视频生成的空间和物理感指标；对视频世界模型训练设计可选读。
