# Encoding Memory in World Models with Test-Time Model-Based Reinforcement Learning

## Insight
观察：在部分可观测迷宫中，共享世界模型重访旧位置后会预测出与本局经历不符的未来，且误差随滚动步数扩大。推论：把本局轨迹用于测试时梯度更新，可将局部地图信息写入动力学参数，补充上下文记忆。作者以三种模型、2D/3D 迷宫的回报与 64 帧预测指标支持此推论；训练数据单独更新几乎无增益、去掉动力学 KL 损失则失败，说明效果来自本局数据驱动的动力学适配。证据是实验性的，并非形式证明。

## Motivation
DreamerV3、TWISTER、R2I 等主要通过 RNN、Transformer 或状态空间模型延长上下文，但单一共享模型仍难记住每局随机生成的迷宫结构。长期部分可观测规划确属世界模型的关键难题；问题核心是如何利用持续获得的本局信息，而非仅增加模型的上下文容量。

## Method
训练阶段沿用 Dreamer 式世界模型与想象轨迹 actor-critic。每个测试 episode 从训练权重复制世界模型、actor、critic，建立仅含本局轨迹的缓冲区；每执行一步，以训练缓冲区和本局缓冲区各 50% 的序列做一次梯度更新，再用适配后的模型训练 actor-critic。测试时冻结视觉编码器和解码器、去掉图像重建损失，主要更新序列动力学、潜变量预测及奖励/终止预测；不足序列长度的本局数据由训练数据补足。创新在把测试时自监督适配系统性地接入 MBRL 的模型与策略闭环，而非新世界模型架构。

## Experiment
自建局部 3×3 观测的 Memory Maze 2D，并在原 3D Memory Maze 的 9×9 至 15×15 四种规模评测；对 DreamerV3、TWISTER、R2I 分别比较有无 TT-MBRL，报告三次训练、每次 100 个评估 episode 的回报。3D 15×15、100M 训练步时，R2I 回报从 20.3 升至 29.3，TWISTER 从 23.1 升至 31.5；R2I 训练 400M 步后从 42.0 升至 54.1，仍低于人类 67.7。2D 15×15 上 DreamerV3 从 46.2 升至 185.0。100 条未见轨迹的 64 帧预测中，3D R2I（400M）的 FVD 从 111.1 降至 70.7，PSNR 从 21.7 升至 26.0；可视化也显示较少的长程漂移。消融覆盖训练/测试数据混合、预填充、更新频率、冻结编码解码器、KL 与 actor-critic 损失，并用只更新训练数据作额外算力对照。DMC 20 项均分 776.2→788.2，Atari 26 项人类归一化均分 109.5%→111.1%，表明非记忆任务总体未明显退化。

## Value
对需要记住单次交互环境布局的视频或隐式世界模型，提供了直接可复用的「固定表征、在线改动力学、混合旧/新轨迹」实验框架；尤其适合研究参数记忆与上下文记忆的分工。下一步应验证低延迟更新、有限训练缓冲区和真实机器人中的收益，以及收益究竟来自地图记忆还是一般的在线策略适配。

## Strengths
跨 RNN、Transformer、SSM 三类骨干重复验证；同时报告任务回报、潜空间 KL、FVD/PSNR/SSIM/LPIPS 和长程预测图像；训练数据单独更新与目标损失消融使因果解释更可信；小迷宫和非记忆任务也揭示收益边界。

## Weaknesses
测试阶段依赖原训练缓冲区且每步反传，3D 15×15 的 R2I 单个评估 episode 需约 0.65 小时；实际在线决策延迟和存储开销较高。提升主要集中于较难迷宫，小规模任务有微降或饱和；400M 步的最佳 15×15 回报仍低于人类。仅验证随机迷宫与常规控制游戏，尚无真实机器人、突变环境或严格限算力部署结果；方法也未隔离世界模型适配与策略适配各自的独立贡献。

## Future Work
作者提出将测试时更新延伸到训练探索阶段，以采集更有信息量的轨迹、提高样本效率；同时降低梯度适配开销，使在线应用可行。

## Rating
创新度评分：3/5 - 将已知测试时训练扩展为世界模型与策略联动适配，证据扎实，但核心技术仍是在线微调及经验回放混合。
相关度评分：3/3 (Core) - 直接研究隐式世界模型在部分可观测、长时规划中的记忆机制。

## TL;DR
测试时按本局轨迹微调世界模型与策略，显著改善长时预测和寻路；对在线记忆与具身规划有直接借鉴价值，值得精读。
