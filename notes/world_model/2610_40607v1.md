# Fight World Model: Customizable Combat through Visual Interaction Proxies

## Insight
同一击中动作在不同规则下可产生不同血量变化，受保护角色甚至会受击却不掉血；因此把“动作尝试—短暂反应—持久状态”混在视频生成器里，会妨碍规则编辑。作者将这三者按角色身份、空间位置和帧时间分别编码为可视代理；在输入同样执行记录的对照中，联合交互保真率由最佳符号编码的 76.35% 升至 98.48%（表 2）。这是实验观察，不是形式证明。

## Motivation
现有游戏视频世界模型多从动作直接预测画面及后果，或额外预测生命值；改规则时仍易沿用训练中的“动作→伤害”关联。可执行引擎能算对状态，但仅给渲染器布局或文本仍难保证受击对象、时机和 HUD 一致。可编辑规则、持久状态与外观定制是可玩世界的关键要求。

## Method
引擎按规则 $R$ 执行动作，维护角色位置、朝向、血量和技能计时器，输出状态与事件；确定性编译器将其映射到逐帧代理。代理用身份色的角色框/HUD 血条表示空间和持久状态，用条纹及技能块表示攻击窗口，用角色框与血条短暂反色表示受击；受击与掉血分开。Wan2.2-TI2V-5B 视频 DiT 同时接收初帧、代理、角色/场景参考图及文本，仅预测后续视频潜变量。随机分配的身份槽同时注入角色参考、初帧与代理，使换边后仍能对应角色。规则编辑只重跑引擎；外观编辑只更换参考图。核心创新是面向交互后果的时空代理，底座生成器与引擎解耦并非全新范式。

## Experiment
FightWorld Corpus 基于《Street Fighter II》，用冻结的视频编辑器扩增并筛选，含 112,618 个训练样本、52 种技能特效、187 种角色外观、15 个场景。与适配后的 H3-WORLD、ReactiveGWM v1/v2 对比，并做等执行信息的文本/状态 token 对照、去除代理线索、身份绑定消融及伤害倍率/有限次数免伤/吸血规则干预。指标含移动/攻击/技能准确率、受击反应、血量 MAE、联合交互保真率 $J$、外观遵从率和 DINO 相似度；部分动作由训练的识别器、反应与外观由 VLM 判断。

FWM 的移动/攻击/技能准确率为 99.78/99.24/99.06%，受击反应 99.79%，血量 MAE 0.15 个最大血量百分点，$J=98.48\%$（表 2/3）；最佳符号代理的 $J=76.35\%$。换边角色外观遵从率因身份绑定由 53.68% 升至 98.27%（表 1）。免伤和吸血时 $J_{rule}$ 分别为 99.92%、99.87%（表 5）；删除血条使 $J$ 降至 57.24%，删除受击提示使受击反应降至 80.42%（表 4）。图 7–9 展示双人交互、技能时序及五种新规则技能的可视化。

## Value
为需要“可执行状态 + 可控视频渲染”的游戏世界模型提供清晰接口：把规则结果对齐到角色、区域和时间，比把同样信息写成文本更可靠。进一步需要验证开放视角、复杂多实体与长时间交互下，代理是否仍足够表达遮挡、接触和状态变化。

## Strengths
- 对照实验保持执行记录、初帧、身份绑定、骨干和训练预算一致，较好地隔离编码方式影响。
- 分离动作、受击和血量，使免伤、吸血等训练分布外组合可由同一渲染器执行；身份绑定有明确换边消融。

## Weaknesses
- 只验证固定 2D 视角、双角色格斗及高度结构化 HUD；引擎先验和手工代理较强，未证明可迁移到开放 3D 世界。
- 训练数据大量由视频编辑器合成，视频渲染仍需大型 5B 底座与 128 张 H200 训练；未报告在线交互延迟/实时帧率。
- 联合指标含学习式动作识别和 VLM 受击判断；论文说明未计算受击精确率，因而对额外虚假受击的惩罚不充分。

## Future Work
作者未给出明确路线图；由当前局限可推导的方向是扩展到多角色、可移动相机和 3D 场景，并补充长时交互、延迟及虚假事件评测。

## Rating
创新度评分：3/5 - 可执行规则与视频生成的解耦已有先例，但身份对齐的交互代理及规则干预对照有实质方法贡献。
相关度评分：3/3 (Core) - 直接研究动作条件视频世界模型与可编辑游戏状态，适合作为结构化代理设计参考。

## TL;DR
以身份对齐的交互代理连接可执行格斗规则和视频生成，显著改善受击与血量一致性；做可控视频世界模型值得精读。
