# Agentsensus: Consensus-Compressed Shared Memory for Multi-Agent Story Worlds

## Insight
在多角色故事模拟中，同一事件被每个见证角色重复存储，随叙事推进形成冗余。作者将“谁知道此事”设为记录的所有者集合，把语义等价事件合并；四个故事世界的模拟写入比最近基线少 22%–44%，关闭合并使存储量增至 3.1 倍。该结论是文本记忆结构效果，不涉及物理世界预测。

## Motivation
传统生成代理给每人独立记忆流，公共事件多次记录且描述易漂移；代理在实验中也几乎不主动调用链接、修订或遗忘工具。论文解决长期角色模拟的存储与共享知识问题，与用户研究的视觉/3D/隐式世界模型无关。

## Method
故事内核按轮同时更新角色动作；文本事件入库时先拆成自足原子，用向量相似度找候选，再由 LLM 判断是否语义等价，等价则合并文本与所有者集合，否则建新记录。一次入库拆出的原子自动互连，角色检索只读自身拥有的记录并沿关联扩展一跳；结构维护内置于记忆写入/读取。

## Experiment
《三国演义》《红楼梦》《哈姆雷特》及俄乌冲突时间线四个文本世界，运行 40–80 轮，与独立记忆流、G-Memory、协作记忆比较；统一原子化粒度。共识库模拟新增 130–974 条，14%–28% 为多所有者、94%–99% 被关联；关闭合并后存储从 6590 增至 20669 条。LLM 评分的叙事质量与基线差别处于三次评分波动范围内，写入调用约慢一倍；所有数字基于每世界单次随机运行。

## Value
对多智能体文本记忆系统有工程参考，但研究目标是视频、3D 与潜动力学世界模型；可跳过。

## Strengths
清楚隔离记忆后端，统一写入粒度；报告压缩、分享、延迟与叙事质量，还承认合并的副作用和有限重复性。

## Weaknesses
错误 LLM 等价判断不可逆，手查 147 次合并中 5 次误并；保留较短文本会丢失人物/命令链；检索关联扩展可返回 1.6–8.8 倍行数。最大库约 7025 条、每世界单次运行，无法证明大规模稳定性。

## Future Work
作者未明确给出路线；局限指向可逆合并、保留事件细节、限制关联检索负载及更长/多次运行验证。

## Rating
创新度评分：2/5 - 记录级多所有者合并有实用设计价值，基础操作主要是既有语义去重与图检索。
相关度评分：0/3 (Noise) - 纯文本多角色故事记忆，与目标视觉物理世界模型无关。

## TL;DR
把多角色故事中的同一事件合并为多所有者记忆，减少存储但增加写入成本；非目标方向，可跳过。
