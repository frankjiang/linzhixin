# AcrossVAM1.0: Particle World Modeling for Text-Assisted Robot Video Prediction

## Insight

观察是机器人视频中大部分像素静止，直接复制最后一帧即可取得不差的全局指标；把运动与纹理都塞进同一 dense latent，还会让模型难以暴露究竟学到了动力学还是外观复制。作者据此推论：用低维语义粒子独立承担机器人部件几何与未来运动，再让只看最后一帧的因果外观支路恢复纹理，能在不泄漏未来的条件下同时获得可诊断运动和较好静态画质。

证据来自分层指标与 oracle：raw particle generation 的 motion PSNR 比 persistence 高 1.34 dB，却破坏 SSIM；learned delivery mask 恢复全局 PSNR/SSIM，但牺牲 0.36 dB motion PSNR，且仍与 per-pixel oracle 相差 1.55 dB。这个结果支持“运动状态与外观交付应解耦”，但语言是否真正控制轨迹只呈现 2.8-3.1% 的 shuffled-text gap，论文正确地只称 text-assisted。

## Motivation

机器人视频世界模型需预测小型关节、夹爪和被操作区域的运动，同时保持大面积静态背景。dense video predictor 的 correspondence、动力学和纹理耦合，object-centric slot/particle 又难保留高频外观；文字条件存在也不等于模型真正使用指令。AcrossVAM 试图用显式粒子动力学、因果外观支路和语言对照统一解决这三点。问题对视频世界模型和具身规划直接相关，但论文只做短时视频预测，尚未展示控制闭环收益。

## Method

1. 输入 4 帧 $128\times128$ context 与自然语言指令，预测未来 5 帧。冻结的 SAM3-DLP codec 借助 VRS part masks，把每帧分成 whole robot、arm、gripper 三个语义粒子及空间背景 latent；每个粒子含位置、尺度、深度、存在度和 appearance。
2. 对无序 proposal，以位置和 appearance cosine cost 做 Hungarian matching；实际离线 VRS cache 已有固定 part ID，因此主实验绕过 matching。粒子 dynamics 输入显式几何、位置/尺度一阶速度、slot/time embedding，不把 appearance 留作动态捷径。
3. 宽 64、2 层、4 heads 的 0.28M 参数 causal spatio-temporal Transformer 在 slot 内做时间推理、slot 间做部件交互，并自回归预测 5 个 future residual states。冻结 OpenCLIP ConvNeXt-L/320 提取指令，零初始化 FiLM 在各 block 调制粒子状态；损失同时监督 one-step transition 与 autoregressive rollout。
4. 冻结 particle renderer 将预测粒子与 context background 渲染为低细节 RGB proposal $r_t$ 和 alpha。另一支只编码最后观察帧 $x_C$，DiffPrior 根据 context appearance、当前/未来 particle render 和时间步预测 dense detail；residual refiner 生成候选 $g_t$。
5. learned causal mask 用预测 alpha motion 与候选分歧等推理期可用量，在 $g_t$ 与 persistence $x_C$ 间逐像素混合。训练使用 $L_1$、SSIM、LPIPS 与 motion-region 加权；future RGB/mask/detail 只作 target 或 oracle，不进入推理。完整可训练 future stack 约 9.5M 参数，但冻结 SAM3-DLP 和大型 OpenCLIP 不计入“轻量”口径。

创新是将语义粒子动力学与 context-only dense appearance delivery 明确分责，并用 causal mask 呈现运动/静态画质的取舍；Transformer、FiLM、Hungarian matching、particle renderer 和 residual blending 本身均为既有组件，属于有针对性的系统组合。

## Experiment

- VRS 从 DROID-style 多机器人轨迹整理 2,746 clips，固定 manifest 为 2,526/106/105 train/val/test，另排除 9 条；9 帧窗口 stride 3，观察 4 帧、预测 5 帧。视频测试实际用 92 clips/460 future frames，trajectory 诊断用 368 windows，覆盖 Franka、WidowX、Mobile ALOHA、Google Robot、Fanuc、Sawyer、UR5 等。
- 指标含全帧 PSNR/SSIM/LPIPS、dilated motion/foreground PSNR 和粒子 trajectory error；persistence 为最后帧复制，ground-truth particle 与 per-pixel selection 是不可部署上界。checkpoint 与阈值在 validation 选，test 只评一次。
- 主表（Table 1，PDF 第 6 页）：persistence 为 19.97 PSNR、0.796 SSIM、0.122 LPIPS、11.89 motion PSNR；raw particle generation 为 19.93/0.763/0.138/13.23；最终 DiffPrior 为 $20.573\pm0.009$、$0.8004\pm0.0002$、$0.1304\pm0.0004$、$12.870\pm0.032$。即 PSNR/SSIM 与 motion PSNR 均改善，但 LPIPS 仍比复制基线差 0.0084。
- 三个 seed 只重新初始化并训练 delivery mask；particle rollout、appearance feature 与 DiffPrior candidate 完全共享，因此方差仅证明交付阶段稳定，不是端到端复现。per-pixel oracle 为 22.12/0.833/0.114/14.09，说明 mask calibration 与 candidate quality 仍有明显余量。
- 表征/动力学消融（Tables 5/7，第 8-9 页）：particle codec 加 $32\times32\times4$ residual code 后重建 PSNR 从 20.94 升至 27.95；残差 box+appearance dynamics 仅比 persistence 降误差 3.9%，clean box、stride 3、去 appearance shortcut 依次升至 15.1%、18.5%，最终模型为 21.0%（3 seed 范围 20.6-21.4%）。
- 语言控制（Table 6）：正确文本相对 shuffled text 的 trajectory-error gap 为 2.8%，规则修订文本 3.1%，VLM caption 2.9%；kinematic pseudo-text 与 random label 仅 0.3%/0.2%。方向上存在语义信号，但低于作者预设 10% 目标。
- 跨机器人诊断：Franka +21.1%（136 windows）、WidowX +19.0%（68）、UR5 +18.4%（8），但 Mobile ALOHA -16.1%（60）、Google Robot -5.2%（32）、Fanuc -9.0%、Sawyer -12.9%；non-Franka 聚合仍 +10.0%，严格 leave-one-robot-out Mobile ALOHA 不胜 persistence。
- 最大口径限制是缺少同协议公开模型数值。LPWM-Language、TextOCVP、FitVid、DDLP、SlotFormer 只列在 reproduction queue（Table 2），尚未完成 VRS 的 4-context/5-future 重训；当前定量比较实质上只有 persistence、内部消融和 oracle。

## Value

工作提供了一个实用的职责分解：把 object-centric state 当作可检查的运动接口，把纹理当作受 context 约束的独立生成问题，并同时报告全局与运动区指标，避免复制基线掩盖失败。对机器人视频世界模型，粒子轨迹还适合作为规划或不确定性估计的中间层。当前模型更像短期、语义部件监督下的视频 predictor；没有动作输入、物体交互状态或闭环控制评测，指令也尚不足以决定未来，因此不能视为通用 video action model。

## Strengths

- 运动/外观分工清楚，外观支路只看最后一帧，并有 leakage audit，因果输入边界明确。
- 同时报告 persistence、raw generation、learned mask 和 oracle，能量化静态画质与运动保真的真实取舍。
- 去 box residual、stride、appearance shortcut、语言 shuffle/random control 等消融与设计动机对应。
- 不把三 seed delivery sweep 写成端到端稳定性，也主动报告 LPIPS 退化、语言弱作用与跨 embodiment 失败。
- 0.28M dynamics core 和显式三个部件轨迹便于诊断，相比 monolithic pixel model 更透明。

## Weaknesses

- 最强证据缺口是没有任何已复现的同协议公开基线；只赢 persistence 不能说明相对 FitVid、SlotFormer、DDLP、TextOCVP 或 LPWM 的竞争力，Table 2 仍是计划而非实验。
- 全局 PSNR 仅提高 0.60 dB、SSIM 提高 0.0044，LPIPS 反而更差；三 seed 又共享全部上游 checkpoint，无法给出训练端到端方差或显著性。
- 语言 shuffle gap 只有约 3%，场景运动前缀和数据先验仍可能主导未来；方法不接收数值 robot action，不能证明指令级可控动力学。
- 只预测 5 帧、分辨率 $128^2$，且 codec 构建依赖 whole-robot/arm/gripper masks 与固定 part ID；主实验没有验证 proposal matching 在真实无序输入中的效果。
- VRS 是作者构建的固定数据协议，实际 future-video test 仅 92 clips；跨机器人表现正负混杂，严格留出 Mobile ALOHA 失败，泛化结论有限。
- “0.28M 轻量”只指 dynamics core；完整可训练栈约 9.5M，部署还包含冻结的大型 SAM3-DLP 与 OpenCLIP，内存和时延未报告。

## Future Work

作者明确提出学习 uncertainty-aware blending、收集 counterfactual instruction pairs、用 proposal-time segmentation 取代 mask supervision，并以闭环控制而非仅视频指标评估；限制部分也把 appearance delivery、语言依赖和跨机器人迁移列为主要改进方向。

合理推断但尚未完成的优先项是：先完成 Table 2 的同 split 基线复现与完整端到端多 seed；加入真实 robot action 和多种可冲突指令，测 instruction intervention；扩展预测时长/分辨率，去除人工 part mask 与固定 ID，并报告推理延迟、轨迹不确定性和规划收益。

## Rating

创新度评分：3/5 - 语义粒子动力学与因果外观交付的解耦有一定系统创新，但主要由既有组件组合，且短时、弱语言与缺基线限制说服力。
相关度评分：3/3 (Core) - 直接研究机器人视频未来预测、对象中心世界状态和语言条件动力学，属于视频世界模型核心方向。

## TL;DR

以语义粒子预测运动、因果外观支路补纹理；运动有益但语言与基线证据薄弱，建议精读方法。
