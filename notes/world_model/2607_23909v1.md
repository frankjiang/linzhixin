# WorldDiT: A Unified Diffusion Architecture for World and Action Modeling

## Insight
有。论文的 observation 是：强机器人控制不一定来自大 VLM action backbone；一个统一 DiT 同时学习 action flow 和未来视觉 patch flow，也可能提供足够的 world/action coupling。推论是 future RGB patch prediction 可以作为训练期辅助监督，推理时保留 action-only 路径，从而构建较小参数量的 WAM baseline。

## Motivation
论文解决 robot policy 中“动作生成能力到底来自大预训练 VLM 还是动作/世界模型架构”的混淆。很多方法把动作头接在数十亿参数 VLM 上，难以判断规模、预训练和 policy design 的贡献。WorldDiT 试图提供一个无大型 VLM action backbone 的 sub-billion baseline。

## Method
WorldDiT 使用冻结 MAE 图像编码器、Perceiver Resampler、冻结 CLIP text encoder 和可训练机器人状态 encoder，把最近 3 个观测步编码成 clean context token。一个共享 DiT backbone 接收加噪的 7-step continuous action chunk 和未来 primary/wrist camera 的 normalized RGB patch tokens，使用 flow matching 同时预测 action velocity 和 RGB patch velocity。

训练时 action target 和 future RGB patch target 共享扩散/flow matching 形式；未来 RGB patch 只提供辅助世界建模监督。推理时不输入 RGB target、不跑 RGB head，仅从高斯噪声积分生成 7 步 action chunk，执行前 3 步后 receding-horizon replan。

## Experiment
实验在 LIBERO 上：先用 libero_90 预训练 30 epoch，再分别在 Spatial/Object/Goal/Long fine-tune。WorldDiT backbone 约 depth 4、hidden 1024、16 heads，总参数 399M，其中 trainable 135M。

结果：Spatial 98.0、Object 97.0、Goal 92.8、Long 91.8，平均 94.9。作者把 24 个方法按总参数和四套 LIBERO 平均成功率作图，WorldDiT 位于 reported Pareto frontier；在无大 VLM action backbone 方法中高于 DreamVLA 92.6、FlowVLA 88.1、DiT Policy 82.4 等。

## Value
价值是提供一个紧凑、统一的 diffusion world/action baseline，并支持“训练期世界预测，推理期 action-only”的设计。对我们有启发的是：未来视觉预测可以只作为 representation shaping objective，不一定作为推理时 planning 模块。但论文没有深入分析 RGB patch objective 到底学到了什么。

## Strengths
架构简单清楚；参数量和成功率 tradeoff 讨论有用；action 与 future visual target 统一到 flow matching；推理图去掉 RGB 分支，部署路径简洁。

## Weaknesses
论文承认 94.9% 包含每 suite 300 个用于 staged checkpoint selection 的 episode，不是完全无偏测试估计；与其他方法多为 reported score 比较，协议未统一；缺少关键消融，如无 RGB patch objective、不同 patch target、不同 horizon；只在 LIBERO 仿真，没有真实机器人。

## Future Work
作者提出未来研究 normalized future RGB objective 如何影响控制、该参数-成功率 tradeoff 是否随规模保持，以及将共享 flow formulation 分解为独立专家以适配异构硬件/受限平台。

## Rating
创新度评分：3/5 - 统一 DiT action+world objective 是有用 baseline，但创新主要在整合和工程设计，证据边界需谨慎。
相关度评分：3/3 (Core) - 直接研究机器人 world-action modeling 和未来视觉预测。

## TL;DR
用单个DiT同时学动作扩散和未来RGB patch预测，核心相关但证据需谨慎，建议选读。
