# Aegis-VLA: Reliability-Gated Action Refinement via a Trajectory World Model for Dynamic Object Manipulation

## Insight
准确预测目标运动不代表应修改原 VLA 动作；原动作可能已提前补偿目标位移。论文观察朴素残差适配器可使成功率从 45.44% 降至 22%，因此把「提出修正」与「是否采用修正」分离。门控推理消融显示直接放开已拒绝残差会显著损害任务表现，但不能证明每次被接纳修正都有因果收益。

## Motivation
动态物体操纵中推理和执行延迟造成目标/末端轨迹错位。现有预测引导方案可能生成或重排动作，却难判断修改已较可靠的基座动作是否有益；需要小规模、可选择的预测式修正。

## Method
冻结 DynamicVLA，另用双视角 RGB 加 0.32 秒末端位姿历史编码运动上下文。轨迹世界模型用常加速度外推加学习残差预测未来 0.64 秒目标位置/速度，并以异方差 NLL 估计位置不确定性。另两支分别仅用历史、及结合基座动作预测未来末端轨迹，二者差值与动作、上下文生成有界手臂残差；夹爪动作保留。门控按候选动作相对示范动作的误差改善、预测精度标签学习逐步准入，推理再用历史有效性、预测不确定性和目标-末端接近程度缩放。总体是轨迹预测加选择式 VLA 残差控制，非通用视频生成世界模型。

## Experiment
DOM 仿真训练约 20 万条示范，测试 9 维度×10 配置×20 次=1800 次；指标包括任务成功率、末端路径长和名义时长。Aegis-VLA 成功率 56.72%，复现 DynamicVLA 为 45.44%；动态适应 32.5→59.5%，运动感知 38→63.5%，长序列维度仍为 34.5%。独立训练的无门控差异修正为 48.11%，加目标预测为 50.56%，完整门控为 56.72%。对同一完整模型取消准入降至 51.33%，将所有残差固定放大降至 17.78%。附加参数 2.45M，离线每 20 动作块推理延时 227.06→239.31 ms（+5.4%）。

## Value
为用世界模型辅助现有策略提供具体教训：预测信息应先决定修正是否可靠与有益，并保留原策略动作作为回退；对动态操纵的轻量世界模型接口有参考价值。

## Strengths
清晰区分修正提议和准入；有独立训练的无门控对照及同检查点推理消融；报告延时/参数开销与多维度任务表现。

## Weaknesses
只有单次仿真评测，较小消融差异无重复运行置信区间；示范动作误差改善不等同任务成功或最佳接触时机。不确定性校准及运动分布外泛化未检验，短时轨迹模型未提升长序列成功率。

## Future Work
作者计划在实体机器人及目标运动、可见性和执行动力学偏移下检验选择式修正，尤其研究预测证据不可靠时的行为。

## Rating
创新度评分：2/5 - 轨迹外推、残差动作和可靠性门控组合合理，但基本方法均属增量。
相关度评分：2/3 (Related) - 以显式目标轨迹预测辅助 VLA，能借鉴世界模型到动作的接口，非核心视频/3D生成模型。

## TL;DR
小型轨迹世界模型先提出动态目标动作修正，再按收益与不确定性选择执行；策略与世界模型耦合可选读。
