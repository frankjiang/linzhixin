# Active Inference as a Convex Markov Decision Process

## Insight
核心 insight 是把固定 world model 下的 Expected Free Energy (EFE) 写成 occupancy measure 上的凸目标：线性项对应偏好/ambiguity/recognition cost，唯一非线性项是状态边际的负熵。由此可把 Active Inference 的 planning phase 放进 convex MDP 框架，并用 mirror descent 转成一系列带策略依赖 reward 的 soft RL 子问题。作者还观察到一旦 world model 随策略诱导数据重新训练，AIF 就变成 performative RL。

## Motivation
Active Inference 和 Dreamer/MBPO 类方法在工程结构上相似：先学 generative/world model，再在想象 rollout 中优化行为。但 AIF 的 EFE 优化缺少 RL 中常见的存在性、收敛和 policy improvement 理论。本文解决的是理论地位问题：EFE 到底是什么优化问题，能否接入凸 MDP、动态规划和自然策略梯度工具。对隐式 world model/RL 理论有参考价值，但不直接处理视频或 3D 表征。

## Method
作者采用 episodic AIF，把流程拆成 VFE world-model learning 和 EFE policy optimization 两步；行为策略写成 beta=pi o nu，即先由 recognition density 推断 latent state，再由 latent policy 行动。对固定模型 m=(p,nu)，定义 causal imagined trajectory law，并将 EFE 化为 G(pi)=<ell,mu_pi>+Phi(mu_pi)，其中 mu_pi 满足 Markov flow constraints，Phi 是负状态边际熵。核心证明包括：occupancy polytope 上 EFE 是 convex MDP；history-dependent 情形可通过增广状态恢复该结构；discounted/average infinite horizon 需要区分先聚合再算熵与先算熵再聚合。算法上给出 MD-AIF，用 conditional negative entropy 作为 Bregman generator，每步线性化 EFE 并用 soft Bellman backup 得到 multiplicative policy update，证明固定模型下 O(1/K) 收敛。闭环部分把 m*(D(pi)) 引入 performative mirror operator，并用 Brouwer fixed-point 证明稳定 policy-model pair 存在。

## Experiment
实验是小规模 deterministic gridworld。5x5 goal preference 任务中比较 MD-AIF、去掉 novelty 的 entropy-regularized RL，以及 Euclidean EFE gradient descent；MD-AIF EFE 下降更快、接近 O(1/k)，occupancy 先扩散探索再集中到目标。10x10 uniform preference 任务中，EFE 变成 pure epistemic drive；交替 model refitting 后，MD-AIF 的 state coverage 更广，mean total-variation model error 比 RL、EFE gradient descent 和短视 AIF planning 降得更快。实验主要验证结构预测，不是大规模控制或视觉世界模型实验。

## Value
价值在于给 Active Inference 和现代 model-based RL 建桥：EFE 的 epistemic drive 可以被理解为 occupancy 上的凸非线性，也可以实现为策略依赖 novelty reward。对研究 Dreamer/隐式 world model 的理论化有启发，尤其是把 world-model learning 和 policy optimization 解耦后分析。待解决的是深度函数逼近、非表格环境、真实闭环 performative convergence，以及 preference/model misspecification 下的稳定性。

## Strengths
理论分解清楚，把 EFE、convex MDP、mirror descent、natural policy gradient 和 performative RL 串成统一框架；证明给出固定模型下的收敛率；也明确指出闭环模型重训后问题会复杂化，而不是把固定模型结论过度外推。

## Weaknesses
实验只在 gridworld 上验证趋势，不能说明 deep world model 或高维连续控制中的收益。主要证明依赖有限状态、固定模型、full support 等假设；真正 AIF 闭环只证明固定点存在，未证明迭代收敛或稳定到正确环境模型。与视频/3D 世界模型的连接偏理论和间接。

## Future Work
作者明确把 performative AIF 的收敛分析留给未来，建议可能通过 dataset aggregation/online learning 或 delayed repeated retraining 处理。还需要将 MD-AIF 推广到函数逼近、历史状态摘要和实际 actor-critic 实现。
