# Pixels to Proofs: Probabilistically-Safe Latent World Model Control via Parallel Conformal Robust MPC

## Insight
核心观察：latent world model 用于控制时，安全不能只靠 nominal rollout；需要对 latent dynamics error、support 和 constraint checker error 做校准不确定性传播。作者用 conformal prediction + system level synthesis 给 latent MPC 加概率安全 tube。

## Motivation
视觉控制中的 latent world model 规划高效，但模型误差会导致违反约束。传统安全控制多在真实状态空间，难以直接用于高维像素/latent 表征。问题对隐式 world model 控制很关键。

## Method
学习 compact Markovian latent world model，支持多步 rollout 与 gradient-based trajectory optimization。用 conformal prediction 校准 latent dynamics error、in-domain latent support、latent safety classifier error；再把校准集合放入 GPU-accelerated SLS，执行 reachability-constrained robust MPC（SLS2）。Nominal 时退化为 iLQR 式 latent planning。

## Experiment
任务包括 Reacher、OGBench Cube、Push-T、双臂 rope。与 Le-WM、DINO-WM、PLDM 以及 HJ-filtered、LPB 等安全基线比较。Reacher 消融中 full model+iLQR 成功率 83.5%，non-Markov history-2 仅 1%，single-step loss 24.5%，CEM planner 57%。Nominal 和 robust setting 下均提升 success/safety/robust success。局限是 Push-T 等复杂序列任务受 latent Euclidean goal distance 限制。

## Value
很有价值：把“latent world model 控制”与概率安全证明连接起来。对机器人/隐式 world model 的评估和部署有启发，建议精读方法。
