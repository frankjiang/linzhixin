# Gamma-World: Generative Multi-Agent World Modeling Beyond Two Players

## Insight
多智能体视频世界模型中，智能体身份应满足**置换对称性**——在共享世界中具有相同能力的智能体不应因占据不同 slot 而被区别对待。Observation：现有方法（如 Solaris）使用 learned per-slot ID embedding，导致 agent 数量增长时二次复杂度且破坏对称性。推论：将 agent 表示为旋转角空间中正则单纯形的顶点（Simplex Rotary Agent Encoding），可实现无参数、等距、置换等价的 agent 编码，并可零样本泛化到更多 agent。实验证明从2人训练可直接推广到4人。

## Motivation
解决视频世界模型从单智能体扩展到多智能体的问题。现有方法要么用 dense joint attention（O(P²n²L²)复杂度），要么用 learned per-slot embedding（破坏对称性、无法扩展 agent 数）。核心问题确实关键：交互式仿真（游戏、机器人协作）本质上是多智能体的。

## Method
整体管线：基于 DiT 的 latent video diffusion，增加显式 agent 轴。
- **Simplex Rotary Agent Encoding**：在 3D RoPE 基础上增加 agent 维度，将 agent 映射到 d_p/2 维空间中正则单纯形顶点，实现等距+置换等价的无参数编码。
- **Sparse Hub Attention**：引入可学习 hub token 作为跨 agent 信息中介，agent token 只 attend 同 agent + hub，跨 agent 交互通过 hub 中转，复杂度从 O(P²) 降至 O(P)。
- **三阶段训练**：(1) 双向 teacher 训练获得高质量分布；(2) Diffusion Forcing 训练因果 student；(3) Self-Forcing 蒸馏为 few-step 因果生成器，支持 KV cache 流式推理，24 FPS。
创新度较高，Simplex RoPE 是优雅的数学设计，Sparse Hub Attention 实用。

## Experiment
- 对比 Frame Concat、Solaris 基线，在 Memory/Grounding/Movement/Building/Consistency 五类场景均大幅领先（FVD 184.1 vs 333.8）
- 架构消融验证 Simplex Encoding > View Embedding > None，Sparse Hub > Full attention（质量相当但效率大幅提升）
- 效率：8 agent 时 Dense attention 的 DiT latency 611ms vs Sparse Hub 246ms，FLOPs 差距更大（7.6T vs 981G）
- 零样本从2人泛化到4人成功
- 真实机器人双臂协作场景也有验证

## Value
工作价值高。首次系统性地解决多智能体视频世界模型的可扩展性问题，Simplex RoPE 和 Sparse Hub Attention 两个设计均可被其他多智能体视觉生成工作复用。启发：位置编码设计空间远不止线性索引，几何结构可编码对称性先验。待解决：真实物理场景的多智能体一致性、更多 agent（>8）的验证。

## Strengths
亮点是首次系统性地解决多智能体视频世界模型的可扩展性问题，Simplex RoPE 和 Sparse Hub Attention 两个设计均可被其他多智能体视觉生成工作复用。
