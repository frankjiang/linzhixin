# Slots, Transitions, Loops: Learning Composable World Models for ARC

## Insight
论文把 ARC 视为“视觉符号世界状态上的规则转移”，而不是语言描述或程序搜索。关键 observation 是 ARC 的颜色、对象、空间关系可以形成 object-centric state；推论是 recurrent transition model 应该显式建模状态更新。证据来自 ARC-1/ARC-2 结果和消融：dense transport 与 slot-conditioned write 两条路径互补，单独使用都不如组合。

## Motivation
ARC 测试 few-shot rule induction。主流路线偏 LLM、程序合成或通用 ViT/recurrent ViT，缺少对“对象状态如何按规则变化”的归纳偏置。该问题对世界模型研究有一定价值，因为它是一个受控的、离散的 compositional dynamics 场景，但与视频/3D/机器人物理世界模型距离较远。

## Method
Loop-OWM 包含 object-centric interpreter、task encoder、looped transition model 和 decoder。用 color-prototype 初始化 Slot Attention，让 slot identity 锚定 ARC 颜色；任务 encoder 用 demonstration input/output 对生成 summary tokens；transition module 循环更新 query grid state。状态更新分两路：dense patch-to-patch transition matrix 负责空间传输，slot-to-grid mixer 负责对象级内容写回，最终 H_{t+1}=P_t H_t + alpha_t R_t。还提出 slot-mediated transition target 和 composed transition supervision，使多步 rollout 的总迁移与输入到输出对齐。

## Experiment
数据为 ARC-1、ARC-2，使用两阶段训练：offline procedural augmentation，再对每个 test task 做 task-time adaptation 和多视角增强投票。Loop-OWM 32/1 在 ARC-1/ARC-2 为 67.3/20.2，64/2 为 68.5/22.5，优于 compact neural baselines 如 LoopViT-L 65.8/14.2，但远低于强 LLM/human。消融显示 complementary update 最好；per-task/hybrid summary 比 shared-only 更强，说明 test-time task memory 仍重要。局限是 loop step 没有稳定可解释语义，需要中间状态监督。

## Value
作为“离散对象世界模型”有参考价值：slots + transition + recurrent rollout 是清晰的归纳偏置。但它主要服务 ARC，不涉及视频生成、3D 表征或物理控制；对用户方向是间接启发，不能按核心视频世界模型论文看。
