# Reinformed Dreamer: An Asymmetric World Model Efficiently Trained through Latent Guidance

## Insight
有。论文的 observation 是：Informed Dreamer 用 observation encoder 训练 privileged information likelihood，ELBO 对真实 log-likelihood 的下界通常很松；当 observation 不含足够 privileged information 时，privileged latent 容易退化成均值式表示。推论是：训练时应显式引入 privileged encoder 来收紧 ELBO，再通过 prior/latent KL 把该 privileged latent guide 到执行时可用的 unprivileged encoder。作者用 Informed ELBO tightness gap 和 Reinformed ELBO 的推导证明该目标更贴近 privileged information likelihood。

## Motivation
论文解决 asymmetric model-based RL 中“训练时可见额外状态信息、执行时只能用 observation”如何高效训练 Dreamer world model 的问题。Informed Dreamer 只用一个 observation-conditioned encoder 去预测 privileged information，理论上无法充分利用比 observation 更丰富的 state/info；Scaffolder 用两个 world model 和 decode-reencode imagination，性能强但计算重。该问题对 Dreamer/RSSM 类隐式世界模型直接相关，尤其是部分可观测控制下的 representation learning。

## Method
方法基于 informed POMDP。Informed Dreamer 的 RSSM 用 observation encoder `q(e|z,o)`、recurrent state `z`、prior `p(e|z)`，预测 reward 和 next privileged information。作者指出其 ELBO tightness gap 包含 conditioning gap 和 information gap：variational posterior 只看 observation，缺少 reward/next information。

Reinformed Dreamer 增加 privileged encoder `q(e_tilde|z,i)`，训练时用它构造更紧的 reinformed ELBO；同时保留 unprivileged encoder `q(e|z,o)` 以便部署。latent guidance 通过 KL 关系让 prior 匹配 privileged encoder，unprivileged encoder 再匹配 prior；最终还加入 unprivileged encoder 的 reconstruction-style loss，用同一 reward/info decoder 增强监督。imagination 和 policy execution 与 Dreamer 保持不变，所以仍是单 world model，而不是 Scaffolder 式双 world model。

## Experiment
实验覆盖三组 informed POMDP：Varying Mountain Hike、Pop Gym、Velocity Control。privileged information 分别是精确位置/朝向、完整状态、关节位置等；baseline 包括 Uninformed Dreamer、Informed Dreamer、Scaffolder。所有结果 5 个 seed，训练 100 万步。

总体结果：Reinformed Dreamer 在多数环境上优于或匹配 Uninformed/Informed Dreamer，和 Scaffolder 接近；少数 Velocity Control 和 Mountain Hike 环境 Scaffolder 更强。运行时间方面，Reinformed Dreamer 约为 Uninformed/Informed 的 118%-122%，而 Scaffolder 为 182%-217%，说明性能/计算折中更好。

## Value
价值在于把 asymmetric Dreamer 的“为什么 privileged information 没被充分利用”形式化为 ELBO looseness，并给出简单有效的 latent guidance 修正。对我们有启发的是：在世界模型训练中，privileged state 不一定应该直接替换 observation encoder；更合理的是训练一个训练期 teacher latent，再约束执行期 latent 与其对齐。

## Strengths
理论推导清晰；方法改动相对小，保持 Dreamer imagination/actor-critic 管线不变；与 Scaffolder 相比只增加一个 encoder，不需要额外 privileged world model 和 observation decode-reencode；实验覆盖部分可观测、记忆、连续控制多类任务。

## Weaknesses
实验仍是标准控制套件，不涉及视觉视频世界模型或复杂 3D 场景；对“为什么少数环境不如 Scaffolder”的分析较浅；privileged information 的形式较理想化，真实机器人/视频任务中 privileged state 获取和噪声未讨论；没有对 latent guidance 各项 loss 做充分消融。

## Future Work
作者主要提出需要在更有挑战性的任务上继续验证。自然后续包括更复杂视觉控制、不同 privileged information 噪声/粒度、latent guidance 消融，以及与双 world model 或 asymmetric critic 的组合。
