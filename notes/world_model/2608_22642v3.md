# Mol-JEPA: A multimodal Joint Embedding Predictive Architecture for Molecules

## Insight

分子结构的微小改动可能造成 property cliff，因此“删原子/键后仍应表示相近”是危险的不变性假设。论文改为遮蔽完整、具有真实语义的模态，并从其余模态预测 latent：不伪造化学结构，而把细胞表型、量化计算、结合、ADMET 等视作同一分子在不同环境中的观测。结果显示全模态相对 Graph+ECFP 将 linear/nonlinear probe MAE 降低 14%/13%，说明跨模态冗余可成为自监督信号；但这仍是静态跨模态表征学习，不是带动作和时间演化的世界模型。

## Motivation

分子 SSL 常依赖可能化学无效的结构增强，contrastive 方法又受负样本、modality gap 与稀疏配对影响；只看结构也无法表达细胞环境、代谢和靶点相互作用。该问题对分子性质预测重要，尤其是小数据和 activity cliff 场景。对用户关注方向的意义主要在 JEPA 的“用自然模态遮蔽替代人工 augmentation”设计，而非分子应用本身。

## Method

作者合并 4.69M unique compounds，构造 14 种模态：UMA/ChemGPT/CLOOME/BioXMol/Boltz-2、GNN、MOE/ECFP/xTB/$\nabla^2$DFT，以及 ChEMBL/PCBA/TDC 实验向量。atom、graph、vector 三类 encoder 将可用模态投影到共同维度；以 0.3 masking ratio 随机遮蔽可用模态并保证至少留一个上下文，约 50M 参数 Transformer 从 mask token 和其余模态预测被遮蔽 embedding，CLS 用于下游。目标为逐模态 latent MSE 加 $\lambda=0.7$ 的 SIGReg；后者以 1,024 个随机一维投影逼近各 target embedding 的各向同性高斯，防止 collapse。下游使用 linear/nonlinear、TabICLv2、两层 Transformer 聚合、LoRA 或 full fine-tuning。

## Experiment

在 ExpansionRx、ASAP/Polaris、PXR、Biogen ADME 共 23 个回归任务上，以 3 个 Butina cluster splits 比较 RF/LGBM、Chemprop、CheMeleon、CLAMP 和 TabICLv2（PDF pp.6–8）。Table 3 的平均 MAE 为 Mol-JEPA Best 0.402、固定 Transformer probe 0.427、TabICLv2 0.453、CheMeleon 0.471、Chemprop 0.519、CLAMP 0.576；平均 $R^2$ 为 0.42，次优 TabICLv2 0.37（p.21）。不过“Best”逐任务从多种 embedding/probe 中取最优；按 FDR-corrected Wilcoxon 的 pairwise win rate，Mol-JEPA 为 38%，低于 TabICL+AlvaDesc 的 47%，且官方时间 split 上 TabICL 的 Wilcoxon/MAE win rate 更高（pp.7, 21）。100k 子集消融显示：全模态 linear/nonlinear MAE 0.436/0.393；semi-supervised 0.467/0.417；去实验模态 0.449/0.407；SIGReg on CLS 0.445/0.406；加 projection head 恶化至 0.468/0.488；维度 256/512/1024 的 nonlinear MAE 为 0.465/0.393/0.397（pp.23–24）。完整训练用 12×RTX-6000 Ada、约 3 天/150 epochs（p.19）。

## Value

对科学多模态表征，论文给出数据规模大、接口可扩展且避免负样本的 JEPA 配方；对隐式世界模型研究，可借鉴“遮蔽真实观测模态、逐模态防坍塌、显式分析模态冗余”。但其任务是静态分子性质回归，没有 action、transition、rollout、planning 或时间动力学，把它称为 molecular world model 更多是宽泛命名，不能直接支持视频/3D 世界模拟结论。

## Strengths

- 预训练数据、14 种模态、缺失模态机制和计算需求披露较详细，代码与 checkpoint 可用。
- 使用盲挑战数据、cluster/官方时间 splits、多种经典与 foundation baselines，并做 FDR-corrected 配对检验。
- 消融覆盖实验模态、semi-supervised 替代、SIGReg 位置、projection head、embedding 维度、模态数量与数据规模。
- 主文不掩盖负结果：承认 TabICL 的显著胜率更高、稀疏模态难训、CLOOME 有时降低性能、LoRA 欠佳。

## Weaknesses

- “world model”缺少通常定义中的状态转移与动作条件；实验只评估静态属性回归，结论中“reason about physical dynamics”没有 rollout 或动力学证据（pp.10–11）。
- 未见对 4.69M 预训练分子与下游测试分子的严格结构去重/标签隔离审计；文中反而显示测试误差随其对预训练库的相似度变化，因此所谓 OOD（相对下游 train）可能仍包含预训练暴露，削弱泛化归因。
- 主表的 Mol-JEPA “Best”在每个任务跨 probe/embedding 变体选最优，存在多重模型选择优势；固定 Transformer 版本平均 MAE 0.427，与 TabICL 0.453 的差距更小，官方 split 的 MAE/Wilcoxon 胜率还落后。
- 大部分架构消融只在 100k（全量约 2.1%）上进行，作者亦承认可能影响结论；完整规模仅验证 all modalities 对 Graph+ECFP，无法保证小集排序外推。
- 多个输入来自冻结的强模型、昂贵计算和商业工具（MOE、MoKa），性能提升混合了 JEPA 学习、教师蒸馏、实验标签和数据覆盖，缺少同数据同容量的 masked-concatenation/autoencoder 强基线。
- 模态极度稀疏，例如 Boltz 仅约 102k/4.69M；简单逐模态平均损失与固定 mask 未建模可预测性方向，训练曲线也显示不稳定。

## Future Work

- 作者明确提出：建模模态间不可恢复的方向性依赖与更高级 masking；测试更远的分子/任务/分布 OOD；理解稀疏度、维度、信息量和冗余对训练的影响；改进模态选择（pp.10–11）。
- 我们推断：需要跨预训练/测试严格去重，使用固定 probe 做预注册式比较，并加入真实反应/轨迹或干预任务，才能支撑“world model”而非表征模型定位。

## Rating

创新度评分：2/5 - 将 modality masking 与 SIGReg JEPA 扩展到大规模分子多模态有工程贡献，但核心架构是既有方法的领域化组合。
相关度评分：1/3 (Tangential) - 直接使用 JEPA 思想，但属于静态分子/药物发现，不涉及视频、3D 或可行动力学世界模型。

## TL;DR

Mol-JEPA用整模态遮蔽整合14类分子信息，性能强但并非时序世界模型；仅对JEPA设计有参考，可选读。
