# When Does Depth Survive Composition? Compute-Quality Regimes in Latent World Models

## Insight
核心 insight 是：更深 predictor 的单步精度优势不一定能在 autoregressive composition 中保留下来，甚至会反转。原因与任务随机性、训练 overshooting、度量空间和 planner 路由有关；因此 adaptive compute 不能只看单步 exit 误差。

## Motivation
latent world model 常引入 early exits、mixture depth 或 adaptive compute，假设深层预测更准、浅层更快。但在规划中模型会递归使用自己的预测，误差组合可能改变深浅层排序。论文要测定“深度什么时候真正有用”。

## Method
作者设计 shallow penalty `rho = err(shallow rollout) / err(full-depth rollout)`，H=10；rho>1 表示深层有用，rho≈1 表示 flat，rho<1 表示 inversion。实验比较 K=1 单步训练与 K=4 latent overshooting，在 9 个 DeepMind Control 任务、3 seeds 上评估，并进一步做 early-exit supervision、度量空间、表示和 CEM planning 消融。

## Experiment
9 个任务中 6 个为 intrinsic depth-help，如 finger-turn_hard rho 4.74，acrobot 3.34→7.46；2 个 inversion，如 cheetah rho 0.85/0.87；1 个 flat。原假设“K=4 会产生 tradeoff”未成立。只在第一个 rollout step 监督 early exits 可消除 cheetah inversion，但 intrinsic 任务不受影响。CEM planning 中 cartpole/acrobot 深层更好，cheetah inversion 下 shallow return 7.24 高于 deep 6.58。观察维度、动作维度和一步误差与 rho 的 Spearman 约 0.75。

## Value
对 latent world model 评估很有帮助：它提醒我们不要默认“更深/更准/更多计算”在 rollout 后仍更好。若做 JEPA/Dreamer 风格模型的 adaptive compute 或 router，这篇提供了实验范式和失败案例。

## Strengths
问题具体，指标 rho 简单有效；覆盖多个任务、训练目标、度量空间和规划验证；诚实报告失败假设。

## Weaknesses
主要是 state-based DMC 和 MLP encoder，像素设置会改变结论；样本任务数和 seeds 有限；部分因果结论只在 cheetah 上建立。

## Future Work
作者没有给出大型路线图，但明确限制指出应扩展到像素/更复杂机器人任务，改进 inversion 判据，扩大相关性分析样本，并更完整验证 router 在 planning 中的作用。

## Rating
创新度评分：3/5 - 不是新范式，但对 latent world model 深度/组合误差的系统实证有价值。
相关度评分：3/3 (Core) - 直接研究 latent world model 的 rollout 与规划质量。

## TL;DR
实证表明 latent world model 的深度优势会随任务和度量反转，评估/路由前值得精读。
