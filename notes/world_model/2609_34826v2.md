# WM-VLM: Probing Internal World Models for Interleaved Visual-Textual Reasoning

## Insight
观察：VLM 可用文字描述旋转，却未必保存足够的中间视觉状态；反过来，生成逼真的视觉 latent 也不保证会拿来推理。推论：先学动作条件视觉状态预测，再用**自身生成**的状态训练答案推理，才能形成有效的视觉—文字交替链。论文以中间真值可验的二维/三维旋转任务、两阶段与单阶段对照、将生成 latent 置零/随机化等干预验证；置零时二维 ID 准确率 87.5%→14.0%，证明输出依赖这些 token，但不能证明它们等同真实物理状态。

## Motivation
普通 VLM 中间推理主要在文本空间；已有视觉草稿多裁剪原图，外部世界模型又把状态预测交给另一个系统。问题是 VLM 自身能否生成并利用动作后的隐式视觉表示，改善空间推理。这与隐式世界模型方向直接相关，但本文任务是合成心智旋转，尚非具身动力学。

## Method
在 Qwen2.5-VL-7B 上增设四层轻量 Mixture-of-Transformers 生成分支：文本与干净视觉 token 走理解分支，噪声视觉 token 走生成分支，全局注意力交互。先冻结理解分支，以 rectified flow 将噪声映射到旋转后的视觉编码；再冻结视觉编码器，以在线生成的 latent 而非真值状态训练语言解码器及生成分支回答问题。推理时文字给出 mental action，生成分支预测下一视觉 latent，并与文字交替作为后续条件。使用程序生成含可验证中间图像的 Tetris-2D/3D 数据；核心贡献是训练顺序与内部隐式状态读写的实证验证。

## Experiment
Tetris-2D 训练 4k、ID/OOD 测试 400/500；Tetris-3D 训练 16k、三种测试 400/400/500。相同任务微调后，WM-VLM 在二维 ID/OOD 为 87.50%/75.00%，文本 SFT 为 48.25%/46.20%；三维三组为 91.00%/66.25%/71.80%，文本 SFT 为 71.75%/44.50%/55.50%。去零或随机替换生成 token 令三维准确率跌至约 14%–25%；单阶段联合训练在所试设置下接近随机。四层生成分支接近全深度；更多 token 改善 ID，却不单调改善 OOD。三维 OOD 生成状态的检索 top-1 仅 13.4%，虽答案准确率仍为 71.8%，说明视觉状态“精确重建”与答题表现并非简单等价。迷宫导航仅 50.0%，低于额外大规模预训练的 ThinkMorph 82.5%。

## Value
**值得精读**：它给隐式世界模型研究提供可操作的验证方法——既测状态预测，又通过中间状态干预检验模型是否真正使用它。后续应从合成旋转扩展到视觉控制与真实动作后果，并验证 latent 对长链规划的因果作用。

## Strengths
中间状态可程序验证，较容易区分预测和决策；在线用自生成 latent 训练，减轻真值输入与推理输入不一致；多种 token 干预、阶段训练、分支深度和损失比消融揭示机制与训练条件。

## Weaknesses
旋转方块与真实视频的接触、遮挡、可变对象及随机动力学差距大；只在一个主干上完整训练，跨底座和真实任务的泛化不足。三维 OOD 精确状态检索率极低，尽管答案正确率尚高，可能仍存在信息捷径，置零实验不能完全排除。所谓轻量分支仍约 0.96B 可训练参数，推理需要流积分；未给延迟/效率完整比较。迷宫导航未超越强预训练图像生成基线。

## Future Work
作者明确提出收集真实机器人或模拟代理的“初始观察—动作—后续视觉状态—最终结果”交替轨迹，用来预训练带内部世界模型的 VLM，并研究其对空间推理与规划的作用。

## Rating
创新度评分：3/5 - 两阶段训练加内部视觉 latent 生成与干预验证有方法价值，但模型结构和任务均建立在已有技术与合成旋转设置上。
相关度评分：3/3 (Core) - 直接研究动作条件隐式视觉状态预测及其对推理的作用，契合 JEPA/Dreamer 一类方向的核心问题。

## TL;DR
让 VLM 先预测中间视觉 latent 再依赖它推理，并用干预验证实际使用；对隐式世界模型的训练与评测值得精读。
