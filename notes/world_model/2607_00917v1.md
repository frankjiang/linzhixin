# Valdi: Value Diffusion World Models

## Insight
论文的核心观察是：扩散世界模型的多模态预测能力未必直接提升 MPC 控制。Valdi 在 latent MPC 中把 deterministic MLP dynamics 换成 latent diffusion dynamics，发现单步 diffusion 已能匹配 MLP 控制表现；增加推理去噪步数会让未来更丰富、多模态，但反而损害当前 CEM planner 的控制性能。这个 trade-off 对“世界模型该预测多真实还是多可控”很有启发。

## Motivation
TD-MPC 类方法适合在线 latent planning，但通常用确定性 MLP transition，无法显式表示部分可观测环境中的多模态未来。扩散模型天然适合建模不确定未来，但多步去噪延迟与在线 MPC 冲突。论文试图把 latent diffusion dynamics 放进 TD-MPC 风格的端到端在线训练循环，验证它是否可用于低延迟控制。

## Method
Valdi 保留 TOLD 风格组件：CNN/proprio encoder、dynamics、reward head、value head。区别在于 dynamics 不再逐步 MLP 预测，而是用 bidirectional encoder-only Transformer 作为 diffusion dynamics，一次生成 H-step latent trajectory 的 velocity。训练联合优化 latent diffusion loss、reward prediction、TD value loss，并用 EMA target encoder 产生 denoised latent rollout。推理用 CEM 在 action sequence 上搜索，以预测 reward 加 terminal value 打分；默认训练和推理均只用一步 diffusion，以满足低延迟。

## Experiment
实验是 preliminary proof-of-concept，仅在 modified CarRacing 上做两次训练、100 条固定赛道评估。对比 deterministic MLP baseline：单步 Valdi 控制表现与 MLP 在方差范围内相当；多步 DDIM 推理提高预测多样性（pairwise LPIPS），但控制表现略降。作者还分析 imagined rollout 上 value function 的 self-consistency 和 grounding，指出 diffusion rollout 短期误差较大，但长 horizon value grounding 可能更稳。

## Value
价值在于提出一个简洁问题并给出负面/警示性结果：多模态世界模型不自动等价于更好控制，planner 必须能利用这种不确定性。对 Dreamer/JEPA/latent world model 方向有直接参考，尤其是低延迟 planning 下 diffusion step 数的取舍。局限很明显：单环境、少 seed、无复杂机器人/视觉任务，且移除了 TD-MPC prior policy，结论还需大规模验证。

创新度：3⭐ - 把 latent diffusion dynamics 接入 TD-MPC/MPC 有新意，但实验仍是早期验证

相关度：3 (Core) - 直接研究 latent/diffusion world model 与 MPC 控制

TL;DR：Valdi 证明单步 latent diffusion 可用于 MPC，但多模态预测会和控制性能冲突，适合选读其 trade-off 分析。
