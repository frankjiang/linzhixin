# EA-WM: Event-Aware World Models with Task-Specification Grounding for Long-Horizon Manipulation

## Insight
核心观察是：视觉/feature-space world model 能想象未来，但长时操作需要判断任务事件是否发生，例如物体是否移动、抽屉是否打开、接触/放置谓词是否满足。把 latent future 解码成 task-grounded events，再用 verifier 打分，比只看视觉 feature 距离更贴近规划。

## Motivation
解决 pretrained-feature WM 与机器人任务进展之间的 mismatch。同行常用图像/latent prediction + CEM，但未来图像相似并不等价于任务成功；长时 manipulation 需要 predicate-level progress 和物理可行性。问题相关且重要，但实现仍主要依赖仿真状态标签。

## Method
EA-WM 由冻结视觉 encoder/action-conditioned feature WM、自动事件标签器、event predictor/verifier、verifier-guided CEM 组成。事件标签来自 simulator state、BDDL/task rules、check_success，而非人工帧标注。预测对象包括 object moved/near/lifted/on target、drawer open、stove on、distance/margin/contact 等。Verifier 将 task progress、semantic consistency、physical feasibility、uncertainty 合成 score；CEM 在 feature rollout 后用事件分数重排或通过 conservative hybrid gate 决定是否替代 demo/PPO proposal。

## Experiment
PointMaze random-state 成功率 DINO-WM 0.90→EA-WM 0.94，dataset goal 已饱和为 1.00。Deformable 中 zero-init EA-CEM 为 0%，nearest-latent init + conservative EA-CEM 达 94%。Wall-Single 中 DINO-WM MPC-CEM 0.88，EA-CEM final 0.92，archive top50 validation 0.95。LIBERO-goal verifier AUC 0.993947，offline CEM > demo 89.5%；Goal10 online conservative hybrid 仅 87/100→88/100，直接 CEM 75/100；wine-rack PPO proposal + top2 verifier hybrid 达 97/100。

## Value
对机器人 world model 的启发是明确的：latent dynamics 应配任务事件验证层，而不只优化未来视觉。局限是事件监督强依赖仿真状态/BDDL/check_success，真实世界迁移仍需感知或 VLM 标签；LIBERO 长时在线结果其实有限，最强结果来自特定 wine-rack proposal setting。
