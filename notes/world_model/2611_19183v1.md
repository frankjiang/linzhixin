# WA-JEPA: Goal-Aware Predictive Feedback Action Refinement for a World-Action Model

## Insight
观察：JEPA 潜变量预测可评估动作后果，但 CEM 等候选搜索反复前向计算；直接模仿策略又不在执行前使用预测。推论：在同一候选计划内部，用预测未来与视觉目标的差值做几轮残差修正，可兼得目标感知与低时延。固定模型的 PushT 消融从 0 次反馈 16% 成功率升至 3 次反馈 96%，预测与执行的场景偏差相关 r=0.844，提供经验支持。

## Motivation
面向视觉目标的机器人控制需要把隐式动力学用于动作生成，而非只训练表示或运行昂贵规划器。LeWM/DINO-WM 用搜索优化动作，普通离线策略缺少预测反馈。此问题与 JEPA 世界模型的决策用途直接相关。

## Method
冻结 DINOv2 提取观察、未来和目标特征，用可学习融合/池化压成同一空间的场景 token。先生成多个动作块的计划，动作条件潜变量模型并行预测各块结束后的场景和本体状态；GDRF 将预测场景与目标的差、当前动作 token、预测状态输入门控残差修正；FSCF 将完整预测场景 token 作为下一轮交叉注意力上下文。四阶段只修正同一待执行计划，不推进环境时间或搜索候选。以示范动作、真实未来潜变量、本体状态和终点对齐联合训练；创新是预测反馈与动作头耦合，骨干和基本 JEPA 思路已有。

## Experiment
短程 PushT/TwoRoom/Cube 成功率 96%/100%/100%；PushT 对 LeWM 的整条计划时延为 32.13 对 1047.36 ms（A40），但两法精度与搜索配置不同。锚定规划长程跨任务平均成功率标准/扰动启动为 80.21%/66.28%，对 AP(LeWM) 的 54.43%/47.14%；其中 PushT 单项反而较低（56.25% 对 69.53%）。全任务 Push-T 覆盖率 71±2%，LIBERO-Goal 成功率 97±1%，分别高于表中所列对照；全任务使用 VQ-BeT 动作头。去掉世界预测及其反馈训练后，PushT 最优成功率由 96% 降至 84%；单独移除 GDRF 或 FSCF 也下降。指标含成功率/覆盖率、时延、FLOPs、参数及显存。

## Value
为隐式世界模型提供一种“预测—目标差—计划修正”的低成本决策接口，适合精读其训练损失、反馈路径及预测/执行一致性检查；可借鉴到视频/3D 模型的动作评测。

## Strengths
同时检验短程、分层长程及完整机器人任务；在同一起点独立执行各阶段动作验证预测与实际后果对应；报告反馈路径和固定模型阶段消融。

## Weaknesses
视觉目标和任务特定模型限制泛化；长程 PushT 不及 AP(LeWM)。部分对照直接采用他文分数、动作头及推理精度不同，速度与成功率比较需按配置解读；核心反馈消融部分仅单训练种子。未见真实机器人测试。

## Future Work
作者未提出明确路线；值得继续检验跨任务共享模型、分布外目标与真实机器人执行，以及预测误差累积时的反馈稳定性。

## Rating
创新度评分：3/5 - 在 JEPA 潜空间中把动作后果反馈给动作生成有明确方法增量和效果，但构件多为已有模型组合。
相关度评分：3/3 (Core) - 直接研究隐式 JEPA 世界模型及其规划/控制用途。

## TL;DR
用目标差和未来场景双反馈修正同一动作计划，减少 JEPA 在线搜索且有控制收益，值得精读。
