# Do AI-Native Biotechs Need Departments? Benchmarking Company World Models for AI-Driven Drug Development

## Insight
论文把“world model”迁移到药企组织设计：公司应维护一个资产到价值的共享状态、转移模型、价值函数和 planner，而不是简单复制人类部门。主要 insight 是 objective-sensitive：当评价目标是 BD/approval/revenue conversion 时，value-conversion 架构更好；中性决策质量评价下优势不稳。

## Motivation
AI-native biotech 常把 agent 角色设计成 biology、clinical、regulatory、commercial、BD 等人类部门的映射。作者认为 AI agent 可以共享状态、调用工具和动态组织，因此更自然的原语是 live asset-to-value state。问题对 agent 组织设计有意义，但与 CS 世界模型研究方向关系很弱。

## Method
提出 Company World Model：状态 St 包含科学证据、不确定性、IP、监管路径、BD 需求、商业潜力、资源和时间；动作 at 包括实验、适应症选择、BD outreach、监管沟通、融资或 kill/partner；还包括转移模型、价值函数、planner 和更新过程。Benchmark 含 45 个 retrospective biopharma 决策案例，有时间 cutoff、隐藏结果、共同输出 schema、自动评分和 blinded pairwise judging。比较 human-org mimic、human-org-mimic-plus、AI-native asset-centric 和 AI-native value-conversion。

## Experiment
原三臂自动 value-conversion score：value-conversion 4.68，高于 human-org mimic 4.33 和 asset-centric 4.26；价值特定盲评中 Codex/Claude 强偏好 value-conversion。加入 stronger human baseline 后，人类增强版到 4.49，差距收窄；value-specific Codex 仅 26-19 胜出，统计不强。中性 judge 下 human-org mimic-plus 25-20 胜过 value-conversion。消融显示去 Revenue Room、Deal Room、Approval Room 损害明显，去 Investment Arbiter 信号较弱。

## Value
作为 agent organization benchmark 有一定价值，尤其提醒必须显式暴露 value function。但这不是视频、3D、隐式世界模型，也没有训练 dynamics model 或可验证模拟器；对用户研究方向基本无参考价值。

## Strengths
任务设计有时间 cutoff 和隐藏结果；主动加入强 human baseline 和 neutral judge，避免过度宣称；消融能说明不同 room 的作用。

## Weaknesses
dry-lab prompt architecture，不是真实生物医药世界模型；评分和架构存在目标对齐偏置；没有专家人工验证和真实长期业务结果；与目标技术方向不相关。

## Future Work
作者提出需要多种正交 judge、人类专家评审、更严格长度控制，以及多时间点纵向案例来验证 state update 和 transition/value estimates。

## Rating
创新度评分：2/5 - 组织设计 benchmark 有新意，但主要是 prompt-level 架构和评估实验。
相关度评分：0/3 (Noise) - 药企组织与商业决策，不属于视频、3D 或隐式世界模型方向。

## TL;DR
这篇把企业决策称为Company World Model，实为药企组织基准，与目标方向无关，可跳过。
