# DashVMC: Real-Time Discrete World Model Control in Geometry Dash

## Insight
观察：世界模型在发展集的下一帧视觉 token 准确率仅 **29.58%**，45 步滚动降至 **2.91%**，但短滚动仍能让冻结模型中训练的策略在实机游戏里超过行为克隆。推论：用于**策略改进**的模型不必长期像素精确，但必须保留动作对危险与生存的短期差异；移除部署时的时序摘要后表现大体保留，也说明模型可主要充当离线训练环境。三种策略种子和动作翻转诊断提供支持，尚未证明可迁移至记忆依赖任务。（§5）

## Motivation
通常世界模型实验让环境等待推理；不停顿的游戏要求采集、编码、决策和键盘动作在一帧内完成。Geometry Dash 的二值跳跃、即时死亡和只读像素输入提供了苛刻的时间控制场景。问题关键是有限离线轨迹能否支持想象中的策略改进，并迁移到真实 60 Hz 游戏循环。（§1）

## Method
- 约 **2.33 小时、251,963 帧**动作标注游戏记录先经裁剪、灰度/Sobel 边缘与 64×64 缩放；卷积编码为 8×8×4，再用 iFSQ 量化成每帧 **64 个、1000 类**离散 token。（§3.1，§4）
- 8 层 Transformer 读取近 **4** 帧及动作，帧内双向、帧间因果注意，一次并行预测下一帧全部 token 和死亡状态；训练用 token 交叉熵、动作条件 CPC、结构化平滑等。4.55 万参数控制器先 BC，再在**冻结世界模型**的每批 512 条、最多 45 步滚动上做 PPO；前 4 步只更新上下文、不给策略学习，奖励为每存活步 +1、每跳 −0.25。（§3）
- 部署时不解码或生成未来画面，只编码当前像素并读取 Transformer 时序摘要决策；另测仅使用当前 token 网格的空间版。核心是现有量化、Transformer、BC/PPO 的实时系统组合。（§3.4）

## Experiment
- 三个控制器种子、三个官方关卡、一个从已知关卡中段开始的布局、一个冻结后选取且在训练外的社区布局；与各自 BC 初始策略及不操作比较，每个 BC/PPO 在主实验各尝试 25 次，以存活帧数和 bootstrap 区间计分。（§4–5）
- 官方第一关 PPO **280.1/280.4/308.8** 帧，BC **120.2/130.6/156.0**；训练外布局 PPO **290.4/342.8/266.7**，BC **104.8/102.1/97.8**。15 个种子×布局均值差都为正，但部分单项 95% 区间跨零。60 Hz 采集到动作延迟中位数 **12.083 ms**、p99 **14.913 ms**，5,000 帧中 **0.22%** 超过 16.67 ms。（表2，§5.2）
- 记录动作滚动的 token 准确率由第 1 步 **30.14%** 降至第 45 步 **2.91%**；翻转末端动作后，原动作在 **69.52%** 的发展集上下文有更低 NLL。去时序摘要、缩短滚动、去 CPC/结构化平滑的消融有诊断价值，但多为单种子、仅模型指标或同时改变训练迭代数。（表3、5、6，§5.4）

## Value
对视频/离散世界模型的**可行动性评测**很有参考价值：同一 BC 父策略的实环境增益、动作翻转、滚动误差曲线、控制循环尾延迟应联合报告。证明短期错误的模型仍可能帮助控制，但不宜据此推断长期世界状态正确。即使算法创新有限，实验设计值得精读。

## Strengths
把冻结模型内学习与不停顿实环境结果直接连接；三个策略种子与逐布局区间，明确开发集不是外部分布测试；报告从采集到动作的尾延迟、行动敏感性和 200 步漂移；空间版揭示在线时序模型的必要性可能很低。（§4–6）

## Weaknesses
只有一个确定性、二值动作游戏，训练外布局仍沿用已知机制；重复关卡前缀令发展集诊断接近同分布。三个种子共享一个视觉编码器与动力学模型，不能估计整个管线方差。缺少直接的帧堆叠/无世界模型训练基线；时序摘要、短视野和损失消融有限，长滚动会重复或创造不可能的地形。60 Hz 与延迟依赖 RTX 2060 和边缘图简化。（§6）

## Future Work
作者未提出成体系的新算法；结论指出世界模型也可在推理时供规划查询。依据局限，后续应检验多游戏/连续动作及新机制、独立世界模型种子、动作排序与死亡奖励失准，以及长期闭环预测是否仍有控制价值。（§6–7；后半为基于局限的延伸）

## Rating
创新度评分：2/5 - 量化、Transformer、BC 与 PPO 均为既有组件，主要贡献是实时部署与较细致的可行动性验证。
相关度评分：3/3 (Core) - 直接训练离散、动作条件视频世界模型，并在冻结模型滚动中优化控制策略。

## TL;DR
离散世界模型用短期想象训练策略并在实时游戏中胜过模仿，评测方法值得精读。
