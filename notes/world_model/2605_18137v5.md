# Xiaomi Auto World Model: A Joint World Model Integrating Reconstruction and Generation for Autonomous Driving

## Insight
3D 重建与视频生成不应作为独立模块拼接，而应深度耦合：重建模块（WorldRec）提供几何锚定抑制生成漂移，生成模块（WorldGen）补偿未观测区域的想象力。关键耦合机制：WorldRec 的 sparse scene tokens 通过 ego-projected rendered prior 为 WorldGen 提供几何 scaffold；WorldGen 的生成帧通过 incremental scene fusion 反馈更新 WorldRec 的 4D Gaussian 表示。

## Motivation
自动驾驶世界模型的两大范式各有瓶颈：重建方法（per-scene 3DGS 优化）几何精确但无法生成未观测区域且训练耗时；生成方法（causal diffusion）能想象未来但几何一致性差、长时间漂移严重。现有混合方法（NeoVerse 等）对自动驾驶的多相机一致性、ego-motion conditioning、layout 控制缺乏专门设计。

## Method
- **WorldRec**：feed-forward 3DGS 重建，用 sparse 3D queries（非 dense per-pixel DPT head）在世界坐标初始化，通过 cross-view cross-temporal feature aggregation（visibility-aware weighting）融合多视角多帧特征，输出紧凑 Gaussian 场景表示。解决了 DPT-based 方法的 ghosting/layering artifacts。
- **WorldGen**：DiT backbone + rectified flow matching，两阶段训练：(1) 双向预训练获得强生成先验；(2) 因果微调三部曲——Teacher Forcing → ODE distillation（50步→4步，~12× 加速）→ DMD（消除 exposure bias）
- **Joint World Model**：WorldRec 增量式场景融合（cross-attention fusion layer 融合新旧 scene tokens）+ WorldGen 增加 rendered-RGB conditioning（WorldRec 渲染的部分图像作为几何 scaffold）
- 条件信号：ego trajectory、camera intrinsics/extrinsics、layout maps、free-form text

## Experiment
- WorldRec：~10 秒/clip 重建，消除 ghosting/layering artifacts，多视角一致性显著优于 DPT-based 方法
- WorldGen：4 步生成即可达到 50 步质量，支持 1 分钟驾驶视频稳定生成（0.19s/帧）
- Joint Model：长时间生成几何一致性和时间稳定性均优于 reconstruction-only 和 generation-only
- 消融验证了 sparse query（vs DPT head）、bidirectional pretraining、DMD 各自贡献

## Value
作为自动驾驶世界模型的系统技术报告，覆盖面广且完成度高。Sparse 3D query 替代 DPT head 解决 ghosting 问题的思路值得关注。Bidirectional pretrain → causal fine-tune 的训练范式正在成为共识。Joint model 的耦合方式（rendered prior + incremental fusion）为 3D+视频世界模型的融合提供了可参考的架构。但单项技术创新有限，更多是已有技术的系统性整合。
