# Learning Latent Goal Costs for Visual World-Model Planning with an Expanding Curriculum

## Insight
观察：预训练视觉特征的目标 MSE 在近处有效，但障碍另一侧的状态可能视觉相似、实际路程很远；有限视野规划会偏好错误方向。推论：可从近目标的成功轨迹出发，用时间顺序构造弱进度偏好，逐步扩大起点范围，学习更接近可达性而非外观相似度的潜在代价。作者以障碍场景的配对规划成功率及未见布局上的合法路径排序验证；没有证明该弱标签在任意任务都成立。

## Motivation
DINO-WM、V-JEPA 2-AC 等以冻结视觉表征做图像目标规划时，常用潜在欧氏距离评价预测状态；这个距离不编码绕墙和可达路径。加长模型滚动时域会增加搜索与预测误差，因此改良短时域目标代价有直接价值。已有价值学习、轨迹表征直线化等方法会改动更多任务相关组件；本文只调整规划评分器。

## Method
冻结 I-JEPA ViT-H/14 编码器和动作条件潜在世界模型；后者由图像、球的本体状态及 5 步动作块预测下一潜态。对每个空间 patch 共享应用一个 64 维瓶颈的残差 MLP，初值为恒等映射；预测潜态与目标潜态经同一适配器后的 MSE 作为 CEM 终点代价。先从目标附近收集规划轨迹，成功轨迹经去回环/静止过滤后以相邻观测的先后次序形成 margin 排序对；失败轨迹的少量观测按当前适配器到同目标成功路径的距离构造附加弱排序。交替采集、拟合，并逐带扩大起点。训练用成功信号和可控起点，不用测地距离标签；创新主要在冻结模型上的课程式代价拟合。

## Experiment
DotWall 与 U 型 PointMaze 两个 2D 仿真任务；同一世界模型、CEM 配置、起点、目标与规划随机种子的各 50 例配对测试，目标均未参与适配器训练，限 100 步。DotWall 成功率从 27/50（54%）升至 49/50（98%），跨墙子集从 6/25 升至 24/25；PointMaze 从 41/50（82%）升至 48/50（96%），绕行子集从 16/25 升至 23/25。另在 16 个未见 DotWall 布局—目标组合上只测代价场：与最短合法路径的全图成对排序一致率从 71.9% 升至 85.8%，对侧房间从 48.5% 升至 77.1%，Spearman ρ 从 0.594 升至 0.864。图示展示错误低代价区域被修正；未提供组件消融或未见布局的闭环成功率。

## Value
直接提醒隐式世界模型：预测得准不代表目标度量适于规划；应把「潜态距离是否反映可执行进展」单独测量，并可用成功轨迹弱监督修正冻结表征。该评测和目标函数设计对 JEPA 类规划尤其有参考意义，规模化能力尚未知。

## Strengths
固定编码器、世界模型和规划器做配对比较，较清楚地隔离目标代价的作用；同时报告闭环成功与脱离模型误差的代价场排序，并测试布局变化。

## Weaknesses
只有两个低维球体导航任务；课程依赖近目标成功样本、成功判据和按目标生成起点，高维状态覆盖会昂贵。时间先后和失败轨迹匹配均为有噪声弱标签；缺课程/失败样本/适配器结构消融、重复种子置信区间以及未见布局的规划成功测试。

## Future Work
作者明确提出向更高维任务扩展；讨论了起点采样随维度增长、成功轨迹绕行和失败匹配依赖当前适配器等需要解决的问题。

## Rating
创新度评分：2/5 - 排序学习、残差适配器和课程采样的组合较直接，实验局限于两个简化导航环境且无关键消融。
相关度评分：3/3 (Core) - 核心是 I-JEPA 潜在世界模型的图像目标规划代价，直接关系隐式世界模型的规划与评测。

## TL;DR
用逐步扩大的成功轨迹弱排序修正冻结 I-JEPA 世界模型的目标代价，显著改善绕障规划；值得精读。
