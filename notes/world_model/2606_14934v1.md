# Separable Neural Architectures as Physical World Models: from Mathematical Theory to Applications

## Insight
核心 insight 是用 tensor decomposition + neural atoms 构造可证明的高维 PDE 函数表示，把低维坐标函数与全局低秩交互解耦，作为 solve-once-query-anywhere 的物理 surrogate。

## Motivation
工程科学中的高维时空-参数 PDE 求解昂贵，传统网格有维数灾难。作者称其为 physical world model，但语义是连续物理场 surrogate，不是视频/3D/机器人 world model。

## Method
Separable Neural Architecture（SNA）用 localized coordinate atoms 表示各维函数，稀疏低秩 interaction object 表示全局交互。Variational SNA（VSNA）作为 Galerkin trial space，给出 Lax-Milgram 下 well-posedness、quasi-optimality、convergence、stability；训练用 tensor-native ALS，复杂度近似线性随维度增长。

## Experiment
椭圆、双曲、抛物 PDE；7D laser powder bed fusion 制造仿真；Inconel 718 thermal-to-property inversion。报告 laptop CPU 上百万次 Monte Carlo 查询 102s、相对 A100 full-grid FEM 约 150000x 加速，inverse reconstruction <100ms。

## Value
数值 PDE/科学机器学习价值可能高，但与用户研究方向无实质关系。除非研究物理 surrogate 表示，否则可跳过。
