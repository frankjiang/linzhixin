# WAM-Sim0.1: World Anchored Memory Meets Online RL for Consistent and Realistic Driving Simulation

## Insight
观察：自回归驾驶视频跨片段生成时，地图、背景与车辆身份在各片段中反复由生成结果重建，导致结构和身份漂移。推论：按各信息的持久范围维护不可随意改写的记忆，再以在线奖励优化画质和运动，可缓解长程退化。记忆/RL 的 2×2 消融及 60 秒曲线支持有效性；“记忆约束策略空间”仅是从 DINO 特征漂移下降作出的经验解释。

## Motivation
现有驾驶视频模型常把地图、框、参考图作为瞬时条件，长程生成难维持真实地理背景与遮挡后个体身份；单纯增加上下文或视觉奖励不能保证状态持久。长程视频世界模拟的核心问题是稳定的可检索世界状态。

## Method
基于 OmniDreams 的 3D DiT 按片段自回归生成多视角视频，使用三层记忆：轨迹对齐 HD 地图 latent 直接相加；按全球位姿从地理图库检索只读背景帧，以时间段掩码交叉注意力注入；以 track ID 索引首次观测的目标裁剪，写一次、遮挡后可取回，以实例掩码注意力注入。随后对自生成片段运行 DiffusionNFT：场景画质、目标识别和 VLM 物理合理性奖励分组归一化，LoRA 更新 DiT 自注意力。创新在持久性语义与检索范围的分层组织及其与在线优化的组合。

## Experiment
nuScenes 上有地理记忆时 FID/FVD 为 5.75/32.40，去掉该记忆为 7.07/42.01；3D 检测 mAP 22.30，路面分割 mIoU 70.32。私有 350 条长序列测试中 FVD 74.20、背景相似度 0.910、主体一致性 0.681，优于比较方法。记忆与 RL 全组合使物理合理性从基线 51.45 升至 55.96；60 秒时带记忆的 FVD 137.92，去记忆为 286.54。另有 60 场景、15 人偏好测试和身份消融；1280×704 推理 6.94 FPS，对照模型 8 FPS。

## Value
多尺度持久状态、地理锚定和遮挡后身份恢复的设计对长视频/3D 世界模型直接有用，值得精读；评测可借鉴不同时间跨度的漂移曲线与重现事件指标。

## Strengths
把地图、背景与对象身份分别定义读写规则，避免生成帧覆盖可信记忆；记忆/RL 正交消融、跨时长评估和人类偏好测试较完整。附录注明遮挡持续 92–184 帧的事件仅 3 例，便于解释其置信范围。

## Weaknesses
依赖 HD 地图、GPS、地理参考图库、已知 3D 框和 track ID，尚未证明无这些条件时的闭环模拟能力。私有数据上部分基线未用相同数据再训练；物理分数来自 VLM 判断，不等价于真实动力学验证。3.1B 参数、32 张 NPU 训练，实例记忆在密集交通下随对象数增长。

## Future Work
作者提出将在线更新的 Gaussian Splatting/NeRF 纳入记忆，实现更强的多视角几何一致性；选择性更新对象记忆以处理状态变化，并压缩/分组实例记忆降低密集场景开销。

## Rating
创新度评分：3/5 - 分层持久记忆与在线奖励优化组合有效，但单个机制已有相关先例。
相关度评分：3/3 (Core) - 直接研究长程驾驶视频世界模型与持久世界状态。

## TL;DR
用地图、地理背景和对象身份的分层记忆配合在线强化学习抑制长视频漂移；值得精读。
