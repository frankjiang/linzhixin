# WorldString: Actionable World Representation

## Insight
核心 insight：物理世界模型的基本构件是"可操作的物体"——物体不是静态的，而是具有由内在属性决定的可变状态的可操作实体。现有方法通过视频生成或动态场景重建隐式处理物体动态，但没有以统一且有原则的方式显式建模物体状态流形。

## Motivation
物理世界模型中，物体是构成物理现实的基本单元。现有方法要么通过视频生成隐式建模，要么通过场景重建，但都没有在统一框架下显式建模关节物体、蒙皮物体和软体物体的状态流形。WorldString 提出一种统一的物体级数字孪生表征。

## Method
全可微架构：(1) State Transformer——通过交叉注意力将规范基态嵌入条件化于动态关键点状态；(2) Object Transformer——自注意力传播局部变形并强制全局结构一致性；(3) Voxel Transformer——通过空间查询的位置编码和与结构化嵌入的交叉注意力预测连续占用场。学习可微的规范基态 + 稀疏关键点作为动态状态 + 变形映射。统一覆盖 FK（关节物体）、LBS（蒙皮物体）和 Jacobian（软体物体）。从点云或 RGB-D 视频流学习。

## Experiment
刚体重建（Utah Teapot, Stanford Bunny 等）、关节物体（机器人手/臂、IKEA 家具）、蒙皮物体（人体、动物）、软体（布料等）、手部。与 Dr. Robot、NSDP、HALO 等专门基线比较，WorldString 在几乎所有几何指标（IoU, F1, Precision, Recall）上显著领先。

## Value
对 3D 世界模型研究有直接价值。统一建模三类物体变形的思路优雅且有原则性。全可微结构使其可与策略学习和神经动力学无缝集成。作为物理世界模型的"物体级基础组件"定位明确。局限：目前仅建模单物体，缺少物体间交互和力学仿真；需要密集 3D 点云/深度输入。
