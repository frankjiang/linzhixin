# Breaking the Uniformity Trap: Scaling Video Diffusion Model via SplitMoE

## Insight
视频 token 高度冗余且语义分布长尾，语言 MoE 式均匀负载会把同一对象切散到不同专家。作者用分割掩码统计语义区域内路由一致性、区域间区分性，发现标准视频 MoE 较差；据此将专家分成语义与通用两组，并用干净 VAE 特征的原型引导语义路由。相同激活参数下的消融和可视化支持该机制，但“均匀性导致生成瑕疵”的因果关系主要由关联性实验证据支持。

## Motivation
视频 DiT 扩容昂贵，稀疏 MoE 可增加总容量；现有 token 级路由及均匀负载正则从语言模型直接移植，难以保留视频的空间连贯性和时间稳定性。该问题对大规模视频生成主干重要，也可能影响以其为底座的世界模型。

## Method
从 Wan2.2 低噪声模型上采样升级部分 FFN，100 个路由专家分成 20 个语义和 80 个通用专家，每 token 激活 2+6 个，另有共享专家。两组分别 Top-K，权重由未加偏置的 sigmoid 得分归一化。干净视频的 VAE 特征与可学习原型形成软语义目标，通过 KL 对齐 DiT 路由；原型以当前/历史 token 的吸引项和原型间排斥项保持覆盖与分离。仅通用专家用无梯度负载平衡偏置。该结构与原型约束是主要创新，未构建动作条件状态转移。

## Experiment
同源对照固定 Wan2.2 低噪声权重、数据和 8 万训练步，对比 dense 微调、普通 MoE、去原型及去 pull/push。VBench-2 上完整方法的人类保真/物理分为 84.47%/69.41%，普通 MoE 为 73.49%/63.32%；T2V-CompBench 的属性/交互/数量为 84.63%/69.98%/44.01%，其中交互虽高于普通 MoE 的 63.89%，却低于原始 Wan2.2 的 73.29%。VBench-2 总分图约 64.59，对照普通 MoE 56.67。等激活 14B 参数时训练单步 6.84 秒，普通 MoE 6.69 秒、dense 5.66 秒；推理单步 6.08/6.12/5.76 秒。路由图、验证扩散损失与去 pull/push 消融表明专家更连贯且原型双约束互补，语义路由权重在高噪声早期更高。

## Value
为视频世界模型的生成主干提供稀疏扩容和路由设计参考，尤其是避免把统一负载目标机械用于视觉 token。价值偏底层生成架构；对动作可控性、物理状态记忆及闭环预测没有直接证据。

## Strengths
同源、同激活参数预算的对照较充分；分开验证专家分组、原型引导和双向原型约束；提供路由可视化、收敛曲线与耗时。

## Weaknesses
仅在文本到视频生成评测，未在交互式世界模型或动作条件任务验证。论文将 VAE 特征视为“语义”教师，但它偏重重建，语义纯度未经独立测量。总参数由 14B 增至 27B，内存/通信代价及跨节点扩展未充分量化；跨模型 SOTA 比较受训练数据和推理设定差异影响。

## Future Work
作者明确提出自适应专家分配、更高效的分布式路由，以及扩展到更广的视频生成任务。
