# Robo-Cortex: A Self-Evolving Embodied Agent via Dual-Grain Cognitive Memory and Autonomous Knowledge Induction

## Insight
提出"经验性遗忘症"概念：现有轨迹驱动或反应式策略无法将过去交互转化为可复用的泛化策略。Robo-Cortex 通过持续的反思-适应循环将经验抽象为可迁移的导航启发式。

## Motivation
具身导航在未见环境中因"经验性遗忘症"而困难——现有方法或模仿成功路径、或检索情景记忆、或从局部观察选择动作，但无法将先前交互转化为可复用的决策知识。Robo-Cortex 通过自主知识归纳实现持续策略进化。

## Method
三个紧耦合组件：(1) Imagine-then-Verify 规划循环——世界模型想象候选动作的未来结果，VLM 评估器验证；(2) 双粒度认知记忆——短期反思记忆（SRM）捕捉局部进展和失败模式，长期原则记忆（LPM）抽象为可复用的指导/警示原则；(3) 自主知识归纳（AKI）——从累积经验蒸馏多模态轨迹为结构化导航启发式库。使用 Qwen2.5-VL-72B + Wan2.1-I2V-A14B 世界模型。

## Experiment
IGNav、AR、AEQA 三个具身任务。Robo-Cortex 一致超越基线（+4.16% SPL），启发式迁移到未见环境时 +15.30% SPL。消融验证 SRM、LPM、AKI 各自贡献。真实机器人初步验证。

## Value
世界模型在此作为 Imagine-then-Verify 循环的想象器，非核心贡献。系统整体聚焦于策略进化和知识归纳。对世界模型本体研究启发有限，但"持续自我进化"的框架思路对具身 AI 有参考价值。
