# World Models as Group Actions

## Insight
核心观察：现有视频世界模型追求视觉逼真度，但"视觉好看"不等于"动力学忠实"。action-conditioned世界模型应当尊重动作的代数结构——在导航等embodied场景中，动作天然形成李群（如SE(2)），满足恒等、逆元、组合律。作者发现SOTA模型NWM虽然生成视觉效果良好，但严重违反这三条群作用性质：零动作导致状态漂移、前进+后退无法恢复原状态、等价分解产生不同终点。这揭示了"视觉真实"与"动力学一致"之间的结构性鸿沟。

## Motivation
问题：视频世界模型作为action-conditioned simulator，其核心功能是产生"由动作治理"的状态转移，而非仅仅产生逼真的视频。但现有方法只优化单步预测的视觉质量，忽略了动作空间的组合结构，导致学到的动力学不满足基本代数性质。缺乏系统的形式化框架来定义和度量"动作忠实性"。

解决思路：将世界模型的状态转移形式化为群G在状态空间S上的群作用(group action)，要求转移函数满足三条公理（恒等、逆一致、组合相容），从而将动作忠实性问题转化为可量化、可训练的代数约束。

## Method
**理论框架**：定义群作用公理（Theorem 1），在导航场景中实例化为SE(2)（Corollary 1.1）。通过位姿估计器从生成的视频中恢复状态，在恢复的状态空间中检验三条性质。

**训练方法 -- 隐空间群作用正则化**：
- 直接在状态空间施加约束需要解码+位姿估计的循环，计算不可行
- 改为在世界模型的latent space中施加三个对应的损失项：L_id（零动作段端点应接近起点）、L_inv（前进-后退段端点应接近起点）、L_comp（等价分解段端点应相互接近）
- 总目标：L = L_diff + lambda_GA * L_GA，其中L_GA = lambda_id*L_id + lambda_inv*L_inv + lambda_comp*L_comp

**监督合成**：无需额外数据，从已有轨迹中合成三类约束：
- Identity段：全零动作序列
- Inverse段：原动作段 + 取反动作段（前进后退循环）
- Compatibility段：用Dirichlet分布重新分配权重生成等价分解

**评估指标**：
- GAC (Group-Action Consistency)：在恢复的状态空间中度量三条性质的违反程度，值越低越好
- GAR (Group-Action Robustness)：相同初始帧+相同动作序列下多次随机rollout的轨迹一致性

## Experiment
在RECON、SCAND、HuRoN三个导航数据集上，以NWM和DIAMOND为backbone：

**GAC结果（RECON）**：NWM+GA的聚合GAC误差从1.73降至1.50，三项均有改善；DIAMOND+GA从1.99降至1.76。

**GAR结果（RECON）**：NWM+GA在64帧non-aligned误差从1.52降至1.28，长horizon改善更显著，说明群作用正则化有效抑制了随机性累积。

**消融实验**：三个约束各自独立贡献，L_comp对长程rollout稳定性贡献最大。三者互补，联合使用最优。

**视觉质量**：FID等图像质量指标无退化，一致性提升不以视觉质量为代价。

## Value
**贡献**：提出了一个数学上优雅的框架，将世界模型的动作忠实性归结为群作用结构的保持。理论清晰、方法实用（隐空间正则化+监督合成不需额外数据），且提出了配套的评估协议(GAC/GAR)。揭示了"视觉真实 != 动力学忠实"这一重要问题。

**局限**：
1. 仅在导航场景（SE(2)）中验证，推广到更复杂的动作空间（如机器人操作）需要进一步探索
2. 隐空间正则化是群作用条件的近似代理，理论保证有限
3. 实验backbone仅限NWM和DIAMOND，尚未在大规模扩散视频模型上验证
4. 评估依赖位姿估计器的精度

**对我们的启发**：群作用视角可以推广到其他类型的世界模型——隐式世界模型（JEPA/Dreamer）的latent dynamics同样应满足动作空间的代数结构，可用类似方法诊断和改善。3D世界模型天然具备一部分几何结构，但组合一致性仍值得检验。
