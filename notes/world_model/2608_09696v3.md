# Model Discovery Agent: LLM-assisted Bayesian experiment design for data-efficient discovery of mechanistic world models

## Insight

论文的核心观察是：被动数据甚至高精度 curve fitting 都不能区分在已观测区域等价、对干预却给出不同答案的机制；真正决定数据效率的是“做哪个实验最能让候选机制分歧”。因此作者把 LLM 限定为开放式结构 proposer，而把模型选择、参数估计、预测和实验设计交给可校准的 Bayesian machinery。MDA 用 SMC evidence 自动惩罚过复杂机制，用候选间预测分歧的 value of information（VoI）选择干预；若新实验的残差表明当前集合失配，再让 LLM 扩展假设空间。Yukawa 案例直观证明：短距离观测下幂律与真实屏蔽力几乎不可辨，VoI 主动选择越过 screening length 的长距离轨迹后，真实机制才成为 accuracy–complexity 前沿的拐点。

第二个重要推论是，随机潜变量下“观测模型”本身也应被选择和审计。忽略过程噪声的确定性 likelihood 会积累错误证据并自信选错；原始轨迹 particle filter 稳健但昂贵，学习/人工 summary 的 synthetic likelihood 快但可能丢失判别信号。作者用 truth-free discrimination probe 按信息量/成本选 likelihood，并以 particle-filter spot-check 兜底，在候选集合变化时重新检验 summary sufficiency。这一论点由噪声扫描、反转案例和六种神经元机制实验支持。

## Motivation

科学发现智能体需回答“若施加未做过的干预会怎样”，这要求可解释、可模拟的 causal/mechanistic model，而不是对固定分布拟合。经典 Bayesian experimental design 能选信息量大的实验，却通常假定真机制已在封闭候选集中；纯 LLM agent 能提出新方程，但参数拟合、复杂度控制、不确定性和实验设计不可靠。作者试图组合两者，使系统既可在 M-open 情况下创造候选，又能用少量昂贵实验识别机制。问题本身重要，且与“可干预的世界模型”概念相关；但论文应用为合成物理、酶动力学和单神经元科学发现，不涉及视频、3D 环境或 JEPA/Dreamer 式策略学习。

## Method

未知系统被写成可控状态空间模型：潜状态 `z_t` 在输入序列、初值和改变机制参数的 `do(a)` 下转移，并产生有噪观测 `y_t`。每轮 MDA 执行：

- LLM 根据领域描述、已有数据、候选及其残差提出可编译的机制结构与宽参数先验；这是 discovery loop 中唯一必需的 LLM 调用。
- 对每种结构，用 adaptive-tempered SMC 近似参数 posterior 和 marginal likelihood；模型 evidence 集成参数后形成 Bayesian Occam penalty，并给出结构 posterior。通常保留 2–14 个结构，每结构 100–200 个参数 particle。
- 选择最大化 `I(M;Y_ξ|D)` 的实验。实现以候选机制 posterior mean 的 between-class predictive variance 近似 VoI；小离散空间枚举，连续空间用 CMA-ES。它针对机制辨识，而非最大化预测反应值。
- 实验后重新推断；当 MAP 模型的 summary/raw-trace 残差超过阈值时，LLM 进行最多若干轮新结构扩展；若 posterior 集中且拟合好则缩小粒子池，减少近重复复杂模型。
- 最终用 MAP 机制的 Bayesian parameter posterior（理论上可做 model averaging）对未见干预输出 posterior-mean forecast，而非让 LLM 从表格直接猜结果。

确定性动态使用逐时刻 Gaussian likelihood；随机动态可用 bootstrap particle filter 在 latent SDE 上估 marginal likelihood，或用多次模拟拟合 summary 的 Gaussian synthetic likelihood。学习 summary 时，以先验模拟库监督分类结构和回归参数，取 1D CNN 中间 embedding，避免常数 collapse。针对 PF、人工 summary 与学习 summary，系统以候选自生成数据上的 discrimination/cost 选择，再在真实已收集数据上用 PF 检查 MAP 是否一致，不一致即回退 PF。方法集成度高，但大量领域结构、可用操作、forward simulator、先验范围和设计菜单仍由人提供。

## Experiment

统一协议按实验数绘制 held-out interventional prediction error，并在已知真模型时另测符号等价：

- ForceBench：六个二体和五个多体合成力学世界。二体任务每世界 3 个初值×3 次运行，最多 8 个单次实验；指标为轨迹 normalized MSE、`nMSE<0.1` 通过率和函数形式等价率。Opus 4.7 下 MDA 的几何平均 nMSE 为 `9.2e-4`，数值/结构通过 93%/74%，预算匹配纯 LLM 为 `5.4e-1`、31%/31%。未限流 LLM 约用 41 次实验才到 nMSE 0.013，MDA 用 8 次达到相近水平。给纯 LLM 同一 13 项设计菜单仍仅 22% 数值通过，说明优势不只是手工菜单。换强 Fable 5 后差距缩小：MDA/agent 数值为 94%/81%，联合“形式且数值正确”均 74%，纯形式则 agent 93% 高于 MDA 经简约规则后的 78%。
- ChemBench：从 57 种酶速率机制抽取 36 个分层任务、两个 seed；用 held-out RMSLE、symbolic accuracy（SA）及阈值 exact accuracy。VoI MDA 约 8 个实验已到 SA 平台，60 次时 SA/Ex 为 55.6%/80.6%，匹配实现的 LLM-AutoSciLab 为 41.7%/69.4%。M-open、CMA-ES VoI、ESS 自适应池逐步把 base SMC 的总体 SA 从 36% 提至 50%、再最终 56%；其中 hard-tier 从 33% 到 54%。
- NeuronBench：六种带隐藏离子通道机制的 Hodgkin–Huxley ODE，36 个刺激/阻断设计；held-out 指标主要为 spike-count MSE。Bayes forecaster 在所有世界优于 in-context forecaster，VoI/LLM 设计相近且优于随机。H-sag 中普通去极化刺激完全不动 posterior，VoI 的超极化 probe 一次即可识别 Ih，并让 conductance posterior SD 约收缩 8 倍。
- 随机 NeuronBench：有限通道噪声使动态成为 SDE。确定性 likelihood 在较强噪声下会把 evidence 符号反转；PF 始终方向正确。学习 summary 的 synthetic likelihood 在二候选例中以约 0.3 ms 对 3 s/decision 复现 PF 决策，但完整开放六世界的 18 次运行中最终仍有 11 次因 spot-check 分歧回退 PF。三次设计后，MDA spike MSE 约从初始下降 4×至 4.6，接近真实模型单次采样噪声底 4.0，并约比 ICL 低一数量级；但若干噪声主导世界在 6 次实验后仍接近或差于先验。

实验覆盖确定/随机、静态/动态、封闭/开放候选及三学科，且有关键组件、强模型和相同菜单控制；但多数结果只有 2–3 seed，环境全为作者可调用 simulator 的合成或半合成机制，VoI 相对随机/LLM design 的优势在 NeuronBench 并不稳定。

## Value

这篇工作最值得借鉴的是职责分离：神经语言模型负责提出结构，显式概率模型负责证据、校准与干预选择；以及把“模型哪里不够”和“下一条数据应采什么”闭成循环。对视频/3D world model，可类比为让生成模型提出对象/动力学假设，用主动交互选择最能区分它们的动作，并以 held-out intervention 而非重建画质检查世界模型。局限是当前要求候选可编译且有便宜 forward simulator，远不能直接扩展到高维自然视频；也没有学习控制 policy 或长时闭环回报。

## Strengths

- 明确以未见干预预测和机制等价评测，能揭露数值拟合很好但科学形式错误的模型。
- M-open residual trigger、SMC evidence、VoI 和自适应候选池各自作用清晰，化学消融能定位收益。
- 对最强 Fable 基线诚实报告差距大幅缩小及其纯结构优势，没有只选弱 LLM 对照。
- 引入随机潜变量、learned summary、PF 安全锚和 observation-model selection，超出简单符号回归。
- 三领域共用同一发现框架，案例可解释，尤其长程 Yukawa probe 与 H-sag 超极化 probe 展示主动辨识价值。

## Weaknesses

- “开放”仍受强模板约束：领域词汇、可编译机制库、参数先验、干预菜单、噪声形式和 simulator 接口均已给定；真正未知变量、对象和方程语法远更难。
- 所有评测依赖合成真值和可重复 simulator，没有真实实验噪声、测量偏差、实验失败、伦理/成本约束或分布漂移。
- 主实验使用 SUMMARY residual，而非论文提出的外部 QUERY check；当学习 summary 丢失目标信息时，候选和表征可能共同拟合错误 lens，当前只靠 PF spot-check 局部缓解。
- VoI 使用 moment-matched Gaussian、MAP 参数和一步贪心近似；NeuronBench 中 VoI 与 LLM 设计相近，随机设计也常紧随，未充分证明主动设计在所有域稳定占优。
- Bayesian evidence 会偏爱带微弱多余项的灵活结构；即使 Fable 已把真式放入池中，MDA 的纯形式恢复仍低于 agent，需要后处理简约规则。
- 嵌套模型 SMC、参数 SMC 与 PF 计算快速膨胀；自动选择的开放随机实验多数回退慢 PF，所谓低 LLM 成本不等于低总模拟成本。
- seed 少，部分化学中间消融只用一个 seed；跨论文 head-to-head 还存在不同 36-task 子集和阈值口径，SOTA 结论需谨慎。

## Future Work

作者明确提出将 learned observation abstraction 与 M-open 机制扩展端到端共同训练，扩展 Fable 5 到多体物理和其他科学域，并可能评测 NewtonBench。更关键的后续包括连续/组合式实验空间的非贪心设计、真实实验硬件与失败成本、结构先验和 simulator 的自动构造、跨候选变化的 summary sufficiency 保证，以及把该主动因果辨识循环迁移到机器人或视频环境，用对象级 latent 动力学和真实动作干预检验可扩展性。

## Rating

创新度评分：3/5 - 将 LLM 开放结构提议、M-open SMC、VoI 主动实验与随机潜变量 SBI 组成完整发现闭环，广度和验证很强；但大部分组件经典，领域模板与模拟器假设较重。

相关度评分：1/3 (Tangential) - 直接研究可干预 mechanistic state-space “world model”，主动辨识和不确定性方法有概念借鉴；但应用是科学方程发现，不涉及视频/3D 表征、JEPA/Dreamer 或具身规划。

## TL;DR

用 LLM 提机制、贝叶斯证据与主动实验辨识因果模型，方法扎实但偏科学发现，建议选读。
