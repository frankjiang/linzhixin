# τ₀-WM: A Unified Video-Action World Model for Robotic Manipulation

创新度：3/5 | 相关度：2/3

## Insight

核心 insight：视频预测与动作生成不应分离处理，而应共享同一个预测性表征（predictive representation）。

**Observation**：(1) 纯机器人遥操作数据虽然动作标注可靠，但场景和任务多样性有限；(2) ego-centric 人类视频虽然视觉动态丰富，但没有可执行的动作标注；(3) 不同数据源的异质性通常被视为噪声。**推论**：可以通过 modality-specific supervision masks 统一训练，让每种数据只监督它实际包含的信号（机器人数据监督动作+视频，ego 视频只监督视频预测），从而将异质性转化为互补监督。**验证**：消融实验表明，加入 UMI 和 ego 数据后，zero-shot 成功率从 0.14 提升至 0.55。

另一个 insight 是 test-time computation 用于动作选择：通过 Re-denoising Consistency Score（RCS）做轻量级的动作一致性筛选，不可靠时才调用更昂贵的 ACVS 进行 rollout 评估和动作修正（LAR），这是一种 coarse-to-fine 的推理时计算策略。

## Motivation

机器人操作需要模型既能生成可执行动作，又能预测动作后果。现有方法要么只学策略（无法想象未来），要么用视频预测做辅助目标但不直接用于决策。τ₀-WM 将策略学习（VAM）和 action-conditioned 仿真（ACVS）统一到一个共享的视频扩散骨干中，使得 future prediction 不仅是训练辅助信号，更是部署时动作评估和修正的直接工具。

## Method

整体框架由两个互补接口组成，共享一个 5B 参数的 Wan 2.2 视频 DiT 骨干：

1. **Video Action Model (VAM)**：策略接口。输入多视角观测、语言指令、机器人状态，联合预测未来视频 latent 和连续动作 chunk。视频分支（5B）和动作分支（0.5B DiT）通过 feature-level cross-attention 耦合。训练目标为 joint flow matching。

2. **Action-Conditioned Video Simulator (ACVS)**：评估接口。给定候选动作 chunk，预测未来视频 rollout 和 dense reward trajectory。复用 VAM 的视频骨干，但去掉动作生成分支，通过 AdaLN 注入候选动作。Reward 通过 subtask 分解 + Monte Carlo 估计获得 dense 监督，失败数据被赋予负 reward。

3. **Test-Time Computation**：
   - RCS (Re-denoising Consistency Score)：对采样的 N 个动作候选加噪再去噪，评估一致性，选最一致的
   - LAR (Low-quality Action Rectification)：当 RCS 分数低于阈值时，调用 ACVS rollout 所有候选，选最高 reward 的 imagined future，再以此为条件重新 query VAM 生成修正后的动作

4. **数据**：27.3K 小时异质数据——17.8K 小时真机遥操作（AGIBOT-G01/ARX/Franka）、6.5K 小时 UMI、3.0K 小时 ego-centric 人类视频。通过 modality-specific supervision mask 统一训练。

**创新程度**：较高。将 VAM 和 ACVS 两个功能统一到共享骨干中的设计较为新颖；RCS + LAR 的 test-time computation 策略有效且实用。

## Experiment

- **任务**：4 个精细操作任务（Toolbox、School Bag、Badminton、Faucet），跨 3 种机器人平台（AGIBOT-G01、ARX、Franka）
- **对比方法**：π₀.₅、Fast-WAM、CFG、ACG
- **主要结果**：
  - τ₀-WM 在 4 个任务上平均成功率最高（0.44 vs. π₀.₅ 的 0.20，Fast-WAM 的 0.20）
  - Task Accomplishment Progress 也全面领先
- **消融**：
  - 预训练数据组成：加入 UMI+Ego 数据显著提升 zero-shot（0.14→0.55）和 SFT（0.70→0.83）性能
  - Test-time computation：RCS 将成功率从 0.43 提升至 0.50，加 LAR 进一步提至 0.60
- **部署延迟**：单 RTX 5090，action-only 推理约 180-220ms，torch.compile 后约 140ms

## Value

这是一项工程和系统设计水平很高的工作（来自 AGIBOT Finch / 上海创新院），展示了将大规模视频生成模型（Wan 2.2 5B）直接用于机器人操作的可行路径。核心贡献在于：

1. 证明了 video prediction 与 action generation 共享表征的有效性
2. ACVS 作为 learned simulator 在部署时进行动作评估和修正，这是 model-based planning 思想在大模型时代的实践
3. 异质数据通过 supervision mask 统一训练的策略值得借鉴

**对我们的启发**：
- 视频世界模型可以同时服务于策略学习和 action-conditioned simulation，这种双接口设计值得关注
- Test-time computation（采样-筛选-修正）是提升部署可靠性的有效手段
- 大规模视频预训练 + modality-specific fine-tuning 是整合异质数据的可行方案

**待解决**：触觉等非视觉模态、更长时间跨度的规划、部署延迟仍需进一步优化。

## TL;DR

将 5B 视频扩散模型统一为机器人策略生成（VAM）和 action-conditioned 仿真器（ACVS），通过 test-time computation 实现动作筛选与修正，在精细操作任务上取得 SOTA。值得精读。
