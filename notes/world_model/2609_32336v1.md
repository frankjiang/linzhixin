# WSM-Aware HRI: An IoT-Enhanced Framework for Early Detection and Norm-Guided Repair of Failures with LLM Guidance

## Insight
观察：人类指令暗含的物理、时间和规范前提可能与机器人当前证据矛盾；在动作前把假设转为可验证约束，可提早澄清或拒绝。50 次案例试验中完整系统的错配类型/证据匹配为 88%/86%，但证据主要来自感知、IoT 和规则检查，而非学习到的世界动力学。

## Motivation
人机交互失败常在动作之后才修复；对杯中液位、室外污染或多用户权限等不可见条件，局部视觉与常识不足。该工作是 HRI 状态核验问题，与视频/3D/隐式世界模型方向关联很弱。

## Method
LLM 由指令推断人的意图、物理及规范假设；机器人状态汇集视觉、传感器、IoT、角色和政策。按逻辑、可供性、时序、多用户与规范约束比对，证据不足则主动请求检查；对已证实错配按严重度解释、澄清、重规划或拒绝，并在执行中监测。实质是规则与证据编排框架。

## Experiment
十个家庭场景、每例五试次，共 50 次。完整框架错配类型匹配 88%、证据覆盖 86%、执行前干预 86%、修复匹配 84%；无 IoT 分别为 74/70/72/72%，后验修复为 28/不适用/10/32%。另有杯中液位等实体展示，以及移除 IoT 文本的离线提示试验。评估任务小且多为脚本场景。

## Value
若做机器人决策安全，可参考“指令前提—外部证据—动作前核验”的交互接口；对世界模型架构或视频/3D 动力学几乎没有贡献。

## Strengths
关注视觉难见的外部状态，区分证据不足和证据矛盾；带有 IoT、视觉、轨迹修正消融。

## Weaknesses
“世界模型”主要是显式事实表及 LLM 推断；缺真实大规模长期交互、概率校准及强 HRI 系统对照。50 次案例不足以验证开放场景鲁棒性。

## Future Work
作者提出扩大场景与时域、接入实时 IoT/传感器、改进不确定性阈值及多用户权限和同意处理。

## Rating
创新度评分：2/5 - 将已有感知、IoT、LLM 和规范检查模块整合，技术贡献有限。
相关度评分：0/3 (Noise) - 未研究指定的视频、3D 或隐式世界模型。

## TL;DR
把人类指令前提与感知和 IoT 事实核对以提前修复交互失配；非目标世界模型方向，可跳过。
