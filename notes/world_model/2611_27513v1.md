# Ego4Gen: Generating Geometry-Grounded Motion Tokens as a World-Action Interface

## Insight
观察：视频潜变量或潜动作可能混入纹理、光照等与控制无关的信息；预训练 4D VAE 的几何加场景流潜变量在跨外观条件下更易解码成动作。推论：未来几何运动可作为世界预测与机器人执行间的接口。论文用表示对照、闭环控制与仅改造世界模型的无动作标签视频实验支持该推论，但没有信息论层面的不变性证明。

## Motivation
视频世界模型能生成未来帧，却不天然提供稳健的动作接口；纯 2D 潜动作容易吸收非控制因素，显式重建 3D 再处理又昂贵。直接生成可解码 3D 点图/场景流的潜 token，并映射为机器人动作，是相关且重要的问题。

## Method
以 Cosmos3-Nano 图像到视频骨干为基础，在首帧和文本条件下共同生成未来 96 帧/24 FPS RGB 与 48 帧/12 FPS 点图、3D 场景流。RGB 使用 Wan2.2 VAE，几何/运动目标来自冻结 MotionCrafter 伪标签；通过时间位置对齐、模态路由 LoRA 和非对称注意力让几何/运动读取 RGB，而 RGB 不接收几何/运动反馈，且 RGB 的键值对几何支路停止梯度；三模态以 rectified flow 联合训练。FlowInverse 对几何和运动潜变量分别卷积编码，加本体状态并用 action query 交叉注意力，回归关节增量、夹爪和末端位移；先在 50 任务预训练，再在目标任务用生成潜变量微调。属于已有生成骨干与 4D VAE 上的多模态接口构造。

## Experiment
TACO 未参与训练，2 秒生成对比：Ego4Gen PSNR 16.06、LPIPS 0.394、深度 AbsRel 0.140/δ1 0.807、点图 δp 73.62%；4 秒为 14.83/0.456、0.153/0.773、67.47%，部分视觉/几何指标并非各模型绝对最佳。场景流无真值，以 VGGT-Ω+AllTracker 伪参考测得 EPE 1.452 cm，与 MotionCrafter 重建的 1.430 cm 接近。RoboTwin 两任务表示测试 Hard 成功率：几何+运动 51%/37%，DreamDojo 潜动作 0%/0%；但 Motion-only 在 Place Empty Cup 为 55%。五任务闭环 Easy/Hard 平均成功率 46.6%/15.2%；仅用无动作标签的混合场景视频再训练生成器、固定控制器后为 37.2%/26.4%，提高困难域同时损伤简单域。去掉 50 任务 FlowInverse 预训练使闭环平均降至 18.4%/7.4%。

## Value
值得精读：几何运动潜变量作为生成到控制的接口，尤其适合研究 3D 世界模型与 action decoder 的分工；无动作标签视频适配的收益与 Easy 性能下降应同时关注。未来需解决生成潜变量更新后与固定控制器的分布漂移。

## Strengths
同时评估 RGB、深度、点图、场景流和闭环动作；表示对照包含潜动作与视频潜变量，且比较 Easy/Hard 分布移位；结构消融和固定控制器的无动作标签后训练揭示各模块作用。

## Weaknesses
几何/场景流训练目标和动态流评测均含现成模型伪标签，误差可能共享；RynnWorld-4D 使用额外初始深度，跨方法输入不完全一致。闭环 Easy 显著弱于强基线，Mixed 训练使 Easy 继续下降；未给成功率置信区间。控制实验的“专家视频潜变量”表示评测比实际生成潜变量更理想，需区分二者。

## Future Work
作者未列独立的未来工作清单；根据已报告的 Mixed 失配与伪标签限制，合理方向是生成器更新时联合校准 FlowInverse、提高几何/运动真值评测覆盖、扩大无动作标签跨域验证。

## Rating
创新度评分：3/5 - 模态路由、非对称注意力和几何运动接口有实用新组合，基础模型及 4D 潜表示均来自已有工作。
相关度评分：3/3 (Core) - 直接研究 3D/4D 视频世界模型及世界预测到动作的接口。

## TL;DR
联合生成 RGB、点图与场景流，并用几何运动潜变量驱动机器人动作；研究 3D 世界模型接口值得精读。
