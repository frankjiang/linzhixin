# Imperfect World Models are Exploitable

## Insight
提出世界模型"可利用性"(exploitation) 的形式化定义：一个世界模型是可利用的，当它暗示应优先选择策略 A 而真实环境暗示应优先选择策略 B。将此与 reward hacking 建立类比但证明不可避免性证明不能直接迁移。

## Motivation
世界模型不可能完美，不完美的世界模型会导致策略优化中的 exploitation 问题。需要形式化理解 exploitation 何时可避免、何时不可避免。

## Method
理论工作：
1. 定义 model exploitation 并与 reward hacking 类比
2. 证明在大策略集上 exploitation 基本不可避免
3. 推导 reward hacking 的不可避免性作为特例
4. 证明保证 unhackability 的有限策略集条件不能推广到 exploitation
5. 引入 relaxed exploitation 概念并推导安全 horizon

## Experiment
纯理论，无实验。

## Value
世界模型安全性的理论分析工作。形式化了"不完美世界模型中规划的固有风险"。但纯理论，与视频/3D 世界模型的实践无直接联系。对世界模型的理论基础研究有参考价值。

## Strengths
亮点是世界模型安全性的理论分析工作。

## Weaknesses
不足是证明保证 unhackability 的有限策略集条件不能推广到 exploitation
