# ForcingBooster: Adaptive Patch-wise Denoising for Fast Autoregressive Video Diffusion

## Insight
同一视频块内，静态背景与新出现、运动或细节复杂的区域达到四步去噪结果所需步数不同。在受控单块试验中，以四步输出为参照，30.60% 的 patch 第一步就达到 35 dB PSNR，仍有 47.45% 直到第四步才达到；据此推断逐 patch 提前退出可节省计算并保留难区域质量。随机分配相同步数分布的对照比学得的路由差，支持“选择哪里继续算”而不仅是减少总步数。

## Motivation
自回归视频扩散虽已蒸馏到约四步，仍对所有空间 patch 执行相同步数，交互式视频世界模型受端到端延迟限制。整块缩短去噪会损伤局部细节；核心问题是把计算量按空间难度分配。

## Method
冻结已有的自回归视频扩散器，轻量路由器读取其末层特征，在每一步给活跃 patch 预测停止概率。停止的 patch 采用该步的干净潜变量估计，并保留 KV 供其他 patch 读取；后续仅计算未停止区域。用原模型四步输出作自监督参照，以当前步与参照的 patch 潜变量误差惩罚过早退出，以预期去噪步数惩罚多算；当前路由策略的在线 rollout 估计继续计算成本。该方法新增的是少步视频扩散的 patch 路由和自监督成本—质量权衡，原生成器与噪声时间表不变。

## Experiment
Causal Forcing 1.3B、81 帧、480×832、单 A800：四步 VBench Quality/Semantic/Total 为 84.54/72.21/82.08、11.15 秒；ForcingBooster 为 83.88/72.20/81.55、8.56 秒，即端到端 1.30 倍加速、patch 去噪次数减少 50.19%。同等耗时的固定两步 Total 81.29，路由高 0.26。Wan2.1 14B、LingBot-World-V2 14B、LongLive 上分别为 1.31、1.25、1.15 倍加速，均较四步有小幅质量下降。等耗时分配消融：路由 Total 81.54，随机位置 79.03，整块路由 80.01。另测 LPIPS—耗时权衡、阈值敏感性和光流分组：低运动视频受益更大。评价重心是 VBench 视觉质量与运行时间，缺少世界模型交互任务的物理一致性或闭环成功率。

## Value
对需要低延迟交互的生成式视频世界模型有直接工程参考：从冻结模型的中间干净估计构造局部提前退出，并用真实端到端耗时检验效率收益。若团队目标是规划或物理推演，还需补做动作条件正确性和长时闭环评测。

## Strengths
无需重训大型生成器或人工停止标签；比较固定步数、随机 patch 与整块路由，并报告包含 VAE 解码和缓存构建的端到端耗时；在不同规模和用途的模型上复验。

## Weaknesses
四步教师输出只是模型自身参照，不保证真实视频或物理正确；路由质量提升相对同耗时两步的 Total 差距较小。速度受内容动态程度影响，LongLive 仅 1.15 倍；未报告大规模长时交互中的误差积累、动作响应或不同硬件上的稀疏计算开销。
