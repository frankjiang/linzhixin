# Learn Where Outcomes Diverge: Efficient VLA RL via Probabilistic Chunk Masking

## Insight
在 GRPO-based VLA RL 中，梯度计算占 78% 的训练时间而非 rollout 收集（21%）。GRPO 对轨迹中每个 chunk 赋予相同 advantage，导致计算浪费在策略已掌握的阶段。关键发现：成功-失败轨迹动作方差可作为每阶段梯度方差的可测量代理。

## Motivation
VLA RL 后训练计算开销大，现有加速集中在 rollout 收集（更快模拟器/世界模型），但真正瓶颈在梯度计算。

## Method
Probabilistic Chunk Masking (PCM): 对每条轨迹，基于成功-失败动作方差为语义阶段评分，概率采样固定 chunk 预算进行反向传播。仅反向传播 <20% 的 chunks。

## Experiment
三个 LIBERO benchmark：匹配标准 GRPO 最终成功率，2.38x wall-clock 加速，4.8x 梯度更新加速，60% 峰值激活内存降低。

## Value
VLA RL 训练效率优化，world model 仅在 abstract 中被提及为加速 rollout 收集的手段。核心贡献是梯度计算的效率优化，与世界模型方向无关。
