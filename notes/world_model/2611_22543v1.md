# JointGV: Structure-Aware Correction of Visual World Models with Parallel Graph Dynamics for Long-Horizon Modeling

## Insight
观察：视觉世界模型在递归预测时，关节和物体关系比整体画质更易漂移；独立图节点和视觉 token 虽无一一对应，其动作诱导的变化描述同一物理转移。推论：用预测图变化及节点位置修正视觉潜状态，可能抑制长时漂移。作者以纯视觉残差、同标签辅助监督、图运动广播和变化匹配消融支持图预测本身与分配方式有贡献；但图质量下降时收益也下降。

## Motivation
DINO-WM、DreamerV3 等动作条件视觉模型长时滚动易累积结构误差。现有图世界模型常替换原视觉状态，残差方法则只利用原潜空间。核心问题是如何把独立的关系预测接入既有视觉动力学，且兼容空间 token 与全局隐状态。

## Method
从 RGB 经 RelTR 特征与任务角色查询构图，含节点特征、二维位置和关系；图动力学按历史状态与动作做关系消息传递，训练时用 K 步自回馈。视觉主干并行预测下步状态。对空间 token，把视觉变化与图节点变化投影到共享空间，以 Sinkhorn OT/余弦匹配建立软分配；预测节点位置再给出局部空间参考。门控、有界残差修正视觉预测，原视觉编码器和动力学不接收修正梯度。全局隐状态用注意力汇聚图变化。创新点是跨粒度变化耦合的可插拔修正接口。

## Experiment
DMC Cheetah Run、Walker Walk 上对 DINO-WM 与 DreamerV3 各做三种子、32 步滚动；另测 Finger Turn Hard、真实 RM65-B 倒立摆视频及 MuJoCo 控制。四个模型-任务组合 32 步平均关节位置误差下降 11.1%–28.0%：例如 DINO-WM Walker 10.740→7.682 px，DreamerV3 Walker 5.835→4.336 px。Cheetah 同主干对照中纯视觉残差 0.898→0.893 px，图运动广播 0.815，变化匹配 OT 0.791；独立热图关键点评估也观察到 13.6% 下降。Finger Turn Hard 14.861→10.754 px，RGB MSE 11.29→5.44×10⁻³。真实倒立摆 DINO-WM 极角误差 12.56°→6.69°；MuJoCo 6 秒任务成功 0/50→46/50。指标含关节/极角误差、DINO token MSE、RGB MSE、SSIM、LPIPS；实体距离分层和观察器噪声消融显示图预测失准会削弱收益。

## Value
对长时视频/隐式世界模型值得精读：用可解释的实体动力学作外部校正，且无需改原模型权重。可借鉴变化对齐、位置路由和独立观察器评测；仍需评估额外图模型成本与自动实体发现。

## Strengths
覆盖 DINO-WM 空间 token、DreamerV3 全局隐状态及 LeWorldModel；有同主干残差/标签对照和独立关键点评估；明确区分 MuJoCo 控制成功与硬件上的短时演示。

## Weaknesses
图观察器依赖任务指定节点角色及训练时的状态/几何标注，可扩展性受限；额外图动态与 OT 带来推理成本。实机七对试验两组均 7/7 触发失败停止，尚未稳定平衡 6 秒。论文附录承认按窗口 bootstrap 的置信区间因同一回合相关而偏乐观；图节点定位错误可能进一步污染滚动修正。

## Future Work
作者提出自动角色发现、置信度感知修正、扩展到更多视觉模型以及稳定的实机闭环部署。

## Rating
创新度评分：3/5 - 将独立图预测以变化匹配接入原潜模型并有扎实消融，但依赖现成图网络、OT 与有界残差模块。
相关度评分：3/3 (Core) - 直接处理视频/隐式视觉世界模型的长时结构一致性与控制。

## TL;DR
独立场景图预测经变化对齐修正视觉潜状态，改善 32 步结构误差和仿真控制；值得精读。
