# μMPC: Microsecond-Scale Nonlinear and World Model Control from Edge to GPU via Koopman-Linearized Precompilation

## Insight
观察：Koopman 潜动力学虽可高维，但固定模型与时域下未来输出对动作序列是仿射的。推论：可预编译“动作→未来输出”映射，把在线 MPC 凝缩成仅含 $Hn_u$ 个变量的二次规划，矩阵逆随固定代价离线计算；更新目标/线性约束时只需矩阵向量乘和投影。推导是代数等价（在线仍用近似模型）；硬件与视觉任务实验显示该结构可显著降低求解延迟。

## Motivation
潜空间视觉世界模型常需重复 rollout 或采样搜索，难在边缘设备上满足控制频率；仅优化模型预测误差又未必产生可控制的表征。已有 Koopman MPC、凝缩与缓存求解器仍可能保留高维状态或需要在线重分解。快速且可约束的规划是重要问题。

## Method
学习 $z_{t+1}=Az_t+Bu_t$ 与输出解码，以有限时域映射将未来目标/约束写成动作序列 $U$ 的二次目标和线性不等式；固定 Hessian 加近端正则后离线存储逆或分解，在线用原始-对偶迭代，目标改变仅更新线性项，约束改变更新乘子项。训练除多步状态/潜预测损失，还反传“从目标轨迹优化出的动作是否恢复示范动作”的可微 QP 损失，并用 DAgger 聚合控制器访问状态。技术贡献是预编译求解与控制导向模型学习的组合，尤其适合低维动作、高维潜变量。

## Experiment
Dubins、平面/3D 四旋翼、Crazyflie、Go2 四足、双臂绳索、Reacher 和实体机械臂。无约束 CPU 中位求解 23 μs；Crazyflie 飞行中约 24.57 ms；200 架四旋翼 GPU 批量约 32.1 ms、到达率 98.4%、碰撞率 2.58%。可微 QP 在四旋翼 $H=75$ 时将成功率从 3.7% 提至 97.7%，加 DAgger 使长时域仍达 95% 以上。视觉任务用图像编码成 36 维状态再提升至 2048 维：双臂绳索/ Reacher 求解 0.725/0.427 ms，成功率 94%/62%，LeWM 和 Fast-LeWM 在相同测试为 24%/4% 与 46%/8%，但作者采用不同于原论文的更随机目标设定。实体方块操作展示可微 QP 对垂直控制的帮助。报告均值/方差、求解器和训练消融，但跨算法训练设置并非完全等价。

## Value
对隐式世界模型规划有直接借鉴：若能学出足够准且可控的近线性潜动力学，动作空间凝缩可绕开高维潜轨迹搜索，并让控制表现参与表征训练。适合研究低延迟规划与闭环控制，但不解决视频生成或复杂场景建模。

## Strengths
从代数推导、可微训练到 CPU/边缘/GPU 和实体机器人覆盖完整；明确区分预测损失与控制损失；固定算子使变化约束和多智能体批量求解可行。

## Weaknesses
依赖高维系统能用足够准确的线性 Koopman 近似；预编译要求模型、时域和代价权重固定，变化后需重编译；迭代预算结束可能残留约束违例，误差收紧经验设定、无形式安全保证；23 μs 是无约束小问题，不能代表视觉/复杂约束全系统延迟。

## Future Work
作者建议建立表征维度、训练时域与闭环表现的选型规律，把约束纳入模型训练以减少迭代，并为模型误差和安全收紧提供正式校准。

## TL;DR
将高维 Koopman 世界模型预编译为动作空间二次规划，并用可微控制损失训练，实现亚毫秒视觉规划；值得精读。
