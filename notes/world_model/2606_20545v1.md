# Current World Models Lack a Persistent State Core

## Insight
核心 observation：视频世界模型常把“世界”绑定在当前可见画面上；当相机转走再返回时，隐藏对象的事件状态往往停在离开视野前，或被重新合成。

推论：可见质量、相机控制、几何先验和模型规模都不能自动带来“不可见期间仍持续演化”的状态核。论文通过 WRBench 把相机运动视为对可观测性的干预，分离“是否转走/返回”和“返回后状态是否正确”，证明 re-observed state consistency 是独立能力。

## Motivation
现有视频/世界模型 benchmark 多评估画质、运动、相机可控性、物理常识或多轮一致性，但没有系统测试：目标离开视野后，世界事件是否仍按时间推进。

这是视频世界模型的关键问题。如果模型只能维护 tracking shot，而不能维护 observation-independent state，它更像条件视频生成器，而不是可用于交互、规划或仿真的世界模型。

## Method
提出 WRBench：
- Natural-25：25 类自然场景，事件设计拆成空间位移和状态变化。
- Viewpoint intervention：给定初始画面、事件和相机动作，让目标短暂不可见再返回。
- 六维诊断链：requested-camera precision、prompt-camera alignment、visual integrity、visible spatial/state consistency、re-observation support、re-observed spatial/state consistency。
- WRBenchLib 记录不同模型实际得到/执行的控制类型，避免把 source-video、geometry-cache、model-inferred、prompt-only 控制混成一个榜单。
- 用 2,547 条人工标注校准自动评估器。

创新点主要是评价设计：不是提出新模型，而是把“世界状态持久性”拆成可归因的诊断指标。

## Experiment
实验覆盖 23 个视频生成/世界模型、9,600 个视频、四类控制范式。

关键结果：
- 当前模型普遍在目标不可见期间不推进状态，返回时常冻结、重置、消失、错位或分裂。
- Wan 2.1 1.3B 到 14B 提升 re-observation support，但 re-observed state 从约 0.66 降到 0.62，说明规模不直接解决状态持久性。
- Lingbot-World 可见空间/状态一致性较高，但 requested-camera precision 低，体现“看起来稳定”和“按干预测试世界状态”是两回事。
- 人类校准显示各诊断维度有较好一致性，尤其 visual integrity、人类偏好和可判定返回边界。

## Value
价值很高：这篇论文清楚指出视频世界模型的一个核心短板，即缺少独立于观察的 persistent state core。对后续模型设计的启发是：需要显式 what-memory、endpoint persistence objective，或训练时构造隐藏-返回监督，而不是只追求更好画质/相机控制。

局限：论文是 benchmark/诊断工作，没有给出模型解决方案；自动评估仍依赖 VLM gate，复杂事件的状态判定可能有偏差。

创新度：4⭐ — 不是新生成架构，但提出了强问题定义和系统诊断基准，对视频世界模型评价范式有明显推进。

相关度：3 (Core) — 直接评估视频世界模型的状态持久性，核心相关。

## TL;DR
提出 WRBench 诊断视频世界模型缺少不可见状态核，结论扎实，值得精读作为评价和模型设计依据。
