# Masked Visual Actions for Unified World Modeling

## Insight
核心 insight 是把动作从机器人专用坐标系转成像素空间的可见 mask 轨迹：世界模型不必理解某个机械臂的 action space，只要学习“哪些可见实体如何运动”。在观察到稀疏末端执行器轨迹和骨架控制容易受 embodiment 限制后，作者推论像素级可视动作能统一前向动力学、逆向动作提取和跨机器人泛化，并用 DROID/BEHAVIOR、真实夹爪和双臂场景做了验证。

## Motivation
机器人视频世界模型常用低维动作、末端执行器轨迹或 skeleton 作为条件，但这些表示和机器人形态、相机、任务绑定，难以迁移到未见 gripper、双臂或物体反事实运动。本文解决的问题是：能否用一种统一、可视、embodiment-agnostic 的动作接口，让同一个视频模型既预测动作后果，也能从目标物体运动反推出机器人动作。问题本身是机器人世界模型里的关键接口问题。

## Method
方法是在视频中用 segmentation/URDF 渲染得到 active entity 或 passive object 的 mask 轨迹，把它作为条件输入 Wan-Fun-Control/Wan2.2 系列视频模型，并用 LoRA 微调。训练数据包括约 15 小时、约 1k DROID demo 和 4k RoboCasa/BEHAVIOR 类样例，既有成功也有失败。前向模式给机器人 mask 轨迹预测环境变化；逆向模式给物体运动轨迹生成能导致该运动的机器人视频。创新主要在动作表示和统一任务接口，模型主体仍依赖大视频扩散模型。

## Experiment
对比 Wan2.2 I2V、Wan-Move、Ctrl-World，以及稀疏 EEF/skeleton 控制。DROID 上达到 LPIPS 0.0945、SSIM 0.887、PSNR 23.74；BEHAVIOR 上 LPIPS 0.123、SSIM 0.843、PSNR 22.90。稀疏 EEF/skeleton 在分布内接近，但在真实自定义夹爪、未见双臂上明显失败。规划实验用 diffusion policy 生成候选动作，Gemini 评估器做 Best-of-N 选择，多个 RoboCasa 任务成功率提升约 7-26 个百分点。作为 policy evaluator 时，模拟成功率与真值相关 r=0.982，但有正偏；动作提取任务 CoffeeServeMug 上成功率 90%，高于 SmolVLA/ACT/DP。

## Value
对视频/机器人世界模型很有启发：动作接口不一定要是低维控制量，像素级实体运动可以作为跨 embodiment 的中间层。待解决问题是评估仍偏短 horizon，规划闭环依赖外部策略和 VLM 评估器，且相关性不等于真正因果可控。

## Strengths
统一了前向预测、规划筛选和逆向动作生成三个任务；mask action 对不同机器人形态更稳；实验覆盖仿真、真实视频、自定义夹爪和双臂，问题抓得准。

## Weaknesses
底层生成模型成本高、推理慢；因果性与可执行性仍靠视频相似度和外部评估间接衡量；训练数据规模不大，复杂接触、遮挡和长程任务仍未充分证明。

## Future Work
作者指出能力和速度受 base video model 限制，未来需要更强、更快的视频模型，并进一步处理安全使用和更可靠的闭环规划。

## Rating
创新度评分：4/5 - 动作接口设计很有辨识度，并在多个机器人世界模型用例中体现效果，但不是从底层重新定义视频世界模型。
相关度评分：3/3 (Core) - 直接研究机器人视频世界模型的动作条件、规划和逆向动作生成。

## TL;DR
Masked Visual Actions把像素mask作为可生成动作接口，统一前向规划与逆向动作提取，值得精读。
