# Deform360: A Massive Multi-view Visuotactile Dataset for Deformable World Models

## Insight
有明确的经验性 insight：可变形物体的世界模型不能只看 RGB 视频预测，必须同时评估几何、接触和动作可控性。论文通过统一数据和 benchmark 观察到，3D 粒子模型在低数据下受物理先验保护，2D 视频基础模型在数据规模和物体多样性增加后更容易泛化；两者的优势边界并不相同。

## Motivation
可变形物体交互长期缺少大规模、多视角、带触觉和真实机器人动作的数据。已有工作多聚焦刚体、短视频或单一传感器，难以评估世界模型是否真正学到 cloth、rope、sponge 等物体的 3D 形变和接触动力学。这是机器人操作和可变形世界模型的关键瓶颈。

## Method
Deform360 采集 198 类日常可变形物体、1,980 条交互序列、约 215.7 小时、2,330 万帧数据，使用 41 个相机和双手触觉 UMI gripper。论文还构建 markerless 的视触觉 3D 跟踪流程，输出密集几何、运动和接触监督。方法创新主要在数据系统和评价协议，而非单个模型结构。

## Experiment
实验覆盖重建/跟踪、接触预测、2D 视频模型与 3D 粒子模型对比、以及基于模型的机器人 MPC。指标包含几何误差、图像质量、动作跟随、接触预测和规划成功率。结果显示 Cosmos 等视频模型零样本图像质量较强，但动作服从不足；3D 模型数据效率高，但缺少大规模预训练带来的泛化。

## Value
这篇更像 deformable world model 的基础设施论文。对我们有价值的是：评价世界模型时要拆开视觉保真、3D 几何、接触和控制，而不是只看 FVD/PSNR。它也提示 2D 生成式先验和 3D 物理先验需要融合。

## Strengths
数据规模、传感器覆盖和任务覆盖都很强；benchmark 设计直接指向机器人控制；对 2D/3D 模型优劣边界的分析有启发。

## Weaknesses
markerless 跟踪仍受自遮挡影响；高度塑性材料会破坏局部刚性/平滑性假设；触觉信号主要是法向压力，缺少微滑移等细粒度接触信息。

## Future Work
作者提出需要更鲁棒的遮挡跟踪、更丰富的触觉表示，以及把 2D foundation model 的泛化能力和 3D 物理模型的可控性结合起来。

## Rating
创新度评分：4/5 - 数据和 benchmark 建设显著推进 deformable world model，虽然不是新范式模型。
相关度评分：3/3 (Core) - 直接面向可变形物体的 3D/视频世界模型和机器人控制。

## TL;DR
大规模视触觉 deformable 数据集系统比较 2D/3D 世界模型，数据和 benchmark 价值高，值得精读。
