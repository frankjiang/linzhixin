# Helping Music Co-Creation Agents 'Listen' Well: Hierarchical Self-Supervised World Models for Understanding and Generation

## Insight
有，但主要属于音乐表征。Observation 是音乐属性具有不同时间尺度，而单尺度 latent 或重构目标不会自然提供可读的层级语义。作者发现冻结的分层 Swin JEPA 中，phrase boundary 在粗层 L0–L2 最易解码，note density、chroma/chord 在细层 L4–L5；纯自监督可形成时间/短语结构，但和弦监督会把 harmony 从细粒度统计提升到粗层，并把未监督 key detection 0.16 提到 0.70。推论是层级 receptive field 可作为抽象尺度，而“是否出现某种语义”仍受训练目标决定。证据来自 linear/ridge probes 与消融，不是表征可辨识性证明。

## Motivation
音乐共创 agent 既要“听懂”结构、能把观察说给人听，又要基于已有片段给有限建议；纯大模型或纯生成 latent 未必可解释，重构与语义表征也存在目标冲突。作者用 RAE 思路把 encoder 与 decoder/generator 分离，并坚持小模型、本地 CPU、用户保留创作权。问题本身有应用价值，但域是 MIDI symbolic music，而非用户关注的视频/3D物理世界。

## Method
输入是 128×128 二值 MIDI piano-roll crop：pitch×time，时间量化为 32 分音符，约覆盖 4 小节，舍弃 velocity。2.55M Swin V2 产生 L0–L5 六级 embedding，总维度 16,128，几乎不压缩。训练随机产生时间/音高平移 view；equivariance loss 让 embedding distance 与标准化 shift magnitude 成比例，避免完全 shift-invariant；SIGReg 以随机投影的 Epps–Pulley test 逼近 isotropic Gaussian、防 collapse；EMA teacher+predictor 做跨层/层内 masked embedding prediction；L0–L2 的 soft factorization 让同向 shift difference 平行、反向反平行、pitch/time 正交。

生成侧冻结 encoder，对每层做保留 ≥90% variance 的 PCA，条件从 16,128 降至 4,835；小型 conditional flow-matching model 从 pixel noise 直接生成 piano roll，训练用 optimal-transport pairing 和 per-level/spatial conditioning dropout。用户 mask 区域对应的 PCA patch 被丢弃，模型补全后，mask 外直接拷回原输入；dropout 的层级和强度控制只改音符还是重写片段。

## Experiment
主要自监督模型在修正后的 POP909 split 上训练 250 epochs，并与 DINOv2、早期非严格可比 MRJ、带 chord/phrase auxiliary head、以及 909/3,636 首 Lakh 子集模型比较。冻结 probe 包括 note density R²、cross-song separation、time-offset R²、root/joint chord、key、chroma R² 和 phrase AP/AUC。

MRJS 的 chroma R² 0.65、phrase AP/AUC 0.27/0.61，优于 DINOv2 0.36、0.21/0.57；但 note density 0.88 低于 DINOv2 0.93。加入 chord head 后 root/joint chord/key 为 0.59/0.54/0.70；phrase head 仅把 AP 0.27→0.29。Lakh 4× 在相同预算下不稳定，chroma 0.76→0.61、cross-song 0.62→0.77（越低越好）。generation 只用 6 songs×3 seeds：自条件重构 pixel F1 0.996±0.004，mask note density 随 dropout 从 100% 降到 96%/76%/53%，没有音乐质量真人评测或强生成基线。默认 10 Euler steps 单次建议为全 CPU 2.8 秒、MPS 0.6 秒、RTX 4090 laptop 0.10 秒。

## Value
对隐式世界模型的可借鉴点是：多尺度 JEPA latent 可分别承载不同时间尺度语义；无需让预测表征同时负责像素重构，另接轻量 conditional generator 即可把 latent 变成可视建议；结构化变换等变和层级 dropout 可提供可解释控制。但论文的 action 是 crop shift，未学习环境动力学、控制或长时未来，和视频/3D世界模型只有方法层面的间接联系。

## Strengths
小模型、本地低延迟和 human-in-the-loop 目标一致；清楚区分表示 probe 与真正 chord detector；分层结果、辅助监督、Lakh transfer、深度/SIGReg/chord weight 消融较丰富；作者诚实说明早期 checkpoint 数据损坏、生成有 off-note 和下游表现有限；图形 mask 与 per-level dropout 的交互设计直观。

## Weaknesses
把符号音乐 encoder 称为 world model 较宽泛：没有 action-conditioned causal transition、rollout/planning 或环境交互，shift prediction 更接近自监督 augmentation task。数据仅几百到几千首 MIDI，单作者实验，probe 多次跨层取 best 容易选择偏差，几乎没有置信区间/多 seed；phrase AP 仅 0.27，接近简单固定网格参考。chord 结果依赖标签，与“无音乐理论词汇”的主叙事存在边界。生成评估只有 6 首歌、pixel F1 和 note density，F1=0.996 更像条件信息泄漏/复制能力，不能说明音乐新颖性、和声合理性或共创价值；PDF 也未充分给出 flow architecture、训练数据和超参数。二值 piano roll 舍弃 velocity、onset、instrument，时间窗仅 4 小节。

## Future Work
作者提出用序列模型连接最粗层或折叠 piano roll 扩大时间域，增加 onset、velocity 和多乐器 channel，并继续以人类创作辅助而非闭环替代为目标。研究上还需要真正的音乐家 user study、音乐质量/多样性基线，以及 action-conditioned latent dynamics。

## Rating
创新度评分：2/5 - 分层 JEPA、SIGReg、flow matching 与图形 inpainting 的组合完整，但主要是已有技术在小型符号音乐系统中的应用。
相关度评分：1/3 (Tangential) - 使用 JEPA/RAE 的隐式表征思想可借鉴，但任务是符号音乐，不是视频、3D或物理世界动力学。

## TL;DR
用分层JEPA表征和流匹配生成符号音乐，跨域启发有限，可跳过。
