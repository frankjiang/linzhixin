# Reinforcement Learning: From Algorithms To Foundation Models

## Insight
有，主要集中在论文后半部分。Observation 是 foundation-model 时代的 RL 不再只是在真实环境中反复试错，而越来越依赖可生成未来、可评估策略、可长期记忆的世界模型。论文中 DWM、VRAG、RAD 分别给出三个推论：序列级扩散 dynamics 能缓解 one-step compounding error；视频世界模型需要显式状态/检索记忆来维持长程一致性；DiT 视频模型需要可并行训练的持久 memory 来突破窗口遗忘。

## Motivation
这是一篇博士论文，覆盖从传统 RL 算法到 diffusion/video/world-model foundation models 的研究线。对用户最相关的是 Part III：Diffusion World Model、DOLLAR 视频生成蒸馏、VRAG 视频世界模型、RAD 带记忆的视频世界模型。

## Method
DWM 用 return-conditioned diffusion world model 直接生成多步 state/reward 序列，并嵌入 TD3+BC/IQL/PQL 的 critic target。DOLLAR 用 VSD+generalized consistency distillation+latent reward model 做少步视频生成。VRAG 在 latent video diffusion world model 中加入 action conditioning、global state conditioning，并用按全局状态检索的历史帧作为记忆。RAD 在 DiT block 中加入 RNN/LSTM/Mamba/TTT 记忆分支，并用 hidden-state prefetch 支持并行训练和长视频 rollout。

## Experiment
DWM 在 D4RL locomotion 9 任务中，world-model 增强算法平均 0.643，高于 one-step MB 平均 0.446，且长 horizon 更稳；DWM-TD3BC 推理快于 Decision Diffuser。DOLLAR 在 VBench 上少步 T2V 达到或接近强商业/开源模型，并用 latent reward model 降低显存。VRAG 在 Minecraft 长视频和 RealEstate10K 上提升 SSIM/PSNR/LPIPS/FVD，Minecraft world coherence SSIM 0.506 vs DF20 0.466；RealEstate10K SSIM 0.9116 vs DFoT 0.4436。RAD 在 Memory Maze 和 Minecraft 上相对 diffusion forcing 改善长程指标，且分析了 LSTM/Mamba/TTT 的资源与效果。

## Value
整体价值高：它把 RL、扩散式世界模型、视频长程记忆和策略评估串成一条研究线。对我们最值得精读的是 Ch6、Ch9、Ch10；前半传统算法章节可按需略读。

## Strengths
涵盖多个已成型工作；对视频世界模型长程一致性、记忆和 action conditioning 的讨论很直接；实验覆盖离线 RL、Minecraft、RealEstate10K 和 memory maze。

## Weaknesses
作为博士论文，章节之间贡献粒度不一；很多结果是已有/待发表论文的汇编，不是单一统一方法；部分章节细节较长，需要选择性阅读。

## Future Work
各章节的未来方向包括更强的长程记忆、更一般的 action-conditioned video world model、更高效的少步生成和把世界模型更深地接入 RL 训练。
