# UniAction: Unified Action Conditioning for World Models

## Insight
观察：力、相机按键、手与机器人关节虽形式各异，都可拆成“做什么”的离散语义和“何时何地生效”的连续坐标。由此将动作 token 放进视频骨干已有的 3D RoPE 坐标系，可复用预训练的时空对应关系；位置编码/注意力路径替换消融支持这一判断。另一个观察是自注意力中动作总权重天然随 token 数量增长；给所有动作 logit 加 `log(Nref/N)` 可代数消去该数量因子，实验也显示稀疏的力和相机动作受益最大。这是注意力权重的代数性质，并非跨动作泛化的理论保证。

## Motivation
现有动作条件视频模型多按动作类型分别设计接口和训练，稀缺的带动作标注视频因而被分割。渲染成控制视频对力等抽象动作不自然；独立编码后交叉注意力又需重新学习动作与画面的位置对应。统一接口与联合训练是可扩展世界模型的关键问题。

## Method
- 将动作表示为稀疏元素集 `{(语义身份, t, y, x)}`；共享码本按身份取 token，再映射坐标到 Wan2.2 视频潜变量网格，与视频 token 一起经原生 3D RoPE 和自注意力处理。
- 手/机器人：逐帧逐关节放置 token；相机：八种移动/旋转按键映射到画面边缘固定位置；力：同一时刻的向量首尾各一个 token，用空间位移编码方向和幅度。
- 对每个视频查询，将动作注意力 logit 加 `log(Nref/N)`（实验中 `Nref=784`），平衡稀疏和密集动作的注意力总量。Wan2.2-I2V-A14B 高噪声专家作骨干，主要训练动作分支 LoRA；核心创新是通用动作表示、复用骨干位置几何及数量校准的组合。

## Experiment
- GoalForce、SolarWM、EgoDex、DROID 各取 1 万个 81 帧视频；同一骨干和 4 万样本下比较 VACE 式视觉条件、独立编码器加交叉注意力，以及 UniAction。107 个未入训练的源场景构造 410 个反事实动作条件，以光流/跟踪/相机位姿估计打 Action Following 分，并报告 LPIPS；100 人对 60 组样例打动作服从和画质分。
- 四类动作的 Action Following：力 `0.763`（VACE `0.605`）、相机 `0.637`（Cross-Attn `0.531`）、手 `0.412`（VACE `0.294`）、机器人 `0.652`（VACE `0.525`）；四类 LPIPS 均优于两个通用条件基线。图 3 的定性帧显示力作用、视角及关节轨迹更贴近指定动作。
- 联合模型在力/相机/手/机器人上分别得 `0.763/0.637/0.412/0.652`，四个同结构单任务专家为 `0.544/0.518/0.370/0.631`；但相机 LPIPS 联合模型略差（`0.486` 对 `0.478`）。改用交叉注意力或非骨干 RoPE 后，手/机器人分数跌至约 `0.05–0.08`；移除数量校准使力从 `0.719` 降至 `0.519`、相机从 `0.584` 降至 `0.497`（此消融使用 5B 骨干）。延后施力至训练未见的时刻时，也展示了定性时间泛化。

## Value
为视频世界模型统一混合动作数据提供可直接复用的条件接口。特别值得借鉴的是把动作坐标对齐预训练视频位置编码，以及用反事实动作评测“控制是否真正生效”。仍需验证跨新动作类型、真实 3D 几何与长期闭环交互。

## Strengths
四类结构差异明显的动作共享一条条件路径；对照保持数据和骨干一致，另有单任务专家、位置编码及数量校准消融；附录给出注意力推导、详细评测规则与开销（该方法约 4.04 亿可训练参数，低于两类通用基线）。

## Weaknesses
所谓通用接口仍依赖人工设计每类动作的语义词表和 2D 投影，没验证加入训练外新动作后的迁移；相机按键的固定画面位置只是约定，不能表达真实 3D 作用点。实验片段仅 81 帧，缺闭环规划、长期状态一致性及物理真实性评估；Action Following 依赖离线估计器，不能完全代表因果控制。不同条件基线的可训练参数也不相同。

## Future Work
作者提出继续把新的干预形式接入共享接口、扩展模型可控能力，但未给出具体新动作实验或长期规划方案。

## Rating
创新度评分：4/5 - 统一异构动作的语义/坐标接口，加上原生位置几何和数量校准，带来跨四类动作的明确增益。
相关度评分：3/3 (Core) - 直接研究动作条件视频世界模型及其联合训练。

## TL;DR
以语义身份和时空坐标统一四类动作，并校正 token 数量偏置，显著改善可控视频生成；值得精读。
