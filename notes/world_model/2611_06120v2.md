# ReactWorld: Structuring Interaction Responses for Embodied Video Generation

## Insight
观察：生成视频的关键交互响应往往只占小区域和短时间段，整体画面连贯不保证接触后物体按任务变化。作者让生成骨干内部预测角色、未来响应强度和局部位移，再以“有动态条件输出−零动态条件输出”构造对象特征增量，辅以位移偏置的跨帧注意力。同数据消融中，单加响应预测头的 EZS Domain 为 84.11，完整反馈为 86.98；去掉位移偏置降至 85.38，支持反馈路径有用，但仍属经验验证。

## Motivation
具身视频模型常在“物体提前运动、抓取后脱落、无关物体跟着动”等局部物理响应上失败。已有运动轨迹约束和区域关系监督未必确保未来对象反应与任务一致。对交互视频世界模型而言，这比纯视觉流畅度更接近可用性。

## Method
输入首帧和任务指令，基于冻结 Wan2.2-I2V-A14B 及 LoRA 训练流匹配生成器。在第 12 个 DiT 块读取中间特征，用四个头预测机器人/直接目标/受影响对象/背景角色、首帧坐标中的未来响应强度、每个时间区间的运动支持和 2D 位移。以角色及响应强度池化交互上下文；对象分支做零动态参考差分，机器人分支直接更新特征；另把位移转成局部 7×7 跨帧注意力的软偏置。约 50 万训练片段中 43.5 万带联合响应标注，标签借 Qwen3-VL、SAM3、CoWTracker 构建；推理只需首帧和文字。创新是把可解释的局部响应预测变为生成器内部反馈。

## Experiment
RBench 九类均分 77.51，优于同数据同预算 Video-FT 的 71.94、PhysisForcing 的 74.21；EZS-Bench Domain/Quality/Avg 为 86.98/76.75/81.87。RBench 机器人与对象稳定性 RSS 从 PhysisForcing 的 11.24 到 11.51，物理语义合理性 PSS 4.52→4.62；50 人主观评分中接触合理性 4.06，对 Video-FT 的 3.24 差异显著，但相对 PhysisForcing 3.78 的差异未达校正后显著。去掉零动态参考，EZS Domain 从 86.98 降至 85.12；等幅度对照为 85.95。人为修改反馈位移能定性改变机械臂趋近方向。

## Value
值得精读局部响应场、零动态对照和注意力反馈的设计，它把“预测交互结果”从辅助损失推进到生成路径。若用于规划，还需独立验证动作可控性与物理状态真实性。

## Strengths
同初始化、同数据、同预算的 Video-FT 对照及多层消融；同时报告自动基准与人评；对零参考做等幅度对照，较好隔离机制作用；区分直接目标和受影响对象。

## Weaknesses
内部响应仍是 2D，缺少明确 3D 几何、接触力及长期物体记忆。模型条件只有首帧与任务文本，没有连续外部机器人动作，不能直接当作可查询动作的模拟器。大量评价由视觉语言模型给出，任务完成分数不能代替真实闭环机器人成功率。

## Future Work
作者计划探索时间一致的 3D 运动表示和 rehearsal，以提升空间一致性。

## Rating
创新度评分：3/5 - 结构化响应预测与零动态差分反馈有明确设计和消融，但建立在现有视频生成骨干及 2D 运动标注上。
相关度评分：3/3 (Core) - 直接研究具身视频世界模型的交互动态生成。

## TL;DR
用局部响应场、零动态参考和位移注意力改善具身视频中的物体反应；研究交互建模值得精读。
