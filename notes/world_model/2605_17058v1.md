# Learning Multi-Timescale Abstractions for Hierarchical Combinatorial Planning

## Insight
核心观察：层次化 RL 中高层策略运行在 Semi-MDP 上（动作持续时间可变），但现有世界模型（如 Director）假设固定步长的 macro transition，无法建模可变持续时间的子目标。LMTA 的关键设计：让潜在空间的几何结构编码时间尺度——macro transition 的位移大小与子目标的实际执行时长相关，从而不需要显式预测持续时间。

## Motivation
Sequential Stochastic Combinatorial Optimization (SSCO) 是一类指数级动作空间+随机动态+长 horizon+有限资源的决策问题。现有 HRL 方法要么无模型（无法前瞻规划），要么使用固定步长世界模型（无法适应可变持续时间）。需要一个 SMDP-aware 的多时间尺度世界模型支持树搜索规划。

## Method
ICML 2026 接收。三个核心组件：
1. **Latent-Space MCTS Planner**: 在潜在空间中对子目标进行树搜索（类 MuZero），选择子目标 z_k 和预算 b_k
2. **Multi-Timescale SMDP World Model**: 单一潜在空间同时支持 micro（逐步）和 macro（子目标级）动态。通过三个几何约束损失：L_cap（限制单步位移）、L_push（确保 macro 位移超过最小 margin）、L_order（按持续时间排序 macro 位移），使得潜在空间自然编码时间尺度
3. **Subgoal-Conditioned Budget Policy**: actor-critic 预算策略，条件化在当前状态和所选子目标上，实现上下文感知的资源分配

## Experiment
- AIM（自适应影响力最大化）和 SOP（随机定向问题），N=500 节点图
- LMTA 在所有配置（不同 horizon T 和预算 K）上均超越 WS-option、Flat DQN、Director、MuZero
- 问题越复杂（K 越大），LMTA 优势越明显
- 消融逐步验证：子目标条件化 → 预算条件化 → MTS 目标 → 可学习 margin，每步均有贡献

## Value
将世界模型扩展到 SMDP（可变持续时间宏动作）的理论性工作，潜在空间几何编码时间尺度的设计优雅。ICML 2026 接收。但应用场景（组合优化）与视频/3D 世界模型距离较远。对 Dreamer/Director 家族的时间抽象问题有理论参考价值，但直接迁移性有限。
