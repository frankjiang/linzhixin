# CRISP: Fixing Flying Pixels in Latent LiDAR Generation via Diffusion Decoding

## Insight
LiDAR 深度边界在卷积 VAE 解码时被平滑，回投 3D 后产生不属于前后任一表面的“飞点”。冻结编码器与生成器、只替换解码器后，边界几何明显改善，说明瓶颈至少部分位于解码阶段；但在冻结世界模型直接替换时，边缘 F-score 反而下降，不能概括为所有几何指标都更好。

## Motivation
LiDAR latent 生成研究常改潜空间、条件或生成器，默认沿用卷积解码器。稀疏 range map 中缺失回波与真实深度跃迁混杂，常规卷积易跨边界插值；这种误差可能污染 3D 模拟与下游感知。论文聚焦可插拔解码质量，世界动力学本身不是其主要贡献。

## Method
CRISP 将冻结的 LiDM、SVD 或 Wan2.1 编码 latent 经统一适配器变成条件 token；两级 DiT 在像素空间从噪声迭代恢复单通道连续深度，条件在最初和中间层注入。单独 U-Net 根据 latent 与预测深度估计每像素有效回波 mask，最终组合稀疏 range map。深度损失包含有效区域速度回归、深度边缘加权、水平/垂直一二阶差分及低噪声 L1；mask 用 Focal、Dice、边缘/Laplacian 等监督。默认只训练解码端，另考察联合微调编码器。整体是既有像素扩散解码思想针对稀疏 LiDAR 的工程化适配。

## Experiment
在 KITTI-360、SemanticKITTI、nuScenes 上评估 LiDM、SVD、Wan2.1；对照同编码器原解码器，使用 FRID/FSVD/FPVD、JSD/EMD/MMD、3D Chamfer 距离、0.5 米 F-score，并把边缘与平滑区分开。冻结骨干时，SVD 的 FSVD 156.5→40.2、Wan2.1 的 FSVD 100.9→32.5；LiDM 的 FRID 2.235→0.639，边缘 CD 7.913→4.052。深度解码替换和有效回波分支都有消融，后者对边缘 F-score/JSD 有明显贡献。

在冻结 LiDM 世界模型中零样本换解码器，FSVD 37.70→31.87（约降 15.5%）、边缘 CD 96.41→79.55；但边缘 F-score 0.0486→0.0389，JSD 略变差。515M 左右的 CRISP 解码器比 LiDM 原解码器大 60 倍，LiDM 端到端吞吐 369→41 fps；论文主要评估单帧质量，缺少时序一致性和下游闭环收益。

## Value
提醒 3D 世界模型不要只看 latent/生成器：解码器可决定几何边界是否可信。可借鉴“冻结上游、单独替换解码器”来定位瓶颈，以及分区几何指标来避免全局分数掩盖飞点。与视频/3D 动力学建模的直接联系有限，更适合研究 LiDAR 输出质量时参考。

## Strengths
- 明确定位边界错误并以冻结上游的受控替换检验假说。
- 同时报告重建、分布、边缘和完整点云指标，也披露退化项目。
- 跨通用视频 VAE 与 LiDAR 原生编码器检查适用性。

## Weaknesses
- 大型多步解码器相对轻量 LiDM 显著增加成本；容量差异未被完全控制。
- 独立逐帧解码可能造成细结构闪烁，未建模反射强度。
- 世界模型直接换解码器时边缘 F-score 下降；下游感知/规划受益尚无实测。

## Future Work
作者提出多通道扩散预测反射强度、对有效回波密度做校准、引入时间条件抑制闪烁，以及蒸馏减少扩散步数和延迟。

创新度评分：3/5 - 解码瓶颈诊断及稀疏 LiDAR 适配有实证价值，但扩散解码与多数损失模块已有先例。

## TL;DR
以像素扩散解码器修复 LiDAR 边界飞点，揭示世界模型输出端的几何瓶颈；做三维传感器生成时可选读。
