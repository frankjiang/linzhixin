# When Do Conservation Laws Survive Learned Representations? Certified Horizons for Latent World Models

## Insight
论文的核心 insight 是 latent world model 中真正应被认证的不是 learned latent Hamiltonian 或某个 learned witness，而是“decode 回物理坐标后计算的真实物理不变量”。Observation 是模型可以完美保持内部标量，但真实能量已经漂移；因此 conservation certificate 必须绑定 decoded physical invariant，并把 representation、readout、latent dynamics 的缺陷都计入 horizon budget。

## Motivation
论文解决物理 world model 在 learned representation 下的可信 rollout 问题。同行包括 Hamiltonian/symplectic neural nets、learned invariants、Koopman、spectral/Lyapunov/conformal trust horizon；这些工作常关注结构保真或点态误差，但不一定说明 latent 表征下的物理守恒是否仍可认证。该问题与隐式/latent world model 的可信性相关。

## Method
作者推导 shell-horizon certificate：在能量壳 tube 内，certified horizon 由 shell tolerance budget 减去初始化/表示/readout 缺陷，再除以每步 invariant drift。关键对象是 H*(Pi D_psi z)。对于 soft witness C_omega，只有通过 controlled-Lipschitz monotone calibration g_C 与 decoded invariant 对齐后，才能作为证书桥梁；单纯单调 isotonic 不够，因为 Lipschitz 常数过大可让 horizon 归零。所有证书都限制在 tube 或 sub-tube 内，并报告排除比例。

## Experiment
结果沿 state -> learned lift -> pixel 三层展开。state-space Kepler 上 hard symplectic Verlet 5/5 non-vacuous，median drift 0.069，对比 plain 0/5、drift 0.452，但 horizon 短。learned lift 上 hard symplectic/Verlet/SympNet 与 plain 几乎无差，soft B-self witness 在 pendulum 上 R_shell 约 1.30、P(B>plain)=0.88/8 seeds，Duffing 上增益约 2.3。alignment bridge 中 spline calibration held-out R2 约 0.984/0.988，T_align 约 5.1；spurious controls R2 为负。pixel 设置中在 readout-stable sub-tube 上 B-self non-vacuous 9/10，P(T_B>T_plain)=8/10，excluded fraction <=2.3%。Kepler lift 暴露 near-periapsis 几何边界。

## Value
对隐式 world model 有理论价值：它强调“证书对象”必须与真实物理量对齐，而不是相信 latent 内部守恒。对视频/3D world model 的直接落地还远，但对可信 rollout、物理不变量和表示学习非常有启发。

## Strengths
问题定义严谨，区分 hard symplectic prior 和 soft invariant alignment；正负结果都清楚；把像素观测下的 readout bottleneck 诚实限定为 stable sub-tube。

## Weaknesses
实验是低维保守系统，horizon 较短；所有证书都是 tube-restricted；pixel 结果不是全局证书；不声称 benchmark-scale vision world model；Kepler 负结果是特定几何边界。

## Future Work
作者提出未来要研究 near-periapsis 不 stiff 的 observation/lift 表征，扩展 joint-shell certificate 到非奇异多不变量系统，并把 alignment bridge 做成 coordinate-free level-set stability theorem。
