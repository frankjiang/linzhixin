# Kairos: A Native World Model Stack for Physical AI

## Insight
Kairos 的核心 insight 是世界模型正在从“视频生成 demo”转向 Physical AI 基础设施，需要同时 learn、maintain、run worlds：从异构经验学习世界知识，长时维护状态，并以低延迟部署在闭环系统中。论文还强调纯局部时间建模不足以保证长时全局状态一致性，因此需要 hybrid multi-scale temporal memory。

## Motivation
论文面向通用 physical AI 世界模型栈，解决碎片化数据学习、长时状态维护、world understanding 与 embodied control 脱节、部署不可用四个问题。同行包括 Cosmos、JEPA/DINO-world、Genie/Marble/TeleWorld、Dreamer 等。问题设定与用户方向高度相关，但论文是大系统报告，边界较宽。

## Method
Kairos 包括三部分。模型上是 Native Unified Architecture，统一 understanding/generation/prediction，并用 Hybrid Linear Temporal Attention：sliding-window attention 处理局部动态，dilated sliding window 处理中程依赖，gated linear attention 维护长期全局记忆；附理论界给出多尺度记忆降低误差累积的界。训练上是 cross-embodiment data curriculum：open-world video、human-centric data、robot interactions，逐步到 joint world-action training。部署上做 timestep distillation、DMD+consistency hybrid objective、sequence/tensor parallel、DiT cache、kernel fusion、FP8/INT4/tiling 等。

## Experiment
WorldModelBench-robot 上 Kairos-4B total 9.30，超过 Cosmos3-Nano 9.26 等；DreamGen Bench 中 AVG_Score 0.618、AVG_PA 0.538 领先；PAI-Bench 和 general world model benchmarks 也报告 strong SOTA/near-SOTA。效率上 Kairos-4B 720P 5s TI2V 在 A800 上 1GPU 43s、4GPU 9s，显著快于 Lingbot-28B、Cosmos-Predict2.5-14B、Wan2.2-5B。还展示长时生成和 action-policy benchmark。

## Value
对用户方向有价值，尤其是多尺度 temporal memory、部署约束和 world-action training 的系统视角。但创新分散在架构、数据、工程和评测，很多结论是报告式自证，开源/复现实验和独立验证仍关键。适合选读架构和效率章节，不必全篇精读。
