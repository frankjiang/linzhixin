# FilmWorld: Agentic Novel-to-Film Generation through Dynamic Cinematic World Modeling

## Insight
论文 insight 是把长篇小说成片拆成“世界状态构建”和“世界状态演化”：先显式维护角色、地点、道具、声音和场景状态，再并行渲染镜头。观察是长视频生成的失败常来自实体状态在章节/镜头之间丢失，而不是单镜头画质不足；推论是外置显式状态轨迹能改善长程一致性并提升并行化。

## Motivation
多镜头、长叙事视频生成难点在人物身份、服装年龄、地点季节、道具状态和剧情因果的一致性。已有 story/video agent 常逐段生成或靠短窗口记忆，容易在跨镜头和跨章节时漂移。问题对长程生成有参考价值，但与物理/交互世界模型关系较弱。

## Method
FilmWorld 形式化为世界状态 Wt、状态转移 T(Wt, pt)、状态识别 Phi 和渲染器 R(Wt, dt)。系统包含 Narrative Structured Translation、World Entity State Modeling with Visual Anchoring、State-driven Shot Planning、State-anchored Visual Generation、Cross-shot Dynamic State Propagation 和 Closed-loop State Verification。核心是预先 materialize 状态轨迹，再让 evolution/rendering 阶段并行执行。

## Experiment
FilmEval 包含 15 部小说，按 easy/medium/hard 分层，评估 Cinematic Presentation、Film Consistency 和 Novel Fidelity 共 9 个指标，使用 Gemini 3.1 Pro 和人工评估。FilmWorld overall 89.38，高于 VideoClaw 84.19、MovieAgent 83.98 等。人工整体评分 4.25，高于 VideoClaw 3.33。消融显示去掉 explicit world state 后平均分从 90.15 降到 84.28，Character Consistency 从 82.12 降到 54.50；去掉 cross-shot、textual end-state、visual keyframe 或 verifier 也会下降。并行 keyframe 带来约 5.62x speedup。

## Value
最有用的是“显式状态轨迹 + 验证纠错”对长程一致性的启发。对视频世界模型研究可借鉴其外置 memory/state design，但它主要解决叙事和影视制作一致性，不学习物理状态转移，也不支持真实交互控制。

## Strengths
问题规模大；状态建模细；ablation 直接证明显式 world state 对一致性的贡献；同时考虑质量和生成吞吐。

## Weaknesses
评估依赖 LLM/VLM judge，且统一使用同一生成栈会掩盖模型差异；“world model”更多是叙事状态管理；物理因果、3D geometry 和可操作动作不强。

## Future Work
作者展示的失败案例包括 keyframe artifacts、不自然动作和复杂空间不一致，隐含未来需要更强 backbone、更可靠 verifier 和更好的空间/动作建模。

## Rating
创新度评分：3/5 - 显式状态轨迹用于长篇成片有一定新意，但方法主要是 agent 管线组合。
相关度评分：1/3 (Tangential) - 与长视频一致性有间接借鉴价值，但不属于用户关注的视频/3D/隐式世界模型核心。

## TL;DR
FilmWorld用显式实体状态轨迹约束长篇成片，适合借鉴长程一致性，世界模型方向可选读。
