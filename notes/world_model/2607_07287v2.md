# TouchWorld: A Predictive and Reactive Tactile Foundation Model for Dexterous Manipulation

## Insight
主要 insight 是触觉不应只作为低频 observation token 塞进单一 VLA，而应同时承担“预测性接触目标”和“高速反馈修正”两种角色。Observation：视觉和语言能给语义/几何目标，但看不到滑移、力、接触稳定性；接触错误又需要比 VLA 推理更高频的反馈。推论是应把慢速语义规划、中速 tactile world-model prediction 和高速 tactile residual control 解耦。证明主要来自六个真实机器人任务的对比、消融和触觉预测指标。

## Motivation
论文解决灵巧操作中长时任务和接触鲁棒性的矛盾。同行 VLA/触觉策略多是单体模型：把 tactile 作为额外输入，与视觉语言在同一控制频率里处理。这会把慢速任务理解、action chunk 生成和快速接触修正耦合在一起，导致插入、擦拭、拉纸巾、浇花等任务在滑移/扰动时失败。问题在机器人 manipulation 中关键，但它不是用户关注的主线视频/3D/JEPA-Dreamer 世界模型。

## Method
TouchWorld 是多时间尺度层级策略：

1. High-Level Planning Layer 低频更新，包含 Subtask Planner 和 Tactile World Model。
2. Subtask Planner 基于 Qwen3-VL-4B-Instruct，输出 executable subtask 和可选 reasoning。
3. Tactile World Model 基于 Wan2.2-TI2V-5B，按当前 observation、触觉和 subtask 预测短时 visual-tactile subgoal。
4. Visuo-Tactile Goal-Conditioned Policy 是 tactile diffusion Transformer，用任务、子任务、视觉、image-form tactile、proprioception 和预测 subgoal 生成 nominal action chunk。
5. Tactile-Conditioned Refinement Policy 是 Tactile Residual Transformer，在更高频控制循环中根据最近 tactile/proprio history 修正 nominal action window。

训练分四阶段：planner 用 128,866 条 subtask supervision 做 LoRA SFT；Tactile World Model 先用 EgoTouch 人类交互数据预训练，再用 10 小时机器人 demo 约 1.08M frames 微调，预测 17 帧 384x224 visual-tactile target；nominal VLA 用 imitation learning 和 flow matching 训练；最后冻结 nominal VLA，训练 residual refinement layer 拟合高频动作残差。

## Experiment
实验是六个真实机器人任务：Water Flower、Tabletop Clearing、Cup Insertion、Power Plug Insertion、Pot Wiping、Tissue Pulling。每个任务 200 条 teleop 训练轨迹，100 次真实机器人评测，包含 clean 和 human perturbation 两种设置。指标包括任务成功率、Tactile World Model 的 temporal contact accuracy/contact IoU/volumetric IoU，以及 Subtask Planner 的 subtask accuracy/execution success/transition F1。

主结果：clean 平均成功率 TouchWorld 65.0%，高于 FTP-1 49.3%、Pi-0.5 40.7%、GR00T N1.7 39.3%；human perturbation 下 TouchWorld 53.7%，高于 FTP-1 35.2%、Pi-0.5 27.7%、GR00T 26.0%。具体任务上 power plug insertion、pot wiping、tissue pulling 提升明显。

Tactile World Model 预测指标：temporal contact accuracy 86.3、contact IoU 52.7、volumetric IoU 43.8，优于 current tactile copy 的 70.4/31.8/24.6 和 nearest-neighbor subgoal 的 77.5/39.2/31.0。Subtask Planner：memory-augmented SFT Qwen3-VL-4B 达到 subtask acc 88、execution success 65、transition F1 82，超过 zero-shot Qwen3-VL-32B 的 69/54/71。消融显示去掉 tactile input 伤害最大；去掉 residual refinement 主要影响扰动场景；去掉 planner 影响长时一致性；去掉 tactile world model 弱化接触目标。

## Value
对我们直接相关度有限，但有一个清晰启发：世界模型不一定只做长期视频 rollout，也可以预测局部、任务相关的 future subgoal，并与高速 reactive policy 解耦。对具身世界模型而言，这种“预测参考 + 反馈修正”的架构比端到端视频预测更接近可部署控制。不过论文的世界模型是触觉/机器人 subgoal predictor，不是视频世界模型、3D 世界模型或 JEPA/Dreamer 式 latent dynamics 的核心贡献。

## Strengths
- 多时间尺度分层设计合理，清楚区分语义、预测、nominal action 和反馈修正。
- 在真实机器人上做了六任务、扰动设置、组件消融和触觉预测评测。
- Tactile World Model 有独立预测指标，不只是看下游成功率。
- 结果显示 tactile feedback 对接触任务确实关键。

## Weaknesses
- 任务和硬件平台较窄，跨触觉传感器、手型、工作空间和对象类别的泛化尚未证明。
- Tactile World Model 只预测短时 subgoal，多模态未来和不确定性处理不足。
- 层级调度超参数固定，缺少自适应调度和延迟/算力分析。
- 训练数据、触觉硬件和平台工程依赖较重，复现门槛高。

## Future Work
作者提出扩展到更多对象、工作空间和任务组合；改进长时和不确定性感知的 tactile subgoal prediction；研究跨触觉传感器与机器人手的迁移；用更自适应的调度提升快速接触变化下的响应。

## Rating
创新度评分：3/5 - 分层触觉预测与高速 residual feedback 组合扎实，真实实验充分，但主要是机器人触觉策略的系统集成。
相关度评分：1/3 (Tangential) - 只在“预测式世界模型/局部未来 subgoal”思想上间接相关，不是视频/3D/隐式世界模型主线。

## TL;DR
TouchWorld 将触觉预测与高速反馈分层用于灵巧操作，和主线世界模型关系间接，可选读。
