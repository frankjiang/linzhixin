# DecMem: Towards Minute-Long Consistent World Generation with Decoupled Memory

## Insight
首次系统分析了可学习记忆架构在长程视频世界模型中的两个根本瓶颈：(1) 计算效率低下——全局KV缓存随历史线性增长；(2) **注意力分散(attention dispersion)**——当历史帧数增多时，注意力权重被稀释，导致每个token获得的有效信息量下降。关键发现：这两个问题需要用不同的记忆机制分别解决，不能用单一架构同时应对。解法：将记忆解耦为稀疏全局记忆(SGM)处理效率问题 + 锚定局部记忆(ALM)解决注意力分散。

## Motivation
- 问题：交互式视频世界模型如何在分钟级长程生成中保持时空一致性？
- 同行方法：Oasis用滑窗、MineWorld/WorldMem用显式3D记忆——前者无法保持全局一致性，后者计算开销大且稀疏
- 关键需求：需要细粒度、可学习、可扩展的记忆机制，而非粗粒度帧级建模或显式3D重建

## Method
- **Sparse Global Memory (SGM)**：对全局历史帧进行token级稀疏采样，每帧只保留top-k信息量最大的token（基于attention score选择），实现高效全局访问
- **Anchored Local Memory (ALM)**：在局部窗口中使用可学习的anchor token（固定数量），将注意力集中到anchor上避免分散，anchor通过cross-attention从局部历史提取信息并传递给生成模块
- 训练：基于1B参数DiT，在Minecraft数据上训练，支持动作条件和非条件两种模式
- 可扩展性：记忆复杂度从O(T·N)降至O(k·T+A)，k为每帧稀疏token数，A为anchor数

## Experiment
- Minecraft 1920帧（约1分钟）生成：FVD/FID/SSIM均显著优于Oasis、MineWorld、WorldMem等
- 消融验证：SGM和ALM各自独立贡献，组合后互补效果最佳
- 注意力分散分析：可视化展示naive记忆的注意力稀释现象，ALM有效缓解
- 对比：1B模型超越现有所有方法，包括使用显式3D记忆的方法

## Value
工作价值很高——首次从理论层面剖析了长程世界模型的记忆瓶颈，提出的解耦记忆架构优雅且有效。注意力分散的发现对所有基于Transformer的长程生成模型都有启示。分钟级一致生成对交互式世界模拟（游戏、embodied AI）有直接应用价值。
