# When a Verified World Model Still Loses: Play-Adequacy vs Prediction-Accuracy in LLM-Synthesized Code World Models

## Insight
论文的 insight 是：对 planning 用 world model 来说，随机 transition accuracy 不是充分的 adequacy 指标。Observation 是 verification gate 采样自随机游戏轨迹，而部署 planner 会集中访问战略关键但随机罕见的深层区域；推论是模型可在 gate 上 100% 正确、在 planner 分布上 >=98% state-accurate，却因漏掉少数关键规则而系统输棋。作者给出 danger = play cost * (1-rarity)^N，其中 gate-miss 项由 Bernoulli 采样精确证明，play cost 通过 instrumented game 测量或在 Beacon witness 上精确证明。

## Motivation
论文解决 LLM-synthesized Code World Model 的验证问题。CWM 范式让 LLM 根据规则和轨迹生成可执行游戏规则，MCTS 在其上搜索；通常通过随机轨迹 transition gate 验收。作者质疑这种验收是否能保证规划可用。虽然对象是代码游戏模型，不是视频/3D world model，但它直指“world model accuracy 与 planning utility 不一致”的通用问题。

## Method
作者搭建 CWM contract，包括 initial_state、legal_actions、apply_action、is_terminal、returns，以及 imperfect-information 下的 observation/infer_states。先在 tic-tac-toe、Connect Four、generalized tic-tac-toe、army5x5a、Trike 上确认小型完整规则游戏中 gate 往往是 identifying。然后构造 army5x5a + material-at-cap 规则：随机 play 触发率约 2.53%，但 competent MCTS 约 50% 游戏会到相关区域。缺失该规则的 CWM 可通过 gate。理论部分给出 gate-miss probability (1-r)^N 和 query-hit mass 上界；不完美信息部分给出 inference gate 覆盖 bound，并构造 Beacon，使 infer_states 在随机 gate 上不暴露错误但在 play 中必败。

## Experiment
已知游戏中 CWM+MCTS 复现强于 direct LLM policy，如 Connect Four 29/30 或 30/30 胜。小型完整规则 grid 中，gate-pass 时 gap 近 0，tic-tac-toe 还枚举验证 5,478 reachable states 和 16,167 transitions 无 search-relevant mismatch。核心结果在 material-at-cap：hand-instrumented rule-blind agent 对 truth 的 win rate 0.404 [0.384,0.424]，低于 truth-vs-truth 0.495 [0.475,0.515]，seed-clustered play cost 0.091 [0.065,0.117]；LLM-synthesized incomplete CWM 在 gate-passing seeds 上 win rate 0.345，play cost 0.154。repair 实验显示 naive/proper DAgger、targeted on-manifold/off-manifold examples 都未让 GPT-5.x 稳定学到缺失规则；完整规则给出时可 0 iter 学会。Beacon 中 random gate 0/8156 mismatch，但 wrong infer_states 对 truth 0/1200 胜，play cost 精确为 1/2。

## Value
对世界模型评估有强启发：prediction accuracy 必须按 planner/search distribution 或直接 play/control outcome 评估，尤其要覆盖稀有但决策关键的事件。对视频/机器人世界模型可迁移为：不要只看随机 held-out frame prediction，需看 planner 会查询的状态、长程任务成功率、model exploitation 和 belief/inference surface。

## Strengths
问题定义尖锐；同时给正例 null result 和构造性反例；danger law 简洁且有证明；区分 transition rule 与 belief/inference 两类 failure surface；作者诚实报告 engineered instrument、planner limitations 和模型家族范围。

## Weaknesses
研究对象是规则游戏的代码 world model，和神经视频/3D 世界模型差距较大；核心 rare-rule instrument 是人工设计，不代表自然任务频率；MCTS 纯 Python 限制规模；repair 结论主要基于 GPT-5.x，跨模型证据只是少量 probe；对连续高维世界模型的适用性还需验证。

## Future Work
作者建议用 play/search distribution 验证而非随机 transition gate，确保规格完整；未来可构造更自然的部分可观测游戏、用 equilibrium/CFR arena 评估、扩展到更强模型和 agentic synthesis scaffolds，并将该类 adequacy 指标迁移到连续/神经 world model。
