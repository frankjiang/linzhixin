# Multi-scale Mixture of World Models for Embodied Agents in Evolving Environments

## Insight
核心 insight 是：embodied agent 的世界知识有尺度差异，低层动态知识更新快，高层抽象规则更稳定；普通 MoE 路由没有“尺度”概念，因此无法定向更新。MuSix 用 experiential distance 把情境新颖性映射到连续 scale space，熟悉场景走低尺度模型，新颖/复杂场景走高尺度模型。

## Motivation
VLM-based embodied agents 需要同时处理局部物理、空间关系、任务规则，并在火灾/洪水等变化环境中适应。层级世界模型和 MoE 各自有启发，但前者不解决 test-time adaptation，后者路由不可解释且更新策略统一。论文要解决 multi-scale reasoning 与 evolving environments 下的 selective adaptation。

## Method
MuSix 将 N 个 world model 分成 G 个尺度组，例如 PINN、Cognitive Map、Relational Network 等。两阶段路由：meta-router 根据当前 observation 与 episode history 的 experiential distance，在连续 scale space 上产生权重；base router 在各尺度内给 world model 打分，最终 top-k mixture。Experiential distance 由 frozen encoder embedding 与历史 embedding 高斯分布的 Mahalanobis distance 定义。适应部分包括 scale-dependent forgetting rate 的 intra-scale update，以及 gated inter-scale transfer，低尺度快速刷新，高尺度保留抽象。

## Experiment
EmbodiedBench 测 EB-Habitat 和 EB-Navigation，HAZARD 测 fire/flood 动态灾害，另有 Franka 真实 8 任务。MuSix 在 EB-Habitat 平均 40.44%，高于 SayCanPay 34.39、FLARE 27.11、Conventional MoE 25.56；EB-Navigation 平均 57.92，高于 SayCanPay 47.20。HAZARD fire rescue value 43.71 最高，flood value 与基线接近但 damage ratio 4.65 低于 6.60-7.49。真实 Franka 平均 56.2%，低于 SayCanPay 58.4 但 worst-case 更稳。消融显示不同 world model group 组合都优于基线，3D scale space 最好。

## Value
它对“世界模型模块化与自适应”有启发，尤其是用 novelty/familiarity 驱动路由和遗忘率。但这里的 world model 更像 VLM agent 的可插拔知识/预测专家，并非视频生成、3D dynamics 或 JEPA/Dreamer 式 learned latent dynamics；实验提升也偏小，真实机器人结果并不压倒最强基线。适合作为多尺度/路由思想参考。

## Strengths
亮点是它对“世界模型模块化与自适应”有启发，尤其是用 novelty/familiarity 驱动路由和遗忘率。
