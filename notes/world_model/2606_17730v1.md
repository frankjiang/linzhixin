# ActWorld: From Explorable to Interactive World Model via Action-Aware Memory

## Insight
论文指出现有交互世界模型大多“可导航但不可操作”：键鼠控制只改变视角/位置，物体交互无法在长 rollout 中保持因果后果。根因有两个：缺少 dense human-object interaction 数据；recency-biased history compression 会丢掉远处但因果关键的 event-transition frames。推论是 memory 应按 interaction importance 而不只是时间近邻分配容量。

## Motivation
解决实时 interactive video world model 中导航和物体交互割裂的问题。同行如 Genie/Matrix/WorldPlay 等更多支持 exploration，物体操作常在游戏小域或离线 prompt-to-video 中。该问题对用户的视频世界模型方向非常核心。

## Method
ActWorld 是 chunk-autoregressive DiT。条件包括高层物体交互命令、低层 WASD/鼠标控制、per-chunk captions、Plücker ray camera FiLM、symbolic text-camera embedding。核心是 hierarchical action-aware memory：local memory bank 用 Event-Aware Frame Routing 保留 coarse/mid/fine history；ACHA 在 self-attention 中放大 action-relevant history tokens；persistent bank 保存 event-update tokens 和 object-identity tokens，跨越 sliding window eviction。训练数据为约 100K interaction videos，40 类 action，每 chunk 用 VLM CoT 标注 interaction flag、phase、description，并用 DINOv3 提取 object anchors。

## Experiment
论文在 I-Bench 长时程基准上比较导航中心模型，报告 ActWorld 在 interaction fidelity 上显著优于 baseline，同时保持 viewpoint/navigation controllability。附录给出训练：从 Helios 14B chunk-autoregressive checkpoint 初始化，约 90K/100K 交互视频数据，Stage-1 5k steps、flow-matching warm-up、GAN distillation，并展示 wipe/pick/place/open 等可视化。缺点是部分标注和数据来自 proprietary models，benchmark 细节和可复现性有限。

## Value
这是核心相关论文。最有价值的点是把“长时记忆”从时间压缩问题改写为交互因果状态维护问题，对构建可操作世界模型很关键。待解决：真实物理交互与合成/第三方视频模型数据之间的 domain gap，动作空间仍是高层命令+相机控制，不是低层可验证动力学。
