# Reduced-Order Models: The Mother of World Models

## Insight
论文的 insight 是一个结构类比：world model 的 encoder、latent state、action-conditioned latent dynamics、decoder、planner，在 MOR/ROM/POD 控制文献中早已以不同术语出现。更重要的推论是：现代 learned world model 缺的不是更高平均预测精度，而是能在闭环控制前给出误差边界/适用域的 verification layer。

## Motivation
现代 world model 在游戏、视频生成、模拟机器人中快速发展，但若进入电力、热控、流程工业等 mission-critical 系统，仅有 rollout fidelity 不够，错误动作可能产生不可恢复后果。MOR/ROM 传统长期处理“高保真仿真太慢、经验规则不可靠”的实时控制问题，强调物理约束、低维动态和误差证书。论文试图把两条互不引用的传统连接起来。

## Method
这是 position/essay，不提出新算法。作者先定义 mission-critical world model 的四个条件：

- Physically grounded：守恒律和构成关系不能被模型随意破坏。
- Verifiable：在控制器使用预测前，模型能给出误差界、残差检查、coverage guarantee 或 runtime assurance。
- Real-time：推理满足控制回路时延。
- Causal and controllable：预测 intervention/action 的后果，而非被动外推。

随后用三类案例说明结构对应：POD turbulence 提供低维 latent dynamics；eigenfaces 提供 encoder/decoder 与 primitive validity check；measurement-based POD thermal control 形成完整闭环，包括 actuator setpoint 作为 action conditioning、modal reconstruction 和 a priori error bound。

最后提出综合 agenda：非线性 learned representation + 物理结构、learned dynamics verification、把 per-installation calibration 变成 transfer learning、仿真/测量混合、衡量 honesty 的 benchmark。

## Experiment
无新实验。证据形式是历史案例与概念对照。论文讨论 classical ROM 的优势：verification、physical grounding、极端数据效率；也承认其短板：线性子空间受 Kolmogorov width 限制、每个设施都要单独校准、认证 horizon 通常较短。现代 learning 的优势是非线性表示、跨实例迁移和更长 horizon，但缺少认证。

## Value
对我们有概念价值：视频/3D/隐式 world model 若要用于规划和控制，应同时报告 rollout accuracy、物理一致性、self-declared validity、refusal behavior、interventional accuracy，而不是只看视觉质量。它也提示可以采用“两层架构”：高容量 learned world model 提议动作，经典可验证 ROM/monitor 负责 bounding/veto。

## Strengths
观点清晰，强调 verifiability 很重要；把 Dreamer/JEPA/world model 与 MOR 控制传统连接起来；提出具体研究问题和成功标准；对数据稀缺的物理系统有现实意义。

## Weaknesses
无算法和实验；大量论证依赖类比；和现代视频/3D world model 的技术连接仍较抽象；若干参考文献标注为待验证或占位，削弱严谨性；案例偏热控/流体/工程，和用户关注的视觉 world model 主线距离较远。

## Future Work
作者提出五类未来方向：物理结构上的非线性 learned dynamics；为 neural dynamics 建立 a priori/a posteriori verification；把设施级校准做成 transfer learning；研究 simulation-measurement 的误差预算；建立衡量 honesty/refusal/物理违规的 benchmark。

## Rating
创新度评分：2/5 - 概念整合和 agenda 有启发，但没有新方法或实验。
相关度评分：1/3 (Tangential) - 与 world model 理念和验证问题相关，但不直接研究视频/3D/JEPA/Dreamer 技术路线。

## TL;DR
从 ROM/MOR 视角强调 world model 的验证证书，概念有启发但技术主线可略读。
