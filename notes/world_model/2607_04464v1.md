# Operator-on-F complements value-equivalence: a planning-time diagnostic for latent world models

## Insight
论文指出：latent world model 是否适合 planning，不能只看 reward prediction 或 value-equivalence。更关键的是模型自身的 k-step latent pushforward 在可观测函数集合 F 上是否与真实环境一致。也就是要诊断“规划时会用到的算子”。

## Motivation
很多 latent model 的 reward loss 很低，但 closed-loop planning 仍失败。传统 value-equivalence 更关注值函数一致性，可能掩盖 latent 动力学在 rollout 中的错误累积。作者希望提供一个 planning-time 的结构诊断。

## Method
Operator-on-F 通过 probe 将 latent rollout 投影到一组可观测特征 F，再比较模型 pushforward 和真实环境 pushforward 的 k-step 差异。它不是新的训练目标，而是和 reward/value 指标互补的评估工具。

## Experiment
主要分析 TD-MPC2 在 mt80 cheetah-run 上的模型尺寸 sweep。reward prediction error 范围很窄，难以解释 return collapse；operator error 则从约 0.28 到 2.62，和 return 呈强负相关，Spearman 约 -0.90。跨架构比较 LeWM 与 TD-MPC2、MLP probe 消融也保持相似排序。

## Value
对世界模型评价有参考：如果目标是 planning，评估应贴近 planner 实际使用的 latent dynamics，而不是只看单步预测或 reward loss。它可作为隐式世界模型的诊断指标。

## Strengths
切中“loss 好但规划坏”的常见问题；指标定义与 planning rollout 对齐；实验证明比 reward loss 更敏感。

## Weaknesses
主要环境和样本数偏少；probe 本身可能引入混淆；目前只是诊断，不直接告诉如何修复模型。

## Future Work
作者建议和 value/reward 指标一起报告，并扩展到更多环境、模型和训练目标。
