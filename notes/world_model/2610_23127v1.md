# BeJEPA: A Goal-Conditioned Humanoid Behavior World Model via Unsupervised RL

## Insight
人体姿态相近不等于世界坐标中的目标已达成；从受扰位置返回原地还须先迈步，短期姿态误差可能增大。论文据此将动作价值拆成「一步物理后果 + 目标条件的后续行为」：若潜在状态足以决定下一状态，继任特征的 Bellman 等式保证该拆分保留原动作价值；梯度消融和固定目标实验支持两类预测共同塑造表征，但理论依赖较强的确定性潜在动力学假设。

## Motivation
主流人形机器人模仿控制多在根坐标系追踪动作，容易维持姿态却偏离世界位置；轨迹模仿也难以响应任意孤立目标。BFM-Zero 等无任务奖励方法以身体相对特征学习行为，未同时编码绝对位置与朝向。世界坐标中的姿态、位置、朝向联合控制是机器人执行任务的关键问题；单靠一步动力学长程滚动又会积累误差。

## Method
在 29 自由度 G1 上，用人体动作先验和机器人在线交互联合训练 256 维球面状态/目标编码器。目标奖励为状态与目标向量内积。目标无关 Dynamic 预测执行动作后的下一潜在状态，以真实转移监督；目标条件 Successor 用 TD 预测策略未来折扣状态特征，以采集时的目标监督。演员经 `Successor(Dynamic(z,a), goal)` 的梯度选动作，另有动作先验和物理惩罚；观测历史编码器将仿真特权状态蒸馏到部署输入。跟踪时可固定网络，用短时 Dynamic 滚动、几何读出和有界动作残差进行在线 MPC 修正。新意主要在一步动力学与继任特征的联合表征及控制组合，而非发明 JEPA、继任特征或 MPC。

## Experiment
4,096 个 Isaac Sim 环境训练；MuJoCo 以 50 Hz 评测 AMASS、LAFAN 的精选非交互 20 秒片段。对照 SONIC、Humanoid-GPT、加入世界姿态输入的 BFM-Zero，指标包括全局/局部 MPJPE、根位置与朝向、手腕位置与旋转误差。AMASS 全局 MPJPE：BeJEPA 278.0 mm、加 Balanced MPC 219.5 mm，SONIC 531.5 mm、BFM-Zero 573.4 mm；但 SONIC 局部 MPJPE 49.7 mm，优于 BeJEPA 的 82.3 mm。LAFAN 全局 MPJPE 分别为 584.5、543.8、887.5、797.1 mm。固定目标消融中 BeJEPA 的最小/平均根位置误差为 0.159/0.642 m，优于合并预测器的 0.666/1.348 m；移除任一预测器对编码器的梯度也会退化。MPC 将 AMASS 平均跟踪滞后从 94.8 ms 降至 21.2 ms；真机 G1 展示受扰返回、倒地起身及连续目标切换，但真机主要为可视化案例，缺少统计量。附录还给出训练曲线、梯度关系和无观测滚动误差：几何预测约八步（160 ms）后明显漂移。

## Value
对隐式世界模型很有参考价值：将可跨目标复用的一步物理预测与长程行为摘要分开，避免把长程决策建立在长滚动上；又能复用局部模型进行实时修正。对 3D/视频世界模型可借鉴「短程可预测性 + 长程任务摘要」的接口。仍需验证复杂交互、视觉定位误差、未知地形和分布外目标下的鲁棒性，以及在线 MPC 的算力成本。

## Strengths
- 问题定义明确，把世界位置、朝向和身体姿态放在同一目标空间。
- 有匹配的合并预测器、阻断梯度和 Dynamic-only MPC 消融，能较好定位两个预测器的作用。
- 同时报告全局与局部指标、真机案例，并承认长滚动漂移与姿态精度权衡。

## Weaknesses
- 依赖人体动作先验、仿真特权状态蒸馏和 LiDAR/FAST-LIO 世界位姿；真机结果没有量化成功率或误差分布。
- 仅评测精选、非交互动作片段，仿真中的较大局部姿态误差表明全局对齐存在代价。
- 理论中的确定性、充分潜在状态不完全对应真实 POMDP；MPC 多步滚动已在附录呈现明显漂移。

## Future Work
作者未给出明确的后续研究路线。自然延伸是量化真机在定位失准和复杂交互中的表现，并提升长时预测与在线修正的稳定性。
