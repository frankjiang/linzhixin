# Let LiDAR Decide Where to Look: Geometry-Aware Token Selection for Efficient Sparse Latent World Models

## Insight
车载多视角图像中大量背景 token 占据编码和规划注意力；25% 随机保留已让规划 L2 从 0.573 降至 0.550，说明稠密输入存在冗余。进一步在视觉主干之前用 LiDAR/雷达几何选择 token，并赋予 3D 锚点，可把计算聚焦于运动物体和道路。随机、几何与去锚点消融支持该推论；低注意力熵本身不证明因果机制。

## Motivation
现有视觉潜世界模型通常先编码六路相机全部 patch，再做预测和规划；很多 token 与驾驶无关，事后 token 剪枝仍支付主干开销。论文要在保持规划质量和危险目标覆盖的前提下压缩前端及世界模型计算，对 3D 隐式世界模型部署很关键。

## Method
将多帧 LiDAR/雷达投影到图像 patch，聚合点数、深度、高度、非地面比例、运动残差和径向速度等 16 维统计；障碍/道路/视觉保底三路以约 55/30/15% 配额选 top-K，轻量 MLP 微调分数，稀疏 ViT 只编码保留 patch。每个 token 以 LiDAR 中位点作 3D 锚点，跨相机/时间用里程计对齐；条件预测 Transformer 输出未来 DINO 特征和 3D 位移，用特征-几何匹配构造无框伪运动标签，并将候选自车轨迹在预测锚点上重排避障。创新重点是预主干几何路由与 3D 锚点的潜预测联合使用。

## Experiment
nuScenes 与 NAVSIM v2，历史 2 帧，未来潜预测 4×0.5 秒，规划评测 3 秒。nuScenes 25% token 时 L2 0.520 m、碰撞 0.04%，稠密融合为 0.573 m/0.09%；NAVSIM EPDMS 88.9 对 85.9。10% token 仍为 0.537 m/87.9，端到端 FLOPs 从 433 降至 24 G（18 倍）。739 个高风险样本的危险车辆覆盖 95.8%（随机 81.5%），碰撞 0.09%（稠密 0.34%）。去 3D 锚点时 25% L2 升至 0.958；运动 EPE 对不同选择器的目标集合不同，不宜直接横比。图示显示路面和交通参与者被优先保留。

## Value
适合研究稀疏视频/3D 潜表征与规划的团队精读：先用廉价传感器确定视觉预算，再以物理坐标对齐潜 token，并同时报告危险目标召回和全链路算力。还需验证相机无 LiDAR 场景、真实推理时延和闭环驾驶收益。

## Strengths
主干前剪枝带来真实理论算力节约；同架构对照了随机、网格、深度、视觉注意力选择，附多预算、消融及图像扰动结果；明确报告 NAVSIM 无雷达输入。

## Weaknesses
选择分数和配额含大量人工设计且在验证集调优；依赖 LiDAR 与里程计，稀疏 backbone 还需蒸馏。只给 FLOPs、无车载端到端时延；规划是开放环或非反应式评测，安全收益未经闭环验证。与已发表驾驶方法的模型与监督条件不同。

## Future Work
作者建议对已选 patch 做更高分辨率编码以覆盖转向灯等细线索；还需实测硬件时延并研究无 LiDAR 的替代路由。

## Rating
创新度评分：3/5 - 预编码几何筛选与 3D 锚定组合有效，但评分规则较工程化，尚缺闭环验证。
相关度评分：3/3 (Core) - 直接构建自监督 3D 锚定潜世界模型并用于未来预测和规划。

## TL;DR
用 LiDAR 在视觉编码前挑选并锚定关键 token，显著省算力且提升规划；稀疏 3D 潜模型值得精读。
