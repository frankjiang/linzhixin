# PBD-AG: Persistent Baseline-Delta Active Graphs with Uncertainty-Aware Inspection for Long-Horizon Service Robots

## Insight

作者观察到长期室内环境具有两种不同时间尺度：家具/fixture 稳定，细粒度物体会出现、消失、移动或换支撑面。若每次重建全局图会累积定位和身份碎片；若把 missed detection 直接视为消失，又会把遮挡/坏视角误判成物理变化。由此提出 baseline-delta：冻结机器人多次确认的结构基线，只以有类型的事件 delta 修改动态对象；负证据只有在保存的 3D extent 确实位于视锥、深度未被遮挡且有足够像素支持时才生效。实验中去掉 visibility gate 后 false absence 从 0.014 激增至 0.262，支持这一推论。

## Motivation

开放词汇地图与 3D scene graph 多针对静态重建；DynaMem 可在线更新但缺少显式长期身份和层级支撑关系；DovSG 能更新动态图，却依赖预先初始化的全局图。服务机器人需要从空环境自主建立可追溯结构记忆，并在跨 session 变化中维护 identity、existence 与 parent relation，同时主动获取不确定节点的近视角证据。

## Method

PBD-AG 维护 occupancy map、persistent track table、canonical fixture view 和有序 audit event stream。流程如下：

1. 通过 frontier exploration 扩展未知空间，融合 posed RGB-D、体素几何与 SigLIP 特征；按 taxonomy 查询、DBSCAN 聚类，并跨批次用类别、中心距和 footprint overlap 关联 coarse fixture。
2. 多时刻一致、高 margin 的 track 被发布为 canonical fixture；模糊候选最多调用一次缓存 VLM 验证。到达 fixture 近视角后，VLM 提议细类与数量，Grounding DINO 定位、SAM2 分割，RGB-D 反投影并挂接到 canonical parent。
3. 每个 track 保存 class/existence/parent belief、3D center/covariance、appearance、时间、persistent ID 和 lifecycle。存在性以固定 log-odds 证据更新；unmatched 只有通过 visibility gate 才算负证据。达到阈值后产生 confirm/update/move/reparent/remove 事件，removed track 仍保留以便恢复原 ID。
4. 对未完成近视角确认的 fixture，按 existence/class/parent/position/age/confirmation uncertainty 和距离排队；候选视角再综合 standoff、路径、clearance、coverage 与边界惩罚选取。

创新是把结构基线、动态事件、几何可见性和 active inspection 组合成持久 3D 图记忆，而不是生成式未来预测。

## Experiment

- 自主建图：OmniGibson/BEHAVIOR 的 Gates bedroom、Hotel suite、Benevolence 三场景，各 3 个 seed，共 9 次从空图开始的 rollout；预算 600 semantic keyframes。PBD-AG coarse/fine F1 为 0.866±0.102/0.713±0.167。
- Shared-evidence coarse 对比：相同 proposal stream 下，PBD-AG F1 0.868、count MAE 0.356，优于 DynaMem-adapted 的 0.757/0.716 与 ConceptGraphs-adapted 的 0.696/1.176；三者中心误差接近，提升主要来自关联、合并和保留。
- 动态记忆：3 条 Hotel、每条 300 帧，包含 appearance、同支撑面移动、消失、跨支撑转移，共 12 个事件。PBD-AG IDF1 0.833、ID switches 0、event recall 11/12；最强即时更新 control 为 IDF1 0.702、8/12。
- 组件消融：去 visibility gate 后 event recall 由 11/12 降至 6/12；去 persistent ID 后 IDF1 降至 0.070、IDS 升至 43.33。append-only/static-only 的零 false absence 是因为根本不能确认消失。
- 真实机器人只给出定性部署图与视频，没有量化定位、图质量或下游任务成功率。

## Value

对 3D 世界模型方向的价值在于持久 object-level memory：baseline/delta、typed event、visibility-conditioned negative evidence 和 graph-driven sensing 都可迁移到长期 3D 场景表示。它不是能 rollout 或想象未来的 dynamics world model，更接近可更新的 3D scene graph，因此对视频/隐式世界模型的直接借鉴有限。若与生成式 3D 动力学结合，可作为稳定结构先验和可审计状态层。

## Strengths

- 明确针对“miss 不等于消失”，visibility gate 的设计物理可解释且消融效果大。
- persistent ID、lifecycle 与 audit event 使跨时变化可追踪，适合长期机器人系统。
- 从空图自主 bootstrap，不依赖预载场景 graph；同时区分 frontier coverage 和 uncertainty-driven inspection。
- shared-evidence、动态记忆、完整自主 rollout 三种协议尽量拆分感知、记忆与采集因素。
- 给出身份、事件、层级 grounding、计数和几何误差等多维指标。

## Weaknesses

- 仿真规模很小：仅 3 个房间、9 次 rollout；动态测试只有 3 条序列和 12 个事件，统计力度不足。
- DynaMem/ConceptGraphs 是 capability-matched adapted control，不是原系统端到端复现；公平性取决于作者的接口实现。
- 真实机器人只有定性展示，没有动态事件、身份保持、长期漂移或任务收益的量化结果。
- 未评估 graph 是否真正提升 navigation/manipulation 成功率，也没有未来预测或反事实能力。
- 大量手工阈值、taxonomy、固定 evidence increment 和权重可能对场景、相机与 detector 敏感；VLM、Grounding DINO、SAM2 的错误传播未系统分析。
- 冻结 baseline 适合慢变 fixture，但家具移动、房间重构或错误基线确认时，如何版本化修复仍不清楚。
- 论文声称 paired active-acquisition 实验支持优先级策略，但正文缺少足够独立的数值表和完整消融。

## Future Work

作者未单列未来工作。合理延伸包括：扩大真实环境与跨月测试；让 structural baseline 可审计地版本升级；学习而非手调 evidence/inspection policy；量化 detector 与定位漂移；连接下游导航/操控；并与生成式 3D dynamics model 结合，预测对象事件而非只记录已发生变化。

创新度评分：3/5 - 将 baseline-delta、可见性门控、持久身份和主动检查组合成完整长期 3D 记忆系统，创新中等。
