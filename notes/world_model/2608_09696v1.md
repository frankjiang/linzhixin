# Model Discovery Agent: LLM-assisted Bayesian experiment design for data-efficient discovery of mechanistic world models

## Insight
LLM 适合提出开放式机制假设，却不适合独自定参和挑实验；Bayesian posterior/Occam penalty 可筛结构，VoI 主动选择最能区分模型的干预。预测检查在 M-open 情形发现“现有假设都不对”后再让 LLM 扩容，从而形成 proposal—identification—residual discovery 循环。

## Motivation
被动拟合不能识别机制，也无法可靠回答未做过的干预；科学实验昂贵，纯 LLM agent 又常选信息量不足的实验并产出数值拟合但机理错误的公式。数据高效发现可干预 mechanistic world model 是重要科学 AI 问题，但不属于视觉/3D/控制世界模型主线。

## Method
用 SMC 粒子表示结构和参数 posterior，adaptive tempering 估计模型 evidence；确定性系统用显式 likelihood，随机/部分可观测系统用 particle filter 或 SBI summary likelihood。LLM 基于残差提出新模型，predictive check 触发 M-open 扩容，可信模型时收缩近重复。实验以 $I(M;Y_\xi|D)$ 最大化，可枚举或 CMA-ES；最后用 MAP/Bayesian mechanistic model 预测未见干预。

## Experiment
统一比较最多 8 次实验的 held-out interventional error。ForceBench 11 种力学世界中，MDA 数次实验即可把廉价 DeepSeek proposer 提升到接近 Opus，显著优于纯 LLM；Yukawa 案例中 VoI 主动选长距离 probe 区分短程近似。ChemBench 36 任务×2 seeds，MDA 约 8 次即达 symbolic accuracy 约 56%，LLM-AutoSciLab 60 次仅约 42%；后者可有低 RMSLE 却公式错误。新 NeuronBench 六类 Hodgkin–Huxley 隐机制中 Bayes forecast 全面优于 ICL，VoI/LLM design 优于随机；随机动力学版用 learned summary 将嵌套粒子计算加速约 $10^4$。

## Value
工作把开放假设生成与严谨 Bayesian experiment design 结合，强调“预测数值准”和“发现机制”不同，方法学价值高。对目标世界模型的间接启发是：真正的反事实能力需要可识别干预和主动数据，而不是仅扩大神经预测器。

## Strengths
- 覆盖物理、化学、生物三种结构与确定/随机、完全/部分可观测设置。
- 同时评价数值外推与符号机制，揭示低误差的伪机制。
- M-open predictive check 和 posterior Occam penalty 使 LLM proposal 可校验。
- 对 experiment design、forecast 方法和 proposer 能力有分解比较。

## Weaknesses
- benchmark 均为已知家族的合成/半合成系统，候选库、设计菜单和先验包含大量领域结构。
- SMC 套 particle filter 计算昂贵；learned summary 可能丢失与新假设有关的信息。
- VoI 为 myopic，一步最有信息不保证全预算最优。
- 结果依赖闭源/特定 LLM proposer，开放假设质量及复现成本不稳定。
- 与视频、3D 或机器人 latent 世界模型没有直接实证联系。

## Future Work
可扩展多步 Bayesian design、自动学习假设相关 sufficient summary、真实实验室噪声/成本/安全约束，以及更开放的连续结构发现。

## Rating
创新度评分：4/5 - LLM proposal、M-open 检查与 Bayesian 设计闭环完整，跨领域数据效率证据强。
相关度评分：1/3 (Tangential) - 研究 mechanistic causal world model discovery，原则相关但非用户关注的视觉/3D/JEPA/Dreamer方向。

MDA 用 LLM 提机制、Bayes 定参与 VoI 选实验，科学发现很强但非目标视觉世界模型，可选读。
