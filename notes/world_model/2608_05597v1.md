# Uncertainty-Aware World Model for Aerial Image-Goal Navigation

## Insight
图像目标导航不应仅比较“预测均值”和目标：当遮挡或长时漂移使多个未来都合理时，目标偏离均值的部分可能只是可解释不确定性。作者把每条候选轨迹的终态分布局部近似为 DINO 特征均值附近的低秩子空间，将目标—均值误差分解为子空间内与子空间外残差，只用后者排序。相较自家确定性基线，32 候选的 ATE 从 1.27 降到 1.09、在线成功率从 70% 升至 76%，支持“决策应惩罚模型无法解释的误差，而非全部预测误差”。但该子空间由重建残差学得，尚未被校准为真实概率不确定性。

## Motivation
现有导航世界模型用预测未来给候选轨迹打分：确定性模型会平均多模态未来，随机模型若只采一两个样本则方差大，多采样又太慢。在视野有限、航程长的户外 UAV 场景，这会错拒本可到达目标。论文将轨迹打分改写为条件 OOD/兼容性检测，希望一次前向同时保留确定性模型效率与分布感知。这是 latent world model 如何在规划中利用不确定性的有价值问题。

## Method
冻结 DINOv3 ViT-B/16 提取 14×14 dense feature，经 compressor 得到 compact tokens；teacher delta encoder 表示相邻状态差，动作条件 causal Transformer 自回归预测 32 个 delta token，再由 decoder/fuser 恢复未来 DINO 均值。Hierarchical Error Projection（HEP）根据预测均值和上下文，在 1、2、7、14 四级网格的每个 cell 预测 rank-2 feature basis，以 ridge least squares 逐层从目标误差中减去可解释分量；最终残差能量作为 CEM 轨迹代价。训练分三段：先学表示/解码，再冻结表示学习动作转移，最后冻结确定性模型，以八步真实未来误差的“未解释能量占比”训练 HEP。该实现是一遍 coarse-to-fine 贪心投影，并非对联合子空间的精确正交投影。

## Experiment
作者基于 AirSim 和既有 aerial VLN 场景构造 AirGoal-10k：8K/1K/1K train/val/test，并重采样航迹使初始航向偏差近似覆盖 0--90°、方位覆盖 360°。离线统一用 NoMaD 生成 8/16/32 候选；UA-NWM 的 ATE 为 1.26/1.17/1.09，均优于 NWM、One-Step WM、MWM、RAE-NWM，单帧 8.47 ms，仅比确定性基线 8.06 ms 略慢。CEM 独立规划 ATE/RPE 为 1.22/0.33。100 个闭环 AirSim episode 中，SR/SPL 为 76.0%/64.5%，高于确定性基线 70.0%/60.1% 和最佳外部 RAE-NWM 70.0%/57.8%，每步规划 2.70 s。去掉任一 HEP 尺度均退化，rank 2 最佳。实机在 MacBook Air + 四旋翼上以 8 waypoint 重规划，五项任务均展示成功的零样本 sim-to-real，但每次含通信约 9 秒，且未报告定量成功率、对照或安全统计。附录还报告 2D 地面导航迁移和大量可视化。

## Value
该工作把“未来不确定性”直接转化为规划代价，而不是追求生成更多漂亮样本；低秩、局部、多尺度误差子空间也可迁移到其他 latent 世界模型的 goal matching 或候选筛选。最重要的启发是把模型偏差拆成可容忍与决策相关部分。但 HEP 目前更像条件残差字典，而非概率世界模型；下一步需要校准 coverage、负样本和空间/时间相关性，证明它不会把系统性错误误当成合理不确定性。

## Strengths
- 条件 OOD 视角简洁，单次前向得到低秩不确定性方向，兼顾打分质量和延迟。
- 与自家确定性骨干及多种像素/latent 随机世界模型比较，离线排序、规划、闭环和实机层次完整。
- AirGoal-10k 主动平衡转弯与三维方位，避免原 VLN 轨迹直行偏置。
- 附录明确承认层级投影不是全局正交投影，并讨论随机采样的空间不一致，理论边界较诚实。

## Weaknesses
- HEP 只最小化真实后继残差，没有分布似然、方差尺度、coverage 或校准目标；“不确定性子空间”和“条件 OOD”主要是解释而非经概率检验的性质。
- rank-2 basis 也可能吸收确定性模型的系统偏差；对子空间内误差零惩罚，在目标不兼容但方向重合时可能误选，论文缺少专门负例/风险分析。
- 主要结果来自自建仿真基准；100 个在线 episode 无置信区间，五个实机任务只有成功案例，没有成功率、碰撞率或基线。
- 成功阈值为目标 20 米内，对精确导航较宽松；机载闭环约 9 秒一次，难称高速实时 UAV 控制。
- HEP 的尺度与 rank 消融幅度较小，未比较 ensemble、分位数回归、异方差协方差或校准 latent dynamics 等更直接不确定性基线。

## Future Work
作者提出更具表达力的不确定性表示，显式保持 patch 间空间一致性和跨帧时间一致性，从而一次预测完整未来分布并高质量采样。还需加入概率校准和分布外负例、真实飞行定量基准、更低延迟控制，以及对碰撞和保守性的安全评估。

## Rating
创新度评分：3/5 - 以多尺度低秩残差子空间做单次分布感知规划有明确新意和效果，但概率语义未经校准，实机证据偏弱。
相关度评分：2/3 (Related) - 属于隐式视觉世界模型与规划，方法可借鉴，但核心场景是 aerial image-goal navigation 而非视频/3D/JEPA 主线。

## TL;DR
用低秩不确定性子空间忽略可解释预测误差，显著改善 latent 世界模型导航打分，值得选读。
