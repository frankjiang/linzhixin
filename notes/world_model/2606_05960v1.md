# Towards a Data Flywheel for Embodied Intelligence in Logistics

## Insight
无显著 insight。论文的核心观察是物流行业天然产生大量异构操作数据（人工操作视频、机器人执行日志、失败案例等），可以构建数据飞轮；但这更多是一个工程视角的观察而非技术洞察。

## Motivation
问题：机器人学习从实验室走向工业部署，需要解决长尾操作场景的数据问题。物流行业是典型场景——需要处理多样的包裹类型、工作台布局和抓取策略。核心研究问题包括：如何将传统自动化数据转为可用训练数据、如何用世界模型生成可靠的合成监督、如何通过部署反馈持续改进。目前仅完成了 RQ2 的初步验证（WM-DAgger）。

## Method
提出 WM-DAgger 框架：
1. 从少量专家演示训练 action-conditioned World Model
2. **Corrective Action Synthesis**：扰动专家轨迹使机器人进入 OOD 状态，然后生成回到专家流形的恢复轨迹
3. **Consistency-Guided Filtering**：过滤终端帧与真实演示帧视觉不一致的生成轨迹，减少幻觉数据的影响
4. 生成的恢复轨迹与真实演示聚合后训练更鲁棒的策略

论文仅 3 页（KDD PhD Consortium），技术细节极为有限。

## Experiment
- 6 个物流相关操作任务：Soft Bag Pushing, Pick-and-Place, Ballot Insertion, Towel Folding
- 每个任务仅 5-20 个真实演示 + 1500 个生成数据
- WM-DAgger 在 Soft Bag Pushing（5-shot）上达 93.3% SR（vs BC 26.7%, DMD 40.0%）
- 整体显著优于标准 BC 和 diffusion-based 数据增强
- 实验规模较小，仅为概念验证

## Value
作为 KDD PhD Consortium 论文，是一个研究提案而非完整工作。WM-DAgger 的 corrective action synthesis 思路有一定参考价值，但技术贡献有限。对世界模型研究的直接启发较少——世界模型仅作为数据生成工具使用。未来方向（legacy data alignment, world foundation model with deployment feedback）有一定前瞻性但缺乏具体方案。
