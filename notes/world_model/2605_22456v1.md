# Steins;Gate Drive: Semantic Safety Arbitration over Structured Futures for Latency-Decoupled LLM Planning

## Insight
无显著 insight。论文观察到 LLM 推理延迟与车辆控制周期不匹配（云端 LLM 延迟 >1s vs 控制窗口 ~100ms），提出用"世界线"隐喻解耦规划和执行。但这一观察并不新颖，延迟补偿在自动驾驶中是常见问题。

## Motivation
解决 LLM 驱动的自动驾驶中推理延迟问题。现有方法将 LLM 推理和控制耦合在同一循环中，导致实时性不足。论文借用《命运石之门》的世界线概念，让 LLM 提前选择未来分支，运行时仅验证安全约束。问题本身重要但解法偏工程化。

## Method
三类世界线角色：alpha（自车名义未来）、beta（交互反事实）、gamma（危险压力测试）。LLM 选择分支后生成 StrategicForecast（含有效期、中止条件、回退策略），运行时通过原子谓词检查安全性。使用 GPT-5.4 mini 作为规划器。整体是一个系统架构设计，创新程度有限。

## Experiment
匹配种子的受试者内实验，10 seeds x 20 steps。4秒预测时延从+3.07s降至-0.01s，保持无碰撞。实验规模小，仅限 normal-highway 场景，缺乏与传统延迟补偿方法的对比。

## Value
工程导向的系统设计，将 LLM 的语义判断与实时安全检查解耦。对世界模型研究无直接启发，与用户关注的视频/3D/隐式世界模型方向无关。"世界线"概念更多是包装而非技术创新。
