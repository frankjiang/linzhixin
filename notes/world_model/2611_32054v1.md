# SurgGenesis: A Generative Surgical World Model for Future-Aware Surgical Understanding

## Insight
外观逼真或数据增强有效均不能单独证明模型预测了场景演化。论文把真实未来误差、提示动作兑现率、下游用途分层检验；但预测未来的帧 RMSE 0.1888 远高于真实 latent 经解码的 0.0227，说明主要误差仍在预测器。

## Motivation
手术视频标注昂贵、罕见器械动作样本少，通用视频生成模型难直接得到保留手术上下文且受器械—动作—目标（IVT）提示控制的未来。问题是视频世界模型在专业领域的数据与动作条件化，但缺少可泛化的交互式控制论证。

## Method
以 WAN2.2-TI2V-5B 的 VAE/DiT 为底座，用过去帧及结构化手术阶段、IVT、运动文本联合条件化生成未来 latent 视频。三阶段 LoRA 分别适配 Cholec80 外观、CholecT50 手术语义、CholecTrack20 运动；每阶段把已有 LoRA 融入底座，缩小可训练层数和秩（32/16/8），后两阶段混入 20% 旧样本。主要是领域适配与渐进训练，动态建模骨干并未另创。

## Experiment
使用 Cholec 系列、EndoNeRF 等数据，检查 FVD 式分数、LPIPS、1–5 秒帧 RMSE、真实数据训练的 IVT 识别器，以及分割和 3D 重建。相对原生 WAN，FVD 式分数 89.54→79.94，5 秒帧 RMSE×100 为 20.19→19.19；432 个生成片段中指定 IVT 被识别 93.06%，错配提示仅 6.25%。4 倍长尾增强 APIVT 从 0.1717 到 0.1823，但简单复制 4 倍已达 0.1815；该增益很小。跨方法 LPIPS 0.516 最好，但表 1 协议并不相同，不能视为严格排名。

## Value
分层验证“未来一致性、动作遵循、任务收益”的设计值得借鉴；手术领域的 LoRA 方案对通用世界模型方法贡献有限。

## Strengths
使用真实未来和独立 IVT 识别器校验生成，而非仅报告视觉质量；明确披露复制重采样解释了多数增强收益。

## Weaknesses
对真实未来的预测误差仍大；动作遵循由识别器代理，缺少真实反事实手术动作结局。表 1 的模型协议不一致，下游提升不足以证明世界动力学。

## Future Work
正文未明确提出具体后续路线；依据其误差分析，提升真实未来状态预测是最直接的未解问题。
