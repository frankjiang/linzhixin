# Do Robotic World Models Really Follow Actions? Diagnosing and Aligning Action-Conditioned Generation for Policy Learning

## Insight

Observation：机器人视频世界模型在专家动作上生成得好，不代表它真正使用了动作条件；离开专家分布后，模型会分化为两类失败——画面仍合理但机械臂运动与指令不符，或动作变化直接触发手臂扭曲、夹爪消失等视觉崩塌。论文据此推论，动作遵循必须同时检查“视频是否有效”和“生成运动是否对应这条动作的真实后果”，且需要在同一初态上执行被测动作取得 action-specific reference。六个模型的诊断支持该推论：off-expert 相对 expert 的 integrity-gated error 增加 0.029–0.099 m，raw NDTW 增加 0.010–0.043 m，视觉失败率增加 6.3–28.1 个百分点。进一步把同一 observation、同一 flow noise 下两条动作的预测差与真值差对齐，能直接约束“换动作时未来应怎样变化”；这是比逐样本重建更接近干预效应的监督，但论文提供的是经验验证而非可辨识性证明。

## Motivation

动作条件世界模型已被当作 VLA policy 的评估器和 post-training simulator，但训练与评测通常只回放专家示范，容易让模型依靠 state-conditioned expert prior 猜出“成功未来”。已有 benchmark 多测画质、语义、图像运动、逆模型恢复动作或任务级失败，缺少对广泛连续数值动作逐条配对的 SE(3) 后果检验。policy 更新、探索和失败恰会查询 off-expert 动作，因此这是决定 learned simulator 能否可信服务闭环策略学习的关键问题。

## Method

WorldEcho 构造五类查询：Demonstrated Action、把别的状态的专家动作移到当前状态的 Cross-State Replay、局部扰动、当前 policy rollout，以及广义可行空间采样；每条都从同一 RoboTwin 初态执行得到真值视频。视觉门由 MUSIQ 画质、插帧一致性平滑度、SAM-based 夹爪可见性和 VLM 手臂完整性四项 AND 组成。随后从生成/真值视频恢复双末端位置与 SO(3) 姿态，以位置误差和旋转测地距离组成 pose-aware NDTW；通过门的样本用 NDTW，失败样本赋固定惩罚 κ，并先 task 内平均再做 task macro-average。

WorldSync 在 flow-matching AC-WM 上加入三层修正：其一，把多任务模拟中的专家、cross-state、扰动、policy 与 feasible-space 轨迹和少量目标域真实示范统一为机器人基座坐标系下的相对笛卡尔末端动作，扩大 action-consequence coverage；其二，Action-Forcing Expert 用 trajectory queries 逐层 cross-attend 视频 DiT 中间特征并回归未来 SE(3) 轨迹，梯度约束 backbone、推理时移除，且它不直接读取动作以避免捷径；其三，Intervention-Effect supervision 对同 observation/指令、同噪声、不同动作 A/B 的 flow velocity 差 `v_A-v_B`，监督为干净未来 latent 差 `x_B-x_A`。总损失为 flow matching、AFE 轨迹损失和 IE 差分损失的加权和。创新点是 benchmark 与 paired intervention supervision 的统一；AFE 和数据扩展本身较常规。

## Experiment

主评测覆盖 50 个 RoboTwin manipulation tasks，比较 CtrlWorld、Cosmos-Predict2.5、Cosmos3、DreamDojo、Motus、LingBotVA；每个 backbone 比较 20k-update 专家训练与 40k-update expanded coverage，WorldSync 则训练 60k updates。指标为 integrity-gated error、raw pose-aware NDTW 和 visual pass rate。Expanded coverage 对六个 backbone 都降低 gated/raw error，但视觉通过率三升、两近似不变、一降。WorldSync 的 gated error 0.0661 和 visual pass 84.51% 均为最佳，只以很小幅度优于 CtrlWorld+coverage 的 0.0670 和 Motus+coverage 的 84.34%；其 raw NDTW 0.0223 并非最佳，Cosmos-Predict2.5+coverage 为 0.0127。

下游采用匹配 rollout、交互和训练预算的两轮 VLAW 式 policy improvement。RoboTwin bin-dumping 从约 51–52% 起步，WorldSync 达 65%（+13 pp），CtrlWorld 的 expert/expanded 两版仅达 57%/56%（均约 +5 pp）；真实 stacking-cups 两组均从 48% 起步，WorldSync 达 68%，CtrlWorld 达 56%。四任务、八共同 checkpoint 的消融中，Base expert→expanded 使 gated/raw 从 0.0781/0.0306 降到 0.0738/0.0258；IE 达 0.0700/0.0170，但 visual pass 从 82.68% 降到 81.25%；AFE 单独为 0.0753/0.0284、visual 83.04%，并未改善动作指标；Full 为 0.0695/0.0189、visual 81.96%。因此 IE 是动作对齐主因，AFE 主要在与 IE 联用时略改善 gated trade-off。

## Value

这项工作的最大价值是把“动作作为输入”与“模型因动作而改变未来”区分开，并给机器人视频世界模型提供 off-expert、action-specific、完整性门控的诊断协议。对我们直接的启发是：动作条件视频模型不能只报 FVD/画质或专家回放，应做同初态反事实动作对、报告 action effect，并把 invalid generation 与可见但错动作分开计数。WorldSync 证明这种改进可能转成更好的 policy post-training，但尚不足以说明已得到通用神经模拟器。

## Strengths

问题定义直接命中 policy-facing world model 的隐含假设；五类查询逐步减少对专家先验的依赖，并为每条动作提供模拟器真值。评价同时保留 gated error、raw NDTW 与视觉通过率，避免单一指标掩盖两种失败。六类架构、50 tasks、模拟与真实 policy improvement 形成较完整证据链。IE 的同 observation、同 noise 设计隔离动作变化，消融也诚实显示 AFE 单独无动作收益、WorldSync 并非所有分项都最佳。

## Weaknesses

主表计算预算不匹配：expert baseline 20k、coverage baseline 40k、WorldSync 60k updates，领先 CtrlWorld 的 gated error 仅 0.0009，无法排除更多训练的贡献；也未给主表模型间显著性。视觉门依赖 MUSIQ、插帧模型、SAM tracking 与 VLM arm judge，阈值和失败惩罚 κ 会影响排名，轨迹 extractor 在严重生成 artifact 上也可能失真。IE 对共享噪声的 latent velocity 差做 L2，并不保证像素级因果因素被正确分离。policy 价值只在一个 RoboTwin task 和一个真实 stacking task、两轮更新上验证，成功率未给重复试验方差。长时交互、碰撞/物体状态、跨 embodiment 和开放世界均未覆盖；AFE 的机制贡献较弱。

## Future Work

作者明确提出扩展到更长时程、多 embodiment 和开放世界交互。后续还应在严格等 update/算力下比较，校准视觉门与 κ 的敏感性，加入物体/接触状态和任务后果指标，扩大真实机器人任务与随机种子，并研究无需模拟器逐动作真值时的反事实动作遵循评测。

## Rating

创新度评分：3/5 - WorldEcho 的 off-expert 配对评测与 IE 差分监督有明确新意，且展示下游收益；但训练配方多为数据扩展与辅助损失组合，主指标优势很小且预算不等。
相关度评分：3/3 (Core) - 直接研究动作条件机器人视频世界模型的可控性、评测和 policy post-training，属于视频世界模型核心问题。

## TL;DR

用 off-expert 配对动作诊断并以干预差分强化机器人视频世界模型，证据扎实但预算不等，值得精读。
