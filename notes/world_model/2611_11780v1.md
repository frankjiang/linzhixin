# Planners Exploit Deterministic Error: Dithered Low-Bit World Models

## Insight
观测：低比特四舍五入的单步潜变量误差常小于随机舍入，却让迭代规划成功率暴跌。推论：关键是量化误差是否跨规划迭代持续，规划器会反复挑中被固定误差高估的动作。固定随机抖动一个控制步会重现 70–130% 的偏移；每次前向重新抽取、候选间共享的抖动则消除大部分偏移。误差拆分与预设对照支持机制，但奖励误差相关解释尚未验证。

## Motivation
MPPI/CEM 要对世界模型调用数千次，低比特部署很有吸引力；只看离线一步预测误差无法预警闭环规划退化。问题对资源受限的隐式世界模型控制重要。

## Method
对 TD-MPC2 与 DINO-WM 的隐藏激活采用均匀 k-bit 量化。比较确定性取整、独立抖动、同次候选共享且每轮重抽（sh-iter）、整个控制步/回合固定抖动。sh-iter 用同一随机舍入偏移公平比较本轮候选，同时不让偏差在下一轮持续；无需重训。测执行动作相对于候选群体的模型返回误差与跨迭代漂移。创新在规划循环中的误差时间相关性控制与机制验证，非新的量化算法。

## Experiment
TD-MPC2 的 Meta-World 19 个受损任务×位宽组合中，sh-iter 均修复至少一半损失（中位 95%）；DINO-WM 为 4/5，317M 多任务 TD-MPC2 为 8/8。例：pick-place 3 bit 时确定性一步误差 0.22、小于 sh-iter 的 0.39，但成功率损失 37.8 vs 7.8 点。DMC 仅 5/12 单元修复过半，walker 3 bit 反而更差。A40 上 W8A4 CUDA graph 的 rollout 比 FP32 快 1.9–3.3 倍，完整规划快 1.28–1.49 倍；共享抖动额外延时 ≤2.3%。但预转换权重的 BF16 仍比该整型路径快。

## Value
世界模型压缩应测闭环任务和规划过程中的误差相关性，而非只看平均一步误差；对部署 MPPI/CEM 的团队是实用诊断和简易修复思路。

## Strengths
横跨两种模型、两种规划器和不同参数规模；同位宽控制误差分布与持续时间；报告预设假说失败、DMC 例外和与 BF16 的速度比较。

## Weaknesses
修复依赖迭代规划和粗粒度共享量化网格；强后训练量化之后增益有限。317M 仅一个 checkpoint，DINO-WM 整型核及 FP4 闭环尚未验证；无真实机器人测试。

## Future Work
作者计划验证奖励误差/单元间相关性作为诊断指标，将整型核移植到 DINO-WM，优化首层以追上 BF16，并在嵌入式与 FP4 硬件上重复闭环和延时测试。

## Rating
创新度评分：3/5 - 经典随机舍入用于规划循环且机制检验充分，有应用创新但非新世界模型范式。
相关度评分：2/3 (Related) - 直接涉及隐式世界模型的规划部署，侧重数值实现而非表征学习。

## TL;DR
迭代规划会利用固定量化误差；候选共享、每轮重抽的抖动可低成本修复，部署低比特模型可选读。
