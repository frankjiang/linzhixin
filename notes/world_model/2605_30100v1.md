# Chess-World-Model: A 10M-Game Benchmark for Exact State Tracking from Chess Move Sequences

## Insight
观察：现有世界模型benchmark要么合成/小规模，要么将状态追踪与感知/控制耦合，难以隔离评估状态维护能力。国际象棋提供了理想的确定性环境：状态完全可观测、转移规则精确可验证。关键发现：in-distribution性能可被模型规模掩盖（recurrent和Transformer在大规模下均接近完美），但random-uniform split（OOD）持续暴露规则学习的失败，表明强ID性能不代表学到了真正的状态转移规则。

## Motivation
- 问题：序列模型能否在确定性动作域中维护精确的结构化潜在状态？
- 同行：合成benchmark（parity、modular arithmetic）太简单可被捷径解决；语言类benchmark缺少精确验证
- 关键性：状态追踪是世界模型的核心能力之一，本benchmark提供了精确可验证的测试床

## Method
- 任务：给定棋步序列，预测每一步后的完整棋盘状态（75个categorical targets: 64格棋子+附加状态）
- 数据：10M真实Lichess棋局 + random-uniform split（随机合法走法生成）
- 架构对比：Causal Transformer vs SLiCE (block-diagonal) vs Mamba-3 vs Gated DeltaNet (negative eigenvalues)
- 统一接口：matched prediction interface + 统一训练协议，4个尺度(3M-38M参数)

## Experiment
- ID real-game：recurrent模型在小/中规模显著优于Transformer；~18M参数后均饱和
- OOD random-uniform：持续discriminative直到40M参数，最强模型~80%精确状态准确率
- 消融：降低state-transition expressivity（diagonal SLiCE / Mamba-2 / positive eigenvalue DeltaNet）均降低OOD性能
- 指标：Exact State Accuracy（75个labels全对才算对）

## Value
作为世界模型中"状态追踪"子能力的精确benchmark有价值。对隐式世界模型研究的启发：(1)ID评估不足以判断是否学到了转移规则；(2)有表达力的循环状态转移机制对state tracking至关重要。局限：象棋是完全可观测、离散、确定性的，与真实世界模型的部分可观测/随机性差距大。

## 创新度：2⭐
Benchmark设计（chess+OOD split）有一定新意，但本质是已有架构的对比实验，无新方法。

## 相关度：1 (Tangential)
研究状态追踪能力，与隐式世界模型有间接关联，但离散棋类域与视频/3D世界模型差距较大。

## TL;DR
用10M国际象棋棋局构建精确状态追踪benchmark，发现recurrent模型优于Transformer且OOD split能暴露规模掩盖的失败。间接相关，可跳过。
