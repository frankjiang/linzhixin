# COUNTERMEM: World-Model Verified Counter-Factual Memory for Language Agents

## Insight
观察：只存失败反思可能把未经检验的建议误用到新任务。将同状态局部替代动作经可执行检查器验证后存为带适用条件的记忆，匹配到新任务时可降低有害复用。这里的“世界模型”是 Lean、测试或 SQL 执行器，不是学习的视觉物理模型。

## Motivation
语言代理的跨任务记忆缺少反事实行动对照，且检索到相似记录不代表适用。目标是改进软件/形式任务代理，与视频和 3D 方向无关。

## Method
失败决策后在复制或重置状态中测试少量局部编辑，只存效用增加且检查成功的“原动作→改进动作、证据、适用条件”记录；容量限制下按验证收益与后续复用保留。后续检索至多三条，DQN 选择使用一条或跳过，奖励任务成功并扣交互成本；测试时冻结记忆和选择器。

## Experiment
数学、代码、形式验证、Text-to-SQL、SMT、SAT 共 12 设置。gpt-oss-120b 的 ReAct/Reflexion 在 12 基准均提升，平均 +12.6 点；四域 ReAct 均值 39.0→57.5，任务运行 token 少 7.7–42.0%。仅无验证建议提升 +5.2/+2.1 点，仅验证不存储 +7.1/+3.4，完整为 +18.5/+8.2。去掉适用条件使近似误用任务的有害使用率 11.8%→34.2%。附录承认离线训练与检查器成本未计入任务 token。

## Value
“验证反事实并记录适用条件”的记忆原则可泛化，但本研究的证据全来自符号执行任务，用户可跳过。

## Strengths
状态重置使反事实比较相对清晰；消融覆盖验证、存储、检索错配与有害复用。

## Weaknesses
依赖可复制状态和强可执行检查器；检查器覆盖不全会接受错误建议。报告的 token 节省不代表总训练/运行成本降低，跨环境迁移仍明显掉分。

## Future Work
作者提出组合多条记录、识别/淘汰过期记忆，并报告端到端训练和运行成本。

## Rating
创新度评分：3/5 - 反事实验证、条件化记忆和选择器组合有效，但属语言代理记忆方法。
相关度评分：0/3 (Noise) - 无视频、3D 或隐式学习世界模型。

## TL;DR
用执行器核验替代动作并保存适用条件，改进语言代理跨任务记忆；与目标方向无关，可跳过。
