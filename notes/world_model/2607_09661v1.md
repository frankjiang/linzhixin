# PanoWorld: Real-World Panoramic Generation

## Insight
核心 insight 是全景 ERP 表示有旋转等变性：相机旋转主要改变投影畸变/heading，而不改变底层场景内容。因此可把旋转从学习问题中剥离为几何变换，让模型主要学习平移导致的 parallax 与长期场景记忆。由此推导出两点：动作条件应在球面 ray 坐标中表达；历史记忆检索也应按 3D ray correspondence 而不是图像平面或普通 KV cache 对齐。

## Motivation
论文解决长程、可控全景视频 world model 的物理一致性问题，尤其是复杂 UAV 轨迹下的几何、光照和场景持久性。已有 3DGS/显式重建方法成本高且扩展性差；普通视频扩散或上下文记忆方法容易漂移；全景方法还会受 ERP 极区畸变和旋转视角变化影响。这个问题对 3D/视频 world model 很关键，因为全景视频天然接近 embodied simulator 的观测接口。

## Method
整体是基于 Wan2.2-5B 的 diffusion panoramic world model。输入初始全景帧、文本和相机轨迹，输出 81/161 帧全景视频。

关键模块：
- Motion Decoupling：先去除 yaw/rotation，固定 heading，把模型学习重心放到 translation。
- DPRC：将 latent grid 每个像素反投影成球面 ray，为每条 ray 构造局部正交基，把相机平移投影到 ray-local SE(3) 表示，再用 PRoPE 注入 DiT block。
- GMA：把 query latent 和 memory bank 编码到同一 ray-based PRoPE 空间，以 attention 检索历史 ray 特征；用 attention affinity 形成 confidence gate，按 `Fbase + g*c*Fmem` 融合，减少 revisit 时的漂移。
- 三阶段训练：全景 LoRA 适配、DPRC 动作学习、GMA 长程记忆学习。补充材料还给出 causal forcing/rolling forcing，将 161 帧生成从约 4m48s 加速到 8s。

创新程度较高，核心不是单纯套视频扩散，而是把全景几何性质用于 action conditioning 和 memory。

## Experiment
构建 World360：70K 真实 UAV 全景 clips + 50K AirSim360 高质量仿真 clips，含多高度轨迹、pose、深度/文本。数据清洗包括旋转解耦、0.05m 空间重采样、曝光/质量过滤。

指标包括 FID/FIDpole/FIDequ、FAED、NIQE、Q-Align、轨迹 PSNR、多时间窗 PSNR，以及 ViPE 重建轨迹对齐验证。对比 Imagine360、Matrix-3D、OmniRoam。

主要结果：480p 下 FID 27.64，优于 Matrix-3D 34.63 和 OmniRoam 60.77；720p 下 FID 16.93。轨迹控制 PSNR 在各时间窗均领先，如 480p PSNR75-80 为 20.92，高于 Matrix-3D 18.02、OmniRoam 17.02。GMA 消融带来约 +1.07 PSNR 长程增益；随机 memory 会严重破坏几何。

## Value
对视频/3D world model 很有价值：它把“动作控制”和“长期记忆”统一到几何 ray 空间，而不是依赖黑盒 temporal context。启发是：如果观测空间本身有明确几何结构，world model 的 action token/memory token 应直接尊重该结构。待解决问题是仍强依赖初始帧，真实帧到生成帧存在质量断层；长期动态环境和大结构变化仍弱。

## Strengths
问题重要且方向核心；几何 insight 清楚；DPRC/GMA 和训练流程成体系；World360 数据集规模大且针对真实 UAV 物理变化；指标覆盖视觉质量、全景畸变和轨迹控制；补充材料给出实时化方案。

## Weaknesses
物理一致性仍主要通过视觉/pose proxy 衡量，不是严格 3D consistency 证明；PSNR 对轨迹控制的解释有限；World360 的真实部分和仿真部分分布差异可能影响泛化；依赖 Wan2.2-5B 和复杂数据管线，复现成本高；初始帧硬复制导致第二帧开始的质量 gap。

## Future Work
作者提出两点：用轻量 boundary refinement 或 latent alignment 缓解真实输入帧到生成帧的域差；发展动态 memory management，持续更新高置信帧并主动遗忘，以减少长程误差累积和初始帧依赖。
