# From Single-Actor Environments to Multi-Actor Event Worlds: Can LLMs Be Event World Models?

## Insight
对其他主体未来动作未知时，行动后果预测需对其可能行动求边缘分布；若直接给定所有主体的未来动作，任务则容易很多。Diplomacy 中 Qwen3-1.7B 使用 32 万条训练转移后，联合动作预测整盘精确率 88.4%，仅本方动作时仅 25.4%；增加模型规模和历史仍难消除差距。这个受控比较把**预测其他主体行为**识别为瓶颈；后续规划实验又显示这种错误会系统性高估候选行动收益。

## Motivation
传统单主体文本/网页世界模型通常在代理每次行动后返回观测；现实事件日志却由多个独立行动者驱动，在代理等待时也演化，且只暴露部分状态。若不区分“已知所有未来动作”和“仅知本方拟议动作”，评测会高估可用于真实规划的模型能力。

## Method
- 将事件世界定义为有时间戳的动作/观测日志与隐状态；预测给定日志、本方行动及时间跨度后的观测。设 Task J 输入所有人的未来动作，Task S 仅输入本方动作，二者对照隔离未知主体动作的影响。
- 从 33,194 局规则引擎可精确回放的 Diplomacy 游戏，以及 4,176 个 Polymarket 市场的约 7,900 万笔订单构造数据；前者预测下一棋盘，后者预测一小时价格方向和分布。
- 逐级评测单步预测、模型自身输出驱动的多步滚动、未实际采取行动的反事实后果、模型辅助选行动与想象经验训练策略。方法贡献主要是问题形式化和评测；基础预测器仍为文本序列 LLM 的监督微调。

## Experiment
- 在共享测试子集上，Qwen3-1.7B 用 2 万条转移微调后，Diplomacy 整盘精确率 Task J 59.7% 对 Task S 20.1%，高交互阶段的 Task S 仅 1.6%；Polymarket 方向准确率为 66.1% 对 59.9%，仍低于 LightGBM 对应的 68.8%/61.4%。扩至 32 万条后 Diplomacy J 达 88.4%，S 仅 25.4%。
- 五步 Diplomacy 滚动时，Qwen3-1.7B 的 Task S 单位级 F1 从给真实中间棋盘的 86.0% 降到使用自身预测的 55.1%；修改本方行动后的反事实预测在其他主体动作缺失时也多报不存在的变化。
- 用 Task S 世界模型规划，内部判定成功率 82.8%，将同一计划回放规则引擎仅 41.2%，直接在引擎规划为 65.0%。但 1,000 局真实加 1,000 局想象经验训练策略可将成功率从真实 1,000 局的 47.5% 提至 53.5%；从 32 万条世界模型初始化后达到 59.5%。

## Value
对复杂视频世界模型的**评测设计**有借鉴：明确区分已知联合动作的预测上限与部署时未知其他主体动作的预测，检查代理不行动期间的演化、闭环误差、反事实动作和真实规划收益。论文本身只建模棋盘/交易事件文本，不提供视觉、3D 或隐式表征方法。

## Strengths
两种互补数据源中，Diplomacy 有规则引擎可核查未执行动作，Polymarket 提供真实多主体日志；从预测精度一直追到决策与策略学习，揭示“预测分数上升但候选越多越高估收益”的风险。

## Weaknesses
仅两类事件世界；反事实及代理收益只在固定 DipNet 对手的 Diplomacy 引擎中可验证，市场的改动订单分析只是观察性参照。Task J 给部署时不可知的未来联合动作；Polymarket 的 Task S 还包含同一小时内本方后续真实订单，若起点尚未计划这些订单则不符合单次在线决策信息条件。没有视觉或连续物理状态建模。

## Future Work
作者主张显式建模其他主体联合行动的不确定性，利用其目标信号预测行动，并在多步滚动中用新观测校正误差；扩展到更多领域和原始事件流，检验真人或会学习的对手，并在无规则引擎的市场中建立更可信的干预评测。

## Rating
创新度评分：3/5 - 将多主体、异步、部分可观测的事件预测形式化，并用分层评测与规划实验证实关键瓶颈；没有提出解决该瓶颈的新模型。
相关度评分：1/3 (Tangential) - 文本事件世界与目标模态相距较远；未知主体动作和闭环规划的评测思想可间接借鉴。

## TL;DR
多主体事件模型在未知他人行动时预测与规划明显失准，给出分层诊断基准；视频世界模型团队可选读。
