# LLM-Based Exogenous World Modeling for Dynamic Scheduling

## Insight
若动作引起的状态转移可精确计算，只需预测外生不确定量，而无需学习整个状态动力学。论文把调度动作先映射到确定性 afterstate，再只预测未来订单到达压力；在可控仿真中，用近期预测残差校准 LLM 的两段到达数，使近端预测相关系数从 0.12 提至 0.93，固定规划策略下迟交成本由 6771 降至 4011（第 3、7 页）。这是合理的模型拆分原则，但没有证明 LLM 比简单统计预测器更适合该任务。

## Motivation
在线车间调度需要在不知道未来订单时安排机器；纯优先级规则只能看当前工作，预设到达分布的滚动优化受模型误差和计算成本影响。作者希望用预训练 LLM 估计未来负载，结合已知车间转移做短视规划。对制造调度是有用问题；与视频、3D、JEPA/Dreamer 模型只有“已知动力学和外生不确定性分治”的间接联系。

## Method
状态含机器可用性、工序进度和到达历史。动作经确定性模拟器形成 afterstate；随后加入未来订单的外生到达事件。冻结的 Claude Haiku 4 只输出预测窗前/后半段的订单数量，不生成单个工单属性；固定、非学习的场景生成器在各区间采样具体到达时间，并从参考分布取工单属性。规划器用信念条件评分筛出至多 K=6 个动作，以至多 d=3 步、n=8 个场景短滚动加终值估计选动作。LLM 仅在已观察到的到达数偏离缓存预测或预测窗失效时重算；近期已完成预测的偏差写入后续提示词。另用 Claude Sonnet 4 离线进化评分、终值函数及 K/d/n/刷新阈值，测试时冻结（第 3–6 页）。

## Experiment
将 Taillard、Brandimarte 和 Hurink 静态算例改为四类合成到达过程：脉冲、后期增速、周期及中途阶跃；指标为总加权迟交成本，并比较 8 种优先级规则和 5 种在线优化。AWMP 在 8 组基准×到达分布中均最优，相比各组最强优先级规则，动态 JSSP 降低 5.8%–20.7%，FJSP 降低 21.9%–46.3%（表 1）。独立非平稳诊断中残差校准让到达预测相关系数 0.12→0.93，固定策略的成本下降约 41%。预测缓存把每回合 LLM 调用从朴素的 7191 次降到 18 次；离线进化相对初始策略在留出 TA03/TA04 上降低目标 62%（第 7–8 页）。

## Value
对我们唯一值得借鉴的是先辨别哪些转移可由物理/规则精确计算，再将学习容量用于未知扰动，并以缓存和残差监测控制推断开销。具体 LLM 两桶到达预测、车间调度目标与视觉世界模型无直接关系。

## Strengths
- 将可知的车间转移与不可知的到达过程明确分开，规划时不让 LLM 模拟机械规则。
- 同时报告预测质量、最终成本与 LLM 调用量，且离线进化和最终评估分离。
- 多种到达过程及 JSSP/FJSP 任务均评估，不只展示单一分布。

## Weaknesses
- 全部到达过程是人为设定的四类合成模式，缺少真实生产日志与复杂工单属性变化。
- 没有把 LLM 预测与泊松/时间序列/简单近期频率等轻量预测器充分对照，也缺少固定进化策略下“无信念或真值信念”的主实验；总体增益难归因于 LLM。
- 两个到达数不足以表征工序路线、优先级和机器需求；场景生成器的工单属性仍取固定参考分布。
- 无图像、视频、3D 或潜在视觉表征，主要是组合优化框架。

## Future Work
作者提出加入工单级到达属性，在真实调度数据和更多到达机制上评估，并改用更快的预测器降低在线延迟（第 8 页）。

## Rating
创新度评分：2/5 - afterstate、短场景滚动和 LLM 启发式进化均有先例，贡献主要是针对在线调度的组合。
相关度评分：1/3 (Tangential) - 有模型规划的结构化拆分启发，但不研究视频、3D 或隐式视觉世界模型。

## TL;DR
将已知调度转移与未知订单到达拆分，用 LLM 预测两段负载再短程规划；对视觉世界模型参考有限，可跳过。
