# From World Models to World Action Models: A Concise Tutorial for Robotics

## Insight
这篇教程的核心 insight 是把 robotics 中混用的 world model 概念统一成“action-conditioned predictive model”，再区分 observation-space、state-space 和 world action model。Observation 是不同社区把 latent dynamics、video prediction、physics simulator、action-conditioned generator 都叫 world model，导致评价和方法边界混乱。

## Motivation
论文不是解决单一技术瓶颈，而是澄清 embodied AI/robotics 中 world model 与 world action model 的设计空间。同行路线分散在 Dreamer/TD-MPC、V-JEPA/DINO-WM、video prediction、3D point/physical simulator、VLA/WAM 等；教程试图用统一 taxonomy 帮助比较取舍。对本研究方向很相关，但不是原创方法论文。

## Method
论文按预测空间拆分 world model：observation-space 直接预测未来 RGB、多视角、RGB-D 或 point cloud；state-space 先抽象成 latent state、point track、neural-symbolic predicate 或 physical state 再预测。随后定义 WAM 为把未来预测与可执行动作耦合的模型，并总结四类范式：imagine-then-execute、video-feature-conditioned action prediction、joint video-action modeling、auxiliary video prediction for policy learning。核心是 taxonomy 和 trade-off 分析。

## Experiment
没有新实验、消融或 benchmark。论文通过图表和文献分类比较不同方法在视觉保真、空间显式性、物理可解释性、控制可用性、推理成本和动作标签需求上的取舍。

## Value
对速读领域非常有用：它提供了一个清晰框架来摆放视频 world model、3D world model、latent/JEPAs 和 robot action model。作为综述/教程可读，但不能当作技术贡献或实验结论引用。

## Strengths
分类清楚，覆盖从 RGB 视频到 3D/物理状态、从低层动作到语言动作；WAM 四范式对机器人世界模型讨论很实用。

## Weaknesses
篇幅短，很多归类较粗；缺少统一评价、定量比较和失败模式分析；引用的是快速发展中的预印本，taxonomy 可能很快过期。

## Future Work
作者没有明确提出具体未来工作；从内容看，后续需要更统一的 benchmark、控制可用性指标和 world prediction 到 action execution 的接口标准。

## Rating
创新度评分：2/5 - 主要是概念整理和 taxonomy，没有新算法或实验。
相关度评分：3/3 (Core) - 直接梳理机器人 world model 和 world action model，核心相关。
