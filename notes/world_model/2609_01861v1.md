# Belief-Calibrated Optimization: An Explicit World Model for Agentic Optimization

## Insight

观察是：迭代式脚手架优化器虽能读取历轮分数、diff 和轨迹，却没有持久载体保存“某种修改为何会改善或伤害哪些任务”的因果信念，后续调用只能反复从原始证据重建判断。论文据此推论，应把环境响应写成可证伪、带作用域和置信度的显式信念，并以“预测—执行—校正”持续更新。证据主要是五个匹配优化实验、目标模型替换，以及保持文档形式而篡改内容的离线预测对照；这是经验支持，并非对贝叶斯最优性的形式证明。

## Motivation

论文解决冻结 LLM 周边 agent scaffold 的自动优化问题。现有 coding-agent optimizer 会据当前分数和轨迹修改程序，也常使用自由文本反思，但其跨轮记忆缺少明确的预测、证据归因和反证机制，容易受 optimizer's curse 与评测噪声影响。问题对 LLM agent 工程有实际意义，但并不是视频、3D 或 Dreamer/JEPA 意义上的物理世界建模。

## Method

- BCO 在标准 propose-and-evaluate 循环外增加持久文件 `world_model_calibration.md`；vanilla 与其共享初始 scaffold、可编辑代码、全部历史证据、目标模型和 proposer，唯一协议差异是 169 行校准模块。
- 每条信念记录可证伪命题、适用条件、置信度、confirmed/refuted 状态、正反证据及可解释失败数；区分执行信念与评测信念，并维护追加式实验历史。
- 每轮先依据上轮 `prediction.md` 与原始逐任务结果/控制流校正信念，再选择探测不确定信念或利用高置信信念的机制级编辑；修改前需预测受益/受损任务子集，修改后执行 Add/Revise/Merge/Remove。
- 方法本质是结构化的自然语言持久记忆与实验纪律，把 Bayes-adaptive MDP 的 belief-state 直觉落到 LLM 上下文；不是参数化动力学模型，也没有统计校准后验，创新属有约束的协议设计。

## Experiment

- 在 LongMemEval-s（100/400）、LoCoMo（80/1449）、GAIA（40/99）、AppWorld（45/372）和 Terminal-Bench 2.0（20/66）上与 vanilla 匹配比较。BCO 的 held-out passrate 分别为 0.608/0.453/0.495/0.796/0.492，vanilla 为 0.533/0.375/0.343/0.766/0.470；五项训练集最优值也均更高。
- 两个记忆基准从训练前沿前三名中再按 held-out 选最好者，存在已披露的 best-of-three 选择；其余基准取训练 top-1。每个 benchmark 每种方法只有一条主优化轨迹，AppWorld 与 TB2.0 的训练子集还经过稳定性筛选。
- 换成未见过的 gpt-5.6-luna 后，GAIA 的 high/medium/low passrate 为 0.657/0.566/0.485，均高于 vanilla 的 0.475/0.545/0.465。AppWorld 全集上 BCO 因无限累积 scratchpad 导致 99/77/65 个上下文超限，仅得 0.516/0.524/0.532，低于或近似 vanilla；限制到三种 scaffold 都完成的任务后才重新领先。
- 对 40 个候选做离线预测消融：None、Scrambled、Intact 的 upside hit rate 为 0.441/0.460/0.538，downside precision 为 0.142/0.181/0.217；两位盲评也支持同一排序，但独立单位仅四条运行，双侧符号检验为 p=0.125。
- 自由持久 Notes 对照在三条短 LongMemEval 运行中的均值为 0.427，vanilla 为 0.430，BCO 为 0.467；组内波动不小于组间差异，不能证明自由笔记无效。BCO 的 proposer token 相对 vanilla 在三个任务下降 12.4%–27.4%，在 AppWorld/TB2.0 上升 5.2%/26.2%。

## Value

最有价值的启发是把 agent 的经验记忆组织成“可下注、可结算、保留反例”的模型，而不是无约束总结；这一实验账本思路可借鉴到世界模型评测与在线校准。对目标研究方向的直接价值很低：它既不预测视觉/三维状态，也不学习动作条件动力学，论文中的 world model 是对代码修改—评测响应的文本化解释。

## Strengths

- 主对照尽量只改变校准层，并同时报告训练、held-out、目标模型替换和文档内容消融。
- 主动披露记忆任务的 held-out 选优、TB2.0 子集筛选、AppWorld 上下文失败与不显著的运行级检验，结论较克制。
- 信念结构、预测文件、校正实例、grader 和 token 成本在附录中较具体，可复核性好。

## Weaknesses

- 每个主 benchmark 仅一条匹配优化轨迹，无法把方法效应与 proposer 搜索方差充分分离；五个任务中的四个还共享 proposer/target 家族。
- 文档由 LLM 启发式自评，并非校准概率后验；离线机制实验只有四个独立 run，统计力度有限。
- 与自由笔记的在线消融只有三条十轮训练轨迹且未做 held-out 比较，尚不能确定收益来自预测—校正协议而非更一般的持久上下文。
- 固定环境假设较强；目标模型或工具漂移时不会自动折旧旧信念，且资源开销可随模型表达长度失控。

## Future Work

作者建议增加单任务重复次数以支持更细粒度信念；检测 target/tool drift 并衰减旧证据；联合多个目标模型优化；把候选的上下文与资源包络纳入目标。还需以更多独立种子和更强 persistent-memory baseline 验证校准协议本身的增益。

## Rating

创新度评分：2/5 - 将结构化信念、预注册式预测和持续校正组合进 agent scaffold 优化，实验认真但技术核心仍是提示协议与文本记忆。
相关度评分：0/3 (Noise) - 研究对象是 LLM 脚手架优化，不涉及视频、3D 或 JEPA/Dreamer 式隐式动力学世界模型。

## TL;DR

以持久文本信念校准 LLM 脚手架优化，证据较完整但并非目标世界模型，可跳过。
