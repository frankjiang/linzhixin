# Reinforced Planning with Latent World Models

## Insight
世界模型只会展开后果，不会告诉系统如何改进整段 plan；搜索规则也可从 imagined rollouts 中离线强化学习。RP1 同时学习 goal-conditioned quasimetric critic 与迭代 multi-step plan optimizer，后者读取当前计划、终点 value 和对计划梯度，却不模仿 CEM/MPPI。

## Motivation
现有 latent WM 依赖手工 CEM/MPPI/Adam，learned optimizer 又多为模仿手工专家、在线训练或只改下一动作。目标是可插拔到冻结 world model、用极少 rollout 学会整段计划更新。

## Method
离线 TD 学 critic 估计 goal cost-to-go；planner network 对整条 action sequence 反复 refinement，训练奖励来自冻结 world model imagined outcome 与 critic。推理仅做9次 rollout。作者还用一次 Dyna 收集 planner exploitation 失败，微调 world model 后重训 planner。

## Experiment
两种 backbone（LeWM/PLDM）、TwoRoom、Reacher、OGBench Cube。RP1 用9 rollouts，对 CEM/MPPI 的9000及Adam的3000；Reacher tight tolerance 达88.7/82.0%，Cube hard success 在四设置为75.2/67.8/61.1/58.1，显著高于搜索基线；单次 Dyna 再提高4.2–19.1点。并发时最高快67×。但 learned critic 常贡献很大，比较需区分 objective 与 optimizer。

## Value
把“如何搜索”本身模块化学习，是隐式世界模型规划的重要方向，也暴露 optimizer 会利用 world-model hallucination 的现实风险。

## Strengths
跨 backbone 和三类任务；严格核算 rollout 与延迟；与多种手工/学习规划器比较；主动分析 no-op floor 与 model exploitation。

## Weaknesses
训练 planner 的 imagined 分布依赖冻结模型和任务数据；critic 与 optimizer 贡献部分混杂；contact hallucination 需 Dyna 修补，稳定性未知；任务仍是小型模拟，9-rollout优势可能以昂贵离线训练换取。

## Future Work
研究 model exploitation 何时复发、规划器跨任务/模型迁移、不确定性约束和更复杂真实机器人。

## Rating
创新度评分：4/5 - 学习整段计划迭代规则且以极少 rollout 获得强结果，是显著方法创新，但尚未形成普适新范式。
相关度评分：3/3 (Core) - 直接研究 pretrained latent world model 上的可学习规划。

## TL;DR
离线学习整段计划的迭代优化器，9次rollout胜过千次手工搜索，值得精读。
