# Manufacturing Differential Sparsity: Planner-Hardware Co-Design for Efficient World Model Planning

## Insight
观察：JEPA 潜空间 MPC 同一次 CEM 迭代中，接近的动作候选常产生接近的预测激活；候选相减后 INT8 数值的置位比特更少。推论：规划器可以主动让候选按根节点相关采样，制造可供硬件跳过的差分稀疏，同时保持每个候选的高斯边际分布。作者证明子候选 `ρ·根噪声+√(1−ρ²)·独立噪声` 保持边际，并在 6 个模型-任务组合中测得每值置位比特由原始约 1.14–2.12 降至 0.35–0.68；但候选相互相关可能降低探索，需自适应控制 ρ。

## Motivation
JEPA/LeWorldModel 用 CEM 规划时每次需数万次预测器调用（例：300 候选×5 步×30 轮=45,000），即使潜状态很小，重复推理仍慢。现有 token 精简无法用于单 token 的 LeWM，普通比特稀疏加速也未利用候选间冗余。问题直接影响隐式世界模型的在线规划成本。

## Method
Candelta 规划器先计算均值候选，再将余下候选组织为参考森林：每组独立采根、子候选与根相关，逐候选按父节点差分编码；仅在 CEM 方差缩小到适当程度后启用耦合，并调组大小以兼顾探索。ASIC 设计将 INT8 激活与同一量化尺度父激活相减，在整数线性层按置位 bit 串行累加并与父输出合并，非线性层恢复完整值后重新差分；按父先子后调度以减少存储。INT32 线性结果与密集 INT8 算术等价，创新在采样结构和硬件执行联合设计。

## Experiment
LeWM 在 Push-T/Cube/TwoRoom/Reacher，DINO-WM 与 JEPA-WM 在 Push-T；固定 300 候选、30 轮、5 步。成功率差相对普通 CEM 均有跨零 95% 区间，例如 LeWM Push-T 88.2%（+1.5 点，区间 −1.6 至 +4.7）；固定强耦合会使最终目标距离增至 1.218 倍。28 nm 同面积 127.9 mm²、1 GHz 周期级仿真与综合功耗估计：对密集 INT8 芯片加速 1.28–1.80 倍、能耗降 38%–52%；对 Pragmatic 加速 1.22–1.58 倍。相对 Jetson Thor，LeWM 147.7→123 ms、JEPA-WM 28.0→25.1 s，但 DINO-WM 18.8→43.7 s 反而更慢。均值参考、相关采样、父节点行分段调度的分步消融显示三者各有贡献。

## Value
对 JEPA 规划系统的候选相关性、量化与硬件映射有直接启发；适合有边缘部署/ASIC 目标的团队精读。当前收益主要来自硬件仿真，不能等同一般 GPU 上即刻可用的软件加速，也未让大视觉模型达到实时规划。

## Strengths
保留候选边际分布并证明正确性；同时评估任务成功率、置位比特、等面积延迟和能耗；报告 DINO-WM 对商业 GPU 的延迟劣势。

## Weaknesses
ASIC 结果来自周期仿真、综合与功耗模型，未实测流片；速度与能耗依赖静态 INT8 量化及特定线性层。候选相关会牺牲探索，参数按任务调优；对 DINO-WM 的 43.7 秒/次仍远非实时。只有少量目标导航/操控任务，尚无视频生成或更广泛动力学检验。

## Future Work
作者提出将相关参考采样推广至 MPPI、iCEM 等群体规划器，继续推进能满足具身控制时延的世界模型规划。

## Rating
创新度评分：3/5 - 规划器主动制造差分 bit 稀疏与硬件协同有新意，但结果限于模拟芯片和特定规划负载。
相关度评分：2/3 (Related) - 直接加速 JEPA 式隐式世界模型规划，但核心贡献在硬件系统而非世界表征或预测。

## TL;DR
相关采样让 JEPA 规划候选的量化激活更稀疏，专用芯片仿真节能提速；关注部署效率可选读。
