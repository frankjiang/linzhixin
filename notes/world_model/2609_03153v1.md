# VeriPhy: Agentic Physical Reasoning for World Model Evaluation and Refinement

## Insight

论文的核心 observation 是：视频视觉流畅或单一质量分无法说明“哪条物理义务在何时被违反”。若在看帧之前把 prompt 编译为带类型的 obligation 和无环执行图，再让观测只负责激活/缩小预先声明的工具调用，就能让每个 verdict 追溯到原文 span、时间窗、mask/track、数值、阈值和工具版本，而不允许事后按画面改评价问题。不可测证据显式记为 unknown，避免 grounding/追踪失败被误当成视频满足要求。该优势是可审计性而非纯 recall：同一 Qwen backbone 的单次自由文本已有 73.0% recall，VeriPhy 为 75.0%。

生成侧另观察到，扩散模型的运动在高噪声早期即大体“承诺”，但接触后的动力学比空中轨迹更依赖持续 control；withdrawal sweep 把 commitment 定位在相对噪声约 0.94–0.96，过早撤去时飞行仍一致、落地滚动/反弹却先失真。这由多个小型受控轨迹实验支持，不是普适理论。

## Motivation

现有 world-model/video evaluator 分散具备规则判断、时间定位、轨迹测量或音画一致性，却很少把开放 prompt、物理义务、异构工具、缺测处理和最终决策连成同一条可重放证据链。物理反馈若要进一步训练或局部修复生成器，必须知道违反了什么、发生在哪里以及依据是什么。该问题对视频世界模型评测和反馈优化直接重要。

## Method

VeriPhy 的 text-only planner 先从 prompt 抽取逐字 span 和 checkable claims，以受限 DSL 写 `exists/count/before/during/rel/traj/sound/text/judge` 检查；compiler 统一跨组实体命名，展开依赖，并验证解析、引用、类型、无环和每 claim 有检查，失败项以计费且留痕的 general verifier 替代。执行时按拓扑序调用 Qwen3-VL dense verifier、SAM 3 grounding/tracking、TAPNext++ 上的 11 种位移/接触/形变/路径/持续/跳跃/阻尼/时序/视角测量、深度、OCR 与 FlexSED；时间关系只有在事件 occurrence 被确认后才使用窗口。

每个 evidence record 保存 claim、scope、measured/abstained/errored 状态、typed payload 或显式 learned-state tag、artifact hash 与成本。固定 resolver 将 sub-check 合成为 supported/contradicted/unknown：任一反证使 claim/clip 不成立，全部支持才 plausible，否则 abstain；基础 verifier 判为通过的 claim 还可被更强 closed gpt-5.6-sol 单向推翻。输出的 contradiction packet 包括证据、时空范围和 mask，可作为未来局部编辑接口。

另建 MuJoCo→depth/silhouette→Wan2.2-VACE 管线：LLM 编写 scene spec，最多三次按轨迹谓词修改并重模拟，验证后渲染统一时钟的深度 control，以全白 mask 和固定 strength 控制冻结视频模型。它与 critic 分开评价。附录再把可读状态形式化为 `S=(operator library O, experience M, external knowledge K)`；本稿只实现固定 O 和由错误蒸馏到 M 的 context lessons，多数控制编辑、准入门、K 与人审仍是 roadmap。

## Experiment

数据为 1,500 个生成视频、2,582 条单人标注 flaw；筛成 150-clip/306-flaw 开发 core，因一例无测量实际报告 149 clips、304 flaws。匹配以语义 whole/partial 边做最大二分匹配，只能测 recall，不能测 precision。VeriPhy 找到 228/304（75.0%，191 whole+37 partial），question decomposition 为 164（53.9%），scene graph 161（53.0%），同 backbone 单次自由文本为 222（73.0%）。VeriPhy 平均 14.1 calls/clip 对单次模型 1.0；其 871 个 finding 仅 26% 对应已标 flaw，question decomposition 为 29%。83/228 匹配来自强 fallback verifier；227 次物理 specialist 调用中 166 次 abstain、61 次反证。分类 recall 从 camera/style 90%、text 84% 到 count 49%、physical motion 57%。

在 VideoPhy-2 固定 200 clips 上，VeriPhy 的 semantic-adherence exact/within-1 为 31/76%，低于 VideoScore2 的 33/83%，但 PLCC/SRCC 为 .464/.465，高于 .353/.327；hard 55 clips 的相关性差距更大但区间宽。Physion-Eval 前 601 个 prequential clips 上，evidence-conditioned flag rate 26.8%、matched-report clip rate 18.4%、anomaly-phrased 15.5%；因样本和协议不同，与公开 evaluator 只能描述性比较。

context lessons 在与经验 pool 隔离的 306 clips/502 flaws 上把 recall 从 340（67.7%）升到 375（74.7%，paired sign test `p=3e-4`），但 25 个经验 clips 已达到 375，增至 117 clips 不再提升；claims/clip 从 9.5 增至 16.7，收益混有更大检查预算。prompt rewrite 闭环在 589 个 held-out Cosmos3-Nano clips 上按 VeriPhy 自评分改善 63/87 个被触发样本、49/65 verdict 翻正；独立 VideoPhy-2 AutoRater 的语义、物理与联合指标均不变或略降，故未证明真实物理改进。

生成管线用 66 类、1,314 个 scenes；591/652 个仿真通过预检。单物体轨迹能紧跟 control，多体 billiards 等仍失败。控制语句/seed/withdrawal、airborne/post-contact 分窗和 tracker 复测较细，但规模较小，且 81 帧渲染会把模拟时间拉伸 1.8–2.3 倍，绝对速度不保真。

## Value

对我们的主要价值是评价协议：把“世界模型是否物理正确”拆为预先承诺的 claim、可失败的测量、三值逻辑和可追溯组合，而非只训练另一个不可解释分数。这种 contradiction packet 很适合未来 reward、preference optimization 或局部重生成。论文也极为诚实地区分已实现、开发集结果、自评改善和 roadmap。现阶段它仍是昂贵的外围 critic，不是世界模型本身；准确性相对单次 VLM 的增益很小，闭环改进尚未由独立评价确认。

## Strengths

- plan-before-frames、静态类型检查、显式 abstain 与 provenance 形成难得完整的可审计评价契约。
- 公开区分 typed measurement 和 learned judgment，且每个工具失败不会悄悄变成负证据。
- 实验覆盖 flaw-level recall、分类型表现、成本、human-score correlation、跨数据集、context lesson、生成 control 与反馈闭环。
- 对开发集、单标注、无 precision、fallback 依赖和独立 rater 不认可改进等负面结果陈述克制。
- 控制撤除实验按飞行/接触后分窗，揭示全片指标会掩盖接触失效，方法论有启发。

## Weaknesses

- 核心 75.0% recall 只比同 backbone 单次自由文本 73.0% 高 2 点，却需 14.1 倍调用；主要确立 auditability，而非更准或更省。
- core 是反复开发使用的非 held-out 集，只含有缺陷视频且单人标注；不能计算 precision/false-positive，也无 inter-annotator agreement。
- 83 个匹配依赖不开放的 gpt-5.6-sol fallback，物理 specialists 又有 73% abstention，实际判定仍高度依赖 learned verifier。
- benchmark 的“physical motion”仅 7 条，count/text/一般 prompt adherence 占比很高，headline 不能等同于广义物理推理能力。
- 工具间实体 binding 只保证符号 ID 一致，不能保证 SAM、tracker、depth 和 VLM 指向同一实例；三值固定组合也会放大单项误判。
- lessons 的准入 gate 未实现，全部 33 条塞入每个 prompt并显著增加 claims；所谓 self-evolution 更接近人工整理的 context expansion。
- prompt-only rewrite 只改善 critic 自评分，独立物理评分没有变化；真正按时空 packet 修改 geometric control 尚未实现。
- simulator control 限于可建模场景，复杂多体、流体/烟雾/有限元软体与绝对速度均未解决，critic 的音频能力本稿也完全未测。

## Future Work

作者给出明确路线：先建立真正 held-out、同时测 precision/recall/unknown 与 provenance completeness 的协议；扩展带成本节点且可版本化的 operator library；为 context edit 实施 held-out proxy 准入和有害先验压力测试；把 contradiction packet 映射为局部 MuJoCo/VACE control 编辑并由人类独立验证净缺陷变化；加入带来源与剪枝的外部知识 K 和人审/回滚。近期最具体方向是启用现有音频工具，将视觉接触窗口与声音 onset 放到同一时钟验证音画物理因果。

## Rating

创新度评分：3/5 - 类型化、三值、可追溯的 agentic 物理评测整合扎实且实验丰富，但多数模块来自既有工具，准确率增益小、开发集与闭环证据不足。
相关度评分：3/3 (Core) - 直接研究视频世界模型的物理诊断、可审计评测与反馈优化；虽不提出新的生成器，研究对象和闭环用途仍属于视频世界模型核心问题。

## TL;DR

以可执行义务和证据链审计视频物理错误，框架扎实但精度与闭环未证实，可选读。
