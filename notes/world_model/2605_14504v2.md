# LongAct: A Benchmark and Agent for Long-Horizon Household Task Execution

## Insight
现有Embodied AI基准测试聚焦短期任务（单步抓取/导航），但真实家务场景需要长时间规划、记忆维护和经验积累。LongAct提出首个长时间跨度（500+人类步骤、2000+Agent步骤）的家务任务基准。

## Motivation
现有benchmark（ALFRED等）任务简单、指令固定，无法评估Agent的长期规划、记忆管理和自我改进能力。论文认为长期任务执行是通向真正家务机器人的核心挑战。同时提出HoloMind Agent架构解决该挑战。

## Method
- **LongAct Benchmark**：100+场景、300个episode，平均9个子目标，需500+人类步骤
  - 四类家务场景：清洁整理、工作学习、休息娱乐、餐厨
  - Checklist自动评估：位置/开关/切片/烹饪/液体填充状态
  - Improvement Rate (IR)指标：衡量Agent随时间的自我改进能力
- **HoloMind Agent**：
  - 两层规划器：高层DAG分解 + 低层子目标执行
  - 多模态空间记忆：3D场景图 + 物体级CLIP索引
  - 经验记忆：积累规则和约束
  - Critic：跨模块反思监督（Pass/Refine/Replan）

## Experiment
- GPT-5 + HoloMind最优：GC 59.0%, SR 16.0%（仍远低于人类93%），证明任务极具挑战性
- 纯VLM（无Agent架构）几乎完全失败（Qwen3-VL-8B: GC 0.74%）
- HoloMind将32B和8B模型的GC差距从8倍缩小到2倍，说明Agent架构比模型规模更重要
- Critic模块移除后GC下降22%，是最关键组件

## Value
与视频/3D世界模型方向间接相关（HoloMind中的空间记忆可视为一种世界状态表示）。但核心贡献是benchmark设计和Agent架构，非世界模型方法论创新。对Embodied AI研究有参考价值，但与用户的视频/隐式世界模型研究方向距离较远。
