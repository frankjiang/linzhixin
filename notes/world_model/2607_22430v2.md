# On the Identifiability of Controlled World Models

## Insight
有。论文的核心 observation 是：受控世界模型在行为策略数据上预测得好，并不意味着学到了可用于反事实控制的真实动力学。推论是 action-conditioned JEPA 需要两个 margin：representation spectral separation `gamma_rep(pi) > 0` 和 conditional action excitation `rho_tr(pi) > 0`。前者保证可预测信号可被表征分离，后者保证给定状态下动作有足够覆盖。若动作覆盖弱，反事实误差会按 `1/rho_tr` 放大。

## Motivation
论文解决 controlled latent world model / JEPA 的可辨识性问题。同行常训练 `h(x_t), a_t -> h(x_{t+1})`，再把低预测误差当作可规划能力证据；但 on-policy 数据可能动作共线、动作几乎确定或覆盖不足，导致 action effect、B 矩阵和 counterfactual response 不可辨识。这是 JEPA/Dreamer 类模型用于 planning/control 的关键理论问题。

## Method
理论设定为高斯 latent state `z_t ~ N(0,I)`，非线性可逆观测 `x=g(z)`，线性高斯受控动力学 `z_{t+1}=Az_t+Ba_t+xi_t`，行为策略可状态依赖并诱导联合高斯分布。学习器包含 encoder `h` 和 action-conditioned predictor `F`，约束 `h(x_t)` 为标准高斯，目标类似 LeJEPA 的 representation-space prediction。

主要结果：Theorem 1 给出 joint identifiability，若 spectral separation 和 conditional action excitation 同时成立，全局最优可在正交变换内恢复 latent state 与 controlled conditional mean。Theorem 2 给 approximate optimization 下的误差界，transition error 受 `1/gamma_rep` 控制。Theorem 3 构造反事实误差放大：on-policy excess risk 为 `delta` 的 predictor，可在 counterfactual action 分布上产生 `delta/rho_tr` 误差；探索噪声 `sigma` 下放大为 `1/sigma^2`。

## Experiment
实验使用低维合成系统和四类非线性 observation maps，分别做 representation-margin sweep、behavior-policy coverage sweep 和 goal-conditioned planning。动作独立高斯时固定 `rho_tr=1`，改变 predictable-signal spectrum；coverage sweep 中通过行为策略的条件噪声 `sigma` 改变 `rho_tr=sigma^2`。

结果支持理论：spectral separation 增大时 representation error 和 controlled-transition error 均下降；当 `sigma=0` 或很小时，behavior action 上预测可准确，但 counterfactual prediction、A/B component recovery 和规划误差很差；随 conditional action coverage 增强，预测 reachable set 与真实 reachable set 对齐，goal-conditioned terminal error 明显下降。

## Value
价值很高：它把“世界模型是否真的能控制”从经验性能推进到可辨识条件。对我们研究 JEPA/Dreamer 的直接启发是：数据采集策略中的 action support 不是工程细节，而是学习反事实 dynamics 的必要条件；仅评估 on-policy prediction 会高估模型的规划可靠性。

## Strengths
理论问题精准；清晰区分 representation identifiability 与 transition identifiability；给出 counterfactual amplification 的可达到构造；实验虽简单但准确验证 margin、coverage、planning 三者关系。

## Weaknesses
假设较强：观测可逆、latent dynamics 线性高斯、表示严格白化/标准高斯、主要识别 controlled conditional mean。实验是低维合成，没有真实视频/机器人；对非线性 dynamics、部分可观测和有限样本只作为未来方向。

## Future Work
作者明确提出未来扩展到 finite-sample settings、非线性 dynamics、部分可观测系统，以及更真实的受控视觉/机器人世界模型。

## Rating
创新度评分：4/5 - 针对 controlled JEPA 给出明确可辨识条件和反事实误差机制，理论贡献显著。
相关度评分：3/3 (Core) - 直接研究受控 JEPA/隐式世界模型的可辨识性，是核心相关。

## TL;DR
证明受控JEPA需状态可辨识和行动覆盖，否则反事实规划会失真，值得精读。
