# SafeMCP: Proactive Power Regulation for LLM Agent Defense via Environment-Grounded Look-Ahead Reasoning

创新度：3/5 | 相关度：0/3

## Insight
Observation: 现有LLM agent guardrail均为事后(ex-post)检测，即agent选完action后再审查，一旦发现违规则终止workflow，导致过度拒绝和workflow中断。SafeMCP观察到agent-defense交互可建模为Cooperative Stackelberg博弈：defender作为leader在agent选择action之前主动约束action space（ex-ante），而非事后审查。由此推出Safe Stackelberg Equilibrium (SSE)的存在性定理，证明在有限action集下总能找到安全均衡策略，使agent在安全约束下最大化utility而不中断workflow。

## Motivation
- **问题**：MCP协议使LLM agent可动态获取工具，action space自动扩展带来power-seeking风险（agent倾向获取高权限状态）。
- **同行做法**：现有guardrail（Llama Guard、ChainGuard、AgentMonitor等）均为reactive的事后过滤，基于静态语义匹配，不理解环境状态转移，导致：(1) 误拦正常工具调用（over-blocking）；(2) 无法预见语义合法但后果危险的操作序列。
- **是否关键**：在MCP生态中是有意义的安全问题，但与视频/3D世界模型方向无直接关联。

## Method
整体管线：三阶段训练 + 两层推理时防御。

**训练：**
1. **Environment Dynamic Grounding**：在ToolEmu/AgentHarm环境中收集安全关键交互轨迹，通过adversarial mutation生成power-seeking数据。用NLL loss联合训练next-state prediction和unsafe-steps prediction，使模型内化环境转移规则。
2. **Safe Policy Initialization**：用oracle-augmented teacher prompt生成2000条高质量推理样本，cold-start SFT建立dual-phase reasoning prior。
3. **RL with Dual Verifiable Rewards**：采用PPO + 双重奖励：binary safety reward + Smooth Tchebycheff (STCH) scalarization的continuous tool-filtering reward，解决离散集合匹配的梯度稀疏问题。

**推理：**
- Tier 1 (Proactive)：预测下一步状态并过滤会导致unsafe转移的工具，缩小agent可用action space。
- Tier 2 (Fail-safe)：若预测当前action直接导致unsafe状态，立即拦截。

**创新程度**：将agent安全建模为Stackelberg博弈有理论新意；STCH reward设计解决了集合匹配稀疏奖励问题，工程上有贡献。但核心思路（world model做前瞻 + 工具过滤）相对直观。

## Experiment
- **基准**：PowerSeeking Bench (112 prompts, 自建)、ToolEmu (144 instructions)、AgentHarm (176+176 benign/harmful)。
- **对比**：Llama Guard 3、Qwen3Guard-8B、NeMoGuard-8B、ChainGuard、AgentMonitor、RL-Guard、Safiron共7个baseline。
- **Agent**：GPT-4o、GPT-4o-mini、Gemini-2.0-Flash、Claude-3.5-Sonnet、LLaMA-3.1-8B。
- **指标**：Safety rate、Utility rate、Average、Libra (safety-utility调和)。
- **效果**：SafeMCP在多数agent上达到Pareto前沿最优：ToolEmu上safety 0.98 + utility 0.22 → Libra 0.44 (GPT-4o); AgentHarm上harmful score 0.19 + benign 0.69 → Libra 0.36，over-blocking率仅0.01。消融验证三阶段和STCH reward各自必要。

## Value
作为LLM agent安全领域的工作，Stackelberg博弈建模和proactive tool filtering的思路有一定价值。但与视频世界模型、3D世界模型、隐式世界模型方向完全无关，这里的"world model"仅指LLM内化的文本环境状态转移模型，不涉及视觉感知或物理世界建模。对我们的研究方向没有直接启发。
