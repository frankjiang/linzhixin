# Frozen in a Frame: The Velocity Blind Spot in JEPA World Models

## Insight
若渲染帧只由位置/构型决定，任何单帧编码 `E(o_t)` 都是构型的函数；当同一构型允许多种速度时，速度不可能由这个编码唯一识别。论文给出数据处理式证明，并用相同起始画面、相反初速度的双分支实验验证。此结论针对单帧**表征/目标**；使用多帧历史的预测器仍可从历史推断运动，不能据此声称所有 JEPA 规划器必然失明。

## Motivation
LeWM 式 JEPA 把下一单帧嵌入当目标，即使预测器接收短历史，也难保证可供探测和规划的表征含速度。惯性任务中“到达目标”与“停在目标”不同，仅由静态目标图像定义的代价不能区分两者。需要同时检查表征可识别性、相反速度分支的 rollout 和实际规划收益。

## Method
RateIdent 分三层评测：跨 episode 的单帧/多帧线性探针；同画面反向速度的开放环分支实验；停在目标的 CEM 开环/闭环规划。TI-JEPA 将潜变量拆成单帧 pose code `q_t` 和由三帧 `q` 的有限差分经无偏置 MLP 生成的 motion code `v_t`；无额外历史输入的预测器联合预测下一 `(q,v)`，只对 `q` 用 SIGReg，另对 `v` 加软方差下界。无偏置保证重复帧差分为零，但 `v` 仍需历史帧计算。新意在给 JEPA 单帧目标的明确诊断和可审计修正，pose/motion 分解本身不是新范式。

## Experiment
官方 LeWM 的 PushT、Reacher、Cube、TwoRoom 权重无需重训：速度线性探针基本处于机会水平，单帧位置探针 R² 约 0.94–0.98。三种受控惯性环境中，对等无记忆基线的闭环最终距离，Pendulum 从 0.647 降到 0.292、CartPole 从 0.490 降到 0.178；模型在同画面反向速度下能分叉。官方尺寸 ViT-Tiny/AdaLN 复现了单帧基线零分叉；dm-control Reacher 渲染图像上 TI-JEPA 分叉比为 2.166，对三帧历史基线 0.057，但角速度线性探针及方向正确率仍接近随机。对照 GRU 历史聚合器在 InertiaBall/Pendulum 的规划指标常持平或更好，TI-JEPA 在 CartPole 占优。论文还报告真 PushT 规划无收益、官方尺寸部分方向指标低于机会水平。

## Value
对隐式世界模型很有用：要区分“目标本身含什么信息”“预测器能从历史估计什么”以及“规划目标奖励什么”；RateIdent 是可直接迁移的评测框架。

## Strengths
给出清晰的可识别性条件与反例；从官方权重、受控物理环境到真实渲染图像逐层验证；报告 RNN 对照、负面结果和多项方法学陷阱，如相邻帧探针泄漏。

## Weaknesses
运动码需三帧，增加历史依赖；真实 Reacher 上分叉幅度超过真值但方向正确率仅 0.525，不能等同于准确速度预测。正向规划收益限于三种受控环境，RNN 在其中两种并不逊色；静态目标代价的局限也可通过显式速度代价解决。

## Future Work
作者未提出明确路线；论文指出需更强规划器、更多真实接触任务和不同动作统计下的真实机器人数据，以检验 motion code 与规划收益的普适性。

## Rating
创新度评分：3/5 - 单帧目标的信息论诊断和结构化双码修正有研究价值，但修正沿用有限差分与内容/运动分解，真实任务优势混合。
相关度评分：3/3 (Core) - 直接研究 JEPA/LeWM 隐式世界模型的运动状态、rollout 与规划。

## TL;DR
证明单帧 JEPA 表征无法识别速度，并用显式运动码修补与诊断；边界清楚，值得精读。
