# SWAP: Symmetric Equivariant World-Model for Agile Robot Parkour

## Insight
Observation：四足机器人和物理动力学天然具有左右镜像对称，但普通 latent world model 会把左右对称交互当成独立模式学习，浪费样本并导致策略陷入非对称次优模式。

推论：把反射等变性硬编码进世界模型和 actor-critic，可压缩 latent dynamics 的冗余，提升极限跑酷中的探索效率和几何泛化。

## Motivation
论文解决四足机器人极限 parkour：gap leaping、box climbing 等任务需要长时预测、稳定接触和高效探索。已有 Dreamer/RSSM 类 locomotion world model 主要数据驱动，缺少结构先验。

该问题对“世界模型 + 控制”相关，但更偏机器人运动控制，不是通用视频/3D生成世界模型。

## Method
SWAP 是端到端等变世界模型 + 等变 actor-critic：
- 基于 RSSM，低频 10Hz 更新 latent state，高频 50Hz 控制。
- Symmetric Equivariant Encoder/Decoder：深度图用 Z2 reflection group 的 SE-CNN，本体感知/heightmap 用 SE-MLP。
- SE-GRU / prior / posterior：latent state 维度成对排列，通过 permutation 实现镜像等变。
- Actor 等变：镜像观测输出镜像动作；Critic 不变：镜像状态 value 一致。
- 训练损失包括观测/heightmap 重建和 KL，policy 在 symmetry-constrained latent 上训练。

创新在于把硬等变约束贯穿 perception、latent dynamics、policy，而不只是数据增强或 symmetry loss。

## Experiment
仿真包括 gap leaping 和 box climbing，并比较 SWAP、去掉等变 policy、去掉等变 world model、SymLoss 等。

结果：
- SWAP 在 gap leaping 中学习到前腿撑边、后腿强推的策略；在 box climbing 中保持双侧协调接触。
- 去等变或仅 symmetry loss 容易出现低效步态或探索坍缩。
- 真实 Apollo 四足零样本部署：跳过 2.13m gap，攀爬 1.63m platform；按论文表格为当前对比中绝对距离/高度最高，约为 body length/hip height 的 3.0 倍。
- Outdoor zero-shot：湿滑石台、浅水反光、黑暗楼梯、高草/纸板、碎石/地毯等环境均展示鲁棒性。

## Value
对机器人世界模型的启发：结构先验可以比单纯扩大模型/数据更有效，尤其在对称、接触、极限动力学场景。对视频世界模型的间接启发是：世界状态表示应尊重物理群结构。

局限：主要验证反射对称和四足 parkour；对离散 foothold、复杂非结构化地形还未充分测试。与视觉生成世界模型的联系较弱。

## Strengths
亮点是对机器人世界模型的启发：结构先验可以比单纯扩大模型/数据更有效，尤其在对称、接触、极限动力学场景。
