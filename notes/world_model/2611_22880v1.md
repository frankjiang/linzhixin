# Learning Agent-Centric Vision-Language-Action World Models for Autonomous Driving

## Insight
观察：密集未来视觉 token 成本高，且不一定转化为规划所需的车、行人运动信息。推论：把周围实体表示为可定位的 agent token，保留几何、运动与交互，可作为更有效的决策状态。相同主干、代理信息及训练下，agent token 的 L2/碰撞率为 0.27 m/0.08%，优于全局潜变量 0.49 m/0.23% 与结构文本 0.58 m/0.21%；打乱 token 与实体对应后降至 0.63 m/0.74%。附录的规划后悔界建立在“agent 状态足够”与 Lipschitz 成本的假设上，并非现实场景的普适证明。

## Motivation
驾驶 VLA 世界模型常生成高成本像素未来或混合场景潜量，难明确表达谁会影响自车。选择紧凑且物理可验证的状态，是隐式世界建模与规划对齐的重要问题。

## Method
在 Qwen2-VL 中加入最多 20 个特殊 agent token，经三层几何/视觉双分支路由注意力，融合离线 VGGT 式 4D 特征与 2D 图像特征。训练头以匈牙利匹配监督 token 的存在/类别、3D 框与未来轨迹；接着 SFT 产生基于 agent 的简短推理、驾驶高层动作和 3 秒自车轨迹；最后 GRPO 以格式、识别、动作、轨迹、交互风险复合奖励微调 MLLM。最终推理移除辅助头及路由模块，直接由 MLLM 的 agent token 隐状态规划。创新重心是可寻址实体状态及其监督/规划接口。

## Experiment
nuScenes 开环 ST-P3 指标下，带自车状态模型平均 L2 0.25 m、碰撞率 0.07%；不带状态为 0.27 m/0.08%，前者优于 VLA-World 的 0.26 m/0.08%，后者并未超越。Bench2Drive 闭环 Driving Score 81.17、成功率 61.36%，高于 AutoVLA 78.84/57.73%；舒适分 54.39。nuScenes 检测 mAP/NDS 0.318/0.416。去掉 4D 或 2D 路由，L2 由 0.27 增至 0.30/0.28；仅 SFT 为 0.32，加入 RL 为 0.27；延迟 0.31 s，对比 VLA-World 0.40 s。附录显示 RL 保留 agent head 时 L2 0.26，略优于默认 0.27。

## Value
值得精读“可寻址实体”作为隐式世界状态的受控对照和对应扰动测试；对于视频/3D 模型，可借其稀疏交互状态设计，但不能直接视作已学会开放式行动条件模拟。

## Strengths
同配置比较三种状态表示、token 对应扰动、视觉/几何消融；同时报告开环、闭环和时延；实体头允许物理量核验。

## Weaknesses
推理时移除训练阶段的显式几何路由，训练/推理存在接口偏移；未来实体预测以训练头监督，未展示候选自车动作条件下的反事实多步 rollout。附录理论依赖状态充分性假设。外部 VLA 比较涉及自车状态与输入差异，默认无自车状态配置并非所有指标最优。

## Future Work
作者提出更可扩展的自监督实体定位与视觉语义绑定，保持跨时间的身份、物理状态和交互语义一致。

## Rating
创新度评分：3/5 - 实体 token 状态与规划接口有明确贡献，但训练主要整合已有路由、匹配及 GRPO。
相关度评分：2/3 (Related) - 与 3D/隐式世界状态设计密切相关，主要成果仍是驾驶 VLA 策略而非通用可滚动模型。

## TL;DR
以物理锚定的实体 token 替代密集未来视觉表示，改善驾驶规划并验证 token 对应关系；值得精读。
