# Dreamer-CPC: Message Learning with World Models for Decentralized Multi-agent Reinforcement Learning

## Insight
核心 insight 是多智能体通信不应只编码当前 observation，而应从 Dreamer/RSSM latent state 中生成 message，因为 RSSM latent 已整合历史 observation/action，可在当前信息暂时缺失时传递预测性上下文。实验中的 CatchApple 正是验证这一点：Agent 2 需要在看不到落点前根据 Agent 1 的历史信息提前移动。

## Motivation
MARL 中通信常用于 partial observability，但 CTDE、共享 reward 或全局 critic 与完全去中心化学习不一致。CPC/MARL-CPC 类方法能从本地 observation 学消息，但消息只依赖当前帧，遇到遮挡、临时缺失或需预测未来的任务就不足。本文试图把 CPC-based message learning 嵌入 DreamerV3 world model，使每个 agent 独立训练、独立执行，同时通过 world-model latent dynamics 交换有时间上下文的消息。

## Method
每个 agent 维护自己的 DreamerV3 RSSM，包括 deterministic state h、stochastic latent z、observation/reward/continuation heads。另有 recurrent message module，其 hidden state xi 汇总历史消息；message prior 从 xi 预测，message posterior 从 xi、h、z 推断。预测消息 m_hat 被输入 RSSM transition，posterior message m 被输入 observation reconstruction。其他 agent 的 message 在训练中 stop-gradient，以避免跨 agent 参数反传，实现 decentralized training with decentralized execution。目标函数是在 DreamerV3 world-model loss 上加入 message prior/posterior 的 KL-balanced/free-bits 项；actor-critic 学习沿用 DreamerV3，但 imagination rollout 中每步会推断并交换 message。

## Experiment
评测两个两智能体环境。Observer 中 Agent 1 观察 reward location 但不动，Agent 2 在 4x4 grid 上行动但不知道 reward 位置；Dreamer-CPC 5x4 message 最终 IQM return 39.85，20x1 为 19.72，明显优于 IPPO-CPC 约 7、IPPO/no-comm 近 0，obs-shared 上限 53.63。CatchApple 中落物轨迹有遮挡，Agent 2 必须提前预测落点；Dreamer-CPC 5x4 达 28.53，20x1 达 20.47，IPPO-CPC 约 5，no-comm DreamerV3 5.93，obs-shared 38.21。曲线以 10 seeds IQM 和 bootstrap 95% CI 展示。

## Value
这篇对隐式 world model 方向直接相关：它展示 RSSM latent 不只是 policy imagination 的内部状态，也可以作为通信消息的语义来源。对多智能体 world model、具身协作和部分可观测控制有启发。待解决的是消息内容可解释性、更多 agent 和更真实任务规模。

## Strengths
方法结构简洁，和 DreamerV3 的 world model/actor-critic 训练兼容；stop-gradient 设计避免了伪中心化；CatchApple 任务很好地区分了“当前 observation 通信”和“历史 latent 通信”的差异。

## Weaknesses
实验只覆盖两个小型自建环境和两个 agent，缺少标准复杂 MARL benchmark。论文没有分析 learned message 的内容，也没有验证在连续控制、视觉输入或更多智能体下是否稳定。方法增益可能部分来自 DreamerV3 本身的模型式样本效率，而非 CPC 消息目标单独贡献。

## Future Work
作者提出未来分析消息携带的信息内容和结构，扩展到更多 agent，并在更通用的 MARL benchmarks 上验证 Dreamer-CPC。

## Rating
创新度评分：3/5 - 把 CPC message learning 嵌入 Dreamer/RSSM 是自然但有用的组合，实验支持明确，但规模较小。
相关度评分：3/3 (Core) - 直接基于 DreamerV3 world model 研究隐式 latent dynamics 在 MARL 通信中的作用。

Dreamer-CPC用RSSM历史latent生成多智能体消息，核心相关但实验小，建议选读。
