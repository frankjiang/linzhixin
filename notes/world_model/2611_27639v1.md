# SOAR: Training-Free Rank-Consistent Rollout Compression for Latent World Model Planning

## Insight
观察：CEM 只用预测代价给候选动作排序并选前 K 个，预测特征或代价数值可以变化而计划不变。命题证明：若压缩代价是稠密代价的严格单调变换，精英集合和后续 CEM 分布逐轮相同；这是充分条件，而在线 16 候选 Spearman 相关只是近似代理。消融显示首个读取真实观测的预测步更敏感，旧帧可通过 KV 缓存保留。

## Motivation
JEPA-WM 的每次 CEM 决策要将数百候选序列经 Transformer 反复展开，H100 上约 20–50 秒。已有稀疏 token 方法主要保图像特征，却未针对规划器实际使用的候选排序优化。加速能否不伤闭环成功率是关键问题。

## Method
冻结已训练 JEPA-WM。第 0 预测步用全部 256 个 patch；其后旧帧读取先前计算的逐层 KV 缓存，新帧从嵌套棋盘格预算 {128,192,256} 取 token。每个决策在第一轮 300 个 CEM 候选中固定抽 16 个，三档预算各展开一次，与 256 档比较 Spearman 相关，选满足阈值 0.9 的最小预算，其余 CEM 迭代共用；探针约占决策耗时 1–2%。新意在“规划排序一致性”驱动在线预算，缓存本身是现成技术。

## Experiment
冻结 JEPA-WM 检查点，在 Maze、Wall、Push-T、MetaWorld 两项、RoboCasa 两项做闭环评测，完整一次 544 片段，含跨批次复验与总计超过 8 万片段；指标为各任务宏平均成功率、完整规划调用延迟和配对 bootstrap 区间。主配对组中稠密成功率 48.96%，SOAR 49.26%，2.31 倍加速；差值 +0.30 百分点，95% 区间 [−4.17,+4.91]，故证据是近似持平而非显著更好。固定 192 token 同为 49.26%，但仅 2.21 倍；固定 128 为 45.39%、2.98 倍。SOAR 在 Push-T 相比固定 192 多 7/96 次成功，在 Wall 多 6/96；但 MetaWorld 两任务各少 4–5 次。只保首步全量可恢复约 5.4 个宏平均百分点；缓存上下文的全量变体已有 1.76 倍加速。

## Value
对 JEPA 类潜世界模型规划很有参考价值：压缩应围绕下游决策不变量，而非默认特征重建误差；值得精读。其“先固定关键时序结构，再在线调空间预算”的诊断方式可迁移到其他采样规划器。

## Strengths
在相同冻结检查点上做空间、时间、上下文、网络深度多轴诊断；包含规划全流程计时、配对闭环评测与强稀疏模型对照；明确命题只适用于按排序选精英的规划器。

## Weaknesses
仅验证两帧上下文的 JEPA-WM 和 CEM；16 个第一轮候选的秩相关不能保证后续轮次前 K 集合一致。RoboCasa 基线成功样本很少，单任务不稳定；固定 192 预算达到相同平均成功率，在线策略的优势主要体现于任务失败分布和小幅速度差。

## Future Work
作者建议扩展到长上下文预测器和 MPPI 等按代价值加权的规划器；在后续 CEM 轮次探测、改用 top-K 重合率、采用更细预算。

## Rating
创新度评分：3/5 - 以候选排序定义压缩目标有清晰 insight，但实现组合了现有 KV 缓存和 token 子采样。
相关度评分：3/3 (Core) - 直接优化 JEPA 隐式世界模型的想象规划。

## TL;DR
以候选排序决定 JEPA 世界模型展开的 token 预算，并保留首步与缓存上下文；规划加速方法值得精读。
