# QQWorld: Quantile-Quantile Matching for World Model Regularization

## Insight
论文从一个反常观察出发：LeWM 明明用 Epps-Pulley（EP）正态性检验约束 latent，所得分布仍有重尾。作者把 EP 等价写成固定带宽 Gaussian-kernel MMD，并证明孤立尾部样本的中心恢复梯度会随距离快速衰减；因此“能检测分布差异”的统计量未必是“有良好优化梯度”的训练目标。QQ 匹配则将排序样本直接拉向对应 Gaussian quantile，恢复力与偏差线性增长。论文进一步证明 QQ 收敛可单向控制 EP，而反之不成立，并以实验连接更薄的 latent tail 与更高的 CEM 规划成功率。

## Motivation
JEPA 式 latent world model 用紧凑表征做 rollout 和规划，latent 分布的极端值会把动力学推向训练稀疏区并放大多步误差。LeWM 用 EP 全分布正则避免 collapse，但固定尺度核对远端样本几乎失去恢复力。这个问题虽然只涉及一个正则项，却直接影响隐式世界模型的表征稳定性和规划，问题明确且重要。

## Method
对每个 batch 的 \(d\) 维 latent 沿随机单位方向投影，原 EP 正则被改写为与标准高斯的 unit-bandwidth MMD。命题 1 表明，当单个投影值 \(h\) 远离其余样本时，主要恢复梯度约为 \(h e^{-h^2/4}\)，在尾部趋零。

QQWorld 将一维投影排序为 \(\hat{x}_n\)，与 \(q_n=\Phi^{-1}((n-0.5)/N)\) 做平方误差。该目标近似一维 \(W_2^2\)，无 tie 时每个样本的梯度为 \(2(x_n-q_{\rho(n)})\)，偏差越大修正越强；作者还说明 rank tie 是局部排斥点，并证明小 QQ loss 蕴含小 EP loss，而小 EP loss 可与任意大的 QQ 尾偏差共存。

Cross-Batch QQ 用 FIFO queue 保存前 \(K\) 个 batch 的 detached projection，只让当前 \(N\) 个样本反传，却在 \(N(K+1)\) 个样本中估计 rank。作者给出近似 MSE 分解：queue 降低 rank estimation variance，但旧表征与当前分布不同会引入 staleness bias。方法只是替换 LeWM 的 EP 正则，主体架构和 CEM 规划不变。

## Experiment
在 Two-Room、Reacher、PushT、OGBench-Cube 四个离线控制环境上，以六随机种子比较 LeWM、Sub-JEPA、SD-JEPA、SMWM 等。QQWorld 平均成功率 85.08%，比 LeWM 的 79.75% 高 5.33 个百分点，并在四环境均优于 LeWM；与其他方法相比则各有胜负，平均值最高。

对 20,000 个 latent 和 6,144 个固定随机投影，QQWorld 将 QQ-RMSE 均值从 0.157 降至 0.121，径向尾概率从 0.315 降至 0.123（高斯参考 0.10），KS/EP 分别下降 15.8%/31.4%。PushT 的线性和 MLP 物理状态 probe 仅小幅或几乎不变，说明主要收益不是显著增加可解码状态信息。Two-Room 轨迹可视化的整体线性 probe RMSE 从 6.01 降至 2.58，但只展示两个代表 episode。

Cross-batch 实验支持理论上的非单调权衡：batch 32 时 queue 总长度从 32 增至 96，平均成功率从 65.42% 升至 83.50%，显存几乎不变；再增至 128 反降到 81.75%。batch 64/128 时增加历史样本也无益。该实验说明 queue 是小 batch 的实用补偿，而非普遍优于标准 QQ。

## Value
该工作最值得借鉴的是“按训练梯度而非仅按统计检验能力选择 latent regularizer”的分析框架。QQ 是简单、可插拔的改善，对 JEPA/latent planning 很直接；cross-batch rank 也适合高分辨率或长序列下的小物理 batch。后续需确认更薄的边缘分布是否真正降低多步动力学误差，以及强制整体各向同性高斯是否会损伤多模态或带拓扑结构的任务状态。

## Strengths
- 从真实重尾现象追溯到 EP/MMD 的梯度几何，理论动机与方法高度一致。
- 给出尾部恢复力、rank boundary、QQ→EP 单向控制和 queue bias-variance 的明确分析。
- QQ 是主体架构不变的 drop-in replacement，实验归因相对干净。
- 六随机种子、四环境、分布指标、规划与显存实验共同覆盖表示和下游效果。

## Weaknesses
- 只在 LeWM 体系和四个规模较小的离线控制任务上验证，尚不清楚能否扩展到大型视频世界模型。
- 没有直接报告多步 latent rollout error、误差累积或尾样本导致规划失败的因果分析，因此“抑制重尾改善规划”的机制连接仍主要是相关性。
- QQ 权重固定为 3.5，但没有与 EP 做同等规模的权重敏感性或计算成本比较；排序与大量随机投影的开销也未报告。
- 对基线使用其跨四任务最佳超参，而自身方案及正则权重的选择过程不透明，且没有显著性检验。
- 强制各向同性高斯依赖特定理论前提；对天然多模态、离散拓扑或分层状态，Gaussian target 未必最合适。
- Cross-Batch QQ 对 queue 很敏感，较大 batch 时还会退化，实用设置需要额外选择。
- 论文未列出独立局限或未来工作。

## Future Work
作者没有明确列出未来方向，只指出 cross-batch 机制可用于更大模型、更高分辨率和更长序列。更关键的后续应包括大型视频/机器人任务验证、直接测量重尾与 rollout instability 的因果关系、不同 target distribution 与自适应 queue，以及 QQ 计算复杂度和超参鲁棒性分析。

## Rating
创新度评分：3/5 - 对 EP 尾梯度失效给出扎实诊断，并提出简单有效的 QQ 与跨批排名修正；属于有理论支撑的正则化改进，但仍是单一组件级贡献。

相关度评分：3/3 (Core) - 直接研究 JEPA 式 latent world model 的分布正则、CEM 规划和隐式状态质量，与关注方向核心相关。

## TL;DR
用 QQ 分位匹配修复 EP 对尾部 latent 梯度消失并提升规划，方法精炼，值得精读。
