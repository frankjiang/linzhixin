# Ms. Forcing: Efficient Streaming Video Generation with Multi-Scale Patchification and Attention

## Insight
有。Observation 是 Rolling Forcing 的 joint denoising window 中，每个窗口位置对应固定噪声级别；扩散去噪本身是 coarse-to-fine，高噪声状态主要恢复低频结构，低噪声状态才需要细粒度细节。推论是可按噪声级别静态分配不同 patch granularity，而不必所有状态都用同一细粒度 tokenization。作者还观察到 RF 的 DMD fake video 由不同 rollout noise level 的预测拼成，与推理时同一位置连续输出存在 mismatch，因此提出 homogeneous-noise-level DMD。

## Motivation
解决流式视频扩散生成的实时性和长程稳定问题。常规 autoregressive video diffusion 需要外层逐帧自回归和内层多步 denoising，延迟高且误差累积。Rolling Forcing 将多个帧块放入混合噪声窗口联合去噪，但每个活跃状态都按原生 patch size 编码，计算冗余。该问题对交互式视频世界模型有工程意义：若视频 world model 不能实时流式输出，难以用于交互环境。

## Method
基于 Rolling Forcing，提出三件事。Multi-Scale Patchification (MSP) 对窗口位置使用固定 patch schedule；实验中的 5-step RF 使用 `(p, p, 2p, 2p, 2p)`，高噪声状态用更粗 patch，窗口 token 数相对 RF 降低 45%。每个粗粒度 tier 有独立 patch embedding/de-embedding、LoRA 和 latent residual，底层 DiT backbone 共享。

Multi-Scale Self-Attention (MSSA) 让 query 的可见 non-sink KV 密度不高于 query 自身尺度，同时保留全分辨率 sink frame，进一步减少 post-MSP dot-product attention 约 12.9%。因为噪声级别由窗口位置决定，MSP/MSSA 都是静态图，硬件友好。

Homogeneous-Noise-Level DMD (H-DMD) 则改变训练 fake video 的组装方式：每次采样一个窗口位置 j，从连续 overlapping windows 中取同一 noise level 的 clean prediction 拼成视频，使 DMD 看到的 fake sequence 在源噪声级别上同质，减少与推理 rollout 的分布错位。

## Experiment
模型基于 Wan2.1-T2V-1.3B，输出 832x480、16 FPS 视频。短视频评测用 946 个 VBench prompt、每个 5 个 seed；长视频用 128 个 MovieGen prompt 生成 60 秒，并报告 drift。硬件为单 H200 GPU。

短视频中，Rolling Forcing 为 16.35 FPS、VBench Total 82.88、Quality 83.63、Semantic 79.88；加入 H-DMD 后 Semantic 到 81.22；加入 MSP 后 21.93 FPS 且 Total 83.89；完整 Ms. Forcing 为 22.84 FPS、Total 83.36、Quality 83.92、Semantic 81.13，速度比 RF 快 39.6%。长视频中，完整方法 Total 79.66，低于 H-DMD-only 的 80.67 但高于 RF 79.38；Dynamic 41.85 高于 RF 33.67，Drift 1.700 低于 RF 2.227。定性结果显示长程曝光漂移和高频伪影更少。

## Value
它不是显式世界状态模型，也不是 action-conditioned simulator，但对实时视频世界模型很有价值：在 rolling denoising window 内利用噪声级别做静态多尺度计算，是可迁移到交互式视频生成/世界仿真的基础优化。值得关注 H-DMD 对训练-推理错位的分析，以及 MSP/MSSA 如何在不动态路由的情况下省算力。

## Strengths
动机来自扩散去噪 coarse-to-fine 的结构性冗余，设计简单且硬件友好。速度、短视频质量、长视频 drift 都有定量消融。H-DMD 把 RF 训练拼接方式中的分布不一致讲清楚，是方法中最有洞察的一点。

## Weaknesses
主要是 T2V streaming generation，不含动作条件、环境状态、3D consistency 或 agent feedback。完整模型短视频 Total 并非表中最高，长视频 Total 也略低于 H-DMD-only，说明效率和质量仍有折中。实验只覆盖 1.3B Wan2.1、832x480，扩展到更大模型/更高分辨率未知。

## Future Work
作者提出扩展到更大 backbone 和更高分辨率；当前 KV-cache 每次 rolling step 更新带来显著延迟，优化 cache update 是让 DiT 省算力完全转化为端到端吞吐的关键。
