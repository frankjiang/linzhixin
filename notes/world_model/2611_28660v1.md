# Persuasion from Within: Model-Based Insider Attacks in Multi-Agent LLM Debate and Consensus

## Insight
观察：攻击者只凭有限交互也可从多智能体对话训练回应模型，用它模拟接收者对消息的反应。推论：在模型中训练与筛选说服消息，比单纯提示或无模型在线强化学习更有效；换成只预测答案、不生成论证的模型，会丢失影响下一轮决策的语言通道。真实代理对照、模型保真度与规划消融提供经验支持，结论限于所测 LLM 讨论协议。

## Motivation
多智能体 LLM 辩论默认所有参与者目标一致；具合法发言权限的恶意成员可在内部改变群体共识。现有说服攻击多针对单个听众，直接在线试错成本高。论文解决的是多智能体安全与自然语言说服问题，而非视觉或具身世界建模。

## Method
先从良性代理对话记录中，以行为克隆训练生成式 Qwen3.5-4B“世界模型”，输入局部对话，输出代理的论证及决定。攻击策略以世界模型评估候选论证形成 DPO 偏好对，再把冻结模型当作 PPO 训练环境；推理时采样多个消息，选预测最能推动目标错误答案者，最后用真实交互数据再做 DPO 精炼。数值共识游戏只用模型内 RL，不用偏好优化和规划。防御部分收集攻击情境，对良性代理做偏好“保持无攻击时答案”的 DPO 训练。

## Experiment
数值共识：三名 Qwen3.5-9B 良性代理与一名攻击者，五个种子各 200 局；无防御时共识率从无攻击的 0.458 降至 0.140，位置 DQN 加文字改写为 0.232。MMLU-Pro 三轮辩论：400 道测试题、三种子；良性代理最终正确率从 0.689 降至 0.254，最强先前 P-RL 攻击为 0.428；监视器检出率 0.130，P-RL 为 0.587。去推理时规划后正确率回升至 0.319，去已训练策略为 0.552。良性代理经对抗训练后，无攻击/本攻击正确率分别为 0.713/0.688。世界模型二轮及后续回答预测准确率 0.827，真实代理重采样上限 0.847；转向新答案的回合上为 0.655，纯决策模型约 0.45–0.46。还测了拓扑、群体规模、其他 LLM 与多种防御。

## Value
展示“模拟他人反应→模型内策略训练→测试时选择”的闭环，在语言多智能体安全中有价值；对视频、3D、JEPA/Dreamer 世界模型的表示、物理预测和评测没有直接参考价值。

## Strengths
在真实良性代理上测试模型训练攻击的迁移；同时测成功率、检出率、模型预测保真度、防御与阶段消融；报告攻击在部分模型和拓扑下无效。

## Weaknesses
“世界模型”实为针对固定 LLM 系统的对话模仿器，不学习物理状态；攻击需要大量目标对话与已知系统设定。监视器和防御均依赖特定协议，跨模型效果不稳，未测试自适应攻击或多个协同内鬼。

## Future Work
作者提出研究协同多内鬼、裁判式决议、异构代理与使用工具的代理；同时需验证针对防御重新训练的自适应攻击。

## Rating
创新度评分：1/5 - 组合行为克隆、PPO、DPO 和候选规划，在目标视觉/3D/隐式世界模型方向几乎无新技术贡献。
相关度评分：0/3 (Noise) - 纯自然语言多智能体攻击，与关注的世界模型方向无实质关联。

## TL;DR
用对话模仿模型训练并筛选内部说服攻击，显著降低多智能体辩论正确率；纯语言安全研究，可跳过。
