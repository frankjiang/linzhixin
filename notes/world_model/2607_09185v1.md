# Causally Debiased Latent Action Model for Embodied Action Conditioned World Models

## Insight
核心 observation：重建式 LAM 只要求 latent action 足以重建下一帧，因此会把背景、相机扰动、episode context 等“可预测但不可执行”的信息编码进 action latent。推论是：下游 ACWM 会把这些 confounder 当作 action condition，导致 rollout 看似合理但不听动作。论文用 zero-transition response、camera-shift response、shortcut leakage 和行动干预实验支持这一点。

## Motivation
Action-conditioned world model 需要大量带 robot action 的数据，但机器人动作标注昂贵；LAM 可从无动作视频中提取 latent action，帮助 ACWM 预训练。问题是现有 LAM/DreamDojo 主要靠下一帧重建，latent action 不够因果，机器人动作适配时要对齐一个混有视觉上下文的 latent space，导致控制性差。这是 embodied world model 的关键问题。

## Method
CD-LAM 在不改变下游 ACWM conditioning format 的前提下，三阶段去偏：

1. LAM debiased fine-tuning：使用三个目标优化 latent action。
2. ACWM debiased fine-tuning：用 debiased latent action 继续训练 ACWM。
3. Robot action adaptation：用轻量 MLP bridge 把真实 robot action 映射到 debiased latent space。

三个核心 loss：
- Embodiment-centric reconstruction：用 SAM3 foreground mask 提高手/物体区域权重，避免背景主导重建。
- Action-centric contrastive learning：用 caption verb 聚类出的 12 类粗粒度 manipulation primitive，让相同行为跨视觉上下文聚拢。
- Latent space calibration：free-bit KL 控制容量，zero-transition calibration 让 `(ot, ot)` 的 latent 接近零，避免静止帧和相机微扰产生虚假动作。

## Experiment
基于 DreamDojo 2B/14B 做对比。评估包括 latent audit、EgoDex latent action rollout、AgiBot robot action rollout 和干预实验。

诊断结果：zero-transition median response 从 0.527 降到 0.043；camera-shift horizontal median 从 0.536 降到 0.096，vertical median 从 0.529 降到 0.064；shortcut leakage 从 0.151 降到 0.014。

latent action rollout：2B FDCE 34.00 -> 19.63，14B 40.29 -> 29.87，同时 PSNR/SSIM/LPIPS 改善。robot action adaptation 后：2B FDCEmean 12.63 -> 8.24，14B 11.11 -> 7.73；PSNR 也提升到 20.60/21.01。zero-action 干预残余运动显著降低，14B 从 9.36 到 2.18。适配效率上，14B 约 3k-4k steps 达到 DreamDojo 50k reference，6k 超过。

消融显示 embodiment weighting 改善前景保真和 FDCE，action contrast 主要改善动作邻域结构，zero-transition calibration 主要抑制相机扰动响应。

## Value
对隐式/具身 world model 很有启发：action latent 不是“能预测下一帧”就够，必须能被当成 intervention handle。论文把 causality/shortcut learning 具体落到 LAM 训练目标和可测指标上，对 Dreamer/JEPA 类隐式表征也有借鉴价值。

## Strengths
问题切中 ACWM 控制性瓶颈；因果解释明确；方法保持下游接口不变，工程侵入小；指标不只看 PSNR，而是引入 foreground displacement 和干预测试；2B/14B 都有一致收益；适配效率提升明显。

## Weaknesses
去偏信号依赖 SAM3 mask 和 caption-derived coarse primitive，数据/标注管线较重；主要围绕 DreamDojo，一个体系内验证，跨架构泛化仍需更多证据；“causal”更多是诊断和目标设计层面的因果动机，并非严格识别证明；FDCE 依赖 tracker/mask 质量。

## Future Work
作者未单列未来工作，但结论强调释放模型、协议和代码，后续自然方向是扩展到更多 LAM/ACWM 架构、更多真实机器人动作空间，以及更严格的 intervention/causal evaluation。
