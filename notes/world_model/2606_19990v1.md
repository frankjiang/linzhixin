# Reward as An Agent for Embodied World Models

## Insight
Observation：世界模型 RL 后训练常采用保守 rollout，因为奖励不可靠；一旦扩大探索，通用视频奖励容易被 reward hacking 利用，产生遮挡、静止、背景简化或物理失效。

推论：瓶颈不是探索本身，而是验证能力。只有 reward evaluation 能覆盖物理合理性、对象交互和任务完成，才可以安全扩大 rollout 分布。

## Motivation
论文解决 embodied world model 的 RL post-training：如何在不被 proxy reward hack 的情况下扩大探索、提升物理与任务能力。

同行多用 GRPO/Flow-GRPO/CPS 等稳定 diffusion rollout，常通过限制随机性、KL 或低温采样保持 reward 可靠，但牺牲动态多样性。该问题与世界模型作为物理 AI simulator 的可训练性相关。

## Method
两部分：
- Reward as an Agent：把奖励评估设计成 agentic/hierarchical evaluator，分维度判断 Planning、Visual Quality、Instruction Following、Physical Compliance、Task Completion，再聚合。
- DynDiff-GRPO：dynamic-aware rollout diversification。不是全局加噪，而是把 stochasticity 分配到动态显著区域；配合动态方差 Gaussian likelihood、clipped GRPO、mean-space KL 约束。

创新点在 reward 验证与探索策略的联动；技术上更像 RL 后训练 recipe，而非新世界模型架构。

## Experiment
基座包括 Cosmos-Predict2.5-2B 和 Kairos3.0-Robot-4B；评估 PAI-Bench robotics subset。

主结果：
- Cosmos 2B：Domain 83.61 -> 84.41，Overall 79.42 -> 80.75。
- Kairos 4B：Domain 83.87 -> 86.95，Overall 80.35 -> 81.88。
- Reward evaluator 在 AgiBotWorld-Beta 100 条样本上与人工一致率 Overall 91%；Planning 98、VQ 96、IF 90、PC 82、TC 87。
- 相比 CPS，DynDiff-GRPO 在 robot domain subset 上 Domain 85.63 vs 84.03，Overall 81.18 vs 80.31，Quality 基本持平。

## Value
启发是：世界模型后训练不能只靠视觉偏好奖励，必须有任务/物理/交互维度的 verifier，并且探索策略要和 verifier 同步扩展。

局限：reward agent 仍依赖 VLM/LLM judge，物理合规维度最低；提升幅度在部分模型上不大；是否泛化到闭环真实机器人或长期规划仍需验证。

## Strengths
亮点是提升幅度在部分模型上不大；
