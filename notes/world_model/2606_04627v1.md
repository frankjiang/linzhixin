# MIRAGE: Mobile Agents with Implicit Reasoning and Generative World Models

## Insight
有一定insight。观察：移动端GUI agent的显式CoT推理（observation-rationale-prediction）虽有效但token开销大、延迟高。关键推论：可以将显式文本推理"蒸馏"到连续隐空间的latent slots中，同时用next-frame feature alignment（世界模型目标）来正则化tail latent slots，弥补并行近似（APLR）带来的尾部误差。证明：APLR经K轮Jacobi迭代后前K个slot精确匹配串行解，尾部残差以A^K衰减（A为严格下三角Jacobian）。

## Motivation
问题：移动GUI agent需要多步推理来决定操作，但显式CoT产生大量中间token，增加延迟和成本。同行方法（UI-TARS, MAI-UI等）多采用显式思考输出。MIRAGE提出用latent思考替代显式CoT，核心是如何在不输出中间文本的情况下保留推理能力。这是一个有价值的效率问题。

## Method
两阶段训练：
1. **Stage 1 (Explicit CoT SFT)**：在结构化thought数据（observation/rationale/predict三段）上做标准next-token CE训练
2. **Stage 2 (Latent CoT SFT)**：将thought文本块替换为N个连续latent slots，通过APLR（Approximate Parallel Latent Refinement）用K轮Jacobi迭代并行细化，外加Q-Former world model head做next-frame feature alignment

关键技术细节：
- **APLR**：利用causal attention的严格下三角结构，将串行latent CoT转为并行Jacobi迭代，K=3轮，前K个slot精确匹配串行解
- **Q-Former World Model**：轻量级cross-attention头，将latent slots映射为next-frame patch-level feature预测，用cosine距离对齐frozen vision encoder输出的target features，弥补APLR尾部误差
- 联合损失：lambda * L_ce + (1-lambda) * L_wm，lambda=0.8

创新程度：中上。APLR有理论支撑，world model正则化latent reasoning是新颖的组合。但latent思考的大思路源自Coconut等先前工作。

## Experiment
- **基准**：AndroidControl（EM/Action Accuracy）和AndroidWorld（SR任务成功率）
- **对比**：Qwen3-VL-4B/8B-Instruct、GPT-4o、GUI-R1、UI-TARS等
- **核心结果**：
  - AndroidControl: MIRAGE-4B low-level EM 77.59 (+13.3%), Action Acc 91.09 (+21.2%), tokens仅18.92（减少83.6%）
  - AndroidWorld: MIRAGE-8B SR 57.8%（+21.3%），tokens 27.0（减少75%）
  - 推理延迟：MIRAGE-4B 1.7s vs Qwen3-4B 3.19s
- **消融**：去掉world model目标 SR从52.6降至48.2；去掉APLR（串行latent）50.9；latent slots从9降到3 SR从52.6降到32.8
- latent slot的UMAP可视化显示slots分化为observation/rationale/prediction三个子空间

## Value
工作有一定价值，但"world model"在这里指的是feature-level的next-frame prediction head（Q-Former），不是真正意义上的视频/3D世界模型。它展示了隐式推理+世界模型正则化的协同效应，对理解latent reasoning如何受益于环境预测有启发。但应用场景（移动GUI agent）与视频/3D世界模型研究较远。

## TL;DR
用latent slots替代显式CoT并结合Q-Former世界模型正则化来加速移动GUI agent推理，token减少75%+性能不降，隐式推理方向有参考但场景偏远，可选读。
