# From Proxy Learning to Driving Decisions: A Transfer-Based Framework for Evaluating Future-Aware Autonomous Driving Planners

## Insight

有。论文抓住了 future-aware planner 中常被混为一谈的五层证据：表征、候选打分、top-1 选择、候选支持集和部署评测。核心 observation 是，代理目标变好只有在相对分数扰动越过原有 top-1 边界、且换轨后的条件效用为正时，才可能改善最终规划。作者给出三条简单但有用的精确关系：（1）候选相对扰动必须补足其相对当前赢家的分数亏空；（2）固定候选和评估器时，平均效用变化严格分解为 `ΔJ = 切换率 ρ × 切换条件效用 μ`；（3）总 regret 等于候选支持 regret 与选择 regret 之和，因此只改 scorer 无法突破候选集上界。

NAVSIM 案例进一步说明这些层级不能相互替代：BCE 从 0.705 降到 0.530，所选轨迹 PDM 却从 0.963 降到 0.961；512 条前缀上的显著正收益在 12,146 条完整支持上消失；总体 PDMS 的微小正号还掩盖了 TTC、碰撞等分量退化。证明主要是 argmax 条件与代数恒等式，价值在于把它们组织成可审计的结论边界，而非提出新的学习理论。

## Motivation

视频/潜空间世界模型、JEPA 和未来预测已被用于驾驶表征、轨迹生成与候选评分，但常见论文会从更低 proxy loss、某个开发子集或单一总分直接推断“规划更好”。proposal-based planner 中间还隔着候选排序、离散 argmax、候选覆盖和评估协议；任何一环都可能截断收益。已有 NAVSIM 等工作改善最终评测目标，decision-focused learning 也强调预测与决策不同，但缺少面向 future-aware 驾驶系统、能定位传递失败位置并约束结论强度的完整协议。这是可信评估中的关键问题，不过本文评估的是世界模型的决策价值，而不是提出更强世界模型。

## Method

PDT 不改变 planner，而是在固定候选集 `C_i`、baseline/candidate proposal score、所选索引和轨迹效用上运行两个模块：

1. **Decision-Transfer Decomposition**：按 F1 表征、F2 打分、F3 选择、F4 支持、F5 部署五个位置给出 pass/fail/indeterminate。它保存候选身份、top-1/top-2 margin 和逐候选扰动，计算 activation surplus 判断是否跨越决策边界；再以切换数、`ρ`、`μ` 和 `ΔJ` 区分“几乎不换轨”与“换轨但无益”。若有逐候选效用和外部轨迹空间，再把 regret 分成 scorer 可降低的 selection regret 与只能靠扩充候选降低的 support regret。
2. **Reliability-Constrained Validation**：要求以不可变 scene key 精确配对；模型选择与规模扩展支持分离；总收益超过预先声明的实用阈值，且安全关键分量不以退化补偿；历史相关指标必须具有相同顺序、前驱、初始化与 reset 规则；统计重采样单位和多配置 family-level gate 需事先固定。缺失关键数组或评估状态时给出 indeterminate，而不是擅自归因。

执行协议依次冻结 claim/utility、安全分量、split、seed 和候选构造，测试 proxy、排序与 margin、selection/regret，再做完整规模与安全门控，最后只发布证据允许的最窄结论。创新主要是把既有 decision-focused、配对统计和安全非补偿原则系统化为 future-aware planner 的审计接口；三个命题本身较基础。

## Experiment

案例使用基于 joint-embedding predictive representation 与多模态轨迹 proposal 的驾驶 planner，在 NAVSIM-v1 非反应式仿真上评估。完整对比含 12,146 个零失败、baseline/candidate token 完全一致的记录；PDM 由 collision、drivable-area 两个乘法项与 progress、TTC、comfort 加权项构成。保留成对 CSV 的实验使用 10,000 次 scene-level bootstrap（固定 seed 20260902），但因 CSV 无 log id，不能表达同一 log 内相关性。

- **Proxy 与选择**：component BCE `0.705→0.530`，held selected PDM `0.963→0.961`。另一次边界审计中 future loss `0.0527→0.0329`，4 个验证 token 在 step 0/25/50 的选择始终为 `[17,28,21,20]`，PDM 始终 0.978；虽有 2.20% validation candidate-oracle headroom，却没有发生选择传递。
- **逐候选 replay**：冻结 256/64 train/val token、每 token 32 proposals。repeatable linear 配置在两 seed 都切换 4/64，`ρ=0.0625`、`μ=0.00170`、`ΔJ=1.06×10^-4`，精确满足 `ρμ`；但四次切换仅一次提高 0.00681，其余三次效用为零，区间下界为零，另一固定 half 无增益。名义最优 set-wise 配置 seed 0 为 `2.25×10^-4`，seed 1 完全不切换。
- **规模扩展**：direct-utility candidate 的 held PDM 为 `+6.38×10^-4`，512 前缀仅 `+1.15×10^-4`（95% CI `[2.19×10^-5,2.45×10^-4]`），低于预注册 `5×10^-4` 门槛，且只有 7/512 改善、504 tie、1 退化。future-supervised candidate 在 prefix512 为 `+0.00909`（`[0.000744,0.0177]`），prefix2048 降至 `+0.00250`（`[-3.11×10^-4,0.00527]`）；完整 12,146 条相对 frozen reference 为 `-6.64×10^-4`（`[-0.00248,0.00121]`），相对 official 为 `-2.20×10^-4`（`[-0.00236,0.00191]`）。
- **总分与分量**：candidate/official 的 PDMS 都约为 0.937，精确差 `+4.44×10^-4`，区间 `[-0.00179,0.00277]`。progress `+0.00666`、drivable `+0.00239`，但 collision `-0.00218`、TTC `-0.00782`、direction `-0.00276`、comfort `-1.65×10^-4`；零容忍非补偿门控失败。只有允许安全分量至少退化 0.00782 且把有意义总收益阈值降到不高于 `4.44×10^-4`，该候选才会通过。
- **多重选择压力测试**：216 arms、每 arm 4 个 checkpoint、2 seeds，形成 864 个 seed-level outcome 和 432 个双 seed 配置；仅 4 个配置的双 seed 平均为正，没有一个同时通过两个固定 half、两个 seed，也没有达到预设 0.002 增益。候选 oracle selection regret 为 0.0125，而代表性 calibration 只减少 `1.06×10^-4`。

评估规则消融表明，分别去掉 proxy-to-decision、完整规模、安全非补偿、family robustness 或 artifact completeness 后，都可得到更乐观但证据不足的结论。

## Value

PDT 最有价值的不是又造一个总分，而是迫使世界模型规划论文回答“预测究竟通过哪次候选排序与选择创造了多少效用”。对视频/JEPA 驾驶模型，建议训练和评测默认记录稳定候选 ID、逐 proposal score、margin、selected index、逐候选效用、关键分量和 evaluator state；这样才能决定下一步应优化表征、校准 scorer、扩充候选还是扩大闭环评测。本文也示范了如何诚实报告 fail 与 indeterminate，避免把小数位正号、局部子集或超参筛选赢家包装成可靠提升。

## Strengths

- 用明确的五阶段接口连接 proxy、argmax、候选支持与部署结论，诊断粒度高于只报最终 PDMS。
- 精确配对、固定支持、实用效应阈值、安全非补偿、顺序可比性与多重筛选门控覆盖了常见评测泄漏。
- 主动呈现负结果、结论反转和无法归因项；`ΔJ=ρμ` 由逐候选 replay 数值闭合，而非只停留在概念图。
- 完整规模达 12,146 条，报告区间、分量和配置族总数，并提供 ancillary 数据、脚本和哈希，复核条件较好。

## Weaknesses

- 只验证一个 future-aware proposal planner family 和 NAVSIM-v1，尚不能证明框架跨 sparse、diffusion 或生成式 world-model planner 通用。
- PDT 是从一系列已有实验回溯归纳；部分 campaign 的阈值与 split 虽在开结果前锁定，完整 taxonomy 并未预注册。
- 早期 4-token 审计和完整 12,146-record run 没保留 proposal arrays，故无法做完整规模的 margin、switch utility 或 score/support 归因；外部轨迹空间也缺失，support regret 始终不确定。
- bootstrap 以 scene 为单位，缺少 log id，未控制同 log 内相关性；非反应式 NAVSIM 也不能证明真实安全或交互交通中的闭环因果收益。
- 三个核心“命题”主要是 argmax 条件和代数恒等式；理论新颖性有限，贡献更多来自规范化与案例审计。

## Future Work

作者提出以前瞻、预注册方式把 PDT 扩展到 sparse、diffusion-based 与 world-model-based planners；统一记录接口并预先冻结 proxy、utility、安全容忍、统计单位、候选支持和规模扩展门槛。后续应做 route/log-level clustered resampling，在 reactive/closed-loop 环境验证同样的失败位置，并通过“固定 scorer、受控扩充候选”的实验真正区分 selection 与 support bottleneck。

## Rating

创新度评分：3/5 - 将决策边界、switch utility、regret 与可靠性门控组合成可执行审计框架，实用且论证完整，但公式多为既有原则的直接特化，也未提出新 planner。
相关度评分：2/3 (Related) - 直接评估 JEPA/世界模型如何把未来表征传递到驾驶决策，对研究方法很有借鉴，但主体是评测框架而非视频、3D或隐式世界模型本身。

## TL;DR

以PDT分解未来表征到驾驶决策的传递链，并揭示多类评测结论反转，研究评估方法时值得精读。
