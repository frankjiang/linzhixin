# AR Forcing: Towards Long-Horizon Robot Navigation World Model

## Insight
扩散式导航世界模型存在训练-推理分布偏移：训练时使用并行监督（teacher forcing），推理时却是自回归生成，导致长程预测不稳定。核心观察：这本质上是exposure bias问题在扩散世界模型中的体现。解法：在训练时引入自回归循环，每步用模型自身预测更新上下文并优化单步去噪目标，显式暴露模型于推理时的状态分布。

## Motivation
- 问题：扩散式机器人导航世界模型在长程路径规划中因训练-推理分布偏移而性能退化
- 同行方法：NoMaD、GNM等用teacher forcing训练diffusion model，推理时自回归展开导致误差累积
- 类比：类似于语言模型中的exposure bias/scheduled sampling，但在扩散框架中需要不同的处理方式

## Method
- **AR Forcing训练策略**：在标准扩散损失基础上加入自回归训练循环
  - 每步生成后用自身预测更新历史上下文（而非ground truth）
  - 仍优化标准单步去噪目标，不改变扩散框架和采样器
  - 无需额外判别器或分布匹配损失
- 实现简单：只需在训练时将模型输出回馈为输入，代码改动小
- 可平衡GT与自身预测的混合比例，渐进式暴露

## Experiment
- 4个导航数据集：RECON（室外越野）、TartanDrive（越野驾驶）、SCAND（社交导航）、HuRoN（室内导航）
- 对比NoMaD等baseline：AR Forcing在长程（20+步）生成的FVD和轨迹精度均有提升
- 生成图像的时序一致性和结构保真度更高
- 消融：自回归步数、混合比例、不同扩散采样器的影响

## Value
方法简单实用——不改变模型架构，仅在训练策略上引入自回归循环即可缓解exposure bias。但洞察本身不够深刻（exposure bias是已知问题），创新主要在于将这一思路干净地应用到扩散导航世界模型中。
