# GigaBrain-WBC-0.5: A Behavior World Model for Robust Whole-Body Control with Environment Interaction

## Insight
有，但因缺少关键消融，证据尚偏相关性。论文的 observation 是：在地形和物体接触下，“什么动作可行”取决于当前环境，无法只靠扩大无条件动作库解决。作者推论：若 causal controller 除 action 外还预测 next proprioceptive state 与 next latent-command distribution，其内部状态就必须吸收接触动力学和条件可行为；预测分布还能直接作为在线 admissibility test。部署时用前一步 GMM 对当前命令做 Mahalanobis 检验并投影，实现 best-effort 行为。大幅成功率提升支持系统有效，但未证明提升来自 world-model auxiliary heads 而非 terrain data、fall curriculum 或 filter。

## Motivation
大规模 humanoid motion tracker 已能在平地接受在线全身参考，却几乎不学习台阶、座椅、负载等接触如何改变动力学；不合理命令和跌倒通常靠拒绝、站立 fallback 或独立 recovery controller，都会中断任务。关键数据瓶颈是 motion capture 没有配套 3D 场景。论文试图用一个统一低层策略解决可交互地形、OOD 命令与跌倒恢复，问题对具身控制重要，但与视频/3D生成式世界模型并非同一主线。

## Method
输入为 67 维 proprioception、上一动作和未来 10 帧的 440 维参考窗口；MLP encoder 得到 64 维 latent command。训练辅助分支用 32-level FSQ 与 decoder 重建干净参考，量化只作 latent shaping，policy 接收连续 code。6 层、4 头 causal Transformer 以 32 帧 local attention 和 KV cache 在 50Hz 单步运行，三头分别输出 29 维 PD target、67 维 next state、4-component diagonal GMM over next command。目标为 PPO + reconstruction/cycle + state MSE + GMM NLL。

3D terrain annotation 从 retargeted motion 反推接触：对足/手等 link 表面采样，依据法向/切向速度与减速度检测持续接触；积累 contact cloud，经全身 penetration filter、normal/offset affinity、DBSCAN、PCA box fitting 与安全扩张，生成 stairs/chair/box 等真正 3D support primitives。训练混合 Bones-Seed、MotionMillion、MotionDecode 共 2188 小时动作，其中识别约72.6小时 terrain interaction，并加入 fallen initialization、外力与 domain randomization。

OOD filter 用前一步预测 GMM，先以 MAP-style responsibility 选 component，再检查 64 维 Mahalanobis radius；越界时沿 component mean 到原命令的射线缩放到安全椭球边界。它无状态、闭式、每步低于1ms，以单一 Rsafe 调节 fidelity-robustness。

## Experiment
在 MuJoCo sim-to-sim 比较 SONIC、HoloMotion-1、Humanoid-GPT，四个 split 为 AMASS Standard 136 clips、MotionMillion OOD 136、Bones-Seed Terrain 150、同 Standard 的 fallen initialization 136。GigaBrain 在 Standard 得 76.6mm MPKPE/96.3% SR，优于 SONIC 82.3/94.1，但 RootVel 211.1mm/s 明显弱于 HoloMotion-1 121.3。Terrain 为 93.3mm/81.3%，各指标最佳 baseline 分别为 283.3mm 与 18.7%；OOD 为158.0mm/83.1%，最强 baseline 208.0/70.6%；Fall recovery 99.3%、jerk 1050.6，baseline recovery 0.7-5.9%。

人工审计 Bones-Seed 每类50段 terrain annotation，总正确率92%：stairs92、chair94、box98、other84%。Rsafe sweep 显示部署值3相对 unfiltered 增加2.9点 OOD survival，但 Standard MPKPE 恶化12.7mm；继续收紧到1仅再增2.2点，却再损失46.7mm。硬件上与 SONIC 同指令做坐箱、登台、举箱等定性对照，并展示缺失支撑、踢倒恢复、G1到Maker L01微调迁移；没有 trial 数、成功率或延迟统计。

## Value
最可借鉴的是把“预测自身下一状态/可行为分布”嵌入 causal policy，再复用预测分布做在线 command projection；以及从动作接触痕迹反推 3D support 的数据扩展思路。它更像带辅助预测头的 behavior policy，而非能独立 rollout、生成观测或供 planner 查询的通用 world model，因此对视频/3D世界模拟的直接启发有限，对机器人 latent dynamics 与安全控制较有价值。

## Strengths
系统整合完整，覆盖地形、物体、OOD、跌倒与跨 embodiment；3D contact annotation 比 2.5D height map 能表示椅面、桌边和悬空结构；filter 使用前一步分布避免 command 泄漏进自身判定，且开销小、旋钮直观；评测不在失败时提前截断，减少错误低估；作者诚实报告 RootVel 退化、annotation failure 和 fidelity-robustness trade-off。

## Weaknesses
论文明确未提供 component ablation，无法区分 auxiliary state/GMM prediction、terrain corpus、FSQ shaping、fall curriculum 与 filter 各自贡献；“预测下一状态因此理解环境”的核心因果论断没有被验证。基线使用不同语料与 retargeting pipeline，非 data/compute-matched；作者也承认比较只能说明系统 generalization。策略没有 exteroceptive terrain input，只能从 proprioceptive/contact history 反应，filter 检测的是训练分布相似性而非物理风险，不能保证提前识别缺失支撑。硬件证据纯定性且挑选案例；terrain annotation 只恢复实际接触的 supports，不是完整环境。Rsafe 需按 checkpoint/platform 重标定。

## Future Work
作者明确计划补充真实机器人 latency 和 component ablations；把 support-only reconstruction 扩展到未接触、非支撑的完整几何；将 next-state prediction 连接到更直接的 physical-risk 指标；在不同 checkpoint 和平台上校准并验证 filter。还需加入外感知和 quantitative hardware trials，检验风险预测能否在接触前生效。
