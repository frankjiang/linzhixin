# Self-supervised Hierarchical Visual Reasoning with World Model

> ResDreamer, ICML 2026 (PMLR 306). Yuanfei Xu et al., USTC.

## Insight
像素级重建的"逼真度"并非关键，关键是提供任务相关的推理信号。借鉴神经科学中的预测编码（Predictive Coding）理论：生物视觉神经元过滤可预测成分，仅传递"意外"残差。据此构建层次化世界模型，每层只学习下层未能解释的残差，自然形成由粗到细的渐进式抽象——类似"世界模型的ResNet时代"。

## Motivation
1. 现有 MBRL 主要依赖隐空间前瞻搜索或模型预测控制，像素级重建作为推理表征存在误差累积问题
2. LLM-CoT 类推理表征延迟高、不适用于高频动态环境
3. 单层 RSSM（如 DreamerV3）表达力受限，简单堆叠多层存在冗余和不稳定问题
4. 需要一种轻量、自监督、无需领域先验的视觉推理表征

## Method
**HRSSM (Hierarchical Recurrent State-Space Model)**: 多层 PPB (Predictive Processing Block) 堆叠

每个 PPB^k 包含: Sequence Model / Encoder / Predictor / Decoder（与 DreamerV3 结构一致）

核心设计——双向残差信息通道:
1. **自底向上 (Lower Residual Observation)**: o_res^k = Norm(o_res^{k-1} - reconstructed^{k-1})，每层仅接收下层未解释的残差信号
2. **自顶向下 (Imaginary Hint Observation)**: 上层 open-loop rollout 解码的预见图像 + 上层残差，作为附加视觉指导注入下层 encoder
3. **增强观测**: o^k = sg(o_imag^k, o_raw, o_res^k)，在通道维度拼接，stop-gradient 传递

行为学习: actor-critic 纯粹在想象轨迹上训练（遵循 DreamerV3 范式），实现策略完全 on-policy，避免分布发散。

参数规模: 50-200M（2-3层），跨层通信仅引入线性增长的开销。

## Experiment
**MineDojo 战斗任务** (5个，含 ghast/shulker/skeleton/spider/wolf):
- ResDreamer (100M x 2) 在所有任务上样本效率最优
- 唯一在高难度 Shulker 任务中取得非零成功率的方法（Shulker 发射制导飞弹）
- 50M x 2 变体仅用 DreamerV3 84% 参数即超越其平均性能

**DMC Vision 连续控制**: 不同 foresight horizon (H=4/8/16) 均超越 DreamerV3

**消融实验**:
- 50M x 3 (三层) > 50M x 2，证明层次结构可扩展
- 去除残差连接性能显著下降 → 残差调制是核心贡献
- 仅用残差（无预测重建）或堆叠全部隐状态均不如完整设计
- DreamerV3 + rollout 仍不及 ResDreamer → 层次结构与残差连接的协同效应

## Value

## Strengths
亮点是创新度: 3/5 — 将预测编码理论与 Dreamer 框架结合的方式新颖，残差连接的层次化世界模型是有意义的架构创新，但核心组件（RSSM、actor-critic）均沿用 DreamerV3。

## Weaknesses
不足是参数规模: 50-200M（2-3层），跨层通信仅引入线性增长的开销。

创新度: 3/5 — 将预测编码理论与 Dreamer 框架结合的方式新颖，残差连接的层次化世界模型是有意义的架构创新，但核心组件（RSSM、actor-critic）均沿用 DreamerV3。

相关度: 2/3 — 属于隐式世界模型（Dreamer 家族）的直接扩展，层次化残差设计对视频世界模型的多尺度表征有启发，但场景限于 RL 任务，与视频生成/3D 世界模型方向间接相关。

## TL;DR
借鉴预测编码理论构建层次化Dreamer，各层通过残差连接渐进学习"未解释信号"，以50-200M轻量规模在Minecraft战斗任务达到SOTA；ICML 2026，对隐式世界模型扩展有参考价值，建议关注其层次化残差架构设计。
