# JEPA4R: Embodied JEPA World Models with 4D Point Planning

## Insight
观察：2D JEPA 的图像特征需隐式推断操控所需的度量几何，且想象潜变量难以检查。作者把同视角的 RGBD 转成世界坐标点云，发现冻结点云潜变量支持更强的策略学习；后置解码器还能把预测潜变量还原为点云。配对 2D/3D 数据及多基准实验支持“输入几何有益”，但其 CEM 规划增益很小，不能把策略增益全部归因于更准确的动态预测。

## Motivation
现有 JEPA 世界模型多用 2D 图像，并以短程潜空间规划评估，难说明表示是否适合机器人策略，也无法直接检查预测的 3D 场景。点云世界模型若只预测显式点，计算与规划接口又不同；本文尝试结合 3D 输入、隐式预测和可视化诊断。

## Method
单深度相机 RGBD 提取 1200 个 xyz+rgb 点，PointNet 编码为 192 维潜变量；动作条件 6 层 Transformer 在最多 3 帧历史上预测下一潜变量，预测 MSE + SIGReg 防塌缩。冻结编码器后，用统一策略头做 OGBench 目标条件离线 RL / CortexBench 模仿学习；CEM 可对 5 个动作块的潜变量终态规划。另以 PAGE-4D 预训练大模型为先验，训练后置点云解码器，将观察或开放循环预测潜变量变成 4D 点序列。技术多为已有模块组合，关键是配对 2D/3D 的评价设计。

## Experiment
OGBench Cube-Single/Double/Triple 成功率 78.4/41.6/18.4%，最佳 2D JEPA PLDM 为 46.8/3.6/4.8%；Scene 为 64.8% vs 46.1%。CortexBench MetaWorld 五任务均值 98.4%、Adroit Relocate 88.0%，高于表中最强 R3M 的 96.0%/65.3%。冻结潜变量单帧解码点误差 0.79 cm，开放循环 200 环境步约 0.89 cm，另一回合动作可达 11.46 cm；但 CEM 在 Cube 的 UR5e/RM75-B 上为 65.2/79.8%，与 2D LeWM 的 69.4/73.8% 接近。真实 RM75-B 展示 8 次成功执行，无统计成功率或 2D 对照。

## Value
值得精读其配对视觉/点云评估和后置解码器诊断方法。适合借鉴到 3D JEPA：把策略成功、模型开放循环预测和真实部署分别测量，避免用短程规划成功替代表示质量。

## Strengths
同一相机、轨迹与策略头比较 2D/3D；覆盖目标条件 RL、模仿学习、解码误差和真实机器人；点云输入具有可解释的度量坐标。

## Weaknesses
点云处理使用模拟器分割移除桌面/地面等静态结构，并非纯传感器原始输入；后置解码器基于约 0.94B 参数先验，几何恢复不完全来自 192 维潜变量。点误差受静态多数点主导，立方体位置误差在 200 步为 1.39 cm；真实展示缺失败率和强基线。规划增益不显著，无法证明“更会预测”而非“输入更利于策略”。

## Future Work
作者计划收集跨场景/机器人多样 3D 数据，研究通用 JEPA 配方，并让规划直接在可检查的 4D 点空间操作。

## Rating
创新度评分：3/5 - 3D 输入、隐式预测和后置点云解码的结合实用，核心模型组件仍以现有方案为主。
相关度评分：3/3 (Core) - 直接研究 3D 与 JEPA 式隐式世界模型。

## TL;DR
将动作条件 JEPA 建在单相机点云上并解码四维想象，策略学习提升明显；做三维隐式世界模型值得精读。
