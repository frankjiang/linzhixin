# HalluWorld: A Controlled Benchmark for Hallucination via Reference World Models

## Insight
提出"参考世界模型"形式化幻觉定义：当模型产生的可观测声明相对于参考世界为假时即为幻觉。通过构建完全指定参考世界的合成/半合成环境，实现幻觉标签的自动生成。

## Motivation
LLM 幻觉基准在摘要、QA、RAG、智能体交互等场景中操作化不一致。HalluWorld 通过显式参考世界统一幻觉定义，支持可控变化和自动评估。

## Method
构建合成和半合成环境（gridworld、国际象棋、终端任务），参考世界完全指定，模型视角可控，幻觉标签自动生成。支持世界复杂度、可观测性、时间变化、源冲突策略的可控变化。细粒度错误分类。

## Experiment
评估前沿和开源 LLM。发现：感知幻觉（直接观测信息）对前沿模型几乎解决，但多步状态跟踪和因果前向仿真仍然困难。扩展思考不能普遍解决问题。

## Value
这里的"世界模型"指 LLM 内部状态模型，与用户关注的视频/3D/隐式世界模型完全不同。对世界模型研究无启发。
