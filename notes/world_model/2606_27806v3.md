# Agent vs. Parametric World Models: Hybrid Planning for Reliable Language Agents

## Insight
论文的 insight 是：语言 agent 自身可以作为 flexible world model，但容易 hallucinate state atoms；小型参数化 world model 可测可控，但单独规划能力弱。二者结合时，参数模型提供结构骨架，LLM 负责语义补全，可以显著降低 hallucination propagation。

## Motivation
复杂工具/资源规划中，LLM agent 常在中间状态预测上犯错，错误会沿计划传播。纯 parametric transition model 又缺少语义泛化和复杂规划能力。作者比较并融合两类 world model。

## Method
Hybrid-WM 训练小型 GNN transition backbone，预测 validity、delta、risk、affected entities 和 value 等结构信息。LLM agent 生成候选状态更新，consistency gate 用参数模型的 skeleton 修复或拒绝不一致 delta。

## Experiment
实验在 TaskGraph、ToolChain、ResourceAlloc、RepairFlow 等模拟 benchmark，主设置校准到 GPT-4o-mini，包含每任务 500/100/100 train/val/test。Agent-Replan 成功率 0.668，Parametric-WM-MCTS 0.625，Hybrid-WM 0.838；长 horizon H>10 下 Hybrid 0.758，明显高于两种单独方案。live GPT-4o-mini 小规模验证也降低 hallucinated state rate。

## Value
对视频/3D 世界模型关联较弱，但 hybrid idea 有启发：强语义模型需要可测的低维结构约束，避免 rollout 中状态幻觉积累。

## Strengths
清楚比较 agent WM 与 parametric WM；hybrid 机制实际降低无效动作和状态幻觉；长 horizon 分析有价值。

## Weaknesses
主要是模拟任务；真实验证规模较小；参数模型如果自信但错误，会误导 LLM；和连续物理世界模型差别大。

## Future Work
未来可在真实工具链、多智能体任务和不可靠参数 backbone 下验证。

## Rating
创新度评分：3/5 - hybrid 规划框架有实用新意，但属于语言 agent 领域。
相关度评分：1/3 (Tangential) - 与用户核心方向只有间接方法启发。

## TL;DR
Hybrid-WM 用小参数模型约束语言 agent 幻觉状态，和用户方向间接，可略读。
