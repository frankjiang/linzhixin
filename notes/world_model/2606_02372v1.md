# COMAP: Co-Evolving World Models and Agent Policies for LLM Agents

创新度：3/5 | 相关度：1/3

## Insight
核心观察：LLM agent 的 textual world model 和 agent policy 存在**分布耦合**问题——固定的 world model 无法适应不断进化的 policy 产生的新状态分布，而弱 policy 又无法为 world model 提供多样的训练数据。两者应当形成**共同进化**的闭环。

进一步发现：冻结 world model 后仅训练 policy，Delta-F1（世界模型预测准确度）会严重下降（-26.9% on 4B, -29.1% on 8B），有力证明了静态 world model 在 long-horizon 交互中会快速失配。

## Motivation
- **问题**：现有 LLM agent 的 textual world model 在构建/训练后就固定不变，无法适应 agent policy 的在线演化，导致在 long-horizon 任务中 lookahead 预测逐渐失准。
- **同行做法**：(1) 训练独立 world model 后固定使用（WKM、IWM）；(2) 在推理时做 lookahead planning（ITP）；(3) Reflexion/RAP 等 test-time evolving 方法。这些方法要么 world model 是静态的，要么依赖外部 reward/verifier。
- **关键性**：world model 与 policy 的联合演化是一个真实且重要的问题，尤其在 long-horizon agentic 任务中。

## Method
**COMAP 框架**包含三个核心机制：

1. **World Model-guided Decision-Making**：
   - Policy 先生成 draft action a_t^draft
   - World model 预测未来状态 s_{t+1} = W_phi(s_t, a_t^draft)
   - **Future-aware Reflection**：policy 基于 (s_t, a_t^draft, s_{t+1}) 生成 refined action a_t^ref 和 refinement probability p_t
   - Action gate 决定是否采纳 refined action

2. **On-policy Self-distillation for World Model**：
   - Student mode W_phi^S 在给定 (s_t, a_t) 下生成预测 s_{t+1}^S
   - Teacher mode W_phi^T 额外观察到真实 s_{t+1}^env 作为 privileged info
   - 用 KL divergence 做 token-level soft distillation（L_WMSD）
   - Teacher 通过 EMA 更新
   - **World-state gate**：根据阈值 tau_wm 决定是否采纳 WM 预测或使用真实环境状态

3. **Initialized Training**：
   - Expert SFT warm-up（policy）+ on-policy transition SFT（world model）
   - Reflection-mode initialization：通过 rollout 对比 draft vs expert action 构建 reflection 训练数据

**Co-evolving Training Loop**：policy 交互 -> world model 预测 -> policy 反思 -> 执行 action -> world model 用 on-policy 数据自蒸馏更新。

## Experiment
- **Benchmark**：ALFWorld（embodied planning）、ScienceWorld（科学推理）、WebShop（web navigation）、StableToolBench（tool-use）
- **基线**：GPT-5.4/DeepSeek-V4-Flash/Pro（API），ReAct/Reflexion/RAP/ITP（test-time），WKM/IWM/ITP_R（world modeling），SFT
- **Backbone**：Qwen3-4B 和 Qwen3-8B
- **指标**：Success Rate（task performance）、Delta-F1（world model prediction quality）、SoPR（StableToolBench）
- **效果**：
  - Qwen3-4B: 平均 60.15%（vs ITP_R 51.52%，+8.6%）
  - Qwen3-8B: 平均 72.11%（vs ITP_R 69.53%，+2.6%）
  - Qwen3-8B w/ COMAP 超越 GPT-5.4 with ReAct
  - World model Delta-F1: 85.40% (4B) / 90.29% (8B)，接近或超越 GPT-5.4
- **消融**：
  - 去掉 future state input: -9.8% / -24.1%（最大影响）
  - 去掉 expert SFT / reflection init / action gate / online reflect 均有显著影响
  - 冻结 world model: Delta-F1 暴跌 -26.9% / -29.1%，强力验证共同进化必要性
- **Reflection 质量**：URR 低（0.07-0.16），HRR 低（0.08-0.11），BRP 高（0.87-0.93），说明 reflection 精准有效

## Value
- **优点**：完整的 world model + policy 共同进化框架，设计合理（self-distillation + reflection + gating），实验全面（4个benchmark + 多维消融），冻结WM的消融实验令人信服。
- **启发**：world model 与 policy 的分布耦合问题同样存在于视频/3D 世界模型中——如果 world model 用于 model-based RL，固定的 world model 同样会在 policy 进化后失准。COMAP 的 on-policy self-distillation 思路可以迁移。
- **局限**：仅限 textual environment（text-based state representation），推理时需额外 world model forward pass，不涉及视觉/连续动作空间。

## TL;DR
提出COMAP框架通过on-policy self-distillation和future-aware reflection实现textual world model与agent policy的闭环共同进化，在4个benchmark上超越静态world model方法。可选读，共进化思想有启发但限于文本agent。
