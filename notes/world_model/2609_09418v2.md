# Valerant: An Automatic Navigable Game Map Generator via Action-Conditioned World Model Exploration

## Insight
能生成可操控的第一视角视频，不代表已有可复用的三维空间。作者将候选动作视频送入 SLAM，按重建后的探索收益及碰撞情况选择分支，再累积点云，从而把视频探索转成显式地图。定性例子支持管线可行，但尚未充分证明地图的可导航性和持久几何一致性。

## Motivation
游戏地图制作需要可供移动和碰撞判定的显式空间，仅有视频流难以直接成为游戏资产。将已有动作条件视频模型用于自动探索与建图，问题与视频—三维世界模型融合直接相关。

## Method
- 冻结 Matrix-Game 3.0，以单张游戏截图初始化；每步保存生成器及 MASt3R-SLAM 状态，从同一历史生成直行、左右转后前进、原地左右转五种候选视频。
- 重建候选轨迹与点云，过滤碰撞后按覆盖和前进收益选择分支；恢复检查点，只提交所选分支，持续扩展地图，可选 video2world 全局后处理。
- 局部拟合地面，以相机离地高度归一化几何，减少单目尺度与高度漂移影响。
- 用沿轨迹的柱体点云占据检测，以及原始深度中的“近墙却继续前进”检测互补过滤穿墙；原地旋转豁免平移碰撞检测。
- 长时间停滞时联合回退生成器和地图，并记住被放弃路径的空间区域，避免重复进入死路。

## Experiment
- 输入均为 VALORANT 截图，只与 HY-World 2.0 比较；展示四个主要场景及三个组件的定性消融。
- 报告 VLM 评价份额 80% 对 20%，人类偏好 83.33% 对 16.67%。但表格将 AS 写为 aesthetic score，正文称 authenticity score，未明确统一定义。
- 缺少总样本数、人类评价人数、VLM 型号和提示、置信区间，无法评估这些百分比的可靠性。
- 可视化显示沿生成路径得到局部点云，但没有覆盖面积、碰撞率、路径成功率、闭环误差或重访一致性等定量指标，也未展示在导出的独立游戏环境中导航。
- 单 H100 运行，未给出生成及重建成本；正文指向“Appendix ??”的超参数，本 PDF 实际没有该附录。

## Value
值得参考的是利用显式几何给视频生成提供候选选择信号，以及生成状态与地图同步回退。需要注意：持久存储一个点云并不保证后续视频服从该点云；文中没有明确把地图渲染或几何约束反馈进冻结生成器。当前成果更接近可探索视频的局部几何提取。

## Strengths
- 免训练组合视频生成、建图和动作选择，输出显式三维表示。
- 对地面漂移、低置信墙体和探索死路给出具体工程处理。
- 所有候选从同一保存状态开始，避免污染已提交地图。

## Weaknesses
- 主要是成熟模块及启发式拼接，评估不足以验证“可导航游戏地图”的核心承诺。
- SLAM 假设跨视图来自一致空间，而生成视频可违背该假设；同一生成数据上的几何检查缺少独立真值。
- 候选评分细节、预算、阈值与重放随机性未完整交代，可复现性较弱。
- 产物仍是点云，缺少可编辑网格、碰撞资产和物体交互；单游戏截图来源限制泛化判断。

## Future Work
作者明确提出提高几何一致性，并把点云转换成更丰富、可编辑的游戏资产。

## Rating
创新度评分：2/5 - 视频模型与 SLAM 探索的组合有应用价值，但技术多为集成，关键定量和复现信息缺失。
相关度评分：3/3 (Core) - 直接连接动作条件视频世界模型、显式三维地图和空间探索。

## TL;DR
将动作条件视频、SLAM和候选探索串成单图建图流程；方向相关但可导航性验证不足，架构可选读。
