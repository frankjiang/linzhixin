# Predictive Safety Guardrails Do Not Always Make LLM Agents Safer

## Insight
预测结果介入决策更深，不必然提升实际安全性：预测可能漏报风险，决策器也可能只受“有预测”这一形式影响。作者用无预测/可咨询/强制门控对比、预测扰动及沙盒验证，区分了预测可靠性与使用忠实性。

## Motivation
LLM 智能体安全护栏通常以端到端安全分数评估，无法判断收益来自准确预判、门控机制还是行为副作用。此问题对 LLM 智能体安全重要，但不属于视频、3D 或 JEPA/Dreamer 世界模型的主要研究对象。

## Method
设计三种预测集成方式：不调用预测器、由 actor 自行咨询、候选动作经预测风险门控且被拒后重提。另用 7 种模型在记录轨迹上比较近/远期风险预测，最后施加空白、无关、损坏、填充、风险反转反馈与沙盒执行证据，检验策略是否真正依据预测语义行动。主要是诊断评测，没有新预测模型。

## Experiment
在数字工作流 HarnessAudit 和家庭任务 IS-Bench 上，用安全遵循率 SAR、任务完成率 TCR、安全成功率、风险精确率/召回率与 token 成本等指标。Qwen3.5-27B 的 HA SAR 从 76.81（无预测）降至 73.40（可咨询），强制门控为 85.10；GLM 强制门控 TCR 从 85.69 降至 77.26。门控平均 token 消耗分别达基线 6.31 倍和 3.15 倍。Qwen 在无关反馈下仍有安全收益，风险全反转时 SAR 90.1 但 TCR 仅 13.7；局部沙盒证据也未消除后续违规。远期风险召回与违规规则匹配不稳。

## Value
提示评估任何预测式决策系统都应拆开看预测覆盖、行为响应、任务完成和成本；对本研究方向仅有跨领域评测启示。

## Strengths
三层诊断设计清晰；控制预测内容的反事实扰动揭示高安全分数可能源于保守门控；同时报告效用和推理成本。

## Weaknesses
预测器是文本 LLM 而非视觉/物理世界模型；基准与风险标签依赖具体任务，不能直接外推到视频世界模型；沙盒只验证单步结果。

## Future Work
作者建议提高长时风险预测可靠性，并研究如何让预测证据持续、忠实地改变后续决策。

## Rating
创新度评分：2/5 - 诊断框架和干预有用，但没有新世界模型技术。
相关度评分：0/3 (Noise) - 研究对象是 LLM 智能体安全护栏，与目标视觉/3D/隐式世界模型无实质方法关联。

## TL;DR
文本预测护栏即使提高安全分数也可能损害任务或未被忠实使用；对本方向可跳过。
