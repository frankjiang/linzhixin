# The Rank-One Corner: How Much Value Equivalence Does a Task Need from a World Model?

## Insight
核心 insight 是 value equivalence 不是 all-or-nothing，而是有 rank/dimensionality。Observation：一个任务真正需要 world model 表示的不是全部观测，而是下游 query 依赖并在 dynamics 下闭合的一组低维坐标，作者称为 closure。若训练目标只是标量 reward/value，即使完全 aligned，也只能给 latent 施加一维预测压力。推论是单标量 value-equivalent objective 只会安装 closure 的一维投影；要安装 d 维 closure，需要 d 维 objective。作者用 DreamerV3 RSSM 控制环境和 reduced-rank regression 解释支撑该结论。

## Motivation
世界模型常被 reconstruction error、reward prediction 或 planning return 评价，好像模型质量是一个单数。但对于控制，关键是 latent 是否包含任务 query 所需的 closure。MuZero/Dreamer 等 value-equivalent 思想认为只建模与价值相关的结构即可，但现实中常用的是单 reward/value 目标。论文问：单标量 value objective 是否足以让 latent 表示任务需要的多维结构？这是 Dreamer/隐式世界模型方向的核心理论问题。

## Method
作者构造一个测量型环境：已知 k 维慢变量 Lt 通过固定 analytic warp 渲染为 64x64 图像，同时加入高方差 distractor Dt。使用 DreamerV3 categorical RSSM，重建头读 h,z；query/value head 只读 stochastic latent z，故不能绕过 z 走 recurrent state。训练目标是标准 reconstruction 加一个权重为 lambda 的辅助 query head 或 value head。评估用 held-out linear probe 读出 L from z，并用 reconstruction-only null 设置 installed rank 阈值，同时检查 h 泄漏。

关键概念：

- closure：下游 queries 在 dynamics 下需要的最小自洽坐标集。
- installed rank：latent 中线性可读、超过 null 的 closure 维数。
- rank-one corner：单 reward/value objective 是 d=1 的 value equivalence，只能安装一维。

## Experiment
主要结果：

1. 在高方差 distractor 下，reconstruction-only 几乎不安装 L；当 query head 被强制只读 z，query-aligned objective 会把 L 安装进 latent，R2 随 lambda 从约 0.55 升到 0.88 并接近观测可线性解码上限。label shuffle 使效果消失，证明是目标导致。
2. 单标量 value objective 对完整 closure 的 R2 只有 0.10，而同配置 full k=4 objective 达 0.76。标量确实学到自己的一维 projection 0.49，说明不是 head 失效。
3. 将 objective dimensionality d 从 1 扫到 4，installed rank 恰好为 1、2、3、4；把 d=1 权重提高到 4.5 倍也只增强同一维，不会招募第二维。
4. 用模型自己的 value head 重复 d 维 value/reward family，rank law 仍成立，R2 随 d 单调增加 0.11、0.27、0.47、0.55。
5. 边界实验显示：当 closure 每帧都可观测，reconstruction 自然安装它，单 reward 和 full value family 在 rank 与 return 上无差别；objective 只在 reconstruction/recurrence/filtering 不能触达的结构上起决定作用。

## Value
这篇对隐式世界模型价值很高。它提供了一个比“重建 vs 价值预测”更精细的评价语言：任务需要多少 value equivalence，取决于 closure rank 以及该 closure 是否已由观测/重建/历史通道提供。对 Dreamer/JEPA 类 latent model 的启发是，不要只问 reward 是否可预测，要问 latent 是否安装了足够维度的可控、可预测 closure。对 benchmark 设计也有启发：应测试 latent 中的 task-relevant rank，而不是只看 return。

## Strengths
- 概念清楚：closure、installed rank、rank-one corner 都直接服务于世界模型评价。
- 实验控制强，DreamerV3 stack、probe、head、capacity 和 objective dimensionality 分离得比较干净。
- 不夸大：明确给出 law 的边界，即 frame-observable closure 下 objective moot。
- 把训练侧表示和评估侧 Bellman residual 的低维切片联系起来。

## Weaknesses
- 证据主要来自单架构、单 synthetic environment family，未证明自然图像或真实控制任务普遍成立。
- continuous-latent 变体存在训练分布可读但 fresh rollout 不泛化的负结果，机制未解释。
- 公共 benchmark 上 closure estimator 只能读到约三分之一相关结构，外部验证较弱。
- 理论部分借用线性/reduced-rank regression，非线性深度模型中仍主要靠实验验证。

## Future Work
作者将 full operator fidelity 与 Bellman residual 的完整跨架构研究推给 companion paper。文中还指出需要更深的 closure estimator、更自然的 benchmark、更广架构验证，以及解释 continuous-latent 泛化失败。开放问题还包括 dual control 场景中哪些 return-relevant 坐标只有 objective 通道能安装。
