# PhiZero: A World Model Built Around Physical Language

## Insight
作者观察到，直接像素预测把动力学和外观纠缠在高维生成器中，而自然语言又过于粗糙，无法精确表达连续物理变化。由此提出介于像素与自然语言之间的离散“physical language”：第一帧负责静态外观，有限容量的离散瓶颈只编码相邻状态变化，预训练扩散先验补全细节。论文通过跨外观复用同一 token 序列、动作类别在表征空间形成结构以及多项物理生成/判别基准证明该表征确实偏向“如何变化”，但尚未证明 token 对应可解释物理变量或定律。

## Motivation
视频世界模型通常直接从图像与条件生成未来帧，视觉质量可以很高，物理因果却仍可能错误；latent-action 方法又常绑定特定任务或 embodiment。关键问题是能否从无标注互联网视频中抽取可预测、可迁移、显式承载状态转移的中间语言，让动力学推理与像素渲染分离。该问题直指视频世界模型的表示与长时可控性，重要性高。

## Method
PHIZERO 采用 reason-then-render 分解：

1. Physical Language Tokenizer 用 Wan2.2 VAE 的时空编码器提取视频 latent；共享 transition-level Q-Former 分别对每对相邻 latent state 做 cross-attention，再按时间拼接。
2. 低维投影经 FSQ 离散化为 25K 词表。33 帧视频形成 9 个时间状态，每个相邻对使用 32 个 query，最终得到 256 个离散 token。
3. 以第一帧和 token 为条件，用 Wan2.2-5B 初始化的 flow-matching 扩散解码器重建未来视频。pure-noise warm-up 强迫解码器先依赖新 token，避免预训练去噪器忽略条件。
4. Physical Language Reasoner 由 Qwen3-VL-4B 初始化，输入第一帧与高层动作意图，自回归预测 token，再由冻结/适配后的扩散解码器渲染视频。

训练包括 10K 小时互联网视频的 tokenizer curriculum pretraining，5M 个四秒真实/模拟 clip 的 tokenizer SFT 与 reasoner continued pretraining，以及 1M 个 motion-rich clip 的 reasoner SFT；tokenizer 与 reasoner 各阶段均使用 128 张 A100。核心结构并非完全从零出现，而是把 transition tokenizer、FSQ、预训练 VLM 与视频扩散组合成一个统一的显式转移预测接口，创新点主要在分解方式与规模化实现。

## Experiment
生成评测覆盖 Physics-IQ Verified、PhyGround 和 WorldModelBench。PHIZERO 分别取得 IQ-Score 41.2、PhyGround Physics 3.01/Overall 2.97、WorldModelBench Physics 4.88/Total 8.19，表中均为最佳或整体最佳；但某些子项并非第一，如 Physics-IQ 的 WS-IoU 为 27.6，低于若干基线。

理解评测把候选视频编码为 token，比较 reasoner 在相同文本条件下的序列似然：IntPhys2 overall 56.34，LikePhys 平均错误率 41.7，YoCausal RSI 55.54、CCI 6.20、aggregate rank 2.0。结果优于表中基线，但绝对值仍离可靠物理判断较远，尤其 LikePhys fluid error 为 53.15。

Tokenizer 在 500 个四秒视频上用 256 个 token 达到 PSNR 28.9、SSIM 0.903、LPIPS 0.087，优于同量级压缩 tokenizer，但明显低于使用 44,800 连续 token 的 Wan VAE。消融显示去掉扩散解码器影响最大（PSNR 26.6）；去掉 transition Q-Former 或 pure-noise warm-up 也退化。Reasoner 消融中，完整模型 IQ-Score 41.2，去掉模拟数据为 37.7，去掉两阶段训练为 39.2；仅增强 Wan prompt 为 26.6。

应用实验展示轨迹条件驾驶、机器人关节/夹爪条件视频、滑窗交互生成，以及跨外观/embodiment 运动迁移。需要注意：驾驶和机器人版本都先在相应领域微调 tokenizer/reasoner；所谓“zero-shot transfer”是对源域 tokenizer 做短暂适配、编辑目标第一帧后的视频重渲染，并非零样本产生可执行机器人控制。

## Value
论文提供了一个很值得跟进的表示思路：把未来预测变成离散 transition sequence modeling，再将生成器视为渲染器。这可能连接视频世界模型、latent action、VLM 推理与策略规划，也便于用序列似然做物理异常检测。后续关键是把“physical language”从生成友好的运动编码提升为带对象持久性、可组合因果结构和可执行动作语义的状态表示，并验证其在闭环控制与规划中的收益。

## Strengths
- 直接针对视频世界模型“视觉逼真但物理错误”的核心矛盾，问题与分解方式清晰。
- 在统一表示上同时支持生成、判别、动作条件和迁移，接口通用性较强。
- 数据规模、训练细节、消融和多类物理基准较完整，结果不只依赖主观案例。
- 相邻状态转移建模、首帧外观锚定与 pure-noise warm-up 共同限制信息捷径，设计逻辑连贯。

## Weaknesses
- “语言”本质上仍是不可解释 FSQ code；没有对象、质量、速度、接触或守恒量的显式 grounding，不能等同于符号物理推理。
- 主模型只预测四秒窗口；长时交互只是把生成末帧递归作为下一窗口首帧，没有量化漂移、状态遗忘或误差累积。
- 训练成本极高且大量数据为 in-house，难以复现；对不同规模、token 数和数据量的 scaling 分析不足。
- 许多基线的参数量、训练数据和条件形式不同，榜单提升不能完全归因于 physical-language 结构。
- “zero-shot cross-embodiment”只展示视频外观和运动转移，依赖 GPT-Image 编辑且未验证运动学可行性、接触成功率或真实机器人执行。
- 观测视频无法覆盖不可见力、触觉和微观状态；论文自己的局限也承认 token 不是物理定律。

## Future Work
作者计划将 physical language 用于 VLM 时空理解和具身策略规划，把人类视频中的状态转移迁移到机器人以降低真机数据需求；通过分层或循环预测扩展固定时长，实现长时状态追踪；并扩大模型、算力与数据规模。另一个明确方向是覆盖视觉不可辨识的触觉与微观动力学，并把离散 token 对齐到可解释物理变量。

## Rating
创新度评分：4/5 - reason-then-render 的离散转移语言形成了较完整的新型视频世界模型接口，规模与效果突出；但基础组件多为已有技术组合，且表示仍不可解释、长时和闭环控制证据不足。

相关度评分：3/3 (Core) - 核心就是可控视频世界模型及其隐式离散动力学表示，与视频和隐式世界模型方向直接相关。

## TL;DR
以离散物理转移语言先推理再渲染未来视频，兼顾物理生成与控制，值得精读但需警惕过度命名。
