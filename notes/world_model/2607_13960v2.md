# GigaWorld-Policy-0.5: A Faster and Stronger WAM Empowered by AutoResearch

## Insight
论文的 insight 是：WAM 的未来视觉建模不一定要在推理时显式 rollout，它可以作为训练期 dense supervision，用来塑造动作表征；推理时只走 action decoding 路径即可保留物理 grounding 同时降低延迟。进一步观察是视觉 dynamics 和动作生成的计算需求不同，因此用 Mixture-of-Transformers 分专家可以让 action path 更轻。

## Motivation
该文解决 World Action Model 在机器人闭环部署中的推理成本问题。现有 WAM 常把训练时的 joint action-video modeling 也搬到推理时，显式生成未来视频或迭代 denoising，视频 token 成本远高于 action token。GigaWorld-Policy 已提出 action-centered WAM，本文是其 0.5 版增强，目标是在保留未来视觉监督收益的同时进一步压缩边缘设备延迟。

## Method
模型沿用 action-centered causal token 结构：action token 可看当前多视角视觉、状态和语言，但不能看未来视觉 token；未来视觉 token 可看 action token，用于 action-conditioned future prediction。训练用 flow matching 同时回归 action 和 future visual token 的速度场，视觉 token 由 Wan VAE 编码，文本用 umT5。新贡献是 MoT 架构：visual expert 负责视觉 dynamics，action expert 负责动作 denoising，二者通过多模态 self-attention 交换信息。action expert 更小，hidden 1024/FFN 4096，相比 visual expert 3072/14336 降低 action-only 推理成本。训练分 robot-data pretraining 和 target-robot post-training，并混合 AC-WM 与 WAM 任务。推理侧用 KV cache、torch.compile 和 C++ runtime。

## Experiment
真实机器人为 AgileX PiPER 6-DoF，评估 text following 和 long-horizon manipulation。水果任务平均成功率 0.85，高于 pi0.5 0.76、Motus 0.80、FastWAM 0.78、GigaWorld-Policy 0.80；物体放置任务平均 0.89，高于最强 baseline Motus 0.83；长程 Food Heating 和 Tableware Arrangement 均为 0.80，baseline 平均最高 0.60。延迟方面，GigaWorld-Policy-0.5 在 A100 为 189ms，RTX 4090 为 110ms，C++ 部署到 RTX 4090 为 85ms；对比 FastWAM 182ms、GigaWorld-Policy 293ms、Motus A100 3231ms。消融显示 mixed AC-WM+WAM pretraining 比纯 WAM 收敛更快、最终水果任务达 0.85；AutoResearch 通过 1K-step sweep 选出 learning rate 6e-5、batch size 16，并在 30K step 取得最佳验证 action MSE。

## Value
对 WAM/机器人世界模型有直接价值。它强调将未来视觉预测作为训练约束而非推理负担，适合 real-time robot policy。对研究上更重要的启发是 causal mask 设计：未来视觉不能泄漏到 action，但 action 要解释未来视觉，从而逼迫 action 表征承载可预测 dynamics。

## Strengths
工程目标清晰；延迟和真实机器人成功率一起报告；MoT 专家拆分与 action-only inference 匹配；混合 AC-WM/WAM 训练的消融有说服力。

## Weaknesses
技术报告色彩较重，数据、训练细节和统计置信区间有限；AutoResearch 更像调参自动化，科研贡献较弱；主要是 GigaWorld-Policy 的增强版，范式创新有限；真实任务数量少，成功率样本量每指令约 10 次，泛化边界不清楚。

## Future Work
作者未展开很多未来工作，主要指向更快、更可部署的 action-centered WAM。自然后续包括更大规模真实任务评估、公开完整训练 recipe、端到端 action-world pretraining、更多边缘硬件优化和不确定性/失败检测。

## Rating
创新度评分：3/5 - action-centered WAM 思路已有，本文主要通过 MoT、混合预训练和部署优化做显著工程增强。
相关度评分：3/3 (Core) - 直接研究机器人 World Action Model 和未来视觉 dynamics 对动作生成的训练价值。

## TL;DR
GigaWorld-Policy-0.5把未来视觉监督留在训练、推理只出动作，WAM方向可选读。
