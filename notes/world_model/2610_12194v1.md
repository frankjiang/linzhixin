# MiniWAM: Learning Compact Future Targets for Efficient World-Action Modeling

## Insight
世界动作模型的收益未必来自重建完整未来特征，而可能来自可预测、与动作有关的转移信息。论文观察到原生 Wan-VAE/DINOv3 未来特征很密集，遂用逆动力学与特征重建共同训练小型转移瓶颈；在同视觉骨干和同策略训练步数下，这个目标同时提升成功率并降低计算。消融显示只做压缩重建不足以获得同样的行为结构，但尚不能证明表征提升是策略性能改善的唯一中介。

## Motivation
现有 WAM 将未来视频 VAE latent 或视觉 patch 直接作为辅助预测目标，世界分支需处理大量时空 token，训练成本高。减少生成开销或缩小模型仍保留稠密目标；论文问能否直接学一个低维、控制相关的未来监督信号。对隐式世界模型和机器人策略共训，这是关键的目标设计问题。

## Method
两阶段：① PRISM 编码器以当前与未来视觉特征为输入，用 3D 卷积压缩成每相机 `3×4×4×64` 的转移网格；逆动力学流匹配从该网格预测动作，特征解码器重建未来原生特征，并加弱 KL 正则。② 冻结 PRISM，以后验均值作未来目标；0.25B 双专家 MoT 用当前视觉、语言和本体状态联合去噪隐式未来 token 与动作 chunk。部署时只需当前观测，PRISM 编码器和特征解码器均不用运行。

默认 16 帧目标的特征网格位置由 3136 降至 48（约 65 倍）；由于原生基线先 patch 化，实际世界分支 token 是 784→48（约 16 倍），不是 65 倍。方法可同时接 Wan2.1-VAE 与 DINOv3，贡献是重新设计预测目标，而非改造视觉骨干。

## Experiment
在 LIBERO、LIBERO-Plus 和 RoboTwin 2.0 仿真任务以成功率评估控制，并测训练吞吐；有同骨干、同数据/更新数的原生未来目标对照和逆动力学/重建/瓶颈大小消融。LIBERO 成功率：VAE 原生目标 92.8%→PRISM 94.8%，DINOv3 93.2%→97.2%；LIBERO-Plus-2K 上分别 50.2%→56.5%、60.9%→74.1%。RoboTwin 2.0 综合成功率 46.1%，优于所列 Fast-WAM 39.9%，但低于 π0.5 的 58.4%。

32 帧 RoboTwin 训练中，世界动作共训阶段吞吐加速 10.48 倍；计入第一阶段训练的估计总加速 8.46 倍。逆动力学+重建在 LIBERO-Plus-2K 的最大瓶颈成功率 74.1%，只重建 69.5%。未见真实机器人部署；跨不同 VLA/WAM 的规模、预训练与部分外部报告设置不完全一致。效率统计还排除了离线视觉特征和 PRISM 目标提取。

## Value
对隐式/JEPA 类方向有直接启发：先确定应预测哪种与控制相关的未来，再决定模型容量；评测应同时报告原生特征位置数、实际 Transformer token 数及端到端成本。跨骨干控制实验值得复用。尚待证明该表征在跨任务、跨机器人和长期规划中能否共享、泛化。

## Strengths
- 同时在生成式 VAE 与判别式 DINOv3 特征上对照，降低“仅换骨干更强”的解释空间。
- 把逆动力学、重建及瓶颈容量拆开消融，并以留出任务的动作邻域分析表征。
- 附录澄清 65 倍特征网格压缩与 16 倍实际 token 压缩的区别。

## Weaknesses
- PRISM 每个下游环境单独训练，跨场景/机器人可迁移性未知。
- 仅有仿真成功率；没有真实世界、长时程或模型预测质量的直接评测。
- 两阶段设计要预先访问未来轨迹，且训练加速没有纳入离线特征与目标提取。

## Future Work
作者提出在更大、更多样的机器人数据上预训练共享 PRISM 编码器，并探索第二阶段联合或部分更新它，而非始终冻结。

## Rating
创新度评分：3/5 - 控制相关的紧凑预测目标与严密对照有价值，但逆动力学、重建和双专家共训都是已有思想的组合。
相关度评分：3/3 (Core) - 直接研究隐式未来表征与世界动作模型的高效学习。

## TL;DR
以逆动力学塑造紧凑未来目标，MiniWAM 在更低训练成本下提升机器人控制；隐式世界模型目标设计值得精读。
