# Learning from World Feedback: Why Model Uncertainty Fails as a Risk Signal in Model-Based RL

## Insight
有。Observation 是 model uncertainty 的支撑域在“预测不确定的状态空间”，而 safety risk 的支撑域在“约束边界/碰撞区域”，两者在部分可观测控制中可能近似正交。推论是把 dynamics uncertainty 当风险惩罚会反而增加碰撞；风险信号应来自世界反馈、验证器或 outcome-supervised feedback model。

## Motivation
解决安全 MBRL 中常见假设：更低 MSE 的 world model 和更高 uncertainty penalty 会带来更安全规划。同行如 MOPO/PETS/RSSM 常复用模型内部不确定性作风险信号。论文质疑这个默认实践，对 world model 评估和 planner cost 设计很重要。

## Method
在 2D navigation POMDP 中固定 MPC planner，比较四类 world model：Residual、Pure Learned、RSSM、PETS-style ensemble。风险项比较 dynamics uncertainty、minimum lidar margin、time-to-collision、以及用历史碰撞标签训练的 2-layer MLP feedback model gψ。提出 RLxF 三原则：风险 grounded in world outcomes；部署前验证 proxy-outcome 相关性；直接信号不可用时用 outcome-supervised feedback model。

## Experiment
四种 world model MSE 差约 2x，但 MPC reward 在单模型架构间 TOST 等价；Ensemble MSE 比 Pure Learned 好却规划更差。风险惩罚中 dynamics uncertainty 让碰撞率从 26% 增至 30%/34%，而 gψ 降至 16%/14%，minimum lidar 降至 4%/1%，TTC 降至 12%/11%。信号 AUC 排序为 min lidar 1.00、gψ 0.97、dynamics uncertainty 0.60，能预测安全效果。

## Value
对我们很有启发：世界模型内部指标如 MSE、latent error、uncertainty 不一定等价于规划安全或任务价值，必须用 world feedback 校验。虽然不是视频/3D 模型论文，但对评估与代价设计值得选读。

## Strengths
问题尖锐；固定 planner 和模型变量做得干净；把 MBRL 与 RLHF/RLxF 的反馈原则类比清楚；给出可操作的 AUC/correlation proxy gate。

## Weaknesses
环境是 2D lidar POMDP，不含像素、视频或复杂机器人；world-feedback 信号如 lidar/TTC 强依赖领域；gψ 在更稀疏、更复杂失败标签下是否足够未知。

## Future Work
作者指出要测试 pixel-based perception，研究 gψ 何时足够、何时需与 verifier/direct signal 组合，并把 P2 diagnostic 连接到 planning failure formal bound。
