# WM-Cov: Test Adequacy for Interactive World-Model-Style Autonomous Driving Simulation

## Insight

Observation：交互式生成 simulator 中，scenario 不再是一条固定轨迹，而是 map、route、初态、背景策略、prompt 和 seed 分布组成的 family；换 ego planner 会产生不同世界响应。因而“请求了某测试条件”不等于“闭环中实现了该交互”，生成碰撞也不等于有效安全证据。论文推论：测试充分性应分别累计 requested、realized、valid-realized coverage，并以最近窗口中新覆盖、新 failure mode 和 failure probability 区间宽度的收敛决定停止。实验确实显示 DriveArena 的 realization rate 随 planner/horizon/prompt 变化，但对“何时足够安全”的停止有效性只做了示例，而非统计保证。

## Motivation

传统自动驾驶 scenario library 有覆盖与充分性概念，world model/generative simulator 则能生成开放、反事实、planner-dependent traces，同时混入重复、条件失败、地图不一致和视觉/动力学 artifact。现有 WM 指标重画质、可控性或风险暴露，不能回答测试预算是否已形成足够有效证据。该问题对把视频世界模型当测试基础设施很重要，但论文不改进世界模型本身。

## Method

把 testing intent 定义为交互 scenario family，provider 对 seed rollout 出 planner-conditioned trace；adapter 统一记录 family、planner、provider、请求条件、实际交互、actor、outcome、risk/realism/artifact scores 与 audit note。trace 被映射到 ODD、interaction、risk bin、behavior、failure mode、validity taxonomy；validity ledger 区分 valid safe/safety-critical/ADS failure、duplicate、conditioning failure、invalid scenario 与 artifact failure。覆盖分别计算 request→realized、realized→valid 和 requested valid，并组合单维/成对 bin coverage。有限预算下贪心分数加权 marginal valid coverage、risk、realism，扣 redundancy 和 artifact risk；报告 coverage、valid failures、failure modes、artifact/invalid、平均 risk/realism 和 valid-evidence precision。停止条件要求窗口内 coverage/failure discovery 增量和 failure-rate 区间宽度低于用户阈值，且 artifact rate/required gaps 合格。创新是证据账本和测试合同，数学与选择策略较常规。

## Experiment

三层证据包括执行的 TeraSim/SUMO 事件、人工构造 WM-like mixed pool，以及真实 DriveArena TrafficManager→WorldDreamer→UniAD/VAD provider chain。TeraSim/SUMO 1219 traces 中标为 valid ADS failure 230、valid safety-critical 299、artifact failure 690；budget 100 时 WM-Cov 选 99 valid failures、0 artifact、coverage 0.2289，risk-only 为 100/0/0.0924，coverage-only 为 17/58/0.2426。mixed pool 中 WM-Cov 为 coverage 0.4874、76 valid、6 modes、0 artifact；污染率 0.10→0.55 时仍选 0 artifact，而 risk-only artifact 25.67→67.00。16 个权重配置结果几乎不变。141-row blind audit 的 artifact precision/recall 均 1.00，但总体 exact agreement 0.411、Cohen κ=0.281，主要分歧在 duplicate 边界。DriveArena 主矩阵含两 planner×两 horizon×六 prompt×每格 15，共 360 请求：304 full、56 partial；UniAD 5/7.5 s realization 为 0.933/0.644，VAD 为 1.0/0.8。另一个不相交 route slice 80 请求中 74 full、6 partial。该矩阵只验证请求—实现账本，未评真实 ADS 安全或视觉 realism。

## Value

工作提醒世界模型评测者：生成能力指标不能直接转成 safety evidence，必须保留 prompt/seed/planner provenance、验证真实 realization，并显式扣除重复和 artifact。这个“生成→审计→覆盖→停止”的层次可用于视频世界模型的闭环测试平台。其研究价值主要在评测治理和数据契约，而非视频/3D/latent dynamics；若要成为可靠 benchmark，需要自动且可校准的 validity assessor、独立审计与有错误控制的停止准则。

## Strengths

清楚区分测试意图、实际交互和有效证据；provider-agnostic schema 对工程落地有用；不仅报告 failure count，也纳入覆盖、失败多样性、重复、artifact 和预算曲线；真实 DriveArena chain 证明 planner/horizon/prompt 会影响完整实现，另有 route-slice check；作者明确不把 provider realization 当作 planner 安全排名或充分性证明。

## Weaknesses

WM-Cov 选择器直接使用预先给定的 validity/artifact risk，实验中“零 artifact”很大程度是标签可用后的定义性结果；真实生成器上如何可靠、自动、低成本判断 artifact 才是难点。总体审核 κ=0.281，说明分类稳定性有限。mixed pool 和污染 stress test 是人为构造，无法代表真实 neural WM artifact 分布。覆盖 taxonomy、bin、权重、阈值均由用户指定，缺少与实际危险发现/残余风险的外部效度；停止规则没有误停概率或安全保证。DriveArena 仅一 map/附加 route slice、两 planner，主要观察文件是否完整，未检验有效失败、反事实可重现性、视频物理正确性或跨 planner transfer。

## Future Work

作者提出扩展到更多地图、流量、prompt、天气、planner 和更大生成 rollout，估计真实世界模型 artifact 分布，并对同一 scenario family 更换 planner 重新闭环生成以研究 transfer。还需独立标注者/审计模型、label noise 感知覆盖、统计功效/顺序检验和安全论证接口。

## Rating

创新度评分：2/5 - 将传统覆盖充分性迁移到交互生成测试并形成可审计账本有实用贡献，但方法主要是 taxonomy、加权贪心与启发式停止，关键 validity 难题未解决。
相关度评分：2/3 (Related) - 面向自动驾驶交互世界模型的测试充分性，能直接借鉴评测设计，但不提出视频、3D 或隐式世界模型技术。

## TL;DR

把世界模型测试从生成数量改为有效交互证据收敛，框架实用但审计近似循环，可选读。
