# Identifiable Token Correspondence for World Models

## Insight
Token-based transformer世界模型将下一帧预测纯粹视为token生成问题，忽略了token跨时间的持久性。视觉环境中相邻帧大部分token对应同一底层实体，应该直接复用而非重新生成。ITC通过最优传输建模token对应关系，每个next-frame token要么从前帧复制，要么新生成。

## Motivation
现有token-based world model（IRIS、Delta-IRIS等）在long-horizon rollout中常出现物体重复、消失、变异等temporal inconsistency。根本原因是transformer并行生成所有output token时无法捕获"同一实体不应重复/消失"的约束。ITC在解码阶段引入最优传输，不改变训练流程。

## Method
- **Optimal Transport解码**：构建affinity matrix A，source包含previous frame tokens和transformer predicted tokens，destination是next frame tokens
- **A^(prev)**：基于token embedding内积和空间距离，衡量前帧token被复用的适合度
- **A^(gen)**：对角矩阵，wildcard penalty c_w控制使用新生成token的代价
- 用Sinkhorn算法求解partial transport plan，再用greedy binarization得到binary assignment
- 解码规则：若Pi^(prev)_{ij}=1则复用前帧token u_i，若Pi^(gen)_{jj}=1则从transformer预测采样
- 配合3D RoPE（时间+空间位置编码）使用
- **即插即用**：不改变transformer架构和训练过程

## Experiment
- **Craftax-classic**：Return 72.5%, Score 35.6%，显著超过前SOTA（67.4%/27.9%）
- **Craftax**：Return 7.09%, Score 2.40%，超越Dedieu et al.和Simulus
- **MinAtar**：4个Atari小游戏全部SOTA
- **Atari 100K**：26个游戏IQM 1.092，超越Simulus的0.990
- **Per-step accuracy**：overall 51.13% vs baseline 46.94%，含creature的hard subset提升最大（33.83->38.37%）
- 计算开销：仅增加2.8%训练时间
- 超参数鲁棒：c_d和c_w在宽范围内性能稳定
- 消融：3D RoPE和ITC各自有贡献，组合效果最佳

## Value
方法简洁优雅，insight明确（token persistence），即插即用无需改变训练。在RL世界模型的4个benchmark上全面SOTA，效果convincing。但应用场景限于离散token-based的RL世界模型（2D游戏环境），与视频生成/3D世界模型方向距离较远。最优传输的计算开销在高分辨率场景可能成为瓶颈。ICML 2026录用。
