# Enhanced Reasoning via Robust Logic and Unary Relational Integracode

## Insight
通过将文本预处理为显式的一元关系表示（Unary Relational Integracode），使实体间关系变为PAC可学习的k-DNF公式，从而增强LLM的逻辑推理能力。

## Motivation
LLM在复杂关系推理上存在困难，Valiant认为这是因为原始文本中关系信息隐含在上下文中，不利于学习。通过增加显式的关系标记（augmented tokens），可以将关系规则转化为更简单的可学习形式。

## Method
- **Robust Logic框架**：定义实体上的关系规则，用Robust Logic的语义处理噪声和不确定性
- **Unary Relational Integracode (URI)**：将多元关系展开为一元谓词+辅助标记，使得关系推理可归约为k-DNF学习
- **理论贡献**：证明在URI预处理后，关系规则的学习复杂度从指数级降为多项式级
- 纯理论论文，无实验验证
