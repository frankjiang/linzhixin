# The World Model Remembers, the Actor Forgets: Dream Rehearsal for Continual Model-Based RL

## Insight
这篇的 insight 很强：在 never-clear replay 的 DreamerV3 continual RL 中，遗忘不是 world model 的记忆问题，而是 actor 读取/保持行为的 channel 问题。作者用组件级 probes 发现 reward head、critic、termination 和旧任务状态上的信号仍在；但 actor 行为崩了。进一步在冻结 world model 且相同 imagined rollouts 下对比，RL-in-imagination 不能恢复旧技能，而 supervised self-imitation 可以，证明失败集中在 policy-gradient channel。

## Motivation
continual model-based RL 通常假设保护 world model accuracy 就能保持旧任务能力，因此使用 never-clear replay、distribution-matched replay 或 world-model augmentation。但标准 return 只看行为，无法区分 world model 忘了还是 actor 忘了。本文先定位哪一部分忘，再提出从 world model 的 dreams 中持续重教 actor 的方法。问题对 Dreamer 类隐式 world model 很关键，因为它挑战了“模型记住即可”的默认路线。

## Method
实验基于 DreamerV3 MiniGrid，world model 约 17M 参数、actor 约 1.8M，任务链包括 DoorKey、SimpleCrossing、LavaGap、MultiRoom，扩展链到 8 个任务。作者先用组件探针测 reward discrimination、critic value、continuation、latent drift 和 frozen actor snapshot。随后做 recovery race：冻结最终 world model，从旧任务 buffer states 开始 imagination，只训练 actor；比较标准 Dreamer actor-critic 更新和 dream self-imitation。dream self-imitation 采样当前 actor 的想象轨迹，用冻结/在线 reward-value-continuation heads 评分，behavior-clone top 25%。正式方法 Dream Rehearsal 在每个新任务训练 chunk 后，对每个旧任务做 50 次 dream imitation 更新，无 task labels、无新增参数、无冻结 policy。关键评分规则是 realized-first：真实在梦中达成 reward 的轨迹优先于 critic 的乐观 value promise，并用 continuation probability 避免 post-terminal latent 污染。

## Experiment
plain never-clear replay 四任务链 0/3 seeds 通过，SimpleCrossing 稳定遗忘；reward discrimination retention ratio 在该任务约 0.99/1.06/1.01，termination discrimination 0.95-1.0，说明 world model 信号仍在。冻结 world model 后，RL-in-imagination 0/3 恢复，且有 seed 从 0.84 又掉到 0.38；dream self-imitation 3/3 在 2k-7.5k imagination-only updates 内恢复，零环境交互。训练中 interleaved dream rehearsal 四任务链 3/3 通过，SimpleCrossing 平均约 0.815；八任务链也 3/3 通过。与 matched real-episode cloning 比，dream rehearsal 在 SimpleCrossing 上平均 0.815 vs 0.684，paired difference +0.131，bootstrap 95% CI [0.073,0.238]。评分器消融显示 naive/post-terminal 或 survival weighting 会导致 AUC 接近随机或反向，realized-first gauge 可把 AUC/top-quartile purity 提到 1.0。

## Value
对隐式世界模型很有启发：world model 不只是 planning 模块，也可作为行为记忆库；但把模型知识转回 actor 的训练通道可能比模型记忆本身更脆弱。它提示 continual Dreamer 类系统可以少做参数隔离，多做基于 imagined trajectories 的稳定监督回放。最大待解决问题是能否从 MiniGrid 扩展到高维视觉、连续控制和真实机器人，并处理探索不足。

## Strengths
组件级定位非常扎实，报告了被推翻的假设和 scoring bugs；recovery race 的对照很干净，同一冻结 world model 和同一 imagined data 下分离 RL channel 与 supervised channel；dream grading 的失败模式分析具体，realized-first rule 有明确机制。

## Weaknesses
所有核心结论都在 MiniGrid、17M world model、n=3 seeds 和固定任务链上，外推风险大。仍依赖 never-clear raw replay buffer，解决的是 actor forgetting，不解决探索和无旧状态起点的问题。Dream rehearsal 成本随旧任务数线性增长；评分器依赖 world model 的 reward/value/continuation 质量，在复杂视觉任务中可能更难稳定。

## Future Work
作者明确说需要在更大领域验证；未来还应研究用生成或有界 starts 替代原始 buffer、解决 greedy exploration 下无法 bootstrap 的任务，以及用 critic pessimism、variance clipping、entropy schedules 等干预解释 RL channel 不稳定的机制。

## Rating
