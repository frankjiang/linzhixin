# EgoCS-400K: An Egocentric Gameplay Dataset for World Models

## Insight
论文的 observation 是交互式世界模型需要 video-action-language-state-event 对齐数据，而 web video 缺动作/状态，机器人数据贵且窄，模拟器数据又常缺大规模人类交互轨迹。Counter-Strike replay demo 天然保留人类动作、相机、状态、事件，并可重渲染为第一人称视频，因此可作为规模化中间 testbed。

## Motivation
解决的是互动世界模型的数据瓶颈，尤其是第一人称 action-conditioned future prediction 和 state/event-aware rollout。同行数据集如 Ego4D、EPIC-KITCHENS、WebVid、MineRL、MineDojo、Plaicraft 各有动作粒度、状态可追溯性、视觉质量或规模限制。该问题对视频世界模型训练很关键。

## Method
EgoCS-400K 从公开职业 CS:GO/CS2 match demos 构建。用 DemoParser2 解析 player state、view direction、movement、keyboard/mouse、weapon usage、game events、round context，并从同一 trajectory 渲染 clean first-person videos。数据层级包括 round-player video、segment、protected action chain、atomic action、per-tick state trace。VLM caption 由 replay-derived priors 约束，输出 strict JSON，包括 scene_draft、long_prompt、confidence、flags。

创新主要是数据工程和监督对齐，不是模型方法。

## Experiment
论文以数据统计和定性样例为主：超过 1,000 场比赛、40,000 轮、400,000 first-person videos、10,000 小时、13 张地图、每轮 10 个玩家视角，平均约 90 秒。展示了四秒片段中视频帧、键鼠轨迹、action timeline 和生成 prompt 的同步。没有训练具体世界模型或报告下游 benchmark 数值。

## Value
对用户的视频世界模型方向很相关：它提供了密集动作、相机、状态、事件对齐的第一人称数据，适合研究 action-conditioned rollout、长时记忆、部分可观测和多智能体动态。局限是 CS 领域强、战术/武器行为偏置大，缺少真实物理操作、触觉、可变形物体和日常任务。

## Strengths
亮点是对用户的视频世界模型方向很相关：它提供了密集动作、相机、状态、事件对齐的第一人称数据，适合研究 action-conditioned rollout、长时记忆、部分可观测和多智能体动态。

## Weaknesses
不足是 CS 领域强、战术/武器行为偏置大，缺少真实物理操作、触觉、可变形物体和日常任务。
