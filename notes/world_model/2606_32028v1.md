# DVG-WM: Disentangled Video Generation Enables Efficient Embodied World Model for Robotic Manipulation

## Insight
核心 insight 是把机器人视频世界模型中的“动力学预测”和“高清视觉合成”解耦。观察是：低层接触动力学需要长时序推理，高清纹理合成需要大模型和高分辨率扩散，二者绑在一起会导致推理慢或接触细节粗糙。论文用 preview-refine 两阶段和消融证明：低分辨率 preview 学到接触轨迹，高分辨率 refine 负责细节恢复，二者合起来比单阶段更稳也更快。

## Motivation
论文解决语言指令条件下机器人操作的未来视频预测与动作规划问题。已有视频世界模型直接生成原分辨率未来帧，迭代规划时推理太慢；若降低分辨率，又容易丢失抓取、接触、抽屉拉动等关键细节。这是具身世界模型的关键问题，因为视频预测要能转化为可执行动作，而不是只好看。

## Method
DVG-WM 使用 3D causal VAE 把 49 帧视频压到 latent。第一阶段用 CogVideoX-5B + LoRA 在 256x384 生成低分辨率动态 preview；第二阶段用较小 CogVideoX-2B 在 480x720 refinement。关键技术包括：用 flow matching 从上采样低清 latent 直接映射到高清 latent，只需少量 NFE；用 latent degradation 而非 pixel degradation 训练 refinement，迫使模型重新生成接触区域细节；再接一个 vision-only Diffusion Policy action expert，把预测视频转成动作。创新属于有效系统组合，关键点清楚，但主要依赖现成视频扩散与策略模型。

## Experiment
实验在 LIBERO 和两套真实机器人平台上做。视频质量指标包括 PSNR、SSIM、LPIPS、FVD、object accuracy；真实任务还用 Grounded SAM 的机器人 mask-IoU 和执行成功率。LIBERO 上 DVG-WM 达到 PSNR 20.019、LPIPS 0.120、FVD 152.36、object accuracy 89%，推理 88.7s，比 LVP 快 3.97x。真实任务中视频质量优于 CogVideoX，九个真实操作任务平均成功率 62.2%，高于 CogVideoX 的 34.0%。消融显示 latent degradation、flow matching、preview/refine 两阶段和 K=4 refinement 都有贡献。

## Value
对视频/具身世界模型很有参考价值：它把“可规划的动态”和“可看的高清”明确拆开，给高效机器人视频世界模型一个务实方向。局限是动作专家仍依赖模仿学习数据，语言指令到可执行控制的泛化还没有被充分证明；方法也偏工程组合，范式性不如 JEPA/Dreamer 一类基础路线。
