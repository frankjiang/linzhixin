# AGI Maze Prediction Datasets: A Compact Benchmark for Learning World Dynamics with Transformers

## Insight

有。论文观察到：在同一组 source-maze-disjoint 数据上，标准 byte Transformer 会随地图尺寸、动作长度和动力机制迅速增加样本需求；增加无结构 latent cells 虽能把训练集拟合到 100%，验证集却不升反降。由此推论，世界状态所需的不是一般意义上的额外容量，而是与环境拓扑对齐、可持续更新的工作记忆。

作者用两项受控设计支撑该推论：一是无结构 auxiliary-memory 对照，二是更严格的 visual-only readout——目标解码器看不到原始地图和动作，只能读取动作逐步更新后的二维 latent frame。后者在 3x3-keys/4-step 和 4x4-keys/2-step 上均达 1.000 验证准确率，在 3x4-rivers/2-step 上达 0.973。证据说明二维结构是有效归纳偏置，但尚未证明 latent cell 与真实格点/物体一一对应。

## Motivation

论文要解决“序列模型能否在内部维护并更新结构化世界状态”的可测量问题。LLM 通常把地图、笔记或程序放在上下文/工具侧，标准 VLA 也多把视觉编码成一维 token；这些接口能保留信息，却不保证网络具有可直接计算的二维动态状态。现有大型环境又混入感知、控制和优化等变量，难以判断失败究竟来自状态表示还是别处。

作者因此把 AGI Maze 改造成低成本监督预测基准，隔离单步动力学、多步组合和文本观察预测。内部状态是世界模型的必要条件，问题本身关键；但迷宫规模很小、规则离散且地图显式给出，只能作为“world dynamics 的 MNIST”，不能代表真实视频或具身世界建模。

## Method

数据来自程序生成的 ASCII 迷宫，含 3x3/4x4/4x5 keys 与 3x3/3x4 rivers；训练和验证按源迷宫完全分离。三个任务为：

- 单步预测：输入当前完整地图和一个方向动作，输出下一位置；共 19,993 条，单族训练 1,875-6,758、验证 480-617。
- 固定时域预测：只给初始地图与 1/2/4/8 个动作，不给中间状态，输出终点；覆盖 3x3-keys、4x4-keys、3x4-rivers，每个 family-horizon 有 4,000 训练和 1,000 验证样本。
- 文本轨迹预测：预测每个动作后的 `<TXT>` 环境观察；3x3-keys 有 4,000/1,000 条训练/验证轨迹，每条 10-50 步。评测时保留此前真值观察以做 teacher forcing，但不提供当前位置或完整隐状态。

标准基线是从零训练的 decoder-only byte Transformer，仅在目标 `<POS>` 或 `<TXT>` 字节上计算 NLL。无结构 memory 对照在文本流旁增加一组 learned cells 和第二个 Transformer。核心 pseudo-video 模型把初始 ASCII 字符按行列放入二维 canvas，叠加 character/row/column embedding；每个完整动作由因果 action encoder 形成写入上下文，经空间注意力和逐 cell 的因果时间注意力更新连续 latent frame。full-text readout 仍允许文本流 cross-attend 当前 frame；visual-only readout 则用独立目标解码器，只能 cross-attend 最终 frame。训练没有中间地图重建、位置标签或 frame 监督，创新主要在“任务拓扑对齐的 latent workspace + 信息瓶颈对照”，而非新的学习目标。

## Experiment

位置任务报告目标字节 NLL 与 greedy exact-target accuracy；文本任务报告单个观察 span exact 和整条 depth-limited trace 全对率。

- 单步 byte baseline：3x3-keys 为 1.000；4x4-keys 为 0.9887；4x5-keys 从 2,215 条时的 0.8253 随 3 shards/6,758 条升至 1.000；3x4-rivers 从 2,051 条的 0.8321 升至两 shards 的 0.9354，混入相关 family 后用 10,508 条仅到 0.9557，跨 family 增益约 2 个点。
- 固定时域 byte baseline：3x3-keys/4-step 从 2,000 条的 0.845 升至 4,000 条的 0.901，混合 2/4/8-step 共 12,000 条为 0.979；4x4-keys/2-step 用 20,000 条混合数据为 0.951；3x4-rivers/2-step 同规模为 0.881。
- 无结构 memory 在上述三个混合任务分别为 0.975、0.886、0.868，均低于 byte baseline 的 0.979、0.951、0.881；其中 3x3 训练准确率已达 1.000，说明问题不只是拟合能力。
- pseudo-video 的 visual-only readout 分别达 1.000、1.000、0.973；full-text readout 为 0.978、0.976、0.905。严格 readout 反而最好，是论文最有说服力的结果。
- 3x3-keys、8-step 文本轨迹用 4,000 条训练时，byte baseline 的 span/整轨迹 exact 为 0.9809/0.869，visual-only 为 0.9996/0.997；余错集中在有无钥匙时的宝箱交互。

实验是诊断性小规模 sweep，而非参数、深度和训练预算严格匹配的全面比较；验证集同时用于模型选择，没有独立隐藏测试集。

## Value

论文对隐式/视频世界模型最直接的启发是：latent state 的形状和更新算子本身就是归纳偏置，不能把“更多 memory token”视作结构化状态的替代品。visual-only 信息瓶颈也是检查模型是否真正使用世界状态的实用实验设计。后续可把二维 workspace 扩展到对象图、3D memory 或视频 latent，并用 probe/干预验证其因果语义。

价值边界同样清楚：当前结果证明的是小型符号地图上的规则迁移，不是开放世界理解；100% source-disjoint validation 也不等于跨尺寸、跨机制或长时域系统泛化。

## Strengths

- 任务定义小而透明，source-maze-disjoint split 与整目标 exact match 能排除一部分布局记忆和“字节大致正确”的假象。
- 同时比较纯序列、无结构额外记忆、二维结构记忆，并用 visual-only decoder 强制信息经过 workspace，因果链比普通性能对比更清楚。
- 三种任务分别覆盖单步转移、多步无中间监督的状态组合、以及文本观察生成，能定位能力随 horizon/机制增长的退化。
- 作者明确限制结论，不把 latent frame 称为可解释地图，也不把迷宫成功等同于通用世界模型。

## Weaknesses

- 只有 3x3 到 4x5 的显式 ASCII 地图、四方向离散动作和少量 keys/rivers 机制；没有像素感知、连续动力学、真实部分可观测性或控制闭环。
- 模型宽度、层数、dropout 与训练时长按任务调整，论文也承认不是 exhaustive、parameter-matched sweep；pseudo-video 的优势可能混入计算量和架构容量差异。
- 评测用可见验证集做模型选择，未提供隐藏测试；所谓迁移主要仍在相关迷宫 family、短 horizon 内，最长 8 步。
- 没有 probe、可视化或 cell intervention 证明后续 latent frame 保持几何/对象语义，因此“语言 grounding”仍是由性能推断的较宽主张。
- 文本轨迹采用 teacher forcing，0.997 的整轨迹指标不反映自由滚动时前序生成错误的累积。

## Future Work

作者提出做严格参数匹配比较、增加更长 horizon、更多地图尺寸与机制、部分可观测任务；对 latent memory 做 probe、拓扑/时间更新消融和选定 cell 的因果干预；混合训练“有中间地图”和“只有文本”的轨迹，测试从文本构造二维状态及从状态生成/校验文本；最终扩展到更丰富视觉环境和 LLM 架构。

## Rating

创新度评分：3/5 - 基准与二维动态 workspace 的组合有明确诊断价值，visual-only 对照也扎实；但环境很小，架构比较未参数匹配，尚属有意义的结构归纳偏置验证。
相关度评分：2/3 (Related) - 结构化 action-conditioned latent state 对隐式世界模型有直接借鉴，但论文只是显式 ASCII 小迷宫上的监督预测中间测试床，并非视频、3D 或 JEPA/Dreamer 模型本身。

## TL;DR

用迷宫基准显示二维动态工作记忆胜过通用潜变量，验证结构化隐式状态的价值，可选读。
