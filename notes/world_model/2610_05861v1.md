# Imagine to Act: High-Fidelity Data Synthesis via Image Editing World Model for Scalable GUI Agent Training

## Insight
手机界面的变化通常局限于局部元素，直接以动作预测整张截图存在较强歧义。作者观察到，把真实前后帧的变化描述成“新增/删除元素”等语义差分后，图像编辑模型能保持未变区域并生成下一帧：去掉差分文本，单步编辑准确度从 68.13 降至 21.56。这个消融支持“先规划语义变化、再生成像素”的分解；它并未证明模型能仅凭截图和动作自主推断应用逻辑。

## Motivation
GUI 智能体需要大量带动作的视觉轨迹，而人工演示和真实设备探索成本高；文本或 HTML 环境模型又丢失图标、布局等像素细节。论文尝试用截图编辑合成可供智能体训练的轨迹。问题对 GUI 智能体重要，但与物理场景的视频、3D 或隐式世界模型只有方法上的间接联系。

## Method
1. 从 AndroidControl 的动作及前后截图，用 GLM-4.7v 提取触发操作、界面新增/删除元素和下一步所需元素，形成结构化差分文本。
2. 在 `(当前截图，差分文本) → 下一截图` 配对上，以整流流目标 LoRA 微调 FLUX.2-Klein 4B/9B 图像编辑模型；生成分辨率为 672×1536。
3. 合成两类训练样本：保持文字与布局的单帧外观改写；以及由大模型 App Designer 先写任务步骤和界面元素，再提取差分文本、递归编辑截图的多步轨迹。另用 VLM 以 90/100 的置信度阈值过滤不可执行步骤，最后微调 Qwen3-VL 2B/4B/8B 智能体。

创新主要是把现成图像编辑器、语义差分和轨迹合成接成 GUI 数据管线。所谓世界模型的视觉部分需要外部给出下一状态的语义差分；测试时并无已验证的、仅从当前图像与动作预测差分的独立模型。

## Experiment
- **图像质量**：与五种图像编辑基线及未微调 FLUX.2 比较，GLM-4.7v 从准确、完整、上下文和视觉保持四项打分。9B 模型四项为 68.13/72.27/75.87/66.55，未微调 9B 为 62.44/65.17/68.95/59.43；十步递归得分 48.84，对照未微调 9B 为 29.61。图示显示局部文字和布局保持较好。
- **智能体在线任务**：仅用合成数据训练后，8B 在 AndroidWorld Pass@1 从 39.37% 升至 43.82%，MobileWorld Pass@3 从 11.40% 升至 21.93%；2B 的 AndroidWorld Pass@1 从 22.56% 升至 31.61%。
- **数据消融**：固定 4B，AndroidWorld Pass@1：基础模型 30.17%，仅合成 39.37%，仅真实轨迹 42.67%，真实加多步生成 44.83%，真实加外观增强 47.41%，三者合用 48.28%。多步生成对较难任务并非普遍有益：Hard 成功率由仅真实数据的 13.2% 降为混合数据的 10.5%。
- **定位与长程误差**：AndroidControl-Curated Hard 的 4B Box Acc 从 77.0% 降至 64.7%。在 1,599 条想象轨迹的缓存中，第一步到第十步的逐步过滤通过率仍约 78%–85%，但到第十步的整轨迹存活率仅 9.3%。论文仅报告每配置一次训练运行。

## Value
对研究的启发是：将高层状态变化和像素生成分开，可能提升局部编辑的可控性；但必须评测动作到语义变化的预测、长程状态一致性，以及合成数据是否真的改善下游策略。本文适合作为视觉轨迹合成案例，不宜把有语义差分输入的截图渲染成绩直接理解为自主动作条件世界建模能力。

## Strengths
- 同时比较图像编辑质量与实际智能体成功率，并做数据来源消融，能看出外观增强比多步合成更稳健。
- 如实报告 Hard 任务、坐标定位退化和十步轨迹存活率，展示下游收益的边界。
- 附录公开训练配置、提示词、筛选规则和失败案例，便于复核管线。

## Weaknesses
- 训练差分文本来自真实前后帧；想象轨迹则由 App Designer 先写出后续界面。对新动作的真实下一状态预测能力没有被单独验证，因此“世界模型”主张偏强。
- 合成样本单独训练的效果低于真实轨迹单独训练；Hard 任务、密集控件和精确坐标定位出现退化，长期递归误差明显。
- 图像质量评审与训练差分提取共用 GLM-4.7v，评审独立性有限；固定随机种子且每配置只有一次训练，缺少方差估计。

## Future Work
作者建议校准任务结束判断并核验后置条件，用边界框监督保持控件位置，在长轨迹中用真实关键帧重新锚定，并以双向一致性检查剔除伪造转移；结论也提出让智能体反馈所需的关键状态转移，以改进生成模型。

## Rating
创新度评分：2/5 - 语义差分驱动的 GUI 图像编辑与两类合成数据形成实用组合，但核心模型和技术路线主要沿用现有组件。
相关度评分：1/3 (Tangential) - 视觉状态递归生成可供类比，但领域是手机 GUI，且缺少独立的动作到状态语义预测，与目标世界模型方向仅间接相关。

## TL;DR
把界面转移拆成语义差分与像素编辑，合成数据提升手机智能体，但长程漂移和动作依赖限制明显；视频世界模型方向可选读。
