# WorldFoundry: Towards Unified Infrastructure for World Intelligence

## Insight
世界模型评测常把「模型已收录」「接口能运行」与「按官方协议完整复现」混为一谈，也常凭视觉质量推断世界一致性。作者据此把可追溯证据作为基础设施的一等对象，主张考察干预后状态是否持续、再观测是否修正状态，才可检验闭环世界建模。此为有启发的操作性定义与工程原则；论文没有用定量实验验证它是唯一或充分的定义。

## Motivation
视频、3D/4D、交互环境与具身策略的运行时、表示和评测协议彼此割裂，导致同一指标未必可比较、复现实验依赖隐含设置。WorldFoundry 试图让异构模型在保留原生输入/输出语义的同时，统一发现、执行、保存产物、重评分和审计。问题对团队搭建世界模型评测平台很实际。

## Method
提出状态推断 q(z|历史)、动作条件转移 p(z'|z,a)、输出 g(o|z') 三项功能，并以「持久状态—干预影响—观测反馈」闭环界定生成式世界模型。系统由多界面（TUI/CLI/Web/Python/MCP）、模型与基准清单、运行器、可序列化请求/结果、带 URI/哈希/元数据的产物引用、评测器及证据 scorecard 组成。模型适配 Operator 负责原生参数转换，Pipeline 管理加载与运行时；请求和结果、失败记录、配置及逐样本指标落盘，产物可在不重新推理时重评分。区分诊断性、可比基准和严格复现三档证据。贡献主要是工程架构与协议整合，并无新的世界模型学习算法。

## Experiment
附录列出 270 个模型条目（视频 64、世界模型 109、3D/4D 34、具身 53、托管 API 10）、74 个基准与 62 个指标，称所有模型 runner 均完成各自参考路线验证；此验证仅涵盖所用配置，不等于逐项完整复现。正文展示视频生成、交互世界、3D 重建及 OpenVLA/LIBERO 的定性案例：后者三任务中一次成功、两次达 520 步上限。评测强调执行可行性和产物追溯，没有跨方法排名，也未给出统一的时延/显存开销、复现成功率或大规模闭环一致性统计。硬件测试主要在 A100/H100。

## Value
对建立视频/3D/具身世界模型实验平台、管理产物和评测可信度有直接参考价值；尤其值得吸收「场景回访」与「动作改变的状态是否保留」分开测的思想。若团队正在建设评测基础设施，值得精读第 3–5 节；算法研究可选读。

## Strengths
覆盖多类模型与评测协议；明确原生语义和统一外层契约的边界；把失败、样本覆盖、运行配置、证据等级纳入结果，避免仅凭目录规模或个别演示宣称可复现。

## Weaknesses
核心成果是基础设施汇编与定性演示，缺少接口额外开销、集成成本、跨界面一致性和官方结果复现率的量化报告。270 个 runner「验证」的配置范围各异，不能推断所有基准都完整可用。作者对世界模型的闭环定义有规范性，可能排除有价值的开放环视频预测模型；所提出的干预持久性和反馈同化尚未形成实际检验基准。

## Future Work
作者明确提出：评测干预效果持久性与反馈同化；扩大硬件验证，做运行时画像、自动后端选择、缓存和量化；加入数据准备与训练，追踪数据、检查点、推理和评测全链路的一致性。

## Rating
创新度评分：2/5 - 大范围工程集成与证据管理实用，但核心抽象和模块多承接已有平台，缺定量验证。
相关度评分：2/3 (Related) - 直接服务视频、3D及交互世界模型的运行与评测，未提出新的世界模型本体。

## TL;DR
以统一运行和可追溯证据管理视频、3D与交互模型，提出闭环评测框架；建设世界模型评测平台的团队值得精读。
