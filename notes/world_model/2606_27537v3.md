# MemoBench: Benchmarking World Modeling in Dynamically Changing Environments

## Insight
核心 insight 是：视频生成模型的“记忆一致性”不能只测目标持续可见时的一致，也要测目标消失期间是否在内部继续更新状态。MemoBench 的 disappear-and-reappear 设计把 object permanence 与 dynamic state evolution 结合起来，暴露出 camera-conditioned 模型也不一定有持久世界状态。

## Motivation
世界生成模型被期望模拟动态环境，但现有 benchmark 多评估画质、物理常识、镜头控制或持续可见对象的一致性。真实 embodied agent 经常转头/移动后目标离开视野，期间对象仍在融化、燃烧、移动、溶解；重新看到时需要恢复更新后的状态。这是视频世界模型的核心能力缺口。

## Method
MemoBench 包含 360 个 GT clips：196 个 UE5 合成场景和 164 个真实物理过程，均为 Visible-Disappear-Reappear 三阶段，并提供 camera trajectories/depth/pose。评估分两类：自动指标包括 Visual Quality、Motion Smoothness、Object Identity Consistency、Geo3D Consistency、Object Reappearance Score、PSNR/SSIM/LPIPS、Camera Controllability、ImageReward；VQA 指标由 Yes/No 问题覆盖 Instruction Following、Object & Background、Continuity of Memory、Physics Adherence。ORS 用 SAM-3 在 reappear phase 根据目标文本检测对象，Camera Controllability 用 MapAnything 估计轨迹旋转误差。

## Experiment
评估 10 个开源模型：CI2V 包括 LingBot-World、Wan2.2、FantasyWorld、HunyuanWorldPlay、HunyuanGameCraft；3D/NVS 包括 Matrix-Game 2.0、Stable Virtual Camera；I2V 包括 Open-SoRA、LTX-Video、CogVideoX。结果显示无模型 ORS 超过 0.6；HunyuanWorldPlay 在 CI2V 中 ORS 最高 0.582，LTX-Video 的高一致性/ORS 部分来自几乎不移动镜头。VQA 中 HunyuanWorldPlay memory 55.6 较高，LingBot-World instruction following 64.2 最高，但所有模型都不能同时实现强 camera control、强 ORS 和高视觉质量。人类-VLM GT VQA agreement 92.9%、kappa 0.85。

## Value
这是高相关视频世界模型 benchmark，明确指出当前模型缺少 persistent state representation。对研究的启发：评估世界模型时必须同时约束相机运动和目标重现，否则静态视频会“作弊”；object permanence 应该成为训练目标或架构记忆机制。局限是 ORS 依赖 SAM-3 检测，真实物理状态更新的精细定量仍有限，benchmark 不是 action-conditioned closed-loop。

## Strengths
亮点是对研究的启发：评估世界模型时必须同时约束相机运动和目标重现，否则静态视频会“作弊”；

## Weaknesses
不足是这是高相关视频世界模型 benchmark，明确指出当前模型缺少 persistent state representation。
