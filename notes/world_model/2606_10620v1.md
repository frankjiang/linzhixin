# Can Image Models Imagine Time? ImageTime: A Novel Benchmark for Probing Visual World Modeling Through Spatiotemporal Consistency

## Insight
核心观察：当前图像生成模型能生成高质量单帧静态图像，但是否真正理解视觉世界随时间演变的过程（即是否具备隐式的 world model）仍是未知。作者提出一个关键推论——**时空一致性（spatiotemporal consistency）可以作为图像模型是否具备 world-model-like behavior 的行为探针（behavioral probe）**。具体证据：让模型在单张图中生成 2x2 四关键帧运动表（initial state / action onset / transition / final state），发现即使最强模型（GPT Image 2, Overall mean 7.86/10）也在因果前置条件、交互几何、约束推理等高层能力上显著退化，暴露出"能画场景但不能维持过程"的根本短板。这说明视觉质量 (C9) 与过程一致性 (C4-C6) 是可分离的两个维度，静态图像先验不等于时序世界理解。

## Motivation
**问题**：现有 text-to-image 评测（DrawBench, T2I-CompBench, GenEval 等）主要衡量单张图像的正确性（对象、属性、空间关系），无法揭示模型是否能维持同一视觉世界在多个有序状态间的一致性。实际应用（故事板、分镜、视频预可视化、参考图引导编辑）要求模型在多状态间保持身份、空间关系和因果顺序。

**同行方案**：(1) 视频评测（VBench, EvalCrafter, WorldModelBench）关注连续帧的运动/光流/物理合理性，但引入了插值/帧间平滑等视频特有干扰；(2) 多图/故事板评测（VinaBench, Story2Board）偏叙事连贯性，缺少对状态谓词、因果约束的细粒度分解；(3) 推理导向评测（R2I-Bench, Envision）关注世界知识推理，但不评估有序多状态转换。

**是否关键**：中等重要。该问题填补了"静态图像评测"和"连续视频评测"之间的空白地带，为图像模型的 world modeling 能力提供了一个轻量且可控的诊断工具。但本质上仍是 benchmark 工作，不涉及模型改进。

## Method
**整体流程**：
1. **任务定义**：给定动作描述（+可选参考图），模型生成一张 2x2 图像，包含 t1-t4 四个时间有序的关键帧。评估对象是空间/时间/因果一致性，而非视频逼真度。
2. **渐进能力树（Progressive Capability Tree, L0-L6）**：七级递进——L0 静态接地 → L1 身份/锚点 → L2 空间转换 → L3 对象状态转换 → L4 交互与可供性 → L5 因果过程 → L6 约束/反事实推理。高层依赖低层，形成能力阶梯。
3. **数据构建**：22 个领域 x 375 个动作概念 x 每概念 2 变体 = 750 个 benchmark case。人工主导 + LLM 辅助扩展，GPT Image 2 生成 pilot 图像后人工修复 170 例。
4. **结构化 VLM-as-Judge 评估**：GPT-5.5 作为评分器，对每张生成图输出 C0-C9 能力分 + D0-D14 诊断子分。C 分定位高层能力缺口，D 分定位具体视觉证据。设计保守封顶规则（如布局失败则 C0=0 并限制后续分数）。
5. **指标聚合**：树节点分 T_L = 0.5*mean(C_L) + 0.5*mean(D_L)，Overall mean = 0.5*C_mean + 0.5*D_mean。

**创新程度**：中等。核心创新在于"四关键帧协议"这一评测接口设计（介于单图和视频之间的甜点），以及 L0-L6 渐进能力树的分解方式。技术上是 benchmark + VLM judge 的标准范式，无模型创新。

## Experiment
**评测模型**（8个，prompt-only）：GPT Image 2, Nano Banana 2, Seedream 5.0 Lite, FLUX.2 Pro, Z-Image-Turbo, Qwen-Image-2512, HunyuanImage-2.1, SDXL。

**主要发现**：
- **排名**：GPT Image 2 (7.86) > Nano Banana 2 (7.45) > Seedream 5.0 Lite (7.16) > FLUX.2 Pro (6.10) > Z-Image-Turbo (5.41) > Qwen-Image-2512 (5.32) > HunyuanImage-2.1 (4.98) > SDXL (1.57)
- **能力树退化**：弱模型在 L4-L6（交互/因果/约束）显著崩塌；强模型（GPT Image 2）L0-L6 较平稳，但仍有退化
- **C 分 vs D 分**：强模型 C/D 接近，弱模型 D 略高于 C，说明它们能局部产生合理视觉证据但无法维持全局过程一致性
- **典型失败模式**：身份漂移、场景漂移、跳过中间状态、提前到达终态、对象复制、因果顺序违反、不可能的接触几何
- **品类分析**：22 个领域中，household/kitchen/gardening 较容易，systems/constraints/quantity-focused 较难
- **成本-性能**：低成本模型已进入基本时空一致性区间，但在因果/约束维度仍显著落后

**不足**：无人类评估对照（完全依赖 GPT-5.5 judge）；无消融实验验证能力树设计或评分规则的必要性；未评测视频生成模型作为对比基线。

## Value
**价值评估**：作为 benchmark 工作，ImageTime 提出了一个有价值的中间态评测协议——用四关键帧避开了视频评测的复杂性，同时比单图评测更能暴露过程建模能力。L0-L6 能力树和 C/D 双轨评分提供了较好的可解释性。

**对我们的启发**：
1. "四关键帧"协议可借鉴用于评估 video world model 的关键状态预测质量（而非逐帧评估），尤其适用于 action-conditioned world model
2. 渐进能力分解（静态→身份→空间→状态→交互→因果→约束）为 world model 评测提供了一个有参考价值的层级框架
3. 实验揭示的"视觉质量与过程一致性可分离"现象，对隐式 world model（如 JEPA/Dreamer）的评估设计有参考意义——需要区分"感知重建质量"和"动力学预测质量"

**待解决问题**：
- 完全依赖 VLM judge（GPT-5.5），评分可靠性未经人类对照验证
- 仅评估图像生成模型，未与视频模型对比，难以回答"图像模型 vs 视频模型谁更理解时间"
- 不涉及模型改进方向，缺少如何利用 benchmark 信号提升模型能力的讨论

## Strengths

## TL;DR
提出 ImageTime 四关键帧评测基准，通过 L0-L6 渐进能力树诊断图像生成模型的时空一致性，发现即使最强模型也在因果/约束推理上退化。纯评测工作，与 video/3D world model 关联有限，可选读。
