# SV-WAM: An Efficient Surround-View World-Action Model for End-to-End Autonomous Driving

## Insight

论文的关键 observation 是：自动驾驶需要六相机上下文，但部署时真正昂贵的是反复生成六视角未来，而不是读取六视角历史。若用非对称因果 mask 令动作 token 只能看历史条件与动作、未来视频 token 可反向看动作，则联合训练因子化为 `p(A|history) p(Z_future|history,A)`；视频分支仍通过共享参数提供动态监督，却不成为动作前向依赖。作者以注意力结构说明这一性质，并实测挂载/移除未来视频 token 后轨迹在数值精度内一致；组件消融则给出经验支持。

第二个 observation 是，轨迹点监督不直接约束车辆完整 footprint。把预测动作经可微 LQR/自行车模型展开，再在可行驶区域 signed distance field 上惩罚四角最危险的越界，可直接优化 NAVSIM 中乘法式 DAC 失败项，且不增加部署成本。

## Motivation

已有 driving world model 常在推理中联合生成未来视频和动作，为控制延迟而只输入前视相机；这会丢失变道、汇入、转弯时的侧后方车辆。直接扩展为六路未来视频又会使视觉 token 与解码成本急剧上升。论文要解决“全向证据与实时规划不可兼得”的关键工程矛盾，并同时改善道路边界安全。

## Method

输入为 4 帧、2 Hz 的六相机图像与 8 维 ego state；每个时刻的六视图横向拼接，送入冻结的 Wan2.2-TI2V-5B 3D causal VAE，得到历史参考 latent。约 5B 的 DiT 同时对 12 个未来动作 token（每步 `Δx,Δy,Δyaw`）和 12 帧未来六视角 latent 做 rectified-flow 去噪。action-centered mask 规定：条件 token 仅内部注意，动作看条件与动作，未来视频可看条件、动作和未来视频；训练损失为动作/视频 velocity MSE。

DAC regularizer 先由 noisy action 与预测 velocity 恢复 clean action，经官方 LQR 和 11 维运动学自行车模型以 0.1 s 网格展开 60 个姿态；在 ego-centric signed distance field 上双线性采样四个车角，以 softplus margin 和 log-mean-exp 近似最大风险，加入总损失。推理时删除未来视频 token/输出头，仅对动作做两步去噪，并缓存历史条件 KV。创新是面向全向 driving WAM 的训练-部署依赖切断，加上可微 footprint 合规约束；基础 DiT、flow matching、VAE 与 LQR 均为既有组件。

## Experiment

模型在 NAVSIM trainval 上以 16×H800 训练 10k step、再 fine-tune 1k step，每阶段约一天。NAVSIMv2 navtest（12,146 场景）报告 EPDMS 91.0，高于表中 EponaV2/DriveLaW 的 88.9；同架构 C×1、C×3、C×6 分别为 89.3、90.5、91.0。组件消融从基础六视角的 83.1，加入未来视频监督升至 87.7，再加 DAC loss 为 90.1，最终微调为 91.0；DAC 相应由 93.4 升至 98.8。无 mask 时 2/5/10 步为 87.3/87.9/88.2，有 mask 为 91.0/90.9/90.8，支持动作路径已与视频噪声解耦。

单张 H20 的预处理输入到轨迹延迟为 341.6±2.1 ms，低于 PWM 552.3、DriveVLA-W0 514.9、Epona 1148.8 ms；去掉 mask 并保留视频分支为 848.0 ms。H800 上 action-only 约 176 ms，联合动作-视频约 776 ms。跨域零样本 nuScenes 的平均 L2/碰撞率为 0.89 m/0.16%；NAVSIMv1 为 90.2 PDMS。更难的 navhard 上仅 36.1 EPDMS，与 EponaV2 持平且低于 RAP 39.6，显示 headline 优势并不普遍。附录还给动作长度、DAC 权重、batch size、注意力与失败案例消融。

## Value

该设计说明“让世界模型帮助策略”不要求在部署时显式想象视频：通过依赖图约束，多任务动态监督可留在训练侧。这对机器人 WAM 与多视角 3D/视频模型同样可借鉴。可微执行器/footprint rollout 也示范了如何把任务安全指标变成训练约束。当前证据仍主要来自 benchmark，尚不能证明真实闭环可靠性或视频分支真的学到可泛化物理。

## Strengths

- 因果 mask 给出清楚的结构性保证，训练和推理接口一致，视频分支可机械删除而非近似裁剪。
- 组件、视角数、mask/步数和延迟消融较完整，收益来源比只报总分更可辨认。
- 同时报告 NAVSIMv2、NAVSIMv1、navhard、零样本 nuScenes、注意力可视化和失败案例，评价面较广。
- footprint-level DAC loss 与官方 tracker/地图语义对齐，且完整 PyTorch 重写保留梯度。

## Weaknesses

- 约 5B 模型仍需 16×H800 训练，所谓高效主要是相对视频生成支路；车载端吞吐、功耗和内存未验证。
- 没有 FVD、相机/几何一致性或未来状态预测指标，不能确认视频辅助任务本身是否是合格世界模型，而非一般多任务正则化。
- 主表混合不同视角、模态、训练设置与来源结果；六视角和大规模预训练骨干带来的优势难与方法贡献完全分离。
- NAVSIMv2 是 pseudo-simulation，nuScenes 是易受 ego-status shortcut 影响的 open-loop sanity check；没有真实车辆闭环测试。
- navhard 只追平一个 WM baseline、落后 RAP，且失败于歧义路形、暴雨信号灯与过度保守加速，交互和不确定性仍弱。
- DAC loss依赖训练时可行驶区地图与特定 LQR/车辆模型，对地图错误、不同动力学和无 HD map 场景的稳健性未知。

## Future Work

作者计划用更大、更丰富的真实驾驶数据提升稳健性与泛化，并用蒸馏、剪枝和量化得到适合边缘部署的轻量版本；还将从 benchmark 扩展到真实车辆闭环测试。值得进一步做视频监督质量/权重的严格消融、不同地图和动力学下的迁移，以及风险与不确定性建模。

## Rating

创新度评分：3/5 - 非对称 mask 与可微道路约束形成扎实的新组合并带来明显效率/性能收益，但核心范式已有训练侧视频监督先例，真实闭环证据不足。
相关度评分：3/3 (Core) - 直接研究六视角视频世界-动作模型、未来动态监督与高效控制部署，属于核心视频世界模型方向。

## TL;DR

用因果掩码把六视角未来视频留在训练侧，兼顾规划性能与低延迟，值得精读。
