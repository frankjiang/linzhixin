# Successive Capacity Growth: Task-Complexity-Driven Width and Depth Expansion for Vision Transformer Encoders in JEPA World Models

## Insight

观察：固定 ViT 编码器会在简单任务上过配、复杂任务上欠配；若扩容瞬间改变函数，在线试错又会破坏既有优化轨迹。论文推论：将增宽/加深构造成 function-preserving transformation，就可在 prediction-loss plateau 时先试训、无收益再连同 optimizer state 回滚，让任务而非预设架构决定容量。结构上，新 head 的输出投影置零、新 block 的 attention/MLP 输出置零，因此扩容前后映射不变；6 次检查报告 loss ratio=1.0、abs/CLS/block diff 全为 0（Algorithm 1、Table 4, pp. 5、8）。但“宽度对应低层语义、深度对应高阶语义”的解释仅由少量扩容行为支持，并非被严格证明。

## Motivation

LeWorldModel 使用约 5.7M 参数的固定 ViT-Tiny；作者认为不同状态维度的任务不应共享最大容量。已有 progressive growing、Net2Net、bert2BERT 和 transformer expansion 要么按预定日程增长、要么只给保函数算子，没有把“何时/向哪一维扩”交给 JEPA 的在线预测信号。这个问题对高效 JEPA 有价值，但当前论文把容量是否足够近似为短窗 prediction loss 是否停滞，问题定义仍较粗。

## Method

- 基于 LeWM：像素观测经 patch size 14 的 ViT 编码，predictor 由当前 latent 与 action 预测下一 latent；目标为三步 MSE prediction loss 加 λ=0.1 的 SIGReg。没有 stop-gradient，SIGReg 将投影 latent 约束为 isotropic Gaussian 以防 collapse。
- SCG 从 1 head、2 layers、d_model=64、283K 参数开始。若最近两个 epoch 的 prediction-loss median 相对前两个 epoch 改善不超过 2%，先尝试 width expansion；训练 2 个 test epochs，改善超过 2% 才保留，否则恢复模型与 Adam 状态，再试 depth expansion。两种都失败便永久标记 converged；成功后 cooldown 2 epochs。试验 epoch 不计入 50 个 effective epochs（pp. 4–5）。
- Width expansion 每次增加一个 64 维 head：复制首 64 维 patch/CLS/position、QKV 与 MLP 相关权重，新 head 输出投影和 projector 新输入列置零。Depth expansion 插入 identity-initialized block：attention output projection 与 MLP W2 为零，LayerNorm 为单位初始化。
- 作者用 SIGReg 解释新增维度能去冗余；以只看 `L_pred` 而非总损失避免 regularizer 波动触发扩容。

## Experiment

- 三个合成环境：Two-Room（2D、离散动作）、Push-T（5D、连续动作）、30-Object Dynamics（60D、连续全局力）；均 200 episodes×200 steps，只用 30% 数据，frame skip 5，4-frame 子轨迹。比较 Fixed Small 283K、Fixed Large 5.7M 与 SCG，3 seeds，50 effective epochs，单 RTX A6000（p. 6）。
- 主结果（平均 `L_pred`，Table 1, p. 7）：Two-Room 为 0.000547/0.000279/0.000362，Push-T 为 0.003775/0.003534/0.003059，30-Object 为 0.008368/0.006666/0.005080（Fixed Small/SCG/Fixed Large）。SCG 相对小模型改善 49.0%、6.4%、20.3%；30-Object 仅加一个 block 至 333K，论文据损失收益/新增参数比宣称约 56× parameter efficiency。
- 扩容高度依赖 seed（Table 3）：Two-Room 只有 seed 42 增宽 64→128；30-Object 只有 seeds 3072、123 加深 2→3，seed 42 在 50 epochs 内未 plateau；Push-T 三个 seed 均不扩容。即使“不扩容”，SCG 与 Fixed Small 同 seed 的最终损失仍不同，如 Push-T seed 3072 为 0.003934 vs. 0.003490。
- 保函数检查覆盖 2 datasets×3 seeds，增宽/加深的 ratio 均 1.0、绝对差 0；训练后新 head 与复制源的 cosine similarity 从 1.0 降至 0.91–0.99，新 block residual ratio 从 0 升至 0.22（Table 4, p. 8）。
- 消融只给摘要性结果：用 total loss 触发会产生 false positives，而 `L_pred` 为 0/9；effective rank 在 2D/60D 均约 3，不能区分容量。无规划成功率或真实数据实验。

## Value

值得借鉴的是“可逆架构试验”：保函数扩容把 dynamic architecture 的风险降为额外算力，失败时完整恢复 optimizer trajectory。它可用于逐步训练 JEPA 编码器，也提示应把世界模型容量当成可学习资源。现有结果更像小规模可行性验证；尚不能说明该触发器在真实视频、长程 latent rollout 或大模型训练中优于常规容量搜索/早停。

## Strengths

- 扩容、验证、回滚和 effective-epoch accounting 构成完整而易实现的闭环。
- 对扩容瞬时等价给出结构说明并做 bit-exact 内部表示检查，而不只比较最终 loss。
- 报告逐 seed 决策及失败/未 plateau 情况，没有只展示平均曲线。
- 作者明确列出 synthetic-only、无规划、单 GPU 规模等适用边界。

## Weaknesses

- 只有三个合成环境、三个 seeds，最大模型 5.7M；主指标还是触发器自身使用的 prediction loss，未报告独立 test protocol、统计区间或 LeWM 最终关心的 CEM planning success（作者限制，p. 10）。
- Width 永远先试；只要 width 在两 epoch 内过 2% 就不会比较 depth，因此观察到的扩容类型不能识别“表征瓶颈”与“计算瓶颈”，更不足以验证论文的 bottleneck decomposition（Algorithm 1, p. 5）。
- 固定 2%/2-epoch 阈值被称为 task-agnostic 且“无需调参”，但只在三个任务验证；30-Object 一个 seed 在预算内根本未触发，说明结论对训练时长/阈值敏感。
- 论文反复将 attention-map cosine similarity≈0.0001 解释为“near-identical/redundant”（pp. 2、9–10）；按通常 cosine similarity 定义，近 0 表示近正交而非近相同，除非实际计算的是 cosine distance。该核心冗余证据需澄清并给出原始矩阵。
- 无扩容的 SCG 与相同 seed Fixed Small 仍出现不同损失，说明平均改善混有训练随机性；“56×效率”又只按参数增量/损失降幅构造，未计试验 epoch、FLOPs、显存或 wall time。

## Future Work

作者明确提出：在真实高复杂度数据上验证；接入完整 LeWM+CEM 规划并报告任务成功；扩展至 ViT-Base；加入任务简化时的 head/layer pruning；与动态深宽推理机制结合。我们的推断：还需随机化 width/depth 试验顺序或并行比较两者，交叉验证 plateau 阈值，并以 matched compute、多 seeds 和真实 held-out planning 评估增长是否优于固定/搜索基线。

## Rating

创新度评分：3/5 - 将保函数 transformer 扩容、loss-triggered 试验与完整回滚组合到 JEPA 训练中有方法新意，但实证规模小，关键瓶颈解释尚未被充分验证。
相关度评分：3/3 (Core) - 直接优化 JEPA world model 编码器容量与 anti-collapse 训练，属于隐式世界模型核心问题。

## TL;DR

用保函数试扩与回滚让JEPA编码器按需增宽或加深，但仅证于合成预测损失，可选读。
