# Next Forcing: Causal World Modeling with Multi-Chunk Prediction

## Insight
核心观察：自回归视频世界模型（WAM）的标准训练目标——teacher-forced next-chunk denoising——本质上是一个**局部（myopic）**任务。由于相邻 chunk 在视觉上高度相似（尤其高帧率时），模型可以通过学习一个近似恒等映射（appearance shortcut）来最小化 denoising loss，而无需真正理解底层物理动力学。这一问题在高帧率（50 fps）下尤为严重：相邻帧几乎无损，shortcut 几乎无成本，导致收敛变慢且最终精度受限。

推论：将单 chunk 的局部监督扩展为多 chunk 的长程监督，可以打破 appearance shortcut——预测 2-3 步之后的 chunk 必然存在显著视觉差异，模型被迫学习真正的时序动力学。该推论通过高帧率场景下的显著收敛加速（2.3x）和精度提升得到了验证。

## Motivation
**问题**：自回归视频世界模型采用 teacher forcing 训练（在 clean 历史上去噪当前 chunk），存在"近视监督"问题——训练信号局限于当前 chunk，缺乏对未来动态的显式约束，模型倾向于学 appearance copy 而非理解物理动力学。

**同行方案**：现有改进主要关注**上下文构建方式**——Diffusion Forcing 通过独立噪声打破 train-test 分布差异；Self Forcing 通过在自生成上下文上训练缩小分布 gap。这些方法改变的是模型"看到什么"或"噪声怎么调度"，而非"预测什么"。

**关键性**：是关键问题。尤其在高帧率场景下，近视监督的代价急剧放大；同时推理速度也受限于逐 chunk 串行去噪。Next Forcing 从训练目标本身入手，与上述方法正交且可组合。

## Method
**整体流程**：在标准 teacher forcing 基础上，增加 3 个轻量级辅助 MCP（Multi-Chunk Prediction）模块，分别负责预测 next^1、next^2、next^3 chunk。主模型照常去噪当前 chunk，MCP 模块形成因果链式结构，逐级预测更远的未来。

**关键技术细节**：
1. **多层特征融合（Multi-Layer Fusion）**：从主模型 30 层 Transformer 的第 4/12/20/30 层收集隐藏状态，拼接后通过 2 层 MLP 压缩，使 MCP loss 梯度能传播到主模型的早期和晚期层。
2. **时间步偏移（Temporal Chunk Shifting）**：MCP 目标通过将视频 latent 向前偏移 k 个 chunk 来构造。每个 MCP 目标独立加噪，采用更高的 timestep shift（s_mcp=10 > s_main=5），迫使 MCP 模块更依赖主模型特征而非自身输入。
3. **因果链式 MCP 模块**：每个深度 k 的 MCP 模块接收上一深度的输出作为输入，形成因果链。每个模块仅含 3 个 Transformer block，非常轻量。
4. **RoPE 位置编码偏移**：将 chunk 偏移量注入旋转位置编码，使 MCP 模块感知其预测的时间位置。
5. **双模式推理**：训练后可选择（a）丢弃 MCP 模块，零额外开销；或（b）保留 depth-1 MCP 模块与主模型并行推理，实现 2x 加速。

**架构基底**：基于 LingBot-VA 框架，采用 Mixture-of-Transformers（MoT）联合建模视频流和动作流，视频与动作通过 cross-modal attention 融合。

**创新程度**：中等。核心思想来自 LLM 的 multi-token prediction（MTP），但将其适配到连续视频 latent + 迭代去噪的场景需要非平凡的设计（时间步偏移、多层融合、因果链）。方法简洁且工程友好。

## Experiment
**实验设置**：
- **RoboTwin**：50 个双臂操作任务，Clean/Random 两种设置，指标为 task success rate
- **PhyWorld**：物理规律遵守性评估，指标为 FVD 和 Abnormal Ratio
- **通用视频预训练**：3.5M 视频片段，指标为 FVD

**对比实验**（Table 1）：在 RoboTwin 上，Next Forcing 达到 94.1/93.5%（Clean/Random），超越 LingBot-VA（92.9/91.5%）、Fast-WAM、Being-H0.7 等所有 VLA 和 WAM 方法。

**收敛速度**（Figure 1）：50 fps 下 5k 步时 Next Forcing 已超出 LingBot-VA 29.7 个百分点（Random），20k 步即达到 baseline 45k 步的水平，约 2.3x 加速。

**消融实验**（Table 2）：
- MCP 带来 +10.2% 绝对提升（75.6% -> 85.8%）
- 去掉多层融合：-2.2%；去掉权重初始化：-2.0%
- s_mcp=5（与主模型相同）降至 83.2%，验证了更高 timestep shift 的必要性
- 1 block vs 3 block vs 5 block：3 block 为最佳平衡点

**PhyWorld**（Table 3）：FVD 从 5.3/3.5 降至 4.7/3.2，Abnormal Ratio 从 12%/3% 降至 8%/2%，out-of-template 提升更大。

**推理加速**（Table 4）：并行 chunk 生成模式实现 2x 加速，精度损失极小（50 fps Clean: 91.8 -> 92.2，甚至略有提升）。

**通用视频**（Figure 4）：FVD 在 50k 步降低超过 50%（Test Set 1: 225 -> 94）。

## Value
**工作价值**：
- 方法简洁有效，作为训练目标层面的改进，与 context construction（Self Forcing）和 noise scheduling（Diffusion Forcing）正交，可自由组合
- 推理时可零成本获得更好模型，或以极低代价获得 2x 加速，工程价值明确
- 在高帧率场景下优势突出，而高帧率恰恰是精细操作和实时控制的刚需

**对我们的启发**：
- 对于视频世界模型，训练目标（"预测什么"）与上下文构建（"看到什么"）是两个正交且同等重要的维度，值得更多探索
- MCP 的多层特征融合机制对 implicit world model（如 JEPA）有借鉴意义——通过辅助预测头从多个层级抽取特征，可能帮助隐式模型学习更好的层级化世界表征
- 该方法目前仅在 latent space 做 flow matching 去噪，尚未验证在 pixel-level diffusion 或 token-based 自回归视频模型上的效果

**待解决问题**：
- MCP 模块引入额外训练成本（约 3 个轻量模块的前向/反向）
- 并行推理仅利用了 depth-1 模块，depth-2/3 的推理利用尚待探索
- 未在更大规模模型（如 DreamZero 14B）上验证

## TL;DR
将 LLM 的 multi-token prediction 思想适配到视频世界模型，通过辅助 MCP 模块同时预测多个未来 chunk 来克服 teacher forcing 的近视监督问题，高帧率下收敛加速 2.3x 并支持 2x 推理加速。可选读，对视频世界模型训练范式有参考价值。
