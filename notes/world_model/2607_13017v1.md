# FlowWAM: Optical Flow as a Unified Action Representation for World Action Models

## Insight
核心 insight 是：对视频世界模型来说，光流比数值动作更接近“视频原生动作表示”。观察是机器人动作、人体演示和视频生成控制本质上都对应像素运动；若把光流编码成 RGB/HSV 视频，就能让同一套 VAE/DiT 同时学习视觉预测、动作条件生成和策略解码。

## Motivation
现有 world action model 多用离散/连续低维动作作为条件，难以迁移到无动作标签的人类视频，也不容易表达空间运动细节。视频世界模型虽然能生成未来画面，但动作可控性和可执行性弱。论文解决的关键问题是：如何用统一表示连接无动作视频预训练、动作条件世界建模和机器人策略学习。

## Method
FlowWAM 将光流转成 RGB 表示，构建 RGB stream 与 flow stream 的双流扩散模型：两路有独立 patch embedding 和输出头，中间共享 transformer block，并通过联合 attention 交互。模型有两种模式：policy mode 同时生成未来 RGB/flow，再由 action expert 从隐藏状态解码可执行动作；world-model mode 固定光流轨迹作为干净条件，生成动作控制的视频未来。训练上使用 RGB/flow 的 flow-matching loss、首帧 latent 条件、运动区域重加权 flow loss；先在 EgoDex 人类第一视角视频上用 RAFT 光流做 action-free 预训练，再在 RoboTwin 上联合训练策略头。

## Experiment
RoboTwin 2.0 50 个双臂任务中，FlowWAM 预训练版在 Clean/Random 设置约 92.94%/92.14% 成功率，优于或追平 X-VLA、Motus、GigaWorld-Policy、X-WAM、Fast-WAM 等强基线；无预训练降到约 82%。WorldArena 上 121 帧长程生成的 EWMScore 最高，轨迹准确率提升明显，说明光流主要改善动作轨迹控制。真实机器人 7 个任务平均成功率约 75.7%，高于两个主要基线。消融显示数值动作、原始 flow tensor、去掉 flow loss reweighting 或 action expert 条件设计都会降低策略或世界建模效果。

## Value
这是视频世界模型和机器人策略结合方向的高价值工作。启发在于：动作不一定要从机器人控制空间出发，可以先找一个跨 embodiment、跨视频数据可获得的中间动作表示。待解决问题是光流对接触力、遮挡后物体状态和长程规划的表达仍有限。

## Strengths
统一了无动作视频预训练、动作条件视频生成和机器人策略学习；光流表示直观、可监督来源广；实验覆盖仿真、WorldArena、真实机器人和关键消融，证据链较完整。

## Weaknesses
依赖大规模视频扩散 backbone 和 RAFT 光流质量，训练成本高；光流只能描述可见像素运动，对力、触觉、不可见状态和物体持久性表达不足；真实机器人任务规模仍偏小。

## Future Work
作者提出进一步扩大 action-free 视频预训练规模，并将 flow-based planning 扩展到更长时间尺度。

## Rating
创新度评分：4/5 - 光流作为统一 action representation 的设定明确、有实验支撑，并把视频生成与策略学习连接得较好。
相关度评分：3/3 (Core) - 直接研究视频世界模型和机器人 world action model。

## TL;DR
用光流作为视频原生动作表示统一机器人策略和动作条件世界建模，实验扎实，值得精读。
