# One Transit Is All You Need: Detecting Exoplanets Through Learned Stellar Behaviour with EXOVEIL

## Insight
论文把“world model”用于天文学：学习恒星正常亮度行为，行星凌日表现为预测残差中的负向异常。核心 insight 是单次凌日无法 phase-fold 分类，因此应做自监督时间序列预测 + matched filter anomaly detection。

## Motivation
现有 ExoMiner/AstroNet/RAVEN 等凌日 vetting 多依赖已知周期和 phase-folded input，天然检测不了单次长周期凌日。PLATO/TESS 长周期类地目标正是稀有单次/少次凌日，因此需要 flux-only、可跨任务泛化的检测器。该问题完全是天文应用，非用户方向。

## Method
ExoVeil 四阶段：causal Transformer world model 预测 expected flux；对残差做 variance-weighted matched filter 找 transit-shaped anomalies；XGBoost 用 21 features 区分行星/false positives；split conformal prediction 给 95% coverage 和 aleatoric/epistemic uncertainty。Transformer 6 层、8 heads、d=192，连续时间编码和 learned detrending；训练时对已知 transit 区域插值遮蔽做 self-supervised next-step prediction。

## Experiment
训练 16499 条 Kepler long-cadence light curves。盲搜 3737 个 Kepler stars，恢复 2873 个 known confirmed planet signals，并发现 179 个不在 DR25 TCE 的 transit-like anomalies；但人工检查显示许多 top-SNR 是 flare overshoot、rotation tracking error、edge-of-data、stitching-boundary residual。TESS LOPS2 zero-shot 恢复 47/47 confirmed planets。PLATO 25s cadence resampling 下 100 ppm depth SNR>30。单次注入恢复：1000 ppm sensitive mode 32%，conservative 23%。

## Value
技术上是时间序列 anomaly detection，不是 CS 世界模型方向。可作为“world model”术语在科学时序中的泛化案例；对视频/3D/JEPA/Dreamer 基本无借鉴，建议跳过。
