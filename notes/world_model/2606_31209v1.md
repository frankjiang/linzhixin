# Long-term Traffic Simulation via Structured Autoregressive Modeling

## Insight
核心 insight 是离散交通 motion tokens 的频率分布近似 Zipf law，和自然语言 token 分布类似，因此小型预训练 LLM 的序列归纳偏置可迁移到交通仿真。论文进一步观察到大模型规模不一定更好，收益主要来自语法/序列结构能力，而不是语言语义知识。

## Motivation
论文解决长时交通仿真中的多智能体交互、agent 进出场和长期 rollout 误差问题。已有短时交通 simulator 在 8s 内表现好，但 trip-level 长时仿真需要同时生成连续运动和动态 agent population；从零训练统一序列模型不稳定。该方向属于自动驾驶交通世界模型，与视频/3D/JEPA 有间接关系。

## Method
RosettaSim 把场景拓扑、agent state、motion 和 spawning intent 投影成结构化自回归 token stream。运动生成阶段并行预测已有 agent 的 motion tokens；agent 生成阶段以当前 scene/motion/map/layout tokens 为上下文，自回归生成新 agent 的 type、grid、yaw，直到 EOS。训练是一阶段 cross-entropy。评估方面提出 Retrieval-based Traffic Evaluation：用预训练 scene VAE 把 rollout segment 和验证集 segment 编码到 latent，以 Wasserstein 距离检索相似真实场景，再计算行为和流量 realism，组合为 RMM-F1。

## Experiment
短时 WOSAC 2025 上 RosettaSim composite 0.7833，接近或超过多数 SOTA，低于闭环调优的 CAT-K 0.7846。消融显示可调层数、Zipfian corruption、不同 LLM 大小/家族，支持“结构先验而非大规模语义知识”结论。长时 31.1s rollout 中，RTE 与标准短时 WOSAC 相关性高于 log-based metrics；RosettaSim RMM-F1 0.7624，高于 InfGen 0.7290、CAT-K 0.7381、SMART 0.7383，并在 Traffic Flow Realism 上明显提升。

## Value
对长程多智能体仿真和评测有价值，尤其是把 token 分布/LLM 结构偏置迁移到非语言序列。对用户方向的直接价值有限：没有视频生成、3D 表示或 JEPA/Dreamer 隐式动力学，更多是交通领域 structured autoregressive simulator。

## Strengths
亮点是RosettaSim 把场景拓扑、agent state、motion 和 spawning intent 投影成结构化自回归 token stream。

## Weaknesses
不足是对长程多智能体仿真和评测有价值，尤其是把 token 分布/LLM 结构偏置迁移到非语言序列。
