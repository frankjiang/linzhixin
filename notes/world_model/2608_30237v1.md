# Motus2: A Self-Evolving General World Model for Dexterous Manipulation

## Insight

有。论文的 observation 是：操作系统中的成功演示、失败轨迹和次优交互并不应被同一种 imitation loss 使用；失败动作不值得模仿，却仍提供“动作会导致什么”和“结果是否推进任务”的有效监督。由此作者把联合密度按 action-first 顺序分解为策略 $\pi(A_t|c_t)$、动作条件视频模拟器 $p(Z_t|c_t,A_t)$ 和价值评估器 $p(Y_t|c_t,A_t,Z_t)$，再用 attention mask 与 trajectory-dependent loss gate 在同一共享 backbone 中暴露三个接口。

推论是：只对 curated success 开 action loss，把失败/无关片段送入 simulation 或 evaluation mode，就能从更广的交互数据学习动力学与价值而不把坏动作教给策略；模拟后果的价值又可同时用于 Best-of-N 选择和 DiffusionNFT 策略更新，形成“提议—想象—评价—改进”闭环。真实机器人结果支持闭环有增益，但论文未独立验证 value calibration、simulator fidelity 或 loss routing 各自贡献，因此更像有力的系统假设与工程证据，而非已完全识别的因果结论。

## Motivation

通用灵巧操作不仅要从当前观察输出动作，还要处理手部遮挡、接触歧义、长时历史和部署后改进。传统 VLA/模仿学习依赖昂贵的 embodiment-aligned 成功演示，没有显式好坏判断；现有 WAM 多在视频模拟器后附动作头，策略、模拟和评价没有组成闭环。与此同时，单目人类第一视角数据覆盖广但深度弱，双目更利于 3D 手姿，触觉又是接触阶段视觉的必要补充。

Motus2 试图同时做 model scaling 与 data scaling：把策略、action-conditioned video world model 和 value model 统一为一个 5B 级共享模型；把约 130K raw hours 的单目/双目人类数据、超过 100 小时机器人及人机对齐数据、目标机器人 SFT 和触觉信号接成分阶段课程。问题直接对应具身视频世界模型能否支持决策与自我改进，价值很高，但论文也因系统变量过多而难以精确归因。

## Method

核心 backbone 从 Wan 2.2-TI2V-5B 初始化。联合预训练时，视频和动作在 chunk 内双向可见；进入 robot-domain mid-training 后改用 action-first mask：动作 token 不能看本 chunk 的未来视频或 value query，未来视频可读动作，read-only value query 可读二者且不被其他 token 读取。统一 flow-matching/CE 目标通过 gate 切换三种模式：policy 同时监督动作与视频，simulation 固定记录动作只预测未来，evaluation 固定动作与视频只预测离散进度值。

数据课程为：Stage 1 单目低分辨率 500K steps、单目高分辨率 340K；Stage 2 双目视频+134-D 人手动作 450K；随后用 $>100$ 小时机器人轨迹与人机对齐数据 mid-train，再做目标机器人 SFT。约 130K raw hours 语料含 111.3K 单目与 17.4K 双目来源，实际过滤后时长未给出。双目视图共享时间/垂直 RoPE、占不同水平 RoPE 区间。

价值目标采用相对进度 $\Delta t/(T-t)$；成功段为正，失败或任务无关段为负，并离散成 201 bins。规划每次采样 8 个动作候选，模拟一个 chunk 的未来、按 value 排序并执行最高者；MBRL 将候选 value 标准化为 $[0,1]$ 权重，以 DiffusionNFT 围绕 EMA reference 构造正/负 implicit velocity field，只更新 action-related parameters，冻结视频与价值部分。

历史模块比较 bounded sliding window、保留全量视觉 KV 的 global autoregression、以及“2 anchor frames + 4 recent frames + 每 latent frame 8 memory tokens”的 hybrid memory。触觉 expert 是 30 层、宽 128 的轻量 Transformer，读取冻结 backbone 的 layer-wise KV，在 48-action chunk 的 8 个子段执行前用最新触觉从 $\sigma_c=0.2$ 精炼动作，并以 future-force flow matching 作辅助训练。

## Experiment

主实验在 5 个真实双臂/灵巧手任务上每任务 20 trials，所有初始化使用相同 target-task SFT 数据与协议。WAN-SFT 与 $\pi_{0.5}$ 均为 0%；egocentric Pretrain-SFT 在 Place Ball/Multi-Finger/Attach Eraser/Screw Bulb/Put Phone 分别为 60/35/90/55/15%，macro 51%；Motus2 Midtrain-SFT 为 100/70/100/90/60%，macro 84%，较 Pretrain-SFT 高 33 点（Table 2，PDF 第 12 页）。

其余实验包括：

- 双目人类数据以 2K/4K/10K/20K raw hours 做 nested scaling，held-out action MSE 单调下降，拟合 $L^*_{val}(D)\approx0.101-0.005\ln D$；但只给四个规模、无置信区间（Fig. 5，第 13 页）。
- Put Phone 与 Multi-Finger 的 $2\times2$ MBRL/Planning：基础 65.0%，仅 Planning 67.5%，仅 MBRL 72.5%，二者结合 75.0%。每任务 20 trials，Planning 的 2.5 点 macro 增益等价于 40 次合计多 1 次成功（Table 3，第 14 页）。
- 长记忆探针 Find Square/Press Button：global autoregression 在 simulation 为 84/72%（macro 78%），hybrid memory 为 64/40%（52%）；真实机器人为 65/50%（57.5%）对 30/20%（25%）（Table 4，第 14 页）。
- 触觉在 Pull Out Paper Cup/Tear Paper 上把 65/55% 提至 75/70%，macro 60.0%→72.5%，各 20 trials（Table 5，第 15 页）。
- 附录仅用每任务一条成功和一条失败轨迹展示 value：成功终值约 0.63-0.65；失败会在丢失进度后下降，如 Put Phone 从 0.60 降至 -0.26、Multi-Finger 终值 -0.53（第 28-29 页）。这些是定性例子，不是 evaluator 的总体准确率或校准评测。

## Value

Motus2 的价值在于把世界模型从“视频预测器+动作头”提升为可按条件查询的决策基础设施：同一表征既能快速只出动作，也能按需展开视频和价值分支；失败轨迹被重新定义为 dynamics/value 数据，而非应丢弃的坏 demonstration。这一 supervision routing 与 action-first mask 对构建可自改进 WAM 很有借鉴性。

工程上，单目→双目→机器人→触觉的数据金字塔、全历史/压缩记忆对比和真实仿生平台也提供了难得的规模证据。尚待解决的是闭环可信度：若 simulator 或 value 在策略分布外偏差，Best-of-N 与 MBRL 会放大模型错误；全量 global KV 又无法长期扩展。对我们而言，最值得跟进的是“共享模型的条件接口+坏轨迹路由”，而不是把 84% 单一结果直接归因于某一个 world-model 技术。

## Strengths

- 在一个共享参数模型中给出明确的 policy/simulator/evaluator 因果顺序，attention mask 避免未来视频泄漏给动作预测。
- 成功、失败、次优和任务无关轨迹按可提供的监督类型路由，数据利用逻辑合理。
- 从约 130K raw-hour 人类数据到三种真实机器人、双目、双臂、灵巧手和触觉，系统规模与任务覆盖突出。
- MBRL 与 Planning 采用 $2\times2$ 因子设计，能区分“改变提议分布”和“只在测试时选候选”。
- 主任务、长记忆、触觉分别设置专门 probe；附录给出训练窗口、候选数、flow steps、EMA、触觉维度等较多实现细节。

## Weaknesses

- 主表的 Midtrain-SFT 84% 相对 Pretrain-SFT 51% 同时改变了机器人数据、人机对齐、action-first mask、simulation/evaluation 样本和 value training，缺少逐项消融，无法把 33 点提升归因于“通用世界模型闭环”。
- MBRL 只测 2 个任务、每格 40 trials；Planning 的 2.5 点提升仅对应多 1 次成功，论文未报告置信区间、显著性或多 seed。MBRL 也未与 model-free/real-rollout post-training 做等数据对照。
- simulator 没有报告视频预测指标、动作条件一致性或 counterfactual fidelity；evaluator 只有 8 条定性轨迹，没有 held-out ranking/AUC/calibration。闭环最关键的两个接口因而缺少独立质量证据。
- 失败轨迹的每个 segment 都赋负进度，可能把“前半程做对、末尾才失败”的局部有效动作误标为负；附录的失败曲线实际先升后降，进一步说明这种监督与真实局部进度并不完全一致。
- 所有真实实验每任务仅 20 次，success 以 5 点跳变，且没有统计区间。$\pi_{0.5}$ 与 WAN-SFT 五项全为 0% 也提示任务/调参可能强烈偏向自家数据课程，跨模型比较虽同 SFT 数据却未做到相同预训练、容量或优化预算。
- 130K 小时是过滤前 raw duration，兼容来源可重复进入不同阶段；有效样本数、公开可得性和去重统计未给出，商业采购数据使复现困难。
- global autoregression 的效果最好，但 KV 和注意力成本随 episode 长度增长；hybrid memory 显著掉点，尚未得到可扩展的长期记忆方案。“self-evolving”也只展示有限 post-training，并非持续部署下无界自主学习。

## Future Work

作者明确提出两条路线：数据侧改进可穿戴触觉材料与制造，扩大整手多模态人类数据，并通过更拟人的灵巧手缩小人/机形态差；模型侧使用更强视频基础模型和统一多模态模型，把视觉、语言、动作、触觉与价值放入共同生成/决策过程，提升长时后果预测与持续交互学习。

我们的推断是：应优先做 simulator/value 的独立校准与 OOD 不确定性评测，按等交互/专家数据比较 MBRL，对 progress label 做阶段级或偏好式监督，开发固定成本但不丢关键证据的长期记忆，并在更大任务集上验证多轮在线更新是否会模型偏置累积或灾难遗忘。

## Rating

创新度评分：3/5 - 共享策略、视频模拟与价值接口并闭环到 DiffusionNFT 是有价值的系统组合，规模和实机结果强，但组件多为既有方法且关键接口缺少独立归因，尚不足 4 分。
相关度评分：3/3 (Core) - 直接研究 action-conditioned 视频世界模型、world-action policy、价值评估与长期记忆，属于视频/具身世界模型核心方向。

## TL;DR

统一策略、视频模拟器与价值评估器闭环改进灵巧操作，系统规模大但归因有限，值得精读。
