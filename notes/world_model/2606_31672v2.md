# WorldOdysseyBench: An Open-World Benchmark for Long-Horizon Stability of Interactive World Models

## Insight
WorldOdysseyBench 的 insight 是交互式世界模型的长期稳定性不能只看轨迹级 action following 或短视频画质。Observation 是模型可能最终轨迹对齐但逐帧按键错、画面中途崩溃后恢复、遵守动作却违反物理、或返回原地时忘记场景。作者因此把评测拆成 Action、Vision、Physics、Memory 四个维度。

## Motivation
论文解决 interactive world model benchmark 覆盖不足的问题。现有 MIND、WorldMark、iWorld-Bench、WBench 等多关注 5-10s 短片、轨迹级动作或有限 memory；缺少 per-frame action、visual drift、interaction physics 和 trajectory-aware memory。该问题是视频/交互式 world model 的核心评测问题。

## Method
Benchmark 包含 600+ cases，覆盖 Nature、Urban、Indoor、first/third-person，WASD/IJKL 连续交互 10-60s。Action 维度用 ViPE 估计轨迹并离散为 per-frame action，报告 strict/partial accuracy 和 TrajScore；Vision 用 aesthetic/imaging score 的 segment drift 捕捉非单调崩溃；Physics 用 mechanics、optics、3D consistency，且只在控制有效时评分；Memory 用 action-decoupled revisit protocol、3D point-cloud reconstruction 和 subject tracking+VLM reasoning。

## Experiment
评估 Genie 3、Happy Oyster、Lyra 2.0、HY-World 1.5、LingBot-World、Matrix-Game 3.0、SANA-WM、Matrix-Game 2.0、Yume 1.5、minWM 等。FPV 总分 Genie 3 73.81 最高，Happy Oyster 71.06，Lyra 2.0 70.32，HY-World 1.5 70.29；没有模型统治所有维度。HY-World/LingBot action score 高，但 physics/memory 不一定强；Genie 3 memory 最好，Happy Oyster TPV control rate 84.43 最高。论文强调 trajectory score 可高于 85 但 strict action accuracy 低于 65，说明轨迹级指标会隐藏失败。

## Value
对我们很有价值：它提供了一个长程交互式 world model 的诊断框架，尤其是逐帧动作、漂移、物理和记忆的分离评估。适合用来定义后续模型目标和 failure taxonomy。

## Strengths
维度设计较全面，覆盖 open/closed-source 模型；区分 action error 与 memory degradation；引入 visual drift 和 physics gate，能发现短视频指标看不到的问题。

## Weaknesses
很多指标依赖 ViPE、VLM、pose/action 转换，可能引入评估噪声；闭源模型不可完全复现；总分权重默认等权，未必适合所有应用；benchmark 本身不提出模型改进。

## Future Work
作者指出未来世界模型需要同时提升 action responsiveness、physical grounding、persistent scene/subject memory 和 third-person controllability。

## Rating
创新度评分：3/5 - 评测维度完整且针对性强，但贡献是 benchmark 而非模型突破。
相关度评分：3/3 (Core) - 直接评测长程交互式视频世界模型，核心相关。

## TL;DR
长程交互式 world model 综合基准，揭示动作、物理和记忆缺陷，值得精读。
