# WorldDirector: Building Controllable World Simulators with Persistent Dynamic Memory

## Insight
核心 insight 是把“长程可控视频生成”拆成两件事：语义层先规划 3D 运动与事件，生成层只负责把这些轨迹和外观锚点渲染成连续视频。Observation 是现有交互式 world model 对静态场景还算稳定，但动态物体一旦离开视野或发生复杂遮挡，就容易丢身份、换外观或无法按指令重现。作者据此推论：动态实体需要显式的、可持久更新的记忆，而不是只依赖隐式 attention。

## Motivation
论文解决可控视频世界模拟中的动态物体持久性问题。同行常见做法是视频扩散模型、长视频自回归、monitor/track-based 控制或隐式特征跟踪；它们要么难扩展到多实体长程交互，要么只在短时可见目标上有效。这个问题对视频 world model 很关键，因为可交互模拟不仅要画得像，还要能在长时间、离屏、重入、事件插入时保持世界状态一致。

## Method
WorldDirector 将生成流程拆为语义 3D 运动编排和 latent 视频合成。LLM 根据用户指令产生 3D bounding box、相机轨迹和事件，再投影为 2D box 条件；Appearance Binding 从上下文中抽取动态实体 RGB 特征作为外观锚点；spatial-aware cross-attention 把实体文本只路由到对应空间区域；自回归 chunk 生成时区分静态上下文和动态上下文。创新点在于显式“动态物体记忆池”与 3D 轨迹控制的组合，工程系统完整。

## Experiment
基于 LingBot-World-Base，在 100 个新视频样本上比较 Yume1.5、HY-World、Infinite-World、LingBot-World、HyDRA。指标包括 PSNR/SSIM/LPIPS、VBench subject/background consistency，以及用 YOLO crop+DINO/CLIP 计算的动态主体一致性 DSC。主结果中 Ours 达到 PSNR 18.127、SSIM 0.502、LPIPS 0.359，明显优于多项基线；DSC_CLIP 0.917 也最高。消融显示去掉 Appearance Binding 后 DSC_DINO 从 0.769 降到约 0.693，说明外观锚定是关键。作者也指出 VBench subject/background consistency 有时会奖励较少运动，不完全等价于动态世界建模质量。

## Value
对视频 world model 很有启发：长程一致性不能只靠更长上下文，需要把对象身份、外观、轨迹和事件显式分层。尤其适合作为“可控世界模拟器”方向的设计参考。

## Strengths
亮点是问题定义清楚，针对动态实体持久性给出结构化方案；LLM 负责可解释的 3D 运动编排，生成模型负责视觉细节，接口清晰；动态主体一致性指标比普通 VBench 更贴近问题。

## Weaknesses
主要依赖合成/游戏式数据，真实世界泛化仍不清楚；人体运动、面部和细粒度接触仍有不自然或模糊现象；3D box 级控制距离真实物理交互还比较远。

## Future Work
作者明确提到未来需要引入真实世界数据，减小合成域差距，并改善动态主体的自然运动和细节质量。

## Rating
创新度评分：4/5 - 显式动态记忆、3D 语义编排和视频生成结合紧密，针对长程交互式 world model 的关键痛点。
相关度评分：3/3 (Core) - 直接研究可控视频世界模型和动态对象持久记忆，核心相关。

## TL;DR
用 LLM 规划 3D 轨迹并绑定动态外观记忆，提升长程可控视频模拟，值得精读。
