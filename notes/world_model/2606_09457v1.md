# omega-EVA: Envision, Verify, and Act with Latent Interactive World Models

## Insight
核心观察：现有策略生成动作后直接执行，动作的未来后果在策略内部是隐式的、不可检视的。而世界模型通常仅作为被动的训练信号或独立模拟器，与策略的交互是单向的。omega-EVA 提出一个关键范式转变：将世界模型变为策略内部的主动反馈模块，构建"Envision-Verify-Act"闭环——策略先提出动作候选，世界模型预测该候选的隐式未来后果，refiner 根据当前状态+想象未来+原始提案联合推理出修正后的动作。这使未来预测从辅助任务变为动作生成的核心组成部分。

## Motivation
- **问题**：机器人操作策略直接从观察映射到动作，无法在执行前检查候选动作的后果。世界模型虽能预测未来，但通常仅用于表征学习/模拟器/规划，很少与策略形成闭环交互。
- **同行做法**：(1) 世界模型作为辅助训练目标（推理时跳过）；(2) 生成视频/rollout 做规划（像素空间计算昂贵）；(3) 外部条件信号引导生成策略。这些方法很少同时做到：在策略自身候选动作上进行想象、将想象结果反馈回策略修正动作。
- **是否关键**：是。如何高效利用世界模型的预测能力来提升策略质量是隐式世界模型方向的核心问题。

## Method
**三阶段训练**：
1. **Stage 1: Action-Conditioned Latent World Model**：学习 W_theta，接收当前视觉特征 I_c 和动作前缀，预测未来 DINOv3 特征 I_f。关键设计：(a) Variable-horizon action conditioning（随机截断动作序列，迫使模型学习不同时间尺度的动力学）；(b) Causal multimodal attention（三分支：current-state/action/future-query，用 block visibility mask 确保 c_t 不依赖动作输入，实现 action-independent 的动力学感知表征）。
2. **Stage 2: World-Aware Action Generator**：在 Stage 1 学到的动力学感知表征 c_t 上训练 flow-matching 策略 pi_phi，生成初始动作提案。使用 Query Transformer + cross-attention 融合 c_t 和语言指令。
3. **Stage 3: Imagined-Interaction Action Refiner**：冻结 W_theta 和 pi_phi，将 Stage 2 生成的动作提案送回世界模型得到想象未来 I_f，然后训练 tri-branch refiner R_psi 联合推理当前状态 c_t、想象未来 I_f、原始提案，输出修正动作。

**推理时**：策略生成提案 -> 世界模型想象后果 -> refiner 修正 -> 执行。全部在 latent feature space 完成，无需解码像素。

**创新程度**：较高。将世界模型从被动预测器转变为策略内部的主动反馈模块是一个清晰且有意义的范式创新，三阶段训练设计合理。

## Experiment
- **基准**：LIBERO（4 个 suite）、LIBERO-PLUS（7 种扰动）、RoboTwin 2.0（双臂操作）。
- **对比方法**：OpenVLA (7B)、pi_0 (3.3B)、pi_0.5 (3.3B)、LingBot-VA (5.3B)、Motus (8B)、VLA-JEPA (3B)、Fast-WAM (6B) 等。
- **结果**：
  - LIBERO：Stage 2 (0.8B) 达 97.9%，Stage 3 (1.2B) 达 98.6%，在无 robot pretrain 组中最优，甚至超过部分有 robot pretrain 的大模型。
  - LIBERO-PLUS zero-shot：Stage 3 从 71.3% 提升至 72.2%，超过 VLA-JEPA (62.9%) 和 Fast-WAM (51.5%)。
  - RoboTwin 2.0：Stage 3 达 90.3%，接近 Fast-WAM (91.8%)，超过 Motus/Being-H0.7。
- **消融**：
  - c_t 的 action invariance 验证（不同动作输入产生完全相同的 c_t）。
  - Stage 3 各分支消融：移除 imagined future 或 proposal 均导致性能下降，证明两者缺一不可。
  - Latent future fidelity：Stage 3 refined action 的想象未来在 SSIM/FID 上更接近 GT。

## Value
- **价值**：提出了一个清晰、实用的范式——将世界模型作为策略内部的 proposal-conditioned 反馈模块。1.2B 参数无需额外机器人数据预训练即可达到竞争力极强的性能，证明了紧凑架构+世界模型交互的有效性。
- **启发**：世界模型不仅可以做"被动预测"，还可以做"主动验证+修正"，这个思路可推广到更多决策系统中。三阶段解耦训练（动力学 -> 策略 -> 交互修正）是一个值得借鉴的范式。
- **待解决**：仅执行一次 refine（无迭代）；仅在仿真中验证；Stage 3 的实际推理延迟增加未充分讨论。

## Strengths
- 把世界模型放进策略内部做候选动作验证与修正，范式清晰且实验证明收益稳定。
- 三阶段解耦训练把动力学建模、动作生成和动作修正分开，便于分析各部分贡献。
