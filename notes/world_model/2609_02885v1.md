# Discriminative World Models for Web Agents

## Insight

有。论文观察到，网页 world model 的常规监督目标是复现预定义的文本摘要、HTML 或 AXTree，但下游 ranker 真正需要的是“候选动作会造成什么不同”；固定摘要可能漏掉关键变化，完整 AXTree 又会被大量未变化结构淹没。由此推论：下一状态表征不必逼近唯一目标字符串，而应直接优化其对同一决策点不同动作后果的可区分性。

作者没有给出形式化定理，而是用受控实验证明这一 objective alignment：相同 Qwen3-8B 初始化与相同 branching data 下，AXTree SFT 的 matching accuracy 仅 47.77%，predicted-state matching 达 80.80%；后者还改善冻结/训练 ranker 和端到端任务成功率。跨三个 judge 的结果说明提升不只依赖训练时的 Qwen3-32B judge，但仍是模型裁判下的经验证据。

## Motivation

网页导航是部分可观测、多步决策问题。已有 ReAct 式 agent 直接预测动作，近期 model-based test-time selection 则先采样动作、用 world model 预测后果，再由 PRM/ranker 选择；WebDreamer、WebWorld 等仍以固定格式的 next-state generation 训练。线性轨迹也只记录被执行的路径，缺少同一状态下反事实动作的真实后果。论文要补齐“训练目标与动作排序目标错位”和“缺少局部分支监督”两点。问题对网页 agent 本身关键，但场景和模型都是文本/AXTree，不是视频、3D 或 JEPA/Dreamer 式隐式世界模型。

## Method

作者把 WebArena Go-Browse 的 2,839 条轨迹中重复出现的浏览器状态合并为 state-action graph；有多个出边的状态形成 7,730 个 branching decision points，再枚举 queried/alternative action-outcome 对，得到 30,920 个 pairwise examples，并按 Shopping、CMS、Reddit、GitLab、Map 域分层切分。

Qwen3-8B world model 输入任务指令、历史、当前 accessibility tree 和 queried action，输出自由文本 `<predicted_state>`。训练时固定 Qwen3-32B judge 只看到该文本与随机顺序的两个真实候选下一状态，不看到任务、历史、当前状态或动作；选对 queried action 的真实后果得 matching reward 1。总奖励为 `R_match + 0.4 R_fmt`，格式项要求非空且 XML 合法。优化用 GRPO：每输入采样 8 个 completion、KL 系数 0.04、训练温度 1.0、最长 2,048 tokens；推理用 greedy decoding。共 4,830 steps、effective batch 32，8 张 A100 运行 48.75 小时（6 张优化、2 张生成），约 390 GPU-hours。

下游把每个候选动作的预测状态附加给 Qwen2.5 PRM/ranker，比较无状态、WebWorld-8B 状态和本文状态；另让 GPT-4o 提议 5 个动作，本文模型预测每个后果，再由 GPT-4o 排序执行。

## Experiment

在 held-out predicted-state matching benchmark 上，本文模型 overall accuracy 为 80.80%，高于 WebDreamer-7B 的 74.51%、WebWorld-8B 的 70.17%、原始 Qwen3-8B 的 62.86%及同数据 Full-AXTree SFT 的 47.77%。换用 GPT-4o/Llama-3.1-70B judge 时为 81.26%/79.31%，仍高于两个现有 world model。输出平均仅 91.6 tokens，而 WebWorld 为 412.7 tokens（还不含其 reasoning）。格式奖励消融中 `λ_fmt=0.2/0.4/0.6/1.0` 分别为 79.0/80.8/78.9/79.2%，对权重相对稳健。

WebPRMBench 覆盖 Mind2Web、WebArena、AssistantBench、WorkArena，指标为 Pairwise 与 Best-of-N accuracy。相同 Qwen2.5-7B answer-only SFT 下，无预测状态平均为 82.02/55.80，WebWorld 状态为 85.48/67.63，本文状态为 89.36/72.70；后者平均优于两种受控基线，但 BoN 仍略低于更复杂的 WebArbiter-7B（74.60）。冻结 3B ranker 中三者分别为 69.27/26.76、68.39/36.76、74.07/42.96；冻结 7B 中为 77.61/42.78、75.61/51.53、80.06/54.65。WebArena-Lite 端到端成功率从 ReAct 的 13.94% 提升到 GPT-4o Best-of-5 的 21.82%，加入本文预测状态后为 28.48%。

## Value

对目标方向的可迁移启发只有一个：训练预测表征时，可把“区分同一状态下不同动作的后果”作为比逐像素/逐 token 重建更贴近规划的目标，并用真实 branching counterfactual 构造 hard negatives。这可能启发视频或 latent world model 的 action-contrastive 表征学习。但本文没有视觉动力学、3D状态、长时 rollout 或隐式 latent，直接阅读价值低。

## Strengths

- 用同数据、同初始化的 AXTree SFT 对照隔离了训练目标，而不只与数据规模不同的已有模型比较。
- judge 被刻意拿掉上下文和动作，只能从预测表征本身匹配后果；又用 GPT-4o、Llama 复核，降低单一裁判过拟合的解释。
- 从表征 matching、训练/冻结 PRM 到端到端 agent 三层验证，且受控 ranker 实验固定 backbone、数据和监督方式。
- branching graph 提供同一真实状态的可执行动作后果，比凭 LLM 编造反事实更可靠；预测文本也显著短于完整 AXTree。
- 公开算力、GRPO、格式奖励和数据规模，并报告格式权重消融。

## Weaknesses

- matching accuracy 仍是 LLM judge proxy；训练直接优化 Qwen3-32B 判断，跨 judge 一致性虽缓解但不能排除共享偏差，也不验证预测是否完整、校准或可执行。
- 分支来自 Go-Browse 轨迹中偶然重访的状态，不枚举全部可行动作；30,920 对只覆盖五个 WebArena 域，反事实覆盖有限。
- 配对判别允许表征只抓住区分当前两个候选的局部线索，不保证全状态 fidelity、多步组合性或长期 rollout 稳定性。
- 端到端实验只用 GPT-4o policy 和 WebArena-Lite；没有其他 policy、真实网站、用户账户或开放环境验证，作者也明确将此列为泛化限制。
- 没有多训练 seed、显著性区间或错误类型统计；WebPRMBench 的若干子域上本文状态并非逐项优于 WebWorld，平均提升不能代表一致改善。
- 这是自由文本网页状态模型，方法没有处理视频时空表征、相机几何或 Dreamer/JEPA 的 latent dynamics。

## Future Work

作者明确提出在更多网页环境和 policy model 上验证，并收集更密集、覆盖更多可选动作的 branching data。还需要开发不依赖单一 LLM judge 的可执行状态验证，研究多步分支 rollout 与误差累积，并测试这种 action-discriminative objective 能否迁移到视觉或隐式状态模型。

## Rating

创新度评分：2/5 - 在网页 agent 内对训练目标和分支数据的设计清楚且有效，但属于任务特定的判别式 RL 微调，对目标世界模型方向技术增量有限。
相关度评分：0/3 (Noise) - 研究对象是纯文本/AXTree 网页智能体，不涉及视频、3D或 JEPA/Dreamer 式隐式世界模型。

## TL;DR

用分支网页轨迹训练可区分动作后果的状态表征，显著改善动作排序；属纯网页智能体，可跳过。
