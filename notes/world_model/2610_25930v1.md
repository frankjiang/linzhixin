# TESS: LLM-guided Translation, Exploration, Simulation, and Search for Embodied Task Planning

## Insight
在有限且可枚举的动作类型下，LLM 不必逐步输出整条计划：把它用于目标谓词翻译、定向探索、一次性编写动作转移函数和搜索剪枝，可让经典图搜索承担长期组合。VirtualHome 消融中，BFS 成功率 64.4%，A* 为 78.5%，再加 LLM 剪枝为 80.0%，说明结构化搜索与先验筛选互补。

## Motivation
LLM 直接规划易忽略动作前提和环境状态；经典搜索需要已知状态、转移与目标，在部分可观测家务任务中难直接使用。作者试图让 LLM 补足这三项输入，以获得可执行的符号计划。

## Method
先把自然语言指令转为场景图谓词和目标物体；LLM 引导探索隐蔽目标并累积局部场景图。再由 LLM 为约 13 类原子动作生成 Python 前提与效果函数，作为符号规则世界模型。用未满足谓词数构造 A* 启发式，按目标物体、动作前提、LLM 合理性三层筛选候选动作；找到路径后在环境中执行。世界模型是离散场景图上的规则函数，未学习视频或 3D 动力学。

## Experiment
VirtualHome 图模拟器新建 25 类任务、50 种公寓、307 类目标物体，主要测试 1000 项。TESS-GPT 在 seen/unseen-object/unseen-task 的成功率为 85.1%/71.4%/74.7%，同为部分观测的 ReAct 为 55.2%/21.7%/53.7%；ALFWorld 文本环境 seen/unseen 为 96.4%/98.5%。探索平均 19.9 步，随机探索 66.6 步。附录小样本视觉扩展在 ALFWorld 图像观测得 43%（GPT-4o 基线 24%），EmbodiedBench-ALFRED 为 59.3%（56.3%）。替换目标翻译及转移函数为真值后，500 次搜索预算下成功率升至 92.5%，说明规则模拟仍是主要瓶颈。

## Value
对世界模型外层的符号规划器、任务目标翻译和搜索剪枝有间接借鉴价值；对视频生成、3D 建模和 JEPA/Dreamer 式隐式动力学帮助有限。

## Strengths
各模块边界清楚；有探索、翻译、搜索和模拟误差消融；任务生成与成功/目标条件召回的评估可复核。

## Weaknesses
主实验在文本场景图而非像素环境；动作确定性、目标物体已可解析，难覆盖开放场景。LLM 筛选可能删去必要动作，启发式未证明可采纳，因此文中对完整性或最优性的理论措辞只适用于理想化真值模型与不剪枝搜索。视觉扩展规模及对照有限。

## Future Work
作者提出加入视觉语义落地与动态更新、非确定性动作、时序约束和更开放的任务，并提高规则模拟准确性、使用子任务分解降低搜索深度。

## Rating
创新度评分：2/5 - 将现有 LLM 模块、规则函数与 A* 组合并扩充任务集，方法新意主要在系统集成。
相关度评分：1/3 (Tangential) - 其“世界模型”是文本场景图规则模拟器，仅与目标方向的规划接口间接相关。

## TL;DR
以 LLM 构造符号规则和搜索剪枝，提高文本具身任务规划成功率；与视频、3D 或隐式世界模型研究关联有限，可跳过。
