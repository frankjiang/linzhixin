# PearlVLA: Progressive Embodied Action-Plan Refinement in Latent Space

## Insight
论文观察到 VLA 存在直接 action decoding 高效但缺 deliberation、显式文本/像素/候选动作推理更强但慢的矛盾。推论是把 deliberation 放进 VLM latent plan，并用 frozen latent world model 反馈未来 latent，可以在低延迟 action chunk decoding 前做闭环 refinement。

## Motivation
解决长时程机器人操作中 one-step reactive policy 不足的问题。同行方法用 textual CoT、visual subgoal、候选 action search、video diffusion future feature 或 world model scoring，但常有延迟、表示不匹配或搜索成本。问题关键且与隐式 world model/control 紧密相关。

## Method
PearlVLA 基于 OpenVLA-7B，把 meta-query representation 分为固定 visual grounding tokens 和可写 latent plan tokens。每轮 refinement 用 plan-conditioned world query 查询 frozen latent WM（UWM 或 VPP 替代）得到 action-free future observation latent，再经 FutureEncoder 和 RefineNet 生成 residual update 写回 plan。anchor query 和 scheduled residual 控制 drift。最后将 K 轮 refinement 后的 plan 并行解码为 H-step action chunk。

CRG-PRL 进一步用同一 refinement state 下的多个 residual 分支做 group-relative process reward，用 Robometer 对解码的 imagined future frames 评分，以 PPO 风格优化 refinement residual。

## Experiment
LIBERO 上平均成功率报告到 98.7%，suite-specific PearlVLA 约 98.5%，单一跨 suite policy 98.1%。K 从 0 到 4 带来逐步提升，默认 K=4 保持约 27.5 Hz action throughput。RoboCasa 24-task few-shot 中 K=4+CRG-PRL 达 52.9%，接近/略高 DiG-Flow 52.6。替换 latent WM 的消融显示 UWM 最好，VPP 仍优于无 WM。

## Value
对用户有较高价值：它不是视频生成世界模型本身，而是展示 latent world model 如何嵌入 VLA policy 的内部思考回路。启发是将 future latent 作为“计划修正信号”而非外部视频输出；待解决问题包括 reward model 代理偏差、frozen WM 与真实动作因果关系不够显式、计算开销较高。

## Strengths
亮点是对用户有较高价值：它不是视频生成世界模型本身，而是展示 latent world model 如何嵌入 VLA policy 的内部思考回路。

## Weaknesses
