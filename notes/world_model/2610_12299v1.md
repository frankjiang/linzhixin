# Multi-Agent Egocentric World Model with Fine-Grained Embodied Interaction

## Insight

观察：一个人的手/身体动作既决定其第一人称画面，也应在其他参与者视角显现；物品状态变化还须同步到所有视角。推论：把多路自我视角当成同一演化世界的联合观测，共享动作与环境证据，比逐路生成更易一致。去掉联合生成、共享动作或共享环境记忆的消融分别损害跨视角一致性、他人动作控制、背景一致性。

## Motivation

已有自我视角视频世界模型通常只处理单人；多智能体方法多给粗粒度移动/相机控制，缺少细致身体交互。这里的关键难点不仅是多视角画质，而是同一动作及交互后状态在各视角保持同步，关系到多智能体仿真可用性。

## Method

给定每位智能体初始帧、历史观测、文本提示、未来头部相机及身体动作，基于 Cosmos-Predict2.5 2B DiT **联合去噪两路 77 帧第一人称视频**：所有视频 token 在共享序列自注意力交互，以 agent embedding 区分视角、各路保留独立文本交叉注意。共享动作条件将本人手臂骨架及他人的 3D 身体姿态投影进目标视角，并以统一坐标下 Plücker 光线表示相机运动。共享环境记忆选历史帧重投影到目标视角，附可见性掩码；另挑覆盖互补的干净历史图作为跨路 anchor token。以 rectified flow 微调；动作是输入条件，并未生成策略。真实 CoMind 与合成双人交互分别训练检查点。

## Experiment

真实测试 100 个未见厨房/人员片段，合成测试 100 个持出场景片段；训练约 1.2 万真实配对片段、4736 合成配对片段。提出 `Senv`（无历史 warp 覆盖区域跨视角 DINOv3 相似度）、`Supdate`（历史与生成不同的已覆盖区域跨视角相似度）、合成数据的身份 `Sid`；另测相机位姿误差、手与人体动作匹配、PSNR/SSIM/LPIPS/FVD。真实集对经相同骨干、数据和共享动作改造的 MetaWorld：`Senv` 0.468 对 0.421，`Supdate` 0.466 对 0.413；他人全身 PCK 0.881 对 0.787；FVD 637.9 对 704.4。合成集 `Sid` 0.561，优于所列预训练基线。消融中去联合生成使 `Senv` 0.468→0.433，去共享环境记忆但保留共享动作使 `Senv` 0.468→0.445。

## Value

多视角同步、动作几何对齐与“只在未直接条件化区域测环境一致性”的评测思路，对交互式视频/3D 世界模型有直接借鉴价值。仍主要是条件视频生成，离可规划的共享状态模型有距离。

## Strengths

细分跨视角动作、静态环境及交互状态三类一致性；自建真实与合成配对数据；以统一训练设置改造多智能体基线并做模块消融；附录给出数据过滤与指标实现。

## Weaknesses

主实验仅两人、每次 77 帧；三人和 221 帧只是定性展示。依赖 SLAM、深度、身体姿态和分割等强外部条件，现实部署成本高；新一致性分数主要是特征相似度，未直接证明交互物体的因果状态完全一致。不同模型基线适配/预训练条件不完全等价，且没有量化实时生成开销。

## Future Work

作者提出联合建模动作与观测以支持规划、开发高效跨智能体通信和记忆以扩展人数，以及更快的视频生成以支持实时交互。

## Rating

创新度评分：3/5 - 联合去噪、共享动作和几何记忆的组合切中多智能体交互，但核心骨干与多数部件有现成基础。
相关度评分：3/3 (Core) - 直接构建细粒度动作条件的多智能体视频世界模型。

## TL;DR

联合生成多路第一人称视频并共享动作与场景记忆，改善交互状态跨视角一致性；对多智能体视频世界模型值得精读。
