# Ask the World Before Acting: Environment Probing for Calibrated Agent World Models

## Insight
论文的 insight 是：LLM agent 在行动前有时应该把“查询环境状态”作为显式动作，用 probe 来校准 belief world model。何时查询不应只由自我不确定性决定，还应看状态字段的 criticality、staleness 和依赖结构。

## Motivation
语言 agent 常在部分可观测环境中维护错误 belief，导致后续动作失败。每步都查询环境会浪费步骤，不查询又会积累错误。作者研究如何在动作和 probe 之间做权衡。

## Method
EnvProbe 维护显式 belief table。行动前可以花一步查询某个 belief field 的当前值并更新。查询评分由 criticality、staleness、verbalized uncertainty 和 dependency role 组成，并区分 procedural 与 spatial 环境。

## Experiment
实验在带 gold belief states 的受控环境中。EnvProbe-Simple 相对 Periodic 提高终端 world-state accuracy：procedural 约 +11.76、spatial 约 +3.79、overall 约 +6.45。结构项是主要贡献，自报不确定性不可靠；probe delay 会导致 ToolDAGWorld 等任务快速崩溃。

## Value
这篇对 LLM agent world model 有参考，但不是视频/3D/隐式世界模型。可借鉴的只是“主动校准世界状态”的思想。

## Strengths
把 probe 作为 action 的设定清楚；实验证明结构化查询优于固定周期；分析了 self-uncertainty 的不足。

## Weaknesses
受控环境较简化；probe 动作和真实机器人感知成本差异大；没有解决连续视觉状态估计。

## Future Work
作者建议发展 type-aware probing policies、成本敏感查询和更强 guardrails。

## Rating
创新度评分：2/5 - 主动 probe 机制实用，但技术增量有限。
相关度评分：1/3 (Tangential) - 属于语言 agent belief 模型，和目标方向间接相关。

## TL;DR
EnvProbe 把环境查询作为校准 LLM agent belief 的动作，非核心方向，可跳过。
