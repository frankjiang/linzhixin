# Learning Explicit Behavioral Models with Adaptive Questions and World-Model Probes

## Insight
Observation: 仅靠任务得分训练的agent可能获得高分但不理解环境机制，导致环境变化时脆弱。推论: 将"理解"形式化为可查询、可验证的符号化机制记忆，并用自适应QA和主动世界模型探测作为训练信号，可同时优化性能和理解。

## Motivation
解决RL agent的"高分低理解"问题——agent可能利用捷径获得高分但不具备环境机制理解。现有LLM反思/程序修复方法仅在失败后修正，缺乏对理解本身的持续训练压力。核心思想是让"理解"可测试：agent必须能回答机制问题并预测符号化的状态转移。

## Method
- **ESBM结构**: 由typed predicates（状态抽象）+ weighted rules（策略）+ bounded options（多步过程）+ mechanism memory K（转移预测）组成
- **Challenger-Optimizer Loop**: Challenger根据当前ESBM状态生成自适应QA题目和主动世界模型探测；Optimizer提出局部符号编辑；Verifier Gate用多标准接受规则筛选
- **主动世界模型探测**: 从检查点分支环境，比较K的预测与真实转移（事件/奖励/对象变化）
- **多标准验证**: 同时评估任务得分G、QA准确率A、被动转移W_passive、主动转移W_active
- 创新程度: 中等偏高。将world model作为可执行的符号化机制记忆并用对抗式QA训练是新颖的

## Experiment
- 环境: 3个Atari风格JAXAtari游戏(kangaroo/seaquest/kingkong)
- 对比: DQN/PPO/NUDGE/BlendRL/EvoSymbol（无QA验证的符号自进化）
- 4个RQ: 竞争性得分、可查询理解、可执行机制预测、机制变化后恢复
- 结果: ESBM在三个游戏上均取得最高分(104K/11.7K/2.7K)，同时产出可解释的QA答案和机制预测
- 局限: 仅在简单Atari环境验证，scale到复杂环境未知

## Value
有趣的方向——将world model理解形式化为可验证的符号系统。但场景过于简单（Atari像素游戏），与视频/3D世界模型范式差距大。对隐式世界模型方向有间接启发：如何评估agent是否真正理解了环境动力学。

## Strengths
亮点是有趣的方向——将world model理解形式化为可验证的符号系统。

## Weaknesses
不足是仅在简单Atari环境验证，scale到复杂环境未知
