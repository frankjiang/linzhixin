# GaussianDream: A Feed-Forward 3D Gaussian World Model for Robotic Manipulation

## Insight
观察：现有VLA缺乏显式3D空间建模和未来环境预测，导致精确操作（如空间关系判断、接触点定位）不稳定。方案：用3D Gaussian Splatting作为世界模型的结构化表征——训练时通过Gaussian reconstruction（当前帧）和Gaussian prediction（未来帧）提供密集3D监督，推理时丢弃所有解码头仅保留compact prefix，实现训练时密集监督+推理时轻量。关键设计：asymmetric training-inference——训练时重，推理时仅需prefix injection。

## Motivation
- 问题：标准VLA仅隐式编码3D信息，对精确空间操作不稳定；现有3D-enhanced方法只做静态anchoring无未来预测
- 同行：GeoVLA/StereoVLA等注入3D但无动态预测；video world models (DreamZero等)需要昂贵的autoregressive rollout
- 关键性：统一当前3D grounding和短时未来预测，同时保持轻量推理

## Method
- GaussianDream Prefix：learnable queries通过TGE module（Temporal Gaussian Evolution）融合多帧VGGT特征，输出1024 tokens作为policy prefix
- Current Reconstruction：prefix → 32×32 latent grid → Gaussian decoder → 256×256 dense Gaussian map → RGB/depth rendering监督
- Future Prediction：Dynamic Gaussian Head预测horizon-conditioned center displacements → 未来Gaussian states → pseudo 3D scene-flow监督
- 训练：Stage I预训练reconstruction+prediction heads；Stage II联合训练policy（flow-matching action loss）+ Gaussian losses
- 推理：仅prefix→policy，丢弃所有Gaussian解码头
- Backbone：PaliGemma/Gemma-2B + VGGT

## Experiment
- LIBERO：98.4%平均成功率（最强Spatial和Goal分数）
- RoboCasa Human-50：54.8%平均成功率（最强Pick&Place）
- Real robot：34.4%→50.0%（相比π_0.5基线）
- 消融：reconstruction alone 97.0% → +prediction 97.5% → +rendering 97.3% → +depth 98.4%，各组件互补
- 相比video/latent world model方法：无需test-time rollout，推理效率高

## Value
设计理念优秀——用3D Gaussian作为structured world model提供训练时密集监督，同时保持推理轻量。asymmetric design是实用的工程智慧。对3D世界模型方向的启发：(1)世界模型不一定要在推理时做rollout，可以作为训练时的auxiliary supervision；(2)3D Gaussian是良好的中间表征。局限：仅预测5帧短时horizon，非通用世界模型；本质更接近3D-enhanced VLA而非独立世界模型。

## 创新度：3⭐
Asymmetric training-inference设计和3D Gaussian作为世界模型表征有新意，TGE module设计合理，但各组件（VGGT、Gaussian Splatting、flow-matching policy）均为已有技术组合。

## 相关度：3 (Core)
直接使用3D Gaussian构建world model为机器人操作提供密集空间监督，核心相关。

## TL;DR
