# CRISP: Fixing Flying Pixels in Latent LiDAR Generation via Diffusion Decoding

## Insight
观察：稀疏 LiDAR 距离图的卷积 VAE 解码器会抹平前景/背景深度跃变；反投影后，插值深度成为悬在两表面之间的“飞点”。推论是潜变量中仍可能保留几何，只替换解码器即可恢复边界。作者冻结 LiDM、SVD、Wan 的编码器进行解码器替换，并在冻结 LiDM 生成器中零样本替换解码器；边界 CD/F-score 改善支持“解码瓶颈”，但未严格排除更大模型容量的作用。

## Motivation
LiDAR 生成研究主要改潜变量、条件或先验；LiDM 的环形卷积虽处理 360° 接缝，仍会跨深度边界平滑。像素扩散解码已有用于稠密深度的 Pixel-Perfect Depth；LiDAR 还必须区分有效回波与空像素。飞点会破坏合成 3D 几何，因此对 3D 世界模型输出质量是实质问题，但本文不研究世界状态动力学。

## Method
输入对数归一化的柱面 LiDAR 距离图；预训练编码器输出潜变量。适配器用逐位置通道投影和空间 token 投影统一不同主干；级联 DiT 从高斯噪声在像素空间进行速度预测，早期与中层各注入一次潜变量，粗阶段后细化，默认 5 步 Euler 采样。另一路 U-Net 利用潜变量和预测深度，预测每像素有效回波概率；二值掩码与稠密深度合成最终稀疏图。

训练用有效像素及边界加权速度误差、深度导数/多尺度梯度和低噪声重建损失；掩码用 focal、Dice、边界、Laplacian、难例挖掘与深监督，分阶段训练。默认仅训练解码器，也测试编码器联合适配。方法是将现有像素扩散深度解码改造为跨主干的稀疏 LiDAR 解码，并非新的时序生成器。

## Experiment
KITTI-360/SemanticKITTI（LiDM，64×1024）及 nuScenes（SVD、Wan，32×1024）；比较继承解码器与 CRISP，覆盖冻结编码器和单通道编码器适配。指标有 FRID/FSVD/FPVD、JSD/EMD/MMD，以及整云、边界、平滑区的 Chamfer Distance 和 F-score@0.5m。边界按有效回波之间的局部深度差定义，空/实转换不计边界；补充图 7–10 可见窄物体和深度缺口保留得更好。

冻结 SVD：FSVD **156.49→40.24**、FPVD **153.60→36.85**、整云 CD **1.331→0.640**、边界 F **0.095→0.238**；冻结 Wan 的 FSVD **100.92→32.53**；LiDM 的 FRID **2.235→0.639**、边界 CD **7.913→4.052**，但 FPVD **16.154→17.034** 变差。零样本替换冻结 LiDM 世界模型时，FSVD **37.70→31.87**、边界 CD **96.41→79.55**，而边界 F **0.0486→0.0389**、JSD **0.21181→0.21436** 反向。编码器适配后 SVD 的 FSVD/FPVD 亦退化，Wan 的 JSD/EMD 退化，收益并不统一。

消融显示去除早期潜变量融合使 CD 增约 15%、FSVD 增约 21%；去掉有效回波分支，JSD **0.071→0.109**、边界 F **0.238→0.193**；5 步是画质/速度折中。表中“五次运行”仅改变采样随机种子，并非五次独立训练。CRISP 约 5.16 亿参数；LiDM 解码从 **1.39→23.06 ms/帧**、全流程 **369→41 fps**（8×H200、编译、batch 25），成本显著。

## Value
对 3D 生成管线的启发是把潜变量、解码器和有效回波密度分别诊断，并用 3D 边界指标而非仅平均误差验证几何。冻结世界模型中的解码替换证明有实用潜力；若目标是多帧 3D 世界一致性，还必须另测时序、动作条件和物体持久性。

## Strengths
覆盖通用视频 VAE 与 LiDAR 原生主干；冻结编码器隔离解码作用；边界/平滑分区、有效回波分支及步骤数消融对应具体误差机制；主动报告反向指标和计算代价。

## Weaknesses
像素扩散深度解码已有先例，容量增至继承解码器的 7–60 倍，缺少同容量非扩散解码器对照。逐帧解码绕开 Wan 的时间压缩，未验证长序列稳定性，细结构仍可能闪烁；单深度通道不含反射率。冻结生成器的边界 F-score 下降说明解码器与潜变量分布仍不匹配。

## Future Work
作者建议多通道预测反射率、校准有效回波密度、加入时间条件抑制闪烁，以及通过蒸馏降低解码延迟；还讨论联合微调世界模型以弥合生成潜变量与新解码器的分布差异。

## Rating
创新度评分：3/5 - 将像素扩散解码系统化用于稀疏 LiDAR 并验证可插拔性，但核心思想和组件多有前例。
相关度评分：2/3 (Related) - 直接改善 3D 世界模型的 LiDAR 输出几何，未建模 3D 状态演化或多视角/时序一致性。

## TL;DR
以扩散解码和有效回波掩码缓解潜空间LiDAR飞点；冻结世界模型边界距离改善但其他指标退化，值得精读。
