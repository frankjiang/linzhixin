# GlobeBench: Evaluating Text-Based World Model Capabilities for Scalable Environment Simulations

## Insight
文本环境模拟器的答案常有正确结构却含错误状态值；隐藏状态、依赖对象更新和长历史审计构成高难样本。20 个模型在「L3 影响半径」项目的平均成功率仅 5.10%，但附录说明 977 个 L3 项中 953 个是操作器声明标签，主要是长程审计；在同一操作器内比较时，L3 与 L0 的差距反而改变符号。因此这是困难样本簇的观察，不能证明状态传播范围本身导致性能下降。

## Motivation
LLM 被用来模拟代码、工具、游戏等强化学习环境；模拟器若预测错误，训练出的代理可能利用虚假动力学。此前文本世界模型评测多按整段答案或通用评分维度打分，较难指出具体哪种状态转换能力失败。论文建立可执行参考状态和按技能诊断的基准；问题重要，但对象并非视频、3D 或 JEPA/Dreamer 式隐式模型。

## Method
构造 1,632 个多轮轨迹与末尾动作，覆盖 Code、Enterprise、Games、Math/Science、Dialogue 五域、四种能力及 19 项技能。给模型完整可见历史与动作，要求预测下一状态；固定软件后端执行该动作产生参考答案。1,137 项来自作者设计的配方（其中 955 项运行于自写规则模拟器），另 495 项改编自可执行开源后端。12 道质量门检查可解性、唯一性、可复现性等。评分先用精确、结构、数值、错误类别等确定性规则，不能裁决时交由盲化 LLM 语义评审。为诊断记录历史回溯距离与影响半径；核心贡献在数据和分层评测设计，没有提出新的世界模型。

## Experiment
对 18 个通用 LLM 与 2 个专用文本世界模型各采样一次，报告整条下一状态的二元成功率、技能/领域分项、错误类型及项目重采样置信区间。最高 GPT-6 Astra 为 49.57%（95% CI 47.06%–52.02%）；Qwen-AgentWorld 14.46%，DWM 5.21%；631/1,632 项无模型解出。已回答失败中 53.21% 至少有一个状态值错误。L0 与 L3 的池化成功率为 43.49% 与 5.10%，回溯≤40 和>40 轮为 42.28% 与 11.44%；但技能、操作器、输出长度、历史长度和半径高度混杂，同操作器内>40 轮差值为 +1.76 个百分点（95% CI −1.57 至 5.17），不能解释为距离的独立效应。6 名标注员审核 200 项参考答案，80 项重复评分；LLM 扩展审核 1,627 项。可视化为成功率热图与分项曲线，没有物理场景或视觉生成评测。

## Value
若团队要评测世界模型的状态保持、因果后果或副作用，可借鉴「执行得到真值 + 确定性优先评分 + 分技能失败分析」；尤其应避免让影响半径、时长和任务类型混杂。对视频/3D 生成质量、几何一致性与潜在规划能力没有直接基准价值，建议按评测需求选读。

## Strengths
- 执行后端生成参考答案，固定版本并发布输出与评审记录，便于重算得分。
- 技能划分、错误类别、未解项目与人类审核比单一平均分更有诊断价值。
- 正面分析了半径、历史长度与操作器的混杂，并报告受限的同组比较。

## Weaknesses
- 只测试给定历史后的单次状态预测，无法测量模型自身滚动误差或代理实际训练收益。
- 绝大多数 L3 标签为设计声明，长历史、长输出和技能相互绑定；样本量小的受控切片限制因果结论。
- 成功判定要求整个状态全对，长答案中一个值错即失败；人工共同标注的 80 项又较少覆盖最难长程审计。
- 模型各题只运行一次，置信区间不含采样随机性；部分答案依赖 LLM 评审。

## Future Work
作者希望形成更可靠的文本世界模型评测与训练信号；文中明确指出还需评测模拟器自身连续滚动时的误差累积。

## Rating
创新度评分：2/5 - 执行真值与技能诊断的基准整合有用，但无新建模方法，且与目标视觉/隐式方向相距较远。
相关度评分：1/3 (Tangential) - 仅状态转移评测理念可间接借鉴；研究对象为纯文本 LLM 环境模拟。

## TL;DR
构建可执行真值的文本环境转移基准，揭示状态错误与评测混杂；仅做世界模型评测设计时可选读。
