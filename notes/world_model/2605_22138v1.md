# Efficient Agentic Reasoning Through Self-Regulated Simulative Planning (SR2AM)

## Insight
将智能体决策分解为三个系统：System I（反应执行）、System II（仿真推理，基于世界模型的未来状态预测）、System III（自我调节，决定何时及多深入地规划）。观察到现有推理链方法在规划的存在性、结构和时域上缺乏控制，导致 token 使用效率低。

## Motivation
端到端训练的推理链智能体缺乏对规划的显式控制，大量增加推理长度但不一定提高准确性。论文通过将 LLM 本身作为世界模型实现仿真推理，并通过学习的自我调节器决定何时/如何规划。

## Method
SR2AM 在 LLM 的思维链中实现仿真推理和自我调节。两种实例化：v0.1 从提示的多模块系统记录决策，v1.0 从预训练推理 LLM 的 trace 重建结构化计划。通过监督学习 + RL 训练。v1.0-30B 在数学、科学、表格分析、网页搜索等任务上与 685B-1T 参数系统竞争，同时减少 25.8-95.3% 推理 token。

## Experiment
v0.1-8B 和 v1.0-30B 在多任务上与大模型竞争。RL 使平均规划时域增加 22.8%，规划频率仅增 2.0%——学会了更远地规划而非更频繁地规划。实验覆盖多种任务类型。

## Value
"LLM 即世界模型"的思路在 agentic reasoning 中有一定价值，但与用户关注的视频/3D/隐式世界模型方向关联很弱。三系统分解的框架设计有一定思想启发，但技术贡献主要在 LLM reasoning 效率优化层面。

## Strengths
亮点是"LLM 即世界模型"的思路在 agentic reasoning 中有一定价值，但与用户关注的视频/3D/隐式世界模型方向关联很弱。
