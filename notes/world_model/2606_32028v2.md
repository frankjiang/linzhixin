# DVG-WM: Disentangled Video Generation Enables Efficient Embodied World Model for Robotic Manipulation

## Insight
DVG-WM 的 insight 是视频 world model 中“低层动态推理”和“高分辨率视觉合成”不应绑在同一个扩散过程里。Observation 是高分辨率视频生成很慢，而机器人规划真正需要的是接触和轨迹动态；低分辨率 latent 足以预览物理过程，高分辨率细化只需少量步骤恢复细节。

## Motivation
论文解决 embodied video world model 在机器人 manipulation 中慢、粗、接触细节不准的问题。同行多直接 fine-tune CogVideoX/Wan/LVP 等大视频模型，一次性生成高分辨率未来；这会让动态学习和纹理合成相互牵制。该问题是视频 world model 落地机器人规划的核心瓶颈。

## Method
DVG-WM 两阶段生成：preview stage 在低分辨率生成中间视觉状态，捕捉接触和物理演化；refinement stage 以 4 步 denoising 生成高保真视频。两阶段之间用 flow matching 直接把动态映射到高分辨率视频 latent，并通过 latent degradation 训练细化器重建 contact-rich details，避免 pixel degradation 导致 shortcut upscaling。

## Experiment
LIBERO 上对比 CogVideoX-5B、Wan2.1-14B、LongScape、LVP-14B。DVG-WM PSNR 20.019、SSIM 0.783、LPIPS 0.120、FVD 152.36、Object accuracy 89%，整体最好或接近最好。推理时间 88.7s，对比 LVP 354.2s，约 3.97x 加速。消融显示 full model 优于 pixel degradation、naive cascading、only preview、only refine；K=4 是效果和计算的平衡。真实机器人九任务中 DVG-WM+action expert 平均成功率 62.2%，CogVideoX 为 34.0%，提升 28.2 个百分点。

## Value
对视频 world model 很有价值：它提出了一个实用分解，把 dynamics preview 作为规划所需的信息，把视觉细化作为后处理。这个结构可迁移到其他长视频/机器人 world model。

## Strengths
针对效率和接触细节的矛盾提出清晰设计；LIBERO 和真实双平台任务都有结果；速度、视频质量、object accuracy、真实成功率共同支撑结论。

## Weaknesses
仍依赖视频生成框架，单次生成时间 88.7s 对实时 MPC 仍重；语言条件而非低层动作条件，闭环规划能力依赖外部 action expert；真实任务范围有限。

## Future Work
作者认为 disentangled video generation 是可扩展 embodied world model 的方向；后续需要更实时的生成、更强动作条件接口和更开放的真实场景验证。

## Rating
创新度评分：3/5 - 动态预览与视觉细化分离有效，但属于结构化改进而非新范式。
相关度评分：3/3 (Core) - 直接研究视频世界模型在机器人操作中的效率与可用性，核心相关。

## TL;DR
把视频 world model 拆成动态预览和高保真细化，机器人视频规划值得精读。
