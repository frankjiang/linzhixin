# Operator-on-F complements value-equivalence: a planning-time diagnostic for latent world models

## Insight
论文指出：latent world model 是否适合 planning，不能只看 reward prediction 或 Bellman/value-equivalence。Observation 是 TD-MPC2 某些 checkpoint reward error 很小但 return 崩溃；推论是需要比较模型自身 k-step latent pushforward 与真实环境 pushforward 在可观测函数集合 F 上的一致性。

## Motivation
论文解决 latent world model 评价指标与规划表现错位的问题。传统 value-equivalence 强调 reward/value 一致，但 planner 实际使用的是多步 latent dynamics；如果 latent rollout 在观测几何上偏离，reward head 仍可能掩盖错误。这对 Dreamer、TD-MPC、JEPA/LeWM 等隐式世界模型都很关键。

## Method
Operator-on-F 是诊断指标，不是训练目标。给定 anchor (s_t, a_{t:t+k-1}, s_{t+k})，用模型 encoder 得到 z_t 和真实 z'_{t+k}，再用模型自身 rollout O_k 得到预测 z_hat。通过 probe phi_F 把 latent 映射到可观测集合 F，计算每个函数上的归一化误差并 RMS 聚合。F 可以是 reward/value slice，也可以加上 held-out PCA basis 表示的 encoded next-state geometry。跨架构比较时用 ridge/MLP probe，并报告 R2 控制 probe 混淆。

## Experiment
主要在 DMC cheetah-run 上评估 TD-MPC2 mt80 五个尺寸 checkpoint。reward prediction error 只在 0.028-0.091 范围内波动，Bellman residual 与 return 的 Spearman 约 -0.10，reward error 约 -0.30；而 full-F operator error 从 0.28 到 2.62，和 return 呈 Spearman -0.90。317M checkpoint 的 operator error 2.62、return 0.9，是最明显反例。跨架构 sanity check 中，LeWM 三个 seed 的 shared-F operator error 0.384±0.009，single-task TD-MPC2 为 0.840，MLP probe 和 commonly-well-probed restriction 保持排序。

## Value
对我们很有用：隐式世界模型的评估应贴近 planning-time latent dynamics，而不是只看单步 reward/value loss。Operator-on-F 也适合没有 reward/value head 的 JEPA/LeWM，用共享可观测集合比较 latent transition。

## Strengths
指标定义直接对齐 planner 使用的 k-step rollout；能揭示 reward/value 指标看不出的失败；跨 TD-MPC2 和 LeWM 做了 probe 控制；强调与 value-equivalence 互补而不是替代。

## Weaknesses
主要结果来自单环境 cheetah-run，尺寸 sweep 只有 5 个点；probe 仍可能引入表示可读性偏差；目前是诊断工具，不能直接修复模型；317M 崩溃是否普遍仍需更多任务验证。

## Future Work
作者建议与 reward/value 指标一起报告，并扩展到更多环境、模型家族、Dreamer 类 reconstruction-anchored world model，以及把 operator error 进一步用于训练或模型选择。

## Rating
创新度评分：3/5 - 提供了有用的 planning-time 诊断视角，但不是新世界模型架构。
相关度评分：3/3 (Core) - 直接研究 latent/隐式世界模型的规划相关评价。

## TL;DR
Operator-on-F用latent pushforward诊断规划错误，对隐式世界模型评估值得精读。
