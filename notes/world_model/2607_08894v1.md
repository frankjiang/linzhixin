# GATS: Graph-Augmented Tree Search with Layered World Models for Efficient Agent Planning

## Insight
论文的 insight 是：很多 LLM agent 规划任务的动作效果可以被形式化或从日志学习，不必每个 search node 都调用 LLM。将 world model 分层为 symbolic/learned/generative，并把 LLM 退化为未知 transition 的一次性 bootstrap，可以把规划从随机 LLM-guided exploration 变成确定性的 UCB search。

## Motivation
ReAct、LATS、Tree-of-Thoughts 等方法在多步规划中频繁调用 LLM，成本高且有随机性。作者想解决 LLM agent planning 的效率和可复现性问题，尤其是有分支、死路、资源约束的任务。问题本身重要，但和视觉/3D world model 不同，更接近符号规划和 tool-use agent。

## Method
GATS 由三部分组成：

- Layered World Model：`W(s,a)->(s',p)`。L1 是 STRIPS-style precondition/effect 精确匹配；L2 是从 execution logs 统计 action effect，置信度随 count 增长；L3 是 LLM 对未知动作预测，并缓存。
- State-Transition Graph Memory：以 canonical state key 合并不同路径到达的同一状态，边上存 action、successor、world model confidence、layer 和 search statistics；跨 planning step 持久化，支持 dead-end reuse。
- UCB over graph edges：每个可行动作视作 bandit arm，按 `Q + c sqrt(2 ln N / N_a)` 选择；value 可乘 world model confidence，并惩罚低置信 transition；StateValue 用当前图中到 goal 的最短距离估计。

创新主要是把经典符号规划、transposition table、UCB 和 LLM fallback 组合到 LLM agent setting。

## Experiment
作者构建 100 个 synthetic multi-step planning tasks，含 easy/medium/hard、分支、dead-end、资源管理；还做 12 类 stress test，每类 10 个任务。对比 Greedy oracle、ReAct、LATS。

主结果：synthetic tasks 上 GATS b=10 成功率 100%，LATS b=10 为 92%，ReAct 为 64%；GATS planning 阶段 0 LLM calls，LATS 每任务约 37 calls。budget 消融中 b=1 为 0%，b=5 为 84%，b=10 达 100%。Stress test 总体 GATS 100%，LATS 88.9%，ReAct 23.9%，在 coding/web/deep horizon 类别领先 36.7 个点。

world model 消融显示 full、no_l1、no_l3 都 100%，但 no_l1 的 L2 预先从同分布 execution traces 初始化。full model 在 synthetic tasks 中 L1 hit rate 100%，L2/L3 planning 使用率 0。

## Value
对“world model + planning”的抽象有启发：规划器不应把 LLM 当作每步 transition oracle，而应把可形式化/可缓存的 dynamics 独立出来。但对用户关注的视频、3D、JEPA/Dreamer 隐式 world model 的直接价值有限。

## Strengths
工程思路务实；清楚区分 L1/L2/L3 成本；图记忆和缓存使 LLM 调用摊销；实验明确展示 deterministic search 相对随机 LLM search 的优势；作者对比较不公平性有一定自我说明。

## Weaknesses
核心实验是 synthetic 且 L1 动作规格完整，导致结果很大程度上是经典规划优势；full model 中 L1 处理 100% transition，难以证明 L2/L3 在真实开放域的价值；no_l1 预初始化 L2 来自同分布 traces，设置偏理想；没有真实 ToolBench/APIBench 主实验；BFS value 在大动作空间和长 horizon 下指数复杂。

## Future Work
作者提出：在真实 API benchmark 和部分可观测场景验证；从生产 execution traces 学 world model；结合 RAG 查找 action spec；用 learned value network 扩展到更大 action space。

## Rating
创新度评分：2/5 - 有用的系统组合，但主要是经典规划/UCB/缓存思想在 LLM agent 中的重组。
相关度评分：1/3 (Tangential) - 属于符号/LLM agent planning，与视频/3D/隐式 world model 主线间接相关。

## TL;DR
用分层符号/日志 world model 支撑确定性树搜索，对规划有启发但主线可略读。
