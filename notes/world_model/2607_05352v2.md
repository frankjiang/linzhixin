# Multiplayer Interactive World Models with Representation Autoencoders

## Insight
核心 insight 是多智能体世界模型不能把其他 agent 当背景，而要显式条件化多个 agent 的 action streams，并在共享 latent 中联合生成多视角。Observation：单智能体视频世界模型容易误分配 agency、忽略某个玩家动作或丢失离屏状态；多视角和多动作流能减少未来不确定性并约束共享物理状态。论文还证明 latent space 质量对长时稳定比像素重建更关键。

## Motivation
现有 playable/game world models 多是单玩家控制，难以支持 self-play、多智能体训练、counterfactual policy evaluation 和人机协作。Rocket League 提供高速 3D 刚体碰撞、四玩家协作/对抗、精确动作日志和物理状态，可作为多智能体交互世界模型试验场。目标是实时生成四个玩家视角，并保持动作响应、跨视角一致和长时稳定。

## Method
MIRA 由视频表征自编码器和 latent diffusion world model 组成。Codec 使用冻结 DINOv3-L 多层特征，学习线性 bottleneck，将 20 fps、288x512 视频压到 10 Hz latent，每个 token 对应 32x32 区域，通道 32；decoder 是 causal space-time ViT，用 L1、LPIPS 和 DINO feature consistency 训练，无 GAN/KL。

世界模型是 5B 参数 flow-matching transformer，在 latent 空间做 diffusion forcing：每帧独立采样 flow time，使训练时上下文混合 clean/noisy，缓解 rollout exposure bias。模型用 factorized spatial bidirectional attention + temporal causal attention，RoPE 编码空间和秒级时间。动作条件通过 AdaLN 注入：四个玩家的九键控制先 per-player embedding，再 concat 成 conditioning vector。四个玩家视角在 latent 高度方向 tiled，一次联合预测，空间注意力可跨视角对齐共享物体。训练先单玩家预训练，再多人联合训练；action dropout 让模型在缺失某玩家动作时自己补全其行为。

## Experiment
数据为约 10,000 小时 Rocket League 2v2 bot 比赛，82,983 matches，四玩家视频、动作和物理状态同步记录。实时推理用 rolling context、streaming KV cache、few-step distillation 和 decoder 分离，5B 模型在单张 B200 上输出 20 fps，约 70 ms 生成两个视频帧。

实验很系统。Latent vs pixel：latent gFID 10.7、gFVD 163.1、ARR 0.91；plain pixel gFID 104.9、gFVD 1456.3、ARR 0.61。冻结 DINOv3-L latent 比从头训练 encoder 更适合生成和长时稳定，5 分钟 rollout drift 更小。Diffusion forcing 明显优于 teacher forcing：gFID 10.7 vs 32.5，gFVD 163.1 vs 944.1。ARR 与人类动作遵循偏好高度相关，Pearson 0.84、Spearman 0.93。模型缩放从 100M 到 5B 带来更低 FVD 和更低 ball-position probe error。失败包括静止球自发运动、未按键 boost/jump、时钟/比分漂移、replay 发散和单玩家模型丢失离屏车辆。

## Value
这是本批最值得读的交互视频世界模型之一。它不仅展示大模型 demo，还给出 latent 选择、训练目标、多玩家 conditioning、动作可控性、物理 state probe 和失败模式的系统证据。对我们启发是：世界模型评估必须包含 action adherence、physical probe、long-horizon stationarity 和 cross-view consistency，不能只看画面质量。

## Strengths
- 首个高动态四玩家实时交互世界模型之一，任务难度高且数据/代码/demo 释放。
- Representation autoencoder 设计和多项 codec 消融很扎实。
- 明确比较 diffusion forcing、teacher forcing、pixel latent、多玩家训练策略。
- ARR、game-state probe、人评和失败案例共同支撑“可控世界模型”评价。

## Weaknesses
- 场景仍是单一游戏、三张地图、一个 bot 策略族，行为和视觉分布有限。
- 物理是游戏引擎物理，不等同于真实机器人/驾驶物理。
- 需要真实 gameplay clip 预热，完全从任意状态初始化的泛化未充分证明。
- rare events、HUD/score、长记忆和静止状态仍会失败。

## Future Work
作者提出扩展到更多样、人类化行为、更长记忆和真实环境。进一步可做：显式状态记忆、更多 agent/policy 分布、真实机器人/驾驶多体交互、可用于训练 agent 的闭环 RL 验证，以及对 contact/dynamics 的更严格物理指标。

## Rating
创新度评分：4/5 - 多智能体动作条件、RAE latent、实时长时 rollout 和系统评估结合很强；但核心组件仍基于现有 latent diffusion/DiT/RAE 技术。
相关度评分：3/3 (Core) - 直接研究可交互视频世界模型、latent 表征和多智能体动态。

## TL;DR
MIRA 用 RAE latent 和四玩家动作条件生成实时 Rocket League 世界，实验扎实，值得精读。
