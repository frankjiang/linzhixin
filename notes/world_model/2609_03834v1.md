# Semantic Bayesian World Models

## Insight

有，但属于架构性洞见而非已验证结论。论文观察到：知识图谱能提供 URI、ontology 和演绎闭包，却只能表示断言存在与否；基础模型能输出概率，却把信念绑定在字符串和参数中，易随措辞变化且不满足概率一致性。因此二者的结合长期停留在“检索三元组再喂给模型”。作者推论：应把世界状态本身表示成 RDF 图上的概率分布，让 ontology 约束 prior、观测做 Bayesian conditioning、动作改变转移核。

关键形式是蕴含单调性 `A |= B => P(A) <= P(B)`：subclass/subproperty 约束概率上下界，disjoint classes 的交概率为零，domain axiom 给出概率为一的条件关系。由此可把神经 scorer 的不一致输出投影到 axioms 定义的凸多面体，形成可微的 semantic calibration layer。论文用家庭安防、保险聚合和 car-wash planning 三个 thought experiments 说明可审计信念、跨来源更新及语义规划的潜力，但没有实现或证明该完整系统可行。

## Motivation

自主 agent 必须在不完备、噪声和时限下决策。传统知识图谱的 open-world assumption 只能区分“未知”和“已陈述”，不能携带信念强度；LLM 的 token 概率又不是稳定的命题概率。既有 probabilistic ontology、Markov logic、ProbLog、BayesOWL、MEBN 等各解决局部问题，却缺少 web-scale 数值来源、statement-level 原生标注和面向 agent 的统一动态模型。

这是语义网与神经符号 AI 的重要议题，但对用户关注的视频、3D、JEPA/Dreamer 世界模型并非关键瓶颈。文中“world model”更接近共享的符号化信念数据库，而非从感知序列学习的隐式动力学。

## Method

作者定义 `M=(Sigma, P0, T, O)`：`Sigma` 是词汇与 TBox，`P0` 是 RDF graphs 上的 prior，`T(G'|G,a)` 描述动作引起的 graph edits，`O(o|G)` 把传感器、信息抽取和模型 log-probability 映射为 likelihood；belief state 是图分布。

表示上，以 subject-predicate-object 三维稀疏张量存边缘 prior，单事件条件扩为六维、双事件条件扩为九维；缺项通过 ontology 邻域上的 semantic Bayesian tensor completion 估计。RDF 1.2 statement annotation 保存概率、校准方式和 provenance；SPARQL `WHERE` 被解释为 conditioning，`DELETE/INSERT` 被解释为 do-style graph surgery，条件结构可用 triple-pattern 节点的 lifted Bayesian networks 表示。

构建管线为：从多语网页抽取带 log-probability 的 typed triples，按 URI 跨语言聚合并保留来源，经语义约束校准和 tensor completion 得到 `P0`，再加入 `T` 与 `O`。这是一份 research agenda；没有给出联合分布参数化、学习目标、近似推断算法或端到端系统。

## Experiment

没有实验、消融、基准或定量指标。Figure 1 仅以 Venn 图定位 SBWM 位于 Bayesian networks、knowledge graphs、foundation models 三者交集，并以稀疏三维张量示意 graph prior；Table 1 是作者对三类技术能力的定性判断，不是测量结果。

正文的证据全部来自 thought experiments：安防 agent 合并警方、快递公司、家庭和相机的独立信念并评估开灯动作；保险案例按 ontology entailment 而非字符串频率聚合；car-wash test 用规则回溯得出必须开车。它们说明预期接口，却未比较 KG、LLM 或 probabilistic-programming baseline，也未验证校准、可扩展性或规划成功率。

## Value

论文最有价值的部分是把可审计概率信念、稳定语义标识、来源和干预放在同一接口中，可作为视觉世界模型之外的 symbolic memory/reasoning layer。ontology-constrained calibration 也可能约束感知模型输出的一致性。

不过它没有回答视频/3D 世界模型如何学习空间状态和连续动力学，也没有 JEPA/Dreamer 式表示或 rollout。对我们是外围架构灵感，不宜把概念上的完整性当作已实现能力。

## Strengths

- 清楚指出 Boolean KG 与概率式 agent 的表示错位，并给出简洁、可讨论的 `P0/T/O` 定义。
- 蕴含单调性、disjointness、provenance 和 belief exchange 形成一致的设计原则。
- 三个案例覆盖感知不确定性、跨来源聚合与行动规划，直观展示为什么命题级概率比字符串置信度更可审计。
- 主动承认 coreference、校准和推断复杂度等关键难题。

## Weaknesses

- 本质是 position paper：没有原型、数据、训练细节或任何实证，声称三领域交集“无人占据”也缺少系统性文献论证。
- 单个三元组的 probability annotations 不能唯一确定图上的联合分布；高阶条件张量指数增长，而 weighted model counting 本身为 #P-hard。
- SPARQL update 只是数据库操作，不会自动获得 causal do-semantics；若 `T`、confounders 和副作用未建模，“graph surgery”等同干预的说法过强。
- LLM log-probability 不天然是事实概率，跨 prompt/model 的校准不稳；对来源相关性、冲突先验和恶意发布者也未给出机制。
- “纯语言模型不可能扩展到超人智能”的强 conjecture 没有理论或实验支持，且不是 SBWM 可行性的必要条件。

## Future Work

作者列出需建设的组件：W3C belief-annotation vocabulary、probabilistic entailment regimes、probabilistic SHACL、semantic calibration layers 与 federated belief exchange。更基础的问题包括概率化 identity/coreference、稀疏分解与 lifted inference、来源可靠性和跨模型/措辞校准。还需要先实现小规模端到端原型，并以 posterior calibration、推断成本和决策收益检验这些主张。

## Rating

创新度评分：2/5 - 将语义网、Bayesian belief 与 agent world model 组织成完整愿景有启发，但主要组件已有且没有实现、证明或实验。
相关度评分：1/3 (Tangential) - 可作世界模型的符号信念层参考，却不直接涉及视频、3D 或 JEPA/Dreamer 隐式动力学。

## TL;DR

提出以概率知识图谱承载可审计信念与干预的SBWM；偏语义网愿景，相关者可选读。
