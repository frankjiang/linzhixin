# LUCID: Latent-Skill Unified Control via Imagined Dynamics for Long-Horizon Humanoid Loco-Manipulation

## Insight
高维接触动力学逐关节 rollout 容易累积误差，但长期任务真正需要预测的是“一个可复用技能执行后，任务状态如何变化”。把 locomotion/transport/release 等技能做成离散 anchor 加连续变体，并让世界模型只预测每 20 个低层动作后的 macro-state，可显著提高多物体 handoff；world-model vs model-free 消融在稀疏/稠密奖励及 ID/OOD 均支持技能级想象的作用。

## Motivation
人形 loco-manipulation 已有强单技能控制器，却常靠 FSM、脚本交接或每任务 model-free policy 串联，无法预见当前选择对后续物体的影响。用 Dreamer 式 imagination 在技能时间尺度规划，是长程控制的直接关键问题。

## Method
第一阶段以 adversarial imitation、任务奖励和交互 curriculum 训练低层 policy；latent 由 $N$ 维 one-hot semantic skill anchor 与连续噪声拼接归一化，低层 policy 冻结。第二阶段每 20 LLC steps 由高层 actor 选 macro latent，确定性 MLP world model 预测 compact task state、reward 与 continuation；真实 simulator replay 持续刷新，DreamerV3 式 actor-critic 在 12 步 imagined rollouts 上更新。categorical skill 初期以几何 oracle BC warm-start，系数退火为零。

## Experiment
HITR 组成 62 个 ID、20 个 OOD 两物体任务，三 seeds；基线在每次 handoff 还被允许重置到有利姿态。LUCID 的 ID SR2 73.4%，最强 HumanVLA 39.8；OOD 为 68.4 vs 37.0，APE 0.32/0.52 m。训练只见两物体，延长到五物体仍有约 21% SR5，HumanVLA 5%。相同 HLC 下，world-model imagination 相比 model-free 的 SR2：ID 稀疏 73.5 vs 59.3、OOD 63.1 vs 42.8；稠密奖励也分别提高 12.1/17.1 点。unstructured ASE latent 虽 command probe 0.95，却在 ID/OOD SR2 都为 0，说明可解码多样性不等于任务可用技能结构。

## Value
LUCID 展示了 Dreamer 思想与 option/skill abstraction 的自然结合：世界模型无需模拟每个关节，只需在与决策匹配的时间尺度预测任务进展。对长程机器人世界模型很有启发；当前结果仍是 privileged-state 模拟，视觉世界模型和真机迁移尚未证明。

## Strengths
- world model、结构化 skill interface 与低层控制职责划分清晰。
- 对 model-free HLC 做同 reward 的直接消融，能支持 imagination 的边际价值。
- 包含 OOD 布局和超训练长度的 3–5 物体链。
- 基线 handoff 获有利重置，仍明显落后，主成功率结果较有说服力。

## Weaknesses
- world model 输入 compact privileged state，非视觉/部分可观测建模。
- 结构化技能语义和 geometry oracle 注入大量任务先验，unstructured baseline 的 0% 可能反映接口不公平。
- 只在 Isaac Gym 单一 humanoid/任务族、三 seeds，无真实机器人或 sim-to-real。
- deterministic MLP 不表达接触结果的不确定性；长程五物体仍降至 21%。
- 低层 curriculum、参考动作和 8192 parallel env 成本高，缺少样本效率/总算力分析。

## Future Work
作者提出视觉控制、更广任务/物体/embodiment 与真机迁移；还可学习而非预定义 skill 语义，引入 stochastic macro dynamics 和 uncertainty-aware planning。

## Rating
创新度评分：3/5 - 技能级 Dreamer 与结构接口组合有效、长程结果强，但组件与 privileged-state 设置偏增量。
相关度评分：3/3 (Core) - 直接研究 Dreamer 式 imagined dynamics、层级 latent 技能和长程控制。

## TL;DR
LUCID 用技能级世界模型想象长程人形任务，模拟增益强但依赖特权状态和预定义技能，值得精读。
