# 4Director: Controlling Video World Models with Rigid 3D Geometry

## Insight
2D 框/轨迹缺少深度和姿态，点云或高斯代理又缺失物体背面；当物体转身或出画重入，生成器需重造未见几何，容易丢身份。若先从单帧重建完整网格，再用每帧一个刚体变换控制，几何与遮挡可先确定，视频模型只需补外观及非刚体细节。论文用转身示例和控制表示消融实证支持，但网格完整性依赖单图重建质量。

## Motivation
专业视频制作希望同时精确指定相机和各物体的三维轨迹；现有图像平面控制有歧义，稀疏 3D 轨迹难以维持未见表面的视角一致性。这是视频/3D 世界模型可控生成的核心问题。

## Method
- 输入图像经 MoGe-2 估深和内参、SAM2 分割；背景反投影为点云，每个物体由 Pixal3D 重建完整 canonical mesh，放入统一场景坐标。用户指定相机轨迹及物体逐帧 SE(3) 刚体变换，也可从参考图插入新物体。
- 将场景渲染成深度视频，作为 Motion Adapter 的条件注入冻结的 Wan2.1-VACE-14B 生成器；适配器用流匹配训练，生成器补足材质、光照、遮挡后的背景和非刚体动作。
- 构建 RealCOD-Rigid：从 RealCOD-25K 估计深度、相机、3D 轨迹和稳定刚体核心，重建及对齐网格，得到 20,774 个训练片段。提出身份门控 IoU：只在 VLM 判定同一物体且结构完好的帧计 mask IoU。

## Experiment
- 100 个留出视频，同运动转换给 MotionCtrl、Perception-as-Control、SymphoMotion、VerseCrafter。4Director 的 FID/FVD 为 44.1/370.4，对次优 45.8/405.4；相机旋转/平移误差 3.65°/0.122，对次优 3.89°/0.132；身份门控 IoU 60.4，对次优 54.8。20 人评测的控制准确度 4.82/5，对次优 2.39。
- 2D 框、3D 框、只平移网格、完整刚体网格消融的 IG-IoU 依次 48.5、50.3、53.0、60.4，支持深度、完整表面、旋转三者互补。LoRA 小适配器 15.3M 参数也有 57.3 IG-IoU。
- 指标含视频质量、文本对齐、相机误差、身份与位置联合评估及用户研究；相机轨迹估计和身份门控本身依赖自动模型。

## Value
给视频世界模型提供可编辑的显式 4D 场景接口，完整网格可作为跨视角身份锚点。对交互式世界模型仍需加入关节级控制及真正的状态动力学，而不只生成指定轨迹。

## Strengths
- 一次网格重建配合统一相机/物体坐标，解决旋转、遮挡和出画重入的控制难点。
- 大规模自动标注数据、成体系的控制表示消融与身份门控指标支撑方法分析。

## Weaknesses
- 刚体控制不能规定跑步、跳跃等关节或形变动作；附录中倒立舞者被锁在首帧姿态。
- 单图补全的背面可错，背景点云只有初见部分，未知区域仍靠生成器幻觉；不具备可验证的物理交互机制。
- 基线使用各自原生分辨率和片长，且部分只生成 16 帧，对 81 帧目标的质量比较存在设置差异；IG-IoU 受 SAM3 与 Qwen3-VL 判断误差影响。
- 61 个用户自编轨迹及物体插入案例只有定性展示，尚无对应的可量化目标视频。

## Future Work
作者明确提出用关节式部件扩展刚体场景，使细粒度非刚体动作也能直接指定；附录还提出对新领域、物体和控制分布持续适配，并保持旧能力。

## Rating
创新度评分：4/5 - 完整网格逐帧控制、深度适配器、自动标注与身份指标形成较强系统贡献，效果显著。
相关度评分：3/3 (Core) - 直接研究 3D 可控视频世界模型。

## TL;DR
以完整物体网格和刚体轨迹驱动深度条件视频生成，显著提升转身与重访控制；值得精读。
