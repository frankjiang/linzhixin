# An Energy-Based Perspective on Machine Learning

## Insight
观察：分类、生成、表征学习与规划看似采用不同目标，却常可写成能量、推断、学习三项选择；最大似然、NCE、伪似然、分数匹配等梯度都可理解为数据正样本与不同来源负样本的对比（§2.6）。进一步，双线性转移能量 $E(s,a,s')=-\phi(s,a)^\top\nu(s')$ 可用随机傅里叶特征近似分解转移核，使任意策略的 $Q^\pi(s,a)$ 对同一动力学特征线性（§6.4）。这些是对已有方法的推导与统一解释，并非本文提出的新世界模型或新定理。

## Motivation
现有文献按监督学习、扩散、对比学习、RL 等领域分述，难以看清模型究竟学了什么、推断为何昂贵、何时可以组合。本文提供选择方法的共同坐标。对世界模型而言，关键问题是学到可复用的动力学表示，以及将动力学、行为先验和新任务约束组合起来；综述本身并不解决视频或 3D 建模的具体性能瓶颈。

## Method
- 统一框架：$p_\theta(x)\propto e^{-E_\theta(x)}$；逐一考察**能量表示、推断/采样、学习目标**及配分函数。最大似然需模型负样本；NCE 用噪声负样本；分数匹配绕过配分函数；短链对比散度较便宜但可能漏掉远离数据的伪低能区域。
- 隐式世界模型的具体路径（§6.4）：用排名 NCE 或多噪声尺度分数匹配学习 $p(s'\mid s,a)\propto e^{\phi(s,a)^\top\nu(s')}$；冻结 $\phi$，用随机特征近似转移核，再在该特征上以 TD 拟合价值函数，无需从世界模型采样。部分可观测情形可把状态换成短历史窗口。
- 轨迹规划（§6.5）：$E(\tau)$ 拆为动力学、行为先验、奖励/代价及终点目标，用 MPPI、CEM、梯度或扩散采样。视频规划实例以视频生成模型产生观测轨迹，再由逆动力学模型求动作（式 155）。不同能量相加对应分布乘积，但噪声尺度逐级相加分数或逐 token 归一化，并不严格等于目标分布的乘积。
- 创新主要在跨领域的系统化解释和推导；列举的模型、学习器及规划器均来自已有工作。

## Experiment
本文为 78 页教程，**没有新的训练、消融、对比实验或性能指标**。图 4、7–10 等用于说明既有论文的采样、隐式世界模型和视频规划；附录表 3 按能量、推断、学习与配分函数归纳已有方法，不能视为本文的新实验结果。

## Value
可为隐式世界模型设计提供一张方法地图：先确定转移能量和行动条件，再按需求选择 NCE/分数匹配、采样规划或直接学价值表征。对视频规划，能量分解说明如何复用生成模型并接入目标/约束。实操时须另外检验模型校准、组合能量尺度、采样误差与长时动态；本文没有给出这些问题的实证答案。

## Strengths
从配分函数这一共同难点推导多类方法，明确正负样本、近似推断和计算代价；§6.4–6.5 给出世界模型到价值学习及轨迹规划的可操作数学联系。指出“逐噪声尺度分数相加”和“逐 token 相乘”不等于对最终分布做精确组合，避免误用组合生成。

## Weaknesses
没有新算法或原创实验，不能据此判断哪种隐式模型在视频/3D、长时预测或控制上更优。EBM 视角覆盖很广，部分联系只是对已有模型的重新表述；能量尺度不一致、组合后不可归一化和采样困难，会限制规划可用性（§8）。

## Future Work
作者未提出明确的新实验计划；讨论建议沿“表示、推断、学习”三轴替换组件，并重点解决组合能量的尺度、归一化与高效采样问题。
