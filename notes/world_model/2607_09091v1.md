# Beyond Time Shifts: Adapting Omni-LLM as a Reference-Free Evaluator for Generative Audio-Visual Models

## Insight
论文的 insight 是：现代音视频生成模型的同步错误不再只是时间偏移，而是结构幻觉、非对称因果关系和连续事件声画不一致；人类更擅长 pairwise preference，但实用指标需要 reference-free scalar。于是可用 pairwise 人类排序训练一个连续打分的 Omni-LLM，再用 listwise RL 让分数拓扑全局一致。

## Motivation
音视频生成正在被视作 world simulator 的一部分，声画同步可作为物理因果一致性的 proxy。传统 SyncNet/offset/contrastive metric 假设音视频结构正确，只需检测 temporal shift；对生成样本中的语义错配、缺声、音色/事件数量不符不敏感。论文要构建一个无需参考答案、可对单个生成 AV pair 打连续分的 evaluator。

## Method
三阶段：

1. SynthSync：对真实视频 anchor，用 10 个 V2A 模型生成候选音轨，由专家做 pairwise preference，形成每个 anchor 下的 ordinal ranking。
2. Continuous Omni-LLM evaluator：基于 Qwen2.5-Omni-3B，替换离散语言 head，在 `[SCORE]` token hidden state 上接 MLP 输出实数分数。用 Bradley-Terry-Luce pairwise ranking loss 训练，并用 curriculum 从容易比较的 pair 逐步过渡到细粒度 pair。
3. R-GRPO：把确定性分数视作 Gaussian policy 的均值，对同一视频下候选列表进行 listwise rollout，用 composite ranking reward 优化全局 causal-semantic topology，同时用 clipped surrogate 和 KL 约束保持稳定。

## Experiment
SynthSync 使用 VGGSound/FoleyBench test split 视频，10 个 V2A 模型生成音轨，20 名专家分 3 组标注，约 306K pairwise annotations。指标包括 NDCG、MRR、Kendall/Spearman、Top-1/Bottom-1 Acc、Pair Acc。

主结果：Ours 达到 NDCG 0.9435、Kendall 0.4899、Spearman 0.5837、Top-1 61.40、Pair Acc 72.38，优于 JavisScore、RALI、Q-Align、VQ-Insight 和 off-the-shelf Omni-LLM。无 R-GRPO 版本 Pair Acc 71.07，说明 RL 带来增益。

SyncBench 用 185 个 prompt 评估 Sora-2、Veo-3.1、WAN-2.6、Vidu-Q3、Grok-3、LTX-2；作者称其 metric 排名更符合人类直觉，而传统指标排名波动大。Best-of-N 实验中用该 metric 做 reward，在 cross-metric generalization 上优于多数传统指标。消融显示 scalar ranking 明显优于文本分数/回归，SynthSync、PFT、RL 都有贡献，dual reward 优于单 pair/list reward。

## Value
对视频 world model 的间接价值在评估：如果生成模型要成为 world simulator，声画因果一致性需要比 FID/FVD 更细的 metric。该工作可作为 AV generation/world simulator 的 evaluator 或 reward model，但不提供 world model 架构、表示学习或规划方法。

## Strengths
问题定义准确，指出“时间偏移 benchmark”与真实生成失败不匹配；pairwise 人类偏好到 reference-free scalar 的桥接有方法新意；指标、reward model 和 SyncBench 形成闭环；消融较充分。

## Weaknesses
与 world model 本体关系较弱；依赖专家偏好，主观性和标注一致性细节有限；SyncBench 排名对闭源模型的评估可复现性不强；把 AV 同步等同于物理因果一致性仍是 proxy；R-GRPO 复杂度较高，实际训练/部署成本未充分展开。

## Future Work
作者未单列 future work。可推断方向包括扩展到更长视频、更开放事件类型、更多 closed/open AV models，以及把该 evaluator 更系统地用于生成模型训练 reward。

## Rating
创新度评分：3/5 - 在 AV 生成评估上有较完整的新数据和训练范式，但不是 world model 本体创新。
相关度评分：1/3 (Tangential) - 只间接服务视频 world model 的评估，与用户核心建模方向关联有限。

## TL;DR
把声画因果同步做成 reference-free 评估器，可用于视频生成评测，建模方向可跳过。
