# MM-ABC: Towards Generalist Mobile Manipulation via Seeing, Coordinating and Imagining

## Insight
观察：移动操作的基座会改变机械臂可达工作空间，动作流虽可分开表示，却必须交换信息；未来几何也能作为当前视觉表征的训练信号。另在已知 13 维动作流形的合成任务里，直接预测干净动作比预测速度少保留噪声：高噪声处端点方差 0.023 对 0.54，五步采样的任务分配误差 0.0090 对 0.0106。真实策略消融支持效果，但合成推论依赖特定网络与训练设定，非一般等价参数化的普遍优越性证明。

## Motivation
移动操作需在连续自运动下保持空间感知，同时协调细粒度机械臂动作与大尺度底盘位移。已有显式 3D/预测模型代价较高，机械臂与底盘分流又可能失去协同。该问题对具身行动重要；本文主目标是操作策略，而非可独立推演的世界模型。

## Method
Qwen3-VL-4B 编码多视图与指令，稀疏 DeepStack 从第 11/19/27/35 层提取特征，以零初始化门控逐层注入动作专家。MM-APT 用 16 层双动作流 Transformer 分别建模机械臂和机身，在同段内联合注意力交换信息；远期 token 可读近期，近期不可读远期。将 64 步动作映射至掩码化的统一 80 维空间（左/右臂各 29、机身 22），直接预测干净动作，以五步 Euler 采样。仅训练时另设未来分支，在 +32/+64 步预测冻结 VGGT-Ω 的几何特征，以余弦损失监督共享感知骨干；未来 token 与动作 token 隔离，部署时删除。预训练使用 12 个数据集、17 种机体、5166.2 小时、40 万余段轨迹，并做控制语义审核和时间连续性过滤。创新属于多种已有手段的针对性组合。

## Experiment
EBench 26 任务成功率 44.71%、阶段分 59，π0.5 为 41.41%、54；RoboCasa365 50 任务平均 61.2%，ABot-M0.5 为 54.2%。ManiSkill-HAB 三套任务均值 86.4%/70.2%/65.6%；LIBERO 99.1%，无需扰动再训练的 LIBERO-Plus 为 82.8%。五项实机长任务各 20 次，平均成功率 83%，π0.5 为 71%。RoboCasa365 16 项复合任务从零训练消融：完整模型 32.8%；速度预测 29.2%，移除未来几何监督 24.9%，仅末层感知 25.6%，交错条件注入 22.0%。这表明各模块有贡献，但完整模型在部分单项任务并非最佳。

## Value
对隐式/3D 世界模型的直接启发是：把未来几何表示作为动作模型的辅助监督，部署时仍可只保留快速策略；对世界模型与行动模型耦合方式及评价有借鉴价值。尚需验证未来特征是否真正编码可干预的状态转移，以及能否用于反事实规划，而不只改善行为克隆。

## Strengths
- 同时覆盖合成控制实验、从零训练模块消融、多项模拟基准与实机对照。
- 未来分支与动作 token 隔离，避免训练时未来观测泄漏到执行策略。
- 对异构控制通道做语义对齐、有效维度掩码与时间连续性过滤，工程细节具体。

## Weaknesses
- 未来“世界想象”只是教师特征预测；没有证明模型能滚动模拟、比较候选动作或进行长期规划。
- 大规模预训练和多模块改动使跨方法性能差异不能单独归因于世界预测分支；组件消融虽隔离模块，却未复用预训练规模。
- LIBERO 已近饱和；LIBERO-Plus 的相机/机器人初始状态扰动仅 73.6%/66.5%，表明视角与姿态变化仍困难。

## Future Work
作者没有给出明确的后续技术路线；将未来几何预测扩展到动作条件反事实、长期滚动预测和可验证的空间状态，是由现有局限推得的方向。

## Rating
创新度评分：3/5 - 多流动作建模、稀疏多层条件与训练期未来几何监督的有效组合，单个组件并非新范式。
相关度评分：2/3 (Related) - 涉及未来 3D 几何表征监督和隐式预测，但核心任务是机器人策略而非世界模型本身。

## TL;DR
MM-ABC用未来几何特征监督和双流干净动作预测提升移动操作，展示世界表征如何服务策略训练；值得精读。
