# Physically Viable World Models: A Case for Query-Conditioned Embodied AI

## Insight
现有"观测预测型"世界模型存在结构性缺陷：它们优化的是视觉相似度而非物理正确性。核心论点：不同物理系统可以产生几乎相同的视觉观测，但在干预(intervention)下行为迥异。因此，embodied AI的世界模型不应追求"最详尽的世界描述"，而应根据给定的干预查询(intervention query)构建"保留相关物理区分的最简抽象"。

## Motivation
- 问题：视觉上合理但物理上错误的世界模型会导致不可行的动作推荐、错误的交互预测或不安全行为认证
- 根本原因：基于观测序列的预测本质上是反问题(inverse problem)——同样的观测可由不同物理系统产生
- 挑战场景：改变材料密度、恢复系数、流体粘度等隐含物理参数，外观几乎不变但碰撞/变形/流动行为完全不同

## Method
- **不是提出具体算法，而是一个设计框架(position paper)**
- 物理可行世界模型的模块化架构：
  - 感知(Perception) → 表示(Representation) → 状态(State) → 动作规范(Action Specification) → 动力学(Dynamics) → 约束(Constraints) → 查询级响应(Prediction)
  - 编排器(Orchestrator)：根据查询选择最简兼容抽象，组合学习/分析/数值/混合组件
- **关键设计原则**：
  - 变量选择由查询决定——不同查询需要不同物理量
  - 动力学必须保留干预相关的物理结构
  - 正确的抽象是"保留查询相关物理区分的最简模型"
- 3个示例构造：斜面碰撞杯子、机器人倒液体、洪水道路驾驶

## Experiment
- 5类受控评估场景：刚体碰撞塔、果冻墙变形交互、液体杯碰撞、机器人推墙、机器人倒液
- 测试3种模型家族：VLM预测、视频扩散续写、动作条件latent预测
- 结果：所有现有模型在隐含物理变化时均产生视觉合理但物理错误的预测
- Bayesian优化估计粘度参数的示例展示了查询条件化构造的可行性

## Value
作为position paper有重要理论价值——清晰揭示了"观测预测≠物理建模"的根本矛盾，对世界模型领域的发展方向有深远启示。模块化架构设计提供了未来研究的框架。但缺乏可直接应用的算法贡献，更多是研究方向的倡导。
