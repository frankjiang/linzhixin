# Towards a Belief-Based World Model for LLM Agents

## Insight
在部分可观测环境中，未来模拟并不能替代当前信念：模拟轨迹的分散同时混合了“当前状态不知道什么”和“未来转移本身的随机性”，LLM 因而难以判断何时应先执行信息采集动作。论文主张世界模型除 `Predict` 外，还应显式维护 (b_t=P(s_t\mid h_t))，经 `Update` 吸收新观测，并提供自然语言 `Query(b_t,q)` 接口；模拟服务于推进目标的 pragmatic action，信念查询服务于降低不确定性的 epistemic action。实验支持“准确、可查询的信念有用”，但这是 POMDP 信念状态在 LLM 接口上的实例化，并非新的理论证明。

## Motivation
现有 LLM agent 世界模型多提供候选动作的后果模拟，却把历史压缩、当前状态估计和不确定性维护都留给 LLM。长时交互中 LLM 容易遗忘或错误更新状态，因此将信念估计与策略推理解耦是重要接口问题。相比只保存单一文本状态的 memory，显式概率分布还能引导主动搜索；不过相关思想在 POMDP、belief-state RL、BeliefMem 与 Agent-BRACE 中已有基础，本文贡献主要是把信念查询与模拟接口组合并做受控验证。

## Method
- 定义 BB-WM 内部状态 (x_t=(b_t,\xi_t))：动作后先 `Predict(x_t,a_t)` 得先验，再用新观测 `Update` 得后验；策略可分别查询未来模拟读出和当前信念读出。
- 为隔离“暴露信念是否有用”，论文没有学习世界模型，而是在两个文字环境中手工规定语义状态、先验、规则更新和自然语言读出。
- ALFWorld 的不确定状态仅是目标物体在 receptacle 上的分类分布。先验利用游戏引擎给出的物体-容器合法放置约束并在合法实例间均匀分配；搜过但未发现就置零并重归一化，发现后坍缩为点质量。确定性状态记录位置、库存、容器内容和物体属性。
- ScienceWorld 同样只维护物体所在十个房间的分布；显式写在任务中的目标位置设为概率 1，其他位置提示赋 0.9。查询返回累计概率覆盖 0.9 的候选位置，也可查询已搜索位置、内容及当前状态。
- ALFWorld 的模拟组件采用规则式 WALL-E，只判断动作有效性；ScienceWorld 直接调用环境作 Oracle 有效性检查。查询不消耗环境步，提示词和 in-context example 明确示范并鼓励使用查询。
- 方法本质上是带特权先验的符号 belief tracker 与 LLM 工具接口，而非从观测学习潜状态、动力学或不确定性的世界模型。

## Experiment
- 在 ALFWorld unseen split 和 ScienceWorld 的 24 类测试任务上，组合 Llama-3.1-8B、Qwen3-14B、Sonnet 4.6 与 ReAct/ReflAct；比较基础 agent、仅 Belief、仅模拟以及二者组合 BB-WM。Llama/Qwen 报告 3 次运行均值与标准差，Sonnet 仅 1 次。
- ALFWorld 最多 30 个环境动作，指标为 SR@1 及仅在成功任务上统计的步数。BB-WM 将 Llama+ReAct 的 SR@1 从 29.9% 提到 62.9%，Llama+ReflAct 从 55.7% 提到 65.2%；Qwen 对应从 76.1% 提到 91.0% 和 90.3%。Sonnet 已饱和，仅从 91.0%/91.8% 变为 94.0%/93.3%。
- Belief 与模拟有时互补：Llama+ReAct 中仅 Belief 为 43.3%，仅 WALL-E 为 43.8%，组合为 62.9%；但 WALL-E 也会伤害 Qwen+ReflAct（76.1% 降至 72.4%），组合后为 90.3%。
- ScienceWorld 以平均奖励 AR 和 AR/step 评测。Llama+ReAct 由 53.0/4.6 提到 66.0/6.2，ReflAct 由 48.7/5.1 提到 67.6/6.2；Qwen 两种框架的 AR 由 71.0/69.0 提到 80.7/81.9。Sonnet 的 AR 基本不变，只有轻微效率变化。
- Memory-only 消融支持概率信念而非纯记忆带来增益：ALFWorld 的 Llama+ReAct 为基础 29.9%、Memory 38.8%、Belief 43.3%；Qwen+ReAct 为 76.1%、76.1%、90.3%。质性轨迹展示查询合法候选位置后避免盲搜垃圾桶或错误地在浴缸种植物。
- 未评估 belief calibration、错误先验鲁棒性、查询策略质量或查询 token/延迟成本；也没有统计显著性检验。ALFWorld 步数只在成功子集上平均，跨方法成功集合不同，会产生选择偏差。

## Value
论文清楚地区分“对未来做模拟”和“对当前不确定性做查询”，对部分可观测世界模型的产品接口很有启发：视频或机器人世界模型也可把后验不确定性显式暴露给规划器，用于主动感知，而不只生成未来。可是实验证明的只是“由环境规则提供的准确位置先验能帮助文字 agent”，没有解决如何从视觉序列学习、校准和更新信念，因此对视频、3D、JEPA/Dreamer 研究仅是概念性参考。

## Strengths
- 研究问题单一且定义清楚，belief-only、simulation-only、组合以及 memory-only 消融能区分几类接口收益。
- 覆盖两个环境、三个规模的 LLM 和两种 agent 框架，并公开完整提示、状态结构、查询协议与代表轨迹，复现信息较充分。
- 对强模型饱和、模拟有时反而有害等负结果没有回避，说明信念与模拟并非简单叠加。

## Weaknesses
- BB-WM 完全手工构造，物体合法位置来自游戏引擎，ScienceWorld 还使用 Oracle 动作检查；这更接近特权状态工具，而非学习到的世界模型。
- 不确定性只限于物体位置，转移确定且更新规则理想化；没有感知噪声、模型误差、多峰动态或长滚动的不确定性传播。
- BB-WM 组额外获得查询说明、修改后的 in-context example、免费查询及游戏知识先验，未与等信息量的检索/启发式提示或等 token 预算基线比较，因果归因并不纯粹。
- 三次运行不足以支持多处“显著”措辞，Sonnet 只有单次；缺少置信区间、跨任务方差及错误信念下的安全性分析。
- 没有学习、校准或泛化实验，也没有视觉、3D、真实机器人或连续控制验证。

## Future Work
作者明确把下一步定位为学习可扩展、领域无关的 BB-WM，并将 belief update 与 continual world model 结合：观测降低当前不确定性，高 surprise 则触发模型修订；目标应用包括主动感知与开放环境决策。还应补充从像素学习概率后验、校准/分布外评估、错误先验鲁棒性、查询成本约束，以及与同信息量 memory/retrieval 基线的公平比较。

## Rating
创新度评分：2/5 - 把标准 POMDP 信念状态包装成 LLM 可查询接口并做较完整实验，但世界模型、信念与更新均未学习，技术贡献偏增量。

相关度评分：1/3 (Tangential) - 主题名义上是世界模型，也涉及隐式状态与不确定性，但实验是纯文本 LLM agent 和手工符号模型，对视频/3D/JEPA/Dreamer 仅有间接启发。

## TL;DR
为 LLM 世界模型增加可查询信念，在文本环境提升决策；但全靠规则与特权先验构造，非视频/隐式模型，可跳过。
