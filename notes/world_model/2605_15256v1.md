# ReactiveGWM: Reactive Game World Model with Decoupled Player and NPC Control

## Insight
游戏世界模型中，玩家操作和NPC行为本质上是不同类型的控制信号：玩家操作是低延迟的即时反应，NPC行为涉及策略性决策。ReactiveGWM通过不同的注入机制解耦这两种控制，并实现NPC策略的跨游戏零样本迁移。

## Motivation
现有游戏世界模型（GameNGen, Genie等）将所有动作统一处理，无法独立控制NPC行为策略。论文希望实现：(1) 精准的玩家操作响应 (2) 可控的NPC策略行为 (3) NPC策略在不同游戏间的迁移。

## Method
- **玩家操作注入**：Additive bias injection——将动作embedding作为偏置加到attention层，低延迟直接影响
- **NPC策略控制**：Cross-attention模块——将NPC策略描述（文本）通过cross-attention注入，允许复杂策略理解
- **Game-agnostic表示**：NPC策略用自然语言描述（如"aggressive", "defensive"），而非游戏特定的动作序列，支持跨游戏迁移
- **基座模型**：Wan2.2-T1V2-5B
- **数据**：Street Fighter II和Street Fighter Alpha 3的游戏录像

## Experiment
- **NPC指令遵循**：75-79%准确率（vs vanilla 43-44%），策略可控性大幅提升
- **玩家操作响应**：操作准确率保持在合理水平
- **零样本跨游戏迁移**：SF II训练的NPC策略模块直接迁移到SF Alpha 3，性能衰减有限
- **用户研究**：NPC行为自然度和可控性获得较高评分
- **局限**：仅在格斗游戏场景验证，泛化到其他游戏类型需进一步研究

## Value
在游戏世界模型的可控性上提出有意义的解耦设计。NPC策略的跨游戏零样本迁移是有趣的结果。与视频世界模型方向相关（游戏场景的世界模型），但应用场景较窄（仅格斗游戏）。技术方案（bias injection + cross-attention）相对直接。

## Strengths
亮点是在游戏世界模型的可控性上提出有意义的解耦设计。

## Weaknesses
