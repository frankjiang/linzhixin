# World-Ego Modeling for Long-Horizon Evolution in Hybrid Embodied Tasks

## Insight
核心 insight：具身世界模型中"世界"（持久的、指令无关的场景规律）和"自我"（机器人中心的、指令条件化的动态）的纠缠导致长时域预测退化。特别是在混合任务（导航+操作交替）中，两种动态的生成模式截然不同。论文从三个视角（运动/语义/意图）定义世界-自我边界，并分析了三种解缠策略（后/前/全解缠）。

## Motivation
现有具身世界模型在单一流中混合预测世界和自我的演化，在长时域混合任务中表现退化。同行缺乏对"世界"与"自我"的显式分解。论文提出这一概念分离范式并构建完整系统。

## Method
World-Ego Model (WEM)：(1) 隐式分离的世界-自我规划器——VLM 状态预测器中使用 RCA（Rotation Cross-Attention）分离世界和自我的注意力；(2) CP-MoE DiT 生成器——级联并行专家混合（Cascade-Parallel Mixture-of-Experts），语义路由将不同 token 分配给世界/自我专家，反路由阶段再融合。三视角定义世界-自我边界，三种解缠策略（post/pre/full disentanglement）。

## Experiment
构建 HTEWorld 基准：125K 视频片段（>4.5M 帧），细粒度动作标注，300 多轮评估轨迹（>2K 指令）。WEM 在 HTEWorld 上 SOTA（EWMScore 61.48），在现有操作基准上保持竞争力。消融验证了世界-自我分解和各组件的贡献。

## Value
对视频世界模型研究有重要启发。世界-自我分解是一个有洞察力的概念范式，对长时域具身任务尤其有价值。CP-MoE 和 RCA 的架构设计具有新颖性。HTEWorld 基准填补了混合任务世界模型评估的空白。局限：概念分离的最优边界定义仍需进一步研究。

## Strengths
亮点是对视频世界模型研究有重要启发。

## Weaknesses
不足是概念分离的最优边界定义仍需进一步研究。
