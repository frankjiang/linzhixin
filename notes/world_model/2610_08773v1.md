# AdvSim2Real : Training Web Agents Against Adaptive Prompt Injection in a Web World Model

## Insight
观察：网页代理面对固定任务/固定注入容易训练到饱和，且攻击造成的失败与代理本来会失败的情况常混淆。推论：任务应跟随当前能力变化，攻击者只因「原本成功、注入后失败」得到奖励。作者在冻结的网页转移模拟器中交替训练任务提出者、攻击者与执行代理；浏览器实验只验证了无攻击能力提升，未验证攻击鲁棒性迁移。

## Motivation
网页第三方内容可夹带提示注入，代理又必须读取页面才能执行表单任务。固定注入微调容易被自适应攻击绕过；已有对抗训练大多固定任务，缺乏持续有效的练习。该问题属网页代理安全，与视频/3D/JEPA/Dreamer 世界模型研究方向无实质交集。

## Method
用冻结的 WebWorld-14B 根据页面和动作预测下一网页，以冻结的 Qwen3.8-27B 判官给任务完成标签。第一阶段让课程代理提出「目标+初始页面」，以当前执行代理约 50% 成功率为奖励；执行代理在新任务轨迹上更新。第二阶段冻结课程代理，攻击者选择一次注入的内容和时机，把已判成功的干净轨迹回放到该步，仅在注入被呈现且续跑被判失败时获益；执行代理混合新攻击、历史攻击和干净任务训练。三个角色为 4B 模型上的独立 LoRA；模拟器与判官不更新。方法创新在网页任务自适应课程与成功翻转奖励，并未提出目标方向的视觉/物理世界模型。

## Experiment
150 个表单任务、三次推理种子：模拟器内干净完成率 74.89%→81.33%，三名训练内攻击者下均值 48.07%→57.48%；未参与训练的 Kimi-K3 攻击下 23.00%→30.72%（相对 +33.6%）。第一阶段能力模型在真实 Chromium 的无攻击严格成功率由 25.56%→44.44%；第二阶段鲁棒模型**未**做真实浏览器注入测试。去掉第一阶段后，最终干净率低 4.67 点，攻击下仅低 0.44 点，且计算量未对齐。最终模型在模拟器内面对 Kimi-K3 仍比干净条件低 50.61 点。

## Value
对本方向主要是间接方法提醒：用模拟环境训练时，需用真实可执行检查校验奖励与迁移。具体网页攻击、可访问性树与表单课程不适合作为视频/3D/隐式世界模型论文精读材料。

## Strengths
攻击奖励以同一干净前缀的成功翻转为条件，减少把自然失败记为攻击成功；报告未见攻击者、浏览器可执行结果和多种判官/模拟器误差；公开逐种子计数及案例。

## Weaknesses
所有攻击鲁棒性数字都来自同一个网页模拟器和语言模型判官；模拟器可虚构页面值，判官会接受错误计算。仅能力阶段有真实浏览器验证，攻击后的任务是否仍可执行亦未核验。150 题来自有限表单模板；三个种子只衡量同一训练权重的推理波动。攻击者与课程模块缺少计算量对齐的独立消融。

## Future Work
作者提出让未知攻击者适应最终代理，并进行盲审人工检查、可执行任务验证及计算量匹配的组件消融。

## Rating
创新度评分：1/5 - 在目标视频/3D/隐式世界模型方向没有新建模贡献；网页代理训练机制虽有自身创新，不能据此抬高本方向评分。
相关度评分：0/3 (Noise) - 研究网页代理提示注入，所谓世界模型仅是语言式网页转移模拟器。

## TL;DR
在网页模拟器中联合训练任务、攻击者与代理以抗提示注入；与目标世界模型方向无关，可跳过。
