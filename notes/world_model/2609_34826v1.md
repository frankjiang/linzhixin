# WM-VLM: Probing Internal World Models for Interleaved Visual-Textual Reasoning

## Insight
观察：视觉潜变量预测质量升至一定程度后，Tetris-2D 推理准确率随之跃升；仅生成视觉状态还不够，模型也须学会读取自己的预测。推论：应分阶段训练“生成状态”和“用状态推理”。将生成潜变量置零时，2D-ID 准确率由 87.5% 降至 14%，支持其确被利用；但生成状态的检索正确性与答案的相关系数在各组仅 0.104–0.399，不能把全部增益归因于精确状态预测。

## Motivation
一般 VLM 主要在文字空间推理，难以直接保持旋转等空间状态；外部视频世界模型或图像编辑工具又不能验证 VLM 内部是否学会预测。关键问题是建立可检验的隐式视觉状态转移，并分离预测质量和答题能力。

## Method
在 Qwen2.5-VL-7B 上加浅层生成分支，文本／已有视觉 token 走理解分支，带噪视觉 token 走生成分支，跨分支共享注意力。第一阶段冻结理解分支，用 rectified flow 预测给定“心智动作”后的视觉编码；第二阶段用模型自己生成的潜变量作为历史，优化答案的交叉熵。构造可验证的 2D／3D 俄罗斯方块旋转题，显式提供中间状态和答案。方法是已有 MoT、flow matching 与课程训练的组合，关键在可干预的内部状态接口。

## Experiment
Tetris-2D（4k 训练）中 ID/OOD 准确率 **87.5/75.0%**，相同底座 SFT 为 **48.25/46.2%**；Tetris-3D（三个测试集）为 **91.0/66.25/71.8%**，均优于同底座 SFT。随机化潜变量让 2D-ID 降至 23.5%，改用像素中间态约 47.25%；直接从头联合训练接近随机。可变 token 数和损失比消融表明更低潜变量 MSE 并不总带来更高答题率。附录 VSP 导航：50.0%，略优于 SFT 的 43.17%，但低于 LatentUM 的 52.0% 和使用额外专有数据的 ThinkMorph 82.5%；更强纯文本 VLM 在部分 2D 题也能超过该方法。

## Value
以可验证中间状态和干预实验检查“隐式世界模型是否真的被用到”，对 JEPA 式潜状态评测有借鉴价值；对真实视频或 3D 环境动力学的直接结论仍有限。

## Strengths
设计可核验的中间视觉状态；同底座对比和置零／随机化干预比只看最终准确率更能检验潜变量作用；浅分支控制了新增参数开销。

## Weaknesses
主要是合成、确定性旋转题，缺少真实观测噪声、遮挡和长期物理转移；“必须视觉想象”并不绝对，强文本模型可编码坐标解题。导航收益有限，生成状态检索率与答案准确率未高度一致；跨底座和真实交互泛化不足。

## Future Work
作者只笼统提出把内部世界模型扩展为具身代理的视觉与文字联合推理基础，未给出具体后续实验路线。

## Rating
创新度评分：3/5 - 轻量内部生成分支与分阶段训练结合了较强的因果干预评测，但主要模块和任务范式已有基础。
相关度评分：2/3 (Related) - 研究隐式视觉状态预测及使用，可借鉴评测设计，但主要场景是合成 VLM 空间题。

## TL;DR
让 VLM 先预测视觉潜状态再据此推理，并用干预证明其确被使用；做隐式世界模型评测值得精读。
