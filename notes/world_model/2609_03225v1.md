# Long-Horizon Consistent and Interaction-Aware World Models for Multi-Style End-to-End Driving

## Insight

论文基于三个 observation 提出一体化方案：RSSM 只依赖单步 prior 时，长 rollout 会累积漂移，因此让当前 prior 门控吸收最近 `m=5` 个 prior 的 cross-attention 上下文；统一建模所有环境因素会浪费决策容量，因此按 ego 相关性把 environment latent 分为 relevant/irrelevant，并对前者用 softmax、后者用 logarithmic normalization；不同驾驶风格的 reward 尺度不同，因此先按风格标准化 PPO advantage，再用同风格并行整轨迹的 group-normalized return 做 GRPO。实验消融支持各组件与总分相关，但没有理论证明其确实辨识独立因子或阻止误差传播。

## Motivation

Dreamer 式自动驾驶用 latent imagined rollout 避免真实危险探索，但已有方法仍有长时不一致、无法突出关键交互者、单一手工奖励难表达多步驾驶意图三类问题；更换保守/中性/激进风格通常要重训策略。稳定长时想象、交互归因和一套模型支持多风格，均是隐式驾驶世界模型的关键问题。

## Method

第一阶段训练扩展 RSSM。六相机和 LiDAR 经预训练 BEVFusion，图像另经 ViT，融合后推断 posterior；latent 分成 ego 与 environment 两个 stochastic branch，各有 GRU prior/posterior。当前 prior 对历史 prior 序列做 gated cross-attention。environment latent 再以 ego-query spatial attention 和一个 cosine “semantic dependency”阈值 `κ` 切成 ego-relevant/irrelevant，最终聚合为策略表示。decoder 重建相机图像并预测 reward、continuation；另用 Argoverse 未来轨迹的距离/TTC 伪标签监督相关性。

第二阶段冻结 WM。奖励仍由 waypoint/destination/time、目标速度/平滑、collision/lane-deviation 手工项组成，通过不同权重采样定义 conservative/moderate/aggressive 三种 style。先在 imagined rollout 中训练 style-conditioned PPO policy/critic，再在 6 个并行 CARLA 环境收集整轨迹，以同组 discounted return 的 z-score 作为每一步共同 advantage，配合 clipped ratio 和 KL 项做 GRPO fine-tuning。创新是历史一致性、交互 latent 拆分与多风格相对优化的组合；各单项均接近既有 attention、Iso-Dream 和 policy optimization 技术。

## Experiment

世界模型用 Bench2Drive Base（约 400 GB、1,000 clips）训练 30 epochs，8×A6000；策略再用 100,000 个在线 CARLA episodes。闭环评测为 220 条约 150 m 路线、44 种场景，指标含 DS、SR、DE、Comfort 与五类 Multi-Ability。多模态 StyleDrive 得到 DS 88.44、SR 66.82%、DE 174.42、Comfort 40.92；相对 Epona 的 71.36/50.24 提升 17.08/16.58 点。相机版为 79.78/57.91%。多能力均值 64.71，高于 Transfuser++ 60.51 和 Epona 53.34。

latent 拆分从不拆分的 DS/SR 54.23/44.25，经 ego-env 69.12/51.53、variance split 80.43/57.62，至 cross-attention 88.44/66.82。policy 消融中固定风格 PPO、多风格 PPO、固定风格 GRPO、完整方法的 DS 为 65.07/67.12/74.21/88.44，自定义 Diversity 为 0.151/0.312/0.193/0.524。时间正则将 DS 70.11 提至 88.44，并在 1/3/5/10 s 的 FID/FVD 全部改善；10 s FVD 为 428.2，对 Epona 572.4。30 个自采真实视频用于 open-loop 质量评测。Scout AGV 仅定性展示三种障碍/行人场景及两种风格轨迹，没有重复次数或成功率。

## Value

工作展示了 Dreamer/RSSM 不必只追求单一平均状态：可把历史一致性、行动相关对象和策略偏好直接写入 latent/control loop。对我们的启发是同时用 closed-loop 任务指标与不同 horizon 的生成指标检查 imagined rollout，并把 style 作为条件而非训练多个独立模型。当前结果很强，但多项贡献绑在一起、依赖特权伪标签与大规模在线仿真，且真实世界证据过弱，应把它视为值得复核的综合系统，而非已证实的通用范式。

## Strengths

- 同时覆盖 latent dynamics、交互表示和 policy optimization，端到端问题定义完整。
- 有相机/相机+LiDAR两种设置、闭环任务、多能力、长时 FID/FVD、组件消融和真实平台演示。
- 时间一致性收益随 horizon 扩大，10 秒结果比只看一步重建更贴近核心主张。
- relevant-agent attention 可视化与危险交互案例为 latent 拆分提供一定可解释证据。

## Weaknesses

- “disentanglement”主要由结构、attention 与阈值命名，没有独立性/可辨识性指标；历史 prior attention 也可能把旧误差重新注入。
- 所谓 semantic dependency 只是 latent cosine 与硬阈值，并由 Argoverse 距离/TTC 伪标签监督，迁移到 CARLA/真实域的偏差未分析。
- 多风格仍来自人工 reward 权重分区，并非自然语言偏好；GRPO 本质是整轨迹 return 标准化，“无需重训适应新风格”没有对未见权重验证。
- 自定义 Diversity 选每个 style 的最高-return 轨迹，会混入选择偏差，也未检验风格是否同时满足安全约束。
- 主表把唯一的 RL 多模态方法与多为单相机 baseline 对比；World4Drive 与 Roach 行完全相同等报告细节削弱可信度。
- 真实 AGV 只有三个精选定性案例，无速度、延迟、试验数、碰撞率或 sim-to-real baseline，不能支撑稳健部署主张。
- 没有公开讨论 failure case、统计方差/显著性、模型参数/实时成本；100,000 在线 episodes 也削弱“world model 提高数据效率”的论点。

## Future Work

正文未单列未来工作，仅总结现有方案。最需要的后续实验是：在未见城镇/天气和不同传感器上量化长时误差与交互对象识别；以等模态、等算力 baseline 重跑；验证连续或语言指定的未见风格；加入真实车辆多次闭环统计，并研究历史记忆在 OOD 下何时帮助或放大漂移。

## Rating

创新度评分：3/5 - 三个模块形成有一定新意且效果显著的完整 Dreamer 式驾驶系统，但多为既有思想组合，评价公平性与真实验证仍有明显缺口。
相关度评分：3/3 (Core) - 直接研究 RSSM imagined rollout、潜状态交互分解和世界模型内策略学习，属于核心隐式世界模型方向。

## TL;DR

历史一致性、交互拆分与GRPO联合提升多风格驾驶，结果强但证据需复核，值得精读。
