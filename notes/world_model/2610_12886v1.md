# LeapBot-JAC: Joint Action Chains for World Action Models

## Insight
动作块策略只执行预测序列前缀，却为整个序列消耗 token；在相同预算中，用稀疏远期动作作参考、密集近期动作作执行，并让执行链读取参考链，可拓宽未来监督范围。LIBERO-Plus 两个宿主的性能改善及可见性消融支持这种组织方式；论文并未证明参考链学到了语义计划，效应也可能含监督权重与位置编码变化。

## Motivation
FastWAM、LeapBot-WA 等世界动作模型联合训练视频表征与控制，但其动作专家仍等密度预测未来控制。长时任务可能需要较远期信息影响眼前抓取，而增加 token/参数有推理成本。论文研究固定动作 token 预算下的序列布局问题，不改变宿主的世界模型预测目标。

## Method
将原 32 个连续动作 token 重分为 16 个稀疏参考 R（真实控制时刻 0,3,…,45）和 16 个密集执行 A（0,…,15），两链共享动作专家、流匹配噪声等级及参数，各用独立噪声；RoPE 按物理控制时刻而非拼接位置编码。定向 attention 允许 A 读 R、不允许 R 直接读 A，并与宿主合法可见性求交。训练损失为执行链误差＋0.2 倍参考链误差＋原世界模型损失；推理两链联合去噪，机器人只执行 A 的前 10 或 16 步。创新集中在动作 token 分工与信息流约束。

## Experiment
同宿主 Base/JAC 配对，在 LIBERO 四套任务、零样本 LIBERO-Plus 七类扰动、RoboTwin 2.0 和两项真实操作评估成功率。LIBERO：FastWAM 97.0%→98.3%，LeapBot-WA 97.3%→98.3%；LIBERO-Plus 总成功率分别 53.5%→70.4%、73.1%→77.3%。RoboTwin 提升较小，仅 +0.22/+0.51 个百分点；两真实任务每模型每任务 200 次，FastWAM 顺序分拣 82%→93%，关抽屉 77%→79%。在 FastWAM 的可见性消融中 R→A 为 98.3%，双向 97.5%、无跨链 97.7%；参考权重和步长也有敏感性。模型参数、10 步去噪及调用延迟（337.0→337.7 ms）基本不变。

## Value
对兼有世界表征与动作专家的系统，提供低成本长短期动作条件设计；如果团队研究 JEPA 视频表征接控制头，可参考其物理时间对齐和固定计算预算对照。论文没有改善或评估视频/3D 世界预测本身，宜作为动作建模选读。

## Strengths
固定 token 数、模型参数、执行前缀与宿主世界损失；跨两个宿主、多个机器人基准及真实任务验证；清楚报告延迟、内存和不同注意力方向。

## Weaknesses
所有训练结果仅一个种子，LIBERO 已接近饱和且 RoboTwin 收益很小。参考步长变化同时改变覆盖、重叠和 padding，参考损失权重变化也改变其相对世界损失的强度；缺少 λR=0、等权重单链及相同目标重复监督等对照，无法隔离机制。仅阻断直接反向 attention，宿主世界 token 可能提供间接路径；没有证明参考动作可解释为高层意图。

## Future Work
作者提出研究稀疏参考的语义解释和跨宿主迁移；附录还要求用匹配控制实验分离目标重复、监督分配与优化效应。

## Rating
创新度评分：2/5 - 固定预算下的双链动作布局有实用性，但属于既有动作专家的局部设计修改，机制证据有限。
相关度评分：2/3 (Related) - 与 JEPA/视频世界动作模型的控制接口相关，但核心改动不涉及世界动力学表征或预测。

## TL;DR
把动作 token 分成稀疏远期参考与密集近期执行链，提升扰动下的机器人成功率；研究世界模型控制接口可选读。
