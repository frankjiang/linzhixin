# Dream-Tac: A Unified Tactile World Action Model for Contact-Rich Robot Manipulation

## Insight
Observation: 现有 world action model 主要依赖视觉，但在接触密集操控（如插 USB、切香蕉）中，视觉无法捕捉关键的接触状态变化（接触前后 RGB 图像可能几乎一致），而触觉信号能提供直接的接触/力反馈。然而触觉信号具有稀疏、瞬态特性，对称地处理触觉与视觉 token 会稀释关键交互信息。

推论: 应将触觉纳入世界动作模型的联合生成框架，并通过 contact-aware attention bias 自适应放大接触事件时的触觉信号影响。

证明: 6 个真实接触密集任务上平均成功率 83.3%，超越 Cosmos Policy (51.7%) 约 31.6 个百分点。消融显示触觉融合贡献 +22.5%，attention bias 再贡献 +9.1%。

## Motivation
- **问题**: WAM 在接触密集操控中因缺乏触觉感知而表现不佳。
- **同行做法**: Cosmos Policy 等仅用视觉；ForceVLA 融合力/触觉但不做预测式建模；RDP 用触觉做反应式控制但非统一框架。
- **关键性**: 接触密集任务是机器人操控的核心挑战之一，触觉信息对精确操控不可或缺。

## Method
**架构**: 基于预训练视频扩散 Transformer (DiT) 的统一视触觉世界动作模型。

1. **统一潜在空间建模**: 将视觉观测、触觉观测、机器人状态、动作 chunk 统一编码到共享潜在空间。视觉和触觉用预训练 VAE 编码为潜在 token，机器人状态和动作用 latent-frame token 填充。模型联合预测未来视觉帧、未来触觉帧和动作序列。

2. **Contact-Aware Self Attention (CASA)**: 核心创新。在标准 self-attention 的 logit 上添加一个标量门控的结构化偏置项：
   - 仅当非触觉 query 注意触觉 key 时激活偏置
   - 门控值 g_t 由相邻帧触觉图像的归一化帧差（normalized mean absolute difference）驱动
   - 接触事件时帧差大 -> g_t 大 -> 放大触觉注意力；无接触时 g_t 小 -> 回退到标准注意力

3. **双层加速**: 
   - FlashBias: 将 CASA 的 gated bias 重构为低秩形式，融入 FlashAttention，训练加速 2.9 倍
   - Diffusion-step caching: 推理时缓存去噪步骤，有效步数从 10 降到 2，推理加速 1.8 倍

## Experiment
- **平台**: Franka Emika Panda + 2 个 RealSense D435i (第三人称+腕部) + 2 个 Xense Photon 触觉传感器
- **6 个任务**: Pick Baguette、Insert USB、Clean Whiteboard、Peel Cucumber、Play Mahjong、Cut Banana
- **对比基线**: pi_0 (30.8%)、pi_{0.5} (45.0%)、ForceVLA (50.8%)、Cosmos Policy (51.7%)
- **Dream-Tac**: 83.3%，5/6 任务最优
- **消融**: Visual WAM 51.7% -> +Tactile 74.2% -> +Attention Bias 83.3%
- **泛化**: 在桌面高度/物体外观/背景变化下比 Cosmos Policy 更鲁棒
- **效率**: 训练比 Cosmos Policy 快 2.9 倍；推理 timestep caching 保持 85% 成功率同时延迟从 1109ms 降到 619ms

## Value
- **价值**: 将触觉模态优雅地整合进视频世界动作模型框架，contact-aware attention bias 设计巧妙（数据驱动的门控而非学习的门控网络），效果显著。
- **启发**: (1) 触觉对接触密集任务至关重要，但需要自适应机制处理其稀疏瞬态特性；(2) 不需要触觉特定预训练，视频 VAE 已能有意义地分离触觉模式；(3) FlashBias 重构 attention bias 的方法值得借鉴。
- **待解决**: 仅在 Panda 单臂 + 平行夹爪上验证；触觉传感器类型固定（Xense Photon）；未探索灵巧手等更复杂场景。
