# Neurosymbolic Alignment for Physiologically-Safe Clinical Language Models

## Insight

Observation：临床 LLM 的回答可在事实层面合理，却因患者状态、药物相互作用或稳态边界而不安全；普通文本偏好未显式表示这些关系。论文推论是，可用结构化生理知识图的 verifier 在训练时为当前 policy 候选排序，让约束通过 iterative on-policy preference optimization 内化到 LLM，而部署时移除 verifier。控制实验中 Iter-5 相对 ORPO 的 CSS/RSS/DID 分别提高 21.3/21.2/18.8 pp、医生评估 HR 降 9.0 pp，且去 HGNN/去迭代训练分别损失 16.2/11.5 pp，支持训练信号确有作用。但 CSS 与 PC 复用了产生偏好的 HGNN，独立指标也来自较窄的 rule engine/有限医生样本，因此不能视为真实临床安全证明。

## Motivation

RAG 改善证据访问，medical SFT 改善语言与知识，DPO/ORPO 降低人类偏好成本，rule-based self-correction 则在推理时增加工具链；它们都难系统捕获多跳生理关系、稳态阈值和组合用药风险。论文目标是用图结构自动生成 safety preference，在不增加推理成本的条件下提升 7B clinical LLM。该问题对医疗 NLP 有意义，但与视频、3D、JEPA/Dreamer 世界模型无实质联系；文中的 “Physiological World Model” 实际是静态 biomedical KG+HGNN scorer，不建模状态转移或环境动力学。

## Method

作者构建含 847,392 nodes、3,241,567 edges 的异构图，整合 UMLS、DrugBank、Reactome、HPO、SIDER、PharmGKB、DisGeNET、STRING。4-layer relation-aware HGNN 采用 type projection、relation message passing，先做 link prediction；scispaCy NER→UMLS linking 后排除低置信和 negated entities。PhysioScore 把 homeostatic soft constraints `S_hom`、最长三跳 path plausibility `S_path` 与 drug-interaction penalty `P_int` 乘为 `S_hom·sigmoid(S_path)·(1-P_int)`，使任一严重安全门接近零时主导评分。

以 Mistral-7B-v0.3+LoRA 为 policy，每个 1,750 个训练 query 采样 K=8 candidates，取 scorer 的 winner/loser 形成 preference pair；每轮更新后由新 policy 重采样，共 T=5。目标含 SFT loss、随轮次线性增加权重的 ORPO odds-ratio loss 与 KG consistency loss；推理只保留 LLM。另构建 Clinical Safety Benchmark (CSB)：2,500 个专家依据教科书模式编写的合成场景，按 1,750/250/500 划分，覆盖 DDI、禁忌、稳态、儿科/老年剂量、器官损害和 polypharmacy。

## Experiment

比较 SFT、light/dense RAG、DPO、ORPO、KG-LLM、DrugBank-Rule、SFT-CSB、SFT+SelfCorrect、GPT-4 zero/5-shot 等。Iter-5 的 MA/CSS/RSS/HR/DID/PC 为 75.2/90.8/86.4/5.1/91.6；ORPO 为 70.1/69.5/65.2/14.1/72.8，GPT-4 5-shot 为 79.1/80.6/78.2/未评/84.3/0.80，SFT+SelfCorrect 的 CSS/RSS 为 79.4/83.7。CSS 与 HGNN-independent RSS 在方法层面相关 r=0.97、κ=0.82。五个医生盲评 600 responses、每例三人，κ=0.84；本方法 HR 5.1% 的 95% Wilson CI 为 [2.2%,11.3%]，critical hallucination 0.4% 对 ORPO 3.7%。组合 EHR-style noise 下 CSS 84.2%，较 clean 降 6.6 pp。

消融：Full CSS/HR 90.8/5.1；rule scorer 77.4/10.2、simple KG 81.6/8.9、无 iterative 79.3/9.8、无 HGNN 74.6/12.4、无 homeostasis 82.1/8.7。分量 drop 的 CSS 降幅为 `S_hom` 8.7、`P_int` 6.5、`S_path` 3.9 pp；30% edge deletion 降到 81.4，20% entity mislink 降到 83.5，10% negation-blind error 降到 86.4。K=4,T=3 的低预算版 CSS 86.1；完整五轮共 42.6 GPU-hours（8×A100）。PhysioScore 用 200 clinician labels 校准，ECE 0.038、阈值 0.85 时 κ=0.91。

## Value

对临床 LLM alignment 而言，工作展示了“训练时强 verifier、部署时轻 policy”的可行配方，并正视 scorer circularity、图更新和实体链接问题。对我们的世界模型研究几乎没有直接价值；至多可类比为用结构化约束模型产生 preference supervision，但它既不处理视觉状态、时序预测、3D 几何，也不是 Dreamer/JEPA 式 latent dynamics，不能因名称含 world model 而纳入核心文献。

## Strengths

方法管线、分数构成和 on-policy 迭代定义清楚；baseline 覆盖 preference、RAG、rule、自纠错和 proprietary LLM。除训练 scorer 指标外还报告 RSS、DID 和医生 HR，并做阈值、KG deletion、entity linking、候选数/轮数、base model 和计算成本分析。论文对 9.2% residual violations、静态图陈旧、无 runtime verifier、真实临床外部验证缺失等限制写得较充分。

## Weaknesses

CSB 全为 2,500 个合成场景，未在 MIMIC-IV、去标识 EHR、多中心 notes 或 prospective queries 上验证；noise injection 不能替代真实临床复杂性。CSS/PC 与训练用 HGNN 同源，RSS 又使用与图知识高度重合且更窄的 DrugBank rules；r=0.97 只能说明两个自动评估器排序一致。医生评估仅六方法各 100 responses，HR 区间很宽。主表声称五 seeds 和显著性却未展示标准差/逐 seed 数值；GPT-4 与 7B 比较不控制数据、规模和工具。KG 是静态 snapshot，coverage、staleness、negation/linking error 会同步污染偏好，且每次图更新需重新预训练和对齐。没有匹配 PPO/RLHF reward model 或完整 tool-agent baseline；数据/代码仅承诺 acceptance 后发布。

## Future Work

作者优先提出真实去标识、多中心 EHR 与扩大 blinded clinician evaluation；加入 temporal physiology、剂量/否定歧义下的实体 grounding、动态 KG delta update 和 warm-start continual alignment；比较 matched-scale PPO/RLHF 与多工具 agent；蒸馏小 scorer/1–3B policy、量化部署，并采用轻量 confidence gate 只对不确定尾部调用 HGNN/rule verifier。对本调研无需继续跟踪，除非研究结构化 verifier 驱动的模型对齐。

## Rating

创新度评分：1/5 - 在目标世界模型方向没有新技术贡献；所谓 Physiological World Model 是静态知识图评分器，整体为 HGNN scorer 与 iterative ORPO 的领域组合。
相关度评分：0/3 (Noise) - 纯临床 NLP/知识图安全对齐，不涉及视频、3D 或 JEPA/Dreamer 隐式世界模型。

## TL;DR

用生理知识图评分候选并迭代 ORPO，合成临床安全指标亮眼但与目标世界模型无关，可跳过。
