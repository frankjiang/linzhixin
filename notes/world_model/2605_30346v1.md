# YoCausal: How Far is Video Generation from World Model? A Causality Perspective

## Insight
观察：视频扩散模型能感知"时间箭头"（正向vs逆向），但这不等于理解因果（如擦桌子→桌子变干净）。推论：需要将"时间方向感知"与"因果认知"解耦评估。方法：利用VLM将数据集分为因果子集D_c和非因果子集D_nc，CCI = RSI(D_c) - RSI(D_nc)，若模型真正理解因果，应对因果视频的反转更"惊讶"。实验证实：高RSI模型可能低CCI（如LTX-Video），验证了两者的独立性。

## Motivation
- 问题：当前VDM是否真正理解因果关系，还是仅拟合统计时序模式？
- 同行方法：PhyWorld、LikePhys等benchmark依赖合成数据或受控录制，存在sim-to-real gap
- 关键性：判断VDM能否成为真正世界模型的核心问题之一

## Method
- 数据集：时间反转真实视频作为零成本的反事实样本，可无限扩展；4个子集（Physics/Human/Animal/General）
- Level 1 RSI：对正向和反向视频计算denoising loss，RSI衡量模型对正向视频赋予更低loss的比例
- Level 2 CCI：用VLM将视频分为因果/非因果子集，CCI = RSI(D_c) - RSI(D_nc)，解耦时间方向感知和因果认知
- 聚合排名：RSI rank + CCI rank

## Experiment
- 评估13个SOTA VDM + 人类基线（1200个视频标注）
- 关键发现：(1)感知时间箭头≠理解因果；(2)Wan2.2-T2V-A14B因果能力最强；(3)因果认知与物理直觉正相关但不可归约；(4)与美学质量零相关；(5)scaling law对因果认知有效
- 熵控制实验验证RSI捕获的是事件级时序而非低级运动统计

## Value
评估角度新颖，提出了VDM距离真正世界模型还有多远的定量度量。对研究方向的启发：视频生成质量高不代表世界理解，需要因果层面的评估。局限：CCI依赖VLM分类的准确性；仅评估因果感知，未涉及可控干预。

## Strengths
