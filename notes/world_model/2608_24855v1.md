# LeFlow: Generative Latent Flow Planning for World Models

## Insight

Observation：冻结 JEPA 世界模型已经把像素压进具有任务几何的 latent，并学习了 action-conditioned transition；继续对每个 start–goal 用 CEM 从零搜索动作，相当于把模型只当黑箱，丢掉了跨查询可复用的规划结构。论文推论是：动作序列高度多模态，而实现相同状态变化的 latent path 更平滑、更低维，因此可先生成“去哪里”的 latent trajectory，再局部解码“怎样做”。生成路径未必可控，故必须用冻结世界模型真实 rollout 重新投影/筛选。实验支持三点：latent flow 优于直接 action flow 3.0–4.5 pp，生成式路径优于确定性回归 1.0–4.5 pp，rollout reranking 在 Reacher/PushT 提升 10.5/2.5 pp；但这些是小型短时任务上的经验结论。

## Motivation

LeWM、DINO-WM 等 latent/JEPA 世界模型已有较强预测能力，但 test-time planning 仍依赖 CEM/iCEM/MPPI 多轮优化，每次 MPC 重规划都要数千次模型查询，既慢又不复用历史规划经验。论文解决“能否把 planning 本身离线 amortize”为 reusable prior。该问题对隐式世界模型很关键：若 latent 只利于预测而不能支持高效规划，其作为 agent world model 的价值受限。

## Method

冻结 LeWM encoder `enc` 与自回归 predictor `pred(z,a)`。当前图像和目标图像编码为固定端点 `z_start,z_goal`；4-layer Transformer rectified-flow planner 只生成长度 H 路径的 H−1 个内部 latent，以离线真值 latent trajectories 为 flow-matching 数据，推理用 16 次 Euler integration 并行采样 N=64 条路径。3-layer MLP inverse dynamics decoder 对每个局部转移读取 `[z_t,z_{t+1},z_{t+1}-z_t]`，输出五步 action chunk，以 MSE 训练。

为减少 off-manifold path，训练时把解码动作送入冻结 predictor，加入一步预测与目标 latent 的 consistency loss；推理时再对每个候选做完整自回归 rollout，以实际终点到 `z_goal` 的 L2 距离选最优。规划运行在 receding-horizon MPC 中，没有 CEM 的反复分布更新，但仍需 N 条冻结模型 rollout。总损失为 flow、inverse dynamics 和权重 0.1 的 consistency；LeWM 全程不更新，因而实验隔离的是 planner 而非更强 world model。

## Experiment

覆盖 LeWM 的四个 goal-conditioned pixel-control benchmark：TwoRoom 2D 导航、PushT 2D 推块、Reacher 双关节到达、OGBench-Cube 3D 操作，动作均连续；主结果 H=5、action block=5、50 episodes，LeFlow 报五个 evaluation seeds，消融用 200 episodes。相对同一冻结 LeWM+CEM，成功率分别从 82.0→100.0、89.3→95.2、68.0→86.8、73.3→100.0；端到端时间从 224.78→15.58 s、198.92→17.42 s、326.01→27.67 s、224.62→50.23 s，即 14.4×、11.4×、11.8×、4.5×。它也优于 iCEM、MPPI 以及论文引用的 GCBC/GCIVL/GCIQL、PLDM、DINO-WM 表中均值，但后几类数字来自 LeWM 原论文而非本工作统一复跑。

PushT/Reacher 上，direct Action-Flow 为 93.5/83.0，deterministic latent planner 为 95.5/83.0，LeFlow 为 96.5/87.5；去 rerank 后为 94.0/77.0。`λ_cons=0/0.1/1.0` 对 PushT 为 96.5/96.5/95.0，对 Reacher 为 85.5/87.5/84.5，说明 consistency 仅边际贡献。80/20 episode-level held-out 的四项为 100.0/97.2/86.0/100.0，与 in-distribution 近似，证明不是简单记忆 episode。关键负结果在附录：PushT horizon 从 5 增至 10/20 时成功率从 94% 暴跌到 32%/6%。转移到 DINO-WM 的 PushT 实验中，15k 训练轨迹、64 proposals 仅 78%，低于 CEM 84%；提高到 512 proposals 后达 86%，用时 2:32 对 37:09（14.7×），说明可迁移但仍依赖大量筛选且只验证一个任务。

## Value

LeFlow 把隐式世界模型的 latent 从“预测空间”提升为“可复用规划对象”，其模块化分工——生成高层 latent path、局部 inverse dynamics、world-model verification——对 JEPA/Dreamer 类模型很有借鉴价值。尤其值得延伸到 goal-conditioned imagination、skill-level planning 和层级 MPC。当前价值主要是短视野规划效率，不是更强的长期 world modeling；在线仍需 batch rollout，离线 planner 训练成本也未计入速度比较。

## Strengths

冻结同一 LeWM backbone 的控制实验较干净；同时比较 CEM/iCEM/MPPI，并对 latent-vs-action、生成-vs-确定性、reranking、consistency 做针对性消融。成功率与端到端时间同时报告，held-out episode 检查了记忆风险。附录主动暴露 horizon scaling 崩塌，并以 DINO-WM 做第二 backbone 验证，论证边界相对诚实。

## Weaknesses

四个任务规模小、视觉简单，TwoRoom 与 OGBench-Cube 多数变体已 ≥99.5% 饱和；目标图来自同一 episode 且固定步数之后，弱于开放目标与跨场景泛化。H=10/20 的 32%/6% 说明方法目前不能支持长时 world-model planning，固定目标端点和短局部 inverse decoder 无法抑制累积误差。所谓 amortized planning 仍对 64 或 512 候选逐条 rollout，只移除了迭代优化；未报告离线训练成本、硬件公平性和随 N 的质量–延迟曲线。主表部分 baseline 是引用值、协议未必完全匹配；DINO-WM 只做 PushT且另训 spatial autoencoder。没有真实机器人、稀疏/动态目标、随机环境或 model-error-aware 风险实验。

## Future Work

作者提出用层级规划串联多个短 LeFlow segment，或换用长程误差更低的 world model，并在真正支持长期决策的 benchmark 上验证。还应学习不确定性感知的 verifier、减少候选 rollout、研究跨任务/跨 embodiment 共享 prior，以及测试 Dreamer/RSSM、视频 JEPA 和真实机器人闭环。

## Rating

创新度评分：3/5 - 将 rectified-flow latent path、inverse dynamics 与冻结模型验证组合成 amortized planner，有清楚的新接口与显著加速；组件本身成熟，且短视野崩塌限制了结论。
相关度评分：3/3 (Core) - 直接在 JEPA latent world model 上研究规划、可控动力学和 imagined rollout，是隐式世界模型核心方向。

## TL;DR

生成潜在路径并由冻结世界模型展开验证重排，规划快 4.5–14.4 倍但仅短视野，值得精读。
