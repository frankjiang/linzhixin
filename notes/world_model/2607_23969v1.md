# LeapBot-WA: World-Anchor Action Models via Predictive Latent Alignments

## Insight
有。论文的核心 observation 是：机器人 WAM 不一定需要生成像素级未来；为了控制，模型更需要 action-relevant semantic dynamics。推论是把 JEPA 式预测表征作为 World-Anchor，在 latent foundation space 中做 Predictive Semantic Alignment，再把世界模型分支作为训练期 privileged expert 蒸馏给动作分支，推理时可剪掉重分支。

## Motivation
论文解决 pixel-level video generation WAM 的表示浪费和视觉 distractor 脆弱性。已有 generative WAM 通过未来帧合成训练世界模型，但会把容量花在纹理、光照、背景；已有 latent WAM 又面临“用什么 latent space”和“JEPA feature 与 diffusion prior 不匹配”的问题。这直接对应 JEPA/隐式世界模型用于机器人控制的核心问题。

## Method
LeapBot-WA 有三块：Predictive Anchor、ISAE、Asymmetric MoT。Predictive Anchor 由 V-JEPA 2.1 初始化并在机器人轨迹上微调，提取预测语义 token。ISAE 把高维非高斯 JEPA feature 压到 96 维 isotropic latent，通过 reconstruction+cosine、KL、Sliced Isotropic Gaussian Regularization 防止 off-manifold drift 和维度塌缩。

Asymmetric MoT 包含 Anchor DiT 和 Action DiT。训练时 semantic latent 和 action trajectory 都做 flow matching；Anchor DiT 被 mask 掉不能看 action token，只根据 instruction/proprioception 预测 intent-conditioned semantic evolution；Action DiT 可以 attend 到 semantic token，从世界分支读取动态先验来生成动作。推理时不跑重的 dynamics branch，只用当前观测的 semantic cache 指导 Action DiT，实现零额外推理开销。

## Experiment
RoboTwin 2.0 上用 27.5K clean/randomized demonstrations 训练多任务策略，LeapBot-WA 平均成功率 91.46%，randomized 92.34%，接近或超过部分使用 embodied pretraining 的 WAM/VLA。LIBERO 四套任务上平均 97.3%，在 predictive WAM 中最好，接近 generative WAM。LIBERO-Plus zero-shot perturbation 上总分 73.1%，高于 VLA-JEPA 62.9 和 JEPA-VLA 25.6，在 robot/background 变化上优势明显。

消融显示 mixed-domain PT 改善 representation linearity：dynamics MSE 降 37.9%，proprioception MSE 降 28.5%。SIGReg 将 latent rank 从 38.1 提升到 92.3，multi-step drift 从 0.45 降到 0.21，success 从 base encoder 42.5% 和 unregularized adapter 58.2% 提到 71.3%。还在 UR5 真实 pick-and-place 上做了定性迁移展示。

## Value
价值很高：它给 JEPA latent world model 如何接入 diffusion policy 一个具体工程答案，即“预测 latent 作为 anchor，扩散友好化，再训练期蒸馏”。对我们研究隐式世界模型尤其有启发：不用把未来视频生成作为核心目标，关键是选择能表达物理变化且能被控制头使用的 latent。

## Strengths
方向与 JEPA/WAM 高度贴合；ISAE 解决 latent distribution mismatch 的问题具体；asymmetric MoT 把训练期 world modeling 和推理期策略效率解耦；LIBERO/LIBERO-Plus/RoboTwin 覆盖较广，鲁棒性结果突出。

## Weaknesses
很多指标来自与近期系统的报告值比较，统一复现实验有限；真实机器人实验主要是定性；性能依赖底层 V-JEPA/预测基础模型质量；对精细接触、触觉、高频动力学承认不足；模块较多，训练成本高。

## Future Work
作者提出未来整合 multimodal priors，例如 audio/visual/haptic priors，并把 predictive-latent paradigm 扩展到 long-horizon task planning，使 latent dynamics branch 成为层级推理引擎。
