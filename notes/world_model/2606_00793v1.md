# MBench: A Comprehensive Benchmark on Memory Capability for Video World Models

创新度：3/5 | 相关度：3/3

## Insight

核心 insight：当前视频世界模型的评估体系存在关键盲区——现有 benchmark 主要衡量视觉质量、运动连贯性和文本对齐，但完全忽视了世界模型最核心的能力：**长时记忆**（long-term memory）。

**Observation**：(1) 现有模型可以生成视觉上逼真的分钟级视频，但当相机离开再返回同一场景时，3D 布局、物体身份、因果状态往往发生漂移；(2) 在 action-conditioned 模型中，一些模型通过生成"静态冻结"的场景来获得高一致性分数，但完全无法模拟状态演化（如 HY-WorldPlay 的空间一致性很高但 state evolution 分数很低）。

**推论**：需要一个多维度、层次化的记忆评估体系，将 trigger coverage（模型是否执行了记忆挑战）与 memory reliability（执行后是否保持一致性）解耦，避免"逃避挑战"的模型获得虚高分数。

**验证**：通过 Trigger-Conditioned Scoring 机制，MBench 成功暴露了这种 trade-off：HY-WorldPlay 虽然空间/渲染一致性最高，但 self-evolution 分数远低于 Yume-1.5。

## Motivation

视频生成模型与视频世界模型的根本区别在于：世界模型必须维持持久的内部世界状态。然而现有 benchmark（VBench、WorldScore、WorldBench 等）主要评估单帧质量或短时一致性，缺乏对长时记忆的系统评估。MBench 旨在填补这一空白，提出首个全面覆盖实体一致性、环境一致性、因果一致性三个维度的记忆能力评估基准。

## Method

MBench 的设计包含三个层面：

**1. 评估维度（三层层次化分类）：**
- **Entity Consistency**（实体一致性）：
  - Object：几何一致性（warp+SSIM）、纹理一致性（DINOv2 centroid 相似度）
  - Human：身份一致性（ArcFace 特征跟踪）、外观一致性（DINOv2 全身 mask）
- **Environment Consistency**（环境一致性）：
  - Spatial：对极几何（基本矩阵 + 点距）、重投影一致性（三角化后重投影误差）
  - Rendering：光照一致性（CIELAB 亮度+色度偏移）、风格一致性（Gram 矩阵距离）
- **Causal Consistency**（因果一致性）：
  - Self-evolution：状态演化（VLM 评分）、演化正确性（VLM 评分 + soft gating）
  - Interaction：文本交互（OpenCLIP 相似度）、动作交互（6DoF twist 余弦相似度）

**2. Trigger-Conditioned Scoring：**
- 先用 VLM（Seed 2.0）验证模型是否执行了记忆触发事件（如物体离开视野再返回）
- 只对成功触发的样本计算一致性分数（memory reliability）
- 最终 M-Score = trigger coverage 与 reliability 的调和平均，惩罚通过回避挑战来获得虚高分数的模型

**3. 数据构建：**
- 从 5 个真实视频数据集（DL3DV、Tanks and Temples、OpenHumanVID、SpatialVID、Physics-aware-video）中筛选
- 1040 个标准化评估用例
- Text-conditioned 模型：5 段连续提示词，每段约 5 秒
- Action-conditioned 模型：Exit-and-Reenter 范式（离开-等待-返回），25 秒 rollout

**创新程度**：较高。三维层次化记忆分类体系和 Trigger-Conditioned Scoring 是核心创新。

## Experiment

**评估对象**：8 个 text-conditioned 模型（Memflow、Self Forcing、Skyreels V2、Longlive、Longcat-Video、Cosmos-Predict 2.5、Causal Forcing、Helios）+ 6 个 action-conditioned 模型（Matrix-Game 2.0/3.0、HY-WorldPlay、Yume-1.5、Lingbot-World、Infinite-World）

**主要发现**：
1. **记忆是系统性瓶颈**：所有模型在空间和因果指标上表现显著弱于实体指标
2. **Text-conditioned**：Self Forcing 和 LongLive 最具竞争力；Helios 几何/纹理最强；风格一致性对所有模型都很低
3. **Action-conditioned**：HY-WorldPlay 空间/渲染最强，但 self-evolution 极低（"冻结场景"问题）；Yume-1.5 的 state evolution 得分最高（97.90）
4. **关键 trade-off**：空间/渲染一致性与因果自演化存在矛盾——通过冻结场景可获得高一致性分数但无法模拟物理过程

**Human Alignment**：2362 条人工标注，几何一致性 ρ=0.97，大部分指标与人类判断高度相关；光照一致性和文本交互对齐度较低。

## Value

MBench 是目前对视频世界模型记忆能力最全面的评估基准。其核心价值在于：

1. **揭示了当前模型的系统性短板**：即使是最先进的模型也无法在离开-返回场景中保持 3D 一致性和因果连续性
2. **Trigger-Conditioned Scoring 是重要的方法学贡献**：防止模型通过回避挑战来作弊
3. **因果一致性是最难的维度**：这对世界模型的内部状态表示提出了更高要求

**对我们的启发**：
- 视频世界模型的评估不能停留在视觉质量，记忆和因果推理能力是区分"视频生成器"和"世界模型"的关键
- Exit-and-Reenter 范式是测试 3D 世界一致性的有效实验设计
- 隐式世界模型（如 JEPA）在记忆维持方面可能有天然优势（latent space 的紧凑表示），值得探索

**待解决**：评估的自动化程度仍依赖 VLM 质量；缺乏对世界模型内部表征的直接探测。

## TL;DR

首个系统评估视频世界模型长时记忆能力的 benchmark，将记忆分解为实体/环境/因果三维度并提出 Trigger-Conditioned Scoring 防作弊机制，揭示当前模型在空间和因果一致性上的系统性不足。值得精读。
