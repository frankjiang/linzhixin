# 3D-Belief: Embodied Belief Inference via Generative 3D World Modeling

- **arXiv**: 2605.11367v1
- **Authors**: Yifan Yin, Zehao Wen, Jieneng Chen, et al. (Johns Hopkins, MIT, CMU)
- **Date**: 2026-05-12

## Insight
世界建模不应仅是新视角合成或未来帧预测，而应是3D空间中的具身信念推断——维护和更新智能体对未观察到的3D世界的belief，包括结构化不确定性。

## Motivation
现有视觉生成式世界模型强调视觉逼真度，但缺乏具身智能体在部分可观察性下所需的结构化不确定性。需要能在3D空间中直接表示不确定性的世界模型。

## Method
- **3D-Belief**：从部分观测推断显式、可操作的3D belief并随时间在线更新
- 基于3D Gaussian Splatting的场景级3D扩散
- 四项关键能力：
  1. **空间一致的场景记忆**：观测过的区域持久保持
  2. **多假设信念采样**：对未观测区域生成多种合理补全
  3. **顺序信念更新**：随新观测到来在线更新belief
  4. **语义知觉预测**：对未见区域进行语义推断
- 不确定性直接在3D空间中表示（而非2D图像空间）

## Experiment
- 2D视觉质量评估：场景记忆和未观测场景想象
- **3D-CORE基准**（本文提出）：物体和场景级3D想象评估
- 仿真和真实世界物体导航任务
- 在2D和3D想象质量及下游具身任务性能上均优于SOTA

## Value
将世界建模重新定义为3D信念推断，提供了具身智能体所需的结构化不确定性表示。3D Gaussian Splatting + 场景级3D扩散的组合是新颖的技术路线。对3D世界模型研究方向有重要推动作用，提出的四项能力为3D世界模型的评估提供了清晰框架。
