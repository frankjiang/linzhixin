# WorldAttention: An Efficient Attention Architecture for Interactive Video World Models

## Insight
观察：交互式长视频需要召回久远细节，滑窗遗忘历史，全量 KV 缓存又超出显存与算力预算。推论：把历史缓存按语义页分层存放、仅取相关页，并用低秩全局分支补足稀疏注意力，可兼顾长程一致性和吞吐。检索消融与端到端速度测试支持该结论。

## Motivation
自回归扩散视频模型要支持提示词中途改变及历史对象重现，现有滑窗和全历史注意力的资源开销制约交互时长；这是视频世界模型落地的关键系统瓶颈。

## Method
HKV 将历史 KV 分为 chunk 和页，以提示词相似度先选 chunk，再按 query-key 相似度选页；GPU SRAM/HBM、CPU DRAM、NVMe 分层驻留。HSA 并行使用序列投影的低秩全局注意力及按头自适应的块稀疏注意力，门控融合；历史块与当前块分别使用 128/64 token 粒度，并实现定制 kernel。贡献主要在检索、注意力和硬件执行的系统协同。

## Experiment
60 秒 VBench-Long 和 InterVBench；评估主体/背景一致性、运动平滑、动态程度、画质、CLIP 对齐及 FPS。VBench-Long 主体一致性 0.9472、背景 0.9691、运动平滑 0.9915；交互视频整体质量 85.53，优于 LongLive 的 83.95。相同活跃 KV 预算下 HKV 为 85.53 分、22.0 FPS；滑窗为 82.52 分、22.1 FPS。H100 上定制 HSA kernel 相对 FlashAttention-3 快 14.02 倍，完整系统快 2.21 倍；B200 的多配置为 2.06–2.46 倍。逐组件消融：仅 HKV 1.15 倍，加入 HSA 1.91 倍。

## Value
可直接借鉴于长时视频世界模型的记忆管理：按交互语义检索历史，同时保留便宜的全局信息通路。针对生成质量和吞吐的系统收益明确，但未证明生成的视频能支持真实控制或物理推理。

## Strengths
同时测量质量、速度和缓存检索；包含误检索、页预算、相似历史及跨硬件规模消融。

## Weaknesses
许多组件基于既有低秩/稀疏注意力与分层缓存；主要是提示词驱动视频，缺少动作条件、闭环规划及真实物理一致性评估。固定页预算下多事件提示词可能无法兼顾，作者也指出 Top-1 设置偏向单一语义段。

## Future Work
论文未给出明确的未来工作清单；多事件检索和面向闭环交互的评测是值得继续验证的方向。

## Rating
创新度评分：3/5 - 有扎实系统协同及性能收益，但核心注意力与缓存思想多为现有技术组合。
相关度评分：3/3 (Core) - 直接服务交互式长视频世界模型。

## TL;DR
分层语义 KV 检索结合混合稀疏注意力，使长时交互视频更快且更一致；视频模型系统设计值得精读。
