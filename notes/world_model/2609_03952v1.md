# WorldReward: Reward Modeling for Camera-Conditioned World Models

## Insight

完整长视频与整段动作一次性送入 VLM 时，短暂的局部动作证据容易被长上下文和总体观感淹没；而几何轨迹奖励与逐帧画质奖励又无法共同解释“动作是否正确地造成了高质量视觉变化”。论文据此提出 local-to-global 判断：先按动作切成短 chunk，用同一 VLM 在结构化局部证据上分别判断动作一致性与视觉质量，再投票汇总。移除 frame-grid、action panel 或逐视频 reasoning 均降低人类一致率，且该奖励用于 RL 后同时提升外部动作与画质指标，构成经验性证明。

## Motivation

相机条件视频世界模型既要执行平移/旋转命令，又要维持几何、外观和时间动力学。现有 3D 轨迹奖励只看控制，图像奖励忽略闪烁和动态，通用视频奖励又不知道命令；这使评估与 RL 后训练依赖异构、解耦信号。该问题是长时可交互视频世界模型的直接瓶颈，尤其涉及局部归因和长程误差累积。

## Method

WorldReward 是基于 Qwen3.5-9B 的生成式 pairwise reward model：

- 在动作序列前加 idle slot，每四个 slot 构成一个 chunk。每个候选视频对的输入含源图、caption、展示每个动作首/中/末帧的双视频 frame-grid，以及四张首末帧 action-level panel，共六图。
- 模型逐动作判断 {A, B, Tie}，同时从 temporal consistency、dynamic generation quality、artifact/structure integrity 三方面推理视觉质量；chunk 结果通过 A/B 票数汇成全视频 action 与 visual preference，Tie 不计票。
- 训练数据由八种相机条件世界模型在相同图像、caption、轨迹下生成 50,000 对视频；约 100,000 个 chunk 先由 Gemini 3.1 Pro 蒸馏结构化 reasoning，再由 GPT-5.5 工具代理多轮检查局部图像，代理建议修改的样本送人工校准。位置交换后共 124,942 条训练样本，SFT 三轮。
- 用于 HY-WorldPlay 1.5 后训练时，同一前缀采样候选 clip，两两比较得到 action/visual win rate，组内标准化后加权为 DiffusionNFT 的 optimality probability；创新在 reward，不在 RL 算法。

## Experiment

- WorldReward-Bench 含 760 对训练条件未见的视频，每段 23 个动作、184 帧，覆盖平移、旋转、复合轨迹和多视觉风格。每对由三名盲审标注 action、appearance、motion，按维度多数票定标签，无多数时加一名标注者。
- 三分类人类一致率为 77.63%/81.32%/73.03%（action/appearance/motion），均为最佳；GPT-5.5 为 74.21%/79.87%/69.47%，Gemini 为 65.79%/80.13%/60.79%。几何模型只能评 action，图像/视频 reward 在其他维度明显较弱。
- 标注流水线消融：直接 Gemini 蒸馏模型平均 68.69%，代理 QC 后 75.94%，人工复核后 77.33%；42.1% annotation 被代理修改，其中 87% 的修改获人工确认。
- 结构证据消融中，去 frame-grid 平均下降 2.48 点，去 action panel 主要令 action 下降 2.82 点；仅 preference label 为 72.47%，加入 summary 和 per-video analysis 后到 77.33%。随机 A/B 顺序仅下降 0.53-1.24 点。
- 在固定数据和 DiffusionNFT 配置下替换 WorldCompass reward，短/中/长程 combined-action accuracy 分别由 58.20/55.01/54.82 提至 59.96/57.79/56.40，HPSv3 同时由 0.42/0.37/0.73 提至 0.68/0.55/1.02；basic action 亦持续提升。200 对长程视频的人评也更偏好 WorldReward-RL；逐对人类一致率 action 70.3%、visual 72.9%，与 GPT-5.5 相近。

## Value

论文把世界模型评估、偏好数据和 RL 奖励连成闭环，并明确验证局部动作证据、时间画质和 reasoning supervision 的作用。对我们的直接启发是：视频世界模型的 reward 不应只看最终帧或重建轨迹，而要把动作-视觉因果证据对齐到局部时间窗，再保留不同优化维度。该范式可迁移到交互视频，但目前仍局限于相机运动，不能直接代表机器人接触与物体动力学。

## Strengths

- 单一判断空间同时产出动作与视觉偏好，避免异构 reward 的语义不一致。
- 数据生成、代理审计、人工校准、独立 benchmark 和下游 RL 验证链条完整。
- 对结构输入、reasoning、标注精炼、候选顺序及两类 reward 都有针对性消融。
- 除自身 reward 外，还用 DAv3、HPSv3、GPT-5.5 和盲审人评交叉验证 RL 结果。

## Weaknesses

- 训练监督高度依赖两个闭源 VLM；人工只集中复核代理提出修改的样本，未报告对“原样保留”部分的等量人工抽检误差。
- Benchmark 仅 760 对且与训练共享多种生成器分布；虽图像和轨迹库独立，是否泛化到全新模型族、动作语义和更长异常模式仍未知。
- 未报告标注者间一致性（如 Fleiss' kappa）；模型逐对与人类的一致率仅约 70%-73%，仍有明显 reward misspecification 空间。
- 多数投票丢弃失败严重度与时序，一次灾难性局部错误可能被多个轻微优势 chunk 淹没。
- 下游只后训练 HY-WorldPlay 1.5，尚未证明 reward 对其他架构稳定，也未系统分析优化后针对 judge 的 reward hacking。
- 任务仅是相机轨迹控制，不覆盖物体交互、接触和可供性等更完整世界动力学。

## Future Work

作者未在结论中明确提出后续方向；从正文局限看，关键待办是扩展到未知生成器和更丰富动作、扩大独立人评，并改进对长程严重局部失败的聚合与抗 reward hacking 能力。

## Rating

创新度评分：3/5 - 动作对齐 chunk、结构化 VLM reasoning、数据审计与 RL 的组合新颖且验证完整，但核心聚合和训练技术较常规，主要是面向相机世界模型的系统创新。
相关度评分：3/3 (Core) - 直接解决交互式视频世界模型的评价与强化学习后训练。

## TL;DR

WorldReward按动作切片统一评估控制与视频质量，并有效指导长程世界模型后训练，值得精读。
