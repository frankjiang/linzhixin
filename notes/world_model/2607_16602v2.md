# PAVXploreRL: Physical-Action-Visual World Model Reinforcement Learning with Action Exploration

## Insight
核心 insight 是 action-conditioned robot world model 不应只用专家 ID action-video 和像素重建训练；作为 policy evaluator，它必须显式优化 Physical Plausibility、Action Adherence、Visual Fidelity，并接触无配对视频的 OOD actions。作者用 action-conditioned VJEPA-2 作为 latent reward/evaluator，把 OOD action exploration 纳入 world model RL。

## Motivation
机器人视频世界模型常用于虚拟评估策略，但如果只看 expert 成功轨迹，会高估 suboptimal policy，尤其对 OOD 动作预测过乐观。现有 RL 后训练多仍依赖 GT video 或像素/VLM reward，难以评估没有真实视频的动作。本文解决的是 world model 的后训练和策略评估可靠性。

## Method
基础模型用 Wan2.2-TI2V-5B 加 action conditioning 和 Framepack 式历史压缩，输入 first frame、历史帧和未来动作，预测未来视频。SFT 收敛后用 DiffusionNFT 更新 action encoder 和 LoRA。奖励分 ID/OOD 两支：ID 有 GT video，结合 pixel reward、VJEPA encoder reward 和 visual fidelity；OOD 用对 GT action 加 temporal shift、magnitude bias、smooth temporal noise 产生 suboptimal actions，无 GT video，使用 VJEPA predictor reward 和 visual fidelity。VJEPA-2 冻结 encoder，训练 action-conditioned predictor，并同时使用 raw frames 与 embodiment-focused segmentation frames，支持 multi-step autoregressive latent prediction。

## Experiment
数据包括 Agibot Alpha 92K trajectories/590h/36 tasks 和 DROID 76K trajectories/350h/86 tasks。Agibot 上 RL 从 PT 的 PSNR 20.52、SSIM 0.793、LPIPS 0.133、EPE 0.346、COS 0.203 提升到 PSNR 21.20、SSIM 0.812、LPIPS 0.127、EPE 0.306、COS 0.231。DROID 上从 PSNR 20.79、SSIM 0.814、LPIPS 0.097、EPE 0.252、COS 0.168 提升到 PSNR 21.71、SSIM 0.828、LPIPS 0.092、EPE 0.227、COS 0.197。消融显示 VJEPA-E、VJEPA-P/OOD、static regularization、embodiment reward 和 visual fidelity 都有贡献，其中 static regularization 最关键。Policy evaluator 实验中比 Ctrl-World 更少高估真实策略成功率。

## Value
对机器人视频世界模型非常相关：它把 JEPA-style latent prediction 用作 reward，并关注 OOD action 下的 evaluator bias。启发是 world model 后训练需要直接服务 P/A/V 目标，而不只是重建验证集。局限在于方法主要改后训练 reward，基础 world model 本身没有多视角一致性或显式几何。

## Strengths
问题贴近实际 policy evaluation；ID/OOD reward 设计合理；VJEPA raw + embodiment 双流用于物理和动作一致性；在两个机器人数据集和真实策略评估上都有提升。

## Weaknesses
训练成本高，RL 5K steps 仍需多天 H200；OOD action 是噪声扰动，不等价于真实策略分布；指标提升幅度中等；VJEPA reward 本身可能引入偏好和盲点。

## Future Work
作者提出将 PAVXploreRL 扩展到更先进的 pretrained world model，测试通用性和鲁棒性；同时未来可结合 multi-view consistency 等结构化 world model 组件。

## Rating
创新度评分：3/5 - 奖励和 OOD action exploration 设计有价值，但属于后训练增量改进。
相关度评分：3/3 (Core) - 直接研究机器人 action-conditioned 视频世界模型和 JEPA-style 隐式奖励。

## TL;DR
PAVXploreRL用PAV奖励和OOD动作探索后训练机器人视频世界模型，方向核心，值得精读。
