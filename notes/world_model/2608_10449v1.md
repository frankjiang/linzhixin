# PBD-AG: Persistent Baseline-Delta Active Graphs with Uncertainty-Aware Inspection for Long-Horizon Service Robots

## Insight
长期室内世界不是均匀变化的：固定设施应形成经机器人验证且可冻结的 baseline，细粒度物体变化作为 delta/event 追加；“没看到”只有在物体应位于视锥、未被遮挡且像素支持足够时才是删除证据。这一分解显著减少误删除并维持身份连续性。

## Motivation
在线重建会累积定位/观测误差，静态 3D 图不能表达变化，纯 VLM 预测又缺少可核验几何；服务机器人还需在未知环境自主建图而非依赖预加载图。论文解决的是持久 3D 语义记忆及主动观测，属于显式世界状态建模的重要邻近问题。

## Method
frontier exploration 从空图建立占据地图与 SigLIP 开放词汇体素证据，经聚类、多帧共识和有限 VLM 验证提升 fixture track，最终冻结结构 baseline。运行时每个 persistent track 维护类别、存在概率、3D 均值/协方差、父支撑、外观、时间和生命周期；出现、移动、消失、跨支撑转移写为有序 delta。几何 visibility gate 限制负证据；图不确定性策略在覆盖、路程、碰撞、冗余和模型调用预算间选择 fixture-centered inspection viewpoint。

## Experiment
设计三类协议隔离表示、动态记忆和主动获取。九个模拟 scene-seed 共享证据下 coarse F1 为 .868±.102，优于 DynaMem-adapted .757 和 ConceptGraphs-adapted .696；自主构图 coarse/fine F1 为 .866/.713。三条 300-frame 动态序列共 12 个事件，PBD-AG IDF1=.833、0 次 identity switch、召回 11/12、false absence=.014。去 visibility gate 后误缺失升至 .262、事件召回降至 6/12；去 persistent ID 后 IDF1=.070、切换 43.33。真机仅定性展示完整管线。

## Value
baseline-delta 与“可观测才计负证据”是很实用的持久 3D 世界状态原则，也有良好可审计性，可作为 3D 世界模型的外部记忆层。但它不预测连续未来或学习动力学，核心仍是显式地图/scene graph 更新。

## Strengths
- 评价协议尽量共享几何证据，较好隔离关联和记忆规则。
- visibility gate、persistent ID 消融效果大且符合机制预期。
- 可从未知场景自主启动，输出身份、支撑关系和事件审计链。

## Weaknesses
- 动态实验只有三条 Hotel 序列、12 个预定事件，场景变化很简单。
- baseline 对家具移动/房间重构等慢变结构的适应性没有验证。
- 真机没有定量精度、任务成功或长期多 session 结果。
- adapted baselines 只是能力匹配控制，不等于完整官方系统公平比较。
- 依赖 posed RGB-D、共享 world frame 和固定 fixture taxonomy，离开放世界仍远。

## Future Work
应扩展跨天/跨房间长期部署、baseline 版本化与结构漂移、开放类别和遮挡密集场景，并用真实服务任务验证图记忆对规划的收益。

## Rating
创新度评分：3/5 - baseline-delta、几何负证据门控与主动检查组合扎实，但属于显式记忆系统的增量创新。
相关度评分：2/3 (Related) - 直接涉及持久 3D 世界状态和机器人记忆，但不是生成式或隐式动力学世界模型。

## TL;DR
以冻结设施基线、事件增量和可见性门控维护长期 3D 图，机制扎实但真机规模小，可选读。
