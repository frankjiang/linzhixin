# Learning Action-Conditional and Object-Centric Gaussian Splatting World Models for Rigid Objects

## Insight
无特别深刻的insight。核心观察比较直观：object-centric的3D Gaussian Splatting表示天然适合刚体动力学建模，因为刚体运动可分解为per-object的SE(3)变换，而GS的点云表示可以直接施加rigid-body transformation。将场景表示与动力学预测解耦（GS负责外观/几何，Transformer负责pose预测），是一个合理的工程设计。

## Motivation
- **问题**：如何学习多物体场景中action-conditional的3D世界模型，用于机器人操作的model-predictive control？
- **同行做法**：(1) 基于NeRF的compositional world model（如Driess et al. 2023），隐式表示难以直接操作；(2) 基于GS的单物体动力学（3DGSim、ManiGaussian等），不支持多物体交互或不是action-conditional；(3) 基于物理引擎的GS（ContactGaussian-WM、Embodied Gaussians），依赖已知物理参数或仅处理单物体。
- **是否关键**：多物体、action-conditional的3D世界模型是机器人操作的核心需求，问题定义合理。

## Method
**场景表示：**
- 基于ObjectGS（ScaffoldGS扩展），用voxel anchor + MLP解码2D Gaussian。每个anchor关联一个object ID，支持per-object rigid transformation。
- 通过投票机制（结合depth验证）将anchor分配给物体，扩展到多场景共享MLP（共享scale/rotation/opacity MLP，per-scene color MLP）。

**动力学模型（Spatio-Temporal Transformer）：**
- 输入：将anchor/Gaussian按object pose做rigid transform到canonical frame，编码历史h步object轨迹 + 未来p步end-effector动作。
- 架构：基于PTv2的多阶段点云处理，4种attention层交替：
  - Spatial attention（邻域点交互）
  - Temporal attention（同一点跨时间步交互）
  - Spatio-temporal attention（新提出，邻域点在不同时间步的交互，编码相对运动信息）
  - MLP层
- 多尺度spatial grid pooling，逐步聚合到per-object级别。
- 输出：预测per-object relative SE(3) pose变化（position + 9D rotation matrix）。

**训练：**
- L2 position loss + normalized rotation matrix L2 loss。
- 60K steps，单卡A40约22小时。

**创新程度**：object-centric GS + spatio-temporal transformer的组合是合理的工程创新，新提出的spatio-temporal attention层有一定新意。但整体思路比较直接，各组件大多借鉴现有工作。

## Experiment
**数据集：** ManiSkill模拟器，YCB物体集（1-5个物体的桌面场景），32视角RGB-D重建，Franka机械臂交互。

**预测评估：**
- 指标：position error (cm)、rotation error (geodesic angle, deg)
- 主模型（YCB-100-100, 4步@10Hz）：median pos err 0.45cm, mean 0.73cm, median rot err 5.54deg, mean 7.08deg
- 消融：spatio-temporal attention去除后position error显著上升（0.49→0.57 median）；多尺度下采样去除影响最大（0.57→median pos, 0.86→mean pos）

**规划评估（MPC）：**
- 两个非抓取操作任务：push-to-position (SR=0.77@1cm) 和 clear-middle (SR=0.66)
- 基于iCEM的sampling-based MPC，2Hz规划频率

**局限：** 假设已知物体mask和pose（来自simulator），仅考虑刚体，未在真实环境验证。

## Value
这是一篇扎实的3D世界模型工作，将object-centric Gaussian Splatting与action-conditional dynamics prediction结合，直接在结构化3D表示上做前向预测。对我们的3D世界模型方向高度相关：(1) 展示了GS作为世界模型表示的可行路径；(2) spatio-temporal transformer处理多物体交互的设计可参考；(3) 从表示到规划的完整闭环验证。

待解决问题：(1) 依赖GT segmentation和pose，需要集成感知模块；(2) 仅处理刚体，可变形物体需扩展；(3) 仅在仿真中验证，real-world gap待考察；(4) 规划仅2Hz，实时性需提升。
