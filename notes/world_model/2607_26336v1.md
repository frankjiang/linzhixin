# Learning Implicit Causal World Models from Multi-Agent Demonstrations

## Insight
核心 insight 是：多智能体演示中的策略意图会把动作与环境转移混淆，普通 associative world model 学到的是专家策略相关性，而不一定是环境因果机制。作者认为在专家策略中加入可控随机性，相当于对动作机制做 soft intervention，可满足多智能体 sequential backdoor condition，从而让世界模型识别更接近不变动力学。

## Motivation
模型式强化学习中的世界模型在分布内可预测，但遇到其他智能体策略变化时容易失效。已有因果世界模型通常需要预定义图或强因果假设，普通 Dreamer/PlaNet/MuZero 类 associative 模型不区分策略意图和物理转移。多智能体场景下这是重要问题，但本文关注低维模拟而非视频/3D生成。

## Method
ICWM 的流程是：用带随机性的专家策略收集不同 interventional strength `sigma` 的多智能体轨迹；把状态、动作、奖励历史看作 VAR 时间序列；用 PCMCI+ 发现滞后因果边，并丢弃 contemporaneous 相关以隔离策略意图混淆；将得到的 causal tensor 作为 soft mask 乘到 MLP/LSTM 世界模型输入上。理论部分给出 MAS-SBC 公式和 OOD generalization error 随 `sigma` 增强而下降的界。

## Experiment
实验在 Two-Door、Navigation、Giveway 三个协调环境中做 full/partial observability、2/3/4 agents 和策略 shift。随着 `sigma` 从 0.01 到 0.99，graph error 与 adversarial MSE/Var 一起下降，Navigation 上可有数量级改善。作者也发现关键杠杆不是图质量本身：在匹配 `sigma` 后，graph-free AWM 可接近 ICWM；causal mask 主要在 partial observation 和 layout extrapolation 中有价值，错误 mask 会让误差膨胀 1.16 到 17.9 倍。布局重排是边界：空间 rearrangement 下 transfer error 会随 `sigma` 增大从约 1.9x 到 5.3x。

## Value
这篇对“因果化世界模型”有参考价值，尤其提醒离线演示中的干预强度比模型结构更关键。但对我们的视频/3D/JEPA主线是间接相关：实验是低维多智能体模拟，模型是小 MLP/LSTM+mask，不涉及视觉表示、生成式视频或 3D 物理重建。

## Strengths
亮点是把策略随机性、sequential backdoor 和世界模型 OOD 预测联系起来；实验不只报平均预测误差，还分析图质量、干预强度、mask 腐坏、布局 shift 和不确定性集中在哪些维度。

## Weaknesses
不足是理论假设较强，例如严格时间滞后和 contemporaneous confounding isolation；所谓 implicit world model 实际规模很小，和现代 latent/video world model 差距大；结论依赖模拟环境，尚未证明可迁移到真实机器人或视觉世界模型。

## Future Work
作者提出未来可连接 causal imitation、causal Q-learning 和 associative model 的 steerability gap，并用于 runtime verification 和 self-correcting agentic systems。还需要研究 targeted 而非 uniform intervention，以及 layout shift 下的机制识别。

## Rating
创新度评分：3/5 - 因果识别框架和干预强度分析有一定新意，但模型与实验规模较基础。
相关度评分：2/3 (Related) - 研究隐式因果世界模型，但与视频/3D/JEPA/Dreamer 主线间接相关。

## TL;DR
用策略随机性作为软干预学习多智能体因果世界模型，启发有限，可选读。
