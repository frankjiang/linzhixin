# ACID: Action Consistency via Inverse Dynamics for Planning with World Models

## Insight
ACID 的 insight 是 world model 规划不能只问“预测轨迹是否接近目标”，还要问“这条预测轨迹是否真由给定动作导致”。Observation 是 CEM/MPC 在动作条件世界模型中常按终点目标距离选轨迹，模型可能生成视觉上合理但动作不一致的未来。作者用 inverse dynamics model 从预测转移反推出动作，并把反推动作与候选动作的残差作为规划代价，从而过滤不可执行的幻觉轨迹。

## Motivation
论文解决 action-conditioned world model 的规划可靠性。同行通常依赖终点 goal cost、trajectory score 或模型自身 likelihood，但这些指标不直接惩罚“动作-结果不一致”。这是关键问题：在 JEPA/latent/video world model 中，规划器若选择了模型幻觉出的好结果，闭环执行会失败。

## Method
ACID 不重训世界模型，而是在决策时加入一个 inverse dynamics verifier。给定世界模型预测的相邻状态，IDM 用 flow matching action decoder 估计导致该转移的动作；规划代价为 goal cost 加 action consistency cost。权重采用自适应归一化，用两个 cost 的 spread 定标，避免手调常数。该方法可插到 CEM-MPC 中，适配 Le-WM、PLDM、DINO-WM、NWM 等不同世界模型。

## Experiment
在 Cube、Reacher、PushT、Rope、Granular 和视觉导航上测试四类 action-conditioned world models。Le-WM 上 Reacher 成功率 76% 提到 88%，PushT 96% 到 100%；PLDM 上 Cube 58% 到 68%、Reacher 76% 到 90%。DINO-WM 在 Rope/Granular 的 Chamfer Distance 分别从 1.38/0.49 降到 0.56/0.30；NWM 导航 ATE/RPE 小幅下降。鲁棒性实验显示 ACID 在较小 CEM 样本数下也能接近或超过原规划器大预算效果。IDM 开销通常较小，Le-WM/PLDM 约增加 9-12%，DINO-WM 较重。

## Value
对隐式 world model 很有价值：它把“动作可解释性”作为规划时的约束，而不是只看视觉目标相似度。这个思想可迁移到视频世界模型的 action grounding、robot policy imagination 和 JEPA planning。

## Strengths
方法简单、可插拔、跨模型验证充分；不要求重训基础 world model；自适应权重比固定权重稳定；清楚地区分视觉可达和动作可达。

## Weaknesses
需要额外训练 IDM；若状态不包含足够信息、存在外部扰动或部分可观测，反推动作不一定唯一；导航任务收益较小，说明方法受模型和任务结构影响。

## Future Work
作者指出未来可与更强 world model 结合，并研究部分可观测、外生干预和更复杂动作空间下的一致性检验。

## Rating
创新度评分：4/5 - 用 inverse dynamics 做决策时动作一致性约束，简洁且跨 JEPA/视频/latent world model 有直接作用。
相关度评分：3/3 (Core) - 直接面向 world model planning 和隐式表示规划，核心相关。

## TL;DR
用 inverse dynamics 检查预测轨迹是否动作一致，显著稳住 world model 规划，值得精读。
