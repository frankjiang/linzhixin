# MOSH-WM: Mask-Grounded Soft-Hamiltonian Dynamics for Object-Centric World Models

## Insight

观察是 object slot 为重建服务时会混合位置、外观、身份和解码器特征，用它直接承载动力学会在闭环反馈中漂移；但若只保留紧凑物理状态，又无法还原外观。论文推论是应把“可传播的几何相状态”与“可解码的视觉上下文”分开：由 slot-owned mask 的空间矩构造位置样状态 Q，以时间差分构造 P，用软哈密顿方向约束长期演化，同时由因果 slot 历史补回身份与外观。30 帧 horizon 曲线、组件移除和跨 SAVi/STEVE observer 的结果共同提供经验验证，但能量并非被识别出的真实 Hamiltonian。

## Motivation

现有 object-centric 视频世界模型通常在无约束视觉 slot 上拟合自回归转移，短期预测尚可，长期闭环则出现物体位置、颜色、身份和相对布局漂移。严格 Hamiltonian 状态又可能与视觉 observer/decoder 不兼容。论文要在保持解码质量的同时，为物体级世界状态加入明确空间落点与物理方向偏置；这是视频世界模型中长期一致性的关键子问题。

## Method

- 冻结 SAVi encoder/decoder，从 L 个观察帧得到 slot 与 soft mask。每个像素 winner-take-all 归属一个 slot，固定空间基在 owned mask 上做归一化池化，再经轻量映射得到 Q；`P=(Qt-Qt-1)/Δt`。
- 能量头 `H(Q,P)` 只看相状态；learned core 则结合 Q、P 和因果视觉上下文 C 预测增量。更新把 learned increment 与裁剪的 Hamiltonian gradient 按 α 混合，使用 forward Euler，属于 soft bias 而非辛积分或真实能量辨识。
- 视觉上下文 C 来自历史 slots。gated composer 将更新后的 phase displacement 与 C 合成物理 slot proposal，再用有界时空 residual 做小幅 decoder-space 修正，最终交给冻结 decoder；预测 slot 与帧闭环回馈。
- 训练损失包含 slot、图像、Hamiltonian 方向、energy drift、centroid trajectory 和 residual bound；OBJ3D 默认 α=0.5，6 帧观察，按 10/15/20/24/30 帧课程训练 8000 步。
- 创新来自 mask-grounded phase/context factorization 及其软物理闭环组合，属于有针对性的结构改进，而非新世界模型范式。

## Experiment

- OBJ3D 64×64：6 帧观察、30 帧无目标反馈预测；对比 SlotFormer、SAVi-dyn 和像素级 PredRNN。MOSH-WM 的 LPIPS/PSNR/SSIM/MSE 为 0.0858/31.02/0.8916/4.718；相对最强 object-centric 基线，LPIPS 降 25.0%、MSE 降 33.7%、PSNR 高 2.43 dB。
- 同一冻结 observer 下的物体指标：ADE 0.00473、FDE 0.00957、velocity 0.00127、pair-distance 0.00592、slot MSE 0.00795，分别较各列最强基线改善 15.4%、9.5%、6.6%、14.9%、32.2%。Final@30 LPIPS 为 0.1744，SlotFormer 为 0.2063。
- CLEVRER：6→10 帧，LPIPS 0.3192、PSNR 26.60、SSIM 0.8375、MSE 10.068、FG-MSE 0.00996；相对 SlotFormer 的 LPIPS 0.3814、MSE 12.379，分别改善 14.5% 和 18.7%。该比较是固定算力的单次 transfer run。
- 消融：完整模型 LPIPS/MSE/Slot@30 为 0.0858/4.718/0.02608；residual-only 为 0.1665/8.468/0.08405，physics-only 为 0.1037/5.840/0.04212，无 context 为 0.1437/8.595/0.04799，说明物理与外观两路均必要。α=0.1/0.2 均不及 0.5；容量 sweep 中两 attention blocks、MLP ratio 2 最佳。
- Physion 跨 observer：使用冻结 STEVE，15 帧观察、未来 35 帧，主要看 slot MSE。horizon 30 时 full MOSH 为 0.0422，Hamiltonian-only 0.0932，residual-only 1.9220；另报告八种场景，Support 最低 0.0278、Drape 最高 0.0683。像素质量受冻结 STEVE decoder 限制。

## Value

论文给出的可迁移思路是：世界模型的动力学变量应由可解释的观测支持定义，而不是任由视觉编码器决定；解码所需信息可以走单独上下文通道。这对 object-centric 视频预测、3D/物体状态建模和长期 rollout 都有直接借鉴价值。下一步若能加入动作、深度和交互关系并进入规划闭环，价值会明显高于当前的合成视频预测结果。

## Strengths

- 问题定位准确，Q/P 的构造与像素支持直接相连，phase 与 appearance 的职责清晰。
- 使用共享冻结 observer/decoder 进行基线比较，并同时报告视觉、轨迹、关系与 slot 指标，证据链较完整。
- 不只给平均终点，还展示 horizon-resolved 误差累积、组件消融、容量敏感性和跨 observer transfer。
- 对“soft Hamiltonian”边界表述克制，明确不是辛求解器也不是能量系统辨识。

## Weaknesses

- 主结果均为单个 validation-selected seed，没有置信区间或多随机种子；CLEVRER/Physion 又是固定预算或单次 transfer，统计可信度有限。
- 数据集中在低分辨率合成 OBJ3D、CLEVRER 与 Physion，尚无真实视频、复杂纹理、检测误差或严重遮挡下的验证。
- 状态质量受冻结 SAVi/STEVE 的 slot 和 mask 直接限制，winner-take-all mask 在遮挡、slot swap 和漏分割时可能产生不连续 Q；作者也承认继承 observer error。
- Hamiltonian 部分只是与 learned increment 混合的方向正则，C 仍进入 learned dynamics core；能量不被证明守恒，难以断言学到了真实物理机制。
- 部分消融保留各自训练协议、训练预算不完全一致，且额外 α 仅微调 2000 步，因此不能把全部差异严格归因于被移除组件。
- 只研究被动闭环预测，没有动作条件、干预、规划或控制，尚未证明更好的 rollout 会带来更好的决策。

## Future Work

作者明确提出三项后续：改善遮挡下的 phase extraction，并向状态中加入 interaction、depth 和 action variables。合理推断的下一步是用多随机种子和真实视频验证稳定性，再把该 phase/context 表示接入动作条件预测与规划；后两项不是作者在结论中明确承诺的实验。

## Rating

创新度评分：3/5 - mask-grounded 相状态与视觉上下文分离有明确新意，闭环指标改善一致；但属于已有 slot 与 Hamiltonian prior 的结构化组合，验证仍局限合成域。

相关度评分：3/3 (Core) - 直接研究 object-centric 视频世界模型的长期动力学与状态表征，属于核心相关工作。

## TL;DR

用掩码落地相空间并以软哈密顿偏置减缓物体视频漂移，合成域证据扎实，值得精读。
