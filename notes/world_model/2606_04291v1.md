# A Cookbook of 3D Vision: Data, Learning Paradigms, and Application

## Insight
无特别突出的 insight。本文是综述性质，核心贡献在于以数据为中心的视角统一梳理了 3D 视觉领域的表示、数据集和学习范式。观察到一个有意义的趋势：benchmark 设计本身正在变得 model-aware（如 MegaSynth、InteriorGS 直接面向 3DGS 训练），以及重建与生成之间的融合趋势（Generation for Reconstruction / Reconstruction for Generation 形成 data flywheel）。

## Motivation
3D 视觉领域碎片化严重：表示形式多样（点云、mesh、体素、隐式场、3DGS、CAD 等），数据集分散，学习范式各异。现有综述多以架构或任务为中心，缺乏以数据为纽带将表示、数据集、学习范式统一起来的全景视角。本文试图填补这一空白。

## Method
本文是一篇综述，不涉及新方法。组织结构为：
1. **3D 表示分类学**（Sec 3）：系统对比了 RGB-D、点云、体素、mesh、CAD、隐式场、3DGS 的结构、效率、保真度
2. **学习范式与应用**（Sec 4）：从可微渲染（NeRF/3DGS）到端到端几何基础模型（DUSt3R、VGGT、RayZer、DA3），再到下游应用（重建、生成、4D 渲染、3D 世界模型）
3. **数据集与 Benchmark**（Sec 5）：按模态、粒度、任务、时间维度分类，整理了 50 个代表性数据集

涉及 3D 世界模型的讨论较浅（仅在 4.3 节简短提及 PointWorld、ParticleFormer 等），主要关注的是静态 3D 重建和生成。

## Experiment
无实验。纯综述论文。提供了 Table 1（3D 表示对比）、Table 2（50 个数据集列表）、Figure 2（数据集时间线和模态分布）等系统性整理。

## Value
作为 3D 视觉入门和全景参考有一定价值，特别是 3D 表示的效率-保真度权衡分析和数据集梳理。但对于世界模型方向的研究者，本文可参考性有限——3D 世界模型只占极小篇幅，且讨论停留在概念层面。文中对 emerging trends（4D 时空推理、physics-aware modeling、world-consistent video generation）的展望可以作为研究方向参考。
