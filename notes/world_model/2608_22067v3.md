# DELE-w0.5: Inferring Action from Future Latent State for Robotic Manipulation

## Insight

论文提出的观察值得重视：机器人控制关心动作后的物理终态，生成全部中间视频帧会把大量容量耗在外观过渡上；因此紧凑终态 latent 可能比稠密视频更适合作为 world-action 接口。但论文声称的推论——“由预测未来状态推断动作”——没有得到清晰实现支撑。Figure 3 与 Sec. 4.4 明确规定 action token 不能访问 future-observation token，推理时未来分支也被删除，按这套声明，因子分解更接近 `p(A|O,q,L)·p(O_future|A,O,q,L)`。然而 Sec. 4.2 对 noise stream 的描述可能先联合 action/future token，Eq. 19 又把 `z_future` 写进动作 velocity field，和声明的 mask 互相矛盾。稳妥结论只能是信息流定义不自洽；即便按作者声明的 mask 理解，实验也最多说明“联合终态预测可能是动作学习的辅助正则”，且没有去掉未来损失的消融来证明这一作用。

## Motivation

视频生成式 WAM 联合去噪高维未来视频与低维动作，中间帧增加序列长度、显存、训练成本和控制延迟，且视觉重建特征未必对动作最有用。已有工作多通过蒸馏、稀疏 token 或小视频 backbone 降本，却仍保留视频合成代理目标。论文试图直接联合预测动作与单个未来 latent，并在部署时彻底去掉未来生成。减少视频 WAM 冗余是重要问题，但要证明“终态足够”，必须与同 backbone、同参数/数据/预算的视频 WAM 及无终态辅助模型做受控比较；本文虽包含跨架构 GWP0.5，却没有这样的同构对照。

## Method

- 输入为语言、三路 RGB（头部与双腕相机）及本体状态；Qwen3 处理语言，DINOv3 编码视觉，线性投影到 1024 维。动作 chunk 长度 H=60，双臂动作为 14-DoF。
- condition stream 将语言与当前视觉 token 拼接，经 single-stream self-attention、RMSNorm/AdaLN、QK normalization 得到条件 Q/K/V。
- noise stream 对动作 chunk 与终态视觉 latent 同时做 flow-matching 加噪。Figure 2 像是二者各自 self-attention 后再拼接，但 Sec. 4.2 又称按 condition stream 的步骤先拼接并做 single-stream attention；之后才与条件流进入 masked attention。训练损失为动作 velocity loss `L_a` 与终态 latent velocity loss `L_o` 的加权和 `L=L_a+λL_o`。
- 论文声明的注意力 mask 规定：动作只看语言、当前观测和动作自身，future token 可看语言、当前观测和动作；按此理解，终态分支是在动作条件下学习未来，而不是给动作提供未来依据。但前置 noise-stream 处理及 Eq. 19 的函数参数与此声明冲突，无法从文本确定是否存在训练期信息泄漏。
- 推理时直接删除 future token，只对动作流去噪。方法避免视频 rollout 的确成立，但“future-state-driven action”只是命名层面的解释。论文未给 λ、模型参数量、flow 步数等关键复现信息。

## Experiment

- 平台为 Astribot S1 双臂机器人，固定实景中的 Door opening、Pepsi retrieval、Add ice、Microwave popcorn 四个长时任务；各自定义 4/5/6/5 个有序阶段与严格终态条件，单次上限 180 秒。
- 与 GWP0.5、XR0、π0.5、LingBot-VLA2、HY-VLA、Spirit-v1.5、GR00T-N1.7 比较。作者称所有方法使用相同任务数据、各按官方配置训练等价 3 epoch；每个方法每任务 20 次，共 `8×4×20=640` 次实机 trial。指标为完整任务成功率与有序阶段进度。
- 主结果（Table 2）：DELE-w0.5 的宏平均进度 81.3%、总体成功率 62.5%（50/80）；最强基线分别为 GWP0.5 的 61.3% 进度和 XR0 的 30.0% 成功率，绝对提升 20.1/32.5 点。四任务成功率依次为 80%、65%、45%、60%，均为最佳。
- 阶段分析（Figure 6）显示优势主要在把早期交互转化为完整执行：门任务 16/20，取可乐 13/20，加冰 9/20，微波炉 12/20；剩余失败集中在交接、精确释放及最终状态保持。
- RTX 4090 上 median core-model latency 为 87.5 ms，低于多种基线；但该数字排除了网络传输、图像解码、动作投影、IK、轨迹处理和机器人执行。成功 trial 的平均完成时间分别为 16.66/45.92/46.27/39.50 秒。
- 论文没有任何架构/损失消融，也没有同构受控的视频-WAM 对照、训练成本对照、置信区间或显著性检验。两个“涌现”干预案例仅为观察性轶事，无试验次数和失败率。

## Value

工作对隐式/latent 世界模型方向的最大价值是提出一个可检验的问题：控制是否只需要终态预测，而不需要视觉轨迹。其 640 次实机结果说明模型本身可能是强策略，但不能证明标题中的机制或“视频生成不必要”的结论。阅读时应将“终态辅助 flow-matching 策略”与“由未来状态反推动作的世界模型”严格区分。真正有说服力的后续应修正信息流，让动作明确依赖预测终态，或至少通过 `λ=0`、不同 horizon、视频/单帧/latent 对照识别终态监督的净贡献。

## Strengths

- 把对视频 WAM 冗余的质疑表述得直接，终态预测是值得研究的效率假设。
- 640 次实机评估覆盖四类长时双臂任务，成功条件、顺序阶段和 180 秒终止规则定义清楚。
- 不只报告完整成功率，还给出 stage-reach map，可定位长时任务中交接、插入和终态保持的瓶颈。
- 推理确实不生成未来视觉 token，core latency 较低，工程部署结果亮眼。

## Weaknesses

- 核心叙述与声明的注意力掩码矛盾：按 Figure 3/Sec. 4.4，动作不能读取未来 latent，future branch 的方向反而是 action-conditioned prediction；但 Sec. 4.2/Eq. 19 又留下潜在泄漏，方法定义本身不自洽。
- 缺少最关键的 `λ=0`/移除 future branch 消融，也没有同 backbone 的视频 WAM 或单未来图像对照，无法把巨大成功率差异归因于终态世界建模；所谓“终态”只是 DINOv3 对一个未来观测的表示，并未被验证为物理状态 bottleneck。
- 虽包含跨架构视频 WAM GWP0.5，但没有同 backbone、参数量、训练预算下的 video-vs-terminal-latent 对照，不能支持“去掉视频更便宜且同样有效”；训练 FLOPs、显存、参数量及端到端延迟也未报告。
- 数据集规模、λ、优化器、batch、flow 采样步数等关键细节缺失；“相同数据、官方配置、三 epoch”不足以确保跨模型公平和复现。
- 只在固定场景、预定义 reset 位姿上每任务 20 次，无分布 shift、仿真规模化测试和统计区间；泛化证据有限。
- “涌现”仅凭少量未量化干预观察，不能作为可靠结论；未来 latent 是否真的编码物理终态也没有探针或可视化验证。

## Future Work

作者未明确提出具体 future work，只在结论中笼统称该方向有望扩展可部署机器人智能。根据论文尚未验证的核心主张，最必要的后续是修正未来到动作的信息通路，补充终态损失/预测 horizon 消融，与视频 WAM 做同构成本对照，并在分布 shift 与量化干预下验证泛化和所谓行为重组。

## Rating

创新度评分：2/5 - “终态替代视频”是有价值的假设，但实现实质上是 VLA 动作流加 action-conditioned 终态辅助分支，且缺少消融支撑核心主张。
相关度评分：3/3 (Core) - 直接讨论以紧凑未来 latent 替代视频生成的 world-action modeling，与隐式世界模型方向核心相关。

## TL;DR

联合预测动作与终态潜变量并在推理时删去未来分支，实机结果亮眼但因果叙述不成立；仅可选读。
