# 4D-WAM: Infusing Spatiotemporal Awareness into World Action Models through Trajectory Fields

## Insight
WAM 与 4D foundation model 的绝对特征空间可能负相关，强行 feature matching 会冲突；但相邻帧的特征差分都描述同一真实运动，方向更一致。论文据此只对齐 token 级时间差，并用首帧到末帧的相似度分布补足局部差分缺失的目标信息；两项消融、OOD 视频质量和控制成功率共同支持“对齐变化/关系优于对齐绝对表征”。

## Motivation
多数 WAM 联合预测视频和动作，却在 2D latent 中学习，而机器人动作发生在动态 3D 空间；逐帧深度重建又偏低层细节，未显式利用轨迹的 4D 连续性。如何以较小训练开销把 4D 先验注入现有 WAM，是直接且关键的问题。

## Method
冻结 Trace Anything 提取 3D trajectory-field 特征，在 WAM 中间层取对应视觉 token。Motion Alignment 用两个 MLP 投影后归一化相邻帧差分，以 cosine loss 对齐运动方向；Destination Alignment 把首帧 token 当 query、末帧 teacher token 当 key，令 WAM 的 source-to-destination softmax 分布以 KL 匹配 teacher。两项辅助损失与原视频 latent/action loss 联训，推理时移除 teacher 和投影头。方法可接 FastWAM-Joint 或 Lingbot-VA，创新在跨表示差分及关系蒸馏。

## Experiment
ID 上 RoboTwin 2.0 平均成功率 90.58→91.34，LIBERO 98.2→98.6，后者接近饱和。OOD 更明显：LIBERO-Plus 七类扰动平均 62.21→71.01，camera 扰动 27.89→45.15；RoboTwin Clean2Rand 的随机域 34.6→41.8。100 episodes 的未来视频 PSNR 19.22→21.44、SSIM 0.75→0.83。删除任一对齐损失，LIBERO 平均均从 98.6 降至 98.0；第 20 层最佳。四项真机任务各 50 次，平均 progress 20.3→31.8%，但成功率仅 1.0→5.5%。训练约 51→52 小时（8×H100）、显存 77.3→82.7%。

## Value
这是把 4D 几何教师蒸馏进生成式动作模型的轻量通用方案，尤其说明 OOD 鲁棒性比饱和 ID benchmark 更能体现结构先验。对本方向的启发是：异构表征应对齐变化量和对应关系，而非生硬对齐坐标；但真实长程任务仍远未解决。

## Strengths
- insight 清楚：先诊断绝对特征冲突，再设计 motion/destination 两种互补目标。
- 适配两个 WAM backbone，推理零 teacher 开销，额外参数与训练成本较小。
- 同时评价 ID、两种 OOD、视频质量、消融与真机任务。
- OOD 改善幅度显著，尤其相机、噪声和背景变化。

## Weaknesses
- trajectory teacher 本身可能在遮挡、反光和非刚体上有误差，论文未传播其不确定性。
- destination 将末帧视为完成信号，失败/中断 demonstrations 或多解任务中不一定成立。
- ID 增益很小，真机绝对成功率仅 5.5%，离可用长程控制很远。
- PSNR/SSIM 只测 100 episodes，缺少 3D trajectory、接触和物理一致性指标。
- 与使用显式 4D 输入/预测的同类方法缺少等算力、等 backbone 的充分比较。

## Future Work
可加入 teacher uncertainty 和可见性门控，处理失败/多目标轨迹，直接评价 3D/接触误差，并在更大真机数据和更长闭环 rollout 上验证。

## Rating
创新度评分：4/5 - 以时间差分和首末关系化解跨空间对齐冲突，方法简洁、跨 backbone 且 OOD 效果强。
相关度评分：3/3 (Core) - 直接研究 4D 先验、视频预测与机器人动作联合的世界动作模型。

## TL;DR
4D-WAM 以运动差分和首末对应蒸馏轨迹场，OOD 提升显著但真机成功率仍低，值得精读。
