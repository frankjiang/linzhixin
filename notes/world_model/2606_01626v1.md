# IMWM: Intuition Models Complement World Models for Latent Planning

创新度：4/5 | 相关度：2/3

## Insight
核心insight非常深刻：**即使世界模型是完美的（用真实环境动力学替换learned predictor），有限预算的sample-based planner仍然会失败。** 论文通过oracle dynamics实验验证了这一点——将CEM planner中的learned world model替换为真实环境rollout，在Two-Room和OGBench-Cube上仍然落后于IMWM（分别差13.7pp和17.9pp）。失败原因不是预测不准，而是搜索（search）本身的瓶颈：在vast action space中，有限CEM采样无法覆盖goal-reaching的candidate。具体来看，98.9%的Two-Room失败episode和91.4%的OGBench-Cube失败episode中，两次replan的CEM population都包含零个goal-reaching candidate。

论文进一步从理论上证明（Theorem A.1）：finite black-box search的成功概率受proposal-volume bound约束，且该bound与predictor质量无关，即这是一个predictor-independent的搜索瓶颈。

这个诊断非常有价值：它指出了latent world model planning的一个fundamental limitation，不是模型不准，而是搜索空间太大。

## Motivation
- **问题**：Latent world model planning（如Dreamer/PlaNet/TD-MPC系列）用learned forward model做rollout + CEM搜索最优action，但在某些任务上仍然失败。是模型不够好还是搜索不够好？
- **同行做法**：主流方向是改进世界模型（更准的dynamics、更好的表征），或改进搜索算法（iCEM的colored-noise correlation、TD-MPC的terminal value）。很少有人质疑搜索本身是否是根本瓶颈。
- **是否关键**：是。论文的oracle实验令人信服地证明了搜索是certain tasks的binding constraint，这为世界模型+规划的研究开辟了新的改进方向。

## Method
IMWM在standard latent WM planning基础上增加一个frozen **intuition model**，通过三个轻量组件协作：

**Intuition Model：**
- Inverse-side encoder phi^I：编码(start, goal) observation为query，编码action chunk为key
- Bilinear scorer D = q * k / tau：评估action chunk与start-goal transition的兼容性（InfoNCE-style对比学习训练）
- 关键设计选择：(i) inverse-conditional（评分action而非预测next state）；(ii) 在demonstration windows上训练；(iii) 返回scalar score而非latent prediction；(iv) 独立latent space，与world model解耦

**三个协作组件：**

1. **Retrieval Initialization**：从demonstration bank（|R|=3000 per task）检索最近邻demo action chunk，以此为均值初始化CEM proposal（而非random初始化），将搜索聚焦到promising区域。

2. **Hybrid Cost**：融合两个z-scored信号：
   - alpha * (-intuition_score)：intuition model的兼容性评分（越高越好→取负）
   - beta * world_model_rollout_MSE：标准的terminal latent-MSE cost
   - J(a) = alpha * z_S(-D) + beta * z_S(MSE)

3. **Reliability Gate**：per-cell自动决策，在搜索开始前通过两个诊断指标选择三种recipe之一：
   - r_inv：检索chunk的intuition score相对neutral chunks的margin
   - r_lag：检索chunk的lag-1 autocorrelation（平滑性诊断）
   - Trusted hybrid (1,3,on) / Intuition-dominant (1,0.1,on) / Forward-only fallback (0,1,off)
   - 阈值固定为(T_inv=0.05, T_lag=0.3)，无per-task tuning

**创新程度**：高。诊断方法论（oracle dynamics实验 + 理论bound）是开创性的。intuition model的设计（作为complement而非replacement）和reliability gate的自适应机制都很巧妙。

## Experiment
**任务：** 4个pixel-based goal-reaching任务（Two-Room、Reacher、Push-T、OGBench-Cube），基于LeWM stack，每任务12 cells × 50 episodes。

**主要结果（IMWM vs World-model-only）：**
- Two-Room: 99.2% vs 87.7% (+11.5pp, 12/0/0 W/T/L)
- OGBench-Cube: 94.7% vs 66.2% (+28.5pp, 12/0/0)
- Push-T: 92.7% vs 89.8% (+2.8pp, 8/1/3)
- Reacher: 83.8% vs 83.2% (+0.7pp, 7/1/4, near-tie → gate routes to fallback)

**Oracle dynamics实验：** 即使用真实环境dynamics，Two-Room仅从87.7→85.5（反而下降！），OGBench-Cube仅从66.2→76.8，都远低于IMWM，有力证明瓶颈在搜索。

**消融：**
- Retrieval Init单独在search-limited tasks上就很有效（OGBench-Cube: 66.2→88.3）
- Intuition-only cost不足以替代world model（全面低于full IMWM）
- Reliability Gate自适应选择recipe，匹配或超越任何固定recipe

## Value
这是一篇高质量的隐式世界模型规划工作，核心贡献是：(1) 诊断出latent planning中搜索瓶颈比模型精度更关键的fundamental insight；(2) 提出intuition model作为world model的互补而非替代，通过retrieval-based proposal初始化和hybrid cost缓解搜索瓶颈。

对我们的研究有重要启发：
- 在视频/3D世界模型做planning时，搜索效率可能是比模型精度更大的瓶颈
- Demonstration-guided search initialization是一个通用的改进思路
- Inverse-conditional scoring（"这个action是否与start-goal transition兼容"）是一个与forward prediction正交的有价值信号
- Reliability gate的自适应信任机制可以推广到其他hybrid planning场景

待解决：(1) 仅在4个pixel-based简单任务上验证，未涉及更复杂的连续控制或真实机器人；(2) intuition model需要成功demonstration，冷启动问题未解决；(3) reliability gate的手工阈值和固定recipe有局限性。
