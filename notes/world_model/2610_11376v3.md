# CRISP: Fixing Flying Pixels in Latent LiDAR Generation via Diffusion Decoding

## Insight
潜变量可能已经保留了锐利几何，但卷积 VAE 解码器在深度边界插值，回投后产生“飞点”；只更换解码器而冻结编码器/生成器即可显著改善边缘几何。作者以冻结主干替换、边缘/平滑区分解和 LiDM 世界模型内即插即用测试支持这一定位。

## Motivation
激光雷达世界模型常先压缩范围图再生成；平滑的深度边缘会污染 3D 点云，影响场景生成和下游感知。既有工作多改潜变量或生成器，解码端瓶颈缺少系统验证。

## Method
CRISP 用通用潜变量适配器把 LiDM/SVD/Wan 编码结果变成 token，以早期和中期融合条件化像素空间 DiT 扩散解码器，重建稠密对数深度；独立 U-Net 根据潜变量及深度预测有效回波 mask，再合成稀疏范围图。训练用边缘加权速度损失、导数/梯度正则和有效像素直接深度损失，mask 用 focal、Dice、边缘等项。创新是将扩散解码与稀疏回波建模组合到 LiDAR 潜变量管线。

## Experiment
KITTI-360、SemanticKITTI、nuScenes；指标含 FRID/FSVD/FPVD、JSD/EMD/MMD、点云 Chamfer Distance 与 F-score@0.5m。冻结 SVD ×3 的 FSVD 156.5→40.2、Wan ×3 为 100.9→32.5；LiDM FRID 2.24→0.64，五设置平均边缘 F-score 提升约 107%。在冻结 LiDM 世界模型中仅换解码器，FSVD 37.70→31.87、边缘 CD 96.41→79.55，但边缘 F-score 0.0486→0.0389，说明收益并不全面。消融显示早期融合和显式 mask 有效。

## Value
对 3D/激光雷达世界模型提示需独立审计编码器、动力学和解码器，特别关注深度断层与回波支持；评价应同时看分布、成对几何和边缘指标。

## Strengths
跨通用视频 VAE 与 LiDAR 专用主干验证；冻结生成潜变量的替换实验定位问题；清楚报告指标回退及计算成本。

## Weaknesses
CRISP 约 516M 参数，对 LiDM 解码器大 60 倍、推理慢 16.6 倍；仅逐帧解码，可能闪烁；世界模型替换时边缘 F-score 倒退，SVD 适配版感知指标也退化。仅范围图单深度通道，不含反射率。

## Future Work
作者提出多通道反射率预测、支持 mask 的点密度校准、时间条件以去闪烁，以及蒸馏降低扩散解码延迟。

## Rating
创新度评分：3/5 - 将扩散解码和有效回波分支用于潜变量 LiDAR 的明确瓶颈，效果扎实，但代价较高。
相关度评分：2/3 (Related) - 是 3D 世界模型的 LiDAR 解码组件，而非通用视频/3D 动力学建模。

## TL;DR
扩散解码可修复潜变量 LiDAR 的边缘飞点，冻结世界模型也有效；做 3D 生成可选读。
