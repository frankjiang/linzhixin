# Temporal-Distance JEPA: Plan-Aware Representation Learning for Latent World Model Predictive Control

## Insight
核心 insight 是：JEPA/LeWM 的训练目标是短程 latent prediction，但 MPC 需要按目标进展排序多步 imagined futures；若规划代价只用 latent 欧氏距离，就是把一个训练副产品当成目标进展。作者推论：可以从无奖励演示轨迹中挖掘有向时间距离，作为规划代价或表示塑形信号，从而缩小 train-plan gap。

## Motivation
LeWM 等 JEPA 世界模型避免像素重建，适合 latent MPC，但缺少显式 reward/value 时，规划只能用 embedding distance。同行有 value-guided JEPA、RC-aux、temporal straightening、progression subspace 等方法，但要么引入价值估计，要么把时间结构当辅助。本文解决的是 JEPA 潜空间“预测可行但排序未必可规划”的问题，和隐式世界模型方向高度相关。

## Method
Temporal-Distance-JEPA 保留 LeWM encoder-predictor 和 SIGReg，新增 directed temporal cost head `d_psi(z_s,z_g)`。同轨迹中 `i<j` 的步数差 `tau=j-i` 作为正样本监督，跨轨迹 goal 作为 hinge negative，避免 off-trajectory pair 代价虚低。cost head 使用 metric-residual/quasimetric 风格参数化，允许 `d(A,B) != d(B,A)`。同时加入 horizon-aligned rollout consistency，使训练中的多步 rollout 与 CEM/iCEM 规划 horizon 对齐。规划时，拓扑型任务直接最小化 `d_psi`，接触型任务仍可用 latent L2，让时间监督只塑形表示。

## Experiment
实验覆盖 Two-Room、Reacher、Push-T、OGBench-Cube，使用锁定 episode manifest 和 planner budget。与 LeWM/RC-aux 对比，TD-JEPA 在 Two-Room/Reacher/Push-T/OGB-Cube 分别为 100.0/97.0/86.0/82.2，LeWM 为 97.4/96.0/83.6/68.0，RC-aux 为 98.6/96.8/81.4/81.6。OGB-Cube 相比 LeWM 提升 14.2 个点。消融显示，对称 Euclidean TD head、去掉 cross-trajectory hinge、去掉 rollout consistency 都会显著降低 Push-T 表现。计划代价分析显示：导航/到达任务适合直接用 `d_psi`，Push-T 这类接触控制即使 `d_psi` 时间排序更好，仍需要 L2 几何代价。

## Value
这篇对 JEPA 世界模型规划很有价值，因为它明确区分“预测 latent”和“用 latent 排序计划”的目标差异。对我们启发是：训练目标要服务于 plan-time cost，且不同任务可能需要不同代价形态；时间进展信号不应被简单等同于接触几何精度。

## Strengths
亮点是问题诊断明确，方法改动小且直接对齐 MPC 使用方式；实验采用 locked protocol，和 LeWM/RC-aux 对比相对干净；作者没有过度宣称 temporal cost 全能，而是指出接触任务仍偏好几何代价。

## Weaknesses
不足是 benchmark 规模较小，主要是短 horizon 离线控制环境；时间距离来自同轨迹步数，只是 on-manifold surrogate，不保证最短路径或可拼接性；任务选择中何时用 `d_psi`、何时用 L2 仍需要人工判断。

## Future Work
作者没有详细展开未来工作。自然方向是学习自动选择/融合 temporal cost 与 geometry cost，扩展到更长程、更复杂视觉机器人任务，并研究 demonstration step count 与真实 reachability 的偏差。

## Rating
创新度评分：3/5 - 对 JEPA train-plan gap 的处理清楚有效，但主要是在 LeWM 上增加时间距离监督和代价头。
相关度评分：3/3 (Core) - 直接研究 JEPA/LeWM 隐式世界模型的 latent MPC。

## TL;DR
从离线轨迹挖掘时间距离代价改进JEPA潜空间规划，值得精读。
