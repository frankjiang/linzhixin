# Sol$^{3}$: Accelerating Video Diffusion for Free via Hierarchical Sparse Attention Routing

## Insight
观察：视频扩散注意力在块间和块内都高度集中，低响应块仍可能含少数关键 token；仅看块中心相关性也不能判断用均值代表该块的误差。推论：先按块选择必须精算的区域，再在难以近似的块内按全局可比的 token 分数细选，可在相同计算预算下降低近似误差。论文给出最优细粒度可行域包含块级方案的命题与构造例，推导均值近似误差依赖 Key/Value 内部变化；实测完整难度分数与误差的秩相关为 0.826，块中心分数仅 0.040。理论说明潜力，实际路由收益仍由实验验证。

## Motivation
视频扩散模型推理中注意力成本高。Sol-Attn 等训练免调方法按整块决定精算或代表近似，容易对块内少数强交互过算或漏算；单一块中心得分又忽略近似难度。对长视频/交互世界模型的高分辨率生成效率，这是重要的系统问题。

## Method
在 Sol-Attn 的精确项与代表项联合 softmax 框架上，按每个查询组的分数均值加 `β·标准差` 设三级阈值：①块中心 Q·K 相关性选择整块精算；②对剩余块用 `中心相关性 + log(块大小×Value 离散度) + Key 沿查询方向方差修正` 识别难近似块；③把这些块的原始 Key token 合成一个候选集，以统一的 Q·K 分数选精算 token。其余成员以块代表项、按剩余数量加权参与同一归一化。Triton 实现把跨块精算 token 压入 CSR 索引，复用路由分数并融合相邻算子。核心创新是决策粒度和评分目标对应的三级路由，非新的世界状态表示。

## Experiment
在 Wan2.2、HunyuanVideo、H3/FastH3、LTX-2.5 和相机控制 SANA-WM 上，与密集 FlashAttention、SVG2、SVG-EAR、PISA、Sol-Attn 比较。Wan2.2 720p/81 帧中，Sol³ 跳过 86.37% 精确视频交互，注意力加速 3.07 倍、整段去噪加速 1.88 倍，PSNR/SSIM/LPIPS 相对密集输出为 25.81/0.854/0.086；Sol-Attn 为 2.45 倍、1.46 倍和 25.55/0.848/0.095。SANA-WM 481 帧中注意力/去噪加速 2.33/1.36 倍，CMC 0.900（密集 0.893、Sol-Attn 0.950）。三级路由、评分统计、Gaussian 阈值分别有消融；附录延长至 961 帧 SANA-WM 并测试不同分辨率。指标还包括 VBench、音视频质量和相机姿态误差。

## Value
若团队正优化扩散式视频世界模型推理，**值得精读**其块内稀疏路由和精确/代表项联合归一化；尤其可借鉴“总体相关性”和“近似困难度”使用不同统计量。对模型是否理解物理、3D 或动作因果的直接启示较少。

## Strengths
覆盖多种视频、音视频和相机控制模型；报告注意力与端到端去噪两种加速，避免把 kernel 加速等同总体收益；同模型基线共享预热和保护层设置；消融与理论分析能解释路由选择。

## Weaknesses
属于推理内核改进，不能提高世界模型本身的学习能力。86% 稀疏率只计启用稀疏路由的调用，非全部去噪步骤；Wan2.2 的 3.07 倍注意力加速转成 1.88 倍去噪加速。部分质量指标与密集计算仍有差距，SANA-WM 的相机指标只接近密集基线；主要评测每模型约 50 个提示或 100 个相机轨迹，未覆盖闭环交互与物理长期一致性。理论可行域与 Top-K 命题不能保证所提阈值路由最优；Gaussian 形状是经验近似。

## Future Work
作者未明确列出具体后续计划，仅表示希望作为实用视频扩散注意力机制。根据局限，值得继续评测更长闭环世界模拟、跨硬件和质量敏感场景，并提高路由开销之外的整体去噪效率。

## Rating
创新度评分：3/5 - 对现有 Sol-Attn 的块级选择作有机制依据的多级改进，效果稳定，但属既有稀疏注意力路线的推进。
相关度评分：2/3 (Related) - 直接加速扩散视频及相机控制世界模型的生成推理，不研究世界表示或动力学本身。

## TL;DR
用块到 token 的三级路由分配视频扩散注意力精算预算，在多模型上加速推理并保持接近密集质量；做生成效率值得精读。
