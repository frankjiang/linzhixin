# HelloWorld: Enabling Socially Interactive Characters in Video World Models

## Insight
有。Observation 是预训练视频生成器本就保有“人物朝镜头做社交动作”的先验，但常见相机控制微调数据只教模型补全 warp video，会削弱这一能力；同时，文本写明交互时段也不能可靠控制动作发生时间。由此推论：可用模型自身生成的“相机运动+社交动作”视频蒸馏相机控制，在推理时再把交互文本 token 的 cross-attention 限定到按键窗口，从空间/内容学习与时间控制两个层面解耦。实验中自生成数据主要改善 ActAcc/GazeDev，而时序 mask 把 TimeAcc 从 36.7 提到 81.7，支持这种功能分解；但论文并未给出理论证明。

## Motivation
现有交互视频世界模型主要控制相机、键盘移动、技能或物体事件，角色通常静止、做环境动作，或只支持特定游戏内 NPC，缺少角色面向用户的通用社交回应。问题对可玩视频世界很关键：世界是否“活着”不仅取决于几何探索，也取决于其中角色能否感知并回应用户。同行已有 talking-video、多人社交生成和文本社会模拟，但都没有同时提供第一帧场景保持、相机轨迹控制和 viewer-directed interaction。

## Method
输入为首帧、场景/交互/质量文本、逐帧 SE(3) 相机轨迹和交互窗口。训练时先用冻结的 LTX-2.3 按四段式 prompt 自生成含社交动作和相机运动的视频，再用 Pi3X 恢复首帧点云及相机轨迹；把首帧点云沿该轨迹重投影成有空洞的 warp video，丢弃不可见 token，将有效 warp token、首帧 token 和噪声 token 一并送入 Video DiT。仅以 rank-32 LoRA 在 flow-matching loss 下重建原视频，并删除 camera prompt，迫使相机控制只来自几何条件。

推理时键盘转为相机轨迹并生成 warp video。按下 F 后，把交互文本 token 对窗口外视频/音频 query 的 cross-attention logit 置为负无穷，使动作和发声仅在窗口内生效。创新主要是把自蒸馏数据、Warp-as-History 和训练免费的时序 attention mask 组合成社交交互接口；各技术本身并非全新。

## Experiment
作者构建 HelloWorldBench：120 张 Unsplash 首帧、264 个角色、101 类交互、4 种相机轨迹和早/中/晚时段，共 400 个样本，每个样本 3 个随机种子。指标包括 Qwen3.6-35B-A3B 判断的 ActAcc/TimeAcc、UniGaze 得到的 217 个人类样本 GazeDev，以及 BgCons、Aesthetic、CamCtrl；另对 41 个样本、30 名受试者做成对偏好实验。

相比 5 个视频世界模型和无轨迹 LTX-2.3，HelloWorld 的 TimeAcc 为 81.7（其他 30.9–52.6），CamCtrl 82.9、BgCons 96.9、Aesthetic 5.27 均最佳或并列最佳；GazeDev 40.2 优于所有相机可控基线，但略差于 LTX-2.3 的 38.1；ActAcc 41.4 也低于 LingBot-World 的 50.5 和 LTX-2.3 的 42.5。真人比较中，对四个选定对手的动作自然度、互动感和场景质量偏好均超过 66%。训练数据消融显示 Real-video→Full 后 ActAcc 36.4→41.4、GazeDev 51.3→40.2；视频+音频 mask 把 TimeAcc 36.7→81.7、SpeechInWin 52.5→69.1。10 秒、1280×704、241 帧视频耗时 60.2 秒，比基座慢约 20%，FLOPs 增加 36%。

## Value
它把“角色是否回应用户”从泛化视频质量中拆成 what/when/toward-whom 三个可测维度，为视频世界模型补上社交交互接口。对我们最有启发的是：保留生成基座先验时，可用自生成数据建立新控制通道；对短暂事件，attention routing 比依赖文本时间描述更直接。不过当前系统更像离线可控视频生成器而非实时、闭环世界模型，尚不能根据用户连续行为或角色内部状态进行多轮互动。

## Strengths
任务定位清楚，首次系统化评估 viewer-directed interaction；156 条自生成视频、2,000 步 LoRA 即获得较强相机与时间控制，数据和训练成本低；训练数据、时序 mask、音频 mask、计算开销和真人偏好均有消融或报告；对人、动物、玩具和风格化角色均展示结果。

## Weaknesses
论文声称在三项社交指标上全面领先并不被表 1 支持：ActAcc 和 GazeDev 各有基线更好。TimeAcc 会排除被判为“无交互”的视频，可能高估只在成功触发样本上的定时能力。核心指标依赖单一 VLM judge 和 gaze estimator，未报告 judge 与人工标注的一致性；真人实验只覆盖 41/400 样本且没有比较所有基线。训练/测试均依赖同一基座的视觉先验，自蒸馏可能放大偏差。按键只选择预先脚本的时间窗口，10 秒视频仍需 60.2 秒，缺少实时反馈、长时身份一致性、对话状态和因果闭环。

## Future Work
作者明确提出采用 autoregressive architecture 实现实时交互，扩展长视频，并保持角色身份以支持持续、多轮互动。还应加入闭环用户状态、交互失败率计入的时间指标、多 judge/人工校准，以及跨基座和跨域测试。

## Rating
创新度评分：3/5 - 社交视频世界模型和对应 benchmark 有新意，但方法主要是自蒸馏、已有 warp conditioning 与 attention mask 的有效组合。
相关度评分：3/3 (Core) - 直接研究可交互视频世界模型，并涉及相机几何控制、角色行为和长时交互接口。

## TL;DR
用自蒸馏与时序注意力掩码让视频世界角色按键回应，指标仍有争议，可选读。
