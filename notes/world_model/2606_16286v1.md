# FlowMPC: Improving Flow Matching policies with World Models

## Insight
Flow Matching policy 是强 action prior，但不直接最大化 return；用 learned world model + MPPI 在推理时重排/细化候选轨迹，可不改 FM 训练目标而提升闭环成功率。

## Motivation
生成式 imitation policy 在多模态动作空间好用，但遇到分布外状态和误差累积会失败。RL fine-tuning FM 是一条路，本文问能否只在 inference-time 通过 world model planning 提升。

## Method
训练 FM policy 生成候选动作轨迹；训练状态或 latent-space world model 预测候选轨迹效果；MPPI 从 512 条候选中采样，其中 24 条由 FM 直接提出，其余随机扰动，按 world model 代价更新。PickCube 用 state-space WM、H=1；PickSingleYCB 用 latent-space WM、H=3。

## Experiment
ManiSkill PickCube 与 PickSingleYCB，50-step episodes，指标为 anytime success 和 end-of-episode success。加入 world model 后两任务 end success 均提升，PickCube anytime success 更明显。实验规模只有两个任务。
