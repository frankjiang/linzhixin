# KineBench: Benchmarking Embodied World Models via IDM-Free Kinematic Grounding

## Insight
核心 insight 是闭环评测 embodied video world model 时，IDM-based action extraction 会把世界模型错误和 action extractor 错误混在一起。作者改用显式 3D kinematic grounding：从生成视频逐帧恢复 6D end-effector pose，再放进物理仿真器执行，这样评测更接近 physical actionability，也更容易定位误差来源。

## Motivation
视频生成指标和 VLM judge 只能评价视觉/语义 plausibility，无法验证机器人生成视频是否物理可执行。已有 closed-loop benchmark 依赖 learned IDM 从 RGB 中反推出动作，但 IDM 对生成视频中的 novel trajectories、遮挡、gripper 形变和 OOD 任务很脆弱，失败后无法归因。KineBench 解决的是 embodied world model 评估中的关键问题：如何减少 action extraction confound，并加入机器人视角的 3D 运动学诊断。

## Method
KineBench 给定世界模型生成的视频，先用 fine-tuned YOLOv11 得到 end-effector mask，再用 MoGeV2 估计 metric depth，用 FoundationPose 和 gripper CAD 进行 6D pose tracking，得到 end-effector 轨迹。轨迹随后在 ManiSkill3 中执行，用闭环 task success 检查物理可行性。除成功率外，作者引入 SPARC 评价轨迹 smoothness，引入 Maruyama Manipulability Index 评价是否接近奇异位形/运动学不可达。Benchmark 包括 20 个 ManiSkill3 manipulation tasks，组织成 Suite 0 basic execution、Suite 1 task transfer、Suite 2 visual OOD、Suite 3 complexity scaling。

## Experiment
动作提取鲁棒性上，KineBench 与 Dino3DFlowIDM 在未见任务和受控视觉扰动下比较，KineBench 的 position error 明显更低；rotation mean 在个别条件下略高，但长尾失败更少。深度消融显示 ground-truth depth 可到厘米级，MoGeV2 depth 约 1.5-3cm 平移误差，剩余约 10 度旋转误差是精密操作瓶颈。主评测覆盖 Wan2.2-5B、CogVideoX-2B、Wan2.1-1.3B、LoRA variants 以及 API 模型：Suite 0 中 Wan2.2-5B 成功率 56.32%，CogVideoX-2B 为 46.17%；Suite 1 中 CogVideoX-2B 57.78% 明显好于 Wan2.2-5B 11.90%；Suite 2 seen/unseen 下 Wan2.2-5B 为 58.00/55.50%，说明简单视觉 OOD 有一定鲁棒性但精细 affordance 会掉分；Suite 3 中 Wan2.1-1.3B 从 1.5k/4.5k 到 15k steps 可升到 73.33%，但增加同质轨迹数量并不单调收益。SPARC 与 success 的关联依赖任务/模型，Manipulability 能暴露 embodiment awareness 缺陷。

## Value
这是视频/机器人世界模型评估方向的核心相关工作。它把评价从像素相似度推进到“生成动作能否被机器人执行”，并用 classical robotics metrics 解释失败类型。对我们做视频世界模型或 3D action-conditioned generation 的启发是：closed-loop benchmark 必须分离视觉生成、pose grounding、物理执行和运动学约束，否则视觉好看不等于可用。

## Strengths
问题抓得准，IDM-free 设计直接针对现有 closed-loop 评测的归因混淆；pipeline 模块化，能检查 segmentation/depth/pose 各环节；四个 suite 覆盖 IID、任务迁移、视觉 OOD 和 scaling；SPARC/Manipulability 给出了比 FVD/PSNR 更机器人中心的诊断信号。

## Weaknesses
KineBench 仍依赖 learned segmentation/depth/pose modules，并非无误差 ground truth；FoundationPose/CAD 假设适合 gripper，但更复杂 hands、遮挡和非刚性接触会变难。实验主要在 ManiSkill3 仿真和有限模型集上，真实机器人闭环缺失。SPARC/Manipulability 与成功率不是稳定单调关系，更多是诊断指标而非统一评分。

## Future Work
作者提出未来引入 human teleoperation data 丰富动作分布，并将 3D kinematic metrics 与现有 2D pixel-based evaluation 结合，形成更完整的 embodied world model 诊断。

## Rating
创新度评分：3/5 - 评测框架设计有新意，尤其是 IDM-free 3D grounding，但底层依赖现有视觉/pose/simulator 工具组合。
相关度评分：3/3 (Core) - 直接评测 embodied/video world models 的物理可执行性和 3D 运动学一致性。

## TL;DR
KineBench用显式3D运动学闭环评测视频世界模型，核心相关，值得精读。
