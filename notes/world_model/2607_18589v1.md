# Planning as Emergent Behavior in Reinforcement Learning with Relational Hidden States

## Insight
核心 insight 是 model-free RL 中的 planning emergence 依赖“状态绑定的关系隐状态”这一架构先验。观察是 DRC/ResNet 等模型会随 test-time thinking 提升表现；作者推论关键不只是 recurrence 或 attention，而是每个环境状态能绑定到一个 hidden cell，cell 间关系学习到 transition graph 后，message passing 就可实现 latent planning。

## Motivation
传统区分中，model-based agent 学 world model 并规划，model-free agent 学 reactive policy。但已有 Sokoban work 发现 model-free recurrent agent 有 planning 行为，未解释什么条件下会涌现。本文要找出架构条件：为什么某些无显式模型的网络会学到类似规划的内部机制。

## Method
作者形式化 relational hidden states：hidden cells 通过 convolution 或 attention 消息传递。提出 state-graph binding：存在从环境状态到 hidden cell 的映射，且 cell 关系尊重环境转移图。若 action statistic localized 到当前状态 cell，则 routing weights 可视为隐式 transition model，K 步 message passing 可实现 horizon-K decision-time planning。实验用 Boxoban/Sokoban，比较已有 ConvLSTM DRC、dense unmasked attention recurrence AttnLSTM，以及取消固定 cell-to-square binding 的 SlotLSTM 控制。

## Experiment
AttnLSTM 仅从 reward 训练 300M steps。额外 thinking ticks 提升 solve rate，峰值约 0.39；DRC 通过 no-op pondering 从 0.754 到 0.805。AttnLSTM 的 agent-square cell 可 60% 解码下一动作，高于 25% chance；attention routing 对一跳 successor 质量约 0.24，随 graph distance 几何衰减 ρ≈0.61；route-blocking wall 让 agent cell shift 是 off-route 的 2.3 倍，并使 greedy move flip 19% vs 7.2%。计划方向在 cell field 上可 61% 指向 goal。SlotLSTM 没有稳定 binding：top square read mass 0.13、routing 近似 broadcast ρ≈0.94、solve rate 0.067 到 0.063，extra thinking 无收益。

## Value
对隐式世界模型和 JEPA/Dreamer 方向的启发在机制层面：世界模型/规划可能隐藏在关系表示与稳定状态绑定中，不一定显式训练预测损失。但它不是视频/3D 世界模型论文，任务也集中在 Sokoban，应用距离较远。

## Strengths
理论链条清楚；mechanistic probes 和 causal interventions 结合；free-slot control 很关键，证明 binding 不是无关细节；多 seed 稳定性有报告。

## Weaknesses
环境单一且离真实视觉/机器人远；AttnLSTM 训练量不小但绝对性能不高；规划指标部分用 goalward proxy，不能完整代表 Sokoban 解法；人脑类比只是猜想。

## Future Work
作者提出要研究更大模型中是否存在稳定 binding、不同 learned-binding 机制、更长训练或更大规模能否让 slot 结构形成 state graph，以及 transformer/LLM 中 planning emergence 的适用范围。

## Rating
创新度评分：3/5 - 对 emergent planning 的条件给出有力机制解释，但实验域较窄。
相关度评分：2/3 (Related) - 与隐式 world representation 和 latent planning 相关，但不是用户核心的视频/3D世界模型。

## TL;DR
该文证明状态绑定的关系隐状态可从奖励中涌现规划，启发隐式模型但可选读。
