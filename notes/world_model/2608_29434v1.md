# Does Latent Planning Survive Point Clouds? Action-Conditioned JEPA World Models for Geometric Observations

## Insight

有两个关键 insight。其一，点云中只有 0.3%–15% returns 属于运动实体，JEPA 仍未落入 slow-feature/geometric shortcut：anti-collapse objective 会让位置在 192 维 latent 中近乎线性可解，CLS attention 也集中到少量运动点，因而 latent-space CEM 仍能控制（Tables 2、4–7, pp. 7、15–17）。其二，3D target 只规定任务相关物体位姿，不能唯一决定整场景 latent；无条件 MSE 学到的条件均值可能落在非凸可达 latent manifold 外。作者在 Appendix B 给出这一条件均值论证，并以当前 latent 补足未指定场景状态，实验显示 OGB-Cube 上可追回最多约 12 pp 成功率（Table 3, p. 8）。

## Motivation

现有 action-conditioned JEPA world model 几乎都以图像为观测；点云稀疏、无序、自遮挡，坐标又给 3D self-supervision 提供几何捷径，能否保持动作敏感 latent 并用于规划并不明确。现有 3D world model 多生成 scan/occupancy 或显式未来几何，推理时要解码点云；action-free 3D JEPA 也没有用 candidate actions 做规划。另一个实际痛点是 latent planner 通常需要从未见过的 goal observation，而机器人更自然得到的是目标 3D pose。

## Method

- 将 stable-worldmodel 的四个数据集用同状态 replay 和模拟 range sensor 重新感知：100×100 rays、sensor-frame xyz、每帧固定 10,000×3；除 OGB-Cube 复用原相机外，其余用按 bounding sphere 推导的 45° oblique view。episodes、actions、goals 与图像版完全相同，移动点比例仅 0.3%–15%（Table 1, p. 4）。
- Point-LeWM 与 Point-Delta-JEPA 共用 Point-BERT 风格 encoder：FPS 取 256 groups（Cube 为 512），metric ball query 每组至多 32 点，经 mini-PointNet 和 ViT-Tiny 得 192 维 CLS latent；固定 workspace affine 保留绝对坐标，LayerNorm 避免 3D BatchNorm scaling 问题。前者用 SIGReg，后者用 N=5 的 latent-displacement action reconstruction 防 collapse（Figure 2, pp. 3、5–6、12）。
- Utonia-WM 冻结约 137M PTv3/Utonia encoder，把不具跨帧身份的 super-points 投入固定重力坐标 voxel grid（约 256 tokens），mean/max pool 后用固定随机正交投影降至 192 维，只训练 DINO-WM predictor。Vox-WM 用每 cell 的 25 个手工统计量作对照（Figure 3, pp. 4–5）。
- 规划沿用图像 baseline：latent autoregressive rollout + CEM MPC，目标为预测终态与 goal latent 的平方距离；300 candidates、30 iterations、horizon 25，每 25 steps replan。
- Target-to-latent 模块以未来目标坐标的 Fourier features 和当前 latent 预测 frozen encoder 的未来 latent；比较 residual MLP（条件均值）与 one-step shortcut flow model（条件分布样本），测试时直接接受 3D target，不需要 goal cloud（Figure 4, pp. 5–6、13–14）。

## Experiment

- 数据为 OGB-Cube/Two-Room/Push-T/Reacher3D，分别 10,000/10,000/18,685/10,000 episodes、约 2.01M/0.921M/2.337M/2.01M frames。每个 planning score 为 10 seeds×50 episodes，共用固定 start-goal pairs（pp. 4、6）。
- Table 2（p. 7）：Point-LeWM 成功率为 87.0±4.4、80.4±4.6、83.6±3.4、66.0±5.9（Two-Room/Reacher/Push-T/Cube），对应 image LeWM 为 85.6±5.7、82.0±5.6、86.4±5.2、69.8±9.3。配对 TOST 在 ±10 pp margin 下四环境均等价（p≤0.005）；Push-T 仍有显著 −2.8 pp 差距（95% CI [−5.2,−0.5], paired p=0.025，Table 8, p. 18）。
- Point-Delta-JEPA 在 Two-Room/Cube 为 100.0±0.0/83.4±3.8，显著高于 Point-LeWM 13.0/17.4 pp；但 Push-T 仅 70.8±7.7，低 12.8 pp。probe 对应显示 Push-T block angle 的 linear R² 为 0.657 vs. Point-LeWM 0.891；Cube joint velocity 的 MLP R² 则为 0.626 vs. 0.102（Tables 4、6, pp. 15–16）。
- Utonia-WM 四任务为 94.0/71.2/46.6/71.2，均高于 Vox-WM 的 81.4/54.4/35.2/63.4，但 predictor rollout 约 256 tokens，比端到端单-token 模型慢约 50×。
- 3D-target 规划与 goal cloud 基准在 seed variance 内相当。例如 conditioned Shortcut 在 Push-T/Cube/Two-Room 上对 Point-LeWM 为 84.8/68.8/88.6，对 Point-Delta-JEPA 为 73.6/83.2/100.0；对应 goal-cloud 为 84.8/65.4/87.2 与 71.2/84.2/100.0（Table 3, p. 8）。
- Test-time degradation（Table 7, p. 17）：50% dropout 下 Point-LeWM 保留 Two-Room/Reacher 的 98.9%/94.8%，但 0.25% range noise 令 Push-T 两模型只剩 clean 的 1.9%/3.7%；说明冗余采样抗 dropout，但薄小物体对量程噪声极脆弱。

## Value

这是 3D 与隐式世界模型的直接交叉：它证明无需生成点云也可在 point-cloud latent 中做 action-conditioned planning，并给出更自然的 metric 3D goal interface。对我们尤其有用的是严格的 modality control、anti-collapse objective 的任务依赖性、物理 probe 与 sensor degradation 诊断。下一步关键不是再堆模拟 benchmark，而是验证真实 LiDAR/深度相机噪声、动态遮挡和真实机器人闭环。

## Strengths

- 通过同状态 re-sensing、相同 start-goal pairs 和重评 image LeWM，尽量把观测模态从数据/规划器差异中隔离。
- 同时覆盖 frozen encoder、distribution prior、action-sensitive 三类 JEPA，并用 Vox-WM、linear/MLP probe、attention 和 perturbation 解释性能，而非只给成功率。
- 对“非显著≠等价”处理正确，使用 paired TOST 并公开置信区间。
- 3D target 模块兼顾理论歧义与闭环结果，且不改变 world model 或 planner，接口简洁。

## Weaknesses

- 仅四个模拟 tabletop scene 和理想 raycast sensor；训练从未含噪，尚无真实点云、扫掠畸变、标定漂移、遮挡变化或真实机器人结果（作者限制，p. 8）。
- Push-T 在仅 0.25% scene-extent range noise 下几乎完全失效，暴露当前 fixed ray budget/薄物体表征不具部署鲁棒性（Table 7, p. 17）；只测独立 dropout/高斯量程噪声也不足以覆盖真实传感器。
- 严格受控的 image comparison 只有 Point-LeWM；image Delta-JEPA 和 DINO-WM 来自不同协议（表中 †），不能支撑对应架构的 modality 结论（pp. 7–8）。
- Utonia-WM 与 Vox-WM 对照有 predictor width 192 vs. 25 的混杂，因而 +7.8 至 +16.8 pp 不能全部归因于 pretrained features；作者承认未跑 matched-width control（p. 12）。
- ±10 pp 的 equivalence margin 对高成功率控制任务偏宽，Reacher/Cube 又未通过更严格的 ±5 pp；“无实际模态差距”应按任务谨慎解释。
- Target-to-latent 需要训练期 privileged target annotations，只测数据分布中的模拟目标；它本身 modality-agnostic，尚未证明 3D 几何在该模块上优于图像 latent。

## Future Work

作者没有单列 future-work 清单，但结论明确指向“在相机失效处预测和行动的机器人”，limitations 直接要求更广场景与真实传感。我们的推断：应在真实机器人上加入训练期 sensor corruption/多帧扫描，补 matched image Delta-JEPA/DINO-WM 和 matched-width Vox 对照，收紧 equivalence margin，并测试未见 target、动态背景及遮挡下的 target-to-latent 泛化。

## Rating

创新度评分：3/5 - 首次把三类 action-conditioned JEPA 系统迁移到点云并闭环规划，3D-target latent 接口也有新意；但核心算法多为既有 JEPA/point encoder 的组合，验证仍限模拟。
相关度评分：3/3 (Core) - 同时直击 3D world model、JEPA 隐式动力学和 latent-space planning，是研究方向的核心论文。

## TL;DR

系统验证点云JEPA可在潜空间规划，并以3D目标替代目标观测；证据扎实，值得精读。
