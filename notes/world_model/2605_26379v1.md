# When Does LeJEPA Learn a World Model?

## Insight
核心Insight：LeJEPA（alignment + Gaussian正则化）在什么条件下能学到世界的"真实"结构？

Observation：(1) 对于高斯潜变量+加性噪声平稳转移的世界，alignment目标的谱分解显示任何非线性变换都严格减少正对之间的相关性（Hermite多项式分解，高阶项特征值为ρ^d < ρ）。(2) 白化约束使得线性映射是唯一全局最优。

推论（Thm 1正方向）：LeJEPA必然线性恢复潜变量（up to正交变换）。
推论（Thm 2逆方向）：在满足假设的世界类中，高斯是唯一保证线性可辨识性的潜变量分布。
推论（Thm 4）：线性可辨识性 → 学到的潜空间可直接用于最优规划。

证明：全部定理有Lean 4形式化证明，实验从2D到1024维验证。

## Motivation
JEPA方法（LeCun 2022提出）在经验上成功用于图像、视频、RL，但缺乏理论保证——学到的表示是否真的是世界的faithful map？本文首次给出JEPA的可辨识性理论。前人工作：非线性ICA需要额外结构（时序、干预等），JEPA的特殊性在于alignment+Gaussianity的组合使得分析可行。这是一个关键的理论空白。

## Method
- 世界假设：独立高斯潜变量z~N(0,I_n)，平稳加性噪声转移（Ornstein-Uhlenbeck过程）
- 学习器：LeJEPA = alignment loss（最小化正对距离）+ SIGReg（嵌入分布→高斯）
- 将alignment等价转化为最大化正对间相关，再利用转移算子的谱分解（Hermite多项式为特征函数）
- 关键引理：高斯变量的函数按Hermite多项式展开，度为d的分量特征值为ρ^d，故线性分量（d=1）相关性最大
- Thm 3（近似可辨识性）：alignment和whitening近似满足时，误差graceful degradation
- Thm 4：线性可辨识性 → 旋转不变的cost下，潜空间规划等价于真实世界规划

## Experiment
- 2D合成实验：4种非线性混合（螺旋旋转、正弦剪切、抛物剪切、RealNVP），LeJEPA恢复高斯结构（up to旋转）
- 高维Scale：SIGReg/VICReg在N=2到1024维均保持R²>0.999；InfoNCE在高维退化
- 潜变量分布消融：广义正态分布族扫描，α=2（高斯）时线性恢复最佳
- DMC Reacher RL轨迹：高斯OU采样R²=0.95(ρ=0.99)；RL策略轨迹违反高斯假设，线性恢复降低
- 近似bound验证：训练loss与实际恢复误差强相关
- 潜空间规划：高斯编码器的直线插值解码接近oracle，轨迹编码器则非最优

## Value
这是JEPA/隐式世界模型方向的**理论基石**工作。首次证明了JEPA何时、为何能学到世界结构——将经验成功转化为数学保证。直接启发：
1. 数据侧：探索性数据（近似各向同性随机游走）优于目标导向数据用于预训练
2. 目标侧：SIGReg/VICReg类moment-based估计器优于InfoNCE在高维
3. 规划侧：线性可辨识性是潜空间规划的充分条件

待解决：真实数据的潜变量是否真是高斯？维度不匹配(m≠n)怎么办？有限样本/优化动态的影响？

创新度：5⭐ — 开创性理论工作，首次为JEPA世界模型提供可辨识性保证，由LeCun本人参与，Lean 4证明。

相关度：3 (Core) — 直接研究JEPA世界模型的理论基础，核心相关。
