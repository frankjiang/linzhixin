# Ego-Dynamics-Augmented World Model for Autonomous Driving with Zero-Shot Cross-Chassis Adaptation

## Insight
论文的 insight 是：BEV 自车坐标系中的观测变化混合了外部世界变化和自车运动导致的视角 warp，世界模型不应从像素统计中反推自车动力学。Observation 是换底盘时，同样动作带来的 ego-motion 不同，latent world model 容易失配；推论是把 ego dynamics 作为显式结构先验注入 Dreamer/STORM，可降低预测熵和 imagination drift。

## Motivation
论文解决自动驾驶世界模型跨底盘 zero-shot 泛化问题。同行包括 DreamerV3、STORM、DreamerAD 等基于 latent world model 的闭环驾驶方法，多在固定车辆动力学下学习。该问题关键，因为真实车辆质量、轴距、转向和轮胎参数变化会改变 egocentric observation dynamics，若世界模型不能适配，会导致规划策略过度修正或碰撞。

## Method
DynaDreamer 在 Transformer world model 旁加入 physics-informed Neural-ODE ego-dynamics 模块。输入 ego state 窗口和动作，编码为 vehicle-dynamics context psi，并估计底盘参数 m、Iz、lf、lr、Cf、Cr、delta_max。ODE 采用 bicycle model、线性轮胎先验和零初始化神经残差，使用多步 rollout loss 和参数 log MSE 辅助训练。psi 通过 AdaLN/RoPE 调制世界模型 prior/posterior，并在 imagination 中随动作在线更新；KV cache 写入也带 psi 印记。理论部分把自车 warp 看成可由已知上下文解释的外生成分，证明条件化 ego dynamics 可降低 prior-posterior KL 并约束多步漂移。

## Experiment
在 CarDreamer/CARLA Town03 urban 和 Town04 highway 上评估，训练包含 17 个 sedan/SUV/van/truck 变体，zero-shot 测 Fusorosa bus 和 Microlino micro。观测是 128x128x3 BEV 语义层，指标包括 success、collision、out-of-lane、timeout、reward、世界模型 KL/PSNR/MAE、低维状态预测和参数估计。Town03 平均成功率 DynaDreamer 0.82，高于 STORM 约 0.64、DreamerV3 约 0.26、VD-STORM 约 0.41；Town04 也整体较强。zero-shot pooled WM 质量中，KL 10.62 低于 STORM 14.19、DreamerV3 36.80，PSNR 23.55 最高，MAE 0.0269 最低。低维状态预测和参数识别显示自车状态跟踪更稳，Microlino 上 lateral/heading error 显著小于 STORM。

## Value
这是与 Dreamer/自动驾驶世界模型高度相关的工作。启发是：在 egocentric 世界模型中，若某些观测变化由已知结构因素决定，应显式建成 structural prior，而不是让通用 Transformer 全部吸收。这个思路可迁移到无人机、腿足机器人和移动操作。

## Strengths
问题定义精准；物理先验和神经残差结合合理；同时给理论分析、世界模型指标和闭环驾驶指标；zero-shot 跨底盘设置比固定车辆更有挑战。

## Weaknesses
依赖 ego-state 和底盘参数监督，现实系统获取成本不低；只在 CARLA/BEV 语义观测验证，离 raw video 和真实道路仍有差距；部分 highway 消融接近或超过完整模型，说明收益并非所有场景稳定；多智能体动态仍未建模。

## Future Work
作者提出两个方向：把 ego-dynamics prior 扩展到多交通参与者，每个 agent 带自己的 dynamics context；以及做 sim-to-real 和在线 ego-dynamics adaptation，检验真实传感噪声与执行延迟下的底盘识别。
