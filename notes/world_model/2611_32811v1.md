# Interactive Neural Computers

## Insight
观察：桌面界面没有相机位姿可为离屏内容索引，同一像素区域会反复被不同文件覆盖；全屏重画还会模糊小字。推论：交互视频模型需要内容寻址的显式记忆，并用预测惊讶控制写入；潜在下一帧预测可在遮挡跨度上给记忆读写提供监督。去除 MEMORY-JEPA 后隐文件回忆接近随机水平（32.1%），固定屏幕/动作/LSTM 只替换记忆库会使 64.7% 的输出转向捐赠者图形，构成较强的因果测试。

## Motivation
已有电脑使用 AI 通常操作固定软件，已有 GUI 视频世界模型则难在闭环中保留离屏文件、执行精确符号操作和清晰生成文字。该问题从交互视频世界模型角度重要，因为通常的 PSNR/LPIPS 可被复制静态屏幕掩盖。

## Method
把屏幕与鼠标/键盘动作建模为下一屏生成。Memory：64 个内容寻址槽存语义和视觉 token，预测特征与实际特征的余弦差形成惊讶写门；MEMORY-JEPA 用 EMA 目标的下一帧表征、InfoNCE/对齐、查询键监督等训练跨遮挡读写。Compute：冻结视觉塔、LoRA 调整 Qwen-VL，训练时在输入与结果文本之间插入 16 个因果查询 token，以执行文本监督提取计算状态，测试时单次前向不解码文本。Interface：残差潜空间扩散只预测变化，U-Net 空间位置通过注意力读取 36 个记忆 token 与 16 个 VLM token。按 128 帧窗联合训练。贡献是可控记忆、计算桥及残差渲染在交互 GUI 世界中的集成；各单独技术有前例。

## Experiment
在三个公共 GUI 语料加自行采集的 Desktop 隐文件和 Maths 清屏算术任务上，分别以 512×384 对比微调 NeuralOS、8 帧窗口模型，以 1024×768 对比相同渲染器的无记忆/计算版本。512 版终端 OCR 50.1%，对窗口 1.3%、NeuralOS 0%；离屏编辑文件三选一回忆 64.2%，对基线最高 56.0%，同位置覆盖 64 步后为 50.0% 对最高 39.6%。1024 版 16 步 PSNR 22.34 对 17.38 dB，活动编辑增益 +5.20 对 +2.73 dB。消融：无 JEPA 回忆 32.1%；无残差预测 OCR 约 0.2%；清屏后 VLM 文本答案准确率仅 28.2%（算术 15.5%），无执行损失为 0%。闭环示例及记忆移植实验补充像素指标。

## Value
对于长时交互视频世界模型，最可复用的是**离屏状态可寻址、可干预且由预测误差监督**的设计，以及把可见画质与隐藏状态正确性分开评测。桌面域特殊，但记忆机制可迁移到持久场景世界。

## Strengths
构造同屏覆盖的对照任务，使记忆无法靠位置索引或近邻帧蒙混；移植记忆库的干预检验比只看生成质量更有说服力；清楚区分文本可读、符号答案和视觉保真度。

## Weaknesses
精确计算远未解决：清屏算术准确率 15.5%；1024 版没有完整记忆/计算指标，训练只覆盖宽语料约 0.044 轮且质量仍上升。高分辨率只和 Copy-Only 比，贡献归因有限；未见桌面上仍无法正确绘制新对话框。受控任务较窄，离真正可作为操作系统的长期可靠性差距大。

## Future Work
作者提出走向开放式、可随用户工作流适应的界面；当前结果指向加强精确执行、跨软件泛化与长期闭环可靠性，后两者是本文结果引出的研究方向。

## Rating
创新度评分：4/5 - 将预测表征监督、可干预的内容记忆与快速 GUI 生成组合，提出有辨识力的持久性评测；仍是多项现有模块的集成而非成熟新范式。
相关度评分：3/3 (Core) - 直接研究带动作条件的交互视频世界模型，且使用 JEPA 式隐空间预测。

## TL;DR
以惊讶门控记忆和潜在下一帧预测维持离屏状态，再残差生成交互桌面；长时视频世界模型研究值得精读。
