# AlayaWorld: Interactive Long-Horizon World Modeling - Full Technical Report (v1.1)

## Insight

核心观察是条件信号与目标视频 latent 若在表示、时间窗口和 train–test 路径上不一致，会让自回归视频模型不断积累边界误差。新版因此不再把静态图、warp、相机 AdaLN 当作异构旁路，而是把图像、时间记忆和 3D 重渲染都按同一 causal VAE 规则编码；相机控制也完全由目标视角下的重渲染视觉条件表达。WBench 的 Perspective/Geometric 分数达到 86.6/94.1，支持该方向，但由于六项修改没有消融，无法证明是哪项导致提升。

## Motivation

旧版 AlayaWorld 同时使用文本、时间记忆、空间记忆和独立相机分支，但不同条件可能缺少 causal VAE 的时间上下文、存在像素/latent 窗口 off-by-one，训练时的零记忆 token 也与首步推理不符。长时 chunk 自回归对这种微小不一致尤其敏感。问题对交互视频世界模型很关键，不过本文是版本改造报告而非完整新模型论文。

## Method

骨干、chunk-wise 自回归、训练数据均沿用前版，只修改条件与记忆：

1. 图像条件不再单帧编码，而用“条件帧+前 8 帧”的九帧 causal-VAE 窗口并取第二个 latent；chunk handoff 采用同一规则。
2. 用 ViGeo 估计逐像素 3D 点并流式写入 point cache；计划相机从 cache 重渲染下一块。相机轨迹以 prefix 位移的 pairwise-median ratio 对齐尺度，内参每 clip 用针孔模型最小二乘估计一次。
3. 重渲染序列前置一帧真实 prefix 后做 causal encoding，再丢弃 prefix latent；无效区域的 token 直接删除以兼容 FlashAttention。
4. 时间记忆从 6 个 latent 改为 4 个，严格由 25 像素帧编码得到，统一 data loader/trainer 边界。
5. hard memory dropout 直接移除 token 而非置零，首个推理 chunk 也无时间记忆；训练、rollout、评估统一 VAE 编解码与 anchor-frame 协议。
6. 删除 camera AdaLN；相机轨迹只决定 3D cache 渲染视角，视差、尺度和可见性通过视觉 latent 输入模型。

## Experiment

- 仅在 WBench navigation split 的 158 个 case 上与 8 个系统比较，并提供少量定性图；没有逐修改消融、随机种子、方差或旧版直接对照。
- AlayaWorld 的 Consistency 平均 89.5，为表中最佳；Background/Perspective/Subject/Geometric 分别为 94.1/86.6/93.4/94.1，Spatial 87.9、Gated Spatial 81.9 均第二，和设计目标一致。
- Video Quality 平均表格为 79.3（正文一处写 79.1），Imaging 67.7 最佳；Navigation 80.0，低于 HY-World 1.5 的 87.5 和 Happy Oyster 的 85.1。
- Setting 平均 69.7、Physical 平均 63.1 较弱，Causal Fidelity 65.1 低于多数对手；说明几何持久性并未带来语义状态或物理动力学能力。
- 定性页声称多环境下结构和对象关系稳定，但只给精选帧，没有失败案例或长时长度说明。

## Value

这份报告提供了一个很实用的工程原则：视觉世界模型的所有视觉条件最好与生成 latent 共享完全一致的 causal 编码统计，且相机控制可通过几何重渲染进入同一路径。流式 3D point cache 对显式 3D 记忆和视点可控生成有直接借鉴价值。然而“Full Technical Report”只有五页，证据不足以判断六个改动的独立价值或长期稳定性。

## Strengths

- 明确定位多种训练–推理不一致，包括时间上下文、边界 latent、dropout 泄漏和首步 memory 差异。
- 把相机控制与可见几何统一，较抽象 AdaLN 更容易维护视差和重访一致性。
- point cache 有显式注册、尺度对齐、内参估计和无效 token 删除，工程细节精炼且可实现。
- WBench 的多个几何/视角一致性指标确实位居前列，结果与设计目标对齐。

## Weaknesses

- 没有与前版的配对结果，也没有六项改动的消融，无法作因果归因；优势可能来自模型/训练更新而非条件协议。
- 完全缺少模型规模、数据、训练目标、优化配置、推理速度、显存、cache 容量及会话长度，复现信息严重不足。
- 只测一个 navigation split，未验证绕回闭环、超长记忆、动态对象、遮挡、漂移与点缓存淘汰。
- 流式单目 3D 点会受尺度、动态物体和累积配准误差影响，论文没有误差分析或 3D 真值评估。
- Physical/Causal Fidelity 较弱，说明显式几何只解决“看起来在原处”，没有真正学习交互动力学。
- 正文 Video Quality 平均 79.1 与表中 79.3 不一致；定性图没有具体 prompt、时长或对照。

## Future Work

作者仅从结果中指出应提升环境级语义保持和物理交互。实际后续还需逐项消融、与旧版严格配对，公开完整训练/推理协议，并研究动态 4D cache、回环校正、置信度融合、记忆淘汰及长时间全局一致性。

## Rating

创新度评分：3/5 - 将 causal-VAE 条件统计统一并以流式 3D cache 驱动相机控制具有明确新意，但属于系统重构，实验论证很薄。
相关度评分：3/3 (Core) - 直接涉及交互视频世界模型、显式 3D 空间记忆、相机控制与长时一致性。

统一 causal 条件并用 3D 点缓存驱动视角控制，思路值得读但报告证据不足，建议选读。
