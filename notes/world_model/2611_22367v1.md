# FailureGen: Scalable Robot Failure Data Generation with World Models

## Insight
观察：真实机器人失败轨迹稀少，但同一失败动作放进不同成功场景时，接触位置、物体与后果可变化。推论：以真实失败动作作为干预，借助动作条件视频世界模型生成新的失败上下文，再依据生成视频中的实际事件标注，而非把原失败标签直接复制。论文用生成案例和真实测试集上的失败检测收益支持可行性；未证明生成动力学普遍忠实。

## Motivation
尾部失败事件难以反复实机采集；仿真中人工扰动不一定覆盖真实失败方式。已有世界模型数据生成或故障合成多从程序扰动出发，本文关注如何复用已发生的真实失败动作，扩展多场景故障数据。对具身视频世界模型的下游价值相关。

## Method
四阶段：用成功/失败实录对 Cosmos3-Nano 做微调，交替训练动作→视频的正向流匹配和视频→动作的逆向目标；以视觉语言模型给真实录像标注步骤、失败与恢复区间，匹配失败 donor 与成功 host；在 host 的对应时段对齐并移植 donor 的关节或末端执行器运动，可施加空间偏移，条件生成 17 帧、5 Hz、3.2 秒视频；重新判读生成事件并人工检查、过滤伪影。保留视频、运动序列、事件时间标签及来源。主要创新是失败动作跨场景组合与事件重新标注，骨干模型沿用已有 Cosmos。

## Experiment
工业双臂任务有 80 条实录，66 条用于生成器/检测器训练；108 个移植候选中挑出 75 个合成失败片段（69 个保留预期失败，6 个产生别的失败）。独立真实会话上，检测器在 36 个失败区间检出 33 个，实录单训为 28 个；平均精度 0.5119 对 0.4085，41 个正常回合中的误报为 0 对 5。三项 ViFailback 操作任务中，两个 Qwen3-VL 检测器的六组任务组合里五组准确率/失败召回提升、一组持平；例如抽屉任务 2B 模型准确率 84.4%→97.0%、失败召回 82.5%→96.7%。生成数据经过人工筛查，工业与 ViFailback 分别去除 9.8% 和 11.2%。包含定性 donor/host/生成帧对比；缺少移植策略、正逆监督及过滤机制的独立消融。

## Value
适合作为动作条件视频模型数据合成与评价的选读材料，尤其是“按生成结果重新标注失败”的原则。若用于策略学习或世界模型评测，仍需验证动作执行忠实度、接触物理和合成数据带来的分布偏差。

## Strengths
真实失败动作而非纯人工噪声提供干预来源；训练与评测录像按回合划分，评测在独立真实会话上完成；明确区分意图失败与实际可见失败，并有人审过滤。

## Weaknesses
生成器的反事实动力学无定量精度/物理一致性评测，只展示下游检测与少量画面。工业增强组与最强实录组的负样本数、采样比例和更新预算不同（233 对 525 个负样本；295 对 400 次更新），故提升不能全归因于合成失败片段。真实评测标签在检查误报后有部分修订；样本量和任务种类有限，合成视频只覆盖短片段。人工审查成本未量化。

## Future Work
作者主张将数据用于更多机器人下游任务，如诊断、纠错、奖励或策略学习，并与程序扰动及受控生成结合；这些拓展尚未实验验证。

## Rating
创新度评分：2/5 - 利用既有 Cosmos 骨干和轨迹迁移做失败数据扩增，流程实用但模型技术增量较小，因果消融不足。
相关度评分：2/3 (Related) - 直接使用动作条件视频世界模型生成具身数据，重点仍是故障数据与检测而非世界模型能力提升。

## TL;DR
将真实失败动作移植到成功场景生成并重标注视频，改善故障检测；研究视频世界模型数据合成可选读。
