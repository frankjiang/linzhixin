# MiniWorld: Democratizing the Training of Video World Models from Scratch

## Insight

Observation：双向视频扩散训练时未来帧可相互注意、历史永远来自真值，而流式部署必须依赖自身生成历史，造成因果结构和分布双重错配。论文推论：从零训练 block-causal DiT，并让各时间块噪声单调不减，可把训练样本变成“过去较干净、未来较不确定”的流式中间态；完成块的 KV 一旦提交便无需重算。实验中 8 个 in-flight chunks 加 rolling cache 相比 32 块全窗口把输出从 3.31 提至 7.29 FPS、首块延迟从 74.0 s 降至 4.86 s，而聚合质量近似不变。该结果支持有界在线窗口的工程可行性，但未证明缓存 state 能保存需要跨越其容量的长期因果信息。

## Motivation

主流视频世界模型常从大型双向视频生成器后训练/蒸馏，流程昂贵且与自回归流式推理不一致；从零因果预训练虽已被 MAGI-1、SkyReels-V2 等验证，却缺少普通研究团队可复现的轻量端到端基线。MiniWorld 目标不是刷新画质，而是降低 action-conditioned streaming world model 的训练门槛。可复现性和训练—部署一致性是领域真实基础设施问题，但算法问题大多已有前作铺垫。

## Method

Wan2.2 VAE 将视频压到 4× 时间、16× 空间 latent，DiT 本体从零训练。latent 按两帧一 chunk；块内双向注意、跨块严格因果。动作经 encoder 同时产生 embedding 与 AdaLN modulation；所有层共享主 modulation，层级差异用零初始化低秩残差表达。Diffusion Forcing 为各块独立采样 timestep，并约束 τ1≤…≤τM；CoPP 从随机 anchor 向两侧传播噪声级，以兼顾单调组合和 timestep 边际覆盖。短片 21/46 帧预训练后继续在 125/253 帧上训练，并混合 image-to-video 与 video-to-video 条件。流式推理维护永久 sink、FIFO rolling KV cache 和有界 active window；完成块提交缓存，淘汰旧块后对 retained keys 做 RoPE re-shifting，多未来块处于不同噪声级并行流水去噪。整体创新是把若干已知因果扩散与缓存技巧整理成可运行配方，而非单一新建模原理。

## Experiment

在 DROID 以 7D 机器人动作、RE10K 以相机射线姿态做控制，分辨率 240×320；主要结果使用 50 个 held-out 视频、253 帧 rollout，并与同控制序列的 29 帧双向滑窗 baseline 比较。论文仅绘制相对分数且把 baseline 归一为 1；DROID 上报告 Trajectory Accuracy +249%、Depth Accuracy +238%、LPIPS 反向比 +216%、SSIM +125%，RE10K 上 Photometric Smoothness +89%、Depth Accuracy +55%、PSNR +34%。381 帧相较 253 帧仍保留约 94% 外观和 96% 动态分数，但几何、VLM 与 fidelity 更明显下降。缓存/窗口、缓存长度、sink 数、CFG、0.5B→1B→3B scaling 和吞吐均有消融；1B 模型 KV cache 令 DiT 吞吐 0.41→0.91 chunks/s，总输出 3.31→7.29 FPS。主要缺口是没有绝对指标、置信区间、标准 SOTA 世界模型、动作可控性干预或任务效用比较；“提升 249%”相对于自建弱滑窗 baseline，难判断绝对质量。

## Value

其最大价值是开放、端到端、8 GPU 单机可训练的 streaming video WM 基线，便于研究长时记忆、因果扩散和效率，而不依赖闭源数据/巨型双向骨干。对后续工作最有启发的是将噪声调度视为训练时模拟异步流状态，以及将 committed latent 的 KV 作为有界推理记忆。待解决的是缓存淘汰后的实体/几何持续性、自生成历史上的鲁棒训练、动作敏感性与真正交互闭环，而不是继续只优化感知分数。

## Strengths

系统从数据处理、训练到流式推理形成完整可复现链路；因果注意、噪声顺序和部署流水线彼此一致；DROID 与 RE10K 覆盖操作动作和相机控制两类条件；效率测量拆分 DiT/VAE 瓶颈，缓存、窗口、sink、长度和模型规模消融较全面；作者对“开放基线而非性能上限”的定位克制。

## Weaknesses

“from scratch”只适用于 DiT，仍依赖预训练 Wan2.2 VAE。算法高度继承 Diffusion Forcing、AR-Diffusion 的单调调度、rolling KV/cache 与 RoPE 技巧，CoPP 和 AdaLN-LoRA 的独立贡献未消融。主比较只有自建 29 帧双向 baseline，且全部展示归一化相对值；未给 FVD/PSNR 等绝对数、随机波动和现代因果视频模型对比。50 个视频规模小；未测试闭环交互、反事实动作、物理一致性或生成视频对下游策略的价值。所谓任意长生成实际上遗忘被淘汰历史，只保留 sink，381 帧已出现几何漂移。

## Future Work

作者提出扩大视频—动作语料和模型规模，采用 SFT/RL 等更强训练—推理对齐策略，并通过历史压缩、少步蒸馏与量化进一步提速。更关键的研究还包括可检索/结构化长期状态、self-forcing、动作遵循基准和闭环 agent 评测。

## Rating

创新度评分：3/5 - 提供了实用、透明、可复现的从零流式训练配方，CoPP 与缓存流水实现有价值；但核心技术多为既有方法整合，实验也不足以证明 SOTA。
相关度评分：3/3 (Core) - 直接研究动作/相机条件的长时流式视频世界模型，是视频世界模型方向的核心基础工作。

## TL;DR

开源单机可训的因果扩散视频世界模型基线，工程价值高但比较偏弱，值得精读。
