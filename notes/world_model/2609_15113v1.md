# Legislating World-Model-Based Planning with Legal Reasoning

## Insight
观察：即使逻辑规则无误，错误的感知事实和不唯一的几何解释仍会导致违规。作者区分“事实落地误差”与“规则到约束的解释差异”，通过真实状态对照和同轨迹不同指标重评分量化二者；不是对法律合规的形式化保证。

## Motivation
普通几何安全约束难表达例外、义务冲突和违规后的补救。本文探索给潜空间规划器增加可审计的规范层，问题有意义，但真实法律的复杂性远超所测规则。

## Method
DINO-WM 预测动作后的潜状态 → 探针解码方块位置和标志颜色 → Defeasible Deontic Logic 推理许可/义务 → 在 RRT 扩展时剪掉违规动作或附加惩罚。比较不约束、硬约束、软惩罚及真值 oracle；补救规则允许违规后改为离开禁区。世界模型本身没有新训练机制（§3–5）。

## Experiment
- Isaac Lab 中机械臂推方块，3×3 网格、8 个任务，每类 agent 400 回合；报告成功率、遵守率、Wilson 区间、探针误差及规则日志。
- 硬约束 agent 成功率 66.2%、遵守率 64.7%，后者为无约束的 5.9 倍；边界加 0.04 m 余量后遵守率升至 88.7%（§6）。
- 模型加探针平均位置误差 0.031 m，p99 为 0.190 m，超过一格；53% 的补救义务由误报触发。
- 单独重评禁区规则时，同一社会型 agent 的遵守率可从全路径/整物体 65.5% 变为静止/中心点 97.8%；这是测量口径差异，不是新控制策略的收益。
- 逻辑决策 16.6 ms，但每动作规划 12.5 s，整体尚非实时控制。

## Value
直接启发是对潜世界模型的“预测→符号事实→约束→动作”接口逐层审计；不能把符号推理正确当成物理执行正确。

## Strengths
将感知误差与规范解释分开测量；提供可追溯规则日志；检验运行时规则插入及外部信号变化。

## Weaknesses
单一简化仿真，方块旋转锁定，部分历史信号来自真值；缺少相近安全屏蔽/时序逻辑基线。手工规则与探针依赖较强，边界余量无校准保证，oracle 也非100%遵守。

## Future Work
作者提出用 conformal prediction 建模感知不确定性、优化安全余量、实机验证，以及原则化地把抽象规则映射为规划约束（§8）。

## Rating
创新度评分：2/5 - DDL、探针和潜空间RRT的组合及诊断有用，方法和验证规模有限。
相关度评分：2/3 (Related) - 直接使用视觉潜世界模型规划，贡献集中在外接规范层。

## TL;DR
为潜世界模型规划接入可撤销规则，量化感知误差与规则解释造成的违规；安全接口研究可选读。
