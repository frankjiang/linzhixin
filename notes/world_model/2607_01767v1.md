# Repair the Amplifier, Not the Symptom: Stable World-Model Correction for Agent Rollouts

## Insight
论文 insight 是长链 LLM agent 失败往往不是单个症状节点错，而是某个因果子图会放大 residual error。Observation 是局部修补当前错误可能让后续 rollout 继续发散；作者据此用谱半径下降来定位“放大器”子图，而不是只修最近错误。

## Motivation
论文解决 agent planning graph 的 world-model correction。同行包括 full replay、local repair、cascade repair、trace scanning 和 LLM self-repair；它们要么 token/计算成本高，要么只修症状。该问题与 agentic world model 有关，但不属于视频/3D/JEPA/Dreamer 主线。

## Method
WM-SAR 将 agent workflow 表示为 node-edge graph，估计 residual node-edge operator 和 Graph Error Amplification Field。选择可最大降低 residual spectral radius 的 connected causal subgraph，再交给 LLM 修复。理论上，谱半径控制 rollout error 和 planning regret 的放大趋势，因此修复应面向谱半径 relief 而非局部误差大小。

## Experiment
主要在合成 agent calling-tree graphs 和 benchmark-inspired topologies 上测试。主表中 WM-SAR 选择子图大小约 8.3，连接率 94%，IoU 0.845，rho-red 1.95，MSE@32 约 6.3；TopK、Window、Cascade 等在长 horizon 下 MSE 明显爆炸。LLM 修复实验中 WM-SAR Rec-Exact 0.500、tokens 855，优于 full graph 或 local repair。不同模型下 Gemini 等也显示 WM-SAR 比 local repair 更稳。

## Value
对目标方向的直接价值有限，但它提出了一个值得借鉴的思想：world model rollout 错误应找“误差放大源”，而不是只对末端预测误差做局部修补。这个思路可迁移到长视频/交互式世界模型的 error attribution。

## Strengths
把稳定性、谱半径和 agent 修复联系起来，问题表述清楚；在 token 成本和修复效果之间有实证权衡；指出 Who&When 类边界案例。

## Weaknesses
实验主要是合成图和 inspired topology，不是真实复杂 agent trace；假设 planning graph 和 residual 可估计；某些边界任务中局部修复反而更好；与视觉/3D 世界模型没有直接技术连接。

## Future Work
作者提出需要真实 agent traces、更多目标/metric 边界评估，并验证 uncertainty term 等组件在真实场景中的作用。

## Rating
创新度评分：3/5 - 稳定性视角和谱半径修复有一定新意，但验证范围较窄。
相关度评分：1/3 (Tangential) - 只在 agent graph world model 层面间接相关。

## TL;DR
用谱半径找 agent rollout 的误差放大子图，概念有启发但与主线偏远，可选读。
