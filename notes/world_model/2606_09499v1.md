# Targeting World Models to Compromise Robot Learning Pipelines

## Insight
核心观察：世界模型作为机器人学习管线中的新组件，引入了一个隐蔽的数据投毒入口。攻击者只需篡改视觉帧（看起来安全的遥操作数据），经世界模型处理后即可生成危险的训练轨迹或扭曲的转移动力学，而这些攻击在数据集层面的安全检查中不可见。论文证明了这一新攻击面的可行性：(1) 对 text-conditioned 世界模型，通过 Visual Prompt Hijacking (VPH) 在图像中嵌入恶意 prompt 覆盖安全指令；(2) 对 action-conditioned 世界模型，通过 Visual Transition Hijacking (VTH) 使非目标动作的预测崩溃，迫使 RL 智能体选择特定后门动作。

## Motivation
- **问题**：世界模型越来越多地被用于生成合成机器人训练数据或作为 DRL 的模拟环境，但其安全性（被攻击后对下游策略的影响）未被研究。
- **同行做法**：传统数据投毒攻击需要直接注入危险轨迹或访问奖励函数/训练环境，检测难度低且实施门槛高。
- **是否关键**：具有一定前瞻性，但目前世界模型在机器人管线中的实际部署仍有限，更多是安全预警性质。

## Method
**两种攻击方法**：
1. **Visual Prompt Hijacking (VPH)**：针对 text-conditioned 世界模型（如 Cosmos-Predict 2.5）。在条件帧中注入微小对抗扰动（LAB 空间 l_p 范围内），使世界模型的 semantic encoding 从安全 prompt 切换到危险 prompt（如"拿炸弹放入礼盒"），进而生成危险示范轨迹。
2. **Visual Transition Hijacking (VTH)**：针对 action-conditioned 世界模型（如 Dino WM、Cosmos-Predict 2.5 AC）。在初始状态帧中注入扰动，使世界模型对非目标动作的预测全面崩溃（embedding 远离正常分布），而仅对攻击者选定的目标动作保持正常预测。这相当于向 DRL 策略注入后门。

**创新程度**：中等。方法本质是对抗样本技术在世界模型场景中的新应用，VPH 和 VTH 的攻击目标设计有新意，但技术手段（梯度优化扰动、LAB 空间约束）较为常规。

## Experiment
- **VPH 实验**：在 Cosmos-Predict 2.5（2B）上微调后评估，3 个任务（Gift Box/Stove/Microwave），比较 vague vs specific prompt、in-distribution vs OOD 相机。OOD + vague prompt 时攻击成功率最高（最高 100%），in-distribution 下攻击效果有限。但 text-conditioned 管线整体尚不成熟，VPH 更多作为 proof-of-concept。
- **VTH 实验**：在 Dino WM 上完整验证 DRL 后门注入，PPO 策略在 Single Wall 环境中被成功植入后门（触发时切换到目标动作，无触发时正常完成任务）。在 Cosmos-Predict 2.5 AC 上验证了大规模真实数据模型的预测退化。

## Value
- **价值**：首次系统性揭示世界模型作为机器人学习供应链攻击面的安全隐患，对世界模型安全研究有开创意义。
- **局限**：VPH 的端到端攻击链未完全验证（inverse dynamics 模型不成熟）；VTH 仅在简单环境中验证；攻击需要白盒访问世界模型。
- **启发**：在将世界模型集成到机器人系统时需要考虑对抗鲁棒性；数据供应链的安全审计需要延伸到世界模型层面。

## TL;DR
首次提出针对机器人学习管线中世界模型的对抗攻击（VPH/VTH），揭示世界模型作为隐蔽数据投毒入口的安全风险。安全方向可选读，世界模型建模方向可跳过。
