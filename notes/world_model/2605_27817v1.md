# VERA: Video World Models Enable Real-World Action Through Embodiment-Aware Jacobian Inverse Dynamics

## Insight
视频世界模型到机器人动作的映射可通过**体现 Jacobian 逆动力学模型（J-IDM）**实现：不直接从视频帧回归动作，而是学习一个映射视觉变化到关节速度的 Jacobian 矩阵 J(q)，再通过 J⁺Δx 求解动作。优势：(1) Jacobian 结构隐式编码了运动学约束，比直接回归更 sample-efficient；(2) 解耦了"世界如何变化"（视频模型负责）和"如何驱动身体实现变化"（J-IDM 负责），使同一视频模型可适配不同 embodiment。

## Motivation
大规模视频生成模型（如 Wan2.1-14B）已学到丰富的物理世界知识，但缺乏 action conditioning 使其无法直接用于机器人控制。现有方法要么需要 action-conditioned 训练数据（稀缺），要么用通用 IDM 做视频→动作映射（忽略机器人运动学结构）。核心问题：如何将 action-free 视频模型的世界知识转化为可执行的机器人动作？

## Method
- **视频规划器**：Wan2.1-14B，language-conditioned 生成未来视频轨迹，不需要 action label
- **J-IDM**：学习 embodiment-specific Jacobian J(q)，将相邻帧视觉差异 Δx 映射为关节速度 Δq = J⁺(q)Δx
- **架构**：Jacobian 网络输入当前关节角 q，输出 J 矩阵；视觉编码器提取帧间 Δx；组合得到动作
- **训练**：仅需少量（~50 episodes）的 embodiment-specific 数据训练 J-IDM，视频模型完全冻结
- 验证平台：Franka Panda 7-DoF 臂 + Allegro 16-DoF 灵巧手

## Experiment
- Franka Panda：6 个操作任务平均成功率 52%（vs π0 的 55%，但 π0 用 10K+ episodes 训练）
- Allegro Hand：4 个灵巧操作任务可执行，现有 baseline 无法处理 16-DoF
- J-IDM vs 标准 IDM：成功率 52% vs 36%，Jacobian 结构带来显著提升
- 视频模型消融：14B > 1.3B，模型容量直接影响规划质量
- 局限：实时性差（视频生成需数秒），对快速反应任务不适用；闭环仅通过重新规划实现

## Value
解耦视频规划与动作执行的思路有价值，J-IDM 是优雅的运动学先验注入方式。证明了 action-free 视频模型可通过少量 embodiment 数据适配到真实机器人。对视频世界模型在机器人中的应用路径有直接参考价值。局限在于实时性和闭环控制。
