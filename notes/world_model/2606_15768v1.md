# LaWAM: Latent World Action Models for Efficient Dynamics-Aware Robot Policies

## Insight
核心 insight：WAM 不一定要生成未来像素；机器人策略需要的是 action-relevant future context。作者复用 latent action model 中常被丢弃的 forward decoder，把 latent action 展开为未来视觉特征/latent visual subgoal，作为动作生成的动态条件。

## Motivation
VLA 主要从当前图像-语言上下文直接预测动作，缺少显式“动作会如何改变场景”的 foresight。像素空间 WAM 虽能给策略提供未来视频，但参数和延迟很高，且大量容量花在像素冗余上。问题对机器人 world-action model 很核心。

## Method
LaWM 在冻结视觉 foundation encoder（如 DINOv3）latent 空间中训练：inverse dynamics encoder 从视觉转移推断 latent action，forward decoder 根据当前 latent state 和 latent action 预测未来 observation features。LaWAM 再让 policy 预测/蒸馏 latent action，并把 LaWM 预测的 latent visual subgoal 输入 Alternate-DiT action expert 生成 action chunk。训练分为 LaWM 预训练与 LaWAM policy integration；human videos 只贡献 dynamics prior，策略集成用带语言指令的机器人轨迹。

## Experiment
预训练约 3000 小时机器人视频和 1500 小时 egocentric human videos。LIBERO 平均成功率 98.6%，RoboTwin 91.22%，并报告真实机器人迁移；LaWM 仅 230M，相比使用 5B WAN backbone 的像素 WAM，world-modeling 参数少约 95%，延迟 187ms，最高约 24x faster。消融显示移除 LaWM 掉点最大，尤其 LIBERO-Long；去掉 latent-action distillation 和 knowledge insulation 也会降性能。限制是稳定相机操作最有效，强自运动/相机抖动和细粒度 deformable dynamics 仍弱。

## Value
核心相关且实用：明确把 WAM 的未来预测接口从像素改成 latent visual subgoal，并验证效率-成功率优势。创新不是全新范式，但工程取舍清晰，值得精读方法和消融。
