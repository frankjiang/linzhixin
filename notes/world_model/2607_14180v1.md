# RENEW: Towards Learning World Models and Repairing Model Exploitation from Preferences

## Insight
论文的 insight 是：人类不一定能演示正确策略，但常能判断 imagined rollout 的动力学是否荒谬，因此偏好信号可以直接监督 world model dynamics，而不只监督 reward。Observation 是 offline MBRL 的模型 exploitation 集中在数据覆盖薄、epistemic uncertainty 高的区域；推论是用 uncertainty 主动选择最可被利用的 imagined transitions 让人类比较物理合理性，可以更高效修补模型。

## Motivation
该文解决离线 world model 被策略利用的问题。传统 MOPO/MOReL/COMBO 等保守方法避免不确定区域，牺牲泛化；DAgger/收集更多数据又昂贵或危险。作者提出不收集新环境 transition，而用人类偏好修补动态模型。这个问题对 Dreamer/MBRL 类隐式世界模型有参考价值，尽管本文实验不是视频或 3D。

## Method
DLHF 将 RLHF 的 Bradley-Terry 偏好框架从 reward model 换成 trajectory log-likelihood。给定 segment sigma，模型 likelihood 为 sum log T_hat(st+1|st,at)，偏好概率为 logistic(l_theta(sigma0)-l_theta(sigma1))，最小化交叉熵直接更新 dynamics model。RENEW 在此基础上用 epistemic uncertainty 主动查询：从当前模型 rollout 中按 ensemble disagreement/uncertainty 采样高风险起点和 transition pair，收集偏好，再迭代 fine-tune；偏好只训练 dynamics，不需要 reward、expert demo 或环境交互。

## Experiment
实验使用 Jumanji 离散环境和 classic control，偏好由 synthetic oracle 根据与真实 transition 的 L1 距离给出。第一组从零学习显示 DLHF 可学简单 dynamics，但 1M preference 才达到 1K supervised transitions 的误差量级，样本效率差。第二组比较 naive DLHF 与 RENEW，在 100K preferences 下 Sliding Tile 3x3 误差从 pretrained 1.320 降到 naive 0.419、RENEW 0.207；Sokoban 中 naive 反而从 0.0377 变差到 0.0428，RENEW 改善到 0.0257，说明主动查询可减少 forgetting。第三组在 Maze 5x5 到 20x20 中用 1600 labels 修补 pretrained model，RENEW transition accuracy 分别为 96.5、97.2、94.4、94.9，高于 naive 的 89.7、93.2、92.3、93.2，并降低高错误区域的不确定性。

## Value
价值在于把 preference supervision 用于 transition dynamics，而不是 reward。对隐式 world model 的安全/可靠性有启发：评估和修补应关注模型最可能被 planner exploit 的状态动作，而非均匀 rollout。局限是当前证据仍偏 proof-of-concept，距离视频世界模型或真实人类反馈很远。

## Strengths
问题切中 offline world model exploitation；DLHF 形式简洁；RENEW 的 uncertainty-directed querying 与 exploitation 机制匹配；实验展示 naive preference learning 的低效率和主动查询的必要性。

## Weaknesses
偏好标签是 synthetic oracle，不是真人；环境小且多为离散低维，segment horizon 主要为 1；没有闭环 offline RL policy 改善结果，只看 dynamics error/uncertainty；高维视觉 latent、长 rollout 和噪声偏好仍未验证。

## Future Work
作者提出最重要方向是用 noisy human labels 验证 DLHF，并扩展到高维 observation；还需把 prediction error 降低与 formal unexploitability guarantee、实际 offline RL 算法收益联系起来。

## Rating
创新度评分：3/5 - 把偏好直接用于 dynamics likelihood 是有新意的设定，但实证仍是小规模初步验证。
相关度评分：2/3 (Related) - 与 Dreamer/MBRL 式隐式世界模型的 exploitation 和修补相关，但不涉及视频/3D 世界模型。

## TL;DR
RENEW用偏好直接修补世界模型dynamics exploitation，隐式模型安全方向可选读。
