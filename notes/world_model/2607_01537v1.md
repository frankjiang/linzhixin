# Certified World Models as Sensing Clocks: Drift-Aware Deadlines for Active Perception

## Insight
论文 insight 是 world model 不应只输出预测，还应输出“何时该重新感知”的 deadline。Observation 是 latent/3D world model 在短期可预测，但 rollout drift 会逐渐破坏等变性或任务证书；主动感知需要一个可审计的 sensing clock，而不是凭固定频率重采样。作者因此将 certified horizon 转化为 no-sensing deadline。

## Motivation
论文解决主动感知中何时重新观测的问题。同行包括 expected-belief information gain、MB-EIG、risk-sensitive sensing 和固定周期感知；这些策略可能预算高，且不直接利用 world model 的可验证漂移边界。该问题与 certified/implicit/3D world model 相关，但偏理论和部署策略。

## Method
方法从 audited equivariant world model 出发，计算 interval-simultaneous certificate violation 的 deadline。关键是用 calibrated native rollout-drift envelope，而不是只用 on-manifold Lyapunov rate；后者会高估可用 horizon。论文把证书 horizon 解释为 sensing clock：在 deadline 前可继续依赖模型，超过则重新感知。

## Experiment
实验包含 frozen 3D VN-JEPA 模型和 synthetic cue-conditioned theorem-bed。结果显示 certified clock 可控制 held-out interval-ICV；在 eventful-tail 场景中，违反率从 expected-belief MB-EIG 的约 0.36 降到 0.16，且 MB-EIG 需要约 3 倍预算才接近。risk-sensitive MB-CVaR 和 robust MB-WorstCase 在 exact-model limit 下可接近 certified clock。部分探索结果为负：partial-reset exploration 无明显收益，spectral term 没有稳定优势。

## Value
对我们有启发：隐式/3D world model 的可信使用应配套“有效期”估计，尤其在主动感知和闭环控制中。它不是改进生成质量，而是给 world model 部署加上可审计时钟。

## Strengths
问题定义新颖，关注 world model 的 trust horizon；强调 drift-aware deployment 而不是漂亮但失真的理论 rate；报告了若干负结果，可信度较高。

## Weaknesses
实验规模和任务较窄；对模型是否有可审计 equivariant/certified 结构有要求；与开放式视频生成、真实机器人长程交互还隔一层。

## Future Work
作者提出未来需要更长 horizon、partial-sensing regime、更丰富 hazards 和跨模型家族比较。

## Rating
创新度评分：3/5 - 将 certified horizon 转为 sensing deadline 有新意，但验证仍偏小规模。
相关度评分：2/3 (Related) - 与 3D/implicit world model 的可信 rollout 直接相关，但不是核心生成/建模方法。

## TL;DR
把 world model 有效期做成主动感知时钟，可信部署有启发，可选读。
