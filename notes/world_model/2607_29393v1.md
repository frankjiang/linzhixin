# AquaJEPA: Action-Conditioned Multimodal Predictive Representations for Underwater Robot Dynamics

## Insight
论文观察到，低 supervised prediction error 不等于模型能为规划比较反事实 action：recurrent world model 的 velocity MAE 最低，却只在 19.8% 样本上把真实 action 排在 zero-action 前；移除 action margin 也会降低 MAE、同时把 action ranking 从 0.436 降至 0.182。由此推论，控制用 latent 世界模型必须显式约束“不同动作产生不同未来”，而不能只追求平均动力学拟合。作者通过 counterfactual margin 消融和共享 MPC 接口验证；同时证明缺失模态鲁棒性主要来自训练时 modality dropout，而显式 mask 的额外收益未被独立确认。

## Motivation
水下机器人同时依赖 RGB、前视声呐、IMU/DVL/压力等传感器，但能见度、视角和 DVL bottom lock 会突然变化。像素预测浪费容量在光照、纹理与声呐 speckle 上；普通多模态融合又可能在传感器失效时崩溃。关键问题是学习既响应八推进器动作、又能在缺失模态下支持短时闭环规划的紧凑预测表征。这是重要但较窄的机器人世界模型场景。

## Method
相机、声呐与 15 维 proprioception 经独立 encoder 得到 64 维特征，连同三类 validity mask 输入融合网络；训练时以 0.35 概率丢弃相机/声呐，并对 DVL dropout。GRU 编码未来 K=5 个八维推进器指令，predictor 从当前 fused latent、action summary 和物理时间间隔预测未来 latent。EMA target encoder 提供 stop-gradient 目标，另有未来速度变化和 32-bin 声呐轮廓 head。

总损失组合 latent cosine、速度/声呐 L1、相机–声呐对齐与 counterfactual action margin；margin 要求真实指令预测优于反向和零指令。推理时三模型 ensemble 在同一候选动作库上做 0.5 s receding-horizon scoring，代价含目标速度、近距声呐、能耗、平滑度与 ensemble uncertainty。贡献是 action-sensitive JEPA、缺失模态训练与物理 head 的整合，不是新的 encoder 或 planner。

## Experiment
训练数据只有 Stonefish BlueROV2 的 12 个 30 秒 episode（8/2/2 train/val/test），但闭环采用预先封存的 120 个配对环境：5 个 replicate × 3 个未见地图 × 4 个能见度 × 2 个动力学条件，并在固定时段移除 DVL。所有方法共享 action library、cost、在线残差修正与场景随机量。

对比 reactive、state-only、普通 multimodal、supervised dynamics 和 recurrent WM，并做 EMA、margin、mask、modality dropout 单因子消融。AquaJEPA 取得 74/120 成功、平均终点误差 0.906 m；state-only 为 68/120、0.916 m，差异区间跨零；相对普通 multimodal、supervised dynamics、recurrent WM 的终点误差改善分别为 0.273、0.364、0.106 m，95% CI 均排除零。移除 modality dropout 后 camera-absent velocity MAE 从 0.0056 恶化至 0.0108；但无 mask 版本为 0.0051，未证明 mask 本身必要。所有方法 collision 都是 0，AquaJEPA clearance 还低于 state-only/recurrent WM。

## Value
最有价值的结论是为“decision-useful world model”增加直接的 action-ranking 指标和反事实训练约束；这比只看 next-state MAE 更贴近规划。配对 factorial 设计也值得复用。当前结果主要证明在一个模拟水下平台和固定候选库中的有效性，尚不能说明可迁移到真实水域、连续优化或长时 latent rollout。

## Strengths
- 共享 encoder、数据、动作 horizon 与 planner，使主要比较集中在预测目标而非控制器调参。
- 预先封存场景，按 episode 做配对 bootstrap，没有把 10 Hz 高相关帧误当独立样本。
- 明确报告 primary state-only 对照未显著，而非只强调有利 baseline。
- 消融覆盖 action margin、EMA、mask 和 dropout，并同时报告预测、闭环与反事实排序指标。

## Weaknesses
- 全部证据来自单一 Stonefish/BlueROV2 模型；仅 8 个训练 episode，真实水下 transfer 未验证。
- primary comparator state-only 的成功率和终点误差优势均未获统计支持，整体收益不大且地图依赖明显。
- 候选动作为固定离散库，目标位置仍由 privileged simulator odometry 提供，限制真实自治解释。
- no-mask 消融没有变差，故显式 validity mask 的主张证据不足；单因子实验也未检查组件交互。
- 只预测 0.5 s、确定性 latent 和低维物理量，未测试长时误差累积或多模态未来。

## Future Work
作者明确将下一步设为真实轨迹上的严格 held-out transfer，并要求验证命令时间对齐；还指出需要同步相机、声呐、状态与因果推进器 telemetry。进一步可扩展连续 action optimization、长 horizon、真实声学伪影/时钟漂移，以及不确定性校准。

## Rating
创新度评分：3/5 - action-margin 驱动的多模态 JEPA 与严谨配对评估有明确价值，但主要是已有组件在水下控制中的精心整合，且核心对照优势有限。

相关度评分：3/3 (Core) - 直接研究动作条件 JEPA latent 世界模型、部分可观测多模态动力学与规划。

## TL;DR
用反事实动作约束训练水下多模态 JEPA，评测严谨但仅仿真且对强对照增益有限，可选精读。
