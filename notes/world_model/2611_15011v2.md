# Fast Inference-Time Policy Refinement via Action-Affine World Models

## Insight
观察：模仿策略已有可用的动作提案，部署时通常只需在提案附近作小幅纠偏；反复用非线性世界模型搜索或求导则很慢。推论：若直接预测整段名义轨迹及其对动作修正的局部仿射响应，就能把在线纠偏写成凸二次规划。作者用泰勒余项证明局部预测误差上界为名义误差 + 响应矩阵误差乘修正幅度 + 曲率项；这是局部光滑条件下的误差分解，不保证全局接触动力学线性或闭环安全。模拟消融验证直接预测和显式响应各自减少计算。

## Motivation
行为克隆在偏离演示分布后会累积误差；残差策略常需在线训练，采样排序或梯度规划要大量模型调用。让世界模型的输出形式服务于快速优化，是机器人模型规划的实际问题，但当前实现依赖显式状态而非视觉输入。

## Method
冻结扩散模仿策略定期产生动作块。以机器人/物体状态、动作历史和策略提案为条件，离线模型一次输出未来八步名义任务状态 Z̄ 和下三角因果响应矩阵 F，令预测 Z=Z̄+FΔA。任务几何量并入提升状态；二次目标与动作修正线性界组成 QP，每个控制步只解一次并执行首个修正。训练数据由冻结策略加动作扰动 rollout 得到，以多步预测损失学习 Z̄、F；把实际执行动作重新当作零修正提案，额外监督名义预测。创新点是将局部动作仿射模型、直接多步输出和模仿策略在线纠偏结合。

## Experiment
Isaac Gym 中 FurnitureBench 的 OneLeg/RoundTable/Lamp 与平面 PushT 四项仿真任务；每方法每任务三种子、每种子 64 回合。对比原扩散策略 DP、LPB、GPC 候选排序与梯度优化；同任务使用相同 DP checkpoint 和动力学数据。平均成功率：DP 27.08%、GPC-OPT 45.57%、本文 57.03%；RoundTable 从 DP 6.25% 到 42.71%，Lamp 从 6.77% 到 35.94%。额外纠偏延迟 4.18 ms/步（不含基础策略采样），GPC-RANK 为 25.27 ms、GPC-OPT 为 438.88 ms；计入策略采样总耗时从 17.71 增至 21.81 ms。四结构消融中直接仿射模型成功率 57.03%，递归仿射 43.75%，直接非线性 42.58%；不做名义重定心则降至 55.08%。

## Value
对基于世界模型的机器人规划，启发是按下游优化器需要设计预测接口，并对已有策略的局部修正建模；对视觉/3D 世界模型的借鉴属方法层面。成功率与延迟需在视觉反馈和真实物理环境下复验。

## Strengths
模型只评估一次即可优化；比较了成功率和完整在线时延；同数据消融直接/递归及仿射/非线性结构；局部误差界明确了方法适用范围。

## Weaknesses
全是仿真，输入为已测机器人和物体状态，不处理视觉表征误差；动作仿射仅适用于提案附近，接触切换可能破坏局部近似。成功率只基于每任务 192 回合，Lamp 方差较大；目标与边界依任务人工设计，泛化性有限。

## Future Work
作者明确提出扩展至视觉观测，在无需显式物体状态测量时仍保持快速策略纠偏。

## Rating
创新度评分：3/5 - 把已有局部线性控制思想落实为条件于策略提案的直接多步世界模型，得到明确的在线计算收益。
相关度评分：2/3 (Related) - 与世界模型辅助机器人规划密切相关，但不是视频、3D 或 JEPA/Dreamer 式表征模型。

## TL;DR
动作仿射世界模型把冻结模仿策略的局部纠偏化为快速二次规划，仿真成功率提升；规划接口设计可选读。
