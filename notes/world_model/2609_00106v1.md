# Deploying and Evaluating a Smart-Agriculture Agentic Engine for Full-Season Soybean Farm Operations

## Insight

Observation：农业 agent 在一两步工具调用上接近满分，不代表它能跨季节维持正确决策；播种、灌溉和收获的误差会通过部分观测、时序约束与延迟生物效应累积，普通 exact-match 或无序 tool-call success 难以反映最终产量。论文据此推论，物理过程型 agent 应同时评估完整事件轨迹和下游状态结果。其 Kendall-style Temporal Correctness（KTC）相对产量保持的回归斜率为 1.01、RMSE 4.2，优于 BFCL 的 1.63/37.1 和 path correctness 的 3.04/62.5；不过 KTC 的 `R²=0.70` 低于 BFCL 的 0.81，且所有产量都来自同一个校准模拟器，因此只能证明该指标在 FAIRY 场景内较好校准，不能证明跨环境普适。

## Motivation

现有 geospatial/LLM agents 多在即时反馈、有限 API 的短任务上评测，而真实农事具有空间异质性、稀疏观测、天气约束和跨数月延迟后果。论文要解决的是在真实农场基础设施上，怎样先通过数字孪生系统检验 agent 的全季节操作可靠性、上下文需求、编排代价和边缘部署成本。问题对 agent deployment 很重要，但其“world model”是显式作物过程模型和事件驱动数字孪生，不是用户关注的视频、3D 或 JEPA/Dreamer 式隐式世界模型。

## Method

FAIRY 将 268m×71m、64 条垄的高校大豆研究农场接入统一工具层：固定土壤/冠层/气象传感器，Sentinel-2、热红外/多光谱无人机与 LiDAR，灌溉施肥设施和农业机械。核心采用“everything is an event”：天气、遥感、作物生长、agent observation/action 和管理干预都作为带时间、垄区、参数与前置条件的 state-changing event，写入共享队列和完整 trace。

数字孪生用 WGEN/Richardson 日天气、bucket soil-water balance、GDD phenology、Monteith 式光能/生物量模型及病虫草压力与处理效应推进状态，并以 2025 年 18 个 plot-level 场景的物候和收成校准。agent 端集成 ReAct、Plan-and-Act、Reflexion、AutoGen、MMRL、ReWOO、LATS、CRITIC、GoT 九类 controller，可直接调用工具或经 weather/sensing/machinery/operations specialist 做 A2A 路由；backbone 包括 Qwen3.6-35B-A3B、DeepSeek-V4-Flash 和 Thor 上的多个本地 Qwen/Gemma。

知识层把农艺流程编码为可检索 skill，默认 top-3，比较 zero context、农业 LLM 生成上下文、skills library 和人工 Expert Instruct。任务分 L1 原子操作、L2 observation–diagnosis–intervention episode、L3 从播种到储藏的全季节 scenario；三位专家构造/复核 oracle event trace。评估同时报告 BFCL tool-call success、CORE edit-distance path correctness、匹配操作顺序的归一化 Kendall `KTC=(τ+1)/2`、相对 oracle 的 Yield Loss、token 和运行时间。

## Experiment

过程模型在 18 个历史 plot 上重放，论文称几乎所有 yield prediction 均达到约 2% MAE。主评测含 70 个 held-out L3 test，并另用 20 个 L3-mini 和 20 个 L3 validation 做 controller/知识库消融；短任务还覆盖 L1/L2。Qwen 在 L3 上从 zero context 到 Expert Instruct 时 Yield Loss 22.3%→4.6%、KTC 87.9%→92.1%；skills library 达 4.9%/93.7%，明显优于 LLM-as-an-Expert 的 15.3%/89.8%。DeepSeek 对应 Yield Loss 为 12.6%→2.9%，skills library 为 6.3%。L1/L2 在专家上下文下 KTC ≥98%、Yield Loss <1%，而 L3 仍明显退化，支持“短任务成功不等于长程可靠”。

A2A 在 L3-mini 上总体有害：跨上下文平均 Yield Loss 对 Qwen 从 direct 7.1% 增至 29.4%，对 DeepSeek 从 10.7% 增至 31.2%，虽减少主 controller token，却丢失 specialist 间的状态与执行记忆。知识库验证中，GeoFlow 式 hierarchical/full-path manual retrieval 的 KTC 最高（Qwen 97.2%、DeepSeek 96.8%）；FAIRY 自身 grouped-path library 为 93.8%/93.9%，没有全面胜过这些对照。

边缘侧 Thor profiling 显示，Expert Instruct 下 Qwen3.6-35B-A3B-FP8 的 L3-mini Yield Loss 2.1%、KTC 94.2%，约 3.3 秒/step、407.1 秒/task；小模型明显不稳，例如 Gemma-4-E2B 为 40.0% Yield Loss。真实系统演示完成一次 L2 无人机巡田、Sentinel-2 分类、正射影像和 UI 展示链路；但论文明确说明农事 tool invocation 仍在数字孪生中模拟，尚未完成 agent 管理地块与人工地块的真实季末收成对照。

## Value

该工作的主要价值是 deployment-readiness 基础设施和评估范式：显式保存时空事件、把 trace correctness 与最终物理结果配对、揭示多 agent 分工可能破坏共享状态。这些经验可间接启发长时世界模型 benchmark，尤其是不能用单步预测或表面成功率替代累计后果评估。但作物动力学由人工设计并校准，模型既不从视频学习 latent dynamics，也不生成/预测视觉未来；对目标研究方向的直接技术迁移有限。

## Strengths

系统覆盖从真实传感器、卫星/UAV、农机 API 到 agent、模拟器、trace 和 UI 的完整链路，资产与过程假设披露具体。实验不仅换 LLM，还比较九种 controller、四类上下文、direct/A2A、知识库结构和本地硬件，且报告 token、时间与产量而非只看工具调用。作者坦率区分了真实基础设施部署、真实 L2 观测演示和模拟干预，避免把预部署评估完全包装成自主农场试验。负结果——A2A 显著恶化长程表现、农业 LLM 不能替代专家流程——有实际参考价值。

## Weaknesses

最核心结论仍是 simulator-on-simulator：18 个 plot、单一 2025 季节的校准不足以覆盖极端天气、土壤异质性和模型错配，且未说明独立校准/验证划分、置信区间或 sensitivity analysis；agent 的 Yield Loss 因而可能放大数字孪生的既有规则，而非真实因果效果。标题中的“deploying”容易让人误读为已执行全季农机干预，实际只有观测链路演示，真正的 agent-managed harvest 尚属未来工作。KTC 只在匹配后的操作上计算顺序，可能对缺失/多余事件不敏感；它在 zero-context L3 仍约 88%，而 Yield Loss 可达 22%，也说明必须与其他指标联合使用。oracle 由少数专家制定且不保证全局最优，尚无 inter-expert disagreement；场景数量、L3 test/mini/validation 的包含关系以及主表按哪种 controller 汇总说明不够清楚。FAIRY library 并未在 Table 4 超过最强人工 hierarchical baseline，技术贡献更多是系统集成而非新的 world-model learning。

## Future Work

作者明确计划把 agent-managed 专用地块与人工管理地块并行运行，比较真实操作 trace 和最终收成；量化专家间分歧并测试不同 oracle 对 KTC/Yield Loss 排名的敏感性；做 ridge-level 空间误差分析，定位低观测区域；建立 A2A task-decomposition failure taxonomy；并考虑接入 WOFOST 等商业作物模型。真实干预前还应加入 process-model uncertainty、distribution shift 和安全约束评估。

## Rating

创新度评分：2/5 - 事件驱动数字孪生、KTC 与全季节 agent 评测形成有价值的系统组合，但核心技术多为已有过程模型、agent scaffold 和检索库的农业集成，且真实闭环证据尚缺。
相关度评分：1/3 (Tangential) - 属于显式农业数字孪生与 LLM agent 评测，仅在长时状态、延迟后果和轨迹评估上间接启发目标方向。

## TL;DR

真实农场接口结合数字孪生评测全季节代理，长程与多代理暴露失效，但偏离目标方向，可选读。
