# StatePlay: State-Aware Game World Models for Mechanics-Consistent Generation

## Insight
核心 insight 是：游戏世界模型不能只预测像素，因为游戏演化由显式内部状态和规则驱动。血量、能量条、计时器等状态如果不被建模，视频可能视觉合理但机制错误。推论是，把状态序列作为与视频并行的预测对象，并让二者交互，可以提升 mechanics fidelity。

## Motivation
现有游戏世界模型多关注画面真实性和动作响应，但在规则一致性上容易失败，例如 0 血继续行动、能量不足仍释放大招。同行主要做 action-conditioned video generation，内部 game state 常被当作隐变量或忽略。对游戏/仿真世界模型而言，这是核心问题，因为交互系统的可信度来自规则一致性而不只是像素质量。

## Method
StatePlay 基于 Wan2.2-TI2V-5B 视频分支，增加约 0.76B 的状态分支。输入首帧状态，未来状态以噪声初始化并回归预测；视觉分支使用 latent flow matching。架构采用 MoT-style 双分支，并通过双向 cross-attention 让视觉 token 与状态 token 互相调节。损失上，视频用 flow matching，状态用 Smooth L1 regression；作者发现紧凑规则状态直接回归优于 flow matching。

## Experiment
数据来自 Street Fighter 3，20 FPS、5 秒 clip，动作包括移动、普通攻击和 super art，状态从 emulator memory 抽取。评估包括 SSIM/LPIPS、动作控制准确率、状态 alignment 和 Gemini/GPT 判定的 mechanics fidelity。StatePlay 相比微调后的 ReactiveGWM，SSIM 相近，LPIPS 从 0.439 改到 0.424，State Alignment 达 0.947，mechanics fidelity 从约 63.7/59.7 提升到 82.3/78.3。消融显示 MoT+Regression 明显优于 shared branch 或 state flow matching。

## Value
这篇对游戏视频世界模型有直接价值：它把“规则状态”从隐式生成副产品变成显式建模对象。对我们做 world model 的启发是，某些机制变量不应期待视频模型自动学会，而应以结构化状态监督进入模型。但它主要针对单一 2D 格斗游戏，通用性仍待验证。

## Strengths
亮点是问题定义清晰，状态抽取与视觉生成耦合自然；用规则一致性指标而不是只报视觉指标；消融清楚证明状态分支结构和回归目标的重要性。

## Weaknesses
不足是数据域窄，依赖 emulator memory 和大模型辅助标注；mechanics fidelity 主要依赖 VLM 判定，可能有偏差；画面中的血条/能量条仍可能与预测状态不完全一致。

## Future Work
作者提出要扩展到更多游戏类型和更大规模的 state-aware game world model 数据集。后续也应让状态与像素级 UI 显示更严格一致。

## Rating
创新度评分：3/5 - 显式状态分支和游戏机制评估很实用，但整体是在现有视频生成骨干上的结构化扩展。
相关度评分：3/3 (Core) - 直接研究动作条件视频/游戏世界模型。

## TL;DR
显式建模游戏状态显著提升视频世界模型规则一致性，游戏方向值得精读。
