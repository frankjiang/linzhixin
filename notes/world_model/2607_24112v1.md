# Scaling GUI Agents with Visual State Transitions

## Insight
有。论文的 observation 是：GUI 轨迹标注贵，但 step-level visual transition `(s_t, a_t, s_{t+1})` 很便宜，且同时包含 action grounding 和 environment response。推论是先用 forward dynamics + inverse dynamics 做 State Transition Pretraining，可以把 GUI agent 的视觉 grounding、动作效果建模和任务规划解耦，作为 trajectory fine-tuning 之外的 scaling axis。

## Motivation
论文解决 GUI agent 难以扩展训练的问题。RL 需要复杂交互环境，trajectory SFT 又依赖人工多步标注，并把视觉定位、动态建模、任务规划绑在一个 next-action objective 里。STP 希望用无需 task instruction 的视觉状态转移做预训练，让模型形成 GUI dynamics 的内部世界模型。

## Method
模型采用 unified multimodal model。每个 transition tuple 拆成两个任务：inverse dynamics 从 `(s_t, s_{t+1})` 预测动作文本/代码，强化 action-relevant visual feature；forward dynamics 从 `(s_t, a_t)` 生成下一屏，学习 UI 状态如何被动作改变。二者联合预训练后，再在带 task instruction 的 trajectory 上 fine-tune。

数据来自 AgentNet、AndroidControl、GUIOdyssey 的已有 trajectory 拆分，也比较 trajectory-level sampling 与独立 step-level sampling。作者还做 objective ablation：inverse-only、forward-only、inverse+forward、inverse+reconstruction，以及只调 ViT vs 全模型调优。

## Experiment
AgentNetBench 上 STP 在不同 fine-tuning data split 下提升 average success rate 2.3%-6.2%，coordinate success 提升 1.6%-6.8%。AndroidControl 上 step success +0.9%、coordinate +1.3%；GUIOdyssey 上 step success +0.6%、coordinate +1.6%。预训练 transition 数据从 48K 增到 320K 时，AgentNetBench 下游表现稳定提升。

消融显示 inverse 与 forward 互补，联合训练比单目标稳；inverse+forward 优于 inverse+reconstruction，说明“预测动作效果”比静态重建更贴近决策。只更新视觉 encoder 的收益会快速消失，全模型更新更有效。step-level sampling 与 trajectory-level sampling 在同样 192K transition 下表现接近。

## Value
对我们有启发的是，world model pretraining 不一定要以完整任务轨迹为单位，局部 transition 也可以形成有用的 dynamics prior；forward/inverse dynamics 联合训练也可迁移到视频/机器人数据。但论文场景是 GUI，不涉及物理、3D、视频生成或 JEPA/Dreamer。

## Strengths
训练信号清晰；对比覆盖桌面和移动 GUI；scaling 实验和目标消融比较完整；提出了低成本 transition data 的实用扩展方向。

## Weaknesses
收益幅度偏小，尤其移动端只有不到 2 个点；forward dynamics 依赖具备图像生成能力的 UMM，成本较高；大部分 transition 仍来自已有 trajectory，尚未证明自动探索采集能大规模成立；与真实物理世界模型的联系有限。

## Future Work
作者明确提出未来要做大规模自动 transition collection，并探索在无图像生成能力的 VLM backbone 上如何使用受限的 inverse dynamics 或替代 forward objective。

## Rating
创新度评分：3/5 - 把 GUI transition 作为预训练轴的设计清楚，但属于已有 forward/inverse dynamics 思路在 GUI agent 上的系统化应用。
相关度评分：1/3 (Tangential) - 是视觉状态转移/世界模型预训练，但场景是 GUI，和视频/3D/机器人/JEPA 方向只有方法借鉴。

## TL;DR
用GUI状态转移做正反动力学预训练，方法可借鉴但领域偏GUI，可选读。
