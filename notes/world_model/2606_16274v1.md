# GraphWorld: Long-Horizon Planning with World Models for End-to-End Autonomous Driving

## Insight
核心观察：自动驾驶长时规划需要建模 ego 与周围车辆的交互，而像素生成式 world model 对规划不一定高效。GraphWorld 用 ego-centric relational graph imagination 学 latent world state，隐式编码未来交互和安全演化。

## Motivation
E2E-AD 多聚焦短 horizon，复杂交互场景下泛化和安全不足。已有 driving world model 常是视频/布局生成，不能直接改善长时轨迹规划。问题与具身/驾驶 world model 相关。

## Method
动态构建 Ego-Centric Interaction Graph（ECIG），按空间邻近选择关键邻车，通过 cross-node cross-attention 将关系上下文传入 planning queries。World-State-Conditioned Planning（WSCP）学习 ego-centric latent world representation，作为安全感知轨迹规划条件。它不显式多步 rollout，而用 latent state 注入规划。

## Experiment
nuScenes 6s planning、NAVSIM v1/v2、Bench2Drive。nuScenes 表中 GraphWorld 6s L2/碰撞率低于 UniAD、SparseDrive、MomAD、World4Drive 等；消融显示 ECIG 和 WSCP 都提升，二者合用在 NAVSIM/Bench2Drive 指标最好。限制中承认邻居选择固定、world-state 仍单步。

## Value
对自动驾驶 world model 相关，但偏轨迹规划 latent conditioning，不是通用视频/3D 生成。可借鉴“关系图 world state”思想。建议选读。
