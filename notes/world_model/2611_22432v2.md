# Think Once, Act Fast: Cost-Effective Recursive Self-Improvement for Decision Model Harness

## Insight
在文字交互任务中，慢速 LLM 可异步把失败经验编成可复用的规则、状态记忆和一步预测程序，供快速决策模型后续使用；这样可能摊薄 LLM 调用成本。论文以三项文字任务的成功率、延迟与模块消融作经验支持，没有关于世界模型表征或泛化的理论证明。

## Motivation
轻量决策模型响应快但复杂任务表现弱，LLM 单步推理更强却耗时耗钱；已有双系统方案多在低置信度时临时调用 LLM。问题属于通用智能体效率，与用户关注的视频、3D、JEPA/Dreamer 世界模型方向基本无关。

## Method
System-1 用 Jev/StartLux 依据任务、观察、最近历史和检索模块选择合法动作；低置信度轨迹进入异步 System-2 队列。LLM 开发三类 harness 模块：文本操作规则、程序生成的状态转移图记忆、用 Python 对候选动作预测下一状态/奖励/终止的一步“world model”。模块按上下文相关性和成功使用率检索，错误预测触发修订；程序经历史回放和基本精度门槛准入。属于文字环境的 agent 程序合成与检索整合，不涉及视觉生成或潜空间动力学学习。

## Experiment
ALFWorld、文字版 BabyAI、TextCraft 各 200 个训练回合，分别有 ID/OOD 评测；比较单独决策模型、LLM agent、JevHarness 与低置信度委托方案，指标为 SR@1、费用、决策延迟及开发触发数。StartLux-27B/Qwen 在 ALFWorld OOD 达 82.83%，原模型 45.52%；BabyAI OOD 64.0%，去掉 world-model 程序后 36.0%；TextCraft OOD 70.66%，原模型 62.66%。System-1 平均决策 0.08–0.58 秒，LLM agent 为 2.14–15.58 秒；部分模型组合反而退化。附录说明一步预测程序只需约 60% 历史可检验精度、50% 覆盖率即可准入。

## Value
对通用 agent 的异步经验压缩和模块准入有启发，但其“世界模型”是 LLM 生成的文字游戏规则程序，不适合直接作为视频/3D/隐式世界模型研究依据。可跳过。

## Strengths
明确区分在线快决策与异步模块开发；三类模块做了消融；公开了检索、准入、成本与提示模板。

## Weaknesses
评测全是文本任务，缺少噪声视觉观测、连续动作与真实物理；成功率对 System-1/2 模型组合敏感，部分配置下降；世界模型仅一步且用历史精度筛选，未展示长期预测校准。

## Future Work
作者提出改进 harness 开发及双系统协作，并扩展到具身/驾驶等有噪声观测、连续交互和不确定动力学的真实任务。

## Rating
创新度评分：2/5 - 将现有记忆、规则检索和程序化一步预测组合为异步自改进流程，目标领域外的技术突破有限。
相关度评分：0/3 (Noise) - 文字游戏中的规则程序不属于视频、3D 或 JEPA/Dreamer 世界模型。

## TL;DR
以异步LLM编写规则、记忆和一步预测程序辅助文字决策，和目标世界模型方向无实质关联，可跳过。
