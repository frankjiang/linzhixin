# Steering Black-Box Large Language Model Agents with Pitfall Anticipation World Model

## Insight
观察：在文本/网页代理中，每步预测下一观测只能轻微提升成功率；预测到下一子目标的轨迹更有效，而真正改变动作的指导多含失败预警。Claude 分别分类 400 条变更及未变更指导，含陷阱预期的比例为 76.8%/29.0%；只传递这类指导，以 ScienceWorld 44.4%、WebArena-Lite 27.5% 的干预率接近全步指导的成功率（表 1–3，PDF 第 4–5 页）。推论是世界模型应在关键失误前预警、瞄准有意义的多步边界；证据为关联分析及门控消融，不是已证明的普适规律。

## Motivation
API 黑盒 LLM 已擅长一般推理，却缺少特定交互环境的操作经验；既有外部世界模型常逐步模拟候选动作的下一观测，调用多、信息少，过长预测又积累误差。本文研究「什么时候」及「预测什么」才能有效引导冻结代理。对模型辅助决策有间接启发，但任务为文本科学游戏与网页操作，不涉及视频、3D 或 JEPA/Dreamer 表征。

## Method
冻结代理先提出暂定动作；Qwen3.5-27B 基础的 PAWM 读取任务历史和该动作，若无明显陷阱返回 `<pass>`，否则用几句预测潜在失败，代理再决定是否改动作。先三次采样同一训练任务，利用 Claude Sonnet 4.5 对比成功与失败轨迹、标注偏离点；全成功任务标注非致命绕路，全失败任务注入真值指导造出成功对照；其余步标 `<pass>`。下采样通过步以防模型总是沉默。再固定黑盒代理，用任务结果为奖励进行 GRPO 训练 PAWM，使预警与代理实际成功对齐。预警主要是未来后果的自然语言概括，未显示显式状态转移或物理模拟（PDF 第 3、5–7、26–32 页）。

## Experiment
ScienceWorld 测试 271 题、WebArena-Lite 测试 165 题，主要指标为任务成功率 Acc、三次尝试通过率 Pass@3，另分析动作变更率 ACR、干预率 IR 和调用数。Claude Sonnet 4.5 无辅助成功率分别为 54.6±1.9%/72.7±0.6%；PAWM 经 SFT 为 71.4±1.7%/75.0±1.8%，再经 GRPO 达 78.9±0.9%/80.4±1.3%，优于 RAG、预任务指导和不同预测跨度的世界模型（表 4，PDF 第 7 页）。单步下一观测指导仅为 58.5%/73.1%；子目标轨迹优于完整轨迹。通过:预警样本比的消融中，原始不均衡数据使 ScienceWorld 干预率仅 3.2%、成功率 67.2%；重采样到 1:1 后为 26.4%/72.3%（表 5）。跨代理骨干转移有定性收益，但主要收集与协同训练只用 Sonnet 4.5。WebArena 的 GRPO 未给其他基线同等训练，且训练环境将若干规则判分改为 LLM 裁判（PDF 第 8–9、31–32 页）。

## Value
「有条件地预警可能失败的动作」可启发视觉世界模型的自适应调用和预算分配，尤其适合已有强策略、仅偶尔需要模型纠偏的设置。但现有证据只覆盖特定文本交互环境，迁移到视觉物理世界必须重新验证何为陷阱、是否能从可观测状态提前识别。

## Strengths
先通过预测跨度、词汇/语义统计和门控消融定位介入条件，再用成对成功/失败轨迹构造监督并以任务奖励优化；基线和调用成本有较完整比较。报告了不均衡 `<pass>` 标签对预警频率的实际影响。

## Weaknesses
训练依赖昂贵的黑盒代理轨迹、同一系列教师标注及 16 张 B200 的微调；事后标注仍可能泄漏未来信息或引入教师偏见。实验限两类文本环境，WebArena 奖励由 LLM 裁判给出且 GRPO 基线不对称；预警正确率、误报/漏报及模型是否真正学到可泛化动力学尚未单独测量。

## Future Work
作者希望进一步研究面向其他黑盒代理分别协同训练后的差异，并在更多环境验证；局限段指出当前任务特定模型、在线交互成本及合成标注噪声仍待解决（PDF 第 9 页）。

## Rating
创新度评分：3/5 - 基于先导实验明确提出选择性陷阱预期，并结合轨迹对照监督与 GRPO；主要算法仍是现成语言模型指导和奖励优化的组合。
相关度评分：1/3 (Tangential) - 自适应世界模型指导策略有间接借鉴价值，但研究和评测均为文本/网页代理，与目标的视觉、3D、JEPA 或 Dreamer 世界模型无直接技术重合。

## TL;DR
选择性预测代理即将遇到的陷阱可提升文本任务成功率，适合借鉴调用策略，视觉世界模型方向可选读。
