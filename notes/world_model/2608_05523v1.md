# HERA: Historical Evidence Routing Adapter for Physical Prediction in Latent World Models

## Insight
长上下文或缓存历史并不等于具有“物理记忆”：早期物体证据必须在未来预测需要时被选择性取回，且不能扰乱预训练 predictor 的原生 latent workspace。HERA 把存储、检索、整合拆开，以按早期/中段/最近/全局组织的 patch memory 保存证据，专用 Memory Registers 读取，另一组 Workspace Registers 经冻结自注意力整合。IntPhys2 总体提升虽只有 1.78 点，但 fixed-camera immutability 从 46.15% 升至 63.46%，提示“路由接口”可能比单纯增大记忆容量更关键；不过证据仍不足以证明模型形成了持久对象状态。

## Motivation
V-JEPA 2 能预测视频 latent 并支持规划，但物体被遮挡后，预测可能只依赖近期运动或场景统计，并未保持物体存在、属性和身份。长窗口会稀释早期 token，通用缓存不知道何时取用，对象中心记忆又要求稳定分割与关联。论文希望用小型 adapter 把历史 patch 证据注入冻结 V-JEPA 2，并以“违反物理的视频应更令人意外”检验物理记忆。这直接触及隐式视频世界模型的长期状态问题。

## Method
对匹配的 possible/impossible 视频，逐滑窗计算 V-JEPA 2 未来 latent 的平均 L1 surprise；若 impossible 的全视频平均 surprise 更高则判断正确。RRPM 将 context tubelet 按时间角色压成 96 个 anchor、28 个 middle、64 个 recent、8 个 global token。12 个 Memory Registers 在 predictor 第 4、8 block 后通过门控 cross-attention 读取 memory；8 个 Workspace Registers 只参与原有 self-attention，使检索证据在后续冻结 block 内传播。编码器、target encoder 和 12 层 predictor 全部冻结，只训练 3.00M 参数的 memory、register、reader 和 gate，目标仍是普通未来 latent L1 预测，无物体或物理有效性标签。

## Experiment
在 Physion 14,000 条视频上训练，在 IntPhys2 Main 的 506 对 possible/impossible 视频上评估；每条为 48 帧、384×384，时间采样间隔 10。V-JEPA 2-G 基线 pairwise AvgSurprise accuracy 为 52.57%，clip-local、cross-window、hierarchical、shared-register memory 为 52.77%--52.96%，直接注入 memory 且微调更多参数为 53.56%，HERA 为 54.35%。在作者挑出的 Hard、fixed-camera、continuity/fixed、immutability/fixed、solidity 子组中，增益分别为 8.93、8.17、11.54、17.31、8.22 点。低学习率继续训练后完整模型降到 53.95%；从该 checkpoint 去掉任一 register 组为 53.56%，仅差 0.39 点。论文称使用多随机种子，但主表未报告均值、方差或显著性。每个方法乃至每个子组都在预定义 context 集中取最高测试准确率。

## Value
HERA 给出一种参数高效、无需对象标注的历史证据接口，适合冻结大型 JEPA 视频模型；把“存了什么”和“如何让 predictor 使用”分离也可借鉴到生成式世界模型。不过整体准确率仍接近随机，不能据此宣称解决物体恒常性。更有价值的是问题定义：应把长期物理记忆拆成证据保留、身份绑定、按需检索与动态更新，而 HERA 只覆盖其中的 patch-level 检索。

## Strengths
- 以 matched possible/impossible surprise 测物理记忆，避免额外训练分类器或使用 IntPhys2 标签。
- 冻结 V-JEPA 2 主干，仅训练 3M 参数，干预位置明确、部署成本可控。
- 与五种 memory 机制比较，并按连续性、不变性、坚固性等物理原则做诊断。
- Memory/Workspace register 职责分离，减少直接改写 context token 的干扰，架构直观。

## Weaknesses
- 总体仅 54.35%，比 52.57% 高 1.78 点且接近机会水平；没有置信区间/显著性，无法判断小增益是否稳健。
- 对每个方法和子组在测试 context length 上取最大值，会产生选择偏差；应在验证集固定 context 后一次性测试。
- register 去除是在性能已降至 53.95% 的 continuation checkpoint 上做，且差异仅 0.39 点，不能强力支持两个角色缺一不可。
- AvgSurprise 的提升只是行为 proxy，未测早期对象身份是否真的可解码、检索是否指向正确历史 patch，或在规划中是否有用。
- memory 是手工时间分区而非内容/对象寻址，无法稳定处理同类多对象、身份交换或超长非规则历史。

## Future Work
作者建议把 patch 证据扩展成更丰富的结构化状态，并在更广物理场景验证。更关键的后续应包括：验证集固定上下文、报告多种子统计，做检索可解释性与对象身份 probe，测试更长遮挡和多对象绑定，并把物理记忆收益连接到动作条件预测和规划成功率。

## Rating
创新度评分：2/5 - 分离式 register 路由是合理的参数高效改进，但总体增益小、评估选择有偏，未证明持久物理状态。
相关度评分：3/3 (Core) - 直接研究 V-JEPA 2 隐式视频世界模型在遮挡下的物理记忆与未来预测。

## TL;DR
用双 register 路由历史 patch 改善 V-JEPA 遮挡物理预测，思路可借鉴但总体增益小，可选读。
