# DeWorldSG: Depth-Aware 3D Semantic Scene Graph Generation via World-Model Priors

## Insight
Insight 是：3D scene graph 的关系缺失不应只靠单帧几何补全，视频世界模型的时序表征可作为关系先验，但必须在不确定时才注入，避免 hallucination。作者把 object geometry 用 instance-level 3D Gaussian 分布建模，把 relation 用 V-JEPA 2 的 16 帧 union-crop 表征补充，在视觉关系高熵时融合 prior。

## Motivation
机器人和 AR 需要稳定的 3D semantic scene graph 来表达对象和关系。点云/SLAM式 3D SSG 依赖重建质量，2D-to-3D lifting 方法更轻量但受深度边界噪声、单帧关系稀疏、遮挡影响，容易出现节点漂移、重复实例、缺边。问题对 3D世界模型方向相关，但论文目标主要是 3D scene understanding，而不是预测/控制世界模型本身。

## Method
流程三段：先用 RT-DETR/EGTR 等得到逐帧 2D object/relation，再用 SAM mask 和深度进行 2D-to-3D lifting，将对象表示为高斯分布而非单点/box；Dual-Domain Depth Refinement 过滤空间和深度分布噪声，稳定全局 merging。关系增强阶段只保留几何近邻 object pair，构建 16 帧 union crop，冻结 V-JEPA 2 并训练两层 MLP probe 输出 predicate distribution；按 class-pair 时间聚合得到 world-model prior，在视觉关系分布熵高时以 additive fusion 注入。

## Experiment
在 3DSSG 和 ReplicaSSG 上评估 Object Recall、Predicate Recall、Relationship Recall、mRecall。3DSSG 上 DeWorldSG Rel/Obj/Pred recall 为 50.2/75.0/57.3，显著高于 FROSS 的 27.9/62.4/33.0；ReplicaSSG 上相对 FROSS 也大幅提升。消融显示 instance mask、DR、world model prior 均有贡献，V-JEPA 2 比 DINOv2 静态特征略好。无 GT pose 时仍保持较强性能。运行时约 108.5ms/frame，主要开销来自 SAM 和 relation refinement。

## Value
对用户方向的启发在于：世界模型表征可以作为结构化 3D graph 的“关系记忆/先验”，并通过不确定性门控减少误导。创新更多是系统组合，V-JEPA 2 只作为 frozen feature extractor，世界模型本身没有被训练或用于 rollout。局限是依赖 2D detector/segmenter，类别错误会导致节点碎片；关系集合固定，物理预测能力有限。

## Strengths
亮点是对用户方向的启发在于：世界模型表征可以作为结构化 3D graph 的“关系记忆/先验”，并通过不确定性门控减少误导。

## Weaknesses
不足是创新更多是系统组合，V-JEPA 2 只作为 frozen feature extractor，世界模型本身没有被训练或用于 rollout。
