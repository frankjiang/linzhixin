# Unlocking Temporal Generalization in Hamiltonian Video Dynamics Models

## Insight
核心 insight 是：连续时间视频世界模型的跨时间步泛化失败，不一定是表示没学到物理，而可能是数值积分和外力注入的具体故障。Observation：HGN 在训练步长内插表现好，但在更大步长外推时会幅值爆炸或相位漂移。推论是要把 failure decomposition 做清楚：action-force map 不受约束导致 latent magnitude growth；固定步长 leapfrog 积分器欠解析导致 global truncation error。作者用 spectral normalization 和 eval-time substepping 分别修复这两个机制。

## Motivation
Dreamer、JEPA、视频 diffusion world model 等多数模型学习固定离散步长 `z_{t+1}=f(z_t,a_t)`，无法自然查询任意时间分辨率。连续时间模型如 Neural ODE/Hamiltonian networks 理论上可变步长，但 HGN 在非保守、受迫、耗散系统中外推会失败。这个问题对 hierarchical planning、sim-to-real、科学/游戏引擎多帧率查询都重要。

## Method
模型沿用 Hamiltonian Generative Networks：encoder 从 64x64 RGB 帧推断 latent phase state，latent 分成 position `q` 和 momentum `p`；separable Hamiltonian `H(q,p)=T(p)+V(q)` 由 MLP 表示；decoder 只从 `q` 重建图像。

作者加入 port-Hamiltonian 结构处理阻尼和外部 action forcing：
`q_dot = dH/dp`，`p_dot = -dH/dq - gamma dH/dp + G(a)`。积分器是改造的 leapfrog，把 damping 和 forcing 对称放进 momentum half-steps。训练目标是 HGN 的 variational open-loop rollout objective，整个 trajectory 从一次 initial encode 开始滚动预测。

两个修复很简单：对 action-force map `G(a)` 加 spectral normalization，限制每步能量注入；推理时把一个 observation step 拆成 `N` 个 integration substeps，保持总 action impulse 不变，只提高积分分辨率。

## Experiment
实验环境是受迫阻尼 mass-spring oscillator，渲染为 64x64 RGB 视频。训练数据 50,000 条序列，每条 50 帧，训练步长 `dt_train=0.4`。评估步长覆盖 0.05 到 1.5，其中小于训练步长是 interpolation，大于训练步长是 extrapolation。指标为 open-loop rollout 的 MAE、PSNR、SSIM、LPIPS。

主要发现：baseline port-HGN 在 `dt_eval` 小于或等于 0.4 时能稳定插值/复现；超过训练步长后先出现误差和相位漂移，未约束 action map 时还会出现 latent 幅值增长和图像高频伪影。对 `G(a)` 做 spectral norm 后幅值爆炸消失，但仍有相位漂移。推理时 substepping 能恢复外推：`N=2` 明显减小误差，`N=4` 时有效积分步长 `1.5/4≈0.375` 接近训练步长，MAE/PSNR/SSIM/LPIPS 曲线在大步长区域基本恢复。作者据此判断外推失败主要来自 global truncation error，而不是 learned Hamiltonian 本身失效。

## Value
这篇对视频世界模型方向很相关，价值在诊断视角而非大规模性能。它提醒我们：如果声称世界模型是 continuous-time 或 physics-aware，必须区分表示失败、能量注入失败和积分器误差；评估时也不能只看固定帧率 rollout。对 JEPA/Dreamer 类 latent dynamics 的启发是：可变时间尺度不是靠训练一个 next-step predictor 自动获得的，需要模型结构和数值求解共同保证。

## Strengths
- 失败分解清晰，把幅值爆炸和相位漂移分成两个可检验机制。
- 修复有针对性，spectral norm 和 substepping 分别只作用于对应故障。
- 明确区分 interpolation 和 extrapolation，指出外推才更能检验 continuous-time structure。
- 讨论了 Dreamer、JEPA、视频生成世界模型固定步长的共性限制。

## Weaknesses
- 实验只在单一低维 mass-spring oscillator 上，视觉和动力学复杂度都低。
- 缺少与 Dreamer/JEPA/video diffusion 等实际世界模型的直接对比。
- 修复中的 substepping 增加推理成本，复杂系统下步长自适应、刚性动力学和多接触场景仍未知。
- 论文图中以曲线展示指标，正文没有给完整数值表，效果量不够便于复核。

## Future Work
作者建议连续时间视频生成要对 learned forcing 做约束，并在目标步长超过训练步长时使用推理期 substepping。进一步值得扩展到更复杂视觉场景、多体碰撞、控制任务、可学习/自适应 ODE solver，以及与 latent JEPA/Dreamer dynamics 的结合。

## Rating
创新度评分：2/5 - 诊断有价值，但核心修复是 spectral normalization 和 substepping，实验范围较窄。
相关度评分：3/3 (Core) - 直接研究视频 dynamics/world model 的时间泛化和连续时间 latent dynamics，是核心相关。
