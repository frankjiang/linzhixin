# MetaWorld: Scaling Multi-Agent Video World Model from Single-view Video Data

## Insight
多智能体视频世界模型的核心瓶颈是多视角数据稀缺和跨视角物理一致性；可以通过从单视角视频中分解多智能体运动状态、并在生成过程中用跨分支注意力同步去噪来解决。

## Motivation
现有视频世界模型限于单智能体/单视角。扩展到多智能体面临两个挑战：(1) 协调的多视角录制数据极其昂贵（open-domain场景几乎不存在）；(2) 独立生成的视频流无法保证共享物理世界的一致演化。先驱工作（Solaris/MultiWorld）依赖游戏引擎的程序化同步，无法泛化到开放域。

## Method
### 1. Monocular World-State Unrolling (MWSU)
- 从标准单视角视频中分解出相机运动 c_i（观察者）和可见主体的空间轨迹 τ_j（被观察者）
- 自然提取共享3D空间中的同步多智能体运动数据
- 数据引擎：MoGe-2提取相机运动 + SAM 2追踪主体 + Depth Anything估计深度 → 重建全局3D轨迹

### 2. Subject-Aware World Generator (SAWG)
- 基于 **Phantom-Wan2.1 14B DiT**
- 三阶段条件注入：
  - **Geometric State Rendering**：将3D背景和轨迹渲染为RGB+Depth条件视频
  - **Subject-Location & Geometry Grounding**：VAE编码RGB+Depth条件，zero-init特征压缩网络注入
  - **Subject-Appearance Anchoring**：ID参考图像通过VAE编码，沿时间轴拼接到latent

### 3. World-State Alignment (WSA)
- **逐帧跨分支cross-attention**：在每个transformer层插入
- Branch i的tokens attend Branch j的同帧tokens（严格限制为within-frame pairs，防止时间泄漏）
- Zero-initialized输出投影，保持预训练模型的生成先验
- 训练时双智能体双向交叉注意力
- **推理时cyclic attention拓扑**：O(N)而非O(N²)扩展到N个智能体

## Experiment
- 基于32×H20 GPU训练，480P 81帧视频
- **Full-3D场景**：CVC 0.8454（最优），Trajectory Consistency 0.9752（最优）
- **Partial-3D场景**：CVC 0.7549（最优），Trajectory Consistency 0.9694（最优）
- 显著优于VerseCrafter（身份一致性好但跨视角一致性差）和MultiWorld（画质低、对齐差）
- 消融验证WSA、Depth Video、背景建模策略、zero-init各自的重要性
  - w/o WSA: CVC从0.8001降至0.7358
  - w/o ZeroInit: 全面性能下降约20%

## Value
**首个开放域多智能体视频世界模型**，问题定义和解决方案都很清晰。MWSU从单视角视频挖掘多智能体数据的思路优雅地绕开了数据稀缺问题。WSA的逐帧跨分支同步机制设计合理。但目前仅处理双智能体场景的训练（推理时可扩展到N），真实复杂场景的泛化性有待验证。

## 创新度评分
3 — 多智能体视频世界模型的问题定义有开创性，MWSU和WSA是清晰的技术贡献。但核心构件（DiT+cross-attention同步）均为已有技术的巧妙组合。

## 相关度评分
3 — 视频世界模型的前沿方向拓展（多智能体），与视频世界模型研究高度相关，代表了该领域的自然演进。

## TL;DR
MetaWorld首次实现开放域多智能体视频世界模型。通过MWSU从单视角视频分解多智能体运动数据解决数据稀缺，SAWG基于Wan2.1 14B DiT实现身份可控生成，WSA逐帧跨分支cross-attention保证物理世界一致性。CVC和轨迹一致性显著优于VerseCrafter/MultiWorld。
