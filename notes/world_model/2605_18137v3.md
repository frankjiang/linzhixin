# Xiaomi Auto World Model: A Joint World Model Integrating Reconstruction and Generation for Autonomous Driving

## Insight
重建和生成是自动驾驶世界模型的两个互补能力，将两者深度耦合形成闭环：3D重建提供确定性几何锚点抑制生成漂移，生成模型补偿未观测区域弥补重建的外推缺陷。两个关键技术观察：(1) 现有 feed-forward 3DGS 的逐像素 DPT head 产生 ghosting 和冗余，sparse query 聚合可避免；(2) 因果扩散模型从头训练缺乏先验且慢，双向预训练+渐进因果微调（TF->ODE蒸馏->DMD）可兼顾质量与效率。

## Motivation
自动驾驶世界模型中重建与生成长期割裂：重建方法无法外推至未见视角/时步，生成方法几何一致性差且长时漂移。需要统一框架同时具备精确3D场景表示和可控长时视频生成能力，服务闭环仿真、数据合成和端到端训练。

## Method
三大模块：
1. **WorldRec**（稀疏查询3D重建）：在世界坐标初始化 N 个 sparse 3D query，投影到多视角多时步特征图采样，通过 visibility-aware 加权融合聚合为 scene token，MLP 解码为 3DGS 属性。相比 DPT head 的逐像素预测，消除 ghosting/冗余，Gaussian 数量大幅减少。10秒clip重建约10秒（vs 传统优化数小时）。
2. **WorldGen**（两阶段DiT视频生成）：
   - Stage 1 双向预训练：rectified flow + 全时序注意力，学习全局时空分布
   - Stage 2 渐进因果微调：Teacher Forcing（因果mask转换）-> ODE蒸馏（50步->4步，~12x加速）-> DMD（用模型自身生成作为历史context，消除exposure bias）
   - 条件信号：多视角首帧、layout map、ego轨迹、相机参数、文本描述
3. **Joint World Model**：
   - WorldRec 增量重建（scene fusion）：新观测 token 通过 cross-attention 与已缓存 scene token 融合，支持渐进扩展4D场景
   - WorldGen rendered-RGB conditioning：将 WorldRec 场景渲染到目标视角作为额外条件，为未观测区域提供几何脚手架
   - 闭环：重建锚定生成、生成补偿重建

## Experiment
- **WorldRec**：Waymo PSNR 28.48 / SSIM 0.861，nuScenes zero-shot PSNR 26.54 / SSIM 0.821，全面超越 DGGT、STORM 等 SOTA
- **WorldGen**：nuScenes FID 7.04 / FVD 64.97，81帧（远超多数方法8-16帧），0.19s/frame（H20 GPU），支持最长1分钟30fps生成
- **Joint WM**：三维度定性验证——长时时序一致性（35s+无漂移）、多视角空间一致性、多次运行稳定性
- 缺乏 Joint WM 的定量消融（无 JWM vs 单独 Rec/Gen 的数值对比）

## Value
小米自动驾驶团队的工业级技术报告，系统完成度高。核心架构（sparse query重建 + 双向预训练因果微调生成 + 增量融合闭环）的设计合理且工程可行。WorldRec 的 sparse query 设计和 WorldGen 的三阶段因果微调流程（特别是DMD解决exposure bias）值得参考。但各模块单独看更多是已有技术的精心组合（3DGS feed-forward、DiT、ODE蒸馏、DMD均非新提出），且 Joint WM 缺乏定量消融实验，说服力打折。v3相比v2无本质变化，主要为文字修订。
