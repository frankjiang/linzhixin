# Macro Control and Capability Evaluation of Black-Box World Models: A Two-Regime Framework for LLM-Agent Markets

## Insight
观察：单看价格路径拟合分数，分不清模拟器是在跟随公开目标、受结构限制，还是确实利用了新闻等信息；加入新闻还会稀释目标的绝对跟踪分数。推论：应先用真实/翻转目标的共同得分测可实现性，再在信息注入条件下比较两者的差值。论文以成对干预和分数敏感性实验说明这一点，但没有证明该差值是纯粹的信息利用量。

## Motivation
现有 LLM 多智能体市场常按历史相似度或交易表现评价，难以审计仅暴露宏观输入/输出的黑盒。问题对金融仿真有意义，但不是视频、3D 或 JEPA/Dreamer 世界模型的核心问题。

## Method
每天向市场公布一条公开参考价格，保持代理决策和撮合机制不变。以真实路径及围绕 1000 翻转的路径做成对实验；跟踪指标 Q 平均了振幅得分和 Spearman 形状得分。仅在无额外信息的“参考路径”条件下解释共同水平 R=(TSR+FSR)/2 和成对偏差 B；加入基本面/新闻后只比较真伪参考的差值 Δ。创新主要是黑盒干预与评测协议，不是新的动态模型。

## Experiment
在 TwinMarket、DeepSeek-Chat、5 个中国行业指数和单个 51 交易日窗口上运行；改变初始持仓比例、技术/基本面代理比例及新闻注入。参考路径使真目标得分由 0.6115 升至 0.9180（无新闻）；70/30 持仓的 R=0.8943、B=0.0418。加入基本面时 Δ=0.0341，再加入新闻为 0.0487，但绝对真/翻转分数下降。附录中改用收益率形状分数后，新闻效应反号（表 14）。

## Value
“输入干预—成对反事实—分离可实现性与信息利用”的评测思想可迁移到黑盒世界模型审计；市场中的价格分数与视觉/动作动力学之间没有直接技术迁移。

## Strengths
明确指出绝对拟合分数在信息条件改变后不能跨条件解释；报告平凡基线、成对分数和指标敏感性。

## Weaknesses
仅一套市场模拟器、一个 LLM、五个指数和一段短窗口；目标是评价者注入的价格路径，不是真实预测。Δ 的增量很小且对得分定义敏感；高跟踪分也可能只是复述公开参考。

## Future Work
作者未列出明确后续方案；按其局限，应在更多市场、模型和时间窗口中验证，并设计能区分复述参考路径与真实信息利用的控制。

## Rating
创新度评分：1/5 - 黑盒成对评测有一定巧思，但领域和技术均远离目标世界模型方向。
相关度评分：0/3 (Noise) - 研究 LLM 金融代理市场，不涉及视频、3D 或隐式视觉/控制世界模型。

## TL;DR
用真实与翻转价格目标审计黑盒金融代理市场，评测思路可借鉴但与目标方向无关，可跳过。
