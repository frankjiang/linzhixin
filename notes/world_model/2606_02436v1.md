# Geometry-Aware Implicit Memory for Video World Models

## Insight
核心观察：
1. 现有视频世界模型的记忆机制（无论显式/隐式）都未显式约束记忆编码跨视角的场景几何结构。显式记忆（帧检索/3D 重建）受启发式选择和重建误差影响；隐式记忆虽紧凑但训练信号仅来自外观重建，导致记忆存储的是冗余的外观信息而非紧凑的世界状态。
2. 几何应该作为被记忆的世界的属性编码在记忆状态中，而非仅作为生成器的附加信号。

推论：设计一个 camera-queryable 的几何监督头，在训练时从冻结的 3D 基础模型（VGGT）蒸馏场景几何到隐式记忆中，推理时丢弃几何头和 3D 教师，保留轻量记忆模块。

证明：在 MIND benchmark 上，GIM-World 的 3D 重投影一致性分数（81.70/87.10）远超最强基线（73.97/70.82），同时记忆一致性也最优，且推理仅增加 0.26% 的 DiT 计算量。

## Motivation
- **问题**：视频世界模型的长时 rollout 面临几何一致性退化——重访区域外观不一致、前进/后退轨迹场景结构不匹配、新视角与已建立结构矛盾。
- **同行方案**：
  - 显式记忆（Matrix-Game 2.0、MIND-World、FramePack、CaM）：保留历史帧或 3D 缓存，但受检索启发式、存储冗余、重建误差影响
  - 隐式记忆（VideoSSM）：紧凑状态但无几何约束，仅靠生成损失训练
  - 几何注入方法（Geometry Forcing、VideoGPA 等）：将几何信号施加于生成器而非记忆
- **关键性**：长时几何一致性是视频世界模型能否支撑具身智能、游戏、持久仿真的核心能力，且现有方案均不令人满意。

## Method
**GIM-World 三大组件**：

**1. 隐式记忆编码器（Sec. 3.2）**：
- 输入：历史帧的 VAE patch token + 相机嵌入 E_c(c_i)
- N_m 个可学习 memory query Q_0 与历史 token 拼接
- 两层 compact self-attention + FFN 块：attention 分支用 s=2 的空间池化降低计算，FFN 保持全分辨率
- 输出前 N_m 个 token 作为记忆 m，沿时间轴拼接到目标 latent 上作为 DiT 条件
- 记忆大小固定，不随历史增长；推理增加不到 DiT 的 0.3% 计算

**2. Camera-Queryable 几何监督头（Sec. 3.3，仅训练时）**：
- 训练时随机采样历史帧 i 及其相机 c_i
- 将 c_i 转为逐 patch 的世界空间射线查询 q_{i,u,v} = MLP_ray(ρ(c_i)) + e_{u,v}
- 几何头：CrossAttn(q, m) -> SelfAttn -> FFN -> 预测 VGGT 特征图 Ĝ_i
- 监督：与冻结 VGGT encoder 特征 G_i 的 per-patch cosine loss
- 推理时丢弃几何头和 VGGT，零额外推理成本

**3. Information-Guided Pruning（Sec. 3.4）**：
- 长历史中相邻帧高度冗余，编码成本随历史线性增长
- 用 Gaussian Process 建模帧间相似性核（位置、朝向、时间的 RBF 核）
- 贪心最大化互信息选择保留子集 S（预算 K=200）
- 确保保留帧在位姿-时间空间中信息量最大化

**训练**：单阶段端到端，L = L_FM + λ·L_geo（λ=0.05），Wan2.1 骨干，8K steps

**创新程度**：将几何约束施加于记忆状态（而非生成器）是关键创新点，camera-queryable 设计优雅，训练-推理解耦（训练时用 3D 教师，推理时零成本）是很好的工程设计。

## Experiment
- **数据集**：MIND benchmark（UE5，100 first-person + 100 third-person clips，50/50 split）
- **指标**：
  - Memory Consistency：MSE、PSNR、SSIM、LPIPS
  - Action Accuracy：Translation/Rotation RPE
  - 3D Geometric Consistency：归一化重投影分数（Depth Anything 3 + cross-frame cycle reprojection）

- **主实验**（Table 1）：
  - GIM-World vs 显式记忆最强（CaM）：重投影 81.70 vs 69.17（FP），87.10 vs 70.82（TP），大幅领先
  - GIM-World vs 隐式记忆（SSM）：重投影 81.70 vs 53.95（FP），全指标领先
  - Memory consistency 四项指标均为最优或次优

- **消融实验**：
  - 几何监督（Table 2）：无几何 58.80，Geometry Forcing 63.40，Ours 81.70（重投影分数）
  - 历史剪枝（Table 3）：MI greedy 全指标最优（81.70），优于 Uniform（77.05）和 Camera FPS（77.52）
  - Compact Attention（Table 4）：s=2 是最优 trade-off（0.26% DiT 时间，81.70 reproj），Full attention 仅提升 MSE 但慢 10x+

- **定性结果**（Fig. 3-5）：
  - 基线在 100 帧内就出现结构崩塌，GIM-World 400 帧仍保持一致
  - 千帧 rollout（Fig. 5）：600+ 帧间隔的两个近视角仍保持细节一致

## Value
**工作价值**：高。提出了一种将 3D 几何知识蒸馏进隐式记忆的优雅框架，在长时几何一致性上取得了显著突破，且推理零额外成本。是视频世界模型记忆设计的重要进展。

**对我们的启发**：
- "几何应编码在记忆中而非施加于生成器"这一设计哲学值得借鉴——记忆应该存储世界状态，而非仅为生成提供外观参考
- Camera-queryable 的训练-推理解耦范式（训练时蒸馏，推理时丢弃教师）可推广到其他模态的世界模型
- Information-guided pruning 基于 GP 的互信息选择是处理长历史冗余的通用方案
- 隐式记忆 + 几何监督的组合可能是视频世界模型走向 3D 一致性的最佳路径

**待解决问题**：
- 仅在 MIND（UE5 合成场景）上验证，真实世界场景的泛化性未知
- 动态物体的几何一致性未专门评估（MIND 主要是静态场景导航）
- 记忆容量有限（N_m 个 token），对极大规模场景的表示能力存疑
- 与其他几何注入方法（如 geometry-as-context）的互补性未探索
