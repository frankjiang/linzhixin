# Hybrid Neural World Models

## Insight
多 horizon 训练的 neural surrogate 隐式编码了不连续性位置信息：比较 horizon T 的单步预测与 T/2 的两步链式预测的分歧（step-doubling），可在无标签情况下定位 shock/front/contact。原理：真实流满足半群性质 Φ_{T} = Φ_{T/2} ∘ Φ_{T/2}，multi-horizon 训练驱使 surrogate 逼近该性质，分歧自然集中在不连续处。

## Motivation
Neural surrogate 在 PDE/ODE 物理动力学中提供巨大加速但在 shock/front/contact 等不连续事件处静默失败。核心问题：如何在没有 ground truth 的推理时检测 surrogate 不可靠的区域？现有方法（deep ensemble、conformal prediction）要么需要多个网络要么需要校准集。

## Method
- **Multi-horizon shortcut surrogate**：单个网络 f_θ(s, T) 预测任意 horizon T 的未来状态，用 FiLM conditioning 编码 T，直接监督回归
- **Error map**：ê(s,T) = ||f_θ(s,T) - f_θ(f_θ(s,T/2), T/2)||₂，无额外训练、无标签、无校准集
- **Mode 1**：纯 surrogate，最大吞吐（26-72x CPU speedup）
- **Mode 2**：error map 门控，高风险轨迹交给 reference solver，低风险保留 surrogate 预测
- 验证环境：Oregonator（反应扩散）、Euler 2D（可压缩流）、Ball 3D（刚体碰撞）

## Experiment
- Step-doubling AUROC 中位数 0.76（53/54 cells > 0.5），优于 deep ensemble (0.77 但需3x网络)、conformal prediction 等
- Mode 1：PDE 环境 26-72x 同硬件 CPU 加速
- Mode 2：q=0.75 时 RMSE 减半，保留 ~3x 有效加速
- 局限：Ball 3D far-OOD 时 AUROC 降至 0.44（碰撞累积误差不再与步长敏感度关联）

## Value
step-doubling error map 是一个优雅且实用的不确定性估计方法，但整体工作聚焦于 PDE/ODE 物理仿真加速，与视频/3D 世界模型方向无关。error map 的思想理论上可迁移到 latent world model 的可信度评估，但论文未讨论。
