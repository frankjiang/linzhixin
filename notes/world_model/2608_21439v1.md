# WorldMind: Decoupled Game World Model for State-Aware NPC Behavior

## Insight

观察是：端到端游戏视频世界模型能生成动作后果，却不擅长长期维护 NPC 的技能、冷却和战术状态；纯语言决策又缺少视觉闭环。作者把几何理解、显式技能状态、LLM 决策、控制信号和视频生成拆层，发现仅替换技能文字描述即可让同一冻结 LLM 在 80.2%–87.0% 的测试中改变行为，说明紧凑、可编辑状态接口比让生成模型隐式吸收规则更利于 NPC 控制。闭环偏好结果支持系统可用性，但因评测主观且基线不等价，不能证明每层均必要。

## Motivation

现有交互式游戏世界模型主要优化视觉和动作响应，NPC 常表现为被动纹理，难以遵循技能规则或随状态改变策略；传统行为树又需手工编程。论文希望把“理解世界”和“渲染世界”解耦，让通用 LLM 依据可读游戏状态控制 NPC，再由视频模型呈现后果。状态一致的多智能体视频世界是核心相关问题。

## Method

四层系统：L1 用 ResNet-18+GRU 从连续三帧预测几何/二值状态，并由确定性 tracker 维护技能、冷却等紧凑状态；L2 冻结 Gemma-4-E2B-it，读取状态、技能描述和冷却，滚动选择首个动作并做规则检查；L3 将动作与移动转换为 direct/director 文本控制；L4 以 BOSS-140K 微调 Wan2.2 TI2V-5B，结合 causal forcing 与 DMD 蒸馏约 70k 步，以约 20 FPS 生成闭环视频。BOSS-140K 含 144,631 个片段、超过 200 小时、14 个 boss，来自一个私有 Game A 及 Hollow Knight、The Binding of Isaac，并记录引擎状态、玩家输入、动作和描述。

## Experiment

L1 在三个游戏上的距离/相对误差/角度误差及两个二值准确率分别为：Game A 0.312/2.9/12.66°/0.807/0.702，Hollow Knight 0.444/6.7/2.96°/0.772/0.996，Isaac 8.187/8.4/29.38°/0.904/0.839，仅报告单 seed。L2 干预测试各有 200/200/121 例，交换技能描述后行为改变率 83.5%/87.0%/80.2%；遵循新机制为 69.0%/73.5%/79.3%，保持旧行为仅 16.5%/13.0%/19.8%。完整闭环只在 Game A 做约一分钟、12 次决策的案例，以 GPT-5.5 和 Gemini 3.1 各评三遍：WorldMind 相对隐式基线偏好约 71.5%/69.8%，相对显式基线约 70.9%/70.3%；有效动作约 74.0%/77.6%，序列得分约 3.85/4.00，对照约 3.2。L4 没有 FVD、动作遵循率或长时漂移等客观生成指标。

## Value

论文提供了一个清晰系统范式：显式状态供推理、生成模型负责呈现，规则可通过文本更新而无需重训渲染器。对视频世界模型尤其有启发的是将 NPC 策略与像素动力学分离，并保留可编辑的技能状态。尚待验证的是，在强客观基线和公开多游戏环境中，这种分层是否真的优于简单的 oracle state + LLM 或行为树。

## Strengths

涵盖数据集、状态估计、语言决策、控制和实时视频闭环，接口可解释且技能描述可直接干预。L2 使用成组反事实机制测试，不只看自然行为；BOSS-140K 同时保存像素、引擎状态和动作，具备训练多层模型的潜力。

## Weaknesses

完整闭环只在 Game A 的一个短序列上展示，依赖 GPT/Gemini 主观裁判，无人类评测、样本规模说明或引擎真值指标。显式/隐式基线没有等价的状态感知决策器，比较同时改变了策略与表示，无法归因于解耦架构。L4 未报告 FVD、身份保持、动作控制精度和长时稳定性；跨游戏泛化只有模糊描述，无完整数值。L1 仅单 seed，约 20 FPS 未说明硬件/延迟。私有 Game A 被模糊处理，数据访问性和可复现性有限，也缺少行为树、启发式策略及 oracle-state LLM 强基线。

## Future Work

作者未明确列出集中式未来工作。合理推断应加入人类盲评和引擎级动作/状态指标，比较 oracle-state LLM、行为树与等条件视频基线，在多个公开游戏做长时闭环，并报告生成漂移、身份一致性、实时硬件成本及失败恢复。

## Rating

创新度评分：3/5 - 分层状态感知 NPC 世界模型的系统设计有新意，但模块多为现成组件，完整闭环证据偏弱。
相关度评分：3/3 (Core) - 直接研究状态化 NPC 决策与可交互视频游戏世界模型。

## TL;DR

把游戏世界模型拆成状态理解、NPC决策、控制与视频生成闭环，系统新颖但评测偏主观，可选读。
