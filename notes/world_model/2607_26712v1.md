# ActSWM: Action-Sensitive World Models for Long-Horizon Planning in Open-World Games

## Insight
论文的核心 insight 是 Context Collapse：latent world model 可以在未来状态相似度上看起来预测很好，但对不同动作序列不敏感，导致规划时候选动作的 imagined futures 难以区分。推论是，世界模型不仅要预测未来 latent，还要让替代动作的 rollout 保持可分，并让局部 transition 中的动作可恢复。

## Motivation
长程 MPC 依赖世界模型比较不同动作序列的后果。已有 LeWM/JEPA 式方法侧重 latent prediction 和 anti-collapse，但预测准确不等于可规划，尤其在 Minecraft/open-world game 中，模型可能把上下文惯性当成未来而忽略动作。这个问题对游戏和交互式视频世界模型很关键。

## Method
ActSWM 在 LeWM 风格多步 latent prediction 上加入两类 action-sensitivity 约束。第一是 rollout-level hinge：同一上下文下，用真实未来动作和全零动作 rollout，要求二者 latent 序列的 cosine similarity 至少拉开 margin。第二是 transition-level fixed readout：随机初始化并冻结的 action readout 从相邻 latent transition 恢复动作，反向迫使 encoder/predictor 把动作信息写进 transition。完整目标还保留预测损失和 SIGReg。

## Experiment
实验包括三组。第一，Minecraft VPT 离线 step-drift 分析中，ActSWM 在保持高 GT rollout similarity 的同时，让真实动作和 zero-action rollout gap 达到 0.760，而强 LeWM baseline gap 接近 0。第二，MineStudio 闭环规划中，ActSWM 在 place torch/mine stone/build pillar 上分别达到 20/20、19/20、17/20，明显高于 LeWM 的 19/20、10/20、11/20。第三，CS/GTA/Apex 视频上做 local action recovery，ActSWM 通常提高 action-dependent gap 和部分 key accuracy，但 active accuracy 在不同游戏上有波动。

## Value
这篇对 latent 世界模型很有启发：模型可规划性需要动作敏感性，不能只靠未来 latent 的重建/相似度评价。对我们做视频/游戏世界模型，Context Collapse 是一个值得加入评测的失败模式。问题是方法仍较启发式，固定随机 readout 的理论解释有限。

## Strengths
亮点是指出了“预测准但不可规划”的具体机制，并用 zero-action 对照给出清晰诊断；训练约束简单，能直接接到 LeWM 类模型；有闭环 Minecraft 规划验证。

## Weaknesses
不足是零动作对照不一定覆盖复杂动作混淆；闭环任务规模和 trial 数有限；跨游戏 action recovery 指标不完全稳定；没有和更强视频生成式世界模型做充分比较。

## Future Work
作者没有展开很多未来方向。自然后续是把 action-sensitivity 评估扩展到更复杂动作空间、真实机器人或更强视频世界模型，并研究比 zero-action 更系统的反事实动作采样。

## Rating
创新度评分：3/5 - 失败模式定义和训练约束有价值，但方法仍是 LeWM 框架内的针对性增强。
相关度评分：3/3 (Core) - 直接研究动作条件 latent/game world model 的可规划性。

## TL;DR
指出latent预测可准但动作不敏感，并用rollout分离修复，值得精读。
