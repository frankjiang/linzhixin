# HGWM: Hierarchical Graph-Guided World Model for Zero-Shot Object Navigation via Graph Matching

## Insight
目标类别本身不提供实例位置，但可以先生成“可能房间—锚物—关系”的假设，再以沿途 RGB-D 观测校验各方向。论文在 HM3D v0.2 的组件删除中发现，去掉目标先验或关系修订均使成功率下降 2.3 个百分点；这是经验支持，不是图匹配必然优于语言提示的证明。

## Motivation
零样本目标导航要在目标不可见时选择搜索方向，同时记住跨视角证据。现有 VLM 打分、语义地图或场景图方法容易重复探索，单一目标类别也难直接做关系匹配。问题与持久空间记忆相关，但本文所谓“世界模型”是符号导航状态，不学习动作条件动力学或生成未来观测。

## Method
- Qwen2.5-7B-Instruct 根据目标类别生成可能房间、替代房间、锚物和连接关系，作为假设；RGB-D、位姿和物体描述写入持久的空间语义图，假设节点与实际观测分开保存。
- Gemini-1.5-Pro 为六个全景朝向给出 0–10 分及场景描述；按房间、物体、空间关系、语义和深度五类启发式特征，将观察图与先验图匹配成 0–1 的细分数，并用 LLM 修订关系。
- 按匹配强度切换探索、聚焦搜索、目标核验三阶段，将粗分、细分和 LLM 推荐加权、裁剪后写入好奇度地图；局部规划器选可行位移。权重与阈值是人工设定，分数不是概率。创新是把类别扩展成关系假设并显式注入逐方向评分，而非新型 3D 动力学模型。

## Experiment
- Habitat 静态场景 HM3D v0.1、MP3D 上评估目标导航成功率 SR 和路径长度加权成功率 SPL。相对 WMNav，HM3D v0.1 从 **58.1/31.2%** 升至 **62.6/31.5%**，MP3D 从 **45.4/17.2%** 升至 **46.8/17.9%**；SPL 增益很小，基线结果取自原论文且模型设置不同。
- HM3D v0.2 上，无记忆 VLM、体素记忆加直接打分、完整 HGWM 为 **67.8/29.3、70.9/30.1、74.4/31.9%**（SR/SPL）；去先验、关系修订、LLM 裁决、适应性细权重使 SR 分别下降 **2.3、2.3、1.7、0.9** 点。该对照同时改变多个环节，不能把完整增益全归于图匹配。
- 换用 Gemini 2.0 Flash 时 HM3D v0.1 SR 从 62.6% 降至 59.2%；主配置三次运行 SR 范围 62.3–62.8%，SPL 31.2–31.7%。VLM 单次调用约 2.3 秒，图更新 12–25 毫秒，未测完整导航延迟。

## Value
对 3D 世界模型研究，可借鉴把“先验预测”和“观测证据”分库存储，以及按方向查询空间记忆的接口；若目标是学习可滚动的 3D/视频动力学，本工作参考价值有限。需要更严格的等调用预算、同模型、同决策规则的图与体素记忆比较。

## Strengths
明确区分假设与观测；主结果外提供组件删除、模型骨干敏感性和导航轨迹；承认 SPL 增益有限、匹配分数未校准以及实验归因边界。

## Weaknesses
图特征、阈值和融合权重依赖手工规则及 VLM/LLM 判断；物体误检与错误低分会在记忆中累积。主要基线并非统一复现；没有配对显著性、统一推理成本、动态场景或真实机器人验证。它不预测未来状态，严格说并非学习型世界模型。

## Future Work
作者建议做只改变显式匹配分数的控制实验、匹配预算下比较图/体素记忆，测关系修订错误和重复访问；进一步检验传感器与定位噪声、非常规房间、动态物体、时间图更新及真实机器人部署。

## Rating
创新度评分：2/5 - 已有场景图、语言先验和 VLM 导航的启发式组合，增益中等且组件归因有限。
相关度评分：2/3 (Related) - 持久空间语义记忆可供 3D 世界模型借鉴，但没有学习动力学或未来观测生成。

## TL;DR
以房间—锚物先验匹配 RGB-D 图记忆改善零样本导航，但无生成式世界动力学；研究空间记忆可选读。
