# E3DGS: Unified Geometric-Photometric Equivariance for 3D Gaussian Splatting via Color-as-Geometry Embedding

## Insight
核心 insight 是 3DGS 的 view-dependent color 不应被当作普通信号丢弃或展平，而可以当作几何对象处理。Observation 是几何属性按 Rmu、RSigmaR^T 变换，SH 外观系数按 Wigner-D 变换，导致等变网络难以统一处理；但 SH degree 0/1/2 与 gl(3) 在 conjugation action 下的 V0/V1/V2 分解同构。推论是可用显式 intertwiner 把 SH(0-2) 嵌入 3x3 矩阵，使几何和光度都统一按 M -> RMR^T 变换。作者给出 Theorem 1/2/3 证明，并在 3DGS perception 和 Gaussian world model 中验证。

## Motivation
论文解决 3D Gaussian Splatting 下游学习中的表征瓶颈：为了实现 SE(3) equivariance，现有 ShapeSplat/SceneSplat/ManiGaussian 等常丢弃或只保留 SH0，损失材质和视角相关外观；若直接拼接高阶 SH，则旋转下不等变，泛化崩溃。对 3D 世界模型和 Gaussian scene representation 很关键，因为 world state 不只有几何，还包括随视角变化的 appearance。

## Method
E3DGS 先做 Unified Matrix Embedding：covariance 用 log(Sigma) 嵌入 Sym(3)，centered position 用 hat map 嵌入 so(3)，每个颜色通道的 SH(0-2) 用 Phi<=2 嵌入 gl(3)，opacity/SH0/任务语义走 invariant scalar branch。Backbone 使用 ReLN 风格 Ad-equivariant operations：ReLN-Attention 用 modified Killing form 构造旋转不变 attention score，ReLN-LayerNorm 用 Frobenius norm 归一化矩阵通道，FFN 用 invariant-gated ReLN nonlinearities。任务头中，分类通过 Killing-form contractions 得到 invariant readout；动力学预测则从输出矩阵取 skew part，再 vee 回 R3 作为 Gaussian mean offset。创新点集中在 color-as-geometry 的表征理论和 3DGS 实例化。

## Experiment
Object recognition 在 ShapeSplat/Gaussian-MAE pipeline 上评估 ModelNet10/40 的 ID/ID、ID/SE(3)、SE(3)/SE(3)。ModelNet10 中 Gaussian-MAE ID/SE(3) 仅 18.28，加入 SH(0,1,2) 后降到 12.89；E3DGS-MAE SH(0,1) 在三种 split 均 95.26。ModelNet40 中 Gaussian-MAE ID/SE(3) 3-7 左右，E3DGS-MAE SH(0,1) 三种 split 均 93.17。低数据 finetune 下 E3DGS 更稳。ShapeNet Part 中 E3DGS 对 SH(0,1,2) 保持 80.81/80.81 mIoU，而 baseline transformed 降到 29.52。RLBench/ManiGaussian 上，E3DGS 平均成功率 50.4，高于 ManiGaussian 44.8，在 sweep to dustpan、put in drawer、open drawer 等刚体/关节任务更强，但 close jar、stack blocks 较弱。参数更少约 2.4-2.6x，但 GMACs 更高。

## Value
对 3D 世界模型很有价值。它给出一种严谨方式把 3DGS 中的几何和光度放进同一个等变 carrier，避免“为了等变而丢外观”的常见折中。对 action-conditioned Gaussian world model、3D scene representation、机器人 manipulation 的 pose generalization 都有直接启发。

## Strengths
数学 insight 清晰且有证明；直接处理 3DGS 高阶 SH 的旋转问题；实验覆盖分类、分割、重建稳定性和机器人 world modeling；对比显示非等变 baseline 在旋转测试下严重崩溃，结论很鲜明。

## Weaknesses
gl(3) 轻量 carrier 只覆盖 SH<=2，3DGS 常用 SH3 需更大 carrier，尚未实证；等变矩阵运算显著增加 GMACs，不一定低延迟；机器人实验只改 Gaussian dynamics 中部分状态，covariance/SH 仍 carried over unchanged；contact-heavy 和长程堆叠任务仍弱。

## Future Work
作者提出将 Theorem 2 的更大 End(Vk) carrier 用于更高阶 SH，实证评估 SH3 及以上；也隐含需要提升与 dynamics 的耦合，尤其是外观/协方差随动作变化和 contact-heavy manipulation。

相关度评分：3/3 (Core) - 直接研究 3DGS 世界状态表征、3D 等变学习和 action-conditioned Gaussian world modeling。
