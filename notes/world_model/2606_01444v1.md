# Self-Revising Discovery Systems for Science: A Categorical Framework for Agentic Artificial Intelligence

## Insight
无直接与世界模型相关的 insight。论文核心观察是：科学发现不仅是在固定表示空间中搜索更好的答案，更重要的是改变表示空间本身（regime transition）。用范畴论中的 copresheaf 和 Kan extension 将"在固定 schema 内搜索"与"扩展 schema"形式化区分。

## Motivation
- **问题**: 现有 agentic AI 科学发现系统擅长在固定表示中优化（检索、搜索），但无法形式化描述何时需要改变表示本身（引入新类型、新操作、新验证器）。
- **同行做法**: 现有 AI for science 系统（ProtAgents、SciAgents、ScienceClaw）缺乏对"发现=改变 schema"的形式化。
- **关键性**: 对 AI for science 社区有意义，但与视频/3D 世界模型方向无关。

## Method
- 用范畴论建模科学发现系统：schema category S_b 定义 artifact 类型和操作，copresheaf I_t: S_b -> Set 存储当前 artifact 状态
- 固定 regime 内的更新是 endofunctor Phi_b
- 发现（regime transition）是 schema 变换 u: S_b -> S_{b'}，通过 left Kan extension 迁移旧 artifact
- 两个实例化：(1) Builder/Breaker 蛋白质力学模型（MDL gate）; (2) CategoryScienceClaw 科学工作流系统

## Experiment
- Builder/Breaker 案例：在蛋白质 B-factor 预测上，经过 4 轮迭代发现了 mode-conditioned compliance 规律
- 非标准 ML 实验，无对比/消融，更像是框架的案例验证

## Value
- **工作价值**: 对 AI for science 和 agentic AI 系统设计有理论参考价值，但与视频/3D 世界模型方向完全无关。
- **启发**: 无直接启发。
- **待解决**: 框架高度抽象，工程落地困难。
