# ECHO: Terminal Agents Learn World Models for Free

## Insight
核心观察：在终端agent的RL训练中，每一次action都会产生环境反馈（stdout、stderr、日志、trace等），这些observation token已经进入了模型的前向计算，但标准GRPO只在action token上施加policy gradient，完全浪费了这些密集的监督信号。特别是在稀疏二值奖励下（<15%的rollout成功），绝大多数trajectory被视为"无用"——但即使失败的trajectory也包含丰富的环境动态信息（构建错误、stack trace、文件内容等）。将环境反馈从"上下文"重新定义为"训练目标"，等价于让policy同时学习一个终端环境的world model，且几乎零额外计算开销。

## Motivation
问题：终端agent的RL训练面临严重的信号稀疏问题——GRPO依赖稀疏的任务级二值奖励，成功率低时大部分rollout没有policy gradient信号。现有方案（专家SFT初始化、teacher model蒸馏）依赖外部数据或额外模型。作者认为rollout本身已包含丰富但被忽视的监督信号——环境observation token。

## Method
**ECHO (Environment Cross-entropy Hybrid Objective)**：在标准GRPO的action-token policy gradient loss基础上，增加一个对environment-observation token的next-token prediction交叉熵损失：

L_ECHO = L_GRPO(A) + λ * L_Env(O')

关键设计选择：
- **零额外开销**：复用GRPO已有的前向传播，仅改变loss mask——在action位置施加policy gradient，在observation位置施加交叉熵，无需额外rollout、teacher模型或第二次前向传播
- **目标选择**：只在terminal-output token（`<command_output>...</command_output>`内的内容）上计算env loss，排除harness的warning前缀（低熵模板，约60步就被记住，梯度无意义）
- **损失权重**：λ=0.05，按总observation长度归一化。λ过大（≥0.1）会与policy目标竞争导致退化。常数λ具有自然退火效果——随模型学会终端统计规律，L_Env自动下降
- **on-policy特性**：observation target来自当前policy的rollout，随策略改进自动演化，形成自进化课程

## Experiment
**基础模型**：Qwen3-8B、OpenThinker-Agent-v1-SFT (OT-SFT)、Qwen3-14B，在8770个终端任务上训练500步GRPO

**核心结果**：
- TerminalBench-2.0 pass@1几乎翻倍：Qwen3-8B 2.70→5.17，Qwen3-14B 5.17→10.79
- 内部评测（val100、ITD、TBLite）全面提升，所有模型/所有评测集一致
- 达到GRPO峰值的训练步数减少1.5-2.3倍
- 推理效率提升：Qwen3-8B在TB2上timeout率降55%，turn数减18%，token数减30%

**世界模型验证**：在off-policy trajectory（Qwen3-32B生成）上测量env-token交叉熵，ECHO大幅降低而GRPO几乎不变——说明ECHO确实学到了可迁移的终端动态知识

**替代专家SFT**：从base Qwen3-8B出发，ECHO在内部评测上完全恢复了expert-SFT的增益（101.6%/103.9%/88.9%），在TB2上恢复约50%，且不需要~15k专家示范

**无验证器自适应**：仅用L_Env（无任何奖励信号），在in-dist任务上仍能提升+3.8pp，OOD任务（过滤clean tool-call trajectory后）提升+5.2-10.0pp

## Value
**方法价值**：提出了一个极其简洁的辅助损失设计——仅通过改变loss mask就将"被丢弃的环境反馈"转化为"密集监督信号"。思路优雅，实现简单（几行代码改动），效果显著且一致。无验证器自适应实验尤其有趣——纯粹通过预测环境反应（无任何奖励）就能改善策略，这是"prediction implies understanding"假说在agent RL中的有力验证。

**与视频/3D世界模型的关系**：本文的"世界模型"是纯文本的终端环境动态模型，与视频/3D/隐式世界模型在模态和应用上完全不同。但在方法论层面有间接启发：(1) 辅助预测损失（auxiliary prediction loss）作为表征塑造手段的思路与Dreamer/JEPA系列一脉相承——本质都是通过预测环境下一状态来学习世界理解；(2) "失败trajectory也包含有用信号"的洞察可迁移到视频世界模型的RL训练中。
