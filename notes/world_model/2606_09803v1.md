# Echo-Memory: A Controlled Study of Memory in Action World Models

## Insight
**Observation 1**: Replay指标（PSNR/SSIM/LPIPS）不能反映世界模型是否真正"记住了世界"——Spatial Memory在replay上最佳但open-domain return最差，block-wise State-Space replay较弱但return最强。replay只衡量轨迹跟随能力，不衡量场景回访一致性。

**Observation 2**: 现有记忆方案的性能提升往往混杂了backbone/训练策略/评估方式的差异，难以公平比较。

**推论**: (1) 评估世界模型记忆需要三分支协议（replay + in-domain return + open-domain return）；(2) Spatial Memory高效但非语义记忆——存储不等于可访问；(3) 隐式循环（state-space）的结构化设计比显式存储更能保持语义一致性。

**证明**: 在统一backbone/训练/评估下，对Context、Compression、Spatial、State-Space四大记忆家族进行受控对比。

## Motivation
- **问题**: action world model中记忆机制的设计空间庞大，但现有方案难以公平比较——不同工作使用不同backbone、训练配方、评估指标
- **同行方案**: Spatia/VMem（空间记忆）、FAR/Framepack（压缩记忆）、RAD/VideoSSM（状态空间记忆）、CaM/StoryMem（上下文记忆）等
- **关键性**: 记忆是世界模型从"生成视频片段"到"维护可回访世界"的核心能力，但缺乏标准化的理解框架

## Method
**Echo-Memory不是新方法，而是受控研究框架**:

**统一基础设施**:
- 固定backbone（Video DiT + per-frame VAE）
- 固定动作接口（12维relative-RT camera action）
- 固定训练配方（5k steps, AdamW, 81帧/段, 352x640）
- 仅改变记忆模块的存储/压缩/读取方式

**四大记忆家族**:
1. **Context**: 直接拼接K=1/5/20历史帧的VAE latent
2. **Compression**: token加权或时序长度压缩
3. **Spatial**: 构建3D场景摘要（如点云），可选不同read-out方式
4. **State-Space**: 通过循环状态（legacy hybrid或block-wise SSM）隐式携带历史

**三分支评估协议**:
1. **Replay**: GT轨迹下的PSNR/SSIM/LPIPS
2. **In-domain Return**: GT支持的180度回环，像素+VLM评分
3. **Open-domain Return**: 用Qwen Edit生成的hold-out首帧，45度来回，VLM语义评分

## Experiment
**核心发现**:

| 记忆家族 | Replay PSNR | Open-domain VLM |
|---------|-------------|-----------------|
| Spatial | **13.60** | 6.00 |
| Context K=20 | 12.54 | 58.63 |
| State-Space (block) | 9.59 | **69.00** |
| Compression | 8.65 | 22.38 |

- **Finding 1**: Open-domain return是最具区分力的记忆测试，replay不足以评估记忆质量
- **Finding 2**: Spatial Memory高效但不等于语义记忆——inject-none（不注入存储token）反而replay更好，说明存储可作为正则化
- **Finding 3**: 压缩需保留return-critical evidence，混合压缩可能破坏关键身份信息
- **Finding 4**: Block-wise State-Space的结构化循环是目前最强的open-domain return机制

**Spatial Read-out消融**: 专用cross-attention read-out提升O-V从6.00到17.12，但仍远低于Context和State-Space

## Value
- **工作价值**: 高。这是一篇重要的系统性研究，提供了公平比较记忆机制的框架和三个有价值的insight
- **启发**: (1) 评估世界模型记忆不能只看replay/视频质量，必须测试回访一致性；(2) Spatial Memory的瓶颈在read-out而非storage；(3) 隐式循环记忆可能比显式存储更适合维护世界语义
- **待解决**: 仅测试camera-conditioned场景（非robotics action）；State-Space的replay质量仍需提升；框架可扩展到更多记忆设计

## TL;DR
对action world model四大记忆家族的受控对比研究，揭示replay指标不等于记忆质量、spatial memory高效但非语义记忆、block-wise循环状态最强——值得精读，对记忆机制设计有重要指导。
