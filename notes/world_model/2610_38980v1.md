# Context Compaction for World Models

## Insight
回访画面相似可能来自真正调用历史、训练集记忆或局部线索推断，不能只凭重访一致性判断记忆。作者用每次随机新造的房间排除训练集重构，再以「保留最近 5 步、打乱更早历史」后的准确率差定义上下文检索增益；实验显示外部上下文压缩可延伸 128 步窗口至 511 步回访，而带滑动窗口注意力的模型在输入自身预测画面后检索显著崩溃。证据限于小型格子世界。

## Motivation
长时视频世界模型离开再回到旧场景时容易变形。现有工作主要改模型内部 KV 缓存/记忆模块，常把输出相似性混同于真实检索。为评估记忆机制，隔离检索、推断和训练记忆，并研究无需重训的外部历史选取，是关键问题。

## Method
- 构造 8×8 房间格子，每个房间由 16×16 的 8 类图块组成，动作是跨门移动；每轮随机新世界，训练/测试种子隔离。每步编码为 8 个图块 token 加 1 个动作 token，训练约 1,400 万参数、8 层的 Decoder-only、CED、CED-SWA、DD 四种模型。
- 同一重访样本比较正常历史准确率 α_oc 与早期历史替换为另一世界、只留最近五步的 α_sc，差值作为检索增益；另以超过原始窗口的重访作阴性对照。
- 外部 agent harness 依据动作知道格子坐标，只保留每房间最新画面，再规划经过已访问房间且终于当前位置的短路径，重排成模型熟悉的合法行走序列。可每步压缩或窗口满时压缩，不更改模型权重。
- 对照模型层 KV 缓存设计，并区分读真实历史与「dreaming」：回访时把模型之前生成的画面重新放入历史。创新重点是评测隔离和外部上下文管理。

## Experiment
- 5,000 个 512 步训练 episode、400 个测试 episode、三种子；每个 1–7 至 256–511 步的 gap 桶抽 40 次回访。比较原始窗口、等长截断、两种压缩策略，另测固定 KV 内存与固定 128 步上下文、回访自生成画面的影响及延迟。
- 128–511 步 gap 上原始窗口的检索增益仅 0.03–0.06；每步压缩为 0.39–0.51，满时压缩为 0.44–0.54；等长截断仍近零。固定 2,304 个 KV 向量时，DD 可容 128 步，Decoder-only/CED 仅 16 步、CED-SWA 32 步。
- 固定 128 步窗口，DD 的 64–127 步检索增益约 0.39，对 Decoder-only 约 0.54。回访画面参与后续预测时，Decoder-only/CED 保持 0.28–0.42，CED-SWA/DD 降至 ≤0.09；作者未证明崩溃机理。满时压缩平均约每 50 步一次，延迟最低。

## Value
对长程视频世界模型的记忆设计和评测值得精读：既要看同等内存的覆盖范围，也要看同等上下文的检索精度，以及自生成帧反馈后的退化。外部历史调度可作为无需重训的基线，但真实场景须先可靠识别位置和重访关系。

## Strengths
把检索与局部推断/训练记忆分离；含负对照与等长截断对照；系统比较模型内缓存、外部压缩、自生成反馈和推理延迟。

## Weaknesses
只有一个高度结构化的玩具世界和约 1,400 万参数模型，不能直接外推至连续相机视频/物理交互；harness 已知精确格子位置，省去了真实 3D 场景定位与回环检测；dreaming 仅在回访时进行、最长环 128 步；打乱对照保留的五步可能仍含重访房间，压低检索增益。

## Future Work
作者指出需测试更大模型与多种世界、超过窗口长度的自生成回访，以及连续相机运动场景中的位置识别和上下文压缩。

## Rating
创新度评分：3/5 - 提出针对世界模型的外部上下文压缩与检索隔离基准，系统实验扎实但环境简化。
相关度评分：3/3 (Core) - 直接研究交互视频世界模型的长程记忆和回访一致性。

## TL;DR
随机新世界和打乱历史隔离真实检索，外部压缩延长回访记忆但滑窗模型自生成后退化；值得精读。
