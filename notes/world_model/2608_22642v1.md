# Mol-JEPA: A multimodal Joint Embedding Predictive Architecture for Molecules

## Insight

观察是分子性质存在 activity/property cliff，删原子、删键等“轻微”结构增强可能改变真实语义；同时仅看结构无法表达细胞环境、结合、ADMET 等上下文。论文据此把增强从“扰动分子”改为“整模态遮蔽”，要求模型由其余模态预测被遮蔽模态的 latent，并用 SIGReg 保持表征各向同性、防止 collapse。全模态模型相对仅 Graph+ECFP 的探针 MAE 降低 13%–14%，且 target-side SIGReg 最稳定，为该设计提供经验支持；这不是关于时序世界动力学的证明。

## Motivation

分子自监督学习常受无效增强、contrastive negative 选择、模态塌缩和生化上下文缺失影响，预训练模型也未必稳定超过传统 descriptor。论文希望把结构、物理模拟、细胞表型、结合、活性与 ADMET 统一到可扩展 JEPA 中，并在小数据和分布外药物性质预测上获得更好表征。药物发现问题本身重要，但与视频/3D/控制世界模型的研究目标相距较远。

## Method

- 汇总 ChEMBL、TDC、PCBA-1328、∇²DFT 和 Enamine REAL，去重后得到 469 万分子；构造 14 个稀疏且部分配对的模态，包括 UMA、ChemGPT、CLOOME、BioXMol、Boltz-2、GNN、MOE/ECFP、xTB/DFT 和实验活性/ADMET 向量。
- Atom、Graph、Vector 三类可学习 encoder 把各模态投到 512 维。以比例 0.3 随机整模态遮蔽，至少保留一个可用模态；约 50M 参数的 Transformer 根据可见 token 和 modality positional encoding 预测遮蔽 embedding，并产生 CLS readout。
- 训练损失是各被遮蔽模态的 embedding MSE，加权 λ=0.7 的 SIGReg。SIGReg 用 1024 个随机一维投影和 Epps-Pulley statistic 约束 target embedding 近似各向同性高斯；论文发现正则 predicted embedding 会 collapse，正则 target 最好。
- 下游使用 CLS 的线性/非线性/TabICLv2 探针、各模态 token 的两层 Transformer 聚合器，或 rank-16 LoRA。主模型用 12 张 RTX 6000 Ada 训练约 3 天、150 epochs。
- 技术核心是“masked modality prediction + 现有 LeJEPA/SIGReg”的直接多模态扩展，主要贡献更偏数据集和系统规模，而非新的 JEPA 学习原理。

## Experiment

- 在 ExpansionRx 9 项、ASAP/Polaris 7 项、PXR 1 项、Biogen ADME 6 项上，用 Tanimoto 0.65 的 Butina cluster 构造 3 个 train/test splits；比较 RF、LightGBM、TabICLv2、Chemprop、CheMeleon、CLAMP。指标包括 MAE、R²、paired Wilcoxon + FDR，以及按训练集相似度分桶的 OOD 误差。
- Table 3 中按任务挑选最佳 Mol-JEPA probe/embedding variant 后，23 项平均 MAE 为 0.402；固定 multimodal Transformer probe 为 0.427，TabICLv2+AlvaDesc 为 0.453，CheMeleon 0.471，Chemprop 0.519。平均 R² 的对应最好结果为 0.42，TabICLv2 为 0.37。
- 优势并非一致：按 Wilcoxon 显著胜出的 pairwise 比例，Mol-JEPA 为 38%，TabICLv2+AlvaDesc 为 47%；在官方 temporal/public splits 上，TabICLv2 的 Wilcoxon 和 MAE win rate 更高，而 Mol-JEPA 的 R² win rate 更高。
- 模态扩展实验在 10 万分子、单 GPU、300 epochs 下，从 2/4/8 模态约需 9/13/27 小时，平均下游 MAE随模态增加改善。全 469 万数据的受控比较中，全模态相对 Graph+ECFP 使线性/非线性 probe MAE 分别下降 14%/13%。
- 10 万子集消融：JEPA 的 linear/nonlinear MAE 为 0.436/0.393，semi-supervised 替代为 0.467/0.417，移除实验模态为 0.449/0.407；SIGReg on CLS 为 0.445/0.406；增加 projection head 退化至 0.468/0.488；维度 256→512 明显改善，1024 无进一步收益。
- OOD 分析显示相似度越低误差越高；pretraining coverage 越充分的 benchmark 越好。CKA 中量化化学模态、细胞表型模态分别成簇，ChEMBL/TDC 与其他模态相似度较低。

## Value

对我们的直接价值有限，但有两个可借鉴点：无法定义语义保持增强时，可把“缺失的另一种观测”当 JEPA prediction target；对稀疏异构模态，防 collapse 机制应按模态检查而不能只看全局 loss。论文把静态分子属性预测称为 world model，但没有时间、动作、状态转移、闭环 rollout 或规划，因此不应与视频/Dreamer 世界模型的能力混同。

## Strengths

- 数据规模大、模态覆盖广，既含结构和人工 descriptor，也含物理模拟、表型、结合与实验信号。
- benchmark 不只用随机 split，而采用 cluster split、官方 temporal split、OOD 相似度分析和 FDR 校正的配对检验。
- 报告负面结果：部分模态会降低性能、LoRA 较差、稀疏模态优化不稳、官方 split 上 TabICLv2 在多项 win rate 更强。
- 提供多类 probe、模态/容量/正则消融、CKA 和数据 scaling，工程分析较丰富。

## Weaknesses

- 核心任务是静态分子多模态 representation learning，不预测时间演化或候选动作后果；“molecular world model”更多是宽泛命名，不能证明世界建模或控制能力。
- `Mol-JEPA (Best)` 对每个任务从多个 probe 和 embedding variant 中取最好值，带有 oracle 选择优势；固定 Transformer 结果 0.427 明显弱于 best 0.402，且若无独立选择集会高估泛化。
- 模型蒸馏多个强预训练模型、商业 descriptor 和昂贵量化/结合计算的输出，却缺少同数据、同算力下的通用 multimodal fusion、masked autoencoder 或 contrastive baseline，难把增益归因于 JEPA objective。
- 多数架构与模态消融只在 10 万样本上完成，作者也承认这可能改变结论；full-scale 仅做有限的全模态对 Graph+ECFP 比较。
- 部分测试 split 极小，例如 ASAP 的某些 test 仅 13–55 个样本，方差较大；没有系统报告预训练库与全部下游 benchmark 的 exact-molecule 去重，coverage 与潜在重叠的界限不够清楚。
- OOD 误差随预训练距离升高，说明所谓泛化仍高度依赖 chemical-space coverage；官方 split 上传统 TabICLv2 的显著性/MAE 胜率更高。

## Future Work

作者明确提出：建模模态之间不可恢复的依赖并设计更高级 masking；检验对新分子、新任务和新分布的稳健性；理解稀疏度、维度、信息量和冗余如何影响多模态训练并改进模态选择。作者还指出可扩展到材料、生物等科学域。若从我们方向推断，真正升级为世界模型还需引入时间、干预/动作和闭环预测；这是本评审的推断，不是论文已承诺的路线。

## Rating

创新度评分：2/5 - 大规模分子多模态数据与系统实现有价值，但方法主要是整模态遮蔽加既有 SIGReg，且“world model”能力没有被建立。

相关度评分：1/3 (Tangential) - 使用 JEPA 式 latent prediction，可作隐式表征学习旁证；但属于静态药物性质任务，与视频、3D及动作条件世界模型仅间接相关。

## TL;DR

以整模态遮蔽和SIGReg学习分子多模态表征，但无时序世界动力学，仅作JEPA旁证，可跳读。
