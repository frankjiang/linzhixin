# DeltaWAM: Change-Centric Visual Foresight via Delta Tokens for an Efficient World-Action Model

## Insight
观察：机器人操作连续帧共享大量静态背景，动作策略真正需要的是物体和手如何变化。作者把当前稠密 DINO 特征作空间锚点，把未来 DINO 差分压成每视角每步一个 token；同设置动作消融中差分条件成功率 92.8%，解码回完整未来 DINO 为 79.0%，仅当前 DINO 为 73.9%。这支持变化表征对该策略更有效，但不能证明单 token 对所有精细接触任务信息充分。

## Motivation
视频式世界行动模型预测整帧昂贵，普通潜变量预测仍反复携带静态场景；只给单个目标又缺少时间动态。需要既有测试时未来预见、又能低延迟闭环控制的隐式世界行动模型。

## Method
沿用 DeltaWorld 的冻结 DINOv3 与差分 tokenizer，把相邻帧的 patch 特征差压为 768 维 token，预测器按时间自回归输出未来变化。新增冻结 T5 指令编码及零初始化 Gated AdaLN，让原先无条件的 DeltaWorld 预测朝任务目标变化。第一阶段用 Kinetics 预训练模型、Best-of-Many 候选最小 Smooth-L1 训练预测器；第二阶段冻结它，用当前 DINO patch 空间锚点和预测 delta 序列经分层 KV adapter 条件化 flow-matching Action DiT。训练动作策略时以 0.5 概率选与真值最接近的 8 条未来分支之一，其余随机；推理只抽一条，十步 Euler 生成 16 步动作、执行 8 步后重规划。变化 token 本身来自前作，本文创新主要在任务条件化与行动耦合。

## Experiment
LIBERO 四套任务平均 92.8%（Spatial/Object/Goal/Long 为 92.6/97.0/95.8/85.8）；强预训练 WAM 通常 95%–98.6%，因此优势主要在效率：总参数 0.725B、可训练 120.3M，A100 上每动作块 142.1 ms、峰值 3.86 GB，训练约 256 H100 GPU 小时。LIBERO-Pro 任务逻辑扰动平均 17.85%，Fast-WAM 7.1%，但绝对值仍低。LIBERO-Plus 相机/机器人/光照/布局扰动为 66.9/62.5/84.2/64.1%。完整未来 DINO 替换 delta 降 13.8 个百分点；零未来 token 的已训练策略成功率为 0%，表明强依赖预测。预测 8 步而非 6 步成功率 90.0% 对 92.8%，反映长时误差。实机 PiPER 仅有拾放案例可视化，未报成功率。

## Value
对隐式世界模型很有启发：表示可显式分解为“当前空间锚点 + 未来变化”，并在策略执行时保留快速未来推演。下一步需保住精细接触几何、减小多步差分误差，并在真实机器人上做量化闭环评测。

## Strengths
- 未来预测确实在推理时条件化动作，且有当前特征、完整未来特征、未来 token 数的直接消融。
- 同时测计算量、动作块延迟和多类分布偏移，效率主张可核验。
- 任务条件化修正了原 DeltaWorld 无条件未来可能偏离指令的问题。

## Weaknesses
- 核心 delta tokenizer 与世界模型基于先前 DeltaWorld，方法新意主要在接入动作模型。
- 标准 LIBERO 落后于较强 WAM，长任务精确放置易偏心；LIBERO-Pro 虽领先仍仅 17.85%。
- 策略训练用最接近真值的未来分支，推理只抽单条，存在训练/推理落差；实机缺量化对照。

## Future Work
作者未明确列出后续计划；文中错误分析提示需减少长时差分滚动误差并恢复精细接触所需的局部空间信息。

## Rating
创新度评分：3/5 - 将已有变化 token 世界模型改造成任务条件化的实时世界行动模型，并有有力表征消融；核心编码思想并非本文首创。
相关度评分：3/3 (Core) - 直接研究隐式未来表征、世界模型滚动与动作生成的耦合。

## TL;DR
DeltaWAM用当前DINO空间锚点加未来差分token驱动快速动作生成，表征消融明显但精细接触仍弱；值得精读。
