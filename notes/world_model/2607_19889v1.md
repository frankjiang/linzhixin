# LAVIFT: Latent-Action-Guided Vision Fine-Tuning for Surgical Interaction Recognition

## Insight
核心 insight 是把 latent action bottleneck 用作视觉编码器微调的结构约束：如果 FWM 只能通过低维 action token 从当前状态预测下一状态，编码器就被迫保留真正由动作引起的 instrument-tissue 变化，而不是背景或无关运动。作者进一步观察到过强压缩会让 transition variance 坍缩到少数方向，因此用 patch-level SIGReg 恢复局部特征多样性，使主导变化方向更落在交互区域。

## Motivation
外科 action-triplet recognition 需要识别 instrument-verb-target 交互。传统分类器闭集泛化弱；VLM/视觉编码器有语义迁移能力，但 frozen encoder 可能保留噪声且定位弱，full fine-tuning 又容易只优化全局语义而不保证交互区域 grounding。已有外科方法常依赖轨迹、pseudo-label 或区域监督，代价高且偏 instrument。本文尝试用无需区域标注的 latent action/world model 目标，提升细粒度交互识别和空间表征质量。

## Method
LAViFiT 使用 8 帧 clip。视觉编码器产生每帧 patch tokens 和 pooled state；Delta-IDM 输入连续状态差 delta=s_{t+1}-s_t，经小 Transformer 和 da=128 bottleneck 得到 latent action；DiT-style FWM 以当前 state 和 action 为条件预测下一 state，并用 stop-gradient target 防止状态坍缩；Aggregator 将 states 和 actions 拼接，经 Transformer 得到 clip embedding，再与 EmbeddingGemma 文本 triplet/component embedding 做余弦对齐。训练 loss 包括 triplet/component BCE、forward prediction、state/action SIGReg，以及随机采样 patch tokens 的 patch-level SIGReg。创新主要是把 latent action + forward world model 从控制/动作发现迁移到 VLM fine-tuning 的表征约束。

## Experiment
数据集为 CholecT50 和 ProstaTD，指标为 triplet mAPIVT 以及 instrument/verb/target mAP。主结果中 LAViFiT-SurgeNet-L 在 CholecT50 达到 mAPIVT 18.50，在 ProstaTD 达到 27.51，优于 DINOv2、V-JEPA2/2.1、TimeSformer 和多个 surgical VLM。以 ViT-L 为例，CholecT50 mAPIVT 从普通 CLIP fine-tuning 的 13.85 提升到 17.22；ProstaTD 从 20.02 提升到 23.58。消融显示去掉 IDM/FWM 的下降明显大于只去掉 patch SIGReg；inference 去掉 action tokens 也会降分。机制分析用 CH score 衡量 patch cluster separability，用 transition covariance 的 PR/entropy rank/d90 衡量压缩，用 top eigen-subspace 与 SASVI instrument-tissue mask 的 IoU 衡量 grounding；full model 在三种编码器上都提升 IoU，SurgeNet 从 0.111 到 0.181。

## Value
对世界模型方向的价值在于说明 latent action/world-model objective 可以作为视觉表征微调的可解释 inductive bias，而不只用于控制或视频生成。它提示动作瓶颈、下一状态预测、局部 anti-collapse regularization 可以组合用于改善 action-relevant grounding。局限是任务是外科识别而非通用视频世界模型，world model 只是辅助训练目标，没有做长 horizon 生成或闭环规划。

## Strengths
问题定义具体，方法把 IDM/FWM、文本对齐和 patch regularization 结合得较自然；不仅报告 mAP，还做了 covariance rank、CH、IoU 和 action dimension 的机制分析；跨一般视觉编码器和 surgical pretrained encoder 都有结果。

## Weaknesses
整体仍是下游识别 fine-tuning，创新依赖现有 latent action/FWM/SIGReg 思路的组合。收益在强 encoder 上较小，mAP 绝对值仍不高。交互区域 mask 主要用于分析且来自外部 SASVI；超参敏感，作者也承认 end-to-end world-model-style objective 调参成本高。没有证明 latent action 学到可执行动作或真实因果控制。

## Future Work
作者提出未来扩展到 pretrained video encoders、长时程视频理解和大规模 web surgical video pretraining，并探索更高效的超参优化和更稳健的 regularizer。

## Rating
创新度评分：3/5 - 将 latent action/FWM 用于外科 VLM 表征微调有一定新意，机制分析充分，但核心技术多为已有模块组合。
相关度评分：2/3 (Related) - 使用 latent action 和 forward world model 约束视频表征，对视频/机器人世界模型有借鉴，但主任务是外科交互识别。
