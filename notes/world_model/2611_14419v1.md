# Evaluating LLM-Generated World Models for Neuro-Symbolic Reasoning

## Insight
观察：LLM 生成的部分可观测随机博弈（POSG）可以通过严格的可执行性检查，却改变参与者、可用动作及后果。推论是机械有效性不能代表对原情境的忠实建模；下游规划器再正确，也只能优化错误的状态转移图。9 个参考博弈中 134/135 个生成模型通过机械审计，但平均结构 F1 仅 0.366，精确匹配 28/134；这是经验支持，而非理论证明。

## Motivation
自然语言情境若需支持规划、可达性或安全推理，必须转成形式化状态—动作模型；现有 LLM 生成 PDDL／代码世界模型的研究常重视能否执行。开放多智能体情境可有多种合理形式化，因此需要分别检查“能运行”“结构是否相符”“语义是否合理”。问题对形式化规划重要，与视频、三维、JEPA/Dreamer 世界模型仅有评测思想上的间接联系。

## Method
构造 10 个手工玩具环境（检验评估器）、9 个有参考 POSG 的博弈、11 个情境案例及 14 个文化情境。提示 5 个 LLM 输出 JSON 或 Python POSG；按三层检查：Lane 1 审计状态/动作覆盖、转移概率、可达性等；Lane 2a 对有参考的模型作角色、状态、动作置换对齐并展开至 3 步，计算覆盖率、精确率、F1，另以无参考图统计诊断；Lane 3 用预定义的应包含／应避免规则做自动语义检查。作者设计了人工标注协议，但本次**尚未实施**。方法贡献在多维评测组合，而非新的世界模型学习算法。

## Experiment
- 3 个 LLM 生成轨道共 410 个首次输出：博弈 135、情境 135、文化 140。Lane 1 通过数分别为 134、104、125；博弈平均置换不变结构 F1=0.366，只有 28/134 个有效模型与参考完全一致。
- 博弈轨道各模型覆盖率普遍高于精确率，表明常加入额外结构；示例 G6 无依据扩大竞价等级，候选图增至 101 状态。情境轨道平均特征 F1=0.432，多数模型反而漏掉结构。两轨道的 F1 定义和参考来源不同，不可直接横比。
- 文化轨道只更换地点标签，4/5 模型的结构 F1 降低（Qwen 下降 0.144），而自动语义分数变化很小。每模型—情境—条件仅 1 个样本，地点变化是否构成偏见仍未有人类评定。
- 附录暴露评估口径问题：手工玩具样例因更细状态分支被结构评分扣分；正文文化语义 checklist 的 133/140 与表 1 的 136/140 不一致；DeepSeek 地点对照的一侧使用其他模型均值锚定，不能视作独立配对结果。

## Value
对本方向有一条可迁移的评测原则：世界模型需检验行动后果、可达集合及决策质量，不能仅凭生成合理性或代码能运行。本文场景全为离散符号 POSG，未评估视频/三维状态预测，也未测下游规划性能，适合作为评测视角的补充。

## Strengths
明确拆分可执行性、结构忠实度和语义；保留首次生成与修复结果的区分；对人工语义验证尚未完成、地点差异尚不足以认定偏见有自我限定。

## Weaknesses
案例量小且手工构造；3 步展开和参考模型的粒度选择会误伤合理形式化；语义规则未经人工验证；正文与表格统计不一致；未直接证明结构差异会改变最终规划/安全指标。

## Future Work
作者提出执行双人盲化语义标注并测标注一致性，使用双模拟等价替代固定步数结构匹配，以及直接比较生成模型上的规划策略、可达性与赋权度量。

## Rating
创新度评分：2/5 - 将已有机械、图结构和语义检查组合为符号世界模型基准，结论有用但技术新意有限。
相关度评分：1/3 (Tangential) - 研究对象是 LLM 生成的离散符号博弈，仅评测原则可间接借鉴。

## TL;DR
对410个符号世界模型的评测发现可执行不等于结构忠实；可借鉴多层评测思路，但与视频及三维模型距离较远，可选读。
