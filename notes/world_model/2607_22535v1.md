# Robot-Factored World Models via Robot Rendering

## Insight
有。核心 observation 是：机器人视频世界模型里的动作影响可以拆成两部分，先是机器人本体如何按控制器运动，再是场景如何响应这段几何运动。直接把动作向量喂给视频模型，会迫使模型同时学习机器人运动学、相机投影和接触后果；用 logged state 又会把未来交互结果泄漏进条件。论文的推论是：只使用部署时可获得的 nominal trajectory，并把它渲染成机器人几何条件，可以给模型一个更接近视频先验的动作表达。实验中 nominal 渲染虽然低于 oracle logged-state 条件，但明显优于原始 action / state vector 条件，并支持跨机器人泛化。

## Motivation
论文解决机器人世界模型中“动作如何条件化视频生成”的问题。已有做法常用低维 action/state 向量、末端位姿或轨迹热图；这些条件要么空间对齐弱，要么绑定具体 embodiment，要么依赖数据集中记录的未来状态，无法用于真实部署。这个问题关键，因为世界模型要用于反事实预测、规划和策略评估时，动作条件必须既可部署又能表达机器人几何。

## Method
整体管线是：动作序列先经过机器人控制器/运动学得到 nominal joint trajectory，再用 URDF 和相机标定把机器人本体渲染成未来每帧的 RGB mesh；同时加入末端执行器深度、静态场景 RGB/depth，作为 latent video diffusion model 的条件。主干使用 SVD 和 Wan2.1-Fun InP 变体，文本 prompt 不提供未来动作语义，避免语言泄漏。

关键技术细节包括：区分 raw action、nominal state、logged state 三种条件；用 robot RGB mesh 表达本体几何，用 EEF depth 强化接触相关空间信号，用 scene depth 保留静态场景结构。创新主要在 action interface 和 robot/world factorization，不在扩散主干本身。

## Experiment
实验在 DROID 和 RoboCasa-GR1 上进行：DROID 约 41,642 clips，RoboCasa 约 9,380 clips，81 帧、480x832、16fps。指标包括 PSNR、SSIM、LPIPS，并做了 action 条件、深度条件、logged/nominal 组合的消融。

主要结果：SVD 上 DROID 的 pose baseline 为 23.15 PSNR / 0.884 SSIM / 0.104 LPIPS，robot rendering 提升到 25.05 / 0.899 / 0.091。Wan 上 DROID AdaLN baseline 为 18.57 / 0.824 / 0.224，本文为 21.87 / 0.859 / 0.178；RoboCasa 从 17.67 / 0.835 / 0.194 提升到 24.61 / 0.889 / 0.131。消融显示 raw action mesh < nominal mesh < nominal mesh + EEF/scene depth。定性实验还展示了轨迹编辑、xArm/Inspire hand、DexYCB 人手轨迹重定向、双 Panda 等零样本泛化。

## Value
这篇对机器人视频世界模型很有价值：它把“动作条件”从低维符号转成可视几何，让预训练视频生成模型更容易使用。对我们有启发的是，世界模型条件不一定要追求端到端学习，合理的可部署中间表示可能更重要。待解决问题是：如何在无精确 URDF/标定、动态相机和失败接触数据中保持同样效果。

## Strengths
亮点是问题定义清楚，避免 logged state 泄漏；方法与视频扩散先验匹配；实验包含真实 DROID、仿真 RoboCasa、消融和跨 embodiment 定性验证。它没有把提升归因于更大模型，而是集中证明 action representation 的作用。

## Weaknesses
依赖 URDF、控制器和 camera-to-robot calibration；场景深度基本假设静态环境；对失败、滑移、复杂接触的覆盖有限；zero-shot 结果主要是定性，尚未闭环验证 planning 或 policy improvement。

## Future Work
作者指出可以扩展到动态相机、更复杂 robot/hand embodiment、更多失败交互和下游规划。自然后续还包括：用生成结果做闭环 MPC、自动校准渲染条件、学习 nominal 与真实接触偏差。

## Rating
创新度评分：4/5 - 不是新生成主干，但 action-as-rendered-robot 的部署可用 factorization 很有洞察，实验支撑强。
相关度评分：3/3 (Core) - 直接研究机器人视频世界模型和动作条件化，是核心相关。

## TL;DR
把机器人动作先转成nominal轨迹并渲染成几何条件，显著改善机器人视频世界模型，值得精读。
