# Hydra-0: Action Flow for Generalist World Modeling and Control

## Insight
不同机器人动作空间难共享，但动作造成的像素运动可作为跨 embodiment 的公共接口；用 action flow 条件视频模型后，同一机制还能反向从目标 object flow 推 compatible robot motion，连接世界建模、离线 policy evaluation 与控制。

## Motivation
关节/末端动作依赖具体机器人，阻碍多机器人视频数据联合训练与 backbone 迁移。目标是把动作后果统一到视觉运动层。

## Method
从视频与机器人几何构造 robot/object action flow，条件化多种视频生成 backbone；支持 action→future 的正向模式、desired object flow→robot flow 的反向 WAM 模式，再以 action head 从 latent 输出可执行动作。

## Experiment
多 embodiment corpus 与 RoboLab；最佳配置相对 action-conditioned baseline 将机器人/物体运动误差降90.4%/60.2%，重放成功率与真实成功率 Pearson r=.96；测试 zero-shot composition、数据高效适配、采样/速度和逆向控制。真机任务范围仍有限。

## Value
action flow 是很有潜力的跨机器人控制语言，直接服务视频世界模型和 world action model，值得精读。

## Strengths
跨 embodiment/任务/backbone；正向与逆向统一；同时验证生成误差、policy ranking 和动作执行；有数据规模/速度分析。

## Weaknesses
flow 依赖可靠分割/对应与相机几何；遮挡、接触力和不可见关节难由2D motion表达；r=.96 的评测任务可能较同分布；逆向动作不保证动力学唯一或安全。

## Future Work
3D/scene flow、力与接触条件、复杂遮挡、更多机器人及闭环长时控制。

## Rating
创新度评分：4/5 - 用 action flow 统一跨 embodiment 世界建模并出现可控逆模式，方法和效果均显著。
相关度评分：3/3 (Core) - 直接研究视频 world/action model 与机器人控制统一接口。

## TL;DR
以像素动作流统一跨机器人视频世界建模和反向控制，创新显著，值得精读。
