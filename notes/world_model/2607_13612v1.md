# The SIGReg Objective as Variational Free Energy: A Theoretical Active-Inference Account of JEPA World Models

## Insight
论文最重要的 insight 是：JEPA 的 anti-collapse regularizer 决定了它能否被解释为 Active Inference 的 variational free energy。Observation 是预测损失本身不足以保证 latent 几何可作为 surprise bound 或 goal cost；不同正则对 latent entropy 的上下界性质不同。推论是 SIGReg 在强条件下可消除 Gaussian prior miscalibration gap，而 VICReg/LogDet 会留下各向异性误差。

## Motivation
论文解决 JEPA 世界模型理论解释不足的问题。同行多从经验上用 JEPA/LeWorldModel 做预测和规划，但对正则项为何支撑可规划 latent 空间缺少严格说明。该问题对隐式世界模型关键，因为 planning cost、goal distance 和 epistemic value 都依赖 latent 几何是否可信。

## Method
这是理论论文。作者建立 AIF-JEPA 字典：hidden state 对应 embedding，complexity 对应预测 MSE，informativeness 对应 SIGReg 约束，pragmatic value 对应 latent goal cost，parameter information gain 对应 ensemble variance，并指出 state epistemic value 在常用 JEPA planning 中缺失。核心证明包括三类 gap 分解：非 Gaussian gap、协方差 off-diagonal gap 和估计误差；在 constant-noise encoder、population limit、SIGReg 成功约束、Gaussian/linear 可辨识等假设下，JEPA 目标等价或上界于 VFE。作者还分析多步 MPC、teacher forcing、autoregressive compounding 和把 VICReg 替换 SIGReg 时的 O(H delta^2) 误差。

## Experiment
没有经验实验，但提供 Lean 4 形式化证明和可检验预测。理论结果包括：PairDist 是安全 lower bound，VICReg 和 LogDet 是不安全 upper bound，SIGReg 通过各向同性约束消除 prior gap；常见 JEPA planning cost 等于 EFE 去掉 future-state coverage/entropy 项，因此缺少主动探索状态空间的 state epistemic term。作者提出经验预测：SIGReg latent condition number 接近 1，goal cost 与成功率 Spearman 更高，VICReg 在近邻目标区分上更易退化。

## Value
这篇对隐式世界模型很有价值。它把“latent 是否适合规划”从经验指标推进到正则、几何和自由能解释，提示我们评估 JEPA/Dreamer 类模型时要测 latent covariance、condition number、goal ranking 和 epistemic coverage，而不只看预测误差。

## Strengths
问题切中 JEPA world model 的理论空白；gap 分解清楚；明确指出常用 planning objective 缺少 state epistemic value；给出可实验检验的预测和 Lean 证明。

## Weaknesses
假设很强，包括 constant-noise、Gaussian、SIGReg 完全成功、线性可辨识和匹配维度；没有实验证据；overcomplete latent、有限样本率、非线性识别和真实控制任务仍未解决。

## Future Work
作者建议实证检验 SIGReg vs VICReg 的 latent condition number 与规划成功关系，加入 state epistemic value，处理 overcomplete latent、有限样本和更现实的噪声/非线性假设。
