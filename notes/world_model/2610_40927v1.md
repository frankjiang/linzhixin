# Agentic World Modeling for Agent Test-time Scaling without Environment Replica

## Insight
在共享、不可复刻的数字工作区，先观察一个记录才能知道下一步该读什么；自适应只读查询因此可比一次性取固定上下文更准确。作者构造多级指针查询任务，证明最坏情形下顺序读取为 O(D)，非自适应读取需 Ω(K^D)；证明针对特定信息访问结构，非视觉/物理世界动力学。

## Motivation
LLM agent 的 Best-of-N 轨迹采样通常假设可复制或重置环境；企业应用的写操作会污染并行分支，而单轮文本模拟器可能漏掉状态。论文解决数字服务中的“安全读取并模拟动作反馈”问题，与视频、3D 或隐式物理世界模型目标不同。

## Method
每个假设动作调用一个上下文隔离的模拟子代理，最多进行 6 次 READ/LIST/CALL/TRACE 等只读查询；根据查询结果继续找证据，必要时用受限 Python 精确拼装下一条工具返回。外层 agent 对模拟轨迹评分，只将最佳轨迹提交真实环境。技术核心是检索、工具执行和上下文管理；没有学习视觉状态、潜动力学或生成视频。

## Experiment
在 τ-bench、AppWorld、OfficeBench 上，以 DeepSeek、GPT、Qwen 多种基座比较单轮 SIMIA 和训练式 WM-Training 的 Best-of-N 真实任务成功率。相对 SIMIA 的汇总提升约 40.07 个百分点；Qwen 的 AppWorld Level 3、BoN@16 从 6.20% 升至 33.33%。64 任务样本的一步观察准确率：AppWorld 41.1% 对 SIMIA 6.87%，OfficeBench 82.2% 对 5.94%。去掉 Python、去掉顺序自适应读取均降低成功率；子代理隔离使 token 开销低于无隔离实现。

## Value
对目标研究仅有间接方法论提醒：预测前按需获取证据可能改善部分可观测状态估计；其应用对象是 API 和文档工作流，不能直接当作视频或 3D 世界模型成果。

## Strengths
同一只读预算下设非自适应消融，并直接测一步观察准确率；区分虚拟模拟与最终真实任务提交。

## Weaknesses
只读访问仍依赖真实当前快照，假设轨迹中写入后的状态主要靠历史推断，长链模拟误差尚难控制。理论是专设指针查询的最坏情形；没有物理预测、视觉、3D 或机器人实验。成本报告偏 token，未完整覆盖 API 调用延迟。

## Future Work
作者未给出明确的后续路线；可研究假设写操作后的状态一致性、只读接口代价及长时模拟误差。

## Rating
创新度评分：1/5 - 在目标研究方向无视频、3D 或隐式物理建模技术贡献。
相关度评分：0/3 (Noise) - 属于 LLM 工具代理和数字工作区模拟，与指定世界模型方向无实质联系。

## TL;DR
多轮只读检索和程序执行提升数字工作区代理的模拟准确率，但不涉及视觉物理世界模型；可跳过。
