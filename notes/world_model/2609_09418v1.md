# Valerant: An Automatic Navigable Game Map Generator via Action-Conditioned World Model Exploration

## Insight
动作条件视频能产生看似可行的移动，却不自动形成可复用的三维空间。作者将“选择值得生成的视角”与“积累几何”联动，用重建结果反过来选择视频分支。这是主动建图思路在生成世界中的应用，证据主要来自少量可视化，并无新的几何或动力学理论。

## Motivation
游戏地图需要持久几何来支持移动、碰撞与编辑；只有视频流无法直接交付这种资产。现有世界模型侧重连续视觉生成，已有 SLAM 则通常重建独立存在的环境。本文尝试从单张截图出发，边生成、边探索、边重建，这与视频到 3D 世界的转换直接相关。

## Method
冻结 Matrix-Game 3.0，以 MASt3R-SLAM 重建；无需额外训练。
1. 保存世界模型与 SLAM 的共同检查点，分别生成五类动作的候选视频：前进、左／右转后前进、原地左／右转。
2. 重建每个分支，以新增覆盖和前进量评分，排除碰撞候选；恢复起点，只重放选中的动作并融合点云。
3. 局部地面估计采用相机到地面高度归一化，缓解单目尺度／高度漂移；结合圆柱体点云占用和原始深度检测穿墙。
4. 陷入死胡同时联合回退模型与地图，记录失败区域以避免重入。可选用 video2world 做全局点云后处理。

贡献主要在已有视频生成、主动 SLAM、碰撞启发式和回溯搜索的系统组合。

## Experiment
输入均为 VALORANT 截图，单张 H100，唯一主要对照为 HY-World 2.0。表 1 报告 VLM 评判占比 80.00% 对 20.00%，人类偏好 83.33% 对 16.67%；没有给出评测样本数、评判模型、标注人数或置信区间。AS 在表注写作 aesthetic，正文称 authenticity，定义不够一致。

图 2 展示四个场景的生成帧和俯视点云，可见沿探索路径形成的空间结构。图 3 对地面估计、碰撞检测、回退分别给出单场景有／无模块对照，说明局部失败现象。未量化地图覆盖、几何误差、碰撞率、路径连通性或导航成功率；感知偏好不能直接证明可导航性。

## Value
提供一条生成视频向显式 3D 资产转化的可实现管线，适合关注主动视角选择和分支状态管理的研究者参考。关键未决问题是：在本身可能不一致的视频上做 SLAM，能否形成全局一致、可碰撞、可编辑的场景。

## Strengths
- 将几何重建用于动作选择，目标明确，组件可替换。
- 联合回退模型与 SLAM，避免候选分支污染持久地图；对尺度漂移与低纹理穿墙给出具体处理。

## Weaknesses
- “可导航地图”的证据主要是点云与生成轨迹，未展示完整碰撞网格、导航验证或游戏资产交付。
- 模型与 SLAM 的错误可能相互强化；持久点云不意味着生成器会服从该点云，也无全局一致性保证。
- 每步五次视频生成和重建再重放，未报告耗时、预算及重放随机性如何保持一致。
- 实验薄弱且复现信息缺失：正文仍引用“Appendix ??”，PDF 实际没有所称超参数附录。

## Future Work
作者明确提出改善几何一致性，并把点云转换为更丰富、可编辑的游戏资产。

## Rating
创新度评分：2/5 - 属于已有世界模型与 SLAM 的工程组合，导航和几何优势尚缺充分量化验证。
相关度评分：3/3 (Core) - 直接连接动作条件视频世界模型与持久 3D 世界构建。

## TL;DR
将视频世界模型、主动探索与SLAM组合成单图生成点云地图管线；导航证据不足，可选读系统设计。
