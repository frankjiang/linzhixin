# SCALE: State-Calibrated Latent Embeddings for JEPA Planning in the Right Geometry

## Insight

核心 observation 是“状态可从 embedding 解码”不等于“状态会影响 planner”。JEPA planner 不使用 learned head，而是直接以预测终点与目标 embedding 的平方欧氏距离排序 action sequence；在 PCA 方向 j 上，两条独立样本对该距离的期望贡献恰为 `2λ_j`。因此，若任务状态藏在低方差方向，即使 probe 能准确恢复，它对规划代价也几乎没有 metric leverage。

由此推论，与其只加 latent-to-state regression head，不如直接让 latent pairwise distance 的排序/尺度随任务状态距离变化。证据按机制逐层闭合：DINO-WM 在多数任务（4/5）的 state-distance alignment 高于 LeWM；SCALE 将五任务 Spearman ρ 从 .13/.18/.00/.41/.52 提至 .77/.53/.56/.77/.80，而 Aux 仍约为 .18/.17/.03/.41/.52；SCALE 的头部 PCA 更能预测状态，并在 rollout 后将 candidate-cost Kendall τ 在五任务上全部提高；最终三种 planner 的 15 个 task–solver 平均值也全部超过 LeWM。该链条有力支持“几何影响力不同于可解码性”，但结论依赖欧氏 planning cost，且 privileged state 的选择本身注入了任务先验。

## Motivation

LeWM 用 next-embedding prediction 和 SIGReg 防止 collapse、维持全局近似各向同性，却不规定哪些变化应主导规划距离；DINO-WM 的 pretrained geometry 在部分任务更好，但本实现训练约慢 2.5×、规划近慢 50×，且跨任务表现不稳定。目标是在保留端到端、image-only 测试和低规划开销的同时，让任务相关变化真正出现在 planner 消费的度量中。这是 JEPA world model 的关键接口问题：表示中“有什么”与规划成本“看见什么”并不是同一件事。

## Method

训练时每帧除图像外还带 simulator state。作者按任务选择位置/角度等相关维度，将角度写成 sin-cos、排除速度，并用训练集统计逐维标准化为 q；q 仅作 detached target，测试时 encoder 与 planner 仍只看图像。一个 batch 含 B 条 T 帧子轨迹，展平后采 K 对不同帧，其中一半来自同一子轨迹、一半跨 episode，以兼顾局部与全局结构。

对每对样本计算平方 latent 距离 x 和平方状态距离 y，分别在本批 pair profile 上中心化、标准化，再以 `L_corr = 1 - mean(x_tilde*y_tilde)` 最大化二者 Pearson correlation。完整目标为 latent prediction + SIGReg + λ_corr L_corr：三项分别训练 dynamics、避免 collapse、把既有表示 spread 重新分配给任务状态。L_corr 只更新 encoder，predictor 仍只由 prediction loss 更新。实现用 ViT-Tiny encoder、六层 action-conditioned causal transformer，K=4096，通常 λ_corr=0.1，Reacher 为 0.15；训练时增加轻量 pairwise 运算，规划时无新增模块。

机制对照 Aux 使用完全相同的 q 和训练协议，只增加一个训练期 latent-to-state MLP 并最小化回归误差。它可以把 q 编码在任意低 leverage 方向，因此用于区分“可解码性提高”与“planner-facing geometry 改变”。

## Experiment

实验覆盖 Push-T、DMC Reacher、OGBench-Cube、Two-Room、PointMaze；比较 LeWM、SCALE、Aux 和 DINO-WM，并分别用 CEM、iCEM、MPPI。五档计算预算每次重规划为 9000/2000/500/100/30 次 rollout，跨度 300×；规划 horizon 为 5 个 action block（25 个环境步），每 5 步重规划。CEM/iCEM 每档在六个 evaluation set、共 600 个配对 episode 上测试；MPPI 用五个 held-out set，并为 LeWM family 共享逐任务调好的 temperature。

iCEM 跨预算平均成功率中，LeWM→SCALE 分别为 Push-T 63.9→68.2、Reacher 78.0→81.1、Cube 65.3→70.5、Two-Room 82.9→92.9、PointMaze 80.2→83.4，即 +4.3/+3.1/+5.2/+10.0/+3.1 个百分点。CEM 和 MPPI 也同向，因此 SCALE 在 15/15 个 task–solver 平均值上胜过 LeWM。Aux 改善 13/15，且 iCEM Push-T 为 69.3，反而高于 SCALE 的 68.2；在其余四任务通常落后 SCALE。

DINO-WM 体现出明显任务依赖：iCEM 下 Two-Room/PointMaze 为 98.2/91.5，数值上明显高于 SCALE 的 92.9/83.4；Push-T 仅 51.3，低于 SCALE 68.2，Reacher/Cube 差异较小。说明 state-calibrated geometry 提升了一致性，却没有普遍取代 pretrained features。

表示诊断中，Aux 在 Push-T、Cube 的 full-embedding state probe R² 甚至高于 SCALE，却几乎不改变 distance alignment，支持“单纯可解码不够”。SCALE 相对 LeWM 的 rollout error 在 Push-T/Reacher/Two-Room/PointMaze 分别下降 21.0/14.6/20.6/12.8%，Cube 仅下降 0.7%；candidate ranking Kendall τ 则从 .7316/.6233/.3654/.5448/−.0029 提到 .7857/.6435/.4433/.6210/.1675，五任务均提高。DINO-WM 在 Cube 有最高 τ 却没有最好成功率，再次说明几何排序还必须与可预测 dynamics 配合。

## Value

论文最有价值之处不是相关性 loss 本身，而是明确提出 metric leverage，并用 Aux 控制实验说明 probe accuracy 不是 planner usability 的充分条件。对于直接在 embedding 上定义 goal cost 的 JEPA/隐式世界模型，这是高度可迁移的分析框架：评价表示时应同时测信息可解码性、距离对齐和 rollout 后候选排序。实际方法依赖特权状态和人工 state selection，因而更像 simulator-supervised geometry shaping，而非通用自监督解法。

## Strengths

- 从平方欧氏距离的方向方差贡献给出简洁推导，问题定义清楚且直接对应 planner 接口。
- Aux 使用同一监督但只优化可解码性，是比普通消融更有解释力的机制控制。
- 五任务、三 solver、五预算的配对评估覆盖面较好，几何、PCA、probe、rollout error、candidate ranking 与成功率形成多层证据链。
- 只增加一个训练期正则项，测试保持 image-only，规划时零额外开销。

## Weaknesses

- 需要 simulator privileged state，且逐任务人工挑选维度、处理角度、设 λ；作者也发现增加不重要状态会稀释 metric leverage，因此 state selection 是关键但未自动化的任务先验。
- 实现只训练一个 seed（3072）；报告的标准差/标准误主要反映 episode sampling，不包含 representation training variance，15/15 的稳定性可能被高估。
- 规划只验证固定短 horizon 和已知 simulator benchmark，没有自然视频、真实机器人、感知噪声、分布外目标或长时 latent rollout。
- 多数任务平均增益为 2–5 个百分点；Aux 在 Push-T 更好，DINO-WM 在两个导航任务明显更强，说明距离校准不是充分条件。
- L_corr 对整批 pair distance 做线性相关，优化目标特定于欧氏 metric；它未处理任务状态中的等价类、不可控因素、阶段依赖或非欧几何，错误 state 选择可能主动扭曲表示。
- 作者没有给出训练时间/显存的定量 overhead，也没有与 value-guided metric、learned planning cost 等替代方案做直接实验比较。

## Future Work

作者未单列明确的 future-work 清单。由论文暴露的边界，最直接的后续是自动或因果地选择 task-relevant state，改用弱监督/无 privileged state 的距离信号，验证多训练 seed、长时 rollout、自然视觉与真实机器人，并把 metric leverage 分析推广到 learned、Mahalanobis 或非欧氏 planning cost；这些属于基于本文局限的建议，而非作者已完成的结论。

## Rating

创新度评分：3/5 - “可解码不等于有度量杠杆”的分析有洞察，控制实验扎实；方法本身是简单的特权状态距离相关正则，尚不足以构成新范式。
相关度评分：3/3 (Core) - 直接研究 JEPA latent world model 的表示几何、rollout 候选排序与 latent-space planning，属于隐式世界模型核心方向。

## TL;DR

以任务状态校准JEPA潜空间距离，让可解码信息真正影响规划代价；概念清晰，值得精读。
