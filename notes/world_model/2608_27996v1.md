# Should I Use This Synthetic Dataset for Training? How to Test with Minimal Real Data

## Insight
观察是：判断合成数据是否有用必须以昂贵的真实测试样本为准，而均值型 sequential test 在 paired loss difference 重尾时积累证据很慢；已有 e-process sign-flip test 只自适应 Monte Carlo 计算量，测试集大小仍预先固定。作者据此把新鲜测试 batch 视作一系列“赌场”：batch 内自适应 sign-flip 轮数，batch 间将 e-value 财富连乘，并在当前 batch 无望时尽早换新数据。Theorem 1 证明，在各 batch 独立、batch size 可预测、轮数是 stopping time 且零假设下 paired difference 关于 0 对称时，跨 batch 财富是非负 test martingale；optional stopping 与 Ville inequality 因而给出任意时刻阈值 $1/\alpha$ 的 Type-I error 不超过 $\alpha$。关键代价是其保证针对更强的“对称性零假设”，不是通常的均值无改进零假设。

## Motivation
给定固定学习算法 $A$、真实训练集 $D$ 和候选合成集 $D_{syn}$，论文要以尽可能少的真实测试点判断 $A(D\cup D_{syn})$ 是否比 $A(D)$ 的真实总体损失低。模拟器校准、domain randomization、PPI 等方法试图让合成数据更好，却不给“这批数据值得用”的错误率证书；influence/Shapley data valuation 关注归因而非决策错误。Adaptive mean test（aMT）直接检验均值但要求已知有界 loss 且重尾下低效；SFT 固定数据量和随机化轮数，eSFT 只自适应后者。问题对所有用 DT/WM 生成训练数据的系统都重要，但论文核心是 sequential hypothesis testing，不是世界模型学习。

## Method
先训练 $f=A(D)$ 与 $f^{syn}=A(D\cup D_{syn})$，对真实测试样本定义 $\delta=L(f;Z)-L(f^{syn};Z)$。直接检验为 $H_0:E[\delta]\le0$；对称路线另假设“合成数据平均不会伤害”，把无用化为 $E[\delta]=0$，再检验 $H_0^{syn}:\delta\overset d=-\delta$。因此拒绝 $H_0^{syn}$ 只证明分布不对称；只有额外的 no-harm 假设近似成立时，才能解释为合成数据有益，论文也明确指出它不等价于拒绝直接均值零假设。

aeSFT 第 $k$ 个 batch 从真实分布抽取 $m_k$ 个新样本，计算 observed mean；每轮用独立随机符号翻转所有 $\delta_{k,i}$，记录翻转统计量是否不小于 observed statistic，并依照公平 betting function 更新 batch 内财富 $W_k^b$。跨 batch 财富为各已停止 batch e-value 与当前财富的乘积。若总财富达到 $1/\alpha$ 即拒绝；若 batch 内财富降至 $\omega$ 则早停并令下一 batch 扩为 $\lceil\beta m_k\rceil$；若连续两个 winning round 的财富增量不超过 $\epsilon$，视为该 batch 证据饱和并保持 batch size。耗尽上限 $M$ 只返回 fail to reject，不能宣称合成数据无用。默认参数为 $\alpha=.1$、$M=2000$、$m_{init}=200$、$\omega=.5$、$\beta=1.2$、$\epsilon=.1$。

## Experiment
基线是直接均值 aMT、固定数据且计算自适应的 eSFT，以及固定样本 paired $t$-test；指标为真实有益实例上的 TPR、无益实例上的 FPR、平均/分布式 stopping time。固定方法的每个点代表事先另选的样本量，不能看结果后继续加样本。

二分类实验用 5 维 logistic regression，真实训练 $n=100$、合成 $n_{syn}=50$，通过低秩协方差和扰动标签映射制造 sim-to-real gap；1000 次独立候选中 573 个为 $H_1$、427 个为直接 $H_0$。单个示例中 aeSFT 用 680 个样本拒绝，aMT 约用 1410，eSFT/$t$-test 固定用 2000。参数消融选出的配置得到 TPR $0.612\pm0.026$、FPR $0.027\pm0.007$、$E_{H_1}[m_{stop}]=1024$；但图中的 FPR 按直接均值 $H_0$ 分组，而对称方法的形式保证只针对 $H_0^{syn}$，二者口径不可混同。

无线 packet scheduling 用 3 类 ON/OFF Poisson 流量和离线 DQN：真实集 10 条轨迹/600 transitions，DT 集 30 条/1800 transitions，每次真实评估为 60-slot episode；200 个实例中 99 个有益、101 个无益。aeSFT 在初始 16 个真实 episode 时 TPR 为 0.657，31.8 个时为 0.717，最终平均 88.0 个时为 0.778；aMT 分别要 68.9 和 143.6 个 episode 才到 0.505/0.717，所有方法经验 FPR 均低于 0.1。

radio-map 实验以 Sionna RT 深度 20、$10^9$ rays/Tx 为高保真数据，构造深度 1–14、$10^4$–$10^5$ rays/Tx 的 $14\times14=196$ 个低保真候选；每个模型用 64 张高保真图，增强模型另加 192 张低保真图。MSE 口径下 123/73 个候选属于 $H_1/H_0$；aeSFT 初始 50 张图即达 TPR 0.463，227.4 张时为 0.512，FPR 最终 0.096，而 aMT 到 400 张只检出 123 个有益候选中的 4 个。换成有界 IoU loss 后，aeSFT 平均 40 张 TPR 0.925，eSFT、$t$-test、aMT 分别为 0.957、0.968、0.957，四者经验 FPR 均为 0，说明优势主要出现在重尾/难检验口径。真实 usefulness 另用 10,000 分类样本、200 网络 episode 或 1000 高保真图估计。

## Value
它提供了一个很实用的“合成数据上线前验证层”：真实 rollout 昂贵时，可把评估预算优先给尚未解决的候选，并保持 anytime-valid continuation。对视频/3D 世界模型的直接启发是，不应仅凭 simulator fidelity 或合成集规模决定是否训练，而应在真实 paired evaluation 上做带错误率控制的决策。但它不改善 world model，也不研究视觉生成或表征。

## Strengths
把数据预算和 Monte Carlo 预算同时自适应，目标清晰；定理明确列出独立性、可预测 batch size 和 stopping-time 条件，证明链完整；paired design 消除大量样本间方差且无需 loss 有界；覆盖分类、offline RL 控制和 3D ray-tracing radio map，并报告 TPR、FPR 与样本消耗；IoU 实验显示作者没有把 aeSFT 在所有分布上都包装成绝对优势。

## Weaknesses
最强反例是：$\delta$ 不对称并不意味着平均改进为正；它可能是零均值但偏斜，也可能来自少数灾难性负增益。而“合成数据不可能伤害”和零均值时严格对称恰是 sim-to-real 场景最难保证的假设。论文图表用直接 $\Delta\le0$ 计算经验 FPR，却只能对对称零假设给形式 Type-I 保证；未系统注入偏斜、异方差或轻度有害分布来检验保证失配，因而标题中的“是否有用”比定理实际回答的问题更强。

此外，fail to reject 不能判定“无用”，radio-map MSE 下即使继续至 227 张平均 TPR 也只有 0.512。独立新 batch 假设在时间相关的机器人/真实视频 rollout 中可能失效，文中没有 block/dependence 扩展。虽然方法声称同时节省计算，实验几乎只量化真实样本数，未报告 sign-flip 总轮数、wall time 或与 eSFT 的等功效计算开销。固定样本基线的比较点各自需预设，适合说明 continuation 合法性，但不足以证明 aeSFT 对最优预注册固定设计始终更省样本。

## Future Work
作者明确提出把 aeSFT 用于 LLM 合成指令/偏好数据、机器人与自动驾驶 world-model rollout，以及无线 channel/radio-map/控制轨迹，并让更多真实评估只流向未决候选。合理推断的改进包括：设计对称性诊断或与直接均值 test 的安全混合检验；处理时间相关和非 i.i.d. 数据；给出 power/expected stopping time 分析；同时报告数据成本与 sign-flip 计算成本。

## Rating
创新度评分：3/5 - 在既有 eSFT 上加入跨独立 batch 的数据自适应、给出 anytime-valid 定理并做多域验证，属实质但非范式级统计扩展。
相关度评分：1/3 (Tangential) - 可用于验证世界模型合成数据，但核心是通用统计检验，不研究视频/3D/JEPA/Dreamer 模型本身。

## TL;DR
aeSFT 双重自适应检验合成增益分布是否对称，统计方法扎实但解释依赖无伤害假设，可选读。
