# $Ψ$-0.6: Adaptive Streams of Thought in a Unified Vision-Language World Model

## Insight
观察：空间和反事实问题所需的中间表示不同，像素或文字推理无法稳定显露视角、深度和运动约束。作者推断，若模型本身能读写图像、几何与文字，就能把生成的几何/未来画面当成可组合的推理步骤，并学习何时调用它们。MindCube 的组合提示、FlowBench 的预测结果及视觉问答的策略增益提供实证支持；没有证明表示统一必然优于分离模块。

## Motivation
现有 VLM 通常只输出文字，视频世界模型擅长生成却不回答问题，工具链则依赖各自训练的固定模块，难以让中间表示和下游任务协同。论文试图把观察、3D 几何、反事实模拟及语言问答纳入同一预测界面。这是构建可规划具身智能体的关键方向，但本文验证主体仍是空间/视觉问答而非机器人控制。

## Method
- 在原有 PSI 视觉模型上扩展一个约 8B 参数的自回归 Transformer。RGB、深度、光流和点轨迹以局部 patch 内容码及带时空坐标的指针 token 表示；相机位姿与文字进入相同序列。通过变换给定/待预测 token 的顺序，单模型可做视角估计、深度/光流预测、新视角/视频生成与问答。
- 训练依次引入 RGB 视频预测、几何、文字语料、图文对齐和指令数据，均使用下一 token 目标。中间输出可作为下一步输入；例如相机位姿→新视角→回答，或文本位移→光流→结果图像→回答。FlowBench 稀疏运动再用运动概率排序 patch 和文本条件 CFG 改善解码。
- 自适应流以“notation”选择深度、相机运动、光流的时间位置与顺序：先从 64 个候选中按参考答案损失蒸馏，再采样每题 16 个 notation，用相对 RGB-only 答案损失奖励训练 LoRA 选择策略（Dr. GRPO）。**此处实证优化重点是选择预设表示的策略，尚不是完整的在线多步行动规划。**
- 新意主要是将 PSI 的视觉/几何 token 界面扩到语言推理与可学习的表示选择；自回归、CFG、GRPO 和几何中间量本身为已有技术。

## Experiment
- MindCube 多视角空间推理：零样本 RGB **49.7%**、加入相机信息 **51.3%**、组合推理 **57.7%**，优于列出的通用开源 VLM；针对该任务 SFT 后 RGB+相机 **76.3%**，但弱于 GeoThinker **83.0%**。Rotation 类别仍是瓶颈。
- FlowBench-Sim 反事实单物体移动：光流准确率从默认解码 **31.8%** 升至运动 patch 排序+CFG 的 **56.4%**，相对移动区域端点误差 **0.454**；模块化几何管线为 **50.8%/0.552**，但使用相机内参。Sim 问答微调 **24.5%→73.1%**，低于同数据微调 Qwen3-VL-8B 的 **76.3%**；零真实样本迁移到 FlowBench-Real 为 **51.4%**，低于该 Qwen 基线 **59.6%**。
- 四个训练视频集上的 notation 策略较纯视频问答平均相对准确率提高 **5.6%**，四个未见问答基准平均提高 **9.0%**；还报告 best-of-16 上界。消融显示 pMotion 与 CFG 都显著改善光流，但 CFG 过强会损伤画面重建。图示展示新视角与反事实模拟的中间表示。

## Value
对视频/3D 世界模型的启发是把显式几何和生成画面设计为**可查询、可组合、可受任务反馈选择**的中间操作，而非只输出最终视频。其工作更适合研究表示接口与反事实评测；把这些能力转成行动决策仍待验证。

## Strengths
统一接口覆盖图像、语言、位姿、深度、光流和轨迹；同时给出空间问答、反事实运动预测、合成到真实迁移及选择策略实验；附录公开 token、训练配比和解码消融，便于理解实现。

## Weaknesses
继承 PSI 的 patch 表示并组合已有训练技术，缺少同资源的统一模型/模块化系统强对照，也未拆解多任务训练的正负迁移。几何标签由外部估计器生成，存在伪标签误差；FlowBench 主要是静止相机、单物体位移。选择策略基于预定义表示和参考答案损失，不能据此证明开放环境中的自主多步推理；无真实动作、闭环规划或控制实验，8B 模型训练成本高。

## Future Work
作者提出加入关节、末端执行器、夹爪等动作 token，或通过逆运动学把光流/点轨迹变为控制；以跨模态/正逆预测一致性构造物理验证信号；探索稀疏专家以缓解统一模型的干扰和成本，并自动发现新的推理表示。

## Rating
创新度评分：3/5 - 视觉世界模型与语言、几何推理和表示选择的整合有实质价值，但主要组件及 PSI 底座已有，自适应推理验证仍有限。
相关度评分：3/3 (Core) - 直接研究视频与显式 3D 几何世界建模，并测试生成中间状态对推理的作用。

## TL;DR
以统一视觉、几何和语言 token 串联反事实生成与表示选择，空间推理有效但尚未验证具身控制，值得精读。
