# From Pixels to States: Rethinking Interactive World Models as Game Engines

## Insight
核心 insight 是：交互式视频世界模型不应只被看成 action-conditioned video generator，而应被看成一个近似游戏引擎，即 action-state-observation 闭环。Observation 是当前方法常把状态隐含在像素或短上下文里，导致长程一致性、规则时序和可控性都弱；推论是显式 state、state-grounded memory 和规则对齐的 transition 才是交互世界模型的关键。

## Motivation
论文解决“互动世界模型如何从像素生成走向可玩环境”的问题。同行多沿视频生成扩展：给定动作、相机或文本条件生成后续帧，但缺少清晰的游戏状态、规则和可维护记忆。作者认为这是关键问题，因为没有状态变量，模型难以表达 HP、技能冷却、物品、动画状态等非视觉但决定交互结果的因素。

## Method
这是一篇框架和数据论文，不提出新网络。作者把交互式世界模型拆成四个维度：玩家动作控制、游戏状态动力学、状态-观测持久性、实时交互生成。动作控制包括几何轨迹/相机、键鼠/手柄/latent action、语义事件；状态可隐式存在于像素、学习到的 latent 或显式符号状态中；记忆既可以存历史观测，也可以估计当前状态；实时性不仅是生成延迟，还包括条件注入和结果触发的时序延迟。论文还构建 Black Myth: Wukong 数据引擎，采集 RGB、depth、键鼠、引擎状态、角色/敌人属性和语义标注。

## Experiment
没有传统模型对比实验。实证部分主要是数据与设计分析：数据包含 90 小时以上游戏轨迹，1280x720、30FPS，帧级对齐键鼠输入和引擎状态；状态字段覆盖相机、玩家/敌人 pose、动作、技能、生命值、耐力、装备等；并用 Qwen3-VL 生成槽位 caption 和语义 caption。实验价值在于展示纯视频数据之外的显式 state 监督如何支撑未来互动模型。

## Value
对我们很有价值：它把视频世界模型的核心矛盾从“帧是否逼真”转到“状态是否可维护、规则是否可执行”。启发是后续研究应优先设计可读 state interface、状态更新器和规则时序约束，而不是只扩展视频扩散模型上下文。

## Strengths
框架清晰，把游戏引擎抽象引入交互式世界模型；指出非视觉状态是长程互动的短板；数据采集包含引擎内部状态，监督信号比普通 gameplay video 更强；讨论了实时生成和条件延迟的系统瓶颈。

## Weaknesses
没有训练或验证一个完整模型，贡献更偏 agenda setting；数据来自单一游戏，泛化到开放物理世界和机器人仍需验证；显式状态依赖引擎访问，现实视频或真实机器人场景未必可得。

## Future Work
作者强调未来应把显式 game state 放入生成闭环，做 state-grounded memory update，并让视觉结果的发生时刻与游戏规则、动作效果和状态转移对齐。
