# GROME: GROunding Factorized MEmory into Video World Models

## Insight
观察：只回放历史帧会混淆不变场景与运动实体；把历史全局融合成 3D 缓存则会累积深度误差并冻结动态对象。推论是“静态按空间覆盖取互补证据、动态按时间取最新状态”，且局部点图只在查询时融合。论文通过匹配同一 LingBotV2 主干和历史 token 预算的对比、去静态/动态和注入策略消融支持这一设计；不是几何一致性的形式保证。

## Motivation
视频世界模型有限上下文导致离开后重访时场景与角色漂移。现有隐式帧检索受上下文和动静纠缠限制；显式全局 3D 存储擅长静态空间，却难维护不断变化的实体并可能产生几何累积误差。这是可探索视频世界的核心瓶颈。

## Method
- 将每段生成视频经 SAM3/CoTracker 动态分割、DA3 深度估计及静态区域逆深度配准，回投影为带相机位姿的**局部**静态和动态点图；动态项额外存时间戳。
- 查询目标相机轨迹时，静态图按最大覆盖选多视角局部证据，动态对象按重叠区域保留最新观测；用 z-buffer 渲染目标视角参考。静态参考采用目标时间 RoPE，动态参考保留源时间 RoPE。
- 冻结生成主干，通过参照当前上下文的 value 均值/方差适配、动静分离的注意力分支、只在前两步注入静态几何的扩散时序路由接入记忆。与既有投影、分割和注意力机制组合，创新集中在动静记忆语义及训练外注入的系统设计。

## Experiment
200 个 WorldScore 场景（静态/动态各 100），24 FPS、15–18 秒探索后重访；指标包括静态区域 PSNR/SSIM/LPIPS、实体一致性/运动、视觉质量、相机误差和提示一致性，报告配对 bootstrap 95% 区间。静态场景上 GROME 相对同主干原始上下文 PSNR 20.62 对 11.40、LPIPS 0.169 对 0.590；动态场景为 PSNR 24.11 对 19.29、实体一致性 0.769 对 0.717。动态 PSNR 略高于 WorldPlay 23.87，但实体一致性低于其 0.910，且动态质量并非全面领先。50 场景消融中完整模型 PSNR 23.84；去静态 18.51、去动态 19.54、共用注意力 5.47、去 value 适配 6.34。附录显示 DA3 几何更新约 54.8 秒/次，参考 KV 约 1.2 秒/段；图例展示极长轨迹色漂移和严重深度错误。

## Value
对视频/3D 世界模型值得精读：可直接借鉴局部几何证据、实体状态时间戳与生成主干原生条件接口分工。应用时需权衡外部深度估计的高延迟，并考虑如何在错误投影下训练模型识别不可靠参考。

## Strengths
同主干、同上下文容量的对照较有说服力；动静组件与注入策略均有消融；附录提供几何配准、运行时成本和失败案例；训练外扩展支持外部视频记忆。

## Weaknesses
高度依赖深度、位姿与运动分割；几何更新开销大，不能据此称整个系统实时。仅 15–18 秒主基准，长期色漂移依旧，严重投影错误可污染生成。外部模型的架构与采样设定不同，不能作严格因果比较。

## Future Work
作者建议从训练外注入走向联合学习，使主干主动识别并纠正不完美的投影参考；还需降低 DA3 成本并检验更长交互与复杂动态的可靠性。

## Rating
创新度评分：3/5 - 动静分离的局部点图记忆及无训练注入是有效系统组合，底层组件和几何检索多沿用现有技术。
相关度评分：3/3 (Core) - 直接解决视频/3D 世界模型的长时程记忆与动态一致性。

## TL;DR
把静态几何与动态实体分开存为局部点图并注入冻结视频模型，显著改善重访一致性；做长时程世界模型值得精读。
