# IMPULSE: Push First, Then Predict in V-JEPA 2 Feature Space

## Insight
观察：单帧相同外观的物体可有不同惯量、摩擦与反弹，预测特征只能在互动后区分；即使「真物理参数」送入普通姿态 token，特征误差改善仍小。作者在理想平方误差预测器、经验与查询条件独立、未来特征只经物体姿态受物理参数影响等假设下给出「无信息≥经验记忆≥真参数≥真未来姿态」误差阶梯，并通过 oracle 诊断显示瓶颈更多在物理信息进入 JEPA 特征的通道。论文也承认校准与查询共用对象噪声等级，严格独立性假设不完全满足；oracle 只含三项物理参数，所以理论阶梯不能直接保证实测比较的排序。

## Motivation
V-JEPA 2 类隐式世界模型从视频特征预测未来，但隐藏物理性质不能由被动外观唯一确定。已有系统辨识/主动探测研究较多，论文聚焦：少量预先推动能否改善冻结视频编码器空间的预测，以及从已辨识性质到特征预测之间是否存在接口瓶颈。

## Method
在 2D 刚体推块模拟中先做 3 次校准推动，从带噪姿态轨迹拟合碰撞后的法向、切向及角速度；基于已知接触模型的网格贝叶斯后验，压成 8 维响应/不确定性记忆。小运动头结合查询动作和记忆预测目标姿态；姿态既作为 token 输入从零训练的 2 层 action-conditioned Transformer，也经随机傅里叶姿态头校正未来 V-JEPA 2 ViT-L 冻结特征。无记忆对照使用同架构并置零记忆，另有真参数、真未来姿态与原始推动测量对照。不是在官方 V-JEPA 2-AC 上微调。

## Experiment
2048 个训练物体、256 个验证物体；模型封存后生成 512 个新 ID 和 128 个超范围物理 OOD 物体，8 种子，预定主要指标为粗糙物体 1 秒的特征 NMSE。相同路径下，无记忆 0.416/0.417，记忆 0.367/0.364（最佳/最终检查点，改善 11.6%/12.8%，8/8 种子均改善），OOD 改善 11.7%/14.0%。对普通姿态 token，真参数仅改善 6.9%–7.8%；加傅里叶头后改善 22.9%，显示接口可用性。原始 23 维推动测量改善 12.5%–13.0%，与贝叶斯记忆无清晰差别。0.2 秒接触初期收益近零，0.5 秒约 8.8%；1 次推动已有 7.9%–8.7%，3 次后趋于饱和。

## Value
为隐式世界模型的主动感知提供可操作诊断：先用真参数与真未来状态测试信息通路上限，再决定是否投入系统辨识。方法和对照值得精读，尤其注意其模拟域约束。

## Strengths
预先封存模型与测试数据、跨种子/物体区间、同架构无记忆对照；区分记忆内容与姿态接口作用；报告原始测量对照，避免把效果误归于贝叶斯摘要。

## Weaknesses
单一已知形状、固定颜色的平面模拟；目标特征主要由物体姿态决定，且记忆使用与模拟器匹配的接触模型和摩擦先验。部分 OOD 惯量对该形状不具物理可实现性；未测试真实视频、官方 V-JEPA 2-AC、规划收益或通用 3D 物理。

## Future Work
作者提出学习式经验编码、真实机器人推动、3D 场景，以及用改进的预测器实际做规划。

## Rating
创新度评分：3/5 - 主动探测、物理记忆与特征通路诊断组合有明确新意和扎实验证，但环境非常受控。
相关度评分：3/3 (Core) - 直接改进 V-JEPA 特征空间的动作条件隐式世界模型预测。

## TL;DR
先推动辨识隐藏物理性，再经姿态通路改善 V-JEPA 特征预测；实验证明接口是关键瓶颈，值得精读。
