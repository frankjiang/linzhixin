# TabPrep: Closing the Feature Engineering Gap in Tabular Benchmarks

创新度：3/5 | 相关度：0/3

## Insight
无。

## Motivation
- **问题**：当前 tabular ML benchmark 完全忽略了特征工程（FE），导致模型评估存在系统性偏差——纯模型比较低估了 FE 能带来的性能提升。
- **同行做法**：现有 AutoFE 方法采用 expand-and-reduce 范式（大量生成特征+有监督选择），计算成本高、容易 OOM，难以集成到大规模 benchmark。
- **关键性**：对 tabular ML 社区有实际价值，但与视频/3D/隐式世界模型方向完全无关。

## Method
提出 TabPrep，一个轻量级特征工程 pipeline，针对三种结构性数据模式设计特征生成器：
1. **OAFE (Ordered Arithmetic Feature Expansion)**：针对数值特征的代数结构，生成有序的算术组合特征（ratio/product/difference/addition）。
2. **CatPrep**：针对分类变量的 group-conditional 结构，包含三个子模块——Out-of-Fold Target Encoding、Target-Encoded Relative GroupBy、Random Subset Feature Compression。
3. 将以上组合为统一的 budgeted pattern-informed generation 范式，避免传统 expand-and-reduce 的高开销。

## Experiment
- 在 TabArena benchmark 的 30+ 数据集上评估
- 将 TabPrep 集成到 LightGBM、TabM、TabPFN-2.5、Linear 等多种模型
- TabPrep 在 16/24 个数据集上建立新的 peak performance
- 超越了现有 AutoFE 方法（如 feature-engine, OpenFE 等）

## Value
对 tabular ML 社区有实际贡献，揭示了 feature engineering gap 的存在。但与视频世界模型、3D世界模型、隐式世界模型等研究方向完全无关，对我们没有任何参考价值。

## TL;DR
提出TabPrep轻量特征工程pipeline填补tabular benchmark中的特征工程空白，与世界模型方向完全无关。可跳过。
