# IGNITE Tokamak World Model Architecture

## Insight
不同诊断信号从 100 Hz 到约 1 MHz、又有缺失通道，直接统一采样和长程回归困难；作者据此采用每种模态独立压缩成离散码，再让动作条件时空 Transformer 自回归预测 50 ms 窗口。单个验证放电显示部分低频信号能延续预测，但频谱细节明显欠佳。论文未用消融证明这种分离式设计优于现有方案，也未验证其物理可控性。

## Motivation
托卡马克实验昂贵，历史数据同时含慢速诊断、快速波形、频谱和控制执行器。先前 TokaMind、PanoMHD、FusionMAE 多做单个短窗口重建或预测，作者想得到可根据执行器轨迹滚动生成整次放电的模型。这是核聚变科学应用问题，非用户关注的视频/3D/JEPA/Dreamer 世界模型方向。

## Method
以 50 ms 为一帧：慢速序列（100 Hz）、8 通道快速滤光信号（10 kHz）、多通道频谱（高频信号重采样至 500 kHz）分别经专用编码器和 FSQ 离散量化；冻结编解码器，再训练 Genie/MaskGIT 风格的因果时空 Transformer。每帧加入执行器均值与模态/位置/时间嵌入，输入 20 帧（1 s）上下文，对遮蔽码作按模态平均的交叉熵预测；推理时逐帧多轮置信度解码并回填预测码。核心结构借鉴 Genie，主要工程适配在多采样率诊断的 token 化与缺失通道损失掩码。文中虽提图像序列可扩展性，但附录实际诊断清单只含时间序列和频谱，未给图像编码器或视频生成实验。

## Experiment
收集 2018–2026 年 DIII-D 放电，按电流轨迹相关性 ≥0.8 过滤后约 8,600 次，按放电随机划分 90/5/5。先用 16 次放电检查可记忆性；1,000 次放电的训练/验证曲线显示约第 12–15 epoch 后验证损失上升，dropout 0.3 与 weight decay 0.1 也未根治。论文称完整数据可改进泛化，但未给完整测试集的汇总指标或与先前模型对比。图 3 只展示一条验证放电 190735：电子密度/电子温度/离子温度 nRMSE 为 0.336/0.112/0.168，ECE/MHR 频谱为 0.656/0.847；高频模态结构明显缺失。未见执行器反事实控制实验、长时误差分布或物理约束指标。

## Value
对于多频率、多缺失值传感器系统，可借鉴「每模态离散 tokenizer＋动作条件潜变量自回归」工程管线；但对视频、3D 或 JEPA 世界模型没有直接实验依据，阅读优先级低。

## Strengths
- 面对真实核聚变设备的异构采样频率和缺失诊断，而非仅在合成轨迹上演示。
- 把编码器、动力学模型和执行器条件分开，给出部分诊断表、窗口长度与训练流程。
- 展示失败现象：小数据过拟合及高频频谱预测不佳。

## Weaknesses
- 实验仍偏架构报告：缺少测试集整体指标、标准基线、消融、随机种子方差和物理有效性检验；单条验证轨迹不足以证明泛化。
- 摘要和正文多次提图像/相机帧，但实际诊断表及附录 tokenizers 不含图像；不能视作已验证的视频世界模型。
- 执行器仅以窗口均值编码，可能丢失 50 ms 内的快速控制变化；未展示不同执行器轨迹导致合理反事实响应。
- 架构说明有 48 层与 24 个 block、7 组与附表 5 组执行器等不一致，复现细节需澄清。

## Future Work
作者明确提出物理学指标评测、用模型设计放电实验与模拟执行器故障，并研究训练/推理时错误或缺失输入的影响。

## Rating
创新度评分：2/5 - Genie/FSQ 的领域化多频率工程组合，缺少新建模机制和充分的定量验证。
相关度评分：0/3 (Noise) - 核聚变诊断信号预测，实际没有视频/3D 实验，也非 JEPA/Dreamer 方向。

## TL;DR
把多频率托卡马克诊断量化为离散码并自回归预测，但评测仅有单例且未验证视频模态；本方向可跳过。
