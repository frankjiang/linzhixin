# The Objective Is the Bottleneck: Latent World Models Encode What Their Planners Cannot Use

## Insight

长时规划失败未必是 world model 预测变差，而可能是 planner 读取 latent 的方式错了。TwoRoom 中预测到 75 environment steps 的误差仍仅为静止 baseline 的 18.9%，位置可从冻结表示以 R²=0.9922 线性解码；但 CEM 使用的 latent L2 在约 80 units 后饱和、120 后反向，甚至奖励远离目标。更深一层，planner 真正需要的是 reachability 而非 Euclidean proximity：仅用帧间时间距离训练的 head 虽较不准地估空间距离，却会给跨墙路径额外 24% 成本，规划成功反而最高。

## Motivation

JEPA/latent world model 通常以预测损失选 checkpoint，并默认 latent L2 可作 goal cost；长 horizon 失败就归咎于 rollout error。LeWorldModel 的独立复现却出现预测更准、长时规划更差的反常排序。论文要诊断表示中是否缺信息、预测是否崩溃，还是 objective geometry 与任务 reachability 失配。这是隐式世界模型与 MPC 的核心评估问题。

## Method

在冻结的 18.03M LeWorldModel（ViT-Tiny 192维+6层 action-conditioned predictor）上保持 CEM 的 300 candidates、30 iterations、30 elites、horizon 5 不变，只测/换终端 cost。先在真实 validation action 下自回归比较 imagined latent 与真实 encoder latent、静止 baseline；再从环境渲染位置构造 7,140 对，测 latent L2 对真实距离的分段单调性。

两种修复均不重训 world model：（1）350 个位置拟合 ridge latent→2D position，用解码后欧氏距离；（2）只用同 episode 两帧的时间间隔监督小 MLP cost(z_t,z_goal)，训练/测试 episode 隔离，并对两种方向对称。后者学习 steps-to-reach，随后又加入按真实动作 rollout 得到的 imagined embedding pairs，缓解 planner 分布和真实编码分布不匹配。

## Experiment

- 当前 checkpoint 在 5/25/50/75 environment steps 的 imagined/static error ratio 为 0.066/0.090/0.152/0.189；planner horizon 只覆盖 25 步，故预测跨度并非当下瓶颈。
- latent L2 与真实距离总体 Pearson r=0.426，20 units 内 r=0.668，40 后低于 0.13，80–300 区间均值反而下降 3.3%。37 个 offset-100 失败中 26 个最终比起点更远。
- 病理也存在于作者原权重（Spearman 0.423、80–300 spread −2.2%）。四 checkpoint 的 offset-100 成功率 80/66/26/14% 与 metric quality 完全同序，却与 one-step accuracy 逆序；不过每 checkpoint 仅一个 seed 且训练条件共同变化。
- 当前 checkpoint 上 ridge probe held-out R²=0.9922、位置 MAE 1.72；decoded cost 与真实距离 r=0.9897。temporal head 对空间距离 r=0.819、held-out temporal MAE 12.8 帧，但跨墙/同室成本比为 1.24；latent L2 为 0.96、position cost 按定义为 1.00。
- offset-100、budget 150 上，latent/position/temporal 成功率为 26/88/98%；temporal 在 budget 50 仍为 92%。McNemar 对两种长时修复均极显著；offset-25 则 94→92/98%，无明显代价。
- 作者原权重因 one-step error 0.410，real-pair 训练的 nonlinear head 在 imagined×real 上 MAE 恶化 74%，最终 temporal 仅 34%，不如更鲁棒的 linear position 70%；加入 imagined pairs 后分布差缩至 11%，但仍未追平。

## Value

论文给出一个非常实用的世界模型诊断顺序：先测 imagination 是否仍有信息，再测 planner objective 在任务尺度是否单调、是否感知障碍，最后检查 cost 的训练分布是否覆盖 imagined states。它提醒我们 prediction loss、linear decodability、latent metric 和 planning usability 是四种不同属性；JEPA 表示可以“编码了信息但几何不可直接用”。对任何 latent MPC/goal-reaching 工作，这比继续加大 predictor 更值得优先检查。

## Strengths

- 诊断链条闭合：排除预测崩溃，直接测 metric 饱和，复现于作者权重，再只换 cost 恢复规划。
- 所有 planning 比较使用同 checkpoint、同 episode draw、同预算，并精确复现发布 baseline。
- 位置 probe 与无状态 temporal head 两条独立修复，进一步用墙的 matched-distance 对照解释 reachability。
- 报告 exact McNemar、pair counts、分段相关及失败轨迹，而非只报最终成功率。
- 主动展示 temporal head 在另一 checkpoint 上失败，并定位 real→imagined distribution shift，避免过度包装。

## Weaknesses

- 全部结论来自一个二维 TwoRoom 环境，墙/门结构简单；尚未证明适用于高维连续控制、3D视觉或多对象接触。
- 每 checkpoint 仅一个 seed，四模型间 history size、action width、像素归一化同时改变，accuracy–metric 逆序只能算相关。
- ridge cost 使用环境可读位置，不是一般方案；temporal distance 也会混入行为 policy、速度和数据覆盖偏差。
- temporal head 的最佳 98% 依赖准确 predictor；在作者权重上仅 34%，说明 nonlinear learned objective 对 off-manifold imagination 脆弱。
- 论文没有解释为何 latent L2 饱和/反向，也未测试让训练表示本身 reachability-aware 的方案。
- 只改 terminal cost，未研究 uncertainty、multi-step accumulated cost、receding horizon 或局部极值对 CEM 的影响。

## Future Work

作者明确将 reachability-aware representation training 视为更有趣的开放问题，并承认需跨环境、多 seed、解开训练因素。后续应在迷宫、3D机器人和 Dreamer/TD-MPC 上复现，用 imagined-state 对训练 cost，比较 successor features、bisimulation/temporal contrastive metrics，并共同校准 predictor uncertainty 与 planner horizon。
