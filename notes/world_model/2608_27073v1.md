# SpatialCrafter: Single Image World Modeling with Generative 3D Proxies

## Insight

观察是仅由输入视图重建的点云永远缺少遮挡区，而让视频扩散先 hallucinate、再把生成帧回灌 3D memory 会把误差永久化。由此可推得：应在生成视频之前一次性补全一个全局 3D 代理，让视频模型只负责在固定几何上恢复外观。论文以 PaSS 锚点消融、81 帧极端相机轨迹及 RPE/RVE 验证：有锚点的生成代理大幅降低错位，RGB-D 条件和 PAC 进一步减少漂移；但“完整代理”仍是学习生成而非几何保证，且部分闭环指标并非最佳。

## Motivation

单图可探索场景生成服务于游戏、VR、导航和 embodied AI。纯视频扩散缺乏显式 3D，历史帧 memory 易发生透视/遮挡错误；静态重建代理对未见区域无约束，增量代理又依赖视频模型自身的空间能力并累积深度与拼接误差；360 panorama 也不能提供平移视差。论文针对的是 3D 世界生成中的核心长期一致性问题，并同时补足单图场景级 3D 训练数据稀缺。

## Method

1. 输入单图、预测深度、初始相机位姿和用户相机轨迹。先将可见 RGB-D 反投影、变换到目标坐标并 voxelize，得到稀疏锚点 Vcond。
2. Point-Anchored Sparse Structure (PaSS) Flow 在 TRELLIS 的 sparse-voxel rectified-flow 基础上，把 noisy voxel 与 Vcond 按通道拼接，以条件流匹配补全与输入坐标严格对齐的全局 sparse structure；随后 SLAT flow 预测各 active voxel 特征，3DGS decoder 得到粗糙全局代理。
3. 沿目标轨迹渲染代理得到时空一致但低质的 coarse RGB-D video。Generative Deferred Refiner 基于 Wan2.1-Fun-Control：RGB 与 depth 经冻结 VAE 独立编码后横向拼成 geometry latent，再与 noisy video latent 按通道拼接；参考图 latent 按 token 拼接。冻结预训练 DiT，仅训练 LoRA，以条件 flow-matching 生成最终 RGB-D 视频。
4. Proxy-Aware Corruption (PAC) 在训练时随机施加自适应模糊、块噪声或局部深度擦除，使 refiner 学会何处服从代理、何处补纹理/孔洞，降低推理代理与理想训练条件间的域差。
5. 数据引擎把 57,431 个 SpatialGen 房间、65,683 个 RealEstate10K 视频和 10,510 个 DL3DV 视频转成 SLAT/3DGS 与成对 RGB-D 轨迹；最终得到 115,295 个单图到场景样本和 87,115 个可控视频样本，其中 2.2K synthetic scenes 重渲染为 22,421 条连续视频。

核心创新是“原生生成的全局 3D proxy + 延迟外观细化”的职责分解，PaSS、并行 RGB-D 注入和 PAC 形成完整接口；底层 TRELLIS、Wan 和 3DGS 均为已有组件，但组合与数据工程具有明显新意。

## Experiment

- 在 104 个 SpatialGen-Video 闭环场景、100 个 RE10K 测试场景和 DL3DV 标准测试集上，从单图沿同一轨迹生成 81 帧。对比 2D memory 的 DFoT、GeometryForcing，以及 reconstructive proxy 的 ViewCrafter、GEN3C、Voyager；另将 Voyager 在新数据上微调为 Voyager†。指标含 FVD、PSNR、SSIM、LPIPS、重投影误差 RPE，以及仅 synthetic 闭环可算的 revisit rFID/RVE。
- SpatialGen-Video 上 SpatialCrafter 达 FVD 193.54、PSNR 14.775、LPIPS 0.416、RPE 0.093，明显优于次佳 ViewCrafter 的 339.04/14.098/0.471/0.125；但 RVE 38.69 不及 GEN3C 的 26.60。RE10K 上以 148.71 FVD、17.185 PSNR、0.266 LPIPS、0.078 RPE 全面领先。DL3DV 上 FVD 242.30、LPIPS 0.453 最好，但 RPE 0.149 略逊 ViewCrafter 的 0.147。论文未给置信区间、多随机种子或显著性检验。
- 仅微调 Voyager 数据虽把 synthetic FVD 从 801.04 降到 363.39，仍远差于 SpatialCrafter，支持收益不只来自数据集。不过架构、训练量与生成代理共同变化，不能完全分解贡献。
- PaSS end-to-end 消融把 synthetic FVD 从 472.07 降至 193.54，RPE 从 0.169 降至 0.093，RVE 从 153.47 降至 38.69。Refiner 消融使用 ground-truth coarse renderings，因而是较理想条件：camera-only、RGB-only、RGB-D、RGB-D+PAC 的 FVD 依次为 178.47、136.27、114.13、107.03，RPE 为 0.107、0.066、0.062、0.057；不能把最后的 107.03 与真实生成代理下的 193.54 直接比较。
- Proxy generator 以 16 张 H20 训练 20K steps；refiner 用 32 张 H20，先 256²/12K steps、再 512²/4K steps，每段 81 帧。论文没有报告端到端代理生成和 81 帧推理的延迟、显存或吞吐。

## Value

这项工作的关键价值是把“记住已见帧”升级为“先形成可渲染的全局 3D 假设”，再把大视频模型当作 deferred renderer。对 3D 世界模型很有启发：显式几何可以承担跨视角状态，生成模型承担未见区域与高频外观；训练时应主动模拟几何代理的缺陷。它目前更接近静态场景的 camera-conditioned world renderer，而不是含动作、物体状态转移和物理交互的通用世界模型。

## Strengths

- 问题分解清晰，PaSS 直接处理单图生成代理最致命的坐标错位，而非只增加视频上下文。
- 同时生成 RGB 与 depth，以全局 3DGS 代理约束 81 帧极端轨迹，兼顾可视化与几何指标。
- 新建 115K 级混合场景数据，并用 Voyager† 区分数据增益与方法增益。
- 消融覆盖 proxy anchor、RGB/depth 条件和 PAC，效果量级大；关键定量结果也在真实与 synthetic 域重复出现。

## Weaknesses

- 场景静态且控制量只有相机轨迹，没有物体动力学、agent action 或交互，标题中的“world modeling”能力边界较窄。
- “global complete 3D proxy”是生成假设而非可验证完整几何；论文主要评估最终视频，没有直接测代理的 mesh/point geometry、遮挡拓扑或新区域正确率。
- Refiner 四阶段消融使用 ground-truth coarse renderings，而部署使用生成代理，因而 PAC/RGB-D 的数值是理想上界，未完整反映两阶段误差耦合。
- SpatialGen、RE10K、DL3DV 同时构成训练来源和测试域；虽使用 held-out split，仍缺少全新数据源、户外长距离和真实机器人相机轨迹的跨域验证。
- SpatialGen 闭环 RVE 不如 GEN3C，DL3DV RPE 也略不如 ViewCrafter，说明最佳外观并不等于所有几何一致性指标最优。
- 训练成本高且没有推理效率、代理生成时间、显存或可交互帧率；代码、模型和数据在文中仍表述为“将发布”。

## Future Work

作者没有单列未来工作或明确改进路线。由实验边界合理推断，下一步应直接监督/评估全局代理几何，在生成代理而非 ground-truth 代理上做完整 refiner 消融，报告长轨迹推理效率，并扩展到动态物体、动作条件和闭环 agent interaction；此外需验证跨数据源泛化及 loop closure，而不只在训练来源的 held-out split 上评测。

## Rating

创新度评分：4/5 - 生成式全局 3D 代理、PaSS 对齐和 deferred video refinement 构成显著新方法，数据与效果也强；但依赖现成大模型且动态世界能力尚缺。
相关度评分：3/3 (Core) - 直接研究单图到可探索 3D 世界及长时跨视角视频一致性，是 3D/视频世界模型的核心问题。

## TL;DR

以单图生成全局3D代理再细化为一致RGB-D视频，大幅减轻长程漂移，值得精读。
