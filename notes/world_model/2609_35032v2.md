# JRDB-AVR: An Active Visual Reasoning Benchmark for Embodied Agents in Real-World Environments

## Insight
观察：具身 VLM 即使猜对问题，也可能从未看见正确的人、时刻和视角。推论：主动视觉推理要同时评价答案和它主动获取的视觉证据。JRDB-AVR 中最强普通基线答案/证据/两者同时正确率分别仅 33.65%/13.01%/5.96%；显式图记忆代理达 38.51%/27.50%/14.54%，验证答案与证据可明显脱钩。

## Motivation
被动视频问答默认提供完整视野，只计最终答案，难检验机器人在有限视角下“何时、往哪里看”以及是否锁定正确目标。这是具身感知与主动评测的重要问题；论文的“世界模型”是观察事实图，不预测未来视频或动作后物理演化。

## Method
利用 JRDB 全景机器人视频及人物轨迹、动作、姿态、关系标注建立时间场景图；七类生成器产出 2098 个跨时间/视角、多跳关系和动作边界问题，过滤掉可走捷径、锚点不唯一或证据不可核实的候选。测试时只给问题，代理调用 `observe(sequence, frame, angle)` 获取 480×480 视图，最后提交答案及目标人物的时间和框。报告答案正确率、目标证据正确率、两者同时正确率及“答对但证据错”的条件比例。参考代理把问题转成图查询计划，逐步观察并只写入有帧/视角出处的实体、属性、关系，最后由图求解器给答案。创新点主要是主动取证协议与答案/证据联合评测。

## Experiment
27 条 JRDB 测试序列、2098 问；比较六个小中型 VLM 在单次输入、思维链、搜索识别及 ReAct 下的表现，参考代理用 Qwen3.5 9B。最强基线两者同时正确率 5.96%，参考代理为 14.54%；其答对但证据错的条件比例仍达 62.25%。消融：无主动观察/无图模型时联合分 2.72%，仅主动 9.20%，仅图模型 3.62%，两者都有 14.54%。附录分项揭示 chain-hybrid 和 long-range 的联合分均为 0，整体受 unique-anchor 类 1620/2098 道题主导。

## Value
对视频/3D 模型评测的可借鉴点是要求预测或答案附带可核实的观察证据，尤其测主动视角选择和长时间目标绑定；作为具身推理基准可选读。其图记忆方法不回答模型是否学到动作条件动力学，需另设未来状态或干预预测测试。

## Strengths
用真实移动机器人全景记录构造可控主动观察接口；明确分开答案与证据分数；题目生成含时间、视角、多跳必要性检验；报告组件消融和各题族失败情况。

## Weaknesses
离线全景裁剪不能替代实时机器人移动与相机控制；证据只核对最终目标框，即使多跳中间关系未真实观察也可能拿到分。数据集中约 77% 为 unique-anchor，难题族样本少且联合分为零。被动与主动基线观察输入不同；“图模型”消融同时改变计划、记忆和求解，无法单独归因。总体联合正确率低，说明当前方案距可靠证据推理仍远。

## Future Work
作者指出应从离线记录迁移到实时机器人主动感知，并进一步提升跨人物、时间和视角的精确证据绑定；论文未给具体动力学世界模型扩展方案。

## Rating
创新度评分：3/5 - 主动观察与证据联合评测设计有价值，参考代理主要组合图记忆和已有工具调用。
相关度评分：2/3 (Related) - 与具身场景记忆和评测密切相关，但未研究视频生成、三维动力学或 JEPA/Dreamer 式隐式预测。

## TL;DR
用主动选时选视角和目标证据框揭示具身 VLM 的“答对却未看对”问题；适合借鉴评测设计，可选读。
