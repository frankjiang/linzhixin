# Physical Canvas: A Vision Tactile World Model For Robot Policy Evaluation And Learning

## Insight
观察：光学触觉图像可被通用视频 VAE 高质量重建，但视觉上可信的动作预测仍可能给出错误接触和任务成功状态。推论：把 RGB、触觉、标记位移、任务状态统一排成图像画布，并针对场景、跨模态和真实任务结果施加奖励监督，能使生成轨迹更适合闭环策略评估。零样本 Wan VAE 触觉重建与专用 UniT 对比、逐项消融及真实机器人评估支持此结论；对未见任务的泛化尚未证明。

## Motivation
接触丰富的机器人任务难以用纯视觉视频模型评估：小的滑动或接触错误足以反转成功判定，真实试验又昂贵。现有视觉触觉模型常用专门触觉编码器，扩展传感器较复杂；逐像素训练也不保证任务状态正确。因而需要能生成一致多模态观测、并以真实成功率验证的世界模型。

## Method
- 在统一 RGB 画布中横向排三路相机，纵向堆触觉图像、XYZ 标记位移的 RGB 编码及任务状态贴片；共用 Wan 2.2 的视频 VAE 与 DiT。将机器人 URDF 前向运动学投影成各相机的动作图，编码后逐位置加入画布潜 token，状态区域不直接注入动作。
- 固定初始 RGB 锚点、逐 8 帧更新一次多模态参考，以 flow matching 递归预测。用三个预训练并冻结的奖励模型后训练生成器：场景模型约束初始场景保留，模态模型约束视觉和触觉兼容；状态模型以真实观测的成功/失败为目标监督生成 RGB 的任务结果，不一味奖励成功。保留原流匹配损失。
- 生成世界中闭环评估 ACT、FM、π0.5；对 FM 和 π0.5，以每初态 8 条想象轨迹的终态状态奖励做 GRPO，只更新策略。训练世界模型用 3,805 条真实机器人轨迹，4 个任务各留 80 条测试轨迹；训练耗约 64 个加速器 × 3 天。

## Experiment
- 零样本触觉 VAE：Wan VAE 的 PSNR/LPIPS 为 35.51/0.0139，专用 UniT 为 31.72/0.0210，但 UniT 的 SSIM 更高（0.9613 对 0.9539）。
- 四项真实双臂任务中，RGB 预测相对 EVAC、Open-Sora、WoVR 最优：PSNR 21.172、FVD 116.274；模态消融 M0→M4 的触觉接触 MAE 0.03012→0.02278，但 Event F1 0.4970→0.4455，指标并非全面提升。
- 九个策略/批次点构成每任务成功率相关性：加状态监督后，四任务 Pearson r 均值从 0.602 升至 0.885，R² 均值 0.413→0.791；这是相关性而非成功率误差。机器人实测 π0.5 四任务平均成功率 SFT 59.1%、普通世界模型中 RL 67.5%、一致性模型中 RL 70.8%；FM 为 11.2%、16.6%、19.1%，其中两任务始终 0%。瓶盖任务的 π0.5 在一致性模型中反而从 90.0% 降至 86.6%。

## Value
对世界模型作为策略评估器提供了比视频观感更贴近用途的检验：跨策略、跨时间批次与真实成功率比较。视觉触觉统一编码和任务状态监督可作为视频世界模型引入接触信号、评价模拟器可用性的直接参考，值得精读。

## Strengths
涵盖多视角、触觉与任务状态的共同闭环；真实机器人验证策略排名与策略改进；成功和失败都进入世界模型数据及状态监督；逐项消融与附录给出数据量、训练/推理配置和指标定义。

## Weaknesses
只在同一双臂平台、四项任务和同类光学触觉传感器上验证，未检验新设备/新任务泛化；初态仍取真实观测，长期完全自主场景生成未评估；状态奖励模型与其所评价的生成轨迹可能共享偏差，Pearson r 高不表示绝对成功率校准；四任务均值掩盖 FM 在两任务 0% 和单任务退化；模型与数据采集成本很高。手工任务状态贴片和已标定 URDF 相机投影也限制迁移。

## Future Work
正文结论未提出明确的后续算法。可进一步检验跨传感器/任务泛化、真实成功率校准和更长时序的接触一致性；这些是本文结果引出的待解决问题，并非已完成实验。

## Rating
创新度评分：3/5 - 共用视频 VAE 的视觉触觉画布、三类一致性奖励和闭环策略评估组合扎实，但核心模块多沿用现有视频生成、动作投影与 GRPO。
相关度评分：3/3 (Core) - 直接研究动作条件视频世界模型，并以真实机器人闭环评估和策略学习检验其用途。

## TL;DR
把视觉触觉和任务状态统一到视频生成画布，用一致性奖励提升真实机器人策略评估及想象训练；值得精读。
