# Mitigating SM-Level Load Imbalance in 3D Gaussian Splatting on GPUs

## Insight
观察：3D Gaussian Splatting 中不同图像 tile 覆盖的高斯数差异很大，GPU SM 等待最慢 tile，平均工作量不足以描述耗时。将极重 tile 沿深度切分、让小任务持续分派，可提高 alpha 混合吞吐；实验的速度与近似无画质损失支持系统优化，未涉及学习世界动力学。

## Motivation
大规模 3DGS 场景渲染在高斯分布不均时出现 SM 负载失衡。常规一 tile 一线程块方案让少数重 tile 拖慢整帧。这对使用 3DGS 的系统有工程意义，但不是世界模型的表征或规划问题。

## Method
LPT 用 persistent kernel 按 tile 高斯数动态分配工作；离群重 tile 再按深度拆成多个 CTA，利用结合律合并前向透射率和颜色：C=C_A+T_A C_B。另用流与每帧代价估计选分块数 2/4/8/16，管理透明度饱和与任务同步。改动集中在 alpha blending/光栅化内核。

## Experiment
在城市级 Hier3DGS 场景，alpha 混合阶段平均提速 2.93×、最高 5.64×；驾驶场景 1.23×、常规场景 1.12×，表明收益依赖高斯分布长尾。渲染 PSNR 差异绝对值不超过约 0.0015 dB。比较基础 tile 内核和分块/调度变体；主要报告推理期混合阶段，而非训练或生成模型端到端耗时。

## Value
若 3D 世界模型使用大规模 3DGS 渲染且 profiling 显示 tile 负载失衡，可借鉴；对动力学建模、视频生成和动作规划没有直接贡献。

## Strengths
定位清楚的 GPU 瓶颈，给出负载统计、调度方案与画质一致性数据。

## Weaknesses
速度收益对普通场景有限；未证明端到端世界模型吞吐或交互延迟改善，平台相关的调度常数需重新调优。

## Future Work
可按 GPU 架构和帧间负载自适应调整分块/调度策略，验证端到端 3D 应用效果。

## Rating
创新度评分：2/5 - 有针对性的渲染内核优化，对世界模型研究仅属增量系统贡献。
相关度评分：1/3 (Tangential) - 3DGS 可作 3D 世界表示底座，但本文只优化 GPU 渲染。

## TL;DR
通过持续调度和重 tile 深度切分加速大规模 3DGS 场景混合；仅遇渲染瓶颈时可选读。
