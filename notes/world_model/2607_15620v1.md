# AEGIS: Assay-Aware Protocol Validation and Runtime Monitoring for Open-Source Liquid Handling Robots

## Insight
论文的 insight 是开放式液体处理机器人有两类 silent failure：协议代码语法正确但违反 assay-level invariant，或物理执行中缺 tip、少吸/少吐、气泡等日志不可见错误。Observation 是便宜 OT-2 没有高端液体处理器的压力/液位监控；推论是需要 pre-flight 语义规则检查和 runtime 视觉轨迹异常检测两层防线。Layer 2 的“world model”非常轻量：用正常四帧 pipette trajectory 的 PCA 重建误差作为异常信号。

## Motivation
论文解决 self-driving lab 中“机器人运行成功但实验数据已被污染”的问题。现有 LLM protocol generation、Opentrons simulator、BioScript/PRISM 等多检查可执行性、粗粒度生物合理性或机器人外部运动，不检查 assay-specific invariants，也不监控 OT-2 内部 pipetting 失败。这个问题对实验室自动化关键，但不是视频/3D/隐式世界模型主线。

## Method
AEGIS 两层结构。Layer 1 是 assay-aware validator：22 条 JSON 规则覆盖 PCR、Bradford、serial dilution、drug controls 等，LLM 读取规则库、Opentrons API 语义和 Python 协议源码，输出 assay family、逐规则判断和 pass/fail。Layer 2 是 runtime monitor：前视 USB 摄像头 1fps，YOLOv8-nano 检出 pipette tip，抽取 aspirate/transit/dispense/post-dispense 四帧，裁剪为 48x48 后拼成 9216-d 轨迹向量；PCA(k=15) 在正常样本上拟合，重建误差做 triage，gray-zone/blank-floor 再交给 Claude Opus 4.7 VLM self-vote 决定是否 pause OT-2。

## Experiment
Layer 1 使用 24 个 OT-2 协议、5 类 assay、13 个单 bug 和 multi-bug set。所有 LLM-backed hybrid 配置对 injected bugs 100% recall；调整标签后 o4-mini、Nemotron-3 Ultra、Claude Opus 4 F1=0.968，规则缺失会显著增加 false positives，rules-only F1=0.741。Layer 2 离线 p1000 LOPO 评估 AP=0.89、AUROC=0.80、operating F1=0.71；partial/no-dispense 较好，air bubble 弱。p20 因分辨率限制 F1=0.47。真实 OT-2 演示中红/黄染料 partial dispense cascade 3/5、always-VLM 5/5，no-tip 5/5，水基本失败；effective-halt latency 13.27s，cascade 估计每 96-well plate VLM 成本 1.63 美元。

## Value
对我们主要方向的直接价值低，但有一个小启发：小数据真实部署时，简单 train-on-normal dynamics/trajectory model 可能比深模型更可靠，且应和昂贵 VLM 做 cascade，而不是让单一模型直接决定安全动作。对于机器人 world model 的异常检测分支可粗读。

## Strengths
问题很真实，系统覆盖 pre-flight 和 runtime 两个互补 failure surface；小样本 PCA 的选择有负结果支撑；评估诚实报告透明液体、水、p20、air bubble、latency 和成本边界；开放 benchmark/rules/weights 的意图明确。

## Weaknesses
World model 技术含量较低，本质是 PCA 重建误差；runtime 样本很小，live demo 每格只有 5 次；水和小体积 pipette 失败明显；VLM 仍可能幻觉或漏检；多通道头、复杂协议和闭环恢复未验证。

## Future Work
作者提出更强/在线的 trajectory world model、tiered VLM gate、主动跟踪或更高分辨率摄像头、top-down plate view 作为透明液体补充、区分可软件恢复和需人工干预的失败，并扩展 assay rules 和 fleet 部署。

## Rating
创新度评分：2/5 - 工程集成扎实，但核心建模是规则库+LLM和PCA异常检测，算法创新有限。
相关度评分：1/3 (Tangential) - 属于机器人视觉监控和实验室自动化，与视频/3D/隐式世界模型只有异常检测层面的间接关系。

## TL;DR
AEGIS用规则LLM和PCA轨迹模型守护OT-2实验流程，工程可借鉴，世界模型主线可跳过。
