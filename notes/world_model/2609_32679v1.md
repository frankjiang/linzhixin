# The GUI Is Not the State: Diagnosing State Aliasing in GUI World Models

## Insight
相同当前界面与动作可能因剪贴板、文件、列表或计时器等隐状态不同而产生不同下一界面。论文形式化“观察等价却预测不等价”的状态混叠，并证明这种成对条件下，观察单独条件化的最优对数损失仍有正的 Jensen–Shannon 散度下界；历史的受控未来等价类构成最小充分预测状态。该结论是信息论性质，实际恢复效果另由实验验证。

## Motivation
GUI 世界模型通常只以当前屏幕和动作预测，忽略了不可见却影响转移的应用状态。此问题对以生成未来界面辅助规划的代理很关键，也与视频世界模型的遮挡状态记忆存在方法联系。

## Method
StateAliasBench 由真实 Android 交互构造严格成对样本：当前模型可见输入与动作相同，隐藏状态与语义未来不同；覆盖持久文件、剪贴板、有序集合、时间截止四类。Qwen3.5-2B 依据历史输出结构化 JSON 状态；四个领域教师提供软标签，经多教师蒸馏为统一估计器。确定性接口把恢复状态与候选动作解析成状态后果，注入冻结的 Code2World-8B/gWorld-8B 请求。创新主要在诊断协议和显式状态接口。

## Experiment
主要指标 PairCorrect 要求一对分支均预测正确。200 对/类别的 StateAliasBench 上，两种冻结 WM 仅看当前观察时所有类别 PairCorrect 均为 0；加入统一恢复状态后，Code2World/gWorld 的宏平均分别达 79.38%/80.63%，oracle 状态更高。直接塞原始历史对部分类别有效但远不稳定。Code2World 的 DINOv2 下一界面相似度 0.4718→0.6218。AndroidWorld 全 116 任务中，GPT-5.4 代理的 +WM 到 +WM+状态成功率为 58.62%→60.34%，Qwen3-VL-8B 为 44.83%→47.41%；后者只对应 3 个救回任务。多教师蒸馏相对直接联合训练的最弱类别状态恢复 PairCorrect 69.5%→82.0%；跨应用转移的平均精确率降为 79.75%。

## Value
为部分可观测世界模型提供可复用的评价范式：固定像素观察和动作、改变历史隐状态，再检测预测是否分叉。视频/3D 中可据此设计遮挡物身份与物理状态的反事实配对测试。

## Strengths
定义清楚，成对干预隔离输入不足；oracle、原始历史、专家及统一模型对照充分；补充真实代理任务、跨应用与时延分析。

## Weaknesses
仅证明一步、规定动作范围内的预测充分性；结构化状态由四类模板与任务知识设计，扩展到开放世界视频未验证。成对数据虽控制输入，GUI 语义具有专门性；代理总任务成功率收益仅 1.72–2.58 个百分点。额外估计器平均产生 0.768 秒延迟。

## TL;DR
用同屏同动作异隐状态配对揭示世界模型状态混叠，并用历史状态恢复改善预测；评测方法值得精读。
