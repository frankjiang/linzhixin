# Thinking with Patterns: Breaking the Perceptual Bottleneck in Visual Planning via Pattern Induction

## Insight
将 Thinking with Images (TWI) 形式化为逐步构建准确内部世界模型的工具。通过 Pattern Inference（识别已知视觉模式并直接推断局部世界模型结构）和 Pattern Induction（从经验中在线发现和优化可复用的视觉模式专家）来提升 VLM 视觉规划的效率。

## Motivation
VLM 在视觉规划中受限于单步感知能力。TWI 可以分解感知过程但计算开销大。需要在准确性和效率之间取得平衡。

## Method
1. **Pattern Inference**: VLM 在新任务中识别已知视觉模式，直接推断局部世界模型结构，跳过逐像素探索
2. **Pattern Induction**: 在线归纳学习策略，将视觉模式视为复合可复用专家，从经验中自主发现和优化

## Experiment
FrozenLake、Crafter、CubeBench 三个领域验证，在准确性和效率之间取得平衡。

## Value
VLM 视觉规划工作，"世界模型"更多是指内部状态表示而非生成式世界模型。与视频/3D 世界模型关联有限。Pattern Induction 的在线学习思路有一定新意。

## Strengths
亮点是VLM 视觉规划工作，"世界模型"更多是指内部状态表示而非生成式世界模型。

## Weaknesses
不足是与视频/3D 世界模型关联有限。
