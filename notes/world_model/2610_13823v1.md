# Same Query, Different Answer: Run-to-Run Variance in Semantic Query Processing

## Insight
观察：温度为 0 的 LLM 语义算子仍会逐行改变判定，而一条查询可依赖大量行。把每行输出视作随机变量、查询结果视作可能世界函数；若完整结果暴露 `n` 个近独立行、平均两次分歧率为 `δ`，答案复现概率约为 `e^(−nδ)`。三个数据库基准的重复执行支持“查询计划放大行级波动”的推论；这是有独立性假设的经验模型，不涉及机器学习中的世界模型。

## Motivation
语义查询系统以 LLM 对记录做筛选、抽取、连接和聚合，现有基准常把温度 0 的少量执行当作确定结果。若单行判断波动可改变查询答案、系统排名或优化器标定，基准结论的可信度就受影响。论文关注数据库／LLM 语义算子可复现性，是该领域的重要测量问题。

## Method
- 保持 SemBench、LRO-Bench、UDA-Bench 的原查询、提示词和评分器，重复运行并记录每次算子调用、逐项输出和最终答案，共约 121.9 万次模型调用；另重新分析 SemBench 已发布的五次执行。
- 将行级分歧经 LIMIT、COUNT、全量连接、SQL 等算子传播；用经验行级输出分布模拟成对可能世界，估计答案复现率，再与实测对比。
- 测试模型／部署、温度、并发、输入顺序、推理长度等因素，并离线重放投票、选择性重复查询与已标定代理级联。论文明确定位为实验分析，不提出新的视频或隐式世界模型算法。

## Experiment
- SemBench 已发布结果中，21% 的文本查询“系统×查询”单元在五次运行间改变质量；温度 0 时五次运行的逐项翻转率依模型为 0.07%–10.2%，一项医疗抽取达 24.0%。在完整暴露每项输出的查询中，`e^(−nδ)` 对 24 个单元的 23 个预测误差不超过 0.15。
- UDA-Bench 仅 4.0%–7.5% 的抽取值变化，却使 123 个 SQL 查询中约 67%–68% 的结果表变化。LRO-Bench 的 28 项方法推荐测试中，16 项置信区间含零。质量分数还会掩盖答案变化。
- 对同一模型 10 次执行重放，三票法约双倍调用成本、平均仅减少 36% 的逐项分歧；仅复查第一轮推理文本最长的 20% 行能以 1.4 倍调用成本获得全票收益的约 64%。指标包括逐项翻转率、答案复现率、质量波动、失败率和置信区间。

## Value
对本项目的视频、3D 或 JEPA／Dreamer 世界模型方法设计无直接价值。一般性的评测启示是：随机模型的逐样本波动与聚合指标可能相差很大，需报告重复运行分布；这不足以构成本方向的相关论文。

## Strengths
- 逐调用日志能区分模型输出、查询答案和基准质量三个层级的复现性；跨多个基准与部署实测。
- 有清楚的概率模型、运行控制和投票／级联复盘，且公开日志与分析脚本。

## Weaknesses
- “可能世界”是概率数据库术语；没有视觉环境、动作条件动力学、3D 场景或潜在状态预测。
- 行独立假设和仅五次常规重复会漏掉稀有翻转；连接实验只采样 40 条评论，部分模型服务负载无法控制。

## Future Work
作者未列出面向世界模型的未来方向；对语义查询系统建议增加重复测量、记录逐项输出与部署信息，并进一步估计罕见输出变化。

## Rating

相关度评分：0/3 (Noise) - 研究对象是 LLM 语义数据库查询，和视频／3D／隐式世界模型无实质关联。

## TL;DR
揭示温度零的语义数据库查询仍会逐行波动并放大为答案变化；与目标世界模型无关，可跳过。
