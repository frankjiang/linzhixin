# One Lens, Many Worlds: A Capability-Typed Interface for World-Model Interpretability

## Insight
核心观察：世界模型的可解释性工具（probing、activation patching、SAE、surprise analysis）在本质上共享相同的原语（读取激活、覆写激活、观察效果），但由于现有工具（如 TransformerLens）假设 transformer LM 结构，每换一个世界模型架构就需要重新实现一遍。论文推论：这种碎片化是工具的属性而非模型的属性——所有世界模型（无论是 Dreamer 的循环状态空间、IRIS 的 token 序列、还是 I-JEPA 的联合嵌入）都可以被统一抽象为 encoder + transition + optional heads 的结构。在 I-JEPA 案例中验证了 attention weight 与 integrated gradients 归因仅弱相关（Spearman rho 在 4 层中仅 1 层显著为正），说明高注意力 patch 并非因果重要 patch，这一发现完全通过统一接口获得，无需任何模型特定代码。

## Motivation
**问题**：世界模型架构多样化（latent-recurrent / transformer-token / joint-embedding），但可解释性方法本质相同，却因缺乏统一抽象而需逐架构重写，结果不可跨架构比较。

**同行做法**：TransformerLens 为 transformer LM 建立了 hook-and-cache 抽象，催生了大量 circuit-level 分析；但它假设 token 序列结构，无法表达 action input、environment step、imagination rollout、混合连续/离散 latent 等世界模型特有语义。Captum/NNsight/Penzai 等通用库提供归因原语但不建模世界模型语义。

**是否关键**：对世界模型可解释性研究是基础设施级问题。但对世界模型建模本身不构成直接推动。

## Method
**三层架构**：
1. **Adapter 层**：每个世界模型实现 `BaseModelAdapter`，提供 4 个必选方法（`encode`, `transition`, `initial_state`, `sample_z`）和 5 个可选 head（`decode`, `predict_reward`, `predict_continue`, `actor_forward`, `critic_forward`）。通过 `WorldModelCapabilities` 描述符声明能力向量 c ∈ {0,1}^7，分析代码按描述符调度而非按模型类调度。
2. **Hook & Cache 层**：`HookedWorldModel` 包装器在 adapter 输出上挂载命名 hook point，通过 `HookCacheManager` 实现时间索引的激活缓存。两个入口：`run_with_cache`（全量缓存用于离线分析）和 `run_with_hooks`（安装临时函数用于 patching/ablation/intervention replay）。
3. **Analysis 层**：probing（线性/ridge/logistic + 交叉验证）、activation patching（Algorithm 1）、SAE（ReLU/top-k/gated，含 L0/重建保真度/死特征率）、surprise（后验-先验 KL 散度）、语义探针（DINO/CLIP 投影）、解纠缠（MIG/DCI/SAP）、CKA、归因（IG + SmoothGrad）、不确定性分解等，均只写一次。

**创新程度**：本质是软件工程 + 类型系统设计的贡献，将 TransformerLens 的思路推广到世界模型家族。方法论上无新分析技术，创新在于抽象设计。

## Experiment
**5.1 覆盖性验证**：Table 1 列出 9 个已实现 adapter（DreamerV1-V3、PlaNet、TD-MPC2、IRIS、Decision Transformer、I-JEPA、Ha-Schmidhuber），展示统一接口对 RL 和自监督模型的兼容性。

**5.2 I-JEPA 案例研究**：对 I-JEPA predictor（ViT）逐层比较 integrated gradients 归因与 attention weight 的 context-patch 重要性排序。指标：top-k Jaccard overlap 和 Spearman rank correlation。结果：4 层中仅 layer 2 有弱正相关（rho ≈ 0.08），其余层与零不可区分。结论：attention ≠ attribution。

**5.3 Hook 层开销**：Table 2，I-JEPA adapter 上测量——bare adapter 202.5 ms/step，挂载 hook points 但不激活 227.4 ms/step（+12.3%），full `run_with_cache` 1360.4 ms/step（6.7x）。12% 的 idle 开销支持 always-on 可解释性遥测。

实验整体偏轻量，深度分析仅限 I-JEPA 单一家族，缺乏跨架构对比实验。

## Value
**工具价值**：如果你需要对 Dreamer/JEPA/IRIS 等多种世界模型做可解释性分析，这个统一框架可以显著减少重复工作。开源实现可直接使用。

**对我们的启发**：
- 将世界模型形式化为 (O, S, Z, A, ι, E, τ, H) 的元组抽象比较清晰，可作为 survey 或分类法的参考框架
- I-JEPA 中 attention ≠ causal importance 的发现值得注意，在分析 implicit world model 内部表征时不应简单依赖 attention map
- 如果我们需要对比不同世界模型的内部表征（如 video world model vs 3D world model），这类统一接口有工程价值

**待解决问题**：
- 深度实证仅限 I-JEPA，Dreamer/V-JEPA/Cosmos 等主流模型的跨架构对比尚未完成
- 部分 adapter 是架构重实现而非加载原始 checkpoint
- overhead 数据缺少硬件细节和统计方差

## Strengths
亮点是如果你需要对 Dreamer/JEPA/IRIS 等多种世界模型做可解释性分析，这个统一框架可以显著减少重复工作。
