# IMU-Free Body-Frame State Estimation with Sparse Scene Flow for Quadcopters

## Insight
核心 observation 是静态场景点可在无 IMU/GPS 时充当隐式惯性参考：在机体系中，其位置随已知刚体运动确定演化，视觉创新可经协方差互相关修正飞行器状态。论文进一步把 EKF 相对位姿作为先验送入四视图 MAP，避免把同一 feature measurement 重复计数。但这属于几何状态估计，不是学习世界模型。

## Motivation
目标是仅用同步双目与电机推力估计无人机位姿、速度、重力、扰动及稀疏 3D scene flow，为下游机体系世界模型提供带协方差的输入。无惯导在 GPS-denied 场景重要，但与用户关注的生成式/隐式世界模型只有接口层联系。

## Method
连续—离散流形 EKF 维护 SE(3)+速度/角速度/重力/扰动和静态特征；FAST/Shi-Tomasi 检测、LK/SSD 时序跟踪、NCC 双目匹配，预测协方差限定搜索区，NIS χ² 门控剔除运动点。两时刻双目四视图联合 MAP 用 EKF 相对位姿先验，同时估计点位置、速度与协方差；兴趣点可围绕外部 focus 做类 foveation 分配。

## Experiment
只在 VID 的单条 79.0 s、4733 帧室内轻载悬停序列验证，无基线和消融。全序列平移 RMSE 1.104 m（中位 0.229 m）、旋转 RMSE 7.55°（中位 2.58°）、线速度 RMSE 0.502 m/s、角速度 RMSE 0.102 rad/s；着陆后 2 秒内平移误差从 0.32 m 恶化至 3.4 m、旋转从 2.2°至 20°。论文坦承过程噪声未标定、滤波过度自信、MM 对应数值不稳定且被禁用，并有 point retirement 实现 bug。

## Value
对构建带不确定性的 3D observation front-end 有参考价值，尤其是机体系锚定和避免双计数；但不涉及学习、想象、预测或规划，不能作为世界模型方法论文看待。

## Strengths
数学推导和接口定义详细；输出状态、相对位姿、稀疏流及联合协方差；主动暴露实现 bug、不可观方向和未标定参数；真实双目飞行序列而非纯模拟。

## Weaknesses
单序列、简单悬停、无基线，外部有效性很弱；起降发生灾难性发散；声称 IMU-free，但未来方案又计划引入陀螺/加速度计；场景流主体的定量评测缺失；多个模块仍未完成或数值不稳定，离实时闭环较远。

## Future Work
作者计划把系统拆成滑窗 ego-state 与环境状态两进程，引入转速、电流、陀螺和加速度计，在线估计偏置/惯量/气动参数，移植 C++ 与可编程硬件，并在有界延迟下做闭环控制。

## Rating
创新度评分：2/5 - 多个经典几何/滤波模块的细致集成有工程价值，但验证不足且系统仍是 work in progress。
相关度评分：1/3 (Tangential) - 可作为 3D 世界模型的感知前端，论文自身并非世界模型研究。

## TL;DR
双目加推力实现无IMU机体系状态与稀疏场景流，前端可参考，世界模型方向可跳过。
