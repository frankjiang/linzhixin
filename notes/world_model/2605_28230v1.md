# Proprio: Training-Free Self-Scoring of Video Generative Models for Physically Plausible Generation

## Insight
视频生成模型的光流残差（flow residual）可作为物理合理性的自评分信号：对同一 prompt 采样 N 个视频，用预训练光流模型提取流场，计算 forward-backward consistency residual，残差越小表示运动越一致、物理越合理。原理：物理合理的运动具有时间对称性（forward-backward flow 一致），不合理运动（穿透、漂浮、突变）会产生大残差。

## Motivation
视频生成模型生成的视频常违反物理规律（物体穿透、悬浮、运动不连续），但现有评估指标（FVD、FID）无法捕捉这些问题。需要一个 training-free、model-agnostic 的方法在推理时筛选物理合理的视频。

## Method
- **Self-scoring**：对每个 prompt 采样 N 个视频候选（N=8-16）
- **Flow residual 计算**：用 UniMatch 提取 forward/backward 光流，计算 cycle consistency residual 作为物理合理性得分
- **Best-of-N 选择**：选残差最小的视频作为输出
- 无需训练、无需额外模型、适用于任意视频生成器
- 可与 self-refinement（iterative denoising with flow guidance）结合进一步提升

## Experiment
- 在 Physics-IQ benchmark 上：Proprio 将 CogVideoX-5B 提升 +16.5%，Wan2.1-14B 提升 +8.2%
- 在 VideoPhy2-hard 上：+20.6% 提升
- 对比 VideoScore、VBench 等 reward model，flow residual 与物理合理性相关性更高
- Self-refinement 模式额外提升 3-5%，但计算成本增加
- 局限：对静态场景（无运动）flow residual 退化为噪声；N 较大时边际收益递减

## Value
方法简洁优雅，flow residual 作为物理合理性代理指标的思路有启发性。对视频世界模型的质量控制有直接参考价值——可用于 world model 生成的视频帧质量筛选。但本身不是世界模型方法，而是视频生成的后处理/评估工具。
