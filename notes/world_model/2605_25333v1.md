# Teaching Video Generators to Remember: Eliciting Dynamic Memory for Out-of-Sight State Evolution

> arxiv: 2605.25333v1 | 2026-05-25 | Tianshuo Xu et al. (Applied Intuition, UC Berkeley)

**TL;DR**: 提出 ReMind 框架，通过记忆导向数据构建、PM-RoPE 位置编码和节点结构化课程训练，激活预训练视频扩散 Transformer 中 KV cache 的动态记忆能力，使模型在遮挡/离屏后能正确恢复隐藏状态演化。方向高度相关，值得精读。

**创新度**: 3/5
**相关度**: 2/3

## Insight

**观察**: 预训练的自回归视频扩散 Transformer 本身已具备 KV cache 的非局部检索机制，但标准训练仅将帧序列视为局部链式结构（local chain），从未暴露过"中断后需跳回远端锚点"的场景。因此模型虽有"硬件"（attention + KV cache），却缺乏将其用作动态记忆的"软件"（训练信号）。

**推论**: 不需要引入额外的记忆模块或 3D 表示，仅需设计合适的训练数据和课程，就能让现有 KV cache 充当可寻址的动态记忆。

**验证**: KV-importance heatmap（Fig. 5）直观展示了训练后模型在遮挡恢复帧上的注意力从"对角线近邻"转变为"跳回遮挡前锚点"（权重 0.92/0.86），与假说一致。

## Motivation

**问题**: 视频世界模型在物体被遮挡、相机移开或灯光关闭后，隐藏状态会冻结/重置，恢复可见时无法正确反映物理演化（如杯子应继续被倒满、气球应继续膨胀）。STEVO-Bench 将此称为 out-of-sight state evolution 问题。

**同行方案**:
- **单向链式记忆**（标准 Diffusion-AR）: KV cache 仅作滚动缓冲，高度依赖时间局部性，遮挡后失效。
- **静态记忆**（WorldPlay、InSpatio-World、NeoVerse）: 注入 3D warp 或历史参考帧作为固定锚点，但忽略遮挡期间的状态演化，且 dual-attention 计算翻倍。

**关键性**: 是的。维持不可见状态的持续演化是世界模型物理一致性的核心要求，直接关系到仿真/规划任务的可靠性。

## Method

**整体流程**:
1. **Memory-Oriented Data Construction**: 从 OpenVid/DL3DV 等数据集出发，构建包含 100+ 动态事件类别的分类体系。用 VLM 过滤 + Pexels 检索获取真实视频，用 Neoverse 渲染合成相机环绕/遮挡场景。每个片段被转换为 frame graph，标注 anchor（可靠状态帧）、interruption（遮挡/黑屏/相机移开）和 recovery（恢复帧），并附加中断增强（camera loop / light toggle / occluder / zoom）。

2. **PM-RoPE (Projective Memory RoPE)**: 将相机外参 + 内参编码为紧凑描述子 c_i，通过零初始化 MLP 映射为 RoPE 相位偏移 delta_i，叠加到标准时间位置上。同时在 value/output 路径注入零初始化残差投影（W_deltaV, W_deltaO），实现相机感知的时空寻址。关键优势：单次 self-attention 操作内完成（不需要 dual-attention），且初始化时等价于原始 RoPE，保留预训练路径。

3. **Streaming KV Cache**: 保留缓存 chunk 的原始帧位置（非连续压缩），使模型能区分远端锚点和近端噪声。

4. **Node-Structured Training Curriculum** (四种互补策略):
   - All-history: chunk-causal 全历史训练，匹配推理流程
   - Node-drop / Noisy-memory: 丢弃或加噪中间节点，迫使模型跳回锚点
   - V2V suffix/frontier: 仅监督恢复后缀，匹配自回归部署
   - Reference-cache: 在时间间隔后拼接干净参考 chunk，训练非连续记忆检索

5. **Dynamic Auxiliary Loss**: flow-matching loss + temporal-delta loss，自适应加权，增强对低占比动态区域的关注。

**创新程度**: PM-RoPE 设计简洁优雅（单注意力路径 + 零初始化保持预训练兼容）；frame graph + 节点课程的训练范式有新意；整体是 training recipe 层面的系统性工作，单点突破性一般。

## Experiment

**评估协议**:
- STEVO-Bench I2V: 5 指标（State Progress / Physical Plausibility / Coherence / Observation Control / Action Control）
- VBench I2V: 语义准确性 / 运动时序 / 视觉质量
- 消融实验 + KV-importance 可视化

**主要结果**:
- STEVO-Bench Total 300.9，最高（InSpatio-World 253.4，WAN 2.2 240.8）
- State Progress 14.5%（第一），Coherence 96.4%（接近最优），关键是在执行 Observation Control（41.6%）的同时维持高 State Progress，而 InSpatio-World 虽 Coherence 99.6% 但 Observation Control 0.0%（回避了遮挡挑战）
- VBench 三项指标均优于 InSpatio-World（语义 98.16 vs 90.29，运动 77.22 vs 76.11，视觉 65.18 vs 56.83），无灾难性遗忘

**消融**:
- PM-RoPE Full > QK only > VO only > Dual Attention (WorldPlay)，LPIPS 0.403 vs 0.507
- Dynamic + adaptive loss 在语义一致性上全面优于 flow-only（以微小 LPIPS 代价换取更好的内容保持）

**KV-importance 分析**: 训练后注意力从对角近邻偏移到语义相关的远端锚点，定量验证了动态记忆假说。

## Value

**工作价值**: 中上。系统性地解决了视频世界模型中一个重要且被忽视的问题（out-of-sight state evolution），方法设计务实（不引入新模块，激活已有能力），实验全面。STEVO-Bench 上的领先幅度显著。

**对我们的启发**:
- KV cache 作为动态记忆的视角很有价值：对于隐式世界模型（如 JEPA/Dreamer），类似的"训练信号缺失导致记忆能力未被激活"的问题可能同样存在
- PM-RoPE 的"零初始化 + 相位偏移"范式可推广到其他需要注入几何先验的 attention 场景
- Frame graph + 节点课程的训练范式可用于其他需要长程记忆的任务
- 提示我们在评估世界模型时，应关注 out-of-sight 恢复能力，而非仅关注可见帧质量

**待解决问题**:
- 仅处理特定中断类型（遮挡/黑屏/相机移开），未覆盖一般性物理推理失败
- 依赖相机位姿和深度估计质量，web 视频的位姿误差可能削弱 PM-RoPE
- State Progress 绝对值仍然很低（14.5%），说明隐藏状态演化仍是开放难题
- 未探索与 3D 表示或显式物理模型的结合

## Strengths
亮点是Memory-Oriented Data Construction: 从 OpenVid/DL3DV 等数据集出发，构建包含 100+ 动态事件类别的分类体系。

## Weaknesses
不足是PM-RoPE 的"零初始化 + 相位偏移"范式可推广到其他需要注入几何先验的 attention 场景

## Future Work
作者未明确提出具体未来工作；从局限看，后续需要围绕“PM-RoPE 的"零初始化 + 相位偏移"范式可推广到其他需要注入几何先验的 attention 场景”补充更大规模验证、跨场景扩展或方法改进。
