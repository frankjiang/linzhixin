# Radio Environment Mapping with World Models for Active Measurement Control

## Insight
将世界模型的"学习内部表征-做梦推演-主动决策"范式迁移到无线通信领域的无线电环境地图（REM）重建问题。核心观察：在测量预算有限时，传统方法（GP插值）被动地处理已有数据，缺乏对"下一步测哪里最有价值"的推理能力。世界模型通过dreaming机制可以模拟不同测量动作的预期后果，从而主动选择最有信息量的测量位置。

## Motivation
6G网络需要精确的无线电环境地图（RSSI地图）来支持室内定位、频谱管理等任务。实际部署中测量成本高、预算有限，且环境会因人员/物体移动而动态变化。现有REM构建方法（GP、GAN、CNN自编码器等）都是被动式的——给定测量数据做插值/回归，无法主动规划测量策略。本文将REM重建形式化为序列决策问题，引入世界模型框架来实现主动测量选择。

## Method
框架由两个核心组件组成：
- **Vision Model（VAE）**：输入三通道网格观测（空环境RSSI地图 + 稀疏测量值 + 二值测量掩码），编码为64维隐状态，解码为完整RSSI地图估计
- **Dynamics Model（LSTM）**：以当前隐状态和候选测量位置（归一化坐标）为条件，预测下一步隐状态的高斯分布

主动测量选择通过dreaming实现：
1. 从候选池（大小P=40）中逐一考虑每个候选测量位置
2. 对每个候选，通过dynamics model采样K=12次rollout，解码得到K张预测RSSI地图
3. 计算每个像素位置上K次预测的方差，取空间平均作为该候选的不确定性得分
4. 选择方差最小的候选（即预测最确定的位置）作为下一个测量点

技术上较为直接——VAE + LSTM的组合是标准配置，dreaming策略也是variance-based的简单启发式。

## Experiment
- **数据**：室内WiFi 2.4GHz RSSI数据集，含空/有人占用的成对地图，多种分辨率（9x11到144x176）
- **基线**：空房间基线（直接用空环境地图）、GP插值（从空环境地图学习协方差核）
- **结果**：
  - 少样本场景优势显著：N=10时RMSE约为GP的1/4；N=1时即已超越GP和空房间基线
  - 随测量数增加，GP逐渐追上，但世界模型始终保持优势
  - 跨分辨率一致有效：9x11环境下RMSE降低4.7倍，144x176下降低1.9倍
  - GP计算复杂度随测量数立方增长，世界模型保持恒定

实验规模较小（单个AP、单一室内场景、4对数据中3对训练1对验证），泛化性验证不足。

## Value
本文的贡献在于将世界模型范式（特别是Dreamer风格的learn-dream-act循环）应用到一个新领域，验证了dreaming机制在主动感知/测量规划中的有效性。但技术组件（VAE+LSTM+variance-based selection）都是标准方法的直接组合，无架构或算法层面的创新。

对视频/3D世界模型研究的启发极为有限——本文处理的是2D静态信号强度地图的序列重建，不涉及时序视觉预测、3D几何理解或隐式表征学习。"世界模型"在此仅是一个方法论框架的借用，而非对世界模型本身的研究推进。
