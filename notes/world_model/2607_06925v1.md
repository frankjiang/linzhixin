# Grounding Spatial Relations in a Compact World Model: Instruction Leakage and a Goal-Free Dynamics Fix

## Insight
这篇的 insight 很明确：目标条件 world model 的高关系读出准确率可能不是感知 grounding，而是指令转录。Observation：当 instruction 直接命名被评分关系时，goal-conditioned predictor 可以把“left/right/above/below”复制进预测 anchor，不必看场景。推论是评估 grounding 时必须做 goal-withheld 和 counterfactual goal probe；若 leakage 存在，goal 不应进入 dynamics，而应只进入 planner cost。作者用 tabletop、BabyAI、Language-Table 和 action ablation 支撑该 characterization。

## Motivation
紧凑 JEPA/latent world model 常用显式 reference anchors 来 grounding 空间关系，再把语言目标作为 dynamics 条件。看起来这能让模型处理“把红块放到蓝块左边”这类 relational goal。但如果目标文本本身包含答案，预测器可能学到捷径，导致表示指标虚高、控制反而受损。这个问题对语言条件 JEPA、object-centric/point-based world model 和规划式 latent world model 都是关键。

## Method
作者构造 PrismWM：ViT-tiny 编码图像序列，状态分解为 JEPA latent z、metric point anchors p 和 goal embedding g；action-conditioned transformer predictor rollout (z, p)。任务是 2D relational tabletop，目标/anchor 之间关系 r 属于 left/right/above/below，ambiguity 由重复 distractor 数控制。

模型变体包括 GoalDyn、GoalDyn+Read、GoalFree、NoGoal、TextGoal、ObjToken。关键评估把 representation 和 control 分开：

- Representation：从 observed/predicted anchors 几何读出关系，并用 linear probe 测 latent。
- Leakage controls：goal withheld 时把 goal token 置零；counterfactual goal 时输入错误关系，观察 predicted anchors 跟 false goal 还是 true scene。
- Control：用 CEM 做 8 步 MPC，模型 rollout anchors，planner cost 根据目标关系打分。

修复是 GoalFree：predictor 完全不看 goal，goal 只放进 planner cost，同时监督 read path，使 anchors 必须从视觉/状态读出关系。

## Experiment
核心发现很强：

GoalDyn predicted-anchor accuracy 看似约 0.90，但 goal withheld 后从 0.900+-0.009 降到 0.270+-0.034，接近四分类 chance 0.25。counterfactual goal 下，predicted anchors 94.5% 跟随 false instruction，只有 2.3% 跟随 true scene。GoalFree 在 amb2 上 goal given/withheld 都约 0.88，说明修复后是 instruction-independent grounding。

控制上，goal-conditioning 单调伤害性能：NoGoal 0.30+-0.02，GoalFree 0.29+-0.03，GoalDyn 0.14+-0.02，GoalDyn + goal in rollout 0.03+-0.02，oracle 约 0.71。结论很诚实：GoalFree 没有超过 NoGoal，价值在 grounded perception，而不是控制成功率提升。

外部验证：BabyAI 的 relation-naming instruction 也泄漏，true instruction 得分 1.00、counterfactual 也 1.00；Language-Table 中 instruction 只命名 referents 时不泄漏，加入 direction token 后出现泄漏。action degradation 不会增加 leakage，反驳“只有 action 弱时才泄漏”的替代解释。

## Value
对隐式/JEPA 世界模型方向价值很高。它给出一个容易被忽略但会污染评测的 failure mode：语言目标进入 dynamics 后，表示指标可能测到的是文本捷径而不是世界状态。对我们做语言条件世界模型、空间关系 grounding、planning with latent dynamics 时，goal-withheld/counterfactual probe 应成为必做 sanity check。

## Strengths
- 问题定义尖锐，区分“perception grounding”和“instruction transcription”。
- 检测协议简单有效：withhold goal、counterfactual goal。
- 结论边界诚实：控制只恢复到 NoGoal，不夸大为控制提升。
- 与 JEPA/compact world model、语言条件 planning 直接相关。

## Weaknesses
- 主实验是 2D synthetic tabletop，尚无 3D、真实图像或高维动作验证。
- 多个跨 ambiguity 曲线和 counterfactual probe 是单 seed，seed x ambiguity 覆盖不完整。
- 没有直接 probe 已发布 pretrained 语言条件 world model，因为缺少公开权重。
- 所提 supervised anchors 依赖 slot convention，对 learned anchors 不公平。

## Future Work
作者明确指出：在公开 pretrained world model 上验证泄漏；扩展到 3D/真实图像/高维动作；用 multi-step prediction 和 action calibration 缩小控制与 oracle 的差距；用 mixed-ambiguity training 改善 grounding 的跨 ambiguity 泛化。
