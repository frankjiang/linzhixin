# PhysPPF: Learning Robotic Manipulation with Past, Present, and Future Physical Representations

## Insight
观察：精细操作既需当前 3D 接触几何，也需记住前序子任务和预见短期物理状态；单独加入空间特征或历史容易缺其中一项。推论：在小型 3D 物理 token 空间同时表示过去、现在、未来，且分支注入动作模型，可兼顾成功率与时延。消融中只用当前 token 的 CALVIN 平均链长 4.28，合用三者 4.69；但实验未证明预测的未来 token 对真实动作后果有高保真度。

## Motivation
传统 VLA 多依赖单帧 2D 特征；某些模型加测试时 3D 编码器增加时延，或用视频世界模型生成未来帧而耗费计算。对长链、接触敏感的机器人操作，既有 3D 对齐又有时间记忆的紧凑状态是有价值的研究问题。

## Method
在 StarVLA 的视觉语言骨干旁加入 12 层世界模块。What/Where/How 三组查询各 16 个 token：分别对应全局 3D 结构、指令条件可供性、局部深度与法向；训练时由 VGGT、GLOVER++、Metric3D 生成场监督，推理时丢弃教师与解码器。已执行步骤的当前 token 存入最多 16 槽的因果记忆，相邻相似项合并，另有全局进度状态。非对称注意从当前视觉特征和过去状态分别估计当前 token、预测未来 token；流匹配动作专家通过三条独立门控交叉注意支路读取过去、现在、未来。训练联合动作流匹配与当前/未来 3D 场对齐。

## Experiment
SimplerEnv 四任务平均成功率 79.7%，StarVLA 62.5%，堆方块从 36.5% 到 75.0%；CALVIN ABC→D 平均连续完成长度 4.69 对 3.70，五连成率 87.4% 对 58.1%；LIBERO 平均 98.9% 对 95.4%。去 What/Where/How 后 SimplerEnv 分别为 73.4%/74.8%/77.1%。CALVIN 仅当前物理 token 为 4.28，加过去或未来分别再增 0.22/0.28，三者合用 4.69。单次策略调用 147.38 ms、4.528B 活跃参数，对 StarVLA 128.67 ms、4.320B；均在 RTX 4090 测量。

## Value
训练时蒸馏 3D 几何、推理时只保留紧凑表示，以及过去/未来分支的低时延接入，适合借鉴到 3D 具身世界模型与 VLA 接口。对世界模型本体的预测机制参考较有限，可选读。

## Strengths
三类 3D 线索和三类时间状态均有消融；同骨干 StarVLA 对照明确；跨三项操作基准并报告推理时延。

## Weaknesses
未来 token 由当前与历史推断，未给候选动作条件预测或独立的长时预测误差评测；策略收益可能主要来自训练期 3D 教师，而非真正可用于规划的动力学。几乎只有仿真评测，LIBERO 接近饱和；没有实机和跨机器人验证。

## Future Work
作者未明确列出后续路线；需量化未来物理状态在不同候选动作下的准确性，并验证实机、跨形态与更长任务。

## Rating
创新度评分：3/5 - What/Where/How 与 Past/Present/Future 的紧凑联合设计有系统性，但偏现有 VLA 模块组合。
相关度评分：2/3 (Related) - 涉及 3D 物理 token 与隐式未来状态，但重心是操作策略而非可交互世界模拟。

## TL;DR
以训练期 3D 蒸馏构建紧凑物理 token，并把过去、当前、未来状态接入操作策略；可选读架构。
