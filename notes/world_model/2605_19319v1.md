# SWEET: Sparse World Modeling with Image Editing for Embodied Task Execution

## Insight
核心 insight：密集视频生成对许多操作任务是不必要的——任务进展可用少量关键帧总结。图像编辑模型可作为稀疏视觉世界模型，预测任务级未来状态而非密集视频 rollout。实验对比显示 FLUX-Kontext（图像编辑）比 Wan2.2（视频生成）在关键帧预测上更可靠。

## Motivation
视觉预测用于具身控制时，密集视频生成计算昂贵且非必要。论文提出用图像编辑模型替代视频生成模型进行稀疏视觉规划，降低计算成本同时保持任务关键信息。

## Method
SWEET 框架：(1) 通过连续图像编辑渐进生成任务相关操作关键帧序列（语言指令 + 可选箭头空间引导条件）；(2) 目标条件化扩散动作预测器将相邻关键帧转化为可执行动作块；(3) 混合训练策略（真实 + 编辑目标过滤），减少真实和编辑视觉子目标之间的差距。

## Experiment
DROID 和 RoboMimic 实验。SWEET 在已见和未见场景中改善关键帧预测。实现从顺序关键帧规划到可执行机器人动作的完整管线。与 Wan2.2 的对比显示图像编辑产生更可靠的关键帧。

## Value
"图像编辑作为稀疏世界模型"是一个有趣且未充分探索的方向。相比密集视频世界模型，稀疏关键帧方法在计算效率和任务聚焦性上有优势。对视频世界模型研究提供了一个替代性思路：是否需要预测每一帧？局限：依赖图像编辑模型的能力边界，复杂操作的关键帧序列质量有待验证。
