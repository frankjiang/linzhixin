# Quo Vadis, World Modeling?

## Insight

论文观察到智能体需要的反馈不只“下一物理状态”：一次查询也可能返回执行结果、历史经验、技能、奖励或验证信号，而且这类交互未必推进物理时间。作者据此把世界模型重新定义为 **Agent-Centric Interactive World Proxy**，将状态转移扩展为由 agent 主动查询触发的信息转移，并以“六类代理 × 三层赋能”组织领域。这个视角能解释世界模型如何服务 agent，但把检索器、技能库和 LLM judge 也纳入后，概念边界显著变宽；论文是立场/综述，不提供实验证明。

## Motivation

真实环境交互昂贵、缓慢且危险，经典 state-action-next-state 模型又主要返回物理未来，无法涵盖代码执行、记忆检索、技能建议和结果验证等 agent 所需反馈。如何从“逼真模拟器”转向“对 agent 有用的可交互代理”是值得讨论的研究议程，尤其有助于统一视频、3D、隐式动力学与工具环境。

## Method

作者提出五项评价标准：groundedness、controllability、feedback usefulness、cost/scalability、forward-looking。按输出功能划分六类 World Proxy：动力学代理预测状态演化；空间代理支持 3D/视点查询；执行代理模拟网页、代码或 API 后果；记忆/经验代理检索过往交互；技能代理提供可执行过程；奖励/验证代理评价结果。按作用时机再分 L1 推理期上下文指导、L2 用代理信号训练策略、L3 由真实反馈驱动 agent 与 proxy 共同进化。两轴网格是论文主要产物，没有新模型、损失或训练流程。

## Experiment

无定量实验。论文通过大量既有工作把视频生成、NeRF/3DGS、web/code sandbox、记忆系统、skill library、reward model 和 verifier 映射到分类框架，并讨论不同代理在 L1–L3 的用法。形式化 `s_{ℓ+1}=WP(s_ℓ,u_ℓ)` 只是统一记号，不能验证各种系统共享同一机制；L3 共进化尤其多为前瞻性设想。

## Value

对本方向最有帮助的是把“world model 是否生成像素”改问为“它向 agent 提供了什么可行动信息，以及信息是否值得信任”。六类功能与三层使用方式可作为文献地图和系统设计 checklist。风险是概念扩张过度：如果任何检索、技能或 judge 都是 world proxy，world modeling 与一般 agent infrastructure 的区分会消失，也削弱对动力学、因果性和可组合状态的要求。

## Strengths

- 从 agent 使用价值而非生成模态出发，给出较清晰的横向领域地图。
- 同时覆盖视频/3D、隐式动力学、执行环境、记忆和验证，便于比较异构系统。
- L1/L2/L3 区分推理、训练和共进化，能暴露许多工作只在单一层次使用模型。
- 明确讨论校准不确定性、真实环境路由、reward hacking、安全与信息增益评估。

## Weaknesses

- 定义过宽，memory retrieval、skill guidance 和 reward model 未必建模“世界”或演化规律。
- 缺少系统纳入/排除准则、系统综述流程和定量分析，分类完整性主要依赖作者判断。
- 六类功能可能重叠，例如执行代理也同时产生动力学和奖励信息。
- groundedness 与 forward-looking 标准同部分代理并不天然一致，未解决概念冲突。
- L3 共进化缺少成熟案例与安全机制，路线图多于可操作方法。

## Future Work

作者提出研究真实度与校准不确定性、何时信任代理/何时回到真实环境、对 reward hacking 的约束、安全治理，以及以信息增益和决策改善而非像素相似度评测世界代理。更需要建立窄而可检验的定义和跨代理统一 benchmark。

## Rating

创新度评分：2/5 - “信息转移的世界代理”及二维分类有概念启发，但主要是扩展定义与综述整理，没有新方法或实证。

相关度评分：3/3 (Core) - 直接讨论视频、3D、隐式等世界模型的统一范式与未来路线，对方向判断核心相关。

## TL;DR

把世界模型扩展为六类可交互信息代理并按三层赋能组织，视角有启发但边界过宽，可选读。
