# GigaBrain-WBC-0.5: A Behavior World Model for Robust Whole-Body Control with Environment Interaction

## Insight
把 whole-body tracker 同时训练为 action、next state 与 next behavior-command distribution 的因果预测器，可用预测分布判断外部命令是否脱离可行行为流形，并把它回缩为 best-effort 动作；环境接触因此进入“下一步能做什么”的模型，而非只靠扩大 reference corpus。

## Motivation
现有 humanoid tracker 多在平地训练，遇到缺失支撑、物体和不可能命令时仍盲目跟踪。目标是统一实时控制、terrain interaction、command rejection 和 fall recovery。

## Method
因果 Transformer 联合建模状态—动作—latent behavior command；自动从 retargeted motion 恢复3D接触几何并生成 terrain training；部署时以行为分布对命令做 likelihood/OOD 检测和 retraction，策略仍低延迟闭环。

## Experiment
对三种大规模 tracker，在 standard、terrain、implausible command、fall recovery 四域比较；成功率分别报告 terrain 81.3%（最强基线4.3×）、不可能命令83.1%、跌倒恢复99.3%（16.8×）。有 terrain annotation 人审、扰动/命令阈值分析、Unitree G1 真机和 Maker L01 微调迁移。

## Value
把低层控制器做成预测“可行行为分布”的 behavior world model 很有启发，尤其适合上游 VLA/WAM 的安全接口。

## Strengths
环境接触数据自动化；多种 failure regime 和真机；预测分布直接复用于部署保护；跨机器人迁移。

## Weaknesses
“world model”和 policy 深度耦合，难分辨联合训练各项贡献；主要是短时局部行为而非可规划长 rollout；自动 terrain 仍来自动作库，真实复杂接触覆盖有限。

## Future Work
更丰富物体/地形、长时任务规划、跨 embodiment 零样本及预测分布校准。

## Rating
创新度评分：3/5 - 行为分布兼作控制与可行性保护有明显新意，但仍是专用 humanoid tracker。
相关度评分：2/3 (Related) - 属于隐式行为世界模型和具身控制，非视频/3D生成主线。

## TL;DR
联合预测行为分布并回缩不可能命令，显著增强人形全身控制，值得选读。
