# MoP-JEPA: Hard-Assigned Predictor Mixtures for Stochastic JEPA World Models

## Insight
核心 insight 是：标准 JEPA 用单一回归器预测下一 latent，在随机转移下会学到条件均值或均值方向，而这个“平均未来”可能不是任何真实后继状态。规划需要的是可枚举的多个候选后继，而不是一个折中点。

## Motivation
JEPA/V-JEPA/DINO-WM 类隐式世界模型适合 latent planning，但真实环境常有多模态未来。单输出 predictor、加权 MoE 或单高斯变分预测都可能无法给 graph search/MPC 提供离散有效 successor。论文解决 stochastic transition 下 JEPA predictor 的分支覆盖问题。

## Method
MoP-JEPA 保持 JEPA encoder/EMA target 不变，只把 predictor 换成 K 个 hard-assigned heads 和一个 context-only router。每个 target 选择最近 head 更新，router 只看当前 context 学习哪些 head 活跃，不看真实未来，避免泄漏。损失包括 winner-take-all cosine/squared distance、router cross entropy 和 load balancing。推理时输出 router-gated candidate successor set，供 graph search 使用。作者还提出 realroute：构图后检查路径是否由真实转移组成，避免只看 raw coverage。

## Experiment
OGBench pointmaze/antmaze、视觉 antmaze、ETH/UCY、SVHN、DINO-WM 等验证单输出 collapse 和多头恢复。graph search 中单输出 predictor planAll 约 0.02-0.09，MoP-JEPA 最高 0.85。same-protocol realroute 上，medium/teleport/large 分别为 dense 0.083/0.035/0.016，MDN 0.134/0.039/0.057，MoP-JEPA 0.247/0.192/0.139。pointmaze teleport gated COV-R 为 0.632，precision 0.924；antmaze 和 pixel 观测中增益变弱但仍高于基线。

## Value
对隐式世界模型非常相关：它指出 JEPA predictor 的多模态未来接口问题，并给出简单可插拔修复。更大的启发是评估不能只看 coverage，要验证候选 successor 是否构成真实可执行路径。

## Strengths
问题定义锋利；方法改动小；realroute/precision/codebook/shuffle controls 有效避免虚假覆盖；对 JEPA、MDN、Var-JEPA、M3-JEPA 做了同协议比较。

## Weaknesses
hard assignment 对初始化敏感，hardest maze seed-bimodal；低概率分支常丢失，四分支完整恢复只有 37%；主要实验仍偏低维 maze，视频/机器人尺度闭环收益未证明。

## Future Work
作者指出未来需要处理 rare modes、head-specific learning rates 或 replay，扩展到视频/机器人尺度，并让验证型 planner 消费完整候选集。

## Rating
创新度评分：3/5 - 关键想法来自经典 multiple-choice/WTA，但用于 JEPA successor interface 且评测扎实。
相关度评分：3/3 (Core) - 直接研究 JEPA 式隐式世界模型的多模态预测与规划。

## TL;DR
用硬分配多预测头避免 JEPA 在随机转移中预测均值幻影，隐式世界模型方向值得精读。
