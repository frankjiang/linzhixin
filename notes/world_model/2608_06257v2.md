# MASS: Multiplayer World Models with Authoritative Shared State

## Insight
多人世界不应为每个玩家独立生成像素视图：先以一次全局转移更新权威、类型化共享状态，再按需投影和渲染各客户端，可从架构上消除跨视角状态分叉，并使动力学成本不随视图数增长。实验支持扩展性，但“一致性为零误差”很大程度由共享状态定义保证。

## Motivation
像素式多人世界模型若逐视角生成，会重复计算并产生玩家位置、物体数量和事件不一致；传统游戏服务器有权威状态，却难覆盖学习型复杂环境。作者试图融合两者，问题对大规模交互世界模型关键，也与 3D/视频世界模型的共享场景表征密切相关。

## Method
为每个游戏定义实体 schema 与类型字段。Logic Engine Transformer 每 tick 仅执行一次全局转移；每条实体记录只注意自身前缀和由全局状态/动作构造的局部邻域，配合字段 mask、排序和唯一性约束。随后相机从权威状态投影，U-Net 渲染器按需生成客户端画面。不同游戏复用架构但拥有各自 tokenizer、embedding、权重和显式 schema；因此它更像学习型结构化模拟器，而非从纯视频发现状态。

## Experiment
在匹配的 Snake 设置（128 tick、128²、20k 一步 teacher-forced 样本）中，MASS 的 LPIPS 0.098、状态解析 0.764、事件 F1 0.552、跨视角不一致 0、非法率 0.177；像素自回归基线解析仅 0.128，而结构化基线非法率更低（0.052）。八个游戏的渲染 PSNR 为 23.72–40.24。系统展示 1,024 玩家、4,096 食物、5,121 条记录和 10k recurrent ticks；客户端缺失其他玩家动作时，一致率从延迟 1 tick 的 0.815 降至 8 tick 的 0.429，给定联合动作的 oracle 为 1.0。状态数量/位置准确率仍只有 0.234/0.355。

## Value
论文清楚提出多人世界模型应以“同步对象”而非独立视频为中心，对共享 3D 状态、服务器侧 world state 和按需视图生成有强启发。其扩展性来自正确的系统分解，但泛化复杂自然世界的学习难题被 schema 和特权状态监督部分绕开。

## Strengths
架构目标、复杂度和多人一致性直接对应；同时评估图像质量、结构解析、事件、非法状态和 stall 场景；千人规模与长时递归展示了系统可用性。

## Weaknesses
跨视角状态一致性主要是共享状态的构造性结果，未充分衡量渲染外观的一致；显式 schema、完整类型状态和已知投影是强特权。每游戏单独权重，不能证明跨游戏或开放世界泛化；状态准确率和非法率仍不理想，训练又以一步 teacher forcing 为主，复杂 3D 场景尚未覆盖。

## Future Work
作者希望扩展更复杂游戏、改善长期状态有效性和客户端缺失输入下的同步。进一步应学习 schema/实体发现，验证跨游戏迁移，并在自然 3D 资产、遮挡和大规模网络延迟下测量端到端吞吐与视觉一致性。

## Rating
创新度评分：4/5 - 权威类型状态、局部记录转移和按需渲染形成鲜明的多人世界模型范式，但依赖强结构先验。
相关度评分：3/3 (Core) - 直接研究可扩展、多视角共享状态的交互世界模型。

## TL;DR
MASS 用权威类型状态解耦多人动力学与按需渲染，千人扩展强但依赖显式 schema，值得精读。
