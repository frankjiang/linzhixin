# Reasoning as Pattern Matching: Shared Mechanisms in Human and LLM Everyday Reasoning

## Insight
论文主张人类与 LLM 在日常因果推理中的错误模式都更像 pattern matching，而非抽象 world model。它通过任务错误和 attention head ablation 关联人类/模型错误。

## Motivation
围绕“LLM 是否有 world model”的认知科学争论。问题本身有趣，但不是视频、3D 或隐式控制 world model。

## Method
构造 common-sense reasoning prompts，比较人类与 25 个 LLM 的准确率和错误模式；对 LLM attention heads 做 causal importance/ablation/patching，识别驱动错误的 pattern-matching heads，并用 prompt 中无关细节预测人类错误。

## Experiment
人类平均准确率约 0.71；frontier models 如 Deepseek-R1/GPT-5.2 准确率更高但未必更像人类；gemma-3-27b 与人类类别级错误相关较高。Attention head 实验证明部分 head 的 pattern matching 可解释模型响应，并与人类错误相关。

## Value
对 LLM cognition 有参考，但对目标 world model 技术无贡献。应判为噪声。

## Strengths
亮点是对 LLM cognition 有参考，但对目标 world model 技术无贡献。

## Weaknesses
不足是对 LLM attention heads 做 causal importance/ablation/patching，识别驱动错误的 pattern-matching heads
