# Dueling World Models: Advantage-Style Action Channels for Common-Mode Distractor Rejection

## Insight
动作无关动态会同时进入所有 action-conditioned predictions，淹没微小可控差异；对同一状态的动作预测减去动作均值，能像 dueling value advantage 一样精确消掉 common mode。合成因子、Atari 和 DMC 中 nuisance probe 接近零且可控变化保留，证明该简单 readout 可恢复已存在但未路由的 action channel；一旦干扰运动与动作相关，消除立即失效，边界也被实验准确复现。

## Motivation
JEPA latent world model 在动态背景下可让 prediction loss 持续下降，却对不同动作给出近乎相同未来，导致规划 action-blind。既有分解依赖重建、reward、inverse dynamics 或 segmentation；用零额外监督隔离可控变化是核心且实际的问题。

## Method
将 predictor 写成 passive baseline $B(z)$ 与 action offset $\Delta(z,a)$，有效通道为 $u(z,a)=\Delta(z,a)-\mathbb E_{a'\sim\nu}\Delta(z,a')$，未来 latent 为 $B+u$。离散动作精确枚举，连续动作 Monte Carlo 采样；命题证明有限样本中任何对所有采样动作相同的分量精确抵消。既可训练 AD-JEPA，也可对冻结 RePo/TIA predictor post-hoc 取 centered readout。learned gate 消融退化为均匀缩放，无实际作用。

## Experiment
13×13 FourRooms 中 30 个滚动干扰 cell 使标准 action separation 约 1.28→0.002；centered offset probe $R^2=0.73$，非 centered 约 0，latent MPC 成功率 0.92 vs 标准 0.57。已知因子的 120 个合成设置中 controllable recovery 0.87–0.93、nuisance leakage 约 0；连续动作 $K=16$ Monte Carlo 仍为 0.87/约0。Freeway 在三种 frameskip 的 agent-change probe 为 0.877/0.838/0.795，traffic leak 约0；DMC 三任务独立干扰下 9/9 seeds 保留通道。动作相关干扰下 probe/控制均崩溃，符合理论边界。大规模控制只在 gridworld 成功，DMC 未证明 return 优势。

## Value
工作给 action-conditioned latent dynamics 一个便宜、可解释且可后处理的可控性 readout，适合动态背景和冻结模型诊断。重要提醒是验证 loss 可能偏好 action collapse，模型选择应加入 action separation/controllability；但 centering 只保证去掉已被 offset 表示为 common mode 的内容，并不等同因果可控性识别。

## Strengths
- 一行代数结构、无需 reward/decoder/额外 loss，可用于冻结第三方模型。
- 理论保证、已知因子 probe、自然干扰和控制结果层层对应。
- 主动测量 action-correlated 边界与 learned gate 负结果。
- 区分“信息仍在 full latent”与“未路由到 action channel”。

## Weaknesses
- 思想直接移植 Dueling DQN/causal influence 的动作均值，概念新颖但数学较简单。
- 保证仅消 common mode；训练出的 action interaction 仍可能携带动作无关 nuisance。
- 连续动作需要选择 proposal $\nu$ 和采样预算，行为策略偏置会改变通道含义。
- 规模化 return 优势只在 gridworld，DMC/Atari 主要是 probe 而非闭环控制。
- 反应于 ego action 的其他 agent、reafferent sensor 或接触变化不会被消除。

## Future Work
可扩展多智能体联合/分边际 centering、学习覆盖更好的连续动作 proposal、结合 uncertainty 和长程 rollout，并在真实机器人动态背景中验证控制收益。

## Rating
创新度评分：3/5 - 将 advantage centering 提升为 latent dynamics 通道很巧且证据充分，但核心算子来自已有思想、规模控制未证。
相关度评分：3/3 (Core) - 直接处理 JEPA/latent 世界模型中的动作可控性与干扰鲁棒性。

## TL;DR
动作均值中心化可免费恢复 JEPA 可控通道并拒绝独立干扰，边界清楚、值得精读。
