# JEPA-x: Cross-Predictive Physics Grounding for Forecastable Latent Dynamics

## Insight

观察是：自预测世界模型中的 encoder 与 predictor 联合训练，两者可能共同适配出“对原 predictor 容易预测、却不忠实反映物理演化”的 latent；另一方面，从单帧 latent 能解码物理状态，也不代表该 latent 在动作条件下容易向前预测。由此作者区分 decodability、forecastability 和 control utility，并推断应约束表示的轨迹级演化，而非只监督瞬时内容。JEPA-x 把视觉与 privileged physical state 视为同一动作轨迹的两种视图，让任一模态历史的预测同时匹配两种未来表示。式 (3) 用平行四边形恒等式把四项损失分解为“预测共同未来中心 + 对齐同一未来的两种表示”，给出目标层面的解释；真正的证据来自对照实验：冻结 encoder 后另训相同 predictor，20 步相对 drift 从 0.361 降至 0.104，而直接状态回归虽把位置 $R^2$ 提至 0.991，drift 仍为 0.373、控制仍约 53.7%。

## Motivation

隐式世界模型用 latent rollout 给候选动作排序，核心要求不是某个联合训练 predictor 能拟合 latent，而是表示本身携带可泛化、可预测的动作条件转移结构。既有 JEPA/LeWM 依靠自预测和防坍缩正则，缺少物理轨迹约束；训练期 privileged information 多用于状态回归、蒸馏、单帧跨模态对齐或 asymmetric policy，主要回答“表示编码了什么”，未直接回答“表示怎样随动作演化”。这是 JEPA/Dreamer 类隐式世界模型中的关键问题。论文还需让一套物理接口横跨多种物体和交互，而不能依赖 task-specific label。

## Method

- 视觉基线沿用 LeWM：ViT-Tiny encoder $f_\theta$ 将图像编码为 192 维 $z_t^o$，action-conditioned Transformer predictor $g_\psi$ 用长度 $H=3$ 的 latent/action 历史预测未来；SIGReg 保持表示各向同性、防止坍缩。
- 训练期增加 physical encoder $h_\phi$。统一状态由最多 6 个物体 token、end-effector token 和 learned table token 组成；物体含 $8^3$ pooled SDF 几何、半尺寸、$3\times3$ 旋转与位置，空槽位从 self-attention 与 pooling 中 mask 掉。状态不含速度、接触力、wrench 或 goal-relative 量，运动仍需由历史和动作推断。
- 视觉和物理历史共用同一个 $g_\psi$，动作通过 AdaLN 注入。目标包含四个等权 source-target 项：visual→visual、physical→physical、visual→physical、physical→visual，另对两支分别加 SIGReg。两个未来 target 均由在线 encoder 产生；没有 stop-gradient、EMA encoder 或固定 teacher，$f_\theta,h_\phi,g_\psi$ 联合更新。
- 推理时完全删除 physical encoder，保留与视觉基线相同的 $f_\theta,g_\psi$ 和成本。planner 以预测末端 latent 到目标图像 latent 的距离为代价。多任务实验用无条件 action VAE 的 32 维空间做 z-CEM：每次搜索 5 个 macro-steps、每步 5 个环境动作，300 candidates、30 次 CEM、30 elites，并开环执行 25 个动作后再规划。
- 多任务数据含 22 个 object-task configurations、13 种 assets；一份 clean shard 加四级 action-noise shards，共 29,260 episodes、约 1.44M transitions。所有核心方法共享数据、视觉 backbone、训练 40 epochs 的 schedule 和部署 planner。

创新点是把 privileged physics 从“瞬时监督信号”提升为“在线第二预测视图”，用对应轨迹的对称交叉预测直接塑造 latent transition。目标形式简洁，建立在 LeWM、multi-view alignment 和 privileged learning 之上，属于有实质洞察的新组合，不是全新世界模型范式。

## Experiment

- 单任务使用 LeWM 的 Push-T、OGBench-Block、Two-Room、Reacher；多任务使用 Meta-World 派生套件，单模型覆盖 22 configurations，并按 grasping、insertion、pushing、stacking、placement、tossing 六个 evaluation families 评测。每个训练 seed 有 300 个多任务场景（每 family 50），共 3 seeds；成功由真实 simulator trajectory 判断，而非 latent 距离。
- Forecastability 的口径很关键：冻结各方法的视觉 encoder、丢弃联合训练 predictor，在不重叠 episodes 上另训相同的 3 层宽 512 action-conditioned MLP probe，再基于记录动作自回归 rollout 20 步；每一 horizon 的误差除以 constant-latent/temporal-persistence error，再对 20 步求平均。多任务 JEPA-x drift 为 $0.104\pm0.003$，Visual 为 $0.361\pm0.024$，Regress 为 $0.373\pm0.005$（Table 7、Figure 3）。
- 四个单任务的 drift 均改善：Two-Room 0.503→0.221，OGBench-Block 0.507→0.269，Push-T 0.399→0.258，Reacher 0.313→0.233（Table 1，第 7 页）。PCA 匹配有效秩后差距仍在：约 rank 52 时 JEPA-x/Visual 为 0.121/0.453；即使 $k=8$，JEPA-x 0.214 仍优于 Visual 任一测试宽度（Table 8，第 15 页）。
- 多任务控制平均成功率从 Visual 的 $53.6\pm2.5\%$ 提至 $78.2\pm1.3\%$；六类均提高：insertion 60.7→95.3、grasping 34.0→66.7、stacking 58.7→90.7、placement 54.0→72.7、tossing 79.3→94.7、pushing 34.7→49.3（Figure 4/Table 6）。配对 episode-clustered sign-flip tests 在每 seed 上均有 $p_{MC}\le10^{-5}$。
- Decodability 反例很有说服力：Regress 将 manipulated-object position $R^2$ 从 Visual/JEPA-x 的 0.978 提至 0.991，但 drift 0.373、控制 53.7%，均无改善。直接预测 raw future state 或 delta 也只有 54.4%/51.3% 控制与 0.386/0.359 drift（Table 9，第 18 页），说明收益不只是“监督目标位于未来”。
- 关键消融（Table 3，第 9 页）：Cross-only 无共享 predictor 仍达 drift 0.101/控制 73.0%；Align-only 为 0.158/72.6%；Share-only 仅 0.309/56.7%；pointwise Distill 为 0.516/57.7%；固定错误轨迹配对 Shuffle 崩至 0.540/3.6%，甚至差于 Visual 的 0.361/53.6%。这支持“正确对应最关键，直接 cross-prediction 主要改善 forecastability，共享参数本身贡献有限”。
- 控制并非随 drift 必然改善：单任务 Two-Room 成功率 74.7→94.8、OGBench-Block 64.9→78.7，但 Push-T 94.9→94.1、Reacher 82.7→83.6，后两者与 Visual 基本相同（Table 2，第 8 页）。论文对此作了保守限定。

## Value

该工作把隐式世界模型评估从“联合训练损失低”推进到“冻结表示后是否仍易于预测”，fresh-predictor probe 很值得复用。方法层面的启发是：训练期高质量物理状态未必应该被硬回归为内容标签，更有效的方式可能是让它约束动作条件下的表示演化；而 decodability、forecastability、control 应分开报告。对 JEPA/Dreamer 研究直接有价值，但目前证据只说明 simulator 中的 paired privileged trajectory 是强正则，尚不能保证学到可解释或真实世界通用的物理规律。

## Strengths

- 准确区分 decodability、forecastability 与 control，并设计冻结 encoder、重训 predictor 的直接测量，避免 encoder-predictor 共适配混淆。
- 状态回归、future-state regression、pointwise distill、frame alignment、shared-only、cross-only 和错误配对消融较完整，能定位收益来源。
- 单一模型跨 22 configurations，六类控制均提升；多任务配对统计检验和三 seeds 的口径清楚。
- privileged branch 只在训练期使用，部署架构和推理成本与 Visual 基线一致。

## Weaknesses

- 最强反例是 Push-T：drift 从 0.399 大幅降至 0.258，控制却从 94.9% 略降至 94.1%；Reacher 也只升 0.9 个百分点。Forecastability 只是规划所需的一部分，论文尚未证明 drift 改善如何改变候选动作排序。
- 所有结果均来自 simulator、精确同步的 privileged state 和固定 rigid-body schema；没有真实感知噪声、状态估计误差、非刚体、接触丰富或随机动力学。
- physical encoder 与 visual encoder 都是在线联合优化，physical latent 不是固定、可解释的物理坐标。收益也可能来自正确配对的第二视图正则，而非特定的“物理规律”；缺少用等信息量非物理辅助视图的对照。
- 只在 held-out episodes 上评测，未展示对未见 asset、configuration、动力参数或 camera domain 的 OOD 泛化；引言暗示的 generalization capacity 因而证据不足。
- Forecastability 仍依赖特定 3 层 MLP、20 步 horizon、标准化和 copy-baseline 分母，不是 predictor-independent 的内在量；更长时域或不同 probe family 的排序未验证。
- 训练期增加 physical encoder、四项预测和 simulator state 数据，代价高于 Visual；论文只强调部署等成本，未报告训练开销。三训练 seeds 也不足以覆盖大规模模型方差。

## Future Work

作者明确提出将方法扩展到真实世界观测和更广泛的物理交互，并承认当前依赖训练期 paired privileged trajectories 与固定 rigid-body schema。合理推断的后续工作是：加入 noisy/estimated state 与缺失配对；验证未见资产、动力参数和相机域；扩展至接触、非刚体和随机长时动力学；用多种 fresh predictor 与更长 horizon 校准 forecastability；加入等信息量非物理辅助视图，以区分“物理 grounding”与一般多视图正则；同时报告训练成本和真实机器人闭环控制。

## Rating

创新度评分：3/5 - 轨迹级对称交叉预测和 forecastability/decodability 分离有明确洞察，实验效果与消融较强；但方法建立在 JEPA、跨模态对齐和 privileged supervision 的组合上，且仅在模拟刚体环境验证。
相关度评分：3/3 (Core) - 直接研究 JEPA 式隐式世界模型的动作条件 latent dynamics、rollout 与规划控制，属于核心方向。

## TL;DR

用训练期物理轨迹交叉预测约束JEPA潜在动力学，显著降低漂移并提升控制；值得精读。
